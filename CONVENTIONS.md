# CONVENTIONS.md — Notation Standards

## Purpose

This document establishes consistent notation across all skill materials.
Consistency enables Claude to parse concepts reliably and users to understand
outputs predictably.

---

## Pitch Notation

### Pitch Classes

- **Integers 0–11** as primary notation (C=0, C♯/D♭=1, ..., B=11)
- **Letter names** in musical examples and when clarity demands
- **Boldface** for pitch-class sets: **{0, 4, 7}** = C major triad

### Pitches (with octave)

- Scientific pitch notation: C4 = middle C
- When octave matters, always specify

### Enharmonic Equivalence

- In pitch-class contexts, C♯ = D♭ = 1
- In tonal/functional contexts, preserve spelling for clarity
- Note when enharmonic distinction matters

## Interval Notation

### Pitch-Class Intervals

- **Ordered pitch-class interval** (directed): i(a,b) = (b - a) mod 12
- **Unordered pitch-class interval** (interval class): ic(a,b) = min(i, 12-i)

### Interval Classes

- ic0 through ic6 (ic6 = tritone, self-inverse)
- ic(a,b) = ic(b,a) always

### Traditional Names

- Use alongside integer notation for clarity: "a major third (4 semitones)"
- Standard abbreviations: P5 (perfect fifth), M3 (major third), m3 (minor third)

### Interval Vector

- Six-element vector: [n₁, n₂, n₃, n₄, n₅, n₆]
- nᵢ = count of interval class i in the set
- Example: Major triad {0, 4, 7} has vector [0, 0, 1, 1, 1, 0]

## Set Notation

### Pitch-Class Sets

- Curly braces, integers: {0, 3, 7}
- **Normal form**: Most compact, starting from smallest span
- **Prime form**: Normal form transposed to start on 0, choosing more-packed-left
  variant under T and I

### Forte Numbers

- Reference where established: "set class 3-11 [0,3,7]"
- Format: cardinality-ordinal, e.g., 3-11, 4-27, 6-Z44
- Z-relation indicated by Z in ordinal (related by interval vector)
- Don't rely solely on Forte numbers — they're reference tags, not definitions

### Complement

- Comp(X) = Z₁₂ \ X
- Complement has cardinality 12 - |X|

## Transformation Notation

### Transposition

- **Tₙ** = transposition by n semitones
- Tₙ(x) = (x + n) mod 12
- Applied to sets: Tₙ({a, b, c}) = {Tₙ(a), Tₙ(b), Tₙ(c)}

### Inversion

- **Iₙ** = inversion that maps 0 to n
- Iₙ(x) = (n - x) mod 12
- **I** alone means I₀ (inversion around C/F♯ axis)
- Alternative: Iₓʸ inverts x to y

### Neo-Riemannian Operations

- **P** = Parallel (C major ↔ C minor)
- **R** = Relative (C major ↔ A minor)
- **L** = Leading-tone exchange (C major ↔ E minor)
- Composition: **LR** means "L then R" (left-to-right reading)
- All preserve two common tones

### Uniform Triadic Transformations (UTTs)

- Hook's notation where relevant
- ⟨+, n⟩ = transpose major by n, minor by n
- ⟨−, n⟩ = transpose and flip mode
- Full notation: ⟨σ, m, n⟩ where σ ∈ {+, −}

## Group Notation

### Standard Groups

| Symbol | Group | Order | Musical Use |
|--------|-------|-------|-------------|
| Z₁₂ | Integers mod 12 | 12 | Pitch classes |
| Zₙ | Integers mod n | n | General cyclic |
| Sₙ | Symmetric group | n! | Permutations |
| Dₙ | Dihedral group | 2n | Symmetries of n-gon |
| T/I | Transposition/Inversion | 24 | Pitch-class operations |
| PLR | Neo-Riemannian | 24 | Triadic transformations |

### Group Actions

- Left action default: g · x means "apply g to x"
- Simply transitive: every pair (x, y) has unique g with g · x = y
- Orbit: Orb(x) = {g · x : g ∈ G}
- Stabilizer: Stab(x) = {g ∈ G : g · x = x}

### Generators

- ⟨g₁, g₂, ...⟩ = group generated by elements
- Example: ⟨T₁⟩ = Z₁₂ (transposition generates all)
- Generator of Zₙ: element g where gcd(g, n) = 1

## Geometric Notation

### Voice-Leading Spaces

- **Tⁿ/Sₙ** = n-note chord space (orbifold)
- Points = chords (unordered pitch-class multisets)
- Paths = voice leadings
- T = pitch-class circle (R/12Z)

### Metrics

- **Default**: Taxicab (L¹) metric for voice-leading size
  - Sum of absolute pitch movements
- **Note when**: Euclidean (L²) is used instead
- **Minimal voice leading**: Smallest total motion

### Orbifold Singularities

- Boundary = chords with repeated notes
- Mirror points = perfectly even divisions

## Messiaen-Specific Notation

### Modes of Limited Transposition

- **Mₙ** or **Mode n** = Messiaen's mode number n (n = 1 to 7)
- Superscript for transposition: M₂³ = Mode 2 at third transposition
- As pitch-class set: M₂ = [0, 1, 3, 4, 6, 7, 9, 10]
- Note: M₁ = whole-tone scale, invariant under T₂

| Mode | PC Set | Transpositions | Invariance |
|------|--------|----------------|------------|
| M₁ | [0,2,4,6,8,10] | 2 | T₂ |
| M₂ | [0,1,3,4,6,7,9,10] | 3 | T₃ |
| M₃ | [0,2,3,4,6,7,8,10,11] | 4 | T₄ |
| M₄–M₇ | various | 6 | T₆ |

### Non-Retrogradable Rhythms

- Palindromic sequence: reads same forward and backward
- Notation: Duration values as integers, e.g., [2, 1, 2] or [3, 5, 8, 5, 3]
- Central element may or may not be shared

### Symmetrical Permutations

- Permutation σ with small cycle structure
- Iterate notation: σ, σ², σ³, ... until identity
- Order of permutation noted

### Deçi-Tâlas

- Reference by number: Deçi-tâla No. 58
- Or by name: amphimacer rhythm
- Rhythm as duration sequence: [2, 1, 2]

## Mathematical Typography

### In Markdown (Primary)

- Subscripts: T₁₂ (Unicode subscript) preferred
- Fallback: T_12 or T<sub>12</sub>
- Groups: Z₁₂, Sₙ, Dₙ (Unicode subscript where possible)
- Sets: {0, 4, 7} (curly braces, commas, spaces)
- Functions: f: X → Y

### When Precision Matters (LaTeX)

Use LaTeX notation in code blocks for complex expressions:

```latex
$T^n/S_n$                           % Chord space orbifold
$$\text{int}(s,t) = g \iff g \cdot s = t$$  % GIS condition
$\mathbb{Z}_{12}$                   % Integers mod 12
```

### Display Math

For centered, standalone equations:
```latex
$$\text{ic}(a,b) = \min(|b-a|, 12 - |b-a|)$$
```

## Common Mistakes to Avoid

| Wrong | Right | Why |
|-------|-------|-----|
| T12 | T₁₂ or T₀ | Subscript; T₁₂ = T₀ in Z₁₂ |
| {C, E, G} | {0, 4, 7} | Integers primary in pc context |
| "the interval 4" | "interval class 4" or "ordered interval 4" | Specify ordered vs unordered |
| I (unqualified) | I₀ or specify axis | Clarify inversion index |
| PLR = 24 elements | PLR group has order 24 | Group vs. set of elements |
