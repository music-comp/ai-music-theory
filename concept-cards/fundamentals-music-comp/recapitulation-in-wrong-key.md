# Quick Definition

A technique found occasionally in Beethoven's later works where the recapitulation begins in a key other than the tonic, creating a structural surprise that is subsequently resolved as the tonic is restored.

# Core Definition

"Recapitulation in the wrong key" is a technique that appears occasionally in Beethoven's later works, where the return of the main theme occurs in an unexpected key rather than the tonic. This creates a deliberate structural deception: the listener recognizes the thematic material but is surprised by the harmonic context. The "wrong" key typically has a logical relationship to the preceding modulation. The tonic is eventually restored during the course of the recapitulation.

- **Recapitulation in scherzo**: Understanding the standard recapitulation procedure

# Key Properties

- The main theme returns recognizably but in an unexpected key
- The "wrong" key has a logical relationship to the preceding modulation
- The tonic is eventually restored during the recapitulation
- Creates simultaneous recognition (thematic) and surprise (harmonic)
- Usually occurs when the modulatory process arrives at a key logically related to the theme but not the tonic
- Distinct from "false recapitulation" (premature deceptive return within the development)

# Construction / Recognition

1. Identify the thematic return (recognizable A-section material)
2. Check the key -- if it is not the tonic, it is a "wrong key" recapitulation
3. Trace the relationship between the "wrong" key and the preceding modulation
4. Follow the process by which the tonic is restored

# Context & Application

This technique represents one of Beethoven's most innovative formal procedures. By beginning the recapitulation in the "wrong" key, he achieves a more seamless transition from the modulatory B-section while maintaining the surprise of the theme's return. The Brahms Sextet Op. 36 also features a "false recapitulation" that similarly exploits the listener's expectations.

# Examples

- Beethoven, Symphony No. 7-III: Modulation follows the circle of fifths from mediant major to subdominant, at which point the recapitulation begins in the subdominant rather than the tonic
- Brahms, Sextet Op. 36, Scherzo: False recapitulation beginning in m. 56 or 57; the real recapitulation arrives at m. 69, introduced by the remote minor triad on F-sharp

# Common Errors

- Treating the "wrong key" as an error rather than a deliberate structural device
- Confusing with a "false recapitulation" (which occurs within the development section, not at the actual point of return)

# Common Confusions

- **Wrong key vs. non-tonic beginning**: A wrong-key recapitulation begins the entire theme in a different key; a non-tonic beginning merely starts on a non-tonic chord within the tonic key.
- **Wrong key vs. false recapitulation**: A false recapitulation is a premature, deceptive return within the development; a wrong-key recapitulation is the actual recapitulation, but in the wrong key.
