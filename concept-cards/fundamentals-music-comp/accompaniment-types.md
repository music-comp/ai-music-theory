# Quick Definition

Schoenberg identifies several distinct accompaniment types: chorale-like, figurated (broken chords), intermittent, afterbeat, and complementary, each with specific textural and rhythmic characteristics, with many hybrid cases in practice.

# Core Definition

Beyond the basic chorale-like and figurated types, Schoenberg identifies several additional accompaniment categories. Intermittent accompaniment presents harmony only once per measure or once per several measures, either sustained or as a short chord. Afterbeat harmony places chords on weak beats, including syncopations. Complementary rhythm fills gaps in the melody's movement to maintain the motus. These types may appear in combination, and many hybrid cases exist in practice (Schoenberg, pp. 52-53).

# Key Properties

1. Chorale-like: all voices in the same rhythm (homorhythmic)
2. Figurated: broken chords distributing chorale harmony across time
3. Intermittent: harmony once per measure or less (sustained or short chord)
4. Afterbeat: chords on weak beats, including syncopations
5. Complementary: one voice fills gaps in another's movement, maintaining motus
6. Many hybrid cases combining multiple types
7. Some complementary cases derive from semi-contrapuntal devices

# Construction / Recognition

1. Identify the dominant rhythmic relationship between accompaniment and melody
2. Classify according to the five types (chorale-like, figurated, intermittent, afterbeat, complementary)
3. Note hybrid cases where multiple types combine
4. Match the accompaniment type to the theme's character, harmonic clarity, and instrumental capabilities

# Context & Application

The variety of accompaniment types allows the composer to match the accompaniment precisely to the theme's needs. Intermittent accompaniment provides maximum transparency, afterbeat harmony creates rhythmic vitality, and complementary rhythm ensures continuous motion. The choice should be governed by the theme's character, harmonic clarity requirements, and instrumental capabilities.

# Common Errors

- **Error**: Applying one type rigidly throughout a piece
  **Correction**: Types may change with the theme's character; many passages are hybrids

# Common Confusions

- **Confusion**: Thinking these are rigid categories
  **Clarification**: Many passages combine features of multiple types or shift between them

- **Confusion**: Equating intermittent with weak
  **Clarification**: Even sparse harmonization can be highly effective
