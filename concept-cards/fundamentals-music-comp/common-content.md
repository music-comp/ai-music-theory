# Quick Definition
The unifying principle that all motive-forms within a phrase or theme should be derived from the same basic motive, ensuring logical coherence through shared motivic material.

# Formal Definition
Common content is provided by using motive-forms derived from the same basic motive. It is one of three principal factors (alongside rhythmic similarities and coherent harmony) that contribute to logic in the connection of motive-forms. Motivic features are indicated by brackets and letters in Schoenberg's examples, and detailed analysis reveals many additional relationships to the basic motive.

# Construction/Recognition
Common content is identified by tracing the motivic features shared between successive phrases or motive-forms. Even when variation has produced substantial changes, the underlying derivation from a shared source should be perceivable. Brackets and letter labels can be used analytically to identify shared features.

# Musical Context
Common content is the most fundamental of the three connecting principles because it ensures that all musical material in a piece is organically related. This principle is the practical manifestation of the motive-as-germ concept: if all motive-forms derive from the same basic motive, the piece achieves organic unity.

# Examples
- Exs. 30-34: all phrases derive from a single basic motive, demonstrating common content despite varying degrees of transformation
- Ex. 31: closely related forms where essential rhythmic features are retained and all notes of the basic motive preserved
- Ex. 32: rhythm strictly preserved while intervals and direction change -- still sharing common content through rhythmic identity
- Ex. 34: even far-reaching variations maintain common content, though comprehensibility may be endangered

# Common Confusions
- Common content does not require literal repetition; it requires derivation from a shared source
- The presence of common content does not guarantee comprehensibility; if variations are too remote, the common origin may not be perceivable
- Common content operates at multiple levels: individual notes, rhythmic patterns, contour shapes, and harmonic implications
