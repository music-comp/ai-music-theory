# Quick Definition
Altered or chromatic chords used in place of diatonic ones within sequential passages, which should primarily reinforce the logic of the harmonic progression while observing the quasi-melodic function of the substituted note.

# Formal Definition
Substitutes (altered or chromatic chords) used in sequences create centrifugal harmonic tendencies that may produce modulations. Schoenberg stipulates that substitutes should be used primarily to reinforce the logic of the progression, carefully observing the quasi-melodic function of the substituted note. The substituted note has a directional tendency -- for example, a raised note tends to lead upward, while a lowered note tends to lead downward. These quasi-melodic functions must be respected for the sequence to sound logical and convincing.

# Construction/Recognition
- Altered chords replace diatonic ones within the sequential pattern
- The substituted note has a melodic tendency (raised = upward, lowered = downward)
- This quasi-melodic function must be observed in the voice leading
- Substitutes should reinforce, not undermine, the logic of the harmonic progression
- Use cautiously: they may create unwanted modulation

# Musical Context
Substitute chords enrich the harmonic palette of sequential passages but introduce the risk of modulatory drift. In minor keys, the varying forms of the scale make this risk particularly acute. The student is advised to be careful with substitutes, using them to strengthen logical harmonic connections rather than merely to add color. The raised or lowered tendency of the substituted note connects harmonic practice to voice-leading principles.

# Examples
- The text describes how a substituted raised note tends to lead upward and a substituted lowered note tends to lead downward within sequential patterns

# Common Confusions
- Substitute chords are not arbitrary chromatic alterations; they should serve a logical harmonic purpose.
- The quasi-melodic function of the substituted note (directional tendency) is not optional; it is essential to making the substitution sound convincing.
- Substitutes in minor keys are particularly tricky because the three scale forms already introduce ambiguity about which notes are "diatonic."
