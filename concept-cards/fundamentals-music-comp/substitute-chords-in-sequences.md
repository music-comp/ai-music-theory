# Quick Definition

Altered or chromatic chords used in place of diatonic ones within sequential passages, which should primarily reinforce the logic of the harmonic progression while respecting the quasi-melodic function (directional tendency) of the substituted note.

# Core Definition

Substitutes (altered or chromatic chords) used in sequences create centrifugal harmonic tendencies that may produce modulations. Schoenberg stipulates that substitutes should be used primarily to reinforce the logic of the progression, carefully observing the quasi-melodic function of the substituted note. A substituted raised note tends to lead upward, while a substituted lowered note tends to lead downward. These quasi-melodic functions must be respected for the sequence to sound logical and convincing (Schoenberg, p. 40).

# Key Properties

1. Altered chords replace diatonic ones within the sequential pattern
2. The substituted note has a directional tendency (raised = upward, lowered = downward)
3. This quasi-melodic function must be observed in voice leading
4. Substitutes should reinforce, not undermine, harmonic logic
5. They may create unwanted modulation if not carefully managed
6. In minor keys, the varying scale forms increase the risk of modulatory drift

# Construction / Recognition

1. Identify where diatonic chords could be replaced by altered ones
2. Determine whether the substitution reinforces the harmonic logic
3. Observe the directional tendency of the altered note (raised = up, lowered = down)
4. Follow through on the quasi-melodic implication in subsequent voice leading
5. Assess whether the substitution creates centrifugal tendencies that need balancing

# Context & Application

Substitute chords enrich the harmonic palette of sequential passages but introduce the risk of modulatory drift. The quasi-melodic function of the substituted note connects harmonic practice to voice-leading principles. The student is advised to use substitutes to strengthen logical harmonic connections rather than merely to add color.

# Common Errors

- **Error**: Using substitute chords merely for coloristic effect without considering harmonic logic
  **Correction**: Substitutes should reinforce the logic of the progression

- **Error**: Ignoring the directional tendency of altered notes
  **Correction**: A raised note should lead upward; a lowered note should lead downward

# Common Confusions

- **Confusion**: Thinking substitute chords are arbitrary chromatic alterations
  **Clarification**: They should serve a logical harmonic purpose and respect the quasi-melodic function of the altered note

- **Confusion**: Applying substitutes freely in minor without considering scale-form complications
  **Clarification**: The three scale forms in minor already introduce ambiguity; substitutes add further risk of unintended modulation
