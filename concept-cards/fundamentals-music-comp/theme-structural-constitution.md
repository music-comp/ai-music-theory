# Quick Definition

The structural requirements for a good variation theme: simple harmony, clear phrasing, definite subdivision, closely related motive-forms, and a unifying accompaniment -- because a theme with too many interesting features leaves little scope for variation.

# Core Definition

There are themes which facilitate, and others which impede, the production of variations. Variations are primarily repetitions, which would become intolerable without constant restimulation of the listener's interest. If the theme contains too many and too interesting features, there remains little scope for the additions which a simple theme readily permits. A simple theme will consist of closely related motive-forms, in preference to distant ones. Structurally, the theme should show definite subdivision and clear phrasing, typically in binary or ternary form.

# Key Properties

- Simple harmony, not changing too frequently or irregularly
- Mere interchange of I and V contributes to simplicity
- Closely related motive-forms (not distant ones)
- Clear phrasing and definite subdivision
- Binary or ternary form (passacaglia-like sentence is exceptional)
- A unifying accompaniment facilitates variation; one that changes too much is a handicap
- Shorter/simpler themes allow more variations; longer/more complex themes limit the number
- Many classical variations are based on popular or folk melodies

# Construction / Recognition

1. Assess the harmonic complexity (should be simple and regular)
2. Check motive relationships (should be closely related, not distant)
3. Verify clear phrasing and definite subdivision
4. Identify the form (binary or ternary, rarely passacaglia-like sentence)
5. Evaluate the accompaniment (unifying is better than changing)
6. Consider theme length (shorter themes allow more variations)

# Context & Application

Even a master like Beethoven did not make many variations when the theme was long or complicated (e.g., 6 Variations in F, Op. 34). It may be useful for students to select a theme whose suitability has already been proved in variation sets by master composers. The first variation of the Dressler Variations changes only the accompaniment to a unifying figure, demonstrating the value of a stable accompaniment.

# Examples

- Beethoven, 12 Variations in A, 24 Variations in D, Op. 111-II: Binary theme structure
- Beethoven, Op. 14/2-II, Op. 26-I: Ternary theme structure
- Beethoven, 32 Variations in c minor: Exceptional passacaglia-like theme (eight-measure sentence)
- Beethoven, Diabelli Variations Op. 120: Theme with harmony changing only once in first eight measures
- Beethoven, 6 Variations in F, Op. 34: Long/complicated theme, resulting in only six variations
- Beethoven, 9 Variations on Dressler March: First variation changes only the accompaniment

# Common Errors

- Writing a theme that is too interesting or complex (leaves no room for variation)
- Using distant motive-forms (should be closely related)
- Creating an accompaniment that changes too much

# Common Confusions

- **Simplicity = weakness**: Simplicity in variation themes is a virtue, not a defect -- it provides the necessary room for the variations to add interest.
- **Binary theme vs. small ternary form**: A binary theme may lack real motival contrast or identifiable repetition, distinguishing it from the small ternary.
- **Passacaglia theme**: The eight-measure sentence (as in the 32 Variations in c) is an exceptional case, not the norm.
