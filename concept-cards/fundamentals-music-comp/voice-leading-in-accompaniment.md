# Quick Definition

Piano style does not require strict preservation of the number of voices; the number may vary freely, and individual voices may be doubled in octaves provided the basic voice leading is free from parallel octaves.

# Core Definition

Piano style does not require strict preservation of the number of voices, as in four-part chorale harmony. If a piece starts in three or four parts, this number will be used rather consistently, but sometimes fewer voices are used (as if one or more rested) and sometimes more are used (as in the orchestra, when for a crescendo, accentuation, climax, or other special effect, additional instruments enter) (Schoenberg, p. 53).

If the basic voice-leading is free from parallel octaves, each individual voice can be doubled in octaves, especially if the doubling is consistently maintained.

# Key Properties

1. Number of voices may vary throughout a piece
2. Fewer voices create transparency (as if some voices rest)
3. More voices create fullness for climax, accent, or crescendo
4. Octave doubling permitted if basic voice leading avoids parallel octaves
5. Consistent doubling is preferred over sporadic doubling
6. Bass, melody, and inner voices may all be doubled

# Construction / Recognition

1. Establish a basic number of voices (three or four)
2. Vary the number as the musical context demands (fewer for transparency, more for intensity)
3. When doubling in octaves, ensure the basic framework is free from parallel octaves
4. Maintain doubling consistently through a passage for best effect
5. Use bass doubling for register variety and contrast
6. Double the melody for enhanced projection

# Context & Application

The freedom of voice leading in piano accompaniment reflects the practical realities of keyboard writing. Unlike choral or orchestral writing, piano writing can freely add or subtract voices. This flexibility is essential for dynamic range and textural variety.

# Common Errors

- **Error**: Creating parallel octaves in the basic voice-leading framework
  **Correction**: The underlying framework must be free from parallel octaves; only then can doubling be added

- **Error**: Inconsistent doubling that sounds arbitrary
  **Correction**: Maintain doubling consistently through a passage

# Common Confusions

- **Confusion**: Confusing octave doubling with parallel octaves
  **Clarification**: Doubling reinforces a single voice; parallel octaves are a voice-leading error between independent voices

- **Confusion**: Thinking variable voice count is a defect
  **Clarification**: It is a feature of piano style, not a failure of voice leading
