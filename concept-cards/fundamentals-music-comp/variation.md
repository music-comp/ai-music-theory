# Quick Definition

The process of changing some features of a motive while preserving others, producing new motive-forms that maintain a recognizable relationship to the original while avoiding monotony.

# Core Definition

"Variation means change. But changing every feature produces something foreign, incoherent, illogical. It destroys the basic shape of the motive. Accordingly, variation requires changing some of the less-important features and preserving some of the more-important ones" (Ch. 3, p. 8). "Variation, it must be remembered, is repetition in which some features are changed and the rest preserved" (Ch. 3, p. 9). Through substantial changes, "a variety of motive-forms, adapted to every formal function, can be produced."

# Prerequisites

- **motive** -- Variation operates on the motive and its features (rhythm, intervals, contour, harmony)

# Key Properties

1. Variation means change, but not total change
2. Changing every feature destroys the motive's identity
3. Less-important features are changed; more-important ones preserved
4. Preservation of rhythmic features is particularly effective for coherence
5. Determining feature importance depends on the compositional objective
6. "Variants" (local embellishments without consequences) differ from true variations
7. Multiple features can be varied simultaneously, but the result must remain related to the original

# Construction / Recognition

1. Identify the basic motive and its features (rhythm, intervals, contour, harmony)
2. Determine which features are most important for the compositional context
3. Preserve the more important features while changing the less important ones
4. Ensure the result remains recognizably related to the original
5. Distinguish between "variants" (local embellishments) and true variations (changes with structural consequences)
6. Allow multiple variation methods to operate simultaneously, but avoid making the result "too foreign to the basic motive"

# Context & Application

Variation is the primary compositional technique for generating content from a basic motive. "A motive appears constantly throughout a piece: it is repeated. Repetition alone often gives rise to monotony. Monotony can only be overcome by variation" (Ch. 3, p. 8). Exploration of variation resources is "of great assistance in the acquisition of technical skill and the development of a rich inventive faculty" (Ch. 3, p. 9).

# Common Errors

- **Error**: Changing every feature of the motive at once
  **Correction**: This "destroys the basic shape of the motive" and produces "something foreign, incoherent, illogical"

- **Error**: Treating all changes as equivalent in structural importance
  **Correction**: "Variants" (local embellishments without consequences) are distinct from true variations that drive development

# Common Confusions

- **Confusion**: Equating variation with contrast
  **Clarification**: Variation maintains a perceivable relationship to the original; contrast may involve unrelated material

- **Confusion**: Treating variation as optional decoration
  **Clarification**: Variation is the fundamental mechanism for generating musical content; it is not decorative but structural

- **Confusion**: Believing "variant" and "variation" mean the same thing
  **Clarification**: "Changes of subordinate meaning, which have no special consequences, have only the local effect of an embellishment. Such changes are better termed variants" (Ch. 3, p. 8)
