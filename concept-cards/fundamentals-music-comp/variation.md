# Quick Definition
The process of changing some features of a motive while preserving others, producing new motive-forms that maintain a recognizable relationship to the original while avoiding monotony.

# Formal Definition
Variation means change. But changing every feature produces something foreign, incoherent, illogical -- it destroys the basic shape of the motive. Accordingly, variation requires changing some of the less-important features and preserving some of the more-important ones. Through substantial changes, a variety of motive-forms, adapted to every formal function, can be produced. Variation is repetition in which some features are changed and the rest preserved.

# Construction/Recognition
The features subject to variation include rhythm, intervals, harmony, and contour. Frequently, several methods of variation are applied to several features simultaneously, but such changes must not produce a motive-form too foreign to the basic motive. Preservation of rhythmic features effectively produces coherence, though monotony cannot be avoided without slight changes.

Changes of subordinate meaning, which have no special consequences, have only the local effect of an embellishment. Such changes are better termed "variants" (as distinct from true variations that contribute to development).

# Musical Context
Variation is the primary compositional technique for generating musical content from a basic motive. It operates at every structural level, from the smallest motive-form adjustments within a phrase to the large-scale treatment of themes in variation form. Exploration of the resources of variation develops both technical skill and inventive faculty.

# Common Confusions
- Variation is not the same as contrast; variation maintains a perceivable relationship to the original
- "Variants" (local embellishments with no structural consequences) are distinguished from true "variations" that drive development
- Changing every feature is not variation but destruction of the motive
- Variation is not optional decoration; it is the fundamental mechanism for generating musical content
