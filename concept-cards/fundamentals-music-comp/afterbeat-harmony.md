# Quick Definition

An accompaniment technique where chords are placed on weak beats (including syncopations), creating rhythmic vitality and forward motion through metric displacement.

# Core Definition

Afterbeat harmony, including syncopations, appears in many forms. The chords are placed on weak beats rather than strong beats, creating a characteristic rhythmic profile that contrasts with the principal voice's metric placement. This technique is one of the standard accompaniment types identified by Schoenberg (p. 53).

# Prerequisites

- **Accompaniment function** -- Afterbeat harmony serves the accompaniment's rhythmic function
- **Motive of the accompaniment** -- Afterbeat placement often constitutes the rhythmic identity of the accompaniment motive

# Key Properties

1. Chords placed on weak beats (offbeats)
2. Includes syncopated forms
3. Creates rhythmic vitality and forward motion
4. Contrasts with the melody's metric placement
5. Appears in many forms across the Beethoven sonatas

# Construction / Recognition

1. Place harmonic support on weak beats rather than strong beats
2. May use syncopation (notes sustained across beat boundaries)
3. The pattern should be maintained consistently as an accompaniment motive
4. Coordinate with the melody to avoid rhythmic confusion

# Context & Application

Afterbeat harmony is one of the most common accompaniment techniques in piano music. It creates a characteristic lightness and forward propulsion that contrasts with block-chord or chorale-like accompaniment. When combined with complementary rhythm, it can create continuous textural motion.

# Common Errors

- **Error**: Using afterbeat harmony inconsistently, creating an unclear rhythmic profile
  **Correction**: Maintain the afterbeat placement as a consistent accompaniment motive

# Common Confusions

- **Confusion**: Equating all offbeat accompaniment with afterbeat harmony
  **Clarification**: Afterbeat harmony specifically refers to harmonic support on weak beats, not all offbeat activity
