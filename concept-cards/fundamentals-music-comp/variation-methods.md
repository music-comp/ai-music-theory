# Quick Definition

The specific techniques for altering the rhythm, intervals, harmony, and melody of a motive to produce new motive-forms while maintaining recognizable relationships to the original.

# Core Definition

"All the features of rhythm, interval, harmony and contour are subject to various alterations. Frequently, several methods of variation are applied to several features simultaneously; but such changes must not produce a motive-form too foreign to the basic motive" (Ch. 3, p. 9). Schoenberg catalogs these methods systematically across four domains using a single broken-chord motive (Exs. 17-29).

# Prerequisites

- **motive** -- Must understand the motive and its features
- **variation** -- Must understand the principle of variation before applying specific methods

# Key Properties

1. Four domains of variation: rhythm, intervals, harmony, melody
2. Methods can be combined simultaneously
3. Combined changes must not produce a result "too foreign" to the basic motive
4. Each domain contains multiple specific techniques
5. Schoenberg prefers "ancillary notes" to "embellishing" or "ornamental" notes
6. Exploration of these methods develops both technical skill and inventive faculty

# Construction / Recognition

## Rhythmic Variation Methods (Exs. 17-24)

1. Modifying the length of notes (Ex. 17)
2. Note repetitions (Exs. 11h, i, k, l, n)
3. Repetition of certain rhythmic patterns (Exs. 17l, m, 18c)
4. Shifting rhythms to different beats (Ex. 23)
5. Addition of upbeats (Ex. 22)
6. Changing the metre -- seldom usable within a piece (Ex. 24)

## Intervallic Variation Methods (Exs. 19-23)

1. Changing the original order or direction of notes (Ex. 19)
2. Addition or omission of intervals (Ex. 21)
3. Filling up intervals with ancillary notes (Exs. 18, 20 ff.)
4. Reduction through omission or condensation (Ex. 21)
5. Repetition of features (Exs. 20h, 22a, b, d)
6. Shifting features to other beats (Ex. 23)

## Harmonic Variation Methods (Exs. 25-27)

1. Use of inversions (Exs. 25a, b)
2. Additions at the end (Exs. 25c-i)
3. Insertions in the middle (Ex. 26)
4. Substituting a different chord or succession (Exs. 27a-i)

## Melodic Adaptation (Exs. 28-29)

1. Transposition (Ex. 28)
2. Addition of passing harmonies (Ex. 29)
3. "Semi-contrapuntal" treatment of the accompaniment (Ex. 29)

# Context & Application

These methods form the practical toolkit for composition. "Such exploration of the resources of variation can be of great assistance in the acquisition of technical skill and the development of a rich inventive faculty" (Ch. 3, p. 9). Schoenberg presents them using a single broken-chord motive to show the full range of possibilities systematically, providing a model for compositional practice.

# Common Errors

- **Error**: Applying too many variation methods simultaneously, producing unrecognizable results
  **Correction**: "Such changes must not produce a motive-form too foreign to the basic motive"

- **Error**: Using metre change freely within a piece
  **Correction**: Changing the metre is "a device seldom usable within a piece" (Ch. 3, p. 9)

# Common Confusions

- **Confusion**: Treating the four domains as independent
  **Clarification**: The domains interact; harmonic changes often require melodic adaptation, rhythmic changes affect intervallic content

- **Confusion**: Using "embellishing" or "ornamental" for added notes
  **Clarification**: Schoenberg prefers "ancillary" to avoid "aesthetically misleading and corrupted terms" (Ch. 3, footnote)
