# Quick Definition

In cadential passages, the melody may employ increasingly smaller note values (rhythmic increase, accelerando effect) or increasingly larger note values (rhythmic decrease, ritardando effect), with increase being more common.

# Core Definition

The melody in the cadence parallels changes in the harmony, obeying the tendency of the smallest notes (like an accelerando) or contradicting it by employing longer notes (like a ritardando). Increase of smaller note values is more frequent in cadences than decrease. In some remarkable cases, instead of a simple rhythmic decrease, a "written-out ritardando" appears as an extension of the phrase, effectively lengthening the period beyond its expected boundaries (Schoenberg, pp. 24-25).

# Prerequisites

- **Cadence contour** -- Rhythmic increase/decrease is one component of the cadence contour
- **Tendency of the smallest notes** -- Rhythmic increase follows the tendency; decrease contradicts it

# Key Properties

1. Rhythmic increase (accelerando): progressively smaller note values approaching the cadence
2. Rhythmic decrease (ritardando): progressively larger note values
3. Increase is more frequent than decrease in cadences
4. Written-out ritardando: the slowing creates an actual phrase extension (formal irregularity)
5. Both techniques are compositional (notated), not performance indications

# Construction / Recognition

1. For rhythmic increase: introduce progressively faster note values in the cadential measures
2. For rhythmic decrease: introduce progressively slower note values
3. A written-out ritardando extends the phrase length, not just the tempo
4. Coordinate rhythmic changes with harmonic concentration and melodic simplification

# Context & Application

The choice between rhythmic increase and decrease affects the character of the cadence. Increase creates urgency and drive; decrease creates settling and relaxation. The written-out ritardando is a particularly expressive device that blurs the boundary between rhythmic technique and formal extension.

# Examples

- **Rhythmic increase** (pp. 24-25): Beethoven, Op. 2/1, Adagio, m. 6-7; Op. 2/2-IV, m. 7; Op. 22, Menuetto, m. 7; Ex. 46g, m. 7-8; Exs. 44b, m. 7; 44f, m. 7; 47c, m. 6-7; 49a, m. 7

- **Rhythmic decrease** (p. 25): Ex. 46h, m. 7 (unusual); Exs. 44j and 46f (very conspicuous)

- **Written-out ritardando as extension** (p. 25): Exs. 44f and 47a -- instead of simple rhythmic decrease, the slowing creates an actual extension of the phrase

# Common Errors

- **Error**: Always using rhythmic increase in cadences
  **Correction**: Rhythmic decrease, though less common, can be a more striking and unexpected effect

# Common Confusions

- **Confusion**: Equating rhythmic increase/decrease with accelerando/ritardando performance markings
  **Clarification**: These are compositional techniques built into the notation, not performance indications

- **Confusion**: Thinking a written-out ritardando is the same as simple rhythmic decrease
  **Clarification**: A written-out ritardando actually extends the phrase length, creating formal irregularity
