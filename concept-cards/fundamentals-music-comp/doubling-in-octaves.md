# Quick Definition

The practice of reinforcing a voice by duplicating it an octave higher or lower, permitted when the basic voice leading is free from parallel octaves and especially effective when consistently maintained.

# Core Definition

If the basic voice-leading is free from parallel octaves, each individual voice can be doubled in octaves. This doubling is especially effective when consistently maintained throughout a passage. It can be applied to any voice: bass doubling can produce variety or contrast through change of register; melody doubling is common and enhances projection; inner voice doubling appears more incidentally for special effects (Schoenberg, p. 53).

# Prerequisites

- **Voice leading in accompaniment** -- The basic framework must be free from parallel octaves before doubling is applied

# Key Properties

1. Prerequisite: basic voice leading free from parallel octaves
2. Most effective when maintained consistently
3. Bass doubling: creates register variety and contrast
4. Melody doubling: enhances melodic projection
5. Inner voice doubling: used incidentally for special effects
6. Sporadic doubling may appear for individual accents

# Construction / Recognition

1. Verify the basic voice leading is free from parallel octaves
2. Choose which voice to double (bass, melody, or inner)
3. Maintain doubling consistently through the passage
4. Use bass doubling for register variety between phrases
5. Use melody doubling for enhanced projection at climactic moments

# Context & Application

Doubling in octaves is a fundamental technique of piano writing that distinguishes it from strict four-part chorale harmony. It allows the piano to achieve dynamic range and textural weight that orchestral instruments achieve through multiple players. The contrast between doubled and undoubled passages can itself be a structural device.

# Common Errors

- **Error**: Doubling voices when the basic voice leading contains parallel octaves
  **Correction**: The underlying framework must first be free from parallel octaves

- **Error**: Using sporadic doubling that sounds arbitrary
  **Correction**: Consistent doubling through a passage is more convincing

# Common Confusions

- **Confusion**: Equating doubling in octaves with parallel octaves
  **Clarification**: Doubling reinforces a single voice; parallel octaves are a voice-leading error between independent voices

- **Confusion**: Thinking doubling changes the harmonic content
  **Clarification**: Doubling reinforces what is already present; it does not add new harmonic content
