# Quick Definition

A cyclic system of nine pitch classes combining consonant [037] triads with antitonic [026] trichords (representing dominant sevenths), organized by Matthew Santa and enriched by Harrison with functional discharge analysis.

# Core Definition

The nonatonic system, devised by Matthew Santa, is "a cyclic system made up of consonant triads and 'dominant seventh chords'" using nine pitch classes (Harrison, p. 554). Harrison's example 20.3a shows a three-voice realization: C+ - Eb7 - Ab+ - B7 - E+ - G7 - C+..., where [026] trichords represent dominant seventh chords with the fifth omitted. Santa labeled four such systems by compass directions (following Cohn's hexatonic convention); the "Northern" system has sum class 11 (p. 556). Harrison enriches this system by adding discharge functions (Da, Db, Dc) to model functional resolutions and by grafting the [026] discords onto Cohn's sum-class framework (pp. 562-564).

# Prerequisites

- **Antitonic trichord** — The [026] entities that alternate with [037] triads in the cycle

# Key Properties

1. Nine pitch classes per system (hence "nonatonic")
2. Alternates [037] tonic concords with [026] antitonic discords
3. Adjacent chords maintain voice-leading sum of 0
4. Four nonatonic systems exist, labeled by compass direction
5. (PL)/(LP) cycles apply to both [037] and [026] trichord classes within the system
6. The [026] members also participate in whole-tone relationships
7. Sum-class membership unifies the [037] and [026] trichords within each system

# Construction / Recognition

## To Construct a Nonatonic System

1. Start with a major triad (e.g., C major: C-E-G)
2. Apply Da (standard V7-I resolution) in reverse to find the preceding [026] (G-B-F)
3. Continue alternating [037] and [026] trichords around the cycle
4. The cycle will use exactly 9 of the 12 pitch classes
5. Verify: all members should have the same sum class (mod 12)

# Context & Application

Harrison uses the nonatonic system as a laboratory for reconciling transformational and functional analysis. Santa's original treatment focused on transpositional relationships among members, effectively making all chords functionally equivalent. Harrison re-inscribes the "sensuous differences among the objects" by distinguishing tonic concords from antitonic discords and tracking how discharge functions create directional energy within the system (pp. 554-564).

# Examples

**Northern system (sum class 11)** (p. 556): C+ - Eb7 - Ab+ - B7 - E+ - G7 - C+. Each [037] can discharge from any of the three adjacent [026]s via Da, Db, or Dc.

**Four-voice realization** (p. 554): Santa's example 20.3b adds a bass line of alternating roots and chordal fifths, forming a whole-tone scale. Harrison replaces this with a chromatic bass (example 20.3c), showing that the "new" chromatic notes create additional [026] trichords that intensify functional energy.

**Integration with sum classes** (pp. 562-563): Harrison grafts the [026] extensions onto Cohn's sum-class system (Cohn's figure 3), creating "interior arrows showing paths of communication between class and other classes based on harmonic combinations of antitonic trichords."

# Common Errors

- **Error**: Treating all members of the nonatonic system as functionally equivalent
  **Correction**: Harrison insists on the sensuous distinction between [037] concords and [026] discords

# Common Confusions

- **Confusion**: Confusing nonatonic systems with hexatonic systems
  **Clarification**: Hexatonic systems contain only [037] triads (6 per system); nonatonic systems contain both [037] and [026] (6 of each type, 12 total, using 9 pitch classes)
