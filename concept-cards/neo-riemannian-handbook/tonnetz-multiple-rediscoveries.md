# Quick Definition

Cohn's catalog of the Tonnetz's multiple independent discoveries across centuries, organized by the interval classes (ICs) generating their primary axes, demonstrating that the structure is "so deeply anchored in the nature of the matter" that it was rediscovered at least seven times.

# Core Definition

Cohn opens Chapter 11 by citing Martin Vogel's observation that the Tonnetz "is so deeply anchored in the nature of the matter that it was 'discovered' twice": by Leonhard Euler in 1773 and by Arthur von Oettingen in 1866. Cohn supplements this count with additional 19th-century graphs "that arise from different motivations and display different orientations on the page, but are otherwise equivalent," plus recent rediscoveries in music theory and music psychology. He organizes these into a catalog by the **interval classes generating their primary axes**, revealing that different IC pairings produce structurally distinct but related spatial models, each suited to different analytical purposes.

# Prerequisites

- **Tonnetz**: The general concept of which these are specific instances

# Key Properties

1. **Multiple independent origins**: At least seven independent discoveries across mathematics, music theory, and psychology
2. **IC-based classification**: Different generating ICs produce structurally distinct Tonnetze
3. **Three principal types**: IC4 x IC5 (standard), IC3 x IC4, IC3 x IC5
4. **Three-axis variants**: IC3 x IC4 x IC5 combines all three IC axes
5. **Analytical specialization**: Each type is suited to different analytical questions

# Construction / Recognition

Cohn's catalog organized by generating interval classes (Ch. 11):

| Axes | Theorists | Application |
|------|-----------|-------------|
| IC4 x IC5 | Euler (1773), Oettingen (1866), Riemann, Longuet-Higgins | Just intonation consonances, standard Tonnetz |
| IC3 x IC4 | Weitzmann (1853), Balzano (1980) | Augmented/diminished cycles, hexatonic/octatonic |
| IC3 x IC5 | Vial, Weber, Schoenberg, Lerdahl | Key relationships, regional space |
| IC3 x IC4 x IC5 | Hostinsky (1879), Krumhansl, Hyer, Cohn | Balanced consonances, three-axis hypertorus |

# Context & Application

The catalog establishes that the Tonnetz is not an arbitrary theoretical construction but reflects deep structural properties of the Western pitch system. The repeated independent discovery by scholars working in different fields (mathematics, acoustics, music theory, psychology) and different centuries underscores its fundamental nature. The IC-based classification also clarifies why different scholars have used different Tonnetz orientations and have emphasized different aspects: they are often working with genuinely different (but related) structures generated by different interval pairs.

# Examples

Specific discoveries cataloged by Cohn (Ch. 11):
- **Euler (1773)**: First known Tonnetz, generated by IC4 x IC5, in a mathematical context
- **Weitzmann (1853)**: IC3 x IC4 Tonnetz representing augmented triad as nexus connecting consonant triads
- **Oettingen (1866)**: IC4 x IC5, acoustical matrix for just intonation (independent of Euler)
- **Hostinsky (1879)**: Three-axis version using IC3, IC4, and IC5 simultaneously
- **Balzano (1980)**: IC3 x IC4 in the context of scale theory and equal temperament
- **Krumhansl**: Rediscovery in music psychology through empirical tonal cognition research
- **Hyer, Cohn**: Neo-Riemannian analytical revival using IC3 x IC4 x IC5

# Common Errors

- **Error**: Assuming there is only one "correct" Tonnetz
  **Correction**: Different IC pairings produce distinct but equally valid Tonnetze suited to different analytical questions

# Common Confusions

- **Confusion**: All Tonnetze are equivalent
  **Clarification**: Tonnetze generated by different IC pairings have genuinely different structures; IC4 x IC5, IC3 x IC4, and IC3 x IC5 each highlight different intervallic relationships
