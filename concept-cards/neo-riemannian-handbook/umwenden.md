# Quick Definition

An *Umwenden* ("about-face") is a point in Riemann's analysis where a periodic function is retrospectively reinterpreted — typically where an "8" function (cadential goal) is heard to function instead as a "7" (upbeat to the next cadence) — marking a shift in harmonic center of gravity within a period.

# Core Definition

*Umwenden* (German: "about-face" or "turning around") refers to a moment in Riemann's periodic analysis where the perceived function of a measure changes retrospectively. Burnham describes the key instance: in Op. 31, No. 1, Period III, Riemann "notes an important 'about-face' [*Umwenden*] at measure 36, in which an 8 function is heard to function retrospectively as a 7 function. This is the point at which the passage shifts from a tonic center of gravity to a dominant center of gravity" (p. 451). The Umwenden reveals that periodic functions are not simply fixed labels but can undergo reinterpretation as the harmonic argument unfolds. Riemann "urges the performer to underline this shift with crescendo and allargando" (p. 451), demonstrating the interpretive and performative significance of the analytical observation.

# Key Properties

1. A periodic function is retrospectively reinterpreted (typically 8 becomes 7)
2. Marks a shift in harmonic center of gravity within the period
3. Occurs at the boundary between two harmonic regions (e.g., tonic to dominant)
4. Has performative implications — Riemann suggests performers underline the shift
5. Reveals that function assignment is not purely mechanical but involves interpretive judgment
6. Shows functional equivalence: 8-9 back-relating pairs are analogous to 4-5 back-relating pairs

# Construction / Recognition

## To Identify an Umwenden

1. Look for a moment that initially sounds cadential (an "8" function)
2. Check whether subsequent events recontextualize that moment as preparatory (a "7")
3. The harmonic context shifts — the passage that was closing now points forward to a new cadential goal
4. The pivot point is the Umwenden

# Context & Application

The Umwenden demonstrates the flexibility (or, critics might say, the ad hoc nature) of Riemann's functional assignments. It shows that periodic functions are not simply assigned from a fixed template but respond to the unfolding harmonic argument. Burnham also notes that when the same passage reappears in the coda, "Riemann renumbers this same passage" — the 8-9 pairs become 4-5 pairs, "showing that 4-back5 is analogous to 8-9: both situations provide a back-relating echo to a strong downbeat function" (p. 451, n. 17).

# Examples

**Example 1** (p. 451, Ex. 16.11): Beethoven, Op. 31, No. 1, Period III, m. 36. An "8" function is retrospectively heard as "7" when the passage shifts from tonic to dominant center of gravity. "Each harmonic goal now has its own 8 function: measure 36 is the 8 for the tonic, and the very next measure is the first of four 8-functioning measures on the dominant."

# Common Errors

- **Error**: Treating Umwenden as a fixed analytical label
  **Correction**: It describes a dynamic moment of retrospective reinterpretation, not a static designation

# Common Confusions

- **Confusion**: Thinking Umwenden indicates an error in the analysis
  **Clarification**: It is a feature, not a bug — it demonstrates Riemann's recognition that metric interpretation can be fluid and context-dependent
