# Quick Definition

Harrison's approach to analyzing music in the Phrygian mode, where the lowered second degree replaces the leading tone as the agent of "pivotal" (dominant-like) function, creating a bifurcation between systematic tonal implications and contextual modal behavior.

# Core Definition

Harrison analyzes the Tallis theme (Phrygian mode on G) using dual functional labels. The "top row" reflects systemic function — "the sense that a key-profile algorithm would propose C minor as a strong candidate for background key" (Harrison, p. 567). The "bottom row" shows the rhetorical and structural functions in the Phrygian piece, where "G is the tonal center and it is frequently confirmed through a plagal cadence from C" (p. 567). Charles Smith's preliminary outline of a "Phrygian progression system" places the lowered 2nd degree as the agent of "pivotal" (dominant-equivalent) function, with traditional dominant function weakened (p. 566). The constant fluctuation between major and minor triads on the modal final "contributes mightily to the unease...by creating a modally indistinct but shimmering tonal center" (p. 567).

# Key Properties

1. Lowered 2nd degree replaces the leading tone as pivotal (dominant-like) agent
2. Plagal cadence (C to G) confirms tonal center rather than authentic cadence
3. Dual functional labels needed: systemic (tonal) and contextual (modal)
4. Major/minor fluctuation on the final creates "shimmering" functional ambiguity
5. "The motive power of the chords here is screwed up" — functional attitudes are confused
6. Functional analysis must "pretend that everything is okay" in this environment

# Construction / Recognition

## To Apply Phrygian Functional Analysis

1. Identify the modal final and the Phrygian collection
2. Apply systemic functional labels as if the piece were in a related key (e.g., C minor for G Phrygian)
3. Apply contextual functional labels recognizing the modal final as tonic
4. Identify the lowered 2nd degree as the agent of pivotal function
5. Note where the two label sets conflict — this is where modal chromaticism operates
6. Note major/minor fluctuation on the final as a characteristic Phrygian feature

# Context & Application

Harrison applies this framework to Tallis's theme (used by Vaughan Williams) and to Vaughan Williams's own treatment of the Tallis material. The analysis shows how Vaughan Williams "recognized that the G-major chords can sound like dominants of a key on C yet are clearly acting as tonics of a mode on G" (p. 566). This recognition informed his compositional strategy: restricting the harmonic vocabulary to major and minor triads, maintaining the Phrygian collection, and using neo-Riemannian operations (PLR) for passages where functional analysis loses traction.

# Examples

**Tallis theme** (pp. 566-567): Functional labels in two rows — systemic function suggests C minor; contextual function shows G-Phrygian center. Boxed progressions show where C-minor hearing is strongest. The final "constantly fluctuates between major and minor triads over the G final."

**Smith's Phrygian progression system** (p. 566): Preliminary system with b2 as pivotal agent, v and bVII as pivotal chords, and the paradigmatic progression "intermediate(?) - b2 = pivotal - TONIC."

**Vaughan Williams's compositional strategy** (p. 568): "(1) restricting the chordal vocabulary...to major and minor triads as much as possible. This restriction was a profound discipline for a post-Wagnerian composer writing in 1910."

# Common Errors

- **Error**: Forcing major/minor key analysis onto Phrygian-mode music
  **Correction**: Dual labels are needed; neither the systemic (key) nor the contextual (mode) reading alone is adequate

# Common Confusions

- **Confusion**: Thinking Phrygian mode is simply "minor with a flat 2"
  **Clarification**: The lowered 2nd transforms the entire functional structure — the dominant function is weakened and replaced by a pivotal function based on b2
