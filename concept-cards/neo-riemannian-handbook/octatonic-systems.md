# Octatonic Systems

## Quick Definition

Three non-overlapping collections of eight triads, each generated by the PR (or RP) compound transformation, that partition the 24 major and minor triads along minor-third root relationships.

## Formal Definition

**Octatonic systems** are cyclic structures created by alternating P and R transformations:

### Structure
Each octatonic system contains:
- 4 major triads
- 4 minor triads
- All 8 triads share membership in a single octatonic collection [0134679T]

### The Three Systems
Starting from any major triad and applying PR repeatedly:

| System | Triads (+ = major, - = minor) |
|--------|-------------------------------|
| OCT₀,₁ | C+, C-, Eb+, Eb-, Gb+, Gb-, A+, A- |
| OCT₁,₂ | Db+, Db-, E+, E-, G+, G-, Bb+, Bb- |
| OCT₂,₃ | D+, D-, F+, F-, Ab+, Ab-, B+, B- |

### Cycle Length
- PR (or RP) has **order 8**
- Returns to starting triad after 8 applications
- 3 systems × 8 triads = 24 total

## Relationship to Hexatonic Systems

| Feature | Hexatonic | Octatonic |
|---------|-----------|-----------|
| Generator | LP (or PL) | PR (or RP) |
| Triads per system | 6 | 8 |
| Number of systems | 4 | 3 |
| Underlying scale | [014589] | [0134679T] |
| Root motion | Minor third (chromatic) | Minor third (diatonic feel) |
| Voice leading | 1 semitone per step | 1-2 semitones per step |

### Complementary Partitions
Together, hexatonic and octatonic systems provide:
- Different ways of grouping the 24 triads
- Different cycle structures
- Different compositional possibilities

## Mathematical Properties

### Group Structure
- PR generates the cyclic group Z₈
- The 3 octatonic systems are orbits under PR
- Each system is closed under PR transformations

### Voice-Leading Properties
Within an octatonic system:
- P: 1 semitone displacement
- R: 2 semitones displacement
- PR combined: 3 semitones total (but smooth overall)

### Intersection with Hexatonic
A single triad belongs to:
- Exactly 1 hexatonic system (from LP cycle)
- Exactly 1 octatonic system (from PR cycle)
- These memberships are independent

## Analytical Applications

### Minor-Third Relations
Octatonic systems capture:
- Progressions moving by minor third
- Symmetrical divisions of the octave
- "Coltrane changes" patterns

### Russian/French Traditions
The octatonic scale was favored by:
- Rimsky-Korsakov and his students
- Debussy and Ravel
- Stravinsky and Messiaen

Octatonic triadic cycles appear naturally in this repertoire.

### Cohn's Parsifal Analysis
The Faith Proclamation uses:
- LP cycling within hexatonic space
- PR motion to connect between hexatonic systems
- Octatonic as "bridge" between hexatonic regions

### Exit and Entry
To move between hexatonic systems:
- Apply R (not in LP group)
- This enters a different hexatonic system
- The transition passes through octatonic space

## The Octatonic Scale

### Collection Properties
The octatonic collection [0134679T]:
- 8 pitch classes
- Symmetrical (divides octave into 4 minor thirds)
- Contains 8 major triads + 8 minor triads (each system uses half)

### Scale Degrees
Two forms:
- Half-whole: C-Db-Eb-E-F#-G-A-Bb
- Whole-half: C-D-Eb-F-Gb-Ab-A-B

### Triadic Content
Within one octatonic collection:
- 4 major triads (roots a minor third apart)
- 4 minor triads (roots a minor third apart)
- 4 diminished triads

Only the major and minor triads participate in PR cycles.

## Relationship to Tonnetz

### Octatonic Path on Tonnetz
A PR cycle traces:
- A zigzag path on the Tonnetz
- Combining vertical P moves and horizontal R moves
- The path eventually closes after 8 steps

### Octatonic Region
Unlike hexatonic (a compact region), octatonic:
- Spreads across the Tonnetz
- Connects through minor-third diagonals
- Forms a different geometric pattern

## Common Confusions

- **Octatonic system vs. scale**: The system is 8 triads; the scale is 8 pitch classes
- **PR vs. RP**: These are equivalent (same cycle, different starting direction)
- **Not the same as diminished**: The octatonic scale contains diminished chords, but the triadic system uses only major/minor
