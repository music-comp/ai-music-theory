# Quick Definition

Three non-overlapping collections of eight triads, each generated by the PR (or RP) compound transformation, that partition the 24 major and minor triads along minor-third root relationships.

# Core Definition

**Octatonic systems** are cyclic structures created by alternating P and R transformations on consonant triads. Each system contains 4 major and 4 minor triads whose roots are related by minor thirds, all sharing membership in a single octatonic collection (set class [0134679T]). The PR compound has order 8, generating a cyclic group Z8. Three such systems partition all 24 consonant triads. On the toroidal Tonnetz, octatonic systems appear as bands encircling the torus in a direction perpendicular to the hexatonic tubes. Cohn uses octatonic systems as bridges between hexatonic regions: since moving from one hexatonic system to another requires an R operation (not part of the LP subgroup), the transition passes through octatonic space (Ch. 11).

# Prerequisites

- **PLR transformations**: P and R are the specific transformations that generate octatonic cycles
- **Tonnetz**: The spatial framework on which octatonic systems appear

# Key Properties

1. **PR generation**: Each system is an orbit under the PR subgroup (cyclic group Z8)
2. **Partition**: Three systems partition all 24 consonant triads completely and without overlap
3. **Octatonic collection**: Each system's pitch classes form set class [0134679T]
4. **Minor-third root relationships**: Triads within a system have roots related by minor thirds
5. **Voice-leading**: P moves one semitone, R moves two semitones (not maximally smooth, but still parsimonious)
6. **Independent from hexatonic**: Each triad belongs to exactly one hexatonic and one octatonic system; memberships are independent

# Construction / Recognition

The three octatonic systems:
- **OCT 0,1**: C+, C-, Eb+, Eb-, Gb+, Gb-, A+, A-
- **OCT 1,2**: Db+, Db-, E+, E-, G+, G-, Bb+, Bb-
- **OCT 2,3**: D+, D-, F+, F-, Ab+, Ab-, B+, B-

To generate any system: start from a major triad, apply P, then R, repeating until return (8 steps total).

# Context & Application

Octatonic systems complement hexatonic systems in neo-Riemannian analysis:
- Hexatonic systems organize LP (maximally smooth) motion
- Octatonic systems organize PR (minor-third related) motion
- Movement between hexatonic systems passes through octatonic space via R

Cohn's Parsifal analysis (Ch. 11) uses this complementarity: LP cycling within a hexatonic system creates local coherence, while PR connections serve as bridges to different hexatonic regions.

# Examples

Cohn's analysis of the Faith Proclamation in Wagner's Parsifal (Ch. 11): the passage uses LP cycling within hexatonic space for primary motion, with R operations transitioning between hexatonic systems. These R operations place the music momentarily in octatonic space, serving as "bridges" between hexatonic regions.

# Common Errors

- **Error**: Confusing octatonic system (8 triads) with octatonic scale (8 pitch classes)
  **Correction**: The system is a set of triads; the scale is the pitch-class set [0134679T]

# Common Confusions

- **Confusion**: PR cycles are maximally smooth
  **Clarification**: R involves a whole-tone (2-semitone) displacement, so PR cycles are smooth but not maximally smooth (LP cycles are the maximally smooth ones)

- **Confusion**: Octatonic and hexatonic systems partition differently because they are unrelated
  **Clarification**: They are complementary perspectives on the same 24 triads; each triad has a unique hexatonic and a unique octatonic membership, and these memberships are algebraically independent
