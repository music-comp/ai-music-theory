# Quick Definition

The application of contextual transformational analysis to chromatic sequential passages, where recurring transposition patterns (particularly by minor third) create systematic motion through triadic space, as demonstrated in Cook's analysis of Franck's *Le chasseur maudit*.

# Core Definition

Cook analyzes chromatic sequences in Franck's *Le chasseur maudit* as paths through a contextually defined transformational system. Three ascents by minor-third transposition (Y9 transformations) divide the passage at mm. 273-346: "measures 273-294, B minor to F minor; measures 305-307, Eb minor to A minor; and measures 312-328, F# minor to C minor" (Cook, p. 535). The constituent triads and their transformations are labeled within the X/Y group framework. These transposition schemes interact with modal inflection, cadential interruption, and motivic parallelism (the 5-6 neighboring figure) to create a complex path through the system (pp. 535-542).

# Prerequisites

- **X/Y transformation group** — Provides the algebraic framework for labeling transformations
- **Contextual harmony analysis** — The broader methodology within which sequences are analyzed

# Key Properties

1. Minor-third transposition (Y9) is the primary sequential device in Franck's chromatic passages
2. Modal inflections within sequences engage nodes of the transformational system that transposition alone would miss
3. Cadential interruptions can arrest and redirect sequential motion (e.g., the F#-minor cadence at mm. 308-310)
4. Semitone root motion intrudes into third-dominated contexts, recalling earlier passages
5. The complete chromatic circuit is achieved through the accumulation of multiple sequential passages

# Construction / Recognition

## To Analyze a Chromatic Sequence Transformationally

1. Identify the transposition interval of the sequence (e.g., ascending minor third)
2. Map the sequence onto the contextual transformational system
3. Label each transformation using the appropriate group operation (e.g., Y9 for minor-third transposition)
4. Note where the sequence is interrupted, redirected, or supplemented by modal inflection
5. Track the cumulative path through the system across multiple sequential passages
6. Relate the sequential path to the overall structure of the piece

# Context & Application

Cook's analysis shows how sequences that might seem monotonously predictable in functional terms become dynamically meaningful within a contextual framework. The three minor-third ascents in Franck's piece, combined with interruptions and reversals, create a dramatic narrative: the music's eventual completion of a full circuit through triadic space corresponds to the count's damnation in the program.

# Examples

**First ascent, mm. 273-294** (p. 535): B minor through D minor to F minor via Y9. A 5-6 neighboring figure in brass/winds marks the ascent, reminiscent of the riding fanfare.

**Semitone descent, mm. 295-304** (p. 536): "A new melodic figure in the low brass begins a descent by semitone root motion from F minor to Eb minor" — stepwise root motion intrudes into a third-dominated context.

**F#-minor cadence, mm. 308-310** (p. 537): "Remarkable not simply because it breaks the chromatic sequence but because it does so in a diatonic manner out of character with its surroundings." F# recalls its earlier role as the musical expression of "Turn back!"

**Final circumnavigation, mm. 328-346** (pp. 537-542): Major-third root motion supports the 5-6 figure, transposition by whole tone combines with it, and the final steps through Eb+ to G- "complete the circumnavigation of the system."

# Common Errors

- **Error**: Treating all instances of the same transposition interval as analytically identical
  **Correction**: Context matters — the same Y9 transformation may have different structural significance depending on where it occurs in the system

# Common Confusions

- **Confusion**: Thinking chromatic sequences are merely mechanical
  **Clarification**: Cook shows they create meaningful paths through triadic space, with interruptions and reversals carrying dramatic significance
