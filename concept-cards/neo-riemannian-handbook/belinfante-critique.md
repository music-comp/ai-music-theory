# Quick Definition

The influential objection, originating with Ary Belinfante in 1904, that Riemann's function labels (T, S, D) -- which assign the same names to corresponding chords in major and minor -- contradict the polar opposition fundamental to harmonic dualism, and therefore reveal an "inconsistency" or "reneging" on dualist principles.

# Core Definition

In 1904, Ary Belinfante argued in "De leer der tonalen functieen in conflict met die der polaire tegenstelling" that Riemann's function symbols mark "a reneging on the polarity of major and minor" and regretted that Riemann "lacked the guts to admit to an honest change of heart" (cited in Ch. 5, p. 191).

The argument: If dualism requires that major and minor be polar opposites, then the dominant in minor should be called the subdominant (and vice versa), since the directional relationships reverse. Using the same labels (D for dominant in both modes) treats major and minor as parallel rather than polar.

Klumpenhouwer (Ch. 6) and Riemann (Ch. 5) both refute this critique by showing it applies monist standards to a dualist system.

# Key Properties

1. Belinfante expected function labels to reverse in minor if dualism is consistent
2. The same critique was repeated by Shirlaw (1917) and Dahlhaus (1968)
3. Riemann responded that the labels preserve correct directional meaning through Schritte terminology
4. Klumpenhouwer shows the critique "defines the conditions for consistency with monist, not dualist terms of reference"
5. The critique reveals a common trope: "dualists are closet monists, either lying or confused"

# Construction / Recognition

## The Critique
1. In C major: T=C major, D=G major, S=F major
2. In C minor (dualist): T=°g (C minor), D=°d (G minor)
3. Belinfante: If major and minor are truly polar, shouldn't D in minor = what was S in major?
4. Since Riemann uses D for both, he is treating the modes as parallel, not polar

## Riemann's Response (Ch. 5, pp. 190-191)
1. These functional designations have been standard since Rameau
2. Riemann has always also used Schritte terminology that preserves dualist distinctions
3. T→D in C major = Quintschritt; T→D in C minor = Gegenquintschritt
4. The function labels describe musical function; the Schritte describe theoretical structure

## Klumpenhouwer's Response (Ch. 6, pp. 203-205)
1. The critique projects "monist expectations for how hard dualisms must operate"
2. When proper dualist transformations are used, the systems are properly inversional
3. K-net analysis shows the major and minor function systems have inversionally related network structure

# Context & Application

The Belinfante critique is historically significant because it was widely accepted as damaging to dualism. Dahlhaus used essentially the same argument in *Studies on the Origins of Harmonic Tonality* (1968). Its refutation by Klumpenhouwer is a key part of the rehabilitation of dualism in late 20th-century theory.

# Examples

**Riemann's rebuttal** (p. 191): "I have, right from the beginning, and even in my most recent writings, introduced the clearly defined designations *schlichter Quintklang, Gegenquintklang, Seitenwechselklang*, and the whole terminology of *Schritte* (*Gegenquintschritt*, etc.), in order to clarify the totally different senses of the dominants in major and in minor."

**Klumpenhouwer's formalization**: In C major, T→D = Quintschritt (Q, up a fifth). In C minor, T→D = Gegenquintschritt (-Q, down a fifth in the dualist sense). Same function label, different transformation -- exactly what dualism predicts.

# Common Errors

- **Error**: Accepting the Belinfante critique at face value without examining its assumptions
  **Correction**: The critique assumes monist criteria for dualist consistency; dualism has its own standards

# Common Confusions

- **Confusion**: Function labels being the same in major and minor proves dualism is abandoned
  **Clarification**: The labels name the same functional roles; the underlying Schritte transformations are properly inversional
