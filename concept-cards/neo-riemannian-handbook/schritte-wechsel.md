# Schritte and Wechsel

## Quick Definition

Riemann's systematic vocabulary for triadic transformations: Schritte (steps) connect Klange of the same quality (major-to-major or minor-to-minor), while Wechsel (exchanges) connect Klange of different qualities (major-to-minor or minor-to-major).

## Formal Definition

**Schritte** (singular: *Schritt*, "step"):
Transformations that preserve Klang quality:
- Major to major
- Minor to minor

Named by the interval of root motion:
- **Quintschritt** (Q): Fifth up (c+ to g+)
- **Gegenquintschritt** (-Q): Fifth down (c+ to f+)
- **Terzschritt**: Third up (c+ to e+)
- **Gegenterzschritt**: Third down (c+ to ab+)
- **Ganztonschritt**: Whole step (c+ to d+)
- **Leittonschritt**: Semitone (c+ to db+)
- **Tritonusschritt**: Tritone (c+ to f#+)

**Wechsel** (singular: *Wechsel*, "exchange"):
Transformations that change Klang quality:
- Major to minor or minor to major

Named by the interval relationship:
- **Seitenwechsel** (W): Same root, opposite quality (c+ to °g [C minor])
- **Quintwechsel**: Fifth relation plus mode change
- **Terzwechsel**: Third relation plus mode change
- **Leittonwechsel** (L): Leading-tone exchange

## Historical Context

**Riemann's Comprehensive Taxonomy**:
Riemann developed this vocabulary to name all possible triadic progressions systematically. The system is:
- Complete: Every triadic progression has a name
- Inversionally consistent: Dual transformations apply to both modes
- Theoretically grounded: Based on interval relationships

**The Function Controversy**:
Klumpenhouwer uses Schritte/Wechsel to defend Riemann against Belinfante's critique:

Belinfante argued that function labels (T, S, D) contradict dualism because they work identically in major and minor.

Klumpenhouwer's response: Using Schritte reveals the inversional structure:
- Major: T to D = Quintschritt (Q)
- Minor: T to D = Quintschritt (Q) but with inverted direction

The apparent parallelism is actually proper dualist inversion when Schritte are used.

## Theoretical Framework

**Inversional Properties**:
Schritte and Wechsel preserve inversional relationships:

| In Major | Transformation | In Minor (dualist) |
|----------|---------------|-------------------|
| c+ to g+ | Quintschritt | °g to °d |
| c+ to f+ | Gegenquintschritt | °g to °c |
| c+ to °g | Seitenwechsel | °g to c+ |

The same *Schritt* or *Wechsel* name applies to inversionally related progressions.

**Klumpenhouwer's Examples**:
Example 6.3a (C major):
```
F major <--(-Q)-- C major --(Q)--> G major
   S               T              D
```

Example 6.3b (C minor, dualist):
```
°c <--(-Q)-- °g --(Q)--> °d
Subdominant  Tonic    Dominant
```

Same arrow labels, same Schritte - the inversion is encoded in the Klang notation.

**Relationship to PLR**:
Modern neo-Riemannian P, L, R relate to Riemann's vocabulary:
- P (Parallel) ≈ Quintwechsel/Seitenwechsel
- L (Leittonwechsel) = Leittonwechsel
- R (Relative) ≈ Terzwechsel

But the systems are not identical - Riemann's is more comprehensive.

## Musical Context

**Analytical Application** (Klumpenhouwer on Beethoven):

In analyzing Beethoven's First Symphony:
- Ged (C major context): c+ to g+ = Quintschritt
- Ged' (D minor context): °a to °e = Quintschritt

The "same" transformation in both contexts - this is how dualism manifests as parallelism at the transformation level.

**The Mixed Minor System**:
Riemann's "mixed minor" (harmonic minor) uses Seitenwechsel for the dominant:
```
°a (tonic) --W--> c+ (dominant)
```

This differs from pure minor (°a to °e). The mixed system shows mode mixture as a specific Wechsel.

## Examples

### Basic Schritte

From C major (c+):
```
Quintschritt (Q): c+ --> g+ (up a fifth)
Gegenquintschritt (-Q): c+ --> f+ (down a fifth)
Terzschritt: c+ --> e+ (up a major third)
Gegenterzschritt: c+ --> ab+ (down a major third)
```

### Basic Wechsel

From C major (c+):
```
Seitenwechsel (W): c+ --> °g (same pitch classes, different quality)
Quintwechsel: c+ --> °d (G minor)
Terzwechsel: c+ --> °b (E minor)
Leittonwechsel (L): c+ --> °b (E minor, via leading-tone logic)
```

### Compound Transformations

The dominant seventh resolution:
```
g+ (V) --W--> °d --Q--> c+ (I)
```
Or equivalently:
```
g+ --Seitenwechselschritt--> c+
```

## Common Confusions

1. **Schritt vs. Wechsel**: Schritte preserve quality; Wechsel change it. The root interval alone doesn't determine which applies.

2. **P, L, R vs. Schritte/Wechsel**: Modern neo-Riemannian notation is simpler but loses some of Riemann's distinctions.

3. **"Gegen-" prefix**: Means "counter-" or "opposite" - Gegenquintschritt is opposite direction from Quintschritt.

4. **Minor Klang notation**: °g means C minor (prime on G). The Schritte apply to the prime, not the conventional root.

## Significance for Dualism

Schritte and Wechsel defend dualism because:

1. **Inversional consistency**: The same transformation name applies to inversionally related progressions
2. **Theoretical completeness**: Every possible progression is named
3. **Function compatibility**: Resolves the apparent contradiction between functions and dualism

Klumpenhouwer: "Using the relevant Schritte as arrow labels, the figure provides the necessary logic to defend Riemann's theoretical practice from critiques like Belinfante's."
