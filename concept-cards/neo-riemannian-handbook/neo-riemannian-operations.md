# Quick Definition

The complete group of 24 transformations acting on the 24 major and minor triads, derived from Riemann's Schritt/Wechsel system but reinterpreted as contextual, dualistic operations describing triadic relationships independent of tonal function.

# Core Definition

The complete system comprises 12 **Schritte** (mode-preserving: major-to-major or minor-to-minor, named by root interval) and 12 **Wechsel** (mode-reversing: major-to-minor and vice versa). Following Gollin's notation: Sx = Schritt moving x semitones; Wx = Wechsel with mode-opposed triad x semitones apart. Total: 24 operations (S0 is identity). The group is isomorphic to D12 (the dihedral group of order 24).

PLR are specific Wechsel: **P = W0** (Seitenwechsel), **R = W4** (Terzwechsel), **L = W3** (Leittonwechsel). Compound equivalences: LR = S7 (Quintschritt); RL = S5 (Gegenquintschritt).

# Prerequisites

- **PLR transformations**: The three generating operations for the complete group.

# Key Properties

1. **Schritte preserve mode; Wechsel reverse it**: This is the fundamental distinction
2. **Group of order 24**: Acts on all 24 major/minor triads
3. **Multiple generator sets**: Can be generated by {L, P, R} or {Q, T, W0} or others
4. **Subgroups**: Schritt subgroup Z12; LP subgroup Z6 (hexatonic); PR subgroup Z8 (octatonic)

# Construction / Recognition

Key Schritte and Wechsel (from C+): S7 (Quintschritt) -> G+; S5 (Gegenquintschritt) -> F+; S4 (Terzschritt) -> E+; S3 (Kleinterzschritt) -> Eb+; W0 (Seitenwechsel) -> c-; W4 (Terzwechsel) -> a-; W3 (Leittonwechsel) -> b-.

# Context & Application

Engebretsen (Ch. 12) highlights the crucial difference between Riemann's and neo-Riemannian conceptions: Riemann's Harmonieschritte were subordinate to functional theory, named by acoustic properties, included judgments of "intelligibility," and required tonal context. Neo-Riemannian operations are independent of function theory, privileged by voice-leading parsimony, structurally equal, and derive coherence from transformational logic. This "appropriation" extracts combinatorial structure while abandoning the tonal-functional overlay -- representing what Riemann called his "horror vision" of unconstrained harmonic possibility.

# Examples

**Schritt/Wechsel table** (Engebretsen, Ch. 12): From C+: S0 = C+ (identity); S7 = G+ (Quintschritt); W0 = c- (Seitenwechsel); W4 = a- (Terzwechsel); W3 = b- (Leittonwechsel).

**Kopp's critique** (Ch. 14): PLR obscures the directness of fifth relations. "LR for dominant" misrepresents acoustic/perceptual simplicity. A full set of direct transformations (D, M, m, F, S, P, L, R...) is preferable.

**Doppelklange extension** (Gollin, Ch. 13): Operations extend to dissonant chords understood as combinations of triads, generating specific set classes for post-tonal repertoire analysis.

# Common Errors

- **Error**: Thinking direction is absolute in the Schritt/Wechsel system.
  **Correction**: "Up a fifth" means different directions for major vs. minor triads (dualistic context).

# Common Confusions

- **Confusion**: Assuming all theorists use S/W notation.
  **Clarification**: Some prefer PLR exclusively; others use Hook's Uniform Triadic Transformations.
