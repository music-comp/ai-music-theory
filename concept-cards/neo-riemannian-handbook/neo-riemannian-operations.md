# Neo-Riemannian Operations (Complete System)

## Quick Definition

The complete group of transformations acting on the 24 major and minor triads, derived from Riemann's Schritt/Wechsel system but reinterpreted as contextual, dualistic operations that describe triadic relationships independent of tonal function.

## Formal Definition

The **complete neo-Riemannian system** comprises operations on consonant triads that form a mathematical group of order 24, isomorphic to Riemann's Schritt/Wechsel group.

### The Schritt/Wechsel Framework

**Schritte** (Steps): Mode-preserving transformations
- Transport a major triad to another major triad
- Transport a minor triad to another minor triad
- Named by root interval and direction

**Wechsel** (Exchanges): Mode-reversing transformations
- Map major triads to minor triads and vice versa
- Named by root interval and relationship type

### Riemann's Original Schritte (S) and Wechsel (W)

| Transformation | Description | Example (from C+) | Example (from e°) |
|----------------|-------------|-------------------|-------------------|
| S₀ (Identity) | No change | C+ → C+ | e° → e° |
| S₇ (Quintschritt) | Up fifth | C+ → G+ | e° → a° |
| S₅ (Gegenquintschritt) | Down fifth | C+ → F+ | e° → b° |
| S₄ (Terzschritt) | Up M3 | C+ → E+ | e° → c°# |
| S₃ (Kleinterzschritt) | Up m3 | C+ → Eb+ | e° → c#° |
| S₂ (Ganztonschritt) | Up M2 | C+ → D+ | e° → d° |
| S₆ (Tritonusschritt) | Up tritone | C+ → F#+ | e° → b°♭ |
| W₀ (Seitenwechsel) | Mode change | C+ → c° | e° → E+ |
| W₄ (Terzwechsel) | Relative | C+ → a° | e° → C+ |
| W₃ (Leittonwechsel) | L-related | C+ → b° | e° → F+ |
| W₇ (Quintwechsel) | To fifth's mode-opposite | C+ → g° | e° → A+ |

### Modern S/W Notation
Following Gollin's notation:
- **Sₓ**: Schritt moving x semitones in direction of chord generation
- **Wₓ**: Wechsel with mode-opposed triad x semitones apart

This yields:
- 12 Schritte: S₀, S₁, S₂, ... S₁₁
- 12 Wechsel: W₀, W₁, W₂, ... W₁₁
- Total: 24 operations (S₀ is identity)

## Relationship to PLR

The PLR operations are specific Wechsel:
- **P = W₀** (Seitenwechsel)
- **R = W₄** (Terzwechsel)
- **L = W₃** (Leittonwechsel)

### Compound Equivalences
| PLR Compound | Schritt Equivalent |
|--------------|-------------------|
| LR | S₇ (Quintschritt) |
| RL | S₅ (Gegenquintschritt) |
| LP = PL | W₈ (Gegenkleinterzwechsel) |
| PR = RP | W₉ (Ganztonwechsel) |

## Group Structure

### Generators
The group can be generated by various sets:
- {L, P, R} with relators L² = P² = R² = (LP)³ = (PR)⁴ = (LR)¹² = 1
- {Q, T, ⊕} where Q = Quintschritt, T = Terzschritt, ⊕ = Seitenwechsel
- Any two non-commuting operations plus one exchange

### Isomorphisms
The group is isomorphic to:
- The dihedral group D₁₂
- The semidirect product Z₁₂ ⋊ Z₂
- The symmetric group S₃ × S₂ (alternate presentation)

### Subgroups of Interest
- Schritt subgroup: Z₁₂ (12 mode-preserving transformations)
- LP subgroup: Z₆ (hexatonic cycles)
- PR subgroup: Z₈ (octatonic cycles)

## Neo-Riemannian vs. Riemann's Original Conception

### Points of Departure

**Riemann's Harmonieschritte**:
1. Subordinate to functional theory
2. Named by root interval and acoustic properties
3. Include judgments of "intelligibility"
4. Ultimately require tonal context

**Neo-Riemannian Operations**:
1. Independent of functional theory
2. Privileged by voice-leading parsimony
3. All operations equally valid structurally
4. Coherence from transformational logic

### The "Appropriation" (Engebretsen)
Neo-Riemannian theory:
- Extracts the combinatorial structure from Riemann's system
- Abandons the tonal-functional overlay
- Privileges parsimonious operations (P, L, R)
- Represents what Riemann called his "horror vision" of unconstrained harmonic possibility

### Kopp's Critique
David Kopp argued that:
- PLR obscures the directness of fifth relations
- "LR for dominant" misrepresents the acoustic/perceptual simplicity
- A full set of direct transformations (D, M, m, F, S, P, L, R...) is preferable

## Analytical Applications

### Chromatic Repertoire
The complete system enables analysis of:
- Wagner's harmonic progressions
- Liszt's third-related chains
- Brahms's chromatic experiments
- Any music resisting functional analysis

### Transformation Networks
Operations are composed into networks showing:
- Motivic harmonic patterns
- Symmetrical structures
- Voice-leading trajectories

### Doppelklänge Extension (Gollin)
Riemann's Doppelklänge (double sounds) extend operations to:
- Dissonant chords understood as combinations of triads
- Operations generating specific set classes
- Post-tonal repertoire (Still, Ravel)

## Common Confusions

- **Schritte preserve mode; Wechsel reverse it**: This is the fundamental distinction
- **Direction is contextual**: "Up a fifth" means different directions for major vs. minor triads
- **Not all theorists use S/W notation**: Some prefer PLR exclusively
- **Riemann didn't conceive these as a "group"**: The group-theoretic interpretation is modern
