# Quick Definition

Arthur von Oettingen's original 1866 table of tonal relations, conceived as a literal multiplication table for calculating relative frequencies of tones in just intonation using the expression 5^m x 3^n.

# Core Definition

In *Harmoniesystem in dualer Entwickelung* (1866), Arthur von Oettingen presented a **table of tonal relations** that provided the graphic model for what later became Riemann's Tonnetz. Unlike the later spatial-metaphorical interpretation, Oettingen's table was a **literal acoustical matrix**: a multiplication table where rows represent powers of 5 (major third) and columns represent powers of 3 (perfect fifth), with entries recording the relative frequencies of tones in just intonation. The table served to illustrate the derivation of tones in pure intonation, support Oettingen's dual principles of tonicity and phonicity, and distinguish syntonically distinct tones via *Striche* (comma marks). Gollin emphasizes that in this conception, "the internal relations among entries are subordinated to and mediated by the external organization" of the table's row and column indices (Ch. 9).

# Prerequisites

- **Oettingen's Harmoniesystem**: The broader theoretical framework within which the acoustical matrix was developed
- **Just intonation**: The tuning system assumed by the table, where intervals are derived from simple ratios

# Key Properties

1. **Literal frequency calculator**: Entries represent actual relative frequencies, not abstract pitch classes
2. **Prime-factor organization**: Generated by 5^m x 3^n, where m and n are integer exponents
3. **Infinite extent**: In just intonation, the table extends infinitely in all directions
4. **Syntonic distinction**: Like-named pitches at different positions differ by syntonic commas, marked by Striche
5. **Static conception**: Entries are calculation results, not waypoints on a navigable path

# Construction / Recognition

To construct Oettingen's matrix:
1. Label columns with powers of 3 (fifths): ..., 3^-2, 3^-1, 3^0, 3^1, 3^2, ...
2. Label rows with powers of 5 (major thirds): ..., 5^-1, 5^0, 5^1, ...
3. Each cell contains the product 5^m x 3^n, representing a frequency ratio relative to a reference pitch
4. Apply Striche (underlines/overlines) to distinguish comma-different versions of like-named pitches
5. The table is read as a static reference, not navigated as a space

# Context & Application

Oettingen's acoustical matrix is the historical origin of the Tonnetz. Understanding it is essential for grasping Gollin's central argument in Chapter 9: that the Tonnetz underwent a fundamental epistemological transformation from a "literal-acoustical" object (Oettingen) to a "spatial-metaphorical" one (Riemann). The matrix also provides context for understanding why Striche originally had acoustic meaning (marking real intonational differences) and why enharmonic equivalence was originally rejected.

# Examples

Gollin describes how Oettingen used his table to support his critique of Beethoven's enharmonic modulation in Op. 26's funeral march: a descent by three major thirds leads to Bbb, not A, because the two are an enharmonic diesis apart (128:125, approximately 41 cents). In Oettingen's strict acoustical conception, this was a compositional error because the table records real frequency differences that cannot be collapsed (Ch. 9).

Riemann adopted this same table in his 1873 dissertation "Ueber das musikalische Hören," using it to list 133 distinct intervals within an octave, all distinguished by their position in the multiplication table.

# Common Errors

- **Error**: Treating Oettingen's table as if it were already a Tonnetz in the modern sense
  **Correction**: Oettingen conceived it as a static frequency calculator, not a navigable space; the spatial interpretation was Riemann's later innovation

# Common Confusions

- **Confusion**: Oettingen and Riemann had the same understanding of the table
  **Clarification**: Oettingen maintained a strictly acoustical interpretation throughout; Riemann progressively shifted from acoustical to psychological-metaphorical understanding over several decades
