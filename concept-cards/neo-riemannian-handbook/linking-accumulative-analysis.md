# Quick Definition

Two modes of sensuous-functional analysis for triads related by (PL)/(LP) cycles: linking analysis interprets all triads relative to a single governing tonic, while accumulative analysis treats each successive triad as receiving or giving tonicizing discharge.

# Core Definition

Harrison distinguishes two types of functional analysis for [037] triads in (PL)/(LP) cycles. In **linking analysis**, "one triad has structural superiority and the others are subordinate," with relations analyzed by reference to the governing T (Harrison, p. 558). The subordinate triads appear as "functional mixtures of various D and S components, as well as modal flavorings of T." In **accumulative analysis**, "each triad receives the same kind of harmonic accent," with tonicizations accumulating either retrospectively (second triad receives tonicizing discharge from first) or prospectively (tonicized first charges the second) (p. 558). The choice between these modes depends on "the musical and analytical context."

# Prerequisites

- **Harmonic function** — T, D, S functional categories are essential to both analysis types
- **Harrisonian functional discharge** — Discharge/charge patterns drive accumulative analysis

# Key Properties

1. Linking: one triad is T; others are functional mixtures measured from that T
2. Accumulative: each triad is tonicized in turn; functional character accumulates
3. Accumulative has two subtypes: retrospective (discharge received) and prospective (charge given)
4. Enharmonic/functional reinterpretation occurs in accumulative analysis
5. The choice between linking and accumulative depends on whether one triad dominates hierarchically
6. Both modes can apply to the same (PL)/(LP) cycle with different analytical results

# Construction / Recognition

## To Apply Linking Analysis

1. Identify the structurally superior triad (the governing T)
2. Interpret all other triads as functional mixtures relative to that T
3. Use Harrison's functional attitudes (D, S, modal T flavorings) for each subordinate triad
4. Movement among triads is "always in reference to the governing T"

## To Apply Accumulative Analysis

1. Take each pair of adjacent triads in the cycle
2. Retrospective: hear the second triad as receiving a tonicizing discharge from the first
3. Prospective: hear the first triad as being tonicized by the charge it gives to the second
4. Note enharmonic reinterpretation at each step
5. Track the accumulation of functional character (e.g., subdominant bias)

# Context & Application

Harrison applies both modes to a (PL) cycle starting from E major (example 20.7). The top staff shows linking analysis with E+ as T; the bottom staves show retrospective and prospective accumulations. The accumulative mode proves analytically powerful for the coda of Liszt's Eb piano concerto, where "the coda's typically strong subdominant bias allows us to hear the arrival of each numbered chord...as a tonicized S. The accumulation of these subdominants then discharges through a final plagal cadence to tonic" (p. 559).

# Examples

**Linking analysis of (PL) cycle from E+** (p. 558): E+ is T. C+ is a functional mixture with D and S components. Ab+ is another mixture. Each is measured by its distance from and functional relationship to the governing E+.

**Accumulative analysis of the same cycle** (p. 558): Retrospective: C+ receives tonicizing discharge from E+. Ab+ receives from C+. Prospective: E+ charges C+ with tonic energy. At each step, enharmonic reinterpretation occurs (turn symbol and respelling).

**Liszt, Eb piano concerto, coda** (p. 559): The accumulation of subdominant-function tonics discharges through a final plagal cadence to tonic (mm. 491-492). The cycle is transposed down a chromatic semitone from E+ to Eb.

# Common Errors

- **Error**: Always defaulting to linking analysis
  **Correction**: Accumulative analysis is appropriate when no single triad has clear structural superiority

# Common Confusions

- **Confusion**: Thinking linking and accumulative are incompatible
  **Clarification**: They are different hearings of the same musical material; both may be analytically relevant
