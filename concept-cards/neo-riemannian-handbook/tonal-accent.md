# Quick Definition

One of Riemann's criteria for expressed meter in which the return to tonic is associated with metrical emphasis, linking tonal stability directly to metric accentuation.

# Core Definition

Tonal accent is one of Riemann's five criteria for expressed meter, in which the return to the tonic pitch or tonic harmony creates a sense of metrical accent. As Caplin discusses, this criterion links Riemann's tonal theory (where the tonic is the center of harmonic gravity) to his metric theory (where endings are accented). The return to tonic provides a sense of arrival that reinforces the perception of a metrically strong position. Tonal accent is closely related to both Harmoniewirkung (as a specific case of harmonic change) and Schlusswirkung (as cadential tonic return often coincides with formal closure).

# Prerequisites

- **Expressed meter** — Tonal accent is one of the criteria within the expressed-meter framework
- **Tonality** — The concept of a tonic as center of harmonic gravity

# Key Properties

1. Return to tonic creates perceived metrical accent
2. Functions as an expressed-meter criterion linking tonal and metric hierarchies
3. Closely related to Schlusswirkung (cadential tonic return is both tonal accent and cadential effect)
4. Serves as an "assistant" criterion alongside durational accent and melodic imitation
5. Most effective when tonic return coincides with other criteria (harmonic change, formal closure)

# Construction / Recognition

1. Identify points where the harmony returns to tonic after departure
2. These tonic returns indicate metrically strong positions
3. Tonic return at phrase endings reinforces Schlusswirkung
4. Tonic return at the beat level creates local accent

# Context & Application

Tonal accent illustrates the deep connection between Riemann's harmonic and metric theories. The tonic, as the center of harmonic gravity, naturally correlates with the center of metric gravity (the downbeat, the "8" function). This criterion is less frequently invoked independently than Harmoniewirkung or Schlusswirkung, as tonic returns typically coincide with one or both of those stronger criteria.

# Examples

**Example 1** (p. 430): In a standard T-S-D-T cadential progression, the final tonic return creates both Schlusswirkung and tonal accent simultaneously, reinforcing the metric weight of the cadential goal.

# Common Errors

- **Error**: Treating tonal accent as independent of Harmoniewirkung
  **Correction**: Tonal accent is closely intertwined with harmonic change; it is effectively a special case of Harmoniewirkung focused on tonic return

# Common Confusions

- **Confusion**: Thinking any occurrence of the tonic creates accent
  **Clarification**: Tonal accent is strongest when tonic *returns* after departure; a sustained tonic does not generate ongoing accent
