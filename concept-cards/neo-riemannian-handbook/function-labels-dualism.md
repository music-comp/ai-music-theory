# Quick Definition

Riemann's system of function labels (T for Tonic, S for Subdominant, D for Dominant), which appear to apply identically in major and minor but which Riemann insisted are consistent with dualism because the underlying transformations (Schritte) connecting these functions reverse direction between modes.

# Core Definition

Riemann introduced function symbols (T, S, D, Tp, Sp, Dp, etc.) in *Vereinfachte Harmonielehre* (1893), though the underlying concepts appeared earlier. In his own defense (Ch. 5, pp. 190-191), Riemann asserts:

1. The function labels have been standard since Rameau and are maintained "with the same rights and for the same reasons" as designations like major, minor, Parallele, Grundton
2. He has always ALSO used the Schritte terminology (Gegenquintschritt, etc.) "in order to clarify the totally different senses of the dominants in major and in minor"
3. The function labels describe musical function; the Schritte describe theoretical structure
4. A student may discard the Schritte names once function symbols are learned, but this does not mean "regarding the dominants of major and minor as equivalent"

The coexistence of function labels (seemingly monist) with Schritte terminology (explicitly dualist) reflects the fact that practical harmonic description and theoretical derivation serve different purposes.

# Key Properties

1. T, S, D apply to both major and minor modes
2. In major: T = c+, D = g+ (Quintschritt from T), S = f+ (Gegenquintschritt from T)
3. In minor: T = °g, D = °d (Gegenquintschritt from T), S = °c (Quintschritt from T)
4. The same function labels name inversionally related transformational positions
5. Additional labels: Tp/tP (Tonikaparallele), Sp/sP (Subdominantparallele), etc.

# Construction / Recognition

## Function Labels in Major (C major)
- T = C major (c+)
- D = G major (g+), reached by Quintschritt
- S = F major (f+), reached by Gegenquintschritt
- Tp = A minor (Tonikaparallele)

## Function Labels in Minor (A minor)
- T = A minor (°e, with E as dualist prime)
- D = E minor or E major (°b or e+), reached by Gegenquintschritt or Seitenwechsel
- S = D minor (°a), reached by Quintschritt
- tP = C major (Parallele of tonic)

## The Dual Consistency
- In major: T → D = Quintschritt (up a fifth from root)
- In minor: T → D = Gegenquintschritt (down a fifth from prime)
- Same function, inversionally opposite transformation

# Context & Application

The function labels are the most widely adopted element of Riemann's theory -- they survive in German music theory pedagogy to this day, largely in monist form. The irony is that the element of Riemann's theory that endured is the element most compatible with monism, while the dualist apparatus that motivated it has been largely abandoned in pedagogy.

In neo-Riemannian theory, the PLR system provides an alternative that is fully dualist from the start, avoiding the apparent monism of function labels. But as Klumpenhouwer notes (Ch. 6), the function labels are not actually inconsistent with dualism when the underlying Schritte are properly understood.

# Examples

**Riemann's notation** (p. 191): "The prime of the tonic minor is the same tone as the prime of the dominant major." This shows how the function label D connects to dualist structure: D in minor (°d in A minor) has its prime on the same tone as D in major (d+ in D major), preserving the dualist relationship.

**Riemann's response to critics** (p. 191): "I still stand by my original idea, and the working of function symbols into new editions of earlier books has in no sense given rise to further text revisions other than the necessary obvious indispensable explanation of the new symbols."

# Common Errors

- **Error**: Using function labels as proof that Riemann abandoned dualism
  **Correction**: The labels coexist with the Schritte terminology; they describe function, not derivation

# Common Confusions

- **Confusion**: D means "the same thing" in major and minor
  **Clarification**: D names the same functional role (tension toward resolution) but is reached by inversionally opposite transformations in the two modes
