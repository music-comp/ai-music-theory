# Quick Definition

The analytical condition where a harmonic passage resists assignment to any single diatonic key, requiring either premature key determination (as in Lerdahl's Tonal Pitch Space) or the suspension of regional commitment (as enabled by the Tonnetz), with the latter being a key advantage of neo-Riemannian analysis.

# Core Definition

**Regional indeterminacy** describes passages of music where triadic progressions operate outside the framework of a single diatonic key, making it impossible or analytically premature to assign a tonal center. Cohn (Ch. 11) identifies this as a crucial advantage of the Tonnetz over Lerdahl's Tonal Pitch Space: TPS requires every event to be assigned to a region (key) for its distance metrics to function, while the Tonnetz allows tracking triadic motion without forcing regional commitment. This is especially important for late Romantic chromatic music (Wagner, Liszt, late Brahms) where triadic progressions often traverse multiple regional boundaries within a few measures, or where hexatonic/octatonic cycles create coherent motion that does not "belong" to any single key. The Tonnetz models such passages as paths through triadic space that happen not to be encapsulated within any single regional parallelogram.

# Prerequisites

- **Regional space**: The concept of keys as bounded regions on the Tonnetz
- **Tonnetz**: The spatial framework that allows motion to be tracked without regional commitment

# Key Properties

1. **Analytical validity**: Regional indeterminacy is a legitimate analytical state, not a failure of analysis
2. **Tonnetz advantage**: The Tonnetz handles indeterminacy gracefully; TPS does not
3. **Hexatonic context**: LP cycles often produce regionally indeterminate passages
4. **Octatonic context**: PR cycles similarly span regional boundaries
5. **Sequential passages**: Sequences modulating through multiple keys may be regionally indeterminate at any given point
6. **Retrospective determination**: Some passages become regionally determinate only in retrospect

# Construction / Recognition

Recognize regional indeterminacy when:
1. A passage resists assignment to a single diatonic collection
2. Triadic progressions cross multiple regional boundaries
3. No single tonic emerges as a reference point for the passage
4. Hexatonic or octatonic cycles are the primary organizing logic
5. Forced key assignment would require arbitrary or analytically premature decisions

The Tonnetz handles this by allowing the analyst to track triadic motion (triangle-to-triangle movement) without requiring the regional parallelogram to be positioned.

# Context & Application

Regional indeterminacy is Cohn's principal argument for the Tonnetz's analytical superiority over TPS in the domain of chromatic music. It also helps explain why neo-Riemannian theory emerged when it did: late Romantic music increasingly exploited regionally indeterminate passages, and existing tonal-functional theories (which require key assignment) could not adequately describe them. The Tonnetz provides a spatial model that tracks harmonic coherence (through voice-leading proximity and transformational logic) without requiring tonal-functional coherence (key assignment).

# Examples

Cohn's analysis of Wagner's Parsifal, Faith Proclamation (Ch. 11): The passage cycles through hexatonic space via LP operations. At any given moment, the triadic motion is coherent (each step preserves 2 common tones and moves 1 voice by semitone), but no single key is sustained. The Tonnetz tracks this as a path through triadic space; TPS would require assigning a key to each moment, producing an artificially fragmented analysis.

Cohn also discusses how some passages become regionally determinate only when a cadence or tonal reference point is established, at which point the regional parallelogram "snaps" into position retrospectively.

# Common Errors

- **Error**: Treating regional indeterminacy as meaning "atonal"
  **Correction**: Regionally indeterminate passages may be fully triadic and coherent; they simply resist key assignment. This is a chromatic-tonal condition, not atonality.

# Common Confusions

- **Confusion**: Every chromatically complex passage is regionally indeterminate
  **Clarification**: Many chromatic passages can be analyzed within a tonal framework with chromatic embellishment; true regional indeterminacy occurs when the triadic logic itself operates outside any single key framework
