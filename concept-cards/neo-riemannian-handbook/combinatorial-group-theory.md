# Quick Definition

The mathematical framework treating harmonic relationships as elements of algebraic groups generated by fundamental operations, where all possible relationships arise as combinations ("words") of a few basic transformations.

# Core Definition

**Combinatorial group theory** describes groups via generators (basic elements), relators (constraining equations), words (sequences of generators), and presentations (complete specifications). Engebretsen (Ch. 12) traces a combinatorial tradition from Hauptmann (1853) through Oettingen (1866), Hostinsky (1879), and Riemann, showing how all theorists sought to identify directly intelligible relationships, build complex relationships from simple ones, and classify all possibilities systematically.

The PLR group presentation: L, P, R | L^2, P^2, R^2, (LP)^3, (PR)^4, (LR)^12. This says L, P, R are generators; each is self-inverse; LP has order 3 (hexatonic); PR has order 4 (octatonic); LR has order 12 (chromatic).

# Prerequisites

- **PLR transformations**: The specific generators of the neo-Riemannian group.

# Key Properties

1. **Generators as "bearers of coherence"**: Directly intelligible relationships (fifth motion, third motion, mode change)
2. **Word length as distance**: Number of generator symbols needed measures harmonic proximity
3. **Cayley graphs**: Groups visualized as graphs where path length = word length
4. **Generator choice matters**: Different generators yield different distance measures

# Construction / Recognition

In the {Q, T, +/-} system (Quintschritt, Terzschritt, Seitenwechsel): Quintschritt = Q (length 1); Terzschritt = T (length 1); Ganztonschritt = Q^2 (length 2); Tritonuswechsel = Q^3T+/- (length 5). Shorter words = closer relationship. The Tonnetz approximates a Cayley graph where generators create the lattice and paths represent transformational derivations.

# Context & Application

Engebretsen documents how 19th-century theorists predated formal group theory but worked combinatorially. Oettingen coined "the chaos of possibilities" for the problem: generators combine infinitely, all chords can connect to all others -- how to constrain the chaos? Riemann's solution was function theory as constraint; the neo-Riemannian solution embraces structural logic without functional constraint.

# Examples

**PLR generators**: L, P, R | L^2, P^2, R^2, (LP)^3, (PR)^4, (LR)^12. The relators specify that LP cycles through 6 triads (hexatonic), PR through 8 (octatonic), LR through all 24.

**Word length comparison**: In PLR system, a fifth relation (Quintschritt) requires LR (length 2) -- Kopp's critique is that this misrepresents the directness of the fifth relation. In {Q, T, +/-} system, fifth is length 1.

**Engebretsen's historical documentation**: Her dissertation *The Chaos of Possibilities* (2002) traced pre-Riemannian combinatorial thinking, development of generator-based systems, and connection to formal group theory.

# Common Errors

- **Error**: Assuming 19th-century theorists were doing formal group theory.
  **Correction**: They thought combinatorially without modern algebraic vocabulary; the group-theoretic interpretation is modern.

# Common Confusions

- **Confusion**: Thinking generators are unique for a given group.
  **Clarification**: Different presentations (different generators) describe the same group but yield different distance measures.
