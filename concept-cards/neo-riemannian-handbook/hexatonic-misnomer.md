# Quick Definition

Kopp's argument that the label "hexatonic" is a misnomer when applied to music organized by chromatic third relations, because such music typically does not remain within the hexatonic set defined by its structural triads but instead is locally diatonic or chromatic.

# Core Definition

Kopp observes that "we call music pentatonic, whole tone, diatonic, or octatonic when it takes place largely within individual instances or related groups of those sets. Music organized by chromatic third relations, however, does not normally remain within the hexatonic set defined by its structural triads, but (other than strict triadic sequences) tends to be as locally diatonic or chromatic as its style and surroundings. Thus, in this context, 'hexatonic' seems like a misnomer" (p. 414). The argument challenges a fundamental premise of neo-Riemannian analysis: that the PL cycle, which generates chromatic third relations, operates within "hexatonic systems." Kopp contends this organization is "better understood as one aspect of a greater chromatic tonality, akin to Riemann's *Tonalität*" (p. 414).

# Key Properties

1. Music organized by chromatic third relations rarely stays within the hexatonic set
2. The local harmonic vocabulary is typically diatonic or fully chromatic, not hexatonic
3. Other scale labels (pentatonic, octatonic) describe music that stays within those collections; hexatonic does not
4. The label conflates the structural organization (chromatic mediant cycles) with the local pitch content
5. Chromatic tonality provides a more accurate description of this music

# Construction / Recognition

## To Test Whether "Hexatonic" is Appropriate

1. Identify the structural triads forming a major-third cycle (e.g., C - Ab - E)
2. Check the hexatonic set defined by these triads (e.g., {C, Db, E, F, Ab, A})
3. Examine the local pitch content between structural triads
4. If the local content includes pitches outside the hexatonic set (which it usually does), "hexatonic" is a misnomer

# Context & Application

This critique is important for analytical practice: calling a passage "hexatonic" implies it belongs to a non-tonal organizational system, while calling it "chromatically tonal" implies it functions within an expanded tonal framework. The choice of label carries significant analytical and interpretive consequences.

# Examples

**Example 1** (p. 414): In Beethoven's "Emperor" Concerto III, the descending major-third cycle (C - Ab - Fb) defines a hexatonic set, but the music between these structural triads is locally diatonic, not hexatonic. The passage is better understood as chromatic tonality than as hexatonic organization.

# Common Errors

- **Error**: Labeling any major-third cycle as "hexatonic organization"
  **Correction**: Check whether the music actually stays within the hexatonic set; if not, a different label may be more appropriate

# Common Confusions

- **Confusion**: Thinking the critique invalidates hexatonic analysis entirely
  **Clarification**: Kopp acknowledges "examples of true hexatonic organization certainly exist in the literature" — but argues it is "questionable to assert hexatonicism as the source and identity of the common chromatic third relations" (p. 414)
