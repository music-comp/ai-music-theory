# Quick Definition

The relationship between a major and minor Klang sharing the same root, derived by changing the third while retaining root and fifth. In C major, C minor (Tv) is the Variante of the tonic. This corresponds to the neo-Riemannian P (Parallel) transformation.

# Core Definition

The **Variante** is the third of Riemann's principal tone-relations, alongside the Parallele and Leittonwechsel. It connects a major Klang to the minor Klang on the same root (or vice versa) by changing the third — raising or lowering it by a semitone while retaining root and fifth.

Hyer naturalizes the three tone-relations as "the parallel, variant, and leittonwechsel" (Ch. 3, n. 36), noting that the Variante "has a cognate" in English ("variant"), unlike the Leittonwechsel which has no standard English equivalent.

In Riemann's functional notation, the Variante is indicated by "v": Tv = tonic variant (C minor in C major). The relationship preserves two common tones (root and fifth) while changing the defining quality (major/minor) of the Klang.

# Key Properties

1. Same root and fifth; only the third changes (semitone motion)
2. Connects major and minor Klange sharing a root
3. Two common tones retained (root and fifth)
4. The semitone motion is in the third (the quality-defining interval)
5. Corresponds to the neo-Riemannian P (Parallel) transformation
6. English "parallel" = Riemann's Variante; English "relative" = Riemann's Parallele (terminological trap)

# Construction / Recognition

## To Find the Variante
1. Start with any Klang (e.g., C major: C-E-G)
2. Change the third by semitone (E → Eb)
3. Result: C-Eb-G = C minor = Tv in C major

## Terminological Warning
- Riemann's **Parallele** = English "relative" (C major ↔ A minor)
- Riemann's **Variante** = English "parallel" (C major ↔ C minor)
- Neo-Riemannian **P** = Riemann's Variante
- Neo-Riemannian **R** = Riemann's Parallele

# Context & Application

Hyer discusses the Variante as one of three operations that each change one component of a Klang while retaining two (Ch. 3, pp. 107-108):

| Tone-Relation | Changes | Retains | Common Tones |
|---------------|---------|---------|--------------|
| Parallele | Fifth | Root, Third | 2 |
| Variante | Third | Root, Fifth | 2 |
| Leittonwechsel | Root | Third, Fifth | 2 |

The Variante is particularly important for Riemann's concept of the "major-minor key" — a unified tonal space encompassing both modes. Modal mixture (borrowing chords from the parallel minor/major) is formalized through the Variante relation.

# Examples

**Example 1**: In C major: Tv = C minor (C-Eb-G), Sv = F minor (F-Ab-C), Dv = G minor (G-Bb-D).

**Example 2**: The neo-Riemannian P transformation between C major and C minor is the formalization of Riemann's Variante relation.

# Common Errors

- **Error**: Using "parallel" to mean Riemann's Parallele
  **Correction**: In Riemannian terminology, "Parallele" means English "relative"; "Variante" means English "parallel" (same-root mode change)

# Common Confusions

- **Confusion**: Believing the Variante is the same as the neo-Riemannian P
  **Clarification**: In Riemann's system, Tv is a *functional representative* (C minor represents tonic function in modified form). In neo-Riemannian theory, P is an autonomous operation without functional hierarchy.
