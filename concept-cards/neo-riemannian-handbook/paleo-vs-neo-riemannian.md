# Quick Definition

A systematic comparison between Riemann's own analytical practices ("paleo-Riemannian") and the modern neo-Riemannian theory that appropriated his name, revealing deep divergences in methodology, ideology, and analytical goals despite shared formal structures.

# Core Definition

Rings compares Riemann's analysis of Schubert's Gb-major Impromptu (from *Musikalische Syntaxis*, 1877) with a neo-Riemannian analysis inspired by Cohn. The comparison reveals that "the central focus is not on the analytical technologies, but rather on the assumptions and values that underlie the distinct analytical perspectives" (abstract, p. 488). Riemann's analysis is centered on function theory (T, S, D), monotonality, and containment of chromaticism within universal tonal laws. Neo-Riemannian analysis is centered on voice-leading parsimony, regional or cyclic structures (hexatonic systems, Weitzmann regions), and valorization of tonal disruption (pp. 488-498).

# Prerequisites

- **Harmonic function** — Riemann's function theory (T, S, D) represents the paleo-Riemannian paradigm
- **PLR transformations** — Neo-Riemannian operations represent the new paradigm

# Key Properties

1. **Technology**: Riemann uses function labels with modifications; neo-Riemannians use transformational labels and regional analysis
2. **Tonic**: Riemann presupposes a governing tonic ("monotonality"); neo-Riemannians can operate without one
3. **Starting point**: Riemann begins with normative passages; neo-Riemannians begin with exceptional ones
4. **Goal**: Riemann demonstrates conformance; neo-Riemannians reveal voice-leading coherence
5. **Chromatic passages**: Riemann contains them; neo-Riemannians valorize them
6. **Shared values**: Both seek systematization, logical rigor, and detection of order

# Construction / Recognition

## To Compare Paleo- and Neo-Riemannian Analyses

1. Identify the same passage as analyzed by both paradigms
2. Note what each takes as the starting point and what it treats as incidental
3. Compare the vocabulary: function labels (T, S, D) vs. transformational labels (P, L, R, regions)
4. Assess the role of the tonic: governing center vs. absent/attenuated
5. Identify the analytical product: demonstration of order vs. revelation of coherence in apparent disorder

# Context & Application

The comparison is anchored in a specific analytical case: Schubert's Impromptu in Gb, D. 899, no. 3. Riemann analyzed this piece as a young man in 1877; Cohn's neo-Riemannian framework provides the modern alternative. Rings focuses not on "which analysis is better" but on "what each values" — the methodological and ethical contrasts between approaches. His chapter ends by proposing a technical rapprochement that might "open ethical horizons and provide new ways to value music through Riemann-inspired analytical activity" (abstract, p. 488).

# Examples

**Riemann's analysis of the Impromptu** (pp. 490-493): "A formally quite lucidly organized composition" in which "the controlling force of the main tonic" governs throughout. The G-minor chord at m. 80 is a passage to the "antilogic-antinomic Terztonart" — an extremely distant chord that Riemann mentions only briefly, stressing the "wholly excellent effect" of the tonal consolidation that follows.

**Neo-Riemannian analysis** (pp. 494-496): The piece's coda (mm. 78-82) is the analytical starting point. Triads around m. 80 lie within a single Weitzmann region, sharing common tones with the augmented triad {Db, F, A}. The analysis reveals voice-leading coherence (AVLS consistency) independent of tonal function.

**Riemann's function label for m. 80** (p. 497): Requires three modifications to basic S — the triply-modified label "betrays an anxiety, an attempt to contain the harmonic extravagance within the systematic framework."

# Common Errors

- **Error**: Treating neo-Riemannian theory as a simple update or correction of Riemann
  **Correction**: The theories have fundamentally different goals, values, and starting assumptions

# Common Confusions

- **Confusion**: Believing Riemann's analysis is "wrong" and neo-Riemannian analysis is "right"
  **Clarification**: Both analyses are internally coherent; they reveal different aspects of the music and reflect different analytical values

- **Confusion**: Assuming "paleo-Riemannian" refers to Riemann's earliest work
  **Clarification**: "Paleo-Riemannian" is Rings's term for Riemann's overall analytical practice (especially function theory), as opposed to the modern appropriation of his name
