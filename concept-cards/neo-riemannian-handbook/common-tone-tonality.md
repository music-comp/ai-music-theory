# Quick Definition

A system of tonal organization in which harmonic coherence is maintained primarily through common-tone connections between chords rather than through fifth-based functional progressions, enabling chromatic mediants to function as stable harmonic entities within an expanded tonal framework.

# Core Definition

Common-tone tonality is Kopp's term for a mode of tonal organization where "the functionality of chromatic mediants... is allowed as part of a system of chromatic or common-tone tonality" (p. 406). In this system, "chromatic mediants may occupy a stable position in harmonic space distinct from their diatonic counterparts, defined less by scale degree than by the constellation of intervallic relations between roots, voice-leading content, and qualitative harmonic change, in ways strongly analogous to, but separate from, functional fifth relations" (p. 406). The shared common tone between a tonic and its chromatic mediant provides the thread of tonal continuity.

# Prerequisites

- **Chromatic mediant** — The primary harmonic relationships operating within common-tone tonality

# Key Properties

1. Common tones between successive chords provide the primary thread of tonal continuity
2. Chromatic mediants function as stable, independent harmonic entities, not merely as altered diatonic chords
3. The system operates "in ways strongly analogous to, but separate from, functional fifth relations"
4. Each chromatic mediant type shares exactly one common tone with the tonic
5. Common-tone connections enable smooth voice-leading between otherwise distant harmonies
6. The system coexists with (does not replace) fifth-based functional tonality

# Construction / Recognition

1. Identify chord progressions where successive chords share one or more common tones
2. Note whether the common-tone connection substitutes for a fifth-based functional progression
3. Check whether chromatic mediants occupy structurally stable positions (not merely passing)
4. Assess whether the common-tone thread maintains tonal orientation across the passage

# Context & Application

Kopp invokes common-tone tonality specifically to explain passages where "conventional harmonic analysis falls short" (p. 404) but where the music remains perceptibly tonal. The concept is especially relevant for nineteenth-century chromatic progressions (Beethoven, Schubert, Wolf) where chromatic mediant cycles create coherent harmonic trajectories through common-tone connections. Riemann himself "was to attribute not only tonal meaning but independent functional status to these chromatic mediants" in his 1917 publication (p. 401).

# Examples

**Example 1** (pp. 405-407): Schubert, Piano Sonata D. 850, I. The progression F major - C# major is explained through common-tone tonality: "The individual chords can be best understood tonally if the functionality of chromatic mediants... is allowed as part of a system of chromatic or common-tone tonality" (p. 406).

**Example 2** (p. 403): Beethoven, "Emperor" Concerto, III. The descending major-third cycle C - Ab - Fb maintains common-tone connections: "the LFM alone contains a leading-tone progression to the goal chord" and "preserves the tonic of the first chord as common tone into the second" (p. 403).

# Common Errors

- **Error**: Treating common-tone connections as merely incidental voice-leading
  **Correction**: In common-tone tonality, shared tones are structurally significant, providing the primary thread of tonal continuity

# Common Confusions

- **Confusion**: Thinking common-tone tonality replaces fifth-based functional tonality
  **Clarification**: The two systems coexist and interact; common-tone tonality provides an additional dimension of tonal coherence in chromatic passages
