# Quick Definition
A well-defined melodic segment insistently repeated, providing tonal clarity and rhythmic drive while other voices move freely, with register determining whether the effect is foundational, obstinate, or obtrusive.

# Core Definition
An **ostinato** is a well-defined melodic segment insistently repeated. Unlike pedal point which sustains single tones, the ostinato maintains a complete melodic pattern. The tonal simplicity of ostinato helps clarify the texture of polytonal writing. The ostinato becomes melodically obstinate in an upper voice and obtrusive in a middle voice. When ostinatos occur simultaneously, harmonic tension rises (Ch. 11, pp. 241-242).

# Prerequisites
- **Harmonic progression** -- understanding the harmonies against which the ostinato repeats

# Key Properties
1. Well-defined melodic segment (not single tones)
2. Insistently repeated
3. Tonal simplicity clarifies polytonal textures
4. Upper voice: melodically obstinate (prominent)
5. Middle voice: obtrusive (interfering)
6. Lower voice: foundational (clarifying)
7. Simultaneous ostinatos increase harmonic tension
8. Different patterns may suggest different tonal areas

# Construction / Recognition
- Identify a repeating melodic pattern (not just single tones)
- Note the register and its effect on character
- Check for simultaneous ostinatos and their combined tension

# Context & Application
The tonal simplicity of ostinato helps clarify polytonal textures by providing a stable reference. Ostinatos contribute to formal coherence through repetition and create forward momentum through rhythmic persistence.

# Relationships
## Builds Upon
- Harmonic progression (ostinato operates against moving harmony)
## Enables
- Tonal clarity in polytonal contexts
## Related
- Pedal point (sustained tone vs. melodic pattern)
- Isorhythm (repeated rhythmic pattern with free pitch -- related but distinct)
- Static harmony (both involve repetition but ostinato is melodic)
## Contrasts With
- Pedal point (ostinato is a melodic pattern; pedal is a single tone)

# Common Errors
- Confusing ostinato with pedal point
- Not considering register effects on ostinato character

# Common Confusions
- Ostinato is a melodic pattern, not a single sustained tone like pedal
- Register placement affects character (obstinate, obtrusive, or foundational)
- Multiple simultaneous ostinatos increase rather than clarify complexity
