# Quick Definition
The simplest quartal formations built by stacking two fourths, with three possible types: perfect-perfect (consonant), perfect-augmented (contains tritone), and augmented-perfect (contains tritone); the augmented-augmented type is impracticable because the outer notes are enharmonically identical.

# Core Definition
Three kinds of intervallic arrangement of three-note chords by fourths are possible: perfect-perfect, perfect-augmented, and augmented-perfect. The augmented-augmented arrangement is impracticable because the first and third notes are enharmonically identical (A4+A4 = 12 semitones = octave). Each type has two inversions. Inverting chords having two perfect fourths helps prevent harmonic monotony. Either inversion can serve as a fundamental structure because of the strong perfect fifth. When the perfect fifth dominates the texture, the resulting second (from the inverted seventh) often sounds like a note added to a simple formation. The perfect-perfect type is consonant in quartal context. Any type can progress diatonically, chromatically, or by skip if one voice moves with strong melodic purpose.

# Key Properties
1. Three types: P4+P4, P4+A4, A4+P4
2. A4+A4 impracticable (enharmonic octave)
3. Each type has two inversions
4. P4+P4: consonant, no sharp interval, any member free to skip
5. P4+A4 and A4+P4: tritone requires resolution to nearest scale tone
6. Inversions introduce perfect fifth, providing color variety
7. Open spacing increases harmonic expressiveness
8. Any note may be doubled (outer parts for color, inner parts for moving voice strength)

# Construction / Recognition
- P4+P4: C-F-Bb (spans m7) -- consonant
- P4+A4: C-F-B (spans M7) -- contains tritone
- A4+P4: C-F#-B (spans M7) -- contains tritone
- Inversions feature the perfect fifth prominently
- If the fifth dominates, the second sounds like an added note

# Context & Application
Three-note quartal chords are the basic building blocks of quartal harmony. The consonant P4+P4 type provides a stable quartal sonority, while the tritone-containing types create tension and direction. Clarity is difficult in low registers; they flow more easily in upper voices. A pedal point lessens dissonant tones' need for resolution. A florid voice added to three-note quartal chords enables greater harmonic freedom.

# Common Errors
- Expecting all three types to behave similarly (P4+P4 is consonant; tritone types need resolution)
- Placing three-note quartal chords in low registers without compensating for muddiness

# Common Confusions
- **Inversion and the fifth**: When a three-note quartal chord is inverted, the prominent fifth can make it sound like a simple chord with an added note rather than a quartal structure
- **A4+A4 impossibility**: Two augmented fourths = octave, producing only two distinct pitches
