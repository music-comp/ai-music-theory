# Quick Definition
The simplest quartal chord formations built by stacking two fourths, with three possible intervallic arrangements: perfect-perfect, perfect-augmented, and augmented-perfect, each having distinctive characteristics and behaviors.

# Formal Definition
Three kinds of intervallic arrangement of three-note chords by fourths are possible: perfect-perfect, perfect-augmented, and augmented-perfect. The augmented-augmented arrangement is impracticable because the first and third notes are enharmonically identical. Each type has two possible inversions.

# Musical/Mathematical Formulation
**Three Types:**
1. **Perfect-Perfect (P4 + P4):**
   - Span: minor seventh
   - Example: C-F-Bb
   - Character: consonant in quartal context, no sharp interval

2. **Perfect-Augmented (P4 + A4):**
   - Span: major seventh
   - Example: C-F-B
   - Contains tritone (upper note resolves chromatically)

3. **Augmented-Perfect (A4 + P4):**
   - Span: major seventh
   - Example: C-F#-B
   - Contains tritone (lower note of tritone resolves)

**Why Not Augmented-Augmented:**
A4 + A4 = 12 semitones = octave
The outer notes would be enharmonically identical, producing only 2 distinct pitches.

**Inversions:**
Each type has two inversions:
- First inversion: bottom note moved up an octave
- Second inversion: top note moved down an octave

# Musical Context/Application
Inverting chords with two perfect fourths helps prevent harmonic monotony of uniform intervals. Either inversion can be used as a fundamental structure because of the presence of the strong perfect fifth. If the resonant interval of the perfect fifth is allowed to dominate the texture, the second (created by the inverted seventh) often sounds like a note added to a simple chordal formation.

The perfect-perfect chord is seldom used as a dissonant structure due to its mild texture. Any member of this chord is free to skip. Chords containing the augmented fourth have the upper note of the tritone resolve to the nearest note of the prevailing scale formation.

# Common Confusions
Students may expect all three-note quartal chords to behave similarly. The perfect-perfect type functions as a quartal consonance, while the types containing the augmented fourth have inherent tension requiring resolution. These differences significantly affect compositional handling.
