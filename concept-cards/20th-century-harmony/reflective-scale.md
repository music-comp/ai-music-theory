# Quick Definition

A scale that is symmetrically invertible, producing either the same scale (self-reflective) or a related scale when its intervals are reflected in contrary motion.

# Core Definition

"Some scales are naturally reflective in that two separate scales move identically, interval for interval, when placed in contrary motion. The entire diatonic scale system is symmetrically invertible. The mirrored diatonic scales appear in a reversed order of color gradation. The dorian in mirrored version produces the same scale" (Persichetti, p. 174). "Any scale may be reflected" (p. 175). "Some synthetic scales, such as the Double Harmonic, are inversely identical" (p. 175).

# Prerequisites

- **Mirror chord** — Reflective scales generate mirror harmony
- **Diatonic modes** — The diatonic system is the primary example of scale reflection

# Key Properties

1. **Diatonic reflective pairs** (reversed color gradation):
   - Lydian <-> Locrian
   - Ionian (Major) <-> Phrygian
   - Mixolydian <-> Aeolian (Natural Minor)
   - Dorian <-> Dorian (self-reflective)
2. Color gradation reverses in mirror (brightest <-> darkest)
3. Any scale (diatonic, synthetic) may be reflected
4. Self-reflective scales: Dorian, Double Harmonic, others with palindromic interval structure
5. Reflective scales imply mirror harmony
6. Reflective scales at different pitch levels produce mirror chords with more pronounced character as spacing widens

# Construction / Recognition

## To Find a Scale's Reflection
1. Write the ascending interval pattern of the scale
2. Read the intervals in reverse (descending becomes ascending)
3. The result is the reflective partner
4. If the pattern is a palindrome, the scale is self-reflective

## Diatonic Mirror Pairs
- Lydian (W-W-W-H-W-W-H) mirrors to Locrian (H-W-W-H-W-W-W)
- Ionian mirrors to Phrygian
- Mixolydian mirrors to Aeolian
- Dorian mirrors to itself

# Context & Application

Reflective scales enable systematic mirror harmony derived from scalar material, harmonic progressions where chords reflect through scale relationships, simultaneous use of a scale and its reflection for textural richness, and modal writing with built-in contrary motion possibilities.

# Common Errors

- **Error**: Assuming all modes mirror to themselves
  **Correction**: Only Dorian is self-reflective; other modes mirror to different modes

# Common Confusions

- **Confusion**: Scale reflection = transposition
  **Clarification**: Mirroring inverts the interval pattern, creating a related but distinct scale; transposition preserves intervals
- **Confusion**: Self-reflective scales are special cases
  **Clarification**: They are scales with palindromic interval structure (Dorian, Double Harmonic, etc.)
