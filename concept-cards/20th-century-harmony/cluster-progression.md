# Quick Definition

The movement of clusters through expansion, contraction, intervallic change, member omission, and voice color shifting, with parallel motion being purely melodic while similar motion and occasional octaves add textural interest.

# Core Definition

"Clusters progress harmonically by expanding and contracting, changing the intervallic construction, omitting chord members, and shifting voice colors. When clusters move in parallel motion the progression is purely melodic. Changing the parallel motion to similar motion in some of the voices adds textural interest, and using occasional octaves in the two outer parts accentuates the color" (Persichetti, p. 126). "As clusters increase in size, harmonic tension increases; as clusters decrease in size, instrumental color can become concentrated because of overlapped and doubled voices" (p. 131).

# Key Properties

1. **Expansion/contraction**: Outer voices move apart (expand) or together (contract); primary tension control
2. **Intervallic change**: Shift between diatonic/chromatic construction; change M2/m2 patterns
3. **Member omission**: Leave gaps for lighter texture and harmonic flexibility
4. **Voice color shifting**: Reassign pitches between instruments for timbral variety
5. Parallel motion = purely melodic progression
6. Similar motion in some voices = added textural interest
7. Octaves in outer parts = accentuated color
8. Expanding = increasing tension; contracting = decreasing tension + concentrated color
9. Large clusters: powerful for dramatic punctuation; smaller clusters: more agile and easier to handle

# Construction / Recognition

## To Create Cluster Progressions
1. Compose outer-voice contrapuntal frame
2. Vary outer voices by contrary, oblique, or parallel movement to change cluster size
3. Change intervallic content (diatonic to chromatic, etc.) for color shifts
4. Omit members strategically for lighter moments
5. Use ornamental tones to increase harmonic circulation

# Context & Application

Cluster progression differs fundamentally from tertian harmonic progression. There is no root movement or functional gravity; instead, progression is achieved through textural manipulation. The outer-voice frame provides the contrapuntal logic while the interior expands and contracts. Ornamental tones increase harmonic circulation in cluster passages (p. 131).

# Common Errors

- **Error**: Keeping clusters at a fixed size throughout a passage
  **Correction**: Vary cluster size for tension control and textural interest
- **Error**: Using only parallel motion for cluster movement
  **Correction**: Mix contrary, oblique, and similar motion for richer texture

# Common Confusions

- **Confusion**: Cluster progression is textural stasis
  **Clarification**: Parallel cluster motion is not static; it is melodic. Other motion types create genuine harmonic progression
- **Confusion**: Size change is secondary to pitch change
  **Clarification**: In clusters, size change is the primary tension control mechanism, not dissonance content
