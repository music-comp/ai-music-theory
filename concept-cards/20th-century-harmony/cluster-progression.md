# Quick Definition
The movement of clusters through expansion, contraction, intervallic change, member omission, and voice color shifting, with parallel motion being purely melodic while similar motion and occasional octaves add textural interest.

# Formal Definition
Clusters progress harmonically by expanding and contracting, changing the intervallic construction, omitting chord members, and shifting voice colors. When clusters move in parallel motion the progression is purely melodic. Changing the parallel motion to similar motion in some voices adds textural interest, and using occasional octaves in the two outer parts accentuates the color.

# Musical/Mathematical Formulation
Progression techniques:

1. **Expansion/Contraction**:
   - Outer voices move apart (expansion) or together (contraction)
   - Inner voices fill the changing span
   - As clusters increase, tension increases
   - As clusters decrease, color concentrates through doubled voices

2. **Intervallic change**:
   - Shift from diatonic to chromatic construction
   - Change the M2/m2 pattern
   - Mix scale sources

3. **Member omission**:
   - Leave gaps in the cluster
   - Creates lighter texture
   - Adds harmonic flexibility

4. **Voice color shifting**:
   - Reassign pitches between instruments
   - Change timbre without changing pitch
   - Orchestrational variety

Motion types:
- **Parallel motion**: Purely melodic, all voices move same direction/interval
- **Similar motion**: Same direction, different intervals (adds interest)
- **Octave doubling in outer voices**: Accentuates color

Tension principle:
- Expanding clusters = increasing tension
- Contracting clusters = decreasing tension + concentrated color (overlapped/doubled voices)

# Musical Context/Application
Cluster progression differs fundamentally from tertian harmonic progression. There is no root movement or functional gravity; instead, progression is achieved through textural manipulation. The outer-voice frame provides the contrapuntal logic while the interior of the cluster expands and contracts.

Large clusters are powerful for dramatic punctuations but smaller clusters are more agile and generally easier to handle.

# Common Confusions
- Cluster progression is textural, not functional (no root movement)
- Parallel cluster motion is not "static"; it is melodic
- Size change is the primary tension control, not dissonance content
- Smaller clusters are generally more useful than large ones
