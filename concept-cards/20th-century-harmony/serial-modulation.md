# Quick Definition
Movement between serial "tonal" areas through transposition of the melodic set, using identical chords between different set forms as pivot formations, with closely related areas found a perfect fifth above or below the original.

# Core Definition
Transposition of the melodic set causes modulatory shifting of the harmonic areas. When a chord from one form (original, retrograde, inversion, or retrograde inversion in any transposition) of the melodic set is identical to a chord of another form of the set, it may be used as a pivot formation when entering new "tonal" areas. Closely related harmonic areas are those that may be found by constructing an inversion or retrograde inversion of the melodic set starting a perfect fifth above or below the original set.

# Prerequisites
- **Serial harmony**: The framework
- **Melodic set**: The tone succession being transposed
- **Serial center chord**: The focal sonority of each "tonal" area

# Key Properties
1. Set transposition causes harmonic area shifting
2. Identical chords between set forms serve as pivot formations
3. Closely related areas: I or RI starting P5 above or below original
4. Pivot chords function analogously to tonal pivot chords
5. Any form (O, R, I, RI) at any transposition may provide pivot chords
6. New thematic material can be built on derived sets

# Construction / Recognition
- Identify the transposition that moves the set to a new harmonic area
- Search for identical chords between the old and new set forms
- Use identical chords as pivot formations for smooth transition
- For closely related areas, construct I or RI starting P5 above/below original
- Derive new melodic sets by selecting top notes of telescoped chords

# Context & Application
Serial modulation parallels tonal modulation: set transposition shifts the harmonic area (analogous to key change), identical chords serve as pivots (analogous to common chords), and closely related areas have a definable relationship (the fifth, analogous to the dominant relationship). Contrasting thematic material may be built upon a new but related melodic set derived from the original, providing both harmonic variety and structural coherence.

# Common Errors
- Ignoring pivot formations between set areas
- Treating serial "key" areas as unrelated
- Failing to identify closely related areas (fifth relationship)

# Common Confusions
- **Analogy with tonal modulation**: Serial modulation uses set transposition and pivot formations analogously to tonal modulation's key change and common chords
- **Closely related areas**: The P5 relationship in serial contexts parallels the dominant relationship in tonal contexts
- **Derived sets**: New melodic sets for contrasting material maintain organic connection to the original
