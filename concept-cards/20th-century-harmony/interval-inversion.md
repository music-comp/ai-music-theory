# Quick Definition
Placing the lower note of an interval above the upper note (or vice versa), which changes the interval's consonant-dissonant quality due to altered spacing and register.

# Core Definition
When intervals are inverted, their consonant-dissonant quality changes because the spacing and register have been altered. The extent of change varies with the individual interval. Inverting the perfect fifth alters its basic function, this solid interval becoming an unstable perfect fourth. When sharp dissonances are inverted, marked changes in intensity occur: the cutting minor second opens into a wide-spreading major seventh and thereby loses some of its sting. Inverting the tritone causes a pronounced shift in register even though no change in intervallic distance has taken place.

# Prerequisites
- **interval** -- the elements being inverted
- **consonance-dissonance** -- inversion changes position on the tension spectrum

# Key Properties
1. **Interval + inversion = 9** (e.g., 3rd + 6th = 9)
2. **Perfect inverts to perfect**, major to minor, augmented to diminished
3. **P5 to P4**: solid becomes unstable -- fundamental functional change
4. **m2 to M7**: concentrated sting opens into wide-spreading intensity
5. **Tritone to tritone**: same distance, pronounced register shift
6. **Quality change varies**: some inversions change character dramatically, others less so

# Construction / Recognition
1. Identify the interval
2. Move the lower note up an octave (or upper note down)
3. Assess the new character -- do not assume it matches the original
4. Note particularly the P5/P4 and m2/M7 transformations

# Context & Application
Composers use inversion to create varied textures and tension levels with related intervallic materials. Understanding that inversion changes character, not just size, is essential for voice leading and chord voicing decisions. The P5-to-P4 transformation is especially significant for quartal vs. quintal harmony.

# Common Errors
- **Error**: Assuming inverted intervals have the same harmonic function. **Correction**: Inversion fundamentally changes character, not just size; the P5 and P4 demonstrate this most clearly.

# Common Confusions
- **Confusion**: Conflating inversion with octave displacement. **Clarification**: Inversion specifically refers to moving one note of the interval across the other, changing the interval's identity, not just transposing both notes.
