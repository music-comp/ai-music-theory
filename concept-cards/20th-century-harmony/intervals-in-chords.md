# Quick Definition
The analysis of chords through their constituent intervals rather than root relationships, enabling more flexible control of harmonic tension and direction.

# Formal Definition
Two or more intervals occurring simultaneously form what is usually felt to be a chord. Before a chord is set in harmonic motion, the consonant-dissonant quality of each interval contained in the chord should be noted. Awareness of intervallic content produces harmonic movement of a more flexible nature than that which results from root relationships within a fixed scale and key.

# Musical/Mathematical Formulation
Interval counts in chords:
- Three-note chord: 3 intervals
- Four-note chord: 6 intervals
- Five-note chord: 10 intervals

Formula: n(n-1)/2 intervals for n notes

Chord construction types:
- Equidistant intervals (same interval stacked)
- Different kinds of same interval number (e.g., major and minor thirds)
- Mixed intervals (various interval types combined)

# Musical Context/Application
Chords may be built with equidistant intervals, with different kinds of the same interval number, or with mixed intervals. It is only by making use of differences in chordal values as determined by interval characteristics that harmonic tension can be controlled. Without this kind of freedom, only limited harmonic progression can be achieved.

# Common Confusions
Students trained in traditional harmony often analyze chords only by root and quality (e.g., "dominant seventh"). Persichetti emphasizes analyzing the actual intervals present, as this reveals the chord's tension characteristics independent of tonal function.
