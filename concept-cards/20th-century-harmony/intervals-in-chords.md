# Quick Definition
The analysis of chords through their constituent intervals rather than root relationships, enabling more flexible control of harmonic tension and direction.

# Core Definition
Two or more intervals occurring simultaneously form what is usually felt to be a chord. Before a chord is set in harmonic motion, the consonant-dissonant quality of each interval contained in the chord should be noted. It is only by making use of differences in chordal values as determined by interval characteristics that harmonic tension can be controlled. Without this kind of freedom, only a limited kind of harmonic progression can be achieved -- that which results from root relationships within a fixed scale and key. Awareness of intervallic tension produces harmonic movement of a more flexible nature.

# Prerequisites
- **interval** -- chords are analyzed as collections of intervals
- **consonance-dissonance** -- each interval has a tension classification

# Key Properties
1. **Interval count formula**: n(n-1)/2 intervals for n notes
   - 3-note chord: 3 intervals
   - 4-note chord: 6 intervals
   - 5-note chord: 10 intervals
2. **Three construction types**:
   - Equidistant intervals (same interval stacked)
   - Different kinds of same interval number (e.g., major and minor thirds)
   - Mixed intervals (various types combined)
3. **Good part-writing** is necessary to achieve flexibility from intervallic awareness
4. **Chord members may be arranged** so that specific interval kinds monopolize the pattern

# Construction / Recognition
1. Count all unique interval pairs in the chord
2. Classify each interval by its tension category
3. Note the overall balance of consonance and dissonance
4. Identify the chord construction type: equidistant, same-number, or mixed
5. Assess how spacing distributes interval tensions across registers

# Context & Application
Chord members may be so arranged that specific kinds of intervals monopolize the musical pattern. The chosen interval may form separate intervallic strands that move in contrary motion. This intervallic approach to chord construction and analysis is fundamental to twentieth-century practice, where chords are understood not by root identity but by interval content.

# Common Errors
- **Error**: Analyzing chords only by root and quality (e.g., "dominant seventh"). **Correction**: Analyze actual intervals present to reveal tension characteristics independent of tonal function.
- **Error**: Ignoring interval count in larger chords. **Correction**: A 5-note chord has 10 intervals; all contribute to the overall tension.

# Common Confusions
- **Confusion**: Thinking only the "stacked" intervals matter. **Clarification**: All interval pairs in the chord contribute to its character, not just adjacent ones.
