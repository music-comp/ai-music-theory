# Quick Definition

The registral placement of chordal units within a polychord, where wider spacing allows maximum tonal vibration, smaller intervals belong in upper registers and wider intervals in lower registers, and contrasting instrumentation clarifies harmonic zones.

# Core Definition

"The density of the polychordal structure is determined by spacing. Placing chordal units well apart allows for maximum tonal vibration. Contrasting instrumentation of the chordal units clearly defines the contrasting harmonic zones" (Persichetti, p. 138). "A polychord gains resonance if smaller intervals are placed in the upper register and wider intervals are placed in the lower register" (p. 139). "When the lowest note of the polychord is placed somewhere below the bass clef low F, the harmony becomes muddy unless an open-position chord is used" (p. 140).

# Key Properties

1. Wide spacing: maximum tonal vibration, clear harmonic zones
2. Close spacing: cloudiness/nebulousness; valuable for fluctuating tension
3. Smaller intervals upper / wider intervals lower = increased resonance
4. Below bass clef low F: muddy unless open position used
5. Contrasting instrumentation clarifies harmonic zones
6. Common tones between units help blend; doubling consonant intervals gives strength
7. Upward transposition: loses body/resonance, gains brilliance
8. Downward transposition: drastic complexion changes
9. Consonant outer voices spread effectiveness throughout; dissonant outer voices do the same
10. The closer dissonant tones are placed, the higher the tension; but if not clearly part of a unit, areas run together and polyharmony ceases

# Construction / Recognition

## To Space a Polychord Effectively
1. Place units far enough apart for distinct perception
2. Use wider intervals in lower register, smaller in upper
3. Assign contrasting instrumentation to each unit
4. Check that the lowest note is not below bass clef low F (or use open position if it is)
5. Consider outer-voice relationship (consonant or dissonant) for overall character

# Context & Application

Careful spacing distinguishes effective polychordal writing from muddy or unclear textures. Close spacing with monochrome scoring produces cloudiness; wide spacing with contrasted instrumentation produces clarity. The "muddy" polychord is nevertheless a valuable structure under appropriate dramatic conditions.

# Common Errors

- **Error**: Placing the entire polychord below bass clef low F in close position
  **Correction**: Use open position or move to higher register to avoid muddiness
- **Error**: Using identical instrumentation for both units
  **Correction**: Contrasting instrumentation clarifies the distinct harmonic zones

# Common Confusions

- **Confusion**: Close spacing is always undesirable
  **Clarification**: Close spacing produces cloudiness that is "a valuable addition to the over-all fluctuating tension of harmony" (p. 139)
- **Confusion**: Register transposition only changes pitch level
  **Clarification**: It changes character fundamentally; upward = less body, more brilliance; downward = drastic complexion changes
