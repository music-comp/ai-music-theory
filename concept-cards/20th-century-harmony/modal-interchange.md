# Quick Definition
Changing modes while keeping the tonal center constant, allowing shifts between modal colors on a single tonic.

# Core Definition
When the modes change while the tonal center remains, modal interchanges result. This technique allows a composer to explore different modal colors while maintaining a stable sense of pitch center. The shifting modes create variety in harmonic color without the sense of tonal movement associated with modulation. Shifting modes are effective on a stationary key center, though much melodic reference must be made to the tonic to stay within each mode.

# Key Properties
1. **Fixed tonal center**: the tonic remains constant throughout
2. **Changing modes**: different modes appear in succession on the same tonic
3. **Color variety**: each mode brings its characteristic flavor
4. **Brightness movement**: can follow the dark-to-bright spectrum for controlled effect
5. **Tonic reinforcement needed**: melodic circling and cadences maintain the center

# Construction / Recognition
1. Confirm the tonal center remains constant
2. Identify where mode changes occur
3. Note the direction of color change (darker or brighter)
4. Check for tonic reinforcement techniques at mode transitions

# Context & Application
Modal interchange provides harmonic variety while maintaining tonal stability. The brightness spectrum offers a systematic framework for planning interchange sequences. Moving from darker to brighter modes can accompany other crescendo effects (register, dynamics, rhythm) as demonstrated in Persichetti's modal crescendo example.

# Common Errors
- **Error**: Confusing modal interchange with modal modulation. **Correction**: Interchange changes mode while keeping the tonic; modulation changes tonic while keeping the mode.
- **Error**: Confusing modal interchange with chromatic alteration. **Correction**: Interchange involves complete shifts between modes, not just borrowing individual altered tones.

# Common Confusions
- **Confusion**: Thinking modal interchange creates instability. **Clarification**: Because the tonic remains fixed, the listener retains a strong sense of tonal center despite the mode changes.
