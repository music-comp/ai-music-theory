# Quick Definition
The simultaneous use of two or more different modes on the same or different tonal centers, creating layers of contrasting modal colors.

# Core Definition
Polymodality involves two or more different modes on the same or different tonal centers. The modal strands may be melodic or harmonic. Three combinations are possible: (1) different modes on the same tonic (polymodal only), (2) same mode on different tonics (polytonal and modal, but NOT polymodal), (3) different modes on different tonics (both polymodal AND polytonal). This taxonomy allows precise description of complex modal-tonal relationships.

# Prerequisites
- **diatonic-modes** -- the modes being layered
- **pure-modal-passage** -- the single-mode baseline that polymodality extends

# Key Properties
1. **Polymodal only**: different modes, same tonic (e.g., lydian + phrygian on D)
2. **Polytonal, not polymodal**: same mode, different tonics (e.g., dorian on D + dorian on Ab)
3. **Polymodal AND polytonal**: different modes, different tonics (e.g., lydian on D + phrygian on Ab)
4. **Modal strands**: may be melodic (different mode in melody vs. harmony) or harmonic (layered harmonic streams)
5. **Independence of layers**: creates rich harmonic textures through modal contrast

# Construction / Recognition
1. Identify the mode(s) used in each layer (melody, harmony, individual lines)
2. Identify the tonal center(s) of each layer
3. Classify: same/different modes x same/different centers
4. Determine whether the passage is polymodal, polytonal, or both

# Context & Application
Polymodality creates complex but coherent harmonic colors by layering different modal collections. The technique is particularly effective when the melody uses one mode and the harmony another, allowing each layer to maintain its own modal identity. This is a key 20th-century resource for enriching modal writing beyond the limitations of pure modal passages.

# Common Errors
- **Error**: Confusing polymodality with polytonality. **Correction**: Polymodality requires different modes (may or may not have different tonics); polytonality requires different tonal centers (may or may not use different modes).

# Common Confusions
- **Confusion**: Thinking a passage with two tonics is automatically polymodal. **Clarification**: Same mode on different tonics is polytonal but NOT polymodal; the modes must differ for polymodality.
