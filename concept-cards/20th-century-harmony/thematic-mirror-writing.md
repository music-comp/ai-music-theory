# Quick Definition

A compositional approach where a melody is constructed so that part inverts another part, and subsequent simultaneous use of original and inversion generates mirror chord structures derived from thematic material.

# Core Definition

"Mirror writing may stem from thematic sources; an initial melody can be constructed so that part of the melody is the inversion of another part. Subsequent simultaneous use of the original melody and its inversion breeds mirrored vertical structures generated by the thematic elements of the work" (Persichetti, p. 178).

# Prerequisites

- **Mirror writing** — Thematic mirror writing is a specialized application
- **Mirror chord** — The vertical structures produced are mirror chords

# Key Properties

1. Melody constructed with self-inverting segments
2. Original and inverted forms used simultaneously
3. Vertical coincidences produce mirror chords
4. All harmony derives from thematic intervals (organic unity)
5. Melodic-harmonic integration: chords grow from melodic material

# Construction / Recognition

## To Apply Thematic Mirror Writing
1. Construct a melody where segment A is the inversion of segment B
2. Present original and inverted forms simultaneously
3. The vertical coincidences automatically generate mirror chords
4. All resulting harmony derives organically from the thematic intervals

# Context & Application

Thematic mirror writing provides organic connection between melody and harmony, built-in developmental potential (theme generates its own harmonization), structural unity across a composition, and fresh sound from consistent intervallic relationships. This integrates mirror technique from the outset rather than applying it to pre-existing material.

# Common Errors

- **Error**: Using any melody for thematic mirror writing
  **Correction**: The melody must be specifically constructed with self-inverting segments; not all melodies produce useful mirror harmony

# Common Confusions

- **Confusion**: Thematic mirror = applied mirror
  **Clarification**: Thematic mirror generates harmony from melodic material; applied mirror mirrors pre-existing chords/progressions
- **Confusion**: Mirror harmony appears without simultaneity
  **Clarification**: The mirror chords emerge only when original and inversion sound together
