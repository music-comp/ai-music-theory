# Quick Definition
A melodic harmonization technique where each melody note is treated as a member of a triad (any quality), with bass notes chosen from seconds above or below any triadic member to create varied outer-voice relationships and phrase shapes governed by melody rather than functional harmony.

# Core Definition
Progression in triad-with-added-bass harmony is often governed by an upper melodic line. Each note of a melody, except ornamental tones, may be considered a member of a major, minor, diminished, or augmented triad. A bass line is then constructed from notes a second from any triadic member. Bass notes are chosen to form the kind of outer-voice relationship that best suits the desired texture and phrase shapes. Freedom of linear movement is made possible by the wide selection of bass notes.

# Prerequisites
- **Triad with added bass**: The chord type used in this technique

# Key Properties
1. Each melody note = potential root, third, or fifth of four triad qualities
2. Bass note = M2 or m2 above or below any triadic member
3. Extensive palette for each melodic moment
4. Selection criteria: outer-voice contour, phrase shape, textural consistency, bass line quality
5. Ornamental melody tones excluded from harmonization
6. Independent from functional harmony
7. Works best in passages consisting solely of this chord type

# Construction / Recognition
1. Take melody note
2. Determine possible triads (as root, 3rd, or 5th of M, m, dim, aug)
3. Select triad quality
4. Choose bass from seconds above/below any triadic member
5. Select based on desired outer-voice relationship and phrase shape

# Context & Application
This technique liberates harmony from traditional root progression while maintaining triadic sonority. The wide selection of bass notes provides freedom, while consistent chord type ensures textural coherence. The technique is not figured bass or functional bass construction; the bass note does not imply root function.

# Common Errors
- Treating the bass as implying root function (it does not)
- Random bass selection without attention to outer-voice contour

# Common Confusions
- **Not figured bass**: The bass note is chosen for linear and textural reasons, not harmonic function
- **Wide choice is not random choice**: Musical criteria (contour, phrase shape, consistency) guide selection
