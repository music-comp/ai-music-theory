# Quick Definition

A mirror chord mirrored a second time, producing complex structures used primarily alongside large unmirrored compound chords, with enharmonic changes for practical notation.

# Core Definition

"Any mirror chord may be doubly mirrored. These complex structures are used primarily with large unmirrored compound chords. Enharmonic changes are made when spelling becomes unwieldy" (Persichetti, p. 174).

# Prerequisites

- **Mirror chord** — Double mirrors apply the mirror process twice
- **Building tone** — The axis of each mirroring operation

# Key Properties

1. Mirror chord subjected to second application of mirroring
2. Produces extremely large sonorities with multiple symmetrical relationships
3. Used primarily alongside large unmirrored compound chords
4. Enharmonic respelling necessary for practical notation
5. Generates multiple axes of symmetry within single formation

# Construction / Recognition

## To Construct
1. Begin with original chord
2. First mirror: reflect intervals around building tone(s)
3. Second mirror: reflect the result around new or same axis
4. Apply enharmonic changes for readable notation

# Context & Application

Double mirror structures serve for massive climactic sonorities, matching complexity of large compound chords in multi-textural writing, providing logical internal organization for extremely complex harmonies, and generating systematic material for extended reflective passages.

# Common Errors

- **Error**: Maintaining strict intervallic spelling without enharmonic adjustment
  **Correction**: Enharmonic changes are practical necessity; theoretical purity yields to readable notation

# Common Confusions

- **Confusion**: Double mirror means two separate mirror chords
  **Clarification**: It is one structure mirrored twice, not two independent mirror formations
