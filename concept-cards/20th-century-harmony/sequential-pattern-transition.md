# Quick Definition
The use of sequential patterns to drive varied chords across harmonic barriers between texture types, where the patterned repetition provides continuity while the harmonic content gradually transforms.

# Core Definition
Sequential patterns can drive varied chords over many harmonic barriers. The momentum of a recognizable pattern allows the harmonic content to change gradually from one texture type to another without the listener losing continuity. Rough tritone relationship or prominent hidden fifths divert attention from harmonic transformations, assisting the sequential pattern in masking the texture change.

# Prerequisites
- **Textural transition**: The broader transitional technique

# Key Properties
1. Sequential repetition provides perceptual continuity
2. Harmonic content can change gradually within the pattern
3. Momentum carries through barriers between texture types
4. Tritone relationships divert attention from transformations
5. Hidden fifths mask harmonic changes
6. Works across any texture type combination

# Construction / Recognition
- Establish a recognizable sequential pattern
- Gradually change the harmonic content of the pattern's chords
- Use tritone relationships or hidden fifths to mask the changes
- Monitor the overall texture transition from beginning to end
- Note whether the pattern maintains its identity despite harmonic changes

# Context & Application
Sequential pattern transitions exploit the listener's tendency to track pattern repetition rather than individual harmonic events. By maintaining a recognizable rhythmic and contour pattern, the composer can smuggle harmonic changes past the ear. This technique is particularly effective when combined with attention-diverting devices (tritone relationships, hidden fifths) and when the pace of harmonic change is gradual within the sequence.

# Common Errors
- Making the sequential pattern too rigid (prevents harmonic change)
- Changing harmonic content too quickly (exposes the transition)
- Neglecting masking devices (tritone, hidden fifths)

# Common Confusions
- **Pattern continuity**: The sequence must maintain recognizable identity while allowing harmonic change
- **Masking, not hiding**: The transition is not concealed but smoothed -- the listener experiences continuity rather than disruption
- **Any barrier**: Sequential patterns can cross barriers between any texture types because the pattern provides continuity independent of harmonic content
