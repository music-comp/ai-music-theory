# Quick Definition
The inversion of a scale's interval pattern (ascending becomes descending), revealing hidden harmonic potentialities and providing fresh compositional material.

# Core Definition
Further harmonic possibilities may be tested by considering the mirrored version of a scale. Scanning intervallic points between the original and mirrored versions reveals hidden potentialities. Fresh material such as cadential patterns, passing textures, and outer-voice movement is suggested and brought into focus by reflection. Some scales are reflectively identical -- inversion produces an exact duplication of the original scale in retrograde (e.g., dorian mode, chromatic scale, whole-tone scale).

# Prerequisites
- **synthetic-scale** -- the scales being mirrored

# Key Properties
1. **Mirror construction**: ascending intervals become descending (W-W-H becomes H-W-W in reverse)
2. **Reveals**: cadential patterns, passing textures, contrapuntal possibilities
3. **Reflectively identical scales**: mirror = retrograde (palindromic interval structure)
   - Dorian mode
   - Chromatic scale
   - Whole-tone scale
   - Double Harmonic scale
4. **Non-identical mirrors**: produce related but distinct scales with shared harmonic resources
5. **Melody + harmony combination**: original scale and mirror can be used simultaneously

# Construction / Recognition
1. Write the original scale ascending
2. Reverse the interval sequence (read intervals from right to left)
3. Build the mirrored scale from the same starting note using these reversed intervals
4. Compare the two scales for shared tones and unique tones
5. Check if the mirror is identical to the retrograde of the original (reflectively identical)

# Context & Application
Comparing a scale with its mirror reveals new compositional resources. The mirrored version can suggest cadential patterns, passing textures, and outer-voice movement not apparent from the original alone. Original and mirror can be used simultaneously in different voices for contrapuntal richness. Melody may use the original while harmony explores the mirror, or vice versa.

# Common Errors
- **Error**: Confusing mirroring with transposition. **Correction**: Mirroring inverts the interval pattern, creating a related but distinct scale -- not a pitch-shifted copy.

# Common Confusions
- **Confusion**: Thinking all scales have interesting mirrors. **Clarification**: Reflectively identical scales (like dorian) yield no new material through mirroring; only non-palindromic scales produce distinct mirrors.
