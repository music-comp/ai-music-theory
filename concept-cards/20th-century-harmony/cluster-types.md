# Quick Definition

Classification of clusters by scale source (diatonic, chromatic, pentatonic, synthetic), with chromatic clusters being least useful due to rapid fatigue, while diatonic and mixed clusters offer more textural variety.

# Core Definition

"Clusters may be formed from one complete scale of any type or from two or more contrasting scales. The chromatic scale is the least useful because when clustered it becomes tiresome quickly. A seven-note scale may be clustered modally in seven different ways; and a two-octave scale, in fourteen" (Persichetti, p. 126). "The consonant-dissonant quality of cluster harmony may oppose or parallel the quality of the counterpoint of the outer voices" (p. 128).

# Key Properties

1. **Diatonic clusters**: From major, minor, or modal scales; M2/m2 in specific patterns; 7 modal positions per octave
2. **Chromatic clusters**: All half steps; uniform m2 construction; becomes tiresome quickly; best for brief punctuation
3. **Pentatonic clusters**: Only M2 in standard pentatonic; milder texture
4. **Synthetic scale clusters**: Unique intervallic combinations; distinctive color
5. **Mixed-scale clusters**: Two or more contrasting scales combined; enriches cluster palette
6. Modal clustering: each starting degree of a seven-note scale yields a different M2/m2 pattern
7. Consonant/dissonant clusters may be used in all combinations with consonant/dissonant outer voices

# Construction / Recognition

## To Create Different Cluster Types
1. Select a scale source (diatonic mode, chromatic, pentatonic, synthetic, or combination)
2. Stack the scale tones in close position as seconds
3. Choose the starting degree for modal clustering position
4. For mixed-scale clusters, combine tones from two or more scales

# Context & Application

The choice of cluster type directly affects musical character. Diatonic clusters retain tonal implications while chromatic clusters create maximal density. Synthetic and mixed-scale clusters offer distinctive colors that may define a composer's personal harmonic vocabulary. Changing intervallic makeup and number of chord members gives cluster harmony textural interest and momentum (p. 126).

# Common Errors

- **Error**: Relying heavily on chromatic clusters for extended passages
  **Correction**: Chromatic clusters become tiresome quickly; use diatonic, pentatonic, or synthetic sources for variety
- **Error**: Treating all modal positions of a scale as identical clusters
  **Correction**: Each starting degree produces a different M2/m2 pattern with distinct character

# Common Confusions

- **Confusion**: "Diatonic cluster" means the cluster sounds consonant
  **Clarification**: It means built from diatonic scale tones; it still contains dissonant seconds
- **Confusion**: Mixed-scale clusters are the same as polyclusters
  **Clarification**: Mixed-scale clusters combine tones from different scales into one mass; polyclusters maintain separate cluster units with space between them
