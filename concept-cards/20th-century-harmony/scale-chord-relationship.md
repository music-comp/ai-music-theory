# Quick Definition
The correspondence between large tertian chord structures and scale formations, where eleventh chords coincide with six-note scale subsets and thirteenth chords equal complete seven-note scales, enabling them to function as rich tonic formations.

# Core Definition
The intervallic make-up of eleventh and thirteenth chords often coincides with various scale formations. The chords become excellent six- and seven-note tonic formations around which polychords and compound structures may function. These formations are usually guided by a melodic line derived from the scale implied by the rich tonic chord; they are seldom found in extensive part-writing. A C major thirteenth contains all C major scale tones; a C dorian thirteenth contains all dorian tones. The chord IS the scale arranged vertically.

# Prerequisites
- **Eleventh chords**: Six-note tertian formations
- **Thirteenth chords**: Seven-note tertian formations

# Key Properties
1. Eleventh chord (6 notes) = 6-note scale subset
2. Thirteenth chord (7 notes) = complete 7-note scale
3. These chords function as rich tonic formations
4. Melodic material derives directly from the implied scale
5. Polychords and compound structures relate to these tonic formations
6. Seldom used in extensive part-writing (too dense for mobile harmony)
7. Various synthetic scales produce corresponding colored formations

# Construction / Recognition
- Compare the pitch content of an eleventh or thirteenth chord with known scales
- C-E-G-B-D-F-A = C major scale in thirds = C major thirteenth
- C-Eb-G-Bb-D-F-A = C dorian scale in thirds
- When such a chord serves as tonic, derive melody from the implied scale
- Build polychordal and compound structures that relate to this tonic

# Context & Application
This scale-chord relationship is particularly important when using large tertian chords as stable tonic formations rather than as transitional harmonies. The complete correspondence allows the composer to derive melodic material directly from the tonic chord, create related polychordal structures, and establish a harmonic environment where the large chord provides both vertical and horizontal coherence. These formations are seldom found in extensive part-writing due to density, but they excel as anchor points.

# Relationships
## Builds Upon
- Thirteenth chords (the formations exhibiting this property)

## Enables
- Using large tertian chords as comprehensive tonic formations
- Deriving melody from chord content

## Related
- synthetic-scale (produces corresponding colored formations)
- polychord (structures that function around the tonic formation)
- compound-chord (structures relating to the tonic formation)

## Contrasts With
- Mobile harmonic writing (these formations are static tonic anchors)

# Common Errors
- Thinking of large tertian chords only as dominant extensions, not realizing they can be stable tonics
- Attempting mobile part-writing with formations that function best as static anchors

# Common Confusions
- **Tonic, not dominant**: When a thirteenth chord equals a complete scale, it becomes the harmonic and melodic center -- not a chord requiring resolution
- **Static, not inert**: These formations anchor active polychordal and melodic activity, though they themselves are not mobile
