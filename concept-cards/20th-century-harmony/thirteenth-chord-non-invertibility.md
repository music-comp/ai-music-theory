# Quick Definition
The property that thirteenth chords cannot be inverted in the traditional sense: any attempt at inversion produces another eleventh or thirteenth chord rather than a true inversion of the original, because every possible bass note can be reinterpreted as a root.

# Core Definition
The thirteenth chord is non-invertible; any attempt at inversion will produce another eleventh or thirteenth. This occurs because the thirteenth chord contains all seven notes of a diatonic scale arranged in thirds. Rearranging which note appears in the bass simply reinterprets the structure as a different large tertian chord with a different root. Triads, seventh chords, and ninth chords maintain their identity through inversions; thirteenth chords lose theirs because every pitch class present can serve as a root.

# Key Properties
1. Every bass-note change produces a different thirteenth or eleventh -- not an inversion
2. The chord contains all seven diatonic pitch classes
3. Any note can be reinterpreted as a root of a new large tertian chord
4. Contrasts with triads through ninths, which maintain identity through inversion
5. Affects compositional handling: thirteenths are best used in root position or with omissions
6. "Voicings" are redistributions, not true inversions
7. Explains why thirteenth chords are cumbersome in progressions (cannot facilitate voice leading through inversion)

# Construction / Recognition
- Attempt to invert a thirteenth: the result has a different root
- Third in bass: new thirteenth chord on the third
- Fifth in bass: new thirteenth or eleventh
- Every rearrangement = reinterpretation, not inversion
- This property relates to why these chords function well as static tonic formations

# Context & Application
Non-invertibility explains why thirteenth chords are best treated as anchor sonorities rather than mobile harmonic units. They cannot be smoothly inverted to facilitate voice leading as smaller chords can. This property also explains their excellence as tonic formations: their completeness (containing the entire diatonic collection) makes them stable reference points from which other harmonies depart and return.

# Common Errors
- Attempting to use thirteenth chord inversions as bass voice-leading tools
- Analyzing rearranged thirteenth chords as "inversions" rather than new chords

# Common Confusions
- **Inversion vs. redistribution**: While any note can be placed in the bass, the result is not a true inversion but a reinterpretation with a different perceived root
- **Practical vs. theoretical**: The notes can be rearranged practically; the issue is that the analytical identity changes
