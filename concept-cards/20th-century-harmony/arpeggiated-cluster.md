# Quick Definition

A cluster whose tones are sounded consecutively rather than simultaneously, with each note held until the last enters, effective when unfolding from top to bottom, bottom to top, or center to extremities.

# Core Definition

"A cluster is not always introduced by sounding all its tones simultaneously. When the tones of a cluster are sounded consecutively they are effective if each note is held until the last enters. These arpeggio versions of the cluster contribute variety to secundal patterns. They may unfold from top to bottom, bottom to top, or from the center to the extremities" (Persichetti, p. 128). "The consonant or dissonant aspect of a cluster's character may be accentuated by the way in which its members enter" (p. 129).

# Prerequisites

- **Tone cluster** — The arpeggiated cluster is a variant presentation of this sonority

# Key Properties

1. Tones enter consecutively rather than simultaneously
2. Each note must be held until the last note enters
3. Three unfolding directions: top to bottom, bottom to top, center outward
4. Entry order can emphasize consonant or dissonant intervals
5. Sounding consonant/dissonant intervals beforehand prepares the cluster character
6. Broken clusters sound like clusters only if cluster context has been established
7. Without prior cluster context, broken clusters sound like scales

# Construction / Recognition

## To Write an Arpeggiated Cluster
1. Determine the cluster's pitch content
2. Choose unfolding direction (ascending, descending, or outward from center)
3. Notate each entry with sustained duration through to the final entry
4. Consider entry order to emphasize consonant or dissonant intervals first
5. Ensure cluster context has been established beforehand

# Context & Application

Arpeggiated clusters offer temporal variety in secundal passages. They serve as introductions to sustained cluster textures, transitional material between sections, melodic gestures within cluster harmony, and building material for accumulative climaxes. The technique is particularly effective for varying texture in extended cluster passages and introducing clusters gradually.

# Common Errors

- **Error**: Writing arpeggiated clusters without prior cluster context
  **Correction**: Establish cluster harmony first; otherwise broken clusters sound like scales
- **Error**: Releasing notes before the final entry sounds
  **Correction**: Each note must be sustained until the cluster is complete for the cluster effect

# Common Confusions

- **Confusion**: Broken clusters are simply scales
  **Clarification**: They are clusters only if cluster context has been established; the same pitches will sound scalar without that context
- **Confusion**: Entry direction is purely aesthetic
  **Clarification**: Entry direction affects perceived consonance/dissonance character; first-entered intervals color perception of the entire cluster
