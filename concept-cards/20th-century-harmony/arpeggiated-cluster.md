# Quick Definition
A cluster whose tones are sounded consecutively rather than simultaneously, with each note held until the last enters, creating variety in secundal patterns through unfolding from top to bottom, bottom to top, or from center to extremities.

# Formal Definition
A cluster is not always introduced by sounding all its tones simultaneously. When the tones of a cluster are sounded consecutively they are effective if each note is held until the last enters. These arpeggio versions of the cluster contribute variety to secundal patterns. They may unfold from top to bottom, bottom to top, or from the center to the extremities.

# Musical/Mathematical Formulation
Arpeggio directions:
1. **Top to bottom**: Descending entry, creates falling gesture
2. **Bottom to top**: Ascending entry, creates rising gesture
3. **Center outward**: Symmetrical expansion from middle pitch(es)
4. **Extremities inward**: Rare, creates converging effect

Key requirement:
- Each note must be held until cluster is complete
- Release timing can vary independently
- Sustain pedal (keyboard) or instrumental sustain essential

Cluster vs. scale distinction:
- Broken clusters sound like clusters only if cluster context established
- Without cluster context, they sound like scales
- Prior establishment of cluster harmony is prerequisite

Consonance/dissonance accentuation:
- Entry order can emphasize consonant or dissonant intervals
- Sounding consonant/dissonant intervals beforehand prepares character
- First-entered intervals color perception of entire cluster

# Musical Context/Application
Arpeggiated clusters offer temporal variety in secundal passages. They can serve as:
- Introductions to sustained cluster textures
- Transitional material between cluster sections
- Melodic gestures within cluster harmony
- Building material for accumulative climaxes

The technique is particularly effective when:
- Varying texture in extended cluster passages
- Creating directional momentum (ascending/descending)
- Introducing clusters gradually rather than abruptly
- Highlighting specific intervals within the cluster

# Common Confusions
- Broken clusters are not scales unless context makes them so
- Notes must be held for cluster effect; releasing creates different texture
- Entry direction affects perceived character of the cluster
- Arpeggiated clusters require prior cluster context to sound clustered
