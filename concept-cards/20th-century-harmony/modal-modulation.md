# Quick Definition
Moving the same mode from one tonal center to another, creating harmonic motion while maintaining consistent modal color.

# Core Definition
When the same mode is moved from one tonal center to another, a modal modulation exists. This differs from modal interchange, where modes change while the tonal center remains constant. Modal modulation maintains the characteristic intervallic relationships of the mode while shifting the pitch level of the entire collection. A melody may move from one mode to another with a different tonal center; if the melody fluctuates through several modes, the harmony may follow with the same or a different set of modes.

# Key Properties
1. **Fixed mode**: the same interval pattern maintained throughout
2. **Changing tonal center**: the tonic moves to a new pitch
3. **Same modal color**: the "flavor" remains consistent despite pitch change
4. **Melodic-harmonic independence**: melody and harmony may follow different modal/tonal paths
5. **May combine with modal interchange**: mode AND tonic may both change

# Construction / Recognition
1. Identify the mode in the initial passage
2. Confirm the same interval pattern in the new passage
3. Verify the tonal center has changed
4. Distinguish from modal interchange (where mode changes but tonic stays)

# Context & Application
Modal modulation provides harmonic motion while maintaining consistent color. When a melody fluctuates through several modes, the harmony may follow with the same or with a different set of modes. This independence between melodic and harmonic modal paths creates rich compositional possibilities.

# Common Errors
- **Error**: Confusing modal modulation with transposition of a melody. **Correction**: Modal modulation is a harmonic concept involving the entire modal framework, not just a melodic line.

# Common Confusions
- **Confusion**: Thinking modal modulation is the same as key modulation in tonal music. **Clarification**: Modal modulation specifically maintains the mode while changing the tonic; tonal modulation typically changes both key and mode.
