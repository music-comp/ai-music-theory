# Quick Definition
The movement from one tonal center to another while maintaining the same mode, creating a sense of harmonic motion without changing the modal color.

# Formal Definition
When the same mode is moved from one tonal center to another, a modal modulation exists. This differs from modal interchange, where modes change while the tonal center remains constant. Modal modulation maintains the characteristic intervallic relationships of the mode while shifting the pitch level of the entire collection.

# Musical/Mathematical Formulation
Modal modulation process:
1. Establish first tonal center in chosen mode
2. Pivot or transition to new tonal center
3. Maintain same mode on new tonic

Example: D Dorian to G Dorian
- Same interval pattern (W-H-W-W-W-H-W)
- Different pitch collection
- Same modal "color," different pitch level

# Musical Context/Application
Modal modulation provides a way to create harmonic variety while maintaining a consistent modal character. A melody may move from one mode to another with a different tonal center. If the melody fluctuates through several modes, the harmony may follow with the same or a different set of modes.

# Common Confusions
Students may confuse modal modulation with modal interchange. Modal modulation changes the tonal center while keeping the mode; modal interchange changes the mode while keeping the tonal center. Both are valid techniques with different expressive purposes.
