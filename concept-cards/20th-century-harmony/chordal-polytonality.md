# Quick Definition
Polytonality established through two or more tonal planes of harmonic (chordal) writing, with each plane maintaining its own key through vertical chord structures.

# Formal Definition
Polytonality may be established by two or more tonal planes of harmonic writing, where each plane consists of chordal structures operating in its own key. This is contrasted with horizontal (contrapuntal) polytonality where independent lines imply different keys. In chordal polytonality, the vertical dimension clearly establishes the multiple tonal planes through chord-to-chord progressions in each layer.

# Musical/Mathematical Formulation
Chordal polytonality characteristics:
- Each tonal plane uses chordal (vertical) writing
- Multiple layers of harmonic progression operate simultaneously
- Each layer maintains its own key identity
- Block chords against contrasting key lines create supple patterns

Construction requirements:
- Clear scale formation in each plane
- Sufficient registral separation
- Tritone-defining tones in each key
- Shifting pedals can ease polytonal texture

# Musical Context/Application
Chordal polytonality creates a more massive and harmonically dense texture than horizontal polytonality. Block chords against a single contrasting key line create supple polytonal patterns. Shifting pedals can ease the polytonal texture, allowing smoother transitions between harmonic areas. The chordal approach makes the multiple keys immediately audible as distinct harmonic planes.

# Common Confusions
- Chordal polytonality differs from horizontal polytonality in its vertical emphasis
- Not the same as polychords, which are single complex structures
- Each plane must progress harmonically within its own key
