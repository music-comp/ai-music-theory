# Quick Definition
Polytonality established through two or more tonal planes of harmonic (chordal) writing, where each plane maintains its own key through chord-to-chord progressions, creating a more massive texture than contrapuntal polytonality.

# Core Definition
Polytonality may be established by two or more tonal planes of harmonic writing, where each plane consists of chordal structures operating in its own key. Block chords against a single contrasting key line create supple polytonal patterns; shifting pedals ease the polytonal texture. In chordal polytonality, the vertical dimension clearly establishes the multiple tonal planes through chord-to-chord progressions in each layer.

# Prerequisites
- **Polytonality**: The broader multi-key technique

# Key Properties
1. Each tonal plane uses chordal (vertical) writing
2. Multiple layers of harmonic progression operate simultaneously
3. Each layer maintains its own key identity through progression
4. Block chords against contrasting key lines create supple patterns
5. Shifting pedals ease the polytonal texture
6. More massive and harmonically dense than horizontal polytonality

# Construction / Recognition
- Identify distinct chordal layers, each progressing in its own key
- Verify each layer maintains a clear scale formation with tritone-defining tones
- Note block chord versus single-line combinations
- Check for shifting pedals that ease textural density
- Distinguish from polychords (which lack independent progression)

# Context & Application
Chordal polytonality creates a more massive and harmonically dense texture than horizontal polytonality. The chordal approach makes the multiple keys immediately audible as distinct harmonic planes. Shifting pedals can ease the polytonal texture, allowing smoother transitions between harmonic areas. This approach is effective when clear, vertical harmonic identity is desired for each tonal plane.

# Common Errors
- Confusing chordal polytonality with polychordal writing (polytonality requires independent key progression)
- Neglecting shifting pedals that ease dense textures
- Failing to maintain each plane's key identity through progression

# Common Confusions
- **Chordal polytonality vs. polychords**: Polychords are single complex vertical structures; chordal polytonality involves independent harmonic progressions in each layer
- **Density management**: Block-chord polytonality can become very thick; shifting pedals and textural relief are essential
- **Vertical vs. horizontal**: Chordal polytonality emphasizes vertical harmonic identity; horizontal emphasizes linear melodic identity
