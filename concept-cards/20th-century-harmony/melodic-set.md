# Quick Definition
Any succession of any number of tones, not necessarily all different, that serves as the basis for serial harmonic organization, subject to transposition, inversion, retrograde, and retrograde inversion operations.

# Core Definition
Any succession of any number of tones, not necessarily all different, may be used in two or more voices at once, forming harmony from horizontal movement, or divided between voices, forming harmony from vertical telescoping. The melodic set may employ twelve different notes or fewer and may be transposed, inverted, retrograded, or subjected to retrograde inversion. Contrasting thematic material may be built upon a new but related melodic set derived by selecting the top notes of a series of telescoped chords from the original set.

# Prerequisites
- **Serial harmony**: The compositional framework in which sets function

# Key Properties
1. Any succession of any number of tones (not restricted to twelve)
2. Notes need not all be different
3. Four basic operations: Original, Retrograde, Inversion, Retrograde Inversion
4. Each form transposable to all twelve pitch levels
5. New sets derivable from original (e.g., selecting top notes of telescoped chords)
6. Identical chords between set forms can serve as pivot formations
7. When set includes repeated notes, serial doublings occur
8. Parallel harmony possible at doubling points

# Construction / Recognition
- Identify the pitch succession that governs a passage
- Track the four operations (O, R, I, RI) and transpositions
- Note whether the set uses twelve, fewer, or repeated notes
- Find identical chords between set forms (potential pivots)
- Look for derived sets created from telescoped chord top notes
- Identify doubling points where parallel harmony may appear

# Context & Application
In an extended passage or section of free serial music, any combination of tones may be set up as a tonality. A succession of three or more notes from the selected melodic set may be used as a center chord. When melodic sets employ twelve different notes, successive chords encompass the entire twelve-tone field. A strong center or harmonic area may result from the completion or fulfillment of the twelve-tone set. The set's construction determines the harmonic vocabulary available for the composition.

# Common Errors
- Assuming sets must use all twelve tones
- Requiring all notes to be different
- Treating the set as a rigid rule rather than a compositional resource

# Common Confusions
- **Not restricted to twelve**: Persichetti explicitly allows any number of tones, not necessarily all different
- **Derivation**: New sets can be organically derived from original through telescoping
- **Doubling**: When the set contains repeated notes, the resulting serial doublings create unique textural effects
