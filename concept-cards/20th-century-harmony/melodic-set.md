# Quick Definition
Any succession of tones, not necessarily all different, that serves as the basis for serial harmonic organization.

# Formal Definition
A melodic set is any succession of any number of tones, not necessarily all different, that may be used as a unifying basis for serial composition. The set may employ twelve different notes, all twelve or fewer, and may be transposed, inverted, retrograded, or subjected to retrograde inversion. Contrasting thematic material may be built upon a new but related melodic set derived from the original.

# Musical/Mathematical Formulation
Melodic set operations:
- **Original (O)**: The basic set form
- **Retrograde (R)**: Set reversed
- **Inversion (I)**: Intervals inverted
- **Retrograde Inversion (RI)**: Both reversed and inverted
- **Transposition**: Set at different pitch levels

Set relationships:
- Identical chords between forms can serve as pivot formations
- Closely related sets: I or RI starting P5 above/below original
- New sets derived by selecting top notes of telescoped chords

When set includes identical notes:
- Doubling of chord members occurs
- Produces colorful serial doublings
- Parallel harmony may be used momentarily at doubling points

# Musical Context/Application
The melodic set provides a unifying basis for extended passages or entire works. In free serial music, any combination of tones from the set may establish a "tonality." Three or more notes may form a center chord, with transpositions and mirrors forming primary and secondary harmonies. The set's construction determines the harmonic vocabulary available for the composition.

# Common Confusions
- Melodic sets need not use all twelve tones
- Notes in the set need not all be different
- The set is a compositional resource, not a rigid rule
