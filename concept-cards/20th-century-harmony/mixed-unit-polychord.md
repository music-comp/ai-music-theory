# Quick Definition

A polychord combining different types of chordal units (triads with quartal, secundal with tertian, etc.), where triads placed below quartal chords create linear freedom and seconds function best as the uppermost unit.

# Core Definition

"Quartal and secundal units are used with those by thirds in a polychord of mixed chordal units. Chords by seconds function sonorously as the uppermost unit of a multi-unit polychord of mixed chordal construction" (Persichetti, p. 154). "When combining chords by fourths with triads, place the triads below for linear freedom whether the fourths are perfect or augmented" (p. 155). "Triads are placed above for less resonant but useful subtle chords of a darker texture" (p. 156).

# Key Properties

1. Combines different chord types in one polychord (triads + quartal, triads + secundal, etc.)
2. Triads below quartal chords = linear freedom (with perfect or augmented fourths)
3. Triads above quartal chords = less resonant, subtle, darker texture
4. Seconds function best as uppermost unit
5. More stable/resonant units toward bottom; more dissonant/focused toward top
6. Greatest variety of polychordal color among all types

# Construction / Recognition

## To Construct Mixed-Unit Polychords
1. Select unit types for desired combination (triad + quartal, triad + secundal, etc.)
2. Place more stable/resonant units lower, more dissonant/focused units higher
3. For triads with quartal: triads below for freedom, above for darker quality
4. Place secundal units as the topmost unit for best sonorous effect

# Context & Application

Mixed-unit polychords offer the greatest variety of polychordal color, combining the strengths of different chord types: triads (stability, resonance), quartal chords (open sound, ambiguity), secundal chords (focus, intensity). Careful attention to unit placement ensures clarity and effective blending.

# Common Errors

- **Error**: Placing secundal units at the bottom of mixed polychords
  **Correction**: Seconds function best as the uppermost unit for sonorous effect
- **Error**: Placing quartal chords below triads when wanting linear freedom
  **Correction**: Triads below quartal chords provide linear freedom; the reverse creates darker but less mobile texture

# Common Confusions

- **Confusion**: Mixed units are random combinations
  **Clarification**: Placement affects result profoundly; systematic principles govern effectiveness
- **Confusion**: "Linear freedom" means melodic range
  **Clarification**: It refers to voice-leading possibilities within the texture
