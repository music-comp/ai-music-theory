# Quick Definition
A polychord combining different types of chordal units (triads with quartal, secundal with tertian, etc.), where triads placed below quartal chords create linear freedom, and chords by seconds function sonorously as the uppermost unit.

# Formal Definition
Quartal and secundal units are used with those by thirds in a polychord of mixed chordal units. Chords by seconds function sonorously as the uppermost unit of a multi-unit polychord of mixed chordal construction. The polychordal combination of the triad with other chordal formations creates an additional and useful polychordal category.

# Musical/Mathematical Formulation
Mixed combinations:

**Triads with quartal chords**:
- Place triads below for linear freedom (perfect or augmented fourths)
- Triads above for less resonant but subtle, darker texture
- Quartal above = more open sound
- Quartal below = darker foundation

**Triads with secundal chords**:
- Seconds function best as uppermost unit
- Creates bright, focused top
- Triad provides stable foundation

**Other combinations**:
- Quartal with secundal
- Seventh chords with any of the above
- Multiple non-triadic types

Voicing principle:
- More stable/resonant units toward bottom
- More dissonant/focused units toward top
- Follows natural acoustic principles

# Musical Context/Application
Mixed-unit polychords offer the greatest variety of polychordal color. They combine the strengths of different chord types:
- Triads: stability, resonance
- Quartal: open sound, ambiguity
- Secundal: focus, intensity

The combination creates textures impossible with homogeneous polychords. Careful attention to unit placement ensures clarity and effective blending.

When combining chords by fourths with triads:
- Triads below = maximum linear freedom
- Triads above = subtle, darker quality
- Both valid but very different

# Common Confusions
- Mixed units are not random combinations; placement affects result
- "Linear freedom" refers to voice-leading possibilities, not melodic range
- The same units in different positions create very different sounds
- Seconds at top is a principle, not an absolute rule
