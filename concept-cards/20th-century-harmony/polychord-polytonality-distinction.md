# Quick Definition
The important distinction that polyharmony is seldom polytonal: polychords are simultaneous combinations of chords from different harmonic areas, while polytonality requires those chordal units to adhere to separate keys over time.

# Formal Definition
Polyharmony is seldom polytonal. Polytonality is present only when the chordal units that make up the structure adhere to separate keys. Polychords that are not polytonal are considerably more flexible and versatile; the harmonic areas of both chordal units shift often.

# Musical/Mathematical Formulation
Key distinctions:

**Polychord (non-polytonal)**:
- Two or more chords from different harmonic areas
- Harmonic areas may shift freely
- No requirement for key adherence
- More flexible and versatile
- Most polychords are this type

**Polytonal polychord**:
- Chordal units adhere to separate keys
- Keys maintained over time
- More restricted
- Less common in practice

Practical implications:
- Non-polytonal polychords: Units can move to any harmonic area
- Polytonal polychords: Units must maintain key allegiance
- The same sonority can be either depending on context

# Musical Context/Application
This distinction matters for both composition and analysis. Much music labeled "polytonal" is actually polychordal without true key adherence. Understanding the difference allows:

- More accurate analysis of 20th-century music
- Greater compositional flexibility when non-polytonal approach used
- Recognition that the freedom of polychordal writing is its strength
- Appropriate choice between techniques based on desired effect

The rare true polytonality requires maintaining separate functional progressions in each key, a significant compositional constraint.

# Common Confusions
- "Polytonal" is often misused to describe any music with polychords
- Most polyharmony is not polytonal (key-adherent)
- The flexibility of non-polytonal polychords is an advantage, not a deficiency
- True polytonality is compositionally demanding and relatively rare
