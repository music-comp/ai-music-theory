# Quick Definition

The critical distinction that polyharmony is seldom polytonal: polychords combine chords from different harmonic areas, while polytonality requires those units to adhere to separate keys over time.

# Core Definition

"Polyharmony is seldom polytonal. Polytonality is present only when the chordal units that make up the structure adhere to separate keys. Polychords that are not polytonal are considerably more flexible and versatile; the harmonic areas of both chordal units shift often" (Persichetti, p. 135).

# Prerequisites

- **Polychord** — The distinction clarifies a fundamental property of polychords

# Key Properties

1. Most polyharmony is not polytonal
2. Polytonality requires chordal units to adhere to separate keys over time
3. Non-polytonal polychords are more flexible and versatile
4. In non-polytonal polychords, harmonic areas shift freely
5. The same sonority can be either type depending on context
6. True polytonality requires maintaining separate functional progressions

# Construction / Recognition

## To Distinguish Polychord from Polytonal Polychord
1. Check whether each chordal unit maintains allegiance to a specific key over time
2. If units shift harmonic areas freely: non-polytonal polychord (most common)
3. If units adhere to separate keys: polytonal polychord (rare)
4. Context over several measures determines the classification

# Context & Application

This distinction matters for both composition and analysis. Much music labeled "polytonal" is actually polychordal without true key adherence. The freedom of non-polytonal polychordal writing is its strength, allowing harmonic areas to shift without constraint.

# Common Errors

- **Error**: Labeling any polychordal passage as "polytonal"
  **Correction**: Polytonality requires key adherence; most polyharmony freely shifts harmonic areas

# Common Confusions

- **Confusion**: "Polytonal" and "polychordal" are synonyms
  **Clarification**: Polychordal refers to simultaneous chord combination; polytonal requires simultaneous key adherence. Most polychords are not polytonal
- **Confusion**: Non-polytonal polychords lack structure
  **Clarification**: The flexibility of shifting harmonic areas is an advantage, providing greater compositional freedom
