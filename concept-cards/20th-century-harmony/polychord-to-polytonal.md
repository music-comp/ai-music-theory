# Quick Definition
The transformation from polychordal harmony to polytonal texture that occurs when each voice group within a polychordal unit begins to function independently within its own stable scale zone, progressing horizontally rather than merely combining vertically.

# Core Definition
Polychordal writing is often tonal, and when each group of voices within a chordal unit functions within the confines of a stable scale zone, polytonality occurs. The harmonic units of a tonal polychordal succession may meet at a point where each progresses in a separate and consistent key zone. The polychordal progression then becomes polytonal. This represents the organic development from static polychordal sonority to active polytonal texture.

# Prerequisites
- **Polychord**: The starting vertical sonority
- **Polytonality**: The resulting multi-key texture

# Key Properties
1. Polychords are starting point -- vertical combinations that may or may not be tonal
2. Polytonal transformation occurs when each layer gains horizontal independence
3. Each voice group must function within a stable scale zone
4. The difference is progressive independence, not just vertical combination
5. The same sonority can be polychordal or polytonal depending on context

# Construction / Recognition
- Start with a polychordal succession
- Give each component chord group its own scale-zone progression
- Maintain consistent key identity in each layer
- The transition point is where layers begin independent horizontal movement
- Verify each layer has its own tonal logic, not just vertical participation

# Context & Application
This transformation represents the organic development from static polychordal sonority to active polytonal texture. The polychordal progression provides the harmonic material; the independent key-zone movement provides the polytonal life. The technique shows that polytonality naturally emerges from polychordal writing when layers gain horizontal independence and consistent key identities.

# Common Errors
- Treating all polychords as automatically polytonal
- Failing to give each layer independent key-zone progression
- Confusing vertical combination with horizontal independence

# Common Confusions
- **Polychord vs. polytonality**: A polychord is a vertical combination; polytonality requires independent horizontal progression in distinct key zones
- **Context-dependent**: The same sonority is polychordal when static and polytonal when each layer progresses independently
- **Scale zone stability**: Each layer must maintain a consistent key identity to qualify as polytonal
