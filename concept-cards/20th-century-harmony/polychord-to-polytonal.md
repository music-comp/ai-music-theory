# Quick Definition
The transformation from polychordal harmony to polytonal texture when each voice group within a polychord begins to function in its own stable scale zone.

# Formal Definition
Polychordal writing is often tonal, and when each group of voices within a chordal unit functions within the confines of a stable scale zone, polytonality occurs. The harmonic units of a tonal polychordal succession may meet at a point where each progresses in a separate and consistent key zone. The polychordal progression then becomes polytonal.

# Musical/Mathematical Formulation
Transformation process:
1. **Polychord stage**: Multiple triads or chords combined vertically
2. **Voice group independence**: Each layer begins following its own scale
3. **Key zone stability**: Each layer maintains consistent key identity
4. **Polytonal result**: Multiple simultaneous functioning keys

Distinction:
- **Polychord**: Vertical combination, may or may not be tonal
- **Polytonality**: Multiple keys functioning simultaneously with progression

# Musical Context/Application
This transformation represents the organic development from static polychordal sonority to active polytonal texture. The difference lies in whether the components are merely combined vertically (polychord) or whether they progress independently within their own key zones (polytonality). Polytonality thus emerges from polychordal writing when voice groups gain horizontal independence.

# Common Confusions
- Polychords are static vertical combinations; polytonality involves progression
- The same sonority can be polychordal or polytonal depending on context
- Polytonal texture requires each layer to function within a key
