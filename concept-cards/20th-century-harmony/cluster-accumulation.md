# Quick Definition

The building of large clusters through the additive use of chords by thirds, fourths, polychords, or smaller clusters, creating massive sonorities through gradual accumulation.

# Core Definition

"Large clusters may accumulate through the additive use of chords by thirds or fourths, polychords, or smaller clusters" (Persichetti, p. 129). "Ornamental tones increase harmonic circulation in passages of clusters" (p. 131).

# Prerequisites

- **Tone cluster** — Accumulation is a process that builds toward clusters

# Key Properties

1. Accumulation sources: chords by thirds, chords by fourths, polychords, smaller clusters
2. Process: begin with identifiable harmonic unit, add successive units, allow sustained tones to merge
3. Ornamental tones increase harmonic circulation within static cluster passages
4. When clusters appear with chords by thirds or fourths, functional root relationships can operate

# Construction / Recognition

## To Build a Cluster Through Accumulation
1. Begin with a smaller, identifiable harmonic unit (triad, quartal chord, smaller cluster)
2. Add successive units of same or different type
3. Allow sustained tones to accumulate
4. Result: large cluster built from discrete, audible additions

# Context & Application

Cluster accumulation provides a compositional pathway from familiar harmonic materials to complex cluster sonorities. Rather than presenting clusters as abrupt foreign sounds, the technique integrates them into broader harmonic development. This is particularly valuable for creating climactic passages through gradual density increase, integrating cluster harmony with tertian/quartal contexts, and making dense harmony accessible through audible construction.

# Common Errors

- **Error**: Beginning with the full cluster rather than building toward it
  **Correction**: Accumulation is a process; start with identifiable smaller units and build gradually
- **Error**: Confusing ornamental tones with accumulation
  **Correction**: Ornamental tones add movement within clusters; accumulation adds mass

# Common Confusions

- **Confusion**: Accumulation is a chord type
  **Clarification**: It is a process or technique, not a chord classification
- **Confusion**: Component harmonies always merge completely
  **Clarification**: They may remain audible as distinct additions or merge into undifferentiated mass; both are valid
