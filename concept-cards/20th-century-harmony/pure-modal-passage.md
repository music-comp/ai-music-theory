# Quick Definition
A passage where a modal melody is harmonized with chords from the same mode and on the same tonal center, creating unified modal color.

# Core Definition
A pure modal passage is one in which a modal melody is harmonized with chords from the same mode and on the same tonal center. Although shifting modes are effective on a stationary key center, much melodic reference must be made to the tonic if one wishes to stay within the mode; otherwise the tonality will switch to major under the ionic power of the tritone. Melodic circling or chant-like repetition of the tonic tone and frequent cadences will help maintain the center.

# Prerequisites
- **diatonic-modes** -- the mode providing both melody and harmony
- **primary-modal-chords** -- the harmonic vocabulary used

# Key Properties
1. **Melody**: uses only tones from one mode
2. **Harmony**: uses only chords from the same mode
3. **Tonal center**: both share the same tonic
4. **Characteristic step**: emphasized in both melody and harmony
5. **Tonic maintenance techniques**: melodic circling, chant-like repetition, frequent cadences
6. **Tritone threat**: the ionic power of the tritone constantly pulls toward major

# Construction / Recognition
1. Verify melody uses only tones from the specified mode
2. Verify all chords are diatonic to the same mode
3. Confirm shared tonal center
4. Check for frequent emphasis on the characteristic scale step
5. Look for tonic-reinforcement techniques (circling, repetition, cadences)

# Context & Application
Pure modal passages maintain a single, consistent modal identity. They contrast with polymodal writing where different modes or tonal centers create layered textures. While shifting modes are effective, maintaining pure modal writing requires deliberate consistency and attention to the tritone's pull toward major. Most effective when the characteristic step appears prominently in both melody and harmony.

# Common Errors
- **Error**: Assuming all modal music is "pure modal." **Correction**: Many modal passages involve polymodality, modal interchange, or foreign harmony; pure modal requires deliberate consistency.

# Common Confusions
- **Confusion**: Thinking pure modal writing is "simpler" than polymodal. **Clarification**: Maintaining pure modal identity against the pull of the tritone requires sophisticated technique.
