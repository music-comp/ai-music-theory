# Quick Definition
The seven distinct seventh chord qualities constructible using only major and minor thirds, each with its own color and character, all equally available as independent sonorities in twentieth-century practice.

# Core Definition
It is possible to build seven different seventh chords with major and minor third construction. Seventh chords with augmented and diminished thirds are misspellings of other chords. Each of the seven types has a distinct color and character. Great variety in seventh chord texture can be had through doubling (any note may be doubled) and inversion. Sevenths may be inverted and spaced in any manner without destroying their harmonic suppleness. The first inversion spaced in fifths is particularly useful because its unique sound enables it to act as a key center chord.

# Prerequisites
- **Triads in twentieth-century harmony**: The four basic triad types from which sevenths extend

# Key Properties
1. Exactly seven types possible with major and minor third construction
2. Augmented and diminished third constructions are misspellings
3. Any note may be doubled
4. All inversions and spacings preserve harmonic suppleness
5. First inversion spaced in fifths = key center chord
6. Moving through different types on one root creates harmonic motion
7. Each type has a distinct expressive character

| 7 | M3+M3+m3 | Augmented-major seventh | C-E-G#-B |

# Context & Application
In twentieth-century practice, all seven types function as independent, stable sonorities. The minor-major seventh and augmented-major seventh, rarely used in common-practice music, become valuable resources. Composers create harmonic progressions by moving through various seventh chord types, using their color differences as an expressive resource. The progression from one type to another on the same root creates harmonic motion without root movement -- a distinctly twentieth-century technique.

# Common Errors
- Thinking only the dominant seventh is a standard type
- Using augmented or diminished thirds in seventh chord construction (these are misspellings)

# Common Confusions
- **Minor-major seventh**: Often unfamiliar to students, this type (m3+M3+M3) has a distinctive dark-bright quality
- **Augmented-major seventh**: Built on an augmented triad (M3+M3) with a major seventh, equally rare in common practice but available in twentieth-century harmony
