# Quick Definition
Chords containing equal numbers of thirds and fourths that can function as either tertian or quartal sonorities, serving as pivot points between the two harmonic systems.

# Core Definition
Thirteenth chords and multi-note quartal chords often contain the same notes. The similarity is theoretical, not aural. If thirds overrun a six- or seven-note chord, the ear hears a thirteenth formation. If fourths overrun, a chord by fourths sounds. If the number of thirds and fourths is equal, the chord may be used as a pivotal structure and regarded as belonging to either the tertian or quartal category, or to both. The arrangement and emphasis of intervals affects perception: grouped thirds = tertian; grouped fourths = quartal; mixed = ambiguous/pivotal.

# Prerequisites
- **Multi-note quartal chords**: Six-or-more-note quartal formations
- **Thirteenth chords**: The tertian equivalent with similar pitch content

# Key Properties
1. Same pitch content can sound tertian or quartal depending on interval dominance
2. More thirds = tertian (thirteenth); more fourths = quartal
3. Equal thirds and fourths = pivotal (both/either)
4. Voicing/arrangement determines perceived identity
5. Grouped intervals strengthen one identity; mixed = ambiguity
6. Pivotal structures enable smooth modulation between harmonic systems

# Construction / Recognition
- Count thirds vs. fourths in the chord's construction
- More thirds: tertian dominant identity
- More fourths: quartal dominant identity
- Equal: pivotal -- can function as either
- Check voicing: grouped vs. mixed arrangement affects perception

# Context & Application
Pivotal structures enable smooth modulation between harmonic systems: approach from tertian context, the pivotal chord functions as both, then depart into quartal context (or vice versa). This is valuable for composers working with mixed harmonic vocabularies.
