# Quick Definition
The application of the modal construction principle to any synthetic scale, creating multiple versions by starting on different scale degrees.

# Formal Definition
The modal construction principle that produced the seven diatonic modes (dorian, phrygian, etc.) may be applied to any scale, creating multiple versions. The first modal version of any scale begins on the tonic, the second on the supertonic of that scale, and so forth. This extends the concept of modality beyond the seven diatonic modes.

# Musical/Mathematical Formulation
Modal version generation:
- Version 1: begins on scale degree 1
- Version 2: begins on scale degree 2
- Version 3: begins on scale degree 3
- Continue through all scale degrees

Number of modes:
- 5-note scale: 5 modal versions
- 6-note scale: 6 modal versions (except whole-tone)
- 7-note scale: 7 modal versions
- Symmetrical scales: fewer unique versions due to repetition

# Musical Context/Application
Each modal version of a synthetic scale has its own intervallic character and harmonic implications. Transposing all versions to the same tonic allows comparison of their distinct qualities. This technique multiplies the harmonic resources available from a single synthetic scale.

# Common Confusions
Students may think of modes as applying only to the diatonic collection. Any scale with unequal interval distribution produces distinct modal versions, each potentially useful for composition.
