# Quick Definition
The application of the modal construction principle to any synthetic scale, creating multiple versions by starting on different scale degrees -- multiplying harmonic resources.

# Core Definition
The modal construction principle that produced the seven diatonic modes may be applied to any scale, creating multiple versions. The first modal version begins on the tonic, the second on the supertonic, and so forth. A 7-tone scale produces 7 modes, a 5-tone produces 5, a 6-tone produces 6 (except for symmetrical scales like the whole-tone, where rotations produce transpositions rather than new modes). Each modal version has its own intervallic character and harmonic implications. Transposing all versions to the same tonic allows comparison of their distinct qualities.

# Key Properties
1. **Number of modes = number of scale degrees** (for asymmetrical scales)
2. **Symmetrical scales**: fewer unique versions (rotations = transpositions)
3. **Each mode is unique**: different intervallic character and harmonic implications
4. **Same-tonic comparison**: transposing all modes to one tonic reveals their differences
5. **Multiplier effect**: one scale generates many harmonic-melodic resources

# Construction / Recognition
1. Write the original scale
2. Begin on the second degree and maintain the same pitches -- this is mode 2
3. Continue through all degrees
4. Transpose all modes to the same tonic for comparison
5. For symmetrical scales, check whether rotations duplicate existing modes

# Context & Application
This technique multiplies the harmonic resources available from a single synthetic scale. Each modal version has its own character, and composers can select the version best suited to a particular passage. The technique extends the concept of modality beyond the seven diatonic modes to an unlimited number of modal possibilities.

# Common Errors
- **Error**: Thinking modes apply only to the diatonic collection. **Correction**: Any scale with unequal interval distribution produces distinct modal versions.

# Common Confusions
- **Confusion**: Assuming all modes of a scale are equally useful. **Clarification**: Some modes may contain awkward intervals or lack strong tonic definition; practical assessment is needed.
