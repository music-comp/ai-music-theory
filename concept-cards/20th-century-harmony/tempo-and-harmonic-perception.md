# Quick Definition
The relationship between tempo and how harmony is perceived, where quick tempo can make chord changes sound ornamental and simple chords moving rapidly can create complex sounds.

# Core Definition
**Tempo** can be a determining factor in harmonic rhythm. Quick tempo may cause chord changes to sound like ornamental chords rather than structural harmonic events. Simple chords moving at a high rate of speed may create relatively complex sounds as rapid succession blurs individual chord identities. Harmonic rhythm does not move when chords are repeated, regardless of tempo (Ch. 10, pp. 212-213).

# Prerequisites
- **Harmonic rhythm** -- understanding chord-change pacing

# Key Properties
1. Fast tempo + chord changes = changes perceived as ornamentation
2. Fast tempo + simple chords = perception of complexity
3. Slow tempo + complex chords = individual character clarified
4. Repeated chords do not create harmonic rhythm movement at any tempo
5. Harmonic complexity is partly a function of temporal presentation

# Construction / Recognition
- Note the tempo and assess whether chord changes read as structural or ornamental
- Check whether simple chords at speed create perceived complexity
- Observe whether slow tempo clarifies complex harmonic detail

# Context & Application
The principle that harmonic complexity is partly a function of tempo enables creating perceived complexity through simple means at fast tempos, clarifying complex harmony through slow presentation, and using tempo as a compositional parameter affecting harmonic character.

# Examples
**Example** (Ch. 10, Ex. 10-1, p. 212): Quick tempo causing chord changes to sound ornamental; simple chords at high speed creating complex sounds.

# Common Errors
- Ignoring how tempo changes the perceived harmonic complexity
- Assuming that what looks complex in the score always sounds complex

# Common Confusions
- **Complexity source**: Perceived complexity can arise from tempo as much as from chord construction
- **Score vs. sound**: Score appearance may not reflect perceptual reality at performance tempo
