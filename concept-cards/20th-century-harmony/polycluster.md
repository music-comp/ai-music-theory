# Quick Definition

Two or more clusters sounding simultaneously with sufficient space between units to allow distinct perception, with roots forming chords by seconds, triads, or fourths.

# Core Definition

"Two or more clusters, derived from one scale or different scales, may be used simultaneously as a polycluster. The roots of the various cluster units of a polycluster may form a chord by seconds (a), a triad (b), or a chord by fourths (c). Space must be left between the cluster units to allow them to sound distinctly. The larger each cluster, the wider must be the space" (Persichetti, p. 129). "The number of contrapuntal voices involved in polycluster harmony is automatically doubled if the cluster sizes fluctuate. Each cluster is then outlined by two independent voices" (p. 130).

# Prerequisites

- **Tone cluster** — Polyclusters combine multiple clusters
- **Polychord** — The principle of simultaneously combining distinct harmonic units applies

# Key Properties

1. Two or more clusters sounding simultaneously
2. Derived from one scale or different scales
3. Root relationships: by seconds, by thirds (triadic), or by fourths
4. Spacing proportional to cluster size: larger clusters need wider gaps
5. Insufficient space causes units to merge into single cluster
6. Fluctuating sizes automatically double the contrapuntal voice count
7. Each cluster outlined by two independent boundary voices (top and bottom)

# Construction / Recognition

## To Construct a Polycluster
1. Select two or more cluster units (same or different scale sources)
2. Determine root relationship (by seconds, triads, or fourths)
3. Space units far enough apart for distinct perception
4. Ensure larger clusters have wider spacing between them
5. Allow cluster sizes to fluctuate for contrapuntal interest

# Context & Application

Polyclusters extend the polychordal principle to secundal harmony. They create massive, complex sonorities while maintaining structural clarity through unit separation. The technique is most effective when the ear can distinguish component clusters. When cluster sizes fluctuate, each cluster requires at least two boundary voices, automatically multiplying the contrapuntal voice count.

# Common Errors

- **Error**: Placing cluster units too close together
  **Correction**: Units must be separated by enough space for distinct perception; larger clusters need wider gaps
- **Error**: Treating polyclusters as single large clusters
  **Correction**: The distinct-unit structure is essential; merged units form a single cluster, not a polycluster

# Common Confusions

- **Confusion**: Polyclusters are simply big clusters
  **Clarification**: Polyclusters are structured combinations of separate cluster units, not undifferentiated masses
- **Confusion**: The root relationship is a tonal function
  **Clarification**: Root relationships (by seconds, thirds, fourths) provide structural organization but not functional tonal gravity
