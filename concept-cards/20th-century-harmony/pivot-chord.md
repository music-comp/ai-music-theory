# Quick Definition
A chord common to two keys that serves as the transitional link between them during modulation.

# Formal Definition
A pivotal chord is one that is common to both keys in a modulation. It is diatonic when belonging to both scale formations and chromatic when it belongs to neither, or only to one. It is not always clear just which formation is the pivot chord - this only enhances modulatory beauty. The pivot chord provides the seamless connection between tonal areas.

# Musical/Mathematical Formulation
Pivot chord types:
- **Diatonic pivot**: Chord belongs to scales of both keys
- **Chromatic pivot**: Chord belongs to neither scale or only one

Pivot chord characteristics:
- Functions in both departing and arriving keys
- May be reinterpreted enharmonically
- Ambiguity about which chord is pivot enhances musical interest

In serial harmony:
- When chord from one form of melodic set is identical to chord of another form, it may serve as pivot formation when entering new "tonal" areas
- Closely related areas found by constructing inversion/retrograde inversion starting fifth above/below original set

# Musical Context/Application
The inherent ambiguity of any chord - its ability to relate to any of the twelve tonal centers - makes pivot chord modulation flexible and natural. The uncertainty about exactly which chord functions as the pivot adds to modulatory beauty rather than detracting from it. In serial contexts, identical chords between different set forms can serve as pivot formations between serial "tonal" areas.

# Common Confusions
- Pivot chord ambiguity is a feature, not a problem
- Chromatic pivots work even when belonging to only one of the keys
- Serial music has pivot formations analogous to tonal pivot chords
