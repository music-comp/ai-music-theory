# Quick Definition
A chord common to both the departing and arriving keys that serves as the transitional link during modulation, classified as diatonic when belonging to both scales or chromatic when belonging to neither or only one.

# Core Definition
A pivotal chord is one that is common to both keys in a modulation. It is diatonic when belonging to both scale formations and chromatic when it belongs to neither, or only to one. It is not always clear just which formation is the pivot chord -- this only enhances modulatory beauty. The inherent ambiguity of any chord, its ability to relate to any of the twelve tonal centers, makes pivot chord modulation flexible and natural.

# Prerequisites
- **Modulation**: The process the pivot chord facilitates
- **Tonality**: The organizational framework in which pivots function

# Key Properties
1. Diatonic pivot: belongs to scales of both keys
2. Chromatic pivot: belongs to neither scale or only one
3. Ambiguity about which chord is the pivot enhances musical interest
4. Any chord can relate to any of twelve tonal centers
5. In serial music, identical chords between set forms serve as pivot formations
6. Closely related serial areas found through inversion/retrograde inversion starting a fifth above/below

# Construction / Recognition
- Identify the chord that plausibly belongs to both the old and new key
- Determine whether the pivot is diatonic (in both scales) or chromatic
- Accept that pivot identification may be ambiguous
- In serial contexts, find identical chords between different forms of the melodic set
- Closely related serial areas: construct inversion or retrograde inversion starting P5 above or below original set

# Context & Application
The uncertainty about exactly which chord functions as the pivot adds to modulatory beauty rather than detracting from it. In serial contexts, when a chord from one form (original, retrograde, inversion, or retrograde inversion in any transposition) of the melodic set is identical to a chord of another form of the set, it may be used as a pivot formation when entering new "tonal" areas. Closely related harmonic areas are those found by constructing an inversion or retrograde inversion starting a perfect fifth above or below the original set.

# Common Errors
- Insisting on identifying a single definitive pivot chord
- Overlooking chromatic pivots
- Failing to recognize serial pivot formations

# Common Confusions
- **Ambiguity as feature**: Not knowing which chord is the pivot enhances rather than diminishes the modulation
- **Chromatic pivots**: These work even when belonging to only one of the keys
- **Serial pivots**: Analogous to tonal pivots but operate between set forms rather than scale formations
