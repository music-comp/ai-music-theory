# Quick Definition
Modulation achieved by shifting an entire chord a half step through sudden parallel motion, creating an immediate but initially insecure key change that requires extended harmonic progression to establish.

# Core Definition
Chromatic modulation is attained by shifting an entire chord a half step in sudden parallel harmony. Abrupt modulations make the arriving tonic felt as a distant chord; to establish a firm feeling of the new key, an extended harmonic progression is necessary in order to secure the new center. All chromatic tones are in the domain of a key when the vertical aspect gives way to the horizontal movement of voices; therefore, all keys have twelve tones in common and may be reached quickly chromatically.

# Prerequisites
- **Modulation**: The broader process of key change

# Key Properties
1. Mechanism: half-step parallel shift of an entire chord
2. The arriving tonic initially feels distant
3. Extended progression required to confirm new key
4. All keys share twelve tones chromatically
5. Any key can be reached quickly through chromatic motion
6. Produces dramatic harmonic jolt

# Construction / Recognition
- Identify sudden parallel motion of all voices by semitone
- Note whether the new key is confirmed by subsequent progression
- Assess whether the arrival feels established or merely transient
- Count the number of confirming chords after the chromatic shift
- Distinguish from transient chromatic shifts that do not establish a new key

# Context & Application
Chromatic modulation provides immediate key shift but requires follow-through. The sudden parallel motion creates a dramatic harmonic jolt, but the new key is not secure until an extended progression establishes it. The universality of chromatic resources means all keys are equidistant chromatically -- horizontal voice movement encompasses all twelve tones regardless of notional key. This technique is effective for dramatic effect but should not substitute for organic harmonic development.

# Examples
- Chromatic modulation through half-step parallel chord motion
- Extended progression following chromatic shift to secure new center

# Common Errors
- Assuming the chromatic shift alone establishes the new key
- Failing to provide extended confirmation in the new key
- Overusing chromatic modulation at the expense of harmonic depth

# Common Confusions
- **Shift vs. establishment**: The half-step shift creates arrival but not confirmation; confirmation requires extended progression
- **Chromatic equidistance**: All keys are equally accessible chromatically because all share twelve tones through horizontal voice movement
- **Dramatic effect vs. structural modulation**: Chromatic modulation is more suited to dramatic moments than to large-scale tonal planning
