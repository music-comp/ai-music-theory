# Quick Definition
A special added-note category: a close-position triad (major, minor, diminished, or augmented) in the upper voices with a note forming a major or minor second with any triadic member added as the bottom voice, yielding thirty-six possible structures governed by the upper melodic line rather than by traditional functional harmony.

# Core Definition
A triad (major, minor, diminished, or augmented) is placed in the upper voices and a major or minor second above or below any of the members is added as the bottom voice, often in octaves for balance. A wide variety of chordal structures is possible; there are thirty-six such chords. Although some resemble traditional chords by thirds, they do not function as such in an added-note context. Progression is often governed by an upper melodic line. This type is most effective when used in progressions consisting solely of this type; primary and secondary relationships are not relevant, melody being the governing factor.

# Prerequisites
- **Added-note spacing**: Wide spacing placing the added note outside the octave

# Key Properties
1. Thirty-six possible structures (4 triad types x 3 members x 3 bass positions)
2. Upper voices: close-position triad
3. Bass: M2 or m2 above/below any triadic member
4. Bass often doubled at octave for balance
5. Some resemble traditional chords but do not function traditionally
6. Progression governed by upper melodic line
7. Primary/secondary relationships irrelevant
8. Most effective in progressions using solely this type
9. Textural consistency from consistent spacing

# Construction / Recognition
- Place close-position triad in upper voices
- Add bass note forming second with any triadic member
- Progression follows the melody, not harmonic function
- Consistent chord type throughout a passage

# Context & Application
This technique liberates harmony from traditional root progression while maintaining triadic sonority. The composer gains wide bass note selection for any melody note, freedom of linear movement, textural consistency, and independence from functional harmony. It works best in passages using only this chord type, avoiding reference to primary/secondary relationships.
