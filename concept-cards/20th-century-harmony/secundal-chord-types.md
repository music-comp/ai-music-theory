# Quick Definition

The four distinct intervallic varieties of three-note secundal chords, classified by the combination of major and minor seconds from bottom to top, arranged from most consonant (major-major) to most dissonant (minor-minor).

# Core Definition

"There are four intervallic types of three-note chords by seconds: major-major, major-minor, minor-major, and minor-minor. Arranged in an order of consonance progressing to dissonance they are: [M-M, M-m, m-M, m-m]" (Persichetti, p. 120). "In major, minor, or the five other modal scales, only the first three types of three-note chords are found naturally; the minor-minor is derived from chromatic or synthetic scales" (p. 122).

# Prerequisites

- **Three-note secundal chord** — The types are classifications within the three-note secundal chord category
- **Consonance-dissonance** — The ordering principle for the four types is based on tension gradation

# Key Properties

1. **Major-Major (M2-M2)**: e.g., C-D-E; outer interval = M3; most consonant; whole-tone flavor
2. **Major-Minor (M2-m2)**: e.g., C-D-Eb; outer interval = m3; moderately dissonant
3. **Minor-Major (m2-M2)**: e.g., C-Db-Eb; outer interval = m3; sharper than M-m due to lower m2
4. **Minor-Minor (m2-m2)**: e.g., C-Db-D; outer interval = M2; most dissonant; chromatic only
5. First three types occur naturally in all seven diatonic modes
6. Minor-minor requires chromatic or synthetic scale sources
7. The naming convention reads intervals from bottom to top

# Construction / Recognition

## To Classify a Three-Note Secundal Chord
1. Identify the bottom interval (major or minor second)
2. Identify the upper interval (major or minor second)
3. Name from bottom up: e.g., M2 + m2 = "major-minor"
4. Check the consonance rank: M-M > M-m > m-M > m-m

## To Find Types in a Scale
1. Build three-note secundal chords on each scale degree
2. Identify the second types at each position
3. Note which of the four types appear (m-m will be absent in diatonic modes)

# Context & Application

The consonance-dissonance spectrum of these four types allows composers to control tension within secundal passages. The natural division between the first three types (diatonic) and the fourth (chromatic) parallels the diatonic/chromatic distinction in tertian harmony.

The choice of type affects overall texture (mild to sharp), compatibility with diatonic or chromatic context, voice-leading complexity, and blend with other harmonic materials.

# Common Errors

- **Error**: Reading intervals top to bottom instead of bottom to top
  **Correction**: Convention names from lowest interval upward: m2-M2 is "minor-major," not "major-minor"
- **Error**: Assuming minor-minor chords occur in diatonic modes
  **Correction**: The minor-minor type requires chromatic or synthetic scales exclusively

# Common Confusions

- **Confusion**: The outer interval defines the chord type
  **Clarification**: The internal seconds define the type; the outer interval is a consequence, not the defining feature
- **Confusion**: "Consonant" means the chord sounds consonant in traditional terms
  **Clarification**: Even the most consonant secundal type (M-M) contains dissonant seconds; consonance is relative within the secundal system
