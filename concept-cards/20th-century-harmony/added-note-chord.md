# Quick Definition
A basic harmonic formation (triad, seventh, or quartal chord) whose textural quality has been modified by tones forming major or minor seconds with any member -- color modifications that change texture rather than function, with the added tones not competing for resolution.

# Core Definition
An added-note chord is a basic harmonic formation whose textural quality has been modified by the imposition of tones not found in the original chord. The tones to be added form one or more major or minor seconds with any member of a chord by thirds or by fourths. These added notes are usually placed a second above or below any member to avoid creating seventh, ninth, compound chords, etc. The added tone or tones are modifying elements attached to a chord of clear directional powers and, as color modifications, change the texture rather than the function of the basic structure. Traditional examples: the cadential tonic six-five and the French augmented sixth chord (Italian + M2 above middle tone).

# Prerequisites
- **Extended tertian harmony**: The tertian base chords receiving added notes
- **Quartal harmony**: Quartal base chords that can also receive added notes

# Key Properties
1. Added notes form M2 or m2 with any chord member
2. Color modification, not functional change
3. Added notes do not compete with seventh/ninth for resolution
4. Added notes cling to inverted as well as fundamental chords
5. May be doubled at will (effective in melodic coupling)
6. Added-note chords are sometimes identical to chords by seconds or compound chords
7. Context determines whether a formation is heard as added-note, secundal, or compound
8. Effective only when clear harmonic progression is felt underneath

# Construction / Recognition
- Start with basic chord (triad, seventh, quartal)
- Add M2 or m2 above or below any member
- Verify the added note does not create a larger basic formation
- Context determines identity: firm progression felt = added-note; no progression = compound
- A large compound chord and a complex added-note chord are often identical in pitch

# Context & Application
Added-note chords function as color variants of their parent structures, preserving harmonic direction while adding textural interest. They are effective only when a clear harmonic progression is implied by the basic chords or previously established without added notes. Without this anchor, complex added-note chords lose identity and merge into compound harmony. Notes may be added to complex chords if the structures are first clearly stated without color tones.

# Common Errors
- Confusing added notes with tertian extensions (added notes = color; extensions = structural expansion)
- Adding notes to complex chords without first establishing the basic progression

# Common Confusions
- **Added-note vs. extension**: Added notes create color without changing function; extensions build larger tertian structures
- **Added-note vs. secundal**: Identical in isolation; only surrounding context determines category
- **Added-note vs. compound**: Identical in pitch; firm progression = added-note; no progression = compound
