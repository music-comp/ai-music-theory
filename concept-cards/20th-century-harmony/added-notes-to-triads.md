# Quick Definition
Major and minor seconds attached above or below any member of major, minor, diminished, or augmented triads -- true color members rivaling the third in color potential, with resonance decreasing as the added note is placed lower in the chord.

# Core Definition
Major and minor seconds may be added not only to augmented sixth formations but to most chords by thirds and fourths. Added notes are not ornamental tones sounding with a chord but true color members that rival the third in color potential. They add spice and increase harmonic density. The lower the added note is placed in the chord the less resonant the formation. Adding above a major third diffuses the rich color of this member; the minor third is less affected. The diminished triad is always sharp-textured regardless of added notes. For augmented triads, M2 additions maintain whole-tone texture; m2 additions create intervallic variety.

# Key Properties
1. Added notes are true color members, not ornamental tones
2. Rival the third in color potential
3. Lower placement = less resonant
4. Major triad + added note above M3 = diffused rich color
5. Minor triad = less affected by added notes
6. Diminished triad = always sharp regardless of addition
7. Augmented triad: M2 = whole-tone texture maintained; m2 = intervallic variety
8. A triad + added note may resemble a ninth chord; context determines identity

# Construction / Recognition
- Add M2 or m2 above or below any triadic member
- Check resonance: higher placement = more resonant
- Verify by context whether the result is added-note or ninth chord
- Four triad types x positions x interval types = comprehensive palette

# Context & Application
This technique is fundamental to Impressionist and twentieth-century composition. The added sixth (major triad + M6) became common in jazz. The added second creates a characteristic "fresh" quality. In some cases a triad with added note resembles a ninth chord; context determines identity.

# Common Confusions
- **Added note vs. extension**: A triad + added second is not the same as a ninth chord with omitted fifth -- context determines identity
- **Resonance hierarchy**: The position of the added note (high vs. low) significantly affects the chord's resonance
