# Quick Definition
Major and minor seconds attached above or below any member of major, minor, diminished, or augmented triads, creating color modifications that add spice and increase harmonic density without changing the triad's basic function.

# Formal Definition
Major and minor seconds may be added above or below any member of a major or minor triad. Added notes are not ornamental tones sounding with a chord but true color members that rival the third in color potential. The lower the added note is placed in the chord, the less resonant the formation becomes.

# Musical/Mathematical Formulation
Placement hierarchy (by resonance, highest to lowest):
- Added note above the fifth
- Added note below the fifth
- Added note above the root
- Added note below the root
- Added note above the third
- Added note below the third (least resonant)

Triad-specific behaviors:
- **Major triad**: Adding above M3 diffuses the rich color of the third
- **Minor triad**: Less affected by added notes than major
- **Diminished triad**: Always sharp-textured regardless of added note placement
- **Augmented triad**: M2 additions maintain whole-tone texture; m2 additions create intervallic variety

36 possible structures:
- 4 triad types x 3 members x 3 placement options (above M2, above m2, below M2, below m2)
- Creates comprehensive palette of added-note triadic sonorities

# Musical Context/Application
This technique was fundamental to the French Impressionist style and became widespread in 20th-century composition. The added sixth (major triad + M6) became particularly common in jazz. The added second creates a characteristic "fresh" quality heard in works by Ravel, Debussy, and later popular music.

In some cases, a triad with an added note may resemble a ninth chord. Context determines the true identity: if the progression implies ninth chord function, it is a ninth chord; if the added tone functions as color modification, it is an added-note chord.

# Common Confusions
- Added note vs. extension: A triad + added second is not the same as a ninth chord with omitted fifth
- The added note does not require resolution like a traditional dissonance
- Placement affects resonance but not function
- Context determines whether a structure is heard as added-note or as larger tertian chord
