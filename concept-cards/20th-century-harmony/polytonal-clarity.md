# Quick Definition
The techniques for maintaining clear distinction between simultaneous tonal planes in polytonal writing, involving tritone definition, registral separation, and sequential introduction.

# Formal Definition
Polytonality is effective as such only when each tonal plane is kept within a clear scale formation. Shifting of modality through chromatic alteration clouds the texture or simply produces miscellaneous polychords. For maximum clarity in the projection of different tonalities, one key is introduced and as the next key is added, the preceding key, having been established, becomes less obvious. The scale steps spanning the tritone should be brought into play as soon as possible.

# Musical/Mathematical Formulation
Clarity requirements:
- Each tonal plane in clear scale formation
- Tritone-spanning scale steps used quickly
- Sufficient registral separation between keys
- Independent lines not placed at random

Sequential introduction:
1. First key introduced and established
2. Second key added
3. First key becomes less prominent
4. Balance achieved between planes

Problems to avoid:
- Closely spaced polytonal areas (muddy)
- Missing tritone-defining tones (ambiguous)
- Chromatic alteration within planes (clouds texture)
- Cramped polytonality (lacks versatility)

# Musical Context/Application
Independent lines should not be placed at random without understanding polytonal construction. Closely spaced polytonal areas become muddy; keys must be kept far enough apart for voice activity. When tritone-defining tones are absent from either key, the result is ambiguously major rather than clearly polytonal. The technique requires careful attention to which tones establish each key's identity.
