# Quick Definition
The techniques for maintaining clear distinction between simultaneous tonal planes, requiring tritone definition in each key, sufficient registral separation, sequential key introduction, and avoidance of chromatic alteration within planes.

# Core Definition
Polytonality is effective as such only when each tonal plane is kept within a clear scale formation. Shifting of modality through chromatic alteration clouds the texture or simply produces miscellaneous polychords. For maximum clarity in the projection of different tonalities, one key is introduced and as the next key is added, the preceding key, having been established, becomes less obvious. The scale steps spanning the tritone should be brought into play as soon as possible; otherwise polytonality will fail to operate.

Closely spaced polytonal areas become muddy. The keys should be kept far enough apart to allow room for voice activity. Harmonic parts of three keys placed a small interval apart run into each other. Independent lines should not be placed at random without an understanding of polytonal construction.

# Prerequisites
- **Polytonality**: The multi-key writing requiring clarity

# Key Properties
1. Each tonal plane must maintain clear scale formation
2. Tritone-spanning scale steps deployed as soon as possible
3. Sufficient registral separation prevents muddiness
4. Sequential introduction: establish one key before adding the next
5. No chromatic alteration within planes (clouds texture)
6. Cramped polytonality lacks versatility
7. Three keys at small intervals run into each other

# Construction / Recognition
- Verify each key's tritone-defining tones (4th and 7th degrees) are present and early
- Check registral separation between planes
- Note whether keys are introduced sequentially (not all at once)
- Look for chromatic alteration within planes (destroys clarity)
- Assess whether closely spaced keys produce mud
- Distinguish successful polytonality from miscellaneous polychords

# Context & Application
When a key's tritone-defining tones are absent, the result is ambiguous rather than polytonal. In the source example, the lower F major strand lacking Bb or E and the upper C major strand lacking F or B produces ambiguously major texture, not polytonality. The technique of sequential introduction (establishing one key, then adding the next while the first recedes) creates the strongest polytonal projection. Secondary textures that become thick can be managed through chord member omission, doubling of stronger intervals, ornamental coloring, unison interpolations, or ostinatos.

# Common Errors
- Omitting tritone-defining tones from one or both keys
- Cramping keys into too narrow a register
- Allowing chromatic alteration to blur key identities
- Introducing all keys simultaneously without sequential establishment

# Common Confusions
- **Tritone-defining tones**: The 4th and 7th degrees of each key are essential; without them, the key is not distinguishable
- **Chromatic alteration vs. polytonality**: Shifting modality within a plane produces polychords, not polytonality
- **Registral separation**: Adequate space between planes is a physical requirement, not merely aesthetic preference
