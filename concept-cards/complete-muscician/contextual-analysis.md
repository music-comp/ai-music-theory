# Quick Definition
Contextual analysis determines a pitch's function by considering the full musical context -- especially the underlying harmony, rhythm, and supporting voices -- rather than analyzing melody in isolation.

# Formal Definition
Contextual analysis requires examining the complete musical texture to determine whether a given pitch functions as a chord tone or a tone of figuration. A pitch's consonant or dissonant status depends entirely on the context in which it appears: the underlying harmonic support, the rhythm, the meter, and the surrounding voices. Analysis that considers only the melody without its harmonic and rhythmic context will produce incorrect results.

# Musical Context
This principle is foundational to all tonal analysis. It prevents the error of assuming that pitches of the tonic triad are always structural or that non-triadic pitches are always embellishments. The harmonic context can completely change the function of melodic pitches.

# Examples
In Schubert's "Der Lindenbaum" (E major), analyzing the melody alone suggests F#4 (m. 11) is a dissonant passing tone and A4 is an upper neighbor to G#. But with the accompaniment, the harmony changes to V (B-D#-F#) in m. 11, making F# a consonant chord tone, G#4 a dissonant passing tone, and A4 the consonant seventh of the dominant harmony. The initial analysis without context was entirely wrong.

# Common Confusions
Students often analyze melodies in isolation, assuming tonic triad members are always structural. This approach fails when the harmony changes, as demonstrated by the Schubert example where the same pitches completely change function when the accompanying harmony is considered.
