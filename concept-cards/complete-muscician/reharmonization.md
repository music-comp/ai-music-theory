# Quick Definition
A technique of strict motivic repetition in which a melody is restated at the same pitch level but placed in a new harmonic context, transforming its character.

# Formal Definition
Reharmonization is a form of strict motivic repetition in which the melodic motive is repeated at pitch (the same notes) but cast in a different harmonic environment. This technique avoids the monotony of pure strict repetition while maintaining the motive's pitch identity. The new harmonic context changes the function of the motive's pitches within the scale, producing a dramatically different expressive effect.

# Musical Context
Reharmonization demonstrates how harmonic context shapes the character of melodic material. It is a powerful tool for creating variety from limited motivic material.

# Examples
- Schubert, "Die Nebensonnen," from Winterreise: the double-neighbor motive C#-B-(C#)-D-C# first appears in A major (C# = ^3), then is reharmonized in F# minor (C# = ^5), creating a dark and tragic-sounding transformation

# Common Confusions
- Reharmonization keeps the pitches the same; transposition changes the pitches -- these are different techniques
- The same pitch can function as different scale degrees depending on the harmonic context
- Reharmonization is classified as strict repetition (of the melody) even though the harmony changes
