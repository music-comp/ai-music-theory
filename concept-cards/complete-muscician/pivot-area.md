# Quick Definition
A group of chords that function in both keys, creating a broader transitional zone between the original and new keys rather than a single pivot chord.

# Formal Definition
A pivot area occurs when the function of connecting two keys is not limited to a single chord but is shared by several chords that work together. The pivot area may include an expanded or tonicized pivot chord, a group of chords sharing the same harmonic function (such as pre-dominants IV and ii coupled through voice exchange), or a sequence that touches on chords functioning in both keys. Sequences make particularly effective pivot areas because they traverse many chords, allowing reinterpretation at any point.

# Musical Context
Pivot areas provide smoother, more gradual modulations than single pivot chords. They are especially common in passages using sequences as modulatory tools.

# Examples
- A pivot chord expanded by its own applied chords, creating a pre-dominant complex that works in both keys
- A sequence that prematurely stops and reinterprets one of its chords as a pre-dominant in the new key

# Common Confusions
- A pivot area is not the same as an extended tonicization; it is a zone of ambiguity where multiple chords function in both keys
- The concept of pivot area explains why some modulations do not have a single clear pivot chord
