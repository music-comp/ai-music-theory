# Quick Definition
The applied-chord version of the ascending 5-6 sequence, A2 (-3/+4), in which raising the bass a half step creates chromatic passing tones functioning as temporary leading tones.

# Formal Definition
The A2 (-3/+4) applied-chord sequence converts the diatonic ascending 5-6 sequence by chromatically raising the bass of the first-inversion chord a half step, transforming it into an applied dominant (typically V6/5 or V6) that resolves to the following root-position triad. This creates a powerful harmonized chromatic passing tone ascending by step. The seventh may be added to the applied chords. An alternative version places the chromatic passing motion in the soprano rather than the bass, using root-position applied chords. The sequence is labeled A2 (-3/+4) with applied chords.

# Musical Context
This is the most common ascending applied-chord sequence. It produces a striking chromatic bass line that ascends by half and whole steps, creating one of the most recognizable chromatic patterns in tonal music.

# Examples
- Leclair, Sonata in C major for Flute and Continuo, op. 1, no. 2, Corrente: ascending applied 6/5 chords alternating with diatonic triads in an A2 (-3/+4) pattern
- Root-position variant with chromatic passing motion in soprano

# Common Confusions
- The chromatic bass version and root-position soprano-chromatic version are two forms of the same underlying sequence type
- The diatonic version must include first-inversion triads (ascending 5-6) before it can be converted to the applied-chord version by raising the bass
