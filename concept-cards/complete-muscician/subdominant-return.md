# Quick Definition
A subdominant return is a harmonic anomaly in sonata form where the recapitulation begins on IV rather than I, creating harmonic interest since the STA must eventually arrive in the tonic.

# Formal Definition
In a subdominant return, the recapitulation begins not on the tonic but on the subdominant (IV). This procedure arose to create harmonic interest in the recapitulation, which otherwise consists largely of tonic-key material. Given that the exposition moves from I up a fifth to V, and given that the STA in the recapitulation must appear in the tonic, beginning the recapitulation down a fifth (on IV) preserves the same root-motion relationship (up a fifth from IV to I) while ensuring the STA arrives in the tonic for proper closure.

# Musical Context
The subdominant return is a relatively uncommon but effective device for adding harmonic variety to the recapitulation. It is particularly associated with Mozart and some works of Beethoven.

# Examples
- Mozart, Piano Sonata in C major, K. 545 (Example 33.6): The recapitulation begins on F major (IV) rather than C major (I). The root motion from IV to I in the recapitulation mirrors the I to V motion of the exposition.

# Common Confusions
A subdominant return is not a false recapitulation. In a false recapitulation, the FTA theme appears in any wrong key during the development. A subdominant return specifically begins the recapitulation on IV, with the thematic material otherwise proceeding normally. The return eventually "corrects" to the tonic for the STA.
