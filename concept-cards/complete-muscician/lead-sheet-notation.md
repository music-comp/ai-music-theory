# Quick Definition
Lead-sheet notation is a chord symbol system used in jazz and popular music that identifies chord roots, qualities, and inversions using letter names and modifiers.

# Formal Definition
Lead-sheet notation identifies chords by root letter and quality symbols: Major triad = uppercase letter (C); minor triad = uppercase + dash (C-) or lowercase (c); diminished = uppercase + degree sign (C); augmented = uppercase + plus (C+). For seventh chords: Mm7 = root + 7 (C7); MM7 = root + triangle + 7 (C-triangle-7) or CM7; mm7 = lowercase + 7 (cm7); dm7 = root + slashed-degree + 7; dd7 = root + degree + 7 (C-degree-7). Inversions use slash notation: root/bass note (e.g., C/E for C major first inversion).

# Musical Context
Lead-sheet notation is the standard chord symbol system for jazz, popular music, and commercial music. It serves a similar practical function to figured bass: providing enough information for a performer to realize harmonies while allowing freedom in voicing and rhythm. Unlike roman numerals, lead-sheet symbols are absolute (not relative to a key).

# Examples
- C major triad: C
- C minor triad: C- or c or Cm
- C dominant seventh: C7
- C major seventh: C-triangle-7 or CM7
- C half-diminished seventh: C-slashed-degree-7
- First-inversion C diminished: C-degree/Eb

# Common Confusions
Students trained in classical notation sometimes confuse lead-sheet "C7" (a dominant seventh/Mm7 chord) with a roman numeral context. In lead sheets, "C7" means a Mm7 chord with root C, regardless of key. In roman numeral analysis, "V7" means a Mm7 chord on ^5. Also, the various minor chord symbols (c, C-, Cm, Cmin) all mean the same thing but use different conventions.
