# Quick Definition
Second-level analysis goes beyond labeling each chord with Roman numerals (descriptive analysis) to interpret which harmonies are structural and which are embellishing, revealing the deeper harmonic progression.

# Formal Definition
Second-level analysis (also called interpretive analysis) distinguishes more important harmonies from less important ones within a passage. The first level labels each sonority with Roman numerals (descriptive analysis). The second level groups chords into larger harmonic units, showing which harmony controls a given span and which chords merely embellish or extend that controlling harmony. Subordinate chords are labeled by their melodic function (PT for passing tone, N for neighbor) while controlling harmonies retain their Roman numerals beneath brackets. There may be multiple levels of reduction needed for complex passages.

# Musical Context
Second-level analysis is the interpretive heart of harmonic analysis. It reveals that not all harmonies labeled with Roman numerals are equally important. Some control large spans while others are subordinate. This understanding directly informs performance decisions about which harmonies to emphasize.

# Common Confusions
Students often stop at first-level analysis, placing Roman numerals beneath every chord without considering their relative importance. Simply labeling chords is description, not analysis. True analysis requires interpretive decisions about which harmonies are structural and which are ornamental. These decisions depend on meter, rhythm, and the counterpoint between bass and soprano.
