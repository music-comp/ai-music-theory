# Quick Definition
A comprehensive overview of all four applied-chord sequence types, organized by direction and root motion, with diatonic and applied variants.

# Formal Definition
The four generic sequence types each have diatonic and applied-chord variants, organized as follows:

Descending by second: Diatonic D2 (-5/+4), applied D2 (-5/+4) with applied dominants
Descending by third: Diatonic D3 (-4/+2), applied D3 (+3/-5) -- note the root motion changes
Ascending by second (fifths): Diatonic A2 (+5/-4), applied variant less common
Ascending by second (thirds): Diatonic A2 (-3/+4), applied A2 (-3/+4) with applied dominants

Within each type, modifications include: triads (5/3), first-inversion triads (6/3), seventh chords in root position, and seventh chords in inversion. Applied-chord sequences intensify sequential motion through chromaticism.

# Musical Context
This summary provides a reference framework for identifying and writing all sequence types encountered in common-practice music.

# Examples
- D2 applied: alternating applied V7 chords and diatonic triads
- D3 applied: each diatonic triad preceded by its applied dominant, changing root motions from (-4/+2) to (+3/-5)
- A2 applied: ascending chromatic bass line created by raising bass of 6/3 chords

# Common Confusions
- The D3 applied-chord sequence changes its root motions from the diatonic version; all other types retain their root-motion labels
- Applied-chord sequences maintain diatonic roots; the chromaticism affects chord quality, not root identity
