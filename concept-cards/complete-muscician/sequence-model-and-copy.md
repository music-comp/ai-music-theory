# Quick Definition
The model is the initial two-chord pattern that establishes the sequence; copies replicate this pattern at successive pitch levels.

# Formal Definition
A sequence divides into two parts: the model, which presents the basic contrapuntal/harmonic pattern (usually two chords), and its copies, which transpose the model to different pitch levels. Any melodic or motivic figuration used in the sequence first appears in the model and is replicated in each copy. Sequences typically have two or three copies. The voice leading established in the model must be maintained exactly in all copies; any errors in the model will be replicated throughout.

# Musical Context
Understanding the model-copy structure is essential for both analyzing and writing sequences. Composers carefully construct the model's voice leading because it determines the quality of the entire sequence.

# Examples
- In a D2 (-5/+4) sequence in C major: model might be I-IV, first copy vii-iii, second copy vi-ii, etc.

# Common Confusions
- The model must have correct voice leading in all voices, because copies merely replicate it
- The second chord of the model often functions as a voice-leading chord that prevents parallels
