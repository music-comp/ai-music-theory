# Quick Definition
An analytical method using two tiers: the first level describes all vertical sonorities with roman numerals, and the second level interprets harmonic functions (T, PD, D) to reveal larger connections.

# Formal Definition
Two-level analysis is a multitiered analytical process central to understanding tonal music. First-level analysis describes all vertical sonorities using roman numerals and figured bass. Second-level analysis interprets harmonic functions within musical context, grouping chords under their structural functions (T, PD, D). The second level reveals connections such as tonic expansions, back-relating dominants, embedded phrase models, and the overall T-PD-D-T trajectory of the phrase. The second level mirrors perception and influences performance shaping.

# Musical Context
Two-level analysis has been developed throughout Chapters 8-19 as the primary analytical tool for tonal music. It accommodates increasingly complex situations: contrapuntal expansions, six-four chords, the submediant, the mediant, back-relating dominants, and contextual interpretations where a chord's hierarchical importance depends on its role in the larger progression.

# Examples
- A progression I-V-vi-ii-V-I: first level labels each chord; second level shows T (with BRD) - vi bridging to PD - D - T
- EPMs within tonic expansions: first level shows all chords; second level groups the EPM under T

# Common Confusions
- First-level analysis is description; second-level analysis is interpretation -- both are needed for complete understanding
- Not every chord with a roman numeral is structurally important; the second level reveals which chords are structural and which are embellishing
- Second-level analysis reflects perception and should influence performance; it is not merely an academic exercise
