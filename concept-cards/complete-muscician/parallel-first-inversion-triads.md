# Quick Definition
A series of triads moving in strict parallel motion using first-inversion (6/3) chords, the only triad position that permits parallel motion without creating forbidden parallels.

# Formal Definition
Parallel first-inversion triads (parallel six-three chords) move in strict parallel motion in three voices. In four voices, the fourth voice alternates between doubling the soprano and doubling the bass to avoid parallels. This technique is not a strict sequence (lacking a two-chord model), but functions similarly: it either prolongs a harmonic function or transitions between functions. Descending parallel 6/3 chords often incorporate 7-6 suspensions, which provide a connection to the D2 (-5/+4) sequence with interlocking sevenths. By changing bass notes as suspensions resolve, parallel 6/3 chords with 7-6 suspensions transform into the D2 sequence.

# Musical Context
This technique has been used since the sixteenth century. Ascending lines occur but descending lines are more common. Parallel 6/3 chords create an impression more of stalling for time than of goal-directed motion, compared to true sequences.

# Examples
- Handel, Suite XIII in B-flat major, Allemande: descending parallel 6/3 chords with 7-6 suspensions
- Ascending parallel 6/3 chords as part of tonic expansion in Handel's keyboard works

# Common Confusions
- Parallel 6/3 chords are not strict sequences (no two-chord model) but function similarly
- In four voices, the problem of parallel fifths is solved by having the extra voice alternate doublings
- The transformation from parallel 6/3 with 7-6 suspensions into D2 with interlocking sevenths is achieved by changing bass notes at resolution points
