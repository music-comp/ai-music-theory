# Quick Definition
A sequence used as a tool for modulation by prematurely ending the sequential pattern and reinterpreting one of its chords as a pre-dominant in a new key.

# Formal Definition
Sequences make effective modulatory tools because they touch on many chords within a key. By stopping a sequence prematurely and reinterpreting one of its chords as a pre-dominant leading to a dominant in a new key, a composer can modulate smoothly. The transitional function of sequences naturally supports this technique. From a single sequence, a composer can potentially modulate to several different closely related keys by choosing different points at which to exit the sequence and different chords to reinterpret as pivots.

# Musical Context
Modulating sequences are common throughout tonal music, particularly in development sections, transitions, and digressions in binary form. They provide elegant, seamless key changes.

# Examples
- Vivaldi, Trio Sonata in C minor: D2 sequence stops on VI (A-flat), which is reinterpreted as IV in E-flat major (III of C minor)
- From a D2 (-5/+4) sequence in G minor, modulations can reach III, VI, and v by choosing different exit points
- From an A2 (-3/+4) sequence in B-flat major, modulations can reach iii, vi, and V

# Common Confusions
- The sequence itself does not modulate; the modulation occurs when the sequential pattern is broken and a chord is reinterpreted in the new key
- Multiple modulation targets are possible from the same sequence by choosing different exit points
- Use pivot notation to show how the last chord of the sequence functions in the new key
