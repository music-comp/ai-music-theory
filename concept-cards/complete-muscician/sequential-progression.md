# Quick Definition
A passage in which the harmonic structure follows a sequential root-motion pattern but the melodic structure does not replicate a model, distinguished from a true sequence.

# Formal Definition
A sequential progression follows the root motions of a sequence type (e.g., D2 root motions of descending fifths and ascending fourths) but lacks the exact melodic replication of a model in each copy. The harmonic pattern is sequential, but the surface texture, figuration, and melodic content change from one chord pair to the next. Sequential progressions are labeled by root type (e.g., "D2 progression") and analyzed with full roman numerals rather than the abbreviated sequence labeling used for true sequences. The D2 (-5/+4) sequential progression is particularly popular.

# Musical Context
Sequential progressions are common because the root motions of three of the four basic sequence types are also common functional progressions. They appear in vocal and instrumental music where the text or musical development demands changing surface content.

# Examples
- Brahms, "Der Gang zum Liebchen," op. 48, no. 1: D2 (-5/+4) sequential progression
- Bach, French Suite in D minor, BWV 812, Menuet II: D2 sequential progression

# Common Confusions
- A sequential progression uses sequential root motions but is not a true sequence because the melodic model is not replicated
- Label sequential progressions with "sequential prog." and use full roman numerals, unlike true sequences which receive only first/last roman numerals
