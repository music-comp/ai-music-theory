# Quick Definition
The Neapolitan chord can function as a pivot chord in modulations, serving as bII in the original key while reinterpreted as a diatonic chord in the new key.

# Formal Definition
The Neapolitan is an effective pivot chord for modulations to both diatonic and chromatic keys. A chord that functions as bII6 (or bII) in the original key can simultaneously be interpreted as a diatonic harmony in a new key, facilitating smooth chromatic modulations. The Neapolitan can also appear within A2 (-3/+4) applied-chord sequences, where its use is more common in minor-mode works. A bonus of incorporating bII in sequences is that it allows root-position bII in minor pieces, since the diatonic ii° (dissonant) cannot be preceded by an applied chord.

# Musical Context
The Neapolitan as pivot chord is particularly useful for modulations to keys that would otherwise be difficult to reach smoothly. It became an important modulatory tool in the late Classical and Romantic periods, enabling access to chromatically remote key areas through a single, dramatic chord.

# Examples
- Schubert, String Quartet in C minor, D. 703 (Example 29.11): A Db chord functions initially as bII6 in C minor but later serves as a pivot precipitating a modulation to Ab major.
- Example 29.10: The Neapolitan participates in an A2 (-3/+4) applied-chord sequence, allowing root-position bII in a minor-mode context.

# Common Confusions
When the Neapolitan serves as a pivot, it is important to show dual roman numeral analysis indicating the chord's function in both the old key and the new key. Students should not simply label it as bII in one key and neglect to show its diatonic function in the target key.
