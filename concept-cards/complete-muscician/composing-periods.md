# Quick Definition
The process of writing periods by first planning the large harmonic picture, then mapping harmonies within each phrase, and finally adding melody with good counterpoint and motivic consistency.

# Formal Definition
Period composition proceeds in three stages: (1) Choose one of the tonal models that defines the period type (e.g., I...HC // I...PAC for interrupted; I...IAC / I...PAC for sectional; I...HC / V7-I...PAC for continuous). (2) Map out the harmonies within each phrase, ensuring changes occur on strong beats (typically beats 1 and 3 in 4/4). (3) Add a melody that creates good outer-voice counterpoint and exhibits motivic consistency. Consequent phrases that open with different harmonies from their antecedents often demand contrasting rather than parallel melodic content.

# Musical Context
Period composition is a fundamental compositional skill that integrates knowledge of diatonic harmonies, cadences, phrase construction, and melodic writing. It develops musical creativity within a structured formal framework.

# Examples
- Interrupted period harmonic plan: m.1 I, m.2 vi, m.3 IV, m.4 V // m.5 I-IV-I, m.6 iii-vi, m.7 ii-V7, m.8 I

# Common Confusions
- Start with the large harmonic picture before writing melody; do not compose melody first
- Test compositions by singing and playing them at the piano
