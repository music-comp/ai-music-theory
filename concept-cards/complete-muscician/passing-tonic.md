# Quick Definition
A tonic chord (usually I6) that functions as a weak passing chord within a pre-dominant expansion, subordinate to the surrounding pre-dominant harmonies.

# Formal Definition
A passing tonic is a tonic chord -- typically I6 -- that serves as a passing harmony within the pre-dominant function. It connects two forms of a pre-dominant chord (e.g., ii to ii6, or IV to IV6) through stepwise bass motion and voice exchange. Although it is literally a tonic chord, it does not function as a structural tonic; instead, it is subordinate to the pre-dominant harmony it connects. This is a key example of how context determines function: a weak I6 can expand ii, but a ii(6) cannot expand I.

# Musical Context
The passing tonic illustrates the principle that even the most structurally important chord (I) can be demoted to an embellishing role when the musical context places it in a subordinate position. This is an important concept for contextual analysis.

# Examples
- I6 passing between ii and ii6 in a pre-dominant expansion, with voice exchange between soprano and bass

# Common Confusions
- A passing tonic is NOT a structural tonic; it is subordinate to the pre-dominant function
- I6 can expand ii, but ii cannot expand I -- this asymmetry reflects the hierarchical nature of tonal music
- Do not interpret every I6 as a passing tonic; only when it occurs within a pre-dominant expansion
