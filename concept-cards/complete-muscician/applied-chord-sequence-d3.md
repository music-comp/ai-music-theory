# Quick Definition
The applied-chord version of the descending-third sequence, transformed from D3 (-4/+2) into D3 (+3/-5) because each applied chord creates a forward-pointing dominant relationship.

# Formal Definition
In the diatonic D3 (-4/+2) sequence, the second chord of each pair lies a fourth below the first. In the applied-chord version, a dramatic transformation occurs: because each applied chord creates a temporary leading tone pointing forward to the next chord, the second chord functions as a dominant of the following chord rather than the previous one. This changes the root motions from (-4/+2) to (+3/-5), creating the D3 (+3/-5) applied-chord sequence. Applied chords most often contain sevenths. Common inversions include the 4/3 inversion, which provides a stepwise bass descent in parallel tenths with the soprano. Applied root-position diminished seventh chords can substitute for the applied dominants, creating a D3 (-4/+1) variant.

# Musical Context
The applied-chord D3 sequence creates powerful forward motion through its chain of dominant-to-tonic resolutions descending by thirds. It is common in Baroque and Classical music.

# Examples
- D3 (+3/-5) with 4/3 inversions: stepwise descending bass in parallel tenths with soprano (most common form)
- D3 variant with applied diminished seventh chords: D3 (-4/+1)
- "Hooking contour" bass in root-position variant: dissonant leap to leading tone balanced by stepwise resolution

# Common Confusions
- The root motions change from the diatonic version: D3 (-4/+2) becomes D3 (+3/-5) because the second chord now points forward
- The diatonic and applied-chord versions have different root motions and different chord functions despite sharing the "D3" label
- Applied diminished sevenths can substitute for applied dominants in this sequence
