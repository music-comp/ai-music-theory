# Quick Definition
A pitch is a specific musical tone at a particular frequency and register, while a pitch class groups together all pitches with the same letter name across all octaves.

# Formal Definition
Pitch refers to the perceived highness or lowness of a sound, determined by its frequency (vibrations per second). Each pitch occupies a specific register and is identified by a letter name plus an octave designation (e.g., C4 for middle C). A pitch class encompasses all pitches sharing the same letter name regardless of octave, so all C's belong to the same pitch class. There are twelve pitch classes in the chromatic system, each separated by a half step.

# Musical Context
The distinction between pitch and pitch class is essential for understanding octave equivalence. When we say a piece is "in C major," we refer to the pitch class C as tonic, regardless of which octave. Pitch-class thinking underlies concepts such as enharmonic equivalence, chord identification, and key relationships.

# Examples
- Middle C (C4) and the C two octaves above it (C6) are different pitches but belong to the same pitch class.
- The twelve pitch classes are: C, C#/Db, D, D#/Eb, E, F, F#/Gb, G, G#/Ab, A, A#/Bb, B.

# Common Confusions
Students often use "pitch" and "note" interchangeably. Strictly speaking, a pitch is the acoustic phenomenon, a note is the written symbol, and a pitch class is the abstract category. In practice, these distinctions are often blurred, but understanding them clarifies discussions of transposition and octave equivalence.
