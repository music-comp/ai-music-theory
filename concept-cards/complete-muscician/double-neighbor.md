# Quick Definition
A double neighbor combines both upper and lower neighbors around a single pitch, creating a four-note figure (main note, upper neighbor, lower neighbor, main note -- or the reverse).

# Formal Definition
A double neighbor results from the combination of an upper neighbor and a lower neighbor around a single pitch. The figure typically presents both the upper and lower neighbors in succession before returning to the original pitch (or vice versa). Double neighbors can appear in melody or be created harmonically when bass neighboring and passing chords combine to create a double-neighbor figure around a structural bass note.

# Musical Context
Double neighbors create more elaborate embellishments than single neighbors while still functioning to prolong a single pitch. In harmonic contexts, combined first-inversion chords (such as V6 and viio6 around I) can create bass double-neighbor figures that extend a single harmony.

# Common Confusions
A double neighbor is not two separate neighbor tones occurring at different times -- it is a specific figure that combines upper and lower neighbors around a single pitch in immediate succession. Students should also recognize harmonic double neighbors, where combined chords create the same pattern in the bass.
