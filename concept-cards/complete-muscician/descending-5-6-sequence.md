# Quick Definition
An alternate name for the D3 (-4/+2) + 6/3 sequence, named for the 5-6 voice motion that occurs as one voice remains stationary against the descending bass.

# Formal Definition
The descending 5-6 sequence is the first-inversion variant of the D3 (-4/+2) sequence. It is so named because one voice (typically the tenor) holds a common tone while the bass descends, creating alternating intervals of a fifth and a sixth above the bass. The result is a smooth stepwise bass descent moving in parallel tenths with the soprano. This is the more common form of the D3 sequence (more common than root position) and provides one of the smoothest sequential patterns in tonal music.

# Musical Context
The descending 5-6 sequence appears extensively in Baroque and Classical music. Its smooth parallel tenths and stepwise bass make it one of the most elegant sequential patterns.

# Examples
- Pachelbel Canon contains elements of this sequence pattern
- The soprano descends stepwise while the bass also descends stepwise, creating parallel tenths

# Common Confusions
- The "5-6" name refers to the intervallic motion above the bass, not the figured bass of the chords
- Distinguished from the ascending 5-6 sequence (A2 (-3/+4) + 6/3), which moves upward
