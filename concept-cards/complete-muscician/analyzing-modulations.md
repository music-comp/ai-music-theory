# Quick Definition
A systematic procedure for identifying the new key, finding the pivot chord, and writing dual roman numeral analysis at the point where the analysis "jumps tracks."

# Formal Definition
Three musical events are identified when analyzing modulations: (1) the location of the new key in relation to the initial tonic (by roman numeral), (2) the function of the new key within the overall harmonic progression, and (3) the pivot chord where original and new keys are momentarily fused. Procedure: start writing roman numerals in the original key; continue until they become nonsensical due to the key change; work backwards from the cadence in the new key; find the first chord with a simple roman numeral in both keys; draw a box around the dual roman numerals for this pivot chord. Erase incorrect roman numerals from the original-key analysis. The second-level analysis also jumps tracks, resulting in incomplete analyses in both keys.

# Musical Context
This analytical procedure is the standard method for annotating modulations in tonal analysis across all common-practice repertoire.

# Examples
- C major to G major: roman numerals in C become complex around the pivot; working backwards from the G-major cadence, A minor is found as the pivot (vi in C = ii in G), boxed with both numerals

# Common Confusions
- The pivot chord receives two roman numerals; all other chords receive only one
- Cadential 6/4 chords are not good pivot candidates
- The second-level analysis will be incomplete in both keys, which is expected
