# Quick Definition
Transposition is the process of shifting all pitches in a musical passage by the same interval, preserving the intervallic relationships while changing the key.

# Formal Definition
Transposition involves moving every pitch in a melody or harmonic passage up or down by a consistent interval, thereby maintaining the same scale degree relationships and intervallic patterns in a new key. Transposition can be performed by interval (moving each pitch by a fixed interval) or by scale degree (identifying each pitch's function in the original key and transferring those functions to the new key).

# Musical Context
Transposition is a fundamental skill for musicians. Instrumentalists transpose when reading parts written for transposing instruments (e.g., clarinet in A). Composers transpose themes to create variety, to modulate, and to write for different instruments. Singers transpose songs to fit their vocal range.

# Examples
- A melody in G major beginning D-G-A-B-F#-G (^5-^1-^2-^3-^7-^1) transposed up a major third to B major becomes F#-B-C#-D#-A#-B (Exercise 1.3).
- Transposition by scale degree: identify each pitch's scale degree number in the original key, then apply those numbers in the new key.
- Transposition by interval: add the same interval to every pitch.

# Common Confusions
Students sometimes transpose by interval but forget to check that all pitches are correctly spelled in the new key. Using the scale-degree method avoids this problem: determine the new key, write its scale, and map scale degrees accordingly.
