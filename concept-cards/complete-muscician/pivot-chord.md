# Quick Definition
A diatonic chord that functions in both the original key and the new key, serving as the point where roman numeral analysis "jumps tracks" during a modulation.

# Formal Definition
A pivot chord is a chord that has a simple roman numeral interpretation in both the original key and the new key. It is the point where the modulation occurs, fusing the two tonal areas. Analysis procedure: (1) start writing roman numerals in the original key, (2) continue until numerals become complex or nonsensical due to key change, (3) work backwards from the cadence in the new key until finding the first chord with a simple numeral in both keys, (4) draw a box around the dual roman numerals for this chord. The best pivot chords act as pre-dominants in the new key. Cadential 6/4 chords are poor pivot candidates because they are part of a strong cadential motion in the new key.

# Musical Context
Pivot chords create smooth, seamless modulations by hiding the moment of key change. They are the most common technique for modulating in common-practice music.

# Examples
- C major to G major (I to V): A-minor chord serves as pivot (vi in C = ii in G)
- C minor to E-flat major (i to III): A-flat major serves as pivot (VI in C minor = IV in E-flat major)
- Best pivot chords function as PD in the new key; avoid using V of the new key as a pivot

# Common Confusions
- The pivot chord receives two roman numerals (one for each key); all other chords receive only one
- Do not use the dominant of the new key as pivot chord, as this creates a harsh-sounding modulation
- Cadential 6/4 chords should not serve as pivot chords
- Place the pivot chord roughly halfway into a modulating phrase for balanced key establishment
