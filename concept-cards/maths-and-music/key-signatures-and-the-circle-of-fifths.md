# Quick Definition

A key signature is a set of sharps or flats placed at the beginning of a staff to indicate which notes are consistently altered, and the circle of fifths is the systematic pattern by which these key signatures are generated.

# Core Definition

A key signature "tailors" notes to effect the standard scale (interval pattern $1, 1, \frac{1}{2}, 1, 1, 1, \frac{1}{2}$) in a desired key. Flat keys are generated by flatting the seventh note of each successive standard scale, producing the sequence C, F, $B^\flat$, $E^\flat$, $A^\flat$, $D^\flat$, $G^\flat$, $C^\flat$, where each successive keynote lies a fourth (5 semitones) above the previous. Sharp keys are generated by sharping the fourth note, producing C, G, D, A, E, B, $F^\sharp$, $C^\sharp$, where each successive keynote lies a fifth (7 semitones) above the previous (Wright, pp. 22-24).

# Prerequisites

- **Diatonic and Chromatic Scales** — Key signatures produce standard scales in different keys
- **Accidentals** — Key signatures use sharps and flats
- **Octave Equivalence** — A fourth up and a fifth down are equivalent modulo octave

# Key Properties

1. Each key signature determines a unique scale in each of the seven modes
2. Flat keys: each successive tonic is a fourth above (or fifth below) the previous
3. Sharp keys: each successive tonic is a fifth above the previous
4. Flats accumulate: $B^\flat, E^\flat, A^\flat, D^\flat, G^\flat, C^\flat, F^\flat$
5. Sharps accumulate: $F^\sharp, C^\sharp, G^\sharp, D^\sharp, A^\sharp, E^\sharp, B^\sharp$
6. Three pairs of enharmonically equivalent keys: $D^\flat \sim C^\sharp$, $G^\flat \sim F^\sharp$, $C^\flat \sim B$

# Construction / Recognition

## To generate flat key signatures:

1. Start with C (no flats)
2. Flat the seventh note of the current scale to get a new standard scale starting a fourth above
3. F has 1 flat ($B^\flat$), $B^\flat$ has 2 flats ($B^\flat, E^\flat$), etc.

## To generate sharp key signatures:

1. Start with C (no sharps)
2. Sharp the fourth note of the current scale to get a new standard scale starting a fifth above
3. G has 1 sharp ($F^\sharp$), D has 2 sharps ($F^\sharp, C^\sharp$), etc.

# Context & Application

The two sequences wrap against each other, yielding three enharmonically equivalent key pairs. This creates a closed cycle of 12 keys — the circle of fifths. Each key signature does not determine the mode alone; the keynote (tonic) must also be identified. Since $5 + 7 = 12$, going up a fourth is equivalent to going down a fifth modulo octave.

# Examples

- Key of F: one flat ($B^\flat$), obtained by flatting B in the F-to-F scale (p. 22)
- Key of G: one sharp ($F^\sharp$), obtained by sharping F in the G-to-G scale (p. 22)
- Key of $B^\flat$: two flats ($B^\flat, E^\flat$), obtained by flatting E in the F scale (p. 22)
- Enharmonic pairs: $D^\flat = C^\sharp$ (5 flats = 7 sharps), $G^\flat = F^\sharp$ (6 flats = 6 sharps), $C^\flat = B$ (7 flats = 5 sharps) (p. 23)

# Common Errors

- **Error**: Assuming key signature determines the mode
  **Correction**: A key signature determines a unique scale in each mode; C major and A minor share the same signature

# Common Confusions

- **Confusion**: Thinking each flat key's tonic is a fifth above the previous
  **Clarification**: Flat keys go by fourths ascending (or fifths descending); sharp keys go by fifths ascending
- **Confusion**: Believing the circle of fifths is an arbitrary convention
  **Clarification**: It follows mathematically from the relationship $7 \times 12 \equiv 0 \pmod{12}$ — after 12 fifths, you return to the starting note class
