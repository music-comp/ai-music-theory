# Quick Definition
A key signature is a set of sharps or flats placed at the beginning of a staff to indicate which notes are consistently altered, and the circle of fifths is the systematic pattern by which these key signatures are generated.

# Formal Definition
A key signature "tailors" notes to effect the standard scale (interval pattern $1, 1, \frac{1}{2}, 1, 1, 1, \frac{1}{2}$) in a desired key. The flat keys are generated by iteratively flatting the seventh note of each successive standard scale, producing the sequence C, F, $B^\flat$, $E^\flat$, $A^\flat$, $D^\flat$, $G^\flat$, $C^\flat$, where each successive keynote lies a fourth (5 semitones) above the previous. The sharp keys are generated by sharping the fourth note, producing C, G, D, A, E, B, $F^\sharp$, $C^\sharp$, where each successive keynote lies a fifth (7 semitones) above the previous.

# Mathematical Context
Each successive flat key's tonic is a perfect fourth (5 semitones) above the previous, or equivalently a perfect fifth (7 semitones) below (modulo octave, since $5 + 7 = 12$). Each successive sharp key's tonic is a perfect fifth above. The two sequences wrap against each other, yielding three pairs of enharmonically equivalent keys: $D^\flat \sim C^\sharp$, $G^\flat \sim F^\sharp$, $C^\flat \sim B$. This creates a closed cycle of 12 keys, the circle of fifths.

# Musical Context
A key signature determines a unique scale in each of the seven modes, so the key signature alone does not determine the mode. The key of a composition is determined by the key signature together with the keynote (tonic). For flat keys, flats accumulate in the order B$^\flat$, E$^\flat$, A$^\flat$, D$^\flat$, G$^\flat$, C$^\flat$, F$^\flat$. For sharp keys, sharps accumulate in the order F$^\sharp$, C$^\sharp$, G$^\sharp$, D$^\sharp$, A$^\sharp$, E$^\sharp$, B$^\sharp$.

# Examples
- Key of F major: one flat ($B^\flat$), since flatting B in the F-to-F scale produces the standard interval pattern
- Key of G major: one sharp ($F^\sharp$), since sharping F in the G-to-G scale produces the standard interval pattern
- Key of $B^\flat$ major: two flats ($B^\flat, E^\flat$), obtained by flatting the seventh of the F scale
- Enharmonic key pairs: $D^\flat = C^\sharp$ (5 flats = 7 sharps), $G^\flat = F^\sharp$ (6 flats = 6 sharps), $C^\flat = B$ (7 flats = 5 sharps)

# Common Confusions
- A key signature does not determine the mode: C major and A minor share the same key signature (no sharps or flats)
- Each flat key's tonic is a fourth above (or fifth below) the previous, not a fifth above -- the sharp keys go by fifths ascending
- The circle of fifths is a consequence of $7 \times 12 \equiv 0 \pmod{12}$ (after 12 fifths, you return to the starting note class)
