# Quick Definition
An axiom of mathematics stating that every non-empty subset of the positive integers has a smallest element.

# Formal Definition
Any non-empty subset of $\mathbb{Z}^+$ has a smallest element. That is, if $S \subseteq \mathbb{Z}^+$ and $S \neq \emptyset$, then there exists $s_0 \in S$ such that $s_0 \leq s$ for all $s \in S$.

# Mathematical Context
The Well-Ordering Principle is an axiom -- it cannot be proved from more basic principles without assuming something equivalent (such as the Principle of Mathematical Induction or Zorn's Lemma). It is used in proofs involving integers, including the proof of the Division Algorithm. Despite its innocent appearance, it is logically equivalent to deep principles in set theory.

# Musical Context
While not directly a musical concept, the Well-Ordering Principle supports the mathematical foundations used throughout the text. It guarantees the Division Algorithm, which in turn underpins modular arithmetic for octave equivalence, interval classes, and the systematic construction of scales and key signatures.

# Examples
- The set $\{3, 7, 11, 15, \ldots\}$ has smallest element 3
- The set of positive integers $n$ such that $n$ semitones exceeds an octave is $\{13, 14, 15, \ldots\}$, with smallest element 13
- Used implicitly when arguing about the existence of a unique remainder in the Division Algorithm

# Common Confusions
- The principle applies only to $\mathbb{Z}^+$ (or $\mathbb{N}$), not to $\mathbb{Z}$, $\mathbb{Q}$, or $\mathbb{R}$ -- the set of all positive rationals, for instance, has no smallest element
- It is an axiom, not a theorem: it looks obvious but cannot be derived without equivalent assumptions
