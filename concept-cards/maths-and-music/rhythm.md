# Quick Definition

The way in which time is organized within measures -- the specific pattern of note and rest durations that fills each measure and gives music its temporal character.

# Core Definition

*Rhythm* is the organization of time within measures, created by the specific sequence of durational notes and rests. A melody is defined and made recognizable not only by its sequence of pitches but by its rhythm. Rhythms can be straightforward or subtle; jazz often obscures the meter using complex sequences (Wright, pp. 36-37).

# Prerequisites

- **Meter and Time Signatures** — Rhythm fills the framework provided by meter
- **Note Durational Values** — Rhythm is constructed from note and rest durations

# Key Properties

1. Rhythm is the organization of time WITHIN measures (meter provides the framework)
2. The same pitches set to different rhythms produce different musical effects
3. Rhythm is as essential to melodic identity as pitch sequence
4. Rhythms can be analyzed as ordered sequences of durations summing to the measure's total
5. Rhythmic patterns can repeat (rhythmic translation)

# Construction / Recognition

## To analyze rhythm:

1. Identify the time signature (gives the measure framework)
2. List the sequence of note and rest durations within each measure
3. Verify durations sum to the total beats per measure
4. Look for repeating patterns (rhythmic translation)

# Context & Application

Rhythm is distinct from meter: meter provides the framework (beats per measure), while rhythm fills it. The same descending C major scale in even eighth notes evokes no particular song, but set to the rhythm of "Joy To The World" it is immediately recognizable. Swing rhythm is a notable convention where written rhythm differs from performed rhythm.

# Examples

- A descending C major scale in even eighth notes is not recognizable; the same pitches set to the rhythm of "Joy To The World" are immediately recognized (p. 37)
- Swing rhythm: written eighth notes performed as tied-triplet + triplet-eighth (pp. 36-37)
- Rhythmic translation: the rhythm of the first two bars repeated in subsequent bars, even while pitches vary (p. 38)

# Common Errors

- **Error**: Conflating rhythm with meter
  **Correction**: Meter is the underlying beat structure; rhythm is how durations are arranged within that structure

# Common Confusions

- **Confusion**: Thinking a melody is defined only by its pitches
  **Clarification**: Rhythm is equally essential — the same pitches with different rhythms create a different melody
- **Confusion**: Thinking swing rhythm is what is literally written
  **Clarification**: Swing notation is a shorthand; the performed rhythm differs from the written notes
