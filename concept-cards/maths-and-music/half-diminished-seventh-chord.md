# Quick Definition

The half-diminished seventh chord is a four-note chord defined by the interval sequence (3, 3, 4, 2) in semitones. It has a discernible root and an unstable, tension-laden quality that suggests resolution.

# Core Definition

The half-diminished seventh chord is defined by the sequence of modular intervals (3, 3, 4, 2) in Z_12:

root --(3)--> third --(3)--> fifth --(4)--> seventh --(2)--> (root)

This sequence has no non-trivial cyclic permutations that reproduce it -- the four permutations (3,3,4,2), (3,4,2,3), (4,2,3,3), (2,3,3,4) are all distinct -- so the root is uniquely identifiable (Wright, p. 49).

# Prerequisites

- **Diminished Triad** -- The half-diminished seventh can be seen as a diminished triad with the interval 6 split into 4 + 2

# Key Properties

1. Contains exactly four distinct note classes
2. Interval sequence: (3, 3, 4, 2) in semitones, summing to 12
3. Contains the diminished triad (3, 3) with the interval 6 split as 4 + 2 by the seventh
4. Root to fifth: diminished fifth (6 semitones = 3 + 3)
5. No non-trivial cyclic symmetries; root is uniquely identifiable
6. Labeled with suffix ø7 (e.g., Bø7)

# Construction / Recognition

## To Construct a Half-Diminished Seventh Chord

1. Build a diminished triad (root, up 3, up 3)
2. From the fifth, go up 4 semitones (major third) to the seventh
3. Verify: the seventh is 2 semitones below the root (completing the cycle)

# Context & Application

The half-diminished seventh chord has "a somewhat unstable aura and suggests the need for resolution." Like the dominant seventh chord, it often resolves around the circle of fifths. It commonly appears on scale degree VII in the major mode (e.g., Bø7 in C major) or scale degree II in the minor mode, where it functions as a predominant chord (Wright, pp. 49-50).

## Contrasts With

- **Diminished Seventh Chord** -- (3, 3, 3, 3): shares the first two intervals (3, 3) but has complete symmetry and no root
- **Seventh Chord** -- (4, 3, 3, 2): both resolve around the circle of fifths, but the seventh chord has a major triad base

# Common Errors

- **Error**: Confusing the half-diminished seventh (3, 3, 4, 2) with the fully diminished seventh (3, 3, 3, 3)
  **Correction**: Compare the last two intervals: (4, 2) vs. (3, 3)

# Common Confusions

- **Confusion**: Thinking "half-diminished" means "halfway to diminished"
  **Clarification**: The name reflects that the chord shares some features with the diminished seventh (the first two intervals of 3, 3) but differs in having a discernible root and a different overall structure
- **Confusion**: Assuming the half-diminished seventh lacks a root because it shares intervals with the rootless diminished seventh
  **Clarification**: The half-diminished seventh has all distinct cyclic permutations, so its root is uniquely identifiable
