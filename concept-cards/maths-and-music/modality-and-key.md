# Quick Definition
The mode of a composition is the scale (one of the seven modal patterns) in which it is most naturally situated; the key combines the keynote (tonic) with the mode designation to fully specify the tonal framework.

# Formal Definition
The mode is the specific cyclic permutation of the diatonic scale interval pattern that a composition employs. The keynote (or tonic) is the initial note of that modal scale, usually identifiable by its frequent appearance as a returning point in melody and as the root of cadential chords. The key of a piece is the combination of the keynote and mode designation (e.g., $B^\flat$ Dorian, G Phrygian, $F^\sharp$ major). The key is determined by the key signature together with the keynote.

# Mathematical Context
The key can be formalized as an ordered pair (keynote, mode) $\in$ {12 note classes} $\times$ {7 modes}, giving $12 \times 7 = 84$ possible keys. However, since a key signature determines a unique scale in each mode, the mapping from key signatures to keys is 7-to-1 (each key signature corresponds to 7 possible modes). The tonic serves as the identity element or reference point for scale degree numbering.

# Musical Context
The tonic (also called tonal center) serves as "home base" for melody and harmony. It is usually identified by its frequent appearance as a returning point and as the root of chords, almost always including the final chord. The keynote together with the mode designation fully specifies the key. In practice since the 18th century, only two modes (major/Ionian and minor/Aeolian) have been standard, though modal writing has been revived in jazz and other genres.

# Examples
- $B^\flat$ Dorian: keynote is $B^\flat$, mode is Dorian
- G Phrygian: keynote is G, mode is Phrygian
- $F^\sharp$ major: keynote is $F^\sharp$, mode is Ionian (major)
- C Ionian and F Lydian share the same key signature but have different tonics and modes

# Common Confusions
- Key signature alone does not determine mode or key; the tonic must also be identified
- "Key" requires both a tonic note and a mode designation
- The tonic is identified from musical context (cadences, melodic contour), not from the key signature alone
