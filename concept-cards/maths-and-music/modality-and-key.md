# Quick Definition

The mode of a composition is the scale (one of the seven modal patterns) in which it is most naturally situated; the key combines the keynote (tonic) with the mode designation to fully specify the tonal framework.

# Core Definition

The *mode* is the specific cyclic permutation of the diatonic scale interval pattern that a composition employs. The *keynote* (or *tonic*) is the initial note of that modal scale, usually identifiable by its frequent appearance as a returning point in melody and as the root of cadential chords. The *key* of a piece is the combination of keynote and mode designation (e.g., $B^\flat$ Dorian, G Phrygian, $F^\sharp$ major). The key is determined by the key signature together with the keynote (Wright, pp. 26-27).

# Key Properties

1. Key = keynote + mode designation (e.g., $B^\flat$ Dorian)
2. The key signature determines a unique scale in each mode, but not the mode itself
3. The keynote can be formalized as an ordered pair: (note class, mode) $\in \{12\} \times \{7\} = 84$ possible keys
4. The tonic is identified from musical context: cadences, melodic contour, harmonic function
5. The tonic is often called the *tonal center* and serves as "home base" for melody and harmony

# Construction / Recognition

## To determine the key of a composition:

1. Identify the key signature (determines which notes are altered)
2. Identify the tonic (from cadences, final chord, returning melodic point)
3. Determine the mode from the relationship between key signature and tonic
4. The key is the tonic plus the mode name

# Context & Application

The tonic serves as "home base" for both melody and harmony. It is usually identified by its frequent appearance as a returning point and as the root of chords, almost always including the final chord. Since the 18th century, only major and minor modes have been standard, though modal writing has been revived in jazz and other genres.

# Examples

- $B^\flat$ Dorian: keynote is $B^\flat$, mode is Dorian (p. 27)
- G Phrygian: keynote is G, mode is Phrygian (p. 27)
- $F^\sharp$ major: keynote is $F^\sharp$, mode is Ionian (p. 27)
- C Ionian and F Lydian share the same key signature but have different tonics and modes (p. 27)

# Common Errors

- **Error**: Determining mode from key signature alone
  **Correction**: Key signature alone is ambiguous — the tonic must also be identified from musical context

# Common Confusions

- **Confusion**: Thinking "key" means only the key signature
  **Clarification**: "Key" requires both a tonic note and a mode designation
- **Confusion**: Believing the tonic can always be read from the notation
  **Clarification**: The tonic is identified from musical context (cadences, melodic contour), not from the key signature alone
