# Quick Definition
Intervals have an upward or downward orientation. An interval from f_1 to f_2 is upward when f_2 > f_1 (ratio > 1) and downward when f_2 < f_1 (ratio < 1).

# Formal Definition
The interval given by pitches (f_2, f_1), read as "the interval from f_1 to f_2," is:
- Upward if f_2 > f_1, equivalently r = f_2/f_1 > 1
- Downward if f_2 < f_1, equivalently r = f_2/f_1 < 1
- Unison if f_2 = f_1, equivalently r = 1

Thus the set of downward intervals corresponds to (0, 1) in R+, and the set of upward intervals corresponds to (1, infinity).

# Mathematical Context
Orientation partitions R+ \ {1} into two subsets: (0, 1) for downward intervals and (1, infinity) for upward intervals. These two sets are related by the inversion map r -> r^(-1), which swaps them. The logarithm transforms this partition into negative reals (downward) and positive reals (upward), with 0 (unison) as the boundary -- matching the more intuitive additive picture.

# Musical Context
When a musician says "up a fifth," they mean the interval with ratio approximately 3/2 (> 1). "Down a fifth" means ratio approximately 2/3 (< 1). By convention, if orientation is not stated, an upward interval is assumed. For example, "the interval of a fourth" means "the upward interval of a fourth."

# Examples
- Up a major third: ratio 2^(1/3) ~ 1.26 (greater than 1)
- Down a minor third: ratio 2^(-1/4) ~ 0.84 (less than 1)
- Unison: ratio 1

# Common Confusions
- Downward intervals have ratios between 0 and 1, not negative ratios -- all interval ratios are positive
- The ratio 0.5 is not "half an interval" but rather "down one octave"
- Orientation is determined by whether the ratio is greater or less than 1, not by its absolute size
