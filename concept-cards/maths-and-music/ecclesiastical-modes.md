# Quick Definition
The seven scales obtained by starting the diatonic scale on each of its seven notes, each producing a distinct interval pattern, named (incorrectly) by the Swiss theorist Heinrich Glarean after ancient Greek modes.

# Formal Definition
The seven ecclesiastical modes are the cyclic permutations of the standard diatonic scale, each yielding a distinct interval sequence. Starting from C on the white keys:

| White keys | Mode | Interval pattern |
|-----------|------|-----------------|
| C-C | Ionian | $1, 1, \frac{1}{2}, 1, 1, 1, \frac{1}{2}$ |
| D-D | Dorian | $1, \frac{1}{2}, 1, 1, 1, \frac{1}{2}, 1$ |
| E-E | Phrygian | $\frac{1}{2}, 1, 1, 1, \frac{1}{2}, 1, 1$ |
| F-F | Lydian | $1, 1, 1, \frac{1}{2}, 1, 1, \frac{1}{2}$ |
| G-G | Mixolydian | $1, 1, \frac{1}{2}, 1, 1, \frac{1}{2}, 1$ |
| A-A | Aeolian | $1, \frac{1}{2}, 1, 1, \frac{1}{2}, 1, 1$ |
| B-B | Locrian | $\frac{1}{2}, 1, 1, \frac{1}{2}, 1, 1, 1$ |

# Mathematical Context
The interval sequence $1, 1, \frac{1}{2}, 1, 1, 1, \frac{1}{2}$ has no non-trivial cyclic permutation equal to itself, which proves that all seven cyclic permutations produce distinct modes. Each mode can be transposed to start on C (or any other note) by applying the appropriate accidentals. The modes demonstrate how a single set of notes (the white keys) can generate seven distinct musical "flavors" through cyclic permutation.

# Musical Context
The names were assigned by Heinrich Glarean (1488-1563), who incorrectly identified them with ancient Greek modes, yet these ecclesiastical names became the accepted terminology. Each mode built on C is shown in the text's chart with the appropriate accidentals. A key signature determines a unique scale in each mode, so the key signature alone does not determine the mode. The mode must be inferred from the music's tonal center.

# Examples
- Dorian on C: C, D, $E^\flat$, F, G, A, $B^\flat$, C
- Lydian on C: C, D, E, $F^\sharp$, G, A, B, C
- Phrygian on C: C, $D^\flat$, $E^\flat$, F, G, $A^\flat$, $B^\flat$, C
- The Ionian mode of C and the Lydian mode of F share the same key signature (no sharps or flats, different tonal centers)

# Common Confusions
- Glarean's names do not correspond to the original Greek mode names -- they are historically incorrect but universally adopted
- The key signature does not uniquely determine the mode: C Ionian and A Aeolian share the same key signature
- Locrian is the only mode with a diminished fifth above the tonic, making it rarely used as a primary key
