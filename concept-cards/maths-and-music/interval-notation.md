# Quick Definition
Standard mathematical notation for subsets of the real number line, using brackets and parentheses to denote closed, open, and half-open intervals.

# Formal Definition
For $a, b \in \mathbb{R}$:
- $(a, b) = \{x \in \mathbb{R} \mid a < x < b\}$ (open interval)
- $[a, b] = \{x \in \mathbb{R} \mid a \leq x \leq b\}$ (closed interval)
- $(a, b] = \{x \in \mathbb{R} \mid a < x \leq b\}$ (half-open)
- $[a, b) = \{x \in \mathbb{R} \mid a \leq x < b\}$ (half-open)

# Mathematical Context
Intervals are fundamental subsets of $\mathbb{R}$ used to describe domains, ranges, and regions of interest. Open intervals exclude endpoints; closed intervals include them. These appear throughout analysis, particularly when discussing functions, graphs, and continuous phenomena like sound waves. The notation distinguishes between strict and non-strict inequalities using parentheses vs. brackets.

# Musical Context
Mathematical intervals (subsets of $\mathbb{R}$) model continuous ranges of pitch or frequency. The range of human audibility, approximately $[20, 20000]$ Hz, is a closed interval in $\mathbb{R}^+$. This mathematical use of "interval" must be carefully distinguished from the musical use of "interval," which refers to the distance between two pitches measured in semitones.

# Examples
- The range of audible frequencies: approximately $[20, 20000]$ in Hz
- The domain of $\sin x$ restricted to one period: $[0, 2\pi)$
- The set of pitches is $\mathbb{R}^+$, which can be written as $(0, \infty)$

# Common Confusions
- Mathematical intervals (subsets of $\mathbb{R}$) vs. musical intervals (distances between pitches in semitones) -- Wright explicitly warns about this ambiguity
- Open vs. closed: $(a, b)$ excludes $a$ and $b$, while $[a, b]$ includes them
- The notation $(a, b)$ can also denote an ordered pair; context distinguishes the two uses
