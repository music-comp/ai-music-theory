# Quick Definition
The arrangement of white and black keys on a keyboard instrument, forming a repeating pattern that represents the chromatic scale, with an abstract infinite extension used for mathematical purposes.

# Formal Definition
The keyboard consists of "white notes" and "black notes" arranged in a specific pattern of juxtapositions that repeats every octave (12 semitones). Abstractly, we envision a keyboard extending infinitely in both directions, giving an infinite set of notes. The notes appearing on this extended keyboard are called keyboard notes. This set does not represent all pitches, as there are pitches between adjacent notes.

# Mathematical Context
The infinite keyboard establishes a discrete subset of $\mathbb{R}^+$ (via frequency), forming a lattice of equally spaced points on the logarithmic frequency axis. Adjacent keys are separated by one semitone (a factor of $2^{1/12}$ in frequency). The keyboard provides a concrete model for $\mathbb{Z}$ when notes are numbered by semitone distance from a reference note.

# Musical Context
The repeating pattern within each octave consists of 7 white keys (corresponding to the diatonic notes C, D, E, F, G, A, B) and 5 black keys (corresponding to the sharps/flats). The black keys are grouped in alternating clusters of 2 and 3, providing a visual reference for orientation. The physical layout reflects the asymmetric interval pattern of the diatonic scale: half steps occur between E-F and B-C (adjacent white keys with no black key between them).

# Examples
- The white keys from C to B span one octave of the diatonic scale
- Black keys provide the remaining 5 chromatic notes within each octave
- The actual piano keyboard ranges from $A_0$ to $C_8$ (88 keys), but the abstract keyboard extends infinitely
- Adjacent keys (white or black) are always one semitone apart in equal temperament

# Common Confusions
- Not all adjacent white keys are a whole step apart: E to F and B to C are half steps
- The keyboard is a discrete sampling of the pitch continuum; pitches between adjacent keys exist but are not represented
- "Keyboard note" refers specifically to notes available on the (abstract) keyboard, as opposed to arbitrary pitches in $\mathbb{R}^+$
