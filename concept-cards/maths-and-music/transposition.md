# Quick Definition
A vertical shift of a melodic pattern, moving each note up or down by a fixed interval, analogous to the graph transformation $y = f(x) + c$, with two types: chromatic (preserving exact semitone intervals) and diatonic (preserving scale-degree intervals).

# Formal Definition
Transposition is a vertical shift applied to a repeating melodic pattern, analogous to replacing $y = f(x)$ by $y = f(x) + c$. Two types are distinguished:

**Chromatic transposition**: each note is shifted by a fixed chromatic interval (fixed number of semitones), exactly preserving all interval sizes.

**Diatonic transposition**: each note is shifted by the same number of diatonic scale tones, producing a melody with the same general shape but with chromatic intervals not perfectly preserved due to the non-uniform spacing of diatonic scale steps.

# Mathematical Context
Chromatic transposition is a true isometry of the pitch axis (measured in semitones): it adds a constant to each pitch value. Diatonic transposition is NOT an isometry of the chromatic pitch space; it preserves scale-degree distances but not semitone distances. The difference arises because the diatonic scale has non-uniform intervals ($1, 1, \frac{1}{2}, 1, 1, 1, \frac{1}{2}$), so shifting by one diatonic step sometimes changes a pitch by a whole step and sometimes by a half step.

# Musical Context
Chromatic transposition exactly preserves the "sound" of a passage (all intervals identical). Diatonic transposition preserves the general contour but alters some interval qualities (e.g., a major third may become a minor third). Both types are common compositional techniques. Diatonic transposition keeps the melody within the key without introducing accidentals.

# Examples
- **Chromatic**: In Gershwin's "Strike Up The Band," the second 8 measures repeat the melody of the first 8, transposed up by a perfect fourth (5 semitones) -- all intervals preserved exactly
- **Diatonic**: In "O Tannenbaum," the first bracketed sequence is shifted down by one diatonic scale tone in the second bracketed sequence -- the general shape is preserved but some interval qualities change

# Common Confusions
- Chromatic transposition (exact interval preservation) vs. diatonic transposition (scale-degree preservation) -- these are fundamentally different operations
- Transposition (vertical shift, pitch change) vs. translation (horizontal shift, time change) -- similar concepts in different dimensions
- A diatonic transposition may simultaneously be a chromatic transposition only in special cases (e.g., when all intervals involved happen to be uniform)
