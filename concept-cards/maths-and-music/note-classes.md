# Quick Definition
The equivalence classes of notes under octave equivalence, each identified by a letter name (with possible accidental) and containing all notes of that name across all octaves.

# Formal Definition
A note class is an equivalence class of the octave equivalence relation on the set of keyboard notes. A note identified by a letter with no subscript (e.g., $B^\flat$) is viewed as an equivalence class: $B^\flat = \{B^\flat_n \mid n \in \mathbb{Z}\}$. There are exactly 12 note classes in the chromatic scale, modulo enharmonic equivalence.

# Mathematical Context
Note classes form the quotient set of the set of keyboard notes by the octave equivalence relation. This quotient set has exactly 12 elements (chromatic note classes) or 7 elements (diatonic note classes within a given key). Note classes can be identified with $\mathbb{Z}/12\mathbb{Z}$ (integers modulo 12), establishing a connection to modular arithmetic. This is distinct from the concept of "durational note" equivalence classes discussed in Chapter 2.

# Musical Context
In practice, musicians routinely work with note classes: a chord labeled "C major" contains the note classes C, E, G regardless of specific octave. Key signatures operate on note classes. Scale construction uses note classes. When a composer writes in the key of G, $F^\sharp$ means every F in the piece is sharped, treating F as a note class.

# Examples
- The note class C contains $\ldots, C_2, C_3, C_4, C_5, \ldots$
- There are 12 chromatic note classes: C, C$^\sharp$/D$^\flat$, D, D$^\sharp$/E$^\flat$, E, F, F$^\sharp$/G$^\flat$, G, G$^\sharp$/A$^\flat$, A, A$^\sharp$/B$^\flat$, B
- There are 7 diatonic note classes in any major key (e.g., in C major: C, D, E, F, G, A, B)

# Common Confusions
- Note classes (equivalence under octave) vs. durational notes (equivalence under duration) -- both are equivalence classes but on different sets with different relations
- A note class may have multiple names due to enharmonic equivalence: the note class containing $F^\sharp$ and $G^\flat$ is one class with two common names
- Note classes are abstract; specific notes like $C_4$ are concrete representatives of the class C
