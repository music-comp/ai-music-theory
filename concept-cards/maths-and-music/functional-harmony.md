# Quick Definition

Functional harmony is the system in which chords serve specific roles (tonic, dominant, predominant) within a key, and progressions create directed harmonic motion -- typically following the circle of fifths toward resolution on the tonic.

# Core Definition

In functional harmony, chords are understood as fulfilling harmonic functions relative to a tonic. Musical "character" is created by the way various chord types are organized and juxtaposed in time. A "progression" is the procedure from one chord to the next. A melody often suggests the chords which should underlie it by offering sequences of notes that lie mostly within a certain chord -- this is "implied harmony." However, this basic implied harmony can be "artistically altered or enhanced" (Wright, pp. 53-55).

# Key Properties

1. Chords serve roles relative to a tonic (I = stability, V7 = tension)
2. Progressions follow patterns that create tension and resolution
3. The circle of fifths governs classical progression patterns
4. A melody can imply harmony through its pitch content
5. Multiple valid harmonizations of the same melody exist
6. The dominant seventh (V7) resolving to tonic (I) is the central functional progression

# Construction / Recognition

## To Analyze Functional Harmony

1. Identify the key and mode
2. Label each chord with Roman numerals and suffixes
3. Identify the harmonic function of each chord (tonic, dominant, predominant)
4. Trace the progression pattern (check for circle-of-fifths motion)

# Context & Application

The source demonstrates functional harmony through a melody in F major that can be harmonized with I -> V7 -> I, but also with I -> IIm -> IIIm, I -> IV -> V, I -> bVII -> I, or I -> bVII -> V, "each giving the passage a different personality." This illustrates that functional harmony provides a framework for artistic choice, not a single correct answer. The dominant seventh chord plays a central role, and when a chord appears in a "dominant" role, it should be spelled as a seventh chord rather than an augmented sixth (Wright, pp. 53-55).

# Examples

**Example 1** (p. 54): A melody in F major is comfortably accommodated by I -> V7 -> I (F -> C7 -> F).

**Example 2** (p. 54): The same melody also works with I -> IIm -> IIIm, I -> IV -> V, I -> bVII -> I, or I -> bVII -> V.

**Example 3** (p. 53): The classical circle-of-fifths progression VI7 -> IIm -> V7 -> I demonstrates directed harmonic motion.

# Common Errors

- **Error**: Assuming there is only one correct harmonization for a melody
  **Correction**: Multiple harmonizations can work; the choice is artistic within functional constraints

# Common Confusions

- **Confusion**: Thinking functional harmony is the only harmonic system
  **Clarification**: Much twentieth-century and non-Western music operates outside functional harmony
- **Confusion**: Believing "function" refers to the chord's acoustic properties
  **Clarification**: Function refers to the chord's role in the key (tonic, dominant, etc.), not its sound quality
