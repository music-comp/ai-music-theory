# Quick Definition

A circular arrangement showing all n-chromatic intervals obtained by successive iteration of a generating interval, generalizing the familiar circle of fifths.

# Core Definition

For a generating interval [m] in Z_n (where gcd(m, n) = 1), the circle of intervals based on [m] is the sequence [0], [m], [2m], [3m], ..., [(n-1)m] arranged around a circle. Since [m] is a generator, this sequence visits all n elements of Z_n before returning to [0] (Wright, pp. 75-76).

# Prerequisites

- **Generating interval** — Only generating intervals produce complete circles
- **N-chromatic scale** — The circle operates within an n-chromatic context

# Key Properties

1. A circle based on a generator visits all n elements of Z_n exactly once
2. Generating intervals [m] and [n - m] produce the same circle traversed in opposite directions
3. Non-generating intervals produce smaller cycles that miss some elements
4. The circle is a visual representation of the cyclic group Z_n generated by [m]

# Construction / Recognition

## To Construct a Circle of Intervals
1. Verify that [m] is a generating interval (gcd(m, n) = 1)
2. Start at [0] and repeatedly add [m] modulo n
3. Record each position: [0], [m], [2m], [3m], ...
4. After n steps, the sequence returns to [0]
5. Arrange these positions around a circle

# Context & Application

The circle of fifths is the most famous example: iterating by 7 semitones in Z_12 produces C, G, D, A, E, B, F#, C#, G#, D#, A#, F, then back to C. This circle is foundational for understanding key relationships, chord progressions, and modulation in Western tonal music. The circle of fourths is the same circle traversed in reverse.

# Examples

**Example 1** (p. 76): In Z_14, the circle based on [5] visits: [0], [5], [10], [1], [6], [11], [2], [7], [12], [3], [8], [13], [4], [9].

**Example 2** (implied): In Z_12, the circle based on [7] (fifths) visits: [0], [7], [2], [9], [4], [11], [6], [1], [8], [3], [10], [5].

**Example 3**: Generating intervals [5] and [7] in Z_12 give the same circle in opposite directions (fourths and fifths).

# Common Errors

- **Error**: Attempting to construct a circle from a non-generating interval
  **Correction**: Non-generating intervals produce smaller cycles, not complete circles visiting all n elements

# Common Confusions

- **Confusion**: Thinking the circle of fifths and circle of fourths are different structures
  **Clarification**: They are the same circle traversed in opposite directions; [5] and [7] are additive inverses in Z_12
