# Quick Definition
Chord spelling refers to the choice of enharmonic representation for each note in a chord. Correct spelling follows rules relating each chord tone's underlying unaltered note class to the root's position on the diatonic scale.

# Formal Definition
A "spelled note" differentiates between enharmonically equivalent notations (e.g., A# vs. Bb). The underlying unaltered note class of a spelled note is obtained by stripping away accidentals in the ambient key. Correct chord spelling requires:
- The third should be spelled so its underlying unaltered note class is two scale tone classes above the root's
- The fifth should be spelled so its underlying unaltered note class is four scale tone classes above the root's
- The seventh should be spelled so its underlying unaltered note class is six scale tone classes above the root's

# Mathematical Context
Chord spelling operates in the diatonic system (Z_7, the seven scale tone classes) rather than the chromatic system (Z_12). The spelling rules ensure that chord tones maintain proper relationships in the diatonic letter-name system, even when accidentals are needed. This is essentially a constraint that the projection from Z_12 to Z_7 (mapping chromatic to diatonic positions) preserves the expected spacing.

# Musical Context
Correct spelling is important for readability and for identifying chord structure at a glance. For example, if the root of a major chord is C#, the third must be spelled E# (not F), even though they are enharmonically identical. Correct spelling sometimes necessitates double flats, double sharps, or non-diatonic notes with diatonic enharmonic equivalents. For augmented and diminished seventh chords (which lack inherent roots), correct spelling identifies which note serves as root.

# Examples
- C# major: C#-E#-G# (not C#-F-G#, which misspells the third)
- Eb7: Eb-G-Bb-Db (not Eb-G-Bb-C#, which misspells the seventh)
- D major: D-F#-A (not D-Gb-A, which misspells the third)
- Correct spelling of Co7 requires Bbb for the seventh (not A)
- Chords are sometimes intentionally misspelled to make voice leading more readable

# Common Confusions
- Enharmonically equivalent notes (A# and Bb) are the same pitch but different spellings; correct chord spelling requires choosing the right one
- Double sharps and double flats are sometimes necessary for correct spelling
- Spelling rules are followed less rigorously for diminished triads and symmetric chords
- The augmented sixth chord is enharmonically the same as a seventh chord but with different spelling
