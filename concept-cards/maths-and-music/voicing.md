# Quick Definition
Voicing refers to the particular way a chord is written or realized -- the specific notes (as opposed to note classes) chosen, including their octave placement and any doublings.

# Formal Definition
A voicing of a chord is a specific selection of pitches (not merely note classes) that realizes the chord. Since chords are defined by note classes modulo octave, any note in a chord may be displaced by one or more octaves and/or doubled. Different voicings of the same chord may place different chord tones as the lowest note, spread the notes across different octaves, and double certain note classes.

# Mathematical Context
Voicing operates at the level of Z (specific pitches measured in semitones) rather than Z_12 (note classes modulo octave). The passage from voicing to chord type is the quotient map Z -> Z_12. Multiple elements of Z may map to the same element of Z_12, corresponding to octave doublings. The root need not correspond to the minimum element in the voicing.

# Musical Context
Voicing is a crucial aspect of arranging and composition. The root need not be the bottom note -- for example, a C major chord voiced as G3-C4-E4 has the fifth as the lowest note (called "second inversion"). Different voicings of the same chord create different sonic textures and affect voice leading between chords. Voicing choices are central to the craft of orchestration and arrangement.

# Examples
- C major chord can be voiced as C3-E3-G3, E3-G3-C4, G3-C4-E4, C3-G3-E4-C5, etc.
- In all these voicings, the root remains C, identifiable from the interval sequence
- The rightmost voicing shown in the text has the fifth as the lowest note

# Common Confusions
- The root is not necessarily the lowest note in a voicing
- Changing the voicing does not change the chord type or root (for chords with discernible roots)
- Voicing is about specific pitch placement; chord type is about abstract note class relationships
