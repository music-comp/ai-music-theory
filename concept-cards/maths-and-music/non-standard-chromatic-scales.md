# Quick Definition
Chromatic scales that divide the octave into a number of equal intervals other than 12, producing alternative tuning systems with unfamiliar interval sizes.

# Formal Definition
A non-standard chromatic scale is an n-chromatic scale where $n \neq 12$. The chromatic unit has ratio $2^{1/n}$ and measures $1200/n$ cents. Standard keyboard intervals can be approximated in the n-chromatic scale by finding the nearest whole number of n-chromatic units.

# Mathematical Context
To convert $\ell$ semitones into n-chromatic units: $\ell$ semitones $= \frac{n}{12} \cdot \ell$ n-chromatic units. To convert any ratio $r$ to n-chromatic units: $x = n \log_2 r = n \frac{\ln r}{\ln 2}$. The best n-chromatic approximation of a keyboard interval is obtained by rounding to the nearest integer.

# Musical Context
Non-standard chromatic scales can be experienced using synthesizer detuning. When $n < 12$, one can detune existing keys to produce the n-chromatic scale. For example, a 5-note chromatic scale starting on G requires detuning A (+40 cents), B (+80 cents), C (+220 cents), and D (+260 cents) to make equal 240-cent intervals.

# Examples
- $n = 14$: the chromatic unit is $\approx 85.714$ cents. A fourth (5 semitones) $\approx 5.833$ units, best approximated by 6 units ($\approx 514.29$ cents, about 14.29 cents sharp of the keyboard fourth)
- $n = 19$: used in some microtonal music traditions
- $n = 5$: unit = 240 cents; five equally spaced notes per octave
- The tritone is exactly $n/2$ units in any even-n scale

# Common Confusions
- Non-standard chromatic scales are not the same as non-equal temperaments; they still divide the octave equally, just into a different number of parts
- A non-standard scale may approximate some standard intervals well and others poorly; there is no guarantee that familiar chords will sound "right"
