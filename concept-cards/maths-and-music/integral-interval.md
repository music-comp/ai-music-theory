# Quick Definition
An integral interval is a musical interval whose frequency ratio is a positive integer. A prime interval is one whose ratio is a prime number.

# Formal Definition
An integral interval is a musical interval with ratio n where n is a positive integer. The set of integral intervals forms a monoid under composition of intervals, identifiable with (Z, *). A prime interval is an integral interval whose ratio is a prime number.

# Mathematical Context
The monoid structure means integral intervals are closed under composition (multiplying ratios), composition is associative, and there is an identity element (unison, ratio 1). Unlike a group, inverses are not required -- the ratio 1/n is not an integer for n > 1.

# Musical Context
Each positive integer n defines a unique musical interval. When sounded, each integer possesses a unique "personality" determined by its prime factorization. The interval for a composite number n = p1 * p2 * ... is obtained by composing (stacking) the intervals of its prime factors.

# Examples
- 1 = unison (identity element)
- 2 = octave
- 3 = octave + fifth (approximately)
- 6 = 2 * 3, so octave + octave + fifth

# Common Confusions
Students may confuse "integral interval" (ratio is an integer) with "interval measured in integers" (like semitone counts). The term specifically refers to frequency ratios that are positive integers.
