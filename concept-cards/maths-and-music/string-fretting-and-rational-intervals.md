# Quick Definition
Rational intervals can be accurately produced on a vibrating string using compass and straightedge to divide the string length, a technique accessible to ancient mathematicians, unlike the irrational intervals of equal temperament.

# Formal Definition
For a vibrating string of length L with fundamental frequency f, fretting the string at distance (m/n)*L from one end produces a vibrating length of (m/n)*L, yielding frequency f*(n/m). The rational interval n/m (where n/m >= 1) is thus obtained by the geometric construction of dividing the string into n equal parts. Since any interval on the real number line can be divided into n equal subintervals using compass and straightedge, this technique was accessible to ancient geometers.

# Mathematical Context
The key mathematical point is that rational divisions of a string length require only the tools of Euclidean geometry (compass and straightedge). By contrast, the equal-tempered semitone requires placing a fret at distance 2^(-1/12)*L from the end, which involves an irrational number not constructible by simple geometric means. This distinction between rational and irrational constructions parallels the ancient Greek distinction between commensurable and incommensurable magnitudes.

# Musical Context
This technique explains how ancient musicians could produce precise just intervals without modern measurement tools. A luthier could divide a string into halves (octave), thirds (interval of 3), quarters, fifths, etc., using only geometric methods. The historical priority of rational intervals over tempered ones is partly a consequence of this constructibility -- just intervals were the intervals that could actually be built with the technology available.

# Examples
- Octave: fret at L/2 (divide string in half)
- Just fifth (3/2): fret at 2L/3 (divide string into thirds, use two-thirds)
- Just fourth (4/3): fret at 3L/4 (divide string into quarters, use three-quarters)
- Just major third (5/4): fret at 4L/5
- Equal-tempered semitone: fret at 2^(-1/12)*L ~ 0.9439*L (not constructible by compass and straightedge)

# Common Confusions
- The string is fretted at (m/n)*L to produce ratio n/m, not at (n/m)*L -- shorter string = higher pitch
- Modern fretted instruments (guitar) use equal-tempered fret placement (irrational distances), not rational divisions
- The fact that rational intervals are geometrically constructible does not mean they are "more correct" -- it explains their historical priority
