# Quick Definition
The standard number sets used throughout mathematical music theory: integers (Z), rationals (Q), and reals (R), along with their positive subsets.

# Formal Definition
The fundamental number sets are denoted:
- $\mathbb{R}$: the set of real numbers
- $\mathbb{Q}$: the set of rational numbers
- $\mathbb{Z}$: the set of integers
- $\mathbb{R}^+ = \{x \in \mathbb{R} \mid x > 0\}$: positive reals
- $\mathbb{Q}^+ = \{x \in \mathbb{Q} \mid x > 0\}$: positive rationals
- $\mathbb{Z}^+ = \{x \in \mathbb{Z} \mid x > 0\}$: positive integers (also called natural numbers, $\mathbb{N}$)

# Mathematical Context
These sets are ordered ($<, \leq, >, \geq$) and satisfy standard ordering properties. Key properties include: if $a < b$ and $c > 0$, then $ac < bc$; if $a < b$ and $c < 0$, then $ac > bc$. The containment relationship is $\mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$, and similarly $\mathbb{Z}^+ \subset \mathbb{Q}^+ \subset \mathbb{R}^+$. Basic set-theoretic notions (element, subset, union, intersection, function, one-to-one, onto) are assumed.

# Musical Context
The set $\mathbb{R}^+$ is identified with the set of all pitches via frequency in hertz. Integers $\mathbb{Z}$ arise in note subscript numbering, semitone counting, and modular arithmetic for octave equivalence. Rationals $\mathbb{Q}$ appear in frequency ratios for just intonation and in durational values of notes (powers of $1/2$).

# Examples
- The pitch A above middle C corresponds to the real number 440 in $\mathbb{R}^+$ (frequency 440 Hz)
- The 12 semitones of the chromatic scale are counted using $\mathbb{Z}^+$
- Frequency ratios like 3/2 (perfect fifth in just intonation) belong to $\mathbb{Q}^+$

# Common Confusions
- $\mathbb{Z}^+$ vs $\mathbb{N}$: some authors include 0 in the natural numbers, but Wright defines $\mathbb{N} = \mathbb{Z}^+$, which excludes 0
- The set of pitches is $\mathbb{R}^+$, not $\mathbb{Z}^+$, even though we typically work with discrete keyboard notes
