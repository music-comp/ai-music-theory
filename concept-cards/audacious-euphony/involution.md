# Quick Definition
An involution is a transformation that "undoes itself" when applied twice consecutively, so that T(T(X)) = X; all mode-switching transformations (P, L, H) are involutions.

# Formal Definition
In mathematical terms, an involution is a function that is its own inverse. For triadic transformations, this means applying the same transformation twice returns to the original triad. The P, L, and H transformations are all involutions because they each switch the mode of a triad: major becomes minor, and applying the same transformation again returns minor to major.

# Musical/Mathematical Formulation
Definition: A transformation T is an involution if T(T(X)) = X for all X.

Hexatonic involutions:
- P(P(C major)) = P(c minor) = C major
- L(L(C major)) = L(e minor) = C major
- H(H(C major)) = H(ab minor) = C major

Note on LP and PL:
- LP(LP(C major)) = LP(E major) = Ab major (NOT C major)
- Therefore LP is NOT an involution
- LP has order 3 (returns after three applications)
- The complete hexatonic cycle has order 6

Involution property arises from mode-switching:
- Any transformation that switches mode (major to minor or vice versa) is necessarily an involution
- Switching mode twice returns to original mode

# Musical Context/Application
The involution property means that each of P, L, and H defines a symmetric relationship between triads: if C major is the P-partner of c minor, then c minor is equally the P-partner of C major. There is no directionality inherent in these relations; either triad can be the "source" or "target."

# Common Confusions
- Not all triadic transformations are involutions; LP has order 3, not 2
- Involution is a mathematical property, not a musical effect
- Being an involution means T inverse = T, not that T has no effect
- The R (relative) transformation is also an involution, though not discussed extensively in Chapter 2
