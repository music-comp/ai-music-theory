# Quick Definition
Tonnetz performance refers to the interpretive shaping of analytical data on a Tonnetz diagram, analogous to how musical performers shape notated music, allowing multiple valid analytical readings of the same harmonic data.

# Formal Definition
**Tonnetz performance** is Cohn's term for the interpretive act of presenting harmonic data on a Tonnetz diagram. Just as musical performers make interpretive choices about a notated score, analysts make interpretive choices about how to shape, connect, and emphasize data points on a Tonnetz.

Two Tonnetz representations of the same passage constitute two "performances" upon a single pattern of dots:
- Both can be "note accurate" (faithful to the harmonic data)
- Each shapes the data differently
- Each draws breaths at different articulation points
- Each suggests different analytical interpretations

# Construction/Recognition
Tonnetz performance involves choices about:
1. **Connection**: Which triads to connect with arrows
2. **Grouping**: How to segment the progression into phrases or regions
3. **Emphasis**: Which arrivals to mark as structural vs. passing
4. **Interpretation**: Whether to show retention loops, chains, or linear progressions

The same harmonic data can support multiple well-formed Tonnetz performances, just as the same score supports multiple well-formed musical performances.

# Musical Context/Application
Tonnetz performance illustrates:
- The interpretive nature of analysis
- Multiple valid readings of the same data
- The relationship between visual representation and analytical interpretation
- How analysts make rhetorical choices about emphasis and grouping

The concept raises questions about:
- To what extent Tonnetz performances relate to musical performances
- Whether analytical representations are metaphoric or directly suggestive
- How performers might translate analytical insights into sound

# Examples
**Dvorak's "New World" Symphony, first movement development**: Figure 6.20 presents two components constituting two "performances" upon a single pattern of black dots:
1. **First reading (6.20a)**: Shows the progression as chains (R/P chain, hexatonic progression, intensive N/L chain)
2. **Second reading (6.20b)**: Interprets the first paragraph as a tour about an E retention loop, bridged by an A retention loop

Both readings are "note accurate" but shape the data differently and draw breaths at different articulation points. They illustrate interpretive leeway available to pan-triadic analysts using the Tonnetz as a representational "instrument."

# Common Confusions
- "Performance" here is metaphorical; it refers to analytical representation, not sound production
- Multiple valid Tonnetz performances don't mean all representations are equally useful
- The concept doesn't privilege any single reading as "correct"
- Tonnetz performance invites, but doesn't require, translation into musical performance
