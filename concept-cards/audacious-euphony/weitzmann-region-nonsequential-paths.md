# Quick Definition
Paths through a Weitzmann region that do not follow cyclic or sequential patterns, exploiting the region's flat-terrain structure where all triadic pairs are equidistant.

# Core Definition
"The flat-terrain status of a Weitzmann region dictates that not all of its progressions will be sequential or cyclic" (p. 97). The N/R cycle provides one possible ordering, but the uniform voice-leading distances permit any trajectory. Composers can explore regions by grouping triads by mode, by proximity to a tonic, or by any other organizational principle.

# Prerequisites
- **Weitzmann region**: The space being traversed
- **Weitzmann region structure**: The flat-terrain property that permits free ordering

# Key Properties
1. The flat terrain means no path is privileged by voice-leading distance
2. Composers can group triads by mode (all minor, then all major)
3. Nonsequential paths became increasingly common as composers moved beyond Classical syntax
4. Wagner and Strauss exploited this freedom extensively

# Construction / Recognition
Any ordering of the six regional triads is structurally valid. The total voice-leading work for visiting all six triads depends on the specific path but the individual steps all require 2 units.

# Context & Application
Nonsequential paths demonstrate that the Weitzmann region is a spatial resource, not just a cyclic pattern. This distinguishes Weitzmann regions from hexatonic cycles, where the graded structure naturally suggests sequential exploration.

# Examples
**Wagner, Parsifal, Act 1, mm. 404-13** (pp. 97-98): All three minor triads sounded in succession, then all three major triads, before resolving via augmented sixth.
**Strauss, "Fruhling"** (pp. 98-100): First half of the region explored through R+LP=S motive; second half through retrograded R+PL=S.

# Common Errors
- **Error**: Treating nonsequential exploration as random
  **Correction**: Composers create coherent trajectories using modal grouping, motivic patterns, or other organizational principles

# Common Confusions
- **Confusion**: The flat terrain means there is no structure to the region
  **Clarification**: The structure is uniform (all pairs equidistant), not absent
