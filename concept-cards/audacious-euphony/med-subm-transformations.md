# Quick Definition
Lewin's subdivision of DOM into two MED transformations (each taking the root down a diatonic third) and SUBD into two SUBM transformations (each taking the root up a diatonic third), allowing diatonic mediant relations to be modeled within the functional framework.

# Core Definition
Lewin proposed dividing DOM into two MED transformations, each taking the root down a diatonic third; he writes that the source chord "becomes the mediant" of the target chord (Lewin 1987, 176). Inversely, SUBD divides into two SUBM transformations, each taking the root up a diatonic third. Integrating these into Rings's model requires placing mediants halfway between DOM- or SUBD-related triads, as in Figure 8.2 (Cohn, p. 189).

# Prerequisites
- **DOM and SUBD transformations**: MED and SUBM are subdivisions of these
- **L transformation**: Need to understand how diatonic third relations overlap with chromatic common-tone relations

# Key Properties
1. Two MED transformations compose to yield one DOM
2. Two SUBM transformations compose to yield one SUBD
3. MED and SUBM measure diatonic thirds, not chromatic common-tone relationships
4. When interpolated into Rings's model, mediants create interpretive complications

# Construction / Recognition
- MED: Root descends by diatonic third (e.g., C major MED yields a minor; a minor MED yields F major; the two compose to C major DOM F major)
- SUBM: Root ascends by diatonic third (inverse of MED)

# Context & Application
Integrating MED/SUBM into the Rings grid creates a critical complication: c minor to Ab major projects both eastward into a hexatonic cycle and southward toward subdominant f minor (p. 189). This forces an arbitrary choice or cultivates an ambiguity. Lewin (1992) asserted a distinction in Parsifal: c minor to Ab major is heard as L when affiliated with Amfortas's suffering but as MED otherwise. "But this offers little guidance in the general case" (p. 189).

This complication motivates the convertible Tonnetz, where each relation occupies a unique position without forced disambiguation.

# Common Errors
- **Error**: Treating MED as equivalent to L
  **Correction**: They overlap in pitch content but differ in syntactic interpretation; Lewin insisted on the distinction

# Common Confusions
- **Confusion**: MED simply means "the mediant chord"
  **Clarification**: MED is a directed transformation where the source chord "becomes the mediant" of the target
