# Quick Definition
An analytical technique presenting a sequence of chronological Tonnetz snapshots that capture the listener's evolving awareness of diatonic and chromatic space as music unfolds, showing how diatonic capsules form, dissolve, and shift over time.

# Core Definition
The stroboscopic Tonnetz portrait is Cohn's analytical method for the convertible Tonnetz, presenting a series of chronological snapshots that "are fused in Web animation 8.9" (p. 204). Each snapshot captures a moment of the listener's awareness: which diatonic region is encapsulated, which chromatic alleys are active, and how the convertible Tonnetz is currently configured. The sequence of snapshots reveals the dynamic process of syntactic interaction -- how walls are erected, shifted, and dissolved over the course of a passage.

# Prerequisites
- **Convertible Tonnetz**: The theoretical model being applied
- **Diatonic encapsulation**: The dynamic process shown across snapshots

# Key Properties
1. Chronological sequence of Tonnetz states (top to bottom)
2. Each snapshot shows currently active diatonic encapsulation and chromatic alleys
3. The sequence captures syntactic conversion as a temporal process
4. Can be merged into animation with embedded sound for real-time experience
5. Shows parallelogram shifts, arrow activations/deactivations, alley sprouting

# Construction / Recognition
Cohn's method for the Liszt Consolation analysis (Figure 8.9, pp. 204-206): six snapshots arranged chronologically from top to bottom, each showing:
- Which diatonic parallelogram is active
- Which triads are currently sounding
- How the hexatonic alley is progressively revealed
- Where Rings arrows are active vs. retracted

Similarly, Figure 8.7 analyzes the first sentence as four Tonnetz snapshots representing "a series of snapshots of a listener's awareness as the music unfolds" (p. 197).

# Context & Application
The technique addresses a limitation of static harmonic analysis: "As an analytic statement about Liszt's Consolation, figure 8.7 is far from ideal. Its four components cumulatively consume considerable space in order to make some fairly rudimentary claims" (p. 199). But the Tonnetz representations add value by "allowing one to track the role of common tones in forging moment-to-moment connections, redefine a single triad in multiple tonal contexts, and observe the interaction of dominant and subdominant regions" (p. 199).

# Common Errors
- **Error**: Each snapshot is a self-contained analysis
  **Correction**: The analytical value lies in the sequence and the transitions between states

# Common Confusions
- **Confusion**: The stroboscopic technique is uniquely applicable to Liszt
  **Clarification**: It applies to any passage exhibiting syntactic interaction; "Readers should now be in a position to translate" other analyses into this format (p. 206)
