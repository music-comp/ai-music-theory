# Quick Definition
A circumnavigation of Cube Dance occurs when a triadic progression traverses all twelve voice-leading zones, completing a full cycle through the four hexatonic and four Weitzmann regions.

# Core Definition
A complete circumnavigation of Cube Dance traverses all twelve voice-leading zones (one full rotation). For chains generated by T1 or T5 transpositions, strict alternation of two transformations would require all twenty-four triads to close the cycle. Transformational substitutions (file transfers) allow shortcutting this journey while preserving the voice-leading trajectory. Some passages execute multiple rotations. Clockwise motion on Cube Dance denotes upshifting; counterclockwise denotes downshifting.

# Prerequisites
- **Cube Dance**: The graph being circumnavigated
- **Voice-leading Zone**: The twelve zones traversed
- **Chromatic Sequences**: The primary vehicle for circumnavigation

# Key Properties
1. One rotation = twelve zones traversed
2. Does not require visiting all twenty-four triads (only twelve zones)
3. File transfers (transformational substitutions) allow shortcutting
4. Multiple rotations possible and indicate sustained directional commitment
5. Clockwise = upshifting; counterclockwise = downshifting
6. Generated by odd-transposition sequences (T1, T3, T5, T7, T9, T11)

# Construction / Recognition
On Cube Dance:
- Track clockwise (upshift) or counterclockwise (downshift) motion through twelve radii
- One rotation = twelve zones traversed
- Shortcutting via file transfers reduces the number of triads needed
- Return to the starting zone (or zone equivalent) provides closure

Sequences that circumnavigate:
- L/R chains (T5): require many triads; Beethoven Ninth nearly completes 2+ tours
- S/P chains (T1): Liszt's Il Penseroso completes one full tour
- N/P chains (T5): circle-of-fifths sequences
- Various H/W combinations from Table 5.1

# Context & Application
Circumnavigation produces a satisfying sense of closure by returning to the starting zone. The technique is characteristic of extended chromatic passages in 19th-century music and can operate at various time scales, from single passages to entire song cycles. It represents the fullest exploitation of the pan-triadic universe.

# Examples
- **Beethoven, Ninth Symphony, Scherzo**: C major through nineteen triads to A major, more than two tours (Cohn 1991, 1992, 1997)
- **Liszt, Il Penseroso**: Complete S/P chain from Gb major to D major, one full clockwise tour (figure 5.14)
- **Brahms, Symphony No. 2, first movement**: R/L chain from f# minor executes a full clockwise rotation returning to zone 4 (figure 5.11)
- **Schumann, Dichterliebe**: Two complete upshifting rotations across sixteen songs (figure 6.15)
- **E.T.A. Hoffmann, Kreisleriana**: Six interior harmonies execute an upshift rotation (p. 149)

# Common Errors
- **Error**: Circumnavigation requires visiting all twenty-four triads
  **Correction**: It requires traversing all twelve zones; file transfers allow fewer triads

# Common Confusions
- **Confusion**: Any extended chromatic progression is a circumnavigation
  **Clarification**: Circumnavigation requires traversal of all twelve zones, not just chromatic motion

- **Confusion**: Multiple circumnavigations indicate lack of direction
  **Clarification**: They indicate sustained directional commitment (consistently upshifting or downshifting)
