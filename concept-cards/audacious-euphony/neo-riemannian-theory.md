# Quick Definition
An analytical approach to triadic harmony that uses transformational labels (P, L, R, etc.) to describe relationships between consonant triads, emerging from David Lewin's reading of Hugo Riemann's harmonic writings.

# Formal Definition
Neo-Riemannian theory is an analytical framework that originated with David Lewin's interpretation of Hugo Riemann's harmonic theories. It employs transformational labels to describe moves between consonant triads, emphasizing relationships based on common tones and voice-leading proximity rather than root motion or diatonic function. The approach has been developed and generalized by subsequent theorists including Cohn, Hyer, Hook, and others, though its precise domain has never been stable.

# Musical/Mathematical Formulation
Core transformations in neo-Riemannian theory:
- P (Parallel): C major <-> c minor (same root, change mode)
- L (Leittonwechsel): C major <-> e minor (shared minor third dyad)
- R (Relative): C major <-> a minor (shared major third dyad)

Additional transformations:
- N (Nebenverwandt): C major <-> f minor
- S (Slide): C major <-> c# minor (shared third)
- H (Hexatonic Pole): C major <-> g# minor (no shared tones, but in same hexatonic cycle)

These transformations are "involutions" - applying the same transformation twice returns to the starting triad.

# Musical Context/Application
Neo-Riemannian theory provides:
- A vocabulary for describing chromatic triadic progressions
- Analytical tools for passages that resist traditional Roman numeral analysis
- Connections to geometric representations (Tonnetz, hexatonic systems)
- A bridge between 19th-century harmonic theory and contemporary transformational theory

However, Cohn notes that labels alone do not constitute an explanation - they are "a bridge to a first approximation" leading toward understanding how transformations function within a compositional system.

# Examples
- Analysis of sequential passages using transformation chains (e.g., alternating L and P)
- Hexatonic cycles described through combinations of L and P transformations
- Weitzmann regions described through combinations of R, N, and S transformations

# Common Confusions
- Cohn avoids the term "neo-Riemannian" in Audacious Euphony because: (1) it gives too much credit to Riemann, who was more transmitter than generator of key ideas; (2) the domain has never been stable; (3) some attributed views (like harmonic dualism) are not shared by all practitioners
- Applying transformational labels is not the same as understanding triadic syntax
- "Neo-Riemannian" has been used to describe both an analytical approach AND the musical progressions analyzed - Cohn prefers "pan-triadic" for the latter
- The theory is not committed to harmonic dualism despite some claims to the contrary
