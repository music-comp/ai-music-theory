# Quick Definition
A "file transfer" is a transformational substitution that moves the voice-leading trajectory across major-third alleys on the Tonnetz, represented as a diagonal jog at 45 degrees to the prevailing horizontal motion, expediting arrival at a tonal goal by eight or sixteen stations in a chain.

# Formal Definition
When an H/W-group pairing generates a chain that must traverse all twenty-four triads before closing (as with T1 and T5 chains), a major-third substitution can advance the goal triad by eight or sixteen stations. On the Tonnetz, these substitutions appear as diagonal jogs (at approximately 45 degrees) against the prevailing horizontal trajectory. The term "file transfer" describes this shift across the vertical fault lines that separate the four major-third alleys. Each file transfer moves the progression from one augmented-triad-bounded alley to a non-adjacent one.

# Construction/Recognition
On the Tonnetz:
- The prevailing trajectory is horizontal (left-to-right or right-to-left)
- A file transfer appears as a diagonal jog at approximately 45 degrees
- The 45-degree fault lines show the orthogonal cut against major-third regions
- One file transfer saves eight stations; two save sixteen
- After the jog, the horizontal trajectory resumes at a different vertical position

# Musical Context
File transfers solve a practical compositional problem: a strict **L**/**R** chain requires seventeen or more stations to return to tonic. File transfers provide shortcuts while preserving the overall voice-leading direction.

# Examples
- Brahms *German Requiem*, mm. 261-271: Single **N**-for-**R** file transfer saves eight stations (figure 5.16)
- Chopin Ballade Op. 23: Two **N**-for-**R** file transfers save sixteen stations, enabling tritone-related tonal areas (figure 5.17)
- Bruckner Symphony No. 3 development: **N** substitution plus **PL** interpolation creates double file transfer (figure 5.18)
- Chopin Fantasy Op. 49: Sharp-angled file transfer creates temporary retreat (figure 5.20)

# Common Confusions
- A file transfer is not a disruption of the voice-leading trajectory; it is a shortcut that preserves it
- The diagonal angle on the Tonnetz represents the orthogonal relationship between the file transfer and the prevailing sequential pattern
- The number of stations saved depends on the number of file transfers: one saves eight, two save sixteen
