# Quick Definition
In 4-Cube Trio, the interlocking Boretz and octatonic regions are subject to figure-ground reversal: a passage may foreground Boretz-region membership (with octatonic bridges as transitions) or conversely foreground octatonic regions (with Boretz spiders as interregional bridges).

# Core Definition
Figure 7.15 "portrays the entire system of interlocking Boretz and octatonic regions. As in the triadic case (figure 5.2), the spiders and pools are subject to figure-ground reversals. The Tristan and Gotterdammerung passages foreground Boretz-region membership, but one can also conceive of passages where octatonic regions act as the primary macroharmonies, and the Boretz spiders constitute interregional bridges between them" (p. 175).

# Prerequisites
- **Boretz region**: One of the two interlocking structures
- **Octatonic region**: The other interlocking structure
- **4-Cube Trio**: The graph displaying the interlocking regions

# Key Properties
1. The same graph supports two complementary readings
2. Boretz-primary: Boretz regions are "figure," octatonic regions are "ground" (bridges)
3. Octatonic-primary: Octatonic regions are "figure," Boretz spiders are "ground" (bridges)
4. The Tristan and Gotterdammerung passages exemplify Boretz-primary hearing
5. Parallels the triadic case (hexatonic-Weitzmann figure-ground reversal, Figure 5.2)

# Construction / Recognition
- In a passage, determine which regional membership is primary:
  - If chords cluster by Boretz region and cross to others via octatonic bridges: Boretz-primary
  - If chords cluster by octatonic collection and cross to others via Boretz connections: octatonic-primary
- The choice depends on musical context, not on the abstract graph structure

# Context & Application
Figure-ground reversal demonstrates the flexibility of the 4-Cube Trio framework. Different passages may foreground different structural principles while using the same underlying voice-leading system. This is analytically productive because it prevents a single hearing from being privileged as the "correct" one.

# Examples
- **Tristan Prelude / Brunnhilde Immolation**: Boretz-region membership is primary; octatonic bridges serve as transitions (pp. 167-174)
- **Hypothetical octatonic-primary passage**: Chords drawn from a single octatonic collection, with Boretz-region chords serving as bridges

# Common Errors
- **Error**: Assuming one perspective (Boretz-primary or octatonic-primary) is always correct
  **Correction**: The choice depends on the musical passage; the graph supports both equally

# Common Confusions
- **Confusion**: Thinking figure-ground reversal is about visual perception of the graph
  **Clarification**: It is about analytical interpretation -- which structural principle is foregrounded in a particular passage
