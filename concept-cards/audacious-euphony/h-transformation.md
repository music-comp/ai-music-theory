# Quick Definition
The H transformation connects hexatonic poles (triads diametrically opposite in a hexatonic cycle), moving all three voices simultaneously by semitone in contrary motion, with zero common tones and 3 units of voice-leading work.

# Core Definition
"I will describe this relation as a *hexatonic pole*, and the corresponding transformation with the label **H** (after Cook 1994). Like all mode-switching operations, **H** is an involution that 'undoes itself' when performed twice consecutively" (Cohn, p. 49). H is equivalent to LP or PL: "Two intermediate triads on the hexatonic cycle are omitted, and all three voices move simultaneously by semitone" (p. 49). Despite being decomposable into L and P, the transformation can be understood as a "unitary *Gestalt*."

# Prerequisites

# Key Properties
1. Voice-leading work: 3 semitones (each voice moves 1 semitone)
2. Common tones: 0
3. All three voices move simultaneously by semitone
4. Motion type: contrary (balanced)
5. Mode: always connects opposite mode (major to minor)
6. Involution: H(H(X)) = X
7. H = LP = PL (both orderings produce the same result)

# Construction / Recognition
- H(C major) = ab minor: (C, E, G) -> (B, Eb, Ab)
- H(Eb major) = b minor: (Eb, G, Bb) -> (D, F#, B)
- H(ab minor) = C major: (Ab, Cb, Eb) -> (G, C, E)

# Context & Application
The H transformation depicts maximal harmonic distance within a hexatonic system. In nineteenth-century music, hexatonic poles "frequently accompany depictions of uncanny, supernatural, or liminal phenomena" (synthesized from pp. 40-41, 49-50).

# Examples
**Example 1** (p. 49): Schubert, Sanctus from Eb major Mass (1828): Eb major to b minor.

**Example 2** (p. 49): Wagner, Parsifal (1882): Grail distortion, Eb major to b minor.

**Example 3** (p. 40): Cited uncanny depictions: Kundry's de-souling, dead Siegfried, Scarpia's murder, Aase at St. Peter's Gates, Salome with severed head.

# Common Confusions
- **Confusion**: Thinking H connects same-mode triads
  **Clarification**: H always connects opposite-mode triads (major to minor or vice versa)
- **Confusion**: Assuming no common tones means high voice-leading work
  **Clarification**: Despite 0 common tones, H involves only 3 units of work (each voice moves just 1 semitone)
