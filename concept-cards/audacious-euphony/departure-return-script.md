# Quick Definition
A fundamental compositional template where music moves away from a referential zone through uniform downshifting and returns through complementary upshifting, generalizing the classical I-V-I scheme to any voice-leading trajectory and its reversal.

# Core Definition
"The path -> reversal sequence is a fundamental template of musical form. Its classical prototype moves from tonic to dominant and back" (p. 138). When both legs realize least-motion voice leading, each upper voice forms a palindrome. "Once fifth relations lose their prototypical status, the specific case of I -> V -> I is absorbed into the general case of downshift/upshift complementarity" (p. 138). A return script is fulfilled not only by literal triadic reversal "but also more abstractly by a progression that moves through the same voice-leading zones in reverse order, freely substituting same-group transformations and same-sum triads" (p. 138).

# Prerequisites
- **Voice-leading zones**: The metric space defining departure and return
- **Upshifting and downshifting**: The directional concepts enabling departure/return identification

# Key Properties
1. Classical prototype: I -> V -> I (zone descent then ascent)
2. Generalized form: any uniform downshift followed by compensatory upshift
3. Substitutional flexibility: same-group transformations and same-zone triads may substitute
4. Performer's kinetics: complementarity of downshift/upshift has physical correlate
5. Return need not be literal triadic reversal -- zonal reversal suffices

# Construction / Recognition
1. Track voice-leading zones through a passage
2. Identify a descent phase (departure) and ascent phase (return)
3. Check for zonal symmetry (palindromic zone sequence)
4. Note substitutions: H-class substitutions (P for L, H for L) create varied realizations of the same trajectory

# Context & Application
The departure-return script provides pan-triadic alternatives to classical tonal frameworks. It enables analysis of formally coherent chromatic passages where diatonic function is strained, while preserving the kinetic experience of departure and return that performers feel.

# Examples
- **Schubert "Auf dem Flusse"** (figure 6.8): All chromatic sections downshift zones 10 -> 5 and upshift back, with H-class substitutions creating variety
- **Schubert Bb Sonata, D. 960, 1st mvt.** (figure 6.9): Two-phase descent 5 -> 4 -> 2, nadir at zone 1, compensatory ascent 2 -> 4 -> 5, overshoot to 7
- **Liszt Kyrie** (figures 6.10-6.12): Zonal palindrome with strict voice-level palindromes but non-palindromic triadic succession
- **Schubert "Liedesend'"** (figures 6.13-6.14): Palindromic tonal structure across nine strophes

# Common Errors
- **Error**: Departure-return requires literal triadic reversal
  **Correction**: Zonal reversal suffices; same-zone substitutions maintain the script

# Common Confusions
- **Confusion**: Departure-return is limited to tonic-dominant-tonic
  **Clarification**: Any uniform voice-leading trajectory and its reversal qualify
- **Confusion**: Functional interpretations are required
  **Clarification**: Zones supervene on functions, "suggesting but not mandating them" (p. 141)
