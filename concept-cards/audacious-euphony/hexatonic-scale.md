# Quick Definition
A six-note collection alternating semitone and minor third intervals, containing the pitch classes of all six triads in a hexatonic cycle, also known as the augmented scale in jazz.

# Core Definition
"The entire cycle engages only six pitches, two for each of its three voices. Accordingly, the progression is referred to as a *hexatonic cycle*. Ordered linearly within an octave, the six tones form a *hexatonic scale*, alternating semitone and minor third" (Cohn, p. 38). The collection is pitch-class set 6-20 [014589] and combines two augmented triads a semitone apart. "Jazz players know the same pattern as the *augmented scale*, because the collection combines two adjacent augmented triads" (p. 38, footnote 4).

- **hexatonic-cycle** — The hexatonic scale is the pitch-class content of a hexatonic cycle

# Key Properties
1. Interval pattern: 1-3-1-3-1-3 (semitone, minor third, alternating)
2. Contains exactly 6 pitch classes
3. Set class 6-20 [014589]
4. Combines two augmented triads a semitone apart
5. Invariant under transposition by major third (T4)
6. Contains 3 major and 3 minor triads (the complete hexatonic cycle)

# Construction / Recognition
Example (Northern hexatonic): B-C-Eb-E-G-Ab
- Contains augmented triads: {C, E, Ab} and {B, Eb, G}
- Contains consonant triads: C, c, E, e, Ab, ab

All four hexatonic scales:
- Northern: {B, C, Eb, E, G, Ab}
- Southern: {C, Db, E, F, Ab, A}
- Eastern: {Db, D, F, F#, A, Bb}
- Western: {D, Eb, Gb, G, Bb, B}

# Context & Application
When a passage uses only these six pitch classes, it enters the "hexatonic trance" state. The scale's T4-invariance reflects the symmetric structure of the hexatonic cycle. The Brahms Concerto for Violin and Cello example (p. 48) "sounds only the six tones of the cycle's associated hexatonic scale."

# Common Errors
- **Error**: Confusing the hexatonic scale with the whole-tone scale
  **Correction**: Both have 6 notes, but the hexatonic alternates semitone/minor-third while the whole-tone uses all whole steps

# Common Confusions
- **Confusion**: Thinking "hexatonic" refers only to the scale or only to the cycle
  **Clarification**: The term applies to both; context usually clarifies
