# Quick Definition
The hexatonic scale is a six-note collection alternating semitone and minor third intervals, containing the pitch classes of all six triads in a hexatonic cycle, also known as the augmented scale in jazz terminology.

# Formal Definition
Ordered linearly within an octave, the six tones engaged by a hexatonic cycle form a hexatonic scale with the interval pattern [1-3-1-3-1-3] (semitone, minor third, alternating). The collection is pitch-class set 6-20 [014589] and has a high degree of symmetry, being invariant under transposition by major third (T4).

# Musical/Mathematical Formulation
Interval structure (in semitones): 1-3-1-3-1-3
Example (C hexatonic): C - Db - E - F - Ab - A - [C]
Or equivalently: C - E - F - Ab - A - C - [E]...

Alternative names for the same collection:
- Augmented scale (jazz term, because it combines two augmented triads)
- Ode to Napoleon collection
- Miracle hexachord
- Liszt model
- Source-set E
- 1:3 collection
- Set class 6-20

Pitch-class content for each hexatonic system:
- Northern: {C, E, Ab} + semitonal neighbors = {B, C, Eb, E, G, Ab}
- Southern: {Db, F, A} + neighbors = {C, Db, E, F, Ab, A}
- Eastern: {D, F#, Bb} + neighbors = {Db, D, F, F#, A, Bb}
- Western: {Eb, G, B} + neighbors = {D, Eb, Gb, G, Bb, B}

# Musical Context/Application
The hexatonic scale provides the pitch-class pool for passages that remain within a single hexatonic system. When a composer uses only these six notes, the music enters the "hexatonic trance" state of suspended tonality. The scale's symmetry (invariant under T4) reflects the symmetric structure of the hexatonic cycle itself.

# Examples
From the text (p. 39):
"The entire cycle engages only six pitches, two for each of its three voices. Accordingly, the progression is referred to as a hexatonic cycle. Ordered linearly within an octave, the six tones form a hexatonic scale, alternating semitone and minor third."

Jazz usage note (p. 39): "Jazz players know the same pattern as the augmented scale, because the collection combines two adjacent augmented triads."

From the Brahms example (p. 48): "Each station along the path is approached directly from its predecessor, and as a result the passage sounds only the six tones of the cycle's associated hexatonic scale."

# Common Confusions
- "Hexatonic" can refer to both the 6-note scale AND the 6-triad cycle; context usually clarifies
- The hexatonic scale is NOT the same as the whole-tone scale (both have 6 notes, but different interval structures)
- Do not confuse with "hexachord" in Renaissance theory or twelve-tone theory
- The scale contains two complete augmented triads (e.g., C-E-Ab and Db-F-A in the Northern hexatonic)
