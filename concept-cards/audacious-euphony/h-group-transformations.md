# Quick Definition
The three transformations that map a consonant triad within its hexatonic region but outside its Weitzmann region: Leittonwechsel (L), Parallel (P), and Hexatonic Pole (H).

# Formal Definition
H-group transformations are the three triadic transformations that preserve hexatonic region membership while moving outside the Weitzmann region. The three H-group transformations are:
- **L (Leittonwechsel)**: connects triads sharing a minor-third dyad (C to e)
- **P (Parallel)**: connects triads sharing a root (C to c)
- **H (Hexatonic Pole)**: connects triads sharing no common tones but belonging to the same hexatonic cycle (C to g#)

These transformations generate all movements within a hexatonic region.

# Musical/Mathematical Formulation
For any consonant triad X in hexatonic region R:
- L(X), P(X), and H(X) all remain in R
- L(X) and P(X) share the Weitzmann region of X
- H(X) is in the same hexatonic region but different Weitzmann region

Properties:
- All three are involutions: applying twice returns to start
- L and P each require 1 unit of voice-leading work
- H requires 3 units of voice-leading work
- H = LP = PL (H can be derived from L and P)

The H-group generates the six triads of any hexatonic region from any starting triad.

# Musical Context/Application
H-group transformations:
- Define the "horizontal" (hexatonic) dimension of triadic space
- Complement W-group transformations (which preserve Weitzmann regions)
- Generate hexatonic cycles through alternation (L-P-L-P...)
- Create the smooth voice-leading progressions characteristic of pan-triadic music

The distinction between H-group and W-group provides a systematic way to describe triadic motion.

# Examples
- LP chain: C - e - E - g# - Ab - c - C (traverses entire hexatonic region)
- PL chain: same triads in different order
- H transformation: C to g# (maximum distance within hexatonic region)

# Common Confusions
- H-group transformations preserve hexatonic region, not Weitzmann region
- The "H" in H-group refers to "hexatonic," not to the H transformation specifically
- H = LP means H can be decomposed into L followed by P
- H-group and W-group together generate all transformations between consonant triads
