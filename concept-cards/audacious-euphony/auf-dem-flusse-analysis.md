# Quick Definition
Schubert's "Auf dem Flusse" (*Winterreise* no. 7) exemplifies the departure-return script: all chromatic sections downshift from e minor (zone 10) through zones to 5 and upshift back, with H-class substitutions (P for L, H for L) creating varied realizations of the same zonal trajectory.

# Core Definition
Figure 6.8 presents a paradigmatic analysis showing that all settings share the abstract pattern W -> H -> W for downshift (zones 10 -> 5) and the same for upshift back to zone 10. Stanzas I-II realize both legs as N -> L -> N. The final stanza introduces substitutions: "P-for-L substitution" at m. 48 diverts the return through g# minor instead of e minor (requiring rectification), and "H-for-L substitution" at m. 66 takes B major to g minor via the "shocking" hexatonic pole (Newcomb 1986, p. 164).

# Prerequisites
- **Departure-return script**: The compositional framework being instantiated
- **Voice-leading zones**: The abstract level at which all settings match
- **Transformational substitution**: The H-class substitutions creating variety

# Key Properties
1. All chromatic sections share abstract trajectory: zones 10 -> 5 -> 10
2. W-class always realized by N (nebenverwandt) without substitution
3. H-class substitutions (P for L, H for L) create variety in the return leg
4. Nebenverwandt-saturated: every minor triad adjacent to its major dominant
5. Extreme modulatory complexity achieved without approaching an enharmonic seam

# Construction / Recognition
Paradigmatic analysis framework (figure 6.8):
- Line 1: Abstract W -> H -> W pattern
- Stanzas I, II: N -> L -> N (both legs identical)
- Stanza V, couplet 1: N -> L -> N departure; N -> P -> N return (P substitutes for L)
- Stanza V, couplet 3: N -> H -> N departure (H substitutes for L)

# Context & Application
Richard Kramer called this song's modulatory adventure "extreme" and its tonal graph "the most complex in *Winterreise*" (1994, p. 159). The analysis reveals that this complexity arises entirely from H-class substitutions within a simple departure-return framework, not from enharmonic ambiguity.

# Examples
- P-for-L at m. 48: d# minor -> D# major instead of -> B major; gears shift to g# minor, requiring rectification via N -> PL -> N
- H-for-L at m. 66: B major -> g minor ("shocking hexatonic pole") instead of -> d# minor
- The subdominant is absent to a remarkable degree: only eight chords with subdominant value, none longer than a single beat
