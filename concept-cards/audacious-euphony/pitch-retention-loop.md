# Quick Definition
A cyclical tour through a neighborhood's six triads using the three common-tone maximizing transformations (P, R, and L) placed in any order and then repeated, taking advantage of the acronymic fortuity "PRL."

# Core Definition
"The triadic adjacencies on Hostinsky's *Tonschema* visually emphasize the relationships between those triads that hold two tones in common, suggesting a canonical ordering that makes a cyclical tour of the neighborhood. The transformational vehicles for such a tour are the three common-tone maximizers, P, R, and L, placed in any order and then repeated in the same order" (p. 133). "Taking advantage of an acronymous fortuity, we will call such a tour a pitch retention loop" (p. 133).

# Prerequisites
- **Neighborhood**: The six-triad structure being toured
- **P, R, L transformations**: The three common-tone maximizers that serve as vehicles

# Key Properties
1. Uses P, R, L in a fixed order, then repeats (e.g., P-R-L-P-R-L)
2. Returns to starting triad after six steps
3. Retains the central pitch class throughout
4. Any permutation of P, R, L works (repeated in same order)
5. The loop visits all six triads in the neighborhood

# Construction / Recognition
Starting from any triad containing the central pitch class:
1. Apply P, R, L (or any permutation) in fixed order
2. Repeat the same order
3. After six steps, return to the starting triad
4. All six triads of the central pitch's neighborhood have been visited

# Context & Application
Pitch retention loops are the systematic realization of the neighborhood script. They provide structural frameworks for development sections, retransitions, and modulatory passages, enabling chromatic exploration while maintaining audible pitch-class continuity.

# Examples
- **Verdi "Ah si, ben mio" (*Il Trovatore*, act 3)** (figure 6.3): Cantabile section tours neighborhood: f minor -> Ab major (P?) -> ab minor -> Fb major -> db minor -> Db major; "a final L would return the initial triad" (p. 133)
- **Brahms Symphony No. 2, 1st mvt., mm. 246-302**: Ambitious double pitch retention loop around D and A neighborhoods, with the timpani sounding only D and A but serving as thirds and fifths dispersing across their neighborhoods

# Common Errors
- **Error**: The specific order of P, R, L is fixed
  **Correction**: Any permutation works, as long as it is repeated consistently

# Common Confusions
- **Confusion**: A pitch retention loop requires completing all six triads
  **Clarification**: Incomplete tours are departures that may or may not return; completion is the formal ideal
- **Confusion**: PRL is a specific transformation sequence
  **Clarification**: "PRL" is an acronymic label for any tour using P, R, and L in some fixed repeated order
