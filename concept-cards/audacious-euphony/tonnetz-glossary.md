# Quick Definition
A graph whose nodes are pitch classes and whose edges represent consonant intervals, providing the fundamental spatial model for Neo-Riemannian theory.

# Formal Definition
The Tonnetz (German: "tonal network") is a graph whose nodes are pitch classes and whose edges represent consonant intervals (perfect fifth, major third, minor third). In the standard format used by Cohn, the axes are angled so that perfect fifths run horizontally, major thirds run diagonally from southwest to northeast, and minor thirds run diagonally from northwest to southeast. Consonant triads appear as triangles (major pointing up, minor pointing down). The Tonnetz was first presented by Leonhard Euler in 1739 and revived by German harmonic theorists in the second half of the nineteenth century.

# Musical/Mathematical Formulation
Basic structure:
- Nodes: 12 pitch classes (with enharmonic identification)
- Edges: Consonant dyads (P5, M3, m3)
- Faces: Consonant triads (major = upward triangle, minor = downward triangle)

Topological properties:
- Planar representation creates apparent distance distortions
- Closed (toroidal) when enharmonic and syntonic equivalences are identified
- Open (planar) when diatonic perspective is imposed

The Tonnetz can be converted between diatonic and chromatic interpretations (see Convertible Tonnetz).

# Musical Context/Application
The Tonnetz serves as the primary spatial model in Audacious Euphony for representing:
- Triadic transformations (L, P, R, N, S, H appear as edge-flips or reflections)
- Hexatonic regions (vertical strips bounded by augmented triads)
- Weitzmann regions (clusters around augmented triads)
- Voice-leading paths between triads
- Diatonic encapsulation and chromatic navigation

Historical development: Euler (1739) -> Oettingen (1866) -> Hostinsky (1879) -> Riemann (1880s-1890s) -> Neo-Riemannian revival (1980s-present).

# Common Confusions
- The Tonnetz represents pitch classes, not pitches; octave equivalence is assumed
- Distance on the planar Tonnetz does not directly represent voice-leading distance
- The angled format differs from earlier rectangular formats
- "Tonnetz" is German (literally "tone-network"); no English translation is standard
