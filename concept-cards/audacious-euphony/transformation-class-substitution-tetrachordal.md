# Quick Definition
Transformation-class substitution in the tetrachordal system replaces one Boretz or octatonic transformation with another that produces a different transpositional value, thereby converting one sequence type to another while maintaining the overall voice-leading trajectory (upshifting or downshifting direction).

# Core Definition
Just as in the triadic case (Chapter 5), "class substitutions can introduce variety while still maintaining an overall voice-leading trajectory" (p. 177). In the tetrachordal system, Table 7.3 shows that each transpositional value (T1, T2, T4, T5) is produced by four distinct transformation pairs. Substituting one transformation for another in a sequence changes the transpositional value but not the voice-leading direction. In Chopin's Mazurka Op. 68 no. 4, "S4 substitutes for S2, so that Aø7 sounds in place of projected Eø7. This substitution triggers a conversion of the T5 sequence to one generated by T11" (p. 177), but "the substitutions do not affect the voice-leading trajectory, which continues to downshift at a uniform pace throughout the passage" (p. 179).

# Prerequisites
- **Circumnavigation**: The overall process within which substitutions occur

- **Octatonic-group transformations**: The inter-regional operations subject to substitution

# Key Properties
1. Each transpositional value has four possible transformation pairs (Table 7.3)
2. Substituting one member of a pair changes the transpositional value
3. Voice-leading direction (upshift/downshift) is preserved across substitutions
4. Substitutions introduce variety without disrupting the overall trajectory
5. Parallels triadic transformation-class substitutions from Chapter 5

# Construction / Recognition
Example from Chopin Mazurka (Figure 7.18):
- Original: T5 chain using S2 (octatonic) + S3(4) (Boretz)
- Substitution: S4 replaces S2 at m. 38
- New pair: S4 (octatonic) + S3(4) (Boretz) = T1 sequence
- But combined with continuation: converts overall T5 to T11
- Downshifting trajectory continues unaffected

# Context & Application
Transformation-class substitution explains how composers can vary the surface details of chromatic seventh-chord passages while maintaining a consistent voice-leading direction. It provides a mechanism for understanding how apparently different sequence types are related at a deeper level.

# Examples
- **Chopin Mazurka Op. 68 no. 4, mm. 33-40**: S4-for-S2 substitution converts T5 to T11 while maintaining downshift (pp. 177-179)
- **Comparison of Chopin Op. 45 with Fig. 7.8(b)**: Both are T11 but use different transformation pairs (S4 + S3(4) vs. S2 + S3(2)) (p. 177)

# Common Errors
- **Error**: Thinking substitution changes the voice-leading direction
  **Correction**: Direction is preserved; only the transpositional value and specific transformations change

# Common Confusions
- **Confusion**: Assuming each sequence type requires a fixed transformation pair
  **Clarification**: Each transpositional value can be achieved by four distinct pairs, and pairs can be mixed freely within a passage
