# Quick Definition
Paradigmatic analysis is an analytical method that aligns related musical passages vertically to reveal substitutional relationships and structural similarities, used by Cohn to compare different realizations of voice-leading scripts.

# Formal Definition
**Paradigmatic analysis** (after Agawu 2009) is a method that facilitates comparison of related progressions by aligning them vertically. This alignment reveals:
- What different passages have in common at an abstract level
- Where substitutions occur within transformation classes
- How voice-leading zones track consistently despite surface differences

The method derives from semiotic analysis in linguistics, adapted for musical structure.

# Construction/Recognition
In paradigmatic presentation:
- Rows represent individual passages or phrases
- Columns align structurally equivalent positions
- Common elements appear in aligned positions
- Substitutions are visible as vertical differences within columns

For voice-leading analysis:
- Abstract level shows transformation classes (W for Weitzmann, H for Hexatonic)
- Concrete realizations show specific transformations (N, L, P, H, S)
- Zone numbers track voice-leading position

# Musical Context
Paradigmatic analysis is useful for:
- Comparing strophic variations in song settings
- Revealing substitutional logic in development sections
- Understanding how different passages realize the same underlying script
- Demonstrating class-substitution relationships

The method illuminates how:
- Surface variety conceals structural similarity
- Transformation-class substitutions maintain voice-leading trajectories
- Same-zone triads can substitute for each other

# Examples
**Schubert's "Auf dem Flusse"**: Paradigmatic analysis compares the chromatic progressions of stanzas I-II, V:1, V:2 (mm. 55-62), and V:2 (mm. 64-72). The abstract level shows W → H → W pattern for downshift and upshift, realized differently in each stanza:
- Stanzas I, II: N → L → N throughout
- Stanza V:1: P-for-L substitution during return leg
- Later settings: H-for-L and other substitutions

Scanning down columns reveals:
- Chordal substitutions within voice-leading zones (all transpositions by major third)
- Transformational substitutions within the Hexatonic class (P and H both stand for L)
- Consistent Weitzmann-class representation by the ubiquitous nebenverwandt

# Common Confusions
- Paradigmatic analysis reveals abstract structure, not compositional process
- Vertical alignment is analytical, not temporal; events don't occur simultaneously
- Substitutions must be within the same class (Hexatonic for Hexatonic) to maintain trajectory
- The method compares passages, not necessarily showing derivation or priority
