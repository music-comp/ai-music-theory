# Quick Definition
An analytical method that aligns related musical passages vertically to reveal substitutional relationships and structural similarities, used by Cohn to compare different realizations of voice-leading scripts.

# Core Definition
Paradigmatic analysis (after Agawu 2009) is a method that facilitates comparison of related progressions by aligning them vertically. This alignment reveals what different passages have in common at an abstract level, where substitutions occur within transformation classes, and how voice-leading zones track consistently despite surface differences. The method derives from semiotic analysis in linguistics, adapted for musical structure.

# Prerequisites
- **Voice-leading Zone**: The abstract level at which consistency is tracked
- **H-group and W-group Transformations**: The transformation classes within which substitutions occur

# Key Properties
1. Rows represent individual passages or phrases
2. Columns align structurally equivalent positions
3. Common elements appear in aligned positions
4. Substitutions visible as vertical differences within columns
5. Abstract level shows transformation classes (W for Weitzmann, H for Hexatonic)
6. Concrete level shows specific transformations (N, L, P, H, S)

# Construction / Recognition
In paradigmatic presentation:
- Abstract level: transformation classes (W -> H -> W pattern for downshift and upshift)
- Concrete level: specific realizations (N -> L -> N, or P-for-L substitution, etc.)
- Zone numbers: track voice-leading position consistently across realizations
- Scanning down columns reveals: chordal substitutions within zones (T4 transpositions), transformational substitutions within classes (P and H stand for L)

# Context & Application
Paradigmatic analysis is useful for comparing strophic variations in song settings, revealing substitutional logic in development sections, and understanding how different passages realize the same underlying script. It demonstrates how surface variety conceals structural similarity, and how transformation-class substitutions maintain voice-leading trajectories.

# Examples
- **Schubert, "Auf dem Flusse"**: Paradigmatic analysis compares chromatic progressions of stanzas I-II, V:1, V:2 (mm. 55-62), and V:2 (mm. 64-72). Abstract level shows W -> H -> W pattern, realized differently in each stanza:
  - Stanzas I, II: N -> L -> N throughout
  - Stanza V:1: P-for-L substitution during return leg
  - Later settings: H-for-L and other substitutions
- **Scanning columns reveals**: chordal substitutions within voice-leading zones (all T4 transpositions), transformational substitutions within the Hexatonic class, consistent Weitzmann-class representation by nebenverwandt

# Common Errors
- **Error**: Paradigmatic analysis reveals compositional process
  **Correction**: It reveals abstract structure; the analytical alignment does not imply compositional derivation

# Common Confusions
- **Confusion**: Vertical alignment means simultaneity
  **Clarification**: Events are aligned analytically, not temporally; they don't occur simultaneously

- **Confusion**: Any substitution within a column is valid
  **Clarification**: Substitutions must be within the same transformation class (Hexatonic for Hexatonic) to maintain trajectory
