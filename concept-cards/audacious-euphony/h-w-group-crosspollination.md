# Quick Definition
The combination of H-group transformations (L, P, H -- hexatonic-preserving) with W-group transformations (R, N, S -- Weitzmann-preserving) to generate interregional chromatic sequences, with classically normative pairings (L/R, L/N, P/R, P/N) appearing earliest and maverick pairings (involving S or H) emerging in Schubert and Liszt.

# Core Definition
"A hexatonic-group (or H-group) transformation" preserves hexatonic region but shifts Weitzmann region; "a Weitzmann-group (W-group) transformation preserves Weitzmann region and shifts hexatonic region. An odd-valued transpositional sequence is generated by alternating two transformations, one from each group" (p. 108). Two transformations from each group are classically normative: L and P from the H-group, R and N from the W-group. "It is as a result of their crosspollination, L or P combined with R or N, that the earliest odd-transposition sequences arise in the eighteenth century" (p. 109).

# Prerequisites
- **H-group transformations**: L, P, H as hexatonic-preserving operations
- **W-group transformations**: R, N, S as Weitzmann-preserving operations

# Key Properties
1. 3 H-group x 3 W-group = 9 possible pairings
2. 4 normative (2 x 2 = L,P x R,N): darkly shaded in Table 5.1
3. 3 maverick-involving (S/L, N/H, H/R): gray-shaded, documented in Schubert/Liszt
4. 2 remaining (P/S, H/S): undocumented
5. Combining within the same group preserves region: H+H stays hexatonic; W+W stays Weitzmann

# Construction / Recognition
1. Identify the two alternating transformations in a sequence
2. Check if one is H-group and the other W-group
3. If both same group: sequence stays within a single region (not interregional)
4. The normative/maverick distinction correlates with historical period

# Context & Application
This concept explains the historical emergence of chromatic sequence types and provides the mechanism by which hexatonic and Weitzmann regions collaborate. The "crosspollination" metaphor captures how two closed systems become productive when their operations are combined.

# Examples
- **Normative crosspollinations**: L/R = T5 (Werckmeister 1698 onward); P/R = T3 (Schubert *Zauberharfe*); L/N = T1 (Rameau, Langle); P/N = T5 (Bach, Schubert)
- **Maverick crosspollinations**: S/L = T3 (Liszt *Lelio Fantasy*); N/H = T3 (Schubert *Drei Klavierstucke*); H/R = T1 (rare)

# Common Errors
- **Error**: Any two transformations can generate an interregional sequence
  **Correction**: Only cross-group pairings (one H, one W) generate interregional motion

# Common Confusions
- **Confusion**: Normative and maverick produce different qualities of sequence
  **Clarification**: Both produce parsimonious voice leading; the distinction is historical (normative appeared first) not structural
