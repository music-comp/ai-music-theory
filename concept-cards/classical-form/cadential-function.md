# Quick Definition
The concluding formal function that closes a theme through a conventionalized harmonic progression and melodic formula (typically of falling contour), whose conventional character opposes the basic idea's thematic uniqueness.

# Core Definition
"A cadential idea contains not only a conventionalized harmonic progression but also a conventionalized melodic formula, usually of falling contour" (Ch. 1, p. 11). The cadential idea stands opposed to the basic idea: "the melody is conventional because it lacks motivic features that would specifically associate it with a particular theme" (Ch. 1, p. 11). When we hear measures 7-8 of Beethoven's Op. 2/1, "we could well imagine them closing any number of themes from different works." The purpose of motivic liquidation is "to strip the basic idea of its characteristic features, thus leaving the merely conventional ones for the cadence" (Ch. 1, p. 12).

# Prerequisites
- **Cadential progression** -- the harmonic formula that supports cadential function
- **Continuation function** -- the medial function that typically precedes cadential function

# Key Properties
1. Supported by a cadential progression (I-PD-V-I for PAC, ending on V for HC)
2. Melodic formula typically descends, often stepwise
3. Content is conventional (non-thematic), not characteristic
4. Often the result of liquidation in the preceding continuation
5. In tight-knit sentences, fuses with continuation into a single phrase
6. In loose contexts, can occupy its own distinct phrase supported by an expanded cadential progression (E.C.P.)
7. Can close with PAC (strongest), IAC, or HC

# Construction / Recognition
- Identify the cadential progression in the harmonic analysis
- Note the conventional (non-thematic) character of the melody
- Determine if liquidation has prepared the cadential material
- Distinguish cadential function (leading TO the cadence) from postcadential function (following the cadence)

# Context & Application
Cadential function appears at the end of themes and larger formal sections. In tight-knit sentences, it fuses with continuation in the second four-measure phrase. In subordinate themes and other loose contexts, it often occupies its own distinct phrase or phrases, supported by an expanded cadential progression. Only material leading to the cadential arrival has cadential function; everything after is postcadential.

# Examples
**Example 1** (Ch. 1, p. 11, ex. 1.1): Beethoven, Op. 2/1, i, mm. 7-8: conventional cadential melody after liquidation of motives "a" and "b," ending with HC.
**Example 2** (Ch. 1, p. 20, ex. 1.8): Beethoven, Op. 2/1, i, mm. 33-41: expanded cadential progression supporting an entire phrase with distinctly different melodic-motivic content from the continuation; cadential evasion at m. 37 motivates repetition.

# Relationships
## Builds Upon
- Cadential progression (the harmonic basis)
- Continuation function (which drives toward the cadential moment)
- Liquidation (which strips characteristic motives to prepare conventional cadential material)
## Enables
- Closure of themes (PAC, HC, IAC)
- Expanded cadential progression (when cadential function fills an entire phrase)
## Related
- Authentic cadence, half cadence (the specific closures achieved)
## Contrasts With
- Postcadential function: cadential leads TO the cadence; postcadential follows it
- Presentation function: cadential uses conventional material; presentation uses characteristic material

# Common Errors
- Conflating cadential function with postcadential function
- Calling a closing section or codetta "cadential" when it follows the cadential arrival

# Common Confusions
- Cadential function and postcadential function are entirely different. Only material leading to the cadential arrival -- the point that marks the structural end of the theme -- can truly be said to fulfill cadential function
- An individual codetta may resemble a cadential idea harmonically but serves a postcadential, not cadential, role
