# Quick Definition
Caplin arranges the sentence, period, and four hybrid types along a spectrum from most sentence-like to most period-like: sentence -- hybrid 3 -- hybrid 1 -- hybrid 2 -- hybrid 4 -- period. This spectrum reveals that hybrid themes are not aberrations but systematic intermediaries between the two fundamental types.

# Core Definition
Inasmuch as hybrid themes combine functional elements from both the sentence and period, it is possible to situate the four hybrid categories within a spectrum of formal possibilities, where the sentence and period occupy the two extreme positions (Figure 5.1 in Caplin):

| sentence | hybrid 3 | hybrid 1 | hybrid 2 | hybrid 4 | period |
|----------|----------|----------|----------|----------|--------|
| pres. + cont. | c.b.i. + cont. | ant. + cont. | ant. + cad. | c.b.i. + cons. | ant. + cons. |

Hybrid 3 (c.b.i. + continuation) is very like a sentence, except that the basic idea is not repeated. Hybrid 4 (c.b.i. + consequent) closely resembles a period. Hybrid 1 (antecedent + continuation) contains aspects of both in equal measure. Hybrid 2 (antecedent + cadential) is somewhat more periodic since continuational traits are missing. One logically possible combination is conspicuously absent: presentation + consequent, which would bring a threefold statement of the basic idea within excessive tonic prolongation.

# Construction / Recognition
1. Identify the first phrase: presentation (repeated basic idea) / antecedent (basic idea + contrasting idea + cadence) / compound basic idea (basic idea + contrasting idea, no cadence)
2. Identify the second phrase: continuation / cadential / consequent (basic idea returns)
3. Place the combination on the spectrum
4. Note that the "missing" type (presentation + consequent) rarely occurs due to redundancy of material

# Context & Application
The spectrum explains why hybrid themes appear regularly throughout classical compositions. Beyond offering more options for theme construction, the latent ambiguity of hybrids renders them especially suitable for assimilation into larger formal units (sixteen-measure periods, small ternaries, small binaries). Most hybrids form part of a larger thematic whole. Additionally, hybrid types 1, 2, and 3 state the basic idea only once, making them useful when the basic idea should not reappear within the eight-measure span (e.g., in compound periods where it must be saved for the higher-level consequent).

# Common Confusions
- The spectrum is not a ranking of quality or frequency — all positions represent valid and common theme types
- The "missing" type (presentation + consequent) is not theoretically impossible but is compositionally undesirable due to redundancy
- A theme's position on the spectrum is determined by its internal phrase types, not by its character or expression
