# Quick Definition
Caplin arranges the sentence, period, and four hybrid types along a spectrum from most sentence-like to most period-like: sentence -- hybrid 3 -- hybrid 1 -- hybrid 2 -- hybrid 4 -- period. This reveals that hybrid themes are systematic intermediaries between the two fundamental types.

# Core Definition
"The relationship between the hybrids and the more fundamental forms can be situated on a spectrum of formal possibilities, where the sentence and period occupy the two extreme positions" (Ch. 4, p. 111, Figure 4.1):

| sentence | hybrid 3 | hybrid 1 | hybrid 2 | hybrid 4 | period |
|----------|----------|----------|----------|----------|--------|
| pres. + cont. | c.b.i. + cont. | ant. + cont. | ant. + cad. | c.b.i. + cons. | ant. + cons. |

"The hybrid type compound basic idea + continuation is very much like a sentence, except that the basic idea is not repeated. The hybrid type compound basic idea + consequent closely resembles a period. The hybrid type antecedent + continuation brings aspects of the sentence and period in equal measure. The hybrid type antecedent + cadential is somewhat more periodic, since continuational traits are missing" (Ch. 4, p. 111).

# Prerequisites
- **Sentence** -- one pole of the spectrum
- **Period** -- the other pole of the spectrum
- **Hybrid themes overview** -- the four hybrid categories

# Key Properties
1. Two poles: sentence (pres. + cont.) and period (ant. + cons.)
2. Four intermediary positions occupied by hybrid types
3. Position determined by the degree to which phrase functions resemble sentence or period
4. Hybrid 3 (c.b.i. + cont.): closest to sentence
5. Hybrid 1 (ant. + cont.): equal aspects of both
6. Hybrid 2 (ant. + cad.): somewhat more periodic
7. Hybrid 4 (c.b.i. + cons.): closest to period
8. All positions represent valid and common theme types

# Construction / Recognition
1. Identify the first phrase: presentation / antecedent / compound basic idea
2. Identify the second phrase: continuation / cadential / consequent
3. Place the combination on the spectrum
4. The position reveals how the theme relates to the fundamental types

# Context & Application
The spectrum reveals that the six theme types (sentence, period, four hybrids) are not isolated categories but form a continuum. It explains why hybrid themes appear regularly throughout classical compositions -- they offer systematic intermediary options. An important additional observation concerns the number of basic idea statements: sentence and period both state the basic idea twice; hybrid type 4 also states it twice; but types 1, 2, and 3 state it only once, making them useful when the basic idea should not reappear within the theme.

# Common Errors
- Treating the spectrum as a ranking of quality or frequency
- Assuming that only the two poles (sentence and period) are "real" theme types
- Placing themes on the spectrum based on character rather than internal phrase structure

# Common Confusions
- The spectrum is not a ranking of quality or frequency -- all positions represent valid and common theme types
- The "missing" type (presentation + consequent) is not theoretically impossible but is compositionally undesirable due to redundancy
- A theme's position on the spectrum is determined by its internal phrase types, not by its character or expression
