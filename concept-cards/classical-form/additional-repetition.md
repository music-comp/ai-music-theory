# Quick Definition
A deviation from the normative sentence in which the basic idea receives three or more statements in the presentation, or in which the entire presentation phrase is repeated, expanding the theme and creating functional redundancy.

# Core Definition
Additional repetition takes two forms: (1) **additional repetition of the basic idea**, where the opening idea is stated three times instead of the normative two, creating an asymmetrical (2 x 3) grouping structure; and (2) **repetition of the entire presentation phrase**, where the four-measure presentation is restated before the continuation begins, resulting in four statements of the basic idea and considerable functional redundancy. A repeated four-measure presentation gives rise to an eight-measure presentation, suggesting a sixteen-measure sentence, but the presentation of a true compound sentence consists of a repeated compound basic idea, not a repeated presentation. The distinction matters: a repeated presentation has four statements of the basic idea (looser), while a repeated compound basic idea has only two (tighter). The redundancy created by a threefold statement of the basic idea helps explain why the hybrid type "presentation + consequent" is conspicuously absent from the repertory.

# Prerequisites
- Presentation Function (the context in which additional repetition occurs)
- Sentence (the overall theme-type being altered)

# Key Properties
- Three or more statements of the basic idea in the presentation
- Creates asymmetrical grouping (e.g., 2 x 3 instead of 2 x 2)
- Functional redundancy: a criterion for loose organization
- Delays the onset of continuation function
- Presentation repetition: four statements of the basic idea total
- Rarely found in main themes; typical of subordinate themes
- A repeated four-measure presentation is NOT the same as a compound sentence's repeated compound basic idea

# Construction / Recognition
1. Count the statements of the basic idea at the opening of the theme
2. If three or more, an additional repetition is present
3. If the entire presentation is repeated (4 measures + 4 measures), note the four total basic-idea statements
4. Check how the continuation accommodates the expanded presentation
5. Presentation repetition often elides with the beginning of the continuation

# Context & Application
Additional repetition occurs both in tight-knit contexts (ch. 3: occasional three-statement presentations) and in subordinate themes (ch. 8: a hallmark loosening technique). In subordinate themes, the redundancy and asymmetry are characteristic of loose organization. The technique helps explain the absence of the "presentation + consequent" hybrid from the repertory: three statements of the basic idea would result from combining a two-statement presentation with a consequent that restates the basic idea.

# Examples
- Mozart, Piano Sonata in D, K. 576, i, mm. 28-33: basic idea stated three times (subordinate theme); second statement sequenced to II requires third statement to return to I
- Beethoven, Piano Sonata in A, Op. 2/2, i, mm. 92-98: four-measure presentation repeated; end of repeated presentation elides with continuation

# Common Errors
- Confusing a three-part presentation with a presentation followed by a consequent beginning with the basic idea
- Equating a repeated presentation (4 b.i. statements) with a compound sentence (2 c.b.i. statements)

# Common Confusions
- **Additional repetition vs. compound sentence**: a repeated presentation (4 basic idea statements) is NOT the same as a compound sentence's repeated compound basic idea (2 statements)--the former is looser
- **Additional repetition vs. recapitulation**: a third statement of the basic idea in the presentation is NOT a return/recapitulation; it extends the initiating function
