# Quick Definition
A loosening technique in which a modal shift to minor within a subordinate theme brings into play tonal regions (bIII, bVI, bVII, bII) that would otherwise be considered remote in a strictly major-mode context.

# Core Definition
A shift to minor mode in the subordinate theme brings into play tonal regions such as bIII, bVI, bVII, and bII that would otherwise be considered remote in a strictly major-mode context. The prominent tonicization of these regions is another loosening device typical of subordinate themes but not of main themes. The tonicization creates harmonic complexity and tonal instability that significantly loosens the formal organization, particularly when combined with model-sequence technique and expanded cadential progressions. These remote regions often function within the broader harmonic framework of a cadential or sequential progression.

# Prerequisites
- **Modal shift**: Minor mode enables access to these remote regions
- **Subordinate theme**: The formal context for this loosening technique
- **Loosening techniques**: The broader category

# Key Properties
1. Modal shift to minor enables access to remote tonal regions
2. Common remote regions: bIII, bVI, bVII, bII (all related to minor mode)
3. Tonicization involves establishing regions briefly through their own dominant
4. Often combined with model-sequence technique (descending fifth progressions)
5. Remote regions may function within expanded cadential progressions
6. Generally absent from tight-knit main themes
7. Particularly common in Beethoven's subordinate themes

# Construction / Recognition
- Identify modal shift to minor that opens access to remote regions
- Note which regions are tonicized (bIII, bVI, bVII, bII)
- Observe whether tonicizations function within sequential or cadential logic
- Distinguish from genuine modulation (tonicization is brief, not confirmed by PAC)
- Check for combination with model-sequence technique

# Context & Application
Tonicization of remote regions extends the harmonic palette far beyond what is available in a major-mode context. The technique is especially prominent in works that feature modal shifts within the subordinate theme. The remote regions create harmonic surprise and tonal instability contributing to the theme's characteristically loose organization.

# Examples
- Mozart, Clarinet Quintet in A, K. 581, i, mm. 54-60: second subordinate theme -- modal shift to minor leads to tonicization of bVI; descending fifth sequential progression through remote regions; bVI sustained prominently before cadential 6/4 restores subordinate key
- Beethoven, Overture to Coriolanus, Op. 62, mm. 60-70: subordinate theme passes through remote tonicizations via model-sequence

# Common Errors
- Confusing tonicization with modulation (tonicization is brief, modulation is confirmed by PAC)
- Treating remote tonicizations as random harmonic excursions (they serve sequential or cadential logic)
- Analyzing remote regions relative to minor mode (they are "remote" relative to MAJOR mode)

# Common Confusions
- **Tonicization vs. modulation**: Remote regions are briefly emphasized but not confirmed by PAC
- **Remote relative to which mode**: The regions are "remote" relative to the MAJOR mode; in minor, some are diatonic
- **Function within structure**: Remote tonicizations serve broader cadential or sequential logic, not random harmonic exploration
