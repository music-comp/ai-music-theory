# Quick Definition
Hybrid type 2 features an antecedent phrase followed by a phrase built exclusively on an expanded cadential progression (ECP), with minimal or no continuational characteristics. Unlike the same ECP-supported phrase in a sentence context (labeled "continuation => cadential"), here the phrase is exclusively cadential.

# Core Definition
"Like the previous type, this hybrid begins with an antecedent phrase. The second phrase, however, displays minimal characteristics of continuation function (such as fragmentation, harmonic acceleration, and sequence). Since the phrase is supported entirely by an *expanded cadential progression* (ECP), it exclusively projects a *cadential* function" (Ch. 4, p. 101). The label differs from the sentence context: "In the context of a sentence, such a phrase would usually contain continuational features along with the ECP and would thus be labeled 'continuation => cadential.' But in the context of a theme that starts like a period, as suggested by an initial antecedent, the situation is different: not only do we not necessarily expect an ensuing continuation, but the phrase supported by the ECP often displays few continuational characteristics, if any" (Ch. 4, p. 108).

# Prerequisites
- **Antecedent** -- the initiating phrase with weak cadence
- **Cadential function** -- the concluding formal function
- **Expanded cadential progression** -- a single cadential progression spanning an entire phrase
- **Hybrid themes overview** -- the general hybrid framework

# Key Properties
1. First phrase: genuine antecedent (b.i. + c.i. + HC or IAC)
2. Second phrase: built entirely on an expanded cadential progression (ECP)
3. Little or no fragmentation -- units may remain at two-measure size
4. Little or no harmonic acceleration -- harmonic rhythm may actually slow
5. Basic idea does not return (distinguishing from period)
6. Function labeled "cadential" (not "continuation => cadential") when continuational traits are absent
7. Rarely modulates: no space for modulation between antecedent's cadence and the ECP
8. States the basic idea only once

# Construction / Recognition
1. Identify antecedent in mm. 1-4: basic idea + contrasting idea + weak cadence
2. Confirm mm. 5-8 are supported by an expanded cadential progression
3. Check for absence of continuational features: no fragmentation, no harmonic acceleration
4. If continuational traits are genuinely absent, label the second phrase "cadential" (not "continuation => cadential")
5. Basic idea does not return at m. 5

# Context & Application
Hybrid type 2 "is somewhat more periodic" than hybrid type 1 "since continuational traits are missing" (Ch. 4, p. 111) and lies between hybrid 1 and the period on the spectrum of theme types. "Hybrids of this type (antecedent + cadential) rarely modulate: there is simply no place for a modulating progression to occur from the weak cadence ending the antecedent (which must be in the opening key) to the immediately following expanded cadential progression" (Ch. 4, p. 109).

# Examples
**Example 1** (Ch. 4, p. 101, ex. 4.2): Beethoven, Violin Sonata in D, Op. 12/1, iii, mm. 1-8: antecedent with HC at m. 4; second phrase brings new material over ECP with no fragmentation and no harmonic acceleration (in fact, harmonies slow down).
**Example 2** (Ch. 4, p. 109, ex. 4.9): Haydn, String Quartet in G, Op. 64/4, ii, mm. 1-8: antecedent is a "mini-sentence"; cadential second phrase with new two-measure melody, no fragmentation, diminished harmonic rhythm.

# Relationships
## Builds Upon
- Antecedent function (from the period)
- Cadential function and ECP (from the sentence)
## Enables
- Recognition of themes where the second phrase is purely cadential
## Related
- Hybrid type 1 (also begins with antecedent, but has continuation traits)
- Expanded cadential progression (the harmonic basis of the second phrase)
## Contrasts With
- Hybrid type 1: has continuation traits; type 2 lacks them
- Period: the consequent returns the basic idea; the cadential phrase does not
- Sentence's "continuation => cadential": same ECP, but labeled differently due to context

# Common Errors
- Looking for continuational features that are not there -- the lack of fragmentation and acceleration is precisely what makes this exclusively cadential
- Confusing this with a period (basic idea does not return)
- Assuming all ECP-supported phrases are "continuation => cadential"

# Common Confusions
- The same phrase type (ECP-based) is labeled differently depending on context: "continuation => cadential" after a presentation (sentence context); "cadential" after an antecedent (hybrid context)
- Do not look for continuational features that are not there -- the lack of fragmentation and acceleration is precisely what makes this an exclusively cadential phrase
- Hybrid type 2 is NOT a period -- the basic idea does not return in the second phrase
