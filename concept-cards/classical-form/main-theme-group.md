# Quick Definition
A main theme followed immediately by a second main theme, both ending with PACs in the home key, creating a multi-theme complex analogous to a subordinate-theme group.

# Formal Definition
A main theme ending with a PAC may be immediately followed by a second main theme to create a main-theme group, analogous to a subordinate-theme group. It is important that both themes in the group end with a PAC in the home key. If a presumed second main theme ends with a HC, it would destabilize the home key and thus express transition function (as either a single nonmodulating transition or the first part of a two-part transition).

# Construction/Recognition
- Two or more themes, each ending with PAC in the home key
- The second theme is a genuine main theme, not a transition
- Both themes establish and confirm the home key
- Distinguished from a main theme followed by a transition: the latter ends with HC, destabilizing the home key
- Distinguished from a main theme with a closing section: the latter consists of codettas, not a full theme

# Musical Context
Main-theme groups are less common than subordinate-theme groups but provide additional melodic-motivic material for the movement. They create a more expansive opening section.

# Common Confusions
- A second main theme must end with PAC in the home key; if it ends with HC, it is a transition
- A main-theme group is not simply a repeated or varied main theme — each theme is a distinct thematic unit
- The distinction between a main-theme group and a main theme + transition depends on the second unit's cadential ending
