# Quick Definition
A main theme followed immediately by a second main theme, both ending with PACs in the home key, creating a multi-theme complex analogous to a subordinate-theme group.

# Core Definition
A main theme ending with a PAC may be immediately followed by a second main theme to create a main-theme group, analogous to a subordinate-theme group. Both themes in the group must end with a PAC in the home key. If a presumed second main theme were to end with a HC, it would destabilize the home key and thus express transition function (as either a single nonmodulating transition or the first part of a two-part transition). The critical distinction rests on the cadential ending of the second theme.

# Prerequisites
- **Main-theme function in sonata**: The formal function both themes serve

# Key Properties
1. Two or more themes, each ending with PAC in the home key
2. Both themes establish and confirm the home key
3. Distinguished from main theme + transition by the second theme's cadential ending
4. Distinguished from main theme + closing section: the latter consists of codettas, not a full theme
5. Analogous to a subordinate-theme group
6. Less common than subordinate-theme groups

# Construction / Recognition
- Identify two or more themes in the opening section
- Confirm each ends with PAC in the home key
- If the second ends with HC, it is a transition, not a second main theme
- If the second consists of codettas, it is a closing section

# Context & Application
Main-theme groups are less common than subordinate-theme groups but provide additional melodic-motivic material. They create a more expansive opening section.

# Common Errors
- Calling a transition a "second main theme" when it ends with HC

# Common Confusions
- **Cadential distinction**: A second main theme must end PAC in HK; if it ends HC, it is a transition
- **Not a repeated theme**: Each theme in the group is a distinct thematic unit
- **Not a closing section**: Codettas following the first theme are not a second main theme
