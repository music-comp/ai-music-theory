# Quick Definition
Caplin's recommended step-by-step methodology for analyzing a development section: first identify a core (large-scale model + sequence), then work outward to find the pre-core, retransition, and standing on the dominant.

# Core Definition
In confronting a development section, the first step should be to determine whether it uses pre-core/core technique. To do so, it is necessary first to identify a core by looking for a large-scale model (usually 4-8 measures) that is sequenced at least once. Then look toward the end of the core to find the HC (or dominant arrival) that marks the structural end. The final boundary of the core occurs where the standing on the dominant plays itself out. After determining the core's presence, return to the beginning to analyze the pre-core (stretching up to the core's onset). Then move to later portions: if the core ends in a development key, observe whether there is a second core or a retransition. If you cannot identify a core, consider other options: pseudo-core, transition-like unit, subordinate-themelike unit, or an ad hoc description. Be prepared to encounter situations that do not conform to expectations, and be flexible with the analytical tools.

# Prerequisites
- **Development section**: The formal unit being analyzed
- **Core technique**: The organizational method being sought
- **Pre-core**: The passage preceding the core

# Key Properties
1. Start by looking for a core, not the beginning of the development
2. Identify a large-scale model (4-8 measures) sequenced at least once
3. Find the HC or dominant arrival marking the core's structural end
4. Locate the standing on the dominant marking the core's final boundary
5. After finding the core, work backward to identify the pre-core
6. After the core, check for a second core or retransition
7. If no core: consider pseudo-core, transition-like unit, subordinate-themelike unit
8. Many situations will not conform -- be flexible and adopt ad hoc approaches

# Construction / Recognition
Step-by-step procedure:
1. Look for a large-scale model (4-8 mm.) sequenced at least once
2. If found: identify the core's structural end (HC or dominant arrival)
3. Identify the standing on the dominant
4. Return to the beginning and analyze the pre-core
5. If core ends in development key: look for second core or retransition
6. If no core found: consider other formal options
7. If nothing fits: describe the harmonic/tonal plan and grouping structure

# Context & Application
This methodology reflects Caplin's pedagogical approach: start with what is most identifiable (the core) and work outward. The "A Final Note" at the end of Ch. 13 explicitly acknowledges that formal analysis of developments can be "extremely difficult" and that the variety of techniques is "enormous and highly diverse."

# Examples
- Mozart, Piano Sonata in A minor, K. 310, i, mm. 50-81 (ex. 13.1): methodology applied -- core identified first (mm. 58-74), pre-core identified second (mm. 50-57)

# Common Errors
- Starting at the beginning of the development and working forward (start with the core)
- Forcing a core analysis when no genuine core exists (consider alternatives)
- Giving up entirely when the development does not conform (describe what you can)

# Common Confusions
- **Core-first methodology**: The instruction to start by finding the core (not the pre-core) is counterintuitive but analytically more effective
- **Flexibility**: The tools provided are starting points, not rigid categories
- **"Ad hoc" is acceptable**: Caplin explicitly allows for descriptive analysis when formal categories do not apply
