# Quick Definition
The fundamental two-part organizational principle of the small binary form, projected through motivic connections between part openings, absence of recapitulation, structural symmetry, and the repeat scheme.

# Core Definition
The bipartite structure of the small binary is expressed through several reinforcing features: motivic connection between part openings (second part usually begins with material from the first part's basic idea), absence of recapitulation, structural symmetry (8 + 8 measures), and the repeat scheme ||: Part 1 :||: Part 2 :||. The two parts have relatively neutral functional meanings compared to the three well-defined functions of the small ternary. The neutral terms "part 1" and "part 2" reflect this less differentiated functional character.

# Prerequisites
- **Small binary**: The form exhibiting bipartite structure

# Key Properties
1. Two parts of roughly equal length (normatively 8 + 8 measures)
2. Motivic connection between part openings reinforces bipartite design
3. No recapitulation to create a third functional section
4. Repeat scheme divides form into exactly two repeated units
5. Cadential differentiation typical of binary: first part HC (or PAC), second part PAC
6. Less distinct functional meanings for each part compared to small ternary
7. The neutral labeling reflects genuine functional non-differentiation

# Construction / Recognition
1. Identify two approximately equal parts, each repeated
2. Check for motivic connection between part openings
3. Verify absence of recapitulation
4. Note the cadential pattern (HC/PAC or PAC/PAC)
5. Compare with rounded binary: same repeat scheme but fundamentally different functional organization

# Context & Application
The bipartite structure is the essential organizing principle distinguishing the small binary from the small ternary. While the rounded binary also has a bipartite repeat scheme, its three distinct formal functions create a fundamentally tripartite functional organization. The small binary's two parts lack such differentiated functions. The bipartite structure is particularly suitable for variation forms, where the return of the basic idea is reserved for the beginning of each new variation.

# Examples
- Beethoven, String Quartet in C-sharp Minor, Op. 131, iv: both parts organized as sentences -- parallel bipartite design
- Haydn, Piano Trio in A-flat, Hob. XV:14, ii: sentence first part, contrasting middle + continuation second part
- Beethoven, Violin Sonata in A, Op. 30/1, iii: compound basic idea opens both parts -- clear motivic connection

# Common Errors
- Assuming a bipartite repeat scheme proves bipartite functional structure -- the rounded binary has the same scheme but tripartite functions
- Treating the motivic connection between part openings as an absolute requirement rather than a typical feature
- Equating the "neutral" labeling with analytical vagueness -- it reflects a genuine theoretical insight about functional non-differentiation

# Common Confusions
- Bipartite structure in the small binary is genuinely two-part, unlike the rounded binary where the bipartite repeat scheme masks a tripartite functional organization
- The motivic connection between part openings is a typical feature but not an absolute requirement
- A two-part repeat scheme alone does not prove bipartite structure -- the rounded binary has the same scheme but tripartite functions
