# Quick Definition
A deceptive *resolution* (V to VI in any context) is distinct from a deceptive *cadence*, which should be recognized only when genuine cadential circumstances are imminent -- that is, when thematic closure is truly expected. Most V-VI motions are noncadential and should not be labeled "deceptive cadence."

# Core Definition
Most students first learn about the "deceptive cadence" in elementary harmony studies, where the term tends to be used whenever V resolves to VI. However, it is crucial to distinguish a deceptive *resolution* of the dominant from a genuine deceptive *cadence*. The latter should be recognized only when there is a truly cadential situation in the making -- when the circumstances for thematic closure are imminent. The motion from V to VI occurs in many entirely noncadential contexts. A useful test: could you change the submediant into a tonic and then recognize a genuine cadence at that moment? If not, the motion is merely a deceptive resolution, not a deceptive cadence.

# Key Properties
1. Deceptive *resolution*: any V-to-VI motion in any context (may be prolongational, sequential, etc.)
2. Deceptive *cadence*: V-to-VI specifically at the moment of expected thematic closure, within a cadential progression
3. Test: substitute I for VI -- if the result would be a genuine cadence, then it is a deceptive cadence; otherwise, it is merely a deceptive resolution
4. "Speak freely of deceptive resolutions; speak with caution of deceptive cadences"
5. The event following the deceptive cadence groups BACKWARD with the preceding music (as a goal)

# Construction / Recognition
1. Identify V-to-VI motion
2. Determine whether the context is genuinely cadential (cadential progression approaching expected closure)
3. Apply the substitution test: would replacing VI with I produce a genuine cadence?
4. If yes: deceptive cadence; if no: deceptive resolution
5. Check grouping: in a true deceptive cadence, the VI groups backward as a partial goal

# Context & Application
The distinction is pedagogically and analytically important because many V-VI motions in classical music serve prolongational or sequential functions, not cadential ones. Mislabeling these as "deceptive cadences" inflates the analytical significance of routine harmonic progressions. Reserve the term "deceptive cadence" for moments of genuine formal significance where cadential closure is denied.

# Examples
- Mozart, Piano Sonata in A Minor, K. 310, iii, m. 16: genuine deceptive cadence -- cadential dominant resolves to VI at the expected moment of PAC closure; event groups backward; motivates repetition of contrasting idea
- Haydn, Piano Sonata in E, Hob. XVI:22, iii, m. 14: deceptive *resolution* (not cadence) -- V resolves to VI but the context is not cadential; no thematic closure was expected

# Common Errors
- Labeling every V-VI motion as a "deceptive cadence" regardless of context
- Failing to apply the substitution test
- Not checking whether the context is genuinely cadential

# Common Confusions
- V-VI in a sequential context is a deceptive *resolution*, not a deceptive *cadence*
- V-VI within a prolongational passage is a deceptive *resolution*, not a deceptive *cadence*
- Only at moments of genuine expected thematic closure should the term "deceptive cadence" be used
