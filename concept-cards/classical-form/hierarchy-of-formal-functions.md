# Quick Definition
The same phrase functions (presentation, continuation, cadential, antecedent, etc.) that construct main themes in Part I also construct all other thematic functions of sonata form (transition, subordinate theme, development core), though in progressively looser configurations -- this multi-level application of formal functionality throughout the entire movement is what distinguishes this textbook's approach.

# Core Definition
In Part I of the textbook, themes (most of which illustrated main themes) are constructed out of various formal functions associated with the ideas and phrases making up the themes. As we move beyond main themes, we see that the same phrase functions (presentation, antecedent, continuation, cadential) are also used to construct the other thematic functions of sonata form, such as the transition, the subordinate theme, and the core of the development, though these functions usually acquire a looser formal expression. What distinguishes the approach to analyzing classical form in this textbook from all prior approaches is this emphasis on identifying the constituent formal functions, at all levels of structure, throughout the entirety of the full-movement form.

# Prerequisites
- **Formal function**: The concept of form-functional expression
- **Interthematic functions**: The movement-level functions (main theme, transition, subordinate theme)
- **Intrathematic functions**: The phrase-level functions (presentation, continuation, cadential)

# Key Properties
1. Phrase functions (presentation, continuation, cadential) operate at all levels of structure
2. The same functions construct main themes, transitions, subordinate themes, and development cores
3. In looser formal contexts, these functions acquire looser expression
4. The form-functional approach applies throughout the ENTIRE full-movement form
5. This emphasis on multi-level functionality distinguishes this textbook from all prior approaches
6. Formal functions are hierarchically nested: phrase functions within thematic functions within section functions
7. Loosening of functions is progressive: main theme (tight-knit) -> transition (looser) -> subordinate theme (loosest in exposition) -> development (loosest overall)

# Construction / Recognition
- At any point in the movement, ask: what formal function is being expressed?
- Identify both the thematic function (main theme? transition? subordinate theme? core?) and the phrase function (presentation? continuation? cadential?)
- Note how the phrase function's expression differs from its tight-knit model in the main theme
- Track the progressive loosening across the movement

# Context & Application
The hierarchical application of formal functions is the theoretical foundation of the entire textbook. It means that the same analytical vocabulary developed for tight-knit themes in Part I can be deployed -- with appropriate recognition of loosening -- throughout the most complex sonata-form movements. This provides analytical consistency and reveals structural relationships that might otherwise be invisible. The approach is presented in the "Focus on Function" text box "A Hierarchy of Formal Functions" in Chapter 9.

# Examples
- Beethoven, Piano Sonata in F minor, Op. 2/1, i (Ch. 9): main theme = tight-knit sentence (presentation + continuation+cadential fused); transition = basic idea + extended continuation + HC (no presentation); subordinate theme = loosened presentation (dominant pedal) + extended continuation (separate phrase) + expanded cadential (separate phrase with evasion)
- The same phrase functions (presentation, continuation, cadential) appear in all three thematic functions, but in progressively looser configurations

# Common Errors
- Applying tight-knit standards (from main themes) to transitions or subordinate themes
- Failing to recognize phrase functions in loose contexts
- Treating each thematic function as requiring its own unique analytical vocabulary

# Common Confusions
- **Same function, different expression**: A presentation in a subordinate theme is still a presentation, even if it is loosened by a dominant pedal or additional repetitions
- **Not a template**: The hierarchy does not prescribe specific configurations; it provides a vocabulary for recognizing what IS present
- **Loosening is systematic**: The progressive loosening from main theme to development follows a consistent pattern, not random variation
