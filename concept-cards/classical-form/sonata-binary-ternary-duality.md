# Quick Definition
Sonata form exhibits both ternary characteristics (three functional sections) and binary characteristics (two repeated halves), and the debate over which is primary is a "false dichotomy."

# Core Definition
Just as theorists and historians have debated whether small ternary is essentially two parts or three parts, so too have they disagreed over the fundamental partitioning of sonata form. The arguments on each side are largely the same, and the dispute is likewise founded on a "false dichotomy," since differing modes of organization generate both bipartite and tripartite characteristics. Ternary traits include three distinct formal functions (exposition, development, recapitulation) and the recapitulation's return of exposition material. Binary traits include the exposition repeat and the sometimes-repeated development-recapitulation pair. The form resembles the rounded binary version of small ternary. Caplin's focus on formal functionality emphasizes the ternary aspects, but without devaluing the binary traits.

# Prerequisites
- **Sonata form**: The form exhibiting this duality
- **Small ternary**: The smaller analogue with the same debate

# Key Properties
1. Three distinct formal functions (ternary trait)
2. Exposition repeat (binary trait)
3. Development-recapitulation sometimes repeated together (binary trait, especially pre-1780)
4. Resembles rounded binary version of small ternary
5. The debate is a "false dichotomy"
6. Form-functional approach privileges the ternary view
7. Both perspectives are valid and complementary

# Construction / Recognition
- Identify the three functional sections (ternary)
- Note the repeat signs (binary)
- Recognize that both perspectives describe real features of the form

# Context & Application
This duality has practical implications for performance (observing repeats) and analysis (conceptualizing the form). Earlier 18th-century practice, when the development-recapitulation repeat was more common, emphasized the binary nature more strongly.

# Examples
- All standard sonata-form movements exhibit both characteristics

# Common Confusions
- **False dichotomy**: Sonata form is neither purely binary nor purely ternary
- **Historical shift**: Binary traits are more prominent in earlier classical works (pre-1780)
- **Analytical perspective**: Emphasizing ternary aspects does not invalidate the binary traits
