# Quick Definition
The opening interthematic function of a sonata exposition, expressing the home key through cadential closure and displaying the most tight-knit organization of any unit in the exposition.

# Core Definition
"The main theme expresses the home key through cadential closure" (Ch. 1, p. 18). It is the most tight-knit unit in the exposition, characterized by "harmonic and tonal stability" from "the clear establishment of the home-key tonic in the presentation phrase and the cadential confirmation of that key at the end of the continuation" (Ch. 1, p. 18). The melodic material is "unified through the use of motives derived exclusively from the basic idea," and the grouping is "highly symmetrical" (Ch. 1, p. 18). The "constituent functions (presentation, continuation, and cadential) are presented in the most compact and efficient manner possible" (Ch. 1, p. 18).

# Prerequisites
- **Interthematic functions** -- the framework of movement-level functions
- **Tight-knit vs. loose organization** -- the dimension along which functions are compared

# Key Properties
1. Confirms the home key through cadential closure (HC or PAC)
2. Most tight-knit organization in the exposition
3. Typically a conventional theme type (sentence, period, small ternary, or hybrid)
4. Symmetrical phrase groupings (usually 4 + 4)
5. Unified motivic material; nothing superfluous
6. Efficient functional expression: every detail contributes to the function

# Construction / Recognition
- Identify the opening thematic unit of the exposition
- Verify cadential confirmation of the home key
- Assess tight-knit character (stability, symmetry, efficiency, unity)

# Context & Application
The main theme opens the sonata-form exposition and establishes the home key. Its tight-knit character contrasts with the looser transition and subordinate theme. Main themes in other movement types are discussed in Chapters 13-17.

# Examples
**Example 1** (Ch. 1, p. 18, ex. 1.1): Beethoven, Op. 2/1, i, mm. 1-8: model sentence in F minor, symmetrical 4 + 4, HC closure. "Every detail of the musical organization contributes to the functional expression, and nothing can be eliminated without obscuring an aspect of that functionality."

# Common Errors
- Assuming the main theme must end with PAC (HC is also possible)

# Common Confusions
- The main theme's tight-knit character is relative to the exposition's other sections, not an absolute measure
