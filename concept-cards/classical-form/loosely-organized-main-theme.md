# Quick Definition
A main theme constructed with loosening techniques normally associated with subordinate themes (redundant repetitions, extensions, expansions) while still remaining tighter than the actual subordinate theme of the movement.

# Core Definition
Some main themes are constructed in a manner considerably less tightly knit than would ordinarily be expected. The loosening techniques resemble those of a subordinate theme: redundant repetitions, cadential extensions and expansions, and internal dominant arrivals. Although the form-functional characteristics may resemble a subordinate theme, the melodic, rhythmic, and textural aspects usually remain typical of a main theme (especially "opening up" gestures and marked discontinuities of rhythm and texture). As a rule, a loosely organized nonconventional main theme is still more tightly knit than the subordinate theme appearing later in the exposition. This comparison is the critical test.

# Prerequisites
- **Nonconventional main theme**: The broader category
- **Loosening techniques**: The devices employed

# Key Properties
1. Features loosening devices: redundant repetitions, cadential extensions, expanded cadential progressions, internal dominant arrivals
2. Melodic and rhythmic characteristics remain typical of a main theme ("opening up" gestures, textural discontinuities)
3. Always more tightly knit than the subsequent subordinate theme
4. The comparison with the subordinate theme is the critical analytical test
5. May resemble a period at a general level but with various expansions
6. Relatively uncommon

# Construction / Recognition
- Identify loosening devices in the main theme
- Note that melodic/rhythmic/textural aspects remain typical of a main theme
- Compare directly with the subordinate theme of the same movement
- The main theme should be perceivably tighter

# Context & Application
Loosely organized main themes create works with distinctive character, often one of breadth and expansiveness at the very start. They challenge the analyst to look beyond surface techniques (which resemble subordinate themes) to deeper formal function.

# Examples
- Beethoven, Piano Sonata in A, Op. 2/2, i (ex. 13.6): opening 8 measures suggest a sentence but lack of harmonic activity in mm. 5-8 prevents this; entire 8-bar group is a primary initiating unit; subsequent measures include modulation to V, IAC extended postcadentially; return of basic idea creates highly expanded antecedent/consequent; yet compared with the subordinate theme (ex. 8.12) -- with its omitted initiation, modal shift, chromatic sequences, expanded cadential progressions -- it is decidedly tighter

# Common Errors
- Classifying a loosely organized main theme as a subordinate theme
- Failing to compare it with the actual subordinate theme of the same movement

# Common Confusions
- **Not a subordinate theme**: The comparison within the same movement always reveals the main theme to be tighter
- **Techniques vs. function**: The presence of loosening devices does not change the theme's function
- **Movement-specific comparison**: The distinction requires comparing both themes within the same movement, not against an abstract standard
