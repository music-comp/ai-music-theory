# Quick Definition
A lengthy development section containing two separate cores: the first typically confirming a development key, the second leading to the home-key dominant for the recapitulation.

# Formal Definition
Lengthy development sections are likely to contain two different cores. The first normally confirms a development key, and the second leads to the dominant of the home key to prepare for the recapitulation. Each core follows the model-sequence-fragmentation process but targets different tonal goals.

# Construction/Recognition
- First core: establishes and confirms a development key
- Second core: drives toward the home-key dominant
- A new model is established for each core
- The transition between cores may involve a dramatic event (evaded cadence, sudden textural change)

# Musical Context
Two-core developments are found in larger-scale works with sufficient scope for multiple phases of model-sequence activity.

# Examples
- Mozart, Piano Concerto in C Minor, K. 491, i (ex. 10.10): first core approaches PAC in G minor (V) but is dramatically evaded; second core begins with new four-measure model

# Common Confusions
- The two cores are not repetitions of the same process -- each has its own model and tonal goal
