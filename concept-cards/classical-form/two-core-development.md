# Quick Definition
A lengthy development section containing two separate cores: the first typically confirming a development key, the second leading to the home-key dominant for the recapitulation.

# Core Definition
Lengthy development sections are likely to contain two different cores. The first normally confirms a development key, and the second leads to the dominant of the home key to prepare for the recapitulation. Each core follows the model-sequence-fragmentation process but targets different tonal goals. A new model is established for each core. The transition between cores may involve a dramatic event such as an evaded cadence of the first core, a sudden textural change, or a new pre-core-like passage.

# Prerequisites
- **Core technique**: Each core follows model-sequence-fragmentation
- **Development section**: The formal context
- **Development key**: The tonal goal of the first core

# Key Properties
1. Two separate cores, each with its own model
2. First core: establishes and confirms a development key
3. Second core: drives toward the home-key dominant
4. Each core follows model-sequence-fragmentation process
5. The transition between cores may involve dramatic events (evaded cadence, textural change)
6. Found in larger-scale works with sufficient scope
7. The two cores are NOT repetitions -- each has its own model and tonal goal

# Construction / Recognition
- Identify two distinct model-sequence-fragmentation processes in the development
- Verify that each targets a different tonal goal
- Note the event that marks the boundary between cores
- Confirm that each core's model is distinct (not a repetition)

# Context & Application
Two-core developments appear in larger-scale works where a single core cannot encompass the full tonal and dramatic scope of the development. The first core often ends with an evaded or abandoned cadence in the development key, prompting a second core with new material that drives toward the home-key dominant.

# Examples
- Mozart, Piano Concerto in C Minor, K. 491, i (ex. 10.10): first core approaches PAC in G minor (HK: V) but cadence is dramatically evaded when orchestral tutti reenters with V5/IV; second core begins with new four-measure model sequenced a fourth higher

- Extended development sections (two phases of model-sequence activity)

## Related

## Contrasts With
- No direct contrast; two-core is an expansion of single-core technique

# Common Errors
- Treating the two cores as repetitions of the same process
- Failing to identify the boundary between cores
- Conflating the two cores' different tonal goals

# Common Confusions
- **Two cores vs. repeated core**: Each core has its own model and tonal goal -- they are distinct processes, not repetitions
- **Boundary identification**: The transition between cores is often marked by a dramatic event (evaded cadence, new material) that signals a fresh start
