# Quick Definition
A recapitulation in sonata-without-development form that brings back only the main theme, eliminating the transition, subordinate theme, and closing section, creating a form that resembles a large ternary.

# Core Definition
In a number of works by Mozart and Haydn, the exposition of a sonata without development is followed only by the main theme, whose structure is the same as in the exposition. The rest of the recapitulation (transition, subordinate theme, closing section) is eliminated, but a coda may be added. This creates a form resembling a large ternary where the interior theme has been replaced by a transition and subordinate theme. Despite this resemblance, the forms should be regarded as distinct, since the listener experiences the movement as a sonata without development until the truncation becomes apparent. The possibility of reinterpreting the movement as a deviational large ternary can emerge only after the fact.

# Prerequisites
- **Sonata without development**: The formal context for this deviation
- **Large ternary form**: The form this deviation resembles

# Key Properties
1. Only the main theme is restated after the exposition
2. Transition, subordinate theme, and closing section are eliminated
3. A coda may be appended
4. The overall structure resembles large ternary form
5. The resemblance is strongest when the main theme is a small ternary or small binary
6. Found in works by both Mozart and Haydn

# Construction / Recognition
- After the exposition, check whether the recapitulation continues beyond the main theme
- If only the main theme appears, the recapitulation is truncated
- Look for a coda following the restated main theme
- Note the resemblance to large ternary but analyze based on listening experience

# Context & Application
This deviation appears in slow movements by Mozart and Haydn. The formal ambiguity between sonata without development (truncated recapitulation) and large ternary form is a characteristic feature of these movements.

# Examples
- Haydn: String Quartet in G, Op. 33/5, ii; String Quartet in D, Op. 33/6, ii; Piano Trio in E-flat, Hob. XV:30, ii
- Mozart: Clarinet Quintet in A, K. 581, ii; String Quartet in D, K. 575, ii; Violin Sonata in F, K. 376/374d, ii

# Common Errors
- Immediately classifying the movement as large ternary without considering the listener's real-time experience
- Failing to notice the truncation and expecting additional material

# Common Confusions
- **Sonata vs. large ternary**: The distinction rests on the listener's experience -- the movement is heard as a sonata without development until the truncation is perceived; reinterpretation as large ternary is retrospective
