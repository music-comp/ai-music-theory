# Quick Definition
The large section following the development that restates the exposition's material in modified form, resolving the tonal conflict by transposing the subordinate theme into the home key.

# Core Definition
The recapitulation brings back, usually in modified form, an earlier exposition. It resolves the principal tonal and melodic processes left incomplete in earlier sections and provides symmetry and balance by restating the melodic-motivic material of the exposition. Minimally, it begins in the home key with the basic idea of the main theme, adjusts following material to remain in the home key, and confirms that key with a concluding PAC. It is analogous to the A' section of a small ternary but at a higher hierarchical level. Two types of changes occur: ornamental changes (dynamics, instrumentation, register, texture, accompanimental figuration, melodic embellishments) and structural changes (harmonic-tonal organization, melodic-motivic material, grouping structure, formal functions).

# Prerequisites
- **Sonata exposition**: The section whose material is restated
- **Subordinate theme**: Must be transposed into the home key
- **Transition**: Must be tonally adjusted
- **Main theme**: Returns to signal "the sense of return"

# Key Properties
1. Begins in the home key with the basic idea of the main theme (the "double return")
2. Resolves the tonal conflict by transposing subordinate theme into the home key
3. Structural changes are motivated by fundamentally different formal functions compared to the exposition
4. The main theme's initiating and key-confirming functions are no longer required
5. The transition destabilizes the home key for different reasons -- to let the subordinate theme sound fresh
6. The subordinate theme retains loose organization, now endowing the home key with greatest expressive power
7. Ornamental changes provide variety; structural changes reflect new functional context
8. Changes may also be prompted by the content of the development section
9. Constituent parts retain exposition labels despite serving different functions
10. The recapitulation is defined by its DIFFERENCES from the exposition

# Construction / Recognition
- Begins with the main theme's basic idea in the home key
- Material restated in roughly the same order as the exposition
- Transition tonally adjusted to remain in (or return to) the home key
- Subordinate theme transposed into the home key
- Compare measure by measure with the exposition to identify structural changes
- Identify the crux (point of tonal adjustment)
- Note any deletions, compressions, or additions relative to the exposition

# Context & Application
The "double return" of the main theme and the home key is a hallmark of classical sonata form. Using the same labels (main theme, transition, subordinate theme) for the recapitulation is convenient but "obscures the significantly different formal functions that these units serve." Every constituent section may undergo structural changes motivated by the new formal context, by aesthetic variety, or by the development's content.

# Examples
- Beethoven, Piano Sonata in A, Op. 2/2, i (ex. 11.1): secondary development added, restatement deleted, final cadence eliminated
- Mozart, Piano Sonata in G, K. 283, i (ex. 11.2): presentation sequenced up a step; new continuation without cadential closure; compensates for lack of core in development
- Beethoven, Symphony No. 7, Op. 92, i (ex. 11.3): A' section transposed into subdominant; mode change shifts further to flat side
- Mozart, Piano Sonata in C, K. 545, i (ex. 11.10): subordinate theme transposed to home key with register adjustments
- Haydn, String Quartet in B Minor, Op. 64/2, i (ex. 11.18): minimal correspondence -- material redistributed to produce a very different formal plan

# Common Errors
- Treating the recapitulation as a mere transposition of the exposition
- Failing to recognize that exposition labels obscure different formal functions in the recapitulation
- Assuming all structural changes are composer whims rather than functionally motivated

# Common Confusions
- **Labels vs. functions**: Using the same labels (main theme, transition, subordinate theme) for both exposition and recapitulation obscures their fundamentally different formal roles
- **Ornamental vs. structural**: Ornamental changes affect surface features; structural changes affect harmony, tonality, grouping, and formal functions
- **Deletion of main-theme opening**: When the main theme is deleted, it raises the question of whether "recapitulation" function truly exists, though the label is maintained by convention
