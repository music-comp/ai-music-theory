# Quick Definition
The large section following the development that restates the exposition's material in modified form, resolving the tonal conflict by transposing the subordinate theme into the home key.

# Formal Definition
The recapitulation brings back, usually in modified form, an earlier exposition. It resolves the principal tonal and melodic processes left incomplete in earlier sections and provides symmetry by restating the exposition's material. Minimally, it begins in the home key with the basic idea of the main theme, adjusts following material to remain in the home key, and confirms that key with a concluding PAC. Two types of changes occur: ornamental (dynamics, register, texture) and structural (harmonic-tonal, grouping, formal functions).

# Construction/Recognition
- Begins with the main theme's basic idea in the home key
- Material restated in roughly the same order as the exposition
- Subordinate theme transposed to the home key
- Transition tonally adjusted
- Structural changes motivated by different formal functions, development content, and aesthetic variety

# Musical Context
The "double return" of main theme and home key is a hallmark of classical sonata form. The recapitulation's constituent parts retain exposition labels despite serving different functions.

# Examples
- Beethoven, Piano Sonata in A, Op. 2/2, i (ex. 11.1): secondary development, deletion of restatement
- Mozart, Piano Sonata in C, K. 545, i (ex. 11.10): subordinate theme transposed with ornamental changes
- Haydn, String Quartet in B Minor, Op. 64/2, i (ex. 11.18): minimal correspondence to exposition

# Common Confusions
- Using the same labels for the recapitulation obscures the different functions these units serve
- The recapitulation is not a mere transposition -- structural changes are the norm
