# Quick Definition
About 90% of minuets are built as rounded binaries (resembling small ternary with exposition, contrasting middle, and recapitulation), while about 10% follow simple binary form (two parts without recapitulatory return of the opening idea).

# Core Definition
Most individual minuets in minuet/trio form are built in a way that strongly resembles the small ternary theme type, also known as rounded binary (about 90% of cases). These contain an exposition (A), contrasting middle (B), and recapitulation (A'). A small number, about 10%, resemble the small binary, also termed binary minuet form. In binary minuet form, the second part contains material functioning like a contrasting middle but does not include a recapitulatory articulation (a return of the opening basic idea in the home key). Although the opening does not return within the normal boundaries of the form, this material may reappear in a closing section or coda, fulfilling a compensatory function (Caplin, pp. 631, 653-654).

# Prerequisites
- **Minuet form** -- The formal type
- **Small ternary** -- The rounded binary model (90% of cases)
- **Small binary** -- The simple binary model (10% of cases)
- **Binary minuet form** -- The specific terminology for the minority type

# Key Properties
1. 90% of minuets: rounded binary (small ternary) with A-B-A' structure
2. 10% of minuets: simple binary (binary minuet form) without recapitulatory return
3. Rounded binary: opening idea returns in the A' section
4. Simple binary: part 2 has contrasting-middle characteristics but no return of opening idea
5. In simple binary, opening material may reappear compensatorily in a closing section or coda
6. Both types have each part repeated

# Construction / Recognition
1. Check whether the second part includes a clear return of the opening basic idea in the home key
2. If yes: rounded binary (small ternary) -- the majority type
3. If no: simple binary (binary minuet form) -- the minority type
4. In simple binary, check for compensatory return of opening material in closing section or coda

# Context & Application
This distinction is important for formal analysis because it determines whether to expect a recapitulation. In binary minuet form, the absence of recapitulation may be compensated for by the reappearance of the opening material in a post-cadential position.

# Examples
**Example 1** (p. 654): Mozart, Serenade in D ("Haffner"), K. 250, iii, mm. 1-40 -- binary minuet form where the opening phrase reappears only at the very end (mm. 37-40) as a cadential unit, fulfilling a compensatory function.

# Common Errors
- **Error**: Assuming all minuets have a recapitulation. **Correction**: About 10% of minuets follow binary form without recapitulatory return.

# Common Confusions
- **Confusion**: Whether binary minuet form is a deficient rounded binary. **Clarification**: It is a legitimate alternative form type, not a failed ternary.
