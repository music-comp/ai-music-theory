# Quick Definition
In some periodic situations, the two-measure position normally filled by a contrasting idea is replaced by a full four-measure continuation phrase, creating an asymmetrical expansion of the period.

# Core Definition
In some periodic situations, the formal position that would ordinarily be filled by a two-measure contrasting idea is replaced by a full four-measure phrase with standard features of a continuation (fragmentation, harmonic acceleration). The resulting deviation is a form of phrase expansion, in that the expected two-measure unit is inflated to four measures. This can affect either the antecedent, the consequent, or both phrases. The resulting asymmetry may create a 6+6, 4+6, or similar grouping pattern.

# Prerequisites
- **Period**: The theme type in which this deviation occurs
- **Contrasting idea**: The unit being replaced
- **Continuation function**: The function that replaces the contrasting idea

# Key Properties
1. A two-measure contrasting idea position is replaced by a four-measure continuation
2. Results in phrase expansion (2-measure unit becomes 4-measure)
3. May affect antecedent, consequent, or both
4. Continuation displays standard features: fragmentation, harmonic acceleration
5. Can create symmetrical deviations (6+6) or asymmetrical ones (4+6)
6. The continuation replaces the contrasting idea's melodic role while adding its own functional characteristics

# Construction / Recognition
1. Identify a period where one or both phrases exceed four measures
2. Check whether the expanded phrase has continuation characteristics (fragmentation, acceleration) rather than an extended contrasting idea
3. Note the grouping structure (symmetrical or asymmetrical)
4. Determine whether the cadence falls at the expected point or is displaced

# Context & Application
This deviation demonstrates the flexibility of phrase-functional organization in classical themes. The replacement of a contrasting idea by a continuation gives the affected phrase a more sentence-like character while maintaining the overall periodic framework (antecedent function followed by consequent function with cadential differentiation).

# Examples
- Haydn, String Quartet in C, Op. 33/3, ii, mm. 1-10: contrasting idea replaced by continuation in both antecedent and consequent, creating 5+5 symmetrical grouping

# Common Errors
- Confusing this with a hybrid theme type 1 (antecedent + continuation) -- here, the continuation REPLACES the contrasting idea within the antecedent or consequent, creating a longer single phrase
- Failing to recognize continuation characteristics (fragmentation, acceleration) in the expanded phrase

# Common Confusions
- This is a deviation of the period form, not a different theme type
- The continuation replaces the contrasting idea's position, not the entire second phrase of the period
