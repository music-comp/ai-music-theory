# Quick Definition
An A section in minuet form that remains entirely in the home key, expressing exclusively main-theme function and leaving subordinate-key establishment to the B section.

# Core Definition

# Prerequisites
See front matter.

# Key Properties
See Core Definition.
When the A section remains in the home key, its interthematic expression is exclusively main theme. The section is relatively short and compact, closing with a PAC in almost all cases. The absence of a subordinate key creates expectations for the B section to bring subordinate-theme function.

# Construction / Recognition
- Begins and ends in the home key
- Closes with a PAC (almost always)
- Relatively short and compact
- Expresses exclusively main-theme function

# Context & Application
A nonmodulating A section leaves the B section to provide the tonal conflict.

# Examples
- Haydn, String Quartet in G, Op. 54/1, iii

# Common Confusions
- A nonmodulating A section does not mean the minuet lacks tonal conflict; it is typically established in the B section.
