# Quick Definition
A sequential progression with descending-second (stepwise) root motion that poses voice-leading problems (parallel fifths) in root position, typically requiring first-inversion chords or 7-6 suspensions, and expressing little harmonic functionality.

# Core Definition
"Sequential progressions by descending seconds pose a potential problem of voice-leading: if the chords appear in root position, then parallel fifths can easily arise" (Ch. 2, p. 32). "Therefore, the unembellished form of the descending stepwise progression finds all the chords in first inversion, thereby eliminating any interval of a fifth against the bass" (Ch. 2, p. 32). "The progression is frequently embellished by a series of 7-6 suspensions" (Ch. 2, p. 32). "Sequential progressions of this category express little, if any, sense of harmonic functionality, since there is no syntactical relationship between harmonies whose roots move in a stepwise descent" (Ch. 2, p. 32).

# Prerequisites
- **Sequential progression** -- the broader category

# Key Properties
1. Root motion: consistently descending seconds
2. Root-position form risks parallel fifths
3. Unembellished: all chords in first inversion to avoid parallels
4. Embellished: 7-6 suspension chain
5. No harmonic-functional expression
6. Voice-leading is the primary organizing principle

# Construction / Recognition
- Stepwise descending root motion
- Chords typically in first inversion or embellished with 7-6 suspensions
- No functional implications at any link

# Context & Application
Descending-second sequences appear in continuation phrases and development sections. Their purely contrapuntal nature makes them useful for creating linear motion.
