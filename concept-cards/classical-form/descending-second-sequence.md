# Quick Definition
A sequential progression with descending-second root motion that poses voice-leading challenges (parallel fifths) in root position, typically requiring first-inversion chords or 7-6 suspensions, and expressing little harmonic functionality.

# Formal Definition
Sequential progressions by descending seconds pose a potential problem of voice-leading: if the chords appear in root position, parallel fifths can easily arise. Therefore, the unembellished form of the descending stepwise progression finds all the chords in first inversion, eliminating any interval of a fifth against the bass. The progression is frequently embellished by a series of 7-6 suspensions. Sequential progressions of this category express little, if any, sense of harmonic functionality, since there is no syntactical relationship between harmonies whose roots move in a stepwise descent.

# Construction/Recognition
- Root motion: consistently descending seconds (stepwise descent)
- Unembellished form: all chords in first inversion to avoid parallel fifths (ex. 2.15a)
- Embellished form: 7-6 suspension chain (ex. 2.15b)
- No harmonic-functional expression: stepwise root descent has no dominant-tonic implication
- Voice-leading is the primary organizing principle, not harmonic function

# Musical Context
Descending-second sequences appear in continuation phrases and development sections. Their lack of harmonic functionality makes them useful for creating purely contrapuntal motion. The 7-6 suspension chain version is a well-known Baroque and classical technique.

# Examples
- All chords in first inversion: stepwise bass descent eliminates parallel fifths (ex. 2.15a)
- With 7-6 suspensions: characteristic embellishment of the descending stepwise pattern (ex. 2.15b)

# Common Confusions
- Root-position chords in descending-second motion easily produce parallel fifths, which is why the first-inversion or suspension forms are preferred.
- This sequence type has essentially no harmonic-functional expression, in contrast to descending-fifth sequences.
