# Quick Definition
The most commonly used sequential progression, featuring root motion by descending fifths (or ascending fourths), with the strongest harmonic-functional expression of any sequence type because each link implies a local dominant-to-tonic relationship.

# Core Definition
"The most commonly used sequential progression features chords whose roots are organized into a series of descending fifths (or ascending fourths)" (Ch. 2, p. 29). "Compared to the other categories of sequential progressions, the descending fifth pattern features the strongest harmonic-functional expression," since "the root motion of a descending fifth lies at the basis of every dominant-to-tonic progression" (Ch. 2, p. 30). "This functional relation is implied, by analogy, at each link in the sequential chain (e.g., VI-II, or II-V), even if the 'dominant' does not actually contain the leading-tone of the 'tonic'" (Ch. 2, p. 30). Despite local functionality, "its use nevertheless promotes a weakening of the harmonic-tonal environment" because "the overall direction of the progression remains somewhat in doubt until it is completed" (Ch. 2, p. 30).

# Prerequisites
- **Sequential progression** -- the broader category

# Key Properties
1. Root motion: consistently descending fifths (or ascending fourths)
2. Basic pattern: I-IV-VII-III-VI-II-V-I (or any portion)
3. Each link implies local dominant-to-tonic by analogy
4. Strongest harmonic-functional expression among the six sequence types
5. Can be varied by chord inversion, chromaticism, added sevenths
6. Normally concludes with tonic harmony
7. Despite local functionality, weakens overall tonal clarity

# Construction / Recognition
- Identify consistent descending-fifth root motion
- Note the "circle of fifths" pattern
- Check for embellishments (inversions, chromaticism, added dissonances)

# Context & Application
Characteristic of continuation function, where its harmonic mobility creates forward motion. Also prominent in development sections and transitions.

# Examples
**Example 1** (Ch. 1, ex. 1.2): Beethoven, Op. 135, iii, mm. 7-9: roots F-Bb-Eb-Ab-Db in continuation phrase.
**Example 2** (Ch. 2, ex. 2.11a-b): Basic form; varied forms with inversions and chromaticism (ex. 2.11c-g).

# Common Errors
- Treating the descending-fifth sequence as confirming a key (it weakens tonal clarity)

# Common Confusions
- Despite each link implying a dominant-tonic relationship, the overall progression weakens tonal stability
- It is the most common AND most functionally charged sequence, but still fundamentally different from a cadential progression
