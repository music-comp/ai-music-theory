# Quick Definition
Formal functions can express their intrinsic temporal quality (beginning, middle, end) independently of their actual contextual position in a theme, creating a "formal dissonance" when a medial or concluding function appears as a structural beginning -- a controlled dissonance suitable for expressing loose organization.

# Core Definition
Since formal functionality involves how music expresses its logical location in a temporal spectrum of beginnings, middles, and ends, the idea that a middle (continuation) or an end (cadential) can serve to articulate a structural beginning seems, on the surface, absurd. Yet one of the special properties of music is the capacity to express a sense of its intrinsic temporal function independent of its contextual location. Because formal functions are so conventionalized, so well defined by their specific characteristics, we can sometimes identify a given function without necessarily taking into account its actual position in a theme. When the contextual placement differs from the intrinsic temporal expression -- a medial function appearing as a beginning, for example -- a kind of "formal dissonance" results. If the dissonance is carefully controlled, it may be suitable for expressing a loose organization. Too great a formal dissonance, however, can produce an illogical succession of formal functions.

# Prerequisites
- **Formal function**: The concept of functions having temporal locations
- **Continuation function**: The most common function to appear "out of place"
- **Cadential function**: Another function that can appear at a theme's opening
- **Presentation function**: The standard initiating function that is being omitted

# Key Properties
1. Intrinsic function: what a passage sounds like based on its characteristics (e.g., sequential = continuation)
2. Contextual function: the passage's actual position in the theme (e.g., first phrase = beginning)
3. Formal dissonance: mismatch between intrinsic and contextual function
4. Controlled dissonance is appropriate for loose organization (e.g., subordinate themes)
5. Too great a formal dissonance produces illogical formal succession
6. Sequential harmonies are the most effective way to express continuation at a theme's start
7. Expanded cadential progressions can express cadential function at a theme's start
8. This theoretical framework explains omission of initiating function

# Construction / Recognition
- Identify the intrinsic function of the opening passage (based on its characteristics)
- Compare with its contextual position (is it actually the beginning of a theme?)
- If there is a mismatch, recognize the formal dissonance
- Assess whether the dissonance is controlled and appropriate for the formal context
- Sequential progressions at a theme's start = continuation intrinsically, beginning contextually

# Context & Application
This concept is central to understanding how subordinate themes can begin with continuation function (via model-sequence technique), cadential function (via expanded cadential progressions), or standing on the dominant -- all of which are intrinsically medial or concluding functions used contextually as beginnings. The concept also applies to transitions that omit initiating function. The resulting formal dissonance is a key loosening technique: because the beginning lacks the stability of a true initiation, the passage feels structurally looser than a theme beginning with a conventional presentation or compound basic idea.

# Examples
- Beethoven, Piano Sonata in A, Op. 2/2, i (Ch. 12, Ex. 12.8): first subordinate theme begins with model-sequence technique (intrinsically continuation) in the minor mode -- the theme group as a whole lacks a sense of structural initiation
- Haydn, String Quartet in B minor, Op. 64/2, i (Ch. 12, Ex. 12.7): subordinate theme begins with an expanded cadential progression (intrinsically cadential function at the theme's start)
- Beethoven, String Quartet in D, Op. 18/3, i (Ch. 12, Ex. 12.13): subordinate theme begins with standing on the dominant yielding directly to continuation

# Common Errors
- Forcing a conventional label (presentation) on passages that intrinsically express continuation
- Treating formal dissonance as compositional error rather than deliberate loosening
- Expecting all themes to begin with conventional initiating functions

# Common Confusions
- **Not an error**: Formal dissonance is a controlled compositional technique, not a deficiency
- **Identification**: The intrinsic function is identified by conventional characteristics (sequential = continuation), not by position
- **Degree of dissonance**: Carefully controlled dissonance creates appropriate looseness; excessive dissonance would produce illogical form
