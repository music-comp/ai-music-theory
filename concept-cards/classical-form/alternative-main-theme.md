# Quick Definition
An entirely new theme introduced at the start of the solo exposition when the ritornello main theme is too orchestral in character to be rendered idiomatically by the soloist.

# Formal Definition
On occasion, the solo exposition begins with an entirely new theme rather than restating the ritornello main theme. This alternative main theme tends to appear when the ritornello main theme is highly orchestral in character and not likely to be rendered idiomatically by the soloist. Common situations include loud, fanfare-like figures for full orchestra that are not effective on the piano, or polyphonic textures highlighting different sonorities that cannot create a similar impression on the homogeneous sound of the solo instrument. When an alternative main theme is used, the ritornello main theme typically reappears at the beginning of the solo transition (Principle 2: theme reappearance), ensuring that this important material is not lost.

# Construction/Recognition
- Entirely new theme at the start of the solo exposition
- More idiomatic for the solo instrument than the ritornello main theme
- Often more lyrical, pianistic, or soloistic in character
- The ritornello main theme typically reappears in the solo transition or later in the movement
- The alternative main theme rarely begins the recapitulation (the ritornello main theme is preferred there)
- May appear elsewhere: at the start of the development, as part of a recapitulation theme group, or may not return at all

# Musical Context
The alternative main theme addresses the fundamental challenge of the concerto: reconciling orchestral and solo idioms. It gives the soloist a theme suited to the instrument's character while allowing the orchestra to retain its own distinctive opening material.

# Examples
- Mozart, Piano Concerto in D Minor, K. 466, i: The intensely brooding orchestral opening (mm. 1-4, continuing for 11 measures in a large crescendo) is never imitated by the piano. The alternative main theme at m. 77 is considerably more pianistic and lyrical.

# Common Confusions
- An alternative main theme is not a variant or variation of the ritornello main theme; it is entirely new material.
- If an alternative main theme is used, students should not expect it to begin the recapitulation. The recapitulation usually begins with the ritornello main theme to project the strongest sense of large-scale return.
- The alternative main theme may not return at all in some concertos; its primary function is to launch the solo exposition.
