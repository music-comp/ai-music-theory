# Quick Definition
A variation form using two different themes that alternate with each other, each becoming varied on successive reappearances. The second theme is typically in the opposite mode.

# Formal Definition
Alternating variations (also called "double variations") uses two different themes as the basis for variation. Haydn regularly employs this form, and several examples appear in Beethoven's works. The second theme is typically a minore (or maggiore) whose opening idea may be derived from the first theme. The themes alternate and become varied on each reappearance.

# Construction/Recognition
- Two distinct themes serve as the basis for variation
- The themes alternate: Theme 1, Theme 2, Theme 1 (varied), Theme 2 (varied), etc.
- The second theme is typically in the opposite mode
- Each theme is varied on successive appearances

# Musical Context
This form is particularly associated with Haydn, who regularly employs it in slow movements.

# Examples
- Multiple examples in Haydn's slow movements featuring alternating major and minor themes
- Several examples in Beethoven's works

# Common Confusions
- Alternating variations should not be confused with a simple theme and variations that includes a single minore variation.
