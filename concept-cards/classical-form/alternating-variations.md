# Quick Definition
A variation form using two different themes that alternate with each other, each becoming varied on successive reappearances, with the second theme typically in the opposite mode. Particularly associated with Haydn.

# Core Definition
Alternating variations (also called "double variations") uses two different themes as the basis for variation. Haydn regularly employs this form, and several examples appear in Beethoven's works. In Haydn's practice, the second theme is a minore (or maggiore for minor-mode themes) whose opening idea is often, but not necessarily, derived from the first theme. Throughout the movement, the themes alternate with each other and become varied on each reappearance (Theme 1, Theme 2, Theme 1 varied, Theme 2 varied, etc.).

# Prerequisites
- **Theme and variations**: The basic formal category being extended
- **Minore/maggiore contrast**: The modal relationship between the two themes

# Key Properties
1. Two distinct themes serve as the basis for variation
2. The themes alternate: Theme 1, Theme 2, Theme 1', Theme 2', etc.
3. The second theme is typically in the opposite mode (minore/maggiore)
4. Each theme is varied on successive appearances
5. The second theme's opening idea may derive from the first theme
6. Particularly associated with Haydn

# Construction / Recognition
- Identify two distinct themes that alternate
- Check if the second theme is in the opposite mode
- Track variations of each theme across successive appearances
- Note any motivic connection between the two themes

# Context & Application
This form is particularly associated with Haydn, who regularly employs it in slow movements. Beethoven also uses it in several works. The alternation of two themes provides greater variety than a single-theme variation set.

# Examples
- Haydn's slow movements featuring alternating major and minor themes
- Several examples in Beethoven's works

# Common Errors
- Confusing alternating variations with a simple theme and variations that includes a minore variation

# Common Confusions
- **Alternating vs. single-theme with minore**: In alternating variations, the minore is a distinct second theme that appears and is varied multiple times; in single-theme variations, the minore is one variation among many
