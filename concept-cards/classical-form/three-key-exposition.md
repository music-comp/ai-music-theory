# Quick Definition
An exposition in which the subordinate theme begins in a key different from the true subordinate key, creating the impression of three tonal areas, though the initial "second key" functions more as an emphasized tonal region than a fully confirmed key.

# Core Definition
Some writers have adopted the expression "three-key exposition" to characterize situations in which a modulating subordinate theme begins in one key and ends in another. This term is somewhat of a misnomer: in the classical style, the initial "second" key is rarely confirmed by cadential closure and thus functions more as an emphasized tonal region in the broader modulatory process from the home key to the true subordinate key (dominant). The initial key is established by its dominant at the end of the transition. Only two keys are truly established through cadential confirmation: the home key (by the main theme's PAC) and the subordinate key (by the subordinate theme's PAC).

# Prerequisites
- **Modulating subordinate theme**: The formal mechanism that creates the three-key appearance
- **Subordinate key**: The true tonal goal of the exposition

# Key Properties
1. Transition ends with dominant of an intermediate key (not the true subordinate key)
2. Subordinate theme begins in this intermediate key
3. Theme modulates to the true subordinate key (V of home key)
4. PAC confirms only the true subordinate key
5. The intermediate key is NOT cadentially confirmed -- it is a tonal region
6. Common intermediate keys: VI in major, III in minor
7. Only TWO keys are truly established: home key and subordinate key

# Construction / Recognition
- Identify a subordinate theme that begins in a different key than it ends
- Note that the transition ends with the dominant of the intermediate key
- Verify that only the true subordinate key receives PAC confirmation
- The intermediate key lacks cadential closure and functions as a waypoint

# Context & Application
The three-key exposition represents the most radical form of tonal loosening in the exposition. The modulatory path -- home key to intermediate key to true subordinate key -- creates a more complex and dramatic tonal journey. However, the term overstates the case: only the home key and subordinate key are truly established as keys through cadential confirmation. The intermediate key is better understood as a waypoint in the modulatory process. Most often found in Beethoven.

# Examples
- Beethoven, Piano Sonata in E-flat, Op. 31/3, ii: home key Ab; transition leads to F major (VI); ST begins in F major, modulates to Eb (V); PAC in Eb
- Beethoven, Overture to Coriolanus, Op. 62: home key C minor; transition leads to Eb (III); ST begins in Eb, modulates through G minor; PAC in G minor (v)

# Common Errors
- Treating the intermediate key as a fully established key on par with home key and subordinate key
- Using "three-key exposition" without acknowledging the term's misleading implications
- Failing to recognize that only two keys receive cadential confirmation

# Common Confusions
- **"Three-key" as misnomer**: The middle key is rarely a fully confirmed key; it is an emphasized tonal region
- **Two vs. three keys**: Only TWO keys are truly established (home key and subordinate key)
- **Beethoven association**: The concept is most associated with Beethoven's more adventurous tonal practices
