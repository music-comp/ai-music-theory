# Quick Definition
A sequential progression with ascending-second root motion that, like the descending-second type, poses parallel-fifth problems but gains functional expression through intervening passing chords that tonicize each ascending step.

# Formal Definition
The ascending-second sequential progression shares the parallel-fifth problem of descending-second sequences. Using first-inversion triads can eliminate the difficulty, although this version occurs infrequently. More often, the stepwise ascent remains in root position while the parallel fifths are broken up by means of a 5-6 pattern formed by one of the upper voices against the bass. The passing chords created by this technique stand, by analogy, in a dominant-to-tonic relationship to the succeeding root-position chords. This functional implication can be made more explicit through chromatic alterations, making each six-three chord a genuine secondary dominant. A still more emphatic expression results when the intervening chords are placed in root position.

# Construction/Recognition
- Root motion: consistently ascending seconds (stepwise ascent)
- First-inversion form: eliminates parallel fifths but occurs infrequently (ex. 2.16a)
- 5-6 pattern: upper voice moves against the bass, creating intervening passing chords (ex. 2.16b)
- Chromatic alteration: passing chords become genuine secondary dominants (ex. 2.16c)
- Root-position passing chords: the most emphatic form, with dominant-tonic tonicizations (ex. 2.16d)
- Can resemble an embellished deceptive cadential progression (ex. 2.16e)

# Musical Context
Ascending-second sequences create a powerful forward-driving effect, with each step potentially tonicized by its preceding passing chord. The ascending motion of every voice propels the progression forward, creating tension. One form can be ambiguous between continuation function (sequential progression) and cadential function (deceptive cadential progression), a compositional resource exploited by classical composers.

# Examples
- 5-6 pattern breaking up parallel fifths (ex. 2.16b)
- With chromatic secondary dominants (ex. 2.16c)
- Embellished form resembling deceptive cadential progression (ex. 2.16e)

# Common Confusions
- One form of the ascending-second sequence resembles an embellished deceptive cadential progression. This ambiguity can be deliberately exploited by composers to blur the boundary between continuation function (sequential) and cadential function (deceptive cadential).
- The ascending-second sequence has more functional potential than the descending-second type, due to the dominant-tonic analogy created by intervening passing chords.
