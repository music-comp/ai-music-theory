# Quick Definition
A sequential progression with ascending-second root motion that gains functional expression through intervening passing chords (5-6 pattern) that tonicize each ascending step, and that can ambiguously resemble a deceptive cadential progression.

# Core Definition
The ascending-second progression shares the parallel-fifth problem of descending-second sequences. "More often, however, the stepwise ascent remains in root position while the parallel fifths are broken up by means of a 5-6 pattern formed by one of the upper voices against the bass" (Ch. 2, p. 33). The passing chords "stand, by analogy, in a dominant-to-tonic relationship to the succeeding root-position chords" (Ch. 2, p. 33). "This functional implication can be made even more explicit through chromatic alterations" making each chord "a genuine secondary dominant" (Ch. 2, p. 33). "One form of the ascending stepwise progression resembles an embellished version of the deceptive cadential progression," creating potential ambiguity between "continuation function (as supported by a sequential progression) or a cadential function (as supported by a deceptive cadential progression)" (Ch. 2, p. 33).

# Prerequisites
- **Sequential progression** -- the broader category

# Key Properties
1. Root motion: consistently ascending seconds
2. First-inversion form eliminates parallel fifths but occurs infrequently
3. 5-6 pattern: upper voice against bass creates intervening passing chords
4. Chromatic alteration: passing chords become genuine secondary dominants
5. Root-position passing chords: most emphatic form
6. Can resemble deceptive cadential progression (formal ambiguity)
7. More functional potential than descending-second sequences
8. Ascending motion creates powerful forward-driving effect

# Construction / Recognition
- Ascending-second root motion
- Check for 5-6 pattern with passing chords
- Note any chromatic alterations creating secondary dominants
- Assess possible ambiguity with deceptive cadential progression

# Context & Application
The ascending-second sequence creates forward-driving tension. The possible confusion with deceptive cadential progression is a compositional resource exploited by composers to blur the boundary between continuation and cadential function.

- Has more functional potential than the descending-second type
