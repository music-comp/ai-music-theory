# Quick Definition
Hybrid type 3 consists of a compound basic idea (basic idea + contrasting idea without a cadence, over tonic prolongation) followed by a continuation phrase. It is "very much like a sentence" except that the basic idea is not repeated -- the contrasting idea replaces the repetition.

# Core Definition
"In this hybrid type, the opening 4-m. phrase is neither an antecedent nor a presentation, but rather a combination (hybrid) of the two, a new phrase function that bears the rather complicated term *compound basic idea*" (Ch. 4, p. 101). A compound basic idea "consists of a 2-m. basic idea followed by a 2-m. contrasting idea (like an antecedent), *but it does not close with a cadence*. The underlying harmonic support for the entire phrase is tonic prolongational (like a presentation)" (Ch. 4, p. 102). The following phrase is a typical continuation with fragmentation and harmonic acceleration. "This hybrid type, one that arises frequently in the repertory, very much resembles a *sentence*. The essential difference is that mm. 3 and 4 do not repeat the basic idea but instead bring contrasting material" (Ch. 4, p. 102).

# Key Properties
1. First phrase: compound basic idea (b.i. + c.i., NO cadence)
2. Underlying harmony of first phrase: tonic prolongational (like a presentation)
3. Melodic content of first phrase: contrasting (like an antecedent)
4. Second phrase: continuation (fragmentation, harmonic acceleration, cadential closure)
5. Absence of cadence in first phrase distinguishes from hybrid type 1
6. Very sentence-like on the spectrum of theme types
7. Frequently occurring type
8. States the basic idea only once
9. The continuation may be supported by an ECP (continuation => cadential)

# Construction / Recognition
1. Identify mm. 1-2 as basic idea, mm. 3-4 as contrasting idea
2. Confirm NO cadence at end of m. 4 -- the crucial test
3. Check that the underlying harmony is tonic prolongational (not cadential)
4. A dominant chord at m. 4 does not automatically create a HC -- check whether it is part of a cadential *progression* or merely a tonic *prolongation*
5. Identify continuation characteristics in mm. 5-8: fragmentation, harmonic acceleration
6. If ECP supports the entire second phrase with continuation traits, label "continuation => cadential"

# Context & Application
Hybrid type 3 is "very close to the sentence theme type except that a contrasting idea appears in place of repeating the basic idea" (Ch. 4, p. 102). It occupies the position closest to the sentence on the spectrum. Like the sentence, it may end with any cadence type and may modulate. The continuation "may very well effect a modulation to a closely related key" (Ch. 4, p. 110).

# Examples
**Example 1** (Ch. 4, p. 102, ex. 4.3): Haydn, Piano Sonata in C, Hob. XVI:35, i, mm. 1-8: dominant at m. 3 supports the entire contrasting idea, creating a single I-V7 tonic prolongation with no cadential progression; continuation follows with fragmentation and PAC.
**Example 2** (Ch. 4, p. 109, ex. 4.10): Haydn, Symphony No. 95 in C minor, iii, mm. 1-8: tonic pedal throughout the c.b.i. destroys any cadential potential; continuation => cadential follows with ECP and harmonic acceleration.
**Example 3** (Ch. 4, p. 110, ex. 4.11): Haydn, Piano Trio in F, Hob. XV:6, ii, mm. 1-8: continuation phrase modulates to a closely related key.

## Contrasts With
- Sentence: the presentation repeats the basic idea; the c.b.i. contrasts it
- Hybrid type 1: the antecedent ends with a cadence; the c.b.i. does not

# Common Errors
- Calling the first phrase an "antecedent" when it lacks a cadence
- Assuming a dominant harmony at m. 4 automatically creates a half cadence
- Confusing this with a sentence when the surface contrast between basic idea and contrasting idea is minimal

# Common Confusions
- The crucial distinction between an antecedent and a compound basic idea is the *cadence* -- if the first phrase ends with a cadence, it is an antecedent (hybrid type 1 or period); if not, it is a compound basic idea (hybrid type 3 or 4)
- A dominant chord at the end of mm. 3-4 does not automatically create a HC -- check whether it is the goal of a cadential *progression* or merely part of a tonic *prolongation*
- The compound basic idea looks like an antecedent but functions like a presentation harmonically
