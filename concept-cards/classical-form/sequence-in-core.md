# Quick Definition
The sequential repetition of the model in a development core, transposing it one or more times to create modulatory or tonicizing progressions through the tonal landscape.

# Core Definition
Following its initial statement, the model is sequenced one or more times. Although a single sequential pattern may be used throughout (such as a descending fifth or an ascending second), the pattern often changes in the course of the core. The supporting sequential progressions either create a true modulation or introduce a variety of tonicized regions. The structure of the model is normally retained in its sequenced version, though the sequence may alter the model, especially if it consists of several phrases. In such cases, the first phrase usually conforms to the original model, but subsequent phrases may be changed or eliminated.

# Prerequisites
- **Core technique**: The organizational method
- **Model**: The unit being sequenced

# Key Properties
1. Model transposed according to a sequential pattern (descending fifth, ascending second, descending third, etc.)
2. Sequential pattern may change partway through the core
3. At minimum, one sequential repetition needed; two or more common
4. The sequence may be incomplete -- the model may be truncated in repetition
5. Sequential progressions generate tonal exploration (modulation or tonicization)
6. Model structure normally retained but may be altered (especially later phrases eliminated)
7. An incomplete sequence often marks the onset of fragmentation

# Construction / Recognition
- Identify the sequential transposition of the model
- Determine the sequential pattern (descending fifth, ascending second, etc.)
- Note any changes in the sequential pattern during the core
- Check whether the model is altered in its sequential repetitions
- Observe whether an incomplete sequence signals the onset of fragmentation

# Context & Application
The sequence provides the engine of tonal motion in the development core, moving through development keys and tonicized regions. The sequential pattern often changes to negotiate tonal turns that a single pattern could not accomplish.

# Examples
- Mozart, Piano Sonata in A Minor, K. 310, i (ex. 10.3): model sequenced twice down a perfect fifth
- Haydn, Piano Sonata in E-flat, Hob. XVI:49, i (ex. 10.4): model sequenced twice by descending thirds
- Beethoven, Piano Sonata in C Minor, Op. 10/1 (ex. 10.5): four-measure model in ascending stepwise sequence

# Common Errors
- Confusing smaller internal sequences with the full-model sequence
- Assuming a single sequential pattern must persist throughout the core
- Failing to note model alteration in later sequential repetitions

# Common Confusions
- **Internal vs. full-model sequence**: The large-scale sequence of the full model should be distinguished from smaller sequential patterns within the model
- **Changing patterns**: The sequential pattern often changes during the core -- this is normal, not anomalous
- **Incomplete sequence**: An incomplete sequence frequently marks the onset of fragmentation
