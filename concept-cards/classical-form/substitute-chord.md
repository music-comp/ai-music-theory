# Quick Definition
A chord that prolongs a given harmony because it expresses the same fundamental function, sharing two common tones with the original chord, typically lying a third below (e.g., VI for I).

# Core Definition
"Some chords can participate in prolonging a given harmony because they express the same fundamental function as does the prolonged harmony. In such cases, the original and substitute harmonies have two chord-tones in common, which largely accounts for their functional similarity" (Ch. 2, p. 26). Most commonly, the substitute lies a third below (I -> VI). "In some situations, a chord lying a third above participates in the prolongation," understood "to arise out of passing motion in the soprano voice with the simultaneous elimination of the root" (Ch. 2, p. 26).

# Prerequisites
- **Prolongational progression** -- the category to which substitute chords belong

# Key Properties
1. Substitute shares two common tones with the prolonged harmony
2. Expresses the same fundamental harmonic function
3. Most common: substitute a third below (I -> VI)
4. Less common: substitute a third above (I -> III, from soprano passing motion)
5. Passing chords may intervene between original and substitute for complex prolongations

# Construction / Recognition
- Check for two common tones between chords
- Verify same fundamental function
- Most common: third below the prolonged harmony

# Context & Application
Substitute chords extend prolongational passages while maintaining harmonic stability. The most prominent example is VI substituting for I (tonic function) in deceptive cadences.

# Examples
**Example 1** (Ch. 2, ex. 2.4a-c): I-VI: VI substitutes for I, sharing two common tones.
**Example 2** (Ch. 2, ex. 2.4d-e): I-passing chord-VI: passing chord connects original and substitute.
**Example 3** (Ch. 2, ex. 2.4f-h): I-III: substitute a third above, arising from soprano passing motion.

# Common Errors
- Treating substitute chords as introducing new harmonic functions

# Common Confusions
- Substitute chords prolong the original harmony; they do not introduce a new function
- The substitute a third above (III for I) is less intuitive but arises from voice-leading processes
