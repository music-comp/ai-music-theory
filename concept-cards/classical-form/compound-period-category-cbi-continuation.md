# Quick Definition
In this compound period category, both the eight-measure antecedent and consequent units are built as hybrid type 3 (compound basic idea + continuation). The c.b.i. provides a stable opening with tonic prolongation, while the continuation drives toward the cadence.

# Core Definition
In this category, the compound antecedent (and consequent) is constructed as a hybrid theme of type 3 (compound basic idea + continuation). The term "compound basic idea" gains particular appropriateness here: a four-measure compound basic idea occupies the same hierarchical position in a sixteen-measure period as a two-measure basic idea does in an eight-measure period. The two continuation phrases may exhibit diverse melodic-motivic content. The consequent's cadential function is often significantly expanded relative to the antecedent's.

# Prerequisites
- **Compound period**: The overarching theme type
- **Compound basic idea**: The opening four-measure unit with no cadence
- **Hybrid theme type 3**: The internal structure (c.b.i. + continuation) of each unit

# Key Properties
1. Each eight-measure unit structured as hybrid type 3 (c.b.i. + continuation)
2. The c.b.i. is typically supported by tonic prolongation (often a tonic pedal)
3. The two continuation phrases in antecedent and consequent may have different melodic content
4. The consequent's cadential function is often significantly expanded
5. The term c.b.i. is most appropriate at this hierarchical level

# Construction / Recognition
1. **Large antecedent (mm. 1-8)**: c.b.i. (mm. 1-4, tonic prolongation) + continuation (mm. 5-8) ending with weak cadence
2. **Large consequent (mm. 9-16)**: restates c.b.i. + alters continuation to end with PAC
3. Check that the c.b.i. does not end with a cadence (otherwise it is an antecedent)
4. The consequent's cadential function may begin earlier than in the antecedent (expanded cadential progression)

# Context & Application
This category highlights the hierarchical relationship between simple and compound formal structures. The c.b.i. at the four-measure level functions analogously to the basic idea at the two-measure level. The tonic pedal that commonly supports the c.b.i. contrasts effectively with the more active harmonic motion of the continuation.

# Examples
- Mozart, Piano Concerto in A, K. 488, i, mm. 1-16: c.b.i. over tonic prolongation; continuation phrases in antecedent and consequent exhibit diverse melodic content; apparent "plagal cadence" at end of first phrase is tonic prolongation embellished by subdominant
- Haydn, String Quartet in C, Op. 74/1, i, mm. 3-18: c.b.i. over tonic pedal; consequent significantly altered with continuation => cadential beginning at m. 13

# Common Errors
- Mistaking a subdominant embellishment at the end of the c.b.i. for a "plagal cadence" -- it is tonic prolongation, not a genuine cadence
- Assuming both continuation phrases must be melodically identical

# Common Confusions
- An apparent "plagal cadence" (IV-I) at the end of the c.b.i. is usually just a subdominant embellishing a tonic prolongation -- it does not constitute a genuine cadence
- The two continuation phrases need not be identical in melodic content -- what must be preserved is the functional pattern
