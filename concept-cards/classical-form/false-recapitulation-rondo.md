# Quick Definition
A premature return of the refrain material in a non-home key during the development section of a sonata-rondo, creating a dramatic deception before the true recapitulation.

# Core Definition
A number of sonata-rondo developments by Beethoven contain near their end a false recapitulation, in which material from the rondo refrain reappears first in some tonal region other than the home key. False recapitulations are more common in rondo movements than in sonata movements because the rondo places its dramatic emphasis on the return of the refrain. An initial appearance in the "wrong" key, corrected shortly thereafter in the right key, is a particularly effective device in this context.

# Construction / Recognition
- Located near the end of couplet 2 (development section) in a sonata-rondo
- Refrain material appears in a non-home key
- Creates the impression of a recapitulation beginning, but in the wrong key
- The true recapitulation follows shortly after in the correct home key
- Particularly associated with Beethoven's sonata-rondos
- More common in rondos than in sonata-form movements

# Context & Application
The false recapitulation exploits the rondo's inherent emphasis on the refrain's return. Because each return of the refrain is a dramatic event in rondo form, the "wrong" appearance intensifies the listener's anticipation for the "right" one, making the true recapitulation even more satisfying.

# Examples
- Various Beethoven sonata-rondo developments that feature refrain material in non-home keys near the end of couplet 2

# Common Confusions
- A false recapitulation should not be confused with an incomplete refrain. A false recapitulation occurs within the development and presents the refrain in the wrong key; an incomplete refrain is a legitimate return that simply lacks full closure.
- False recapitulations are a compositional device, not a formal anomaly. They represent deliberate deception, not error or oversight.
