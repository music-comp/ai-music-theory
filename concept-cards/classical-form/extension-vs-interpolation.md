# Quick Definition
Extension adds material that continues to express the ongoing formal function, while interpolation inserts material that belongs to neither the preceding nor the following function. In practice, extension is far more common in classical music, and when in doubt, the analyst should opt for extension.

# Core Definition
Extensions often result from adding on units of the same or similar melodic-motivic content. But extension can also arise with the use of different, contrasting material. As a result, it is easy to confuse extension with interpolation, which always inserts completely unrelated material into the theme. The difference lies not only in the nature of the added material but also in its relation to the form-functional context. In extension, the newly added material continues to express the ongoing function. In interpolation, the added material does not seem to belong to either of its immediately preceding and following functions. In the classical repertory, extension is far more frequently occurring than interpolation. When in doubt, opt for the extension interpretation, unless you are completely sure that the inserted material does not belong functionally to its surrounding material.

# Key Properties
1. Extension: added material CONTINUES the ongoing formal function
2. Interpolation: added material does NOT BELONG to either surrounding function
3. Extension is far more common in classical music
4. Interpolation inserts COMPLETELY UNRELATED material
5. The difference is in the FUNCTIONAL RELATIONSHIP of the added material to its context
6. When in doubt, opt for extension
7. Extension can use contrasting material (not just repetition of existing material)
8. Interpolation can be easily eliminated without disturbing formal syntax

# Construction / Recognition
1. Identify added material that exceeds normative phrase length
2. Ask: does the added material express the ongoing formal function? If yes: extension
3. Ask: is the added material unrelated to both surrounding functions? If yes: interpolation
4. Check whether the material can be eliminated without disturbing the formal logic -- if so, interpolation is more likely
5. If the material uses contrasting content but still supports the ongoing function (e.g., additional fragmentation in a continuation): extension
6. When genuinely uncertain: prefer extension

# Context & Application
This distinction is important for accurate formal analysis but can be difficult to apply in practice. Caplin advises a default preference for extension because the vast majority of added material in classical themes does participate in the ongoing formal function, even when it introduces new melodic-motivic content. True interpolation -- where the material is entirely foreign to its functional context -- is relatively rare.

# Examples
- Mozart, Piano Sonata in F, K. 280, i, m. 7: the new material (sixteenth-note flurry) extends the continuation function with additional fragmentation and harmonic acceleration -- this is extension, not interpolation, because it continues to express continuation function
- Mozart, Piano Concerto in F, K. 459, ii, mm. 3, 8: ascending chromatic figure belongs neither to the basic idea nor to the contrasting idea -- this is genuine interpolation; can be eliminated to yield a structurally sound 8-measure period

# Common Errors
- Calling any contrasting material within a phrase "interpolation" -- contrasting material can still extend the ongoing function
- Automatically classifying repeated material as extension and new material as interpolation -- the criterion is functional participation, not motivic similarity
- Overusing the "interpolation" label -- it is rare in classical music

# Common Confusions
- Extension can use contrasting, non-repetitive material -- it need not repeat prior content
- Interpolation requires that the material belong to NEITHER surrounding function
- When in doubt, opt for extension -- this is Caplin's explicit analytical recommendation
- The distinction is about functional participation, not motivic similarity
