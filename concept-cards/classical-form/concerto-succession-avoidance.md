# Quick Definition
The principle that the solo exposition should not reproduce the same succession of ideas found in the opening ritornello from the main theme to the transition.

# Formal Definition
Principle 1 of concerto-form composition states that the solo section should not reproduce the same succession of ideas found in the ritornello from the main theme to the transition. This principle governs the choice of material for the solo transition and helps explain why the solo exposition is almost never a mere repetition of the opening ritornello. The principle accounts for approximately half of Mozart's mature concertos, where the solo main theme is based on the ritornello main theme but the solo transition begins with new material, avoiding the same main-theme-to-transition succession heard in the ritornello.

# Construction/Recognition
- If the solo main theme uses the ritornello main theme, the solo transition will begin with new material
- If an alternative main theme is used, the ritornello main theme typically reappears immediately (in the transition), since the succession is already different
- If an alternative main theme is followed by the ritornello main theme (as a "second" main theme), the transition again uses new material
- The principle ensures that the solo exposition sounds like a fresh development of the material, not a repeat

# Musical Context
This principle reflects the classical concerto's need to avoid redundancy between its two "expositions." Since the audience has already heard the opening ritornello, the solo exposition must present the material in a new order to maintain interest and give the solo a distinctive identity.

# Examples
- Approximately half of Mozart's mature concertos follow the pattern: solo main theme based on ritornello main theme, solo transition based on new material
- Mozart's concertos with alternative main themes follow Principle 2 instead, bringing the ritornello main theme back in the solo transition

# Common Confusions
- This principle does not mean the solo exposition avoids ritornello material entirely; it specifically governs the succession (order) of ideas from main theme to transition.
- When an alternative main theme is used, Principle 2 takes precedence, prompting the immediate return of the ritornello main theme.
