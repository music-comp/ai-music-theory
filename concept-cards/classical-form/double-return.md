# Quick Definition
The simultaneous return of the basic idea of the exposition's main theme and tonic harmony of the home key at the opening of the recapitulation -- traditionally cited as a hallmark of classical sonata form.

# Core Definition
The opening of the recapitulation's main theme usually features what has traditionally been called a "double return": (1) a return of the basic idea of the exposition's main theme, and (2) a return of tonic harmony of the home key. For some theorists, both returns must take place at the same time in order to speak of a genuine recapitulation. But these returns are sometimes not coordinated with each other, or one of them -- the return of the opening basic idea -- may be missing altogether. (There will always be a return of home-key tonic somewhere in the recapitulation.) For this reason, Caplin's concept of recapitulation does not depend entirely on a double return but relies on the appearance of other functional obligations as well.

# Prerequisites
- **Recapitulation**: The formal context requiring the double return
- **Main theme**: Provides the basic idea for thematic return
- **Tonic function**: Provides the harmonic return

# Key Properties
1. Two simultaneous events: return of main theme's basic idea AND return of home-key tonic
2. Traditionally considered the hallmark of classical sonata form
3. Haydn and Mozart almost always open the recapitulation as they opened the exposition
4. Beethoven often gives the recapitulation a different dynamic (louder, more forceful)
5. The two returns are sometimes not coordinated temporally
6. The thematic return (basic idea) may be missing entirely
7. The tonal return (home-key tonic) is always present somewhere
8. Caplin's concept of recapitulation does not depend entirely on the double return
9. When the recapitulation begins with great dynamic force, the V-I resolution may misleadingly suggest an authentic cadence

# Construction / Recognition
- Look for the main theme's basic idea returning in the home key
- Check whether both returns occur simultaneously
- If the basic idea is absent, consider whether recapitulation function is still fulfilled
- If the tonic return occurs but with different thematic material, note the deviation
- Do NOT interpret the V-I resolution as an authentic cadence

# Context & Application
The double return reinforces the character of "starting over again." Haydn and Mozart almost always open the recapitulation just as the exposition opened. Beethoven, however, often gives the start of the recapitulation an entirely different dynamic, more forceful and dramatically charged. This effect of apotheosis may give the misleading impression that the recapitulation is the structural goal, but Caplin cautions against interpreting this as an authentic cadence.

# Examples
- Mozart, Piano Sonata in G, K. 283, i (ex. 14.5): standard double return with same opening material
- Beethoven, Piano Sonata in A, Op. 2/2, i (ex. 14.4): double return present but main theme significantly altered
- Haydn, String Quartet in E-flat, Op. 50/3, i (ex. 14.15): basic idea of main theme deleted -- no thematic return at the start of the recapitulation

# Common Errors
- Treating the V-I resolution at the start of the recapitulation as an authentic cadence
- Assuming the double return is an absolute requirement for recapitulation
- Confusing Beethoven's dynamic apotheosis with cadential function

# Common Confusions
- **Double return vs. authentic cadence**: The V at the end of the development is an "ultimate dominant" that resolves to initiate, not conclude
- **Apotheosis effect**: Beethoven's forceful recapitulation openings may create a misleading impression of cadential arrival
- **Recapitulation without double return**: Caplin maintains the label "recapitulation" even when the basic idea is missing
