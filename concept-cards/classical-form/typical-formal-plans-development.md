# Quick Definition
Three standard organizational patterns for the development section: (1) single core leading to home-key dominant; (2) two cores, first ending in a development key, second in the home key; (3) single core ending in a development key, followed by a retransition.

# Core Definition
Caplin identifies three typical formal plans for a development section (Figure 13.1). In the first plan, a single core leads directly to dominant of the home key, preceded by a pre-core. In the second plan, two cores appear: the first ends in a development key, the second returns to the home key. The first core always ends in a development key; the second usually in the home key. A second core normally contains different melodic-motivic material from the first. Multiple cores are especially likely in large-scale symphonic movements by Beethoven. In the third plan, a single core ends in a development key, after which a retransition brings the music back to the home key. These three plans describe developments that use pre-core/core technique; many developments (especially Haydn's) do not conform to any of them.

# Prerequisites
- **Development section**: The formal context
- **Core technique**: The organizational principle at the heart of all three plans
- **Pre-core**: The passage preceding the core in all three plans
- **Retransition**: Required in the third plan

# Key Properties
1. Plan 1: pre-core + core (ending in home key) + standing on the dominant
2. Plan 2: pre-core + core 1 (ending in development key) + core 2 (ending in home key) + standing on the dominant
3. Plan 3: pre-core + core (ending in development key) + retransition + standing on the dominant
4. All plans typically end with a standing on the dominant
5. Multiple cores are common in Beethoven symphonic movements
6. The second core normally uses different material from the first
7. A retransition is needed only when the core ends in a development key (Plans 2 and 3)
8. Many developments (especially Haydn's) do not use pre-core/core technique at all

# Construction / Recognition
- First, identify whether the development uses pre-core/core technique
- Look for a large-scale model (4-8 measures) that is sequentially repeated
- Determine whether the core ends in a development key or the home key
- If development key: look for a second core or a retransition
- If home key: the development likely follows Plan 1
- Check the standing on the dominant at the end

# Context & Application
These three plans provide a starting framework for analyzing developments, but many developments do not conform to any single plan. Haydn frequently constructs developments without a genuine core, using transition-like units, pseudo-cores, or subordinate-themelike units instead. Even in Mozart and Beethoven, ad hoc approaches are sometimes needed.

# Examples
- Mozart, Piano Sonata in A minor, K. 310, i, mm. 50-81 (ex. 13.1): Plan 1 -- single core with model sequenced twice, fragmentation, HC in home key
- Haydn, Piano Sonata in E-flat, H. 49, i, mm. 84-107 (ex. 13.3): first of two cores (Plan 2)
- Haydn, Piano Sonata in B-flat, H. 41, i (ex. 13.11): retransition following development key confirmation (Plan 3)

# Common Errors
- Assuming all developments conform to one of these three plans (many do not)
- Confusing a pseudo-core with a genuine core (the model-sequence process is essential)
- Assuming the second core must use the same material as the first

# Common Confusions
- **Plan 2 vs. Plan 3**: Both involve a core ending in a development key; Plan 2 has a second core, Plan 3 has a retransition
- **Haydn's developments**: Haydn frequently omits the core entirely, so these plans do not apply
- **"Ad hoc" developments**: Even in Mozart and Beethoven, some developments resist formal classification
