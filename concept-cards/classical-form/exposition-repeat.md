# Quick Definition
The standard classical practice of repeating the exposition, indicated by double-bar lines, creating a binary aspect and establishing a musical connection between the exposition's end and the main theme's return.

# Core Definition
The sonata exposition is normally repeated, as indicated by double-bar lines. The development and recapitulation are sometimes repeated together, almost always in works written before 1780. The exposition repeat creates a binary aspect to the overall form (analogous to the rounded binary version of small ternary). It also establishes a musical connection between the end of the exposition (closing section/retransition) and the beginning of the main theme -- a connection the pre-core of the development later varies. The repeat is normative in the classical period; its omission is the exception.

# Prerequisites
- **Sonata form**: The formal context
- **Sonata exposition**: The section being repeated

# Key Properties
1. Indicated by repeat signs (double-bar lines) at the end of the exposition
2. Creates a binary aspect within the ternary design
3. Establishes the connection: closing section to main theme (later varied by pre-core)
4. Development-recapitulation repeat is separate, mostly pre-1780
5. The repeat is normative; omission is exceptional
6. Reinforces the listener's grasp of thematic material before development

# Construction / Recognition
- Look for repeat signs at the end of the exposition
- Note the musical connection between the exposition's ending and the main theme's opening
- Check for a second set of repeat signs after the recapitulation (development-recapitulation repeat)

# Context & Application
The exposition repeat is a formal convention with important structural consequences. It ensures the listener has absorbed thematic material before the development transforms it. The link it creates between the exposition's end and beginning is compositionally exploited when the pre-core begins with main-theme or closing-section material.

# Examples
- Standard practice in nearly all classical sonata movements
- Development-recapitulation repeat is common in Haydn's earlier works

# Common Confusions
- **Not optional**: The exposition repeat is part of the form's design in the classical period

- **Binary trait**: The repeat creates binary characteristics even within the ternary design
