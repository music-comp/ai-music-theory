# Quick Definition
Two principles guide the solo transition: (1) the solo section should not reproduce the same succession of ideas as the ritornello, and (2) use of an alternative main theme prompts the immediate reappearance of ritornello main-theme material.

# Core Definition
The choice of material to begin the solo transition is guided by two general principles. First, the solo section should not reproduce the same succession of ideas found in the ritornello from the main theme to the transition. Second, the use of an alternative main theme prompts the immediate reappearance of material from the ritornello main theme. These principles generate several scenarios: if the solo main theme is based on the ritornello main theme, the solo transition begins with new material (principle 1); if an alternative main theme is used, the transition is based on the ritornello main theme (principle 2); if an alternative main theme is followed by the ritornello main theme as a "second" theme, the transition uses new material (principle 1). Although most concertos follow these principles, some bring a solo main theme and transition that largely restate the opening ritornello, reinforcing the "double exposition" concept (Caplin, pp. 708-709).

# Key Properties
1. Principle 1: solo should not reproduce the same succession as the ritornello
2. Principle 2: alternative main theme triggers reappearance of ritornello main-theme material
3. If solo MT = ritornello MT, then solo TR = new material
4. If solo MT = alternative, then solo TR = ritornello MT material
5. If alternative MT is followed by ritornello MT, then solo TR = new material
6. Some concertos restate the ritornello transition despite these principles

# Construction / Recognition
1. Identify whether the solo main theme is based on the ritornello MT or is new
2. Apply the two principles to predict the transition's content
3. Verify whether the actual transition follows the expected pattern
4. Note deviations from the principles

# Context & Application
These principles ensure variety and forward momentum in the solo exposition. They prevent the solo section from being a mere copy of the ritornello while ensuring that important ritornello material is heard again in appropriate contexts.

# Examples
**Example 1** (p. 707): Mozart, Piano Concerto in D minor, K. 466, i -- alternative main theme (lyrical, pianistic) at m. 77 contrasts with the brooding orchestral opening; ritornello main-theme material must then reappear nearby.
**Example 2** (p. 705): Mozart, Horn Concerto in E-flat, K. 447, i, mm. 33-36 -- solo exposition brings a more normal main theme with continuation belonging to the character of the ritornello's opening.

# Common Errors
- **Error**: Expecting the solo transition to repeat the ritornello transition. **Correction**: The solo usually avoids reproducing the same succession of ideas as the ritornello.

# Common Confusions
- **Confusion**: Why the solo transition sometimes uses main-theme material. **Clarification**: When an alternative main theme is used, principle 2 requires ritornello MT material to reappear, often in the transition.
