# Quick Definition
When comparing a recapitulation to its exposition, changes fall into two categories: ornamental changes (melody, texture, dynamics, instrumentation, accompanimental patterning) and structural changes (harmonic progression, basic melodic patterning, grouping structure, formal functions). The analytical procedure is to compare sections bar by bar and then ask "why" each change was made.

# Core Definition
Whether or not the recapitulation undergoes structural changes relative to the exposition, it may at any time experience ornamental changes. Ornamental changes include alterations in melody (embellishments), texture, dynamics, instrumentation, and accompanimental patterning. Structural changes emerge from differences in harmonic progression, basic melodic patterning, grouping structure, and formal functions. The analytical procedure for any recapitulation is simple but powerful: compare the exposition to the recapitulation bar by bar, observe every change, classify each as structural or ornamental, and then ask "why" the composer made each change.

# Key Properties
1. **Ornamental changes**: melody (embellishments), texture, dynamics, instrumentation, accompanimental patterning
2. **Structural changes**: harmonic progression, basic melodic patterning, grouping structure, formal functions
3. Tonal adjustment (required when A modulates) is a structural change
4. Change of formal function (e.g., consequent becoming continuation) is structural
5. Added dynamics markings or textural changes are ornamental
6. The "why" question is essential: why did the composer make each change?

# Construction / Recognition
1. Compare A and A' measure by measure (or note by note if necessary)
2. Note every change from one section to the other
3. Classify each change as structural or ornamental
4. Ask "why" each change was made
5. If no changes: also ask why no changes were made
6. Practice this mode of analysis repeatedly to develop insight

# Context & Application
This analytical framework applies not just to small ternary recapitulations but to any restatement in classical music (sonata recapitulations, variation forms, rondo refrains). The distinction helps the analyst move beyond mere description to interpretation. The "why" question may not always yield a clear answer, but the effort to ask it consistently leads to many interesting observations about compositional craft.

# Examples
- Haydn, Piano Sonata in E-flat, Hob. XVI:49, iii: tonal adjustment (structural) to remain in home key; bass line approaches dominant from above instead of below (structural, counteracting modulation)
- Beethoven, Piano Sonata in E-flat, Op. 7, ii: new continuation (structural); deceptive cadence (structural); fortissimo outburst (ornamental/structural hybrid); added closing section (structural)

# Common Errors
- Treating all changes as equally significant -- structural changes are analytically more important
- Failing to distinguish ornamental from structural changes
- Not asking the "why" question after identifying changes

# Common Confusions
- A change in dynamics is ornamental even if it creates a dramatically different effect
- A change in harmonic progression is structural even if the melodic surface remains similar
- Some changes resist easy classification (e.g., a fortissimo outburst that introduces new melodic material is both ornamental and structural)
