# Quick Definition
A small binary whose first part expresses periodic organization yet ends with a half cadence rather than an authentic cadence, denying the implied period form through a "failed consequent" and strongly suggesting binary structure.

# Core Definition
The first part of a small binary can express periodic organization yet end with an HC. When the second phrase restates the basic idea in the manner of a consequent but closes with an HC instead of the expected authentic cadence, the result is a "failed consequent." This is a nonconventional form: the second phrase is not a true antecedent (since it may modulate) but cannot be called a consequent either (since it lacks strong cadential closure). When the first part is repeated, a compound antecedent interpretation may seem viable, but when it ends again with HC, the period interpretation fails: the antecedent of any period is never repeated prior to the onset of the consequent.

# Prerequisites
- **Small binary**: The overarching form
- **Period**: The form being suggested but not realized

# Key Properties
1. First part opens with regular antecedent phrase (or compound basic idea)
2. Second phrase begins like a consequent (restating basic idea)
3. Second phrase ends with HC instead of expected authentic cadence
4. The second phrase is a "failed consequent" -- not a true antecedent
5. When repeated, initially implies a compound antecedent but the repeated HC denies this
6. Overall two-part structure suggests a period-like cadential differentiation (HC then PAC)
7. The failed consequent is nonconventional: neither true antecedent nor consequent
8. A modulating second phrase cannot be an antecedent (antecedents do not modulate)

# Construction / Recognition
1. Identify periodic qualities in the first part (antecedent-like opening, basic idea return)
2. Note the HC ending instead of expected PAC
3. Label the second phrase as "failed consequent"
4. When repeated: test against compound period interpretation (fails if both repetitions end HC)
5. The second part's structure confirms binary form

# Context & Application
This form is particularly interesting because it sets up and then denies multiple formal expectations. The listener initially expects a period within the first part, then a compound period when the first part repeats. Both expectations fail. The resulting cadential differentiation between parts (HC then PAC) suggests a period-like relationship, but without genuine consequent function in the second part.

# Examples
- Haydn, Piano Sonata in E, Hob. XVI:31, iii, mm. 1-16: antecedent followed by modulating phrase ending with HC ("failed consequent")
- Beethoven, Violin Sonata in A, Op. 30/1, iii, mm. 1-32: compound basic idea followed by HC-ending phrase; "reversed period" suggested

# Common Errors
- Labeling the failed consequent as a "true antecedent" -- a true antecedent is nonmodulatory and implies a subsequent consequent
- Hearing the repeated first part as a compound antecedent -- the repeated HC denies compound period form
- Calling the period-like cadential pattern (HC then PAC) across both parts a "period"

# Common Confusions
- A "failed consequent" is NOT a true antecedent -- a true antecedent is nonmodulatory
- The period-like cadential pattern (HC then PAC) across both parts does NOT make the form a period
- The repetition of part 1 does not create a consequent -- when both repetitions end with HC, the consequent function remains unrealized
- If a presumed compound antecedent is fully repeated (ending HC both times), reinterpret as first part of a small binary
