# Quick Definition
A formal type (e.g., sentence, period) is a theme type defined by its internal organization of phrase functions. A formal function (e.g., presentation, antecedent) expresses a temporal sense of beginning, middle, or ending. Types have no predetermined temporal location; functions do. A sentence or period is a type that can serve various functions depending on its larger formal context.

# Core Definition
"The terms *sentence* and *period* refer to formal *types*, in this case *theme types*. Each theme type embraces a conventional set of *phrase functions*. Thus the sentence contains the functions of presentation, continuation, and cadential. The period contains the two functions of antecedent and consequent" (Ch. 3, p. 73). "It is useful to keep in mind the difference between a formal *type* and a formal *function*. A function relates to some temporal sense of beginning, being-in-the-middle, or ending. A type, on the contrary, does not have any predetermined temporal location; the sentence form, for example, is not necessarily associated with a beginning, middle, or end of anything. Later we will see that certain theme types are used in specific contexts where they fulfill a formal function, as when a sentence or period takes on the initiating function of *main theme* of a movement" (Ch. 3, p. 73).

# Prerequisites
- **Formal function** -- the concept of temporal roles (beginning, middle, ending)

# Key Properties
1. Theme types: sentence, period, hybrid themes, small ternary, etc.
2. Phrase functions: presentation, continuation, cadential, antecedent, consequent, etc.
3. Types are defined by internal organization; functions are defined by temporal role
4. Types have no predetermined location; functions have inherent temporal orientation
5. A type can serve different functions in different contexts
6. The distinction operates at multiple structural levels

# Construction / Recognition
- When analyzing, distinguish between asking "what type is this?" and "what function does it serve?"
- Type question: what is its internal organization (phrase functions, cadences)?
- Function question: what temporal role does it play in the larger form (beginning? middle? ending?)
- A sentence (type) serving as main theme (function) is common; a sentence serving as subordinate theme is also possible

# Context & Application
This distinction is crucial for understanding larger forms. A sentence that serves as a main theme fulfills an initiating function within the sonata form; the same sentence type appearing as a subordinate theme fulfills a different function. The distinction also prevents the common error of equating "sentence" with "beginning" or "period" with any two-phrase theme.

# Examples
**Example 1**: A sentence serving as the main theme of a sonata movement -- the theme type is "sentence," and its formal function is "main theme" (initiating).
**Example 2**: A period serving as a subordinate theme -- the theme type is "period," and its formal function is "subordinate theme."

- Approaches that conflate type and function (e.g., calling any opening unit a "sentence")

# Common Errors
- Equating a theme type with a specific formal function (e.g., assuming a sentence always serves as a beginning)
- Confusing "theme type" with "cadence type" or "phrase type"
- Treating function labels as purely descriptive rather than as expressing temporal orientation

# Common Confusions
- "Sentence" is a type, not a function -- a sentence can serve as main theme (beginning), subordinate theme (middle in some sense), or even as coda material (ending)
- "Antecedent" is both a phrase function (initiating within a period) and a label for a specific phrase type -- context determines which sense is meant
- The distinction is not just terminological -- it reflects a fundamental difference in how formal units relate to musical time
