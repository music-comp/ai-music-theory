# Quick Definition
The second primary key of the sonata exposition -- typically V in major-mode and III in minor-mode movements -- confirmed by a PAC in the subordinate theme and creating large-scale tonal dissonance with the home key.

# Core Definition
The subordinate key is the tonal region established in contrast to the home key, creating the fundamental tonal opposition of the exposition. It must be confirmed by a perfect authentic cadence in the subordinate theme. The subordinate key engenders large-scale dissonance with the home key; for that key to acquire sufficient weight to vie for prominence with the home key, it must be fully confirmed by a PAC. The home key must also be so confirmed, if not at the end of the main theme, then at least later in the movement (usually in the recapitulation). The subordinate key is primarily associated with the subordinate theme and the last part of the transition.

# Prerequisites
- **Sonata exposition**: The formal context in which the subordinate key is established
- **Subordinate theme**: The thematic unit that confirms the subordinate key
- **Authentic cadence**: The cadential type required for confirmation

# Key Properties
1. In major: typically V (dominant region)
2. In minor: typically III (relative major)
3. Must be confirmed by PAC in the subordinate theme (essential expositional closure)
4. Represents the "tonal antagonist" creating structural dissonance with the home key
5. Resolved in the recapitulation when the subordinate theme is transposed to the home key
6. May appear briefly in the main theme (small ternary or binary main themes)
7. Extended into the beginning of the development, then rarely returns
8. In three-key expositions, the subordinate theme begins in an intermediate key and modulates to the true subordinate key

# Construction / Recognition
- Identify the key in which the subordinate theme's PAC occurs
- In major: V is standard; other keys are exceptional
- In minor: III (relative major) is standard; minor V is less common
- The transition's modulation (or lack thereof) determines how the subordinate key is approached
- Nonmodulating transitions leave the subordinate key to be established directly by the subordinate theme
- The subordinate key's confirmation requires cadential function, not merely tonicization

# Context & Application
The establishment of the subordinate key is what creates the fundamental tonal conflict in sonata form. The dramatic purpose of the subordinate theme is to confirm this competing tonality through PAC. The subordinate key's dramatic weight comes from the effort required to achieve cadential confirmation -- hence the appropriateness of cadential extension and expansion in subordinate themes. In the recapitulation, the tonal conflict is resolved by presenting the subordinate theme in the home key.

# Examples
- Standard major-mode sonata: subordinate key is V
- Standard minor-mode sonata: subordinate key is III (relative major)
- Beethoven, Overture to Coriolanus, Op. 62: C minor to Eb major (III)
- Three-key expositions: subordinate theme begins in one key (e.g., VI) and modulates to true subordinate key (V)
- Mozart, Violin Concerto in A, K. 219, i: subordinate key E major (V), confirmed by PAC

# Common Errors
- Treating any key other than the home key as the subordinate key
- Assuming the subordinate key is merely tonicized rather than cadentially confirmed
- Confusing the key that begins a modulating subordinate theme with the true subordinate key

# Common Confusions
- **Subordinate key vs. "a different key"**: The subordinate key is the specific key creating the fundamental tonal opposition, not just any contrasting tonality
- **Confirmation vs. tonicization**: The subordinate key is confirmed by cadence (PAC), not merely tonicized
- **Three-key exposition**: The key beginning the subordinate theme may differ from the true subordinate key (which is always the one cadentially confirmed)
- **Minor-mode dissonance**: In minor movements, the sense of structural dissonance is less palpable because III shares the same basic scale
