# Quick Definition
The three fundamental harmonic functions--tonic, dominant, and pre-dominant--that embrace all harmonic formations in a key and form the logical progression that expresses tonality.

# Formal Definition
Caplin's harmonic theory combines features from both the scale-degree (Stufentheorie) and the functional (Funktionstheorie) traditions. The functional theory, developed by Hugo Riemann in the late nineteenth century, rejects the notion of seven independent harmonies and instead recognizes three fundamental functions that embrace all harmonic formations in a key. These functions form a logical progression that serves to express tonality: (1) tonic--the central harmony to which all others relate; (2) dominant--harmonies containing the leading-tone whose primary role is to progress to the tonic; (3) pre-dominant--harmonies whose primary purpose is to lead to the dominant. The temporal sequence tonic -> pre-dominant -> dominant -> tonic constitutes the fundamental cadential progression.

# Construction/Recognition
- Tonic: I, VI (as substitute)
- Dominant: V, V7, VII6, VII7 and inversions (all contain the leading-tone)
- Pre-dominant: II6, IV, bII6, V/V, VII7/V, augmented sixth chords
- The three functions arrange in the order T -> PD -> D -> T for cadential confirmation
- Prolongational progressions sustain a single function
- Sequential progressions operate outside normal functional syntax

# Musical Context
These three functions are the harmonic foundation of Caplin's entire formal theory. Every harmonic progression in classical music can be classified as prolongational (sustaining one function), cadential (cycling through the three functions to confirm tonality), or sequential (operating outside functional syntax). The choice among these three progression types is what defines formal functions at the theme level.

# Examples
- Cadential progression: I-II6-V-I (tonic -> pre-dominant -> dominant -> tonic)
- Prolongational progression: I-V-I (tonic sustained, with dominant as neighbor)
- The complete system of three functions is illustrated by all examples in Chapter 2

# Common Confusions
- The functional theory recognizes three functions, not seven independent scale-degree harmonies. Multiple chords can represent a single function (e.g., II6, IV, bII6, augmented sixths all represent pre-dominant function).
- VI can function as either tonic (substitute for I) or pre-dominant, depending on context.
- Caplin uses the term "pre-dominant" rather than "subdominant" because the function encompasses chords not directly related to IV.
