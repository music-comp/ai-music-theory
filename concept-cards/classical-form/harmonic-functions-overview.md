# Quick Definition
The three fundamental harmonic functions -- tonic, dominant, and pre-dominant -- that embrace all harmonic formations in a key and form the logical progression T -> PD -> D -> T that expresses tonality.

# Core Definition
Caplin's harmonic theory "combines features from both the scale-degree and the functional theories" (Ch. 2, p. 23). The functional theory, developed by Hugo Riemann, "rejects the notion of seven independent harmonies and instead recognizes three fundamental functions, which embrace all harmonic formations in a key. These functions form a logical progression that serves to express tonality" (Ch. 2, p. 23): (1) tonic -- "the central harmony of a key, the one to which all others ultimately relate"; (2) dominant -- harmonies "whose primary role is to progress to the tonic," all containing the leading-tone; (3) pre-dominant -- harmonies "whose primary purpose is to lead to the dominant" (Ch. 2, p. 23). The term "pre-dominant" is preferred over "subdominant" because the function "includes a number of harmonic formations not directly related to the harmony built on the fourth degree of the scale" (Ch. 2, p. 23).

# Prerequisites
None -- this is the foundational harmonic framework for the book.

# Key Properties
1. Three functions embrace ALL harmonic formations in a key
2. Tonic: I, VI (as substitute)
3. Dominant: V, V7, VII6, VII7 and inversions (all contain the leading-tone)
4. Pre-dominant: II6, IV, bII6, V/V, VII7/V, augmented sixth chords
5. The temporal sequence T -> PD -> D -> T constitutes the fundamental cadential progression
6. "Pre-dominant" is preferred over "subdominant" for broader inclusiveness

# Construction / Recognition
- Classify each harmony according to its function (T, D, or PD)
- Identify the progression type: prolongational (sustains one function), cadential (cycles through T-PD-D-T), or sequential (operates outside functional syntax)

# Context & Application
These three functions are the harmonic foundation of Caplin's entire formal theory. Every harmonic progression in classical music can be classified as prolongational, cadential, or sequential, and this classification is what defines formal functions at the theme level.

# Examples
**Example 1** (Ch. 2, p. 23): Cadential progression: I-II6-V-I (T -> PD -> D -> T).
**Example 2** (Ch. 2, p. 24): Prolongational progression: I-V-I (tonic sustained, with dominant as neighbor).

# Common Errors
- Treating all seven scale-degree harmonies as independent functions

# Common Confusions
- The functional theory recognizes three functions, not seven independent scale-degree harmonies. Multiple chords represent a single function
- VI can function as either tonic (substitute for I) or pre-dominant, depending on context
- Caplin uses "pre-dominant" rather than "subdominant" because the function encompasses chords not directly related to IV
