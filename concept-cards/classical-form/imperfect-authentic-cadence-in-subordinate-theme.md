# Quick Definition
An imperfect authentic cadence within a subordinate theme that signals the theme has not yet reached its true end, typically motivating a repetition of the preceding phrase to achieve the required perfect authentic cadence.

# Core Definition
Since subordinate themes almost always close with a PAC, the appearance of an IAC signals that the theme's true end has not yet been reached. Typically, the phrase ending with the IAC (be it continuation, cadential, or continuation=>cadential) is repeated, leading this time to a PAC. When an IAC phrase is followed by a repetition achieving PAC, a sense of antecedent-consequent functionality is expressed. However, the result should not normally be considered a period, since the passage seldom contains other characteristics of a true antecedent or consequent phrase, and elision between the IAC phrase and its repetition is possible (which does not occur with genuine periods).

# Prerequisites
- **Cadential function**: The function producing the IAC
- **Subordinate theme**: The context requiring PAC for closure
- **Authentic cadence**: The cadential type (imperfect variant)

# Key Properties
1. Authentic cadential progression resolves with 3 (not 1) in the soprano voice
2. Provides partial closure but not the conclusive PAC required
3. The preceding phrase is typically repeated with adjustments to achieve PAC
4. The repetition may feature a stronger cadential dominant
5. An antecedent-consequent expression results, but not a true period
6. Elision between IAC phrase and repetition is possible (unlike true periods)
7. The IAC is the mildest form of cadential extension

# Construction / Recognition
- Identify an authentic cadence with 3 in the soprano (not 1)
- Note whether the phrase is then repeated with a stronger cadential ending
- Observe whether the repetition achieves PAC
- Check for elision between the two phrases
- Assess whether the IAC-PAC pattern constitutes a true period (usually not)

# Context & Application
The IAC is the mildest form of cadential extension in subordinate themes. It provides partial closure (unlike evaded and abandoned cadences) but leaves the theme's primary cadential goal unfulfilled. As a loosening technique, the IAC-to-PAC pattern is somewhat redundant but less dramatically powerful than the evaded or deceptive cadence. In main themes, an IAC closing a theme is acceptable; in subordinate themes, an IAC always demands a subsequent PAC.

# Examples
- Beethoven, Overture to Coriolanus, Op. 62, mm. 102-118: 8-measure sentence closes with IAC at m. 110; continuation repeated with stronger cadential dominant, achieving PAC at m. 114

# Common Errors
- Treating IAC followed by PAC as a period (usually lacks other periodic characteristics)
- Equating IAC's dramatic effect with evaded cadence (IAC is much milder)
- Assuming an IAC is always a loosening technique (in main themes it may simply end the theme)

# Common Confusions
- **IAC-PAC vs. period**: The antecedent-consequent expression should not be confused with a true period -- elision and lack of other periodic characteristics prevent this reading
- **IAC vs. evaded cadence**: IAC provides PARTIAL closure; evaded cadence provides NO closure
- **Context matters**: An IAC ending a main theme is acceptable; the same IAC in a subordinate theme demands further cadential activity
