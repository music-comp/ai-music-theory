# Quick Definition
Caplin advocates labeling rondo parts with numbered refrains and couplets (refrain 1, couplet 1, etc.) combined with formal-function designations (main theme, subordinate-theme complex, interior theme) rather than relying solely on letter schemes (ABACA, ABACABA).

# Core Definition
The standard use of letters (ABACA, ABACABA) for rondo forms is deficient in several respects. First, letters indicate melodic-motivic material but reveal nothing about formal function. Second, letters can be confused with those representing other forms, especially the small ternary. Caplin proposes a dual labeling system: a primary set distinguishing refrains and couplets by number (refrain 1, couplet 1, refrain 2, etc.) and a complementary set specifying formal function (main theme, subordinate-theme complex, interior theme, first return of main theme, etc.). This system reveals the form-functional attributes of each part while maintaining clarity about the rondo structure (Caplin, pp. 664-666).

# Prerequisites
- **Five-part rondo** -- One rondo type requiring labeling
- **Sonata-rondo** -- The other rondo type

# Key Properties
1. Letter labels (ABACA) tell about melodic content but not formal function
2. Letters can be confused with small ternary labels
3. Preferred system: numbered refrains and couplets
4. Complementary labels specify formal function of each part
5. Five-part rondo: refrain 1 (main theme), couplet 1 (subordinate-theme complex or interior theme), refrain 2 (first return), couplet 2 (interior theme), refrain 3 (final return)
6. Sonata-rondo adds exposition/recapitulation function labels

# Construction / Recognition
1. Use refrain 1, 2, 3 (and 4) for statements of the main theme
2. Use couplet 1, 2, 3 for contrasting sections
3. Add formal-function labels: main theme, subordinate-theme complex, interior theme, development, first/final return
4. Avoid relying solely on letter labels

# Context & Application
This labeling system aligns with Caplin's broader form-functional approach, where understanding formal function is paramount. The letter system persists in traditional textbooks but obscures the analytical insights available through functional labeling.

# Common Errors
- **Error**: Relying on letter labels to understand rondo form. **Correction**: Use numbered refrains/couplets with formal-function designations.

# Common Confusions
- **Confusion**: Whether ABACA letters and rondo labels are interchangeable. **Clarification**: Letters describe melodic content; functional labels describe formal role. Both systems can coexist but the functional labels are more analytically useful.
