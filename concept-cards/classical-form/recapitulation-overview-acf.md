# Quick Definition
The recapitulation resolves the tonal conflict by restating the exposition's material in the home key, with the transition tonally adjusted to remain in the home key and the subordinate theme transposed -- analysis proceeds by systematic bar-by-bar comparison with the exposition, noting all structural and ornamental changes.

# Core Definition
The recapitulation resolves the tonal conflict of the movement by bringing back most of the material of the exposition firmly in the context of the home key. The start is signaled by the return of the main theme's basic idea in the home key. The basic thematic units of main theme, transition, and subordinate theme return in order, but usually undergo significant structural changes in harmonic-tonal organization and phrase structure. In addition, the recapitulation may bring about a range of ornamental changes (in instrumentation, dynamics, accompaniment, texture). The main theme usually returns without significant structural alterations. The transition must be adjusted to remain in the home key (often emphasizing the subdominant region). The subordinate theme returns transposed into the home key. The principal analytical method is comparison: work through the section bar by bar and compare how each part relates to the exposition.

# Key Properties
1. Resolves the tonal conflict by restating everything in the home key
2. Start signaled by return of main-theme basic idea in home key
3. Main theme: usually structurally unchanged; ornamental changes common
4. Transition: must be adjusted to remain in home key; often emphasizes subdominant
5. Subordinate theme: transposed to home key; must achieve PAC (ESC)
6. The final PAC sometimes made more emphatic than in the exposition
7. Closing section normally returns intact, possibly extended
8. Structural changes vs. ornamental changes: both occur but serve different purposes
9. Haydn typically reworks the entire recapitulation more extensively than Mozart or Beethoven

# Construction / Recognition
- Identify the return of the main theme's basic idea in the home key
- Compare bar by bar with the exposition
- Note all structural changes (harmonic, tonal, phrase-structural)
- Note all ornamental changes (instrumentation, dynamics, texture, register)
- Ask "why" for each change: is it mandated by sonata form (tonal adjustment) or specific to this work?
- The recapitulation ends when it no longer corresponds with the exposition (beginning of coda)

# Context & Application
The analytical approach to recapitulation is fundamentally comparative. Some changes are mandated by the general requirements of sonata form (adjusting the transition, transposing the subordinate theme). But many others are specific to the individual work and offer insight into the composer's creative process. Asking the "why" question for each change is a key analytical strategy. One major stylistic difference: Haydn effects major structural changes throughout the recapitulation, while Mozart and Beethoven normally bring their subordinate-theme groups largely unaltered.

# Examples
- Beethoven, Piano Sonata in F minor, Op. 2/1, i, mm. 101-152 (Ch. 9, Exs. 9.9-9.11): main theme unchanged; transition adjusted (basic idea in F minor instead of C minor, subdominant emphasis, diminished standing on dominant); subordinate theme transposed to F minor; closing section extended to form a possible "second" subordinate theme

# Common Errors
- Analyzing the recapitulation in isolation rather than by comparison with the exposition
- Treating ornamental changes as structural (or vice versa)
- Assuming the recapitulation is a mere transposed repeat of the exposition
- Not asking "why" for each change

# Common Confusions
- **Structural vs. ornamental**: Structural changes affect harmonic-tonal organization and phrase structure; ornamental changes affect surface features (dynamics, register, accompaniment)
- **Mandated vs. individual**: Some changes are required by sonata form (tonal adjustment); others reflect the specific work's compositional logic
- **Haydn vs. Mozart/Beethoven**: Haydn's recapitulations are typically much more extensively reworked than those of Mozart and Beethoven
