# Quick Definition
Material following a PAC that initially appears to be a postcadential closing section (codettas) but is retrospectively understood as the beginning of a new subordinate theme, transition, or other formal unit.

# Core Definition
Within a subordinate-theme group, a true closing section appears only after the final theme. The PACs of prior themes may be followed by material with prominent codetta characteristics (tonic pedal, prolongation of 1 in the soprano, recessive dynamic). The subsequent development of this material, however, is revealed retrospectively to function as the beginning of a new subordinate theme. In most cases, the codetta-like idea can be reinterpreted as a basic idea whose repetition creates a presentation phrase. The false closing section also appears in transitions (codettas following the main theme's PAC merge into transition material) and at the recapitulation-coda junction.

# Prerequisites
- **Closing section**: The genuine postcadential structure being mimicked
- **Codetta**: The unit type that the false closing section resembles
- **Subordinate theme**: The formal context (between themes in a group)

# Key Properties
1. Follows a PAC (of subordinate theme, main theme, or recapitulation)
2. Material has prominent codetta characteristics: tonic pedal, 1 prolongation, recessive dynamic
3. Subsequent development reveals passage as BEGINNING of a new theme or transition
4. Codetta-like idea reinterpreted as basic idea; repetition creates presentation
5. Recognized only RETROSPECTIVELY
6. Grouping-structure test: codettas followed by LARGER unit = genuine closing section; codettas followed by SMALLER unit (fragmentation) = false closing section
7. The same material can be a false closing section in one context and genuine in another

# Construction / Recognition
- Locate material after a PAC with codetta characteristics
- Apply grouping-structure test: is the next unit larger or smaller?
- Watch for the moment when codetta character gives way to thematic development
- Note the dynamic shift from recessive to progressive
- Consider whether the broader formal context suggests the group should continue

# Context & Application
False closing sections exploit the listener's expectation that a PAC will be followed by postcadential codettas. The technique appears in three main contexts: (1) between subordinate themes in a group, (2) between main theme and transition, (3) at recapitulation-coda junction. The same material can function as false in one context and genuine in another (as in Mozart K. 543, ii).

# Examples
- Mozart, Symphony No. 39, K. 543, ii, mm. 54-59: PAC of subordinate theme elides with codetta-like material; 8-measure sentence emerges as second ST; when theme repeats at m. 60, the SAME ideas function as genuine codettas
- Haydn, String Quartet in B Minor, Op. 64/2, i, mm. 20-23: first ST ends PAC at m. 20; codetta-like idea over tonic pedal proves false when evaded cadence at m. 26 destroys closing-section impression
- Mozart, Piano Trio in D Minor, K. 442, iii, mm. 16-26: false closing section to main theme merges into transition

# Common Errors
- Identifying false closing sections in real-time rather than retrospectively
- Treating all codetta-like material after a PAC as a true closing section
- Missing the grouping-structure test for distinguishing true from false

# Common Confusions
- **False vs. true**: A false closing section is recognized only RETROSPECTIVELY -- at the moment of hearing, it sounds genuine
- **Context dependency**: The same musical material can function as false in one context and genuine in another
- **Grouping-structure test**: Codettas followed by larger unit = genuine closing section; followed by smaller (fragmenting) unit = false, beginning a transition or new theme
