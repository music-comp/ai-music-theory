# Quick Definition
A harmonic progression in which chords are linked by a consistent intervallic root pattern and melodic-contrapuntal design, projecting harmonic mobility independent of normal functional syntax, classified into six categories by root-motion interval.

# Core Definition
"Sequential progressions involve harmonies arranged according to a consistent intervallic pattern among the individual voices of the chords" (Ch. 2, p. 29). Their "fundamental purpose" is "to move the music away from, or return it to, a particular harmonic function or tonal center" (Ch. 2, p. 29). A sequential progression "normally begins with a chord that has a definite harmonic function within a key"; subsequent chords "are linked together according to a particular melodic-contrapuntal pattern and consistent root motion"; "the final chord restores a clear functional meaning" (Ch. 2, p. 29). Six categories based on root motion: descending/ascending fifths, thirds, and seconds.

- **Harmonic functions overview** -- the functional framework that sequences operate outside of

# Key Properties
1. Consistent root-motion pattern throughout
2. Consistent melodic-contrapuntal voice-leading pattern
3. Begins and ends on functionally clear harmonies
4. Six categories: descending fifth, ascending fifth, descending third, ascending third, descending second, ascending second
5. The same root progression can yield different contrapuntal patterns depending on voice distribution
6. May be embellished by chromatic alterations, added dissonances, chord inversions
7. Sequential progressions weaken harmonic-tonal clarity despite possible local functional implications
8. "Especially suitable for destabilizing harmonic activity" (Ch. 2, p. 29)

# Construction / Recognition
- Identify consistent root-motion interval
- Verify consistent voice-leading pattern
- Note the beginning and ending harmonies (should be functionally clear)
- Classify by root-motion category

# Context & Application
Sequential progressions are characteristic of continuation function, contrasting middles, transitions, and development sections. Their open-ended, forward-driving quality contrasts with the stability of prolongational progressions and the goal-directed quality of cadential progressions.

# Common Errors
- Classifying sequences by voice-leading pattern rather than root motion

# Common Confusions
- Sequential progressions weaken harmonic-tonal clarity despite having local functional implications at each link
- The same root-motion pattern can produce different contrapuntal patterns; sequences are more reliably classified by root motion
