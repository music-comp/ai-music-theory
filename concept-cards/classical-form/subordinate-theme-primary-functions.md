# Quick Definition
The subordinate theme serves three primary functions: (1) to contrast with the main theme through new melodic material and diverse motivic ideas, (2) to loosen the formal organization through extensions and expansions, and (3) to confirm the subordinate key with a perfect authentic cadence.

# Core Definition
The subordinate theme of a sonata exposition serves three primary functions: (1) To contrast with the main theme, in order to support thematically the tonal contrast of home and subordinate keys. Contrast is usually provided by new melodic-motivic material, though Haydn frequently opens subordinate themes with the main theme's basic idea (monothematic exposition). The opening material of many subordinate themes is tuneful and lyrical and set in a piano dynamic. But subordinate themes display diverse motivic ideas, and toward the end they tend to become highly energetic, dramatically charged, and dynamically aggressive. (2) To loosen the formal organization -- especially through extensions and expansions -- to give rhetorical and dramatic weight to the subordinate key. (3) To confirm the subordinate key with a perfect authentic cadence.

# Prerequisites
- **Subordinate theme**: The formal unit in question
- **Main-theme function in sonata**: The tight-knit model against which contrast is measured
- **Essential expositional closure**: The PAC fulfilling function 3

# Key Properties
1. Function 1 (contrast): new melodic material, diverse motivic ideas, initial lyrical/piano character
2. Function 1 exception: Haydn's monothematic expositions reuse the main theme's basic idea
3. The dynamic curve: opening is often lyrical/piano but ending is energetic/forte as PAC approaches
4. Function 2 (loosening): extensions, expansions, phrase-structural deviations
5. Function 3 (confirmation): the subordinate key must receive a PAC (the EEC)
6. The three functions are interdependent: loosening delays the PAC, making its achievement more dramatic
7. The subordinate theme does NOT modulate to the subordinate key (the transition does that)
8. The subordinate theme does NOT use ternary functions (exposition/contrasting middle/recapitulation)

# Construction / Recognition
- Identify new melodic material or reused material from the main theme
- Note the dynamic curve: does the theme begin quietly and build toward the cadence?
- Track the loosening techniques deployed
- Locate the confirming PAC (the EEC)
- Verify the theme is in the subordinate key throughout (unless it is a modulating subordinate theme)

# Context & Application
The three primary functions are interdependent and create the subordinate theme's characteristic formal trajectory. The contrast with the main theme supports the tonal contrast. The loosening delays and dramatizes the confirming PAC. And the PAC itself, when finally achieved, provides the powerful sense of subordinate-key confirmation that allows the key to "reign supreme" temporarily. Understanding these three functions is essential for analyzing any subordinate theme and for understanding why it is organized the way it is.

# Examples
- Beethoven, Piano Sonata in F minor, Op. 2/1, i, mm. 21-41 (Ch. 9, Ex. 9.3): new basic idea (actually inverted variant of MT), piano dynamic, presentation + extended continuation + expanded cadential with evasion, PAC at m. 41
- Haydn monothematic expositions: subordinate theme opens with the same basic idea as the main theme but treated in a looser fashion

# Common Errors
- Assuming the subordinate theme must always be lyrical throughout (only the opening tends to be lyrical)
- Confusing the subordinate theme's function with the transition's function (ST confirms; TR destabilizes)
- Treating the subordinate theme as merely a "second melody" rather than a functional unit with specific requirements

# Common Confusions
- **ST does not modulate**: The transition modulates to the subordinate key; the subordinate theme confirms it
- **Dynamic curve**: The opening is often lyrical/piano, but the theme builds toward an energetic, aggressive close -- the cadential drive is the climax
- **Monothematic exception**: In Haydn, using the same basic idea does not mean the subordinate theme is a mere repeat; the looser treatment is the distinguishing factor
