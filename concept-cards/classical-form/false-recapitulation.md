# Quick Definition
A passage in the development that begins like the recapitulation by restating the main theme's opening material but in the wrong key, creating a momentary illusion of return that eventually gives way to the true recapitulation.

# Core Definition
A retransition sometimes starts with reference to the opening material from the main theme, usually in the development key just confirmed by a prior half cadence. This effect can be characterized as a false recapitulation. The gesture is recapitulatory in melodic-motivic content, but the tonal requirements of a genuine recapitulation are not met (the material appears in the development key, not the home key). Eventually, the music modulates back to the home key for the true recapitulation. The music from the beginning of the false recapitulation to the real recapitulation thus functions as a retransition.

# Prerequisites
- **Development section**: The formal context
- **Retransition**: The false recapitulation functions as part of the retransition
- **Recapitulation**: The genuine return that the false recapitulation mimics

# Key Properties
1. Main theme's opening material restated in development key (not home key)
2. Creates momentary expectation of recapitulation
3. Recognized as "false" when music modulates rather than continuing in home key
4. Often appears after the core's concluding function
5. Functions as the beginning of the retransition
6. Eventually leads to the true recapitulation in the home key
7. The passage from false to real recapitulation constitutes the retransition

# Construction / Recognition
- Identify the return of main-theme opening material
- Verify the key: if NOT the home key, it is a false recapitulation
- Note the subsequent modulation to the home key
- Locate the true recapitulation (in the home key)
- The entire passage functions as a retransition

# Context & Application
False recapitulations are a dramatic device playing on the listener's expectations, particularly effective after long development sections where the desire for tonal return is acute. The false recapitulation delays the gratification of the true return, heightening its impact when it finally arrives.

# Examples
- Beethoven, Piano Sonata in G, Op. 14/2, i, m. 98 (ex. 10.20): after core concludes on dominant of Bb (HK: bIII), a new part begins like the main theme but in Bb; presentation followed by modulation back to G; HC in home key at m. 107; standing on dominant; real recapitulation at m. 125

# Relationships
## Builds Upon
- Retransition (the false recapitulation begins the retransition)
- Recapitulation (the formal event being falsely anticipated)

## Enables
- Heightened return (delays gratification of true recapitulation)
- Retransitional function (the false recap modulates to the home key)

## Related
- Main theme (the material being restated)
- Standing on the dominant (follows the retransition's HC)

## Contrasts With
- Recapitulation (true return in home key vs. false return in wrong key)

# Common Errors
- Treating every main-theme restatement in the development as a false recapitulation
- Confusing a pre-core beginning with main-theme material with a false recapitulation (different formal position)
- Missing the false recapitulation by focusing on key alone without noting the motivic return

# Common Confusions
- **False vs. true recapitulation**: The sole criterion is tonal -- the false recapitulation occurs in the wrong key
- **Deliberate device**: A false recapitulation is a deliberate dramatic device, not a compositional mistake
- **Not every main-theme reference**: Not every appearance of main-theme material in the development constitutes a false recapitulation -- it must occur in a position where the recapitulation might reasonably be expected
