# Quick Definition
The combination of a presentation phrase followed by a consequent phrase is conspicuously absent from the classical repertory. It would produce a threefold statement of the basic idea (twice in the presentation, once at the start of the consequent) within excessive tonic prolongation, creating undesirable redundancy.

# Core Definition
Of the logically possible ways in which the various phrases of the sentence and period can be combined to make a hybrid, one pattern is conspicuously absent — a theme that begins with a presentation and ends with a consequent. Such an arrangement brings a threefold statement of the basic idea within a single theme. The resulting redundancy of material within an excessive tonic prolongation likely explains why this potential type of hybrid seldom occurs in the repertory. The basic idea would appear in mm. 1-2 (statement), mm. 3-4 (response), and again in mm. 5-6 (consequent beginning), all substantially within the ambit of tonic harmony.

# Construction / Recognition
1. Presentation (mm. 1-4): basic idea stated and repeated (exact, statement-response, or sequential) — two statements
2. Consequent (mm. 5-8): basic idea returns for a third time + contrasting idea + PAC — third statement
3. The basic idea thus appears three times within eight measures
4. The first six measures would be dominated by tonic prolongation (presentation) plus a tonic-initiated consequent
5. This combination is theoretically possible but compositionally undesirable

# Context & Application
The absence of this type from the repertory is itself analytically significant — it reveals a compositional constraint operating in classical theme construction. The classical aesthetic values variety and forward motion; three statements of the same idea within tonic prolongation provides neither. Understanding why this type does not occur deepens one's appreciation of why the four hybrid types that do occur are each individually valuable.

# Common Confusions
- This type is not "forbidden" — it is simply redundant and therefore avoided by classical composers
- Do not confuse this absent type with hybrid type 4 (c.b.i. + consequent), which has only two statements of the basic idea (one in the c.b.i. and one in the consequent) — the c.b.i. uses a contrasting idea rather than repeating the basic idea
