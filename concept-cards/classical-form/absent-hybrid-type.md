# Quick Definition
The combination of a presentation phrase followed by a consequent phrase is conspicuously absent from the classical repertory. It would produce a threefold statement of the basic idea (twice in the presentation, once at the start of the consequent) within excessive tonic prolongation, creating undesirable redundancy.

# Core Definition
"Of the logically possible ways in which the various phrases of the sentence and period can be combined to make a hybrid, one pattern is conspicuously absent: a theme that begins with a presentation and ends with a consequent" (Ch. 4, p. 114). "Such an arrangement of phrases brings a threefold statement of the basic idea. The resulting redundancy of material within an excessive tonic prolongation likely explains why this potential type of hybrid rarely occurs in the repertory" (Ch. 4, p. 114). The basic idea would appear in mm. 1-2 (statement), mm. 3-4 (response), and again in mm. 5-6 (consequent beginning), all substantially within the ambit of tonic harmony.

# Prerequisites
- **Presentation function** -- the initiating phrase with basic idea repetition
- **Consequent** -- the concluding phrase that returns the basic idea
- **Hybrid themes overview** -- the general framework showing why this combination fails

# Key Properties
1. Logically possible but compositionally avoided
2. Would produce THREE statements of the basic idea in 8 measures
3. First six measures dominated by tonic prolongation (presentation + tonic-based consequent)
4. The redundancy of material is the primary reason for its absence
5. Not theoretically impossible -- just compositionally undesirable
6. Its absence reveals a compositional constraint in classical theme construction

# Construction / Recognition
1. Presentation (mm. 1-4): basic idea stated and repeated -- two statements
2. Consequent (mm. 5-8): basic idea returns for a third time + contrasting idea + PAC
3. The basic idea thus appears three times within eight measures
4. The first six measures would be dominated by tonic prolongation
5. This combination is theoretically possible but compositionally undesirable

# Context & Application
The absence of this type from the repertory is analytically significant -- it reveals a compositional constraint operating in classical theme construction. The classical aesthetic values variety and forward motion; three statements of the same idea within tonic prolongation provides neither. Understanding why this type does not occur deepens appreciation for why the four hybrid types that do occur are each individually valuable.

# Common Errors
- Assuming this type is "forbidden" by theoretical rule -- it is avoided by compositional practice, not theoretical prohibition
- Failing to recognize that its absence is informative about classical aesthetic values

# Common Confusions
- This type is not "forbidden" -- it is simply redundant and therefore avoided by classical composers
- Do not confuse this absent type with hybrid type 4 (c.b.i. + consequent), which has only two statements of the basic idea -- the c.b.i. uses a contrasting idea rather than repeating the basic idea
- The problem is specifically the *three* statements of the basic idea -- two statements (as in sentence, period, and hybrid 4) are acceptable
