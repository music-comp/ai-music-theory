# Quick Definition
A tonal area in the development that receives emphasis through tonicization but lacks the cadential confirmation needed to establish it as a true development key.

# Core Definition
Tonicized regions reside at the bottom of the tonal hierarchy. They do not receive cadential confirmation but can still acquire considerable structural importance if associated with an initiating formal function (such as a basic idea, presentation, or compound basic idea). When a tonicized region supports an initiating function, it can be termed an "initiating region." Tonicization differs from modulation in that the new tonic is disassociated from cadential articulation and is perceived as a localized tonal emphasis within a prevailing key. Very local tonicizations (brief chromatic inflections) lie at the very bottom of the hierarchy. In major-mode developments, both IV and bVI frequently serve as initiating regions.

# Prerequisites
- **Tonal hierarchy in development**: The ranking system
- **Development key**: The higher-level category requiring cadential confirmation

# Key Properties
1. Lacks cadential confirmation (no HC, PAC, or dominant arrival in the region)
2. May be associated with initiating function (becoming an "initiating region")
3. Regions arising from sequential activity have less structural potential
4. Very local tonicizations (chromatic inflections) lie at the very bottom
5. In major: IV and bVI frequently serve as initiating regions
6. A tonicized region can be "promoted" to a key if cadential confirmation follows
7. Duration does not determine tonal rank -- only cadential confirmation does

# Construction / Recognition
- Identify tonal emphasis lacking cadential confirmation
- Check whether the region supports an initiating function (basic idea, presentation)
- If so, it is an "initiating region" with greater structural weight
- Distinguish from development keys (which receive cadential confirmation)
- Note that sequential regions have less structural potential than initiating regions

# Context & Application
Not every development confirms a development key -- shorter developments may rely entirely on tonicized regions for tonal contrast. The distinction between tonicized regions and development keys provides analytical precision in discussing the development's tonal plan.

# Examples
- Mozart, String Quintet in E-flat, K. 614, i (ex. 10.6): Ab major (HK: IV) serves as an initiating region for the core model -- no cadential confirmation in Ab, but it supports the model's presentation

# Common Errors
- Treating prominent tonicized regions as development keys (cadential confirmation is required)
- Ranking tonal levels by duration rather than cadential confirmation
- Conflating sequential tonicizations with initiating regions

# Common Confusions
- **Tonicization vs. modulation**: Tonicization lacks cadential confirmation; modulation confirms the key
- **Duration vs. rank**: A region emphasized by duration but lacking cadential confirmation remains a tonicization
- **Promotion**: A tonicized region can be "promoted" to a key if subsequent cadential confirmation follows
- **Initiating vs. sequential regions**: Regions supporting initiating functions have greater structural weight than regions arising from sequential activity
