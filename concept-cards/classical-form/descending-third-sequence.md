# Quick Definition
A sequential progression with descending-third root motion, most often embellished by stepwise passing chords that create intervening dominant-like chords between each main harmony, producing a powerful tension-building effect.

# Core Definition
The unembellished form is relatively plain. "More often, however, the leap in the bass voice is filled in by stepwise motion, which produces intervening passing chords in first inversion" (Ch. 2, p. 31). These passing chords introduce "a degree of harmonic functionality: since each root-position harmony is followed by a passing chord whose fundamental is a fifth above (or fourth below), the latter stands as a 'dominant' in relation to the former" (Ch. 2, p. 31). When the passing chords are placed in root position, they become "genuine secondary dominants" (Ch. 2, p. 31), and the sequence gains a "powerful tension-building effect" (Ch. 2, p. 32).

# Prerequisites
- **Sequential progression** -- the broader category

# Key Properties
1. Root motion: consistently descending thirds
2. Embellished form: stepwise bass fills the descending third with first-inversion passing chords
3. Passing chords function as "dominants" of the following main chord
4. Root-position passing chords emphasize the dominant-tonic analogy
5. Creates powerful tension-building effect when passing chords tonicize each member

# Construction / Recognition
- Descending-third root motion
- Check for intervening passing chords (especially in first inversion)
- Root-position passing chords = secondary dominants = strongest tension

# Context & Application
Descending-third sequences create tension, especially with chromatic secondary dominants. They appear in continuation phrases, development sections, and transitions.

# Examples
**Example 1** (Ch. 2, ex. 2.13a): Unembellished: simple root-position chords descending by thirds.
**Example 2** (Ch. 2, ex. 2.13b-c): Embellished: first-inversion passing chords filling the bass gap.

# Common Errors
- Treating the passing chords as independent members of the sequence

# Common Confusions
- The passing chords are contrapuntal fill between main harmonic stations, not independent sequential members
- When chromatically altered to genuine secondary dominants, the character changes significantly
