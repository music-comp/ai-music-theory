# Quick Definition
A sequential progression with descending-third root motion, most often embellished by stepwise passing chords that create intervening dominant-like chords between each main harmony of the sequence.

# Formal Definition
The descending-third sequential progression features chords whose roots descend by thirds. The unembellished form is relatively plain. More often, the leap in the bass is filled in by stepwise motion, which produces intervening passing chords in first inversion. These passing chords introduce a degree of harmonic functionality: since each root-position harmony is followed by a passing chord whose root is a fifth above (or fourth below), the passing chord stands as a "dominant" in relation to the following root-position chord. When the root-position harmony is a tonic, the passing chord is its literal dominant; when it is another scale-degree, the passing chord is a dominant "by analogy." This functional interpretation becomes even more evident when the passing chords are placed in root position.

# Construction/Recognition
- Root motion: consistently descending thirds
- Unembellished form: simple descent by thirds (ex. 2.13a)
- Embellished form: stepwise bass fills the descending third, creating first-inversion passing chords (ex. 2.13b-c)
- Passing chords function as "dominants" of the following root-position chord
- Placing passing chords in root position emphasizes the dominant-tonic analogy (ex. 2.13d)
- Creates a powerful tension-building effect when the dominant-like passing chords tonicize each member

# Musical Context
Descending-third sequences create a powerful tension-building effect, especially when the passing chords tonicize each successive harmony. They appear in continuation phrases, development sections, and transitions.

# Examples
- Unembellished: simple root-position chords descending by thirds (ex. 2.13a)
- Embellished with passing chords: first-inversion chords filling the bass gap (ex. 2.13b-c)
- With root-position passing chords creating explicit tonicizations (ex. 2.13d)

# Common Confusions
- The passing chords in an embellished descending-third sequence are not independent harmonies in the sequence proper; they are contrapuntal fill between the main harmonic stations.
- When these passing chords are chromatically altered to become genuine secondary dominants, the sequence gains a strong tension-building character.
