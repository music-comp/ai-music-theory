# Quick Definition
The optional coda in a large ternary form follows the return of the main theme and serves a special compensatory function: it is the only place where the composer can reference material from the interior theme, which cannot be accommodated within the main theme's return.

# Core Definition
Following the return of the main theme, which normally brings back the same basic structure and musical content of the original main theme, the composer may add an after-the-end formal function, either a simple closing section following the final PAC or a full-fledged coda. One particular advantage of the coda in a large ternary is that it allows the composer to reference material from the interior theme that would otherwise not be possible within the general plan of the large ternary form. Since the return of the main theme simply restates the original main theme, there is no structural opportunity to incorporate interior-theme material within the return. The coda thus provides the logical place for such material.

# Prerequisites
- **Large ternary form**: The formal context
- **Coda**: The formal function being described
- **Compensatory functions**: The role the coda serves

# Key Properties
1. Follows the return of the main theme (after the final PAC)
2. May be a simple closing section or a full-fledged coda
3. Special function: referencing interior-theme material
4. The main theme's return cannot accommodate interior-theme material
5. The coda is the only place for such material in the large ternary
6. May also bring other compensatory functions (circular effect, implication realization)
7. The coda may bring back the opening material for circular effect

# Construction / Recognition
- Identify the final PAC of the returned main theme
- Note any material following this PAC
- Check whether the material references the interior theme
- Observe whether the coda brings back main-theme ideas for circular effect
- Note any expanded cadential progressions or other structural expansion

# Context & Application
The coda in a large ternary serves a parallel role to the coda in sonata form: both address secondary processes that cannot be completed within the main body of the form. The large ternary coda has a distinctive advantage: it is the only way to "recapitulate" interior-theme material, since the return of the main theme is structurally committed to restating the original main theme.

# Examples
- Beethoven, Piano Sonata in E-flat, Op. 7, ii, mm. 72-90 (ex. 17.9): coda begins at m. 74 after the main theme's final PAC; left hand brings back interior-theme material (from Ex. 17.8, mm. 25ff.) now in the home key of C major; a separate coda theme follows with further development of the main theme's dotted motive; closing section in high register; then return of main theme's opening ideas with chromatic bass descent (circular effect + realization of F-sharp resolution)

# Common Errors
- Expecting the large ternary coda to function like a sonata coda (different compensatory needs)
- Missing the interior-theme reference (the coda's distinctive contribution)
- Treating the coda as merely a closing section

# Common Confusions
- **Coda vs. closing section**: A coda contains thematic units ending with PAC; a closing section consists of codettas
- **Interior-theme reference**: Material from the minore interior theme is transposed into the home key's major mode
- **Circular effect**: The return of main-theme opening ideas at the very end creates formal circularity
