# Quick Definition
The hierarchical arrangement of discrete, perceptually significant time spans in a musical work, identified by measure length and content relationships, which constitutes the temporal skeleton distinct from formal function.

# Core Definition
Grouping structure describes the form of a musical work as "a hierarchical arrangement of discrete, perceptually significant time spans" (Ch. 1, p. 9). Each group is a self-contained "chunk" of music at one level of the hierarchy, identified most neutrally by its measure length. Groups combine hierarchically: a two-measure idea groups with another to form a four-measure phrase, which groups with another phrase to form an eight-measure theme. Grouping structure and formal function are conceived as "different, yet interactive, dimensions of musical form" (Introduction, p. 5).

# Prerequisites
None -- this is a foundational descriptive concept.

# Key Properties
1. Groups are identified neutrally by measure length
2. Groups nest hierarchically: ideas within phrases, phrases within themes, themes within sections
3. Symmetrical groupings (4 + 4, 8 + 8) characterize tight-knit organization
4. Asymmetrical groupings characterize loose organization (created by extensions, expansions, compressions, interpolations)
5. Letter labels (A, B, A') indicate content similarity/difference between groups
6. Grouping structure is distinct from formal function: they are often congruent but need not be

# Construction / Recognition
- Identify groups by their measure lengths and boundaries
- Recognize hierarchical nesting
- Note symmetrical vs. asymmetrical groupings
- Use letter labels for content relationships
- Distinguish grouping from functional analysis

# Context & Application
Grouping structure provides the temporal skeleton of a work. In classical music, symmetrical groupings (especially 4 + 4 at the phrase level) are normative for tight-knit themes, while asymmetrical groupings characterize looser formal regions like transitions and subordinate themes.

# Examples
**Example 1** (Ch. 1): A typical sentence: 2 + 2 + 4 grouping (basic idea + repetition + continuation).
**Example 2** (Ch. 1): A typical period: 4 + 4 grouping (antecedent + consequent).
**Example 3** (Ch. 1, p. 20): Beethoven, Op. 2/1, i, subordinate theme: asymmetrical 4 + 8 + 4 + 5 grouping; adding seven measures of closing section (2 + 2 + 3) further extends the asymmetry.

## Related

## Contrasts With
- Formal function: a single group may express multiple functions (e.g., continuation and cadential fuse in one phrase); multiple groups may express a single function (e.g., several distinct phrases supported by one expanded cadential progression)

# Common Errors
- Equating grouping labels directly with formal functions
- Assuming symmetrical groupings are always normative (asymmetry is appropriate for loose formal regions)

# Common Confusions
- Grouping structure and formal function are not the same thing. Traditional theories often assign a single functional label to each group, but Caplin shows that function and group can be incongruent
- Formal function arises from harmonic, melodic, and rhythmic processes not necessarily identical to those creating grouping structure
