# Quick Definition
A loosening technique in which additional material is appended after a formal function has already been expressed, stretching the passage beyond its normative length.

# Formal Definition
Extension results from "adding on" material to stretch out a particular formal function in time. Continuation extension occurs when additional fragmented units appear beyond the minimum needed. Cadential extension occurs when an implied cadence fails and the cadential phrase is repeated.

# Construction/Recognition
- Identify the point at which a function has been fully expressed
- Material beyond that point continuing the same function = extension
- Continuation extension: extra fragmented units beyond minimum
- Cadential extension: repetition of cadential phrase after evasion

# Musical Context
Extension is a primary loosening technique in subordinate themes, transitions, and development sections, creating asymmetrical groupings.

# Examples
- Beethoven, Op. 2/1, i, mm. 25-32: continuation extended five measures beyond the two needed
- Beethoven, Op. 2/1, i, mm. 33-41: cadential phrase extended by repetition after evasion at m. 37

# Common Confusions
- Extension adds on after a function is expressed; expansion stretches from within. They are different processes.
