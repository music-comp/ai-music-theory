# Quick Definition
A loosening technique in which additional material is appended after a formal function has already been expressed, stretching the passage beyond its normative length from without.

# Core Definition
"Extension results from 'adding on' material to stretch out a particular formal function in time" (Ch. 1, p. 20). "Continuation phrases are frequently extended when more units of fragmentation are included in the phrase than are necessary to express the function" (Ch. 1, p. 20). Cadential extension occurs "when an implied cadence fails to materialize, and the function is repeated in order to achieve the cadential goal" (Ch. 1, p. 21). Extension adds material AFTER a function has been expressed.

# Prerequisites
- **Continuation function** and **cadential function** -- the functions most commonly extended
- **Tight-knit vs. loose organization** -- extension is a loosening technique

# Key Properties
1. Material is appended AFTER the function has already been expressed
2. Continuation extension: extra fragmented units beyond the two-measure minimum
3. Cadential extension: repetition of cadential phrase after failed cadence (evasion, deception)
4. Creates asymmetrical phrase groupings
5. Delays the expected formal goal, making its eventual arrival more powerful
6. Distinct from expansion (which stretches from within)

# Construction / Recognition
- Identify the point at which a function has been fully expressed (e.g., after two measures of fragmentation)
- Material beyond that point continuing the same function = extension
- For cadential extension: look for failed cadences that motivate repetition

# Context & Application
Extension is a primary loosening technique in subordinate themes, transitions, and development sections, creating the asymmetrical groupings characteristic of loose organization.

# Examples
**Example 1** (Ch. 1, p. 20): Beethoven, Op. 2/1, i, mm. 25-32: continuation function manifest by end of m. 27 (two measures of fragmentation); Beethoven extends the phrase by five more measures (mm. 28-32), "significantly loosening the functional expression."
**Example 2** (Ch. 1, p. 21): Beethoven, Op. 2/1, i, mm. 33-41: cadential evasion at m. 37 motivates repetition of the entire cadential phrase, extending cadential function by an additional four measures.

# Relationships
## Builds Upon
- Continuation and cadential function (the functions being extended)
## Enables
- Loose organization through asymmetrical phrase groupings
## Related
- Expansion (the complementary loosening technique)
- Subordinate theme (primary context for extension)
## Contrasts With
- Expansion: extension adds on from WITHOUT (appending material); expansion stretches from WITHIN (internal lengthening of components)

# Common Errors
- Confusing extension with expansion

# Common Confusions
- Extension adds on AFTER a function is expressed; expansion stretches FROM WITHIN. They are different processes that can co-occur
