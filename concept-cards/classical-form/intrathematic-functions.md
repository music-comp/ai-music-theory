# Quick Definition
The formal functions operating within individual themes -- presentation, continuation, cadential, antecedent, consequent, exposition, contrasting middle, recapitulation -- linked in a conventionalized syntactic order.

# Core Definition
Intrathematic functions are "the functional constituents of individual themes -- the formal properties of the various phrases or sections associated with a single thematic unit" (Ch. 1, p. 17). They are "linked together in a specified order and thus establish a kind of 'syntax' of formal organization. Thus, a typically syntactical sequence of functions -- presentation, continuation, cadential, and closing section -- creates a theme conforming to the formal conventions of music in the classical style. Conversely, the following succession of functions -- continuation, closing section, cadential, presentation, and introduction -- is entirely nonsyntactic and unstylistic" (Ch. 1, p. 17).

# Prerequisites
- **Formal function** -- the broader concept of which intrathematic functions are a subset

# Key Properties
1. Defined primarily by underlying harmonic progressions in a given key
2. Follow a conventionalized syntactic order within each theme type
3. Sentence: presentation -> continuation -> cadential
4. Period: antecedent -> consequent
5. Small ternary: exposition -> contrasting middle -> recapitulation
6. Nonsyntactic orderings are "unstylistic"

# Construction / Recognition
- Identify the theme type
- Verify that the constituent functions appear in syntactical order
- Note any deviations from the conventional ordering

# Context & Application
Every classical theme is built from intrathematic functions. The three principal theme types each contain specific sets. Understanding intrathematic syntax is essential before moving to interthematic functions (relationships between themes).

# Examples
**Example 1** (Ch. 1, p. 17): Beethoven, Op. 2/1, i, mm. 1-8: presentation (mm. 1-4) -> continuation/cadential (mm. 5-8) -- syntactic ordering.
**Example 2** (Ch. 1, p. 17): Mozart, K. 525, ii, mm. 1-8: antecedent (mm. 1-4) -> consequent (mm. 5-8) -- syntactic ordering.

## Contrasts With
- Interthematic functions: intrathematic operate within a single theme and are defined by local harmonic progressions; interthematic operate between themes and involve tonal (key) relationships

# Common Errors
- Confusing intrathematic with interthematic levels of analysis

# Common Confusions
- Intrathematic functions are determined by local harmonic progressions in a given key; interthematic functions are determined by tonal relationships between keys
