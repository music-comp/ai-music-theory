# Quick Definition
The formal functions that operate within the boundaries of individual themes, such as presentation, continuation, cadential, antecedent, and consequent.

# Formal Definition
Intrathematic functions are the functional constituents of individual themes--the formal properties of the various phrases or sections associated with a single thematic unit. These functions are linked together in a specified order and establish a kind of "syntax" of formal organization. A syntactical sequence such as presentation-continuation-cadential creates a theme conforming to the formal conventions of classical style. Conversely, a nonsyntactical ordering (e.g., continuation-closing section-cadential-presentation) would be entirely unstylistic.

# Construction/Recognition
- Defined primarily by their underlying harmonic progressions in a given key
- Follow a conventionalized syntactic order within each theme type
- Sentence: presentation -> continuation -> cadential
- Period: antecedent -> consequent
- Small ternary: exposition -> contrasting middle -> recapitulation

# Musical Context
Every classical theme is built from intrathematic functions. The three principal theme types each contain specific sets: the sentence has presentation, continuation, and cadential; the period has antecedent and consequent; the small ternary has exposition, contrasting middle, and recapitulation.

# Examples
- Beethoven, Op. 2/1, i, mm. 1-8: presentation (mm. 1-4) -> continuation/cadential (mm. 5-8)
- Mozart, K. 525, ii, mm. 1-8: antecedent (mm. 1-4) -> consequent (mm. 5-8)

# Common Confusions
- Intrathematic functions operate within a single theme and are defined by local harmonic progressions; interthematic functions operate between themes and involve tonal (key) relationships.
