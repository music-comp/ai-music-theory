# Quick Definition
Contrary to the 19th-century stereotype of a "masculine" main theme, many classical main themes actually exhibit hesitancy and uncertainty through sudden textural changes, rhythmic discontinuities, and marked changes in dynamics -- yet they retain sufficient cadential and phrase-structural solidity to function as the formal beginning.

# Core Definition
Since the mid-19th century, when A. B. Marx proposed the notorious distinction between a "masculine" main theme and a "feminine" subordinate theme, listeners have believed that a main theme features a highly charged, aggressively assertive character. Some sonata forms (especially symphonies and minor-mode works in Sturm und Drang style) conform to this stereotype. But an examination of the broader classical repertory suggests, on the contrary, that main themes frequently exhibit a hesitancy and sense of uncertainty: they commonly bring sudden, striking changes in texture, dynamics, and articulation, along with marked discontinuities in rhythmic momentum. It is often not until the beginning of the transition that the movement seems finally to "get under way." Despite these textural instabilities, the main theme still contains sufficient tonal, cadential, and phrase-structural solidity to function as the true formal beginning of the exposition. We must be careful not to confuse such main themes with an actual introduction.

# Key Properties
1. The 19th-century masculine/feminine stereotype is inadequate for the classical repertory
2. Many main themes exhibit hesitancy, uncertainty, textural discontinuity
3. Sudden changes in texture, dynamics, articulation, and rhythm are common
4. The movement often seems to "get under way" only at the transition
5. Despite surface instabilities, the main theme has cadential and tonal solidity
6. An "introductory" character does NOT make a main theme an actual introduction
7. Some main themes do feature lyrical, songlike character (normally associated with subordinate themes)
8. Main themes may combine "masculine" and "feminine" styles (e.g., Mozart K. 543, Ex. 10.8)

# Construction / Recognition
- Listen for textural, dynamic, and rhythmic discontinuities in the main theme
- Note sudden changes in articulation (staccato to legato), register, or texture
- Observe whether the movement seems to "get under way" only at the transition
- Despite these surface features, verify cadential and tonal solidity (genuine cadence, home-key confirmation)
- Do not confuse hesitant main themes with actual introductions

# Context & Application
Understanding the true character range of main themes is important for avoiding the 19th-century stereotype. The hesitancy and uncertainty of many main themes actually serve a compositional purpose: they create a sense of potential that is then realized in the transition and subordinate theme. The energy of the movement builds across the exposition rather than being established from the very first note. This progressive intensification is a hallmark of classical sonata form.

# Examples
- Beethoven, Piano Sonata in A, Op. 2/2, i (Ch. 10, Ex. 10.7): basic idea with diverse durational values and articulations, followed by rest; "continuation" brings staccato quarter notes, again stopping; steady eighths at m. 9 yield to polyphonic texture; regular changes throughout
- Mozart, Symphony No. 39, K. 543, i (Ch. 10, Ex. 10.8): first main theme has clearly "feminine" character, juxtaposed with "masculine" second main theme
- Some main themes feature the lyrical, songlike character associated with subordinate themes (Ex. 10.9)

# Common Errors
- Applying the masculine/feminine stereotype to all classical sonata forms
- Confusing a hesitant main theme with an actual introduction
- Assuming the movement's energy level should be established in the main theme

# Common Confusions
- **Main theme vs. introduction**: A main theme with introductory character has cadential substance and phrase-structural solidity; an actual introduction typically lacks these features
- **Masculine/feminine**: The 19th-century gendered terminology is inadequate; form-functional analysis (tight-knit vs. loose) provides a better framework for understanding the contrast
- **Character diversity**: Main themes can be hesitant, lyrical, assertive, or all of these in succession
