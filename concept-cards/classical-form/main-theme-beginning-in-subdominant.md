# Quick Definition
A deviation where the main theme returns at the recapitulation in the subdominant rather than the home-key tonic, raising questions about whether a true recapitulation function is expressed.

# Formal Definition
The "double return" of the main theme and the home key is often cited as a hallmark of classical sonata form. But a few examples see the main theme return in the context of subdominant harmony. Like the deletion of opening main-theme ideas, the use of the subdominant in place of the tonic at this point has antecedents in baroque and preclassical practice. When the recapitulation begins in the subdominant, a tonic setting of the main theme or ideas derived from it may appear later in the movement, most likely in the coda.

# Construction/Recognition
- Main theme returns with recognizable material but in IV rather than I
- May emerge from the development's tonal context (especially if the development emphasizes the subdominant area)
- The listener may not initially perceive this as the recapitulation
- A tonic-key version of the main theme typically appears later (usually in the coda)
- Raises questions about the "double return" paradigm

# Musical Context
This deviation is relatively rare in the high classical style but connects to earlier 18th-century practices. It creates an ambiguity about the formal boundary between development and recapitulation.

# Examples
- Beethoven, Overture to Coriolanus, Op. 62 (ex. 11.17): development centered on subdominant; main theme returns at m. 152 still in the subdominant; listener recognizes the recapitulation only in retrospect as music continues with adjusted transition and subordinate theme; main-theme material in the tonic returns in the coda (ex. 12.6, m. 276)

# Common Confusions
- A subdominant-key main theme in the recapitulation is not the same as subdominant emphasis in the development — the key is whether subsequent events confirm this as the recapitulation's beginning
- The subdominant beginning does not mean the entire recapitulation is in the subdominant; subsequent material is adjusted to the home key
- This is a deviation from the norm, not a norm itself
