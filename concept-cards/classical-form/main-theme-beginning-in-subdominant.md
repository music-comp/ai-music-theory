# Quick Definition
A deviation where the main theme returns at the recapitulation in the subdominant rather than the home-key tonic, raising questions about whether a true recapitulation function is expressed.

# Core Definition
The "double return" of the main theme and the home key is often cited as a hallmark of classical sonata form. But a few examples see the main theme return in the context of subdominant harmony. Like the deletion of opening main-theme ideas, the use of the subdominant in place of the tonic at this point has antecedents in baroque and preclassical practice. The question of whether a true recapitulation function is at hand is raised by this tonal procedure. When the recapitulation begins in the subdominant, a tonic setting of the main theme or ideas derived from that theme may appear later in the movement, most likely in the coda.

# Prerequisites
- **Recapitulation**: The formal context for this deviation

# Key Properties
1. Main theme returns with recognizable material but in IV rather than I
2. Challenges the "double return" paradigm
3. Has antecedents in baroque and preclassical practice
4. The listener may not initially perceive this as the recapitulation
5. The recapitulation is recognized in retrospect as the music continues
6. A tonic-key version of the main theme typically appears later (usually in the coda)
7. The development may have been centered on the subdominant, facilitating this beginning
8. Subsequent material (transition, subordinate theme) is adjusted to the home key

# Construction / Recognition
- Main theme returns with familiar material but supported by subdominant harmony
- May emerge from the development's tonal context (especially if development emphasizes IV)
- Subsequent transition and subordinate theme are adjusted to the home key
- Look for tonic-key main-theme material in the coda

# Context & Application
This deviation is relatively rare in the high classical style but connects to earlier 18th-century practices. It creates ambiguity about the formal boundary between development and recapitulation. The listener may only understand retrospectively that the recapitulation has begun.

# Examples
- Beethoven, Overture to Coriolanus, Op. 62 (ex. 11.17): development centered on subdominant (and briefly VI, III); at m. 152 the opening material returns, still in the subdominant, within a broad model-sequence plan; listener recognizes the recapitulation only in retrospect; main-theme material in the tonic returns in the coda (ex. 12.6, m. 276)

# Common Errors
- Confusing a subdominant main-theme return in the recapitulation with subdominant emphasis in the development

# Common Confusions
- **Retrospective recognition**: The listener may not realize the recapitulation has begun until subsequent events (transition, subordinate theme) confirm it
- **Not the entire recapitulation**: The subdominant beginning does not mean the entire recapitulation is in the subdominant; subsequent material is adjusted to the home key
- **Distinct from deletion**: This is a different deviation from deleting the main theme; here the material is present but in the wrong key
