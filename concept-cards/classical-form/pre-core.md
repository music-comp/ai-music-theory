# Quick Definition
The opening passage of a development section that precedes and sets up the core, typically more relaxed and quiet than the dramatic core that follows -- "the calm before the storm."

# Core Definition
A development section does not normally start with a core, as the dramatic character projected by a core usually requires it to be set up by material of lesser emotional intensity. Ratz refers to this opening passage as an "introduction" (Einleitung), but Caplin uses the neutral term "pre-core" instead, since "introduction" has a restricted form-functional meaning in his theory and no single functional label adequately covers the many different formal procedures that can precede a core. The pre-core typically begins with tonic of the subordinate key, retaining the harmony from the end of the exposition. It may remain in that key or modulate to a development key for the beginning of the core.

# Prerequisites
- **Development section**: The formal context
- **Core technique**: The passage the pre-core sets up

# Key Properties
1. Does not normally begin with core-like dramatic intensity
2. Generally more relaxed, hesitant, and anticipatory
3. Dynamic level tends to be soft
4. Rhythmic motion frequently discontinuous (or less active than the core)
5. "The calm before the storm"
6. Begins with tonic of subordinate key (retaining harmony from exposition end) or in a different key
7. May modulate to a development key for the core's beginning
8. Three main opening material sources: main theme's basic idea, closing section material, new material (especially Mozart)
9. Four phrase-structural types: complete tight-knit, complete transition-like, incomplete, multiple units

# Construction / Recognition
**Beginning material**:
1. Main theme's basic idea (most common; links exposition repeat to development)
2. Closing section material (promotes continuity from exposition end)
3. New material (Mozart especially; no direct continuity; acts as foil for later familiar ideas)

**Phrase-structural types**:
1. Complete tight-knit (sentence, period, hybrid -- like a new main theme but in different key)
2. Complete transition-like (modulating, sentential, ending on dominant of development key)
3. Incomplete (one or two intrathematic functions, usually lacking conclusion; tends to be short)
4. Multiple units (two thematic units, usually one complete and one incomplete)

# Context & Application
The pre-core establishes continuity from the end of the exposition into the development. When beginning with the main theme's basic idea, it varies the link between exposition end and main theme created by the exposition repeat. A transition-like pre-core may contain limited model-sequence technique, but the model must be small enough not to suggest a genuine core. An incomplete pre-core may consist of just a transitional introduction on dominant harmony.

# Examples
- Beethoven, Piano Sonata in G, Op. 14/2, i, mm. 64-80 (ex. 10.11): two-part pre-core -- first part like main theme but in parallel minor; second part brings first subordinate theme's compound basic idea
- Haydn, Piano Sonata in E-flat, Hob. XVI:49, i, mm. 65-84 (ex. 10.12): transition-like pre-core with polyphonic "learned" style; modulates to development key
- Mozart, Piano Sonata in B-flat, K. 333, i, mm. 64-71 (ex. 10.13): tight-knit sentential pre-core in subordinate key
- Mozart, String Quintet in E-flat, K. 614, i (ex. 10.6): incomplete pre-core as transitional introduction on dominant

# Common Errors
- Calling the pre-core an "introduction" (has restricted meaning in Caplin's theory)
- Confusing a transition-like pre-core with the core itself (model must be too small for genuine core)
- Assuming all pre-cores begin with main-theme material

# Common Confusions
- **"Pre-core" vs. "introduction"**: Caplin avoids "introduction" because it has specific form-functional meaning; "pre-core" is a neutral term
- **Transition-like pre-core vs. core**: If the model-sequence technique in the pre-core uses models small enough (one measure), it does not suggest a genuine core
- **Pre-core as independent entity**: A pre-core's presentation phrase may group more intimately with the core than with the rest of the pre-core
