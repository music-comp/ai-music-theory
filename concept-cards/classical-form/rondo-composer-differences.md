# Quick Definition
Haydn, Mozart, and Beethoven treat rondo forms distinctively: Haydn favors five-part rondos with interior-theme first couplets; Mozart prefers subordinate-theme complexes and uses double-region couplets; Beethoven expands tonal range and favors false recapitulations.

# Core Definition
Each of the three classical composers treats rondo forms somewhat differently. Haydn prefers the five-part rondo over the sonata-rondo and normally writes the first couplet as an interior theme (reflecting his preference for large ternary slow movements). Mozart, on the contrary, favors subordinate-theme complexes for the first couplet (reflecting his preference for sonata without development slow movements). For the second couplet's tonal region in the five-part rondo, Haydn favors a minore, Mozart the subdominant. Mozart, more than Haydn or Beethoven, eliminates one refrain of the sonata-rondo and is the principal composer to employ a genuine double-region couplet. Beethoven tends to conform to standard models but expands the range of usable tonal areas and favors false recapitulations within rondos -- a device rarely found in Haydn and never in Mozart (Caplin, p. 686).

# Prerequisites
- **Five-part rondo** -- One of the two main rondo forms
- **Sonata-rondo** -- The other main rondo form

# Key Properties
1. Haydn: prefers five-part rondo; first couplet as interior theme; second couplet in minore
2. Mozart: prefers subordinate-theme complex for first couplet; second couplet in subdominant; uses double-region couplets; eliminates refrains
3. Beethoven: expands tonal range; favors false recapitulations; generally follows standard models
4. These preferences correlate with each composer's slow-movement form preferences

# Construction / Recognition
1. In a Haydn rondo, expect the first couplet to be an interior theme
2. In a Mozart rondo, expect a subordinate-theme complex and possible refrain omission
3. In a Beethoven rondo, look for expanded tonal palette and false recapitulations

# Context & Application
These composer-specific tendencies provide interpretive guidelines for analysis. Knowing which composer wrote a piece can help generate expectations about its formal organization, though exceptions always exist.

# Common Errors
- **Error**: Applying one composer's norms to another. **Correction**: Each composer has distinct tendencies; a Haydn rondo should not be analyzed with Mozartean expectations.

# Common Confusions
- **Confusion**: Whether these are strict rules or tendencies. **Clarification**: These are tendencies and preferences, not absolute rules; exceptions exist.
