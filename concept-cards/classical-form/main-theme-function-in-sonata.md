# Quick Definition
The main theme of a sonata exposition establishes the home key, introduces the principal melodic-motivic ideas, and defines tight-knit organization as a baseline for comparison with looser units.

# Formal Definition
The main theme of a sonata exposition is most often constructed as a conventional theme-type (sentence, period, hybrid, small ternary, or small binary). It must reside primarily in the home key. Most main themes end with a PAC, rarely an IAC. A main theme may also end with a HC as long as there has been no internal modulation. Main themes in minor mode often close with HC, matching the unsettled emotional quality. Unlike subordinate themes, main themes normally remain in a single mode. Many main themes exhibit hesitancy or uncertainty — sudden textural changes and rhythmic discontinuities — yet retain sufficient tonal, cadential, and phrase-structural solidity to function as the true formal beginning.

# Construction/Recognition
- Built as sentence, period, hybrid, small ternary, small binary, or nonconventional type
- Resides primarily in the home key (transient modulations may occur but the key returns)
- Ends with PAC (most common), IAC (rare), or HC (common in minor mode)
- May be followed by a closing section (codettas) after PAC, or standing on the dominant after HC
- May have a "main-theme group" with two themes, both ending PAC in HK
- Often displays an "introductory" character (hesitancy, textural gaps) that should not be confused with an actual introduction
- A significant minority of main themes are nonconventional

# Musical Context
The main theme's tight-knit organization provides the standard against which the looser organization of the subordinate theme is measured. Its establishment of the home key provides the tonal stability that the transition will subsequently destabilize.

# Examples
- Haydn, String Quartet in G Minor ("Rider"), Op. 74/3, iv (ex. 13.1): eight-measure nonconventional theme (2+3+3)
- Mozart, Symphony No. 38 ("Prague"), K. 504, i (ex. 13.2): nonconventional theme moving directly from introduction to continuation
- Haydn, Symphony No. 97 in C, i (ex. 13.4): tonic-pedal fanfare theme

# Common Confusions
- A main theme with an "introductory" character is not an actual introduction — it contains cadential and phrase-structural substance
- A main theme ending with HC does not mean the home key is unconfirmed — partial confirmation is sufficient in the exposition
- If a second theme ends with HC, it destabilizes the home key and functions as a transition, not a second main theme
