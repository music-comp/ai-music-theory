# Quick Definition
A return of the rondo refrain that brings back only the A (or A') section of an original small ternary main theme, concluding with a home-key PAC but omitting the B and subsequent sections.

# Core Definition
When the rondo refrain is originally built as a small ternary, a return of the refrain may bring back only the A (or A') section, concluding with a home-key PAC. This shortened version is termed an abridged refrain. The abridged refrain retains cadential closure in the home key, distinguishing it from an incomplete refrain, which either lacks cadential closure or concludes with a cadence in some other tonal region (Caplin, p. 677).

# Prerequisites
- **Refrain (rondo)** -- The thematic element being abbreviated
- **Refrain return types** -- The broader category
- **Small ternary** -- The typical form of the original refrain

# Key Properties
1. Returns only the A (or A') section of a small ternary refrain
2. Concludes with a PAC in the home key
3. Omits B and A' sections of the original ternary
4. Retains structural closure (unlike incomplete refrain)

# Construction / Recognition
1. Compare the returning refrain with the original
2. Determine whether the full small ternary or only its A section returns
3. Verify that the returned section closes with a home-key PAC
4. If PAC is present, the refrain is abridged; if absent, it is incomplete

# Context & Application
Abridged refrains are a practical way to avoid redundancy in movements with multiple refrain returns while maintaining the formal closure needed for structural integrity.

# Common Errors
- **Error**: Confusing abridged and incomplete refrains. **Correction**: An abridged refrain maintains a home-key PAC; an incomplete refrain does not.

# Common Confusions
- **Confusion**: Whether shortening the refrain damages the form. **Clarification**: Abridgement is a standard technique that preserves structural closure while reducing redundancy.
