# Quick Definition
The least frequently used sequential pattern in the classical repertory, featuring ascending-third root motion; its unembellished form is virtually never found, though a version with passing chords that function as "dominants" of each successive harmony is more viable.

# Core Definition
"The ascending third progression is the least frequently used sequential pattern in the classical repertory. Its unembellished form is rarely, if ever, found" (Ch. 2, p. 32). "A version employing passing chords is more viable: each passing chord is the 'dominant' of the following main harmony of the sequence, and thus a degree of functionality accrues to the progression. Yet even this pattern seldom appears in the literature" (Ch. 2, p. 32).

# Prerequisites
- **Sequential progression** -- the broader category

# Key Properties
1. Root motion: consistently ascending thirds
2. Unembellished form: virtually never found
3. Embellished form with passing chords: each is "dominant" of following main harmony
4. The rarest of the six sequential categories
5. Even the embellished form seldom appears

# Construction / Recognition
- Ascending-third root motion (extremely rare in practice)
- Look for embellishing passing chords providing dominant function

# Context & Application
More a theoretical possibility than a common compositional resource. When it does appear, passing chords provide necessary functional momentum.
