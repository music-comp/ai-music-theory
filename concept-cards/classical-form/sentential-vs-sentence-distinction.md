# Quick Definition
Many formal units in classical movements present a grouping structure resembling the sentence (model + repetition + fragmentation) but do not truly create this theme type because they lack genuine tonic prolongation in the opening units -- the term "sentence" should be reserved for tight-knit themes with clear presentation and continuation phrases.

# Core Definition
The grouping structure of a core often strongly resembles an extended (compound) sentence. But there is one important functional difference that should prohibit us from regarding a core as a sentence theme type: the opening model and its sequence together do not prolong tonic harmony of a key, and thus they cannot legitimately be identified as forming a genuine presentation. The grouping structure of a standing on the dominant may also resemble a sentence, but the lack of any real harmonic activity and cadential articulation makes the sentence idea completely untenable there. Many thematic regions of a classical movement -- transitions, subordinate themes, development cores -- employ the sentential functions (presentation-like, continuation, cadential) in loose configurations. The term "sentence" is best reserved for relatively tight-knit themes featuring clear presentation and continuation phrases.

# Prerequisites
- **Sentence**: The theme type being distinguished from sentential grouping
- **Presentation function**: Requires tonic prolongation, which sentential units lack
- **Continuation function**: Can appear in both sentence and sentential contexts
- **Core technique**: A common context for sentential grouping without genuine sentence

# Key Properties
1. Genuine sentence requires tonic prolongation in the presentation (not just grouping repetition)
2. Development core: model + sequence resembles presentation but lacks tonic prolongation
3. Standing on the dominant: may resemble sentence grouping but has no harmonic activity or cadence
4. The label "sentential" or "sentence-like" is appropriate for loose configurations
5. The term "sentence" should be reserved for tight-knit manifestations
6. Length and complexity may vastly differ from the standard 8-m. sentence
7. Transitions, subordinate themes, and developments regularly employ sentential functions loosely

# Construction / Recognition
- Check for tonic prolongation in the opening units: if present = genuine presentation = possible sentence
- If the opening is sequential or over dominant pedal: sentential grouping, not genuine sentence
- In development cores: model + sequence = sentential, not sentence
- In standing on the dominant: no harmonic activity = cannot be a sentence
- Use "sentential" or "sentence-like" for loose contexts

# Context & Application
This distinction becomes increasingly important as analysis moves beyond tight-knit main themes into the looser formal regions of the exposition, development, and recapitulation. Almost every formal region outside the main theme uses sentential functions in some degree, but labeling them all "sentences" would obscure the fundamental difference between tight-knit and loose organization. The distinction is pedagogically important: students should not assume that any repeated unit followed by fragmentation constitutes a sentence.

# Examples
- Beethoven, Piano Sonata in F minor, Op. 2/1, i, development core (Ch. 9, Ex. 9.6): 8-m. model sequenced, followed by fragmentation -- sentential grouping but NOT a sentence because the model and sequence do not prolong tonic
- Standing on the dominant in the same movement (Ch. 9, Ex. 9.7): 4-m. idea + repetition + fragmentation -- resembles sentence grouping but lacks any harmonic activity or cadence
- Many transitions employ sentential functions loosely (Ch. 11, "Sentence or 'Sentential'?" text box)

# Common Errors
- Labeling every model + sequence + fragmentation pattern as a "sentence"
- Identifying a development core as having "presentation function" when it lacks tonic prolongation
- Treating a standing on the dominant as a sentence-like structure

# Common Confusions
- **Grouping ≠ function**: A repeated unit followed by fragmentation LOOKS like a sentence but requires tonic prolongation to BE a sentence
- **Sentential quality**: "More sentential than periodic" is a legitimate characterization for nonconventional themes
- **Degree of looseness**: As the length and complexity increase beyond the 8-m. norm, the "sentence" label becomes more problematic
