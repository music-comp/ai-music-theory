# Quick Definition
The typical use of only one subordinate theme in slow-movement sonata expositions, contrasting with the multiple subordinate themes common in fast movements.

# Formal Definition
An exposition in a slow-movement sonata usually contains a single subordinate theme, often one that is relatively tight knit (though still looser than the main theme). This contrasts with fast-movement sonata expositions, which more commonly feature a subordinate-theme group of two or more themes. The single subordinate theme contributes to the overall formal compression characteristic of slow movements.

# Construction/Recognition
- Only one theme follows the transition (or main theme, if the transition is eliminated)
- The theme typically ends with a PAC in the subordinate key
- It is relatively tight knit compared to subordinate themes in fast movements
- Extensions and expansions are generally kept in check

# Musical Context
The use of a single subordinate theme is one of the standard compression techniques in slow-movement sonata form.

# Examples
- Beethoven, Piano Sonata in D, Op. 10/3, ii: Single subordinate theme following the transition/subordinate-theme fusion passage
- Haydn, Piano Sonata in E, Hob. XVI:31, ii: A single subordinate theme begins directly in the subordinate key

# Common Confusions
- A single subordinate theme does not mean the subordinate-key area is insubstantial; the theme still cadentially confirms the subordinate key with a PAC.
