# Quick Definition
The typical use of only one subordinate theme in slow-movement sonata expositions, contrasting with the multiple subordinate themes common in fast movements, contributing to the overall formal compression.

# Core Definition
An exposition in a slow-movement sonata usually contains a single subordinate theme, often one that is relatively tight knit (though still looser than the main theme). This contrasts with fast-movement sonata expositions, which more commonly feature a subordinate-theme group of two or more themes. The single subordinate theme contributes to the overall formal compression characteristic of slow movements. Standings on the dominant are generally held in check, and extensions and expansions are kept limited.

# Prerequisites
- **Slow-movement sonata form**: The formal context
- **Subordinate theme**: Understanding standard subordinate-theme construction

# Key Properties
1. Only one subordinate theme follows the transition (or main theme, if transition is eliminated)
2. The theme typically ends with a PAC in the subordinate key
3. It is relatively tight knit compared to subordinate themes in fast movements
4. Extensions and expansions are generally kept in check
5. Contributes to overall formal compression

# Construction / Recognition
- Count the number of subordinate themes in the exposition
- Assess the theme's relative tightness compared to fast-movement subordinate themes
- Note any compression of cadential areas

# Context & Application
The use of a single subordinate theme is one of the standard compression techniques in slow-movement sonata form, working alongside transition/subordinate-theme fusion and reduced development.

# Examples
- Beethoven, Piano Sonata in D, Op. 10/3, ii: Single subordinate theme following the transition/subordinate-theme fusion passage
- Haydn, Piano Sonata in E, Hob. XVI:31, ii: A single subordinate theme begins directly in the subordinate key

# Common Errors
- Expecting slow-movement subordinate-theme groups to contain the same number of themes as fast movements

# Common Confusions
- **Single vs. insubstantial**: A single subordinate theme still cadentially confirms the subordinate key with a PAC; "single" does not mean weak or insignificant
