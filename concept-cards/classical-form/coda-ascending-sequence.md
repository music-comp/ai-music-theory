# Quick Definition
The ascending-stepwise sequence is the most popular sequential pattern within codas, naturally projecting an increasingly intense emotional excitement appropriate to the movement's conclusion.

# Core Definition
Prominent tonicizations and sequential progressions frequently occur early in a coda to provide harmonic contrast between the end of the recapitulation and the end of the coda, both of which emphasize the home-key tonic. The ascending-stepwise pattern, which naturally projects an increasingly intense emotional excitement, seems to be the most popular sequence within codas. Unlike the development's sequences, which are typically modulatory and explore remote keys, the coda's sequences remain closely bound to the home key, even when they employ model-sequence technique suggestive of a core. A coda may use model-sequence technique with 4-measure groups that resemble a development core, but the harmonic areas remain allied with the home key, making the unit function more as a subordinate theme than as a development.

# Prerequisites
- **Coda**: The formal context where this technique appears
- **Sequential progression**: The harmonic technique employed

# Key Properties
1. The ascending-stepwise sequence is the most popular pattern in codas
2. Projects increasingly intense emotional excitement
3. Provides harmonic contrast early in the coda
4. Both ends of the coda (and recapitulation) emphasize home-key tonic
5. Sequences in codas remain closely bound to the home key (unlike developmental sequences)
6. Model-sequence technique may resemble a core but functions differently
7. The tonally stable context distinguishes coda sequences from development sequences

# Construction / Recognition
- Look for ascending-stepwise sequential patterns early in the coda
- Note that the harmonies remain closely allied with the home key
- If model-sequence technique appears, check whether it is modulatory (development) or non-modulatory (coda)
- The ascending pattern creates progressive dynamic excitement

# Context & Application
This observation helps distinguish the coda from a "terminal development." Even when the coda uses similar sequential techniques, the tonal stability marks it as fundamentally different. The ascending pattern also supports the progressive dynamic curves (crescendo toward climax) that characterize many Beethoven codas.

# Examples
- Beethoven, String Quartet in F, Op. 18/1, i, mm. 274-93 (ex. 15.1): ascending sequential scale patterns (bIV, bII, then V); model-sequence technique with 4-m. groups; harmonies remain allied with home key
- Haydn, Symphony No. 97 in C, i, mm. 246-61 (ex. 15.5): ascending-stepwise sequence of cadential idea

# Common Errors
- Treating coda sequences as evidence of "terminal development" (the tonal context is different)
- Missing the ascending pattern's role in creating excitement
- Confusing non-modulatory sequences with genuine modulation

# Common Confusions
- **Coda vs. development sequences**: The key difference is tonal stability -- coda sequences stay near the home key
- **Model-sequence resemblance**: 4-measure model-sequence groups in the coda may look like a core but function as a subordinate theme
