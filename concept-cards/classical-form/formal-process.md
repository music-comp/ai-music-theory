# Quick Definition
The compositional devices -- repetition, fragmentation, liquidation, extension, expansion, and others -- that operate within and across formal functions to shape a theme's structure and character.

# Core Definition
In addition to formal functions and formal types, "the theory defines a set of formal processes (e.g., repetition, fragmentation, extension, expansion)" (Ch. 1, p. 9). These processes are the compositional techniques that articulate and differentiate formal functions. They interact with harmonic progression to create the specific character of each formal function: presentation relies on repetition; continuation depends on fragmentation and harmonic acceleration; cadential function involves liquidation.

# Prerequisites
- **Formal function** -- the roles that processes help articulate

# Key Properties
1. Repetition: immediate restatement (exact, statement-response, or sequential)
2. Fragmentation: reduction of unit size (e.g., 2mm to 1mm)
3. Liquidation: systematic elimination of characteristic motives
4. Extension: appending material after a function is expressed
5. Expansion: internal lengthening of components beyond normative size
6. These processes are independent and can occur in various combinations

# Construction / Recognition
- Identify which processes are operating in a given passage
- Note how processes interact (fragmentation + liquidation, extension + expansion)
- Use processes to identify and confirm formal functions

# Context & Application
Formal processes are essential to the identity of formal functions. Understanding them is prerequisite to accurate formal analysis.

# Examples
**Example 1** (Ch. 1, p. 10): Fragmentation in Beethoven, Op. 2/1, i, mm. 5-6: two-measure basic idea reduced to one-measure units.
**Example 2** (Ch. 1, p. 11): Liquidation in Op. 2/1, i, mm. 5-8: motive "a" eliminated, conventional cadential figures replace characteristic motives.
**Example 3** (Ch. 1, p. 12): Sequential repetition in Beethoven, Op. 135, iii, mm. 7-9: model-sequence technique with descending-fifth pattern.

# Common Errors
- Conflating different processes (e.g., fragmentation and liquidation are independent)

# Common Confusions
- Fragmentation concerns unit length, not motivic content
- Extension and expansion are different: extension adds on after; expansion stretches from within
