# Quick Definition
A group of two or more subordinate themes in the exposition, each ending with a PAC in the subordinate key, that collectively fulfills subordinate-theme function through a broader range of loosening techniques than any single theme could contain.

# Core Definition
The exposition of a large-scale movement often features a group of subordinate themes, each ending with a PAC in the subordinate key. The use of multiple subordinate themes is one of the principal means for enlarging the formal dimensions of the composition, since a greater number of loosening techniques can be employed across multiple themes. The way loosening techniques are dispersed among the themes is of significant analytical interest. The functional relationship among the themes is difficult to define; they are identified neutrally by order of appearance (first, second subordinate theme). The themes are linked by elision (final tonic functioning as initial tonic of the next) or accompanimental overlap.

# Prerequisites
- **Subordinate theme**: The individual formal units making up the group
- **Loosening techniques**: Dispersed across the group

# Key Properties
1. Each theme in the group ends with PAC in the subordinate key
2. Themes connected by elision (cadential tonic = initial tonic) or accompanimental overlap
3. One theme often distinctly more tight knit (often the first, especially in Mozart)
4. The overall group (not any single theme) should be compared to the main theme for looseness
5. A true closing section appears only after the LAST theme
6. False closing sections may intervene between themes
7. Themes identified neutrally by order (first, second ST)

# Construction / Recognition
- Identify PACs in the subordinate key that separate individual themes
- Note elision or overlap between themes
- Assess the distribution of loosening techniques across the group
- Identify which themes are tighter or looser in relation to each other
- Locate the true closing section (only after the final theme)
- Watch for false closing sections that begin a new theme

# Context & Application
Multiple subordinate themes are typical of large-scale movements in sonata, rondo, and concerto forms. The group as a whole provides the loosening contrast to the main theme. The interplay between tighter and looser themes within the group is a key analytical feature. If the first theme is very loose (e.g., beginning with continuation), a later tight-knit theme may compensate.

# Examples
- Haydn, Piano Sonata in C, Hob. XVI:35, i: two STs -- first is entirely cadential with expanded I6; second begins with continuation and features "one more time" technique
- Beethoven, Piano Sonata in A, Op. 2/2, i: two STs -- first begins with model-sequence continuation (very loose); second begins with repeated presentation (compensatory tightness)
- Mozart, Clarinet Quintet in A, K. 581, i: two STs -- first is tight-knit compressed sentence; second features modal shift, tonicization of bVI, expanded dominant

# Relationships
## Builds Upon
- Subordinate theme (individual units composing the group)
- Loosening techniques (dispersed across the group)

## Enables
- Broader loosening range (more techniques than any single theme could contain)
- Compensatory relationships (tight and loose themes balance each other)

## Related
- False closing section (may intervene between themes)
- Closing section (only after the final theme)
- Elision (structural connection between themes)

## Contrasts With
- Two-part subordinate theme (a single theme with internal HC; multiple themes each end with PAC)

# Common Errors
- Failing to recognize that each subordinate theme must end with PAC
- Comparing individual themes rather than the entire group to the main theme
- Treating a false closing section as a true closing section (prematurely ending the group)

# Common Confusions
- **Group vs. two-part theme**: In multiple STs, EACH theme ends with PAC; in a two-part ST, only the second part achieves PAC
- **Individual vs. group looseness**: The overall group, not any single theme, provides the loosening contrast to the main theme
- **False vs. true closing section**: A false closing section between themes initially suggests the group has ended but is retrospectively understood as the beginning of the next theme
