# Quick Definition
The third part of a large ternary form, restating the main theme essentially as it appeared in the first part, often with ornamental embellishment but without tonal adjustment -- better described as a "return" than a "recapitulation."

# Core Definition
Because the main theme of a large ternary essentially resides in the home key, the return does not require any tonal adjustment. In the majority of cases, the third part is structured the same as the first part, though often with considerable ornamental changes (especially melodic embellishments of the kind found in theme-and-variations movements). It is more appropriate to speak of a "return" rather than a genuine "recapitulation." The returning theme may be changed structurally, with portions eliminated or, more commonly, material added as interpolations, extensions, or expansions. A coda may follow, often of great scope (especially in Beethoven), frequently referring to material from the interior theme -- analogous to how sonata codas "recapitulate" development ideas.

# Prerequisites
- **Large ternary form**: The formal context
- **Interior theme**: The contrasting section that precedes the return

# Key Properties
1. No tonal adjustment is needed (main theme already in home key)
2. Structure matches the first part in the majority of cases
3. Ornamental changes are common (melodic embellishment, variation technique)
4. Material may be added (interpolation, extension, expansion) or occasionally eliminated
5. A coda may follow, often referencing interior-theme material
6. Better described as a "return" than a "recapitulation"

# Construction / Recognition
- Compare the third part to the first part for structural correspondence
- Note ornamental changes (especially melodic embellishment)
- Check for added or eliminated material
- Look for a coda following the return, especially one referencing interior-theme ideas

# Context & Application
The ornamental embellishment in the return connects large ternary form to variation technique. Beethoven's large ternary movements frequently conclude with extensive codas that reference the interior theme, providing the formal expansion typically absent from the return itself.

# Examples
- Beethoven's large ternary slow movements: frequently conclude with extensive codas referencing the interior theme, analogous to how sonata codas refer to development material

# Common Errors
- Calling this section a "recapitulation" when no tonal conflict needs resolution

# Common Confusions
- **Return vs. recapitulation**: The third part lacks the tonal-resolution function that defines a true recapitulation; it is simply a return of material already in the home key
