# Quick Definition
A phrase in the first part of a small binary that begins like a consequent (restating the basic idea in the manner expected to lead to a strong cadence) but "fails" to achieve the expected authentic cadential closure, ending instead with a half cadence. It is a nonconventional form -- neither a true consequent nor a true antecedent.

# Core Definition
In certain small binaries, the second phrase of the first part gives the impression that an implied consequent has "failed" to materialize because of weak cadential closure. The phrase opens with material resembling the basic idea (as a consequent would) but closes with an HC instead of the expected PAC. Though the internal organization -- basic idea followed by contrasting idea leading to HC -- is suggestive of an antecedent, in the context of the first part as a whole, the listener much more has the impression that an implied consequent has failed. The phrase may also modulate, which further disqualifies it as a true antecedent (since antecedents do not modulate). The result is a nonconventional form.

# Prerequisites
- **Consequent**: The formal function being suggested but not realized
- **Small binary**: The form in which this construction typically appears
- **First part of binary**: The section containing the failed consequent

# Key Properties
1. Second phrase of part 1 begins like a consequent (restating basic idea)
2. Closes with HC instead of expected PAC
3. Creates the impression of an implied consequent that has "failed"
4. NOT a true antecedent (may modulate; the phrase-structural context suggests consequent, not antecedent)
5. Results in a nonconventional form (compound basic idea + failed consequent, or antecedent + failed consequent)
6. The HC ending strongly suggests binary rather than ternary form for the overall theme
7. When the first part is repeated, a compound period is briefly implied but fails when the second repetition also ends HC

# Construction / Recognition
1. Identify a first part where the second phrase restates the basic idea
2. Check whether the second phrase closes with HC instead of PAC
3. Assess whether the context suggests a failed consequent or a true antecedent
4. Note any modulation in the second phrase (disqualifies antecedent interpretation)
5. The "failed" label reflects the listener's experience of denied expectations

# Context & Application
The failed consequent is a key construction in the small binary because it immediately establishes the form's identity. A genuine consequent (PAC) would complete a period; the failed consequent (HC) prevents the period from materializing, creating formal ambiguity that is resolved only when the second part also fails to provide a recapitulation. The concept captures the real-time listening experience of expecting a PAC and receiving an HC.

# Examples
- Haydn, Piano Sonata in E, Hob. XVI:31, iii, mm. 5-8: opening antecedent (mm. 1-4) followed by modulating phrase ending with HC; modulation disallows antecedent interpretation; "failed consequent" best models the hearing experience
- Beethoven, Violin Sonata in A, Op. 30/1, iii, mm. 5-8: compound basic idea followed by HC-ending phrase; the return of the basic idea and HC ending suggest a "reversed period" feel

## Builds Upon
- Consequent (the function being suggested but not realized)

## Enables
- Small binary identification (the HC ending strongly suggests binary form)
- Periodic binary with half cadence (the broader category)

## Contrasts With
- Consequent: a true consequent achieves PAC; a failed consequent ends HC
- Antecedent: a true antecedent is nonmodulatory and implies a subsequent consequent; a failed consequent may modulate and suggests that a consequent should have occurred but did not

# Common Errors
- Labeling the failed consequent as a "second antecedent" -- the phrase-structural context (following an initial antecedent) makes consequent function the expected interpretation
- Treating the failed consequent as simply an antecedent that happens to modulate
- Ignoring the experiential dimension: the listener expects PAC and receives HC

# Common Confusions
- A "failed consequent" is NOT a true antecedent -- a true antecedent is nonmodulatory and implies a subsequent consequent
- The phrase is called "failed" because it fails to achieve the strong cadential closure that would complete the period
- A modulating second phrase cannot be an antecedent (antecedents do not modulate)
- The "failure" is compositionally productive -- it generates the binary form
