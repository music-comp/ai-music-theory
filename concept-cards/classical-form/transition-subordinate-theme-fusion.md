# Quick Definition
A single thematic unit in the exposition that fuses transition and subordinate-theme functions: it modulates to the subordinate key and confirms it with a PAC, without a clear initiating function for a discrete subordinate theme.

# Core Definition
Some expositions witness the fusion of transition and subordinate-theme functions into a single thematic unit. This unit not only modulates to the subordinate key (transition function) but also closes with a PAC to confirm that key (subordinate-theme function). It is not possible to find an appropriate initiating function for a discrete subordinate theme, even in retrospect. This fusion corresponds to Pattern 8 in Table 13.1. Caplin argues it is theoretically more consistent to interpret such passages as fusions than to allow transitions to close with PACs, which would blur the fundamental distinction between interthematic functions: "authentic cadential confirmation of a subordinate key is an essential criterion of the subordinate theme's function."

# Prerequisites
- **Transition**: Provides the modulatory function
- **Subordinate theme**: Provides the cadential confirmation function
- **Eight cadential patterns**: Fusion corresponds to Pattern 8

# Key Properties
1. A single unit performs both modulation and cadential confirmation
2. No point can be identified as the beginning of a discrete subordinate theme, even in retrospect
3. The unit ends with PAC in the subordinate key
4. Corresponds to Pattern 8 in Table 13.1
5. Theoretically more consistent than allowing transitions to close with PAC
6. Preserves the fundamental distinction: PAC in subordinate key = subordinate-theme function
7. A subsequent discrete subordinate theme may follow the fused unit
8. Differs from obscured boundary: in the latter, a subordinate theme can be identified retroactively

# Construction / Recognition
- Look for a passage that modulates and closes with PAC in the subordinate key
- Check whether any point within the passage can serve as a subordinate-theme initiation
- If no initiation can be found even in retrospect, the passage fuses both functions
- A subsequent discrete subordinate theme may follow

# Context & Application
This fusion is relatively uncommon but theoretically important because it blurs the fundamental distinction between interthematic functions. Caplin's terminological preference ("fusion" rather than "transition with PAC") preserves the principle that authentic cadential confirmation of the subordinate key is exclusive to subordinate-theme function.

# Examples
- Haydn, Symphony No. 93 in D, i (ex. 13.8): after two-part transition activity (mm. 46-61), the music leads to cadential progressions from m. 66 to PAC at m. 74; no point can be identified as subordinate-theme initiation; the cadential unit resembles an internal HC followed by a cadential phrase, suggesting a single fused unit (mm. 53-74)
- Mozart, Violin Sonata in B-flat, K. 454, i (ex. 13.9): 16-measure unit (mm. 14-29) functions as a modulating period; antecedent (mm. 14-21) serves as main theme (HC in HK); consequent (mm. 22-29) fuses transition and subordinate-theme functions (modulates and closes with PAC in SK); a new discrete subordinate theme begins at m. 29

# Common Errors
- Calling the fused unit simply a "transition that ends with PAC" (this blurs the fundamental distinction)
- Confusing fusion with an obscured boundary (in the latter, initiation can be found retroactively)

# Common Confusions
- **Not a deviant transition**: A transition closing with PAC has incorporated subordinate-theme function; it is more consistent to call it a fusion
- **Differs from obscured boundary**: In an obscured boundary, a subordinate theme can be identified in retrospect; in fusion, it cannot
- **Subsequent theme**: A new discrete subordinate theme may follow the fused unit, beginning a new thematic process
- **Theoretical consistency**: Caplin's terminology preserves the principle that PAC in the subordinate key belongs to subordinate-theme function
