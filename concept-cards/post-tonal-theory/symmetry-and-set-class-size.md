# Quick Definition
The relationship between a set class's degree of symmetry and the number of distinct sets it contains: dividing 24 by the number of self-mapping operations gives the number of sets in the set class.

# Formal Definition
The size of a set class (the number of distinct pitch-class sets it contains) is inversely proportional to its degree of symmetry. For any set class:

Number of sets in the class = 24 / (number of self-mapping operations)

The number of self-mapping operations equals the degree of transpositional symmetry times the degree of inversional symmetry (when In-symmetry exists) or just the degree of transpositional symmetry (when the set is not inversionally symmetrical).

Most set classes have degree (1, 0), meaning they map onto themselves only at T0 and contain 24 distinct sets.

# Mathematical Formulation/Recognition
For a set class with degree of symmetry (n, m):
- If m = 0: Set class contains 24/n distinct sets
- If m > 0: Set class contains 24/(n times m) distinct sets

Examples:
- Degree (1, 0): 24/1 = 24 sets
- Degree (1, 1): 24/(1 times 2) = 12 sets (note: In-symmetry at one level counts as 2 operations)
- Degree (2, 2): 24/4 = 6 sets
- Degree (4, 4): 24/16 = 1.5? No - actually 24/8 = 3 sets (the formula uses the actual number of operations)

For (0167) with degree (2, 2): 2 Tn operations times 2 In operations = 4 total self-mappings; 24/4 = 6 sets.

# Musical Context/Application
This relationship has practical implications:
- Highly symmetrical sets have fewer distinct transpositions available (limiting transposition as a developmental technique)
- Asymmetrical sets offer more variety through transposition
- Understanding set class size helps in composition and analysis

The diminished seventh chord (0369) has only 3 distinct forms; the whole-tone scale (02468T) has only 2 distinct forms. This "limitation" is actually a distinctive characteristic that makes these sonorities immediately recognizable.

# Examples
From Example 3-19: sc(0167) has degree (2, 2)
- Each set maps onto itself in 4 ways: T0, T6, I1, I7
- Total operations: 4
- Number of sets: 24/4 = 6

The six members of sc(0167):
| Set | Operations producing it |
|-----|------------------------|
| [0, 1, 6, 7] | T0, T6, I1, I7 |
| [1, 2, 7, 8] | T1, T7, I2, I8 |
| [2, 3, 8, 9] | T2, T8, I3, I9 |
| [3, 4, 9, 10] | T3, T9, I4, I10 |
| [4, 5, 10, 11] | T4, T10, I5, I11 |
| [5, 6, 11, 0] | T5, T11, I6, I0 |

The diminished seventh chord (0369) has degree (4, 4): 24/8 = 3 distinct forms.

# Common Confusions
- Forgetting that most set classes have 24 members
- Miscounting self-mapping operations
- Not recognizing that inversional symmetry effectively doubles the symmetry count
- Thinking smaller set classes are "less important" (they are often the most compositionally distinctive)
