# Quick Definition
A six-note collection, sc(02468T), consisting entirely of whole steps with the highest possible degree of symmetry, existing in only two distinct transpositions (WT0 and WT1).

# Formal Definition
The whole-tone collection, set class (02468T) (Forte-name 6-35), has the highest possible degree of symmetry, both transpositionally and inversionally. Its set class contains only two distinct members: WT0 (containing pitch-class C, the "even" collection) and WT1 (containing pitch-class C#, the "odd" collection). When written as a scale, there is only one possible interval order: 2-2-2-2-2-2. The collection's intervallic and subset structures are correspondingly restricted and redundant.

# Mathematical Formulation/Recognition
The two whole-tone collections:

| Name | Pitch Classes | Parity |
|------|---------------|--------|
| WT0 | [0, 2, 4, 6, 8, 10] (C, D, E, F#, G#, A#) | Even |
| WT1 | [1, 3, 5, 7, 9, 11] (C#, D#, F, G, A, B) | Odd |

Interval content: Only even intervals
- ic2: 6 instances
- ic4: 6 instances
- ic6: 3 instances
- ic1, ic3, ic5: 0 instances

Symmetry: Maps onto itself at T0, T2, T4, T6, T8, T10 (maximum transpositional symmetry)

# Musical Context/Application
The whole-tone collection is associated with:
1. Impressionism (especially Debussy)
2. Dream-like, floating, non-directional quality
3. Absence of half-steps (no leading tones)
4. Limited but distinctive harmonic vocabulary

# Common Confusions
- Only 2 whole-tone collections exist (not 12 like diatonic)
- The collection lacks half-steps entirely
- "Even" and "odd" refer to pitch-class integer parity
- Limited subset variety is a defining characteristic
