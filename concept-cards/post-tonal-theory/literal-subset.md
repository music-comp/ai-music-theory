# Quick Definition
A set whose specific pitch classes are all contained within another set; literal subsets share actual pitch-class content with their supersets.

# Formal Definition
Set X is a literal subset of Set Y if all of the pitch classes in X are contained in Y. This is the most direct form of subset relationship: the exact pitch classes of X appear among the pitch classes of Y.

The literal subset relation is about actual pitch-class content, not set-class membership. Transposing or inverting X may remove it from being a literal subset of Y while preserving abstract subset status.

# Mathematical Formulation/Recognition
X is a literal subset of Y if and only if:
- Every element of X is also an element of Y
- Formally: X is a subset of Y (set theory notation)

To verify: Check that each pitch class in X appears in Y.

Example:
- Y = [E, F, G, Bb]
- X = [E, F, G]
- X is a literal subset of Y (all three pcs of X are in Y)

# Musical Context/Application
Literal subsets are important for:
- Identifying how a smaller motive is literally present within a larger harmony
- Analyzing registral projections (high notes, low notes, etc. form literal subsets)
- Understanding voice leading when certain voices continue while others change
- Tracing how a collection breaks down into smaller components

When composers arrange sets registrally, the extreme notes often form meaningful literal subsets of the whole.

# Examples
From Example 3-33:
- Set Y = [E, F, G, Bb] = sc(0136)
- Set X = [E, F, G] = sc(013)
- X is a literal subset of Y (E, F, and G all appear in both)

From Example 3-31: Schoenberg, Little Piano Pieces, op. 19, no. 2
- Full chord: member of (014589)
- Highest 4 notes form a literal subset belonging to (0148)
- Lowest 4 notes form another literal subset, also belonging to (0148)
- Highest 3 notes form a literal subset that is an augmented triad (048)

From Example 3-32: Schoenberg, Ode to Napoleon
- Full collection: [D, Eb, F#, G, Bb, B] = (014589)
- G minor triad [G, Bb, D] is a literal subset
- B minor triad [B, D, F#] is a literal subset
- Eb major triad [Eb, G, Bb] is a literal subset

# Common Confusions
- Confusing literal subsets with abstract subsets (literal requires actual pc match)
- Thinking transposition preserves literal subset status (it doesn't)
- Not recognizing that a set has many literal subsets, most of which are not musically relevant
- Assuming literal subsets must be members of musically important set classes
