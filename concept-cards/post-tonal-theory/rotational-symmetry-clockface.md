# Quick Definition
The visual representation of transpositional symmetry on the pitch-class clockface, where a set can be rotated by a fixed number of positions and land back on itself -- the mathematical equivalent of rotational symmetry.

# Core Definition
Transpositional symmetry is equivalent to rotational symmetry when pitch-class sets are displayed on the twelve-position clockface. A set that maps onto itself at Tn can be literally rotated n positions clockwise on the clockface and overlay its original position exactly. This geometric interpretation makes the abstract algebraic property visually intuitive: the set's shape has a rotational symmetry that allows it to "fit back onto itself" after a partial rotation (Straus, pp. 118-119).

# Prerequisites
- **Pitch-class clockface** -- the circular representation of the 12 pitch classes
- **Transpositional symmetry** -- the algebraic property being visualized

# Key Properties
1. Rotation by n positions on the clockface = transposition by Tn
2. A set with degree-k symmetry has k-fold rotational symmetry on the clockface
3. The shape of the set on the clockface must have the appropriate rotational symmetry
4. This is the musical analog of geometric rotational symmetry in regular polygons

# Construction / Recognition
To visualize:
1. Plot the set on the 12-position clockface (0 at top or right, proceeding clockwise)
2. Rotate the pattern by the symmetry interval
3. If all dots land on other dots, the set is transpositionally symmetrical at that level

# Context & Application
The clockface visualization makes transpositional symmetry immediately apparent. Regular or near-regular shapes on the clockface correspond to symmetrical sets. This representation is particularly useful for teaching and quick identification of symmetry properties.

# Examples
**Example 1** (p. 119, Ex. 3-9): [0, 2, 6, 8] displayed on the clockface. Rotating clockwise by 6 positions moves [0, 2] to [6, 8] and simultaneously moves [6, 8] to [0, 2]. The shape has 2-fold rotational symmetry.

**Example 2**: (0369) on the clockface forms a square inscribed in the circle. Rotating by 3 positions maps each vertex onto the next, demonstrating 4-fold rotational symmetry.

**Example 3**: (048) forms an equilateral triangle on the clockface, with 3-fold rotational symmetry.

# Common Errors
- Confusing rotational symmetry (transpositional) with reflective symmetry (inversional) on the clockface
- Forgetting that the rotation amount corresponds to the transposition interval

# Common Confusions
- Rotational symmetry on the clockface is the same mathematical concept as in geometry -- not a musical metaphor but an exact equivalence
- A set can have rotational symmetry without reflective symmetry, or vice versa
