# Quick Definition
The sum (mod 12) of any pitch class and its image under a given inversion; for In, any pitch class x maps to (n - x) mod 12, and x + (n - x) = n.

# Formal Definition
The index number n in an inversion operation In represents the sum of each pitch class and its inversional partner. Under In, pitch class x maps to pitch class (n - x) mod 12. The index number can be understood as:
- The sum of any pc and its inversion: x + In(x) = n (mod 12)
- The axis of symmetry on the pitch-class clockface (when n is even, the axis passes through n/2 and (n/2)+6; when n is odd, the axis passes between adjacent pitch classes)

Index numbers range from 0 to 11, corresponding to I0 through I11.

# Mathematical Formulation/Recognition
For inversion at In:
- In(x) = n - x (mod 12)
- x + In(x) = n (mod 12)

To find the index number that maps pitch class a onto pitch class b:
- n = a + b (mod 12)

To find what pitch class x maps to under In:
- In(x) = n - x (mod 12)

Fixed points (notes that map to themselves) occur when:
- 2x = n (mod 12)
- When n is even: x = n/2 is a fixed point
- When n is odd: no pitch class maps to itself

# Musical Context/Application
Index numbers are essential for:
- Calculating inversional relationships between sets
- Determining common tones under inversion
- Understanding inversional symmetry
- Analyzing twelve-tone row operations

The index number defines the axis of inversional symmetry. Composers may choose specific index numbers to preserve certain pitch classes or create particular voice-leading effects.

# Examples
Under I4:
- 0 maps to 4 (0 + 4 = 4)
- 1 maps to 3 (1 + 3 = 4)
- 2 maps to 2 (2 + 2 = 4) - fixed point
- 5 maps to 11 (5 + 11 = 16 = 4 mod 12)

Under I7:
- 0 maps to 7 (0 + 7 = 7)
- 3 maps to 4 (3 + 4 = 7)
- No fixed point (7 is odd)

From Example 3-10: To find common tones of [1, 3, 6, 9] under In, calculate all sums:
- 1 + 3 = 4, so 1 and 3 are common at I4
- 1 + 6 = 7, so 1 and 6 are common at I7

# Common Confusions
- Confusing index number (sum) with transposition level (difference)
- Thinking In always has the same meaning as "inversion about pitch class n" (it's actually about the axis defined by n)
- Not recognizing that the index number is a sum, not a single pitch class
- Forgetting that index numbers cycle through mod 12
