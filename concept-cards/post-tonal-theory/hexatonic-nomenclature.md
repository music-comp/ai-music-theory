# Quick Definition
A naming system for the four hexatonic collections using subscript pairs that indicate the numerically lowest pitch-class semitone each collection contains: HEX0,1, HEX1,2, HEX2,3, and HEX3,4.

# Formal Definition
HEX nomenclature identifies each of the four hexatonic collections by the numerically lowest pitch-class semitone (adjacent pitch-class pair) it contains. Since each hexatonic collection contains three semitones (at T4-related positions), the lowest one uniquely identifies the collection. The subscript consists of two adjacent pitch-class integers representing this defining semitone.

# Mathematical Formulation/Recognition
The four hexatonic collections:

| Name | Defining Semitone | Contains Semitones | Pitch Classes |
|------|-------------------|-------------------|---------------|
| HEX0,1 | C-C# (0-1) | 0-1, 4-5, 8-9 | [0, 1, 4, 5, 8, 9] |
| HEX1,2 | C#-D (1-2) | 1-2, 5-6, 9-10 | [1, 2, 5, 6, 9, 10] |
| HEX2,3 | D-Eb (2-3) | 2-3, 6-7, 10-11 | [2, 3, 6, 7, 10, 11] |
| HEX3,4 | Eb-E (3-4) | 3-4, 7-8, 11-0 | [3, 4, 7, 8, 11, 0] |

Quick identification:
- If collection contains C and C#: HEX0,1
- If collection contains C# and D (but not C): HEX1,2
- If collection contains D and Eb: HEX2,3
- If collection contains Eb and E: HEX3,4

# Musical Context/Application
HEX nomenclature allows:
1. Identification of which hexatonic system is in use
2. Tracking collection changes and relationships
3. Correlation with LP-cycles (each HEX corresponds to one LP-cycle)
4. Parallel naming convention with OCT nomenclature

# Common Confusions
- The subscript identifies the collection by its lowest semitone, not a "root"
- HEX3,4 wraps around (contains 11-0 as one of its semitones)
- The four HEX collections correspond to the four LP-cycles
- Complementary hexatonic collections (e.g., HEX0,1 and HEX2,3) together span 10 pitch classes (share 2)
