# Quick Definition
A geometric representation showing all members of a set class positioned according to their relationships via defined contextual inversions, useful for tracing melodic and harmonic progressions.

# Formal Definition
A contextual-inversion space is a network diagram in which the locations (nodes) are specific members of a set class (or series forms), and the connections (edges) represent contextual inversions. Unlike voice-leading spaces that show semitonal offset between set classes, contextual-inversion spaces show relationships among specific pitch-class sets within a single set class, connected by internally-defined inversional operations.

# Mathematical Formulation/Recognition
Construction of a contextual-inversion space:
1. Select a set class and define relevant contextual inversions (J, K, L, etc.)
2. Position all members of the set class as nodes
3. Connect nodes that are related by each contextual inversion
4. The resulting network allows tracing of progressions

For Stravinsky's four-note series (Example 4-25):
- Outer circle: P and I forms connected by J and K
- Inner connections via L
- Series forms labeled by first pitch class (P8, I0, etc.)

# Musical Context/Application
Contextual-inversion spaces:
1. Enable visualization of compositional pathways through a set class
2. Reveal systematic use of contextual inversions
3. Show cadential arrivals (completing a circle or returning to starting point)
4. Illuminate the logic behind seemingly disparate harmonic choices

# Examples
Example 4-22b: Complete cycle of JK inversions for sc(014), forming a circular space of twelve positions.

Example 4-25: Stravinsky's "Musick to heare" - a contextual inversion space for the four-note series shows P and I forms connected by J, K, and L. Stravinsky largely confines himself to the outer circle, working counterclockwise, with the final series form (P8) completing the outer circle, reinforcing the cadential effect.

# Common Confusions
- These spaces show relationships within a single set class, not between different set classes
- The specific shape and connectivity depend on how contextual inversions are defined
- Different definitions of contextual inversions produce different space topologies
