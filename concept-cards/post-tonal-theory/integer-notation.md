# Quick Definition
Integer notation uses the numbers 0-11 to represent the twelve pitch classes, with C assigned to 0 and subsequent pitch classes numbered chromatically upward.

# Formal Definition
Integer notation is a system for representing pitch classes using integers from 0 through 11, following a "fixed do" convention where pitch class C (and its enharmonic equivalents) is assigned 0, C#/Db is assigned 1, D is assigned 2, and so on chromatically. This system allows mathematical operations on pitch classes and facilitates the analysis of intervallic relationships.

# Mathematical Formulation/Recognition
The twelve pitch classes and their integer names:
| Integer | Pitch Classes |
|---------|---------------|
| 0 | C (B#, Dbb) |
| 1 | C#/Db |
| 2 | D |
| 3 | D#/Eb |
| 4 | E (Fb) |
| 5 | F (E#) |
| 6 | F#/Gb |
| 7 | G |
| 8 | G#/Ab |
| 9 | A |
| 10 | A#/Bb |
| 11 | B (Cb) |

For pitch-class integers larger than 11 or smaller than 0, reduce using mod 12 arithmetic.

# Musical Context/Application
Integer notation enables precise calculations of intervals and transpositions. When referring to pitch classes, analysts use either traditional letter names or pitch-class integers, whichever is clearest in a particular context. The system is traditional in music theory (similar to figured-bass numbers) and useful for representing musical relationships mathematically.

# Common Confusions
The use of integers does not make the music itself "mathematical." We use numbers and arithmetic to help think about aspects of music, just as we use integers to count our ages without our lives being "mathematical." The integer notation system is simply a tool for representing and calculating pitch-class relationships.
