# Quick Definition

The interval cycle produced by moving repeatedly by major third (interval 4), generating four distinct cycles that correspond to the four augmented triads.

# Formal Definition

The **4-cycle (C4)** is the interval cycle generated by repeated transposition by interval class 4 (the major third). Because GCD(4, 12) = 4, there are exactly four distinct 4-cycles, each containing three pitch classes:

- **C4_0**: {0, 4, 8} = {C, E, G#} = augmented triad
- **C4_1**: {1, 5, 9} = {C#, F, A} = augmented triad
- **C4_2**: {2, 6, 10} = {D, F#, A#} = augmented triad
- **C4_3**: {3, 7, 11} = {D#, G, B} = augmented triad

Each C4 corresponds to one of the four augmented triads. Combining specific pairs of C4s produces hexatonic collections.

# Mathematical Formulation/Recognition

**Properties of C4:**
- Interval: 4 semitones (major third)
- Number of distinct cycles: GCD(4, 12) = 4
- Pitch classes per cycle: 12/4 = 3
- Set class of complete cycle: sc(048) = augmented triad

**The four cycles:**
- C4_0: 0 - 4 - 8 - (0) [C - E - G# - (C)]
- C4_1: 1 - 5 - 9 - (1) [C# - F - A - (C#)]
- C4_2: 2 - 6 - 10 - (2) [D - F# - A# - (D)]
- C4_3: 3 - 7 - 11 - (3) [D# - G - B - (D#)]

**Relationship to hexatonic:**
- C4_0 + C4_1 = hexatonic collection
- C4_0 + C4_3 = hexatonic collection
- C4_2 + C4_1 = hexatonic collection
- C4_2 + C4_3 = hexatonic collection
(Note: Combining two even or two odd C4s produces a whole-tone collection, not hexatonic)

**Relationship to C2:**
Taking every other note of a C2 produces a C4:
- C2_0: C-D-E-F#-G#-A# → taking every other: C-E-G# (C4_0)

# Musical Context/Application

The 4-cycle provides:
- **Augmented triads**: The foundational trichord for C4
- **Major-third melodic motion**: Systematic motion by ic4
- **Hexatonic collections**: Combining appropriate pairs of C4s
- **Maximally even trichord**: sc(048) is the most evenly distributed three-note set
- **Enneatonic collections**: Combining any three C4s

The C4 is central to:
- Late Romantic augmented triad usage
- Neo-Riemannian transformational theory (L and P transformations)
- Hexatonic compositional practice
- Music organized around major-third relationships

# Examples

**Hexatonic derivation** (referenced in text):
- Combining C4_0 {C, E, G#} with C4_1 {C#, F, A} yields hexatonic collection {C, C#, E, F, G#, A}
- This is set class (014589)

**Combination cycle <1, 3>** (Example 4-11b):
- The four <1, 3> combination cycles are generated from different combinations of C4s
- These correspond to the four hexatonic scales

**Enneatonic collection** (referenced in table, Example 4-10):
- Combining any three C4s produces the enneatonic (nonatonic) collection
- Set class 9-12 (01245689T) = maximally even nonachord

**General application:**
- The four augmented triads partition all twelve pitch classes
- Pairs of C4s (one even, one odd subscript) produce hexatonic collections
- C4 underlies neo-Riemannian L and P transformations on triads

# Common Confusions

- **Four cycles, not one**: C4 produces four distinct augmented triads, not a single twelve-tone cycle
- **Even/odd pairing for hexatonic**: Combining two even (C4_0 + C4_2) or two odd (C4_1 + C4_3) C4s produces whole-tone, not hexatonic
- **C4 vs. hexatonic**: A single C4 is an augmented triad (3 notes); combining two appropriate C4s produces a hexatonic collection (6 notes)
- **Major third vs. minor sixth**: Motion by i4 and i8 (its complement) traverse the same cycle in opposite directions
