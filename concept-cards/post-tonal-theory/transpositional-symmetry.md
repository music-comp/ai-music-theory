# Quick Definition
A property of sets that map entirely onto themselves under transposition at some level other than T0; mathematically equivalent to rotational symmetry on the pitch-class clockface.

# Formal Definition
A set is transpositionally symmetrical if it can map entirely onto itself under some transposition Tn where n is not equal to 0. Such sets have the property that transposing them at certain intervals produces no change in pitch-class content. This occurs when the interval-class vector contains an entry equal to the number of notes in the set (or half that number for the tritone/ic6).

All sets are trivially transpositionally symmetrical at T0 (every set maps onto itself when transposed by 0). True transpositional symmetry refers to mapping at levels other than T0.

# Mathematical Formulation/Recognition
A set of cardinality n is transpositionally symmetrical at Tn if:
- The interval-class vector entry for ic(n) equals the cardinality of the set
- Exception for T6: the ic6 entry must equal half the cardinality

To identify transpositionally symmetrical sets:
1. Check the interval-class vector
2. If any entry (except ic6) equals the set's cardinality, the set is Tn-symmetrical at that interval
3. If the ic6 entry equals half the cardinality, the set is T6-symmetrical

On the pitch-class clockface, transpositionally symmetrical sets can be rotated to fit back onto themselves.

# Musical Context/Application
Transpositionally symmetrical sets have attracted composers including Messiaen, who identified seven "Modes of Limited Transposition." These sets include familiar sonorities:
- Augmented triad (048): T4, T8 symmetry
- Diminished seventh chord (0369): T3, T6, T9 symmetry
- Whole-tone scale (02468T): T2, T4, T6, T8, T10 symmetry
- Octatonic scale (0134679T): T3, T6, T9 symmetry
- Hexatonic scale (014589): T4, T8 symmetry

These sets create distinctive harmonic colors due to their limited number of transpositions.

# Common Confusions
- Forgetting that T0 symmetry is trivial (all sets have it)
- Confusing transpositional symmetry with inversional symmetry
- Not recognizing the tritone exception for ic6
- Thinking symmetrical sets are "less useful" when in fact they have distinctive compositional properties
