# Quick Definition
The modulus is the number that defines the cycle length in modular arithmetic. In standard pitch-class theory, the modulus is 12, corresponding to the twelve pitch classes of equal temperament.

# Core Definition
In modular arithmetic, the modulus is the number at which values "wrap around" to zero. Straus defines it: "Twelve is called the modulus, and we will frequently use arithmetic modulo 12." The choice of 12 reflects the twelve equal-tempered semitones in the octave. Other moduli are possible (mod 7 for diatonic operations, or non-standard chromatic systems), but mod 12 is the standard for pitch-class theory.

# Key Properties
1. The modulus determines how many distinct values exist (0 through modulus-1)
2. For standard pitch-class theory, modulus = 12
3. Adding or subtracting the modulus yields an equivalent value
4. Analogous to 12 hours on a clock or 7 days in a week

# Construction / Recognition
## To Construct:
1. Choose the number of distinct equivalence classes (for pitch classes: 12)
2. This number is the modulus

## To Recognize:
1. The number after "mod" in expressions like "mod 12"
2. The cycle length of the system

# Context & Application
The modulus of 12 is so fundamental to pitch-class theory that it is often taken for granted. However, awareness of the modulus concept is important when encountering non-standard chromatic scales or microtonal systems that use different moduli.

# Examples
**From the text** (p. 22): "Twelve is called the modulus." The analogy: clock time uses modulus 12 (hours), and the weekly cycle uses modulus 7 (days).

# Common Errors
- **Error**: Confusing the modulus with a divisor
  **Correction**: The modulus defines the cycle length for equivalence, not division. In mod 12, 15 is equivalent to 3 because 15 - 12 = 3, not because 15/12 = something.

# Common Confusions
- **Confusion**: Thinking the modulus must always be 12
  **Clarification**: 12 is standard for pitch-class theory, but other moduli exist. Diatonic set theory uses mod 7; some microtonal theories use mod 19, mod 24, etc.
