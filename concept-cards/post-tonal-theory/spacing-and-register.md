# Quick Definition
Spacing refers to how pitch classes are distributed vertically in a chord, identified by the ordered pitch-class intervals between registrally adjacent notes reading from bass to treble.

# Core Definition
Collections of notes with the same total interval-class content can be arranged in different ways in pitch space, producing different spacings with distinctive sonic effects. The spacing of a chord is identified by the ordered pitch-class intervals between registrally adjacent notes, reading from the lowest note up. A collection of n pitch classes can be arranged in n different registral orders, each with distinctive spacing intervals. Spacing notation uses brackets: [interval1] [interval2] ...

# Prerequisites
- **Pitch Class** — the elements being arranged in pitch space
- **Ordered Pitch-Class Interval** — the intervals used to describe spacing (0-11)
- **Interval-Class Content** — different spacings share the same total ic content

# Key Properties
1. Spacing intervals use ordered pitch-class intervals (0-11), not interval classes (0-6)
2. Read from lowest note upward
3. A set of n pitch classes has n possible registral orderings
4. Different spacings of the same pc set produce different sonic effects
5. Same interval-class content, different arrangement in pitch space

# Construction / Recognition
## To Construct:
1. Take a collection of pitch classes
2. Arrange them in a specific registral order (lowest to highest)
3. Calculate the ordered pitch-class interval between each adjacent pair, reading upward
4. Express as [int1] [int2] ...

## To Recognize:
1. A series of bracketed integers describing intervals between adjacent voices from bass up
2. Describes a specific vertical arrangement of pitch classes

# Context & Application
Spacing significantly affects the sound of a chord even when pitch-class content is unchanged. Composers make deliberate choices about spacing. Webern, for example, tends to use wide spacings, avoiding the expression of ic 1 as the close semitone pi 1, preferring the wider pi 11 instead.

# Examples
**Example 1-23** (p. 33): The set {G, G#, B} in six different spacings:

| Bottom-Middle-Top | Spacing |
|---|---|
| G - G# - B | [1] [3] |
| G - B - G# | [4] [9] |
| G# - B - G | [11] [4] |
| G# - G - B | [8] [1] |
| B - G - G# | [3] [8] |
| B - G# - G | [9] [11] |

**Example 1-24** (p. 34): In Webern, Concerto for Nine Instruments, op. 24, third movement, Webern uses the same chord type (same ic content) in four of six possible spacings. His presentations are generally widely spaced, avoiding expression of ic 1 as pi 1.

# Common Errors
- **Error**: Using interval classes (0-6) for spacing intervals
  **Correction**: Spacing uses ordered pitch-class intervals (0-11). This allows distinguishing, e.g., a gap of 9 semitones from a gap of 3, even though both are ic 3.

# Common Confusions
- **Confusion**: Thinking spacing is determined by pitch-class content alone
  **Clarification**: Pitch-class content determines interval-class content, but the same pc set can be spaced in multiple distinct ways, each with a different sound.
