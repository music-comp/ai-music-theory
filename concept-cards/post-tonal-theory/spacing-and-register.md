# Quick Definition
Spacing refers to how pitch classes are distributed vertically in a chord, identified by the ordered pitch-class intervals between adjacent notes reading from bass to treble.

# Formal Definition
Collections of notes with the same total interval content can be arranged in different ways in pitch space, creating different spacings. The spacing of a chord is identified by the ordered pitch-class intervals between registrally adjacent notes, reading from the lowest note up. A set of n pitch classes can be arranged in n different registral orders, each with distinctive spacing intervals.

# Mathematical Formulation/Recognition
Spacing notation uses brackets to show intervals between adjacent notes:
- [interval1] [interval2] [interval3] ...
- Read from bass (lowest) to treble (highest)
- Uses ordered pitch-class intervals (0-11)

Example: The set {G, G#, B} in six possible spacings:
| Registral Order | Spacing |
|-----------------|---------|
| G - G# - B | [1] [3] |
| G - B - G# | [4] [9] |
| G# - B - G | [11] [4] |
| G# - G - B | [8] [1] |
| B - G - G# | [3] [8] |
| B - G# - G | [9] [11] |

# Musical Context/Application
Spacing significantly affects the sound of a chord, even when pitch-class content remains the same. Composers make deliberate choices about spacing to achieve particular sonic effects. Some spacings may project certain intervals prominently while others are more evenly distributed.

# Examples
**Example 1-23**: The set {G, G#, B} shown in six different spacings with spacing intervals.

**Example 1-24** (Webern, Concerto for Nine Instruments, op. 24, third movement): Webern uses the same chord type (same interval-class content) in four of the six possible spacings. His presentations are generally widely spaced, avoiding the expression of ic1 as pitch interval 1 (adjacent semitone).

# Common Confusions
Spacing intervals use ordered pitch-class intervals (0-11), not interval classes (0-6). This allows distinguishing between, say, a chord with an interval of 9 semitones between two adjacent voices versus one with an interval of 3 semitones (both would be ic3). Spacing is always read from the bass up.
