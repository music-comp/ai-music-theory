# Quick Definition
The seven different ways of ordering a diatonic collection as a scale, each named after a church mode (Ionian, Dorian, Phrygian, Lydian, Mixolydian, Aeolian, Locrian), specifying which note serves as the first scale degree.

# Formal Definition
Each of the twelve diatonic collections can be ordered in seven ways, corresponding to the seven church modes. The mode name specifies the pattern of whole steps and half steps relative to the starting note (which becomes scale degree 1). Within each collection, any of the seven notes can serve as the centric tone, each producing a different modal ordering. Modal orderings are distinct from the collection itself and from the centric tone.

# Mathematical Formulation/Recognition
The seven modes and their interval patterns (W = whole step, H = half step):

| Mode | Pattern | White-note equivalent |
|------|---------|----------------------|
| Ionian | W-W-H-W-W-W-H | C to C |
| Dorian | W-H-W-W-W-H-W | D to D |
| Phrygian | H-W-W-W-H-W-W | E to E |
| Lydian | W-W-W-H-W-W-H | F to F |
| Mixolydian | W-W-H-W-W-H-W | G to G |
| Aeolian | W-H-W-W-H-W-W | A to A |
| Locrian | H-W-W-H-W-W-W | B to B |

Example: DIA2# [D, E, F#, G, A, B, C#] can be:
- D Ionian, E Dorian, F# Phrygian, G Lydian, A Mixolydian, B Aeolian, C# Locrian

# Musical Context/Application
In analyzing post-tonal diatonic music:
1. Identify the collection (DIA nomenclature)
2. Determine the centric tone (if one can be identified)
3. Specify the modal ordering

This approach separates three distinct aspects of diatonic organization.

# Common Confusions
- Mode and collection are different: G Mixolydian and C Ionian use the same collection (DIA0#)
- Mode specifies the relationship between centric tone and collection pattern
- Post-tonal modal music need not follow traditional modal voice-leading conventions
- Scale-degree function in post-tonal modes differs from tonal contexts
