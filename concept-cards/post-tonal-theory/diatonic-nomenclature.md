# Quick Definition
A system for naming the twelve diatonic collections by their key signatures (number of sharps or flats), independent of centric tone or modal ordering.

# Formal Definition
DIA nomenclature identifies each of the twelve diatonic collections by its key signature, using subscripts to indicate the number of sharps (#) or flats (b). This identification is independent of scalar ordering (mode) or centric tone. For example, DIA2# refers to the diatonic collection with two sharps [F#, G, A, B, C#, D, E], which could support D Ionian, E Dorian, F# Phrygian, G Lydian, A Mixolydian, B Aeolian, or C# Locrian.

# Mathematical Formulation/Recognition
The twelve diatonic collections:

| Name | Key Signature | Pitch Classes |
|------|---------------|---------------|
| DIA0# (DIA0b) | No sharps/flats | C, D, E, F, G, A, B |
| DIA1# | 1 sharp | G, A, B, C, D, E, F# |
| DIA2# | 2 sharps | D, E, F#, G, A, B, C# |
| DIA3# | 3 sharps | A, B, C#, D, E, F#, G# |
| DIA4# | 4 sharps | E, F#, G#, A, B, C#, D# |
| DIA5# | 5 sharps | B, C#, D#, E, F#, G#, A# |
| DIA6# (DIA6b) | 6 sharps/flats | F#/Gb, G#/Ab, A#/Bb, B/Cb, C#/Db, D#/Eb, E#/F |
| DIA5b | 5 flats | Db, Eb, F, Gb, Ab, Bb, C |
| DIA4b | 4 flats | Ab, Bb, C, Db, Eb, F, G |
| DIA3b | 3 flats | Eb, F, G, Ab, Bb, C, D |
| DIA2b | 2 flats | Bb, C, D, Eb, F, G, A |
| DIA1b | 1 flat | F, G, A, Bb, C, D, E |

Each collection supports 7 modal orderings with 7 possible centric tones.

# Musical Context/Application
DIA nomenclature allows analysts to:
1. Identify collections without committing to a specific mode
2. Track collection changes through a piece
3. Discuss relationships between collections (shared tones)
4. Separate collectional identity from scalar/modal identity

# Common Confusions
- DIA names identify collections, not scales or modes
- The subscript indicates sharps/flats in the key signature, not transposition level
- DIA6# and DIA6b are the same collection (enharmonic equivalence)
- Modal ordering and centric tone are specified separately from collection name
