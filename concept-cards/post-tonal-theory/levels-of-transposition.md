# Quick Definition
The choice of transposition level is often compositionally significant, frequently replicating an interval found within the set being transposed, creating unity between local and large-scale intervallic relationships.

# Core Definition
"There is often a good reason why a composer has chosen some particular transposition" (Straus, Ch. 2). Sometimes the interval of transposition duplicates an interval within the set being transposed. When the same operation that connects notes within a set also connects the set to its transposition, this creates multi-level structural coherence -- the same musical gesture operates at both local and global levels.

# Prerequisites
- **Transposition (Tn)** -- the operation whose level is being examined
- **Mapping** -- the correspondences created by transposition

# Key Properties
1. The transposition interval may replicate an interval within the set
2. Same operation at note-level and set-level creates isographic networks
3. This multi-level coherence is a hallmark of post-tonal composition
4. The principle extends to inversion as well

# Construction / Recognition
To identify meaningful transposition levels:
1. Note the interval of transposition (Tn) connecting two statements of a set
2. Check if n appears as an interval within the set itself
3. If so, the same operation connects both note-to-note and set-to-set

# Context & Application
This concept connects to the broader post-tonal principle that local and global structures mirror each other. Analyzing not just *which* sets appear but *at what transposition levels* they appear reveals how composers create deeper structural unity. This is related to the concept of composing-out (Chapter 4).

# Examples
**Example 2-8** (p. 65, Webern, *Concerto for Nine Instruments*, op. 24): The first melodic interval is opi +8 (G to D#). T8 is also the transposition connecting the first melodic fragment to the second. The same T8 operates at both the note level and the set level.

**Model Analysis 2.1** (pp. 93--95, Schoenberg, *Book of the Hanging Gardens*, op. 15, no. 11): Five statements of sc(0347) at T0, T3, T7, T10, and T2. The succession of transposition levels (ascending by 3 then 4, then 3 then 4) replicates the opening melodic intervals (Bb--Db = +3, Db--F = +4).

# Common Errors
- **Error**: Ignoring the choice of transposition level. **Correction**: "It is never enough just to identify set classes... We will always want to know more -- why the sets occur at those particular levels" (Straus, Ch. 2).

# Common Confusions
- **Confusion**: Every transposition level must be motivically significant. **Clarification**: Not every transposition choice has an obvious motivic explanation, but it is always worth investigating.
