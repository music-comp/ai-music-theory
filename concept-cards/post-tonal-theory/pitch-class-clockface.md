# Quick Definition
The pitch-class clockface is a circular diagram representing the twelve pitch classes arranged like hours on a clock, with 0 (C) at the top, useful for visualizing pitch-class relationships.

# Formal Definition
The pitch-class clockface is a visual representation of modular pitch-class space as a circle containing the twelve pitch classes, analogous to a clock face. Pitch class 0 (C) is conventionally placed at the 12 o'clock position, with subsequent pitch classes arranged clockwise. This circular representation reflects the cyclical nature of pitch-class space, where movement by twelve semitones returns to the starting point.

# Mathematical Formulation/Recognition
The clockface arrangement:
- Position 0 (12 o'clock): C
- Position 1: C#/Db
- Position 2: D
- Position 3: D#/Eb
- Position 4: E
- Position 5: F
- Position 6: F#/Gb
- Position 7: G
- Position 8: G#/Ab
- Position 9: A
- Position 10: A#/Bb
- Position 11: B

Clockwise movement = ascending (adding semitones)
Counterclockwise movement = descending (subtracting semitones)

# Musical Context/Application
The clockface is an invaluable tool for:
- Calculating pitch-class intervals (count semitones around the circle)
- Determining normal form (find the smallest span on the clockface)
- Visualizing transpositional and inversional relationships
- Identifying interval classes (shortest distance between two points)

Linear pitch space (the grand staff) can be imagined as wrapped around onto this circular pitch-class space.

# Common Confusions
The clockface represents abstract pitch-class space, not pitch space. All octave-equivalent pitches map to the same point on the clockface. Students should remember that clockwise movement represents ascending motion (positive intervals) and counterclockwise represents descending motion (negative intervals, which can be expressed as their mod 12 complements).
