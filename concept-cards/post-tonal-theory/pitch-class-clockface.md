# Quick Definition
The pitch-class clockface is a circular diagram showing the twelve pitch classes arranged like hours on a clock, with 0 (C) at the top, used for visualizing pitch-class relationships and calculating intervals.

# Core Definition
The pitch-class clockface is a visual representation of modular pitch-class space as a circle containing the twelve pitch classes, analogous to a clock face. Pitch class 0 (C) is placed at the 12 o'clock position, with subsequent pitch classes arranged clockwise in chromatic order. The clockface illustrates that linear pitch space has been "wrapped around" onto circular pitch-class space. Clockwise movement corresponds to ascending motion (positive intervals); counterclockwise movement corresponds to descending motion (negative intervals).

# Prerequisites
- **Pitch Class** — the twelve elements placed on the clockface
- **Integer Notation** — the integers 0-11 that label the positions
- **Mod 12 Arithmetic** — the cyclic arithmetic that the clockface visualizes

# Key Properties
1. Contains exactly 12 positions (0-11), one per pitch class
2. 0 (C) is at the 12 o'clock position
3. Clockwise = ascending (positive intervals)
4. Counterclockwise = descending (negative intervals)
5. The shortest path between two points gives the interval class

# Construction / Recognition
## To Construct:
1. Draw a circle with 12 equally spaced points
2. Place 0 (C) at the top (12 o'clock)
3. Label clockwise: 1, 2, 3, ..., 11

## To Recognize:
1. A circular diagram with 12 labeled positions representing pitch classes
2. Used to visualize and calculate pitch-class intervals and relationships

# Context & Application
The clockface is the primary visual tool for pitch-class calculations in post-tonal theory. It is faster and more intuitive than the algebraic formula for calculating ordered and unordered pitch-class intervals. The clockface also aids in visualizing transposition (rotation), inversion (reflection), interval cycles, and symmetry properties of pitch-class sets.

# Common Errors
- **Error**: Placing a pitch class at the wrong position
  **Correction**: Always verify: C=0 at top, then count clockwise through the chromatic scale.

# Common Confusions
- **Confusion**: Thinking clockwise means "to the right" regardless of position
  **Clarification**: Clockwise always means ascending (adding semitones), counterclockwise always means descending (subtracting semitones), just like a clock.
