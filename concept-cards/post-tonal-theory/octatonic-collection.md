# Quick Definition
An eight-note collection, sc(0134679T), constructed from alternating semitones and whole tones, highly symmetrical with only three distinct transpositions, favored by Bartók, Stravinsky, and Messiaen.

# Formal Definition
The octatonic collection, set class (0134679T) (Forte-name 8-28), is an eight-note collection that has been a post-tonal favorite. It is highly symmetrical both transpositionally and inversionally, mapping onto itself at four levels of transposition (T0, T3, T6, T9) and four levels of inversion. As a result, there are only three distinct octatonic collections (like the complement, the diminished seventh chord). Each collection contains two of the three diminished seventh chords and excludes the third.

# Mathematical Formulation/Recognition
The three octatonic collections:

| Name | Pitch Classes | Defining Semitone |
|------|---------------|-------------------|
| OCT0,1 | [0, 1, 3, 4, 6, 7, 9, 10] | C-C# |
| OCT1,2 | [1, 2, 4, 5, 7, 8, 10, 11] | C#-D |
| OCT2,3 | [2, 3, 5, 6, 8, 9, 11, 0] | D-Eb |

Interval vector: [448444]
- Equal numbers of all interval classes except ic5 (fewer P4/P5s)
- Rich in tritones (ic6)

Symmetry: T0, T3, T6, T9 (maps onto itself)

# Musical Context/Application
The octatonic collection:
1. Contains many familiar harmonies (major/minor triads, seventh chords, diminished sevenths)
2. Can create quasi-tonal passages without functional harmony
3. Often emerges from T3 and T6 transpositional schemes
4. Provides rich subset structure

# Common Confusions
- Only three distinct octatonic collections exist (unlike 12 diatonic)
- The naming system (OCT0,1 etc.) identifies the lowest semitone, not a root
- Octatonic passages often arise from T3/T6 transposition schemes
- The collection is Messiaen's "Mode 2" (mode of limited transposition)
