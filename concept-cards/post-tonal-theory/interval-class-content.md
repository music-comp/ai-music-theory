# Quick Definition
The interval-class content of a pitch-class collection is the count of each interval class (1-6) that can be formed between pitch classes in the collection.

# Formal Definition
The interval-class content of a collection of pitch classes is the number of times each non-zero interval class can be formed between pitch classes in the collection. This content roughly suggests the sound quality of the collection. The total number of interval classes in a collection depends on the number of distinct pitch classes present. All intervals in a collection contribute to its overall sound, not just those formed by adjacent notes.

Interval-class content is tallied for each of the six non-zero interval classes (ic1 through ic6).

# Musical Context/Application
Interval-class content provides a fingerprint for the sonic character of a collection. Different composers tend to favor collections with different intervallic profiles. Comparing interval-class content reveals why certain harmonies sound similar or different.

# Examples
**Example 1-19** (Schoenberg, Three Piano Pieces, op. 11, no. 1): The three-note collection {B, G#, G} contains one each of interval classes 1, 3, and 4 (no 2s, 5s, or 6s).

**Example 1-20** (Stravinsky, The Rake's Progress): Chords containing only interval classes 2 and 5.

**Example 1-21** (Varese, Density 21.5): Melodic cells containing only interval classes 1, 5, and 6.

The different sounds of Schoenberg, Stravinsky, and Varese's harmonies reflect their different interval-class content.

# Common Confusions
Remember to count all intervals in a collection, not just those between adjacent notes. A three-note chord contains three intervals (between notes 1-2, 2-3, and 1-3), all of which contribute to its sound. The formula n(n-1)/2 gives the total number of intervals for n pitch classes.
