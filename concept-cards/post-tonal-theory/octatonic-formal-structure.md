# Quick Definition
The use of different octatonic collections to define contrasting formal sections, analogous to contrasting key areas in tonal sonata form, as demonstrated especially in Bartok's music.

# Core Definition
Just as tonal sonata form uses contrasting keys for first and second themes, post-tonal music can use contrasting **octatonic collections** to define formal sections. Each section draws its pitch material from a different octatonic collection, and the shift between collections creates the harmonic contrast that articulates the form. Within each octatonic area, a centric tone may be established through emphasis, and the relationship between centers across areas parallels the key relationships of tonal form (Straus, Model Analysis 5.2, pp. 548-564).

# Prerequisites
- **Octatonic collection** -- the three collections that define areas
- **OCT nomenclature** -- naming system for the collections
- **Centricity** -- how pitch centers function within each area

# Key Properties
1. Different formal sections use different octatonic collections
2. Centric tones within each section may relate as in traditional forms
3. Subsets (triads, (014), etc.) function differently in different collections
4. The shift between collections provides harmonic contrast
5. Only three distinct octatonic collections available (vs. twelve diatonic)

# Construction / Recognition
1. Identify the octatonic collection governing each formal section
2. Note the centric tone established within each section
3. Compare the formal function to traditional models (sonata, etc.)
4. Track how specific subsets change role across sections

# Context & Application
Bartok frequently uses this technique, organizing sonata-form movements so that contrasting themes lie in contrasting octatonic collections. The technique "reanimates the generative contrasts of sonata form within a new, post-tonal idiom."

# Examples
**Example 1** (Model Analysis 5.2, p. 548-564): Bartok, *Piano Sonata*, first movement -- First theme lies mostly within OCT1,2, centered on E triads (major or minor). Second theme lies mostly within OCT0,1, centered on A triads (major or minor). This parallels tonal sonata form: the first theme establishes a referential collection and pitch-class center; the second theme presents a transposition and new center. The E-major triad functions as primary harmony in the first theme; (014) emerges from subsidiary role in first theme to central role in second theme.

# Common Errors

# Common Confusions
- **Three vs. twelve**: With only three octatonic collections, the options for contrast are more limited than with twelve diatonic collections, making the choice of center within each collection more significant
