# Quick Definition
A property of sets that map entirely onto themselves under some inversion In; such sets can be written as intervallic palindromes and display mirror symmetry on the pitch-class clockface.

# Core Definition
A set class is inversionally symmetrical if its members can map entirely onto themselves under some inversion operation In. Every note in the set has an inversional partner also in the set. Of the 232 set classes (excluding dyads and decachords, all of which are inversionally symmetrical), 79 have this property. On the pitch-class clockface, inversionally symmetrical sets are their own mirror images around an axis. When written in order, the intervals between adjacent notes form a palindrome (Straus, pp. 123-127).

# Prerequisites
- **Inversion (In)** -- the operation under which the set is invariant
- **Inversional equivalence** -- the general concept of In-related sets
- **Common tones under inversion** -- symmetry is the maximal case

# Key Properties
1. Every note in the set has an inversional partner within the set
2. Intervals form a palindrome when the set is written in normal form
3. Mirror symmetry on the pitch-class clockface
4. 79 of 232 set classes have this property (excluding dyads/decachords)
5. Can be realized as pitch symmetry (in register) or only as pitch-class symmetry (abstract)

# Construction / Recognition
To identify inversional symmetry:
1. Write the set in normal form
2. Check if the interval sequence is a palindrome
3. Alternatively: check if on the clockface the set is its own mirror image
4. Alternatively: in the addition table, check if any sum n appears as many times as the set's cardinality
5. In the List of Set Classes: the second number in (n, m) is greater than 0

# Context & Application
Inversional symmetry creates balanced, stable-sounding harmonies and establishes axes of symmetry that can function as centers of gravity. It can be realized concretely in pitch space (pitch symmetry) or exist only abstractly in pitch-class space. The property is particularly important for establishing pitch centricity, a topic developed further in Chapter 5.

# Examples
**Example 1** (p. 123, Ex. 3-13): Three inversionally symmetrical sets as palindromes:
- [B, C, D, E, F]: intervals 1-2-2-1
- [D, E, F, A, Bb]: intervals 2-1-4-1 (with wraparound)
- [F#, G, Bb, B, D, Eb]: intervals 1-3-1-3-1

**Example 2** (p. 125, Ex. 3-16): Boulez, Le Marteau sans maitre, "L'Artisanat furieux" -- melody based entirely on inversionally symmetrical sets including (0134) and (01348).

**Example 3** (p. 126, Ex. 3-17): Varese, Hyperprism -- [C, C#, D] arranged pitch-symmetrically around C#. D enters 23 semitones below middle C#, C enters 23 semitones above. Grace notes reinforce symmetry: F (4 above C#) balanced by A (4 below C#).

# Relationships
## Builds Upon
- **Common tones under inversion** -- symmetry is when all tones are common

- **Pitch centricity** -- inversional symmetry establishes axes that function as centers
- **Symmetry and set class size** -- reduces the number of sets in the class

## Related
- **Transpositional symmetry** -- nearly all Tn-symmetrical sets are also In-symmetrical
- **Intervallic palindrome** -- the characteristic structural feature

## Contrasts With
- **Transpositional symmetry** -- rotational vs. reflective symmetry on the clockface

# Common Errors
- Confusing inversional symmetry (self-mapping under In) with inversional equivalence (two different sets related by In)
- Thinking inversional symmetry must be realized in pitch space (it often exists only in pitch-class space)

# Common Confusions
- The axis of symmetry depends on the specific index number n
- Major and minor triads are inversionally symmetrical; diminished seventh chords and octatonic scales have multiple axes of symmetry
