# Quick Definition
A property of sets that map entirely onto themselves under some inversion In; such sets can be written as intervallic palindromes and display mirror symmetry on the pitch-class clockface.

# Formal Definition
A set class is inversionally symmetrical if its members can map entirely onto themselves under some inversion operation In. Of the 232 set classes (excluding dyads and decachords, which are all inversionally symmetrical), 79 have this property.

Inversionally symmetrical sets have a characteristic structure: every note in the set has an inversional partner also in the set. When written in order, the intervals between adjacent notes form a palindrome (reading the same forward and backward).

# Mathematical Formulation/Recognition
A set is inversionally symmetrical at In if:
- Every pitch class x in the set has its In image (n - x mod 12) also in the set
- The addition table shows n appearing as many times as there are notes in the set

Visual identification:
- On the pitch-class clockface, the set is its own mirror image around some axis
- When written in order (often normal form), intervals form a palindrome

To find the axis of symmetry: The index n defines the axis. When n is even, the axis passes through n/2 and (n/2)+6. When n is odd, the axis passes between adjacent pitch classes.

# Musical Context/Application
Inversional symmetry is an important compositional resource because:
- It creates balanced, stable-sounding harmonies
- It can be realized in pitch space (pitch symmetry) or only in pitch-class space
- It establishes axes of symmetry that can function as centers of gravity
- It relates to the "mirror" quality heard in certain chord progressions

Many familiar sonorities are inversionally symmetrical, including major and minor triads, diminished seventh chords, and the octatonic scale.

# Common Confusions
- Confusing inversional symmetry (mapping onto itself under In) with inversional equivalence (two different sets related by In)
- Thinking inversional symmetry must be realized in pitch space (it often exists only in pitch-class space)
- Not recognizing that the axis of symmetry depends on the specific index number
- Confusing sets that are inversionally symmetrical with set classes that are their own inversional equivalents
