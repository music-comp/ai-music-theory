# Quick Definition
A pitch-class set is an unordered collection of pitch classes, serving as the basic building block of much post-tonal music.

# Core Definition
A pitch-class set is an *unordered collection of pitch classes*. It can be thought of as a motive from which register, rhythm, and order have been abstracted away. What remains is "simply the basic pitch-class and interval-class identity of a musical idea" (Straus, Ch. 2). A single pitch-class set can be expressed musically in many different ways -- melodically, harmonically, or in combination.

# Prerequisites
- **Pitch class** -- pitch-class sets collect pitch classes, not pitches
- **Interval class** -- interval-class identity is what persists across different presentations of the same set

# Key Properties
1. **Unordered**: {C, E, G} = {G, C, E} = {E, G, C}
2. **No duplicates**: {C, C, E, G} = {C, E, G}
3. **Notation**: curly braces {} for unordered sets; square brackets [] for normal form
4. **Elements**: listed using letter names or integers 0--11
5. **Cardinality**: can range from 0 to 12 elements; most analytically useful are 3--9

# Construction / Recognition
To identify a pitch-class set in a musical passage:
1. Identify all distinct pitch classes sounding in the grouping (exclude doublings)
2. Strip away register, rhythm, and order
3. List the remaining pitch classes as an unordered collection
4. For comparison, put into normal form

# Context & Application
Pitch-class sets enable analysts to recognize when the same collection appears in varied musical guises -- different registers, rhythms, and orderings. This reflects Schoenberg's statement: "The two-or-more-dimensional space in which musical ideas are presented is a unit." Sets allow identification of deeper structural relationships beneath a varied musical surface.

# Examples
**Example 2-1** (p. 60, Schoenberg, *Suite for Piano*, op. 25, Gavotte): The pitch-class set {Db, E, F, G} appears five times, expressed differently each time with different registers, rhythms, and orderings.

**Example 2-2** (p. 60, Wolpe, *Form for Piano*): The opening melodic statement Ab--F--Bb--A--G--E presents a six-element pitch-class set that returns twice more with notes in different registers, rhythms, and order.

# Relationships
## Builds Upon
- **Pitch class** -- sets collect pitch classes, not specific pitches
- **Interval class** -- interval-class identity defines the set's sonic character
## Enables
- **Normal form** -- standardized representation for comparison
- **Set class** -- families of related sets
- **Transposition / Inversion** -- operations on sets
## Related
- **Set notation conventions** -- bracket types distinguish ordered from unordered collections
## Contrasts With
- **Pitch set** -- pitch sets preserve register; pitch-class sets do not

# Common Errors
- **Error**: Including duplicate pitch classes. **Correction**: Each pitch class appears at most once in a set.
- **Error**: Treating order as significant. **Correction**: Pitch-class sets are unordered by definition; order matters only in normal form representation.

# Common Confusions
- **Confusion**: Confusing pitch-class sets with motives or themes. **Clarification**: A pitch-class set abstracts away register, rhythm, and order. It captures only the pitch-class and interval-class identity of a musical idea.
