# Quick Definition
A pitch-class set is an unordered collection of pitch classes, serving as the basic building block of much post-tonal music.

# Formal Definition
A pitch-class set is an unordered collection of pitch classes that can be thought of as a motive from which register, rhythm, and order have been abstracted away. What remains is the basic pitch-class and interval-class identity of a musical idea. A single pitch-class set can be expressed musically in many different ways: melodically, harmonically, or as a combination of both.

# Mathematical Formulation/Recognition
Set notation conventions:
- Curly braces {} for unordered sets: {C, E, G}
- Square brackets [] for ordered sets (normal form): [C, E, G]
- Elements listed using letter names or integers 0-11
- Duplicates are not counted (each pitch class appears once)

Properties:
- Unordered: {C, E, G} = {G, C, E} = {E, G, C}
- No duplicates: {C, C, E, G} = {C, E, G}
- Can have 0 to 12 elements (most useful are 3-9 elements)

# Musical Context/Application
Pitch-class sets provide a way to identify and compare musical ideas that appear in different registers, rhythms, and orderings. Schoenberg's statement captures this: "The two-or-more-dimensional space in which musical ideas are presented is a unit." Sets allow analysts to recognize when the same pitch-class collection appears in varied musical guises.

# Examples
**Example 2-1** (Schoenberg, Suite for Piano, op. 25, Gavotte): A single pitch-class set {Db, E, F, G} appears five times, expressed differently each time with different registers, rhythms, and orderings.

**Example 2-2** (Wolpe, Form for Piano): The opening melodic statement of six pitch classes {Ab, F, Bb, A, G, E} is stated three times with notes in different registers, rhythms, and order.

# Common Confusions
A pitch-class set is unordered by definition. The order of elements does not matter: {C, E, G} and {G, E, C} are the same set. To compare sets systematically, we put them into normal form, which is an ordered representation of the unordered set.
