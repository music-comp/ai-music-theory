# Quick Definition
Complement-related set classes share not only proportional interval content but also identical degree of symmetry (and thus the same number of members) and shared Z-relation status.

# Core Definition
Complementary set classes share affinities beyond their proportional interval distributions. They always have the same degree of symmetry (both Tn and In), meaning they contain the same number of sets in their respective classes. Furthermore, if Set X is Z-related to Set Y, then the complement of X is Z-related to the complement of Y. These shared properties demonstrate that complementation preserves deep structural features of set classes (Straus, p. 136).

# Prerequisites
- **Complement relation** -- the base relationship
- **Degrees of transpositional symmetry** and **Degrees of inversional symmetry** -- the shared property

# Key Properties
1. Same degree of symmetry (n, m) for complement-related set classes
2. Same number of sets in each class (24 / total operations)
3. Z-relation preserved: complement of a Z-correspondent is Z-related to complement of its partner
4. These properties are visible in the List of Set Classes (compare across rows)

# Context & Application
These shared properties reinforce the complement relation as a deep structural relationship, not merely an intervallic coincidence. They constrain the organization of the List of Set Classes and have implications for twelve-tone music, where row structure depends on complementary hexachords.

# Examples

**Example 2**: 5-Z12 is Z-related to 5-Z36; correspondingly, 7-Z12 is Z-related to 7-Z36. The Z-relation is preserved under complementation.
