# Quick Definition
The two possible scalar arrangements of the hexatonic collection: the 1-3 ordering (alternating semitone-minor third) and the 3-1 ordering (alternating minor third-semitone).

# Formal Definition
When written out as a scale, the hexatonic collection alternates intervals of 1 and 3 semitones (compare the octatonic, which alternates 1s and 2s). Like the octatonic, there are only two distinct interval orderings: 1-3-1-3-1-3 (beginning with a semitone) or 3-1-3-1-3-1 (beginning with a minor third). Each of the four hexatonic collections can be presented in either ordering, starting on any of three notes for each ordering type.

# Mathematical Formulation/Recognition
The two orderings:

1-3 ordering:
- Interval pattern: 1-3-1-3-1-3
- Example (HEX0,1): C-C#-E-F-G#-A-C

3-1 ordering:
- Interval pattern: 3-1-3-1-3-1
- Example (HEX0,1): C#-E-F-G#-A-C-C#

For each collection and ordering, there are 3 possible starting notes (related by T4):
- HEX0,1, 1-3: can start on C, E, or G#
- HEX0,1, 3-1: can start on C#, F, or A

Total: 4 collections x 2 orderings x 3 starting points = 24 scales

# Musical Context/Application
Hexatonic orderings are relevant when:
1. Analyzing scalar melodic passages in hexatonic contexts
2. Understanding the alternating semitone-minor third pattern
3. Relating hexatonic scales to augmented triad structures
4. Connecting scalar patterns to the underlying LP-cycle

# Common Confusions
- There are only 2 orderings (like octatonic, unlike diatonic's 7)
- The ordering concerns interval pattern, not which collection
- Each augmented triad provides starting points for one ordering type
- The minor third interval (3) distinguishes hexatonic from octatonic (which uses 2)
