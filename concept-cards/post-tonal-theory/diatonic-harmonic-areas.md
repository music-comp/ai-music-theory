# Quick Definition
Distinct sections of post-tonal music defined by the diatonic collection in use, where changes in collection (identified by key signature) create a sense of large-scale harmonic motion analogous to tonal modulation.

# Core Definition
In post-tonal diatonic music, **harmonic areas** are defined by the diatonic collection in use rather than by traditional key relationships. When the collection changes (e.g., from DIA0# to DIA1#), the shift conveys a sense of large-scale movement from one harmonic area to another, analogous to modulation in tonal music. The shift may be accompanied by a change in centric tone, modal ordering, or both (Straus, Ch. 5, pp. 260-262).

# Prerequisites
- **Diatonic collection** -- the collection defining each area
- **DIA nomenclature** -- naming system for identifying collections
- **Centricity** -- how centers operate within each area

# Key Properties
1. Each harmonic area is defined by a diatonic collection (identified by key signature)
2. Changes in collection create formal articulation
3. Collection change may or may not coincide with centric tone change
4. The shift carries three dimensions: collection, center, and modal ordering
5. Adjacent collections on the circle of fifths share six common tones

# Construction / Recognition
1. Identify the diatonic collection for each section (check for accidentals)
2. Note when accidentals change, indicating a collection shift
3. Determine the centric tone (if identifiable) for each section
4. Specify the modal ordering
5. Track the three dimensions (collection, center, mode) independently

# Context & Application
This framework applies especially to Stravinsky's neoclassical works and minimalist music. The collection change itself creates harmonic contrast, even when the centric mechanism (e.g., emphasis, repetition) remains the same.

# Examples
**Example 1** (p. 261): Stravinsky, *Petrushka*, Russian Dance -- First 8 measures: DIA0# (no sharps/flats), centered on G, G Mixolydian. At m. 9: DIA1# (one sharp), centered on A, A Dorian. All three dimensions change: collection, center, and modal ordering.

**Example 2** (p. 264): Reich, *Piano Phase* -- Uses only five notes of DIA2# throughout. The collection is static, but rhythmic phase-shifting creates harmonic variety within the unchanging collection.

# Common Errors
- Assuming collection change always means key change (it may involve only a single accidental)

# Common Confusions
- **Three independent dimensions**: Collection, center, and mode can change independently. G Mixolydian and A Dorian use the same collection but different centers and modes.
