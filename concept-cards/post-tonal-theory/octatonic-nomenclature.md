# Quick Definition
A naming system for the three octatonic collections using subscript pairs that indicate the numerically lowest pitch-class semitone each collection contains: OCT0,1, OCT1,2, and OCT2,3.

# Formal Definition
OCT nomenclature identifies each of the three octatonic collections by the numerically lowest pitch-class semitone (adjacent pitch-class pair) it contains. Since the octatonic collection contains four semitones, the lowest one uniquely identifies the collection. The subscript consists of two adjacent pitch-class integers representing this defining semitone.

# Mathematical Formulation/Recognition
The three octatonic collections:

| Name | Defining Semitone | Contains Semitones | Pitch Classes |
|------|-------------------|-------------------|---------------|
| OCT0,1 | C-C# (0-1) | 0-1, 3-4, 6-7, 9-10 | [0, 1, 3, 4, 6, 7, 9, 10] |
| OCT1,2 | C#-D (1-2) | 1-2, 4-5, 7-8, 10-11 | [1, 2, 4, 5, 7, 8, 10, 11] |
| OCT2,3 | D-Eb (2-3) | 2-3, 5-6, 8-9, 11-0 | [2, 3, 5, 6, 8, 9, 11, 0] |

Quick identification:
- If collection contains C and C#: OCT0,1
- If collection contains C# and D (but not C): OCT1,2
- If collection contains D and Eb (but not C# or C): OCT2,3

# Musical Context/Application
OCT nomenclature allows:
1. Unambiguous identification of the collection in use
2. Tracking of collection changes through a piece
3. Discussion of relationships between the three collections
4. Analysis independent of scalar ordering or centric pitch

# Common Confusions
- The subscript identifies the collection, not a starting note or "root"
- OCT0,1 is not "the octatonic on C"; it is the collection containing the C-C# semitone
- Any of the eight notes can serve as a centric pitch or starting point for scalar ordering
- The three collections are related by T1 (not T3 or T4)
