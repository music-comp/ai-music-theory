# Quick Definition
A set class relationship where some transposed or inverted form of Set X is contained within Set Y; abstract subsets preserve set-class inclusion even when specific pitch classes do not match.

# Formal Definition
Set X is an abstract subset of Set Y if any transposed or inverted form of X (i.e., any member of the set class containing X) is found among the literal subsets of Y. In other words, the set class of X is contained within Y.

This generalizes the subset concept to set-class level: we say sc(X) is an abstract subset of sc(Y) when any member of sc(Y) contains at least one literal subset that belongs to sc(X).

Abstract subset relations persist under transposition and inversion of the superset.

# Mathematical Formulation/Recognition
X is an abstract subset of Y if:
- Some Tn(X) or In(X) is a literal subset of Y
- Equivalently: the set class of X appears among the subset classes of Y

To determine:
1. List all literal subsets of Y (of appropriate cardinality)
2. Put them in prime form
3. If the prime form of X matches any of them, X is an abstract subset of Y

Abstract subset is a relation between set classes, not just individual sets.

# Musical Context/Application
Abstract subsets are valuable for:
- Describing systematic relationships between set classes
- Understanding which smaller set types "fit inside" larger ones
- Analyzing motivic connections that persist across transpositions
- Building inclusion lattices showing hierarchical set-class relationships

Abstract subset relations show what is compositionally possible: if sc(X) is an abstract subset of sc(Y), then forms of X can always be found within forms of Y.

# Examples
From Example 3-33:
- Y = [E, F, G, Bb] = sc(0136)
- [E, F, G] is a literal subset, belonging to sc(013)
- [A, Bb, C] is NOT a literal subset (A and C are not in Y)
- But [A, Bb, C] IS an abstract subset: it's T5 of [E, F, G]
- The set class (013) is an abstract subset of (0136)

From Example 3-30: Inclusion lattice for (014589)
- (0148) is an abstract subset of (014589)
- (048) is an abstract subset of both (0148) and (014589)
- These relations hold regardless of which specific transposition we examine

Saying "sc(013) is a subset of sc(0136)" means:
- Every member of sc(0136) contains at least one member of sc(013)
- This is an abstract subset relationship between set classes

# Common Confusions
- Confusing abstract with literal subset (abstract doesn't require pitch-class match)
- Thinking that because [A, Bb, C] is not literally in [E, F, G, Bb], they have no subset relation (they have an abstract relation)
- Not recognizing that abstract subset is a set-class-level concept
- Assuming all members of a superset class contain the same number of each subset type (this varies)
