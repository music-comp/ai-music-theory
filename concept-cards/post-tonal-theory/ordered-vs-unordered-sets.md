# Quick Definition
Unordered sets (pitch-class sets) retain their identity regardless of how elements are arranged, while ordered sets (series) have a fixed sequence where changing the order changes the identity.

# Formal Definition
An *unordered set* is a collection of pitch classes where the identity of the set depends only on its content—the same pitch classes in any arrangement constitute the same set. An *ordered set* (or *series*) is a succession of pitch classes where the identity depends on both content and the specific sequence—changing the order produces a different series. Previous chapters focused on unordered sets; twelve-tone music concentrates on ordered sets.

# Mathematical Formulation/Recognition
- **Unordered set**: {C, E, G} = {G, C, E} = {E, G, C} (all represent the same set)
- **Ordered set**: <C, E, G> ≠ <G, C, E> ≠ <E, G, C> (different orderings = different series)
- Notation: Curly braces {} for unordered sets; angle brackets <> or parentheses () for ordered sets
- Set class membership is determined by unordered content; series identity requires ordered content

# Musical Context/Application
- In atonal analysis (Chapters 1-5), unordered pitch-class sets are the primary analytical units
- In twelve-tone music (Chapter 6), the ordered series becomes the fundamental structure
- The distinction is crucial because twelve-tone transformations (P, R, I, RI) operate on the order of pitch classes
- While both ordered and unordered perspectives can be useful, twelve-tone composition specifically depends on ordered relationships

# Examples
- The pitch classes {D, C#, A} form the same unordered set regardless of arrangement
- The series <D, C#, A> is different from <C#, D, A> or <A, C#, D>
- In Schoenberg's String Quartet No. 4, the specific ordering D-C#-A-Bb-F-Eb-E-C-Ab-G-F#-B defines P2

# Common Confusions
- Applying unordered set-class analysis without considering the crucial role of order in twelve-tone contexts
- Forgetting that the same 12 pitch classes in different orders constitute different series
- Conflating set-class equivalence (which ignores order) with series equivalence (which requires identical ordering under transformation)
