# Quick Definition
A pitch class is a group of pitches related by octave and enharmonic equivalence, all sharing the same (or enharmonically equivalent) letter name.

# Formal Definition
A pitch class is a collection of pitches related by octave and enharmonic equivalence. Pitch-class A, for example, contains all the pitches named A (in any octave), and any pitch named A is a member or representative of pitch-class A. There are exactly twelve pitch classes in the equal-tempered system. A pitch class is an abstraction that cannot be adequately notated on musical staves; rather, it represents a class of things (pitches one or more octaves apart with the same or enharmonic names).

# Mathematical Formulation/Recognition
Pitch classes are represented using integers 0-11:
| Integer | Pitch-Class Content |
|---------|---------------------|
| 0 | B#, C, Dbb |
| 1 | C#, Db |
| 2 | C##, D, Ebb |
| 3 | D#, Eb |
| 4 | D##, E, Fb |
| 5 | E#, F, Gbb |
| 6 | F#, Gb |
| 7 | F##, G, Abb |
| 8 | G#, Ab |
| 9 | G##, A, Bbb |
| 10 | A#, Bb |
| 11 | A##, B, Cb |

# Musical Context/Application
Pitch class is a fundamental abstraction in post-tonal theory that allows analysts to identify relationships between musical events occurring in different registers. When analyzing post-tonal music, we often describe collections in terms of their pitch-class content rather than specific pitches, revealing deeper structural connections.

# Examples
**Example 1-5** (Feldman, Durations III, No. 3): Each of the three instruments plays a series of notes spanning many different pitches, but the passage as a whole uses only three pitch classes: F#, G, and Ab. The tuba plays five different pitches, but these are all representatives of the same small set of pitch classes.

# Common Confusions
A pitch class is not a single thing but a class of things. Students sometimes treat pitch classes as if they were pitches, but pitch classes are abstract categories. When we notate a pitch class for convenience (e.g., putting a C on a staff), we are representing the entire class, not just that specific pitch.
