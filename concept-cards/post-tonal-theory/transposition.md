# Quick Definition
Transposition (Tn) is an operation that adds a fixed interval n to every pitch class in a set or line, producing a new set or line at a different pitch level.

# Formal Definition
Transposition is an operation represented as Tn, where T stands for transposition and n is the transposition number (the interval of transposition, 0-11). When transposing a line of pitches, order is preserved and so are the ordered pitch intervals (contour). When transposing a line of pitch classes, ordered pitch-class intervals are preserved. When transposing a set of pitch classes, interval-class content is preserved but not order or contour.

# Mathematical Formulation/Recognition
**For a single pitch class x:**
Tn(x) = (x + n) mod 12

**For a set {a, b, c, ...}:**
Tn{a, b, c} = {(a+n), (b+n), (c+n)} mod 12

**Recognition of transpositionally related sets:**
- Put both in normal form
- Check if they have the same interval succession
- Calculate n by subtracting corresponding elements: n = y - x (mod 12)

**Inverse transposition:**
- Tn and T(12-n) are inverses
- Tn followed by T(12-n) = T0 (identity)

# Musical Context/Application
Transposition is a fundamental means of developing musical material in post-tonal music. Sets related by transposition share the same interval-class content, giving them a similar sound quality. The choice of transposition level is often meaningful, frequently replicating intervals found within the set being transposed.

# Examples
**Example 2-5** (Schoenberg, String Quartet No. 4): Two melodies related by T6. Despite different contours, their ordered pitch-class intervals are identical: 11-8-1-7-10-1-8-8-11-11-5.

**Example 2-7** (Webern, Concerto for Nine Instruments, op. 24): Four pitch-class sets related by successive transpositions: T11, T6, and T3.

**Example 2-8** (Webern): The interval of transposition (T8) duplicates an interval within the set (the opening melodic interval opi+8).

# Common Confusions
Transposition of a set preserves interval-class content but not necessarily order or contour. When sets are in normal form, the first note of one corresponds to the first note of the other, etc. If a set is in normal form, its transposition will also be in normal form.
