# Quick Definition
In post-tonal theory, intervals are measured by the number of semitones they contain, rather than by diatonic steps or traditional quality designations.

# Core Definition
Post-tonal theory names intervals by the number of semitones they contain, abandoning traditional diatonic names (major third, diminished fifth, etc.). Since post-tonal music does not necessarily reference diatonic scales, traditional interval names can be cumbersome or misleading. Enharmonically equivalent intervals (like a major third and a diminished fourth) are treated as the same interval because both contain four semitones. The semitone is the basic unit of measurement for all interval types in post-tonal analysis.

# Prerequisites
- **Enharmonic Equivalence** — enharmonically equivalent intervals are treated as the same interval

# Key Properties
1. Intervals are counted as integers representing the number of semitones
2. Traditional quality distinctions (major, minor, augmented, diminished) are collapsed
3. Enharmonically equivalent intervals receive the same number (e.g., major 3rd = diminished 4th = 4)
4. The system extends to compound intervals (13 = minor 9th, 14 = major 9th, etc.)

# Construction / Recognition
## To Construct:
1. Count the number of semitones between the two pitches on a keyboard or staff
2. Express the result as an integer

## To Recognize:
1. An interval expressed as a single integer rather than a traditional name

# Context & Application
Measuring intervals in semitones is essential for post-tonal analysis because post-tonal music does not necessarily reference diatonic scales, making traditional interval names potentially misleading. The semitone-based system allows precise, unambiguous description of intervallic relationships and supports mathematical operations.

# Examples
**Example 1-9** (p. 24): In Carter, String Quartet No. 3, a series of seven harmonic intervals played in rhythmic unison. The first six are spelled as major thirds and the seventh as a diminished fourth, but in context all seven are understood as enharmonically equivalent: all are 4s, or compound (octave-equivalent) 4s.

# Common Errors
- **Error**: Using traditional interval names in post-tonal analysis
  **Correction**: Use semitone counts. A "major third" is simply interval 4.

# Common Confusions
- **Confusion**: Thinking a diminished fourth is different from a major third in post-tonal context
  **Clarification**: Both are 4 semitones. Post-tonal theory treats them as the same interval.
