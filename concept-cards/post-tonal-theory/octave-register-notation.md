# Quick Definition
Octave-register notation designates specific pitches using a letter name plus an octave number, where middle C is C4.

# Core Definition
Octave-register notation identifies a specific pitch by combining its letter name (with accidentals as needed) with a number indicating its octave register. Middle C is designated C4. The system numbers octaves starting from the lowest: the lowest C on the piano is C1, and each octave extends up to the next B. This system distinguishes specific pitches from abstract pitch classes.

- (none)

# Key Properties
1. Middle C = C4
2. Each octave number spans from C to B (e.g., C4, D4, E4, ..., B4)
3. Moving up one octave increments the number by 1 (C4 to C5)
4. Uniquely identifies any specific pitch

# Construction / Recognition
## To Construct:
1. Determine the letter name (A-G, with accidentals)
2. Determine the octave register (middle C = C4 as reference)
3. Combine: e.g., F#5, Bb3, C2

## To Recognize:
1. A letter name followed by a number (e.g., A4, C2, G#5)

# Context & Application
Straus uses octave-register notation to distinguish between specific pitches and abstract pitch classes. "When we say that the lowest note on the cello is a C, we are referring to a specific pitch ... the lowest note on the cello is thus C2." This notation is essential when pitch-space analysis (as opposed to pitch-class-space analysis) is required.

# Examples
**From the text** (p. 20): "We can refer to [middle C] using the numerical designation of middle C as C4 -- the lowest note on the cello is thus C2."

# Common Errors
- **Error**: Confusing octave-register notation (e.g., C4) with pitch-class integers (e.g., 0)
  **Correction**: C4 is a specific pitch; 0 is a pitch class. C2, C3, C4 are all different pitches but all belong to pitch class 0.

# Common Confusions
- **Confusion**: Thinking all notation with numbers refers to pitch classes
  **Clarification**: C4 designates a pitch (with register); the integer 0 designates a pitch class (without register). The two systems serve different purposes.
