# Quick Definition
A 12×12 matrix is a grid displaying all forty-eight forms of a twelve-tone series, with P-forms read left-to-right, R-forms right-to-left, I-forms top-to-bottom, and RI-forms bottom-to-top.

# Formal Definition
A *12×12 matrix* is the simplest way to construct a list of all forty-eight forms of a series. The matrix is a 12-row by 12-column grid containing pitch-class integers. The rows reading from left to right contain all of the prime forms, and reading from right to left, the retrograde forms. The columns reading from top to bottom contain all of the inverted forms, and from bottom to top, the retrograde-inversion forms. The matrix can also be written using letter names instead of integers.

# Mathematical Formulation/Recognition
**Construction Steps:**
1. Write P0 horizontally across the top row
2. Write I0 vertically down the left column
3. Fill in remaining rows as prime orderings, starting on whatever pitch class is in the first column
4. The second row will be P_x where x is the second note of I0, the third row P_y, etc.

**Reading the Matrix:**
- Left to right: P-forms (row n contains P_n where n is the first element)
- Right to left: R-forms (R_n ends on pc n)
- Top to bottom: I-forms (column n contains I_n where n is the first element)
- Bottom to top: RI-forms (RI_n ends on pc n)

# Musical Context/Application
- Provides a quick reference for all 48 series forms during analysis
- Essential tool for twelve-counting a piece
- Reveals relationships between series forms at a glance
- Shows which forms share starting or ending notes
- Useful for identifying combinatorial relationships

# Examples
Schoenberg, String Quartet No. 4 matrix (partial):
```
     I
     0  11  7  8  3  1  2  10  6  5  4  9
P  1  0   8  9  4  2  3  11  7  6  5  10   R
   5  4   0  1  8  6  7   3 11 10  9   2
   ...
     RI
```
- P0 is the top row (read left to right)
- I0 is the first column (read top to bottom)
- Each row is a P-form; each column is an I-form

# Common Confusions
- Incorrect construction order—must start with P0 across and I0 down
- Reading R-forms and RI-forms in the wrong direction
- Forgetting that R_n and RI_n end on (rather than begin on) pitch-class n
- Not realizing the matrix shows pitch-class integers, not order positions
