# Quick Definition
The four types of hexachordal combinatoriality are I-combinatoriality (hexachords I-related to each other), P-combinatoriality (hexachords T-related to each other), RI-combinatoriality (hexachords I-related to themselves), and R-combinatoriality (hexachords T-related to themselves).

# Core Definition
"There are four different kinds of hexachordal combinatoriality: I-combinatoriality (Schoenberg's kind), P-combinatoriality, RI-combinatoriality, and R-combinatoriality. These are determined by the capacity of a hexachord for transposing or inverting onto its complement or onto itself" (Straus, p. 339).

The four types:
1. **I-combinatoriality**: H1 and H2 are I-related to each other (P combines with I_x)
2. **P-combinatoriality**: H1 and H2 are T-related to each other (P combines with P_x)
3. **RI-combinatoriality**: H1 and H2 are I-related to themselves (P combines with RI_x)
4. **R-combinatoriality**: H1 and H2 are T-related to themselves (P combines with R_x)

# Prerequisites
- **Hexachordal combinatoriality** -- the general concept being classified

# Key Properties
1. Each type involves a different mapping: complement via T, complement via I, self via T, self via I
2. Not all hexachords possess all types
3. I-combinatoriality is the most common (Schoenberg's primary method)
4. P-combinatoriality is the rarest (only one hexachord type)
5. R-combinatoriality at T0 is trivial (all hexachords map onto themselves)
6. Six hexachords (A--F) possess all four types

# Construction / Recognition
- P: Does T_n(H1) = H2 for some n? Then P_0 + P_n produces aggregates
- I: Does I_n(H1) = H2? Then P_0 + I_n produces aggregates
- R: Does T_n(H1) = H1? Then P_0 + R_n produces aggregates
- RI: Does I_n(H1) = H1? Then P_0 + RI_n produces aggregates

# Context & Application
The four types provide different ways of creating aggregates between series forms. Schoenberg primarily used I-combinatoriality. Babbitt explored all types extensively. The combinatoriality chart (Ex. 6-37) lists all hexachords possessing each type.

# Common Errors
- Confusing the four types (each involves different mappings: complement vs. self, T vs. I)
- Forgetting that R-combinatoriality at T0 is trivial
- Not recognizing that a hexachord can have multiple types simultaneously

# Common Confusions
- **Complement vs. self**: I and P map onto the complement; RI and R map onto themselves
- **T vs. I**: P and R use transposition; I and RI use inversion
