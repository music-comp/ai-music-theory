# Quick Definition
The four serial transformations create systematic intervallic relationships: P-related forms share the same intervals in the same order; I-related have complementary intervals in the same order; RI-related have the same intervals reversed; R-related have complementary intervals reversed.

# Core Definition
"Series that have the same ordering (P and P, I and I, R and R, or RI and RI) are said to be *prime-related* and have the same intervals in the same order" (Straus, p. 317). The complete relationship table:
1. **Prime-related** (P-P, I-I, R-R, RI-RI): same intervals, same order
2. **Inversion-related** (P-I, R-RI): complementary intervals, same order
3. **RI-related** (P-RI, I-R): same intervals, reverse order
4. **Retrograde-related** (P-R, I-RI): complementary intervals, reverse order

# Prerequisites
- **Series class** -- the family within which these relationships exist

# Key Properties
1. Four distinct intervallic relationships among the four transformations
2. Complement of interval n = (12 - n) mod 12
3. P and RI are intervallically closest (same intervals, just reversed)
4. P and R are intervallically most distant (both complemented and reversed)
5. All 48 forms share the same predominant/excluded intervals

# Construction / Recognition
Given P's interval succession <a, b, c, ..., k>:
- P-related: <a, b, c, ..., k>
- I-related: <12-a, 12-b, 12-c, ..., 12-k>
- R-related: <12-k, ..., 12-c, 12-b, 12-a>
- RI-related: <k, ..., c, b, a>

# Context & Application
These relationships explain why all series forms share a characteristic sound. Understanding them enables efficient series form identification and reveals why certain form-pairs create more or less similar musical effects.

# Examples
**Example 1** (p. 316, Ex. 6-7): Schoenberg, String Quartet No. 4:
- Prime: 11, 8, 1, 7, 10, 1, 8, 8, 11, 11, 5
- Retrograde: 7, 1, 1, 4, 4, 11, 2, 5, 11, 4, 1
- Inversion: 1, 4, 11, 5, 2, 11, 4, 4, 1, 1, 7
- Retrograde-Inversion: 5, 11, 11, 8, 8, 1, 10, 7, 1, 8, 11

Intervals 1, 4, 8, 11 predominate; intervals 3, 9 are completely excluded in all four orderings.

# Common Errors
- Confusing which pairs have "same" vs. "complementary" intervals
- Confusing which pairs have "same order" vs. "reverse order"

# Common Confusions
- **P and RI seem dissimilar in pitch class but are very similar in interval content** -- a counterintuitive but important relationship
