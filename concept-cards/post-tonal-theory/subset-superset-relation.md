# Quick Definition
The relationship where one set is contained within another; if Set X is included in Set Y, then X is a subset of Y and Y is a superset of X.

# Formal Definition
Set X is a subset of Set Y if every pitch class in X is also in Y. Conversely, Y is a superset of X. A set containing n pitch classes will contain 2^n total subsets, including:
- The null set (empty set)
- n one-note sets (singletons)
- Various sets of sizes 2 through n-1
- The set itself (the "improper subset")

The subset/superset relation can be either literal (actual pitch-class containment) or abstract (set class inclusion).

# Mathematical Formulation/Recognition
For a set S with cardinality n:
- Total number of subsets = 2^n
- Subsets of musical interest = 2^n - (n + 2) (excluding null set, singletons, and improper subset)

Example: A 4-note set contains:
- 1 null set
- 4 one-note sets
- 6 two-note sets (dyads)
- 4 three-note sets (trichords)
- 1 four-note set (itself)
- Total: 2^4 = 16 subsets

Subset notation: X is a subset of Y, or Y is a superset of X.

# Musical Context/Application
Subset/superset relations are important for:
- Understanding how smaller motives relate to larger harmonies
- Analyzing how composers project certain subsets of a larger collection
- Examining inclusion relationships between set classes
- Tracing motivic connections across different cardinalities

Composers choose which subsets to emphasize through register, articulation, rhythm, and other musical parameters. The subsets of a set are a kind of abstract potential; compositional choices determine which are highlighted.

# Examples
From Example 3-28: A four-note set [G#, A, B, C] contains:
- 4 trichordal subsets: [G#, A, B], [G#, A, C], [G#, B, C], [A, B, C]
- 6 dyadic subsets: [G#, A], [G#, B], [G#, C], [A, B], [A, C], [B, C]
- Plus singletons and null set
- Total: 16 subsets

From Example 3-29: sc(0268) - all four trichordal subsets are members of the same set class (026). This redundancy is characteristic of highly symmetrical sets.

From Example 3-31: Schoenberg, Little Piano Pieces, op. 19, no. 2
- Chord is member of sc(014589)
- Highest and lowest 4 notes project sc(0148)
- Highest and lowest 3 notes are augmented triads sc(048)
- Composer chooses which subsets to emphasize registrally

# Common Confusions
- Thinking all subsets are equally important musically (only those articulated compositionally matter)
- Confusing literal subsets (specific pitch classes) with abstract subsets (set class relationships)
- Not recognizing that subsets of the same type create redundancy
- Forgetting that the improper subset (the set itself) is technically a subset
