# Quick Definition
A set class is a family of pitch-class sets all related to each other by either transposition (Tn) or inversion (In), sharing the same interval-class content.

# Core Definition
A set class (also called a *T/I set class*) is a collection of pitch-class sets where each member is related to every other member by transposition or inversion. All members share the same interval-class vector. A typical set class contains 24 members: two Tn-types of 12 sets each. Some symmetrical sets produce set classes with fewer members (e.g., the diminished seventh chord has only 3 distinct members; the whole-tone scale has only 2). Set classes are identified by their prime form. "Every pitch-class set belongs to a single set class" (Straus, Ch. 2).

# Prerequisites
- **Pitch-class set** -- set classes collect pitch-class sets
- **Transposition (Tn)** -- one of the equivalence operations
- **Inversion (In)** -- the other equivalence operation
- **Normal form** -- facilitates comparison and identification

# Key Properties
1. Usually contains two Tn-types, each with 12 sets (total: 24)
2. All members share the same interval-class vector
3. Identified by prime form: sc(014), sc(0134), etc.
4. Fewer members for symmetrical sets
5. Every pitch-class set belongs to exactly one set class

# Construction / Recognition
**To identify set-class membership:**
1. Put the set in prime form
2. Consult the List of Set Classes
3. All sets with the same prime form belong to the same set class

**Structure of a set class:**
- Column 1: a set and all 12 of its transpositions (one Tn-type)
- Column 2: the inverted set and all 12 of its transpositions (other Tn-type)
- Within columns: related by transposition
- Between columns: related by inversion

# Context & Application
Set-class membership is "an important part of post-tonal musical structure" (Straus, Ch. 2). By moving from set to set within a single set class, a composer creates coherent, directed musical movement. The mere presence of many members of a single set class guarantees a certain sonic unity. Analysts are often interested not just in set-class membership but in the specific Tn and In paths connecting the members.

# Relationships
## Builds Upon
- **Transpositional equivalence** -- one component of set-class equivalence
- **Inversional equivalence** -- the other component
## Enables
- **Prime form** -- the identifier for a set class
- **Musical coherence** -- set-class membership creates sonic unity
## Related
- **Forte names** -- alternative labeling system (3-11, 4-Z29, etc.)
- **List of Set Classes** -- comprehensive catalog
- **Interval-class vector** -- shared by all members
## Contrasts With
- **Tn-type** -- a Tn-type is more restrictive (transposition only); a set class typically contains two Tn-types

# Common Errors
- **Error**: Thinking "is a (014)" means literally the set {0, 1, 4}. **Correction**: It means "is a member of set class (014)" -- any of the 24 sets in that family.

# Common Confusions
- **Confusion**: Set class vs. pitch-class set. **Clarification**: A set class is a family of related sets; a pitch-class set is a specific collection. The statement "this passage is saturated with (014)" means many different members of that set class appear.
