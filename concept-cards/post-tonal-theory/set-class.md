# Quick Definition
A set class is a family of pitch-class sets that are all related to each other by either transposition or inversion, sharing the same interval-class content.

# Formal Definition
A set class (also called a T/I set class) is a collection of pitch-class sets where each member is related to every other member by transposition (Tn) or inversion (In). All members of a set class share the same interval-class vector. A typical set class contains 24 members: 12 transpositions of a set and 12 transpositions of its inversion. Some symmetrical sets produce set classes with fewer members. Set classes are identified by their prime form.

# Mathematical Formulation/Recognition
**Structure of a set class:**
- Usually contains two Tn-types (transpositionally related families)
- Each Tn-type contains 12 sets (one at each transposition level)
- Total: typically 24 sets per set class
- Fewer for symmetrical sets

**Identifying set-class membership:**
1. Put the set in prime form
2. Consult the List of Set Classes
3. All sets with the same prime form belong to the same set class

**Notation:**
sc(prime form) - e.g., sc(014), sc(0134)

# Musical Context/Application
Set-class membership creates coherence in post-tonal music. Moving from set to set within a single set class maintains interval-class consistency while allowing variety in pitch-class content and registral placement. Composers use set classes as a source of unity, analogous to how tonal composers use key relationships.

# Examples
**Example 2-29**: Twenty-four sets belonging to a single T/I set class, arranged in two columns (one Tn-type each). Within each column, sets are related by transposition; between columns, they're related by inversion.

**Example 2-30** (Crumb, "Gargoyles"): Twelve trichords all belonging to sc(016). Right-hand trichords are related by transposition; left-hand by transposition; hands relate by inversion.

**Example 2-32** (Schoenberg, Three Piano Pieces, op. 11, no. 1): Multiple members of sc(014) create a network of relationships, with the opening three-note motive developed through transposition and inversion.

# Common Confusions
A set class is not the same as a pitch-class set. A set class is a family of related sets, while a pitch-class set is a specific collection. The sentence "this passage is saturated with (014)" means the passage contains many members of set class (014), not just the specific set {0, 1, 4}.
