# Quick Definition
Set-class membership creates coherence in post-tonal music: the recurring presence of members of a single set class guarantees a certain sonic unity, while directed transposition and inversion among those members creates purposeful musical motion.

# Core Definition
"The mere presence of many members of a single set class guarantees a certain kind of sonic unity. But we often will be more interested in the ways in which the music moves from set to set within a set class than in the simple fact of set-class membership" (Straus, Ch. 2). Coherence in post-tonal music is often created by relationships among sets within a set class, as one or more sets are transposed and inverted in purposeful, directed ways. Multiple paths through the music may intersect, diverge, or run parallel.

# Prerequisites
- **Set class** -- the family of related sets
- **Transposition (Tn)** -- one means of moving between members
- **Inversion (In)** -- the other means of moving between members

# Key Properties
1. Sonic unity from shared interval-class content
2. Directed musical motion from specific Tn and In paths
3. Multiple simultaneous analytical strands are common
4. A set class can appear melodically, harmonically, or in combination
5. "Saturation" = a passage pervaded by members of a single set class

# Construction / Recognition
To analyze set-class membership in a passage:
1. Identify recurring set classes through segmentation
2. Put each instance in normal form
3. Determine the Tn or In relating each pair
4. Build networks showing how the music moves from set to set
5. Look for connections between transposition/inversion levels and intervals within the sets

# Context & Application
"It is never enough just to identify set classes or just to point out that two collections are members of the same set class. We will always want to know more -- why the sets occur at those particular levels of transposition or inversion, and why they occur in the order they do" (Straus, Ch. 2). The analytical goal is to trace purposeful paths through set-class space.

# Examples
**Example 2-32** (p. 81, Schoenberg, *Three Piano Pieces*, op. 11, no. 1): The passage is "virtually saturated with occurrences of members of [sc(014)]." It appears as a melodic fragment, a chord, a combination of melody and chord, articulated by register, and over a large span by contour. "An entire network of musical associations thus radiates out from the opening three-note melodic figure."

**Example 2-30** (p. 79, Crumb, "Gargoyles"): Twelve trichords all in sc(016), with right-hand sets related by Tn, left-hand sets related by Tn, and cross-hand sets related by In.

**Examples 2-31a/b** (p. 80, Wuorinen and Stockhausen): Two different pieces with four sets each in the same set class, connected by I1, I7, and T6 -- the same network applies to both passages.

# Common Errors
- **Error**: Stopping at identification ("this is a (014)"). **Correction**: Always investigate *why* those sets appear at those transposition/inversion levels and in that order.

# Common Confusions
- **Confusion**: Set-class membership guarantees coherence. **Clarification**: Membership provides sonic unity, but *directed motion* between members (via specific Tn and In) creates the deeper musical logic.
