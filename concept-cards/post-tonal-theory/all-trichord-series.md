# Quick Definition
An all-trichord series is a twelve-tone series in which each of the segmental trichords represents a different set class, containing all twelve trichord types within its structure.

# Formal Definition
It is possible to write series in which each of the segmental trichords represents a different set class. An *all-trichord series* contains all twelve trichord set classes among its segmental subsets. This is contrasted with derived series, where all segmental trichords belong to the same set class. The all-trichord series represents maximum set-class diversity at the trichord level.

# Mathematical Formulation/Recognition
- There are 12 trichord set classes: (012), (013), (014), (015), (016), (024), (025), (026), (027), (036), (037), (048)
- An all-trichord series must contain each of these as a segmental subset
- A 12-note series has 10 overlapping trichords (positions 1-3, 2-4, 3-5, ..., 10-12)
- Plus 4 discrete trichords = 10 overlapping positions total
- Constructing such a series requires careful planning

# Musical Context/Application
- Represents maximum trichordal diversity
- Opposite approach from Webern's concentrated derivation
- Every trichord type appears, giving variety in the harmonic vocabulary
- Challenging to compose—requires specific construction
- Creates a very different sound world from derived series

# Examples
- The text mentions all-trichord series as a compositional possibility
- Contrasted with series where "all of the segmental trichords are of the same type"
- The all-trichord hexachord (012478)/(012568) is related conceptually

# Common Confusions
- Confusing "all-trichord series" with "all-trichord hexachord" (6-Z17/6-Z43)
- Assuming there are more than 12 trichord types—there are exactly 12
- Not recognizing that overlapping trichords count for the property
- Thinking any random series might be all-trichord—requires deliberate design
