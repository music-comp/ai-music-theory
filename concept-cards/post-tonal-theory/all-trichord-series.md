# Quick Definition
An all-trichord series contains all twelve trichord set classes among its segmental subsets, representing maximum set-class diversity at the trichord level.

# Core Definition
"It is possible to write series in which each of the segmental trichords represents a different set class (called 'all-trichord series')" (Straus, p. 327). This is contrasted with derived series, where "all of the segmental trichords are of the same type" (p. 327). "In every case, the subset structure of the series will profoundly shape the sound and structure of a work based on it" (p. 327).

# Prerequisites
- **Segmental subsets** -- the trichords being diversified
- **Set class** -- trichords classified by set-class membership

# Key Properties
1. Contains all 12 trichord set classes among its overlapping segmental trichords
2. A series has 10 overlapping trichords (positions 1--3, 2--4, ..., 10--12)
3. Represents maximum trichordal diversity
4. Contrasts with derived series (all same class)

# Construction / Recognition
- Identify all 10 overlapping segmental trichords
- Classify each by set class
- Check if all 12 trichord types appear (some must appear in non-overlapping positions as well)

# Context & Application
The all-trichord series provides maximum harmonic variety at the trichord level. Each statement of the series presents every possible trichord type, creating a rich and diverse motivic vocabulary. This approach is the opposite of Webern's concentrated derivation.

# Examples
**Example 1** (p. 327): Mentioned as a constructive possibility representing maximum diversity, contrasted with derived series.

# Relationships
## Contrasts With
- **Derived series** -- all discrete trichords of the same class

## Related

# Common Errors
- Confusing with "all-trichord hexachord" (6-Z17/6-Z43), which is a different concept
- Assuming there are more than 12 trichord types

# Common Confusions
- **All-trichord series vs. derived series**: Opposite extremes of trichordal organization
