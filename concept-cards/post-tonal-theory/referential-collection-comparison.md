# Quick Definition
A systematic comparison of the four main referential collections (diatonic, octatonic, whole-tone, hexatonic) across their defining properties: cardinality, number of distinct forms, symmetry, scalar orderings, interval content, and subset richness.

# Core Definition
The four principal referential collections of post-tonal music each have distinctive structural properties that determine their harmonic resources and characteristic sound. Comparing them systematically reveals their contrasts and explains why each creates a different musical effect (Straus, Ch. 5, pp. 260-276).

# Construction / Recognition
To identify which collection is in use:
1. Check for semitones (absent in whole-tone)
2. Check for perfect fifths (absent in whole-tone and hexatonic)
3. Check for minor thirds without semitones (suggests whole-tone)
4. Check for alternating patterns: 1-2 = octatonic, 1-3 = hexatonic
5. If 7 notes with mixed step sizes, likely diatonic

# Context & Application
Understanding the comparative properties helps analysts:
- Identify which collection governs a passage
- Understand the harmonic resources available within each collection
- Predict the types of subsets and harmonies that will appear
- Explain the characteristic sound of each collection type

# Examples
The four collections are associated with different composers and styles:
- **Diatonic**: Stravinsky neoclassical, Copland, minimalism (Reich, Glass)
- **Octatonic**: Bartok, Stravinsky, Messiaen (who called it "Mode 2")
- **Whole-tone**: Debussy, impressionism
- **Hexatonic**: Found in Schoenberg, Bartok, Babbitt; underlies LP-cycles

# Common Errors
- Assuming all 6-note or 8-note collections are referential (many are not)
- Confusing the number of distinct forms with the number of scalar orderings

# Common Confusions
- **Forms vs. orderings**: The number of distinct forms (transpositions) is different from the number of scalar orderings (modes). Diatonic has 12 forms x 7 orderings = 84 scales, while whole-tone has 2 forms x 1 ordering = 2 scales.
