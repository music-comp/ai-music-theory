# Quick Definition
Enharmonic intervals are intervals with different traditional names but the same number of semitones (e.g., major third and diminished fourth are both 4 semitones), treated as equivalent in post-tonal theory.

# Core Definition
Just as enharmonically equivalent pitches (like Bb and A#) belong to the same pitch class, enharmonically equivalent intervals (like a major third and a diminished fourth) are treated as the same interval in post-tonal theory because both contain the same number of semitones. Traditional interval names with their quality distinctions (major, minor, augmented, diminished) are abandoned in favor of semitone counts, which collapse enharmonic distinctions.

# Prerequisites
- **Enharmonic Equivalence** — extends the principle from pitches to intervals
- **Intervals Calculated in Semitones** — the measurement system that collapses enharmonic interval distinctions

# Key Properties
1. Intervals with the same semitone count are treated as identical regardless of spelling
2. Traditional quality distinctions are abandoned
3. Examples: major 3rd = diminished 4th = 4 semitones; augmented 6th = minor 7th = 10 semitones
4. This is a direct consequence of applying enharmonic equivalence to intervals

# Construction / Recognition
## To Construct:
1. Take any traditional interval name
2. Convert to semitone count
3. Any other interval with the same count is enharmonically equivalent

## To Recognize:
1. Two differently-named intervals that contain the same number of semitones

# Context & Application
The collapse of enharmonic interval distinctions is essential to post-tonal theory because post-tonal music does not reference diatonic scales consistently. Without a diatonic context, the distinction between a major third and a diminished fourth is meaningless -- both are simply "4."

# Examples
**Example 1-9** (p. 24): In Carter, String Quartet No. 3, a series of seven harmonic intervals. "The first six intervals are spelled as major thirds while the seventh is spelled as a diminished fourth, but in this musical context it is clear that all seven intervals are to be understood as enharmonically equivalent: all are 4s, or compound (i.e., octave-equivalent) 4s."

# Common Errors
- **Error**: Treating augmented sixths and minor sevenths as different intervals in post-tonal analysis
  **Correction**: Both are 10 semitones. In post-tonal theory, they are the same interval.

# Common Confusions
- **Confusion**: Carrying tonal-theory interval distinctions into post-tonal analysis
  **Clarification**: In tonal theory, a diminished fifth and an augmented fourth have different tendencies and resolutions. In post-tonal theory, both are simply 6 semitones (ic 6).
