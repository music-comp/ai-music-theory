# Quick Definition
Inverse transpositions are pairs of Tn operations that undo each other (sum to T0), such as T3 and T9, or T4 and T8.

# Formal Definition
Two transpositions Tn and Tm are inverses if performing one after the other returns to the starting point (Tn followed by Tm equals T0). Since transposition numbers work mod 12, inverse pairs are transpositions whose indices sum to 12. If Tn takes Set X to Set Y, then T(12-n) takes Set Y back to Set X.

# Mathematical Formulation/Recognition
**Inverse pairs:**
- T0 is its own inverse (T0 + T0 = T0)
- T1 and T11 (1 + 11 = 12 = 0)
- T2 and T10
- T3 and T9
- T4 and T8
- T5 and T7
- T6 is its own inverse (6 + 6 = 12 = 0)

**Property:**
Tn(Tm(x)) = T(n+m) mod 12 (x)

So: T3(T9(x)) = T0(x) = x

# Musical Context/Application
Understanding inverse transpositions helps in analyzing passages where music moves away from and returns to a pitch level. If a passage progresses by T3, returning to the original requires T9. This is analogous to how going up a minor third and then down a minor third returns to the starting pitch.

# Common Confusions
The term "inverse" here refers to inverse operations, not to pitch-class inversion (In). Inverse transpositions are complementary transpositions that cancel each other out. Note that T6 is its own inverse because 6 + 6 = 12 = 0 mod 12.
