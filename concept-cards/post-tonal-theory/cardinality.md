# Quick Definition
Cardinality is the number of pitch classes in a set, indicated by the first number in a Forte name and determining the set's basic size classification.

# Formal Definition
The cardinality of a pitch-class set is the number of distinct pitch classes it contains. Sets are classified by cardinality using standard names: monad (1), dyad (2), trichord (3), tetrachord (4), pentachord (5), hexachord (6), septachord (7), octachord (8), nonachord (9), decachord (10), undecachord (11), aggregate (12). The first number in a Forte name indicates cardinality (e.g., 3-11 is a trichord).

Formula for number of intervals: n(n-1)/2

# Musical Context/Application
Cardinality is a basic classifier for sets. Most analytical work focuses on sets of cardinality 3-6, which provide rich intervallic content without approaching the aggregate. Larger sets (7+) are often analyzed in relation to their complements. The List of Set Classes organizes sets by cardinality.

# Examples
From the List of Set Classes:
- 12 trichordal set classes (cardinality 3)
- 29 tetrachordal set classes (cardinality 4)
- 38 pentachordal set classes (cardinality 5)
- 50 hexachordal set classes (cardinality 6)

Note the symmetry: cardinalities n and (12-n) have the same number of set classes because of the complement relation.

# Common Confusions
Cardinality refers only to the number of distinct pitch classes, not the number of notes in a musical passage. A chord with doubled notes may have fewer pitch classes than notes. Also, cardinality does not determine set-class: many different set classes share the same cardinality.
