# Quick Definition
A pitch is a specific note with a particular frequency, occupying a unique position in the range from lowest to highest audible tones.

# Core Definition
A pitch is a note with a specific frequency located at a unique point in pitch space. Pitches are designated using octave-register notation (e.g., middle C is C4; the lowest note on the cello is C2). A pitch can be precisely notated on a musical staff and represents a concrete, specific musical event, unlike pitch class, which is an abstraction.

# Key Properties
1. A pitch occupies a unique location in linear pitch space
2. Pitches are designated with letter name plus octave number (e.g., C4, A3, F#5)
3. Each pitch belongs to exactly one pitch class
4. Multiple distinct pitches can belong to the same pitch class (e.g., C2, C3, C4 all belong to pitch class C)

# Construction / Recognition
## To Construct:
1. Specify a letter name (A-G, with accidentals if needed)
2. Specify an octave register (using the system where middle C = C4)

## To Recognize:
1. A pitch is any note that can be placed at a specific position on the grand staff
2. It has a definite frequency and register

# Context & Application
When we refer to "the lowest note on the cello is C," we mean a specific pitch (C2). When we say "the tonic of Beethoven's Fifth Symphony is C," we refer to pitch class C. Analysis in post-tonal theory moves between pitch-level and pitch-class-level descriptions depending on what musical relationships are being examined.

# Examples
**Example 1-5** (p. 20): In Feldman, Durations III, No. 3, each of three instruments plays a series of notes. The tuba plays five different pitches, most of which are repeated. However, the passage as a whole uses only three pitch classes: F#, G, and Ab. This illustrates the distinction: many pitches, few pitch classes.

# Common Errors
- **Error**: Using "pitch" and "pitch class" interchangeably
  **Correction**: A pitch is a specific note at a specific register; a pitch class is the abstract category containing all octave- and enharmonically-equivalent pitches.

# Common Confusions
- **Confusion**: Thinking pitch class is just another name for pitch
  **Clarification**: "A pitch class is not a single thing; it is a class of things: namely, pitches one or more octaves apart" (Straus). Pitch is concrete; pitch class is abstract.
