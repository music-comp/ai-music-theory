# Quick Definition
Analytical levels refer to the spectrum of abstraction in post-tonal analysis, from concrete pitch descriptions to abstract set-class relationships.

# Core Definition
Post-tonal analysis employs concepts at varying levels of abstraction. The most concrete level deals with specific pitches and pitch intervals. More abstract levels involve pitch classes, ordered and unordered pitch-class intervals, pitch-class sets, Tn-types, and set classes. Analysts should "feel free to draw on the full range of concepts" and choose the level that best illuminates the relationship being described.

# Prerequisites
- **Pitch-class set** -- one of the levels
- **Set class** -- the most abstract set-level concept
- **Interval class** -- the most abstract interval-level concept

# Key Properties
1. No level is inherently better than another
2. More abstract levels reveal patterns obscured by surface detail
3. More concrete levels capture register and contour information lost in abstraction
4. Rich analysis moves between levels

# Construction / Recognition
**Hierarchy from concrete to abstract (Example 2-36, p. 87):**

*Pitch level:*
- Pitch (specific register)
- Pitch interval (specific semitone distance with direction)

*Pitch-class level:*
- Pitch class (octave-equivalent)
- Ordered pitch-class interval (direction preserved, mod 12)
- Interval class / unordered pitch-class interval (most abstract interval)

*Set level:*
- Pitch-class set (specific collection)
- Tn-type (transposition-related family)
- Set class / T/I set class (most abstract set category)

# Context & Application
Different analytical levels reveal different aspects of musical structure. Concrete levels capture voice-leading and registral detail. Abstract levels identify deeper patterns that transcend registral placement. The analyst selects the level most pertinent to the relationship being examined.

# Examples
**Example 2-36** (p. 87): The spectrum laid out:
- Pitch --> Pitch class
- Pitch intervals --> Ordered pc intervals --> Interval classes
- Pitch-class set --> Tn-type --> Set class

**Model Analysis 2.1** (Schoenberg, op. 15, no. 11): Analysis moves between levels, identifying specific pitch-class sets, their Tn and In relationships, and their common set-class membership, while also noting registral placement and contour.

# Relationships
## Builds Upon
- **Pitch-class set** -- mid-level concept

## Enables
- **Flexible analysis** -- choosing the right level for each observation
## Related
- **Segmentation** -- produces elements to be analyzed at various levels
- **Tn-type** -- intermediate abstraction between set and set class

# Common Errors
- **Error**: Analyzing only at the most abstract level. **Correction**: Concrete observations about register, contour, and voice-leading are often musically essential.

# Common Confusions
- **Confusion**: More abstract = more important. **Clarification**: "You should feel free to draw on the full range of concepts." The most musically revealing observation may be at any level.
