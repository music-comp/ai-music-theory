# Quick Definition
Analytical levels refer to the spectrum of abstraction in post-tonal analysis, from concrete pitch descriptions to abstract set-class relationships.

# Formal Definition
Post-tonal analysis employs concepts at varying levels of abstraction. The most concrete level deals with specific pitches and pitch intervals. More abstract levels involve pitch classes, ordered and unordered pitch-class intervals, pitch-class sets, Tn-types, and set classes. Analysts choose the appropriate level based on what musical relationship they seek to describe.

# Mathematical Formulation/Recognition
**Hierarchy from concrete to abstract:**

**Pitch level:**
- Pitch (specific frequency/register)
- Pitch interval (specific semitone distance)

**Pitch-class level:**
- Pitch class (octave-equivalent)
- Ordered pitch-class interval (direction preserved)
- Unordered pitch-class interval / Interval class (most abstract interval)

**Set level:**
- Pitch-class set (specific collection)
- Tn-type (transposition-related family)
- Set class / T/I set class (most abstract set)

# Musical Context/Application
Different analytical levels reveal different aspects of musical structure. Concrete levels capture register, contour, and specific voice-leading. Abstract levels identify deeper patterns that transcend registral placement. Rich analysis typically moves between levels, showing how abstract relationships are realized in concrete musical events.

# Examples
**Example 1-17**: A single interval (+19 semitones) described at four levels:
- opi +19: ordered pitch interval (most concrete)
- upi 19: unordered pitch interval
- opci 7 (or -5): ordered pitch-class interval
- upci 5 (or ic5): interval class (most abstract)

**Example 2-36**: The spectrum from pitch to set class:
- Pitch → Pitch class
- Pitch intervals → Ordered pc intervals → Interval classes
- Pitch-class set → Tn-type → Set class

# Related Concepts
- Pitch vs. pitch class
- Ordered vs. unordered intervals
- Interval class
- Pitch-class set
- Set class
- Tn-type

# Common Confusions
No level is inherently "better" than another. More abstract levels reveal patterns that might be obscured by surface details, while more concrete levels capture registral and contour information lost in abstraction. Choose the level that best illuminates the relationship you wish to describe.
