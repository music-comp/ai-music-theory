# Quick Definition
The relationship between a set and the collection of all pitch classes it excludes; a set and its complement together contain all twelve pitch classes, and they share a proportionally similar distribution of intervals.

# Formal Definition
For any pitch-class set, its complement contains all the pitch classes not included in the original set. If a set contains n pitch classes, its complement contains 12 - n pitch classes. A set and its complement, taken together, constitute the aggregate (all twelve pitch classes).

The complement relation has an important intervallic property: complementary sets have strikingly similar interval distributions. For complements of different sizes, the difference in the number of occurrences of each interval class equals the difference between the sizes of the sets (except for ic6/tritone, where the difference is half the size difference).

# Mathematical Formulation/Recognition
For a set S with cardinality n:
- Complement of S contains all pcs not in S
- Cardinality of complement = 12 - n

Interval-class vector relationship for complements:
- If set of size n has vector [a, b, c, d, e, f]
- Its complement of size (12-n) has vector [a+k, b+k, c+k, d+k, e+k, f+k/2]
- Where k = (12-n) - n = 12 - 2n

For hexachords (n = 6): k = 0, so a hexachord has the SAME interval-class vector as its complement.

# Musical Context/Application
The complement relation is crucial in:
- Twelve-tone music where the aggregate is a structural unit
- Understanding relationships between melody and accompaniment that together exhaust all pitch classes
- Analyzing hexachordal structures (hexachords and their complements share identical interval content)
- Creating coherent large-scale pitch organization

Composers often use complement-related sets in melody vs. accompaniment, creating unity through similar intervallic profiles.

# Examples
From Example 3-22 and 3-23:
- Set: [2, 3, 6, 9] - sc4-18 (0147), vector [102111]
- Complement: [4, 5, 7, 8, 10, 11, 0, 1] - sc8-18 (01235689), vector [546553]
- The 8-note set has 4 more of each interval class (except ic6, which has 2 more)

From Example 3-24: Schoenberg, String Quartet No. 3
- Melody (7 notes): [5, 6, 8, 10, 11, 1, 2] = sc7-32
- Accompaniment ostinato (5 notes): the complementary pitch classes
- Melody and accompaniment have similar intervallic profiles

Forte-names identify complements: 4-18 and 8-18 are complements (same number after dash, numbers before dash sum to 12).

# Common Confusions
- Thinking complementary sets have opposite interval content (they actually have similar content)
- Forgetting the tritone exception (difference in ic6 is half the difference in size)
- Confusing literal complement (specific pcs) with abstract complement (set class relationship)
- Not recognizing that complement-related set classes share other properties (degree of symmetry, Z-relation status)
