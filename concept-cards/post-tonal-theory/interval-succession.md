# Quick Definition
The interval succession is the sequence of eleven ordered pitch-class intervals between consecutive notes of a series, defining the series's identity and remaining invariant under transposition.

# Core Definition
"That particular interval succession is what defines the prime ordering of this series" (Straus, p. 313). The intervals are "usually represented as positive integers, 1--11, but sometimes we will use negative numbers for 7 and above (7 = -5; 8 = -4; 9 = -3; 10 = -2; 11 = -1)" (p. 312). The interval succession is the fundamental property that identifies a series form: all P-forms share the same succession, I-forms have the complementary succession, R-forms reverse and complement, and RI-forms reverse the succession.

# Prerequisites
- **Twelve-tone series** -- the series whose intervals are being described
- **Ordered pitch-class intervals** -- the type of interval being measured
- **Prime ordering** -- the reference from which other interval successions are derived

# Key Properties
1. Eleven ordered pc intervals define the series identity
2. Invariant under transposition (same intervals, same order)
3. Can be represented as positive integers 1--11 or with negative equivalents
4. Determines the intervallic "sound" of the series class
5. All 48 forms share closely related interval successions

# Construction / Recognition
- List the ordered pc interval between each consecutive pair of notes
- A twelve-tone series has exactly 11 intervals
- Verify transposition preserves the succession

# Context & Application
The interval succession determines the characteristic sound of a series. Schoenberg's String Quartet No. 4 series emphasizes intervals 1, 4, 8, and 11 while completely excluding 3 and 9 -- all 48 forms share this intervallic profile.

# Examples
**Example 1** (pp. 312--313, Ex. 6-2): Schoenberg, String Quartet No. 4 -- P2 interval succession: 11, 8, 1, 7, 10, 1, 8, 8, 11, 11, 5.

# Common Errors
- Using unordered intervals instead of ordered pitch-class intervals
- Forgetting that negative notation is sometimes used for intervals 7--11

# Common Confusions
- **Same intervals in same order (P-related)** vs. **complementary intervals in same order (I-related)** vs. **same intervals reversed (RI-related)** vs. **complementary intervals reversed (R-related)**
