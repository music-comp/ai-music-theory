# Quick Definition
Transposition and inversion both preserve interval-class content: sets related by Tn or In contain exactly the same interval classes in the same quantities.

# Core Definition
A fundamental property of both transposition and inversion is that they preserve *interval-class content*. When a set is transposed or inverted, the resulting set contains the same unordered pitch-class intervals (interval classes) as the original. This is why transpositionally and inversionally related sets -- members of the same set class -- have a similar sound quality. "Transposition of a set of pitch classes may involve many changes, but it preserves interval-class content. As a result, it can be an important compositional means of creating a deeper unity beneath a varied musical surface" (Straus, Ch. 2).

# Prerequisites
- **Transposition (Tn)** -- one operation that preserves interval content
- **Inversion (In)** -- the other operation that preserves interval content
- **Interval class** -- the preserved quantity

# Key Properties
1. Tn preserves interval-class content (same ic vector)
2. In preserves interval-class content (same ic vector)
3. All members of a set class share the same interval-class vector
4. Interval-class content determines the set's "sonic fingerprint"
5. This is the fundamental reason set classes are musically meaningful

# Construction / Recognition
To verify: compute the interval-class vector for both sets. If identical, they may be related by Tn or In (and belong to the same set class).

# Context & Application
Interval-class content preservation is what makes set classes analytically meaningful. When a composer uses multiple members of the same set class, the shared interval content creates sonic unity even when the specific pitch classes differ. This is analogous to (though different from) how tonal transposition preserves the intervallic structure of a melody.

# Examples
**Example 2-7** (p. 64, Webern, *Concerto for Nine Instruments*, op. 24): Four transpositionally equivalent sets, all containing ic1, ic3, ic4 and no others: [D#, E, G], [D, D#, F#], [Ab, A, C], [B, C, Eb]. Their shared interval content "gives them a similar sound."

**Example 2-21** (p. 73, Schoenberg, op. 11, no. 1): Three inversionally related sets [G, G#, B], [Db, E, F], [G, Bb, B] all contain ic1, ic3, ic4 and no others -- same interval content despite different pitch-class content.

# Common Errors
- **Error**: Assuming Tn or In preserves everything. **Correction**: They preserve interval-class content but not specific pitch classes, order, or (for sets) contour.

# Common Confusions
- **Confusion**: Same interval content means identical sound. **Clarification**: Sets with the same interval content sound *similar* but not identical -- they have different pitch classes and may appear in different registers and rhythms.
