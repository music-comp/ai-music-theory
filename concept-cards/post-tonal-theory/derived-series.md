# Quick Definition
A derived series is one in which all discrete segmental trichords (or tetrachords) are members of the same set class, guaranteeing extraordinary motivic unity throughout the piece.

# Formal Definition
A *derived series* is one in which the discrete segmental trichords or tetrachords are all members of the same set class. The set class from which the series is derived is called the *generator*. Any trichord—except (036)—can act as a generator for a trichord-derived series. For tetrachord derivation, any tetrachord that excludes interval class 4 can act as generator. A derived series makes possible extraordinary motivic unity because the generating set class appears constantly throughout all 48 series forms.

# Mathematical Formulation/Recognition
**Trichord derivation:**
- Positions 1-3, 4-6, 7-9, 10-12 are all members of the same set class
- Generator can be any trichord except (036)
- The four trichords are related by P, R, I, and RI

**Tetrachord derivation:**
- Positions 1-4, 5-8, 9-12 are all members of the same set class
- Generator must exclude ic4
- The three tetrachords are related by T, I, and/or R

**Bonus structure:** Trichords may be ordered as P, I, R, RI transformations of each other.

# Musical Context/Application
- Guarantees that the generating set class permeates all series forms
- Creates extreme intervallic concentration typical of Webern
- Every statement of the series produces four (or three) statements of the generator
- The generator shapes instrumentation, register, articulation—not just pitch
- Economy and concentration are hallmarks of this approach

# Examples
- Webern, Concerto for Nine Instruments, op. 24: Derived from (014)
- All four discrete trichords are (014)
- First trichord (G-B-Bb) is P; second (Eb-D-F#) is RI; third (E-F-C#) is R; fourth (C-Ab-A) is I
- Ordered pitch-class intervals: <+4,-1>, <-1,+4>, <+1,-4>, <-4,+1>
- Every circled trichord in the music is a (014)

# Common Confusions
- Thinking any series is "derived"—only those with same-class discrete subsets qualify
- Forgetting that (036) cannot generate a derived series (trichords)
- Not recognizing that ic4 exclusion is required for tetrachord generators
- Assuming derivation limits compositional freedom—it actually enables concentrated development
