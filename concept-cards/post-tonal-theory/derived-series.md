# Quick Definition
A derived series is one in which all discrete segmental trichords (or tetrachords) are members of the same set class, guaranteeing extraordinary motivic unity.

# Core Definition
"A derived series is one in which the discrete segmental trichords or tetrachords are all members of the same set class" (Straus, p. 334). The set class from which the series is derived is called the *generator*. Constraints on generators: "Any trichord -- except (036) -- can act as a *generator*. It is also possible to derive a series from a tetrachord. In that case, all three discrete tetrachords must be members of the same set class. Any tetrachord that excludes interval class 4 can act as generator" (p. 335).

# Prerequisites
- **Twelve-tone series** -- the series being derived
- **Set class** -- used to classify the discrete subsets

# Key Properties
1. Trichord derivation: positions 1--3, 4--6, 7--9, 10--12 all same set class
2. Tetrachord derivation: positions 1--4, 5--8, 9--12 all same set class
3. Trichord generators: any trichord except (036)
4. Tetrachord generators: any tetrachord excluding ic4
5. Discrete trichords may be ordered as P, I, R, RI of each other
6. "A derived series makes possible an extraordinary motivic unity" (p. 335)

# Construction / Recognition
- Identify the four discrete trichords (or three discrete tetrachords)
- Check if all belong to the same set class
- If so, identify the generator and the transformational relationships between segments
- Check if the trichords are ordered as P, I, R, RI of each other

# Context & Application
Derived series guarantee that the generating set class permeates all 48 series forms. Every statement of the series produces four (or three) instances of the generator. This creates the extreme motivic concentration characteristic of Webern's style.

# Examples
**Example 1** (pp. 334--335, Exx. 6-28 and 6-29): Webern, Concerto for Nine Instruments, op. 24 -- derived from (014). Four discrete trichords: G-B-Bb = P7; Eb-D-F# = RI6; E-F-C# = R1; C-Ab-A = I0. Ordered pitch-class intervals: <+4,-1>, <-1,+4>, <+1,-4>, <-4,+1>.

**Example 2** (p. 360): Webern, String Quartet, op. 28 -- derived from (0123). All three discrete tetrachords are chromatic clusters related by T, I, or RI.

## Contrasts With
- **All-trichord series** -- maximum diversity vs. maximum unity

# Common Errors
- Thinking any series with recurring set classes is "derived" -- all discrete segments must be the same class
- Forgetting (036) cannot generate a trichord-derived series
- Not checking the ic4 exclusion for tetrachord generators

# Common Confusions
- **Derived vs. merely concentrated**: A series might emphasize a particular interval without meeting the strict definition of derivation
