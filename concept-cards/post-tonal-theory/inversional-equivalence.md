# Quick Definition
Sets are inversionally equivalent when they are related by some In operation, sharing the same interval-class content with mirror-image interval successions in normal form.

# Formal Definition
Two pitch-class sets are inversionally equivalent if one can be transformed into the other by inversion (In). Inversionally equivalent sets share the same interval-class vector but have mirror-image interval successions when placed in normal form. The first element of one set corresponds to the last element of the other, the second to the second-to-last, and so on. Sets related by inversion belong to the same set class but different Tn-types.

# Mathematical Formulation/Recognition
**Tests for inversional equivalence:**
1. Put both sets in normal form
2. Compare interval successions: should be mirror images
3. If mirrors, sets are inversionally equivalent
4. Find n by adding corresponding elements (first + last, second + second-to-last)

**Properties preserved under inversion:**
- Interval-class content (and vector)
- Set-class membership
- Cardinality

**Properties changed:**
- Interval direction (reversed)
- Specific pitch-class content
- Tn-type membership

# Musical Context/Application
Inversionally equivalent sets have the same interval-class content as transpositionally equivalent sets, maintaining sonic similarity. However, their interval successions are reversed, which can create musical contrast while maintaining underlying coherence. Composers often alternate between transposition and inversion for variety.

# Examples
**Example 2-21** (Schoenberg, Three Piano Pieces, op. 11, no. 1):
- [G, G#, B] has intervals 1-3 (reading up)
- [Db, E, F] has intervals 3-1 (mirror image)
- They are related by I0 (corresponding pairs sum to 0: G+F=0, G#+E=0, B+Db=0)

**Example 2-22**: Shows how inversionally related sets in normal form appear as mirror images:

# Common Confusions
Inversionally equivalent sets share the same set class but belong to different Tn-types. To test for inversion, check that the normal-form interval successions are mirror images and that corresponding elements sum to a constant value (the index number).
