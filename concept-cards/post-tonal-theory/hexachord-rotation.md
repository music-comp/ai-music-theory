# Quick Definition
Hexachord rotation moves the first pitch class to the end of the ordered hexachord, creating a new ordering that preserves the interval content with wraparound.

# Core Definition
Rotation involves taking an ordered collection and moving its first element to the end. For a hexachord [a, b, c, d, e, f]: rotation 1 = [b, c, d, e, f, a]; rotation 2 = [c, d, e, f, a, b]; etc. In Stravinsky's practice, each rotated hexachord is transposed to begin on the original first note, creating rows of a rotational array that "describe the same succession of intervals (allowing for wraparound)" (Straus, p. 346).

# Prerequisites
- **Twelve-tone series** -- the series whose hexachords are rotated

# Key Properties
1. Moves first element to end (not reversal)
2. Preserves interval content with wraparound
3. Combined with transposition in Stravinsky's arrays
4. Six rotations exhaust all starting points
5. Different from retrograde (which reverses order)

# Construction / Recognition
- Original: [x1, x2, x3, x4, x5, x6]
- Rotation 1: [x2, x3, x4, x5, x6, x1]
- Rotation 2: [x3, x4, x5, x6, x1, x2]
- Through Rotation 5

# Context & Application
Used by both Stravinsky (in rotational arrays) and Crawford Seeger (in multilevel rotation). The operation is fundamental to generating the rows of rotational arrays.

# Examples
**Example 1** (p. 345): Stravinsky -- hexachord Eb-D-Gb-E-F-Ab. Rotation 1: D-Gb-E-F-Ab-Eb, then transposed to start on Eb.

# Common Confusions
