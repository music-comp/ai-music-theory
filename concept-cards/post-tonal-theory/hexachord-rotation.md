# Quick Definition
Hexachord rotation is the process of moving the first pitch class of a hexachord to the end, creating a new ordering that preserves the interval content but starts on the next pitch class.

# Formal Definition
*Rotation* involves taking an ordered collection and moving its first element to the end, creating a new ordering. In the context of rotational arrays, each hexachord undergoes successive rotations:
- Original: a-b-c-d-e-f
- First rotation: b-c-d-e-f-a
- Second rotation: c-d-e-f-a-b
- And so on...

In Stravinsky's rotational arrays, each rotated hexachord is then transposed to begin on the original first note, creating rows that describe the same interval succession with wraparound.

# Mathematical Formulation/Recognition
For hexachord [x1, x2, x3, x4, x5, x6]:
- Rotation 0: [x1, x2, x3, x4, x5, x6]
- Rotation 1: [x2, x3, x4, x5, x6, x1]
- Rotation 2: [x3, x4, x5, x6, x1, x2]
- ...through Rotation 5

Combined with transposition:
- Array Row I: Original hexachord starting on x1
- Array Row II: Rotation 1, transposed to start on x1
- etc.

# Musical Context/Application
- Generates the rows of a rotational array
- Creates canonic relationships between array rows
- Preserves intervallic relationships with "wraparound"
- Each rotation emphasizes a different note of the hexachord
- Used systematically by Stravinsky and Crawford Seeger

# Examples
- Stravinsky, A Sermon, a Narrative, and a Prayer:
  - Hexachord Eb-D-Gb-E-F-Ab generates the array
  - Row II: D-Gb-E-F-Ab-Eb, transposed up a semitone to start on Eb
  - Row III: Gb-E-F-Ab-Eb-D, transposed to start on Eb
  - All rows share the same first note (Eb)

# Common Confusions
- Confusing rotation with retrograde—rotation moves first to last, retrograde reverses all
- Forgetting that transposition is applied after rotation in Stravinsky's arrays
- Not recognizing that rotation preserves interval content (with wraparound)
- Assuming rotation always starts from the original—successive rotations are cumulative
