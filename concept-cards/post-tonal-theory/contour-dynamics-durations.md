# Quick Definition
The application of contour analysis to musical parameters beyond pitch, including dynamics, durations, and timbre; the same CSEG notation and operations apply to any orderable musical dimension.

# Core Definition
Contour analysis extends naturally to any musical parameter where elements can be ordered from least to greatest. Dynamics can be ordered from softest to loudest, durations from shortest to longest, timbres from fewest to most overtones. The same integer-assignment method and CSEG notation apply: 0 = lowest/shortest/softest, ascending to n-1 = highest/longest/loudest. Cross-parameter contour relationships (e.g., the same CSEG in both pitch and dynamics) reveal structural coordination among dimensions (Straus, pp. 146-148).

- **Contour segment** -- the notation system being extended

# Key Properties
1. Any orderable parameter can be analyzed for contour
2. The same CSEG notation and operations apply
3. Cross-parameter relationships (same CSEG in different domains) reveal coordination
4. Different contours in different parameters reveal independence or heterogeneity
5. Particularly valuable for experimental and graphic-notation music

# Construction / Recognition
To analyze non-pitch contour:
1. Identify the parameter (dynamics, duration, timbre, etc.)
2. Assign 0 to the least value (softest, shortest, fewest overtones)
3. Assign ascending integers to increasing values
4. Write in temporal order within angle brackets
5. Compare with pitch contour or contours of other parameters

# Context & Application
Non-pitch contour is especially useful for analyzing experimental music (Feldman, Cage, Stockhausen) where exact pitch may be indeterminate but other parameters are structured. Even in fully determined music, comparing pitch contour with dynamic or durational contour reveals hidden structural relationships.

# Examples
**Example 1** (p. 146, Ex. 3-39): Stockhausen, Klavierstuck II:
- Upper melody pitch contour: <3201>
- Upper melody dynamic contour: also <3201> -- the louder the note, the higher
- Lower melody pitch contour: <0132> (inversion of upper melody)
- Dynamic and timbre contours are inversions of each other: louder = fewer overtones

**Example 2** (p. 147, Ex. 3-40): Feldman, Projection No. 1 for Solo Cello:
- Pizzicato pitch contour: <102> (middle-low-high)
- Temporal distance between pizzicato notes: 4 beats, 1 beat, 8 beats = <102> (medium-short-long)
- Same contour in both pitch and duration

**Example 3** (pp. 147-148, Ex. 3-41): Cage, complete piece with four events in four dimensions:
- Durations: <1230>
- Dynamics: <1302>
- Pitch: <3201>
- Timbre: <2031>
- All four are different, suggesting structural heterogeneity
- But dynamic and timbre contours are inversions: louder = fewer overtones, showing some coordination

# Common Errors
- Assuming contour analysis applies only to pitch
- Not recognizing cross-parameter contour relationships

# Common Confusions
- The ordering principle must be meaningful for the parameter (e.g., loudness is orderable; pitch class without register is not)
- Contour analysis of non-pitch parameters is most revealing when compared with pitch contour
