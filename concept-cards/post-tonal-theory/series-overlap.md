# Quick Definition
Series overlap occurs when a single note functions simultaneously as the last note of one series form and the first note of the next, creating continuity between series statements.

# Formal Definition
In twelve-tone music, a single note can be simultaneously the last note of one series form and the first note of the next. This *overlap* creates a seamless connection between consecutive series statements. Such overlapping is typical of certain composers, particularly Webern, and contributes to the flowing, continuous quality of twelve-tone counterpoint.

# Mathematical Formulation/Recognition
**Overlap conditions:**
- Last note of Form 1 = First note of Form 2
- The shared note counts toward both series forms
- Total pitch classes sounded = 23 (not 24) for two overlapping forms

**Finding overlappable forms:**
- R_n ends on pc n; P_n begins on pc n → R_n can overlap with P_n
- RI_n ends on pc n; P_n begins on pc n → RI_n can overlap with P_n

# Musical Context/Application
- Creates smooth transitions between series forms
- Particularly characteristic of Webern's style
- Allows continuous twelve-tone counterpoint
- The shared note serves double function
- Can create elision effects in phrasing

# Examples
- Webern, "Wie bin ich froh!":
  - The G in the accompaniment (m. 2) is both the last note of RI7 and the first note of P7
  - This overlap is "typical of Webern"
  - Creates seamless flow between series statements

# Common Confusions
- Counting the overlapping note twice when twelve-counting
- Missing overlap because one note seems to belong to the "wrong" series
- Assuming all series must be fully separated
- Not recognizing that overlap creates ambiguity in formal boundaries
