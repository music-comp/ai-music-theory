# Quick Definition
Series overlap occurs when a single note functions simultaneously as the last note of one series form and the first note of the next, creating seamless continuity.

# Core Definition
"A single note can be simultaneously the last note of one series form and the first note of the next" (Straus, p. 322). This overlap creates a seamless connection between consecutive series statements. "This kind of overlap is typical of Webern" (p. 322).

# Prerequisites
- **Twelve-counting** -- overlap is discovered during the counting process
- **Twelve-tone series** -- the forms being connected

# Key Properties
1. The shared note counts toward both series forms
2. Two overlapping 12-tone forms yield 23 pitch classes sounded (not 24)
3. Overlap is possible when the last note of one form equals the first note of the next
4. Creates elision effects in phrasing

# Construction / Recognition
- R_n ends on pc n; P_n begins on pc n -- so R_n can overlap with P_n
- RI_n ends on pc n; I_n begins on pc n -- potential overlap
- Look for notes that seem to belong to both the ending of one form and the beginning of the next

# Context & Application
Overlap creates smooth transitions between series statements, contributing to the flowing quality of twelve-tone counterpoint. It is particularly characteristic of Webern's style, where the continuous unfolding of the series is prioritized over clear segmentation.

# Examples
**Example 1** (p. 322): Webern, "Wie bin ich froh!" -- the G in the accompaniment in measure 2 is both the last note of RI7 and the first note of P7.

# Common Errors
- Counting the overlapping note twice when tracking series forms
- Missing overlap because one note seems ambiguous
- Assuming all series forms must be cleanly separated

# Common Confusions
- **Overlap vs. simultaneity**: Overlap involves one note serving two functions sequentially; simultaneity involves two forms sounding at the same time in different voices
