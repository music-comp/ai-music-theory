# Quick Definition
An ordered succession of relative pitch heights, notated as a string of numbers in angle brackets where 0 represents the lowest note, 1 the next lowest, and so on up to (n-1) for the highest note.

# Formal Definition
A contour segment (CSEG) represents the relative registral positions of notes in an ordered succession, without regard to the specific pitches or intervals involved. Each note is assigned an integer based on its position from lowest (0) to highest (n-1), where n is the number of distinct notes. The CSEG is then written as these integers in the order the notes occur, enclosed in angle brackets.

CSEGs capture melodic shape independently of pitch content. Different melodies with the same CSEG share a common contour even if they contain different intervals and belong to different set classes.

# Mathematical Formulation/Recognition
To determine a CSEG:
1. Identify the number of distinct pitch levels in the segment
2. Assign 0 to the lowest pitch, 1 to the next lowest, etc.
3. Write the resulting integers in temporal order
4. Enclose in angle brackets: <...>

The highest integer in a CSEG of n distinct notes is n-1.

Example: For pitches C5-E4-D4-G5 (in that order):
- Lowest is D4 = 0
- Next is E4 = 1
- Next is C5 = 2
- Highest is G5 = 3
- CSEG = <2103>

# Musical Context/Application
CSEGs are valuable for:
- Analyzing melodic shapes without pitch-class considerations
- Finding hidden relationships between intervallically different melodies
- Understanding music where exact pitch is indeterminate but contour is specified
- Analyzing non-pitched elements (dynamics, durations) using the same framework

Contour analysis is particularly useful for music that is less concerned with specific pitch relationships and more concerned with general shapes and gestures.

# Examples
From Example 3-36: Crawford Seeger, String Quartet, first movement

Three melodic fragments with CSEG <2013>:
- Fragment 1: Different pitches
- Fragment 2: Different pitches and intervals
- Fragment 3: Different pitches and set class
- All three share the same contour: second-highest, lowest, second-lowest, highest

The melody is unified by contour even though the three fragments:
- Contain different intervals
- Represent different set classes
- Have no common pitch classes

From Example 3-40: Feldman, Projection No. 1 for Solo Cello
- First three pizzicato notes: middle register, low register, high register = CSEG <102>
- The same contour describes the durational pattern: medium duration, short duration, long duration

# Common Confusions
- Using actual pitch numbers instead of relative position numbers
- Confusing CSEGs (ordered, uses angle brackets) with pitch-class sets (unordered, uses square brackets)
- Forgetting that CSEG captures order, not just relative height
- Thinking CSEG requires specific pitches (it only requires relative relationships)
