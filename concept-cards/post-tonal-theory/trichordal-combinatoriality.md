# Quick Definition
Trichordal combinatoriality is the formation of aggregates in the columns of a trichordal array, where four trichords from different rows combine to produce all twelve pitch classes.

# Core Definition
In Babbitt's trichordal arrays, each column contains four trichords (one from each row) that together form an aggregate. "Aggregates are thus formed... in the columns of the array, with one trichord taken from each of the rows (trichordal combinatoriality)" (Straus, p. 350). Each column's four trichords are presented in various temporal arrangements -- before and after temporal boundaries -- exploring all possible ways to partition four elements.

# Prerequisites
- **Trichordal arrays** -- the structural format containing column aggregates

# Key Properties
1. Each column contains 4 trichords = 12 pitch classes = aggregate
2. All four trichords in a column must be mutually exclusive (no shared pcs)
3. Trichords can be presented in 15 possible temporal arrangements
4. Complements hexachordal combinatoriality (operates in a different dimension)

# Construction / Recognition
- Check that each column's four trichords contain all 12 pcs
- Identify the temporal arrangement (which trichords before/after the boundary)

# Context & Application
"The music is presenting systematically all the possible arrangements of four distinct things (in this case, trichords) into two or fewer parts. There are fifteen such arrangements" (Straus, p. 353). Trichordal combinatoriality provides vertical harmonic structure in four-voice textures.

# Examples
**Example 1** (pp. 352--353, Ex. 6-48): Babbitt, String Quartet No. 2, mm. 7--12 -- first aggregate: one trichord alone (first violin), then three intermingled. Second aggregate: three intermingled, then one alone (cello).

# Relationships
## Builds Upon
- **Trichordal arrays** -- trichordal combinatoriality operates in array columns

## Contrasts With
- **Hexachordal combinatoriality** -- operates between row-pairs (horizontal); trichordal operates in columns (vertical)

# Common Errors
- Confusing trichordal with hexachordal combinatoriality (different dimensions)
- Assuming trichords must sound simultaneously (they can be ordered in time)

# Common Confusions
- **15 arrangements**: Not 15 different trichord types, but 15 ways to partition 4 elements into 2 or fewer groups
