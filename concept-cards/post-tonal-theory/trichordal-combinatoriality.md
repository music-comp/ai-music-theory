# Quick Definition
Trichordal combinatoriality is the property where four trichords from different series lines combine to form an aggregate, creating vertical aggregate formation in trichordal arrays.

# Formal Definition
In Babbitt's trichordal arrays, *trichordal combinatoriality* refers to the formation of aggregates in the columns of the array, where each column contains one trichord from each of the four rows. The four trichords together contain all twelve pitch classes, forming an aggregate. This vertical dimension of aggregate formation complements the horizontal aggregates within each row and the diagonal aggregates between row pairs.

# Mathematical Formulation/Recognition
**Column aggregate formation:**
```
Row 1: [T1a]  [T1b]  [T1c]  [T1d]
Row 2: [T2a]  [T2b]  [T2c]  [T2d]
Row 3: [T3a]  [T3b]  [T3c]  [T3d]
Row 4: [T4a]  [T4b]  [T4c]  [T4d]
```

Each column {T1x, T2x, T3x, T4x} contains 12 distinct pitch classes.

**Requirements:**
- All four trichords in a column must be mutually exclusive (no shared pcs)
- Each trichord covers 3 pcs; 4 × 3 = 12

# Musical Context/Application
- Provides vertical harmonic structure in four-voice textures
- Ensures aggregate completion at regular intervals
- Allows for various presentations (1+3, 2+2, 3+1, 4 simultaneous)
- Complements hexachordal combinatoriality
- Central to Babbitt's approach to twelve-tone organization

# Examples
- Babbitt, String Quartet No. 2:
  - Four instruments present four trichords in each column
  - Columns are presented with temporal boundaries (some trichords before, some after)
  - First aggregate: one trichord alone, then three intermingled
  - Second aggregate: three intermingled, then one alone
  - Systematic exploration of all 15 arrangements of 4 into 2-or-fewer parts

# Common Confusions
- Confusing trichordal with hexachordal combinatoriality—they operate in different dimensions
- Assuming trichords must be presented simultaneously—they can be ordered in time
- Not recognizing the 15 possible arrangements of four elements
- Overlooking that trichordal combinatoriality is specifically about column aggregates
