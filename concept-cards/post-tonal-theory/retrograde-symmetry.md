# Quick Definition
Retrograde symmetry (or palindromic structure) occurs when a series or passage reads the same forward and backward, reducing the 48 series forms to 24 distinct orderings.

# Formal Definition
A series has *retrograde symmetry* when its interval succession is the same reading from right to left as from left to right. This means for every P-form, there is an RI-form that presents the twelve pitch classes in exactly the same order. Similarly, for every I-form there is an identical R-form. As a result, such series have only twenty-four rather than the usual forty-eight distinct orderings.

# Mathematical Formulation/Recognition
**Symmetric interval succession:**
- If intervals are <a, b, c, d, e, f, e, d, c, b, a>
- Then R has identical ordering to some P (and vice versa)

**Consequences:**
- P_n = RI_m for some m
- I_n = R_m for some m
- Only 24 distinct series forms instead of 48

**Testing for symmetry:**
- List the 11 ordered pitch-class intervals
- Check if sequence reads same forward and backward

# Musical Context/Application
- Particularly associated with Webern's aesthetic of economy
- Creates special equivalences between series forms
- Reduces the distinct forms, increasing concentration
- Often reflected in the formal structure of phrases and sections
- Webern's String Quartet, op. 28 is a notable example

# Examples
- Webern, String Quartet, op. 28:
  - All intervals are ic1 (as discrete dyads), with ic3 and ic4 connecting them
  - The interval succession is retrograde-symmetrical
  - P7 = RI4 (identical orderings)
  - Only 24 distinct orderings
  - The formal layout (ABA) mirrors the series symmetry

# Common Confusions
- Assuming all series are retrograde-symmetrical—most have 48 distinct forms
- Confusing retrograde symmetry of the series with retrograde symmetry of musical phrases
- Not recognizing that P = RI equivalence is a consequence of interval symmetry
- Overlooking the aesthetic connection to Webern's concentrated style
