# Quick Definition
Imbrication is a systematic segmentation method that considers all overlapping note groups of a given size within a melodic line.

# Formal Definition
Imbrication is a technique for generating melodic segments by taking all consecutive groups of n notes from a melody. For example, in a six-note melody (notes 1-6), imbricated trichords would be: 1-2-3, 2-3-4, 3-4-5, and 4-5-6. This systematic approach ensures that no potentially significant grouping is overlooked. Imbricated groups may span across rests or phrasing boundaries, revealing interactions between phrase structure and set-class structure.

# Mathematical Formulation/Recognition
**For a melody of m notes, extracting groups of size n:**
- Number of groups = m - n + 1
- Groups overlap by n - 1 notes

**Example (6-note melody, trichords):**
```
Notes:    1  2  3  4  5  6
Group 1: [1  2  3]
Group 2:    [2  3  4]
Group 3:       [3  4  5]
Group 4:          [4  5  6]
```

# Musical Context/Application
Imbrication reveals hidden relationships within melodic lines. A melody may contain multiple members of the same set class that overlap and interlock. This technique is particularly useful for uncovering the systematic use of a particular set type throughout a melodic line, even when phrase structure does not highlight these groupings.

# Examples
The technique is implied throughout the analytical discussions in the text. When analyzing a melody, considering imbricated segments reveals:
- Which set classes recur
- How set classes relate to phrase structure
- Hidden continuities across phrase boundaries

For example, in analyzing Webern's melodies, imbrication often reveals intensive use of a single trichord type throughout.

# Common Confusions
Imbrication is systematic but not exhaustive of all possible segmentations. It covers only contiguous melodic groups. Other segmentation strategies (registral, rhythmic, timbral) may reveal additional important groupings that imbrication misses. Use imbrication as one tool among many.
