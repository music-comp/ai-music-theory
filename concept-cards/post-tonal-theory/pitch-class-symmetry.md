# Quick Definition
Inversional symmetry that exists in the abstract pitch-class domain but is not realized through registral arrangement; every note has an inversional partner in the set, but the actual voicing does not form a pitch-interval palindrome.

# Core Definition
A set exhibits pitch-class symmetry when it is inversionally symmetrical (every note has an inversional partner within the set) but the registral arrangement does not make this symmetry audible as a pitch palindrome. The symmetry exists in pitch-class space but not in pitch space. This is the more common compositional situation: composers frequently use inversionally symmetrical harmonies without arranging them symmetrically in register (Straus, pp. 124-126).

# Prerequisites
- **Inversional symmetry** -- the underlying abstract property
- **Pitch-class space** -- the domain where symmetry exists

# Key Properties
1. The set is inversionally symmetrical at the pitch-class level
2. The registral arrangement is not palindromic
3. The symmetry can be verified by reducing to pitch classes and checking the clockface or addition table
4. This is a weaker realization than pitch symmetry but still structurally significant

# Construction / Recognition
To identify pitch-class symmetry:
1. Reduce all pitches to pitch classes
2. Check for inversional symmetry via palindrome test, clockface, or addition table
3. Compare with the actual registral arrangement
4. If the pc set is In-symmetrical but the pitch intervals are not palindromic, it is pitch-class-symmetrical (not pitch-symmetrical)

# Context & Application
Pitch-class symmetry preserves the harmonic "color" of inversionally symmetrical sets while allowing compositional freedom in voice distribution and register. The inversional symmetry still influences how the harmony functions, even when not perceptually obvious. This is by far the more common way inversionally symmetrical sets appear in actual music.

# Examples
**Example 1** (p. 124, Ex. 3-15c): Schoenberg, Orchestra Pieces, op. 16, no. 3 ("Farben") -- the opening chord is sc(01348), which is inversionally symmetrical. But Schoenberg's arrangement is not pitch-symmetrical. The symmetry is "felt only in the more abstract pitch-class space, not in the more concrete, immediate pitch space."

**Example 2** (p. 125, Ex. 3-16): Boulez, Le Marteau sans maitre -- [A, Bb, C, C#] at the beginning of the melody is sc(0134), inversionally symmetrical, but the Bb would need to be an octave lower to make it pitch-symmetrical. It is pitch-class-symmetrical but not pitch-symmetrical.

**Example 3** (p. 125): The last five notes of the Boulez melody include the same set class (01348) as the Schoenberg chord. If the A were an octave higher, it would be pitch-symmetrical, but as written it is only pitch-class-symmetrical.

# Relationships
## Builds Upon
- **Inversional symmetry** -- the abstract property

## Related
- **Pitch symmetry** -- the stronger, registrally realized version

## Contrasts With
- **Pitch symmetry** -- which requires palindromic pitch intervals in register

# Common Errors
- Assuming pitch-class symmetry means no symmetry is present (the symmetry exists, just not in register)
- Thinking pitch-class symmetry is "less important" than pitch symmetry

# Common Confusions
- The same pc set can be arranged either way -- the distinction is about voicing, not about the set itself
- Pitch-class symmetry is the norm; pitch symmetry is the marked, special case
