# Quick Definition
Inversional symmetry that exists in the abstract pitch-class domain but is not realized through registral arrangement; the symmetry is present but not immediately audible as a mirror image.

# Formal Definition
A set exhibits pitch-class symmetry when it is inversionally symmetrical (every note has an inversional partner within the set), but the actual registral arrangement does not make this symmetry audible as a pitch palindrome. The symmetry exists in the abstract pitch-class space but not in the concrete pitch space.

This represents the more common compositional situation: composers frequently use inversionally symmetrical harmonies without arranging them to display their symmetry in register.

# Mathematical Formulation/Recognition
A pitch-class symmetrical arrangement:
- Contains pitch classes that form an inversionally symmetrical set
- Does NOT arrange these pitch classes so that pitch intervals form a palindrome
- The symmetry can be verified by:
  1. Reducing all pitches to pitch classes
  2. Checking for inversional symmetry via addition table or clockface

The distinction from pitch symmetry is purely about registral arrangement, not pitch-class content.

# Musical Context/Application
Pitch-class symmetry:
- Preserves the harmonic "color" of inversionally symmetrical sets
- Allows compositional freedom in voice distribution and register
- Creates a more subtle, less obvious sense of balance
- Can interact with other musical dimensions (rhythm, dynamics, timbre) without being dominated by registral symmetry

The inversional symmetry is still structurally present and may influence how the harmony functions, even when not perceptually obvious.

# Examples
From Example 3-15c: Schoenberg, Orchestra Pieces, op. 16, no. 3 ("Farben")
- Opening chord is a member of sc(01348), which is inversionally symmetrical
- Schoenberg's actual arrangement is NOT pitch-symmetrical
- The E still has an inversional partner within the chord, but the registral distances are not palindromic
- The symmetry is "felt only in the more abstract pitch-class space, not in the more concrete, immediate pitch space"

From Example 3-16: Boulez, Le Marteau sans maitre
- [A, Bb, C, C#] at beginning: inversionally symmetrical but arranged asymmetrically in pitch space
- [C#, D, E, F] at end: same set class (0134), this time arranged pitch-symmetrically
- Contrast demonstrates compositional choice between the two types of symmetry

# Common Confusions
- Assuming pitch-class symmetry means no symmetry is present (it is present, just not in register)
- Thinking pitch-class symmetry is "less important" than pitch symmetry (both are valid compositional resources)
- Not recognizing that the same pitch-class set can be arranged either way
- Confusing pitch-class symmetry with general pitch-class operations
