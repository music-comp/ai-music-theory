# Quick Definition
Transposition in twelve-tone music shifts each pitch class in the series by the same interval, changing the order positions of pitch classes while preserving the interval succession that defines the series.

# Formal Definition
When a twelve-tone series is transposed, the order of the pitch classes changes (no pitch class occupies the same order position it did), but the content remains the same (all twelve pitch classes are still present) and, more importantly, so is the interval succession. That particular interval succession is what defines the prime ordering of the series. Transposition can be applied beginning on any of the twelve pitch classes, producing P0, P1, P2, ... P11.

# Mathematical Formulation/Recognition
- T_n applied to series: each pitch class x becomes (x + n) mod 12
- Interval succession remains invariant under transposition
- P_n = T_n(P_0)
- Example: P2 transposed up 7 semitones = P9
- After T7: D moves from position 1 to a later position; A moves from position 3 to position 1

# Musical Context/Application
- Transposition is one of the four basic operations for generating series forms
- Series related by transposition (P and P, I and I, etc.) are "prime-related"
- Prime-related series have the same intervals in the same order
- The twelve transpositions of the prime ordering exhaust the P-forms of the series class
- Used for development, contrast, and continuity in twelve-tone compositions

# Examples
- Schoenberg, String Quartet No. 4: P2 transposed up 7 semitones yields P9
- In P2, D is first and A is third; in P9, A is first and D is toward the end
- The interval succession (11, 8, 1, 7, 10, 1, 8, 8, 11, 11, 5) remains the same in both

# Common Confusions
- Expecting transposition to change pitch-class content as it does with smaller sets
- Confusing transposition level with order position—T_n shifts starting pitch class, not position
- Not recognizing that all transposed P-forms share identical interval content
