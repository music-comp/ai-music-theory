# Quick Definition
The combinatoriality chart (Example 6-37) lists all hexachords possessing at least one non-trivial type of combinatoriality, organized by type (ALL, P, R+I, I-only, RI-only) with their transposition levels.

# Core Definition
The chart lists all hexachords with at least one type of combinatoriality, "excluding those that are combinatorial only at R0, i.e., that map onto themselves only at T0, a trivial case" (Straus, p. 340). Categories:
- **ALL (6 hexachords)**: A--F, possessing all four types
- **P only (1 hexachord)**: (013458) at 1 level
- **R and I (1 hexachord)**: (013679) "Petrushka" with 1 non-trivial R and 2 I levels
- **I only (12 hexachords)**: each at 1 level
- **RI only (7 Z-related pairs)**: complementary and Z-related hexachord pairs

# Prerequisites
- **Four types of combinatoriality** -- the chart classifies hexachords by these types

# Key Properties
1. P = maps onto complement via T_n
2. R = maps onto self via T_n (trivial case T0 excluded)
3. I = maps onto complement via I_n
4. RI = maps onto self via I_n
5. I-only is the most common non-trivial combinatorial type
6. Z-related pairs appear in the RI-only category

# Construction / Recognition
Use the chart as a reference when constructing series. Check a hexachord's prime form against the chart to determine its combinatorial properties.

# Context & Application
Essential reference for composers constructing twelve-tone series with specific combinatorial properties. Reveals the relative rarity of P-combinatoriality and the commonality of I-combinatoriality.

# Examples
**Example 1** (pp. 340--341, Ex. 6-37): Selected entries:
- I-only hexachords include (012346), (012357), (013579), etc.
- RI-only Z-related pairs include (012348)/(012456), (012369)/(013467), etc.
- P-only: only (013458)

# Common Errors
- Not excluding trivial R0 (all hexachords map onto themselves at T0)
- Confusing the number of levels with the number of types

# Common Confusions
- **Z-related pairs in RI-only**: These hexachord pairs are complementary and have identical interval vectors but different combinatorial properties from each other
