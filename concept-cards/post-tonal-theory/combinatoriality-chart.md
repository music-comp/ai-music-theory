# Quick Definition
The combinatoriality chart (Example 6-37) lists all hexachords that possess at least one type of combinatoriality, showing which types (P, R, I, RI) each hexachord has and at how many transposition levels.

# Formal Definition
The combinatoriality chart is a reference table listing all hexachords with at least one type of combinatoriality (excluding trivial R_0 cases). The chart identifies:
- All-combinatorial hexachords (A-F): possess all four types
- P-only hexachords: possess only P-combinatoriality
- R and I hexachords: possess both R and I types
- I-only hexachords: the most common, possess only I-combinatoriality
- RI-only hexachords: possess only RI-combinatoriality (often Z-related pairs)

# Mathematical Formulation/Recognition
**Key information in the chart:**
| Type | Description |
|------|-------------|
| P | Maps onto complement via T_n |
| R | Maps onto self via T_n (includes trivial T_0) |
| I | Maps onto complement via I_n |
| RI | Maps onto self via I_n |

**All-combinatorial hexachords (A-F):**
- A (012345): Chromatic, 1 level each
- B (023457): 1 level each
- C (024579): Diatonic, 1 level each
- D (012678): 2 levels each
- E (014589): Hexatonic, 3 levels each
- F (02468T): Whole-tone, 6 levels each

# Musical Context/Application
- Essential reference for composers constructing twelve-tone series
- Reveals which hexachords enable which combinatorial relationships
- Shows the relative rarity of P-combinatoriality
- Identifies Z-related pairs with RI-combinatoriality
- Guides series construction for specific combinatorial properties

# Common Confusions
- Not excluding trivial R_0 (all hexachords map onto themselves at T_0)
- Confusing the number of levels with the number of types
- Overlooking that most I-combinatorial hexachords are not all-combinatorial
- Not recognizing Z-related pairs in the RI-only category
