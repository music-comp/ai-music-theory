# Quick Definition
The pitch classes that remain unchanged when a set is inverted at In; determined by examining the sums (index numbers) formed by pairs of notes within the set.

# Formal Definition
When a pitch-class set is inverted at In, common tones are those pitch classes that appear in both the original set and the inverted set. Unlike transposition (which involves differences/intervals), inversion involves sums: the sum of any pitch class and its image under In equals n (mod 12).

For common tones under In:
- If two different notes in the set sum to n, both become common tones (they map onto each other)
- If a note added to itself equals n (i.e., 2x = n mod 12), that note becomes a common tone (it maps onto itself)

# Mathematical Formulation/Recognition
For a set S inverted at In:
- Calculate all possible sums of pairs of pitch classes in S
- Each sum n produced by two different notes yields 2 common tones at In
- Each sum n produced by a note added to itself (2x = n) yields 1 common tone at In

An addition table systematically calculates all sums:
- Write the set along both axes
- Fill in all pairwise sums (mod 12)
- Count occurrences of each sum in the table
- Each occurrence = 1 common tone at that index number

# Musical Context/Application
Common tones under inversion provide important voice-leading connections between inversionally related set forms. Composers use this to:
- Create smooth transitions between inversionally related harmonies
- Maintain pitch continuity while changing set content
- Establish inversional axes as compositional centers

The calculation of common tones under inversion is more complex than under transposition, but equally important for analyzing post-tonal voice leading.

# Examples
From Example 3-10: [1, 3, 6, 9] (sc 0258)
- 1 + 3 = 4: notes 1 and 3 are common tones at I4
- 1 + 6 = 7: notes 1 and 6 are common tones at I7
- 3 + 3 = 6: note 3 is a common tone at I6
- 6 + 6 = 0: note 6 is a common tone at I0

From Example 3-12: Webern, Movements for String Quartet, op. 5, no. 3 - Uses common tones under both T and I to create smooth voice leading among forms of sc(014). At I0, [8, 9, 0] retains C as a common tone, which Webern keeps in the same register and instrument.

# Common Confusions
- Confusing sums (for inversion) with differences (for transposition)
- Forgetting that two different notes mapping onto each other counts as 2 common tones
- Forgetting that a note mapping onto itself counts as only 1 common tone
- Not recognizing that In and I(12-n) may produce different numbers of common tones
