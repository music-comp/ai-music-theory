# Quick Definition
Sets are transpositionally equivalent when they are related by some Tn operation, sharing the same interval-class content and interval succession in normal form.

# Formal Definition
Two pitch-class sets are transpositionally equivalent if one can be transformed into the other by transposition (adding a constant to all pitch classes). Transpositionally equivalent sets share identical interval-class vectors and, when placed in normal form, have the same succession of intervals between adjacent elements. They belong to the same Tn-type and, by extension, the same set class.

# Mathematical Formulation/Recognition
**Tests for transpositional equivalence:**
1. Put both sets in normal form
2. Compare interval successions
3. If identical, sets are transpositionally equivalent
4. Find n by subtracting corresponding elements: n = y - x (mod 12)

**Properties preserved under transposition:**
- Interval-class content (and vector)
- Interval succession in normal form
- Set-class membership
- Cardinality

**Properties not preserved:**
- Specific pitch-class content
- Order (for unordered sets only direction-independent)

# Musical Context/Application
Transpositionally equivalent sets have a similar sound quality due to their shared interval content. Composers use transposition to develop material while maintaining intervallic consistency. Recognizing transpositional equivalence reveals structural relationships that might not be apparent from the note names alone.

# Common Confusions
Transpositional equivalence is not the same as set-class equivalence. Two sets might be members of the same set class but related by inversion rather than transposition (different Tn-types). Transpositionally equivalent sets have the same normal-form interval succession; inversionally equivalent sets have mirror-image successions.
