# Quick Definition
Pitch-class space is a modular, circular space containing only the twelve pitch classes, where movement by twelve semitones returns to the starting point.

# Formal Definition
Pitch-class space is a modular space represented by the pitch-class clockface, which circles back on itself and contains only the twelve pitch classes. In this space, moving up or down by twelve semitones leads to another member of the same pitch class. Pitch-class space can be understood as the linear pitch space of the staff "wrapped around" onto a circular representation.

# Mathematical Formulation/Recognition
Properties of pitch-class space:
- Contains exactly 12 elements (pitch classes 0-11)
- Cyclical: pc + 12 = pc (mod 12)
- No direction preference: moving 7 clockwise = moving 5 counterclockwise
- Maximum distance between any two pitch classes = 6 semitones

The space operates under mod 12 arithmetic, where all operations result in values from 0 to 11.

# Musical Context/Application
Pitch-class space provides an abstract framework for understanding pitch relationships that transcend register. Two pitches three octaves apart occupy the same point in pitch-class space. This abstraction enables analysts to identify motivic and harmonic connections that might be obscured by registral distance in the actual music.

# Examples
The text draws an analogy with time: while individual hours are unique in linear time, the concept of "eleven o'clock" recurs every twelve hours in cyclical clock time. Similarly, while each pitch is unique in linear pitch space, pitch classes recur cyclically in pitch-class space.

# Common Confusions
Pitch-class space is an abstraction that removes registral information. This is useful for certain kinds of analysis but means that contour and register, which are often musically significant, are not represented. Analysis in pitch-class space complements rather than replaces analysis in pitch space.
