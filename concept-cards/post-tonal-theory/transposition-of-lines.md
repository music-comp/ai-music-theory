# Quick Definition
Transposition operates differently depending on what is transposed: a line of pitches preserves order and contour; a line of pitch classes preserves ordered pitch-class intervals; a set of pitch classes preserves only interval-class content.

# Core Definition
Straus distinguishes three types of transposition with decreasing amounts preserved:

1. **Line of pitches**: Transposition preserves *ordered pitch intervals* and thus *contour* (the pattern of ups and downs). This is traditional melodic transposition.

2. **Line of pitch classes**: Transposition preserves *ordered pitch-class intervals* but not necessarily contour, since pitch-class intervals do not specify direction. Two melodies can be related by pitch-class transposition while having different contours.

3. **Set of pitch classes**: Since a set has no specified order or contour, transposition preserves neither. Only *interval-class content* is preserved.

# Key Properties
1. **Pitch line**: preserves contour, ordered pitch intervals, ordered pc intervals, ic content
2. **PC line**: preserves ordered pc intervals and ic content (not contour)
3. **PC set**: preserves only ic content (not order, contour, or opci)

# Construction / Recognition
**Pitch line transposition**: Add the same pitch interval to each note in order. Contour is preserved.

**PC line transposition**: Add the same pitch-class interval to each note in order. Ordered pitch-class intervals are preserved, but contour may differ (Example 2-5).

**PC set transposition**: Add the same pitch-class interval to each element. Only interval-class content is preserved (Example 2-7).

# Context & Application
Understanding these distinctions is important because much post-tonal music uses set transposition (the most abstract level), where the "same" musical idea can appear with completely different surface characteristics. Recognizing the level of transposition at work helps analysts describe relationships at the appropriate level of abstraction.

# Examples
**Example 2-5** (p. 63, Schoenberg, *String Quartet No. 4*): Two melodies related by pitch-class transposition at T6. Despite different contours (one goes up where the other goes down), their ordered pitch-class intervals are identical: 11-8-1-7-10-1-8-8-11-11-5.

**Example 2-7** (p. 64, Webern, *Concerto for Nine Instruments*, op. 24): Four sets related by transposition. "Despite their obvious dissimilarities," they are all transpositionally equivalent because they share interval-class content.

# Common Errors
- **Error**: Expecting transposition of sets to preserve order or contour. **Correction**: Set transposition preserves only interval-class content.

# Common Confusions
- **Confusion**: Pitch-class transposition should preserve contour. **Clarification**: Pitch-class intervals do not specify direction; two pc-transpositions of the same line can have different contours while sharing the same opci succession.
