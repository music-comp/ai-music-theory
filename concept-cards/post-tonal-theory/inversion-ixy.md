# Quick Definition
Ixy notation identifies an inversion by specifying two pitch classes (x and y) that map onto each other, providing a musically intuitive label for inversional relationships.

# Formal Definition
In Ixy notation, an inversion is identified by naming any pair of pitch classes that exchange under that inversion. The notation Ixy (where x and y are pitch classes written as superscript and subscript) indicates the inversion that maps pitch class x onto pitch class y (and y onto x). Multiple Ixy labels can describe the same inversion, since every inversion creates multiple exchange pairs. The relationship to index-number notation is: x + y = n (mod 12).

# Mathematical Formulation/Recognition
**Conversion between notations:**
- Ixy corresponds to In where n = x + y (mod 12)
- I(G/B) = I(7+11) = I6

**Equivalent labels:**
All of these describe the same inversion (I9):
- I(A/A) = I(G#/Bb) = I(G/B) = I(F#/C) = I(F/C#) = I(E/D) = I(D#/D#)

**Properties:**
- Order doesn't matter: Ixy = Iyx
- There are always 6 exchange pairs for each In (or 7 if counting self-mappings)

# Musical Context/Application
The Ixy notation is particularly useful when an analysis wants to emphasize a specific pitch-class mapping that has musical significance in the passage being analyzed. Rather than using the abstract index number, Ixy highlights which actual notes exchange, making the relationship more musically concrete.

# Examples
**Example 2-24, 2-25**: G and B are related by inversion. The same inversion maps C onto F#, C# onto F, D onto E, Bb onto G#, and maps D# and A each onto themselves. This could be called I(G/B), I(F#/C), I(E/D), etc.

**Example 2-26** (Schoenberg, Three Piano Pieces, op. 11, no. 1): The sets [G, G#, B] and [G, Bb, B] are related by I(G/B) (emphasizing that G and B exchange). The label I(Bb/G#) would also be accurate since that inversion also exchanges G# and Bb.

**Example 2-27** (Berio, Sequenza for Solo Flute): Three sets related by inversions labeled I(D/G) and I(D/C), highlighting musically prominent pitch classes at registral boundaries.

# Common Confusions
Many different Ixy labels can describe the same inversion. Choose the label that makes the most musical sense in context, typically highlighting notes that are prominent in the passage. The relationship to In is: add the two pitch classes to get the index number.
