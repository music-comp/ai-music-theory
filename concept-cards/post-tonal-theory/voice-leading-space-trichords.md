# Quick Definition
A two-dimensional geometric map showing all trichord-classes positioned by their voice-leading distances from each other, where adjacent set classes differ by only one semitone of adjustment.

# Formal Definition
The voice-leading space for trichords is a two-dimensional representation in which all twelve trichord-classes are arranged according to their semitonal offset from one another. Each line connecting two trichords represents one semitone of voice-leading adjustment (one voice moving by one semitone while other voices remain stationary). The distances accumulate consistently across the space.

# Mathematical Formulation/Recognition
Given a set belonging to one set class, semitonal adjustment of each note (up or down by one semitone) produces different trichords representing different set classes. For example:
- sc(024) adjusted by one semitone produces sc(013), sc(014), and sc(025)
- From (012): 1 semitone offset reaches (013); 2 semitones reach (014) or (024); 3 semitones reach (015) or (025); up to maximum 6 semitones between (012) and (048)

The space forms a triangular lattice with:
- (012) (chromatic trichord) at one extreme
- (048) (augmented triad) at the opposite extreme

# Musical Context/Application
Voice-leading spaces allow analysts to:
1. Visualize and interpret harmonic progressions as journeys through the space
2. Measure both the distance and direction of progressions
3. Understand whether music moves toward chromaticness (tension) or evenness (relaxation)
4. Trace the number of semitonal adjustments between successive harmonies

# Common Confusions
- The space represents abstract set classes, not specific pitch-class sets
- Distance in the space measures voice-leading adjustment, not intervallic content
- Adjacency in the space indicates minimal voice-leading distance (one semitone), not musical similarity in other parameters
