# Quick Definition
A Tn-type is a class of sets that are all related to each other by transposition only, forming half of a typical set class.

# Formal Definition
A Tn-type is a collection of pitch-class sets where every member is related to every other member by transposition (but not necessarily by inversion). A typical Tn-type contains twelve sets, one at each of the twelve transposition levels. A set class (T/I type) normally contains two Tn-types: one comprising the set and its transpositions, the other comprising the inverted set and its transpositions.

# Mathematical Formulation/Recognition
**Properties:**
- Normally contains 12 sets
- All members related by Tn
- Part of a larger set class (T/I type)
- Sets within a Tn-type have identical normal forms (same intervals)

**Relationship to set class:**
- Set class = Tn-type 1 + Tn-type 2 (related by inversion)
- Some symmetrical sets: Tn-type = set class (inversion produces same Tn-type)

# Musical Context/Application
Distinguishing between Tn-type and set class can be analytically valuable. Some passages may use only transposition (staying within a Tn-type), while others use both transposition and inversion (moving throughout the set class). Identifying this distinction reveals compositional strategies.

# Common Confusions
Not all sets with the same prime form are in the same Tn-type. Sets with the same prime form belong to the same set class, but they may be in different Tn-types (related by inversion rather than transposition). Check the interval succession in normal form: sets in the same Tn-type have identical interval patterns.
