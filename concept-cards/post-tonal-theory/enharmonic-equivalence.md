# Quick Definition
Notes with different spellings but the same sounding pitch (like Bb and A#) are considered functionally equivalent in post-tonal music.

# Core Definition
Enharmonic equivalence is the principle that notes spelled differently but sounding at the same pitch on an equal-tempered instrument are treated as functionally identical in post-tonal music. In common-practice tonal music, Bb and A# have different functions (e.g., in G major, Bb is flat-3 while A# is sharp-2), but post-tonal music largely abandons these distinctions. The notation of post-tonal music is generally functionally arbitrary, determined by convenience and legibility.

# Key Properties
1. Enharmonically equivalent notes map to the same pitch-class integer (e.g., Ab and G# both map to 8)
2. In tonal music, enharmonic spelling carries functional meaning; in post-tonal music, it generally does not
3. Enharmonic equivalence, together with octave equivalence, defines pitch class
4. Notation may occasionally suggest function (sharps ascending, flats descending), but this is not systematic

# Construction / Recognition
## To Construct:
1. Take any pitch
2. Respell it using a different letter name (e.g., C# becomes Db)
3. The two spellings are enharmonically equivalent

## To Recognize:
1. Two note names that sound the same on an equal-tempered instrument
2. They map to the same pitch-class integer

# Context & Application
Enharmonic equivalence liberates post-tonal analysis from dependence on spelling conventions inherited from tonal music. It enables a consistent integer representation of pitch classes where each integer corresponds to exactly one pitch class, regardless of spelling.

# Examples
**Example 1-4** (p. 19): In Stockhausen, Klavierstuck III, a passage involves three pitch repetitions: A returns an octave higher, B returns two octaves lower, and Ab returns three octaves higher spelled as G#. All three pairs are octave equivalent; the last pair also demonstrates enharmonic equivalence.

# Common Errors
- **Error**: Assuming enharmonic spelling always carries meaning in post-tonal analysis
  **Correction**: Notation in post-tonal music is generally arbitrary. Analyze by pitch-class integer, not spelling.

# Common Confusions
- **Confusion**: Carrying tonal-music habits into post-tonal analysis and treating Bb and A# differently
  **Clarification**: In post-tonal theory, Bb and A# are the same pitch class (10). Functional distinctions of tonal music do not apply.
