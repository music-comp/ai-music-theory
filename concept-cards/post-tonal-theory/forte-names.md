# Quick Definition
Forte names identify set classes using a two-number format (cardinality-ordinal), such as 3-11 for the major/minor triad or 4-23 for the quartal chord.

# Formal Definition
Forte names are a labeling system for set classes developed by Allen Forte, who pioneered pitch-class set theory. Each name consists of two numbers separated by a hyphen. The first number indicates the cardinality (number of pitch classes in the set). The second number gives the set's position on Forte's ordered list of sets of that cardinality. For example, 3-4 indicates the fourth set class on the list of trichords; 6-Z44 indicates a hexachord (the Z indicates it shares its interval-class vector with another set class).

# Mathematical Formulation/Recognition
**Format:** cardinality-ordinal

Examples:
| Forte Name | Prime Form | Description |
|------------|------------|-------------|
| 3-1 | (012) | chromatic trichord |
| 3-11 | (037) | major/minor triad |
| 4-23 | (0257) | quartal tetrachord |
| 5-35 | (02479) | pentatonic scale |
| 6-1 | (012345) | chromatic hexachord |
| 6-35 | (02468T) | whole-tone scale |

The ordinal number reflects Forte's ordering criteria, which differs slightly from a simple prime-form ordering.

# Musical Context/Application
Forte names remain in use in much of the theoretical literature, though contemporary practice (including this book) tends to favor prime forms for everyday reference. Understanding Forte names is essential for reading older analytical literature and for using reference works that employ this system.

# Examples
From the List of Set Classes:
- 3-3: (014) - the set class containing augmented triads and Webern's characteristic trichord
- 4-Z15: (0146) - one of the "all-interval tetrachords" (Z indicates Z-relation)
- 4-Z29: (0137) - the other all-interval tetrachord

The Z-related pairs share identical interval-class vectors but have different prime forms.

# Common Confusions
The ordinal number in a Forte name is not related to the intervals in the set; it's simply a list position. Don't try to derive musical meaning from the ordinal number itself. Also, some sources use slightly different ordering criteria, so occasionally a Forte name may refer to different sets in different sources.
