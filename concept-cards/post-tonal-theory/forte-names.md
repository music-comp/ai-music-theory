# Quick Definition
Forte names identify set classes using a two-number format (cardinality-ordinal), such as 3-11 for the major/minor triad or 4-23 for the quartal chord.

# Core Definition
Forte names are a labeling system developed by Allen Forte, "who pioneered the theory of pitch-class sets" (Straus, Ch. 2). Each name consists of two numbers separated by a hyphen: the first number indicates the cardinality (number of pitch classes); the second gives the set's position on Forte's ordered list. For example, 3-4 is the fourth set class on the list of trichords. A Z in the name (e.g., 4-Z15) indicates a Z-related pair -- two set classes that share the same interval-class vector but have different prime forms.

# Key Properties
1. Format: cardinality-ordinal (e.g., 3-11, 6-Z44)
2. First number = cardinality (number of pitch classes)
3. Second number = position on Forte's list
4. Z prefix indicates Z-relation (shared interval-class vector, different prime form)
5. Ordinal number reflects Forte's ordering criteria, not musical intervals

# Construction / Recognition
To find a Forte name:
1. Determine the prime form of your set
2. Look up the prime form in the List of Set Classes
3. Read off the Forte name from the second column

# Context & Application
Forte names remain in wide use in the theoretical literature, though contemporary practice (including Straus) tends to favor prime forms for everyday reference. Understanding Forte names is essential for reading older analytical literature. This book "will usually refer to set classes by their prime form, but we will occasionally use the Forte-names also" (Straus, Ch. 2).

# Common Errors
- **Error**: Trying to derive musical meaning from the ordinal number. **Correction**: The ordinal is simply a list position; it has no intervallic or musical significance.

# Common Confusions
- **Confusion**: Different sources listing different prime forms for the same Forte name. **Clarification**: Forte and Rahn differ on a few set classes (5-20, 6-29, 6-31, 7-18, 7-20, 8-26). This book follows Rahn.
