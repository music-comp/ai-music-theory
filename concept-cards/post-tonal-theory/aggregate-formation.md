# Quick Definition
Aggregate formation encompasses the various methods by which all twelve pitch classes are collected -- through single series statements, hexachordal combination, trichordal combination, and vertical array arrangements.

# Core Definition
"The *aggregate* -- a collection consisting of all twelve pitch classes -- is the basic harmonic unit in twelve-tone music, so it is not surprising that composers find various ways of combining collections to create it" (Straus, p. 341). Methods include: single series statement, hexachordal combinatoriality (combining complementary hexachords from different series forms), trichordal combinatoriality (four complementary trichords from array columns), and vertical aggregates in arrays.

# Prerequisites
- **Aggregate** -- the complete collection of all twelve pitch classes
- **Hexachordal combinatoriality** -- one key method of aggregate formation

# Key Properties
1. A single series statement is the simplest aggregate
2. Hexachordal combination pairs complementary hexachords from different forms
3. Trichordal combination uses four complementary trichords
4. Babbitt's arrays achieve aggregates in multiple dimensions simultaneously
5. Aggregate completion often marks structural boundaries

# Construction / Recognition
- Within rows of a trichordal array: 12 consecutive pcs = aggregate
- Between combinatorial pairs: H1 of P + H1 of I = aggregate
- Within array columns: four trichords = aggregate
- Between registral pairs: hexachordal combination = aggregate

# Context & Application
Different composers emphasize different methods: Schoenberg uses hexachordal aggregates; Babbitt achieves multi-dimensional aggregates; Stravinsky often avoids systematic aggregate formation. "Completion of an aggregate frequently coincides with, or articulates, the end of a phrase or section of music" (p. 365).

# Examples
**Example 1** (pp. 338--342): Schoenberg, String Quartet No. 4 -- aggregates formed between hexachords of P0 and RI5, and between RI5 and R0.

**Example 2** (pp. 350--354): Babbitt, String Quartet No. 2 -- aggregates in rows, between row-pairs, and in columns simultaneously.

# Common Errors
- Assuming all twelve-tone music emphasizes aggregate formation equally (Stravinsky often doesn't)
- Not recognizing multiple simultaneous aggregates

# Common Confusions
- **Aggregate formation vs. series statement**: A series statement is one aggregate, but aggregates can also be formed between series forms
