# Quick Definition
An interval class (ic) is a category containing all pitch intervals related by octave equivalence and complementation, representing the most abstract way of describing intervals.

# Formal Definition
An interval class (abbreviated ic) is synonymous with unordered pitch-class interval. Just as each pitch class contains many individual pitches, each interval class contains many individual pitch intervals. Due to octave equivalence, compound intervals (larger than an octave) are equivalent to their within-octave counterparts. Additionally, pitch-class intervals larger than 6 are equivalent to their complements mod 12 (the pairs 0/12, 1/11, 2/10, 3/9, 4/8, 5/7, 6/6). These pairs correspond to what tonal theory calls inversions (like minor thirds and major sixths).

# Mathematical Formulation/Recognition
The seven interval classes and their contents:
| Interval Class | Pitch Intervals |
|----------------|-----------------|
| 0 | 0, 12, 24, ... (unisons, octaves) |
| 1 | 1, 11, 13, 23, ... (m2, M7, m9, ...) |
| 2 | 2, 10, 14, 22, ... (M2, m7, M9, ...) |
| 3 | 3, 9, 15, 21, ... (m3, M6, m10, ...) |
| 4 | 4, 8, 16, 20, ... (M3, m6, M10, ...) |
| 5 | 5, 7, 17, 19, ... (P4, P5, P11, ...) |
| 6 | 6, 18, 30, ... (tritone, compound tritone) |

# Musical Context/Application
All intervals within an interval class share a characteristic sound quality. We might say there is something "1-ish" about all intervals belonging to interval class 1, whether they are semitones, major sevenths, or minor ninths. This shared quality makes interval class a powerful tool for describing the sonic character of post-tonal harmonies and melodies.

# Common Confusions
There are only seven interval classes (0-6), not twelve. Interval class 6 (tritone) is its own complement; it maps onto itself. Students sometimes confuse ordered and unordered pitch-class intervals; remember that interval class always takes the shorter route around the clockface.
