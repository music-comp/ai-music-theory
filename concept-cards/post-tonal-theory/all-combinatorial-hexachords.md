# Quick Definition
All-combinatorial hexachords are the six hexachord types (labeled A-F) that possess all four kinds of combinatoriality—I, P, R, and RI—at one or more transposition levels.

# Formal Definition
The first six hexachords on the combinatoriality chart are *all-combinatorial*—they possess all four types of combinatoriality. These six hexachords, traditionally labeled A-F, have varying degrees of combinatorial potential:
- **A (012345)**: Chromatic hexachord, 1 level each
- **B (023457)**: 1 level each
- **C (024579)**: Diatonic hexachord, 1 level each
- **D (012678)**: 2 levels each
- **E (014589)**: Hexatonic hexachord, 3 levels each
- **F (02468T)**: Whole-tone hexachord, 6 levels each

# Mathematical Formulation/Recognition
The six all-combinatorial hexachords:
| Label | Prime Form | Name | Levels |
|-------|-----------|------|--------|
| A | (012345) | Chromatic | 1 each |
| B | (023457) | — | 1 each |
| C | (024579) | Diatonic | 1 each |
| D | (012678) | — | 2 each |
| E | (014589) | Hexatonic | 3 each |
| F | (02468T) | Whole-tone | 6 each |

- A, B, C: All four types at 1 level each (R only at T0)
- D: All four types at 2 levels each
- E: All four types at 3 levels each
- F: All four types at 6 levels each (maximum symmetry)

# Musical Context/Application
- All-combinatorial hexachords offer maximum combinatorial flexibility
- Composers can create aggregates through any transformation type
- Higher-level combinatoriality (D, E, F) provides more options
- Babbitt extensively used all-combinatorial hexachords
- The E-hexachord (hexatonic) appears frequently in Babbitt's trichordal arrays
- The whole-tone hexachord has the highest degree of symmetry

# Examples
- Babbitt, String Quartet No. 2: Uses E-hexachord (014589) in rows and A-hexachord (012345) between row-pairs
- Schoenberg's series often use I-combinatorial hexachords that are not all-combinatorial
- The chromatic hexachord (A) and diatonic hexachord (C) are among the most familiar

# Common Confusions
- Thinking all I-combinatorial hexachords are all-combinatorial—most have only one or two types
- Confusing the number of levels with the types of combinatoriality
- Not recognizing the A-F labeling system in the literature
- Assuming all-combinatorial hexachords are rare—there are exactly six types
