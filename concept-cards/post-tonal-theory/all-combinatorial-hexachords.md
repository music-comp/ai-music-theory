# Quick Definition
The six all-combinatorial hexachords (labeled A--F) possess all four types of combinatoriality at one or more transposition levels, ranging from 1 level each (A, B, C) to 6 levels each (F, the whole-tone scale).

# Core Definition
"The first six hexachords on the chart are *all-combinatorial*" (Straus, p. 340). These are labeled A--F in the literature:
- **A (012345)**: Chromatic hexachord, 1 level each
- **B (023457)**: 1 level each
- **C (024579)**: Diatonic hexachord, 1 level each
- **D (012678)**: 2 levels each
- **E (014589)**: Hexatonic hexachord, 3 levels each
- **F (02468T)**: Whole-tone hexachord, 6 levels each

"The first three hexachords have all four types of combinatoriality at one transposition level each... The fourth hexachord has each type of combinatoriality at two levels; the fifth is all-combinatorial at three levels; and the sixth, the whole-tone scale, is all-combinatorial at six levels" (p. 340).

# Prerequisites
- **Four types of combinatoriality** -- the properties being combined

# Key Properties
1. Exactly six hexachord types are all-combinatorial
2. Increasing levels of combinatoriality correlate with increasing symmetry
3. A, B, C have 1 level each (R only at T0 trivially)
4. D has 2 levels each
5. E has 3 levels each
6. F (whole-tone) has 6 levels each -- maximum symmetry

# Construction / Recognition
- Check if a hexachord possesses all four types (P, I, R, RI)
- Use the combinatoriality chart (Ex. 6-37) as reference
- Higher symmetry = more combinatorial levels

# Context & Application
Babbitt extensively used all-combinatorial hexachords, particularly the E-hexachord (014589) in his trichordal arrays. These hexachords offer maximum flexibility for aggregate formation through any transformation type.

# Examples
**Example 1** (pp. 350--354): Babbitt, String Quartet No. 2 -- uses E-hexachord (014589) within array rows and A-hexachord (012345) between row-pairs.
