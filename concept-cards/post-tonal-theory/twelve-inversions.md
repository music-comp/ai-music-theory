# Quick Definition
There are exactly twelve possible inversions (I0 through I11), each with a unique index number and a unique set of pitch-class exchange pairs.

# Core Definition
Each of the twelve inversions (I0 through I11) brings about a unique set of mappings between pitch classes. For each inversion, every pitch class maps onto exactly one partner (which may be itself). The mappings can be visualized as curved lines on the pitch-class clockface connecting paired pitch classes. Multiple Ixy labels describe the same inversion; the choice of label depends on musical context.

# Prerequisites
- **Inversion (In)** -- the operation being cataloged
- **Index number (sum)** -- each inversion has a unique index number
- **Inversion (Ixy)** -- alternative labeling for each inversion

# Key Properties
1. Exactly 12 inversions: I0 through I11
2. Each has a unique set of six exchange pairs
3. When n is even: two pitch classes map to themselves (fixed points at n/2 and n/2 + 6)
4. When n is odd: no fixed points; all pitch classes exchange with a different one
5. Each inversion can be labeled with any of its exchange pairs as Ixy

# Context & Application
Understanding the complete catalog of inversions is valuable for determining which specific inversion connects two sets and for recognizing inversional symmetry. Each inversion defines a unique axis on the clockface.

# Examples

# Common Errors
- **Error**: Thinking there are more than twelve inversions. **Correction**: There are exactly twelve, one for each index number 0--11.

# Common Confusions
- **Confusion**: Fixed points. **Clarification**: Even index numbers have two fixed points (pitch classes that map to themselves); odd index numbers have none.
