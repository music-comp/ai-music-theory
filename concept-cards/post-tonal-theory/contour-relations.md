# Quick Definition
The study of melodic shapes based on relative pitch height rather than specific pitches or intervals; contour analysis identifies patterns of higher and lower without requiring knowledge of exact notes.

# Core Definition
Contour relations analyze musical lines and gestures in terms of their up-and-down motion, independent of specific pitch content. Notes are represented by integers based on their relative position (0 = lowest, ascending to n-1 = highest), grouped into contour segments (CSEGs), and classified into equivalence classes (CSEG-classes) via contour inversion, retrograde, and retrograde-inversion. Contour extends beyond pitch to dynamics, durations, and other orderable parameters (Straus, pp. 142-148).

# Prerequisites
- **Pitch space** -- the domain where contour operates (though contour abstracts away from specific pitches)

# Key Properties
1. Uses relative position, not absolute pitch
2. Ordered: angle brackets <...> indicate temporal order
3. Four operations: identity, inversion, retrograde, retrograde-inversion
4. Applicable to non-pitch parameters (dynamics, duration)
5. CSEG-classes grow rapidly: 2 for 3-note, 8 for 4-note segments
6. Provides a less precise but sometimes more perceptually relevant level of analysis

# Construction / Recognition
Contour analysis process:
1. Assign 0 to the lowest note, 1 to the next, etc.
2. Write integers in temporal order within angle brackets
3. Compare CSEGs for identity, I, R, or RI relationships
4. Group into CSEG-classes (analogous to set classes)

# Context & Application
Contour is valuable for analyzing music where pitch is indeterminate but direction is specified, atonal music where shape is more salient than interval, and experimental/graphic notation. It also reveals hidden relationships between intervallically different melodies that share shape.

# Examples
**Example 1** (p. 143, Ex. 3-36): Crawford Seeger, String Quartet, first movement -- three fragments share CSEG <2013> despite different intervals and set classes. Unity through contour rather than pitch content.

**Example 2** (p. 146, Ex. 3-39): Stockhausen, Klavierstuck II -- upper melody CSEG <3201> in both pitch and dynamics; lower melody <0132> (contour inversion).

**Example 3** (p. 147, Ex. 3-40): Feldman, Projection No. 1 -- pizzicato notes describe CSEG <102> in pitch; durational pattern also describes <102>.

**Example 4** (pp. 147-148, Ex. 3-41): Cage, Variations -- four events in four dimensions (duration, dynamics, pitch, timbre) each described by different contours: <1230>, <1302>, <3201>, <2031>.

# Common Errors
- Thinking contour analysis replaces pitch analysis (they are complementary)
- Confusing contour operations with pitch-class operations (analogous but distinct)

# Common Confusions
- Contour is not only for indeterminate music -- it adds insight to fully determined music too
- Contour can apply to any orderable parameter, not just pitch
