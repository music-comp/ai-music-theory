# Quick Definition
The compositional technique of arranging a set in register so that its extreme notes (highest, lowest, or registrally grouped) form meaningful subsets; the subsets of a set represent abstract potential, and composers choose which to project through voicing.

# Core Definition
Projecting subsets in pitch space is the compositional act of arranging pitch classes in register so that certain subsets become perceptually prominent -- through being the highest notes, lowest notes, or otherwise registrally grouped. The subsets of a set are an abstract potential; the composer chooses which to emphasize and which to repress. Only a small number of a set's many subsets will be musically significant in any given context (Straus, pp. 138-140).

# Prerequisites
- **Subset and superset relation** -- the potential being realized
- **Inclusion lattice** -- shows the full range of possibilities

# Key Properties
1. Register (voicing) determines which subsets are perceptually prominent
2. Different arrangements of the same set project different subsets
3. The composer's choice of projection is a primary compositional decision
4. Only a few of a set's many subsets are musically significant in any context
5. Articulation, dynamics, and rhythm also contribute to subset projection

# Construction / Recognition
To analyze projected subsets:
1. Identify the full set (all pitch classes present)
2. Determine registral groupings (highest n notes, lowest n notes, etc.)
3. Find the set class of each grouping
4. Compare with the inclusion lattice to see what was emphasized vs. what was possible

# Context & Application
Subset projection reveals compositional intent. Two different arrangements of the same hexachord can project completely different harmonic characters -- one emphasizing augmented triads, another emphasizing major/minor triads. This analysis connects abstract set-class theory to concrete musical decisions.

# Examples
**Example 1** (p. 138, Ex. 3-31): Schoenberg, Little Piano Pieces, op. 19, no. 2 -- chord is (014589). Arranged so that:
- Highest 4 notes = sc(0148)
- Lowest 4 notes = sc(0148)
- Highest 3 notes = augmented triad (048)
- Lowest 3 notes = augmented triad (048)

**Example 2** (p. 139, Ex. 3-32): Schoenberg, Ode to Napoleon, final measures -- same set class (014589), same member [D, Eb, F#, G, Bb, B], but arranged to project:
- G minor triad [G, Bb, D]
- B minor triad [B, D, F#]
- Eb major triad [Eb, G, Bb]
Different compositional choices from the same abstract material.

# Common Errors
- Assuming all subsets are projected (most are not perceptually prominent)
- Ignoring register when identifying subsets (register is what makes them audible)

# Common Confusions
- Subset projection is a compositional choice, not an inherent property of the set
- The same set can be arranged to project completely different subset types
