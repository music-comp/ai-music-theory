# Quick Definition
A theorem stating that when a set is transposed at Tn, the number of common tones equals the number of occurrences of interval n in the set (with tritone transposition producing twice that number).

# Formal Definition
The Common Tone Theorem for Transposition states: For any pitch-class set S transposed at Tn, the number of pitch classes held in common between S and Tn(S) equals the number of times interval-class n appears in S. The sole exception is T6 (tritone transposition), where the number of common tones equals twice the number of tritones in the set.

This theorem allows prediction of common-tone relationships directly from the interval-class vector without calculating actual transpositions.

# Mathematical Formulation/Recognition
Given interval-class vector [ic1, ic2, ic3, ic4, ic5, ic6]:

- Common tones at T1 or T11 = ic1
- Common tones at T2 or T10 = ic2
- Common tones at T3 or T9 = ic3
- Common tones at T4 or T8 = ic4
- Common tones at T5 or T7 = ic5
- Common tones at T6 = 2 times ic6

For T0: common tones = cardinality of the set (all notes held in common)

# Musical Context/Application
The theorem is essential for:
- Predicting voice-leading smoothness between transposed set forms
- Understanding why certain keys are "closely related" in tonal music
- Analyzing composers' choices of transposition levels
- Identifying transpositionally symmetrical sets (when common tones equal set cardinality)

The theorem explains the graduated hierarchy of key relationships in tonal music: the major scale's interval-class vector [254361] produces different numbers of common tones at each transposition level, creating the circle of fifths.

# Examples
Set class (0134) has interval-class vector [212100]:
- T1/T11: 2 common tones (two ic1s)
- T2/T10: 1 common tone (one ic2)
- T3/T9: 2 common tones (two ic3s)
- T4/T8: 1 common tone (one ic4)
- T5/T7: 0 common tones (no ic5s)
- T6: 0 common tones (no ic6s)

The whole-tone scale [060603]:
- T2/T4/T8/T10: 6 common tones (complete duplication)
- T1/T3/T5/T7/T9/T11: 0 common tones (no overlap)

# Common Confusions
- Forgetting that T6 is the exception (multiply ic6 count by 2)
- Assuming the theorem gives specific pitch classes (it only gives the count)
- Not recognizing that complementary transposition levels (Tn and T12-n) always produce the same number of common tones
- Confusing this theorem with the common tone theorem for inversion
