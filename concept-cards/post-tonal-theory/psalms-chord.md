# Quick Definition
The E-minor chord (with added (0134) figure) that opens Stravinsky's *Symphony of Psalms*, functioning as a pivot between octatonic and diatonic collections that share it as a common subset.

# Core Definition
The **Psalms chord** is the famous opening harmony of Stravinsky's *Symphony of Psalms*, consisting of an E-minor triad embedded within set-class (0134), which Stravinsky described as "two minor thirds joined by a major third." This chord functions as a pivot between OCT1,2 (beginning on E: E-F-G-Ab-Bb-B-C#-D) and E Phrygian (diatonic). When first heard, it is followed by octatonic music; when it recurs, it is followed by diatonic music. The centric tone E remains constant throughout, while the collectional environment shifts (Straus, Ch. 5, pp. 276-277).

# Prerequisites
- **Octatonic collection** -- one collectional context for the chord

# Key Properties
1. Contains (0134), described by Stravinsky as "two minor thirds joined by a major third"
2. Belongs simultaneously to OCT1,2 and E Phrygian (diatonic)
3. Serves as a pivot harmony between octatonic and diatonic sections
4. The centric tone E remains constant through the collection changes
5. Exemplifies how a single harmony can link different referential collections

# Construction / Recognition
1. The chord is built from E-minor triad plus the (0134) figure
2. Check membership in both OCT1,2 and the diatonic collection on E
3. The dual membership enables the pivot function

# Context & Application
The Psalms chord is a textbook example of how post-tonal composers use shared subsets to create coherent shifts between referential collections. It demonstrates that the same harmony can function in radically different collectional contexts, with the shift in context (rather than the change of chord) providing the sense of harmonic motion.

# Examples
**Example 1** (p. 277): Stravinsky, *Symphony of Psalms* -- Opening chord followed by OCT1,2 music. The collection on E: E-F-G-Ab-Bb-B-C#-D.

**Example 2** (p. 277): Same piece, later -- The chord returns, now followed by E Phrygian (diatonic) music. Same chord, different collectional context.

# Common Errors
- Analyzing the chord in only one collectional context (it belongs to both)

# Common Confusions
- **The chord itself doesn't change**: The harmonic shift comes from the collectional context that follows it, not from any change to the chord itself
