# Quick Definition
Patterns generated by repeatedly transposing a pitch class by a single interval, creating six distinct cycle types (C1-C6) that underlie many melodic and harmonic structures in post-tonal music.

# Core Definition
An **interval cycle** is the sequence of pitch classes produced when starting from any pitch class and moving repeatedly by a single interval (measured in semitones). There are six interval cycles, designated C1 through C6, corresponding to intervals 1 through 6 semitones. Each cycle type has characteristic properties determined by GCD(interval, 12). Moving clockwise around the cycle involves the stated interval; counterclockwise involves the complement. Interval cycles are "generic shapes" that guide motion across many post-tonal works, unlike piece-specific motives in composing-out (Straus, Ch. 4, p. 180).

# Prerequisites
- **Pitch class** -- the basic unit that cycles through
- **Interval class** -- the generating interval for each cycle type
- **Transposition (Tn)** -- the operation that generates cycles

# Key Properties
1. Number of distinct cycles for interval i = GCD(i, 12)
2. Size of each cycle (pitch classes) = 12 / GCD(i, 12)
3. C1 and C5 pass through all 12 pitch classes; C2-C4, C6 create smaller cycles
4. Complementary intervals (e.g., i5 and i7) generate the same cycle in opposite directions
5. The large referential collections derive from cycles: chromatic = C1, whole-tone = C2, octatonic = two C3s, hexatonic = two C4s, diatonic = C5 segment

Subscript notation identifies pitch-class content: C3_0 = {0,3,6,9}, C3_1 = {1,4,7,10}, C3_2 = {2,5,8,11}.

# Context & Application
Interval cycles provide melodic frameworks, harmonic foundations, and referential collections. They generate cyclic sets and maximally even harmonies. They are used systematically by Bartok, Stravinsky, Varese, Ives, and many others as organizing principles for both melody and harmony.

# Examples
**Example 1** (p. 181): Bartok, *String Quartet No. 6*, fourth movement -- Cello approaches C-minor cadence with descending C1 (E-Eb-D-Db-C); first violin uses ascending C2 (A-B-C#-Eb); C3 shapes the main theme.

**Example 2** (p. 182): Varese, *Density 21.5* -- Principal melodic boundary tones follow C3_1 (C#-E-G-Bb). Arrival on D5 (fff) signals harmonic shift.

**Example 3** (p. 182): Ives, *"The Cage"* -- Melody uses five-note segments of C2 (whole-tone); accompanying chords use five-note segments of C5 (circle of fifths).

**Example 4** (p. 183): Bartok, *String Quartet No. 3* -- Opening chord: four-note C1 segment (C#-D-D#-E); opening melody: complementary eight-note C1 segment; final chord: four-note C5 segment (C#-G#-D#-A#).

# Relationships
## Builds Upon
- **Transposition** -- cycles are generated by repeated Tn
- **Pitch class** -- the elements that form cycles

## Enables
- **Cyclic linear motion** -- melody following a cycle
- **Cyclic sets** -- harmonies drawn from cycles
- **Maximal evenness** -- maximally even sets arise from cycles
- **Referential collections** -- diatonic, octatonic, whole-tone, hexatonic derive from cycles

## Related
- **Combination cycles** -- cycles using alternating intervals rather than a single interval

## Contrasts With
- **Composing-out** -- piece-specific motivic projection vs. generic cyclic shapes

# Common Errors
- Confusing C5 and C7 (they are the same cycle traversed in opposite directions)
- Treating subscript as a starting point rather than a content identifier

# Common Confusions
- **C5 vs. C7**: Both traverse all 12 pitch classes; C5 (fourths) and C7 (fifths) are inverses generating the same cycle
- **Cycles vs. scales**: A cycle is a theoretical construct; a scale is a realized, ordered pitch collection
- **Single interval vs. alternating**: Interval cycles use one repeated interval; combination cycles alternate two
