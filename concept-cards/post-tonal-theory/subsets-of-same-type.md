# Quick Definition
The phenomenon where multiple distinct subsets of a set belong to the same set class, reducing the variety of subset types; highly symmetrical sets tend to have more such redundancy.

# Core Definition
Among the many subsets of a set, some may be members of the same set class. This reduces the number of distinct set-class types represented among the subsets. sc(0268) is an extreme case: all four of its trichordal subsets belong to the same set class, (026). Most set classes are not as restricted, but there is often some redundancy in subset content. This redundancy is one factor limiting the otherwise vast combinatorial possibilities (Straus, p. 137).

# Prerequisites
- **Subset and superset relation** -- the framework
- **Set class** -- the equivalence being checked

# Key Properties
1. Multiple distinct subsets can share the same set class
2. Highly symmetrical sets tend to have more redundancy
3. The degree of redundancy varies widely across set classes
4. Redundancy reduces the number of distinct subset types available to the composer

# Construction / Recognition
To assess subset-type redundancy:
1. List all subsets of a given cardinality
2. Determine the set class of each
3. Count how many distinct set classes appear
4. Compare with the total number of subsets at that cardinality

# Context & Application
Subset redundancy affects compositional potential: a set with all trichords of the same type offers less variety in three-note gestures than one with diverse trichordal subsets. Composers may choose supersets specifically for their subset diversity or, conversely, for the unity provided by redundancy.

# Examples
**Example 1** (p. 137, Ex. 3-29): sc(0268) -- all four trichordal subsets:
- [0, 2, 6], [0, 2, 8], [0, 6, 8], [2, 6, 8]
- All are members of sc(026)
- Maximum redundancy at the trichord level

# Common Errors
- Assuming all subsets must be of different types (they often are not)

# Common Confusions
- Redundancy is not the same as symmetry, though the two are correlated
- The same set class may appear different numbers of times as a subset
