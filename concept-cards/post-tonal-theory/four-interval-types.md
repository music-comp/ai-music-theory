# Quick Definition
Post-tonal theory provides four interval types forming a spectrum from most concrete (ordered pitch interval) to most abstract (interval class): opi, upi, opci, and upci/ic.

# Core Definition
There are four different ways of talking about intervals in post-tonal theory: (1) ordered pitch interval (opi), (2) unordered pitch interval (upi), (3) ordered pitch-class interval (opci), and (4) unordered pitch-class interval (upci), also called interval class (ic). These form a hierarchy from most specific and concrete to most general and abstract. None is "better or more right" than the others; which one to use depends on what musical relationship is being described.

# Prerequisites
- **Ordered Pitch Interval** — the most concrete interval type
- **Unordered Pitch Interval** — removes direction from opi
- **Ordered Pitch-Class Interval** — reduces opi to mod 12
- **Unordered Pitch-Class Interval** — the most abstract type (= interval class)

# Key Properties
1. opi: specifies size, direction, and register (any integer, + or -)
2. upi: specifies size and register, not direction (any positive integer)
3. opci: specifies size and direction mod 12, not register (0-11)
4. upci/ic: specifies only the abstract interval type (0-6)
5. Each successive type discards information while gaining generality

# Construction / Recognition
## To Construct:
1. Start with two pitches
2. opi = signed difference in semitones (e.g., +19)
3. upi = absolute difference in semitones (e.g., 19)
4. opci = opi mod 12 (e.g., 7 or -5)
5. upci/ic = smaller of opci and its complement (e.g., 5)

## To Recognize:
1. opi: includes + or - and may exceed 12
2. upi: positive, may exceed 12, no direction
3. opci: 0-11, may include direction
4. upci/ic: 0-6, no direction

# Context & Application
Choosing the right interval type is an analytical decision. Use opi when contour and register matter. Use upi when spacing matters but not direction. Use opci when pitch-class relationships matter but direction is relevant (e.g., melodic succession). Use ic when seeking the most abstract classification of intervallic content.

# Examples
**Example 1-17** (p. 29): A single interval from a low pitch to a high pitch 19 semitones above, described all four ways:
- opi = +19 (ascending compound fifth: most specific)
- upi = 19 (compound fifth, direction removed)
- opci = 7 or -5 (mod 12, direction preserved)
- upci = 5 = ic 5 (most abstract)

"None of these labels is better or more right than the others--it's just that some are more concrete and specific while others are more general and abstract. Which one we use will depend on what musical relationship we are trying to describe."

# Common Errors
- **Error**: Using only one interval type for all analyses
  **Correction**: Different analytical questions call for different interval types. Contour analysis requires opi; set-class analysis requires ic.

# Common Confusions
- **Confusion**: Thinking one interval type is universally "correct"
  **Clarification**: Each captures different information. The choice depends on the analytical question, not on correctness.
