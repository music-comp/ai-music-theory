# Quick Definition
A trichordal array is a four-row by four-column arrangement where each cell contains a trichord, with aggregates formed within each row (linearly), between row-pairs (hexachordally), and in each column (from four trichords).

# Core Definition
"An array is an arrangement of rows and columns. In Babbitt's trichordal arrays, there are four rows, each containing a linear ordering of the twelve pitch classes, and four columns, each containing four trichords (one from each of the rows) that together state the aggregate of all twelve pitch classes" (Straus, p. 350). "Aggregates are thus formed within each row of the array, between pairs of lines (hexachordal combinatoriality), and, in the columns of the array, with one trichord taken from each of the rows (trichordal combinatoriality)" (p. 350).

# Prerequisites
- **Aggregate** -- the basic harmonic unit formed in multiple dimensions
- **All-combinatorial hexachords** -- used in row and row-pair organization

# Key Properties
1. 4 rows x 4 columns; each cell contains one trichord
2. Each row contains all 12 pcs (aggregate)
3. Each column's four trichords combine to form an aggregate
4. Row-pairs combine hexachordally for additional aggregates
5. Each cell's trichord represents the same set class (within a block)
6. All four interval orderings of the trichord appear in each column and row

# Construction / Recognition
- Verify aggregates in all rows (12 pcs each)
- Verify aggregates in all columns (4 trichords = 12 pcs)
- Check hexachordal content within rows and between row-pairs
- Identify the generating trichord and its four orderings

# Context & Application
The trichordal array provides Babbitt's primary structural framework. "None of these arrangements of the aggregate should be taken as *the* series for the piece" (p. 351). The series lies behind the arrays, emerging only gradually. Multiple array blocks with changing parameters create compositional progression.

# Examples
**Example 1** (pp. 350--352, Ex. 6-47): Babbitt, String Quartet No. 2, mm. 7--12 -- (014) in each cell; E-hexachord (014589) in rows; A-hexachord (012345) between row-pairs. Four orderings: <+3,-4>, <-3,+4>, <-4,+3>, <+4,-3>.

**Example 2** (pp. 353--354, Ex. 6-50): Same piece, mm. 24--29 -- (015) in each cell; E-hexachord in rows; B-hexachord (023457) between row-pairs.

## Contrasts With
- **Rotational arrays** -- Stravinsky's 6x6 arrays with different construction and purpose

# Common Errors
- Confusing trichordal arrays with rotational arrays (different structures)
- Not recognizing three simultaneous layers of aggregate formation
- Assuming the array IS the series (the series lies behind the arrays)

# Common Confusions
- **Array vs. series**: The array is the structural framework; the generating series emerges gradually and is fully revealed only near the end of the piece
