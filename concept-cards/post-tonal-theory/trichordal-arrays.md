# Quick Definition
A trichordal array is a four-row by four-column arrangement where each cell contains a trichord, each row contains a complete aggregate, and each column also contains an aggregate formed by combining the four trichords.

# Formal Definition
Babbitt maintained a consistent interest in the *trichordal array*. An array is an arrangement of rows and columns. In Babbitt's trichordal arrays:
- There are **four rows**, each containing a linear ordering of the twelve pitch classes
- There are **four columns**, each containing four trichords (one from each row) that together state the aggregate
- Each series is divided into two hexachords, and pairs of hexachords combine to create a third layer of aggregates

Aggregates are thus formed in three dimensions: within each row, between pairs of lines (hexachordal combinatoriality), and in the columns (trichordal combinatoriality).

# Mathematical Formulation/Recognition
**Array structure:**
```
| Trich | Trich | Trich | Trich |  ← Row 1: aggregate
| Trich | Trich | Trich | Trich |  ← Row 2: aggregate
| Trich | Trich | Trich | Trich |  ← Row 3: aggregate
| Trich | Trich | Trich | Trich |  ← Row 4: aggregate
   ↓       ↓       ↓       ↓
  agg     agg     agg     agg    (each column = aggregate)
```

Additional aggregate layers:
- Rows 1+2 hexachords combine for aggregates
- Rows 3+4 hexachords combine for aggregates

# Musical Context/Application
- Provides multiple simultaneous aggregate structures
- Four instrumental parts can correspond to four rows
- Columns organize vertical (harmonic) content
- All trichords in the array often share the same set class
- Hexachords combine for additional aggregate formations
- Creates richly interlocking serial structures

# Examples
- Babbitt, String Quartet No. 2:
  - Four rows = four instruments (Vn1, Vn2, Va, Vc)
  - Array with (014) in each cell, ordered as four interval orderings
  - E-hexachord (014589) in each row
  - A-hexachord (012345) between row-pairs
  - Aggregates in all columns

# Common Confusions
- Confusing trichordal arrays with rotational arrays—different structures
- Not recognizing the three layers of aggregate formation
- Assuming the array is "the series"—it's derived from a generating series
- Overlooking the role of hexachordal combinatoriality alongside trichordal
