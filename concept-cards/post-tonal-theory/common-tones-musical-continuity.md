# Quick Definition
The compositional technique of using pitch classes held in common between transposed or inverted set forms to create smooth voice leading and musical continuity, often retaining common tones in the same register.

# Core Definition
Common tones under both T and I can be an important source of musical continuity. When composers retain common tones in the same register (as common pitches, not just common pitch classes), the voice leading becomes particularly smooth and the connection between successive set forms is aurally apparent. Conversely, avoiding transposition levels that produce common tones emphasizes contrast between set forms (Straus, pp. 121-123).

# Prerequisites
- **Common tones under transposition** -- one source of common tones
- **Common tones under inversion** -- the other source

# Key Properties
1. Common tones provide continuity between different set forms
2. Retaining common tones in the same register reinforces the connection
3. Absence of common tones emphasizes contrast
4. Composers deliberately choose transposition/inversion levels for their common-tone behavior
5. Common tones can be retained in the same instrument for additional continuity

# Construction / Recognition
Analytical approach:
1. Identify successive set forms (same set class)
2. Calculate expected common tones using interval-class vector (for T) or addition table (for I)
3. Check whether common pitch classes are retained as common pitches (same register)
4. Note the compositional treatment: same instrument? same register? simultaneous? sustained?

# Context & Application
The deliberate use of common tones for voice leading is a primary compositional technique in post-tonal music, connecting abstract set theory to concrete musical decision-making. It explains why composers choose specific transposition and inversion levels.

# Examples
**Example 1** (pp. 121-123, Ex. 3-12): Webern, Movements for String Quartet, op. 5, no. 3:
- Six pairs of sc(014) in the first ten measures
- Tn-related pairs: T8 and T11 produce one common tone each (because (014) has one ic4 and one ic1)
- Common tones are retained in the same register as common pitches
- In-related pairs: At I0, [8, 9, 0] retains C as a common tone -- Webern keeps it in the same register and instrument
- At I3, [0, 3, 4] retains both C and Eb, arranged to sound simultaneously
- Common tones under both T and I create smooth, continuous voice leading

# Common Errors
- Assuming common pitch classes are always presented as common pitches (register may change)
- Ignoring the compositional treatment of common tones (instrument, register, timing)
