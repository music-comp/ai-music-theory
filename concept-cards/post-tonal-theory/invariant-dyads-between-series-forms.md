# Quick Definition
When two inversionally related series forms sound note-against-note, the pitch-class dyads formed between them are invariant—if pitch class x sounds opposite y once, it will sound opposite y again, because the index number constrains all pairings.

# Formal Definition
When a series sounds note-against-note with an inversionally related form, the pitch-class dyads formed between the series are invariant. The sum of each element in the first series with the corresponding element in the inversionally related series must equal the index number. Since there are only so many ways to sum to a given number, the same dyads recur. If P_i and I_j are sounding together, and the index number is n (where i + j = n mod 12), then every vertical dyad will sum to n.

# Mathematical Formulation/Recognition
Given P_i paired with I_j where index = i + j (mod 12):
- Each vertical dyad (x from P, y from I) satisfies: x + y = index number
- For index = 6: possible dyads sum to 6 (0+6, 1+5, 2+4, 3+3, 5+1, etc.)
- Only 7 different pitch-class dyads are possible (including unisons when x = y)
- Each dyad occurs twice, except unisons which occur once
- Transposing both series while maintaining the index preserves the same dyads

Example (Webern, Piano Variations, op. 27):
- P_8 paired with I_10: index = 8 + 10 = 18 → 6 (mod 12)
- Dyads: (8,10), (9,9), (5,1), (7,11), (4,2), (6,0), (3,3)

# Musical Context/Application
- Creates a fixed repertoire of vertical sonorities throughout a passage
- Provides unity through recurring dyadic relationships
- The seven dyads give a passage a distinctive harmonic color
- Rhythmic variety comes from presenting dyads in different orders
- The shared axis of inversion can create a sense of pitch centricity

# Examples
- Webern, Piano Variations, op. 27, second movement: Only seven pitch-class dyads appear throughout
- P and I forms are always paired to keep index = 6
- When P_8 and I_10 are transposed to P_1 and I_5, the dyads remain the same (1+5=6)
- The dyads G#-Bb, A-A, F-C#, G-B, E-D, F#-C, Eb-Eb recur constantly
- A above middle C is always a unison and serves as an audible pitch center

# Common Confusions
- Expecting different index numbers to produce the same dyads—each index has its own dyad set
- Forgetting that transposing both series can maintain the same index
- Not recognizing that the dyads balance on a shared axis (e.g., A-Eb for index 6)
- Assuming all positions have different dyads—many recur
