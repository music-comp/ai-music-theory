# Quick Definition
When two inversionally related series forms sound note-against-note, the vertical pitch-class dyads are invariant -- only seven different dyads appear, each constrained by the index number, providing harmonic unity.

# Core Definition
"When a series sounds note-against-note with an inversionally related form... the pitch-class dyads formed between the series are invariant. If 8 sounds with 10 once, it will sound with 10 again" (Straus, p. 331). "The sum of each element in the first series with the corresponding element in the inversionally related series must be [the index number]. But there are not that many different ways of summing to [that number]" (p. 331).

There are only seven different pitch-class dyads; each occurs twice, except unisons which occur once. Transposing both series while maintaining the same index number preserves the same dyad set.

# Prerequisites
- **Invariants** -- this is a specific type of invariant relationship
- **Index number** -- the sum constraining all vertical dyads
- **Inversion** -- the series must be inversionally related

# Key Properties
1. Each vertical dyad (x, y) satisfies x + y = index number (mod 12)
2. Only 7 distinct pitch-class dyads are possible for any given index number
3. Each dyad occurs twice except unisons, which occur once
4. Transposing both series to maintain the same index preserves the dyad set
5. The dyads balance on a shared axis of symmetry

# Construction / Recognition
1. Pair P_i with I_j; calculate index number: i + j (mod 12)
2. Each vertical dyad must sum to the index number
3. List all dyad possibilities for that sum
4. Verify that the same dyads recur throughout

# Context & Application
This relationship creates a fixed repertoire of vertical sonorities throughout a passage. Rhythmic variety comes from presenting the dyads in different orders. The shared axis of inversion can create a sense of pitch centricity: "all the other notes are arranged pitch-symmetrically around it" (p. 334).

# Examples
**Example 1** (pp. 331--334, Exx. 6-25 through 6-27): Webern, Piano Variations, op. 27, second movement -- P8 paired with I10 (index = 6). The seven dyads: G#-Bb, A-A, F-C#, G-B, E-D, F#-C, Eb-Eb. These same dyads recur throughout the movement because all P/I pairings maintain index 6. When P8/I10 are transposed to P1/I5, the dyads remain the same (1+5=6). "A above middle C is particularly audible as a pitch center" since it always appears as a unison (p. 334).

# Common Errors
- Expecting different index numbers to produce the same dyads (each index has its own set)
- Forgetting that transposing both series in opposite directions can maintain the index

# Common Confusions
- **Fixed dyads vs. fixed order**: The dyads are fixed but can appear in varying order and rhythm
- **Index number as constraint**: The index number determines which seven dyads are possible, not the specific transposition levels
