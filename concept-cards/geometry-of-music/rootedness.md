# Quick Definition
Rootedness is the local form of centricity that applies to individual chords — the perception that one note in a chord is more fundamental or stable than the others, functioning as the chord's "root."

# Core Definition
Rootedness is one of two forms of centricity distinguished by Tymoczko (the other being tonicity). It applies at the level of individual chords, designating a particular note as the most fundamental. Elementary theory defines the root mechanically as the lowest note when a chord is arranged in stacked thirds ("snowman form"). But Tymoczko argues this is an oversimplification: context can override the mechanical rule. The same pitch classes {C, E, G, A} might function as an Am chord (root A) in one context or a C6 chord (root C) in another, as shown in Figure 5.6.1. A more sophisticated approach uses pitch-class profiles — bar graphs showing the relative prominence of each note — to represent the graded nature of rootedness. In twentieth-century music, rootedness often becomes a matter of degree rather than a binary property.

# Key Properties
1. Applies to individual chords (short time spans)
2. Can be overridden by musical context — not purely a function of intervallic structure
3. Represented by pitch-class profiles with higher values for more prominent notes
4. Continuous rather than binary in complex music — notes have degrees of prominence
5. In twentieth-century music, the line between rootedness and tonicity can blur

# Construction / Recognition
## To Construct/Create:
1. Establish a chord whose lowest third-stacked note functions as most prominent
2. Or use contextual emphasis (repetition, duration, register, dynamics) to establish prominence
## To Identify/Recognize:
1. Listen for which note feels most "fundamental" in a chord
2. Check whether mechanical "snowman" analysis matches perceptual impression
3. Use pitch-class profiles to represent the relative prominence of chord tones

# Context & Application
Rootedness is essential for traditional harmonic analysis but becomes more complex in extended tonal music. Figure 5.6.2 illustrates this: a chord whose members are attacked repeatedly can transform from one sonority to another (D-Eb-F# shifting to C-E-G) through changes in note prominence rather than changes in pitch content. This shows that rootedness is not just about which notes are present but about their relative emphasis. In impressionist or minimalist music, where chords can last for extended periods, rootedness can shade into tonicity, making the distinction between chord root and tonic note ambiguous.

# Examples
**Example 1** (p. 188, Figure 5.6.1): The pitch classes {C, E, G, B, A} sound like i-iv in E minor in one context but V-I in C major in another. The "root" depends on context, not just on stacking thirds.

**Example 2** (p. 188, Figure 5.6.2): A repeated 16-note pattern with the same pitch classes creates a perceptible transformation — D, Eb, F# recede while C, E, G emerge — showing rootedness as a continuous, time-varying property.

# Common Errors
- **Error**: Always determining the root by stacking thirds ("snowman form")
  **Correction**: Context can override the mechanical rule — the same pitch classes can have different roots depending on voicing, emphasis, and surrounding harmonies

# Common Confusions
- **Confusion**: Treating rootedness and tonicity as identical
  **Clarification**: Rootedness applies to individual chords; tonicity applies over longer stretches. They can conflict — in C major, the tonic C can be locally unstable when it serves as a neighbor to the third of a V7 chord
