# Quick Definition
Two voice leadings are individually T-related when they share the same abstract pattern (each voice moves the same number of semitones) but connect different specific chords — a relationship that creates audible family resemblance between superficially different progressions.

# Core Definition
Voice leadings within the same square of the twelve-schema grid (Figure 8.2.4) are individually T-related: each voice moves by the same directed interval, but the specific chords differ because one is transposed relative to the other. For example, if one voice leading moves (root up 1, third down 1, fifth to fifth, seventh down 1), a T-related voice leading moves each voice by exactly those same intervals but starting from a different seventh chord and landing on a different triad. Composers exploit this relationship extensively: Brahms Op. 76 No. 4 takes a voice leading from the first section and transposes the second chord up by semitone to create a contrasting middle section. Wagner's Tristan prelude features three resolutions of the same half-diminished chord, some T-related to each other. The AAB form at mm. 36ff of the Tristan prelude uses individually T-related voice leadings in a contrasting third iteration.

# Key Properties
1. Same abstract voice-leading pattern, different specific chords
2. Creates audible family resemblance between progressions
3. Voice leadings in the same schema square are T-related by definition
4. Composers use this to create variation while maintaining voice-leading unity
5. A powerful compositional technique for generating coherent chromaticism

# Construction / Recognition
## To Construct/Create:
1. Take an existing voice leading (e.g., Fø7 -> E7)
2. Transpose either the first or second chord by any interval
3. Adjust voices to maintain the same intervallic motion in each voice
4. The result is an individually T-related voice leading

## To Identify/Recognize:
1. Two progressions that sound similar despite involving different chords
2. Check if each voice moves by the same interval in both progressions
3. If so, the voice leadings are individually T-related

# Context & Application
Individual T-relatedness is a key mechanism of late Romantic harmonic coherence. Where functional harmony creates unity through shared tonal center and harmonic cycles, chromatic harmony can create unity through shared voice-leading patterns. This allows composers to move through distant tonal regions while maintaining a palpable structural thread.

# Examples
**Example 1** (Fig. 8.3.2, p. 296): Brahms Op. 76 No. 4 — the first ending's voice leading is individually T-related to the passage opening the middle section, with the second chord transposed up by semitone.

**Example 2** (Fig. 8.6.10, p. 318): Tristan prelude mm. 36ff — the third French sixth resolution is individually T-related to the first two, with one voice moving upward rather than three moving down.

# Common Errors
- **Error**: Assuming T-related voice leadings must sound identical
  **Correction**: They share the same abstract pattern but involve different specific chords, so they sound similar but not identical

# Common Confusions
- **Confusion**: Conflating individual T-relatedness with transposition of the entire passage
  **Clarification**: In individual T-relatedness, only one chord is transposed; the voice-leading pattern is preserved while the harmonic context changes
