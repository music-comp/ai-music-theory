# Quick Definition
A comparison between Tymoczko's pitch-class profiles and Lerdahl's "basic space," arguing that scale, macroharmony, and centricity should be treated as independent concepts rather than fused into a single hierarchical representation, enabling analysis of jazz, modal, and twentieth-century music.

# Core Definition
Tymoczko's pitch-class profiles look similar to Lerdahl's basic space but differ in two crucial ways. First, Lerdahl encodes scale structure (five melodic "alphabets": chromatic, diatonic, triad, fifth, tonic) alongside macroharmony and centricity, while Tymoczko represents only pitch stability without committing to specific scalar structure. This is important because some music (Chopin's pentatonic passages, jazz voicings) uses melodic alphabets not in Lerdahl's space. Second, Lerdahl fuses global stability (within a key) with local stability (when the tonic chord is sounding), which fails in jazz where a voicing like F-Bb-Eb for F7 does not make Bb globally more stable than A. By separating scale, macroharmony, and centricity, Tymoczko creates more flexible tools for analyzing diverse tonal styles.

# Key Properties
1. Scale, macroharmony, and centricity are in principle independent
2. Lerdahl's basic space fuses all three into one hierarchical representation
3. Tymoczko's profiles represent stability without committing to scale structure
4. Lerdahl's model fails for pentatonic melodies and jazz voicings
5. The separation allows analysis of twentieth-century and jazz styles
6. Lerdahl optimizes for classical listening; Tymoczko aims at broader composition

# Construction / Recognition
## To Identify/Recognize:
1. When analyzing a passage, ask separately: What is the scale? What is the macroharmony? What is the center?
2. Note cases where these diverge (jazz voicings, modal music, twentieth-century works)

# Context & Application
This distinction is crucial for extending tonal theory beyond classical music. Jazz musicians routinely play the lydian mode over tonic chords, demonstrating that local chord voicings need not restructure global key stability.

# Examples
**Example 1** (p. 443-444): Chopin's "black key" etude, Dvorak's "American" Quartet, and McCoy Tyner's solo all use pentatonic melodic alphabets not in Lerdahl's space.

**Example 2** (p. 445, Fig. E3): Chick Corea's solo on "Matrix" uses F-Bb-Eb for F7 tonic, but Bb is not globally more stable than A.
