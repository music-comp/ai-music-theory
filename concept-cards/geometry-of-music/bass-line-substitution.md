# Quick Definition
Bass-line substitution presents the same chord progression over different bass notes (through inversion), keeping harmonic content constant while varying the bass — the complement to third substitution, which keeps the bass constant while varying harmonic content.

# Core Definition
In bass-line substitution, the same chord progression appears over different bass notes through the use of inversions. A I-IV-V-I progression can appear with bass lines C-F-G-C or C-C-B-C (using inversions) while preserving the same Roman numeral analysis. Traditional Roman numeral analysis was developed precisely to capture the similarity between such progressions. Bass-line substitution and third substitution together define the two basic types of substitution in functional tonality: one preserves harmonic identity (Roman numeral) while varying the bass; the other preserves the bass while varying the harmonic content.

# Prerequisites
- Understanding of chord inversions and their figured-bass representation

# Key Properties
1. Same chord progression, different bass lines
2. Roman numeral analysis captures this equivalence by definition
3. Complements third substitution: bass-line substitution varies bass, third substitution varies harmony
4. Figured-bass notation was historically developed to privilege the bass perspective
5. Both types of substitution must be accounted for in a complete theory of functional harmony

# Construction / Recognition
## To Construct/Create:
1. Take a chord progression (e.g., I-IV-V-I)
2. Re-voice some or all chords in different inversions
3. The Roman numeral analysis remains the same; the bass line changes

## To Identify/Recognize:
1. Two passages with identical Roman numeral analysis but different bass lines
2. The harmonic content is preserved while melodic bass varies

# Context & Application
The distinction between bass-line and third substitution illuminates a fundamental tension in music theory between the figured-bass tradition (which privileges the bass) and the Roman numeral tradition (which privileges harmonic roots). Tymoczko's model accommodates both by using geometry: the thirds chain handles harmonic identity, while the spatial proximity of third-related chords handles bass-note equivalence.

# Common Errors
- **Error**: Thinking bass-line substitution changes the harmonic meaning
  **Correction**: The Roman numeral analysis is identical; only the voicing and bass differ

# Common Confusions
- **Confusion**: Conflating bass-line substitution with reharmonization
  **Clarification**: Bass-line substitution preserves the same chords in different inversions; reharmonization changes the actual chords
