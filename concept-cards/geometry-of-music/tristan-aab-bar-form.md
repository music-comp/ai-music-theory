# Quick Definition
The Tristan prelude uses AAB ("bar form") schemas at multiple structural levels: A sections present a voice-leading pattern transposed exactly (often by minor third), while the B section resolves the same chord type in a contrasting way that is individually T-related to the A sections.

# Core Definition
The prelude's opening uses AAB form: Fø7->E7 (A) is transposed up by minor third to produce Abø7->G7 (A), followed by the contrasting Dø7->B7 (B), which uses a different resolution type. The same schema returns at mm. 36ff with French sixths: the first resolves conventionally to C7, transposed by major second for the second A section, then the B section resolves to B7 (a fifth away from the expected E7) — this alternate resolution is individually T-related to the first two, with one voice moving upward rather than three moving down. At the end of the prelude, Wagner repeats the mm. 36 music but substitutes a half-diminished seventh for the French sixth, making explicit the connection between the two chord types. This recurring AAB structure provides formal coherence through the systematic exploration of voice-leading possibilities.

# Key Properties
1. Two A sections related by exact transposition
2. B section presents a contrasting resolution of the same initial chord type
3. The B section is individually T-related to the A sections
4. The schema appears at multiple structural levels
5. At mm. 36ff, the transposition interval changes from minor third to major second
6. The half-diminished/French sixth interchange at the reprise makes the relationship explicit

# Construction / Recognition
## To Construct/Create:
1. Choose a voice-leading pattern (chord A -> chord B)
2. Transpose exactly to create the second A section
3. For the B section, begin on the same chord type but resolve differently
4. Ensure the B resolution is individually T-related to the A resolution

## To Identify/Recognize:
1. Two similar passages related by exact transposition (A+A)
2. A third passage beginning similarly but resolving differently (B)
3. The B resolution should involve the same abstract voice-leading pattern

# Context & Application
The AAB schema demonstrates that Wagner is not simply improvising at the keyboard but working with a systematic formal plan based on voice-leading possibilities. The recurring structure at different levels and with different chord types suggests that voice-leading logic, rather than purely harmonic logic, drives the prelude's form.

# Examples
