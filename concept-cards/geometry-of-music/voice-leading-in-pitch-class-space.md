# Quick Definition
A voice leading in pitch-class space is an abstract schema specifying how voices move between pitch-class sets, independent of the specific octave — like a recipe that can be realized in many different registers.

# Core Definition
A voice leading in pitch-class space (or pitch-class voice leading) is an equivalence class of progressions generated by uniform applications of the O and P symmetries. It describes how voices move between pitch-class sets using paths on the pitch-class circle. The notation (G, G, B, D, F) -> (C, G, C, C, E) with numbers (5, 0, 1, -2, -1) above the arrow indicates the path each voice takes. Multiple pitch-space voice leadings can be instances of the same pitch-class voice leading — for example, voice leadings in different octaves that follow the same pattern. When all paths are shortest (within -6 to +6 semitones), the path numbers can be omitted.

# Key Properties
1. Uniform OP equivalence class on progressions
2. Specifies voice motion using paths in pitch-class space (direction + distance)
3. Multiple pitch-space voice leadings are "instances" of one pitch-class voice leading
4. Abstract schemas central to the enterprise of Western composition
5. Convention: omit path numbers when all voices move by shortest path
6. Paths can wrap around the circle one or more times

# Construction / Recognition
## To Construct/Create:
1. For each voice, specify a starting pitch class, a direction, and a distance
2. The collection of paths defines the pitch-class voice leading
## To Identify/Recognize:
1. Two pitch-space voice leadings are instances of the same pitch-class voice leading if they have the same pitch-class paths

# Context & Application
Pitch-class voice leadings are the central compositional schemas of Western polyphony. A composer who knows that "you can transform C major to F major by moving E up by one and G up by two" possesses a pitch-class voice leading — an abstract recipe that can be instantiated in any octave. Without this level of abstraction, each registral variant would need to be memorized separately, placing impossible burdens on compositional memory. The concept formalizes one crucial aspect of the composer's craft.

# Common Errors
- **Error**: Thinking pitch-class voice leadings specify register
  **Correction**: They are octave-free; a single schema can be realized in many different registers

# Common Confusions
- **Confusion**: Confusing a pitch-class voice leading with a chord progression
  **Clarification**: A pitch-class voice leading specifies the path each voice takes (including direction); a chord progression specifies only what chords occur
