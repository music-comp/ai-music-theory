# Quick Definition
A basic musical object is an ordered series of pitches, uncategorized and uninterpreted, serving as the raw material from which chords, chord types, and set classes are formed through successive applications of symmetry operations.

# Core Definition
A basic musical object is defined as an ordered series of pitches with no symmetry operations applied. The object (C4, E4, G4) is absolutely different from (E4, C4, G4) at this level of description — they become "the same" only when we apply the permutation symmetry. Basic musical objects can be ordered in time (as a melodic arpeggio) or by instrumental voice (as a simultaneous chord with assigned voices). They are "so particular as to be uninteresting" on their own; musical understanding requires grouping them into categories through symmetry operations.

# Prerequisites
- **pitch-space** — Basic musical objects are ordered series of pitches

# Key Properties
1. Ordered series of specific pitches (not pitch classes)
2. No symmetry operations applied — maximally specific
3. Can represent either melodic or harmonic material
4. Serve as the starting point for all musical classification
5. Become musically meaningful only through symmetry-based categorization

# Construction / Recognition
## To Construct/Create:
1. List specific pitches in a specific order: (C4, E4, G4)
2. Parentheses indicate ordered collection
## To Identify/Recognize:
1. An ordered collection of specific pitches with no equivalences applied
2. Changing order, octave, or any note creates a different basic musical object

# Context & Application
Basic musical objects are the foundation of Tymoczko's systematic approach to chord classification. By starting from maximally specific objects and progressively applying OPTIC symmetries, we can derive all standard music-theoretical categories (chords, chord types, set classes, etc.) as well as many non-standard ones. The framework reveals that musical classification is a process of discarding information through symmetry.

# Examples
**Example 1** (p. 54, Fig 2.4.1): The basic musical object (C4, E4, G4) can appear as an ascending arpeggio or as a simultaneous chord with voice 1 on C4, voice 2 on E4, voice 3 on G4.

# Common Errors
- **Error**: Treating basic musical objects as musically meaningful on their own
  **Correction**: They become meaningful only through categorization via symmetry operations

# Common Confusions
- **Confusion**: Thinking (C4, E4, G4) and (E4, C4, G4) are "obviously" the same
  **Clarification**: At the level of basic musical objects they are different; they become equivalent only when we apply the permutation symmetry
