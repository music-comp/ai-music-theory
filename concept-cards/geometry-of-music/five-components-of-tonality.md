# Quick Definition
Tonality, broadly defined, is characterized by five basic features: conjunct melodic motion, acoustic consonance, harmonic consistency, limited macroharmony, and centricity.

# Core Definition
Tymoczko proposes that tonality in the broad, expansive sense — encompassing not just common-practice music but also rock, jazz, medieval, Renaissance, and much non-Western music — can be understood as the conjunction of five independent but interacting features: (1) conjunct melodic motion (melodies move by small steps), (2) acoustic consonance (harmonies tend to sound pleasing), (3) harmonic consistency (chords in a passage tend to be structurally similar), (4) limited macroharmony (music uses a restricted set of pitch classes at any given time), and (5) centricity (one pitch class serves as a point of rest). Different tonal styles combine these features in different ways and to different degrees.

# Key Properties
1. The five components are individually identifiable properties, not a single monolithic thing
2. Different styles emphasize different subsets or degrees of these components
3. The components interact and constrain each other in nontrivial ways
4. "Tonality" exists on a spectrum depending on how many components are present and how strongly
5. The five features are broadly applicable across the "extended common practice"

# Construction / Recognition
## To Construct/Create:
1. Incorporate conjunct melodic motion in individual voices
2. Use acoustically consonant chords
3. Maintain harmonic consistency across chord progressions
4. Restrict pitch-class usage to a limited macroharmony
5. Establish centricity around one pitch class
## To Identify/Recognize:
1. Check for each of the five properties in a passage of music
2. Assess the degree to which each property is present
3. More components present and more strongly present = more "tonal"

# Context & Application
This framework provides a principled way to use "tonal" in the expansive sense while still making precise claims about what tonality involves. Rather than treating tonality as a binary (tonal vs. atonal), Tymoczko treats it as a multi-dimensional space where different styles occupy different regions. This allows meaningful comparison across vastly different repertoires and resolves the awkward question of what medieval music, common-practice tonality, jazz, and rock have in common.

# Examples
**Example 1** (p. 21-25): Common-practice music exhibits all five features strongly. Twentieth-century atonal music may exhibit conjunct melodic motion and harmonic consistency while lacking acoustic consonance, limited macroharmony, and centricity.

# Common Errors
- **Error**: Treating the five components as a definition of "tonality" in the narrow (common-practice) sense
  **Correction**: These five components define tonality in the broad, expansive sense; common-practice tonality adds additional constraints

# Common Confusions
- **Confusion**: Thinking all five components must be present for music to be "tonal"
  **Clarification**: Different styles exhibit different subsets; tonality is a matter of degree, not a binary classification
