# Quick Definition
Twentieth-century scalar music exploits the fact that chromatic harmonies can be embedded in a small number of familiar scales, treating these scales as ready-to-hand accompaniments for particular chords — a technique that originated in impressionism and was systematized in jazz.

# Core Definition
The first half of the nineteenth century expanded harmonic options (new chords, chromatic voice leadings) without proportionally expanding the scalar vocabulary, creating a dilemma: what melodic notes should accompany chromatic chords? Three nineteenth-century solutions existed: (1) use the basic diatonic scale despite clashes, (2) insert additional chromatic notes, (3) replace diatonic notes with altered forms. Twentieth-century composers found a fourth solution: since the sonorities of chromatic harmony can all be embedded in a small number of familiar scales (just seven scale types contain every "cluster-free" chord, per Chapter 4), these scales serve as ready accompaniments. For example, the acoustic scale accompanies altered dominant chords, and the octatonic scale accompanies diminished-related harmonies. Jazz musicians inherited and systematized these techniques, providing explicit "recipes" for which scales to play over which chords. The result layers three historical periods: a diatonic foundation (classical), chromatic embellishments (Romantic), and scale-chord associations (twentieth century).

# Key Properties
1. Solves the chord-scale problem: which melody notes accompany chromatic chords?
2. A small number of familiar scales contain every cluster-free chord type
3. Each chromatic chord can be embedded in specific scales (acoustic, octatonic, whole-tone, etc.)
4. Jazz systematizes the intuitive scalar exploration of impressionism
5. A single passage can layer three historical periods: diatonic, chromatic, scalar
6. Applies to both functional (ii-V-I) and non-functional (impressionist, minimalist) contexts

# Construction / Recognition
## To Construct/Create:
1. Begin with a chord progression (functional or non-functional)
2. For each chord, identify the scale type that contains its notes
3. Use that scale for melodic material over the chord
4. When chords change, scales may change correspondingly
## To Identify/Recognize:
1. Check whether melodic material conforms to a recognizable scale over each chord
2. Identify the scale type (acoustic, octatonic, whole-tone, diatonic mode, etc.)
3. Note whether scale changes correspond to chord changes

# Context & Application
Ravel's String Quartet (Figure 6.7.4) illustrates the layered historical logic: at the deepest level, a diatonic ii9-V9-I6 progression; at the middle level, chromatic embellishments (B-natural as applied leading tone, C# as chromatic alteration); at the surface, whole-tone and octatonic scales accompanying the altered chords. Bill Evans' "Turn Out the Stars" (Figure 6.7.5) uses the same technique, playing octatonic scales over dominant chords. Jazz theorists are "both systematic and explicit" in codifying these chord-scale relationships, standardizing what earlier composers discovered intuitively. This package of scalar procedures represents one of the most significant recent developments in the extended common practice.

# Common Errors
- **Error**: Treating jazz chord-scale theory as an independent invention
  **Correction**: Jazz systematizes techniques already present in Ravel, Debussy, and other early twentieth-century composers

# Common Confusions
- **Confusion**: Thinking twentieth-century scalar music applies only to functional progressions
  **Clarification**: Chapter 9 presents examples from non-functional contexts: impressionism (Debussy, Ravel), minimalism (Reich, Adams), and modal jazz (Miles Davis quintet)
