# Quick Definition
A compositional texture in which different chords within a single progression are each accompanied by different scales, creating a multi-scale environment within a functional harmonic framework.

# Core Definition
Polyscalar composition arises when the principle of chord-scale compatibility is applied rigorously to each chord in a progression. A simple ii-V-I, the archetype of functional harmony, becomes a fundamentally polyscalar construction when avoid notes are raised by semitone: ii7 uses C diatonic, V7 uses G acoustic, and Imaj7 uses G diatonic. This occurs throughout twentieth-century music, from Debussy's chord-first passages (where each chord generates its own scale) to jazz practice (where improvisers navigate different scales for each chord in a progression).

# Prerequisites
- Understanding of chord-scale compatibility
- Familiarity with chord-first composition

# Key Properties
1. Each chord in a progression has its own compatible scale
2. The simplest case: ii-V-I uses three different scales
3. Arises naturally from raising avoid notes by semitone
4. Creates scalar variety within a single harmonic framework
5. Central to both jazz improvisation and twentieth-century notated music

# Construction / Recognition
## To Construct/Create:
1. Begin with a chord progression
2. Assign a compatible scale to each chord
3. Raise avoid notes by semitone where desired, creating altered chords
4. Improvise or compose within the assigned scale for each chord
## To Identify/Recognize:
1. Look for passages where the complete scalar collection changes with each chord
2. Check whether different chords within the same key use different scales

# Context & Application
Polyscalar composition is perhaps the most fundamental practical application of chord-scale theory. It operates in jazz improvisation, impressionist harmony, and postminimalist composition.

# Examples
**Example 1** (p. 384, Fig. 10.4.1): A ii-V-I where raising avoid notes creates C diatonic over ii7, G acoustic over V7, and G diatonic over Imaj7.

**Example 2** (p. 327): Scriabin's Op. 48 No. 2 uses different diatonic scales for each chord in the progression.
