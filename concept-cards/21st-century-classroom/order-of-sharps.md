# Quick Definition
The order of sharps is the fixed sequence F-C-G-D-A-E-B, the invariable order in which sharps are added to key signatures.

# Core Definition
The order of sharps is F-C-G-D-A-E-B, often remembered by a mnemonic. One common mnemonic for the order of sharps is "Fast Cars Go Dangerously Around Every Bend." A mnemonic that works forward and backward is "Father Charles Goes Down And Ends Battle." The order of sharps must be memorized since key signatures are written regularly.

# Prerequisites
- **Key signature**: The context in which the order of sharps is used

# Key Properties
1. Sequence: F-C-G-D-A-E-B
2. Each new sharp key adds the next sharp in the sequence
3. The last sharp is always a half step below the tonic of the major key (^7)
4. This is the reverse of the order of flats
5. Follows the circle of fifths ascending

# Construction / Recognition
- F-C-G-D-A-E-B (always this order, never rearranged)
- To find the major key: go up a half step from the last sharp
- Each successive key adds one sharp

# Context & Application
The order of sharps follows the circle of fifths ascending. Each new key is a fifth higher than the previous one. Understanding this order is essential for writing and identifying key signatures correctly.

# Examples
- G major: F# (one sharp)
- D major: F#, C# (two sharps)
- A major: F#, C#, G# (three sharps)
- E major: F#, C#, G#, D# (four sharps)
- To find the major key: go up a half step from the last sharp (e.g., last sharp is C# -> D major)

# Common Errors
- Writing sharps in the wrong order
- Forgetting that the order is always the same regardless of clef

# Common Confusions
- **Fixed order**: Always F-C-G-D-A-E-B, never rearranged
- **Reverse relationship**: This is the exact reverse of the order of flats
- **Last sharp = ^7**: The last sharp is always the leading tone of the major key
