# Quick Definition
The order of sharps is the fixed sequence in which sharps appear in key signatures: F-C-G-D-A-E-B.

# Formal Definition
The order of sharps (F-C-G-D-A-E-B) is the invariable sequence in which sharps are added to key signatures. Each new sharp key adds one more sharp to this sequence. This order must be used when writing key signatures; sharps are never added in a different order.

# Construction/Recognition
- Sequence: F-C-G-D-A-E-B
- Mnemonic: "Fast Cars Go Dangerously Around Every Bend"
- Alternative mnemonic: "Father Charles Goes Down And Ends Battle"
- Each sharp key adds the next sharp in the sequence
- The last sharp is always a half step below the tonic of the major key

# Musical Context
The order of sharps follows the circle of fifths ascending. Each new key is a fifth higher than the previous one. Understanding this order is essential for writing and identifying key signatures.

# Examples
- G major: F# (one sharp)
- D major: F#, C# (two sharps)
- A major: F#, C#, G# (three sharps)
- E major: F#, C#, G#, D# (four sharps)
- To find the major key: go up a half step from the last sharp

# Common Confusions
- The order is always F-C-G-D-A-E-B, never rearranged
- This is the reverse of the order of flats
- The last sharp is always ^7 (leading tone) of the major scale
