# Quick Definition

Sonata rondo form replaces the second episode (C) with a development section, creating a hybrid structure: A-B-A-Development-A-B-A.

# Core Definition

Sonata rondo form is a rondo in which the second episode (the C section) is replaced by a development section, resulting in a design of A-B-A-Dev.-A-B-A. This combines the recurring refrain principle of rondo with the developmental procedures of sonata form (Hutchinson, Ch. 25, p. 380).

# Prerequisites

- **Rondo form** -- Sonata rondo is based on rondo structure
- **Sonata form** -- The development section draws from sonata form

# Key Properties

1. A-B-A-Development-A-B-A structure
2. Development replaces the C episode
3. B returns in tonic (sonata principle)
4. Combines rondo's accessibility with sonata's developmental depth

# Construction / Recognition

## Comparison:
- 7-part rondo: A B A **C** A B A
- Sonata rondo: A B A **Dev** A B A

# Context & Application

- **Typical contexts**: Common Classical finale form
- **Historical/stylistic notes**: Combines the light character of rondo with sonata-like developmental depth; many Beethoven and Mozart finales use this form

# Examples

**Example 1**: Many Beethoven and Mozart finales use sonata rondo form

# Relationships

## Builds Upon
- **Seven-part rondo** -- Sonata rondo modifies the 7-part design
- **Sonata form** -- The development section comes from sonata form

## Related
- **Sonata principle** -- B still returns in tonic
- **Classical multimovement forms** -- Sonata rondo is one option for fourth movements

## Contrasts With
- **Seven-part rondo** -- Seven-part has a C episode; sonata rondo has development

# Common Errors

- **Error**: Thinking the C section is simply omitted
  **Correction**: The C section is REPLACED by a development section; it is not simply absent

# Common Confusions

- **Confusion**: Difficulty distinguishing sonata rondo from 7-part rondo with a developmental C section
  **Clarification**: If the central section uses developmental procedures (fragmentation, sequencing, multiple modulations) rather than presenting new episodic material, it is a sonata rondo
