# Quick Definition
Fifth species (florid counterpoint) freely combines elements from first through fourth species, creating varied rhythmic textures against the cantus firmus.

# Formal Definition
Fifth species counterpoint, also called "florid counterpoint," represents the culmination of species study. It freely mixes whole notes, half notes, quarter notes, and tied notes (suspensions) against the cantus firmus. All rules from the previous species apply, but the composer has freedom to choose which rhythmic values and techniques to employ at any given moment. Fifth species most closely approaches free composition.

# Rules/Procedures
1. Combine rhythms from all previous species freely
2. Rules from each species apply to their respective note values:
   - Whole notes: First species rules (consonances only)
   - Half notes: Second species rules (passing tones on weak beat)
   - Quarter notes: Third species rules (passing tones not on beat 1, cambiata)
   - Tied notes: Fourth species rules (suspensions resolve down)
3. Create variety by mixing rhythmic values
4. Maintain melodic interest and flow
5. All consonance/dissonance rules remain in effect
6. Avoid monotony - vary the rhythmic texture

# Musical Context
Florid counterpoint appears throughout Renaissance polyphony. Orlande de Lassus's "Expectatio Justorum" demonstrates fifth species texture with varied rhythmic activity against sustained notes in other voices. This species prepares students for free contrapuntal composition.

# Examples
- Lassus, "Expectatio Justorum": Opening shows all species combined
- A measure might have: quarter-quarter-half tied to half (mixing 3rd and 4th species)

# Common Confusions
- Forgetting that all individual species rules still apply
- Creating monotonous textures by not varying rhythms
- Using dissonances incorrectly for a given note value
- Not understanding that fifth species is preparation for free composition
