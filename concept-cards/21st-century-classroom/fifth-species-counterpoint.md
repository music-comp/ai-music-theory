# Quick Definition
Fifth species (florid counterpoint) freely combines elements from first through fourth species, creating varied rhythmic textures against the cantus firmus.

# Core Definition
Fifth species counterpoint, also called "florid counterpoint," is a free mixture of first through fourth species. It represents the culmination of species study, combining whole notes, half notes, quarter notes, and tied notes (suspensions) against the cantus firmus. All rules from the previous species apply to their respective note values. Fifth species most closely approaches the style of actual Renaissance polyphony (Hutchinson, Ch. 30, p. 429).

# Prerequisites
- **First species** -- Whole-note consonance rules
- **Second species** -- Half-note passing tone rules
- **Third species** -- Quarter-note and cambiata rules
- **Fourth species** -- Suspension and syncopation rules

# Key Properties
1. Free mixture of all four preceding species
2. Rules from each species apply to their respective note values
3. Whole notes follow first species rules (consonances only)
4. Half notes follow second species rules (passing tones on weak beat)
5. Quarter notes follow third species rules (passing tones not on beat 1, cambiata)
6. Tied notes follow fourth species rules (suspensions resolve down by step)
7. Rhythmic variety is expected -- avoid monotony

# Construction / Recognition
**Combining species:**
1. Choose rhythmic values freely to create a varied, flowing line
2. Apply the correct species rules for each note value used
3. Maintain melodic interest by mixing note values
4. All consonance/dissonance rules remain in effect for their respective rhythms
5. Strive for a natural, musical line that resembles free composition

**To recognize fifth species:**
- Mixed note values against a whole-note cantus firmus
- Adherence to individual species rules within each rhythmic context

# Context & Application
Florid counterpoint appears throughout Renaissance polyphony and represents the practical goal of species study. Mastery of fifth species prepares students for free contrapuntal composition in any style. The ability to combine different rhythmic textures while maintaining correct consonance/dissonance treatment is a hallmark of skilled contrapuntal writing.

# Examples
- **Orlande de Lassus, *Expectatio Justorum*** (p. 429): Opening demonstrates all species observable, with varied rhythmic activity against sustained notes in other voices
- A measure might combine: quarter-quarter-half tied to half (mixing third and fourth species)

# Common Errors
- **Error**: Applying the wrong species rules to a given note value
  **Correction**: Each rhythmic value retains the rules of its species (e.g., quarter notes still follow third species rules)
- **Error**: Creating monotonous textures by using only one species
  **Correction**: Vary rhythmic values throughout to create musical interest

# Common Confusions
- **Confusion**: Thinking fifth species means "no rules"
  **Clarification**: All individual species rules still apply to their respective note values; only the choice of which rhythmic values to use is free
- **Confusion**: Believing fifth species is unrelated to free composition
  **Clarification**: Fifth species is the direct preparation for free contrapuntal writing
