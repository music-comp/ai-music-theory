# Quick Definition
To analyze a potential secondary diminished chord: stack in thirds to verify diminished quality (triad, half-diminished 7th, or fully diminished 7th), then check whether a minor second above its root is a diatonic scale degree -- if so, it is a secondary diminished chord.

# Core Definition
When encountering a chord with chromaticism and suspecting it is a secondary diminished chord, use this two-step process: (1) Stack the chord in thirds to determine root and quality -- if the quality is a diminished triad, half-diminished seventh, or fully diminished seventh, proceed to step 2; if not, it is not a secondary diminished chord. (2) Determine the note a minor second above the root -- if this note would be the root of a diatonic chord, the chord is a secondary diminished of that chord.

# Prerequisites
- **Secondary diminished chord**: Understanding the concept
- **Interval quality**: Ability to identify minor seconds and chord qualities

# Key Properties
1. Step 1: Verify chord quality (must be diminished type)
2. Step 2: Check if m2 above root is a diatonic chord root
3. Both conditions must be met
4. Parallels the secondary dominant process but with different quality and interval
5. Include the inversion in the final label

# Construction / Recognition
Worked example -- G#o7/B in D major:
1. Stack in thirds: G#-B-D-F# = half-diminished seventh, first inversion
2. Quality is half-diminished -- proceed
3. m2 above G# = A
4. A is scale degree 5 in D major (root of V chord)
5. Therefore: G#o7/B = viio6/5/V in D major

# Context & Application
This process is the mirror of the secondary dominant analysis but uses a minor second above (the leading-tone relationship) instead of a perfect fifth below. The two processes together cover all secondary chords. When encountering any chromatic chord, first check quality to determine whether to apply the secondary dominant test (major/Mm7) or the secondary diminished test (diminished types).

# Examples
- G#o7/B in D major: m2 above G# = A = scale degree 5; label: viio6/5/V

# Common Errors
- Using P5 below (that is for secondary dominants, not secondary diminished)
- Checking m2 below instead of m2 above

# Common Confusions
- **m2 ABOVE, not below**: The target root is a half step above the secondary diminished root
- **Quality determines which test**: Major/Mm7 = secondary dominant test; diminished types = secondary diminished test
- **Both tests can fail**: If neither quality nor interval condition is met, the chord is some other type of chromatic harmony
