# Quick Definition
To analyze a potential secondary diminished chord, verify the chord is diminished (triad or seventh), then check if a minor second above its root is a diatonic chord.

# Formal Definition
When encountering a chord with chromaticism, use this process: (1) Stack the chord in thirds to determine root and quality; (2) If diminished triad or half-diminished/fully-diminished seventh chord, continue; (3) Determine the note a minor 2nd above the root; (4) If that note is the root of a diatonic chord, the chromatic chord is a secondary diminished chord.

# Analysis/Application
Step-by-step example (G#ø7/B in D major):
1. Stack in thirds: G#-B-D-F# (half-diminished seventh, first inversion)
2. Quality is half-diminished, so continue
3. Minor 2nd above G# = A
4. A is ^5 in D major (root of V chord)
5. Label: viiø6/5/V

# Musical Context
This process parallels the analysis of secondary dominants but uses the minor second above (rather than perfect fifth below) to identify the target chord.

# Examples
G#ø7/B in D major:
- Stack: G#-B-D-F# (half-diminished)
- m2 above G# = A = ^5 in D major
- Analysis: viiø6/5/V

# Common Confusions
- The target is a MINOR SECOND ABOVE the root (unlike secondary dominants which are P5 below)
- Check the chord quality first - must be diminished type
- If the m2 above is not a diatonic scale degree, it's not a secondary diminished
