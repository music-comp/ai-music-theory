# Quick Definition
A half-diminished seventh chord consists of a diminished triad with a minor seventh above the root, combining diminished-triad tension with a less extreme seventh than the fully-diminished chord.

# Core Definition
The half-diminished seventh chord is built from a diminished triad plus a minor seventh interval from root to seventh (10 half steps). Its intervallic structure is m3 + m3 + M3. It is "half" diminished because only the triad is diminished; the seventh is a minor seventh, not a diminished seventh. It naturally occurs on viiO/7 in major keys and on iiO/7 in minor keys.

# Prerequisites
- **Seventh chord**: General concept of four-note chords
- **Diminished triad**: The triad type on which this chord is built

# Key Properties
1. Diminished triad + minor seventh from root to seventh (10 half steps)
2. Third-stacking pattern: m3 + m3 + M3
3. Occurs on viiO/7 in major; iiO/7 in minor
4. Symbol: O/7 (slashed circle with 7)
5. Lead-sheet symbols: Cm7(b5), CO/7, Cmin7(b5)
6. The "half" means the triad is diminished but the seventh is not

# Construction / Recognition
1. Build a diminished triad on the root
2. Add a note a major third above the fifth (or a minor seventh above the root)
3. Distinguish from fully-diminished by checking the seventh interval (minor, not diminished)
4. Distinguish from minor seventh by checking the fifth (diminished, not perfect)

# Context & Application
The half-diminished seventh chord serves a dominant function as viiO/7 in major and a pre-dominant function as iiO/7 in minor. In jazz, it is the standard ii chord in minor-key ii-V-i progressions. It has a darker, more tense quality than the minor seventh chord.

# Examples
- BO/7: B-D-F-A (viiO/7 in C major)
- DO/7: D-F-Ab-C (iiO/7 in C minor)

# Common Errors
- Confusing half-diminished with fully-diminished (the seventh interval differs)
- Writing a perfect fifth instead of diminished fifth
- Confusing the symbols: O/7 (slashed circle) vs. o7 (plain circle)

# Common Confusions
- **Half vs. fully diminished**: Half-diminished has a minor seventh; fully-diminished has a diminished seventh
- **O/7 vs. o7**: The slashed circle means half-diminished; the plain circle means fully-diminished
- **Also called m7(b5)**: "Minor seven flat five" is an equivalent lead-sheet designation
