# Quick Definition
The four row forms -- Prime (P), Retrograde (R), Inversion (I), Retrograde Inversion (RI) -- generate 48 possible versions of a twelve-tone row (4 forms x 12 transpositions).

# Core Definition
The prime (P) is the original row. The retrograde (R) is the prime backward. The inversion (I) is the original with all intervals inverted (opposite direction). The retrograde inversion (RI) is the inversion retrograded. Note: "retrograde inversion" means the inverted form backward, not the backward form inverted (Hutchinson, Ch. 34, p. 493).

# Prerequisites
- **Tone row** -- Row forms are transformations of the row

# Key Properties
1. P (Prime): original row
2. R (Retrograde): prime backward
3. I (Inversion): intervals reversed in direction
4. RI (Retrograde Inversion): inversion backward
5. P and I labeled by STARTING note; R and RI by ENDING note
6. 4 forms x 12 transpositions = 48 total row forms

# Construction / Recognition
**Labeling:**
- P_n and I_n: subscript = starting pitch class
- R_n and RI_n: subscript = ending pitch class
- This ensures P_n and R_n share the same subscript (same pitches, reversed)

# Common Errors
- **Error**: Labeling R and RI by their starting note
  **Correction**: R and RI use their ending note for the subscript

# Common Confusions
- **Confusion**: Thinking RI means "retrograde then invert"
  **Clarification**: RI is "inversion retrograded" (invert first, then reverse)
