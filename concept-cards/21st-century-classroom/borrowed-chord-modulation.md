# Quick Definition
In borrowed chord modulation, the pivot chord is a borrowed (mode mixture) chord in one of the keys -- enabling modulation between more distantly related keys by using the parallel minor's chords as a bridge.

# Core Definition
In modulation by borrowed common chord (or mode mixture), the pivot chord will be a borrowed chord in one of the keys involved in the modulation. The borrowed chord from the parallel minor creates additional common chords between keys that would otherwise have none or few diatonic common chords. This technique bridges the gap between keys that are distantly related in their major forms but closer through their minor modes.

# Prerequisites
- **Chromatic pivot chord modulation**: The broader category
- **Mode mixture**: The source of the borrowed pivot chord

# Key Properties
1. Pivot is a borrowed chord in one (or both) keys
2. The borrowed chord creates common ground between distant keys
3. Enharmonic respelling may be needed between keys
4. Expands the range of reachable modulation targets
5. The parallel minor provides additional chords for pivot duty

# Construction / Recognition
- Identify the pivot chord
- Determine if it is borrowed (from parallel minor) in one key
- Check if the same pitches function diatonically in the other key
- Example: i6 in Db major (borrowed from db minor, respelled as c# minor) = vi6 in E major

# Context & Application
This technique bridges keys that have no diatonic common chords. By borrowing from the parallel minor, a composer gains access to chords that may be diatonic in the target key. The technique is characteristic of Romantic-era modulation and demonstrates how mode mixture can serve structural as well as coloristic purposes.

# Examples
- Beethoven, Piano Sonata No. 31 in Ab major, Op. 110, I (1821):
  - From Db major to E major
  - i6 in Db major (borrowed from db minor, respelled as c# minor chord) = vi6 in E major
  - Bridges two foreign keys through the borrowed chord

- Not recognizing the enharmonic respelling between keys
- Overlooking borrowed chords as potential pivots

# Common Confusions
- **Borrowed in one key, diatonic in another**: The pivot is chromatic in one key but fits naturally in the other
- **Enharmonic respelling**: The borrowed chord may need respelling (e.g., Db minor = C# minor)
- **Not limited to close keys**: This technique specifically addresses distant modulation
