# Quick Definition
An elision is a technique for joining phrases where the final measure of one phrase simultaneously serves as the first measure of the next phrase, creating an overlap.

# Core Definition
An elision is a special device for joining phrases together in an overlapping manner. In an elision, the final bar of one phrase is simultaneously the first bar of the next phrase. The cadential arrival and new phrase beginning occur in the same measure. This shared measure counts for both phrases and often explains seven-measure phrases (8 minus 1 shared = 7 apparent measures).

# Prerequisites
- **Phrase**: Understanding of phrase structure
- **Cadence**: Recognizing cadential arrivals

# Key Properties
1. Final bar of one phrase = first bar of the next
2. The shared measure counts for both phrases
3. Creates seamless connection between phrases
4. Often explains apparent seven-measure phrases
5. Cadence and new material coincide

# Construction / Recognition
1. Look for a cadence point that simultaneously begins new melodic material
2. The cadential arrival and new phrase beginning occur in the same measure
3. When counting phrase lengths, the shared measure counts for both
4. If a phrase seems seven measures long, check for an elision

# Context & Application
Elisions create seamless connections between phrases, maintaining forward momentum. They are common in Classical music and make phrase boundaries less obvious to the listener. They help explain apparently irregular phrase lengths.

# Examples
- Mozart, Eine kleine Nachtmusik, K. 525, I -- clear elision between phrases
