# Quick Definition
An elision is a technique for joining phrases where the final measure of one phrase simultaneously serves as the first measure of the next phrase, creating overlap.

# Formal Definition
An elision is a special device for joining phrases together in an overlapping manner. In an elision, the final bar of one phrase is simultaneously the first bar of the next phrase. This creates phrases that share a common measure.

# Analysis/Application
To identify an elision:
1. Look for a cadence point that also begins new melodic material
2. The cadential arrival and new phrase beginning occur simultaneously
3. When counting phrase lengths, the shared measure counts for both phrases
4. Elisions often explain seven-measure phrases (8 - 1 shared = 7)

# Musical Context
Elisions create seamless connections between phrases, maintaining forward momentum. They are common in Classical music and can make phrase boundaries less obvious to the listener.

# Examples
- Mozart, Eine kleine Nachtmusik, K. 525, I - clear elision between phrases

# Common Confusions
- The elided measure counts for both phrases
- Elisions are different from phrase extensions (which add material)
- The cadence and new phrase beginning happen in the same measure
