# Quick Definition
Enharmonic modulation uses a pivot chord that must be respelled enharmonically to function properly in the new key, creating a harmonic "pun" with dual meanings.

# Formal Definition
In an enharmonic modulation, the pivot chord is almost always misspelled in one of the keys and therefore must be reconceptualized enharmonically by the analyst. Like a verbal pun, the pivot chord has two "meanings" depending on its context. The chord can only be spelled correctly in one of the keys. Two sonorities commonly used in enharmonic modulation are the dominant seventh chord and the fully diminished seventh chord.

# Construction/Recognition
The pivot chord has dual function:
- In one key: spelled and functions one way
- In other key: enharmonically respelled, functions differently

Key principle: The chord is spelled correctly in only ONE key; the analyst must envision the other spelling.

Two main types:
1. V7 / Ger+6 enharmonic relationship
2. Fully diminished seventh respellings

# Musical Context
- Like a verbal pun: "sun of York" = "son of York"
- Creates dramatic modulations to distant keys
- Common in Romantic-era music
- The enharmonic respelling shows different voice-leading implications

# Examples
Simple example from C major to B minor:
- G7 (V7 in C major) respelled as Ger+6 in B minor
- G7 normally resolves to C (down a fifth)
- As Ger+6, the root (G) wants to resolve down a half step to F# (i6/4)

# Common Confusions
- The chord sounds the same but is spelled differently in each key
- You must VISUALIZE the respelling (it's not written on the page)
- This is not just a theoretical construct - it reflects different voice-leading
- Understanding both spellings is essential for proper analysis
