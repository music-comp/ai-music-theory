# Quick Definition
A fully-diminished seventh chord consists of a diminished triad with a diminished seventh above the root -- all three stacked thirds are minor, producing maximum tension and a symmetrical division of the octave.

# Core Definition
The fully-diminished seventh chord (often simply called "diminished seventh chord") is built from a diminished triad plus a diminished seventh interval from root to seventh (9 half steps). Its intervallic structure is m3 + m3 + m3 -- three minor thirds stacked equally. This symmetrical structure means the chord divides the octave into four equal parts. It naturally occurs on viio7 in harmonic minor.

# Prerequisites
- **Seventh chord**: General concept of four-note chords

# Key Properties
1. Diminished triad + diminished seventh from root to seventh (9 half steps)
2. Third-stacking pattern: m3 + m3 + m3 (all minor thirds)
3. Symmetrical: divides the octave into four equal parts
4. Only three distinct diminished seventh chords exist (due to symmetry)
5. Occurs naturally on viio7 in harmonic minor
6. Symbol: o7 (plain circle with 7)
7. Lead-sheet symbols: Co7, Cdim7

# Construction / Recognition
1. Build a diminished triad on the root
2. Add a note a minor third above the fifth (or a diminished seventh above the root)
3. All intervals between adjacent notes are minor thirds
4. The diminished seventh interval is enharmonically equivalent to a major sixth
5. Any inversion sounds like a root-position diminished seventh on a different root

# Context & Application
The fully-diminished seventh chord creates intense dissonance and urgency. Its symmetrical structure makes it useful for enharmonic modulation since any note can be respelled as the root, allowing resolution to four different keys. It is a staple of dramatic passages in Classical and Romantic music. It commonly functions as viio7 resolving to i in minor keys.

# Examples
- Bo7: B-D-F-Ab (viio7 in C minor)
- The same pitches can be respelled as Do7, Fo7, or Abo7
- Only three unique fully-diminished seventh chords exist: {B,D,F,Ab}, {C,Eb,Gb,A}, {Db,E,G,Bb}

# Common Errors
- Confusing o7 (fully-diminished) with O/7 (half-diminished)
- Spelling the diminished seventh enharmonically as a major sixth (e.g., writing A instead of Bbb above C)

# Common Confusions
- **Symmetry means enharmonic equivalence**: All four inversions contain the same pitch classes, so any note can function as root
- **Double-flat spelling**: The diminished seventh (e.g., Bbb above C) looks strange but is the correct spelling
- **"Fully" or just "diminished seventh"**: Both terms refer to this chord, as distinguished from "half-diminished"
