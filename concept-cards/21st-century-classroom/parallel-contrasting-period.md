# Quick Definition
Periods are labeled "parallel" when both phrases begin with similar melodic material (a a'), or "contrasting" when the phrases begin with different melodic material (a b).

# Core Definition
In a parallel period, the melodies in both phrases begin similarly. In a contrasting period, the phrases begin differently. The prime mark (') means "similar to a previous phrase but ends with a different cadence." Therefore a' is "a prime." If a further alteration occurs, use a" ("a double prime"). For analyses requiring more, use numbered superscripts (a1, a2, a3).

# Prerequisites
- **Period**: Understanding of antecedent-consequent structure

# Key Properties
1. Parallel: both phrases begin similarly (a a')
2. Contrasting: phrases begin differently (a b)
3. Prime (') indicates similar melody with different cadence
4. Parallel periods are more common
5. The distinction is based on melodic beginnings, not endings

# Construction / Recognition
1. Compare the opening melodic material of both phrases
2. If similar, label as parallel period (a a')
3. If different, label as contrasting period (a b)
4. Use primes for altered repetitions, not for transpositions

# Context & Application
Parallel periods are more common than contrasting periods in Classical music. The parallel construction reinforces melodic unity while different cadences provide harmonic variety. Both types appear throughout the common-practice era.

# Examples
- Mozart, K. 331, I -- parallel period (a a')
- Haydn, Hob. XVI:9, III -- parallel period
- Beethoven, "Fur Elise" -- parallel period
- Beethoven, Pathetique Sonata, Op. 13, II -- contrasting period (a b)

# Common Errors
- Using primes for simple transposition (do not use prime for sequences)
- Basing the distinction on endings rather than beginnings

# Common Confusions
- **Prime means different cadence, not different melody**: a' begins like a but ends differently
- **Distinction is about beginnings**: Similar openings = parallel; different openings = contrasting
- **In this chapter, prime = different cadence**: Not embellishment, register change, or reharmonization
