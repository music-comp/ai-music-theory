# Quick Definition
A countersubject is counterpoint that consistently accompanies each statement of the fugue subject; if the accompanying counterpoint varies, there is no countersubject.

# Core Definition
A countersubject is counterpoint that consistently accompanies each occurrence of the subject. If the same melodic material appears each time the subject is stated, it is identified as a countersubject. A fugue may have multiple countersubjects (Countersubject 1, Countersubject 2, etc.). The alternative to a countersubject is for the composer to write different accompanying counterpoint (labeled "CTRPT") each time the subject appears. Countersubjects, like subjects, can be fragmented in episodes (Hutchinson, Ch. 30, p. 435).

# Prerequisites
- **Fugue subject** -- The countersubject accompanies the subject
- **Fugue exposition** -- Countersubjects appear in expositions alongside subject entries

# Key Properties
1. Consistent melodic material accompanying each subject statement
2. Appears after a voice has stated the subject (that voice continues with the countersubject)
3. Multiple countersubjects numbered CS1, CS2, etc.
4. Must work both above and below the subject (invertible counterpoint)
5. If accompanying material is different each time, it is labeled "counterpoint" (CTRPT), not countersubject
6. Can be fragmented in episodes alongside subject fragments

# Construction / Recognition
**Identifying a countersubject:**
1. After the first voice states the subject, observe what it plays during the answer
2. Compare this material to what accompanies later subject entries
3. If substantially the same material recurs: countersubject
4. If different material each time: no countersubject (label as CTRPT)

# Context & Application
The countersubject provides continuity and helps unify the fugue. It demonstrates the composer's skill at invertible counterpoint, since it must work both above and below the subject. Bach's fugues often feature memorable countersubjects with distinctive rhythmic profiles that complement the subject.

# Examples
- **Bach, Fugue 2 in C minor** (p. 435): Countersubject 1 in alto (m. 3) when soprano has the answer, then in soprano (m. 7) when alto has the subject; Countersubject 2 also identified
- Fragments of both countersubjects appear in episodes alongside subject fragments

# Relationships
## Related
- **Fugue episode** -- Episodes use fragmented countersubject material
- **Motivic fragmentation** -- Countersubjects can be divided into head and tail motives

# Common Errors
- **Error**: Calling any accompanying counterpoint a countersubject
  **Correction**: Only label it as countersubject if the material is consistent across subject entries

# Common Confusions
- **Confusion**: Confusing the countersubject with the answer
  **Clarification**: The answer IS the subject transposed; the countersubject is different material that accompanies the subject/answer
- **Confusion**: Not recognizing the countersubject when transposed
  **Clarification**: Countersubjects appear at different pitch levels as they move between voices
