# Quick Definition
A countersubject is counterpoint that consistently accompanies each statement of the fugue subject; if the accompanying counterpoint changes each time, there is no countersubject.

# Formal Definition
A countersubject is a consistent contrapuntal line that accompanies the fugue subject whenever it appears. After a voice has stated the subject, it typically continues with the countersubject while another voice states the answer. If this accompanying material is substantially the same at each subject entry, it is identified as a countersubject. A fugue may have multiple countersubjects (Countersubject 1, Countersubject 2, etc.). If different counterpoint accompanies each subject statement, there is no countersubject - the accompanying material is simply labeled "counterpoint" (CTRPT).

# Rules/Procedures
1. Look for recurring melodic material accompanying subject entries
2. If material is consistent, it's a countersubject; if different each time, it's "counterpoint"
3. Countersubjects typically:
   - Have distinctive character complementing the subject
   - Work contrapuntally both above and below the subject (invertible counterpoint)
   - Maintain consistent identity despite transposition
4. Multiple countersubjects are numbered: CS1, CS2, etc.
5. Countersubjects may be fragmented in episodes (like subjects)

# Musical Context
The countersubject provides continuity and helps unify the fugue. It demonstrates the composer's skill at invertible counterpoint since it must work both above and below the subject. Bach's fugues often feature memorable countersubjects with distinctive rhythmic profiles.

# Examples
- Bach, Fugue 2 in C minor: Countersubject 1 appears in alto (m.3) when soprano has the answer, then in soprano (m.7) when alto has the subject
- A fugue without countersubject: Each time the subject appears, different counterpoint accompanies it

# Common Confusions
- Calling any accompanying counterpoint a "countersubject" (it must be consistent)
- Not recognizing countersubject when it's transposed to different pitch level
- Missing countersubject entries in inner voices
- Confusing countersubject with the answer
