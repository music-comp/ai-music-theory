# Quick Definition

The viio7 and viiø7 chords consist entirely of tendency tones (^7, ^2, ^4, ^6); when the 7th is voiced above the 3rd, resolve the 3rd (^2) UP by step to avoid parallel fifths, while resolving all other tendency tones normally.

# Core Definition

When the 7th of a viio7 or viiø7 chord (^6) is voiced above the 3rd of the chord (^2), resolve the 3rd UP by step while resolving all other tendency tones normally (^4 to ^3, ^6 to ^5, ^7 to ^8). If the 7th is below the 3rd, resolve all tendency tones normally. An alternative solution is to revoice the chord (Hutchinson, Ch. 27, pp. 407-408, Principle 27.4.1).

# Prerequisites

- **Seventh chord resolution** -- The general 7th-resolves-down rule applies
- **Rules of melody** -- All four notes are tendency tones requiring careful resolution

# Key Properties

1. All four chord members are tendency tones: ^7, ^2, ^4, ^6
2. If 7th (^6) is ABOVE 3rd (^2): resolve ^2 UP to ^3 (exception to normal tendency)
3. If 7th is BELOW 3rd: resolve all tendency tones normally (^2 down, ^4 down, ^6 down, ^7 up)
4. The exception prevents parallel 5ths
5. Revoicing the chord is an alternative solution
6. Parallel 4ths are acceptable as an alternate fix

# Construction / Recognition

## Procedure:
1. Identify the viio7 or viiø7 chord
2. Check: is the 7th (^6) above or below the 3rd (^2)?
3. If 7th ABOVE 3rd: resolve ^2 UP to ^3; all others resolve normally
4. If 7th BELOW 3rd: resolve all tendency tones normally
5. Alternative: revoice to put 7th below 3rd, then resolve normally

# Context & Application

- **Typical contexts**: viio7 and viiø7 chords resolving to I; also secondary viio7 chords

# Common Errors

- **Error**: Resolving all tendency tones normally without checking voicing
  **Correction**: Always check whether the 7th is above or below the 3rd first

- **Error**: Resolving ^2 up in all viio7 chords
  **Correction**: Only resolve ^2 up when the 7th is ABOVE the 3rd

# Common Confusions

- **Confusion**: This rule applies to all seventh chords
  **Clarification**: It applies only to viio7 and viiø7 (and their secondary equivalents) because all members are tendency tones
