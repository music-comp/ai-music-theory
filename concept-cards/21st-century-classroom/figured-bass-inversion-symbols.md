# Quick Definition
Abbreviated figured bass numbers placed after Roman numerals to indicate chord inversions: triads use 5/3 (root), 6 (first), 6/4 (second); seventh chords use 7 (root), 6/5 (first), 4/3 (second), 4/2 (third).

# Core Definition
Figured bass inversion symbols are the most commonly used figured bass abbreviations for triads and seventh chords. For triads: root position is 5/3 (often omitted), first inversion is 6 (abbreviated from 6/3), and second inversion is 6/4. For seventh chords: root position is 7, first inversion is 6/5, second inversion is 4/3, and third inversion is 4/2. Because the figures 6/5, 4/3, and 4/2 are used only for seventh chords, the "7" is omitted when labeling inverted seventh chords. Quality symbols like "M" (major seventh), the diminished sign, and the half-diminished sign are placed before the figured bass numbers and after the Roman numeral.

# Prerequisites
- **Figured bass**: The underlying notational system
- **Triad inversions**: Root position, first inversion, second inversion
- **Seventh chord inversions**: Four possible positions

# Key Properties
1. Triad symbols: (5/3), 6, 6/4
2. Seventh chord symbols: 7, 6/5, 4/3, 4/2
3. The "7" is omitted for inverted seventh chords (6/5, 4/3, 4/2 are unambiguous)
4. Quality symbols (M, diminished, half-diminished) precede the figures
5. These are abbreviations of the full figured bass showing every interval above the bass
6. In modern usage, placed after Roman numerals (not below a bass line)

# Construction / Recognition
- Identify the bass note and determine which chord member it is
- Root in bass: 5/3 (triads) or 7 (seventh chords)
- Third in bass: 6 (triads) or 6/5 (seventh chords)
- Fifth in bass: 6/4 (triads) or 4/3 (seventh chords)
- Seventh in bass: 4/2 (seventh chords only)
- Add quality symbols before figures: e.g., viio6/5, IM4/3

# Context & Application
Unlike original Baroque figured bass notation, modern music theory places these symbols after Roman numerals. This system replaces the modified slash notation used in some textbooks (e.g., "I/5th" becomes I6/4). The combination of Roman numeral and figured bass symbol communicates root, quality, function, and inversion in a compact format used throughout classical music theory courses.

# Examples
- V6/5 = dominant seventh chord in first inversion
- viio6 = diminished triad in first inversion
- IV6/4 = subdominant triad in second inversion
- Comparison with slash notation: V/3rd = V6, V7/5th = V4/3, V7/7th = V4/2

# Common Errors
- Including "7" when labeling inverted seventh chords (write V6/5, not V7-6/5)
- Forgetting quality symbols for seventh chords (write viio7, not vii7)

# Common Confusions
- **Why omit the 7?**: Because 6/5, 4/3, and 4/2 only occur with seventh chords, so the 7 is redundant
- **Quality placement**: Quality symbols go between the Roman numeral and the figured bass numbers
- **Slash notation vs. figured bass**: "I/5th" (old notation) = I6/4 (figured bass notation)
