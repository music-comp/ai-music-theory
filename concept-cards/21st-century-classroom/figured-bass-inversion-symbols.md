# Quick Definition
Figured bass inversion symbols are abbreviated numbers that indicate chord inversions: for triads (no figure, 6, 6/4) and for seventh chords (7, 6/5, 4/3, 4/2).

# Formal Definition
Figured bass inversion symbols for triads: Root position has no figure (or 5/3); first inversion uses 6 (abbreviation of 6/3); second inversion uses 6/4. For seventh chords: Root position uses 7 (abbreviation of 7/5/3); first inversion uses 6/5; second inversion uses 4/3; third inversion uses 4/2.

# Analysis/Application
Triad inversions:
- Root position: I (no figure, or 5/3)
- First inversion: I6 (6 = 6/3)
- Second inversion: I6/4

Seventh chord inversions:
- Root position: V7 (7 = 7/5/3)
- First inversion: V6/5
- Second inversion: V4/3
- Third inversion: V4/2

# Musical Context
Figured bass symbols are used in Roman numeral analysis throughout music theory. They provide a standardized way to indicate inversions that dates back to the Baroque era.

# Examples
Comparison with slash notation:
- V/3rd = V6 (first inversion)
- V7/3rd = V6/5 (first inversion seventh)
- V7/5th = V4/3 (second inversion seventh)
- V7/7th = V4/2 (third inversion seventh)

# Common Confusions
- The "7" is omitted when seventh chords are inverted (use 6/5, 4/3, 4/2, not 7/6/5 etc.)
- Include quality symbols (M, diminished, half-diminished) before the figured bass numbers
- The numbers represent intervals from the bass note, not chord construction
