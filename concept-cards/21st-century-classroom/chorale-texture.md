# Quick Definition
Chorale texture (also called homorhythmic texture) occurs when all voices move in the same rhythm, with a chord for every (or nearly every) melody note.

# Core Definition
Chorale textures are those in which there is a chord for every (or nearly every) melody note. All parts move in the same rhythm, creating "homorhythmic" texture. The melody may occasionally move in a slightly different rhythm from the chords below, but the overall effect is of unified rhythmic motion.

# Prerequisites
- **Texture**: Understanding of vertical and horizontal dimensions

# Key Properties
1. A chord for every (or nearly every) melody note
2. All parts move in the same rhythm (homorhythmic)
3. Melody may have slight rhythmic independence
4. Creates a powerful, unified sound
5. Common in hymns, anthems, and dramatic moments

# Construction / Recognition
1. Check if all voices move together rhythmically
2. Look for chord changes that align with melody notes
3. Note any slight rhythmic independence of the melody
4. The overall effect should be of unified motion

# Context & Application
Chorale texture derives from the Lutheran chorale tradition and Bach's harmonizations. It creates a powerful, unified sound common in hymns, national anthems, and climactic moments in other genres including contemporary pop.

# Examples
- "The Star-Spangled Banner" -- familiar chorale texture
- Schubert, Winterreise, "Die Nebensonnen" (1828) -- chorale-style with slightly independent melody
- "Some Nights" (Fun., 2011) -- chorale texture in popular music

# Common Errors
- Assuming melody must be exactly rhythmically aligned (slight independence is allowed)

# Common Confusions
- **Slight melodic independence is okay**: The overall effect is still homorhythmic
- **Different from block chord accompaniment**: In chorale texture, ALL voices move together; in block chord accompaniment, the melody is clearly independent
- **Homorhythmic = all parts in same rhythm**
