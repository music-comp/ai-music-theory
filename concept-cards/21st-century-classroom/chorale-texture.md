# Quick Definition
Chorale texture (also called homorhythmic texture) occurs when all voices move in the same rhythm, with a chord for every (or nearly every) melody note.

# Formal Definition
Chorale textures are those in which there is a chord for every (or nearly every) melody note. All of the parts move in the same rhythm, creating what is also called "homorhythmic" texture. The melody may occasionally move in a slightly different rhythm from the accompanying chords.

# Analysis/Application
To identify chorale texture:
1. Check if all voices move together rhythmically
2. Look for chord changes that align with melody notes
3. Note any slight rhythmic independence of the melody
4. Often occurs in hymns, national anthems, and dramatic moments

# Musical Context
Chorale texture derives from the Lutheran chorale tradition and Bach's harmonizations. It creates a powerful, unified sound and is common in hymns, anthems, and climactic moments in other genres.

# Examples
- "The Star-Spangled Banner" (Francis Scott Key/John Stafford Smith) - familiar example of chorale texture
- Schubert, Winterreise, "Die Nebensonnen" (1828) - chorale-style accompaniment with slightly independent melody
- "Some Nights" (Fun., 2011) - chorale texture in popular music

# Common Confusions
- Melody may have slight rhythmic independence and still be chorale texture
- Different from block chord accompaniment where melody is clearly independent
- Homorhythmic means all parts in same rhythm
