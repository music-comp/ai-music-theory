# Quick Definition

Five-part rondo has the structure ABACA or ABABA, with the refrain (A) appearing three times alternating with two contrasting episodes.

# Core Definition

The 5-part rondo has ABACA form (two different episodes) or ABABA form (same episode returns). The refrain (A) is always in tonic, while episodes provide contrast through different keys and thematic material (Hutchinson, Ch. 25, p. 375).

# Prerequisites

- **Rondo form** -- Five-part rondo is a specific type of rondo

# Key Properties

1. ABACA: two different episodes (more common)
2. ABABA: same episode returns (less common)
3. Refrain always in tonic
4. Transitions and retransitions connect sections
5. Simpler than 7-part rondo

# Construction / Recognition

## ABACA:
- A: Refrain (tonic)
- B: First episode (contrasting key)
- A: Refrain (tonic)
- C: Second episode (different contrasting key)
- A: Final refrain (tonic)

# Context & Application

- **Typical contexts**: Often used in slow movements of Classical works
- **Historical/stylistic notes**: Simpler rondo structure suitable for lighter or slower movements

# Examples

**Example 1**: Mozart, *Eine kleine Nachtmusik*, K. 525, II -- five-part rondo (discussed in the chapter on Creating Contrast Between Sections)

# Relationships

## Builds Upon

## Contrasts With
- **Seven-part rondo** -- Seven-part adds additional refrain and B return in tonic

# Common Errors

- **Error**: Confusing ABACA with ABABA
  **Correction**: ABACA has two different episodes; ABABA has the same episode returning

# Common Confusions

- **Confusion**: Thinking all episodes must be in different keys
  **Clarification**: In ABABA, the same episode returns (possibly in a different key the second time)
