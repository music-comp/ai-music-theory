# Quick Definition
Non-chord tones are notes that do not belong to the current chord, classified by how they are approached and left (by same tone, step, or leap). There are nine types.

# Core Definition
Non-chord tones (also called "embellishing tones" and "non-harmonic tones") are notes that are not members of the prevailing harmony. There are nine types, each defined by its approach and departure: passing tone (step/step same dir.), neighbor tone (step/step opposite dir.), appoggiatura (leap/step), escape tone (step/leap opposite dir.), double neighbor (see text), anticipation (step/same note), pedal point (same note/same note), suspension (same note/step down), and retardation (same note/step up).

# Prerequisites
- **Roman numeral analysis**: Identifying the prevailing chord
- **Triad**: Knowing which notes belong to the chord

# Key Properties
1. Nine types classified by approach and departure
2. Qualifiers: accented/unaccented, chromatic/diatonic, metrical/sub-metrical/super-metrical
3. Accented = on the beat; unaccented = off the beat
4. Chromatic = not in the key; diatonic = in the key
5. Metrical = equal to beat duration; sub-metrical = shorter; super-metrical = longer
6. Always identify the chord first, then determine which notes are non-chord tones

# Construction / Recognition
1. Determine the chord being played (Roman numeral analysis)
2. Identify notes not belonging to that chord
3. Examine how the NCT is approached (step, leap, or same note)
4. Examine how the NCT is left (step, leap, or same note)
5. Match the approach/departure pattern to the nine types
6. Apply qualifiers (accented, chromatic, etc.)

# Context & Application
Non-chord tones add melodic interest, create tension and release, and embellish the underlying harmony. They appear in all styles of Western music. Understanding NCTs is essential for both analysis and composition.

# Common Errors
- Analyzing NCTs without first identifying the chord
- Confusing chromatic NCTs with chromatic chord tones (secondary dominants)

# Common Confusions
- **Always identify the chord first**: You cannot determine NCTs without knowing the harmony
- **Multiple valid interpretations**: Some notes may be analyzed as different NCT types depending on context
- **Chromatic NCTs vs. chromatic chords**: A chromatic note might be an NCT or part of a secondary dominant
