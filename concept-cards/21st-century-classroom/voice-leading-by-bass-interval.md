# Quick Definition

When voice leading root position triads, the procedure depends on the bass interval: 3rd/6th (hold two common tones), 4th/5th (hold one common tone or move all voices same direction), 2nd (contrary motion), repeated note (repeat or arpeggiate).

# Core Definition

Voice leading root position triads systematically follows the melodic interval between consecutive bass notes (Hutchinson, Ch. 26, pp. 392-394):
- **3rd or 6th**: Retain two common tones, move one voice by step
- **4th or 5th**: Either retain one common tone and move two by step, OR move all upper voices in the same direction
- **2nd**: Move all upper voices in contrary motion to bass (exception: deceptive progression)
- **Repeated note**: Repeat or arpeggiate upper voices

- **Voice leading** -- This is the core procedural technique for voice leading

# Key Properties

1. Bass by 3rd/6th: hold 2 common tones, move 1 by step
2. Bass by 4th/5th: Option A (hold 1 common tone, move 2 by step) or Option B (all upper voices same direction)
3. Bass by 2nd: contrary motion in upper voices (exception: deceptive progression)
4. Bass repeats: hold or arpeggiate, maintain doubled root + one 3rd + one 5th
5. Root is always doubled in root position chords

# Construction / Recognition

## Step-by-Step:
1. Identify the bass interval
2. Apply the appropriate rule
3. Check for objectionable parallels, spacing errors, and melodic errors
4. If bass moves by 2nd in V-vi/VI: apply deceptive progression rules instead

# Context & Application

- **Typical contexts**: All root position voice leading in SATB
- **Historical/stylistic notes**: These procedures ensure smooth voice leading with minimal motion; common tone approach maximizes chord connection

# Common Errors

- **Error**: Moving voices unnecessarily when common tones are available
  **Correction**: Always check for common tones first

- **Error**: Applying the 2nd rule to the deceptive progression
  **Correction**: V-vi/VI has special rules (see deceptive progression card)

# Common Confusions

- **Confusion**: Thinking bass movement by 4th/5th has only one solution
  **Clarification**: There are TWO valid options (common tone or all voices same direction)
