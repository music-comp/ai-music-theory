# Quick Definition
Note values are symbols indicating the duration of musical sounds, with each value being half the length of the previous larger value.

# Formal Definition
Note values (durational symbols) represent the relative length of sounds in music. In standard notation, each note value is half the duration of the next larger value. In 4/4 time, a whole note fills a measure, a half note fills half a measure, a quarter note fills one quarter, and so on through eighth, sixteenth, and thirty-second notes.

# Construction/Recognition
- Whole note: open oval, no stem (4 beats in 4/4)
- Half note: open oval with stem (2 beats in 4/4)
- Quarter note: filled oval with stem (1 beat in 4/4)
- Eighth note: filled oval, stem, one flag (1/2 beat in 4/4)
- Sixteenth note: filled oval, stem, two flags (1/4 beat in 4/4)
- Thirty-second note: three flags, etc.

# Musical Context
Note values provide the rhythmic structure of music. Combined with the time signature and tempo, they tell performers exactly how long to sustain each sound. Multiple short notes are often beamed together for easier reading.

# Examples
- In 4/4: whole = 4 beats, half = 2, quarter = 1, eighth = 1/2, sixteenth = 1/4
- Two eighth notes = one quarter note
- Four sixteenth notes = one quarter note
- Eighth notes are beamed in groups matching the beat

# Common Confusions
- Note values are relative to the time signature (a quarter note is not always "one beat")
- In 2/2, a half note gets one beat, not two
- In 6/8, an eighth note is one division of the beat, not the beat itself
