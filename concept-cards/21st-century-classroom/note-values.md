# Quick Definition
Note values are symbols indicating the duration of musical sounds, with each value being half the length of the previous larger value; in 4/4, a whole note fills a whole measure.

# Core Definition
In the present day, the most common time signature is 4/4 (also known as "common time"). It makes sense to introduce durational symbols in the context of 4/4 because a whole note takes up a whole measure in 4/4, a half note takes up half a measure, a quarter note takes up 1/4 of a measure, and so on. Each note value is exactly half the duration of the next larger value. Two rare durational values are the double whole note (also called a "breve") and the 64th note.

# Prerequisites
- **Time signature**: The framework in which note values are measured

# Key Properties
1. Whole note: open oval, no stem (4 beats in 4/4)
2. Half note: open oval with stem (2 beats in 4/4)
3. Quarter note: filled oval with stem (1 beat in 4/4)
4. Eighth note: filled oval, stem, one flag (1/2 beat in 4/4)
5. Sixteenth note: filled oval, stem, two flags (1/4 beat in 4/4)
6. Thirty-second note: three flags; 64th note: four flags
7. Each value is half the duration of the next larger value

# Construction / Recognition
- Open notehead + no stem = whole note
- Open notehead + stem = half note
- Filled notehead + stem = quarter note
- Filled notehead + stem + flags = eighth (1 flag), sixteenth (2), thirty-second (3)
- Multiple flagged notes are often beamed together

# Context & Application
Note values provide the rhythmic structure of music. Combined with the time signature and tempo, they tell performers exactly how long to sustain each sound. Multiple short notes are often beamed together for easier reading, with beaming showing where beats begin.

# Examples
- In 4/4: whole = 4 beats, half = 2, quarter = 1, eighth = 1/2, sixteenth = 1/4
- Two eighth notes = one quarter note
- Four sixteenth notes = one quarter note
- Double whole note (breve) = 8 beats in 4/4

# Common Errors
- Assuming note values always equal the same number of beats (they are relative to the time signature)
- In 2/2, a half note gets one beat, not two

# Common Confusions
- **Relative, not absolute**: Note values are relative to the time signature; a quarter note is not always "one beat"
- **In 6/8**: An eighth note is one division of the beat, not the beat itself
- **Beaming**: Flags become beams when multiple short notes are grouped together
