# Quick Definition
Parallel major and minor keys share the same tonic note but have different key signatures; parallel minor has three more flats (or three fewer sharps) than parallel major.

# Formal Definition
Parallel keys are major and minor keys that share the same tonic note but have different key signatures. The parallel minor has ^3, ^6, and ^7 lowered compared to the parallel major. To find the parallel minor key signature, add three flats to (or subtract three sharps from) the parallel major key signature.

# Construction/Recognition
- Same tonic, different key signature
- Parallel minor = major key signature minus 3 sharps (or plus 3 flats)
- ^3, ^6, ^7 are lowered in parallel minor
- C major (0 sharps) → C minor (3 flats)
- A major (3 sharps) → A minor (0 sharps/flats)

# Musical Context
Parallel major/minor relationships are common in mode mixture and modulation. Composers often shift between parallel keys for expressive contrast while maintaining the same tonal center. This technique is called "mode mixture" or "borrowed chords."

# Examples
- C major (no sharps/flats) and C minor (3 flats: Bb, Eb, Ab)
- G major (1 sharp) and G minor (2 flats)
- D major (2 sharps) and D minor (1 flat)
- "The parallel minor of E major is E minor"

# Common Confusions
- Parallel keys have the SAME tonic but DIFFERENT key signatures
- Relative keys have DIFFERENT tonics but the SAME key signature
- Do not confuse "parallel" with "relative"
