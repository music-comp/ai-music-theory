# Quick Definition
Parallel major and minor keys share the same tonic note but have different key signatures; the parallel minor has three more flats (or three fewer sharps) than the parallel major.

# Core Definition
We use the term parallel minor when referring to a minor scale that has the same first scale degree as the major. We say, "The parallel minor of E major is E minor," and "The parallel major of F minor is F major." A minor key signature will have three lowered notes -- the 3rd, 6th, and 7th -- in relation to the corresponding major key signature. One method of figuring out a minor key signature is to add three flats to the parallel major key signature, which is the same as subtracting three sharps.

# Prerequisites
- **Major scale**: One half of the parallel relationship
- **Natural minor scale**: The other half
- **Key signature**: Understanding that parallel keys have different key signatures

# Key Properties
1. Same tonic, different key signature
2. Parallel minor = major key signature minus 3 sharps (or plus 3 flats)
3. ^3, ^6, ^7 are lowered in the parallel minor
4. Uppercase for major keys (C), lowercase for minor keys (c) when writing below the staff
5. In prose: "C major" and "C minor" (both uppercase)

# Construction / Recognition
- Same tonic, different key signature
- Add three flats (or subtract three sharps) to find parallel minor
- C major (0 sharps) -> C minor (3 flats)
- A major (3 sharps) -> A minor (0 sharps/flats)

# Context & Application
Parallel major/minor relationships are fundamental to mode mixture (borrowing chords from the parallel key) and to understanding how the same tonal center can produce different expressive qualities. Composers often shift between parallel keys for contrast.

# Examples
- C major (no sharps/flats) and C minor (3 flats: Bb, Eb, Ab)
- G major (1 sharp) and G minor (2 flats)
- D major (2 sharps) and D minor (1 flat)
- A major (3 sharps) and A minor (0 sharps/flats)

# Relationships
## Builds Upon
- Major scale, natural minor scale, key signature

## Enables

## Related
- Relative major/minor (same key signature, different tonic -- the opposite concept)

## Contrasts With
- Relative major/minor (relative = same key signature, different tonic; parallel = same tonic, different key signature)

# Common Errors
- Confusing parallel with relative (they are opposite concepts)
- Adding sharps instead of flats when converting to parallel minor

# Common Confusions
- **Parallel vs. relative**: Parallel = same tonic, different key signature; Relative = different tonic, same key signature
- **Notation convention**: Uppercase for major keys (C), lowercase for minor (c) when annotating below the staff
