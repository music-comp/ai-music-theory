# Quick Definition
The smoothest pivot chord modulations use a chord with tonic or tonic-prolongation function in the first key and pre-dominant function in the second key -- pivots with dominant function in the new key sound abrupt and unconvincing.

# Core Definition
In terms of harmonic function, composers typically do not use a pivot chord that has dominant function in the new key because such a modulation might sound abrupt and unconvincing. Instead, the pivot chord in the first key often has tonic or tonic prolongation function. In the second key, the pivot ideally has pre-dominant function. This creates a seamless, less jarring progression: the listener hears a stable chord in the first key, which then naturally leads to dominant function in the new key.

# Key Properties
1. Ideal: tonic function in key 1, pre-dominant function in key 2
2. Also good: tonic prolongation function in key 1
3. Avoid: dominant function in the new key (sounds abrupt)
4. The pivot should feel stable in the first key
5. The pivot should lead naturally to V in the second key
6. Multiple valid pivots may exist; choose the one with best function pairing

# Construction / Recognition
Analyzing pivot function:
- In the G-to-D example: Em chord
  - In G major: vi = tonic prolongation function
  - In D major: ii = pre-dominant function
  - This is an excellent pivot (stable in key 1, functional in key 2)
- Compare: D chord
  - In G major: V = dominant function
  - In D major: I = tonic function
  - Less ideal (dominant function in the first key creates forward motion away from it)

# Context & Application
This principle guides composition and analysis equally. When composing a modulation, select the pivot chord with the best functional pairing. When analyzing, the pivot with the most logical function pairing is likely the one the composer intended. This explains why some common chords work better as pivots than others, even though multiple common chords exist between two keys.

# Examples
- J.S. Bach, Christmas Oratorio, "Ermuntre dich": G chord has tonic function in G major and pre-dominant function (IV) in D major
- General principle: vi in key 1 often becomes ii in key 2 (an excellent functional pairing)

- Not considering function when multiple common chords are available

# Common Confusions
- **Multiple candidates**: Between two closely related keys, several chords may be common; function determines the best pivot
- **Dominant in key 2 = abrupt**: Even if a chord is diatonic in both keys, dominant function in the new key makes the modulation sound forced
- **vi = ii pivot**: This common pairing (tonic prolongation to pre-dominant) is one of the most effective
