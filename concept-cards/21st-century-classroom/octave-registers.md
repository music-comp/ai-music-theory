# Quick Definition
Octave registers use subscript numbers (C4, D5, etc.) to specify the exact octave of a note, with C4 designated as middle C.

# Core Definition
We use octave registers (C4, D5, etc.) to specify the exact register of a note. The note C4 is known as "middle C" and is an important reference point. The musical alphabet repeats seven times across the keyboard (with an extra ABC at the top), giving at least seven octave registers. The register number changes after each B (B4 is followed by C5).

# Prerequisites
- **Pitch**: Understanding that notes have highness/lowness and letter names

# Key Properties
1. Numbers written as subscripts after note names: C4, D5, A3
2. The register number increases after each B note (B4 is followed by C5)
3. C4 = middle C, the primary reference point
4. Higher numbers indicate higher octaves
5. The piano ranges from A0 to C8
6. The musical alphabet repeats 7 times across the keyboard

# Construction / Recognition
- Note letter + octave number: C4, D5, A3
- Register changes after B, not after G
- C4 is middle C (center of the piano)

# Context & Application
Octave registers provide precision when discussing specific pitches, eliminating ambiguity when multiple octaves of the same note name exist. They are essential in theoretical analysis, acoustics, and electronic music programming.

# Examples
- Middle C = C4
- The C one octave above middle C = C5
- The A used for orchestral tuning = A4 (440 Hz)
- B4 is followed by C5 (not B5)

# Common Errors
- Assuming the register number changes after G (end of the musical alphabet) rather than after B
- Thinking C4 means "the fourth C" rather than "the C in register 4"

# Common Confusions
- **Register change point**: The number changes after B, not after G -- B4 is followed by C5
- **Alternative systems**: Some notation systems use C3 for middle C; this text uses C4
