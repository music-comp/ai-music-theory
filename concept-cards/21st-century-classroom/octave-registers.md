# Quick Definition
Octave registers are a numbering system that identifies the specific octave location of a pitch, with C4 designating middle C.

# Formal Definition
Octave registers use subscript numbers (C4, D5, etc.) to specify the exact octave position of a note. The system divides the pitch range into numbered octaves, with the register number changing after each B (B4 is followed by C5). C4 is designated as "middle C" and serves as the primary reference point.

# Construction/Recognition
- Numbers are written as subscripts after note names: C4, D5, A3
- The register number increases after each B note
- C4 is middle C (the C nearest the center of the piano)
- Higher numbers indicate higher octaves
- The piano ranges from A0 to C8

# Musical Context
Octave registers provide precision when discussing specific pitches, especially in theoretical analysis, acoustics, and when programming electronic music. They eliminate ambiguity when multiple octaves of the same note name exist.

# Examples
- Middle C = C4
- The C one octave above middle C = C5
- The A used for orchestral tuning = A4 (440 Hz)
- B4 is followed by C5 (not B5)

# Common Confusions
- The register number changes after B, not after G (the end of the musical alphabet)
- Thinking C4 means "the fourth C" rather than "the C in register 4"
- Different notation systems exist (some use C3 for middle C)
