# Quick Definition
Secondary diminished chords can tonicize most diatonic chords in major (ii, iii, IV, V, vi) and minor (III, iv, V, VI, VII), with the notable exception that viio/III in minor is excluded because it would be identical to the diatonic iio chord.

# Core Definition
In major keys, secondary diminished chords can tonicize ii, iii, IV, V, and vi. In minor keys, they can tonicize III, iv, V, VI, and VII. The chord viio/III in minor is not included because it would be the same notes as iio -- it has no accidentals. However, viio7/III in minor also has no accidentals and is the same notes as iio7, but the two are distinguished by function: iio7 has pre-dominant function and progresses to V, while viio7/III progresses to III.

- **Secondary diminished chord**: The concept being catalogued

# Key Properties
1. In major: viio/ of ii, iii, IV, V, vi (five targets)
2. In minor: viio/ of III, iv, V, VI, VII (five targets)
3. viio/III (triad) in minor = iio (excluded -- no chromaticism)
4. viio7/III in minor = iio7 in notes, but different function (progresses to III, not V)
5. Minor triads tonicized by fully diminished 7ths
6. Major triads traditionally tonicized by half-diminished 7ths (fully diminished also possible)

# Construction / Recognition
- In C major: viio/ii = C#o, viio/iii = D#o, viio/IV = Eo(or Eo7), viio/V = F#o, viio/vi = G#o7
- In C minor: viio/iv = Bo, viio/V = F#o, viio/VI = Go, viio/VII = Ao
- For viio7/III in C minor: iio7 = Do7 = D-F-Ab-Cb -- same as viio7/III but different function
- Quality rule: half-diminished for major targets, fully diminished for minor targets

# Context & Application
The distinction between iio7 and viio7/III in minor is a key analytical insight. The notes are identical, but the progression that follows determines the label: if the chord moves to V, it is iio7 (pre-dominant); if it moves to III, it is viio7/III (secondary diminished). This principle illustrates that Roman numeral analysis reflects function, not merely pitch content.

# Common Errors
- Including viio/III as a secondary diminished triad in minor (it is just iio with no chromaticism)
- Using half-diminished to tonicize a minor triad (traditionally use fully diminished)

# Common Confusions
- **viio/III in minor**: Excluded as triad because it equals iio; as seventh chord, same notes as iio7 but different function
- **Function determines label**: iio7 goes to V; viio7/III goes to III -- same chord, different analysis
- **Quality matching**: Half-diminished for major targets is traditional, but fully diminished can also tonicize major triads
