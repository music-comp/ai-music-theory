# Quick Definition
Impressionist composers used church modes (Dorian, Phrygian, Lydian, Mixolydian) to create harmonic color distinct from major/minor tonality and chromatic Romanticism.

# Core Definition
Composers such as Debussy and Ravel wrote in the church modes as an alternative to heavily chromatic late-Romantic harmony (Wagner's *Tristan und Isolde* being the paradigmatic example). Each mode produces different harmonic qualities: in Phrygian, the seventh chord on scale degree 5 is half-diminished; Lydian creates a "floating" quality from the raised 4th; Dorian has a characteristic raised 6th degree. Composers often briefly depart from the mode for expressive purposes (Hutchinson, Ch. 32, pp. 464-466).

# Prerequisites
- **Impressionism** -- Modal writing is one of the three core techniques
- **Scales and modes** -- Must know the church mode structures

# Key Properties
1. Modes used: Phrygian, Lydian, Dorian, Mixolydian, Aeolian
2. Alternative to major/minor without chromaticism
3. Each mode produces unique chord qualities on each scale degree
4. Composers sometimes briefly depart from strict modal writing
5. Modal music still has a clear tonal center

# Construction / Recognition
- Identify the scale collection (all diatonic notes)
- Determine which note is the tonal center (final)
- Check for characteristic mode intervals (e.g., b2 = Phrygian, #4 = Lydian)
- Note departures from strict modal writing (chromatic chords)

# Context & Application
Modal writing emerged as a reaction against Wagner's heavy chromaticism. It allows diatonic harmony while avoiding dominant-tonic relationships of common-practice tonality. Modal writing influenced jazz (modal jazz of the 1950s-60s) and popular music.

# Examples
- Debussy, String Quartet, Op. 10, I: Phrygian mode (v7 is half-diminished, p. 465)
- Debussy, *Danses*, II "Danse profane": Lydian mode (p. 465)
- Ravel, Piano Trio, I: Opens in Dorian, ends in Lydian (pp. 466)
- Penultimate chords in Ravel examples are often outside the mode (p. 466)

# Common Errors
- **Error**: Analyzing modal impressionist passages with major/minor Roman numerals
  **Correction**: Use Roman numerals relative to the mode's tonal center and scale

# Common Confusions
- **Confusion**: Thinking modal = atonal
  **Clarification**: Modal music has clear tonal centers; it avoids major/minor, not tonality
- **Confusion**: Expecting strict modal writing throughout
  **Clarification**: Composers often include chromatic chords that briefly depart from the mode
