# Quick Definition
To find common chords between two keys: list all diatonic chords (with root and quality) in both keys, then identify those with the same root AND same quality -- these shared chords are potential pivot chords for modulation.

# Core Definition
In order to compose or analyze a diatonic common chord modulation, you need to determine which chords are diatonic -- having the same root and quality -- in both keys. The process involves listing the diatonic chords in each key (with both lead-sheet symbols and Roman numerals), then identifying the chords that appear in both lists with identical root and quality. Quality differences eliminate potential pivots (e.g., A minor in G major cannot be a common chord with A major in D major).

# Prerequisites
- **Diatonic pivot chord modulation**: The context for finding common chords
- **Diatonic chords in major/minor**: The chords being compared

# Key Properties
1. Both root AND quality must match
2. List chords as lead-sheet symbols to compare actual pitches
3. Also list as Roman numerals to show dual function
4. Closely related keys share more common chords
5. Foreign keys may share no diatonic common chords
6. Quality mismatches eliminate otherwise matching roots

# Construction / Recognition
Example: G major and D major common chords:
- G major: G, Am, Bm, C, D, Em, F#o
- D major: D, Em, F#m, G, A, Bm, C#o
- Common: G (I in G = IV in D), D (V in G = I in D), Bm (iii in G = vi in D), Em (vi in G = ii in D)
- NOT common: Am (ii in G) vs. A (V in D) -- different quality
- NOT common: F#o (viio in G) vs. F#m (iii in D) -- different quality

# Context & Application
This systematic process is essential for composing modulations and for identifying pivot chords in analysis. By comparing chords as lead-sheet symbols (which show actual pitch and quality), the comparison is concrete rather than abstract. Closely related keys will always share multiple common chords, while distantly related keys share fewer or none, which is why chromatic pivots or other techniques are needed for distant modulations.

# Examples
- G major to D major: four common chords (G, D, Bm, Em)
- C major to a minor: extensive shared chords (all six non-diminished chords)
- C major to F# major: very few or no common chords (requires chromatic techniques)

# Common Errors
- Accepting root matches without checking quality (Am is not the same as A major)
- Only comparing Roman numerals without verifying actual pitches

# Common Confusions
- **Use lead-sheet symbols**: Comparing Roman numerals alone can mislead -- compare actual pitches and qualities
- **Quality is decisive**: Two chords with the same root but different quality are NOT common chords
- **Roman numeral dual labeling**: After identifying common chords, label with Roman numerals in both keys
