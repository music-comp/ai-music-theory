# Quick Definition
Diatonic chords in major follow the pattern I-ii-iii-IV-V-vi-viio (Major-minor-minor-Major-Major-minor-diminished), consistent in all major keys.

# Core Definition
Diatonic means notes within a key signature and can be contrasted with the term "chromatic." Triads built on each scale degree of a major key produce a consistent pattern of qualities: I (major), ii (minor), iii (minor), IV (major), V (major), vi (minor), viio (diminished). One sees the pattern M-m-m-M-M-m-o in triad quality. This pattern holds for all major keys.

# Prerequisites
- **Roman numeral analysis**: The notation system used
- **Major scale**: The scale from which diatonic chords are built

# Key Properties
1. I = major (^1); ii = minor (^2); iii = minor (^3)
2. IV = major (^4); V = major (^5); vi = minor (^6)
3. viio = diminished (^7)
4. Pattern: M-m-m-M-M-m-o (consistent in ALL major keys)
5. Primary triads (I, IV, V) are all major
6. Secondary triads (ii, iii, vi) are all minor
7. "Diatonic" = notes within the key signature (vs. "chromatic")

# Construction / Recognition
- Build a triad on each scale degree using only notes from the key signature
- The quality pattern is always M-m-m-M-M-m-o
- Primary triads: I, IV, V (all major)
- Secondary triads: ii, iii, vi (all minor)

# Context & Application
Understanding diatonic chords allows quick identification of chord qualities in any major key. This knowledge is essential for harmonization, composition, and analysis. The primary triads (I, IV, V) are all major; the secondary triads (ii, iii, vi) are all minor. The viio is the only diminished triad.

# Examples
- C major: C-Dm-Em-F-G-Am-Bo (I-ii-iii-IV-V-vi-viio)
- G major: G-Am-Bm-C-D-Em-F#o
- F major: F-Gm-Am-Bb-C-Dm-Eo

# Common Errors
- Assuming viio is minor (it is diminished)
- Forgetting that the pattern is the same in ALL major keys

# Common Confusions
- **Consistent pattern**: M-m-m-M-M-m-o is the same in every major key
- **viio is diminished**: Not minor -- the tritone between its root and fifth makes it diminished
- **"Diatonic" definition**: Means "within the key signature," contrasted with "chromatic"
