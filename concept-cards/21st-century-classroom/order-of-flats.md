# Quick Definition
The order of flats is the fixed sequence B-E-A-D-G-C-F, the invariable order in which flats are added to key signatures.

# Core Definition
The order of flats is B-E-A-D-G-C-F. It is the reverse of the order of sharps. It is easy to remember since the first four letters make the word BEAD, and GCF is something most students learn as "Greatest Common Factor" when studying math in elementary school. The reversed mnemonic is "Battle Ends And Down Goes Charles' Father."

# Prerequisites
- **Key signature**: The context in which the order of flats is used

# Key Properties
1. Sequence: B-E-A-D-G-C-F
2. Each new flat key adds the next flat in the sequence
3. The second-to-last flat is the name of the major key
4. This is the reverse of the order of sharps
5. Follows the circle of fifths descending

# Construction / Recognition
- B-E-A-D-G-C-F (always this order, never rearranged)
- To find the major key: the second-to-last flat is the key name
- Exception: F major has only one flat (Bb), so there is no "second-to-last"

# Context & Application
The order of flats follows the circle of fifths descending (or ascending by fourths). Each new key is a fifth lower (or fourth higher) than the previous one. Understanding this order is essential for writing and identifying key signatures.

# Examples
- F major: Bb (one flat)
- Bb major: Bb, Eb (two flats -- second-to-last flat is Bb)
- Eb major: Bb, Eb, Ab (three flats -- second-to-last flat is Eb)
- Ab major: Bb, Eb, Ab, Db (four flats -- second-to-last flat is Ab)

# Common Errors
- Writing flats in the wrong order
- Applying the "second-to-last flat" rule to F major (which has only one flat)

# Common Confusions
- **Fixed order**: Always B-E-A-D-G-C-F, never rearranged
- **F major exception**: With one flat, there is no "second-to-last flat" -- you must memorize F major = one flat (Bb)
- **Reverse relationship**: This is the exact reverse of the order of sharps
