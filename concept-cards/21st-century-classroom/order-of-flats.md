# Quick Definition
The order of flats is the fixed sequence in which flats appear in key signatures: B-E-A-D-G-C-F.

# Formal Definition
The order of flats (B-E-A-D-G-C-F) is the invariable sequence in which flats are added to key signatures. Each new flat key adds one more flat to this sequence. This order must be used when writing key signatures and is the reverse of the order of sharps.

# Construction/Recognition
- Sequence: B-E-A-D-G-C-F
- Mnemonic: "BEAD GCF" (BEAD plus "Greatest Common Factor")
- Alternative: "Battle Ends And Down Goes Charles' Father" (reverse of sharps mnemonic)
- Each flat key adds the next flat in the sequence
- The second-to-last flat is the name of the major key

# Musical Context
The order of flats follows the circle of fifths descending (or ascending by fourths). Each new key is a fifth lower (or fourth higher) than the previous one. Understanding this order is essential for writing and identifying key signatures.

# Examples
- F major: Bb (one flat)
- Bb major: Bb, Eb (two flats)
- Eb major: Bb, Eb, Ab (three flats)
- Ab major: Bb, Eb, Ab, Db (four flats)
- To find the major key: the second-to-last flat is the key name

# Common Confusions
- The order is always B-E-A-D-G-C-F, never rearranged
- This is the reverse of the order of sharps
- F major (one flat) is the exception to the "second-to-last flat" rule
