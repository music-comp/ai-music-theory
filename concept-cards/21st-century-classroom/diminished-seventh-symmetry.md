# Quick Definition
The fully diminished seventh chord divides the octave into four equal parts (all minor thirds), creating a symmetrical structure with only three unique sonorities in the twelve-tone system -- each sonority has four possible spellings, each implying a different key.

# Core Definition
The fully diminished seventh chord consists entirely of minor thirds stacked upon each other, creating a symmetrical structure that divides the octave into four equal parts. Because of this symmetry, there are only three unique diminished seventh sonorities -- all other diminished seventh chords are enharmonic respellings of one of these three. Each note of the chord can function as the root, creating four possible spellings for the same sound, with each spelling implying a different key.

# Prerequisites
- **Fully diminished seventh chord**: The chord whose symmetry is being examined
- **Enharmonic equivalence**: The principle enabling multiple spellings

# Key Properties
1. Structure: m3 + m3 + m3 (+ m3 to complete octave)
2. Divides the octave into four equal parts
3. Only THREE unique diminished seventh sonorities exist
4. Each sonority has FOUR possible spellings
5. Each spelling implies a different key (through leading-tone function)
6. All four notes are equidistant (minor thirds apart)
7. The chord is inherently tonally ambiguous until it resolves

# Construction / Recognition
Three unique sonorities (all others are respellings):
1. C-Eb-Gb-Bbb (= C#-E-G-Bb = D-F-Ab-Cb = D#-F#-A-C)
2. Db-Fb-Abb-Cbb (= D-F-Ab-Cb = Eb-Gb-Bbb-Dbb = E-G-Bb-Db)
3. D-F-Ab-Cb (= Eb-Gb-Bbb-Dbb = E-G-Bb-Db = F-Ab-Cb-Ebb)

Each spelling determines the implied resolution:
- The note treated as root = scale degree 7 of the implied key
- G#o7 implies A (G# as leading tone); Bo7 implies C; Do7 implies Eb; Fo7 implies Gb

# Context & Application
The symmetry of the diminished seventh chord is the foundation of diminished-seventh enharmonic modulation. Because any note can serve as the leading tone, the chord is inherently ambiguous -- it belongs equally to four keys. Composers exploit this ambiguity to modulate rapidly to distant keys. The analyst must determine the intended resolution by examining the actual resolution chord, then assign the correct spelling. This symmetry is analogous to linguistic homophones: just as "two," "to," and "too" sound identical but mean different things, the four spellings of a diminished seventh sound identical but imply different keys.

# Examples
The sonority G#-B-D-F can be spelled four ways:
- G#o7 (resolves to A minor/major: G# as leading tone)
- Bo7 (resolves to C minor/major: B as leading tone)
- Do7 (resolves to Eb minor/major: D as leading tone, respelled as D#)
- Fo7 / E#o7 (resolves to F#/Gb minor/major: F/E# as leading tone)

# Common Errors
- Believing there are more than three unique diminished seventh sonorities
- Assuming the spelling in the score is the only valid interpretation

# Common Confusions
- **Only three unique sonorities**: All twelve possible diminished seventh chords reduce to just three sounds
- **Spelling = resolution**: The spelling determines which key is implied
- **Inherent ambiguity**: Until the chord resolves, it belongs equally to four keys
