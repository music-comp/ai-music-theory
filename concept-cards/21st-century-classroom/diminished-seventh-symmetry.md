# Quick Definition
The fully diminished seventh chord divides the octave into four equal parts (minor thirds), making it symmetrical and enharmonically equivalent to three other diminished seventh chords.

# Formal Definition
The fully diminished seventh chord consists entirely of minor thirds stacked upon each other, creating a symmetrical structure that divides the octave into four equal parts. Because of this symmetry, there are only three unique diminished seventh sonorities (the other nine are enharmonic respellings). Each note of the chord can function as the root, creating four possible spellings for the same sound.

# Construction/Recognition
Structure: m3 + m3 + m3 (+ m3 to complete octave)

Three unique diminished seventh sonorities:
1. C-Eb-Gb-Bbb (= C#-E-G-Bb = D-F-Ab-Cb = etc.)
2. C#-E-G-Bb (= D-F-Ab-Cb = Eb-Gb-Bbb-Dbb = etc.)
3. D-F-Ab-Cb (= Eb-Gb-Bbb-Dbb = E-G-Bb-Db = etc.)

Each spelling implies a different key:
- The note treated as root = scale degree 7 of the implied key
- Example: G#dim7 implies A; Bdim7 implies C; Ddim7 implies Eb; Fdim7 implies Gb

# Musical Context
- Symmetry enables pivot to four equidistant keys
- Composers exploit this for rapid, distant modulations
- The chord is tonally ambiguous until it resolves
- Important in Romantic-era chromaticism

# Examples
From the chapter: the sonority G#-B-D-F can be spelled four ways:
- G#dim7 (resolves to A)
- Bdim7 (resolves to C)
- Ddim7 (resolves to Eb)
- Fdim7 / E#dim7 (resolves to F#/Gb)

# Common Confusions
- Only THREE unique dim7 sonorities exist (others are enharmonic)
- The spelling determines the implied resolution
- The symmetry means the chord is inherently ambiguous
- All four notes are equidistant (minor thirds apart)
