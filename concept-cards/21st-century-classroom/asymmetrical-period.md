# Quick Definition
An asymmetrical period consists of three or five phrases with an unequal number of antecedents and consequents (e.g., one antecedent with two consequents).

# Core Definition
Asymmetrical periods consist of three or five phrases. There will be an unequal number of antecedents and consequents, hence the "asymmetry." Common configurations include one antecedent and two consequents, or two antecedents and one consequent.

# Prerequisites
- **Period**: Understanding of antecedent-consequent structure

# Key Properties
1. Three or five phrases (odd number)
2. Unequal number of antecedents and consequents
3. Ends with the most conclusive cadence
4. Less common than standard two-phrase periods

# Construction / Recognition
1. Count the total number of phrases (should be 3 or 5)
2. Identify which phrases function as antecedent (less conclusive ending)
3. Identify which phrases function as consequent (more conclusive ending)
4. Note the imbalance in the number of each
5. The final cadence should be the most conclusive

# Context & Application
Asymmetrical periods create variety by extending the expected two-phrase structure. They provide interesting formal alternatives in Classical music.

# Examples
- Chopin, Prelude Op. 28, No. 20, in C minor -- one antecedent and two consequents (three phrases)

# Common Confusions
- **Odd number of phrases**: Asymmetrical periods have 3 or 5 phrases
- **The "asymmetry"**: Refers to unequal antecedents and consequents
- **Not a phrase group**: Phrase groups end with HC; asymmetrical periods end with the most conclusive cadence
