# Quick Definition
An asymmetrical period consists of three or five phrases with an unequal number of antecedents and consequents, such as one antecedent with two consequents.

# Formal Definition
Asymmetrical periods consist of three or five phrases. In an asymmetrical period, there will be an unequal number of antecedents and consequents, hence the "asymmetry." Common configurations include one antecedent and two consequents, or two antecedents and one consequent.

# Analysis/Application
When analyzing asymmetrical periods:
1. Count the total number of phrases (should be 3 or 5)
2. Identify which phrases function as antecedent (less conclusive ending)
3. Identify which phrases function as consequent (more conclusive ending)
4. Note the imbalance in the number of each

# Musical Context
Asymmetrical periods create variety by extending the expected two-phrase structure. They are less common than regular periods but provide interesting formal alternatives.

# Examples
- Chopin, Prelude Op. 28, No. 20, in C minor - one antecedent and two consequents

# Common Confusions
- Asymmetrical periods have an odd number of phrases (3 or 5)
- The "asymmetry" refers to unequal numbers of antecedents and consequents
- Different from phrase groups which end with a half cadence
