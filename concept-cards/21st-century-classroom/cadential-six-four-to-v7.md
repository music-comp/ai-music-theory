# Quick Definition

When the cadential I6/4 resolves to V7, beware of parallel fifths if the 5th is above the root in the I6/4; the solution is to move all upper voices upward or use an incomplete V7.

# Core Definition

When I6/4 resolves to V7, parallel fifths can occur if the 5th is above the root in the I6/4 chord. If this voicing creates parallel fifths, move all upper voices upward to the closest notes of the V7 chord, or resolve to an incomplete V7 (no 5th) (Hutchinson, Ch. 27, p. 407).

# Prerequisites

- **Types of six-four chords** -- Understanding the cadential 6/4
- **V7 to I voice leading** -- The V7 that follows will resolve to I

# Key Properties

1. Potential for parallel 5ths when 5th is above root in I6/4
2. Solution A: move all upper voices upward to nearest V7 tones
3. Solution B: resolve to incomplete V7 (no 5th)
4. The problem depends on specific voicing of I6/4

# Construction / Recognition

## Procedure:
1. Voice the I6/4 chord (double the bass, which is ^5)
2. Check if the 5th of the I chord is above the root in the upper voices
3. If yes: move all upper voices upward, or use incomplete V7
4. If no: standard smooth voice leading

# Common Errors

- **Error**: Not checking for parallel 5ths when 5th is above root
  **Correction**: Always check the voicing of I6/4 before resolving to V7

# Common Confusions

- **Confusion**: Parallel 5ths always occur in this progression
  **Clarification**: They only occur when the 5th is above the root in the I6/4 voicing
