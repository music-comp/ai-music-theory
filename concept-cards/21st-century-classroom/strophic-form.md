# Quick Definition
Strophic form (also called verse-repeating or AAA form) is a song structure where the same music repeats for each verse, with only the lyrics changing between repetitions.

# Core Definition
In strophic form, the same musical section repeats multiple times with different lyrics for each repetition. This is one of the simplest formal structures. The form can be labeled AAA (one A for each strophe). Chapter 12 focuses on more complex forms (verse-chorus, AABA, ABAC, 12-bar blues) but strophic form provides the baseline from which these more elaborate structures evolved.

# Prerequisites
- None (fundamental form concept)

# Key Properties
1. Same music repeats for each verse
2. Only lyrics change between repetitions
3. Simplest formal structure
4. Labeled AAA...
5. Common in folk songs, hymns, and some art songs

# Construction / Recognition
1. Listen for identical or near-identical music in each verse
2. Note changing lyrics with unchanging melody and harmony
3. Modified strophic form has slight musical variations between strophes

# Context & Application
Strophic form is common in folk songs, hymns, and some art songs (Lieder). While simpler than verse-chorus or AABA forms, it focuses attention on text-setting and lyrical content.

# Examples
- Many folk songs and hymns
- Some Lieder (art songs)

# Common Errors
- Confusing with verse-chorus (strophic has no contrasting chorus section)

# Common Confusions
- **No chorus**: Strophic form has only verses, no contrasting chorus
- **Modified strophic**: Slight variations between strophes, but fundamentally the same music
- **Through-composed is the opposite**: No repeated sections at all
