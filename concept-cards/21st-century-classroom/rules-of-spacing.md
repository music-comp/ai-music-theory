# Quick Definition

Rules of spacing require that the distance between adjacent upper voices (soprano-alto and alto-tenor) not exceed an octave, while the bass can be more than an octave from the tenor.

# Core Definition

The three upper voices (soprano, alto, tenor) should be kept close together. The distance between soprano and alto, and between alto and tenor, must remain within an octave. Exceeding an octave between these pairs is a **spacing error**. The distance from bass to tenor can be greater than an octave. This reflects the natural spacing of the overtone series, where larger intervals occur lower (Hutchinson, Ch. 26, pp. 391-392).

# Key Properties

1. Soprano to Alto: within one octave (error if exceeded)
2. Alto to Tenor: within one octave (error if exceeded)
3. Tenor to Bass: may exceed one octave (no restriction)
4. Reflects overtone series spacing: wider intervals lower, closer intervals higher
5. Better-sounding voicings follow this acoustic principle

# Construction / Recognition

## To Check Spacing:
1. Measure the interval from soprano to alto -- must be <= P8
2. Measure the interval from alto to tenor -- must be <= P8
3. The bass-tenor distance has no upper limit
4. Check spacing on EVERY chord, not just the first

# Context & Application

- **Typical contexts**: All SATB voice leading
- **Historical/stylistic notes**: The overtone series demonstrates why this works acoustically -- harmonics are spaced farther apart in lower registers

# Common Errors

- **Error**: Applying the octave restriction to bass-tenor
  **Correction**: The bass can be more than an octave from the tenor; the restriction is only S-A and A-T

- **Error**: Checking spacing only on the first chord
  **Correction**: Spacing must be correct on EVERY chord in the exercise

# Common Confusions

- **Confusion**: Spacing and range are the same thing
  **Clarification**: Spacing = distance between adjacent voices; range = limits of individual voices
