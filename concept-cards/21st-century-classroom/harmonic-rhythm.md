# Quick Definition
Harmonic rhythm refers to how long each chord lasts in a progression, describing the rate at which harmonies change.

# Formal Definition
Harmonic rhythm is a term for how long each chord lasts. It can be described in terms of note values (whole-note harmonic rhythm, half-note harmonic rhythm, etc.) or beats per chord. Harmonic rhythm may remain consistent throughout a piece or vary infinitely.

# Analysis/Application
When analyzing harmonic rhythm:
1. Identify how many beats each chord receives
2. Note whether the harmonic rhythm is consistent or varies
3. Observe how harmonic rhythm changes between sections
4. Consider how harmonic rhythm affects phrase structure and momentum

# Musical Context
Harmonic rhythm significantly affects the energy and character of music. Faster harmonic rhythm (frequent chord changes) creates more activity, while slower harmonic rhythm (longer chord durations) creates stability or tension depending on context.

# Examples
- "Fly Me To The Moon," "I Will Survive," "Love You Like A Love Song" - whole-note harmonic rhythm (4 beats per chord)
- Mozart and Wagner examples - half-note harmonic rhythm (2 beats per chord)
- "Pompeii" by Bastille - harmonic rhythm changes from four-beat to two-beat

# Related Concepts
- Phrase structure
- Cadences
- Metric placement of harmonies
- Creating contrast between sections

# Common Confusions
- Harmonic rhythm is independent of tempo - a piece can have slow harmonic rhythm with fast melodic rhythm
- Changes in harmonic rhythm often signal formal divisions
- Surface rhythm (melodic activity) differs from harmonic rhythm
