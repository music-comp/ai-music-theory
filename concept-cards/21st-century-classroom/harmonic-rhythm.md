# Quick Definition
Harmonic rhythm refers to how long each chord lasts in a progression, describing the rate at which harmonies change.

# Core Definition
Harmonic rhythm is a term for how long each chord lasts. It can be described in terms of note values (whole-note harmonic rhythm = 4 beats per chord, half-note harmonic rhythm = 2 beats per chord, etc.). Harmonic rhythm may remain consistent throughout a piece or vary, and changes in harmonic rhythm often coincide with formal divisions or changes in energy.

# Prerequisites
- **Roman numeral analysis**: Ability to identify when chords change

# Key Properties
1. Measured in beats per chord or note values
2. Can be consistent or varied within a piece
3. Faster harmonic rhythm creates more activity and momentum
4. Slower harmonic rhythm creates stability or spaciousness
5. Changes in harmonic rhythm often signal formal structure
6. Independent of tempo and surface rhythm

# Construction / Recognition
1. Identify how many beats each chord receives
2. Note whether the harmonic rhythm is consistent or varies
3. Observe how harmonic rhythm changes between sections
4. Consider the relationship between harmonic rhythm and phrase structure

# Context & Application
Harmonic rhythm significantly affects the energy and character of music. Composers use changes in harmonic rhythm to create contrast between sections, build tension, or signal cadences. Throughout tonal music, harmonic rhythm is one of the key tools for shaping form.

# Examples
- "Fly Me To The Moon," "I Will Survive," "Love You Like A Love Song" -- whole-note harmonic rhythm (4 beats per chord)
- Mozart K. 545 and Wagner Die Meistersinger -- half-note harmonic rhythm (2 beats per chord)
- Bastille, "Pompeii" -- harmonic rhythm changes from four-beat to two-beat within the song

# Common Errors
- Confusing harmonic rhythm with melodic/surface rhythm
- Assuming harmonic rhythm must be constant throughout a piece

# Common Confusions
- **Independent of tempo**: A piece can have slow harmonic rhythm with fast melodic rhythm, or vice versa
- **Surface rhythm differs from harmonic rhythm**: Rapid sixteenth-note arpeggiation of one chord is slow harmonic rhythm with fast surface rhythm
- **Changes signal form**: Shifts in harmonic rhythm often mark section boundaries
