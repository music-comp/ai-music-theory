# Quick Definition
Additive process is a minimalist technique, associated with Philip Glass, where patterns are gradually lengthened by systematically adding or subtracting notes.

# Core Definition
In Philip Glass's version of additive minimalism (as found in *Two Pages*, 1969), he adds a repetition of a pattern but subtracts the final note in the repetition. Each addition is another repetition with the final note of the previous repetition subtracted. In *Einstein on the Beach*, each chord in a five-chord cadential progression is gradually lengthened by adding subdivisions. The process creates gradual change the listener can perceive (Hutchinson, Ch. 35, pp. 501-502).

# Prerequisites
- **Minimalism** -- Additive process is a minimalist technique

# Key Properties
1. Patterns gradually lengthened or shortened
2. Systematic addition or subtraction of notes
3. Glass's method: repeat pattern with final note subtracted
4. Alternative: adding subdivisions to chords
5. Each step is audible to the listener
6. Creates hypnotic, gradually evolving textures

# Construction / Recognition
**Glass's method (Two Pages):**
1. State original pattern
2. Repeat, subtracting the final note
3. Each subsequent repetition subtracts one more note
4. Shortened versions accumulate, lengthening the total

**Einstein method:**
1. Begin with short rhythmic values per chord
2. Gradually add subdivisions to each chord
3. Chords grow progressively longer

# Context & Application
Glass developed additive process in early works like *Two Pages* (1969) and *Music in Fifths* (1969). The technique creates hypnotic, gradually evolving textures.

# Examples

# Common Errors
- **Error**: Thinking additive process is just "repeating more times"
  **Correction**: The process involves systematic modification of the pattern's structure, not just repetition count

# Common Confusions
- **Confusion**: Confusing additive process with augmentation
  **Clarification**: Augmentation proportionally lengthens note values; additive process adds or subtracts notes from a pattern
