# Quick Definition
When chord roots are a second apart (as in ii6-I6/4 or I-vii-diminished-6), parallel fifths can occur; the solution is to revoice the chords so the 5th is below the root in the upper voices.

# Formal Definition
Certain chord progressions where the roots are a second apart are prone to parallel fifths, particularly ii6-I6/4 and I-vii-diminished-6. In these situations, typical voice leading can inadvertently create parallel fifths between upper voices. The solution is to revoice each chord so that the fifth of the chord appears below the root in the upper voices, creating parallel fourths instead (which are acceptable).

# Rules/Procedures
1. Be alert when roots are a second apart (especially with inversions)
2. Common problem progressions:
   - ii6 to I6/4
   - I to vii-diminished-6
3. **Standard voicing creates parallel 5ths**: When 5th is above root
4. **Solution**: Revoice so 5th is BELOW root in upper voices
5. This creates parallel 4ths instead of parallel 5ths
6. Parallel 4ths between upper voices are acceptable

# Musical Context
This special case shows how voice leading rules interact with chord progressions. The solution (revoicing to create parallel 4ths) is a common technique in Bach's chorales and demonstrates awareness of potential voice leading pitfalls.

# Examples
- ii6 to I6/4 in C major: D-F-A to C-E-G with parallel 5th potential
  - Problem: F-A (5th above) to E-G creates parallel 5ths
  - Solution: Revoice ii6 with 5th below (A-D-F) to avoid
- I to vii-diminished-6: C-E-G to D-F-B similarly prone

# Common Confusions
- Not recognizing when roots are a second apart
- Thinking all parallel 4ths are forbidden (only 4ths with the bass are problematic)
- Applying this rule when roots are NOT a second apart
- Not revoicing both chords appropriately
