# Quick Definition

When chord roots are a second apart (as in ii6 to I6/4 or I to viio6), parallel fifths can occur; the solution is to revoice chords so the 5th is below the root in the upper voices, creating acceptable parallel fourths instead.

# Core Definition

Certain progressions where the roots are a second apart are prone to parallel fifths, particularly ii6 to I6/4 and I to viio6. The solution: in any situation where roots are a second apart (even if inverted), revoice each chord so the 5th of the chord is below the root in the upper voices. This creates parallel fourths instead, which are acceptable (Hutchinson, Ch. 26, pp. 397-398).

# Key Properties

1. Problem occurs when chord roots are a second apart
2. Common problem progressions: ii6 to I6/4, I to viio6
3. Standard voicing can create parallel 5ths between upper voices
4. Solution: revoice so 5th is BELOW root in upper voices
5. Creates parallel 4ths instead (acceptable between upper voices)

# Construction / Recognition

## To Fix:
1. Identify progressions where chord roots are a step apart
2. Check for parallel 5ths between upper voices
3. If found: revoice both chords so the 5th appears below the root in the upper voices
4. This converts parallel 5ths into parallel 4ths

# Context & Application

- **Typical contexts**: Any progression with roots a second apart, especially involving inversions

# Common Errors

- **Error**: Not recognizing when roots are a second apart in inverted chords
  **Correction**: Determine the ROOT of each chord regardless of inversion

# Common Confusions

- **Confusion**: All parallel fourths are forbidden
  **Clarification**: Parallel 4ths between upper voices are acceptable; only 4ths involving the bass are problematic
