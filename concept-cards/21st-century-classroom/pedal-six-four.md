# Quick Definition
A pedal six-four chord occurs when the bass repeats three times on the same note, with the middle chord being a 6/4 chord -- the static bass acts like a pedal point while the upper voices move to create the 6/4 embellishment.

# Core Definition
The pedal six-four is one of the four approved contexts for second-inversion chords in classical music. The bass line consists of three repeated notes (the same pitch), and the middle chord is a 6/4 chord. The static bass functions like a pedal point while the upper voices move to create the neighboring 6/4 chord before returning. Common patterns include I-IV6/4-I (bass stays on do) and V-I6/4-V (bass stays on sol).

# Prerequisites
- **Six-four chord types**: The broader category of approved 6/4 contexts
- **Pedal point**: The sustaining function the bass imitates

# Key Properties
1. Bass repeats three times on the same note
2. Middle chord is a 6/4 chord
3. The bass acts like a pedal point
4. Upper voices move up and back (neighbor motion)
5. Common patterns: I-IV6/4-I, V-I6/4-V
6. The 6/4 chord has an embellishing/neighboring function

# Construction / Recognition
- Look for three repeated bass notes
- The middle bass note supports a 6/4 chord
- The outer bass notes support the same chord (root position)
- Example: bass C-C-C with chords C-F/C-C (I-IV6/4-I)
- The upper voices create neighbor-tone motion

# Context & Application
The pedal six-four embellishes a harmony over a static bass. It is one of the most common voice-leading patterns in tonal music, appearing in all periods and styles. The static bass provides stability while the upper-voice motion adds harmonic interest. The pattern I-IV6/4-I is particularly common.

# Examples
- I-IV6/4-I (bass stays on do; upper voices: C-E-G becomes C-F-A becomes C-E-G)
- V-I6/4-V (bass stays on sol; upper voices neighbor above and return)

# Common Errors
- Using a pedal 6/4 without a repeated bass note
- Confusing with cadential 6/4 (check: is the bass repeated three times?)

# Common Confusions
- **Repeated bass is the key**: Three identical bass notes, middle supports 6/4
- **Embellishing function**: Like the passing 6/4, the pedal 6/4 is non-structural
- **Upper voices create neighbors**: The motion in upper voices is neighbor-tone motion
