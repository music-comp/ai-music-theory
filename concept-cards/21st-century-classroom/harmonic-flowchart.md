# Quick Definition
A visual diagram showing the typical paths that chords follow based on their harmonic function: Tonic to Tonic Prolongation to Pre-Dominant to Dominant and back to Tonic.

# Core Definition
The harmonic flowchart maps chord progressions according to harmonic function. In major: Tonic (I) can progress to any function; Tonic Prolongation (vi, iii) progresses to Pre-Dominant; Pre-Dominant (ii, IV) progresses to Dominant; Dominant (V, viio) progresses to Tonic. Dashed lines show possible movement within a functional area. The basic flow is T -> TP -> PD -> D -> T. In minor, the subtonic VII chord is added with one function: to progress to III.

# Prerequisites
- **Harmonic function**: Understanding of the four functional categories

# Key Properties
1. Major: I (T) -> vi/iii (TP) -> ii/IV (PD) -> V/viio (D) -> I (T)
2. I can progress directly to any function
3. Minor adds subtonic VII, which progresses only to III
4. Dashed lines show movement within a functional area
5. Two exceptions: plagal cadence (IV-I) and deceptive cadence (V-vi)
6. Popular music adds bVII with flexible function (see separate card)

# Construction / Recognition
1. Identify each chord's function
2. Follow the flowchart to predict or verify the next chord
3. When progressions deviate, check for exceptions or sequential patterns
4. In popular music, consult the expanded flowchart with bVII

# Context & Application
The flowchart represents common-practice harmony from the Baroque through Romantic eras and remains applicable to much popular music. Exceptions often occur through harmonic sequences, stylistic conventions, or the plagal and deceptive cadences. The popular music flowchart adds bVII, which can precede tonic, dominant, or pre-dominant chords.

# Examples
- Major key: I(T) -> vi(TP) -> IV(PD) -> V(D) -> I(T)
- Plagal cadence exception: IV(TP) -> I(T)
- Deceptive cadence exception: V(D) -> vi
- Minor key: VII -> III (subtonic VII's only function in minor)
- Popular music: bVII can precede I, V, IV, or ii

# Common Errors
- Forgetting the plagal and deceptive cadence exceptions
- Assuming the flowchart is rigid (it represents tendencies, not rules)

# Common Confusions
- **Plagal cadence (IV-I)**: IV has tonic prolongation function here, not pre-dominant
- **Deceptive cadence (V-vi)**: An exception where dominant goes to tonic prolongation
- **I can go anywhere**: The tonic chord can progress directly to any other function
- **Minor key VII**: The subtonic VII progresses only to III
