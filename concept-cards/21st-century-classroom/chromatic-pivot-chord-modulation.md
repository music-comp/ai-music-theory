# Quick Definition
Chromatic pivot chord modulation uses a pivot that is chromatic in at least one key -- including secondary common chords, borrowed common chords, and Neapolitan common chords -- enabling modulation to more distant keys than diatonic pivots allow.

# Core Definition
In chromatic pivot chord modulation, the pivot chord is a chromatic chord in at least one (and sometimes both) of the keys involved. Three subtypes exist: (1) Secondary common chord, where the pivot is a secondary chord in both keys; (2) Borrowed common chord (mode mixture), where the pivot is a borrowed chord in one key; (3) Neapolitan common chord, where the Neapolitan bridges two foreign keys. These techniques enable modulation to more distant keys than diatonic pivot chords allow.

# Prerequisites
- **Diatonic pivot chord modulation**: The foundational pivot technique
- **Secondary dominants**: Used in secondary common chord pivots
- **Mode mixture**: Used in borrowed common chord pivots
- **Neapolitan chord**: Used as an adventurous pivot

# Key Properties
1. Pivot is chromatic in at least one key (sometimes both)
2. Three subtypes: secondary, borrowed, Neapolitan
3. Enables modulation to foreign (distant) keys
4. Neapolitan pivot can bridge keys a tritone apart
5. Borrowed chord pivot: respelling may be needed between keys
6. Analyzed with pivot bracket showing chromatic analysis in one or both keys

# Construction / Recognition
Subtypes:
- **Secondary common chord**: V7/IV in key 1 = V7 in key 2 (pivot is secondary in both)
- **Borrowed common chord**: i6 in Db major (borrowed) = vi6 in E major (diatonic)
- **Neapolitan common chord**: N6/5 in D minor = V6/5 in Ab minor (tritone away)

# Context & Application
Romantic-era composers favored chromatic pivot chords for their ability to reach more adventurous key areas. The Neapolitan pivot is particularly imaginative, bridging the maximum tonal distance (tritone). These techniques represent the next level of modulatory sophistication beyond diatonic pivots and are essential for analyzing Romantic-era music.

# Examples
- Schubert, Schwanegesang, "Abschied" (1828) -- secondary common chord pivot
- Beethoven, Piano Sonata Op. 110, I (1821) -- borrowed common chord: i6 in Db major = vi6 in E major
- Schubert, Schwanegesang, "Fruhlingssehnsucht" (1828) -- Neapolitan pivot: D minor to Ab minor (tritone)

# Common Errors
- Not recognizing that a pivot can be chromatic in both keys simultaneously
- Limiting pivot chord search to diatonic chords only

# Common Confusions
- **Chromatic in one or both**: The pivot can be chromatic in just one key or in both
- **Neapolitan for distance**: The Neapolitan pivot specifically bridges distant keys
- **Augmented sixth pivots**: Covered separately under enharmonic modulation (Ch. 23)
