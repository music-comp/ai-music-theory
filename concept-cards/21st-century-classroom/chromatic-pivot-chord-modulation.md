# Quick Definition
Chromatic pivot chord modulation uses a pivot chord that is chromatic in at least one of the keys, including secondary chords, borrowed chords, Neapolitan, or augmented sixth chords.

# Formal Definition
In chromatic pivot chord modulation, the pivot chord is a chromatic chord in at least one (and sometimes both) of the keys involved in the modulation. Types include: secondary common chord (pivot is secondary chord in both keys), borrowed common chord (pivot is borrowed chord in one key), and Neapolitan common chord (Neapolitan in one key becomes a functional chord in the new key).

# Construction/Recognition
Types of chromatic pivot chords:

1. Secondary Common Chord:
   - Pivot is a secondary chord in both keys
   - Example: V7/IV in key 1 = V7 in key 2

2. Borrowed Common Chord (Mode Mixture):
   - Pivot is borrowed chord in one key
   - Example: i6 in Db major (borrowed) = vi6 in E major

3. Neapolitan Common Chord:
   - Neapolitan in one key functions differently in new key
   - Can bridge foreign (distant) key relationships
   - Example: N6/5 in D minor = V6/5 in Ab minor (tritone relation!)

# Musical Context
- Enables modulation to more distant keys
- Creates more dramatic tonal shifts
- Neapolitan pivot can span a tritone
- Romantic era composers favored these techniques

# Examples
- Schubert, Schwanegesang, "Abschied" (1828) - secondary common chord
- Beethoven, Piano Sonata Op. 110, I (1821) - borrowed common chord: i6 in Db = vi6 in E
- Schubert, Schwanegesang, "Fruhlingssehnsucht" (1828) - Neapolitan pivot: D minor to Ab minor

# Common Confusions
- The pivot can be chromatic in one or BOTH keys
- Chromatic pivots enable modulation to foreign keys
- The Neapolitan pivot is particularly useful for distant modulations
- Augmented sixth pivot chords are covered in enharmonic modulation
