# Quick Definition
To write a secondary diminished chord, identify the target chord's root, find the note a minor second below it, build the appropriate diminished chord on that note, then apply the specified inversion.

# Formal Definition
To write a secondary diminished chord: (1) Determine the root of the chord being tonicized (after the slash); (2) Find vii° in that chord's key (root is m2 below target root); (3) Build a diminished triad or appropriate seventh chord; (4) Invert according to the figured bass symbols.

# Analysis/Application
Example: Write vii°4/2/iv in G minor
1. iv in G minor = C minor; root is C
2. vii°7 in C minor has root B (m2 below C)
3. Build fully-diminished seventh on B: B-D-F-Ab
4. 4/2 = third inversion (7th in bass) = Ab in bass
5. Result: Ab-B-D-F

# Musical Context
Writing secondary diminished chords requires understanding key relationships and diminished chord construction. The skill complements writing secondary dominants.

# Examples
vii°7 4/2/iv in G minor:
- Target: iv (Cm)
- vii°7 in C minor = B°7
- 4/2 inversion = 7th (Ab) in bass
- Notes: Ab-B-D-F

# Common Confusions
- For minor targets, use fully-diminished seventh
- For major targets, traditionally use half-diminished (but fully-dim also works)
- The inversion applies to the chord you're building
