# Quick Definition
To write a secondary diminished chord: identify the target chord's root, find the note a minor second below it, build the appropriate diminished chord (fully diminished for minor targets, half-diminished for major), then apply the specified inversion.

# Core Definition
To write a secondary diminished chord: (1) Determine the root of the chord being tonicized (the Roman numeral after the slash). (2) Determine viio in the key of that chord -- the root is a minor second below the target root. (3) Build the appropriate diminished chord (fully diminished seventh for minor targets, half-diminished for major targets, or as specified). (4) Invert the chord according to the figured bass symbols.

# Prerequisites
- **Secondary diminished chord**: Understanding the concept and quality rules
- **Figured bass inversion symbols**: Knowing which note goes in bass for each inversion

# Key Properties
1. Target chord = Roman numeral after the slash
2. Secondary diminished root = m2 below the target root
3. Fully diminished 7th for minor targets; half-diminished for major targets
4. Apply the specified inversion
5. Verify by analyzing backward

# Construction / Recognition
Worked example -- viio4/2/iv in G minor:
1. iv in G minor = C minor; root is C
2. viio7 in C minor: root is B (m2 below C)
3. Build fully diminished seventh on B: B-D-F-Ab
4. 4/2 = third inversion = seventh (Ab) in bass
5. Result: Ab-B-D-F

# Context & Application
Writing secondary diminished chords requires careful attention to the quality conventions: fully diminished seventh chords tonicize minor triads, and half-diminished seventh chords traditionally tonicize major triads (though fully diminished can also work for major targets). The construction process mirrors the secondary dominant procedure but uses the minor-second-below relationship instead of perfect-fifth-above.

# Common Errors
- Building on a note P5 above instead of m2 below
- Using wrong quality (half-diminished for minor target, or vice versa)

# Common Confusions
- **m2 below**: The root of viio is always a half step below its resolution target
- **Quality rule**: Fully diminished for minor targets; half-diminished for major (traditional)
- **Inversion applies to the built chord**: The figured bass describes the secondary diminished, not the target
