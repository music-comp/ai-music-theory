# Quick Definition
Chord-scale relationships match specific scales to specific chord types, providing improvisers with note choices that sound consonant over each chord.

# Formal Definition
Chord-scale relationships identify which scale best fits a given chord by writing all chord tones as a scale within an octave, then filling in gaps while avoiding augmented 2nds and consecutive half steps. This knowledge allows improvisers to play melodically over chord changes and enables arrangers to write chordal passages where non-chord tones come from the corresponding scale.

# Construction/Calculation
To determine a chord-scale relationship:
1. Identify all notes in the chord (including upper extensions and alterations)
2. Write all chord tones as a scale within one octave
3. Fill in any gaps with notes that avoid augmented 2nds and consecutive half steps
4. Analyze the resulting scale
5. Also consider the chord's relationship to the overall key

# Musical Context
Understanding chord-scale relationships is essential for jazz improvisation and arranging. This knowledge becomes second nature to experienced improvisers. Context matters: the same chord quality might use different scales depending on its function. For example, Fm7 as vi7 in Ab major uses F Aeolian (not Dorian) because D-natural would conflict with the key.

# Examples
Common chord-scale relationships:
- CΔ7: C major or C Lydian
- CΔ7(#11): C Lydian
- Cm7: C Dorian or C Aeolian
- C7: C Mixolydian
- C7(#11): C Lydian-Dominant
- C7alt: C Diminished-Whole Tone
- Cø7: C Locrian or C Locrian #2
- CmΔ7: C melodic minor ascending

# Common Confusions
- The same chord quality can have multiple scale options
- Context within the key affects scale choice
- Dorian vs Aeolian choice depends on whether 6 or b6 fits the key
- Avoid augmented 2nds and consecutive half steps when constructing scales
