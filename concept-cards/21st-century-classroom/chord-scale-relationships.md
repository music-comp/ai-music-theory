# Quick Definition
Chord-scale relationships match specific scales to chord types by writing all chord tones as a scale and filling gaps while avoiding augmented 2nds and consecutive half steps.

# Core Definition
To determine a chord-scale relationship, write all notes of the chord (including extensions and alterations), arrange them as a scale within an octave, then fill in gaps while avoiding augmented 2nds and consecutive half steps. This knowledge allows improvisers to play melodically over changes and enables arrangers to write chordal passages where non-chord tones come from the corresponding scale. Context matters: the same chord quality may use different scales depending on its function in the key (Hutchinson, Ch. 31, pp. 459-460).

# Prerequisites
- **Jazz ninth chords** -- Must understand chord extensions to identify chord tones
- **Altered dominant seventh chords** -- Altered chords have specific scale correspondences

# Key Properties
1. Write chord tones, fill gaps avoiding augmented 2nds and consecutive half steps
2. Consider the chord's relationship to the overall key
3. The same chord quality may have multiple valid scale options
4. This knowledge becomes second nature to experienced improvisers

# Construction / Recognition
**Process (p. 459):**
1. Identify all notes in the chord
2. Write chord tones as scale within one octave
3. Fill gaps avoiding augmented 2nds and consecutive half steps
4. Analyze the resulting scale

**Example:** GΔ7(#11) yields G Lydian (p. 459, Figure 31.10.1)

# Context & Application
Understanding chord-scale relationships is essential for jazz improvisation and arranging. Context matters: Fm7 as vi7 in Ab major uses F Aeolian (not Dorian) because D natural conflicts with the key signature (p. 460).

# Examples
**Common pairings (Table 31.10.3, p. 460):**
- CΔ7: C major or C Lydian
- CΔ7(#11): C Lydian
- Cm7: C Dorian or C Aeolian
- Cø7: C Locrian or C Locrian #2
- CmΔ7: C melodic minor ascending
- C7: C Mixolydian
- C7(#11): C Lydian-Dominant
- C7(#5) or C7(b5): C Whole Tone
- C7(b9) or C7(#9): C Octatonic (Half-Whole)
- C7alt: C Diminished-Whole Tone

# Common Errors
- **Error**: Ignoring the chord's relationship to the overall key
  **Correction**: Context affects scale choice (e.g., Dorian vs. Aeolian for minor 7th chords)

# Common Confusions
- **Confusion**: Thinking each chord has exactly one correct scale
  **Clarification**: Some chords have multiple valid scale options depending on context
