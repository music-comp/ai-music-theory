# Quick Definition
To analyze a potential secondary dominant, stack the chord in thirds to verify it's major or major-minor seventh, then determine if its root is a perfect fifth above a diatonic chord.

# Formal Definition
When encountering a chord with chromaticism, use this process to identify secondary dominants: (1) Stack the chord in thirds to determine root and quality; (2) If major triad or major-minor seventh, continue; (3) Determine the note a P5 below the root; (4) If that note is the root of a diatonic chord, the chromatic chord is a secondary dominant.

# Analysis/Application
Step-by-step example (F# major chord in C major):
1. Stack in thirds: F#-A#-C# (major triad, first inversion)
2. Quality is major, so continue
3. P5 below F# is B
4. B is ^5 in C major, so F# major tonicizes V
5. Label: V6/V

# Musical Context
This analytical process helps identify chromatic chords that function as secondary dominants versus other types of chromatic harmony.

# Examples
F# major triad in first inversion in C major:
- Stack: F#-A#-C# (major)
- P5 below F# = B = ^5 in C major
- Analysis: V6/V

# Common Confusions
- If the chord quality is not major or major-minor seventh, it's not a secondary dominant
- If the P5 below the root is not a diatonic scale degree, it's not a secondary dominant
- Check for both the chord quality AND the target chord
