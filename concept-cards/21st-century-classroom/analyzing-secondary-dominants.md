# Quick Definition
To analyze a potential secondary dominant: stack the chord in thirds to verify it is major or major-minor seventh quality, then check whether a perfect fifth below its root is a diatonic scale degree -- if both conditions are met, it is a secondary dominant.

# Core Definition
When encountering a chord with chromaticism and suspecting it is a secondary dominant, use this two-step process: (1) Stack the chord in thirds to determine the root and quality -- if the chord quality is major (triad) or major-minor seventh, proceed to step 2; if not, it is not a secondary dominant. (2) Determine the note that would be a perfect fifth below the root of the chord -- if this note would be the root of a diatonic chord, the chord is a secondary dominant of that diatonic chord.

# Prerequisites
- **Secondary dominant**: Understanding what secondary dominants are
- **Interval quality**: Ability to identify perfect fifths and chord qualities

# Key Properties
1. Step 1: Verify chord quality (must be M triad or Mm7)
2. Step 2: Check if P5 below root is a diatonic chord root
3. Both conditions must be met
4. If quality is wrong (diminished, minor, etc.), it is NOT a secondary dominant
5. If P5 below root is not diatonic, it is NOT a secondary dominant
6. The resulting label shows the inversion: V6/V, V4/3/ii, etc.

# Construction / Recognition
Worked example -- F# major triad in first inversion, in C major:
1. Stack in thirds: F#-A#-C# = major triad in first inversion
2. Quality is major -- proceed
3. P5 below F# = B
4. B is scale degree 5 in C major (root of the V chord)
5. Therefore: F# major in first inversion = V6/V

# Context & Application
This analytical process is the standard method for identifying chromatic chords as secondary dominants. It works systematically and avoids guesswork. The process parallels the analysis of secondary diminished chords (which uses a minor second above instead of a perfect fifth below). When combined with the distinguishing-chromatic-harmonies framework, it helps differentiate secondary dominants from other chromatic chord types.

# Examples
- F# major/A# in C major: stack as F#-A#-C#, P5 below F# = B = scale degree 5; label: V6/V
- Any chromatic major triad or Mm7: apply the two-step test

# Common Errors
- Skipping the quality check (not all chromatic chords are secondary dominants)
- Checking P5 above instead of P5 below

# Common Confusions
- **Quality first**: If the chord is not major or Mm7, stop -- it is not a secondary dominant
- **P5 below, not above**: The target chord is a P5 below the secondary dominant's root
- **Inversion matters**: Include the figured bass symbol for the inversion in the final label
