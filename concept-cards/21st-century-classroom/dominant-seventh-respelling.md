# Quick Definition
To respell a V7 as a Ger+6: most commonly change the 7th of the V7 to #4 of the Ger+6 (e.g., F becomes E# in G7) -- less commonly, the bottom three notes are respelled while the top note is retained as a common tone.

# Core Definition
The dominant seventh chord and the Ger+6 have the same sound but are spelled differently. The most common respelling involves changing the top note: the 7th of V7 becomes the #4 of Ger+6. For example, G7 (G-B-D-F) can be respelled as Ger+6 in B minor by changing F to E# (G-B-D-E#). Less commonly, the bottom three notes could be respelled while the uppermost note is retained as a common tone. Each chord implies a key based on its spelling: V7 implies a key where its root is scale degree 5; Ger+6 implies a key where its lowest note is b6.

# Key Properties
1. Most common: respell the 7th of V7 as #4 of Ger+6
2. Less common: respell the bottom three notes, keep top note
3. V7 implies: root = scale degree 5 of a major key
4. Ger+6 implies: lowest note = b6 of a key
5. The respelling is never written in the score
6. The analyst must visualize the alternative spelling

# Construction / Recognition
Common respelling (top note changes):
- G7 = G-B-D-F; respell F as E#: Ger+6 in B minor (G=b6, B=1, D=b3, E#=#4)
- Ab7 = Ab-C-Eb-Gb; respell Gb as F#: Ger+6 in C (Ab=b6, C=1, Eb=b3, F#=#4)

Less common respelling (bottom three notes change):
- G7 = G-B-D-F; respell G as Ab, B as Cb, D as Ebb; keep F: Ger+6 in Db
- This version retains F as common tone between the two interpretations

# Context & Application
Developing the ability to respell dominant seventh chords as Ger+6 (and vice versa) is a crucial skill for analyzing enharmonic modulations. The analyst will never see both spellings written out -- only one appears in the score, and the other must be imagined. The most common approach (respelling the top note) is simpler and should be learned first. The less common approach (respelling the bottom three notes) can be useful for understanding certain modulations where the top note is sustained.

# Examples
- G7 (V7 in C): F respelled as E# = Ger+6 in B minor
- D7 (V7/IV in D major): C respelled as B# = Ger+6 in F# minor (Tchaikovsky, "Waltz of the Flowers")
- Ab7 (as heard): Gb respelled as F# = Ger+6 in C major/minor

# Common Errors
- Expecting the respelling to appear in the score (it does not)
- Only practicing common respelling without learning the less common version

# Common Confusions
- **Not written**: You must visualize the respelling mentally
- **Two methods**: Top-note respelling (common) and bottom-three-notes respelling (less common)
- **Key implications**: V7 root = scale degree 5; Ger+6 bass = b6
