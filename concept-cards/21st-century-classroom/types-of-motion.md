# Quick Definition

The four types of motion describe how two voices move in relation to each other: contrary (opposite directions), oblique (one stationary), similar (same direction, different intervals), and parallel (same direction, same interval).

# Core Definition

Types of motion classify the relative melodic direction of any two voices (Hutchinson, Ch. 26, pp. 389-390):
- **Contrary motion**: Two voices move in opposite directions by step or leap
- **Oblique motion**: One voice stays the same while the other moves up or down
- **Similar motion**: Both voices move in the same direction (also called "direct" motion)
- **Parallel motion**: A specific type of similar motion where both voices move in the same direction by the same interval

# Prerequisites

- **Voice leading** -- Types of motion are fundamental to voice leading analysis

# Key Properties

1. Contrary: opposite directions
2. Oblique: one voice static, other moves
3. Similar (direct): same direction, different interval sizes
4. Parallel: same direction AND same interval size
5. Parallel motion is a subset of similar motion

# Construction / Recognition

## To Identify Motion Type:
1. Determine the direction each voice moves (up, down, or static)
2. If opposite directions: **Contrary**
3. If one static: **Oblique**
4. If same direction, different interval: **Similar**
5. If same direction, same interval: **Parallel**

# Context & Application

- **Typical contexts**: Analyzing voice leading between any pair of voices
- **Common applications**: Contrary and oblique motion promote voice independence; parallel motion can undermine it (depending on the interval)

# Relationships

## Enables
- **Objectionable parallels** -- Parallel 5ths/8ves are a specific concern arising from parallel motion

# Common Errors

- **Error**: Not checking motion between ALL voice pairs
  **Correction**: In SATB writing, check S-A, S-T, S-B, A-T, A-B, T-B

# Common Confusions

- **Confusion**: Similar motion and parallel motion are the same
  **Clarification**: Parallel is a SUBSET of similar -- parallel requires the same interval size in both voices

- **Confusion**: All parallel motion is forbidden
  **Clarification**: Parallel 3rds and 6ths are acceptable; only parallel 5ths and 8ves are objectionable
