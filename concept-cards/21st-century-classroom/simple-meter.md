# Quick Definition
Simple meter is any meter where the beats naturally divide into two equal parts; simple time signatures have a top number of 2, 3, or 4.

# Core Definition
If the beats are normally divided into two parts, the meter is described as simple. The top number of a simple time signature indicates the number of beats per measure (2, 3, or 4), and the bottom number indicates which note value receives one beat. The division of the beat is twice as fast as the beat note value. Simple meter is the most common type of meter in Western music.

# Prerequisites
- **Meter**: The concept of beat grouping and division
- **Time signature**: The notation that expresses simple meter

# Key Properties
1. Beats divide naturally into two equal parts
2. Top numbers: 2 (duple), 3 (triple), or 4 (quadruple)
3. Bottom number = the beat unit directly
4. Division note value = half the beat note value
5. Common examples: 2/4, 3/4, 4/4, 2/2, 3/8

# Construction / Recognition
- Top number is 2, 3, or 4
- Bottom number directly indicates the beat note value
- 4 = quarter note beat; 8 = eighth note beat; 2 = half note beat

# Context & Application
Simple meter is the most common type in Western music. The two-part division of the beat feels natural and is found in most popular music, marches, waltzes (3/4), and much classical music. 4/4 ("common time") is the most frequently encountered time signature.

# Examples
- 4/4 (simple quadruple): 4 quarter-note beats, each divides into 2 eighths
- 3/4 (simple triple): 3 quarter-note beats, each divides into 2 eighths
- 2/4 (simple duple): 2 quarter-note beats, each divides into 2 eighths
- 2/2 (simple duple): 2 half-note beats, each divides into 2 quarters
- 3/8 (simple triple): 3 eighth-note beats

# Common Errors
- Assuming the bottom number always shows the beat (true in simple but NOT in compound)
- Confusing 3/4 (simple triple) with 6/8 (compound duple)

# Common Confusions
- **"Simple" vs. "easy"**: Simple means beats divide by two, not that the music is easy
- **Bottom number**: In simple meter, the bottom number IS the beat unit (unlike compound)
- **3/4 vs. 6/8**: 3/4 is simple triple (3 beats of 2); 6/8 is compound duple (2 beats of 3)
