# Quick Definition
A turnaround is a chord progression (typically iii-vi-ii-V) used in the final measures of a tune to create harmonic motion leading back to the beginning.

# Core Definition
The iii-vi-ii-V progression is called a turnaround because it replaces the static harmony of the I chord in the last two measures of a tune with harmonic motion that leads to the I chord upon repetition. This also applies to the I-vi-ii-V version. The turnaround can be modified so all four chords become dominant sevenths (III7-VI7-II7-V7), which then enables tritone substitutions creating chromatic bass motion (e.g., E7-Eb7-D7-Db7). Because of tritone substitutions, the bII7 chord can substitute for V7 (Hutchinson, Ch. 31, p. 455).

# Prerequisites
- **ii-V-I progression** -- The turnaround extends the ii-V concept
- **Tritone substitution** -- Enables chromatic variants of the turnaround

# Key Properties
1. Replaces static I harmony at the end of a tune
2. Creates forward motion back to the top of the form
3. Standard form: iii-vi-ii-V or I-vi-ii-V
4. Can convert all chords to dominant 7ths: III7-VI7-II7-V7
5. Tritone subs create chromatic bass: E7-Eb7-D7-Db7
6. bII7 substitutes for V7 because they share guide tones

# Construction / Recognition
**Basic iii-vi-ii-V (in C):** Em7-Am7-Dm7-G7
**Dominant version:** E7-A7-D7-G7
**With tritone subs:** E7-Eb7-D7-Db7 (chromatic bass descent)
**bII7 for V7:** Db9(13) substitutes for G7(#9/#5) (identical voicings minus roots, p. 455)

# Context & Application
Turnarounds appear at the end of the form in countless jazz standards. They are particularly common in 32-bar AABA forms and 12-bar blues. The chromatic voice leading created by tritone-substituted turnarounds is a hallmark of bebop harmony.

# Common Errors
- **Error**: Applying tritone subs without first converting chords to dominant 7ths
  **Correction**: Tritone substitution requires dominant 7th quality on all chords

# Common Confusions
- **Confusion**: Thinking "turnaround" refers to one specific chord sequence
  **Clarification**: "Turnaround" refers to the function (leading back to the top); multiple chord sequences serve this function
