# Quick Definition

When a triad is in second inversion, always double the fifth (the bass note), and restrict usage to three specific contexts: pedal, passing, and cadential six-four chords.

# Core Definition

When a triad is in second inversion, double the fifth (the bass note). Second-inversion triads are restricted to specific contexts due to the dissonant fourth above the bass (Hutchinson, Ch. 26, p. 397).

# Prerequisites

- **Voice leading** -- Second-inversion voice leading is a specific application
- **Doubling rules triads** -- Second inversion: double the bass (the 5th)

# Key Properties

1. Always double the bass (the 5th of the chord)
2. Restricted to three contexts: pedal 6/4, passing 6/4, cadential 6/4
3. The 4th above the bass is considered dissonant

# Construction / Recognition

## Rule:
1. Identify the second-inversion chord
2. Double the bass note (which is the 5th of the chord)
3. Ensure the chord fits one of the three allowed contexts

# Context & Application

- **Typical contexts**: Specific harmonic situations (pedal, passing, cadential)
- **Historical/stylistic notes**: Random use of 6/4 chords sounds stylistically incorrect in common practice

# Examples

**Example 1** (p. 397): J.S. Bach, Chorale 204, "Wer weiss, wie nahe mir" -- second-inversion triad with doubled bass (5th)

# Common Errors

- **Error**: Using six-four chords freely without a specific context
  **Correction**: Only use in pedal, passing, or cadential contexts

# Common Confusions

- **Confusion**: Thinking you should double the root (as in root position)
  **Clarification**: In second inversion, double the BASS (which is the 5th, not the root)
