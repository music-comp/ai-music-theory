# Quick Definition
In a time signature, the top number tells you "how many" and the bottom number tells you "of what" note value.

# Core Definition
In a time signature, the top number of the time signature tells you "how many" and the bottom number tells you "of what." In simple meter, the top number indicates beats per measure and the bottom number indicates the beat note value. In compound meter, the top number indicates divisions per measure (divide by 3 for the number of beats) and the bottom number indicates the division note value (the beat is a dotted version of that value).

# Prerequisites
(none -- this is a foundational rhythm concept)

# Key Properties
1. Two numbers stacked vertically at the beginning of a piece
2. Top number: "how many" (beats in simple, divisions in compound)
3. Bottom number: "of what" note value (4=quarter, 8=eighth, 2=half)
4. Common time (C symbol) = 4/4
5. Applies until a new time signature appears
6. Simple: top number is 2, 3, or 4; Compound: top number is 6, 9, or 12

# Construction / Recognition
- Top number 2, 3, or 4 = simple meter
- Top number 6, 9, or 12 = compound meter
- Bottom number: 4 = quarter note, 8 = eighth note, 2 = half note

# Context & Application
Time signatures establish the metric framework for a piece, defining how beats are grouped into measures and how rhythms relate to the underlying pulse. They are essential for performers to understand the rhythmic organization of music. The most common time signature in present-day music is 4/4 (also known as "common time").

# Examples
- 4/4: four quarter-note beats per measure (simple quadruple)
- 3/4: three quarter-note beats per measure (simple triple)
- 6/8: six eighth-note divisions per measure, grouped as two dotted-quarter beats (compound duple)
- 2/2: two half-note beats per measure (simple duple)

# Common Errors
- In compound meter, treating the bottom number as the beat (it is the division)
- Assuming 6/8 has six beats (it has two beats, each divided into three)

# Common Confusions
- **Compound bottom number**: In compound meter, the bottom number is NOT the beat; the beat is a dotted note
- **6/8 vs. 3/4**: 6/8 has two beats (compound duple); 3/4 has three beats (simple triple)
- **Persistence**: The time signature applies until a new one appears
