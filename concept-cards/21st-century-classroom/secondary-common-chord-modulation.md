# Quick Definition
In secondary common chord modulation, the pivot chord is a secondary chord (such as a secondary dominant) in both keys -- chromatic in both contexts but providing a functional link between them.

# Core Definition
In a secondary common chord modulation, the pivot chord is a secondary chord in both keys involved in the modulation. This means the pivot is chromatic in both keys, yet it connects them through shared chromatic function. For example, a chord functioning as V7/IV in the first key might simultaneously function as V7 in the second key, creating a pivot that is secondary in one context and primary dominant in another.

# Prerequisites
- **Chromatic pivot chord modulation**: The broader category
- **Secondary dominants**: The chord type most commonly involved

# Key Properties
1. Pivot is a secondary (chromatic) chord in both keys
2. The pivot may be secondary dominant in one key and primary dominant in the other
3. Sometimes secondary in both keys
4. Enables modulation through chromatic common ground
5. More subtle than diatonic pivots

# Construction / Recognition
- Identify a chromatic chord that appears between two key areas
- Analyze it as a secondary chord in the first key
- Re-analyze as a secondary chord (or primary chord) in the second key
- The dual analysis creates the pivot bracket

# Context & Application
Secondary common chord modulation represents a more sophisticated level of pivot technique. The analyst must recognize that the pivot chord is not diatonic in either key but still connects them functionally. This technique appears in Romantic-era music and in any context where closely related key modulation is insufficient.

# Examples
- Schubert, Schwanegesang, D. 957, "Abschied" (1828): a chord functioning as a secondary dominant in both keys serves as the pivot

# Common Confusions
- **Chromatic in both**: The pivot is not diatonic in either key -- it is secondary/chromatic in both
- **V7/x in key 1 = V7 in key 2**: A secondary dominant in one key may be a primary dominant in the other
- **Requires secondary chord knowledge**: Analysis depends on fluency with secondary dominants and diminished chords
