# Quick Definition
Full figured bass symbols show every interval above the bass note -- triads show 5/3, first inversion shows 6/3, seventh chords show 7/5/3, etc. -- whereas modern usage abbreviates these (5/3 becomes nothing, 6/3 becomes 6, 7/5/3 becomes 7).

# Core Definition
Although modern analysis uses abbreviated figured bass symbols, the full (unabbreviated) versions show every interval above the bass note. For triads: root position = 5/3, first inversion = 6/3, second inversion = 6/4. For seventh chords: root position = 7/5/3, first inversion = 6/5/3, second inversion = 6/4/3, third inversion = 6/4/2. The common abbreviated forms used in modern Roman numeral analysis are shorthand versions of these full symbols. These full symbols sometimes appear in Baroque scores containing figured bass.

- **Figured bass**: The basic system
- **Figured bass inversion symbols**: The abbreviated forms used in modern analysis

# Key Properties
1. Full triads: 5/3 (root), 6/3 (1st inv.), 6/4 (2nd inv.)
2. Full seventh chords: 7/5/3 (root), 6/5/3 (1st), 6/4/3 (2nd), 6/4/2 (3rd)
3. Abbreviated: (nothing), 6, 6/4 for triads; 7, 6/5, 4/3, 4/2 for sevenths
4. Full symbols appear in actual Baroque music scores
5. Modern analysis uses only the abbreviated forms
6. Understanding the full forms clarifies why abbreviations work

# Construction / Recognition
- Full 5/3 abbreviates to: (nothing or 5/3) -- root position triad
- Full 6/3 abbreviates to: 6 -- first inversion triad
- Full 6/4 stays as: 6/4 -- second inversion triad (no abbreviation possible)
- Full 7/5/3 abbreviates to: 7 -- root position seventh
- Full 6/5/3 abbreviates to: 6/5 -- first inversion seventh
- Full 6/4/3 abbreviates to: 4/3 -- second inversion seventh
- Full 6/4/2 abbreviates to: 4/2 -- third inversion seventh

# Context & Application
Understanding the full figured bass symbols clarifies why the abbreviated forms work: each abbreviation retains only the numbers that are unique to that inversion. The full symbols are encountered when studying urtext editions of Baroque music or when learning thoroughbass realization at the keyboard. In modern theory courses, only the abbreviated forms are used for Roman numeral analysis.

# Examples
- Root position triad: full = 5/3; abbreviated = (none)
- First inversion seventh: full = 6/5/3; abbreviated = 6/5
- Third inversion seventh: full = 6/4/2; abbreviated = 4/2

# Common Errors
- Confusing full and abbreviated forms in analysis

# Common Confusions
- **Modern = abbreviated only**: In theory class, always use the abbreviated forms
- **Full forms = historical**: Full figured bass appears in Baroque scores, not in Roman numeral analysis
- **Abbreviation logic**: Each abbreviated symbol retains only the intervals unique to that inversion
