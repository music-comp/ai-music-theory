# Quick Definition
Phase shifting is a minimalist technique, associated with Steve Reich, where identical patterns gradually move out of synchronization and eventually realign.

# Core Definition
Steve Reich conceived phase shifting from tape music experiments, noting that tape loops of slightly differing lengths containing the same idea went slowly out of phase and gradually back into phase when repeated. Reich applied this to live performance. Two performers play identical patterns; one gradually speeds up (or shifts by one note), creating new rhythmic and melodic combinations. The process continues until patterns return to unison, having cycled through all possible phase relationships (Hutchinson, Ch. 35, pp. 502-504).

# Prerequisites
- **Minimalism** -- Phase shifting is Reich's primary minimalist technique
- **Rotation** -- Phase shifting is built on the rotation concept

# Key Properties
1. Two identical patterns begin in unison
2. One gradually desynchronizes from the other
3. New rhythmic/melodic combinations emerge at each phase position
4. After cycling through all positions, patterns return to unison
5. Total positions = number of notes in the pattern
6. Two methods: gradual acceleration or discrete shifts

# Construction / Recognition
**Implementation methods:**
1. Gradual acceleration (*Piano Phase*): one player gradually speeds up until one note ahead
2. Discrete shifts (*Clapping Music*): pattern shifts by one note at each measure boundary

**Phase positions:**
- Each rotation of the pattern creates a new phase relationship
- Number of unique positions = number of notes in the pattern

# Context & Application
Reich discovered phasing in tape experiments: *It's Gonna Rain* (1965) and *Come Out* (1966). He applied it to live performance in *Piano Phase* (1967), *Violin Phase* (1967), and *Clapping Music* (1972). The technique also appears in *Three Movements*, II.

# Examples
- Reich, *It's Gonna Rain* (1965): Tape loops of speech going out of phase (p. 503)
- Reich, *Come Out* (1966): Tape phase piece (p. 503)
- Reich, *Piano Phase* (1967): 12-note pattern, gradual acceleration (p. 503, Figure 35.2.2)
- Reich, *Clapping Music* (1972): Pattern shifts one beat per measure (p. 503, Figure 35.2.1)
- Reich, *Three Movements*, II (p. 504, Figure 35.2.5): Orchestral phase shifting

# Common Errors
- **Error**: Thinking phase shifting is random desynchronization
  **Correction**: Phase shifting is a deterministic, systematic process

# Common Confusions
- **Confusion**: Confusing phase shifting with polyrhythm
  **Clarification**: Phase shifting creates polyrhythmic effects but is a process, not a fixed polyrhythm
- **Confusion**: Thinking gradual and discrete shifting produce the same effect
  **Clarification**: Gradual (Piano Phase) creates smooth transitions; discrete (Clapping Music) creates abrupt shifts
