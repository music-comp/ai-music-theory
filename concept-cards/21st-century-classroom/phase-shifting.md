# Quick Definition
Phase shifting is a minimalist technique, associated with Steve Reich, where identical patterns gradually move out of synchronization and eventually realign.

# Formal Definition
Phase shifting is a compositional technique developed by Steve Reich where two identical patterns begin in unison, then one gradually speeds up until it is one note ahead, creating new rhythmic and melodic combinations. The process continues until the patterns are again in unison, having cycled through all possible phase relationships. Reich discovered this technique while working with tape loops of slightly different lengths.

# Construction/Calculation
Phase shifting process:
1. Two performers play identical patterns in unison
2. One performer gradually accelerates (or one pattern is displaced by one note)
3. New rhythmic relationships emerge as patterns desynchronize
4. Each phase position creates different composite rhythms
5. After cycling through all positions, patterns return to unison
6. Total positions = number of notes in the pattern

Implementation methods:
- Gradual acceleration (Piano Phase): one player gradually speeds up
- Discrete shifts (Clapping Music): pattern shifts by one note at measure boundaries

# Musical Context
Reich discovered phase shifting through tape experiments with It's Gonna Rain (1965) and Come Out (1966). He applied the technique to live performance in Piano Phase (1967), Violin Phase (1967), and Clapping Music (1972). The technique creates evolving patterns and resultant melodies from simple source material.

# Examples
- Reich, It's Gonna Rain (1965): Tape loops of speech going out of phase
- Reich, Come Out (1966): Tape phase piece
- Reich, Piano Phase (1967): 12-note pattern, gradual acceleration
- Reich, Clapping Music (1972): Pattern shifts one beat per measure
- Reich, Three Movements, II: Phase shifting in orchestral context

# Common Confusions
- Phase shifting is NOT the same as polyrhythm (though it creates polyrhythmic effects)
- The process is deterministic, not aleatoric
- "Phase" comes from electronic terminology (wave phases)
- Gradual vs. discrete shifting produces different effects
