# Quick Definition
An interval is the distance between two pitches, measured by quality (major, minor, perfect, etc.) and numeric size (2nd, 3rd, 4th, etc.).

# Formal Definition
Intervals are measurements between two pitches, either vertical (harmonic interval, notes sounding simultaneously) or horizontal (melodic interval, notes sounding in succession). Every interval has two components: the numeric size (how many letter names apart) and the quality (perfect, major, minor, augmented, or diminished).

# Construction/Recognition
- Count letter names inclusively: C to E = 1-2-3 = third
- Odd-numbered intervals: line to line, or space to space
- Even-numbered intervals: line to space, or space to line
- Quality determined by half-step content
- Harmonic = vertical (simultaneous); Melodic = horizontal (successive)

# Musical Context
Intervals are the building blocks of scales, chords, and melodies. Understanding intervals is essential for constructing triads, analyzing harmony, and recognizing melodic patterns. Ear training often focuses heavily on interval recognition.

# Examples
- C to E = Major 3rd (M3)
- C to G = Perfect 5th (P5)
- C to Bb = minor 7th (m7)
- Harmonic intervals create chords; melodic intervals create melodies

# Common Confusions
- The numeric size counts BOTH notes (C to E = 1, 2, 3 = third)
- Quality and number are both required for complete interval identification
- Same numeric size can have different qualities (M3, m3, +3)
