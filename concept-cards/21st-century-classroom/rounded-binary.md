# Quick Definition

Rounded binary form features the return of opening material (often shortened) after a contrasting phrase at the beginning of the second section, creating an ABA' structure within a two-section frame.

# Core Definition

In rounded binary form, the material at the beginning of the first section returns, often shortened, after a contrasting phrase at the beginning of the second section. The phrase diagram typically shows: First Section (phrases 1-2) || Second Section: contrasting material (phrase 3), return of opening (phrases 4-5) || (Hutchinson, Ch. 24, p. 349).

# Prerequisites

- **Binary form** -- Rounded binary is a subtype of binary form
- **Sectional vs continuous** -- Rounded binary can be either sectional or continuous

# Key Properties

1. Opening material RETURNS after contrasting material in the second section
2. The return is often abbreviated or varied
3. The second section has TWO parts: contrast followed by return
4. Still classified as binary (two sections) despite internal ABA' shape
5. Can be sectional or continuous
6. Extremely common in Classical era music

# Construction / Recognition

## Phrase Diagram:
```
First Section: a a' (or a b)
Second Section: c (contrasting) | a a' (return, often shortened)
```

## Full Naming Example:
"Two-reprise continuous rounded binary" means:
- Two-reprise: both sections repeat
- Continuous: first section doesn't end on tonic
- Rounded: opening material returns in second section

# Context & Application

- **Typical contexts**: Classical era themes from variations, minuet sections, short character pieces
- **Common applications**: Haydn, Mozart, and Beethoven use rounded binary extensively
- **Historical/stylistic notes**: The return of opening material provides satisfying closure; evolved into larger formal structures including sonata form

# Examples

**Example 1** (pp. 349-350): Mozart, Piano Sonata K. 284, III (Theme) -- two-reprise continuous rounded binary form with clear return of opening material

**Example 2** (pp. 350-351): Schubert, 20 Minuets, D. 41, No. 18 in F major -- two-reprise continuous rounded binary form

## Contrasts With
- **Ternary form** -- Ternary has three independent sections; rounded binary has two with internal return
- **Balanced binary** -- Balanced has similar endings; rounded has return of openings
- **Simple binary** -- Simple lacks the return of opening material

# Common Errors

- **Error**: Labeling a rounded binary as ternary because opening material returns
  **Correction**: Check the proportion and nature of the contrasting section; use the three criteria from Section 24.8

- **Error**: Expecting the return to be exact
  **Correction**: The return is often shortened or varied

# Common Confusions

- **Confusion**: Believing the "rounding" means the piece is circular
  **Clarification**: "Rounded" refers specifically to the return of opening material in the second section

- **Confusion**: Thinking rounded binary must be continuous
  **Clarification**: Rounded binary can be either sectional or continuous
