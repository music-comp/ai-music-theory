# Quick Definition
The subtonic VII chord (bVII) is a major triad built on the lowered seventh scale degree, ubiquitous in rock and popular music, where it can substitute for any harmonic function except tonic.

# Core Definition
The bVII chord can precede tonic, dominant, and pre-dominant chords, meaning it can substitute for any function except tonic. In the expanded harmonic flowchart for popular music, bVII occupies a flexible position, able to progress to I, V, IV, or ii. It is derived from the Mixolydian mode or mode mixture and creates a characteristic "rock" sound.

# Key Properties
1. Major triad built on lowered scale degree 7
2. Can substitute for dominant, pre-dominant, or tonic prolongation function
3. Cannot function as tonic
4. Common progressions: bVII-IV-I, bVII-I, bVII-V
5. Related to Mixolydian mode and mode mixture
6. Ubiquitous in rock and popular music

# Construction / Recognition
1. Identify the major triad a whole step below the tonic
2. Determine its function based on what chord follows
3. bVII to I suggests dominant or tonic prolongation function
4. bVII to IV suggests pre-dominant function
5. bVII to V suggests pre-dominant function

# Context & Application
The bVII chord enables progressions not found in common-practice classical music and is one of the defining harmonic features of rock music. The IV-I motion that often follows bVII raises interesting questions about whether IV has dominant function in popular music.

# Examples
- Beatles, "Hey Jude" (1968) -- bVII-IV-I ending
- U2, "Desire" (1988) -- bVII begins phrase, proceeds to IV-I
- "Don't You (Forget About Me)" (1985) -- bVII precedes and follows IV
- Steely Dan, "Reelin' in the Years" -- bVII cadences to I, then to vi (deceptive)

# Common Errors
- Confusing bVII (major triad on lowered 7) with viio (diminished triad on natural 7)
- Assigning a single fixed function to bVII (its function depends on context)

# Common Confusions
- **bVII is not viio**: The subtonic is a major triad; the leading-tone chord is diminished
- **Function depends on context**: bVII's function is determined by what chord follows
- **IV-I question**: When bVII-IV-I occurs, consider whether IV has dominant function in popular music
