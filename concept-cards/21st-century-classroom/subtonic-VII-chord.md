# Quick Definition
The subtonic VII chord (bVII) is a major triad built on the lowered seventh scale degree, commonly used in rock and popular music where it can substitute for dominant, pre-dominant, or tonic prolongation functions.

# Formal Definition
The bVII chord can precede tonic, dominant, and pre-dominant chords, meaning it can substitute for any function except tonic. In the harmonic flowchart for popular music, bVII occupies a flexible position, able to progress to I, V, IV, or ii.

# Analysis/Application
When analyzing bVII:
1. Determine its function based on what chord follows it
2. bVII to I suggests dominant or tonic prolongation function
3. bVII to IV suggests pre-dominant function
4. bVII to V suggests pre-dominant function
5. Note the connection to the Mixolydian mode

# Musical Context
The bVII chord is ubiquitous in rock and popular music, derived from the Mixolydian mode or mode mixture. It creates a characteristic "rock" sound and enables progressions not found in common-practice classical music.

# Examples
- Lennon-McCartney, "Hey Jude" (1968) - bVII-IV-I ending
- U2, "Desire" (1988) - bVII begins phrase, proceeds to IV-I
- "Don't You (Forget About Me)" (1985) - bVII precedes and follows IV
- Steely Dan, "Reelin' in the Years" - bVII cadences to I, then to vi (deceptive)

# Related Concepts
- Mode mixture
- Mixolydian mode
- Plagal cadence (IV-I)

# Common Confusions
- bVII is different from vii° (diminished) - the subtonic is a major triad
- The function of bVII depends on context and resolution
- When bVII goes to IV and IV goes to I, consider whether IV has dominant function
