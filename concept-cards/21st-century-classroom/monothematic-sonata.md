# Quick Definition

A monothematic sonata uses the primary theme (or material derived from it) in place of a contrasting secondary theme, emphasizing tonal design over thematic contrast.

# Core Definition

Haydn was especially fond of restating the Primary Theme in the dominant where the Secondary Theme would normally occur. This monothematic approach reinforces the idea that the tonal design of a sonata was as important as thematic design (Hutchinson, Ch. 25, p. 369).

# Prerequisites

- **Sonata form** -- Monothematic sonata is a variant of sonata form
- **Sonata principle** -- The monothematic approach highlights the primacy of tonal design

# Key Properties

1. Primary theme appears in both tonic and secondary key areas
2. The key change provides the contrast, not thematic material
3. Transition and closing sections provide variety
4. Reinforces that sonata form is fundamentally about tonal drama

# Construction / Recognition

## Structure:
- Exposition: PT in I, "ST" area uses PT material in V
- Recapitulation: PT in I, "ST" area uses PT material in I

## To Identify:
1. Note when the expected secondary theme uses material from the primary theme
2. The secondary key area exists TONALLY even without new thematic material

# Context & Application

- **Typical contexts**: Particularly associated with Haydn
- **Historical/stylistic notes**: Demonstrates that sonata form is fundamentally about tonal journey, not thematic contrast

# Examples

**Example 1**: Many Haydn piano sonatas and symphonies use the monothematic approach

# Common Errors

- **Error**: Assuming a monothematic sonata is not really in sonata form
  **Correction**: It is a fully valid sonata form; the "secondary theme area" is defined by KEY, not theme

# Common Confusions

- **Confusion**: Thinking monothematic means "no contrast"
  **Clarification**: KEY provides the contrast even when the same theme is used

- **Confusion**: Viewing the monothematic approach as a deficiency
  **Clarification**: It is a deliberate compositional choice that foregrounds tonal drama
