# Quick Definition
A slash chord places the chord symbol before a slash (/) and the bass note after it: C/E means a C major triad with E as the lowest note.

# Core Definition
In lead-sheet notation, an inverted chord has the triad before the slash (/) and the bass note after it. "C/E" means a C triad with an E as the lowest note. Therefore, a slash chord has a bass note that is not the root of the chord. In fact, it is possible to have slash chords where the bass note is not one of the chord tones (e.g., C/F#). The first letter always represents the root of the chord; the letter after the slash is the lowest note (the bass).

# Prerequisites
- **Triad inversions**: Understanding that different notes can be in the bass
- **Lead-sheet symbols**: The notation system that slash chords extend

# Key Properties
1. Format: Chord/Bass (e.g., C/E, Dm/A)
2. First letter = chord root
3. Letter after slash = bass note (lowest note)
4. Can indicate standard inversions: C/E = first inversion, C/G = second inversion
5. Can have non-chord tone in bass: C/F# has F# not in the C triad
6. The chord symbol before the slash is always the complete chord identity

# Construction / Recognition
- Read the chord symbol before the slash for root and quality
- Read the note after the slash for the bass note
- Determine if the bass note is a chord tone (standard inversion) or not

# Context & Application
Slash chords are essential for specifying bass notes in lead sheets and chord charts. They allow precise bass line notation while maintaining the flexibility of chord symbols. Common uses include inversions, pedal tones, and descending bass lines.

# Examples
- C/E = C major with E in bass (first inversion)
- C/G = C major with G in bass (second inversion)
- Dm/A = D minor with A in bass (second inversion)
- Go/Db = G diminished with Db in bass (second inversion)
- C/F# = C major over F# bass (non-chord tone in bass)

# Common Errors
- Reading the letter after the slash as another chord (it is a single bass note)
- Forgetting that the first symbol is always the chord, not the key

# Common Confusions
- **Bass note, not a second chord**: The letter after the slash is a single bass note, not another chord
- **Non-chord-tone bass possible**: Slash chords can specify bass notes that are not part of the chord (e.g., C/F#)
- **Root is always before the slash**: The first letter is always the chord root
