# Quick Definition

First-inversion triads require doubling the root or fifth (NOT the bass/3rd), with three exceptions: diminished triads in first inversion always double the bass, consecutive first inversions alternate doubled/undoubled bass, and the 3rd may be doubled when approached by contrary motion.

# Core Definition

Instead of focusing on bass intervals, voice leading first-inversion triads requires focusing on the doubling of the chord. Do NOT double the bass note (the 3rd) in first-inversion triads. Instead, double the root or fifth, depending on which can be approached and left most smoothly (Hutchinson, Ch. 26, pp. 394-397).

# Prerequisites

- **Voice leading** -- First-inversion voice leading extends root-position techniques
- **Doubling rules triads** -- The general principle for first inversion is "do NOT double the bass"

# Key Properties

1. Default: double the root or fifth, NOT the bass (3rd)
2. Exception 1: Diminished triads in first inversion -- ALWAYS double the 3rd (bass)
3. Exception 2: Consecutive first inversions -- alternate between doubling and not doubling the 3rd
4. Exception 3: 3rd may be doubled when approached by contrary motion in both parts
5. NEVER double the 3rd of the V chord (it is the leading tone)
6. Move as smoothly as possible while avoiding parallels, spacing errors, and melodic errors

# Construction / Recognition

## Procedure:
1. Determine the chord and inversion
2. If diminished triad in first inversion: double the bass (3rd)
3. If consecutive first inversions: alternate doubling the 3rd
4. Otherwise: double the root or fifth (whichever is smoother)
5. Move all voices smoothly to avoid parallels

# Context & Application

- **Typical contexts**: Creating smoother bass lines by using first inversions
- **Historical/stylistic notes**: Bach chorale examples demonstrate all three exceptions

# Examples

**Example 1** (p. 395): J.S. Bach, Chorale 237, "Gott lebet noch" -- first-inversion voice leading with root or fifth doubled

**Example 2** (p. 396): J.S. Bach, Chorale 103, "Nun ruhen alle Walder" -- diminished triad in first inversion with doubled 3rd (bass)

**Example 3** (p. 396): J.S. Bach, Chorale 106, "Jesu Leiden, Pein und Tod" -- consecutive first inversions with alternating doubling

**Example 4** (p. 397): Palestrina, *Missa Aeterna Christi Munera*, Sanctus -- 3rd doubled when approached by contrary motion

# Common Errors

- **Error**: Doubling the bass of the V chord in first inversion
  **Correction**: Never double the 3rd of V because it is the leading tone (^7)

- **Error**: Automatically avoiding all doubled 3rds
  **Correction**: Diminished triads and consecutive first inversions are legitimate exceptions

# Common Confusions

- **Confusion**: The "don't double the bass" rule applies to all inversions
  **Clarification**: It applies specifically to first inversion; root position and second inversion DO double the bass
