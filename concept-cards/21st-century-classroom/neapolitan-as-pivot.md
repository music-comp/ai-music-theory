# Quick Definition
The Neapolitan chord can serve as a pivot chord in modulation, bridging the gap between distantly related keys -- including keys a tritone apart -- by functioning as N in one key and V (or another chord) in the new key.

# Core Definition
A particularly adventurous and imaginative pivot is the Neapolitan, which can bridge the tonal distance between two foreign (distantly related) keys. Because the Neapolitan is a major triad built on b2, it can be reinterpreted as a dominant chord or other function in a key that is distantly related to the original. The Neapolitan may sometimes appear with dominant-seventh quality, facilitating its reinterpretation as V7 in the new key.

# Prerequisites
- **Neapolitan chord**: The chord being repurposed as pivot
- **Chromatic pivot chord modulation**: The broader modulatory technique

# Key Properties
1. Neapolitan in first key = functional chord in second key
2. Can bridge keys a tritone apart (maximum tonal distance)
3. The Neapolitan may have dominant-seventh quality (N7)
4. Common reinterpretation: N6/5 in key 1 = V6/5 in key 2
5. Part of Romantic era expansion of modulatory techniques
6. The pivot may need enharmonic respelling in the new key

# Construction / Recognition
- Identify the Neapolitan in the first key (N or N6)
- Reinterpret the same pitches as a functional chord in the new key
- Common pivot: N with added seventh = V7 in new key
- The new key will often be a tritone away from the original
- Use a pivot bracket to show dual analysis

# Context & Application
The Neapolitan pivot enables modulation to keys that cannot be reached by diatonic pivot chords. It is especially effective for dramatic modulations in Romantic-era music and demonstrates the imaginative reinterpretation of chromatic harmony. The tritone relationship (maximum tonal distance) creates a particularly striking modulatory effect.

# Examples
- Schubert, Schwanegesang, D. 957, "Fruhlingssehnsucht" (1828):
  - Modulates from D minor to Ab minor (tritone relation)
  - N6/5 (with dominant-seventh quality) in D minor becomes V6/5 in Ab minor
  - Bridges the maximum tonal distance (tritone)

# Common Errors
- Expecting the Neapolitan pivot only for closely related keys (it is specifically for distant ones)
- Not recognizing the dominant-seventh form of the Neapolitan (N7)

# Common Confusions
- **Distant keys**: The Neapolitan pivot is specifically for DISTANT modulations, not closely related keys
- **Enharmonic respelling**: The Neapolitan may need to be respelled in the new key
- **N7 form**: The Neapolitan with an added seventh facilitates reinterpretation as V7
