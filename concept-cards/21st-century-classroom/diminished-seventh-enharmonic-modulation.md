# Quick Definition
Each fully diminished seventh chord can resolve to four different keys by treating any of its four notes as the leading tone (scale degree 7), or by resolving any note down to the root of a dominant seventh -- enabling modulation to four equidistant keys a minor third apart.

# Core Definition
Each diminished seventh sonority implies four different keys because each note can be treated as scale degree 7 (leading tone), resolving up by half step to the tonic of a new key. Additionally, each note can function as the 7th of the chord, moving down by half step to the root of a dominant seventh chord. This means any diminished seventh chord can pivot to four equidistant keys (a minor third apart). The analyst must imagine the alternative spellings, like imagining other spellings of homophones (two/to/too, there/their/they're).

# Prerequisites
- **Enharmonic modulation**: The broader concept
- **Fully diminished seventh chord**: The symmetrical structure being exploited
- **Diminished seventh symmetry**: The equal-interval structure enabling four resolutions

# Key Properties
1. Each note as leading tone (7): resolves up m2 to four different tonics
2. Each note as chord 7th: resolves down m2 to root of V7 (in four keys)
3. Four possible resolutions = four possible keys
4. The four keys are equidistant (minor thirds apart)
5. Only three unique diminished seventh sonorities exist
6. The spelling on the page determines which resolution is intended
7. Diminished triads are NOT tonicized (only major/minor chords can be targets)

# Construction / Recognition
For the sonority G#-B-D-F:
- G# as 7: resolves up to A (minor or major)
- B as 7: resolves up to C (minor or major)
- D as 7: resolves up to Eb (minor or major)
- F (respelled E#) as 7: resolves up to F# (minor or major)

Each note resolving down as chord 7th:
- G# down to G: creates V7 in C
- B down to Bb: creates V7 in Eb
- D down to Db: creates V7 in Gb
- F down to E: creates V7 in A

# Context & Application
Diminished seventh enharmonic modulation enables rapid modulation to distant keys. The symmetry of the chord (all minor thirds) means all four resolutions are equally valid theoretically; context and the actual resolution determine the analysis. Beethoven and Schubert used this technique extensively. Because the chord is inherently ambiguous, the analyst must examine where the chord actually goes to determine the correct spelling and interpretation.

# Examples
- Beethoven, Pathetique Sonata, Op. 13, I (1798): F#o7/C in G minor (viio4/3) reinterpreted as D#o7/C (viio4/2 in E minor), resolves to V7 in E minor
- Beethoven, Symphony No. 5, II (1808): Eo7 in C (viio7/IV) reinterpreted as viio4/2 in Ab (Go7/Fb), unusual resolution to Ger+6
- Schubert, Schwanegesang, "Der Atlas" (1828): G#o7 in G minor reinterpreted as E#o7 (viio6/5/V) in B minor

# Common Errors
- Not visualizing the enharmonic respelling
- Attempting to tonicize diminished triads with the respelled chord

# Common Confusions
- **Four possibilities, one realization**: Context and resolution determine which interpretation applies
- **Diminished triads excluded**: The respelled chord cannot resolve to a diminished triad
- **Visualize the respelling**: The alternative spellings are never written -- you must envision them
