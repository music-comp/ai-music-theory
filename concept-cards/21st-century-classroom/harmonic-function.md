# Quick Definition
Harmonic function describes the tendency of chords to progress to other chords or remain at rest, categorizing chords by their role in creating harmonic motion toward or away from the tonic.

# Formal Definition
Harmonic function refers to the tendency of certain chords to progress to other chords, or to remain at rest. There are four harmonic functions: (1) Tonic function - state of stability and rest; (2) Dominant function - tendency to progress to tonic; (3) Pre-dominant function - tendency to progress to dominant; (4) Tonic prolongation function - tendency to occur after tonic and progress to pre-dominant.

# Analysis/Application
When analyzing harmonic progressions, label each chord's function using abbreviations:
- "ton." for tonic function
- "dom." for dominant function
- "pre-dom." for pre-dominant function
- "ton. prol." for tonic prolongation function

# Musical Context
Harmonic function underlies most tonal progressions from the Baroque era through contemporary popular music. Understanding function explains why certain chord progressions feel natural and others feel unusual.

# Examples
- I chord has tonic function
- V and vii° have dominant function (contain ^7 and ^2)
- IV and ii have pre-dominant function (contain ^4 and ^6)
- vi and iii have tonic prolongation function (share two common tones with I)
- I/5th has dominant function when resolving to V (as in "The Star-Spangled Banner")

# Common Confusions
- IV has tonic prolongation function (not pre-dominant) when it progresses to I in a plagal cadence
- The term "dominant" in dominant function refers to progression toward tonic, not specifically the V chord
- vii° has dominant function even though it is not the V chord
