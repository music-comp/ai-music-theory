# Quick Definition
Enharmonic notes are pitches that sound the same but are written with different note names, such as C# and Db.

# Formal Definition
Two notes are enharmonically equivalent when they sound identical (have the same pitch frequency) but are notated differently. This occurs because the same key on a piano or the same pitch can be named using different letter names with appropriate accidentals.

# Construction/Recognition
- Black keys on piano have two common names: C#=Db, D#=Eb, F#=Gb, G#=Ab, A#=Bb
- White keys can also be spelled enharmonically: C=B#, E=Fb, F=E#, B=Cb
- Double sharps and flats create additional enharmonic possibilities: D=C##, D=Ebb

# Musical Context
Enharmonic spelling is chosen based on musical context, key signature, and voice leading conventions. The choice of spelling affects how a note functions harmonically even though it sounds the same.

# Examples
- C# and Db are enharmonic (same key on piano, different notation)
- E and Fb are enharmonic
- G and F## (F double sharp) are enharmonic
- B and Cb are enharmonic

# Common Confusions
- Enharmonic notes sound the same but have different musical functions
- The context (key, chord, voice leading) determines the correct spelling
- All notes can be spelled enharmonically, not just black keys
