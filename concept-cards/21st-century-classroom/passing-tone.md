# Quick Definition
A passing tone is a non-chord tone approached by step and left by step in the same direction, filling in the space between two chord tones.

# Core Definition
Passing tones are notes that pass between chord tones. They are approached by step and left by step in the same direction (either ascending or descending). Passing tones can be accented (on the beat) or unaccented (off the beat), and diatonic or chromatic. There can be two consecutive diatonic passing tones in a descending scale segment from the root to the fifth of a chord.

# Prerequisites
- **Non-chord tones overview**: Understanding the classification system

# Key Properties
1. Approached by step, left by step in the same direction
2. Can be accented or unaccented
3. Can be diatonic or chromatic
4. Two consecutive passing tones possible (filling root to fifth)
5. Among the most common non-chord tones

# Construction / Recognition
1. Look for notes moving stepwise between two chord tones
2. Confirm approach and departure are in the same direction
3. Label as PT; add qualifiers (accented, chromatic)
4. Check for consecutive passing tones spanning larger intervals

# Context & Application
Passing tones create smooth melodic connections between chord tones. They are among the most common non-chord tones across all styles. Chromatic passing tones add chromaticism without implying a chord change.

# Examples
- "Want to Want Me" (2015) -- unaccented PT in bar 1, accented PT in bar 3
- "As Time Goes By" (1931) -- two consecutive diatonic PTs descending from root to fifth
- Thelonious Monk, "Blue Monk" (1954) -- chromatic passing tones

# Common Errors
- Confusing passing tones with neighbor tones (PTs continue; NTs return)
- Missing accented passing tones on strong beats

# Common Confusions
- **Two consecutive PTs**: Can fill in a larger interval like root to fifth
- **Accented PTs**: Occur on the beat and can be quite expressive
- **Chromatic PTs**: Add chromaticism without implying a key change
