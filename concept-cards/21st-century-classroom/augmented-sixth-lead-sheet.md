# Quick Definition
In lead-sheet notation, augmented sixth chords are analyzed as dominant seventh chords built on b6, reflecting their sonic quality rather than their classical spelling -- creating a fundamental disagreement between classical analysis (showing resolution) and lead-sheet analysis (showing sound).

# Core Definition
When using lead-sheet symbols for augmented sixth chords, they are treated as major-minor seventh chords (dominant seventh quality) built on b6, since that matches the sonic quality and is similar to how they occur in jazz and popular music. This creates a disagreement between "classical" analysis and lead-sheet analysis: classical spelling shows the direction of resolution (with #4), necessitating special labels (It+6, Fr+6, Ger+6), while lead-sheet analysis shows root, quality, and inversion, treating the chord as a dominant 7th with a "misspelled" 7th.

# Key Properties
1. All augmented sixth chords are analyzed as Mm7 on b6 in lead-sheet
2. Classical: Ab-C-Eb-F# (Ger+6); Lead-sheet: Ab7 (Ab-C-Eb-Gb)
3. Classical spelling shows resolution direction (#4 resolves up)
4. Lead-sheet spelling shows sonic quality (dominant 7th)
5. The "misspelled 7th" (F# instead of Gb) is the crux of the disagreement
6. Both systems describe the same sound

# Construction / Recognition
- In lead-sheet: treat augmented sixth chords as dominant 7th on b6
- Ger+6 in C: classical = Ab-C-Eb-F#; lead-sheet = Ab7
- Fr+6: analyzed as an altered chord in lead-sheet
- It+6: analyzed as incomplete dominant 7th (no 5th) in lead-sheet
- Jazz examples: VI7 in minor, bVI7 in major

# Context & Application
Understanding both analytical traditions is essential for musicians who work across genres. Jazz musicians read Ab7; classical analysts see Ger+6. The same chord progression (e.g., Am-F7-E) is labeled i-Ger+6-V in classical analysis and i-bVI7-V in lead-sheet/jazz analysis. Neither system is "wrong" -- they prioritize different information: function/resolution vs. sonic quality.

# Examples
- John Coltrane, "Mr. P.C." (1959) -- VI7 (lead-sheet) = Ger+6 (classical)
- Henry Mancini, "Pink Panther Theme" (1963) -- VI7
- Fiona Apple, "Criminal" (1996) -- F7 in A minor

# Common Errors
- Insisting on one system when the other is contextually appropriate
- Not recognizing the same chord in both analytical traditions

# Common Confusions
- **Neither is wrong**: Classical shows function/resolution; lead-sheet shows sound/quality
- **Same chord, different lens**: Ab-C-Eb-F# (classical) = Ab-C-Eb-Gb (lead-sheet) = same sound
- **Context determines system**: Use classical labels in tonal analysis; lead-sheet in jazz/pop
