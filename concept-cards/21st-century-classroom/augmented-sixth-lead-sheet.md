# Quick Definition
In lead-sheet notation, augmented sixth chords are analyzed as major-minor seventh chords built on flat-6, reflecting their sound rather than their classical spelling and resolution.

# Formal Definition
When using lead-sheet symbols for augmented sixth chords, they are treated as major-minor seventh chords (dominant seventh quality) built on flat-6, matching the sonic quality and resembling their spelling in jazz and popular music. This creates a disagreement between classical analysis (which shows resolution direction) and lead-sheet analysis (which shows root, quality, and inversion).

# Construction/Recognition
Classical spelling vs. Lead-sheet spelling (in C major/minor):
- Ger+6: Ab-C-Eb-F# (classical) = Ab7 (lead-sheet)
- Fr+6: Ab-C-D-F# = analyzed as altered Ab chord
- It+6: Ab-C-F# = Ab with no 5th, raised 7th

The fundamental difference:
- Classical: Shows chromatic alterations and resolution direction (sharp-4)
- Lead-sheet: Shows sonic quality (treats sharp-4 as flatted 7th)

# Musical Context
- Jazz and popular music typically use lead-sheet spelling
- Classical analysis preserves the voice-leading function
- Both systems describe the same sound differently
- Understanding both is essential for cross-genre analysis

# Examples
In A minor:
- Classical: Ger+6 (F-A-C-D#)
- Lead-sheet: F7
- Same sound, different analytical perspective

Jazz examples using lead-sheet notation:
- John Coltrane, "Mr. P.C." - VI7
- Henry Mancini, "Pink Panther Theme" - VI7
- Fiona Apple, "Criminal" - F7 in A minor

# Common Confusions
- The chord SOUNDS like a dominant 7th but FUNCTIONS as pre-dominant in classical contexts
- Lead-sheet analysis prioritizes sound; classical analysis prioritizes function
- The "misspelled 7th" (F# instead of Gb) distinguishes classical from lead-sheet spelling
- You may need to use both systems depending on the musical context
