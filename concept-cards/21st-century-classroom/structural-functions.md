# Quick Definition
The four structural functions (expository, transitional, developmental, terminative) describe the character and purpose of musical passages based on stability, melodic clarity, and tonal behavior.

# Formal Definition
In A Practical Approach to the Study of Form in Music, Peter Spencer and Peter Temko enumerate four structural functions: expository (stable tonal center, clear melodies), transitional (moving between tonal centers), developmental (sequences, fragmentation, modulation), and terminative (affirming tonal center through I-V alternation).

# Construction/Recognition
1. EXPOSITORY FUNCTION:
   - Stable tonal center
   - Clear, well-defined melodies
   - Regular phrase structure
   - Examples: Primary theme, Secondary theme

2. TRANSITIONAL FUNCTION:
   - Moves from one key to another
   - More rhythmically active
   - May include tonicizations
   - Often ends with half cadence and rest (Mozart, Haydn)

3. DEVELOPMENTAL FUNCTION:
   - Sequences and fragmentation
   - Modulates through multiple keys
   - Irregular phrase lengths, elisions
   - Longer and more varied than transitions

4. TERMINATIVE FUNCTION:
   - Emphatic I-V alternation
   - Affirms tonal center
   - Closing theme has this function
   - Creates sense of conclusion

# Musical Context
- These functions apply across all forms
- Recognizing function aids formal analysis
- Cadences demarcate between functions
- Listening for these qualities aids aural analysis

# Examples
- Mozart, Piano Sonata K. 333, I: clear secondary theme = expository
- Haydn, Piano Sonata Hob. XVI:35, I: transition with half cadence = transitional
- Mozart, Symphony No. 41, K. 551, I: closing theme = terminative
- Beethoven, Moonlight Sonata, III: closing theme with I-V alternation = terminative

# Common Confusions
- Developmental function is longer than transitional
- Both transitional and developmental involve key change
- Terminative is not just "ending" but I-V emphasis
- Multiple functions can occur within one section
