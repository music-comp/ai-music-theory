# Quick Definition

The four structural functions -- expository, transitional, developmental, and terminative -- describe the character and purpose of musical passages based on their stability, melodic clarity, and tonal behavior.

# Core Definition

In *A Practical Approach to the Study of Form in Music*, Peter Spencer and Peter Temko enumerate four structural functions: (1) expository function -- stable tonal center, clear melodies, well-defined phrases; (2) transitional function -- moves from one key to another, rhythmically active; (3) developmental function -- sequences, fragmentation, multiple modulations, irregular phrases; (4) terminative function -- emphatic I-V alternation affirming a tonal center (Hutchinson, Ch. 25, pp. 369-375).

# Prerequisites

- **Sonata form** -- The four functions map directly onto sonata form sections
- **Cadence** -- Cadences are important demarcations between functions
- **Modulation** -- Transitional and developmental functions involve key change

# Key Properties

1. Expository: stable key, clear melodies, regular phrases
2. Transitional: moves between keys, more rhythmically active, may include tonicizations
3. Developmental: sequences, fragmentation, multiple modulations, irregular phrases, elisions
4. Terminative: emphatic I-V alternation, affirms tonal center
5. These functions apply across all forms, not just sonata form
6. Cadences demarcate boundaries between functions

# Construction / Recognition

## To Identify Structural Function:
1. **Expository**: Is the key stable? Is the melody clear with regular phrases? --> Expository
2. **Transitional**: Is the music moving from one key to another? Is it more active? --> Transitional
3. **Developmental**: Are there sequences, fragmentation, multiple key changes? --> Developmental
4. **Terminative**: Is there emphatic I-V alternation to confirm a key? --> Terminative

## Distinguishing Transitional from Developmental:
- Transitions are typically shorter
- Developments have more sections of varying nature
- Developments have a greater number of modulations

# Context & Application

- **Typical contexts**: Applied to all forms, but especially useful in analyzing sonata form
- **Common applications**: PT = expository, Transition = transitional, Development = developmental, CT = terminative
- **Historical/stylistic notes**: Mozart and Haydn often ended transitions with a half cadence followed by a rest

# Examples

**Example 1** (pp. 369-370): Mozart, Piano Sonata K. 333, I -- secondary theme demonstrates expository function (clear melody, stable key, parallel double period ending with PAC)

**Example 2** (pp. 370-373): Haydn, Piano Sonata Hob. XVI:35, I and Mozart, Piano Sonata K. 284, I -- transitions demonstrate transitional function (modulating, rhythmically active, ending with HC)

**Example 3** (pp. 374-375): Mozart, Symphony No. 41, K. 551, I -- closing theme demonstrates terminative function; Beethoven, *Moonlight Sonata*, Op. 27, No. 2, III -- closing theme with emphatic I-V alternation

# Common Errors

- **Error**: Confusing transitional and developmental function
  **Correction**: Development is longer, explores more keys, and has more varied sections

# Common Confusions

- **Confusion**: Thinking terminative function simply means "ending"
  **Clarification**: Terminative function specifically involves emphatic I-V alternation, not just any ending

- **Confusion**: Assuming each section has exactly one function
  **Clarification**: Multiple functions can occur within one section
