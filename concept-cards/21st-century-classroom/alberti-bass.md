# Quick Definition
Alberti bass is an arpeggiated accompaniment pattern following a specific "low-high-middle-high" sequence, characteristic of Classical-era keyboard music.

# Core Definition
Alberti bass accompaniment patterns involve arpeggios that do not arpeggiate chords in simple upward or downward motion, but in a specific "low-high-middle-high" pattern. Named after Domenico Alberti (1710-1746), this pattern creates constant eighth-note or sixteenth-note motion while outlining the harmony.

# Prerequisites
- **Arpeggiated accompaniment**: Understanding of broken-chord patterns

# Key Properties
1. Specific pattern: low-high-middle-high
2. Not a simple ascending or descending arpeggio
3. Creates constant rhythmic motion
4. Named after Domenico Alberti
5. Characteristic of Classical-era piano music (Mozart, Haydn)
6. Can appear in any register, not just bass

# Construction / Recognition
1. Identify the low-high-middle-high pattern
2. Low = bass note of chord; high = top note; middle = middle note
3. Pattern repeats for each chord change
4. Creates constant motion even when harmony is static

# Context & Application
The Alberti bass is characteristic of Classical-era piano music, especially Mozart and Haydn. It provides rhythmic drive and harmonic clarity. The same pattern can be used in any register and has been adapted in other genres.

# Examples
- Mozart, Piano Sonata K. 545, I (1788) -- classic Alberti bass
- "Pipeline" (1962) -- Alberti pattern transposed to E minor in lower register

# Common Errors
- Calling any broken-chord pattern "Alberti bass" (it must be low-high-middle-high)

# Common Confusions
- **Specifically low-high-middle-high**: Not just any arpeggio pattern
- **Can appear in any register**: Not limited to the bass clef
- **Named after Domenico Alberti**: Italian composer, 1710-1746
