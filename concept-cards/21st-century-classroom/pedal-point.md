# Quick Definition
A pedal point is a sustained or repeated note held through changing harmonies, starting as a chord tone before becoming a non-chord tone.

# Formal Definition
A pedal point is a note that is held through changing harmonies, starting as a chord tone before becoming a non-chord tone. It is approached by same note and left by same note. The term "pedal" relates to the foot pedals on an organ, where bass pedal points originated.

# Analysis/Application
To identify pedal points:
1. Look for a sustained or repeated note, typically in the bass
2. Harmonies change above (or around) this note
3. The pedal begins as a consonance and becomes a dissonance
4. Label as Ped. or indicate which note is the pedal

# Musical Context
Pedal points are common in Baroque music (especially organ works), Romantic music, and continue into contemporary styles. They create tension as harmonies move around a static bass, then release when the pedal becomes consonant again.

# Examples
- J.S. Bach, Well-Tempered Clavier, Book I, Prelude 1 in C major BWV 846 (1722) - C pedal in bass
- Clara Schumann, Op. 13, No. 2, "Sie liebten sich beide" (1844) - pedal point with suspensions

# Common Confusions
- When a pedal point is in the bass, do not specify chord inversions - the pedal obscures the true bass
- Pedal points can occur in upper voices too, not just bass
- Double pedal point: two notes (often a fifth apart) act as pedals simultaneously
