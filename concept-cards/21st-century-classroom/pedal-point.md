# Quick Definition
A pedal point is a sustained or repeated note held through changing harmonies, starting as a chord tone before becoming a non-chord tone. The term derives from organ foot pedals.

# Core Definition
A pedal point is a note that is held through changing harmonies, starting as a chord tone before becoming a non-chord tone. It is approached by same note and left by same note. The term "pedal" relates to the foot pedals on an organ, where bass pedal points originated. Pedal points are most often in the bass voice but can occur in upper voices as well. A "double pedal point" has two notes (often a fifth apart) acting as pedals simultaneously.

# Key Properties
1. Approached by same note, left by same note
2. Starts as consonant (chord tone), becomes dissonant (NCT) as harmony changes
3. Most often in the bass voice
4. Can occur in upper voices too
5. Double pedal: two notes (often a fifth apart) as simultaneous pedals
6. Named after organ foot pedals
7. Do not specify chord inversions when bass pedal is present (it obscures inversion)

# Construction / Recognition
1. Look for a sustained or repeated note, typically in the bass
2. Harmonies change above (or around) this note
3. The pedal begins as consonant and alternates between consonance and dissonance
4. Label as Ped. and indicate which note

# Context & Application
Pedal points are common in Baroque organ music, Romantic music, and contemporary styles. They create tension as harmonies move around a static note, then release when the pedal becomes consonant again. Tonic and dominant pedals are most common.

# Examples
- J.S. Bach, Well-Tempered Clavier, Book I, Prelude 1 in C major BWV 846 (1722) -- C pedal in bass
- Clara Schumann, Op. 13, No. 2, "Sie liebten sich beide" (1844) -- pedal point with suspensions above

# Common Errors
- Specifying chord inversions over a bass pedal (the pedal obscures the true bass)
- Analyzing the pedal as the root of each chord

# Common Confusions
- **Do not label inversions**: When a bass pedal is present, do not specify chord inversions
- **Can be in upper voices**: Not only in the bass
- **Double pedal**: Two simultaneous pedal notes, often a fifth apart
