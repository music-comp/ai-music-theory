# Quick Definition
Z-relations occur when two different prime forms share the same interval vector; "Z" stands for "zygotic" (twinned).

# Core Definition
"Z" in a set label (e.g., 4-Z29) stands for "zygotic" ("twinned") and is used when different prime forms have the same interval vector. For example, 4-Z29 (0137) and 4-Z15 (0146) both have interval vector 111111. Z-related sets cannot be related by transposition or inversion yet contain the same distribution of interval classes (Hutchinson, Ch. 33, p. 485).

# Prerequisites
- **Interval vector** -- Z-relations defined by shared vectors
- **Forte numbers** -- Z appears in the Forte number

# Key Properties
1. Different prime forms with identical interval vectors
2. "Z" = "zygotic" (twinned)
3. Not related by transposition or inversion
4. Always occur in pairs
5. Similar sonic qualities despite different structures

# Construction / Recognition
- Compare interval vectors of different prime forms
- If identical vectors but different prime forms: Z-related

# Examples
- 4-Z15 (0146) and 4-Z29 (0137): both vector 111111 (p. 485)
- These "all-interval tetrachords" are the most famous Z-pair

# Relationships
## Related
- **Set class** -- Z-related sets are in different set classes despite same vector
- **Interval vector** -- Z-relations defined by shared vectors

# Common Errors
- **Error**: Assuming Z-related sets are related by transposition or inversion
  **Correction**: They are NOT -- that would make them the same set class

# Common Confusions
- **Confusion**: Thinking "Z" is a mathematical variable
  **Clarification**: Z stands for "zygotic" (twinned)
