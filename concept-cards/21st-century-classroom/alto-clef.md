# Quick Definition
The alto clef is a C clef that places middle C (C4) on the middle line of the staff, used primarily by violas.

# Core Definition
The alto clef is one of the two commonly used C clefs. When placed on a five-line staff, the C clef symbol designates the middle line (third line from bottom) as middle C (C4). The symmetrical shape of the C clef centers on the line representing middle C.

# Prerequisites
- **Staff**: The five-line framework for notation
- **Middle C**: The reference pitch C4

# Key Properties
1. Uses the C clef symbol centered on the middle line
2. Middle line = C4 (middle C)
3. Lines (bottom to top): F3-A3-C4-E4-G4
4. Spaces (bottom to top): G3-B3-D4-F4
5. Primarily used by viola

# Construction / Recognition
- C clef symbol centered on the third line from the bottom
- That line = middle C (C4)
- Notes read outward from that reference point

# Context & Application
The alto clef is primarily used for the viola, which has a range that sits between the treble and bass clef ranges. It allows most viola music to be written on the staff without excessive ledger lines. Some trombone and other instrumental parts occasionally use alto clef.

# Examples
- The middle line of the alto clef staff is always C4 (middle C)
- Viola parts are almost exclusively written in alto clef
- F3 is on the bottom line; G4 is on the top line

# Relationships
## Builds Upon
- Staff, middle C

## Enables
- Reading viola parts, certain orchestral scores

## Related
- Tenor clef (also a C clef, but middle C on a different line)
- Treble clef, bass clef (the more common clefs)

## Contrasts With
- Tenor clef (places middle C on the fourth line instead of the third)

# Common Errors
- Confusing alto clef with tenor clef (both are C clefs but place middle C on different lines)
- Trying to read alto clef as if it were treble or bass clef

# Common Confusions
- **Alto vs. tenor clef**: Both use the C clef symbol but on different lines; alto = middle line, tenor = fourth line
- **C clef appearance**: The C clef symbol looks different from treble and bass clef symbols
