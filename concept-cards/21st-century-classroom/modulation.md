# Quick Definition
Modulation is a change of key within a composition, confirmed by a cadence in the new key, as distinguished from the temporary tonicization achieved by secondary chords.

# Formal Definition
At its simplest, modulation is a change of key that happens within a composition. In popular music, this is often called a "key change." Classical music theory typically reserves "modulation" for slower, more subtle key changes, though "direct modulation" resembles popular music key changes. A modulation to a new key requires an eventual cadence to confirm that new key.

# Construction/Recognition
Cadential formula to establish a key:
Pre-dominant - Dominant - Tonic (in new key)
Example: ii - V7 - I (or ii6 - I6/4 - V7 - I)

This "full cadence" (per Douglass Green) establishes a key more strongly than a simple V-I authentic cadence.

Recognition process:
1. Listen for the cadence in the new key
2. Work backward to find pre-dominant chords in the new key
3. Analyze from the beginning of the phrase to the new key
4. Look for a logical pivot point

# Musical Context
- Baroque/Classical: typically modulate to dominant (from major) or relative major (from minor)
- Romantic era: modulations to more remote "foreign" keys
- Popular music: key changes often for emotional intensification (final chorus)

# Examples
- Beyonce, "Love on Top" (2011) - multiple key changes
- "My Heart Will Go On" (1997) - key change at climax
- Bon Jovi, "Livin' on a Prayer" (1986) - key change
- J.S. Bach chorales - frequent modulations with fast harmonic rhythm

# Common Confusions
- Tonicization is temporary; modulation requires cadential confirmation
- Ambiguity exists between short modulation and extended tonicization
- Fast harmonic rhythm (Bach chorales) creates analytical ambiguity
- "Key change" in pop = "direct modulation" in classical terminology
