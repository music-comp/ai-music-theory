# Quick Definition
Modulation is a change of key within a composition, confirmed by a cadence in the new key -- distinguished from tonicization by its permanence and from popular music "key changes" by its typically subtler, more gradual approach.

# Core Definition
At its simplest, modulation is a change of key that happens within a composition. In popular music, this is often called a "key change." Classical music theory typically reserves "modulation" for the slower and more subtle change of key that occurs in many classical pieces, although "direct modulation" resembles popular music key changes. A modulation to a new key requires an eventual cadence to confirm that new key, typically with a cadential formula: pre-dominant - dominant - tonic.

# Prerequisites
- **Tonicization**: The temporary key emphasis that modulation makes permanent
- **Key signatures**: Understanding the key being left and entered
- **Cadences**: The mechanism that confirms the new key

# Key Properties
1. Change of key within a composition
2. Confirmed by a cadence in the new key
3. Cadential formula: pre-dominant - dominant - tonic (in new key)
4. More permanent than tonicization
5. "Key change" (popular music) = "direct modulation" (classical)
6. Multiple types: pivot chord, direct, common-tone, sequential, enharmonic

# Construction / Recognition
- Listen for the cadence in the new key
- Work backward from the cadence to find pre-dominant chords in new key
- Analyze from phrase beginning until reaching the new key
- Look for a logical pivot point between the keys
- If two successive chords could both be pivots, include both in the bracket

# Context & Application
Modulation is a fundamental structural technique. Baroque and Classical composers typically modulated to closely related keys (dominant from major, relative major from minor). Romantic-era composers explored more remote key areas. Popular music uses direct modulation (key changes) for emotional intensification, typically in final choruses. The cadential formula (pre-dominant - dominant - tonic) establishes a key more strongly than a simple V-I.

# Examples
- Beyonce, "Love on Top" (2011) -- multiple key changes
- James Horner and Will Jennings, "My Heart Will Go On" (1997) -- climactic key change
- Jon Bon Jovi et al., "Livin' on a Prayer" (1986) -- final chorus key change
- J.S. Bach chorales -- frequent modulations with fast harmonic rhythm

# Common Errors
- Calling every secondary chord a "modulation"
- Missing cadences that confirm new keys

# Common Confusions
- **Tonicization vs. modulation**: Tonicization is temporary; modulation requires cadential confirmation
- **Ambiguity is real**: Some passages are genuinely ambiguous (extended tonicization vs. short modulation)
- **"Key change" = "direct modulation"**: The popular music and classical terms describe the same thing
