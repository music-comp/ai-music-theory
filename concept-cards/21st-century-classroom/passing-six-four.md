# Quick Definition
A passing six-four chord occurs when the bass line moves stepwise through three ascending or descending notes, with the middle chord being a 6/4 chord -- the bass acts like a passing tone, connecting root position and first inversion chords.

# Core Definition
The passing six-four is one of the four approved contexts for second-inversion chords in classical music. The bass line consists of three stepwise ascending or descending notes, and the middle chord is a 6/4 chord. The bass note of the 6/4 chord functions like a passing tone, connecting a chord in root position to the same or another chord in first inversion (or vice versa). Common patterns include I-V6/4-I6 (ascending bass: do-re-mi) and I6-V6/4-I (descending).

# Prerequisites
- **Six-four chord types**: The broader category of approved 6/4 contexts
- **Passing tone**: The embellishing function the bass imitates

# Key Properties
1. Bass moves by step through three notes (ascending or descending)
2. Middle chord is a 6/4 chord
3. The bass of the 6/4 acts like a passing tone
4. Common patterns: I-V6/4-I6, IV-I6/4-IV6
5. Connects root position to first inversion (or reverse)
6. The 6/4 chord has weak metric placement (typically)

# Construction / Recognition
- Look for three stepwise bass notes
- The middle bass note supports a 6/4 chord
- The outer bass notes support root position and first inversion of the same or related chords
- Example: bass C-D-E with chords C-G/D-C/E (I-V6/4-I6)

# Context & Application
The passing six-four smooths out bass motion between root position and first inversion chords. It is a voice-leading-driven usage where the 6/4 chord serves an embellishing rather than structural function. The pattern is common in all periods of tonal music.

# Examples
- I-V6/4-I6 (bass: do-re-mi ascending)
- I6-V6/4-I (bass: mi-re-do descending)
- IV-I6/4-IV6 (bass: fa-sol-la ascending)

# Common Errors
- Using a passing 6/4 without stepwise bass motion
- Confusing with cadential 6/4 (check: is the bass stepwise?)

# Common Confusions
- **Stepwise bass is the key**: Three notes moving by step, middle one supports 6/4
- **Embellishing, not structural**: The passing 6/4 does not have dominant function
- **Direction can be ascending or descending**: Both are valid passing 6/4 contexts
