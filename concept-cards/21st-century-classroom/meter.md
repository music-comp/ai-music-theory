# Quick Definition
Meter describes the number of beats in a measure (duple, triple, quadruple) and how the beats are normally divided (simple into 2, compound into 3).

# Core Definition
Meter describes the number of beats in a measure (also known as a "bar") and how the beats are normally divided. Meters with two beats in a bar are described as duple. If there are three beats in a bar, the meter is described as triple, and if there are four beats in a bar, the meter is described as quadruple. If the beats are normally divided into two parts, the meter is described as simple. If the beats are normally divided into three parts, the meter is described as compound. When describing meter, we say how the beat is divided before the number of beats in the measure (e.g., "simple duple," not "duple simple").

# Prerequisites
- **Time signature**: The notation that expresses meter
- **Beat and pulse**: The unit that meter organizes

# Key Properties
1. Duple: 2 beats per measure
2. Triple: 3 beats per measure
3. Quadruple: 4 beats per measure
4. Simple: beats divide into 2 parts
5. Compound: beats divide into 3 parts
6. Division type stated first when describing: "simple duple," "compound triple"

# Construction / Recognition
- Top number 2 = duple, 3 = triple, 4 = quadruple (simple meters)
- Top number 6 = compound duple, 9 = compound triple, 12 = compound quadruple
- Simple top numbers: 2, 3, 4; Compound top numbers: 6, 9, 12

# Context & Application
Meter provides the rhythmic framework that organizes music into predictable patterns of strong and weak beats. Different meters create different feels: triple meter suggests waltz or minuet; quadruple meter is common in pop and rock; compound meters create a lilting or swinging feel.

# Examples
- 2/4 = simple duple; 3/4 = simple triple; 4/4 = simple quadruple
- 6/8 = compound duple; 9/8 = compound triple; 12/8 = compound quadruple
- 2/8 = simple duple; 3/2 = simple triple
- 6/16 = compound duple

# Common Errors
- Saying "duple simple" instead of "simple duple" (division type comes first)
- Counting 6/8 as having six beats (it has two: compound duple)

# Common Confusions
- **Word order**: Say division before count -- "compound duple," not "duple compound"
- **6/8 vs. 3/4**: Both have six eighth notes per measure, but 6/8 groups them as 2 groups of 3 (compound duple) while 3/4 groups them as 3 groups of 2 (simple triple)
- **Quadruple vs. two duple**: Quadruple has a characteristic 1-2-3-4 feel with beats 1 and 3 stronger
