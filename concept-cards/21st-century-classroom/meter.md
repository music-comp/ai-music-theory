# Quick Definition
Meter describes the number of beats in a measure (duple, triple, quadruple) and how beats are normally divided (simple or compound).

# Formal Definition
Meter is the organization of musical time into recurring patterns of strong and weak beats. It has two components: the number of beats per measure (duple=2, triple=3, quadruple=4) and how those beats divide (simple=into 2, compound=into 3). Meter is expressed through time signatures.

# Construction/Recognition
- Duple meter: 2 beats per measure
- Triple meter: 3 beats per measure
- Quadruple meter: 4 beats per measure
- Simple meter: beats divide into 2 parts
- Compound meter: beats divide into 3 parts

# Musical Context
Meter provides the rhythmic framework that organizes music into predictable patterns. Different meters create different feels: triple meter suggests waltz or minuet; quadruple meter is common in pop and rock; compound meters create a lilting or swinging feel.

# Examples
- 2/4 = simple duple (2 beats, each divides into 2)
- 3/4 = simple triple (3 beats, each divides into 2)
- 4/4 = simple quadruple (4 beats, each divides into 2)
- 6/8 = compound duple (2 beats, each divides into 3)
- 9/8 = compound triple (3 beats, each divides into 3)

# Common Confusions
- 6/8 has 2 beats (compound duple), not 6 beats
- When describing meter, say division type first: "compound duple," not "duple compound"
- Quadruple can be felt as two duple groups but has a characteristic 1-2-3-4 feel
