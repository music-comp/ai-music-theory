# Quick Definition

The Neapolitan chord (N6) has two voice leading rules: double the bass (the 3rd of the chord, which is ^4), and resolve b2 (the root) down to the nearest note in the following chord.

# Core Definition

There are two rules for voice leading the N6 chord in four parts (Hutchinson, Ch. 29, p. 419):
1. Double the bass (the 3rd of the chord)
2. Resolve b2 down to the nearest note in the next chord

# Prerequisites

- **Neapolitan chord** -- Must understand the chord structure (bII in first inversion)
- **First-inversion voice leading** -- N6 is a first-inversion chord, but with different doubling rules

# Key Properties

1. Double the bass (the 3rd, which is ^4)
2. Resolve b2 (the root of the chord) DOWN to nearest note
3. To V or V7: b2 moves to the leading tone
4. To cadential 6/4: b2 moves to ^1
5. Exception to normal first-inversion rule (normally don't double the bass)
6. Avoid augmented second from b2 to leading tone in same voice if possible

# Construction / Recognition

## Procedure:
1. Voice the N6 with doubled bass (^4)
2. Resolve b2 DOWN:
   - To V: b2 --> leading tone (^7)
   - To cadential 6/4: b2 --> ^1
3. Move remaining voices smoothly
4. Avoid creating an augmented 2nd (b2 to ^7) in a single voice

# Context & Application

- **Typical contexts**: Chromatic pre-dominant chord in minor-key cadences
- **Historical/stylistic notes**: The Neapolitan creates a dark, dramatic color; almost always in first inversion

# Common Errors

- **Error**: Applying the normal first-inversion rule (don't double the bass)
  **Correction**: The Neapolitan is an EXCEPTION -- always double the bass (the 3rd)

- **Error**: Resolving b2 upward
  **Correction**: b2 must resolve DOWN

# Common Confusions

- **Confusion**: The Neapolitan is sometimes in root position
  **Clarification**: N6 is almost always in first inversion (6 = first inversion symbol)

- **Confusion**: The augmented 2nd from b2 to ^7 is unavoidable
  **Clarification**: Try to place b2 and the leading tone in different voices; if in the same voice, an intervening cadential 6/4 helps
