# Quick Definition
Lead-sheet symbols are shorthand chord notations using letters and quality indicators to communicate root and quality, allowing performers to choose their own voicings.

# Core Definition
Lead-sheet symbols (also known as "lead-sheet notation" and "lead-sheet chord symbols") are often used as shorthand for chords in popular music and jazz. These symbols allow a guitarist or pianist to choose how to "voice" the chords, i.e., how they want to arrange the notes. Lead-sheet symbols communicate the root and quality of a chord: uppercase letter for major, letter + "m" for minor, letter + "o" for diminished, letter + "+" for augmented.

# Prerequisites
- **Triad**: Understanding of the four chord qualities

# Key Properties
1. Root: uppercase letter (C, F#, Bb)
2. Major triad: letter alone (C, F, G)
3. Minor triad: letter + lowercase "m" (Cm, Am, F#m)
4. Diminished triad: letter + "o" or "dim" (Co, Bdim)
5. Augmented triad: letter + "+" or "aug" (C+, Gaug)
6. Allows performer freedom in voicing

# Construction / Recognition
- First letter = chord root (always uppercase)
- No modifier = major
- "m" = minor
- "o" or "dim" = diminished
- "+" or "aug" = augmented

# Context & Application
Lead-sheet symbols are essential for jazz musicians and pop/rock performers who need to read chord changes quickly and create their own voicings. They appear in fake books, chord charts, and above melody lines in sheet music. A C major triad can be voiced in many different ways -- all containing only C, E, and G -- and lead-sheet notation permits this flexibility.

# Examples
- C = C major triad (C-E-G)
- Gm = G minor triad (G-Bb-D)
- Do = D diminished triad (D-F-Ab)
- C+ = C augmented triad (C-E-G#)
- F#m = F# minor triad (from "Girl on Fire" by Alicia Keys)

# Common Errors
- Adding "M" or "maj" for major triads (just the letter is sufficient for triads)
- Using lowercase for the root letter (it is always uppercase, even for minor chords)

# Common Confusions
- **No symbol = major**: A plain letter without modifier means major (for triads)
- **Root always uppercase**: Even for minor chords, the root letter is uppercase (Cm, not cm)
- **Voicing freedom**: Lead-sheet symbols specify what notes but not how to arrange them
