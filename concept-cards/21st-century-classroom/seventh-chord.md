# Quick Definition
A seventh chord is a four-note chord built by adding a note a third above the fifth of a triad, creating root, third, fifth, and seventh.

# Core Definition
A seventh chord adds to a triad another note a third higher than the fifth. Chords, being built in thirds, have members that are odd numbers -- third, fifth, seventh -- and extensions continue through the ninth, eleventh, and thirteenth (the fifteenth would be the double octave, so chords only extend as high as the thirteenth). There are five types of seventh chords commonly encountered in classical and popular music: major seventh, major-minor (dominant) seventh, minor seventh, half-diminished seventh, and fully-diminished seventh.

# Prerequisites
- **Triad**: The three-note chord to which the seventh is added
- **Intervals**: Understanding of thirds (major and minor) for stacking

# Key Properties
1. Four notes: root, third, fifth, seventh
2. Built by stacking three thirds above the root
3. Five common types differentiated by triad quality and seventh quality
4. Each type has a distinctive pattern of major and minor thirds
5. Extensions (9th, 11th, 13th) continue the pattern of stacked thirds

# Construction / Recognition
1. Begin with a triad (major, minor, diminished, or augmented)
2. Add a note a third above the fifth
3. Identify the type by examining the quality of the triad and the interval from root to seventh
4. Another method: learn the stacking pattern of major and minor thirds for each type

# Context & Application
Seventh chords are richer and more colorful than triads. The dominant seventh chord is essential for tonal harmony, creating strong pull toward resolution. Jazz makes extensive use of all seventh chord types. Seventh chords built on augmented and minor triads appear in later chapters.

# Examples
- Major seventh: M3 + m3 + M3 (e.g., Cmaj7: C-E-G-B)
- Dominant seventh: M3 + m3 + m3 (e.g., G7: G-B-D-F)
- Minor seventh: m3 + M3 + m3 (e.g., Am7: A-C-E-G)
- Half-diminished seventh: m3 + m3 + M3 (e.g., Bm7b5: B-D-F-A)
- Fully-diminished seventh: m3 + m3 + m3 (e.g., Bo7: B-D-F-Ab)

# Common Errors
- Confusing the five seventh chord types (each has a unique third-stacking pattern)
- Forgetting that the "seventh" refers to the interval from root, not a scale degree

# Common Confusions
- **Five distinct qualities**: Not all seventh chords sound the same; quality depends on both the triad and the seventh interval
- **Dominant seventh vs. seventh chord**: "Seventh chord" is the general term; "dominant seventh" is one specific type
