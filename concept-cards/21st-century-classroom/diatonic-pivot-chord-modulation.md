# Quick Definition
In diatonic common chord modulation, a chord that is diatonic in both the original and new keys serves as a pivot, analyzed with a bracket showing its function in both keys.

# Formal Definition
In a diatonic common chord modulation, the pivot chords are diatonic in both keys, having the same root and quality. A pivot bracket shows the Roman numeral in both keys. The pivot chord typically has tonic or tonic prolongation function in the first key and pre-dominant function in the second key for the smoothest modulation.

# Construction/Recognition
Process for determining common chords:
1. List diatonic chords (root and quality) in both keys
2. Identify chords with same root AND same quality
3. These shared chords can serve as pivots

Example: G major to D major common chords
- G major = I in G, IV in D
- A minor = ii in G, vi doesn't exist (A major in D)
- B minor = iii in G, vi in D
- Em = vi in G, ii in D (excellent pivot!)
- D major = V in G, I in D

# Musical Context
- Pivot chord in first key: often tonic or tonic prolongation function
- Pivot chord in second key: often pre-dominant function
- Avoid using pivot with dominant function in new key (sounds abrupt)
- Creates seamless, convincing modulation

# Examples
- J.S. Bach, Christmas Oratorio, "Ermuntre dich" - vi in first key = ii in second key
- J.S. Bach, Chorale 4, "Es ist das Heil uns kommen her"
- J.S. Bach, Chorale 8, "Freuet euch, ihr Christen"

# Common Confusions
- The chord must have the SAME root AND quality in both keys
- Avoid pivot chords with dominant function in the new key
- The pivot bracket notation shows dual analysis
- Quality differences eliminate potential pivots (e.g., ii in major vs. II in another key)
