# Quick Definition
In diatonic pivot chord modulation, a chord that is diatonic in both the original and new keys serves as a pivot -- analyzed with a bracket showing its function in both keys, with the smoothest modulations using pivots that have tonic function in the first key and pre-dominant function in the second.

# Core Definition
In a diatonic common chord modulation, the pivot chords are diatonic in both keys, having the same root and quality. A pivot bracket shows the Roman numeral in both keys. To find common chords, list the diatonic chords in both keys and identify those with the same root AND same quality. Composers typically avoid using pivot chords with dominant function in the new key because such modulation might sound abrupt. Instead, the pivot chord ideally has tonic or tonic prolongation function in the first key and pre-dominant function in the second key.

# Key Properties
1. Pivot chord is diatonic in BOTH keys (same root AND quality)
2. Analyzed with a pivot bracket showing dual Roman numeral labels
3. Best pivots: tonic function in key 1, pre-dominant function in key 2
4. Avoid pivots with dominant function in the new key (sounds abrupt)
5. Works best between closely related keys (more common chords available)
6. Two successive chords may both be valid pivots

# Construction / Recognition
Finding common chords (G major to D major example):
1. List diatonic chords in both keys with root and quality
2. G major: G, Am, Bm, C, D, Em, F#o
3. D major: D, Em, F#m, G, A, Bm, C#o
4. Common: G (I in G = IV in D), Bm (iii in G = vi in D), D (V in G = I in D), Em (vi in G = ii in D)
5. Best pivot: Em (vi in G with tonic prolongation function; ii in D with pre-dominant function)

# Context & Application
Diatonic pivot chord modulation is the most common type of modulation in Classical-era music. It creates seamless, convincing key changes because the pivot chord sounds natural in both contexts. The process of finding common chords is systematic and can be applied to any pair of keys. Closely related keys have more common chords; distantly related keys may have none, requiring chromatic pivot techniques.

# Examples
- J.S. Bach, Christmas Oratorio, "Ermuntre dich" -- vi in first key = ii in second key
- J.S. Bach, Chorale 4, "Es ist das Heil uns kommen her"
- J.S. Bach, Chorale 8, "Freuet euch, ihr Christen"

# Common Errors
- Accepting chords with same root but different quality as pivots (both root AND quality must match)
- Choosing a pivot with dominant function in the new key

# Common Confusions
- **Root AND quality**: Am in G major is not the same as A in D major -- quality must match
- **Function preference**: Tonic in key 1, pre-dominant in key 2 = smoothest modulation
- **Multiple valid pivots**: If two successive chords could be pivots, include both in the bracket
