# Quick Definition
Roman numeral analysis uses Roman numerals to represent chords based on the scale degree of their root, showing harmonic patterns that transfer across keys.

# Formal Definition
Roman numeral chord symbols represent triads built on each scale degree within a specified key. The numeral indicates the scale degree of the chord root (I through vii). Uppercase numerals represent major triads; lowercase numerals represent minor triads. Additional symbols indicate diminished (o), augmented (+), and inversions. This system reveals harmonic patterns independent of key.

# Construction/Recognition
- Uppercase = major triad (I, IV, V)
- Lowercase = minor triad (ii, iii, vi)
- Lowercase + o = diminished (viio)
- Uppercase + = augmented (III+)
- The numeral corresponds to the scale degree of the root

# Musical Context
Roman numeral analysis allows musicians to understand chord progressions independent of key and to transpose music easily. It reveals common patterns like I-IV-V-I that occur in countless pieces across different keys.

# Examples
- In C major: C = I, Dm = ii, Em = iii, F = IV, G = V, Am = vi, Bo = viio
- In G major: G = I, Am = ii, Bm = iii, C = IV, D = V, Em = vi, F#o = viio
- The progression I-IV-V-I works in any major key
- V-I = authentic cadence in any key

# Common Confusions
- The numeral indicates scale degree, not chord position in a progression
- Uppercase/lowercase indicates quality, not loudness or importance
- Roman numerals show function; lead-sheet symbols show specific notes
