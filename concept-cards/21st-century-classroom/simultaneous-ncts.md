# Quick Definition

When non-chord tones occur in multiple voices simultaneously, they should form consonant intervals (3rds, 5ths, 6ths, 8ves); if consonance is impossible, the NCTs should be staggered rhythmically.

# Core Definition

When non-chord tones are added to different voices on the same beat, consonant intervals (3rds, 5ths, 6ths, or 8ves) should be formed between the NCTs. If consonant intervals cannot be made, the voices should be staggered rhythmically. Parallel 5ths and 8ves between NCTs are still objectionable (Hutchinson, Ch. 28, p. 415).

# Prerequisites

- **Adding NCTs to progressions** -- Must know how to add NCTs individually first
- **Avoiding parallels from NCTs** -- Simultaneous NCTs create additional parallel concerns

# Key Properties

1. Simultaneous NCTs should form consonant intervals with each other
2. Consonant intervals: 3rds, 5ths, 6ths, 8ves
3. Dissonant intervals between simultaneous NCTs: avoid or stagger
4. Parallel 3rds and 6ths between NCTs are particularly effective
5. Parallel 5ths and 8ves between NCTs are still forbidden
6. Rhythmic staggering creates interest while avoiding clashes

# Construction / Recognition

## Procedure:
1. Plan NCTs in one voice
2. If adding NCT in another voice on the same beat: check the interval formed
3. Consonant (3, 5, 6, 8): acceptable
4. Dissonant (2, 4, tritone, 7): stagger rhythmically

# Context & Application

- **Typical contexts**: Enriched chorale writing with multiple embellished voices

# Common Errors

- **Error**: Placing NCTs in two voices on the same beat without checking their interval
  **Correction**: Always check the vertical interval formed by simultaneous NCTs

# Common Confusions

- **Confusion**: NCTs do not need to form good intervals with each other
  **Clarification**: Simultaneous NCTs interact vertically and must produce acceptable sonorities
