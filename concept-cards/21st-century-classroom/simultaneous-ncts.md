# Quick Definition
When non-chord tones occur in multiple voices simultaneously, they should form consonant intervals (3rds, 5ths, 6ths, 8ves) with each other; if this is impossible, the NCTs should be staggered rhythmically.

# Formal Definition
Simultaneous non-chord tones require the same intervallic considerations as chord tones. When two or more voices have NCTs on the same beat, the intervals formed between those NCTs should be consonant (unisons, 3rds, 5ths, 6ths, or 8ves). If consonant intervals cannot be achieved, the NCTs should be displaced rhythmically so they do not sound at exactly the same time, avoiding the harshness of dissonant clashes.

# Rules/Procedures
1. When planning NCTs in multiple voices on the same beat:
   - Check what interval the NCTs form with each other
   - Consonant (1, 3, 5, 6, 8): Acceptable
   - Dissonant (2, 4, tritone, 7): Avoid or stagger
2. If simultaneous consonance is impossible:
   - Place one NCT slightly before or after the beat
   - Use different note values to offset the NCTs
3. Parallel 3rds and 6ths between NCTs are particularly effective
4. Parallel 5ths and 8ves between NCTs are still objectionable

# Musical Context
This principle reflects the Renaissance and Baroque preference for consonant sonorities even in decorative passages. Staggered NCTs create rhythmic interest while avoiding harsh vertical clashes.

# Examples
- Soprano has upper neighbor D, alto has upper neighbor B: D and B form a 3rd (consonant) - acceptable
- Soprano has neighbor E, alto has neighbor F: E and F form a 2nd (dissonant) - stagger rhythmically
- Solution: Alto neighbor on beat, soprano neighbor on "and" of the beat

# Common Confusions
- Thinking that NCTs do not need to form good intervals with each other
- Not checking the vertical interval formed by simultaneous NCTs
- Forgetting that parallel 5ths and 8ves between NCTs are still forbidden
- Placing harsh dissonances on strong beats without rhythmic offset
