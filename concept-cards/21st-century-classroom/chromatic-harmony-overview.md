# Quick Definition
Chromatic harmony introduces chords with accidentals beyond the key signature, expanding the diatonic vocabulary with five main categories: secondary dominants, secondary diminished chords, mode mixture (borrowed chords), the Neapolitan chord, and augmented sixth chords.

# Core Definition
Chapters 17-21 introduce chromatic harmony -- chords containing accidentals not found in the key signature (with the exception of raised 6 and 7 in minor, which are considered diatonic). The five categories of chromatic chords studied are: secondary dominants (V/x, V7/x), secondary diminished chords (viio/x, viio7/x), mode mixture / borrowed chords (chords from the parallel minor), the Neapolitan chord (N, bII), and augmented sixth chords (It+6, Fr+6, Ger+6). Each category has its own identification method, construction process, and characteristic sound.

# Prerequisites
- **Diatonic chords in major**: The baseline being expanded
- **Diatonic chords in minor**: Including the raised 6 and 7 considered diatonic

# Key Properties
1. Secondary dominants: M or Mm7 quality; root P5 above target
2. Secondary diminished: dim quality; root m2 below target
3. Mode mixture: lowered accidentals (b6, b3, b7); from parallel minor
4. Neapolitan: bII major triad; labeled N; pre-dominant function
5. Augmented sixth: diminished 3rd when stacked; b6 and #4; pre-dominant
6. All chromatic chords function within the established key
7. Chromatic harmony enriches without replacing diatonic harmony

# Construction / Recognition
Identification workflow:
1. Stack chord in thirds
2. Check for diminished third: augmented sixth chord
3. Check quality:
   - Major/Mm7: possible secondary dominant (check P5 below)
   - Diminished types: possible secondary diminished (check m2 above)
4. Check for lowered accidentals without secondary function: mode mixture
5. Check for bII: Neapolitan
6. Verify with resolution and context

# Context & Application
Chromatic harmony represents the next layer of complexity beyond diatonic harmony. It is found in music from the Baroque era through the present day. The five categories are introduced sequentially in Chapters 17-21, building from secondary dominants (most common) through augmented sixth chords (most specialized). Understanding chromatic harmony is essential for analyzing any tonal music beyond the simplest diatonic progressions.

# Examples
- Secondary dominant: V7/V in C major = D7
- Secondary diminished: viio/V in C major = F#o
- Mode mixture: iv in C major = Fm (borrowed from c minor)
- Neapolitan: N6 in c minor = Db/F
- Augmented sixth: Ger+6 in c minor = Ab-C-Eb-F#

# Common Errors
- Treating all chromatic chords as the same type
- Not following the systematic identification workflow

# Common Confusions
- **Raised 6 and 7 in minor are diatonic**: These are not chromatic despite requiring accidentals
- **Five distinct categories**: Each type has its own identification method and analytical label
- **Enrichment, not replacement**: Chromatic harmony works within and alongside diatonic harmony
