# Quick Definition
Melodic alteration refers to the various ways a melody or motive can be changed while retaining its identity, including inversion, intervallic change, augmentation, diminution, rhythmic change, ornamentation, extension, and retrograde.

# Formal Definition
There are seven basic methods of melodic alteration: (1) Inversion - melody turned upside down; (2) Intervallic change - some intervals modified; (3) Augmentation - rhythmic values doubled; (4) Diminution - rhythmic values halved; (5) Rhythmic change - some rhythmic values varied; (6) Ornamentation - non-chord tones added; (7) Extension - material added to the end.

# Analysis/Application
When analyzing melodic alterations:
1. Identify the original motive or melody
2. Compare subsequent versions to the original
3. Label the type of alteration used
4. Note that multiple alterations may be combined

# Musical Context
Melodic alteration techniques are fundamental to composition and development. They allow composers to create unity (using the same melodic material) while providing variety (transforming it in different ways).

# Examples
- Bach, Invention No. 1 - melodic inversion in measure 3
- "The Very Thought of You" - intervallic change
- "I'm Not In Love" - intervallic change with contour change
- Holst, "Uranus" from The Planets - diminution
- "Push It" (1987) - rhythmic change
- Beethoven, Pathetique Sonata - rhythmic change in development section
- "Sir Duke" (Stevie Wonder, 1976) - ornamentation
- "Toxic" (2003) - melodic retrograde in popular music

# Common Confusions
- Inversion can be "real" (exact intervals) or "tonal" (adjusted to fit the scale)
- Transposition (sequence) is not considered an alteration since it's so common
- Multiple alteration techniques can be combined
