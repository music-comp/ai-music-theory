# Quick Definition
Melodic alteration refers to seven basic methods of transforming a melody or motive while retaining its identity: inversion, intervallic change, augmentation, diminution, rhythmic change, ornamentation, extension, and retrograde.

# Core Definition
There are seven methods of basic melodic alteration: (1) Inversion -- melody turned upside down ("mirrored"); can be real (exact intervals) or tonal (adjusted to scale). (2) Intervallic change -- rhythm intact but some intervals differ. (3) Augmentation -- exact doubling of rhythmic durations. (4) Diminution -- exact halving of rhythmic durations (or use of shorter values). (5) Rhythmic change -- some but not all rhythmic values varied. (6) Ornamentation -- non-chord tones added to embellish. (7) Extension -- additional material added at the end. Additionally, retrograde (exact reversal of note order) is mentioned as rare in tonal music.

# Prerequisites
- **Motive**: Understanding of the smallest melodic idea

# Key Properties
1. Inversion: upside-down; real (exact) or tonal (diatonic)
2. Intervallic change: rhythm preserved, some intervals modified
3. Augmentation: rhythmic values doubled
4. Diminution: rhythmic values halved
5. Rhythmic change: some rhythmic values varied
6. Ornamentation: non-chord tones added
7. Extension: material added at the end
8. Retrograde: exact reversal (rare in tonal music)
9. Transposition (sequence) is not labeled as an alteration

# Construction / Recognition
1. Identify the original motive or melody
2. Compare subsequent versions to the original
3. Determine which alteration(s) are applied
4. Multiple alterations may be combined
5. Label the specific type(s) used

# Context & Application
Melodic alteration techniques are fundamental to composition and development. They allow unity (same material) with variety (transformed). These techniques appear from Bach inventions through contemporary pop music. Transposition (sequence) is so common that it is not labeled as an alteration.

# Examples
- Bach, Invention No. 1 -- melodic inversion in measure 3; augmentation of fragment "a"
- "The Very Thought of You" (1934) -- intervallic change
- "I'm Not In Love" (1975) -- intervallic change with contour change
- Holst, "Uranus" from The Planets -- diminution
- "Push It" (1987) -- rhythmic change
- Beethoven, Pathetique Sonata -- rhythmic change in development
- Stevie Wonder, "Sir Duke" (1976) -- ornamentation and extension
- "Toxic" (2003) -- melodic retrograde in popular music

# Common Errors
- Labeling simple transposition as a motivic alteration
- Missing combined alterations (multiple techniques at once)

# Common Confusions
- **Real vs. tonal inversion**: Real preserves exact intervals; tonal adjusts to fit the key
- **Transposition is not an alteration**: It is too common to warrant labeling
- **Multiple alterations can combine**: A motive may be inverted AND augmented simultaneously
