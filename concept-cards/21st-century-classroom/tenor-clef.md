# Quick Definition
The tenor clef is a C clef that places middle C (C4) on the fourth line from the bottom, used for higher passages in cello, bassoon, and trombone.

# Core Definition
The tenor clef is one of the two commonly used C clefs. When placed on a five-line staff, the C clef symbol designates the fourth line from the bottom as middle C (C4). It is used for higher-register passages in instruments that normally read bass clef.

# Prerequisites
- **Staff**: The five-line framework for notation
- **Middle C**: The reference pitch C4

# Key Properties
1. Uses the C clef symbol centered on the fourth line from the bottom
2. Fourth line = C4 (middle C)
3. Lines (bottom to top): D3-F3-A3-C4-E4
4. Spaces (bottom to top): E3-G3-B3-D4
5. Used for higher passages in cello, bassoon, trombone

# Construction / Recognition
- C clef symbol centered on the fourth line from the bottom
- That line = middle C (C4)
- Notes read outward from that reference point

# Context & Application
The tenor clef is used for higher passages in instruments that normally read bass clef, such as cello, bassoon, and trombone. It allows these instruments to read notes in a higher register without excessive ledger lines above the bass staff.

# Examples
- The fourth line from the bottom of the tenor clef staff is always C4 (middle C)
- Cello music often switches to tenor clef for higher passages
- Bassoon and trombone parts may use tenor clef for upper register music

# Relationships
## Builds Upon
- Staff, middle C

## Enables
- Reading higher passages for bass-clef instruments

## Related
- Alto clef (also a C clef, but middle C on a different line)
- Bass clef (the normal clef for these instruments)

## Contrasts With
- Alto clef (places middle C on the third line instead of the fourth)

# Common Errors
- Confusing tenor clef with alto clef (middle C is on different lines)
- Assuming all C clefs are interchangeable

# Common Confusions
- **Tenor vs. alto clef**: Both use the C clef symbol; tenor = fourth line, alto = middle (third) line
- **Switching clefs**: Cello and bassoon players must read both bass and tenor clef fluently
