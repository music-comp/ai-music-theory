# Quick Definition
A real answer transposes the subject exactly to the dominant key; a tonal answer alters certain intervals (typically scale degrees 1-5 become 5-1) to smooth the tonic-dominant relationship.

# Core Definition
When the second voice enters in a fugue with the answer, it may be real or tonal. A real answer transposes all intervals exactly, creating a precise transposition to the dominant. A tonal answer alters certain intervals, typically when the subject prominently features the motion between scale degrees 1 and 5. The subject's 1-5 is answered by 5-1, and 5-1 is answered by 1-5. This prevents an awkward emphasis on the supertonic that would result from exact transposition of a prominent tonic-dominant leap (Hutchinson, Ch. 30, pp. 433-434).

# Key Properties
1. Real answer: exact transposition of all intervals to the dominant
2. Tonal answer: selected intervals altered at the beginning
3. Tonal convention: subject's 1-5 answered by 5-1 (and vice versa)
4. Interval changes typically limited to the first few notes
5. After the tonal adjustment, the answer usually continues with exact intervals
6. Both types are legitimate compositional conventions

# Construction / Recognition
**To identify real vs. tonal:**
1. Write out the subject's intervals
2. Write out the answer's intervals
3. Compare: if all intervals match, the answer is real
4. If certain intervals differ (especially at the beginning), the answer is tonal

**When to use tonal answer:**
- Subject begins with prominent motion from scale degree 1 to 5: answer starts 5 to 1
- Subject begins with prominent motion from 5 to 1: answer starts 1 to 5

**When to use real answer:**
- Subject does not feature prominent 1-5 or 5-1 motion at the start
- Exact transposition creates no tonal problems

# Context & Application
The tonal answer evolved as a convention to handle the tonal implications of subject entries in tonic and dominant. If a subject leaps 1-5 (e.g., C to G in C major), an exact transposition would yield G to D (5 to 2), which awkwardly emphasizes the supertonic. The tonal answer (G to C) corrects this.

# Examples
- **Bach, Fugue 2 in C minor** (p. 434): Subject's third note descends a perfect 4th to the fourth note; the answer descends a perfect 5th instead (TONAL answer)
- **Real answer example**: Subject C-D-E-F-G becomes G-A-B-C-D (all intervals preserved)
- **Tonal answer example**: Subject C-G... becomes G-C... (P5 becomes P4)

# Common Errors
- **Error**: Failing to recognize a tonal answer and calling it a mistake
  **Correction**: Compare the first few intervals of subject and answer carefully

# Common Confusions
- **Confusion**: Thinking tonal answers are "wrong" or errors
  **Clarification**: Tonal answers are a deliberate, standard compositional convention
- **Confusion**: Expecting the entire answer to be altered in a tonal answer
  **Clarification**: Usually only the first few notes are adjusted; the rest continues with exact intervals
