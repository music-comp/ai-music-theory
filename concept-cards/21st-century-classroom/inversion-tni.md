# Quick Definition
Inversion (TnI) is a compound operation that first inverts a set around C (pitch class 0), then transposes the result by n semitones.

# Formal Definition
Inversion in set theory, notated TnI (or In in Straus's notation), is a two-step operation. First, each pitch class is inverted around C (pitch class 0) as an axis - what went up now goes down by the same interval. Then, the result is transposed by n semitones. The inversion of pitch class x is 12-x (or equivalently, -x mod 12).

# Construction/Calculation
Step 1: Invert each pitch class (T0I)
- Formula: 12 - x (or -x mod 12)
- E (4) inverts to Ab (8): 12 - 4 = 8

Step 2: Apply Tn transposition
- Add n to each inverted pitch class

Example: [2, 4, 5] at T7I
1. Invert: [10, 8, 7] (T0I)
2. Transpose by 7: [5, 3, 2]
3. In ascending order: [2, 3, 5]

To identify TnI between two sets:
- Write second set backward
- Add corresponding elements
- Each sum equals n

# Musical Context
Inversional relationships are crucial in twelve-tone analysis and atonal set theory. Sets related by TnI share the same prime form. Identifying inversional relationships reveals structural connections that may not be apparent from the score's surface.

# Examples
- E (4) at T0I = Ab (8): 12 - 4 = 8
- [2, 4, 5] at T7I = [2, 3, 5]
- To find n: [2, 4, 5] and [2, 3, 5] -> second set backward: 5, 3, 2
- Add: 2+5=7, 4+3=7, 5+2=7 -> confirms T7I

# Common Confusions
- TnI is a compound operation: invert first, THEN transpose
- T0I inverts around C (pitch class 0)
- Inversion formula: 12 - x (not simply negation)
- Joseph Straus uses In instead of TnI, but the result is the same
