# Quick Definition
Rotation cyclically shifts a pattern so each successive version begins on a different note, with the first note moving to the end; it underlies the phase-shifting process.

# Core Definition
During the phase-shifting process, one can think of the lower voice as going through rotation. The pattern rotates one note to the left: the second note begins the pattern on the second line, the third note on the third line, etc., until the first note starts the pattern again to complete the process. Number of unique rotations = number of notes in the pattern. Stravinsky also applied rotation to serialism (Hutchinson, Ch. 35, pp. 503-504).

# Prerequisites
- **Minimalism** -- Rotation is used in minimalist context

# Key Properties
1. Pattern shifts one note to the left each rotation
2. First note moves to the end
3. Number of rotations = number of notes in pattern
4. Returns to original after all rotations complete
5. Underlies the phase-shifting process
6. Also applicable to serialism (Stravinsky)

# Construction / Recognition
**Five-note pattern example (p. 504, Figure 35.2.3):**
- Original: A-B-C-D-E
- Rotation 1: B-C-D-E-A
- Rotation 2: C-D-E-A-B
- Rotation 3: D-E-A-B-C
- Rotation 4: E-A-B-C-D
- Returns to original

# Context & Application
In *Piano Phase*, Reich has the second pianist gradually speed up to achieve rotation. In *Clapping Music*, the second performer shifts to the next rotation at each measure boundary. Stravinsky applied rotation to his serial procedures in later works (noted by Straus, p. 504).

# Examples
- Five-note rotation demonstration (p. 504, Figure 35.2.3)
- Short phase-shifting piece (p. 504, Figure 35.2.4): One part maintains original, other rotates
- Reich, *Piano Phase*: 12-note pattern has 12 rotations
- Reich, *Clapping Music*: Pattern shifts one rotation per measure

# Relationships
## Related
- **Phase shifting** -- Phase shifting is rotation applied in performance over time
- **Non-twelve-tone serialism** -- Stravinsky applied rotation to serial procedures

# Common Errors
- **Error**: Confusing rotation with transposition
  **Correction**: Rotation changes order; transposition changes pitch level

# Common Confusions
- **Confusion**: Thinking rotation reverses the pattern
  **Clarification**: Rotation shifts leftward (first note to end); retrograde reverses the order entirely
