# Quick Definition
Rotation is the process of cyclically shifting a pattern so that each successive version begins on a different note of the original pattern.

# Formal Definition
Rotation is a technique where a musical pattern is cyclically permuted so that the second note becomes the first, the third becomes the second, and so on, with the original first note moving to the end. In phase shifting, one voice maintains the original pattern while another cycles through all rotations. The number of unique rotations equals the number of notes in the pattern.

# Construction/Calculation
Creating rotations:
1. Write the original pattern: A-B-C-D-E
2. Rotation 1: B-C-D-E-A (first note moves to end)
3. Rotation 2: C-D-E-A-B
4. Rotation 3: D-E-A-B-C
5. Rotation 4: E-A-B-C-D
6. Rotation 5: A-B-C-D-E (returns to original)

Number of rotations = number of elements in pattern

# Musical Context
Rotation underlies phase shifting in Reich's music. While one performer maintains the original pattern, the other effectively moves through rotations (either gradually or in discrete steps). The technique also connects to serial practices: Stravinsky applied rotation to his serial procedures in later works.

# Examples
- 5-note pattern rotation:
  - Original: A-B-C-D-E
  - Rot 1: B-C-D-E-A
  - Rot 2: C-D-E-A-B
  - (continues until return to original)
- Reich, Piano Phase: 12-note pattern has 12 rotations
- Reich, Clapping Music: Performer shifts to next rotation each measure

# Common Confusions
- Rotation is not transposition - pitches don't change, order does
- Rotation shifts the pattern leftward (beginning note moves to end)
- The original pattern IS one of the rotations
- Rotation differs from retrograde (which reverses order)
