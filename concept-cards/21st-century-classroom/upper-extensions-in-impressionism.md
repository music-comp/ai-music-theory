# Quick Definition
Impressionist composers used chords with 9ths, 11ths, and 13ths as coloristic sonorities, often with chromatic alterations, anticipating jazz harmony.

# Core Definition
Debussy and Ravel used chords containing ninths, elevenths, and thirteenths, sometimes with chromatic alterations to those upper extensions. Unlike functional harmony where these tones resolve, impressionist composers treated extended chords as stable, coloristic sonorities valued for their sound rather than harmonic function (Hutchinson, Ch. 32, pp. 466-468).

# Prerequisites
- **Impressionism** -- Upper extensions are one of the three core techniques
- **Jazz ninth chords** -- Same chord structures applied in a different aesthetic context

# Key Properties
1. 9ths, 11ths, 13ths added to triads and seventh chords
2. Chromatic alterations: b9, #9, #11
3. Chords treated as coloristic sonorities, not functional
4. Multiple alterations can occur simultaneously
5. Directly anticipates and influences jazz harmony

# Construction / Recognition
- Extended chords built on triads/7ths with 9th, 11th, 13th added
- Alterations add further color: b9, #9, #11
- Chords move without traditional resolution requirements

# Context & Application
This practice directly influenced jazz harmony. The rich sonorities became signatures of the impressionist sound, providing harmonic density without chromatic complexity.

# Examples
- Debussy, "Clair de lune," bar 15: Ebm9 with 9th (F) in melody (p. 467, Figure 32.1.5)
- Debussy, "La Puerta del Vino," bar 8: Db7 with alternating #9 and b9 (p. 467, Figure 32.1.6)
- Debussy, "La Puerta del Vino," bar 70: #11, #9, and b9 simultaneously (p. 468, Figure 32.1.7)

# Common Errors
- **Error**: Expecting upper extensions to resolve as they would in classical harmony
  **Correction**: In impressionism, extended chords are coloristic and may not resolve traditionally

# Common Confusions
- **Confusion**: Thinking impressionist extended chords and jazz chords are the same thing
  **Clarification**: The chord structures are similar but the aesthetic context differs; impressionism uses them for color while jazz uses them functionally
