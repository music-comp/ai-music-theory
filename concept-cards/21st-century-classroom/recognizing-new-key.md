# Quick Definition
To recognize a new key after modulation: look for recurring accidentals (sharps typically create leading tones/scale degree 7; flats typically create scale degree 4), then mentally add them to the key signature -- canceled accidentals indicate tonicization or chromatic NCTs, not modulation.

# Core Definition
When examining music containing modulations, look for recurring accidentals and add them mentally to the key signature to determine the new key. Lowered notes (flats) usually create scale degree 4 (as do the flats in key signatures). Raised notes (sharps) often create scale degree 7, the leading tone. If there are multiple raised notes, look for the "sharpest of sharps" (in key signature order) to determine which sharp is acting as scale degree 7. Accidentals that are canceled out indicate tonicizations or chromatic non-chord tones, not modulation.

# Prerequisites
- **Modulation**: Understanding that a key change has occurred
- **Key signatures**: How sharps and flats define keys
- **Leading tone**: The role of scale degree 7

# Key Properties
1. Recurring accidentals = clues to new key
2. Sharps typically create scale degree 7 (leading tone)
3. Flats typically create scale degree 4
4. Multiple sharps: "sharpest of sharps" = scale degree 7
5. Canceled accidentals = tonicization or chromatic NCTs
6. Cadence in the new key confirms the analysis

# Construction / Recognition
Step-by-step process:
1. Look for RECURRING accidentals (not isolated ones)
2. Add recurring accidentals to the existing key signature mentally
3. For sharps: identify which is the leading tone (latest in key signature order)
4. For flats: identify which creates scale degree 4
5. If accidentals cancel out: suspect tonicization, not modulation
6. Confirm with a cadence in the proposed new key

# Context & Application
This practical skill is essential for score analysis. The "sharpest of sharps" principle helps when multiple new sharps appear simultaneously. The distinction between recurring and canceled accidentals helps differentiate genuine modulations from tonicizations and chromatic passing tones. Always confirm the analytical hypothesis with a cadence.

# Examples
- J.S. Bach, English Suite No. 4 in F Major, Sarabande:
  - Key signature: one flat (F major)
  - Recurring C# indicates modulation
  - C# as leading tone suggests D minor or D major
  - Cadence confirms the new key

# Common Errors
- Treating every accidental as evidence of modulation (isolated accidentals may be secondary chords or NCTs)
- Not looking for cadential confirmation

# Common Confusions
- **Recurring vs. isolated**: Only recurring accidentals suggest modulation
- **Sharpest of sharps**: When multiple sharps appear, the last one in key-signature order is likely scale degree 7
- **Canceled accidentals**: These return to the original key or are chromatic embellishments
