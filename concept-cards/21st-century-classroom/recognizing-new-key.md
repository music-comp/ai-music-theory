# Quick Definition
To recognize a new key after modulation, look for recurring accidentals that suggest a new key signature, with sharps typically creating leading tones and flats creating scale degree 4.

# Formal Definition
When examining music containing modulations, recurring accidentals provide clues to the new key. Lowered notes (flats) usually create scale degree 4, while raised notes (sharps) often create scale degree 7 (the leading tone). When there are multiple raised notes, the "sharpest of sharps" in key signature order indicates scale degree 7. Accidentals that are canceled out typically indicate tonicizations or chromatic non-chord tones rather than modulation.

# Construction/Recognition
Steps to identify new key:
1. Look for RECURRING accidentals (not just occasional chromatics)
2. Add recurring accidentals to the key signature mentally
3. For sharps: identify which sharp is acting as scale degree 7 (leading tone)
   - Multiple sharps: the "sharpest of sharps" (latest in key signature order) = 7
4. For flats: identify which flat is acting as scale degree 4
5. If accidentals cancel out (natural signs), suspect tonicization, not modulation

# Musical Context
- Sharp accidentals: usually creating leading tones in new key
- Flat accidentals: usually creating scale degree 4 in new key
- Canceling accidentals: returning to original key or chromatic passing tones
- Context of cadences confirms the analysis

# Examples
J.S. Bach, English Suite No. 4 in F Major, Sarabande:
- Original key: F major (one flat)
- Recurring C# indicates modulation
- C# as leading tone suggests D minor or D major
- Cadence confirms the new key

# Common Confusions
- Not all accidentals indicate modulation (could be secondary chords or NCTs)
- Look for RECURRING accidentals, not isolated ones
- The "sharpest of sharps" principle helps with multiple new sharps
- Canceled accidentals suggest temporary, not permanent, key change
