# Quick Definition
Different types of chromatic chords can be distinguished by their quality, accidentals, characteristic intervals, or specific scale degree relationships.

# Formal Definition
When analyzing chromatic harmonies, specific features help identify each chord type:
- Secondary dominants: Major triad or Mm7 quality
- Secondary diminished: Diminished, half-diminished, or fully diminished quality
- Mode mixture: Lowered accidentals (flat-6, flat-3, flat-7)
- Neapolitan: flat-II (major triad on lowered 2)
- Augmented sixth: Contains a diminished third when stacked in thirds

# Construction/Recognition
| Chromatic Chord Type | What to Look For | Chord Labels |
|---------------------|------------------|--------------|
| Secondary Dominant | QUALITY: M triad or Mm7 | V/, V7/ |
| Secondary Diminished | QUALITY: dim, half-dim7, fully dim7 | vii°/, vii-half-dim7/, vii°7/ |
| Mode Mixture | ACCIDENTALS: lowered notes | ii°, ii-half-dim7, iv, vii°7, bVI, etc. |
| Neapolitan | flat-II | N |
| Augmented Sixth | diminished 3rd interval | It+6, Fr+6, Ger+6, EnGer+6 |

# Musical Context
- Secondary chords tonicize diatonic chords
- Mode mixture borrows from parallel minor
- Neapolitan and augmented sixth chords have pre-dominant function
- Context and resolution help confirm identification

# Examples
Analysis process:
1. Stack chord in thirds to identify root and quality
2. Check for diminished third (= augmented sixth chord)
3. Look for Mm7 quality (= secondary dominant OR Ger+6)
4. Check for lowered scale degrees (= mode mixture or Neapolitan)
5. Consider function and resolution

# Common Confusions
- Ger+6 sounds like a dominant 7th but functions differently
- Both Neapolitan and mode mixture use lowered scale degrees
- The diminished third is the key identifier for augmented sixth chords
- Context and resolution are essential for accurate analysis
