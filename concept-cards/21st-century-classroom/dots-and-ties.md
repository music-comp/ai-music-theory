# Quick Definition
A dot adds half the value of a note to its duration; a tie connects two notes of the same pitch into a single sustained sound.

# Formal Definition
A dot placed after a note increases its duration by half its original value. A second dot adds half the value of the first dot (quarter of the original). A tie is a curved line connecting two notes of the same pitch, combining their durations into one continuous sound. Ties can cross bar lines; dots cannot.

# Construction/Recognition
- Dot: small dot placed to the right of the notehead
- Dotted half note = 3 beats (2 + 1) in 4/4
- Dotted quarter note = 1.5 beats in 4/4
- Double-dotted note: adds half the first dot's value (1 + 0.5 + 0.25)
- Tie: curved line between two notes of the same pitch

# Musical Context
Dots and ties allow composers to notate durations that cannot be expressed with single note values. Ties are essential for sustaining notes across bar lines and for creating rhythms that span beat boundaries.

# Examples
- Dotted half note = half note + quarter note = 3 quarter notes
- Dotted quarter note = quarter note + eighth note = 3 eighth notes
- A tie from beat 4 to beat 1 sustains a note across the bar line
- Double-dotted half note = 3.5 beats in 4/4

# Related Concepts
- Note values

- Slur (different from tie)

# Common Confusions
- Tie vs. slur: ties connect same pitches; slurs connect different pitches and indicate legato
- Only the first tied note is attacked; subsequent notes sustain
- Dots extend notes; ties combine note durations
