# Quick Definition
A dot adds half the value of a note to its duration; a tie links two notes of the same pitch into a single sustained sound.

# Core Definition
A tie links two notes together to create a new duration. Ties occur between notes of the same pitch. A slur, which looks like a tie, is placed over or under notes of different pitches and means to play them in a connected manner. A dot added to a note increases the duration of that note by half. A second dot represents half the value of the first dot, or a quarter of the original duration (these are known as "double-dotted notes").

# Prerequisites
- **Note values**: The base durations that dots and ties modify

# Key Properties
1. Dot: increases note duration by half its original value
2. Double dot: first dot adds half, second dot adds quarter of original
3. Tie: curved line connecting two notes of the same pitch
4. Ties combine durations into one continuous sound
5. Only the first tied note is attacked; subsequent notes sustain
6. Ties can cross bar lines; dots cannot

# Construction / Recognition
- Dot: small dot placed to the right of the notehead
- Dotted half note = 2 + 1 = 3 beats (in 4/4)
- Dotted quarter note = 1 + 0.5 = 1.5 beats (in 4/4)
- Double-dotted half note = 2 + 1 + 0.5 = 3.5 beats (in 4/4)
- Tie: curved line between two noteheads of the same pitch

# Context & Application
Dots and ties allow composers to notate durations that cannot be expressed with single note values. Ties are essential for sustaining notes across bar lines and for creating syncopated rhythms. Dotted notes are fundamental to compound meter (the beat in 6/8 is a dotted quarter).

# Examples
- Dotted half note = half note + quarter note = 3 quarter-note beats
- Dotted quarter note = quarter note + eighth note = 3 eighth-note beats
- A tie from beat 4 to beat 1 sustains a note across the bar line
- Double-dotted half note = 2 + 1 + 0.5 = 3.5 beats in 4/4

# Common Errors
- Confusing ties with slurs (ties connect same pitches; slurs connect different pitches)
- Attacking every tied note instead of sustaining through

# Common Confusions
- **Tie vs. slur**: Ties connect notes of the same pitch (creating one longer sound); slurs connect notes of different pitches (indicating legato playing)
- **Dots extend; ties combine**: A dot extends one note; a tie combines two separate notes into one duration
- **Only first note attacked**: In a tied pair, only the first note is struck; the second sustains
