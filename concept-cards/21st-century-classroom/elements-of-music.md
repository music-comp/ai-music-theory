# Quick Definition
The elements of music are the fundamental components that can be varied to create contrast between sections: melody, harmony, rhythm, timbre, texture, articulation, dynamics, and register.

# Formal Definition
Creating contrast usually involves varying one or more of the Elements of Music: (1) Melody - identifiable melodic ideas; (2) Harmony - key and mode; (3) Rhythm - common rhythmic values; (4) Timbre - tone colors of instruments; (5) Texture - vertical and horizontal density; (6) Articulation - staccato vs. legato; (7) Dynamics - loud vs. soft; (8) Register - high vs. low.

# Analysis/Application
When analyzing contrast between sections, consider:
1. Which elements change between sections?
2. Which elements remain constant?
3. How dramatic is the change?
4. Do changes occur gradually or suddenly?

# Musical Context
Understanding the elements of music enables composers and arrangers to create effective contrast and variety while maintaining unity. Different combinations of changes create different effects.

# Examples
See Mozart, Eine kleine Nachtmusik, K. 525, II for analysis of all elements across sections:
- A section: C major, eighth notes common, legato, soft
- B section: More staccato, all voices together rhythmically, sixteenth-note runs
- C section: C minor, sixteenth notes in accompaniment, imitation, mixed articulation

# Common Confusions
- Melody is different from ostinato (melody has variety and breathes)
- Multiple elements typically change together between sections
- Some elements may remain constant to provide unity
