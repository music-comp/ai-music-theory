# Quick Definition
The elements of music are eight fundamental components that can be varied to create contrast between sections: melody, harmony, rhythm, timbre, texture, articulation, dynamics, and register.

# Core Definition
Creating contrast usually involves varying one or more of the "Elements of Music": (1) Melody -- identifiable melodic ideas (not to be confused with ostinato, which lacks variety). (2) Harmony -- key and mode (major vs. minor). (3) Rhythm -- what the most common rhythmic value is. (4) Timbre -- different tone colors of instruments and their variations. (5) Texture -- vertical (number of voices) and horizontal (rhythmic activity) dimensions. (6) Articulation -- staccato (short/clipped) vs. legato (sustained/connected). (7) Dynamics -- loud vs. soft. (8) Register -- high vs. middle vs. low.

# Prerequisites
- None (fundamental conceptual framework)

# Key Properties
1. Melody: identifiable ideas with variety (not ostinato)
2. Harmony: key and mode
3. Rhythm: most common rhythmic value in a section
4. Timbre: tone colors of instruments
5. Texture: vertical (voices) and horizontal (rhythmic activity)
6. Articulation: staccato vs. legato
7. Dynamics: loud vs. soft
8. Register: high vs. middle vs. low

# Construction / Recognition
1. For each section, identify the state of each element
2. Compare across sections to find what changes
3. Note which elements remain constant
4. Use this framework for both analysis and composition

# Context & Application
Understanding the elements of music enables composers and arrangers to create effective contrast and variety while maintaining unity. Different combinations of changes create different effects. This framework applies equally to classical and popular music.

# Examples
- Mozart, Eine kleine Nachtmusik, K. 525, II:
  - A section: C major, 8th notes common, legato, soft
  - B section: more staccato, all voices rhythmically together, 16th-note runs
  - C section: C minor, 16th notes in accompaniment, imitation, mixed articulation

# Common Errors
- Confusing melody with ostinato (melody has variety; ostinato repeats)

# Common Confusions
- **Melody vs. ostinato**: Melody "lives and breathes and has variety"; ostinato repeats
- **Multiple elements typically change together**: Sections rarely differ by just one element
- **Some elements stay constant for unity**: Not everything needs to change
