# Quick Definition

Non-chord tones are common in chorale-style writing and add melodic interest, but adding them to otherwise correct voice leading can inadvertently create parallel fifths and octaves if not carefully placed.

# Core Definition

Non-chord tones are common in J.S. Bach's 371 Chorales, which are the model for voice leading. When adding non-chord tones to an otherwise correct voice leading framework, one must avoid creating objectionable parallels. The embellishments themselves can form parallel 5ths or 8ves with other voices if not carefully placed (Hutchinson, Ch. 28, pp. 410-411).

# Key Properties

1. First complete basic voice leading without NCTs
2. NCTs add melodic interest to individual voices
3. NCTs can inadvertently create parallel 5ths and 8ves
4. The NCT itself participates in voice leading (counts as part of the line)
5. Bach chorales demonstrate extensive NCT usage within proper voice leading

# Construction / Recognition

## Workflow:
1. Complete the basic voice leading framework (all chord tones only)
2. Check that the framework is correct (no parallels, proper doubling/spacing)
3. Add NCTs to individual voices
4. Re-check for parallels created by the NCTs
5. If simultaneous NCTs: ensure they form consonant intervals

# Context & Application

- **Typical contexts**: Chorale harmonizations, Baroque-style writing
- **Historical/stylistic notes**: Bach's chorales frequently use NCTs while maintaining contrapuntal integrity

# Examples

**Example 1** (p. 410): J.S. Bach, Chorale 323, "Wie schon leuchtet der Morgenstern" -- rich NCT usage

**Example 2** (p. 411): J.S. Bach, Chorale 326, "Allein Gott in der Hoh' sei Ehr" -- demonstrates NCT usage

# Common Errors

- **Error**: Assuming that a correct framework means any embellishments are safe
  **Correction**: NCTs can create NEW parallels that did not exist in the framework

# Common Confusions

- **Confusion**: NCTs do not "count" in voice leading
  **Clarification**: NCTs are part of the melodic line and participate in creating intervals with other voices
