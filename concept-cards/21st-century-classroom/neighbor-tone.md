# Quick Definition
A neighbor tone is a non-chord tone approached by step and left by step in the opposite direction, moving away from a chord tone and returning to it.

# Formal Definition
Neighbor tones move away from a note by step then return to the original note by step in the opposite direction. They can be upper neighbors (step up then step down) or lower neighbors (step down then step up), and can be accented or unaccented.

# Analysis/Application
To identify neighbor tones:
1. Look for a note that departs from and returns to the same pitch
2. Confirm stepwise motion in both directions
3. The surrounding notes should be the same pitch
4. Label as NT (or N.T.), specifying upper (UNT) or lower (LNT) if needed

# Musical Context
Neighbor tones embellish a sustained or repeated pitch by briefly departing and returning. They create melodic interest without actually progressing to a new pitch.

# Examples
- Beethoven, Minuet in G, WoO 10, No. 2 - neighbor tones embellishing the melody

# Common Confusions
- Neighbor tones return to the original note; passing tones continue in the same direction
- Upper neighbor = step up then down; lower neighbor = step down then up
- The incomplete neighbor is a variant that lacks either the approach or return
