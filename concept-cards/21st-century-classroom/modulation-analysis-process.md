# Quick Definition
To analyze a modulation: first listen for the cadence in the new key and work backward to find pre-dominant chords, then analyze from the phrase beginning forward to find the logical pivot point where the two key analyses overlap.

# Core Definition
The analysis of a modulation proceeds in a specific order: (1) Listen to the music to hear the cadence in the new key. (2) Work backward from the cadence to see if the dominant in the new key was approached by pre-dominant chords (ii or IV) in the new key. (3) Analyze from the beginning of the phrase until you reach the new key. (4) Look for a logical pivot point where a chord can be analyzed in both keys. If two successive chords could logically be pivot chords, include both on either side of the pivot bracket.

# Prerequisites
- **Modulation**: Understanding what constitutes a modulation
- **Tonicization vs. modulation**: Knowing the distinction
- **Cadential formula**: Recognizing what confirms a new key

# Key Properties
1. Start by identifying the cadence in the new key
2. Work BACKWARD from the cadence to find pre-dominants
3. Then analyze FORWARD from the phrase beginning
4. The pivot is where forward and backward analyses meet
5. Two successive chords may both be valid pivots
6. Use a pivot bracket for the dual analysis

# Construction / Recognition
Step-by-step process:
1. Listen: hear where the new key is established (the cadence)
2. Backward: identify V(7)-I in new key, then pre-dominants before V
3. Forward: analyze Roman numerals from phrase beginning in original key
4. Pivot: find where the two analyses overlap (chord diatonic in both keys)
5. Bracket: show dual Roman numeral analysis for the pivot chord(s)
6. If ambiguous: include multiple chords in the pivot bracket

# Context & Application
This reverse-then-forward analytical approach is more reliable than trying to identify the pivot while analyzing linearly through the music. By starting with the cadence (the most certain evidence), the analyst anchors the analysis in the confirmed new key and then traces the transition backward. The forward analysis from the phrase beginning completes the picture, and the pivot emerges where the two analyses overlap.

# Examples
- J.S. Bach, Christmas Oratorio, "Ermuntre dich" -- applying the analysis process to find pivot chords
- Robert Schumann, "Little Morning Wanderer" -- analysis process with dual key interpretation

# Common Errors
- Analyzing only forward and missing the pivot
- Not starting from the cadence in the new key

# Common Confusions
- **Backward first**: Start from the cadence, not from the beginning of the phrase
- **Two valid pivots**: If ambiguous, include both in the bracket -- this is acceptable
- **Forward analysis completes the picture**: After backward analysis identifies the new key area, forward analysis reveals the original key context
