# Quick Definition
Rests are symbols indicating silence for a specific duration, with each rest value corresponding to a note value of the same length.

# Formal Definition
Rests are durational symbols that indicate silence rather than sound. Each note value has a corresponding rest of equal duration. Rests follow the same mathematical relationships as notes: each rest value is half the duration of the next larger rest.

# Construction/Recognition
- Whole rest: rectangle hanging from line 4 (fills entire measure in any meter)
- Half rest: rectangle sitting on line 3 (2 beats in 4/4)
- Quarter rest: squiggly vertical symbol (1 beat in 4/4)
- Eighth rest: flag-like symbol with one hook
- Sixteenth rest: two hooks; thirty-second rest: three hooks

# Musical Context
Rests are as important as notes in shaping musical phrases and rhythms. They create space, articulation, and dramatic effect. Proper rest notation is essential for clear rhythmic communication.

# Examples
- A whole rest fills an entire measure regardless of time signature
- Two half rests equal one whole rest
- Four quarter rests equal one whole rest
- Eighth rests have one "hook," sixteenth rests have two

# Common Confusions
- Whole rest vs. half rest: whole rest hangs down, half rest sits up
- A whole rest indicates "rest for the entire measure" in any meter
- Rests cannot be tied (use longer rest values instead)
