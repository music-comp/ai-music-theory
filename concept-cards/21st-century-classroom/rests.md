# Quick Definition
Rests are durational symbols indicating silence, with each rest value corresponding to a note value of the same length.

# Core Definition
Rests are durational symbols that indicate measured silence rather than sound. Each note value has a corresponding rest of equal duration. Rests follow the same mathematical relationships as notes: each rest value is half the duration of the next larger rest.

# Prerequisites
- **Note values**: The sound durations that rests mirror as silence

# Key Properties
1. Whole rest: rectangle hanging from line 4 (also fills an entire measure in any meter)
2. Half rest: rectangle sitting on line 3
3. Quarter rest: squiggly vertical symbol
4. Eighth rest: flag-like symbol with one hook
5. Sixteenth rest: two hooks; thirty-second rest: three hooks
6. Each rest has the same duration as its corresponding note value

# Construction / Recognition
- Whole rest hangs down from the fourth line
- Half rest sits up on the third line
- Quarter rest is a distinctive squiggly shape
- Eighth and shorter rests have increasing numbers of hooks

# Context & Application
Rests are as important as notes in shaping musical phrases and rhythms. They create space, articulation, and dramatic effect. A whole rest in any meter indicates "rest for the entire measure."

# Examples
- A whole rest fills an entire measure regardless of time signature
- Two half rests equal one whole rest
- Four quarter rests equal one whole rest
- Eighth rests have one hook; sixteenth rests have two

# Common Errors
- Confusing whole rest and half rest (whole hangs down, half sits up)
- Trying to tie rests together (rests cannot be tied; use a longer rest value)

# Common Confusions
- **Whole rest vs. half rest**: Whole rest hangs down, half rest sits up -- "the whole rest is heavier so it hangs"
- **Whole rest special rule**: A whole rest indicates "rest for the entire measure" in any time signature, not just 4/4
