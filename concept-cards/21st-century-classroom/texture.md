# Quick Definition
Texture describes the vertical and horizontal elements of music -- how many voices or parts sound simultaneously (vertical) and the rhythmic activity of those parts (horizontal).

# Core Definition
Texture is considered in terms of vertical and horizontal elements. The vertical nature relates to the number of notes occurring simultaneously as harmonies, or the number of voices/instruments performing melodies in a contrapuntal texture. The horizontal element relates to rhythmic activity: whether the most common rhythmic values are slow or fast. Both dimensions interact to create the overall textural character.

# Prerequisites
- None (fundamental concept)

# Key Properties
1. Vertical: number of simultaneous voices/notes
2. Horizontal: rhythmic activity and common note values
3. Both dimensions contribute to textural character
4. Texture can change between sections to create contrast
5. More voices does not always mean "thicker" -- rhythmic activity matters too

# Construction / Recognition
1. Count the number of independent voices/parts (vertical)
2. Observe the rhythmic density and common note values (horizontal)
3. Note how voices are grouped (pairs, all together, independent)
4. Consider how texture changes between sections

# Context & Application
Texture is one of the elements of music that can be varied to create contrast between sections. Changes in texture help articulate form and create variety. Understanding texture aids both analysis and composition/arrangement.

# Examples
- Barber, Adagio for Strings (1936) -- five-voice chords with slow rhythms: thick vertically, slow horizontally
- Mozart, String Quartet K. 428, IV (1783) -- four voices with active sixteenth notes and syncopation: lighter vertically but rhythmically active horizontally

# Common Errors
- Equating more voices with thicker texture (rhythmic activity also matters)
- Confusing texture with dynamics

# Common Confusions
- **Two dimensions**: Texture has both vertical (simultaneous) and horizontal (rhythmic) components
- **Not the same as dynamics**: A piece can be texturally thick but dynamically soft
- **Not the same as articulation**: Staccato/legato is a separate element
