# Quick Definition
Texture describes the vertical and horizontal elements of music - how many voices or parts sound simultaneously (vertical) and the rhythmic activity of those parts (horizontal).

# Formal Definition
Texture exists in both vertical and horizontal dimensions. The vertical nature relates to the number of notes occurring simultaneously as harmonies or the number of voices/instruments performing melodies in a contrapuntal texture. The horizontal element relates to rhythmic activity: whether the most common rhythmic values are slow or fast.

# Analysis/Application
When analyzing texture:
1. Count the number of independent voices/parts (vertical)
2. Observe the rhythmic density and common note values (horizontal)
3. Note how voices are grouped (pairs, all together, etc.)
4. Consider how texture changes between sections

# Musical Context
Texture is one of the elements of music that can be varied to create contrast between sections. Changes in texture help articulate form and create variety.

# Examples
- Barber, Adagio for Strings (1936) - 5-voice chords with slow rhythms, thick and slow texture
- Mozart, String Quartet K. 428, IV (1783) - 4 voices with active sixteenth notes and syncopation, lighter but rhythmically active texture

# Common Confusions
- Texture is distinct from dynamics (loud/soft) or articulation (staccato/legato)
- More voices doesn't always mean "thicker" texture - it depends on rhythmic activity too
- Texture has both vertical (simultaneous) and horizontal (rhythmic) components
