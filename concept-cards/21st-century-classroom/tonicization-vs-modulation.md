# Quick Definition
Tonicization is a brief, temporary emphasis on a non-tonic chord using secondary chords, while modulation is a more permanent key change confirmed by a cadence.

# Formal Definition
Tonicization involves secondary chords and can be as short as two chords (V/V to V) but can sometimes encompass several measures. Modulation requires a cadence to confirm the new key, typically with a cadential formula: pre-dominant - dominant - tonic. The distinction lies in the permanence of the tonal shift and its confirmation through cadential motion.

# Construction/Recognition
Tonicization characteristics:
- Brief (can be two chords)
- Uses secondary dominants/diminished chords
- Returns to original key without cadence in "new" key
- Analyzed with secondary chord symbols (V/V, vii°/ii, etc.)

Modulation characteristics:
- Longer duration
- Confirmed by cadence in new key
- Uses pivot chords (common chords between keys)
- New key is analyzed with its own Roman numerals

Cadential formula for modulation:
Pre-dominant (ii, IV, N6, +6) - Dominant (V, V7) - Tonic (I)

# Musical Context
- Baroque: frequent tonicizations within modulating passages
- Fast harmonic rhythm creates ambiguity (Bach chorales)
- Longer tonicizations may be analyzed either way
- Contextual judgment required

# Examples
- Schubert, Schwanegesang, "Abschied" (1828):
  - Extended tonicization spanning several measures
  - Underlying diatonic progression revealed through reduction

# Common Confusions
- Extended tonicizations can look like short modulations
- The presence of a cadence in the new key is the key distinction
- Context and duration help determine the analysis
- Some passages are genuinely ambiguous
