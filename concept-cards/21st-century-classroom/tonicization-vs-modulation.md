# Quick Definition
Tonicization is brief and temporary (can be two chords, no cadence in "new" key), while modulation requires cadential confirmation in the new key -- typically with a "full cadence": pre-dominant followed by dominant followed by tonic.

# Core Definition
Tonicization can be as short as two chords (V/V to V) but can sometimes encompass several measures. Modulation requires a cadence to confirm the new key. The cadential formula to establish a key is: pre-dominant (ii, IV, N6, or +6) to dominant (V or V7) to tonic (I). Douglass Green calls this a "full cadence" -- a V-I authentic cadence with a pre-dominant prefix. This establishes a key more strongly than a simple V-I, which means there will be ambiguity between tonicization and short modulation, especially in fast harmonic rhythm.

# Prerequisites
- **Tonicization**: The temporary emphasis being contrasted
- **Modulation**: The permanent key change being contrasted

# Key Properties
1. Tonicization: brief, no cadence in "new" key, analyzed with secondary chord symbols
2. Modulation: longer, confirmed by cadence, analyzed with new key's Roman numerals
3. Cadential formula: pre-dominant - V(7) - I in new key
4. "Full cadence" (Green): pre-dominant + authentic cadence
5. Fast harmonic rhythm creates analytical ambiguity
6. Some passages are genuinely ambiguous

# Construction / Recognition
To determine tonicization vs. modulation:
1. Listen for a cadence in the new key
2. Check if the cadence has a pre-dominant prefix (making it a "full cadence")
3. If yes: modulation; if no cadence: tonicization
4. Extended tonicizations may span several measures but lack cadential confirmation
5. Context and duration provide additional clues
6. A harmonic reduction can reveal the underlying diatonic progression

# Context & Application
The distinction matters for analysis: tonicizations are analyzed with secondary chord labels (V/V, viio/ii), while modulations establish new Roman numeral contexts. In Bach chorales, with their fast quarter-note harmonic rhythm, the distinction is often ambiguous. Schubert's "Abschied" provides an example of extended tonicization that could be analyzed either way. The underlying diatonic progression can be revealed through reduction.

# Examples
- Schubert, Schwanegesang, "Abschied" (1828) -- extended tonicization spanning several measures with underlying diatonic progression revealed through reduction
- J.S. Bach, English Suite No. 4, Sarabande -- cadential formula establishing new key
- J.S. Bach chorales -- frequent analytical ambiguity due to fast harmonic rhythm

# Common Errors
- Insisting on modulation for every passage with chromaticism
- Failing to look for cadential confirmation before labeling as modulation

# Common Confusions
- **The cadential formula**: Pre-dominant + V + I is stronger than V-I alone for establishing a key
- **Genuine ambiguity**: Some passages truly are ambiguous; acknowledge this rather than forcing a label
- **"Full cadence"**: Douglass Green's term for pre-dominant + authentic cadence
