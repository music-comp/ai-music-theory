# Quick Definition
Binary principle states that the first section of a binary form modulates to a new key and the second section modulates back to the original key.

# Formal Definition
Binary principle, as defined by Peter Spencer and Peter Temko in A Practical Approach to the Study of Form in Music, states that the first section of a binary form modulates to a new key and the second section modulates back to the first key. This principle is exemplified in a high percentage of binary forms in the Baroque era.

# Construction/Recognition
Tonal plan diagram:

For major keys:
| First Section | Second Section |
| I --> V | V --> I |
| Original key | New key --> Original key |

For minor keys:
| First Section | Second Section |
| i --> III (or v) | III (or v) --> i |
| Original key | New key --> Original key |

Key characteristics:
- First section establishes tonic, then modulates
- Second section begins in new key, returns to tonic
- The tonal journey away and back creates large-scale structure

# Musical Context
- Foundational principle of Baroque binary forms
- Anticipates the tonal plan of sonata form
- Creates sense of departure and return
- The secondary key creates "tension" resolved by return to tonic

# Examples
- Most Baroque dance movements follow binary principle
- J.S. Bach dance suites consistently demonstrate this pattern
- The principle underlies the evolution toward sonata form

# Related Concepts
- Binary form
- Modulation

# Common Confusions
- Binary principle is about TONAL plan, not thematic content
- Not all binary forms follow binary principle (sectional binary may not modulate)
- The new key in minor can be III (relative major) or v (minor dominant)
- This principle connects binary form to later sonata form
