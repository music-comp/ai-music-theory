# Quick Definition

Binary principle states that the first section of a binary form modulates to a new key and the second section modulates back to the original key.

# Core Definition

Binary principle, as defined by Peter Spencer and Peter Temko in *A Practical Approach to the Study of Form in Music*, states that the first section of a binary form modulates to a new key and the second section modulates back to the first key. This principle is exemplified in a high percentage of binary forms in the Baroque era (Hutchinson, Ch. 24, p. 353).

# Prerequisites

- **Binary form** -- Binary principle describes the tonal plan within binary forms
- **Modulation** -- The principle is fundamentally about key changes

# Key Properties

1. First section: establishes tonic, then modulates to a new key
2. Second section: begins in the new key, modulates back to tonic
3. In major keys: I to V, then V back to I
4. In minor keys: i to III (or v), then III (or v) back to i
5. Creates large-scale tonal departure and return
6. Found in a high percentage of Baroque binary forms

# Construction / Recognition

## Tonal Plan:
- **Major**: First Section (I --> V) | Second Section (V --> I)
- **Minor**: First Section (i --> III or v) | Second Section (III or v --> i)

## To Identify Binary Principle:
1. Determine the key at the beginning and end of each section
2. If first section moves away from tonic and second section returns: binary principle

# Context & Application

- **Typical contexts**: Baroque dance suites and binary movements
- **Common applications**: Nearly universal in Baroque binary forms
- **Historical/stylistic notes**: Anticipates the tonal plan of sonata form; the tonal journey of departure and return is a foundational organizing principle in tonal music

# Common Errors

- **Error**: Expecting all binary forms to follow binary principle
  **Correction**: Sectional binary forms that end the first section on tonic may not follow binary principle

# Common Confusions

- **Confusion**: Thinking binary principle is about thematic content
  **Clarification**: Binary principle is purely about the TONAL plan (modulation away and back), not about themes

- **Confusion**: Believing the new key must always be the dominant
  **Clarification**: In minor keys, the new key is often III (relative major) or v (minor dominant)
