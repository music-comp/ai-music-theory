# Quick Definition
Impressionism is a late 19th/early 20th century style characterized by modal harmony, extended chords (9ths, 11ths, 13ths), and parallelism (planing), primarily associated with Debussy and Ravel.

# Core Definition
Impressionism is associated with Claude Debussy and Maurice Ravel (France), Ottorino Respighi (Italy), Charles Tomlinson Griffes (America), and Frederick Delius (England). The textbook focuses on three techniques: (1) use of modes as an alternative to chromaticism, (2) use of upper extensions (9ths, 11ths, 13ths, sometimes with chromatic alterations), and (3) parallelism (planing) where chord voicings move in parallel motion (Hutchinson, Ch. 32, p. 464).

# Prerequisites
- **Scales and modes** -- Modal writing is one of the three core techniques
- **Seventh chords** -- Extended tertian chords build upon seventh chord structures

# Key Properties
1. Three main techniques: modes, upper extensions, parallelism
2. Emerged as reaction against Wagner's chromaticism
3. Uses church modes (Phrygian, Lydian, Dorian, etc.)
4. Chords with 9ths, 11ths, 13ths (sometimes chromatically altered)
5. Parallelism/planing: all voices move in same direction by same interval
6. Harmonic function is de-emphasized

# Construction / Recognition
**The three techniques:**
1. **Modal writing**: Phrygian, Lydian, Dorian, etc. instead of major/minor
2. **Extended tertian harmony**: 9ths, 11ths, 13ths with possible chromatic alterations
3. **Parallelism (planing)**: Entire chord voicings move in parallel motion

# Context & Application
Impressionism emerged as a deliberate reaction against Wagner's chromaticism (particularly *Tristan und Isolde*). Composers sought new sounds through modes, extended chords, and non-functional harmony. The style profoundly influenced 20th-century harmony and jazz.

# Examples
- Debussy, String Quartet, Op. 10, I: Phrygian mode (p. 465)
- Debussy, *Danses*, II "Danse profane": Lydian mode (p. 465)
- Ravel, Piano Trio, I: Dorian mode, later Lydian (pp. 466)
- Debussy, "Clair de lune": Ebm9 with 9th in melody (p. 467)
- Ravel, *Pavane pour une infante defunte*: Parallel dominant 9ths (p. 468)
- Debussy, *Prelude to the Afternoon of a Faun*: Chromatically ascending dom7ths (p. 469)

# Common Errors
- **Error**: Analyzing impressionist harmony using only classical Roman numeral analysis
  **Correction**: Impressionist chords often function for color rather than functional progression

# Common Confusions
- **Confusion**: Thinking impressionism is merely "atmospheric" or vague
  **Clarification**: It has three specific technical characteristics (modes, extensions, planing)
- **Confusion**: Thinking modal equals atonal
  **Clarification**: Modal music has clear tonal centers; it avoids major/minor, not tonality itself
