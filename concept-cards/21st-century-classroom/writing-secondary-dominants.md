# Quick Definition
To write a secondary dominant: identify the target chord's root (after the slash), build V or V7 in that chord's key (root a P5 above), construct the major or Mm7 chord, then apply the specified inversion.

# Core Definition
To write a secondary dominant, follow this procedure: (1) Determine the root of the chord being tonicized (the Roman numeral after the slash). (2) Determine the root of V or V7 in the key of that chord (a perfect fifth above the target root). (3) Build a major triad or major-minor seventh chord on that root. (4) Invert the chord according to the figured bass symbols.

# Prerequisites
- **Secondary dominant**: Understanding the concept
- **Figured bass inversion symbols**: Knowing which note goes in the bass for each inversion

# Key Properties
1. Target chord = Roman numeral after the slash
2. Secondary dominant root = P5 above the target root
3. Build major triad or Mm7 on that root
4. Apply the specified inversion
5. Double-check by analyzing backward to verify

# Construction / Recognition
Worked example -- V4/3/IV in C major:
1. IV in C major = F major; root of IV is F
2. V7 in F major: root is C (P5 above F)
3. Build Mm7 on C: C-E-G-Bb
4. 4/3 = second inversion = fifth (G) in bass
5. Result: G-Bb-C-E

Worked example -- V6/5/V in Eb major:
1. V in Eb = Bb; root is Bb
2. V7 in Bb: root is F (P5 above Bb)
3. Build Mm7 on F: F-A-C-Eb
4. 6/5 = first inversion = third (A) in bass
5. Result: A-C-Eb-F

# Context & Application
Writing secondary dominants is an essential skill for harmonization, arranging, and composition. The procedure builds on understanding of key relationships and chord construction. Always verify your result by analyzing the chord back using the analyzing-secondary-dominants procedure to confirm correctness.

# Examples
- V4/3/IV in C major: target F, build C7, invert to G in bass = G-Bb-C-E
- V6/5/V in Eb major: target Bb, build F7, invert to A in bass = A-C-Eb-F

# Common Errors
- Forgetting to apply accidentals for the target key area
- Inverting based on the target chord rather than the chord being built

# Common Confusions
- **Inversion applies to the built chord**: The figured bass describes the secondary dominant, not the target
- **Verify by analyzing back**: After building, use the analysis procedure to confirm your chord is correct
