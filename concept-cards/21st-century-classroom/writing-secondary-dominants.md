# Quick Definition
To write a secondary dominant, identify the target chord's root, build a V or V7 in that chord's key, then apply the specified inversion.

# Formal Definition
To write a secondary dominant: (1) Determine the root of the chord being tonicized (after the slash); (2) Determine the root of V or V7 in that key (a P5 above the target root); (3) Build a major triad or major-minor seventh chord on that root; (4) Invert the chord according to the figured bass.

# Analysis/Application
Example: Write V4/3 of IV in C major
1. IV in C major = F; root of IV is F
2. V7 in F major has root C (P5 above F)
3. Build major-minor seventh: C-E-G-Bb
4. 4/3 = second inversion (5th in bass) = C7/G
5. Result: C-E-G-Bb with G in bass

# Musical Context
Being able to write secondary dominants is essential for harmonization, arranging, and composition. The skill builds on understanding of key relationships and chord construction.

# Examples
V4/3/IV in C major:
- Target: IV (F)
- V7 of F = C7
- 4/3 inversion = 5th (G) in bass
- Notes: G-Bb-C-E

# Common Confusions
- Remember to apply accidentals for the new "key area"
- The inversion is based on the chord you're building, not the target chord
- Always check your answer by analyzing back
