# Quick Definition

Balanced binary form features a first section ending in a new key, with the second section ending with essentially the same cadential material transposed back to the original key.

# Core Definition

According to Douglass Green in *Form in Tonal Music*, balanced binary form features a binary form with a first section (A) ending in a new key, and the second section ending with essentially the same cadence, now transposed to the original key. Because the first section ends in a new key, balanced binary is inherently a continuous binary form (Hutchinson, Ch. 24, p. 347).

# Prerequisites

- **Binary form** -- Balanced binary is a specific subtype of binary form
- **Modulation** -- The first section must modulate to a new key
- **Cadence** -- The "balance" is defined by similar cadential material in both sections

# Key Properties

1. First section ends in a NEW key (typically V or III)
2. Second section ends with the SAME cadential material, transposed to the original key
3. Always continuous (first section modulates, so it never ends on tonic)
4. The similar endings create the "balance" between sections
5. Common in Baroque era dance movements

# Construction / Recognition

## To Identify Balanced Binary:
1. Confirm the piece is in binary form (two sections)
2. Check that the first section ends in a new key (continuous)
3. Compare the endings of both sections
4. If the second section's ending is the first section's ending transposed to tonic: balanced binary

# Context & Application

- **Typical contexts**: Baroque dance suites (courantes, gavottes, etc.)
- **Common applications**: Found in movements by Bach, Handel, and other Baroque composers
- **Historical/stylistic notes**: Douglass Green coined/codified the term; Green also notes sonata form evolved partly from balanced binary

# Examples

**Example 1** (p. 347-348): J.S. Bach, Invention No. 8 in F major, BWV 779 -- balanced binary with similar cadential material in both sections

**Example 2** (pp. 348-349): J.S. Bach, French Suite No. 6 in E major, BWV 817, Courante -- bars 15-16 end the first section in the dominant; bars 31-32 end the second section with similar material transposed to tonic

- **Sonata form** -- Green notes sonata form evolved partly from balanced binary (closing material returns in tonic)

## Related
- **Binary principle** -- Both concern tonal journey away from and back to tonic

## Contrasts With
- **Rounded binary** -- Rounded has similar BEGINNINGS (return of opening); balanced has similar ENDINGS
- **Simple binary** -- Simple lacks both similar endings and return of opening material

# Common Errors

- **Error**: Looking for similar beginnings rather than similar endings
  **Correction**: The "balance" refers to cadential material at the END of each section

- **Error**: Classifying a balanced binary as sectional
  **Correction**: Balanced binary is always continuous because the first section must modulate

# Common Confusions

- **Confusion**: Thinking "balanced" means the sections are equal in length
  **Clarification**: "Balanced" refers to the similar cadential endings, not proportional length
