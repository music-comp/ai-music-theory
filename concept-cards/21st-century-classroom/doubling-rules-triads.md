# Quick Definition

Doubling rules: root position -- double the bass (root); first inversion -- do NOT double the bass (3rd), with exceptions for diminished triads and consecutive first inversions; second inversion -- double the bass (5th).

# Core Definition

The summary of doubling rules for voice leading triads (Hutchinson, Ch. 26, p. 399):
- **Root Position Chords**: DOUBLE THE BASS
- **First-Inversion Chords**: DO NOT DOUBLE THE BASS
  - Exception: vii-dim and ii-dim in first inversion: DOUBLE THE BASS
  - Exception: Consecutive first-inversion chords: alternate between DOUBLE THE BASS and DO NOT DOUBLE THE BASS
- **Second-Inversion Chords**: DOUBLE THE BASS

# Prerequisites

- **Voice leading** -- Doubling rules are a core voice leading requirement
- **Triad inversions** -- Understanding inversions is necessary to apply doubling rules

# Key Properties

1. Root position: double the bass (= the root)
2. First inversion: do NOT double the bass (= the 3rd)
3. First inversion diminished triads: DO double the bass (exception)
4. Consecutive first inversions: alternate doubling
5. Second inversion: double the bass (= the 5th)
6. Never double the leading tone (3rd of V)

# Construction / Recognition

## Mnemonic:
- Root position: DOUBLE THE BASS
- First inversion: DON'T DOUBLE THE BASS (with exceptions)
- Second inversion: DOUBLE THE BASS

Note: "double the bass" works for root position and second inversion but is specifically reversed for first inversion.

# Context & Application

- **Typical contexts**: All SATB voice leading exercises
- **Historical/stylistic notes**: These rules evolved from practice because doubling certain notes produces better voice leading and avoids forbidden parallels

# Examples

**Example 1**: Root position C major: C-E-G-C (root C doubled)
**Example 2**: First inversion C major: E-G-C-G (root or 5th doubled, NOT E)
**Example 3**: vii-dim first inversion: double the 3rd (bass) because root and 5th are tendency tones
**Example 4**: Cadential 6/4: double the bass (5th of the chord)

# Common Errors

- **Error**: Doubling the leading tone (3rd of V chord)
  **Correction**: NEVER double the leading tone; it creates two voices needing to resolve to ^8

- **Error**: Using the "double the bass" mnemonic for first inversion
  **Correction**: First inversion is the EXCEPTION -- do not double the bass (3rd)

# Common Confusions

- **Confusion**: Thinking "double the bass" means the same note in every inversion
  **Clarification**: The bass note changes with inversion; "double the bass" doubles whichever note is in the bass
