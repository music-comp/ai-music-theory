# Quick Definition
Doubling rules specify which chord member to double when writing four-part triads: root position doubles the bass (root), first inversion does not double the bass (3rd), and second inversion doubles the bass (5th).

# Formal Definition
Since triads have three notes but SATB writing requires four voices, one note must be doubled. The doubling rules for triads are:
- **Root position**: Double the bass (the root)
- **First inversion**: Do NOT double the bass (the 3rd); instead, double the root or fifth
- **Second inversion**: Double the bass (the 5th)

These rules have specific exceptions for diminished triads, consecutive first-inversion chords, and the leading tone.

# Rules/Procedures
1. **Root Position**: Always double the root (which is in the bass)
2. **First Inversion**: Double the root or fifth, NOT the bass (3rd)
   - Exception: Diminished triads in first inversion - always double the bass (3rd)
   - Exception: Consecutive first inversions - alternate doubling the 3rd and not doubling it
   - Exception: When approached by contrary motion in both parts, doubling the 3rd is acceptable
3. **Second Inversion**: Always double the bass (the 5th)
4. **Never double the leading tone** (the 3rd of the V chord)

# Musical Context
These rules evolved from practice because doubling certain notes produces better voice leading and avoids forbidden parallels. The root is the strongest chord member acoustically, so doubling it reinforces the chord identity. Doubling the 3rd of V would create two leading tones requiring resolution to tonic.

# Examples
- Root position C major: C-E-G-C (root doubled)
- First inversion C major: E-G-C-E would double the bass (avoid this); use E-G-C-G instead
- vii diminished first inversion: Double the 3rd (bass note) because the root and 5th are tendency tones
- Cadential 6/4: Double the bass (5th of the chord)

# Common Confusions
- Forgetting the "double the bass" mnemonic works for root position and second inversion but NOT first inversion
- Doubling the leading tone (never do this)
- Not recognizing that diminished triads are an exception in first inversion
- Confusing which note IS the bass vs. which chord member should be doubled
