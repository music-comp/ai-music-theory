# Quick Definition
Elision is a technique for hiding the seam between two phrases by evading the cadence (using V4/2 instead of V5/3), creating one large continuous phrase instead of two separate ones.

# Core Definition
**Elision** is a technique in which a composer hides the seam between two independent phrases by evading the cadence at the end of the first phrase (converting the cadential V to V4/2, which resolves to I6). This averts the potential cadence and thus covers the boundary between the two phrases, creating one large phrase instead of two shorter ones. It differs from cadential extension, which intensifies a cadence by repeating cadential material rather than hiding a phrase boundary (Laitz, Ch. 14, pp. 336-337).

# Prerequisites
- **Evaded cadence** -- the mechanism creating elision

# Key Properties
1. Hides phrase boundaries
2. Uses V4/2 -> I6 to avert expected cadence
3. Creates one large phrase from two shorter ones
4. The second phrase begins seamlessly from the I6

# Examples
**Example 1** (pp. 337-338): Mozart's Symphony K. 114: cad 6/4 in m. 12 converts to V4/2, covering the seam between two four-measure units to create a single eight-measure phrase.
