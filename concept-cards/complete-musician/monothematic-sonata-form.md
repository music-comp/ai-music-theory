# Quick Definition
Monothematic sonata form uses the same theme (often varied) in both the FTA and STA, distinguishing tonal areas by key rather than by contrasting themes.

# Core Definition
Haydn frequently used the same theme (although often varied) in both the FTA and STA, creating a monothematic sonata form. The lack of differentiation between themes plays havoc with attempts to define a "first theme" and "second theme," but poses no problem to the FTA/STA analytical system, which defines tonal areas by key, not theme (Laitz, Ch. 33).

# Prerequisites
- **Sonata Form** -- the underlying form
- **First Tonal Area and Second Tonal Area** -- tonal areas defined by key, not theme

# Key Properties
1. Same theme appears in both FTA and STA
2. Theme may be varied in the STA
3. Tonal areas distinguished by key, not thematic material
4. Particularly associated with Haydn

# Examples
**Example 1** (p. 760): Haydn, String Quartet in A major, op. 55, no. 1 -- Opening FTA theme reappears in the STA in the dominant key.

# Common Errors
- **Error**: Failing to identify the STA because the theme is the same
  **Correction**: The STA is defined by key, not by theme; look for the change of key, not a new melody
