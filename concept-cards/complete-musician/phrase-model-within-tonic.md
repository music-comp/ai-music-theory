# Quick Definition
The T-PD-D-T phrase model can occur at a smaller structural level within the tonic prolongation itself; inversions weaken the progression to prevent confusion with the actual structural cadence.

# Core Definition
Composers often incorporate the T-PD-D-T model **within the tonic prolongation**, creating a miniature, non-cadential version of the phrase model at a subordinate structural level. To prevent the listener from confusing this with the actual structural cadence, the progression is weakened through inversions -- most commonly by following IV or ii6 with V4/2, which maintains ^4 in the bass (resolving to ^3 and I6). This creates a mini PD-D-T within the tonic expansion without producing cadential closure (Laitz, Ch. 12, pp. 296-298).

# Prerequisites
- **Phrase model** -- the full-scale version being embedded
- **Contrapuntal expansion** -- the tonic prolongation within which it occurs

# Key Properties
1. T-PD-D-T occurs at a subordinate level within tonic prolongation
2. Weakened by inversions (especially V4/2 instead of V5/3)
3. V4/2 maintains ^4 in bass, resolving to I6 (not root-position I)
4. Creates musical motion within prolongation without cadential closure
5. Common technique: PD (ii6 or IV) followed by V4/2
