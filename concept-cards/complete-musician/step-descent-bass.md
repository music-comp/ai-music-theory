# Quick Definition
A bass line descending stepwise from ^1 to ^5, creating a powerful tonic-to-dominant motion. Direct descents go ^1-^7-^6-^5; indirect descents continue through ^5 to reach PD on ^4 before returning to ^5.

# Core Definition
Step-descent basses move from tonic to dominant by descending steps. A **direct step-descent bass** falls ^1-^7-^6-^5 directly. An **indirect step-descent bass** overshoots ^5 and continues to ^4 (PD), then returns to ^5, creating a descent by fifth: ^1-^7-^6-^5-^4-^5. Common harmonizations: i-passing v6-iv6-V. In minor, non-functional v6 (with lowered ^7) avoids the augmented second between raised ^7 and lowered ^6. The first ^5 is typically harmonized with a passing 6/3 or 6/4 to avoid premature arrival on dominant. (Laitz, Ch. 18, pp. 434-440)

# Prerequisites
- **Submediant** — vi/VI participates in the descent
- **Contrapuntal expansion** — The descent is a contrapuntal elaboration

# Key Properties
1. Direct: ^1-^7-^6-^5
2. Indirect: ^1-^7-^6-^5-^4-^5
3. In minor, lowered ^7 avoids augmented second (non-functional minor v)
4. Most common harmonization: i-v6-iv6-V
5. More common in minor than major (the half step ^6-^5 is expressive)
6. Can be used as an ostinato (ground bass / chaconne)

# Context & Application
Step-descent basses have been used since the early 17th century (Monteverdi) and appear in works from Purcell's "Dido's Lament" to Ray Charles's "Hit the Road, Jack" and the folk song "Erie Canal."

# Examples
**Example 1** (p. 435): Schutz, "Nacket bin ich" -- diatonic descent i-v6-iv6-V in minor.

**Example 2** (p. 436): "Erie Canal" -- lament bass descent ^1-^7-^6-^5 in minor.

**Example 3** (p. 436): Rachmaninoff, Prelude in G minor, op. 23, no. 5 -- step-descent bass.

# Common Errors
- **Error**: Using raised ^7 (leading tone) in the bass descent, creating an augmented second to ^6
  **Correction**: Use lowered ^7 in the bass (minor v) to create a smooth diatonic descent
