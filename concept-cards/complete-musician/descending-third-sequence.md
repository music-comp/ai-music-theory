# Quick Definition
A sequence in which each copy descends by a third from the model, with root motion alternating between descending fourths and ascending seconds. Labeled D3 (-4/+2). Features a miniature deceptive motion (V-vi) and a stepwise descending soprano.

# Core Definition
The D3 (-4/+2) sequence descends by third overall, with root motions of descending fourth (-4) and ascending second (+2). It features a characteristic miniature deceptive motion (V-vi pattern within each model) and a stepwise descending soprano line. The first-inversion variant D3 (-4/+2) + 6/3 creates parallel stepwise bass descent with 5-6 motion, also called the **descending 5-6 sequence**. D3 sequences often serve a dual function: prolonging tonic while also leading to the PD. (Laitz, Ch. 22, pp. 502-505)

# Key Properties
1. Root motion: -4/+2
2. Overall descent by third
3. Miniature deceptive motion (V-vi pattern) within each model
4. Stepwise descending soprano characteristic
5. First-inversion variant = descending 5-6 sequence
6. Often serves dual function: T prolongation and T-PD transition

# Examples
**Example 1** (p. 503): Pachelbel, Canon in D major -- I-V-vi-iii-IV-I-IV-V uses the D3 (-4/+2) pattern; the sequence prolongs tonic while leading to PD.
