# Quick Definition
A key signature is a pattern of sharps or flats placed at the beginning of each staff that indicates which pitch classes are chromatically altered throughout the piece, implying the key.

# Core Definition
The **key signature** appears at the beginning of each musical staff, to the right of the clef. It presents a pattern of either sharps or flats that serves as shorthand for conveying the pitch classes of a key. When you indicate a sharp or flat in a key signature, the accidental applies to the entire pitch class (all octaves). Key signatures imply but do not guarantee the key, since the actual key is made explicit by how pitches are used.

# Key Properties
1. Sharp keys (ascending by fifths from C): G(1#), D(2#), A(3#), E(4#), B(5#), F#(6#), C#(7#)
2. Flat keys (descending by fifths from C): F(1b), Bb(2b), Eb(3b), Ab(4b), Db(5b), Gb(6b), Cb(7b)
3. Order of sharps: F-C-G-D-A-E-B; order of flats: B-E-A-D-G-C-F
4. For sharp keys: the tonic is one half step above the last sharp
5. For flat keys: the tonic is the second-to-last flat (except F major, which has only one flat)
6. Minor key signatures use the natural minor form; raised ^6 and ^7 appear as accidentals

# Construction / Recognition
## To Determine Key from Signature:
1. If sharps: the pitch one half step above the last sharp is the major key tonic
2. If flats: the penultimate flat is the major key tonic
3. To find the relative minor: go three half steps below the major tonic

# Context & Application
Key signatures eliminate the need for repeated accidentals throughout a piece. Understanding key signatures is essential for sight-reading, transposition, and harmonic analysis.

# Common Errors
- **Error**: Assuming a key signature uniquely determines the key.
  **Correction**: Each key signature implies two possible keys (a major key and its relative minor). Context determines which is in use.
