# Quick Definition
The outer-voice framework is the contrapuntal relationship between bass and soprano, which controls the harmonic flow and against which inner voices and embellishments are measured.

# Core Definition
The **outer-voice framework** is the contrapuntal relationship between the bass and soprano voices, which controls the flow of harmonic events. For every change of harmony (bass note), there is a single primary soprano note. This two-voice skeleton, when placed in a rhythmic-metrical context and fleshed out with complete chords and textural embellishments, generates actual music. The outer voices are the most audible and therefore the most important for both analysis and composition. Write the outer voices first (Laitz, Ch. 9, p. 206).

# Prerequisites
- **Voice leading** -- the outer voices follow voice-leading principles

# Key Properties
1. Bass defines harmony; soprano provides primary melodic content
2. One primary soprano pitch per harmony change
3. Inner voices fill out the chords between the outer voices
4. Write outer voices first, then add inner voices
5. Analysis should focus first on the outer-voice counterpoint

# Context & Application
The outer-voice framework is the analytical and compositional starting point. Understanding it reveals the underlying structure of any passage, regardless of texture or instrumentation.
