# Quick Definition
Composers use two primary strategies to create coherent variation sets: (1) driving toward a climax through ever-smaller note values or increasing elaboration; (2) grouping variations into larger units distinguished by mode, character, or texture.

# Core Definition
Two common strategies for avoiding monotony in variation sets: (1) Creating a sense of drive toward a musical climax through rhythmic crescendo (ever-smaller note values), increasingly elaborate textures, expanded registers, and dynamics. (2) Grouping two or more variations to create another level of organization, with each group distinguished by mode change, character, or texture, creating large-scale ebb and flow (Laitz, Ch. 26, pp. 602-603).

# Key Properties
1. Rhythmic crescendo: progressively smaller note values across variations
2. Textural expansion: increasing voices, register, and dynamic range
3. Grouping: organizing variations into larger units (e.g., 5+2+5)
4. Mode change: shifting to parallel minor/major to create contrast between groups
5. Seeds for later developments often planted in the theme itself

# Examples
**Example 1** (p. 603): Beethoven, "Nel cor piu non mi sento" variations -- six variations with progressive intensification (Vars. I-III), a mode change to minor (Var. IV), a contrasting pastoral character (Var. V), and a summarizing finale (Var. VI) with coda.
