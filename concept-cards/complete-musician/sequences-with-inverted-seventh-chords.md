# Quick Definition
D2 sequences using first-inversion or third-inversion seventh chords, creating smoother bass lines. Third-inversion sevenths (4/2) resolve to first-inversion chords, with the bass seventh creating a suspension-like effect.

# Core Definition
First-inversion seventh chords in D2 sequences create smoother voice leading, just as first-inversion triads do. Third-inversion seventh chords (4/2) are also common; they resolve to first-inversion triads or seventh chords. When the seventh is in the bass (4/2 position), it gives the impression of a bass suspension. To determine sequence type, locate the root of each chord rather than the bass note. All inverted-seventh-chord sonorities must be complete. (Laitz, Ch. 23, pp. 522-524)

# Key Properties
1. First-inversion sevenths create smoother bass
2. Third-inversion (4/2) creates bass suspension effect
3. 4/2 resolves to 6 or 6/5
4. Determine sequence type by roots, not bass notes
5. All inverted seventh chords must be complete

# Examples
**Example 1** (p. 522): Mozart, Symphony in G major, K. 74 -- D2 sequence first with triads, then repeated with oboes adding seventh-chord suspensions.

**Example 2** (p. 523): Leclair, Trio Sonata in D major -- D2 sequence with interlocking 4/2-6 pattern, roots revealing the underlying -5/+4 motion.
