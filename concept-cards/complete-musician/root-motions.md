# Quick Definition
The three basic root motions of tonal music: descending fifth (V-I), ascending second (IV-V), and descending third (I-vi). All diatonic harmonic progressions are built from these fundamental patterns.

# Core Definition
Tonal music relies on three basic root motions: (1) the **descending fifth**, exemplified by V-I; (2) the **ascending second**, exemplified by IV-V; (3) the **descending third**, exemplified by I-vi. The submediant's functions are tied to all three of these root motions. These motions govern not only individual chord progressions but also the larger patterns of harmonic sequences. (Laitz, Ch. 18, p. 425)

# Key Properties
1. Descending fifth: strongest motion, basis of authentic cadence
2. Ascending second: common PD-D motion
3. Descending third: creates harmonic arpeggiations
4. All sequence types derive from combinations of these root motions

# Relationships
## Enables
- **Descending-thirds progression** — I-vi-IV uses descending thirds
- **Descending-fifths progression** — vi-ii-V uses descending fifths
- **Deceptive motion** — V-vi uses ascending seconds
