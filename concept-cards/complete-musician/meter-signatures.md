# Quick Definition
A meter signature (time signature) is two stacked numbers at the beginning of a piece: in simple meter, the top number gives beats per measure and the bottom gives the beat's note value; in compound meter, the top number gives total divisions and must be divided by 3 for beat count.

# Core Definition
The **meter signature** (or **time signature**) appears at the beginning of a composition, directly after the key signature. It consists of two numbers stacked vertically. For **simple meters**, the top number indicates beats per measure and the bottom number indicates the note value receiving one beat (2 = half, 4 = quarter, 8 = eighth). For **compound meters**, the top number indicates total beat divisions (divide by 3 for actual beats), and the bottom number shows the subdivision note value.

# Key Properties
1. Simple meter examples: 2/4, 3/4, 4/4, 2/2, 3/8
2. Compound meter examples: 6/8, 9/8, 12/8, 6/4
3. Common symbols: C = 4/4 (common time); cut C = 2/2 (cut time/alla breve)
4. The meter signature appears once and remains in effect until changed
5. Asymmetrical meters (5/8, 7/8) combine duple and triple groupings

# Construction / Recognition
## To Read:
1. If top number is 2, 3, or 4: simple meter; top = beats, bottom = beat value
2. If top number is 6, 9, or 12: compound meter; divide top by 3 for beats; beat = dotted version of bottom value
3. If top number is 5 or 7: asymmetrical meter

# Context & Application
Meter signatures are essential for sight-reading and performing. They establish the temporal framework that guides rhythmic interpretation.

# Common Errors
- **Error**: Reading 6/8 as "six eighth-note beats."
  **Correction**: 6/8 is compound duple -- two dotted-quarter beats, each divided into three eighth notes.
