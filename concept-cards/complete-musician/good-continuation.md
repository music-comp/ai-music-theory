# Quick Definition
Good continuation is a Gestalt principle: once a pattern (texture, mood, harmonic rhythm) is established, listeners expect it to continue.

# Core Definition
**Good continuation** is a Gestalt principle stating that once a musical pattern has been established -- whether of texture, mood, rate of harmonic change, or melodic direction -- listeners expect it to continue. This expectation is a powerful analytical tool: knowing the established harmonic rhythm, for example, helps predict where chord changes will occur. Changes to established patterns create accents that draw listener attention (Laitz, Ch. 7, p. 176).

# Prerequisites
- **Melodic fluency** -- good continuation supports analysis of melodic lines

# Key Properties
1. Established patterns create expectations for continuation
2. Breaking a pattern creates a musical accent
3. Applies to harmonic rhythm, texture, melody, and rhythm
4. Fundamental to both analysis and performance

# Examples
**Example 1** (p. 176): In Bach's Sonata no. 3 for Solo Violin, the established two-beat harmonic rhythm creates an expectation of continuation, allowing the listener to track a rising chromatic line across measures despite intervening pitches.
