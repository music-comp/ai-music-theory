# Quick Definition
A subdominant return begins the recapitulation on IV instead of I, creating harmonic interest by starting a fifth below the eventual tonic, so that the STA arrives naturally in the tonic.

# Core Definition
In a subdominant return, the recapitulation begins not on I but on IV. This procedure arose to create harmonic interest in the recapitulation, since so much of it is traditionally cast only in the tonic. Given the exposition's tonal model of root motion up a fifth from I to V, beginning the recapitulation down a fifth from the tonic means the transition's upward-fifth motion naturally arrives on I for the STA (Laitz, Ch. 33).

# Key Properties
1. Recapitulation begins on IV, not I
2. Transition's upward-fifth motion then naturally reaches I for the STA
3. Creates harmonic variety in the recapitulation
4. Mirrors the exposition's I-V motion as IV-I

# Examples
**Example 1** (p. 763): Mozart, Piano Sonata in C major, K. 545 -- Recapitulation begins on F major (IV).
