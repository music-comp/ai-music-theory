# Quick Definition
The four generic sequence types (D2, D3, A2 descending third, A2 ascending third) each have diatonic and applied-chord variants, organized by triads, sixth chords, and seventh chords in root position and inversions.

# Core Definition
Applied-chord sequences are organized by four generic types: descending by second (D2), descending by third (D3), and two forms of ascending by second (A2). Each type has diatonic and applied-chord modifications, ranging from simple triads to seventh chords in various inversions. The applied-chord versions intensify sequential motion through chromaticism. Rules for writing: (1) construct the two-chord model carefully; (2) copies must follow the model's voice leading; (3) the root of each chord must be diatonic; (4) write complete seventh chords, especially in inversion (Laitz, Ch. 24, pp. 556-558).

# Prerequisites
- **Applied-Chord Sequence D2** -- descending second type
- **Applied-Chord Sequence D3** -- descending third type
- **Applied-Chord Sequence A2** -- ascending second type

# Key Properties
1. Four generic sequence types, each with diatonic and applied variants
2. Applied variants add chromaticism through temporary leading tones
3. Within each type: triads (root, inversion), seventh chords (root, inversion)
4. Voice leading of the model must be replicated exactly in copies

# Context & Application
This summary provides a comprehensive reference for all sequence types encountered in the common-practice period, serving as a foundation for composition and analysis.
