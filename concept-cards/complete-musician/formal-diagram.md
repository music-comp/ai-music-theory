# Quick Definition
A schematic representation of a passage's formal structure, showing measures, harmonic endpoints (cadences), melodic labels (a, b, a', b'), period labels, and hierarchical relationships.

# Core Definition
A formal diagram summarizes the formal structure of a passage. It includes: measure numbers, cadence types at phrase endings, melodic labels (lowercase a/b for phrases, uppercase A/A' for large-level groupings), period-type labels (PIP, CCP, etc.), and hierarchical relationships (antecedent/consequent, sentence structure). For double periods, the diagram shows both smaller-level and large-level period structure. (Laitz, Ch. 20, pp. 466-475)

# Key Properties
1. Shows measure numbers and phrase boundaries
2. Indicates cadence types (HC, IAC, PAC)
3. Uses lowercase for phrase-level melody, uppercase for large-level
4. Labels period types and sentence structures
5. Reveals hierarchical relationships
