# Quick Definition
A composite form is a musical structure constructed of multiple self-contained sections, each featuring strong melodic contrast and tonal closure.

# Core Definition
Composite forms are built from independent sections that begin and end conclusively in the same key. Ternary and rondo forms are composite forms. Binary form is not composite, since its sections are tonally dependent on one another and can be viewed as more organic in construction. In composite forms, the omission of one or more sections would not seriously jeopardize the structural integrity of the piece (Laitz, Ch. 31 and Ch. 33 Summary).

# Prerequisites
- **Binary Form** -- understanding tonally dependent vs. independent sections

# Key Properties
1. Multiple self-contained sections
2. Each section has strong melodic contrast
3. Sections feature tonal closure (begin and end in the same key)
4. Sections are tonally independent of one another

# Construction / Recognition
## To Construct:
1. Create self-contained sections, each with its own tonal closure
2. Arrange sections in a pattern of contrast and return (ABA, ABACA, etc.)

## To Recognize:
1. Check that each section begins and ends in the same key
2. Verify that sections can stand alone as independent musical units
3. Confirm that sections feature melodic and thematic contrast

# Context & Application
Composite forms include ternary (ABA) and rondo (ABACA or ABACABA). They contrast with organic forms like sonata, where each part depends on every other part, creating a single integrated whole. Understanding the composite/organic distinction is fundamental to analyzing large-scale form.

# Examples
**Example 1** (p. 702): Ternary form -- each of the three sections (A, B, A) is harmonically and thematically closed and self-standing.

**Example 2** (p. 730): Rondo form -- alternates self-contained refrains and episodes.

# Relationships
## Builds Upon
- **Binary Form** -- binary is not composite but provides the building blocks for composite forms

## Enables
- **Ternary Form** -- ternary is the simplest composite form
- **Rondo Form** -- rondo extends the composite principle with more sections

## Contrasts With
- **Sonata Form** -- sonata is organic, with interdependent parts forming a single integrated whole

# Common Errors
- **Error**: Assuming all multi-section forms are composite
  **Correction**: Sonata form has multiple sections but is organic, not composite, because its parts are interdependent

# Common Confusions
- **Confusion**: "Composite form" vs. "compound form"
  **Clarification**: These terms are used interchangeably by Laitz. "Compound" also refers to forms with nested sub-forms (compound ternary), which is a related but distinct concept.
