# Quick Definition
A seventh chord is a four-note chord built by stacking three thirds (or equivalently, adding a seventh above the root of a triad), producing a dissonant sonority because the seventh is a dissonant interval.

# Core Definition
A **seventh chord** contains four different pitches that can be stacked in thirds. Because the chord spans the interval of a seventh -- a dissonant interval -- all seventh chords are dissonant, though to varying degrees. Seventh chords are labeled by two features: the type of triad (major, minor, diminished) and the type of seventh above the root (major, minor, diminished).

# Prerequisites
- **Triads** -- seventh chords extend triads by adding a fourth pitch
- **Triad Quality** -- the triad component determines half the label
- **Consonant and Dissonant Intervals** -- the seventh creates dissonance

# Key Properties
1. Four distinct pitch classes stacked in thirds
2. All seventh chords are dissonant (they contain a 7th)
3. Five important types (see seventh-chord-types)
4. The root-position seventh chord may omit the fifth and double the root
5. Inverted seventh chords almost always use complete harmonies with no doublings

# Context & Application
Seventh chords add harmonic richness and tension beyond what triads provide. They are essential in common-practice harmony, jazz, and popular music. Understanding seventh chords requires solid knowledge of triads, intervals, and inversion.
