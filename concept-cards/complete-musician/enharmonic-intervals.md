# Quick Definition
Enharmonic intervals sound identical (same number of half steps) but are spelled differently and have different generic and specific names (e.g., m3 C-Eb and A2 C-D#).

# Core Definition
Just as there are enharmonic pitches, there are **enharmonic intervals** -- intervals that sound identical but are notated differently. For example, the minor third C-Eb and the augmented second C-D# contain the same number of half steps and sound the same, but their notation reflects different harmonic contexts.

# Key Properties
1. Enharmonic intervals have the same number of half steps but different generic sizes
2. The notation depends on the musical context and key
3. Common pairs: m3/A2, M3/d4, P5/A4+1 (d6), A4/d5

# Examples
**Example 1** (p. 83): The m3 C-Eb sounds identical to the A2 C-D#, but the A2 would occur only in specific harmonic contexts (e.g., harmonic minor on E).
