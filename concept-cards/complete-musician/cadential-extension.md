# Quick Definition
A cadential extension intensifies a cadence by repeating elements of the cadential gesture (PD, cad 6/4) after an evaded cadence, building momentum before finally achieving the authentic cadence.

# Core Definition
A **cadential extension** occurs when a composer intensifies a cadence by repeating elements of the cadential gesture -- including the pre-dominant function and the cadential six-four chord -- before finally completing the authentic cadence. After an evaded cadence (V4/2 -> I6), the music "tries again" with repeated PD and cad 6/4 material, each attempt building more momentum. This creates a "harmonic crescendo" that heralds the impending structural cadence. The cadential extension prolongs the dominant function area and extends the phrase beyond its expected length (Laitz, Ch. 14, pp. 337-339).

# Prerequisites
- **Evaded cadence** -- the trigger for cadential extension
- **Cadential six-four chord** -- the repeated element

# Key Properties
1. Follows an evaded cadence
2. Repeats PD and cad 6/4 elements
3. Creates "harmonic crescendo"
4. Extends phrase beyond expected length
5. Multiple evasion-extension cycles possible
6. Final attempt achieves the structural AC

# Examples
**Example 1** (pp. 338-339): Mozart's Magic Flute quintet: three attempts at cadential closure, each progressively more intense.
