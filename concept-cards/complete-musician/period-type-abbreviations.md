# Quick Definition
A systematic labeling scheme for period types using three components: melodic relationship (P=parallel, C=contrasting) + harmonic type (I=interrupted, C=continuous, S=sectional, P=progressive) + P(eriod).

# Core Definition
Period types are labeled using a three-letter abbreviation: (1) **P** (parallel) or **C** (contrasting) for the melodic relationship; (2) **I** (interrupted), **C** (continuous), **S** (sectional), or **P** (progressive) for the harmonic structure; (3) **P** for "period." Common types: PIP (parallel interrupted period), CCP (contrasting continuous period), PSP (parallel sectional period), PPP (parallel progressive period). (Laitz, Ch. 20, pp. 466-475)

# Key Properties
1. First letter: P (parallel) or C (contrasting) -- melodic openings
2. Second letter: I (interrupted), C (continuous), S (sectional), P (progressive) -- harmonic type
3. Third letter: P (period)
4. Eight possible combinations, though some are more common than others
5. PIP is the most common type
