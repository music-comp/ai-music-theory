# Quick Definition
Analyzing modulations involves identifying three elements: the location of the new key, its function in the overall progression, and the pivot chord where the two keys are momentarily fused.

# Core Definition
Three important musical events to identify: (1) the location of the new key area in relation to the initial tonic (by roman numeral); (2) the function of the new key within the overall harmonic progression; (3) the point where the original key and new key are momentarily fused (the pivot chord). The analytical method: start roman numerals in the original key, continue until they become nonsensical, then work backward from the cadence in the new key until finding a chord with simple labels in both keys (Laitz, Ch. 25, pp. 570-572).

# Prerequisites
- **Modulation** -- the process being analyzed
- **Pivot Chord** -- the analytical mechanism

# Key Properties
1. Identify the goal key by roman numeral relative to the home key
2. The second-level analysis "jumps tracks" at the pivot
3. The pivot chord has two roman numeral labels (one per key)
4. Incomplete second-level analyses result in both keys
