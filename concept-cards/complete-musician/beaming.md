# Quick Definition
Beaming groups smaller note values (eighth notes and shorter) with horizontal beams that clarify the metric structure by showing beat groupings visually.

# Core Definition
**Beaming** uses horizontal lines (beams) to connect eighth notes and shorter values into groups that correspond to beat units. In **simple meter**, beaming groups notes by the beat (e.g., in 4/4, eighth notes beam in pairs within each quarter-note beat). In **compound meter**, beaming groups notes by the dotted beat (e.g., in 6/8, eighth notes beam in groups of three within each dotted-quarter beat). Proper beaming makes the metric structure visually explicit.

# Key Properties
1. Beams replace individual flags for eighth notes and smaller values
2. In simple meter: beam according to the beat unit (quarter note in 4/4)
3. In compound meter: beam in groups of three (showing the dotted-note beat)
4. Beaming should never obscure the beat -- avoid beaming across beats
5. Incorrect beaming is one of the most common notation errors

# Context & Application
Correct beaming is essential for readable notation. It immediately communicates the meter to the performer and makes rhythmic patterns intelligible at a glance.
