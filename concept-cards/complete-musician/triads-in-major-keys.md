# Quick Definition
In major keys, triads built on each scale degree follow a fixed pattern: I (major), ii (minor), iii (minor), IV (major), V (major), vi (minor), vii-deg (diminished).

# Core Definition
Each scale degree of a major scale supports a triad built from pitches of that scale. The pattern is consistent across all major keys: the **tonic** (^1), **dominant** (^5), and **subdominant** (^4) support major triads; the **supertonic** (^2), **mediant** (^3), and **submediant** (^6) support minor triads; the **leading tone** (^7) supports the only diminished triad.

# Prerequisites
- **Triads** -- the chord type being built on each degree
- **Triad Quality** -- major, minor, diminished
- **Major Scale** -- provides the pitch material

# Key Properties
1. I = major, ii = minor, iii = minor, IV = major, V = major, vi = minor, vii-deg = diminished
2. Primary triads (I, IV, V) are all major
3. Secondary triads (ii, iii, vi) are all minor
4. vii-deg is the only dissonant diatonic triad
5. This pattern is identical in every major key
