# Quick Definition
Voice overlap occurs when a voice moves past the previous note of an adjacent voice; voice crossing occurs when voices simultaneously occupy each other's register. Both should be avoided.

# Core Definition
**Voice overlap** occurs when a voice intrudes into the register of an adjacent voice's previous pitch (e.g., the alto moves above the soprano's previous note). **Voice crossing** occurs when voices simultaneously occupy each other's register (e.g., the alto sounds below the tenor in the same chord). Both destroy voice independence by confusing the listener about which melodic line belongs to which voice. These usually result from excessive leaping and registral shifting (Laitz, Ch. 8, pp. 193-194).

# Key Properties
1. Voice overlap: a voice moves past the PREVIOUS note of an adjacent voice
2. Voice crossing: voices are in each other's register SIMULTANEOUSLY
3. Both result from excessive leaps and poor registral control
4. Both are guidelines (strong avoidance) rather than absolute rules
