# Quick Definition
Root-position IV can function as an embellishing chord (EC) that prolongs tonic through neighbor motion, rather than as a pre-dominant; context determines which function applies.

# Core Definition
While IV typically functions as a pre-dominant, it can also appear in root position as an **embellishing chord** (EC) that prolongs the tonic. When IV appears between two tonic chords and the bass leaps to ^4 and back to ^1, it renders the upper-voice neighbor tones consonant, but tonic still controls the passage. Context is essential: the same IV chord can be a pre-dominant (leading to V) or an embellishing chord (prolonging I), depending on what follows it (Laitz, Ch. 14, pp. 341-342).

# Prerequisites
- **Subdominant as pre-dominant** -- the alternative function of IV
- **Contrapuntal expansion** -- EC is a form of tonic expansion

# Key Properties
1. Root-position IV between two tonic chords
2. Bass leaps ^1-^4-^1
3. Upper voices create neighbor motion
4. Tonic still controls the passage
5. Context determines whether IV is PD or EC
6. Labeled EC in second-level analysis

# Examples
**Example 1** (p. 342): Mozart's Symphony no. 39 Menuetto: IV appears as both EC (m. 2, prolonging I) and PD (mm. 3-4, leading to V).
