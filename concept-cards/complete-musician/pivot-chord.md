# Quick Definition
A pivot chord is a diatonic chord common to both the original key and the new key, serving as the point where a modulation shifts from one tonal area to another.

# Core Definition
The pivot chord is the point where roman numerals "jump tracks" to a new key. It is a diatonic chord in both keys and receives two roman numeral labels (one for each key), enclosed in a box in analysis. The best pivot chords act as pre-dominants in the new key. Cadential 6/4 chords are not good pivot chord candidates because they are part of strong cadential motion in the new key (Laitz, Ch. 25, pp. 571-572).

# Prerequisites
- **Modulation** -- the process requiring a pivot chord
- **Closely Related Keys** -- keys sharing common chords

# Key Properties
1. Must be diatonic in both the original and new keys
2. Receives roman numeral labels in both keys (boxed in analysis)
3. Best pivots function as pre-dominants (ii or IV) in the new key
4. Should not be the dominant of the new key (produces harsh modulation)
5. Should not be a cadential 6/4 (belongs to the cadential motion)

# Construction / Recognition
## To Construct:
1. Line up diatonic chords for both keys
2. Identify chords appearing in both keys
3. Choose the one that functions best as PD in the new key

## To Recognize:
1. Analyze from the beginning in the original key
2. Analyze from the cadence backward in the new key
3. The first chord analyzable in both keys is the pivot

# Context & Application
Analytical method: (1) Start writing roman numerals in the original key; (2) continue until numerals become complex or nonsensical; (3) write numerals backward from the cadence in the new key; (4) the first chord with simple labels in both keys is the pivot.

# Examples
**Example 1** (p. 571): C major to G major -- the A-minor chord serves as pivot: vi in C becomes ii in G.

**Example 2** (p. 571): C minor to Eb major -- VI in C minor becomes IV in Eb major.
