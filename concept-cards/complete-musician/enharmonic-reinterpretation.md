# Quick Definition
Enharmonic reinterpretation is the technique of respelling one or more notes of a chord to change its harmonic function, enabling modulation to distant keys through an inaudible notational change.

# Core Definition
Through enharmonic reinterpretation, a chord's function changes when one or more of its pitches are respelled. The most common applications involve the diminished seventh chord (vii-dim-7 reinterpreted in four keys) and the German augmented sixth chord (Ger-6/5 respelled as V7 or vice versa). Within a given chord, the inaudible enharmonic alteration of a single note allows the chord to function in two remotely related keys. This technique is similar to the reinterpretation of the German augmented sixth chord as a V7, though the Ger-6/5 has more limited access to remote keys because it is not symmetrical (Laitz, Ch. 34).

# Key Properties
1. Inaudible change in notation produces audible change in function
2. Diminished seventh: access to 4 keys per chord
3. German sixth/V7: access to 2 keys per chord
4. Enables modulation to remotely related keys
5. Analysis uses pivot chord notation
