# Quick Definition
A passage where the harmonic structure follows a sequential root-motion pattern but the melodic content does not replicate a model, creating sequential harmony without melodic sequence.

# Core Definition
A sequential progression occurs when the harmonic roots follow a sequential pattern (e.g., D2 circle-of-fifths motion) but the melodic content does not replicate a model with copies. Sequential progressions are labeled by root motion (e.g., "D2 progression") and analyzed with individual roman numerals rather than sequence brackets. They are common because the root motions of three of the four basic sequence types are also common harmonic progressions. (Laitz, Ch. 23, pp. 528-529)

# Prerequisites
- **Harmonic sequence** — Must understand true sequences to distinguish sequential progressions

# Key Properties
1. Harmonic roots follow sequential pattern
2. Melodic content does NOT replicate a model
3. Labeled "D2 progression" (etc.), not "D2 sequence"
4. Analyzed with individual roman numerals
5. Common because sequential root motions are common progressions

# Examples
**Example 1** (p. 528): Brahms, "Der Gang zum Liebchen" -- D2 sequential progression where the harmonic roots follow the circle of fifths but the melody does not replicate a pattern.

**Example 2** (p. 529): Bach, French Suite in D minor, Menuet II -- D2 sequential progression.

# Relationships
## Contrasts With
- **Harmonic sequence** — True sequences have both harmonic and melodic model-copy replication

# Common Confusions
- **Confusion**: Any circle-of-fifths progression is a sequence
  **Clarification**: A true sequence requires melodic replication of a model; a sequential progression has only the harmonic root pattern
