# Quick Definition
Harmonic analysis combines roman numerals (identifying root and quality relative to a key) with figured bass (identifying inversion and voice movement) to describe the harmonic content of music.

# Core Definition
A complete **harmonic analysis** combines roman numerals and figured bass. Roman numerals identify the root (by scale degree) and quality of each chord; figured bass (usually without accidentals) identifies the inversion and melodic motion between chords (such as 5--6 or 4--3).

# Prerequisites
- **Roman Numeral Analysis** -- identifies chord function
- **Figured Bass** -- identifies inversion and voice motion
- **Key** -- analysis is always relative to a key

# Key Properties
1. Step 1: Determine the key (key signature alone implies two possible keys)
2. Step 2: Write key name + colon under the bass staff
3. Step 3: Identify triad roots and place roman numerals
4. Step 4: Add figured bass for inverted chords
5. Do not repeat roman numerals for immediately repeated chords (use a line)
6. Chromatic alterations often indicate leading tones in minor keys

# Context & Application
Harmonic analysis is the primary tool for understanding how chords function within a key. Roman numerals reveal hierarchical relationships; figured bass reveals how intervals connect one harmony to another.
