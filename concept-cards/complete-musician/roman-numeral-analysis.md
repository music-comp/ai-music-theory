# Quick Definition
Roman numeral analysis labels each chord by the scale degree of its root (I-VII) with uppercase for major triads, lowercase for minor, and a degree sign for diminished, showing harmonic function within a key.

# Core Definition
**Roman numerals** indicate the scale degree on which a triad is built and its quality. **Uppercase** roman numerals represent major triads; **lowercase** represent minor triads. Diminished triads use lowercase with a degree sign (deg). For example, a Bb major triad in F major is IV (built on ^4). A complete harmonic analysis combines roman numerals (showing root and quality) with figured bass (showing inversion and voice motion).

# Prerequisites
- **Triads** -- roman numerals label triads
- **Triad Quality** -- uppercase/lowercase reflects quality
- **Key** -- roman numerals are relative to a key

# Key Properties
1. Uppercase = major triad; lowercase = minor triad; lowercase + deg = diminished
2. Roman numerals are always relative to a key
3. The key is written as a letter followed by colon (e.g., "D:" for D major, "d:" for D minor)
4. A complete analysis combines roman numerals with figured bass for inversions
5. A repeated chord is shown with a horizontal line, not a repeated numeral
6. Roman numerals reveal harmonic function (hierarchical); figured bass reveals intervallic connections (contextual)

# Construction / Recognition
## To Analyze:
1. Determine the key
2. Write the key name followed by a colon
3. Identify each chord's root by scale degree
4. Apply uppercase/lowercase based on quality
5. Add figured bass for inverted chords (6 for first inversion, 6/4 for second)
