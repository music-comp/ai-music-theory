# Quick Definition
A pattern of chords in which a two-chord model is transposed and repeated at successive pitch levels, creating seamless, goal-directed musical motion within a phrase.

# Core Definition
A harmonic sequence consists of a **model** (a basic contrapuntal/harmonic pattern, usually two chords) and its **copies** (which replicate the model at different pitch levels). Sequences typically have two or three copies. They are classified as descending or ascending and labeled by three criteria: (1) root distance from first chord of model to first chord of copy (D2, D3, A2); (2) root motion between the two chords within the model (e.g., -5/+4); (3) whether inversions are used (e.g., +6/3s). Sequences create the paradox of intense motion (rapid harmonic rhythm) and stasis (repetitive pattern subordinate to the phrase model). (Laitz, Ch. 22, pp. 495-504)

# Prerequisites
- **Phrase model** — Sequences operate within the T-PD-D-T framework
- **Voice leading** — The model must have correct voice leading; copies replicate it exactly

# Key Properties
1. Two-chord model replicated at successive pitch levels
2. Typically two or three copies
3. Classified as descending (D) or ascending (A)
4. Labeled: direction + interval + root motions + inversions
5. Within sequences, normally forbidden voice leading (parallel 5ths, doubled leading tones, root-position dim triads) is acceptable
6. Only first and last chords receive roman numeral analysis
7. The second chord in each two-chord unit is a voice-leading chord preventing parallels

# Construction / Recognition
## To Recognize:
1. Determine overall direction: ascending or descending?
2. Measure the distance from the first chord of the model to the first chord of the copy (D2, D3, A2)
3. Measure the root motion within the model (e.g., -5/+4)
4. Note any inversions (+6/3s)
5. Label: e.g., D2 (-5/+4) + 6/3s

## To Construct:
1. Write the model with correct voice leading in the first three chords
2. Replicate the voice-leading pattern exactly in each copy
3. Start with bass and soprano; aim for contrary step motion
4. Include at least one imperfect consonance (3, 6, 10) in the outer voices
5. Do not use accidentals within diatonic sequences

# Context & Application
Sequences first appeared during the Renaissance and became central in the Baroque. They remain important through popular and commercial music today (Pachelbel Canon, "Fly Me to the Moon," "All the Things You Are"). They prolong harmonic functions or transition between them.

# Examples
**Example 1** (p. 496): Vivaldi, Concerto Grosso in C minor -- D2 (-5/+4) sequence interpolated between tonic and pre-dominant.

- **Melodic sequence** — Only a melodic pattern is transposed, not a full harmonic model
- **Sequential progression** — Harmonic roots follow a sequential pattern but melodic content does not

# Common Errors
- **Error**: Faulty voice leading in the model that gets replicated in every copy
  **Correction**: Make sure the first three chords have correct voice leading before continuing

# Common Confusions
- **Confusion**: Each chord in a sequence should receive a roman numeral
  **Clarification**: Only the first and last chords receive roman numerals; the sequence label covers the rest
