# Quick Definition
A key identifies the tonic pitch and the mode (major or minor) of a composition, specifying which diatonic scale provides the primary pitch material.

# Core Definition
A composition based on a diatonic scale is said to be in a **key**. The key name provides two pieces of information: the **tonic pitch** and the **mode** (major or minor). Thus, a composition is in the key of E if it is based on a scale generated from the pitch class E. Keys are made explicit by how pitches are actually used; the key signature often implies but does not guarantee the key.

# Prerequisites
- **Tonality** -- keys exist within the tonal system
- **Diatonic Scale** -- a key is based on a specific diatonic scale
- **Mode** -- major or minor completes the key identification

# Key Properties
1. 15 major keys exist (including 3 enharmonic pairs at the bottom of the circle of fifths)
2. Each major key has a corresponding relative minor key sharing the same key signature
3. The key is determined by how pitches function, not solely by the key signature
4. Key changes (modulations) are a primary means of creating large-scale musical structure

# Context & Application
Key identification is the first step in harmonic analysis. Determining the key establishes the framework for identifying scale degrees, chords, and harmonic function.

# Examples
**Example 1** (p. 7): A composition based on E-F#-G#-A-B-C#-D# is in the key of E major.

# Common Confusions
- **Confusion**: The key signature alone determines the key.
  **Clarification**: A key signature implies two possible keys (major and its relative minor). The actual key is determined by how pitches function in the music.
