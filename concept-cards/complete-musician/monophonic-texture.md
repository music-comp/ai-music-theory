# Quick Definition
Monophonic texture is a single-line melody with no accompaniment; even if played in octaves by multiple instruments, it remains monophonic because only one melodic line exists.

# Core Definition
**Monophonic texture** is defined as a single-line melody with no accompaniment. Both a cantus firmus and a tune you whistle are monophonic textures. A texture can be monophonic even though it might be played in octaves by more than one instrument, because only one melodic line is present.

# Examples
**Example 1** (p. 148): Schubert's last symphony begins monophonically with horns playing the primary melody in octaves (Example 6.6).
