# Quick Definition
First-species (1:1) counterpoint places one note in the contrapuntal voice against each note of the cantus firmus, using only consonant harmonic intervals and emphasizing contrary motion.

# Core Definition
In **first-species counterpoint** (1:1), a single pitch is written above or below each pitch of the cantus firmus, creating **note-against-note counterpoint**. Only consonant harmonic intervals are permitted (P1, P5, P8, M3, m3, M6, m6). The perfect fourth is dissonant in two-voice counterpoint.

# Prerequisites
- **Counterpoint** -- first species is the simplest species
- **Cantus Firmus** -- the given melody
- **Contrapuntal Motions** -- govern how voices interact
- **Consonant and Dissonant Intervals** -- only consonances allowed

# Key Properties
### Rules (absolute):
1. All harmonic intervals must be consonant (P4 is dissonant in two voices)
2. Parallel perfect intervals (P1, P5, P8) are forbidden
3. Approach perfect consonances by contrary motion (similar motion to P5/P8 allowed only when upper voice moves by step)
4. Begin and end on ^1 (counterpoint above CF may begin on ^5)
5. In minor, use lowered ^6 and ^7 within; raise ^7 only at penultimate measure; raise ^6 if it precedes raised ^7

### Guidelines (aesthetic):
1. Move primarily by step with occasional skips/leaps; change direction after leaps
2. Use contrary motion as much as possible
3. Prefer imperfect consonances; limit octaves and fifths to one or two within
4. Avoid two perfect consonances in a row

# Construction / Recognition
## To Write:
1. Begin on ^1 (or ^5 if above CF)
2. Write primarily consonant intervals, preferring imperfect consonances
3. Use contrary motion as much as possible
4. End: penultimate = ^2 and ^7 in contrary motion to octave on ^1
