# Quick Definition
Harmonic rhythm is the rate at which chords change in a piece of music, ranging from one chord per measure to multiple chords per beat.

# Core Definition
The rate of harmonic change is called **harmonic rhythm**. Depending on the composer, style period, and type of piece, chords may change slowly (one chord per measure or slower) or quickly (multiple chords per beat). Harmonic rhythm is shown in analysis by note values beneath roman numerals that correspond to the duration of each harmony. Harmonic rhythm is intimately tied to meter: chord changes create harmonic accents that should generally align with metric accents. Avoid syncopated harmonic rhythm. Established harmonic rhythm patterns follow good continuation.

# Prerequisites
- **Homophonic Texture** -- harmonic rhythm describes chord change rate within texture
- **Harmonic Analysis** -- harmonic rhythm is revealed through analysis

# Key Properties
1. Slow harmonic rhythm: one chord per measure or less (common in Romantic style)
2. Fast harmonic rhythm: multiple chords per beat (common in Baroque chorales)
3. Harmonic rhythm can be regular (even changes) or irregular
4. Slow harmonic rhythm is sustained by interesting accompaniment patterns (e.g., Alberti bass)
5. Harmonic rhythm often accelerates approaching cadences, creating momentum
6. Chord changes create harmonic accents that should align with metric accents
7. Changes in harmonic rhythm create structural accents

# Examples
**Example 1** (p. 150): Mozart, K. 545 (Example 6.8C) has approximately seven chords in four measures -- a moderate harmonic rhythm sustained by Alberti bass figuration.
**Example 2** (p. 151): Chopin's Etude op. 25/1 has very slow harmonic rhythm -- a single A-major triad spans two full measures.
