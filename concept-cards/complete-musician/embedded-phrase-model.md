# Quick Definition
A mini T-PD-D-T progression that occurs within the tonic expansion portion of a phrase, functioning not as a cadence but as a contrapuntal elaboration of the tonic.

# Core Definition
An embedded phrase model (EPM) is a complete T-PD-D-T progression that occurs within the initial tonic portion of a larger phrase. Although tonally closed (ending on tonic), an EPM does not function as a cadence -- it is a contrapuntal elaboration that expands the tonic. In a two-level analysis, only the overall T-PD-D-T of the phrase is structural; EPMs appear under the "T" label at the second level. Composers distinguish EPMs from actual cadences by using inversions (weakening the PD and D harmonies). (Laitz, Ch. 17, pp. 411-413)

# Prerequisites
- **Phrase model (T-PD-D-T)** — Must understand the structural phrase model
- **Contrapuntal expansion** — EPMs are a form of tonic expansion

# Key Properties
1. Complete T-PD-D-T within the tonic expansion
2. Not a cadence -- does not function as a structural arrival
3. PD and D are typically in inversion to weaken the cadential feel
4. Shown under "T" in second-level analysis
5. Multiple EPMs can occur within one phrase

# Construction / Recognition
## To Construct:
1. Begin with a tonic chord
2. Add a PD-D-T progression using inverted harmonies
3. Ensure the result sounds like an elaboration, not a cadential arrival
4. Continue the phrase to the actual structural cadence

## To Recognize:
1. Find T-PD-D-T progressions that occur before the phrase's structural cadence
2. Check if PD and/or D are in inversion (weakened)
3. Verify that the progression expands the tonic function at the second level

# Context & Application
EPMs enrich the tonic expansion with harmonic interest while reserving the powerful root-position V-I for the structural cadence. Common EPM patterns include I-IV6-V6/5-I and I-ii4/2-V6/5-I.

# Examples
**Example 1** (p. 411): A four-measure phrase has two PD-D-T progressions: the first (in inversions) is an EPM expanding tonic; the second (root position) is the structural cadence.

# Relationships
## Builds Upon
- **Phrase model** — EPM is a miniature version of the phrase model embedded within the tonic expansion

## Enables
- **Longer, richer phrases** — EPMs allow for more elaborate tonic expansions

## Related
- **Contrapuntal cadence** — Uses similar harmonies but at phrase endings

## Contrasts With
- **Structural cadence** — A cadence creates arrival; an EPM creates elaboration

# Common Errors
- **Error**: Labeling every T-PD-D-T progression as a cadence
  **Correction**: Only root-position V-I at a phrase boundary is a structural cadence; earlier T-PD-D-T progressions within the tonic expansion are EPMs

# Common Confusions
- **Confusion**: An EPM creates a new phrase boundary
  **Clarification**: EPMs are internal to the phrase and expand the tonic function; they do not create phrase boundaries
