# Quick Definition
Applied chords typically appear on metrically weak beats because they contain leading tones that precipitate motion toward a metrically stressed goal.

# Core Definition
Weak metrical placement of applied chords is common because they contain leading tones that precipitate motion toward a metrically stressed goal. Applied chords are embellishing harmonies and often appear in weak metrical contexts to create rhythmic drive toward structural harmonies on strong beats (Laitz, Ch. 24, p. 546).

# Prerequisites
- **Applied Chord** -- the chords being placed metrically
- **Meter** -- understanding of strong and weak beats

# Key Properties
1. Applied chords commonly fall on weak beats
2. Their target chords typically fall on strong beats
3. This creates a rhythmic pattern of tension (weak beat) to resolution (strong beat)
4. The pattern mirrors the anacrustic quality of dominant-to-tonic motion

# Context & Application
When composing with applied chords, consider metric placement as part of the phrase structure. Beethoven's practice (String Quartet op. 59, no. 3) demonstrates that every applied chord can appear on a metrically weak beat, creating a consistent pattern of chromatic tension resolving to diatonic stability.

# Examples
**Example 1** (p. 546): Beethoven, String Quartet no. 9, op. 59 no. 3, Menuetto -- all applied chords appear on weak beats in a parallel interrupted period.
