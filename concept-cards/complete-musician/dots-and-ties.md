# Quick Definition
A dot adds half the value of the note it follows (e.g., a dotted half note = 3 beats in 4/4); a tie connects two notes of the same pitch, combining their durations into one continuous sound.

# Core Definition
A **dot** placed after a note adds half the note's original value to its duration. A dotted half note equals three quarter notes; a dotted quarter equals three eighth notes. A **double dot** adds half the value of the first dot (i.e., three-quarters of the original value total). A **tie** is a curved line connecting two notes of the same pitch, combining their durations. Unlike a slur (which connects notes of different pitches for legato), a tie creates a single sustained pitch spanning the combined duration.

# Key Properties
1. Single dot: adds half the note's value (note value x 1.5)
2. Double dot: adds half and then a quarter (note value x 1.75)
3. Ties connect notes of the same pitch across beat or measure boundaries
4. Ties are essential for creating durations that cannot be represented by a single note value
5. Ties look similar to slurs but function differently (ties connect same pitch; slurs connect different pitches)

# Context & Application
Dots create durational values between the standard note-value hierarchy. Ties are essential for sustaining pitches across bar lines and for creating rhythmic durations that do not correspond to a single note value.

# Common Errors
- **Error**: Confusing a tie with a slur.
  **Correction**: A tie connects two notes of the same pitch, combining their durations. A slur connects different pitches, indicating legato articulation.
