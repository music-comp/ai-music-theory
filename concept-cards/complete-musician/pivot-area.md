# Quick Definition
A pivot area is an expanded pivot spanning several chords that function in both the original and new keys, often involving a tonicized or expanded pivot chord, a pre-dominant complex, or a sequence.

# Core Definition
The function of a pivot is not limited to a single chord. Several chords that function in two keys may work together to create a pivot area. This can occur through expansion or tonicization of the pivot chord, coupling of pre-dominant chords through voice exchange, or use of sequences that touch on many chords within a key (Laitz, Ch. 25, p. 575).

# Prerequisites
- **Pivot Chord** -- the single-chord concept being expanded

# Key Properties
1. Multiple chords function in both keys simultaneously
2. Sequences are particularly effective as pivot areas
3. A sequence can be "quit" prematurely, with one of its chords reinterpreted as a PD in the new key
4. Creates a more gradual, seamless transition than a single pivot chord

# Examples
**Example 1** (p. 575): Vivaldi, Trio Sonata in C minor -- a D2 sequence stops on VI (Ab chord), which functions as IV in the new key of Eb (III of C minor).
