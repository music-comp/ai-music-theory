# Quick Definition
Four types of contrapuntal motion describe how voices move relative to each other: contrary (opposite directions), similar (same direction, different intervals), parallel (same direction, same generic interval), and oblique (one moves, one stays).

# Core Definition
**Contrapuntal motion** refers to the contours produced between two or more voices. Four types exist:
1. **Contrary motion**: voices move in opposite directions (most independence)
2. **Similar motion**: voices move in the same direction but by different intervals
3. **Parallel motion**: voices move in the same direction maintaining the same generic interval (least independence)
4. **Oblique motion**: one voice moves while the other remains stationary

# Prerequisites
- **Counterpoint** -- contrapuntal motions describe voice interaction

# Key Properties
1. Contrary motion creates the most voice independence -- use it as much as possible
2. Parallel motion in thirds or sixths is beautiful but limited to three consecutive uses
3. Parallel perfect intervals (P5, P8, P1) are forbidden -- they ruin voice independence
4. Similar motion to perfect intervals is generally forbidden (creates hidden/direct intervals)
5. Oblique motion arises in second species when one voice sustains while the other moves
6. A balanced mixture of motion types creates the best counterpoint

# Context & Application
Understanding contrapuntal motion types is essential for voice leading in all tonal music, not just species counterpoint. These principles govern how chords connect.
