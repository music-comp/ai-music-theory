# Quick Definition
Ternary form is a three-part composite form (ABA or ABA') with a three-part tonal structure (original key -- contrasting key -- original key), in which each section is self-contained with strong melodic contrast and tonal closure.

# Core Definition
Ternary form features a three-part melodic design (ABA or ABA') and a three-part tonal structure. Unlike rounded binary form, which shares the three-part melodic design (a-dig.-a') but has only a two-part tonal structure, ternary form's sections are tonally independent. Three subtypes exist based on how sections close: full sectional ternary, sectional ternary, and continuous ternary. Ternary and rondo forms are composite forms, constructed of multiple self-contained sections featuring strong melodic contrast and tonal closure (Laitz, Ch. 31).

# Prerequisites
- **Binary Form** -- understanding rounded vs. simple binary is essential for distinguishing ternary from binary
- **Key Relationships** -- recognizing contrasting keys in the B section

# Key Properties
1. Three-part melodic design: ABA or ABA'
2. Three-part tonal structure: original key, contrasting key, original key
3. Each section is self-contained with tonal closure
4. B section typically in a contrasting key (major mode: IV, vi, iv, bVI, i; minor mode: III, iv, VI, I)
5. Sections feature strong melodic contrast

# Construction / Recognition
## To Construct:
1. Write an A section that closes in the tonic key
2. Write a contrasting B section in a related but different key
3. Return to A (literal or modified) in the original key
4. Optionally add transitions and/or retransitions between sections

## To Recognize:
1. Identify three distinct sections with clear boundaries
2. Verify that each section is tonally self-contained (not just melodically contrasting)
3. Check that the B section establishes its own key center
4. Distinguish from rounded binary by assessing how independent B is from A

# Context & Application
Ternary form appears across many genres and style periods: da capo arias (Baroque), minuet-trio movements (Classical), and character pieces (Romantic). The form embodies the balance of variety (B section) and return (final A) fundamental to musical structure. It is one of the most common large forms alongside rondo and sonata.

# Examples
**Example 1** (p. 703): Grieg, "Hjemve," Lyric Pieces, op. 57, no. 6 -- A full sectional ternary form (ABA') with a brooding A section contrasted by a folklike B section in the parallel major.

**Example 2** (p. 707): Brahms, Romanze in F, op. 118, no. 5 -- A sectional ternary form with B section in the remote key of D major (bVI), featuring both a transition and retransition.

# Relationships
## Builds Upon
- **Binary Form** -- ternary extends the principle of tonal departure and return found in binary form

## Enables
- **Rondo Form** -- rondo can be understood as an extension of ternary with additional episodes and refrains
- **Compound Ternary Form** -- larger ternary structures with nested binary forms

## Related
- **Composite Form** -- ternary is a type of composite form
- **Da Capo Form** -- a specific realization of ternary using da capo marking

## Contrasts With
- **Rounded Binary Form** -- shares three-part melodic design but has only two-part tonal structure
- **Sonata Form** -- an organic form where parts are interdependent, unlike ternary's self-contained sections

# Common Errors
- **Error**: Labeling any piece with an ABA melodic design as ternary form
  **Correction**: Verify the tonal structure is also three-part; rounded binary has ABA' melody but two-part tonal structure

# Common Confusions
- **Confusion**: Difficulty distinguishing continuous ternary from rounded binary
  **Clarification**: Consider how independent B is from A. If there is little thematic/motivic connection and a clear change of key, ternary is indicated. If B is developmental and motivically tied to A with little key change, rounded binary is more appropriate.
