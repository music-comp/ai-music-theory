# Quick Definition
The Neapolitan can serve as a pivot chord for modulations to both diatonic and chromatic keys, as its major triad quality makes it reinterpretable in multiple key contexts.

# Core Definition
The Neapolitan is an effective pivot chord when modulating to diatonic as well as chromatic keys. A Db sonority in C minor, for instance, can function locally as bII6 leading to V, but when it recurs later it may function as a pivot precipitating modulation to Ab. The Neapolitan's major triad quality gives it versatility across multiple tonal contexts (Laitz, Ch. 29, pp. 670-671).

# Key Properties
1. bII's major triad quality makes it reinterpretable in multiple keys
2. Can modulate to both diatonic and chromatic destinations
3. The same chord may function as bII in one context and as a pivot in another
4. Particularly effective for modulations involving flat-side keys

# Examples
**Example 1** (p. 670): Schubert, String Quartet "Quartettsatz" -- a Db chord functions as bII6 in m. 9 but as a pivot to Ab in m. 23.
