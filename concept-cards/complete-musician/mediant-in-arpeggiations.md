# Quick Definition
The mediant functioning as the middle chord in an ascending-bass arpeggiation I-iii-V (bass ^1-^3-^5), replacing the usual I6 with a root-position triad that provides richer sonority.

# Core Definition
In the ascending-bass arpeggiation ^1-^3-^5, the mediant can replace I6 as the middle chord, creating the progression I-iii-V. The iii provides a richer harmonic color than I6 because it is a root-position triad rather than an inversion. Passing chords can fill the steps between iii and V: iii-IV-V or iii-iv6-V (with iv6 in minor). (Laitz, Ch. 19, pp. 446-448)

# Key Properties
1. Bass arpeggiation: ^1-^3-^5
2. iii replaces I6 in the arpeggiation
3. Root-position triad richer than first inversion
4. Can be filled with passing harmonies (IV or iv6)
