# Quick Definition
An ascending sequence with root motion of ascending fifths and descending fourths, creating an overall step ascent. Less common than D2 because ascending fifths create retrogressions. Usually in root position only, leading to a PD on ^4.

# Core Definition
The A2 (+5/-4) sequence ascends by step overall, with root motion alternating between ascending fifth (+5) and descending fourth (-4). It is much less common than D2 because ascending fifths create weak retrogressions (e.g., V ascending to ii). However, its overall ascent provides some drive, and the voice-leading chord prevents potential parallels. It typically occurs in root position only and leads to a PD on ^4 or, in minor, to ^6 as part of a Phrygian cadence. (Laitz, Ch. 22, pp. 505-506)

# Key Properties
1. Root motion: +5/-4
2. Overall ascent by step
3. Less common due to retrogressive quality
4. Usually root position only
5. Typically leads to PD on ^4
