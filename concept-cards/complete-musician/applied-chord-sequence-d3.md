# Quick Definition
The D3 applied-chord sequence transforms the diatonic D3 (-4/+2) into a D3 (+3/-5) pattern, where each applied chord creates a temporary leading tone pointing forward to the next chord rather than back.

# Core Definition
In the diatonic D3 (-4/+2), the second chord of each pair lies a fourth below the first, creating a retrogressive or weak deceptive motion. In the applied-chord version, each applied chord creates a temporary leading tone that leads to the following chord, transforming the root relationships. The diatonic D3 (-4/+2) becomes the D3 (+3/-5) applied-chord sequence, where chords have different roots from their diatonic counterparts. Applied chords in this sequence most often contain sevenths (Laitz, Ch. 24, p. 553).

# Key Properties
1. Root motion is transformed from the diatonic pattern
2. The four-three inversion provides stepwise bass descent (most common form)
3. Bass hooks (dissonant leap to leading tone balanced by stepwise resolution) create another common variant
4. Applied diminished seventh chords may substitute for applied dominants, creating a D3 (-4/+1) pattern

# Construction / Recognition
## To Construct:
1. Begin with the D3 sequence framework
2. Convert each second chord into an applied dominant (with seventh) of the following chord
3. Use inversions (especially 4/3) for smooth bass motion

## To Recognize:
1. Stepwise descending bass with chromatic inflections
2. Parallel tenths between soprano and bass in the 4/3 inversion form

# Context & Application
This sequence commonly features the four-three inversion, which produces a smooth stepwise bass descent moving in parallel tenths with the soprano.

# Examples
**Example 1** (p. 554): The D3 (+3/-5) with four-three inversions creates a stepwise descending bass in parallel tenths with the soprano.
