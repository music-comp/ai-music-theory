# Quick Definition
A diatonic half step involves two different letter names (e.g., G#-A); a chromatic half step involves the same letter name (e.g., A-Ab).

# Core Definition
There are two types of half steps: **diatonic half steps** include two different letter names (e.g., G# and A, as in the E scale), while **chromatic half steps** share the same letter name (e.g., Ab and A). Both span the same acoustic distance of one semitone, but their notation reflects different functional contexts.

# Prerequisites
- **Half Step and Whole Step** -- this concept subdivides the half step category
- **Accidentals** -- accidentals create both types of half steps

# Key Properties
1. Diatonic half steps: two different letter names (e.g., E-F, B-C, G#-A)
2. Chromatic half steps: same letter name with different accidentals (e.g., F-F#, Bb-B)
3. Both span exactly one semitone acoustically
4. The distinction matters for correct notation and harmonic spelling

# Context & Application
Correct identification of diatonic vs. chromatic half steps ensures proper enharmonic spelling and reflects the underlying harmonic function of each pitch.

# Examples
**Example 1** (p. 8): In the E-major scale, G#-A is a diatonic half step (two different letter names). In a chromatic passage, A-Ab would be a chromatic half step (same letter name).
