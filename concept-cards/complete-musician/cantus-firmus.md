# Quick Definition
A cantus firmus (CF) is a pre-existing melody used as the structural foundation against which one or more contrapuntal voices are composed.

# Core Definition
**Cantus firmi** (singular: **cantus firmus**, abbreviated **CF**, meaning "fixed song") are melodies used as structural pillars against which one or more additional voices (the **contrapuntal voice** or **counterpoint**) are composed. The CF can appear above or below the added voice.

# Prerequisites
- **Melody** -- the CF is a melody following the principles of good melodic writing

# Key Properties
1. The CF provides the structural foundation for counterpoint exercises
2. It can appear in any voice (above or below the counterpoint)
3. CF melodies follow the guidelines for good melody: primarily stepwise, limited range, single climax
4. Each note of the CF typically receives one note value (whole notes in traditional exercises)
