# Quick Definition
A harmonic progression following the descending circle of fifths, which can include vi as a link: I-vi-ii-V-I or extended patterns like iii-vi-ii-V-I.

# Core Definition
The submediant fits naturally into descending-fifths progressions, extending the circle-of-fifths chain. The progression I-vi-ii-V-I combines the strong descending-fifth root motion with the smooth bass motion I-vi-ii6-V (producing ^1-^6-^4-^5 in the bass). The vi-ii connection blends descending-fifth root motion with a melodic bass arpeggiation. (Laitz, Ch. 18, pp. 427-428)

# Prerequisites
- **Submediant** — vi participates as a link in the chain

# Key Properties
1. Root motion by descending fifths (or ascending fourths)
2. vi-ii is a descending-fifth root motion
3. Using ii6 creates smooth stepwise bass motion ^6-^4
4. The complete chain can traverse all diatonic harmonies
