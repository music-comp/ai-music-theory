# Quick Definition
Durational symbols are the written notes and rests that represent specific lengths of sound and silence, organized in a hierarchy where each value is half the duration of the next larger value.

# Core Definition
Musical durations are represented by a hierarchy of note values: whole note, half note, quarter note, eighth note, sixteenth note, thirty-second note, and so on. Each note value is exactly half the duration of the next larger value. For every note value there is a corresponding **rest** symbol representing an equivalent duration of silence.

# Prerequisites
- **Rhythm** -- durational symbols are the notation of rhythmic values

# Key Properties
1. Each successive subdivision halves the duration: whole = 2 halves = 4 quarters = 8 eighths = 16 sixteenths
2. Rests mirror note values: whole rest, half rest, quarter rest, eighth rest, etc.
3. Flags or beams indicate subdivisions: one flag = eighth, two flags = sixteenth
4. Beaming groups notes to clarify metric structure

# Context & Application
Fluent reading of durational symbols is essential for performing, composing, and analyzing music. The hierarchical doubling/halving principle makes the system systematic and extendable.
