# Quick Definition
A minor v chord (with lowered ^7) used as a passing chord in minor-mode bass descents, avoiding the augmented second between raised ^7 and lowered ^6. It does not function as a dominant.

# Core Definition
In minor-mode step-descent basses, first-inversion minor v (v6) is used to precede minor iv6, giving the bass line ^8-lowered^7-^6-^5 and avoiding the augmented second that would result from using raised ^7. Minor v in first inversion or root position does not function as a dominant -- it is a passing or voice-leading chord subordinate to the prevailing descent. (Laitz, Ch. 18, pp. 434-435)

# Key Properties
1. Contains lowered ^7, not the leading tone
2. Does not function as a dominant
3. Avoids augmented second in bass
4. Typically in first inversion (v6)
