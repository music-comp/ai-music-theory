# Quick Definition
A tonic chord (typically I6) that functions as a passing chord within a pre-dominant expansion, subordinate to the surrounding PD harmony rather than serving as structural tonic.

# Core Definition
A passing tonic is a tonic chord -- usually in first inversion (I6) -- that appears within a pre-dominant expansion as a contrapuntal passing chord between two forms of the PD harmony (e.g., between ii and ii6). Despite being a tonic chord, it does not restore tonic function; it is subordinate to the pre-dominant context in which it appears. (Laitz, Ch. 17, p. 415)

# Prerequisites
- **Pre-dominant expansion** — The passing tonic occurs within PD expansion

# Key Properties
1. Usually in first inversion (I6)
2. On a metrically weak beat
3. Functions as a voice-leading chord, not a structural harmony
4. Part of a voice exchange between soprano and bass

# Relationships
## Builds Upon
- **Pre-dominant expansion** — The passing tonic is a component of PD expansion

## Contrasts With
- **Tonic expansion** — Structural tonic is the prevailing harmony; passing tonic is subordinate to PD

# Common Confusions
- **Confusion**: Every tonic chord restores tonic function
  **Clarification**: A weak-beat I6 within a PD context is a passing chord, not a return to structural tonic
