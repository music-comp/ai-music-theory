# Quick Definition
Techniques for altering a motive's pitch or rhythm while preserving its identity, including inversion, retrograde, augmentation, diminution, fragmentation, extension, truncation, and change of mode.

# Core Definition
Motivic transformations are compositional procedures that alter a motive's pitch content, rhythm, or both while maintaining enough of the original identity for the listener to perceive a connection. Principal transformations include: **inversion** (reversing the direction of all intervals), **retrograde** (stating the motive backward), **augmentation** (proportionally lengthening rhythmic values), **diminution** (proportionally shortening rhythmic values), **fragmentation** (using only a portion of the motive), **extension** (adding notes to the motive), **truncation** (removing notes from the end), and **change of mode** (major to minor or vice versa). (Laitz, Ch. 16, pp. 371-378)

# Prerequisites
- **Motive** — Must understand the original motive before studying its transformations
- **Motivic repetition types** — Transformations extend the concept of modified repetition

# Key Properties
1. Each transformation preserves some essential feature while altering others
2. Transformations can be combined (e.g., inverted and augmented simultaneously)
3. The listener must be able to perceive the connection to the original motive
4. Fragmentation is especially powerful for generating momentum and climax

# Construction / Recognition
## To Recognize:
1. Identify the original motive and its defining features (contour, rhythm, intervals)
2. For inversion: check if interval directions are reversed
3. For augmentation/diminution: check if rhythmic values are proportionally altered
4. For fragmentation: check if only a portion of the motive is used
5. For retrograde: check if the motive is stated backward

# Context & Application
Motivic transformations are the primary engine of musical development, especially in development sections of sonata forms. They allow composers to generate extended passages from minimal material while maintaining coherence.

# Examples
**Example 1** (p. 373): Beethoven -- motivic inversion where ascending intervals become descending intervals while rhythm is preserved.

**Example 2** (p. 375): Augmentation and diminution where a motive's rhythmic values are doubled or halved.

# Common Errors
- **Error**: Labeling any vaguely similar passage as a motivic transformation
  **Correction**: The connection must be perceptible -- at least one defining feature (contour, rhythm, key intervals) must be preserved

# Common Confusions
- **Confusion**: Retrograde and inversion are the same thing
  **Clarification**: Retrograde reverses the temporal order; inversion reverses the direction of intervals
