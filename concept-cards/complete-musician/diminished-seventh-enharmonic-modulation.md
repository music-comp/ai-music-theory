# Quick Definition
The diminished seventh chord can be enharmonically respelled to function as vii-dim-7 in four different keys, each a minor third apart, enabling modulation to distant tonal areas through inaudible pitch respelling.

# Core Definition
Through enharmonic reinterpretation, the vii-dim-7 becomes a vehicle that can modulate to many key areas. Each of the four pitches in a diminished seventh chord can be interpreted as a leading tone, giving access to four keys related by minor thirds or tritone. For example, the chord B-D-F-Ab can resolve to C, Eb, F#, or A. The enharmonic conversion is inaudible -- only the notation changes -- yet the harmonic ramifications are powerful, accessing keys that are six accidentals apart. Analysis uses pivot chord technique, showing the chord's function in both the old and new keys (Laitz, Ch. 34).

# Key Properties
1. Each pitch in the chord can function as a leading tone to a different key
2. Four keys accessible from one chord (related by minor thirds/tritone)
3. Enharmonic conversion is inaudible
4. Analysis uses pivot chord notation showing dual function
5. Composers may notate the chord as it functions in either the old or new key

# Examples
**Example 1** (p. 804): Beethoven, "Pathetique" Sonata, op. 13, i -- Diminished seventh in G minor enharmonically becomes vii-dim-7 in E minor.

**Example 2** (p. 805): Schubert, String Quartet in A minor, D. 804 -- Diminished seventh in A minor accesses the tritone-related Eb major without visible notation change.
