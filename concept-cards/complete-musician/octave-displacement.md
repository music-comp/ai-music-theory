# Quick Definition
A motivic transformation in which one or more notes of a motive are moved to a different octave, altering the registral profile while preserving the pitch-class content and order.

# Core Definition
Octave displacement shifts one or more pitches of a motive into a different octave. The pitch classes and their order are preserved, but the motive's contour is dramatically altered. This transformation can convert a stepwise motive into one with wide leaps, creating new melodic interest while maintaining the underlying motivic identity. (Laitz, Ch. 16, p. 374)

# Prerequisites
- **Motive** — The original motive must be established

# Key Properties
1. Pitch-class content and order preserved
2. Contour dramatically altered by register change
3. Can convert steps into leaps (or vice versa)
4. Related to compound melody (implied voices in different registers)

# Context & Application
Octave displacement is used to create dramatic contrast between motivic statements and to create compound-melody effects in solo instrumental writing.
