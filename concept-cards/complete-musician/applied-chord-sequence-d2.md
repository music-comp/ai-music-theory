# Quick Definition
The D2 (-5/+4) applied-chord sequence substitutes applied dominants for diatonic chords in the descending-second sequence, intensifying sequential motion through chromaticism.

# Core Definition
When applied chords are added to the diatonic D2 (-5/+4) sequence, the result is an applied-chord sequence that intensifies sequential motion significantly. The chromatic version features applied chords substituting for the second chord of each pair in the diatonic model. Sevenths may be added as alternating or interlocking, further enhancing goal-directed motion (Laitz, Ch. 24, p. 552).

# Prerequisites
- **Applied Chord** -- the chords added to the sequence
- **Harmonic Sequences** -- the underlying diatonic pattern

# Key Properties
1. Based on the diatonic D2 (-5/+4) sequence pattern
2. Applied chords substitute for diatonic chords, adding chromaticism
3. Sevenths can be alternating (each chord has its own seventh) or interlocking (sevenths overlap)
4. Parallel tritones may appear in upper voices (as in Beethoven's "Moonlight" Sonata Trio)

# Construction / Recognition
## To Construct:
1. Begin with a diatonic D2 (-5/+4) sequence
2. Replace the second chord of each pair with an applied dominant of the following chord
3. Optionally add sevenths (alternating or interlocking)

## To Recognize:
1. Descending bass motion by step with chromatic alterations
2. Each pair of chords follows a dominant-tonic pattern

# Context & Application
This is the most common applied-chord sequence type. It occurs frequently in music from the Baroque through the Romantic periods.

# Examples
**Example 1** (p. 552): Beethoven, Piano Sonata in C# minor ("Moonlight"), op. 27, no. 1, Trio -- parallel tritones appear in the upper voices of a D2 (-5/+4) applied-chord sequence.
