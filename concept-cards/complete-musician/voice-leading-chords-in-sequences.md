# Quick Definition
The second chord in each two-chord sequence model (and copy), which serves to break up the parallel motion that would result from moving directly by the overall step interval.

# Core Definition
In every sequence type, the second chord of the model and each copy functions as a **voice-leading chord** (or "helping chord"). Without it, moving the entire model by step would produce parallel motion in all voices. The voice-leading chord interrupts these potential parallels by inserting different root motion between the outer steps. (Laitz, Ch. 22, pp. 499-500)

# Key Properties
1. Second chord of each two-chord unit
2. Breaks up potential parallel motion
3. Essential to the contrapuntal integrity of sequences
4. Present in all four basic sequence types
