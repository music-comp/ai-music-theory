# Quick Definition
An accented neighbor tone is identical to a regular neighbor but occurs on a metrically accented beat, making the dissonance more striking; accented upper neighbors are more common than lower.

# Core Definition
The **accented neighbor tone** (AN) is a three-note figure identical to the unaccented neighbor but occurring on accented beats, creating a more striking dissonance. Accented upper neighbors are more common than accented lower neighbors. The displacement of the expected chord tone can create analytical confusion: for example, an accented neighbor in the soprano over V6 might be mistaken for a viio6/7 chord, but contextual analysis reveals it as a nonchord tone with performance implications (two-note slur patterns) (Laitz, Ch. 13, pp. 308-309).

# Prerequisites
- **Neighbor tone** -- AN is its accented version
- **Accented vs. unaccented dissonance** -- AN belongs to the accented category

# Key Properties
1. Three-note figure: chord tone - neighbor - chord tone
2. Neighbor occurs ON the beat (accented)
3. Upper AN more common than lower AN
4. Can be mistaken for a chord member -- context determines function
5. Chromatic variant also exists (accented chromatic neighbor)
