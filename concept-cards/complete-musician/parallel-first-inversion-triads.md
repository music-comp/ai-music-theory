# Quick Definition
A series of triads in first inversion moving in strict parallel motion, used since the 16th century to prolong a harmonic function or transition between functions. Not true sequences but function similarly.

# Core Definition
Parallel first-inversion triads are the only way to write a series of triads in strict parallel motion (in three voices). They function like sequences -- prolonging a harmony or transitioning between functions -- but are not strict sequences because they lack the two-chord model-and-copy structure. In four voices, the solution to parallels is alternating doublings (double soprano, double bass, double soprano...). Descending six-three passages often include 7-6 suspensions, which connect them to the D2 (-5/+4) sequence with interlocking sevenths. (Laitz, Ch. 23, pp. 525-528)

- **Harmonic sequence** — Parallel 6/3 chords function similarly but are not strict sequences

# Key Properties
1. Only way to write strict parallel triadic motion
2. Three voices: strict parallel motion; four voices: alternating doublings
3. Not strict sequences (no model-copy structure)
4. Can prolong a function or transition between functions
5. Descending 6/3 with 7-6 suspensions connect to D2 with interlocking sevenths
6. Sound more like "stalling for time" than goal-directed sequences

# Examples
**Example 1** (p. 526): Handel, Suite XIII in B major, Allemande -- descending parallel six-three chords with 7-6 suspensions.
