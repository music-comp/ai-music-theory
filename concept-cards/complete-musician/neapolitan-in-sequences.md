# Quick Definition
The Neapolitan can participate in applied-chord sequences, particularly the A2 (-3/+4), where it provides a consonant triad on b2 that can be preceded by an applied chord -- something impossible with the diatonic diminished ii° in minor.

# Core Definition
In minor-mode works, diatonic ii° cannot participate in applied sequences because diminished triads cannot be preceded by applied chords. The Neapolitan (bII) solves this problem by providing a consonant major triad on scale-degree 2. The A2 (-3/+4) sequence with applied chords commonly incorporates bII, and the sequence allows root-position bII in minor pieces (Laitz, Ch. 29, pp. 669-670).

# Key Properties
1. bII replaces diminished ii° in minor-mode sequences
2. Enables applied-chord sequences in minor that would otherwise be impossible
3. Most common in A2 (-3/+4) sequences
4. Allows root-position Neapolitan (normally restricted to first inversion)
