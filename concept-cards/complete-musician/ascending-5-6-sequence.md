# Quick Definition
The first-inversion variant of the A2 (-3/+4) sequence, featuring a sustained bass common tone and alternating 5-6 intervals in the outer voices. The bass steps up only at the start of each new copy.

# Core Definition
The ascending 5-6 sequence is the A2 (-3/+4) + 6/3 variant. The bass is sustained as a common tone within each two-chord unit, creating a 5-6 contrapuntal motion that averts parallels. The bass steps up to begin each new copy. This is perhaps the oldest of all sequences, traceable to Josquin and 16th-century composers. (Laitz, Ch. 22, pp. 507-508)

# Key Properties
1. Bass sustained as common tone within each unit
2. 5-6 contrapuntal motion in outer voices
3. Bass steps up at start of each new copy
4. Extremely smooth voice leading
5. Historical: oldest known sequence type
