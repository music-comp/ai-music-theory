# Quick Definition
Compound meter is a metric type in which the beat divides naturally into three equal parts, with the top number of the time signature divisible by 3 (6, 9, or 12).

# Core Definition
In **compound meters**, the beat divides into three equal parts (ternary division). The beat unit is a dotted note. Compound meters are classified as **compound duple** (2 dotted beats, e.g., 6/8), **compound triple** (3 dotted beats, e.g., 9/8), and **compound quadruple** (4 dotted beats, e.g., 12/8). In compound time signatures, the top number indicates the total number of beat divisions (not beats), so you divide by 3 to find the number of beats. The bottom number indicates the note value of each division.

# Prerequisites
- **Meter** -- compound meter is one category of meter

# Key Properties
1. Beat divides into three equal parts (ternary division)
2. The beat unit is always a dotted note value
3. Top number divided by 3 = number of beats per measure
4. Common compound meters: 6/8 (2 beats), 9/8 (3 beats), 12/8 (4 beats)
5. 6/8 has 2 dotted-quarter beats, not 6 eighth-note beats

# Construction / Recognition
## To Recognize:
1. If the top number is 6, 9, or 12, the meter is compound
2. Divide the top number by 3 to find the number of beats
3. The beat unit is a dotted version of the bottom number's note value

# Context & Application
Compound meter creates a lilting, rolling quality distinct from simple meter. It is common in dance forms (jigs, barcarolles), pastoral music, and lullabies.
