# Quick Definition
An unprepared chromatic modulation is a direct, abrupt shift to a new key without a pivot chord or common tone, relying on formal context (such as phrase boundaries) to justify the juxtaposition.

# Core Definition
In unprepared chromatic modulations, there is no pivot chord or common tone; the new key simply arrives. Such juxtapositions typically occur at formal boundaries (after double bars or between phrases) where the listener accepts the tonal surprise. The new key is usually confirmed by a strong cadence. The technique was used by Haydn, Beethoven, and Romantic composers for dramatic effect (Laitz, Ch. 28, p. 646).

# Key Properties
1. No pivot chord or common tone
2. Direct juxtaposition of two keys
3. Often occurs at formal boundaries
4. Relies on confirmation by cadence in the new key
5. More dramatic than prepared modulations

# Examples
**Example 1** (p. 646): Haydn, String Quartet in C major, op. 54 no. 2 -- abrupt shift to a new key at a formal boundary.
