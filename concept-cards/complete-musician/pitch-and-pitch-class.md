# Quick Definition
A pitch is a specific musical tone at a particular frequency and register; a pitch class groups together all pitches sharing the same letter name across all octaves.

# Core Definition
**Pitch** refers to the relative highness or lowness of sound, generated by a vibrating body. The speed of regularly recurring vibrations (the frequency) determines the pitch: faster vibrations produce higher pitches. Pitch specifies both the name and register placement. **Pitch class** refers to all pitches with the same letter name regardless of octave. Pitches separated by octaves sound nearly identical because the frequency doubles with each octave ascent. **Register** refers to the specific area in which musical activity takes place (e.g., middle C is C4).

# Prerequisites
- No formal prerequisites

# Key Properties
1. There are 12 pitch classes in the chromatic system
2. Pitches at a distance of one or more octaves share the same pitch class and letter name
3. The frequency relationship: each octave higher doubles the frequency; each octave lower halves it
4. Octave designations number each octave from C upward (C1 is the lowest C on piano; middle C is C4)
5. The waveform of a vibrating body creates the timbre (tone quality) that distinguishes instruments

# Construction / Recognition
## To Recognize:
1. Determine the letter name (A through G)
2. Add the octave designation to specify the exact pitch
3. For pitch class, disregard octave -- all Cs are pitch class C

# Context & Application
The distinction matters for understanding octave equivalence, transposition, and chord identification. When we say a piece is "in C major," we refer to pitch class C as tonic regardless of octave.

# Relationships
## Enables
- **Octave** -- the interval that connects pitches of the same class
- **Enharmonic Equivalence** -- same pitch class, different spelling
- **Register** -- the specific octave placement of a pitch

# Common Errors
- **Error**: Using "pitch," "note," and "pitch class" interchangeably.
  **Correction**: A pitch is the acoustic phenomenon, a note is the written symbol, and a pitch class is the abstract category grouping all octave-related pitches.

# Common Confusions
- **Confusion**: Assuming pitch class implies a specific octave.
  **Clarification**: Pitch class is octave-independent; C4 and C6 are different pitches but the same pitch class.
