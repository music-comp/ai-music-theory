# Quick Definition
Seventh chord analysis uses roman numerals with subscript 7 and inversion figures, following the same uppercase/lowercase conventions as triads, with added symbols for half-diminished (slashed-deg) and fully diminished (deg).

# Core Definition
When analyzing seventh chords with roman numerals: **Mm and MM** seventh chords require uppercase roman numerals; **mm, dm, and dd** require lowercase. The dd seventh chord adds a degree sign (deg7); the dm (half-diminished) adds a slashed degree sign. Particular seventh chord types are associated with particular scale degrees in each key.

# Key Properties
1. Uppercase: Mm7 and MM7 (e.g., V7, IV-triangle-7)
2. Lowercase: mm7 (e.g., ii7), dm7 (e.g., ii-slashed-deg-7), dd7 (e.g., vii-deg-7)
3. In major: I-triangle-7 (MM), ii7 (mm), iii7 (mm), IV-triangle-7 (MM), V7 (Mm), vi7 (mm), vii-slashed-deg-7 (dm)
4. In minor: i7 (mm), ii-slashed-deg-7 (dm), III-triangle-7 (MM), iv7 (mm), V7 (Mm), VI-triangle-7 (MM), vii-deg-7 (dd)
5. Add inversion figures as subscripts: V6/5, V4/3, V4/2
