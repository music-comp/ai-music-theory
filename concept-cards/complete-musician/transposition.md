# Quick Definition
Transposition is the process of moving a pitch pattern so that it begins on a different pitch while preserving the same intervallic relationships.

# Core Definition
**Transposition** is moving any pitch pattern so that it begins on a different set of pitches while maintaining the same intervallic structure. A major scale can be generated on each of the 12 pitch classes by transposing the same pattern of half and whole steps. Transposition can be performed by scale degree (maintaining function within a new key) or by interval (shifting each pitch by the same distance).

# Prerequisites
- **Key** -- transposition moves material from one key to another
- **Scale Degrees** -- scale degree method preserves functional relationships

# Key Properties
1. Transposition preserves all intervallic relationships
2. Two methods: by scale degree (functional) or by interval (mechanical)
3. The circle of fifths guides transposition by fifths

# Context & Application
Transposition is used in composition, arranging, and performance (especially for transposing instruments). It is fundamental to understanding key relationships.

# Examples
**Example 1** (p. 10): Building a major scale on A by transposing the E-major pattern yields A-B-C#-D-E-F#-G#-A.
**Example 2** (p. 22): Exercise 1.3 demonstrates transposing a melodic fragment from G major to E major by identifying scale degrees and applying them in the new key.
