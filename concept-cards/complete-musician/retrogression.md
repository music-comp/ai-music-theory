# Quick Definition
A harmonic motion that reverses the normal functional order of the phrase model (e.g., D moving back to PD). Often, apparent retrogressions are better explained as back-relating dominants.

# Core Definition
A retrogression is a harmonic motion that moves backward in the phrase model's functional order -- for example, from D back to PD (V to ii). While true retrogressions exist, many apparent retrogressions are better analyzed as back-relating dominants, where V prolongs the preceding tonic rather than progressing forward to ii. True retrogressions are relatively rare in common-practice music. (Laitz, Ch. 19, pp. 451-452)

# Key Properties
1. Reverses the normal T-PD-D-T functional order
2. Many apparent retrogressions are actually BRDs
3. True retrogressions are rare in common practice
