# Quick Definition
A sequence that moves from one harmonic function to another (e.g., T to PD), serving as a bridge between functional areas within the phrase model.

# Core Definition
A transitional sequence moves from one harmonic function to a different one. For example, a sequence beginning on tonic and ending on the pre-dominant creates a T-PD transition. The sequence connects the tonic expansion to the cadential portion of the phrase. Composers can blur the distinction between prolongational and transitional sequences by altering rhythm and metric placement. (Laitz, Ch. 23, pp. 514-516)

# Key Properties
1. Connects two different harmonic functions
2. Common transition: T to PD
3. Bridges the gap between tonic expansion and cadence
4. Distinction from prolongational can be blurred
