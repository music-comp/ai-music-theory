# Quick Definition
Contrapuntal expansion extends a structural harmony (usually I or V) over time by using subordinate chords derived from melodic motions (passing, neighboring, chordal skip) in the bass and upper voices.

# Core Definition
**Contrapuntal expansion** (or **prolongation**) is the process of extending a structural harmony over time through subordinate chords that arise from melodic motions in the outer voices. These subordinate chords -- including first-inversion triads, neighboring chords, passing chords, and chordal skips -- do not represent changes in harmonic function but rather embellish the controlling harmony. The technique makes the bass line melodic while maintaining harmonic stability. It is far more common to expand tonic than dominant (Laitz, Ch. 10, pp. 226-230).

# Key Properties
1. A single harmony controls a passage despite intervening chords
2. Subordinate chords arise from melodic motions (passing, neighboring, chordal skip)
3. Subordinate chords are usually in inversion (first inversion)
4. Subordinate chords usually occur on metrically weak beats
5. Tonic expansion is far more common than dominant expansion
6. Three types: chordal leap (I-I6), neighbor (I-V6-I), passing (I-viio6-I6)

# Construction / Recognition
## To Construct:
1. Establish the structural harmony in root position
2. Add subordinate chords using one of three bass motions: leap, neighbor, or passing
3. Place subordinate chords on weak beats
4. Ensure the structural harmony frames the expansion

## To Recognize:
1. Identify root-position structural chords on strong beats
2. Note inverted chords between them on weak beats
3. Check if the intervening chords share a contrapuntal relationship with the framing harmony
4. In second-level analysis, label subordinate chords by melodic function

# Context & Application
Contrapuntal expansion is the primary means by which composers create musical interest within a harmonic function. It transforms static harmonies into dynamic, goal-directed passages with melodic bass lines.

# Examples
**Example 1** (pp. 228-229): Brahms's "Vom verwundeten Knaben" uses only I, I6, V, and V6, but with first inversions the passage becomes buoyant and directed toward the half cadence.
