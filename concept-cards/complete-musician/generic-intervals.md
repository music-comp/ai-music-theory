# Quick Definition
A generic interval is the numerical distance between two pitches measured by counting the letter names spanned (including both endpoints), without regard to accidentals.

# Core Definition
The **generic** name of an interval is the number derived from counting the pitch letter names that separate the two notes, including both endpoints. For example, G up to E spans six letter names (G-A-B-C-D-E), so it is a generic sixth. Contour (ascending/descending) and accidentals do not change the generic size.

# Prerequisites
- **Interval** -- generic intervals are one component of interval identification

# Key Properties
1. Count both the lower and upper pitch: C to E = 3rd (C-D-E)
2. Accidentals do not affect generic size: C to E, C to Eb, C# to E are all thirds
3. Staff shortcut: both notes on lines or both on spaces = odd-numbered interval; one on line, one on space = even-numbered interval
4. Unison = 1, second = 2, third = 3, ... octave = 8

# Construction / Recognition
## To Determine:
1. Count the letter names from the lower to the upper pitch, inclusive
2. The count gives the generic interval number
3. Use staff shortcuts: line-to-line or space-to-space = odd; line-to-space = even

# Examples
**Example 1** (p. 71): G4 up to E5 spans six letter names (G-A-B-C-D-E), so it is a sixth, regardless of accidentals.
