# Quick Definition
In the larger context, modulations never permanently displace the prevailing tonic; they participate in a single overall harmonic motion that encompasses the entire work.

# Core Definition
Very few compositions end in a different key from the one in which they begin. Modulations in tonal music participate in a single overall harmonic motion. For example, a piece in C minor might modulate to Eb major and F minor before returning to C minor, constituting a large-scale i-III-iv-V-i progression. New keys should be referred to in relation to the original tonic (Laitz, Ch. 25, p. 574).

# Key Properties
1. The home key always returns
2. Modulations form large-scale harmonic progressions
3. New keys are labeled by roman numeral relative to the original tonic
4. Determining whether a tonal shift is a tonicization or modulation is often a matter of interpretation
