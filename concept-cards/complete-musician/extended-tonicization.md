# Quick Definition
An extended tonicization is a prolonged tonicization in which a diatonic harmony is expanded through multiple applied chords and contrapuntal devices, functioning as a temporary key area within a phrase.

# Core Definition
A tonicization is extended in the same way that a harmonic function is extended within a phrase: through passing chords, neighbor chords, and other contrapuntal devices applied within the temporary key. To analyze an extended tonicization: (1) bracket where the tonicization occurs; (2) label the temporary tonic chord under the bracket; (3) label all chords within the bracket as if they were in the temporary new key. Extended tonicizations may last several measures but do not include strong cadences in the temporary key (Laitz, Ch. 25, pp. 563-566).

# Prerequisites
- **Tonicization** -- the basic concept being extended

# Key Properties
1. Multiple chords function within the temporary key
2. The temporary key area is bracketed in analysis
3. All chords within the bracket are labeled in the temporary key
4. The tonicized harmony retains its structural function in the home key
5. Can create large-scale arpeggiations of the tonic triad

# Construction / Recognition
## To Construct:
1. Select a target harmony for tonicization
2. Write a mini-progression in the temporary key (e.g., I-vii°6-I6 in the temporary key)
3. Ensure the extended tonicization fits within the larger phrase structure

## To Recognize:
1. Multiple chromatic chords pointing toward a single non-tonic harmony
2. Contrapuntal expansion patterns (passing chords, neighbors) within a temporary key
3. No strong cadence in the temporary key

# Context & Application
Extended tonicizations allow composers to dwell on a particular harmony for expressive effect while maintaining the overall tonal progression. They can create large-scale arpeggiations (e.g., tonicizing i, III, and v in minor outlines the tonic triad at a deep structural level).

# Examples
**Example 1** (p. 564): Beethoven, Piano Sonata op. 27 no. 1 -- extended tonicization of ii (F minor) in E-flat major, expanding the pre-dominant area.

**Example 2** (p. 565): Robert Schumann, "Sangers Trost" -- tonicizations of G minor, B-flat major, and D minor create a large-scale arpeggiation of the G-minor tonic triad.
