# Quick Definition
The analytical convention for sequences: provide only the roman numeral for the first and last chords, plus a sequence label showing overall motion, specific root motions, and inversions.

# Core Definition
Given the contrapuntal derivation of sequences, individual chords within a sequence do not receive separate roman numeral analysis. Instead, provide: (1) the roman numeral for the first chord; (2) the roman numeral for the last chord; (3) a sequence label including overall motion (D2, D3, A2), specific root motions (-5/+4, -4/+2, etc.), and inversions (+6/3s). Bracket the model and copies in the score. (Laitz, Ch. 22, p. 501)

# Key Properties
1. Only first and last chords get roman numerals
2. Label format: direction + interval + root motions + inversions
3. Bracket model and copies in the score
