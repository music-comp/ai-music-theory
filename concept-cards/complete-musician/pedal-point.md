# Quick Definition
A pedal point is a sustained pitch (usually tonic or dominant in the bass) held motionless through multiple harmonic changes; the harmonies above it are subordinate to the pedal's implied function.

# Core Definition
A **pedal** (or **pedal point**) is a sustained pitch or harmony that remains stationary during multiple harmonic changes above it. Derived from the organ's ability to sustain a pitch indefinitely, the pedal usually occurs in the bass and is almost always a tonic or dominant scale degree. It slows harmonic motion and firmly grounds the music on a single function. In second-level analysis, the harmonic successions above a pedal are subordinate to the pedal's function (Laitz, Ch. 13, pp. 320-321).

# Prerequisites
- **Tones of figuration** -- the pedal creates a framework for figuration above it

# Key Properties
1. Usually in the bass voice
2. Almost always ^1 (tonic pedal) or ^5 (dominant pedal)
3. Sustained through multiple chord changes
4. Subordinate harmonies unfold above
5. Common in cadential situations
6. Can occur in upper voices (inverted pedal) or inner voices

# Examples
**Example 1** (p. 321): Bach's Fugue in C minor (WTC Book 1) ends with a tonic pedal in the bass, over which multiple harmonic successions unfold, all subordinate to the sustained tonic.
