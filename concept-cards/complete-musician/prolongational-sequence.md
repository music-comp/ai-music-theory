# Quick Definition
A sequence that expands a single harmonic function (e.g., T-T), prolonging the prevailing harmony without moving to a new function.

# Core Definition
A prolongational sequence expands one harmonic function. For example, a D2 sequence that begins and ends on tonic prolongs the tonic function (T-T). At the second level, the entire sequence falls under one functional label. Prolongational sequences contrast with transitional sequences, which move from one function to another. Composers often blur this distinction for seamless musical structures. (Laitz, Ch. 23, pp. 514-516)

# Key Properties
1. Expands one harmonic function (T-T, PD-PD, etc.)
2. Begins and ends on the same function
3. Second-level analysis shows one functional label
4. Distinction from transitional sequences can be blurred by rhythm/meter
