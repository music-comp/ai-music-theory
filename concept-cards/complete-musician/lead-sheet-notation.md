# Quick Definition
Lead-sheet notation identifies chords by root letter and quality symbol (e.g., Cmaj7, Dm7, G7), used in jazz and popular music as an alternative to roman numeral analysis.

# Core Definition
**Lead-sheet notation** identifies chordal roots, qualities, and inversions using letter names and quality symbols. Root-position triads: uppercase letter for major (C), uppercase + dash or lowercase for minor (C- or c), uppercase + deg for diminished (C-deg), uppercase + plus for augmented (C+). Seventh chords: C7 (Mm), C-triangle-7 (MM), Cm7 (mm), C-slashed-deg-7 (dm), C-deg-7 (dd). Inversions use a slash followed by the bass note (e.g., C/E for first inversion).

# Prerequisites
- **Triads** -- lead-sheet symbols label triads
- **Seventh Chords** -- extended to seventh chord labeling

# Key Properties
1. Major triad: uppercase letter alone (C)
2. Minor triad: C- or Cm or c
3. Diminished: C-deg
4. Augmented: C+
5. Seventh chords add the quality + 7: C7 (Mm), CM7 or C-triangle-7 (MM), Cm7 (mm)
6. Inversions: root/bass note (e.g., Cm7/G for second inversion)
7. Lead-sheet is not function-based (no key reference, unlike roman numerals)

# Context & Application
Lead-sheet notation is standard in jazz, popular music, and commercial music contexts. It provides quick chord identification but does not show functional relationships within a key.

# Relationships
## Contrasts With
- **Roman Numeral Analysis** -- function-based (relative to key)
- **Figured Bass** -- interval-based (above a bass note)
