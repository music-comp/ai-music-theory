# Quick Definition
Musical accents are events that draw the listener's attention; they include temporal accents (metric position, agogic/durational) and nontemporal accents (dynamic, registral, textural).

# Core Definition
Accent in music refers to events that are emphasized or draw the listener's attention. There are two broad categories: **temporal accents** and **nontemporal accents**. Temporal accents include **metric accent** (prominence due to position on a strong beat), **agogic accent** (emphasis created by a longer duration), and accent created by pattern changes. Nontemporal accents include **dynamic accent** (louder volume), **registral accent** (extreme high or low pitch), and **textural accent** (change in density or instrumentation). When two or more accent types align, they create particularly strong emphasis.

# Key Properties
1. Metric accent: beats on strong positions feel heavier naturally
2. Agogic accent: longer notes stand out against shorter surrounding notes
3. Dynamic accent: louder notes draw attention
4. Pattern-change accent: the beginning of a new melodic gesture attracts attention
5. Multiple accent types working together create the strongest emphasis
6. Accents help establish tonal hierarchy by emphasizing structurally important pitches

# Context & Application
Understanding accent types is essential for analysis (determining which pitches are structurally important), performance (shaping phrasing), and composition (controlling listener attention).
