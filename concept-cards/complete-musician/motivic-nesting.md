# Quick Definition
A motive that contains within itself a smaller-scale version of the same pattern, creating a self-similar structure across levels.

# Core Definition
Motivic nesting occurs when a motive's internal structure replicates the shape of the motive at a smaller scale -- the motive contains itself, so to speak. This creates an especially tight form of organic unity, as the same pattern governs both the motive's overall shape and its internal construction. (Laitz, Ch. 16, p. 386)

# Prerequisites
- **Motivic parallelism** — Nesting is a special case of parallelism within a single motive

# Key Properties
1. Self-similar structure across levels
2. Creates exceptionally tight organic unity
3. Often revealed through analytical reduction

# Context & Application
Motivic nesting is a mark of the most sophisticated compositional craft and is particularly associated with the works of Beethoven and Brahms.
