# Quick Definition
Strophic form is a song structure in which the same music is repeated for each stanza of text, with a modified strophic variant allowing harmonic or melodic alterations for dramatic stanzas.

# Core Definition
Strophic form is the simplest formal type for the German Lied, in which the same music accompanies each stanza of the poem. Modified strophic form maintains the basic strophic structure but allows harmonic, melodic, or textural changes in certain stanzas for dramatic effect. This stands in contrast to through-composed form, where new music is written for each stanza (Laitz, Ch. 28, p. 649).

# Key Properties
1. Same music repeated for each stanza
2. Modified strophic: allows changes for dramatic stanzas
3. Simplest formal type for Lieder
4. Unity from repetition, variety from text change
