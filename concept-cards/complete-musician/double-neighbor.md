# Quick Definition
A double neighbor combines an upper neighbor and a lower neighbor (or vice versa) around a single chord tone, creating a three-note embellishment that returns to the original pitch.

# Core Definition
A **double neighbor** (DN) results from the combination of the upper neighbor and lower neighbor around a single chord tone. The figure moves stepwise away from the chord tone in one direction, then to the other neighbor, and returns to the original pitch. The ordering can be upper-then-lower or lower-then-upper (Laitz, Ch. 7, p. 163).

# Prerequisites
- **Neighbor tone** -- double neighbor combines upper and lower neighbors

# Key Properties
1. Combines upper and lower neighbors around a single pitch
2. Returns to the starting chord tone
3. Can be ordered UN-LN or LN-UN
4. Creates a more elaborate ornamental figure than a single neighbor
