# Quick Definition
Simple meter is a metric type in which the beat divides naturally into two equal parts, with the top number of the time signature indicating the number of beats per measure.

# Core Definition
In **simple meters**, the beat divides into two equal parts. Simple meters are classified by the number of beats per measure: **simple duple** (2 beats, e.g., 2/4), **simple triple** (3 beats, e.g., 3/4), and **simple quadruple** (4 beats, e.g., 4/4). In simple meter signatures, the top number indicates the number of beats per measure, and the bottom number indicates the note value that receives one beat.

# Prerequisites
- **Meter** -- simple meter is one category of meter

# Key Properties
1. Beat divides into two equal parts (binary division)
2. Top number of time signature = number of beats per measure
3. Bottom number = note value receiving one beat (4 = quarter note, 2 = half note)
4. Common simple meters: 2/4, 3/4, 4/4, 2/2
5. Further subdivision creates groups of four (two groups of two)

# Construction / Recognition
## To Recognize:
1. Check if the beat divides naturally into two
2. In the time signature, if the top number is 2, 3, or 4, the meter is simple

# Context & Application
Simple meter is the most common metric framework in Western music. Most marches, waltzes, and standard songs use simple meters.
