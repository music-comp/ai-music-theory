# Quick Definition
Enharmonically equivalent pitches share the same keyboard location and sound the same but have different letter names (e.g., C# and Db).

# Core Definition
Pitches and pitch classes that have the same location on the keyboard but different names are **enharmonically equivalent**. Since enharmonically related pitches sound the same, they are considered to be the same pitch class. However, the specific name given to a pitch is determined by how it functions within a musical context.

- **Accidentals** -- understanding sharp, flat, and their effects

# Key Properties
1. On fixed-pitch instruments (piano), enharmonic pitches are physically identical
2. On moveable-pitch instruments (strings), players slightly alter enharmonic pitches to fit the context (e.g., G# may be played slightly higher than Ab)
3. Two principles govern spelling choice: (a) use the name representing membership in the prevailing key; (b) in chromatic passages, use sharps/naturals ascending and flats/naturals descending

# Construction / Recognition
## To Recognize:
1. Identify two pitch names that occupy the same keyboard key
2. C#/Db, D#/Eb, F#/Gb, G#/Ab, A#/Bb are common pairs
3. Less common: B#/C, Cb/B, E#/F, Fb/E

# Context & Application
Correct enharmonic spelling communicates harmonic function and voice-leading direction. An F# ascending to G and a Gb descending to F are the same pitch class but convey different musical meanings.

# Common Errors
- **Error**: Assuming enharmonic spellings are interchangeable in all contexts.
  **Correction**: Use the spelling that reflects the harmonic function. F# in a context ascending to G is correct; Gb would mislead the reader.
