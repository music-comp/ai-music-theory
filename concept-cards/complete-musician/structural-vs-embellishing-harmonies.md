# Quick Definition
Structural harmonies are progressional (indicating movement between functions like I and V); embellishing harmonies are prolongational (extending a single structural harmony through contrapuntal motion).

# Core Definition
**Structural harmonies** are **progressional** -- they indicate genuine movement from one harmonic function to another (e.g., tonic to dominant). They tend to be in root position, on strong beats, and part of a harmonic progression. They retain their roman numerals in second-level analysis. **Embellishing (subordinate) harmonies** are **prolongational** -- they extend or prolong a single structural harmony through contrapuntal motion. They tend to be in inversion, on weak beats, and are labeled by melodic function (N, P, CL) in second-level analysis (Laitz, Ch. 10, pp. 233-234).

# Prerequisites
- **Second-level analysis** -- the notation distinguishing structural from embellishing
- **Contrapuntal expansion** -- embellishing harmonies arise from contrapuntal motions

# Key Properties
| Feature | Structural | Embellishing |
|---|---|---|
| Function | Progressional | Prolongational |
| Roman numerals | Retained | Replaced by melodic labels |
| Position | Usually root position | Usually inversion |
| Metric placement | Usually strong beats | Usually weak beats |
| Role | Part of harmonic progression | Part of contrapuntal progression |

# Context & Application
This distinction is essential for meaningful analysis. Merely labeling every chord with a roman numeral (first-level analysis) is description, not analysis. True analysis requires interpreting the function of each harmony within its context.
