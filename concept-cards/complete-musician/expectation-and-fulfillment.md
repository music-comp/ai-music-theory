# Quick Definition
Expectation/fulfillment is a Gestalt principle: composers delay or thwart expected musical events to create drama; the longer the postponement, the more powerful the effect.

# Core Definition
**Expectation/fulfillment** is a Gestalt psychological principle central to music. Composers momentarily change a melodic line's direction or delay an expected harmonic event, postponing what listeners assume will happen. The longer the postponement, the more dramatic the eventual fulfillment. This process is central to the unfolding of a musical work (Laitz, Ch. 7, p. 177).

# Prerequisites
- **Melodic fluency** -- expectations arise from structural lines

# Key Properties
1. Expectations are set up by established patterns
2. Composers delay fulfillment to create tension
3. Longer delays create more dramatic effects
4. Applies to melodic lines, harmonic arrivals, and cadential patterns

# Examples
**Example 1** (p. 177): In Corelli's Sarabande in D minor, a clear descending fifth from A to D is postponed by an upper-neighbor A-B-A figure after the initial arpeggiation, delaying four of the five descent pitches to mm. 3-4.
