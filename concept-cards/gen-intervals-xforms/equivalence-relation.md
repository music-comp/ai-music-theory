# Quick Definition

An equivalence relation on a set S is a relation that is reflexive (every element relates to itself), symmetric (if s relates to t then t relates to s), and transitive (if r relates to s and s relates to t, then r relates to t).

# Core Definition

"Given a family S, an equivalence relation on S is a subfamily EQUIV of S x S that satisfies conditions (A), (B), and (C) following. (A): For every s in S, (s, s) is in EQUIV. (B): If (s, t) is in EQUIV, then so is (t, s). (C): If (r, s) and (s, t) are in EQUIV, then so is (r, t)" (Lewin, Definition 1.9.1, p. 37). Every function f from S onto S' induces an equivalence relation: s ~ t if and only if f(s) = f(t) (Theorem 1.9.2). Conversely, every equivalence relation can be regarded as generated in this fashion.

# Prerequisites

- **Function** — equivalence relations can be generated by functions (Theorem 1.9.2)

# Key Properties

1. Reflexive: s ~ s for all s (Condition A)
2. Symmetric: s ~ t implies t ~ s (Condition B)
3. Transitive: r ~ s and s ~ t implies r ~ t (Condition C)
4. Every onto function induces an equivalence relation: s ~ t iff f(s) = f(t)
5. An equivalence relation partitions S into disjoint equivalence classes

# Construction / Recognition

## To Construct:
1. Define a relation on S (a subset of S x S)
2. Verify reflexivity, symmetry, and transitivity

## To Recognize:
1. Check all three conditions: reflexive, symmetric, transitive
2. Failure of any one condition means the relation is not an equivalence relation

# Context & Application

Equivalence relations partition musical spaces into meaningful categories. Octave equivalence groups pitches into pitch classes. Transposition/inversion equivalence groups pitch-class sets into set-types. Understanding equivalence relations is fundamental to pitch-class theory, set theory, and quotient constructions in GIS theory.

# Examples

**Example 1** (1.9.6.1, p. 37): Let S be all pitches under equal temperament. Define s ~ t if s and t have the same letter name (modulo enharmonic equivalence). S/EQUIV comprises the twelve pitch classes. The natural map E takes each pitch to its pitch class.

**Example 2** (1.9.6.2, p. 37): Let S be all beats in a waltz. Define s ~ t if they share the same beat number. The three equivalence classes are the "beat classes."

**Example 3** (1.9.6.3, p. 37): Let S be all collections of pitch classes. Put (s, t) in SAMETYPE if t is a transposed or inverted form of s. The equivalence classes are Forte's set-types: class 3-11 contains all 24 major and minor triads.

# Common Errors

- **Error**: Checking only one or two of the three conditions.
  **Correction**: All three conditions (reflexive, symmetric, transitive) are required.

# Common Confusions

- **Confusion**: Thinking any relation is an equivalence relation.
  **Clarification**: "Less than" is not symmetric; "is a friend of" may not be transitive. Only relations satisfying all three conditions qualify.
