# Quick Definition
The senario is Zarlino's foundational set of numbers 1 through 6, from which all consonant intervals derive through ratios (2:1 = octave, 3:2 = fifth, 4:3 = fourth, 5:4 = major third, 6:5 = minor third, 5:3 = major sixth). The minor sixth (8:5) notably falls outside this system.

# Core Definition
The senario comprises {1, 2, 3, 4, 5, 6}. Ratios between these numbers produce all consonant intervals recognized in Renaissance theory. The minor sixth requires the ratio 8:5, necessitating adjunction of the number 8 to the senario, which raises awkward questions about why 7 is excluded. Both Zarlino and Hindemith encounter the minor sixth as the interval that resists derivation from six-element harmonic systems (Lewin, Appendix A, pp. 247-250).

# Key Properties
1. Contains only the numbers 1 through 6
2. All ratios between senario numbers yield consonant intervals
3. The minor sixth (8:5) requires extending beyond the senario
4. The number 7 is excluded, avoiding the "natural seventh" (7:4)
5. Zarlino and Hindemith both encounter difficulties at the number 8

# Examples
**Example 1** (pp. 247-248): Senario ratios: 2:1 (octave), 3:2 (fifth), 4:3 (fourth), 5:4 (major third), 6:5 (minor third), 5:3 (major sixth)

**Example 2** (p. 248): Zarlino's problematic extension: adjoining 8 to derive the minor sixth, claiming 6 is a "harmonic mean" between 8 and 5 (false)
