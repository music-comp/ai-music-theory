# Quick Definition
A node in a node/arrow system from which no proper arrows issue - arrows only come into it (plus the reflexive arrow from itself), giving it a terminal or goal function in the network.

# Formal Definition
An output node OUT in a node/arrow system satisfies:
- If (OUT, N) is in the ARROW relation, then N = OUT
- No proper arrows go FROM the output node
- Only the reflexive arrow (OUT, OUT) issues from OUT

# Mathematical Formulation
Formal criterion:
- For all N in NODES: (OUT, N) in ARROW implies N = OUT
- Equivalently: The only N with (OUT, N) in ARROW is N = OUT

Output nodes have:
- Zero out-degree (except reflexive)
- Possibly positive in-degree

# Musical Context/Application
Output nodes model endpoints or goals of transformational processes. They correspond to musical objects that are generated by the network but do not themselves generate others within the network's scope. Output nodes often represent:
- Cadential goals
- Structural arrivals
- Tonal centers (when arrows point toward the tonic)

# Common Confusions
- Output is formal graph property, not claim about temporal sequence
- The same Klang can be input at one position and output at another
- Output does not mean "last heard" in musical chronology
- A network may have multiple outputs, one output, or no outputs
