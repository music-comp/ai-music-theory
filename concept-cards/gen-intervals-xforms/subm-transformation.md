# Quick Definition
The formal inverse of MED: SUBM transforms a Klang so that it becomes the submediant of the result, changing mode. (C, +)SUBM = (E, -) means "C major becomes submediant of E minor."

# Core Definition
"In similar vein, we can define and explore SUBM, the formal inverse of MED" (Lewin, 8.1.1, p. 177). SUBM changes both pitch class and mode. Networks using SUBM and PAR together are genuinely non-intervallic because both operations map (C, +) to some minor Klang but via different routes, violating simple transitivity.

# Prerequisites
- **Klang representation** — SUBM operates on Klangs
- **MED transformation** — SUBM is defined as MED's inverse

# Key Properties
1. (p, +)SUBM = (p + 3, -) mod 12
2. (p, -)SUBM = (p + 4, +) mod 12
3. SUBM = MED^{-1}
4. SUBM changes mode
5. The group generated by SUBM equals the group generated by MED

# Construction / Recognition
## To Construct:
1. For major Klang (p, +): move root up a minor third, change to minor
2. For minor Klang (p, -): move root up a major third, change to major
## To Recognize:
1. A Klang arrow that changes mode and moves the root upward

# Context & Application
SUBM appears in the Tarnhelm and Valhalla networks (Figure 8.2), where it combines with PAR to create genuinely non-intervallic transformational structures.

# Examples
**Example 1** (p. 177): (C, +)SUBM = (E, -): C major becomes submediant of E minor. (A, -)SUBM = (C, +): A minor becomes submediant of C major.

# Relationships
## Builds Upon
- **MED transformation** — SUBM = MED^{-1}
## Enables
- **Non-intervallic transformations** — SUBM + PAR in a group prevents simple transitivity
- **Tarnhelm network** — Uses SUBM alongside PAR
## Contrasts With
- **MED transformation** — SUBM is the inverse
- **REL transformation** — SUBM differs from REL: (C, +)SUBM = (E, -) but (C, +)REL = (A, -)

# Common Errors
- **Error**: Confusing SUBM with REL
  **Correction**: (C, +)SUBM = (E, -) but (C, +)REL = (A, -); they map to different Klangs

# Common Confusions
- **Confusion**: Thinking SUBM preserves mode like SUBD
  **Clarification**: SUBM changes mode (like MED); SUBD preserves mode (like DOM)
