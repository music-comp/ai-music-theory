# Quick Definition
The formal inverse of MED; SUBM transforms a Klang so that it becomes the submediant of the result, changing mode in the process.

# Formal Definition
SUBM = MED^(-1):
- (p, +)SUBM = (p + 3, -): Major Klang becomes submediant of result
- (p, -)SUBM = (p + 4, +): Minor Klang becomes submediant of result

The transformation changes mode and adjusts pitch class in the inverse pattern of MED.

# Mathematical Formulation
SUBM transformation:
- (p, +)SUBM = (p + 3, -) mod 12
- (p, -)SUBM = (p + 4, +) mod 12

Key relationships:
- SUBM = MED^(-1)
- MED = SUBM^(-1)
- (SUBM)(MED) = (MED)(SUBM) = identity

# Musical Context/Application
SUBM and MED together generate the simply transitive group on Klangs derivable from a given Klang. Networks using only powers of MED (equivalently, powers of SUBM) can be considered "formally intervallic." When PAR or REL appear alongside SUBM, the network becomes genuinely non-intervallic.

# Examples
Applications:
- (C, +)SUBM = (E, -): C major becomes submediant of E minor
- (C, -)SUBM = (E, +): C minor becomes submediant of E major

Relationship to MED:
- (C, +)MED = (A, -)
- (A, -)SUBM = (C, +) [inverse operation returns to start]

# Common Confusions
- SUBM is not the same as REL (they differ on minor Klangs)
- SUBM changes mode; SUBD does not
- SUBM = MED^(-1), not DOM^(-1)
- The group generated by MED = the group generated by SUBM
