# Quick Definition
An underlying structural pattern that can be realized differently in different musical contexts, allowing multiple passages to be understood as manifestations of one phenomenon rather than as original and parody.

# Formal Definition
An abstract gesture is a transformation graph (nodes connected by labeled arrows) considered independently of:
- The specific objects filling the nodes
- The chronological order of events
- The musical surface realization

Different networks that share the same graph manifest the same abstract gesture.

# Mathematical Formulation
Formally, an abstract gesture is a transformation graph (NODES, ARROW, SGP, TRANSIT) without a CONTENTS function. Multiple networks can realize the same graph with different contents:
- Network 1: (S, NODES, ARROW, SGP, TRANSIT, CONTENTS_1)
- Network 2: (S, NODES, ARROW, SGP, TRANSIT, CONTENTS_2)

Both manifest the same abstract gesture if they share the same graph.

# Musical Context/Application
The concept enables a critical alternative to parody-based interpretation. Instead of saying passage B parodies passage A, we can say both passages realize one abstract gesture, neither having inherent priority. This is valuable when temporal priority in the composition does not imply structural priority.

# Examples
From Beethoven Symphony No. 1 analysis:
- Figure 7.9 shows an abstract harmonic gesture (the normative network)
- The Adagio introduction and the Minuet opening both realize this gesture
- Neither is the "norm" for the other; both are realizations of the abstract pattern

The analogy: Like encountering Mr. X in formal attire and then at a picnic - we infer an abstract "X-ness" manifested differently in each context, rather than one occasion being the norm.

# Common Confusions
- Abstract gestures are not audible; they are analytical constructs
- Recognizing an abstract gesture does not eliminate the value of other analytical approaches
- The choice between "parody" and "shared gesture" interpretations is critical, not factual
- Abstract gestures can be realized at different structural levels, not just the foreground
