# Quick Definition

The quotient set S/EQUIV is the family of all equivalence classes under a given equivalence relation -- it "collapses" equivalent elements into single representatives.

# Core Definition

"Given an equivalence relation EQUIV on a family S, the family of equivalence classes is called the quotient family of S modulo EQUIV. We shall denote it symbolically by S/EQUIV" (Lewin, Definition 1.9.5, p. 38). The natural map E takes each s to its equivalence class E(s). Every equivalence relation can be regarded as generated by the natural map: s and t are equivalent if and only if E(s) = E(t).

# Prerequisites

- **Equivalence Relation** — the quotient is defined modulo an equivalence relation
- **Equivalence Class** — the elements of the quotient set are equivalence classes

# Key Properties

1. Elements of S/EQUIV are equivalence classes, not elements of S
2. The natural map E: S -> S/EQUIV is onto by definition
3. |S/EQUIV| <= |S| (equality when each class has one element)
4. Every equivalence relation can be recovered from its natural map

# Construction / Recognition

## To Construct:
1. Define an equivalence relation EQUIV on S
2. Collect all equivalence classes
3. The family of all classes is S/EQUIV

## To Recognize:
1. Elements are collections (classes), not individual elements of S
2. The classes partition S completely

# Context & Application

The twelve pitch classes form the quotient of all pitches modulo octave equivalence. Set-types form the quotient of pitch-class sets modulo transposition/inversion. Quotient constructions allow working at higher levels of abstraction, treating equivalent objects as identical.

# Examples

**Example 1** (1.9.6.1, p. 37): S = all pitches, EQUIV = octave equivalence. S/EQUIV = the 12 pitch classes.

**Example 2** (1.9.6.2, p. 37): S = all beats in a waltz, EQUIV = same position in measure. S/EQUIV = the 3 beat classes {1, 2, 3}.

**Example 3** (1.10.4.1, p. 39): S = integers, EQUIV = congruence mod 12. S/EQUIV = the 12 classes C(0), C(1), ..., C(11).

# Common Errors

- **Error**: Treating elements of S/EQUIV as elements of S.
  **Correction**: Elements of S/EQUIV are classes (collections of elements of S), not individual elements.

# Common Confusions

- **Confusion**: Thinking the quotient "removes" elements.
  **Clarification**: The quotient groups elements together into classes; no elements are removed, but many are identified as "the same."
