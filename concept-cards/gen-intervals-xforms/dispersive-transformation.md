# Quick Definition
A dispersive transformation is one for which INJ(X, Y)(f) is minimal or relatively small - it maps X largely outside Y.

# Formal Definition
Definition (6.4): A transformation f is dispersive (for the progression X to Y) if INJ(X, Y)(f) is minimal or relatively small.

Dispersive transformations are the opposite of progressive transformations: they map X away from Y rather than toward Y.

# Mathematical Formulation
f is dispersive for X -> Y if:
INJ(X, Y)(f) is near or at min{INJ(X, Y)(g) : g in INSPECT}

Algebraic tendencies:
- Progressive followed by Y-external tends to be dispersive
- X-internal followed by dispersive tends to be dispersive

When INJ(X, Y)(f) = 0, f is maximally dispersive: no element of X maps into Y.

# Musical Context/Application
Dispersive transformations model "avoidance" - when a transformation of X specifically does not produce elements of Y. This can create tension, as the transformed X is maximally different from Y. In Schoenberg's op.19 no.6, dispersive transpositions of the rh chord appear in measure 8, creating a climactic passage before the final reprise.

# Examples
From Schoenberg's op.19 no.6 (Figure 6.10):

rh chord, lh chord
- Six values of i make T_i dispersive: i = 0, 2, 4, 5, 7, 9
- For these i: INJ(rh, lh)(T_i) = 0
- T_i(rh) has no common tones with lh

Measure 8 embeds four of these dispersive forms:
- T_2(rh), T_5(rh), T_7(rh), T_9(rh)

This creates maximum "distance" from lh, setting up the return of rh = T_0(rh) at measure 9 (which is also dispersive but now signals reprise).

The accumulation of dispersive forms in measure 8 creates the cryptic, dense texture before resolution.

# Common Confusions
Dispersive describes relationship to Y, not to X. A dispersive transformation might still be X-internal (mapping X to itself) while being dispersive (the transformed X avoids Y). The concepts operate on different set pairs.
