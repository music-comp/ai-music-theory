# Quick Definition
Three principal ideas about tonicity expressed through network formalism: tonic-as-generator (input function), tonic-as-goal (output function), and tonic-as-center (balance in graph structure).

# Formal Definition
In a Klang network, a tonic Klang may manifest tonicity through:
1. Input function: The tonic node has arrows only going out (generator)
2. Output function: The tonic node has arrows only coming in (goal)
3. Central position: The graph structure balances visually/formally around the tonic

These three ideas correspond to historical conceptions of what makes a tonic "tonic."

# Mathematical Formulation
In the CADENCE network (Figure 9.10):
- (C, +) fills both left node (input) and right node (output)
- As input: (C, +) generates the progression
- As output: (C, +) is the goal of the progression
- As center: The figure balances around the (C, +) nodes

The formal input/output functions correspond to but do not fully capture tonicity:
- (G, +) is also an input node but not a tonic
- (F, +) is also an output node but not a tonic

# Musical Context/Application
The formalism provides precise vocabulary for discussing tonicity:
- Tonic-as-generator: "The tonic asserts itself in the act of sounding, setting musical process in action"
- Tonic-as-goal: "The tonic appears at the end as a point of repose toward which events have been moving"
- Tonic-as-center: "A center of balance in a well-balanced structure"

# Examples
From Figure 9.10 (CADENCE in C major):
- (C, +) on left: input function (tonic generates dominant and subdominant)
- (C, +) on right: output function (tonic receives cadential motion)
- Visual balance: The figure is symmetric around the (C, +) positions

Not all input/output nodes are tonics:
- (G, +) is input but functions as dominant
- (F, +) is output but functions as subdominant
- Tonicity involves more than graph-theoretic position

# Common Confusions
- Input/output formalities are suggestive but not sufficient for defining tonicity
- A Klang can have input function without being a tonic
- The three ideas (generator, goal, center) are distinct aspects of tonicity
- Network formalism captures but does not fully explain tonal function
