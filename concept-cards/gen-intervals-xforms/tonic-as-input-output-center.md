# Quick Definition
Three principal historical ideas about tonicity mapped onto network formalism: tonic-as-generator (input function), tonic-as-goal (output function), and tonic-as-center (structural balance), as demonstrated through the CADENCE network.

# Core Definition
The input and output functions for a tonic Klang in a network reflect two of the three principal ideas about tonicity that have governed tonal theories since the eighteenth century. The input function reflects tonic-as-generator: "a tonic that asserts itself in the very act of sounding a tone, setting a musical process in action." The output function reflects tonic-as-goal: "a tonic that appears at the end of a completed gesture as a point of repose towards which events have been moving." The third idea asserts tonic as "a center of balance in a well-balanced structure," manifest in the visual symmetry of the network (Lewin, Section 9.6.3, pp. 238-239).

# Prerequisites
- **Input node** — the generative function corresponds to input
- **Output node** — the goal function corresponds to output

# Key Properties
1. Input/output formalities are suggestive for tonicity but not sufficient
2. Not all input nodes are tonic (e.g., (G,+) may be input without being tonic)
3. Not all output nodes are tonic (e.g., (F,+) may be output without being tonic)
4. The same Klang can function as input at one position and output at another
5. The three ideas of tonicity are distinct aspects, not synonymous

# Construction / Recognition
## To Construct:
1. Build a Klang network for a tonal passage
2. Identify input, output, and central nodes
3. Relate these to tonic-as-generator, tonic-as-goal, tonic-as-center
## To Recognize:
1. Note which nodes are inputs and outputs
2. Assess whether tonic Klangs occupy these positions

# Context & Application
This concept connects transformational network theory with historical tonal theory. The CADENCE network (Figure 9.10) exemplifies all three ideas: (C,+) as input (generator), (C,+) as output (goal), and the visual balance around the (C,+) nodes (center). However, Lewin cautions that input/output formalities alone cannot fully define tonicity.

# Examples
**Example 1** (Figure 9.10, p. 238): CADENCE network in C major. The (C,+) Klang fills both the left (input) node and the right (output) node. The figure visually balances around these nodes. But (G,+) is also an input node and (F,+) an output node, yet neither is tonic.

# Common Errors
- **Error**: Asserting any input node as tonic
  **Correction**: Input function is necessary but not sufficient for tonicity

# Common Confusions
- **Confusion**: Thinking network formalism fully captures tonality
  **Clarification**: Lewin states explicitly that "we cannot completely translate our input/output formalities into ideas about tonicity"
