# Quick Definition
Stufen theory assigns structural priority to contextual scale degrees, enabling discriminations between intervals that are harmonically identical but modally different, such as distinguishing "major" from "minor" modal character of sixths.

# Core Definition
Stufen theory holds that scale degrees carry functional meaning within a tonal context. The identity of an interval depends not only on its acoustic size but on the scale degrees involved. Schenker uses Stufen theory to discriminate between intervals that Zarlino cannot distinguish: E4-C5 in C-major has a "major" modal character despite being a minor sixth, while A3-F4 in D-Dorian has a "minor" modal character matching its small size. Zarlino lacked Stufen theory and "would have been uncomfortable making the meaning of his harmonic intervals so dependent on the contextual assignment of a modal tonic" (Lewin, Appendix A, pp. 248-249).

# Key Properties
1. Scale degrees have contextual functional meaning
2. The same pitch has different Stufen identity in different keys
3. Intervals gain modal character from their Stufen context
4. Enables discriminations that purely harmonic theories cannot make
5. Zarlino lacked this tool; Schenker wielded it powerfully

# Examples
**Example 1** (p. 248): Modal sixths:
- G3-E4 in C-Ionian: "major" modal character + large size
- A3-F4 in D-Dorian: "minor" modal character + small size
- E4-C5 in C-major: "major" modal character despite small size
- F4-D5 in D-Dorian: "minor" modal character despite large size

**Example 2** (p. 248): Zarlino's limitation: "Zarlino had no Stufen theory that could enable him to make such discriminations."
