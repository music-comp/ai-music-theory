# Quick Definition
The same musical set can be legitimately articulated in different ways depending on the analytical context -- which other sets it is heard in relation to and which intervals are being attended to -- with different IFUNC relationships highlighting different structural features, none of which is the "real" structure.

# Core Definition
"If Y 'really is' an ornamented version of T_3(X), then are we not 'wrong' to consider Y as a spatio/temporal gesture framed by T_8(X)?" Lewin responds: "The disquietude arises intellectually, from considering Y as something which 'really is,' independent of any specified environment." Each articulation "does not try to assert a 'real' form for Y" but rather "says that Y will tend to articulate in that way when heard in a complicated environment involving" the specific sets and intervals at hand (Lewin, Ch. 5, pp. 95-97).

# Prerequisites
- **IFUNC** — The interval function that reveals different structural relationships at different interval values
- **Transposition** — T_i relationships between sets provide the analytic contexts

# Key Properties
1. A set Y has different structures in different environments
2. IFUNC(X, Y)(i) at different values of i reveals different articulations
3. No single articulation is the "real" one; all are valid in their contexts
4. A good performer can realize multiple hearings
5. Different articulations may engage different instrumental perspectives

# Construction / Recognition
## To Construct:
1. Compute IFUNC(X, Y) for relevant sets X and Y
2. Identify maximal IFUNC values at different intervals
3. For each maximal value, trace which elements of Y participate in the T_i relationship
4. Each such tracing yields a different articulation of Y
## To Recognize:
1. Multiple valid ways to hear a set's internal structure
2. Different IFUNC maxima suggesting different transpositional relationships

# Context & Application
This methodological point addresses a common analytical pitfall: seeking a single "correct" hearing. Lewin argues that different environments -- the lyric melody's phrasing, the violin ostinato's commentary, registral boundaries -- each bring out different structural features. "What one can hear, one can play" -- these are practical as well as theoretical distinctions.

# Examples
**Example 1** (Figures 5.2-5.5, Webern op. 7 no. 3):
- Context 1 (Figure 5.2c): Y heard as ornamented T_3(X). IFUNC(X, Y)(3) = 3 (maximum). Articulation: B-C#-F# as structural backbone. Environment: "remembering X and hearing the many intervals of 3."
- Context 2 (Figure 5.4): Y heard as bounded by T_8(X). IFUNC(X, Y)(8) = 3 (also maximum). Articulation: B-E-F# as registral/temporal boundary frame.
- Context 3 (Figure 5.5e): Y heard as expanding Z_3. IFUNC(Z_3, Y) maximal at i = 0, 5, 6, 11. Articulation: boundary trichords in class 3-5, with chromatic interior set.

"The various IFUNC values ... are useful tools ... for exploring the multifaceted aspects of Y in various of its environments."

# Common Errors
- **Error**: Seeking Y's "real" structure independent of context
  **Correction**: Y has different structures in different environments; the question "what Y really is" presupposes a context-free identity that music does not have

# Common Confusions
- **Confusion**: Thinking multiple valid articulations constitute analytical contradiction
  **Clarification**: Different IFUNC values at different intervals reveal different structures, all of which can be heard and performed. "This is richness, not contradiction" -- Lewin explicitly rejects the worry that "the pianist must decide which way to play it," noting this "seriously under-estimates ... the resources available to a good pianist."
