# Quick Definition
The same musical set can be legitimately articulated in different ways depending on the analytical context, with different IFUNC relationships highlighting different structural features.

# Formal Definition
A set Y in a musical passage may be articulated (divided, structured, heard) differently depending on:
- Which other sets it is heard in relation to
- Which intervals are being attended to
- Which transformational relationships are relevant

These different articulations are not contradictory but reflect different valid "hearings" of the music in different contexts.

# Mathematical Formulation
For set Y related to sets X, Z0, Z3:
- IFUNC(X, Y)(3) = 3 suggests Y articulates around T_3(X)
- IFUNC(X, Y)(8) = 3 suggests Y articulates around T_8(X)
- IFUNC(Z3, Y) at maxima i = 0, 5, 6, 11 suggests different articulation

Each IFUNC relationship reveals structure relevant to its particular context.
None is the "real" structure; all are valid in their contexts.

# Musical Context/Application
This methodological point addresses potential reader confusion: If Y "really is" an ornamented T_3(X), are we "wrong" to consider it as framed by T_8(X)? Lewin argues this question presupposes Y has a context-free "real" structure.

Instead: Y has different structures in different environments:
- Y-following-X with sensitivity to interval 3
- Y-following-X with sensitivity to interval 8
- Y-as-commentary-on-Z3 with sensitivity to intervals 0, 5, 6, 11

A good performer can realize multiple hearings.

# Examples
From Webern op.7 analysis (Figures 5.2-5.5):

Y = 7-note melodic phrase

Context 1 (Figure 5.2c): Y heard as ornamented T_3(X)
- Articulation: B-C#-F# as structural backbone = T_3(ordered X)
- Environment: Y following X, attending to interval 3
- Relevant to: pianist shaping melody phrase-to-phrase

Context 2 (Figure 5.4): Y heard as bounded by T_8(X)
- Articulation: B-E-F# as spatio/temporal boundary frame
- Environment: Y following X, attending to interval 8
- Relevant to: registral hearing of phrase shape

Context 3 (Figure 5.5e): Y heard as expanding Z3
- Articulation: boundary trichords in class 3-5, interior chromatic set
- Environment: Y in relation to violin ostinato Z3
- Relevant to: violinist making ostinato comment on melody

All three are valid; none supersedes the others.

# Common Confusions
The temptation to find Y's "real" structure assumes context-independence that music does not have. Different IFUNC values at different intervals reveal different structures, all of which can be heard and performed. This is richness, not contradiction.
