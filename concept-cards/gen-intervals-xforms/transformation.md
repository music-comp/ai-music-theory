# Quick Definition
A transformation on a set S is a function from S into itself, mapping elements of S to other elements of S.

# Formal Definition
A function from a family S into S itself will be called a transformation on S. A transformation maps elements of a single set to elements of the same set.

# Mathematical Formulation
- f: S -> S is a transformation on S
- For every s in S, f(s) is also in S
- Transformations can be composed: if f, g are transformations on S, then fg is also a transformation on S
- The identity transformation 1 satisfies 1(s) = s for all s in S

# Musical Context/Application
Transformations are the core objects of study in transformation theory. Musical transformations include transposition, inversion, retrograde, and many others. The key insight is that these map musical objects (pitches, pitch classes, chords, time points) back to objects of the same type. This self-referential quality allows chains of transformations and group structures.

# Examples
Musical examples of transformations on pitch classes:
- Transposition Tn: maps each pitch class to the pitch class n semitones higher
- Inversion I: maps each pitch class to its chromatic inversion
- Identity 1: maps each pitch class to itself

Non-example: The function mapping pitches to their pitch classes is NOT a transformation because the domain (pitches) differs from the codomain (pitch classes).

# Common Confusions
- All operations are transformations, but not all transformations are operations
- A transformation need not be 1-to-1 or onto (those are additional properties)
- "Transformation" emphasizes the self-mapping aspect (S to S)
- The term "transformation" in Lewin's technical sense differs from informal usage
