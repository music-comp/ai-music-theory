# Quick Definition
A node in a node/arrow system to which no proper arrows point - arrows only go out from it (plus the reflexive arrow to itself), giving it a generative or initiating function in the network.

# Formal Definition
An input node IN in a node/arrow system satisfies:
- If (N, IN) is in the ARROW relation, then N = IN
- No proper arrows point TO the input node
- Only the reflexive arrow (IN, IN) points to IN

# Mathematical Formulation
Formal criterion:
- For all N in NODES: (N, IN) in ARROW implies N = IN
- Equivalently: The only N with (N, IN) in ARROW is N = IN

Input nodes have:
- Zero in-degree (except reflexive)
- Possibly positive out-degree

# Musical Context/Application
Input nodes model points where transformational processes begin - the "starting point" of an analytical network. They correspond to musical objects that generate others but are not themselves generated within the network's scope. Input nodes often represent:
- Referential sonorities
- Opening gestures
- Structural origins

# Common Confusions
- Input nodes are formal properties of the graph, not claims about musical chronology
- A network may have multiple input nodes
- A network may have no input nodes (all nodes receive arrows)
- "Input" describes graph structure, not how we listen to the music
