# Quick Definition
A Klang transformation where the input Klang becomes the mediant of its output, changing mode in the process; (C, +)MED = (A, -) and (C, -)MED = (Ab, +).

# Formal Definition
MED transforms a Klang so that it becomes the mediant of the result:
- (p, +)MED = (p - 3, -): Major Klang becomes mediant of relative minor
- (p, -)MED = (p - 4, +): Minor Klang becomes mediant of relative major

The transformation changes mode and adjusts the pitch class accordingly.

# Mathematical Formulation
MED operation:
- For major: (p, +)MED = (p + 9, -) mod 12
- For minor: (p, -)MED = (p + 8, +) mod 12

Key property: DOM = MED^2 (MED applied twice equals DOM)
- ((C, +)MED)MED = (A, -)MED = (F, +) = (C, +)DOM

This means DOM is generated by MED, so the group generated by DOM and MED equals the group of powers of MED.

# Musical Context/Application
MED captures the mediant/submediant functional relationship that changes mode. The fact that DOM = MED^2 shows how dominant function can be understood as iterated mediant function. When the group generated by MED is simply transitive on a Klang family, networks using only MED powers can be considered "formally intervallic."

# Examples
Applications:
- (C, +)MED = (A, -): C major becomes mediant of A minor
- (C, -)MED = (Ab, +): C minor becomes mediant of Ab major

Chain showing DOM = MED^2:
- (C, +)MED = (A, -)
- (A, -)MED = (F, +)
- Therefore (C, +)MED^2 = (F, +) = (C, +)DOM

# Common Confusions
- MED changes mode; DOM does not
- "Becomes the mediant of" means the result contains the input as its mediant
- MED generates DOM but DOM does not generate MED
- The group of MED powers is infinite in just intonation but cyclic in equal temperament
