# Quick Definition
Rameau's concept of a chord having two simultaneous functional interpretations - in Lewin's analysis of the Beethoven Appassionata, a sonority understood both as Gb-major with added sixth and as eb-minor with minor seventh.

# Formal Definition
Double emploi occurs when a single sonority is modeled by two different Klangs in a network:
- The sonority is connected by a transformation arrow to both interpretations
- Both interpretations are analytically valid
- The transformation between them (often REL) captures the dual function

# Mathematical Formulation
In the Appassionata network (Figure 9.14):
- Sonority 4 is both (Gb, +) and (eb, -)
- (Gb, +)REL = (eb, -) [REL transforms major to relative minor]
- The arrow goes only one way (from Gb to eb)
- This asymmetry reflects functional priority

# Musical Context/Application
Double emploi represents moments where harmonic function is ambiguous or dual. The concept originates with Rameau's recognition that certain chords serve multiple syntactic roles simultaneously. In transformational terms, double emploi manifests as multiple Klang nodes for a single sounding event.

# Examples
From Beethoven Appassionata, slow movement (Figure 9.14):
- Fourth sonority: Gb-Bb-Db-Eb
- As Gb major + 6: (Gb, +)
- As eb minor 7 (inverted): (eb, -)
- REL transformation connects the two interpretations
- Arrow direction suggests Gb -> eb (Gb understood first, then reinterpreted)

Lewin's comment: "This is Rameau's double emploi."

# Common Confusions
- Double emploi is not about enharmonic spelling but functional interpretation
- Both interpretations are simultaneous, not sequential
- The transformation arrow represents analytical connection, not temporal change
- The concept extends beyond Rameau's original harmonic context
