# Quick Definition
Triple proportion is a classical four-term relationship where A:B :: C:D, creating balanced proportional structure among input and output elements of a transformation network.

# Formal Definition
A triple proportion exists when four terms A, B, C, D satisfy the relationship A:B :: C:D (A is to B as C is to D). In transformation networks, this manifests when the same transformation that takes input A to output B also takes input C to output D, creating a balanced, symmetric structure that can be represented as isographic subnetworks.

# Mathematical Formulation
For transformation f and elements A, B, C, D:
- Triple proportion: A:B :: C:D iff f(A) = B and f(C) = D

In network terms:
- Left subnetwork: A -> B via f
- Right subnetwork: C -> D via f
- The left and right subnetworks are isographic

The triple proportion also implies:
- The relation of A to C equals the relation of B to D

# Musical Context/Application
Triple proportion creates structural balance and symmetry in musical networks. When present, it often correlates with audible formal balance, such as antecedent-consequent relationships or harmonic parallelism. The proportional structure can evoke tonal functions even in non-functional contexts.

# Common Confusions
Triple proportion is a structural relationship among four terms, not three (despite the name). The "triple" refers to the classical terminology for a four-term proportional relationship (A:B :: C:D), where the middle terms can be seen as mediating a "triple" relationship. Students should not confuse this with simple 1:2:3 ratios.
