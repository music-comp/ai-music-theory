# Quick Definition
A "classical triple proportion" in which three terms stand in the relation A:B::B':A', exhibited by the input/output chords of the RI-chain network in Bartok's "Syncopation," involving isography between left and right sides.

# Core Definition
Among the input and output chords of Figure 10.6, the relation is: C#-D#-F# (input) is to F#-G#-B (output) as G#-A#-C# (input) is to C#-D#-F# (output). This classical triple proportion involves isography of the left side with the right side of the network. The TCH interval of 5 spanning the trichords makes the proportion "sound almost like I-IV-V-I" (Lewin, Section 10.2, p. 262).

# Prerequisites
- **Isography** — the proportion involves isographic network halves
- **RICH transformation** — the diagonal arrows connecting trichords

# Key Properties
1. A:B :: B':A' proportional structure
2. Involves isography between network halves
3. TCH interval = 5 creates quasi-functional sound
4. The cadential proportioning balances trichord forms

# Context & Application
The triple proportion demonstrates how RI-chaining can produce quasi-functional harmonic relations in non-functional contexts. Travis's hearing of "functional I-IV-V-I" in the piece may derive from this proportioning.

# Examples
**Example 1** (Figure 10.6, p. 262): C#-D#-F# : F#-G#-B :: G#-A#-C# : C#-D#-F#. TCH interval = 5.

# Common Errors
- **Error**: Hearing the proportion as literally functional
  **Correction**: Lewin says "almost like I-IV-V-I" -- the resemblance is suggestive, not literal

# Common Confusions
- **Confusion**: Thinking triple proportion requires functional harmony
  **Clarification**: It is a formal proportional relationship, not a functional one
