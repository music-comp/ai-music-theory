# Quick Definition
The requirement that TRANSIT(N, N) must be an idempotent element of the semigroup SGP - an element e satisfying ee = e - ensuring consistency for the reflexive arrow from any node to itself.

# Formal Definition
In a transformation graph (NODES, ARROW, SGP, TRANSIT):
- Every node N has (N, N) in ARROW (reflexive arrow)
- TRANSIT(N, N) must be idempotent in SGP
- An element e is idempotent if ee = e

This follows from Criterion 9.2.1(D) applied to arrow chains from N to N.

# Mathematical Formulation
Proof that TRANSIT(N, N) is idempotent (Section 9.2.2):
- Consider two arrow chains from N to N:
  - Chain 1: N_0 = N_1 = N (length 1)
  - Chain 2: M_0 = M_1 = M_2 = N (length 2)
- Let x_1 = TRANSIT(N_0, N_1) = TRANSIT(N, N)
- Let y_1 = y_2 = TRANSIT(N, N)
- By Criterion (D): x_1 = y_2 * y_1
- So TRANSIT(N, N) = TRANSIT(N, N) * TRANSIT(N, N)
- Therefore TRANSIT(N, N) is idempotent

# Musical Context/Application
In most musical applications, SGP is a group, and the only idempotent in a group is the identity element. Therefore:
- In operation graphs, TRANSIT(N, N) = identity for all nodes
- This means "staying at the same node" corresponds to the identity transformation
- In semigroup contexts (rare in music), other idempotents may be possible

# Examples
In a Klang transformation operation graph:
- SGP = group generated by DOM, MED, PAR, etc.
- Identity = IDENT (leave Klang unchanged)
- TRANSIT((C,+), (C,+)) = IDENT

In a semigroup context (theoretical):
- SGP might have multiple idempotents
- Each node could have a different idempotent as its reflexive TRANSIT value
- This would be unusual in musical applications

# Common Confusions
- Idempotent is required even in semigroups, not just groups
- In groups, the only idempotent is the identity
- The reflexive arrow (N, N) always exists even if not drawn
- TRANSIT(N, N) is determined by the consistency criterion, not chosen freely
