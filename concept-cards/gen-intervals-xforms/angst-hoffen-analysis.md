# Quick Definition
Lewin's analysis of Schoenberg's "Angst und Hoffen" (op. 15 no. 7) demonstrates INJ's power to engage wedge transformations, inversional symmetry, progressive/internal distinctions, if-only adjustments, transitivity sets, and system modulation in a single coherent analysis.

# Core Definition
The analysis (Figures 6.2-6.5) examines: X = {Gb, Bb, D} (Angst chord), Y = {Fb, Bb, Eb} (Hoffen chord), w^E = wedge-to-E, I = I_E^{Bb} (inversion). Key findings: INJ(X, Y)(w^E) = 2 (progressive), INJ(X, X)(I) = 3 (fully internal), INJ(Y, Y)(I) = 2 (imperfectly internal). The Fb of Y is simultaneously a wedge focal point, a "wrong note" (substitute for F), and a missing I-partner, connecting text ("Angst und Hoffen") to structure. The melodic analysis uses ordinal-pitch-class pairs to model serial structure.

# Prerequisites
- **INJ Function** — Primary analytical tool
- **Wedge Transformation** — w^E is the progressive transformation
- **Progressive/Internal Transformation** — Classification of w^E and I
- **If-Only Adjustment** — The Fb/F analysis

# Key Properties
1. w^E is progressive: pushes Angst toward Hoffen
2. I is internal: each chord maps to (approximately) itself
3. Fb has multiple structural functions simultaneously
4. Chord progression Z_1 -> Z_2 -> ... -> X -> Y maintains consistent wedging
5. System modulation from E-center to F#-center via T_2
6. Melodic analysis uses space of (ordinal, pitch-class) pairs — not a GIS

# Construction / Recognition
## Analytical Method:
1. Identify the key transformations (w^E, I) and compute INJ values
2. Classify transformations as progressive, internal, external, or dispersive
3. Identify if-only situations and analyze the "problematic" notes
4. Track how transformational patterns develop through the piece
5. Relate transformational structure to text and expression

## To Recognize:
1. An analysis using INJ to classify transformations and track their structural roles

# Context & Application
This analysis is Lewin's primary demonstration of INJ's analytical power. It shows that INJ can engage wedge transformations (not operations), inversional symmetry, text-music relationships, and system modulation — none of which IFUNC could handle. The analysis extends from harmonic structure to melodic serial structure, demonstrating INJ's versatility.

# Examples
**Example 1** (pp. 156-158, Figures 6.2-6.3b): Harmonic: w^E maps D->Eb (in Y), Bb->Bb (in Y), Gb->G (not in Y). If Fb were F, the wedge would be perfect. The song resolves when F appears on "begehre."

**Example 2** (pp. 161-163, Figure 6.4): Melodic: ordinal-pitch pairs model the vocal melody. Internal transformations (1,I) and (2,w) bind tetrad X_1^4; progressive T_6 connects X_1^4 to X_5^8; ordinal augmentation of I and w spans.

**Example 3** (pp. 158-160, Figure 6.3c): System modulation by T_2 from E-centered to F#-centered wedge/inversion structure.

# Common Errors
- **Error**: Treating the Fb as simply a "wrong note"
  **Correction**: Fb has multiple structural functions (wedge focal point, tonic, missing partner) that are all part of the analysis

# Common Confusions
- **Confusion**: Thinking INJ analysis replaces hearing
  **Clarification**: INJ reveals relationships "our ears might not otherwise pick up quickly" but the relationships are meant to be heard and performed
