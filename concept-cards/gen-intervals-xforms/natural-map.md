# Quick Definition
The natural map E sends each element s of a set S to its equivalence class E(s) in the quotient set S/EQUIV - it "projects" elements onto their equivalence classes.

# Formal Definition
The function E of 1.9.3 maps S onto S/EQUIV, mapping each argument s to the value E(s), the member of the quotient family that contains s. The function E is called the natural map of S onto S/EQUIV. Every equivalence relation can be regarded as generated by some natural map: s and t are equivalent if and only if E(s) = E(t).

# Mathematical Formulation
- E: S -> S/EQUIV defined by E(s) = equivalence class containing s
- E is onto S/EQUIV (every class is the image of some element)
- s ~ t if and only if E(s) = E(t)
- For congruences on semigroups, the natural map C: X -> X/CONG is a homomorphism

# Musical Context/Application
The natural map from pitches to pitch classes sends each pitch to its pitch class (C4 -> C, D5 -> D, etc.). This projection is fundamental to twelve-tone analysis where octave position is disregarded. Similarly, the natural map from pitch-class sets to set-types sends each set to its Forte number.

# Examples
Pitch to pitch-class: E(C4) = E(C5) = E(C3) = pitch class C

Beat to beat-class: In a waltz, E(measure 5 beat 1) = E(measure 12 beat 1) = beat-class 1

From Section 1.9.7: Given f: S -> S', define EQUIV by s ~ t iff f(s) = f(t). Then there is a 1-to-1 correspondence between S' and S/EQUIV via the function ARGS(s') = {s : f(s) = s'}.

For congruences: C(x1)C(x2) = C(x1x2) - the natural map preserves the semigroup operation.

# Common Confusions
- The natural map is always onto (surjective)
- The natural map is generally NOT 1-to-1 (unless each class has one element)
- For congruences, the natural map is a homomorphism
- E(s) denotes both the function E applied to s AND the equivalence class containing s
