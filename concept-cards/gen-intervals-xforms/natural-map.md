# Quick Definition

The natural map E sends each element s of a set S to its equivalence class E(s) in the quotient set S/EQUIV, projecting elements onto their classes.

# Core Definition

"The function E of 1.9.3 maps S onto S/EQUIV, mapping each argument s to the value E(s), the member of the quotient family that contains s. The function E is called the natural map of S onto S/EQUIV" (Lewin, Section 1.9.5, p. 38). Every equivalence relation can be regarded as generated by some natural map: s and t are equivalent if and only if E(s) = E(t). For congruences on semigroups, the natural map C is a homomorphism: C(x1)C(x2) = C(x1x2) (Section 1.11).

# Prerequisites

- **Equivalence Relation** — the natural map is defined from an equivalence relation
- **Equivalence Class** — the natural map sends elements to their classes
- **Quotient Set** — the codomain of the natural map

# Key Properties

1. E: S -> S/EQUIV defined by E(s) = equivalence class containing s
2. E is always onto (every class is the image of some element)
3. E is generally NOT 1-to-1 (unless each class has one element)
4. s ~ t if and only if E(s) = E(t)
5. For congruences: C(x1)C(x2) = C(x1x2), i.e., C is a homomorphism

# Construction / Recognition

## To Construct:
1. Given an equivalence relation on S, define E(s) = the class containing s

## To Recognize:
1. Check that the function sends each element to its equivalence class
2. Verify it is onto the quotient set

# Context & Application

The natural map from pitches to pitch classes sends each pitch to its pitch class (C4 -> C, D5 -> D). This projection is fundamental to twelve-tone analysis. For congruences on groups, the natural map is always a homomorphism, establishing the foundational link between quotient constructions and structure-preserving maps.

# Examples

**Example 1** (p. 38): Pitch to pitch-class: E(C4) = E(C5) = E(C3) = pitch class C.

**Example 2** (p. 37): Beat to beat-class: E(measure 5 beat 1) = E(measure 12 beat 1) = beat-class 1.

**Example 3** (p. 39): For congruences on integers mod 12: C(x1)C(x2) = C(x1 + x2). The natural map C preserves the group operation.

**Example 4** (Section 1.9.7, p. 38): Given f: S -> S', the ARGS function maps each s' in S' to the equivalence class of arguments that map to s'. ARGS is a 1-to-1 onto map between S' and S/EQUIV.

# Common Errors

- **Error**: Assuming the natural map is 1-to-1.
  **Correction**: The natural map is onto but generally not 1-to-1 (multiple elements map to the same class).

# Common Confusions

- **Confusion**: Confusing E(s) the function application with E(s) the equivalence class.
  **Clarification**: Both notations mean the same thing: E(s) is the equivalence class containing s, which is also the value of the function E at argument s.
