# Quick Definition
When a transposition Tn and an inversion I_u^v are composed, the result is another inversion whose parameters are related to the original by transposition. The theorem provides explicit formulas for these combinations.

# Formal Definition
**Theorem 3.5.6:** For any transposition Tn and any inversion I_u^v:

(A): Tn I_u^v = I_x^v where x = Tn(u)
(B): I_u^v Tn = I_u^w where w = Tn^(-1)(v)
(C): Tn commutes with I_u^v iff n is central and nn = e (n is its own inverse)

# Mathematical Formulation
**Proof of (A):**
LABEL(Tn I_u^v(s)) = LABEL(I_u^v(s)) * n
                    = i * LABEL(s)^(-1) * j * n
                    = LABEL(I_x^v(s))

where x has LABEL jn, meaning x = Tn(u).

**Proof of (C):**
Tn I_u^v = I_u^v Tn requires I_x^v = I_u^w.
By Theorem 3.5.3, this needs w = I_x^v(u) and int(u, x) central.
One derives: int(v, w) = n^(-1) and int(u, x) = n.
So n = n^(-1) (i.e., nn = e) and n is central.

# Musical Context/Application
These formulas show how the familiar "TnI = ITn" relationship from pitch-class theory generalizes. In the 12-tone GIS:
- T6 commutes with every inversion (since 6 + 6 = 0 and 6 is central)
- No other non-trivial transposition commutes with any inversion

The formulas are essential for understanding the structure of the group generated by transpositions and inversions.

# Examples
**Pitch-class calculations:**
- T5 I_C^C = I_{T5(C)}^C = I_F^C = I_5^0 (using integer notation)
- I_C^C T5 = I_C^{T(-5)(C)} = I_C^G = I_0^7

**Commutation with T6:**
- T6 I_0 = I_0 T6 (in 12-tone pitch-class GIS)
- 6 + 6 = 0 mod 12, and 6 is central (trivially)
- This is the only non-trivial Tn that commutes with all inversions

**Non-commutative time-span GIS:**
- No transposition (except identity) commutes with any inversion
- Only (0, 1) satisfies nn = e and is central

# Common Confusions
1. **TnI vs. ITn:** These are generally different operations. They are equal only when n is central and self-inverse.

2. **The formula Tn I_u^v = I_x^v:** The v parameter stays fixed; u moves to x = Tn(u).

3. **The formula I_u^v Tn = I_u^w:** The u parameter stays fixed; v moves to w = Tn^(-1)(v). Note the inverse!

4. In commutative GIS, all intervals are central, so the only constraint for Tn to commute with inversions is nn = e. In 12-tone GIS, only T0 and T6 satisfy this.
