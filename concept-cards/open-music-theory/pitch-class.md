# Pitch Class

## Quick Definition

A category that groups together all pitches with the same letter name, regardless of octave, including their enharmonic equivalents.

## Formal Definition

A **pitch class** is a set of all pitches that share the same name (letter and accidental) across all octaves, along with their enharmonic equivalents. While a pitch is a specific frequency in a specific octave (e.g., C4 = middle C), a pitch class abstracts away the octave information.

In integer notation (used in post-tonal theory):
- Pitch classes are represented as integers 0-11
- C = 0, C♯/D♭ = 1, D = 2, D♯/E♭ = 3, E = 4, F = 5, F♯/G♭ = 6, G = 7, G♯/A♭ = 8, A = 9, A♯/B♭ = 10, B = 11

The pitch class C includes:
- All C naturals: C0, C1, C2, C3, C4, C5, C6, C7, C8, etc.
- All enharmonic equivalents: B♯ (any octave), D𝄫 (any octave)

Mathematically, pitch class is defined by the equivalence relation of octave equivalence and enharmonic equivalence.

## Musical Context

Pitch class is essential for analyzing music where octave placement is less important than pitch identity—particularly useful in:
- Post-tonal and twelve-tone music analysis
- Jazz chord-scale theory
- Understanding harmonic relationships independent of register

The concept acknowledges that a C in any octave has a similar function and relationship to other pitch classes, even if the specific register affects timbre and voice leading.

## Examples

### Basic

Pitch vs. Pitch Class:
- C4 = a specific pitch (middle C, ~261.63 Hz)
- Pitch class C = all Cs in all octaves, plus B♯ and D𝄫

Integer notation:
- C♯3, C♯4, C♯5, D♭2, D♭6 all belong to pitch class 1
- E2, E4, F♭5 all belong to pitch class 4

### From Repertoire

In Schoenberg's twelve-tone works, a tone row uses each of the twelve pitch classes exactly once, regardless of which octave each pitch appears in. A row might have C4, then C♯6, then D2—three different pitches but three different pitch classes.

## Common Confusions

- Pitch vs. pitch class: A pitch includes octave information; a pitch class does not
- All C♯s and D♭s (regardless of octave) belong to the same pitch class (pitch class 1)
- In tonal contexts, register often matters (C4 ≠ C5 functionally), but in pitch-class thinking, they're equivalent
- Pitch class 0 traditionally = C (not A), following integer notation convention
