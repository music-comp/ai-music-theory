# Quick Definition
A form featuring a recurring main section (refrain/A) alternating with contrasting sections (episodes/B, C), most commonly in five-part (ABACA) or sonata-rondo (ABACABA) layouts.

# Core Definition
**Rondo form** consists of a recurring main section (the **refrain** or A) alternating with **episodes** (B, C, etc.). The refrain is "essentially the same throughout" and always in the tonic key. Episodes contrast tonally and usually thematically. Two main types: **Five-part rondo** (ABACA) -- C is a stable thematic statement; **Sonata rondo** (ABACABA) -- the first ABA functions as a sonata exposition, C functions like a development, and the second ABA functions as a recapitulation with B now in the tonic (Ch. 9).

# Prerequisites
- **Phrase/cadence** -- Refrains typically end with PAC
- **Transition/retransition** -- Common auxiliary sections in rondo

# Key Properties
1. Recurring refrain (A) always in tonic key
2. Contrasting episodes (B, C) in different keys
3. Five-part rondo: ABACA
4. Sonata rondo: ABACABA
5. In sonata rondo, C may function like a development
6. In sonata rondo, B returns in tonic in the "recapitulation"
7. Retransitions common before refrain returns
8. Codas common; introductions rare
9. Episodes may end ambiguously, becoming retransitions through "becoming"

# Construction / Recognition
## To Analyze Rondo:
1. Find all A sections (same material, tonic key)
2. Identify episodes between refrains
3. Determine if ABACA (five-part) or ABACABA (sonata rondo)
4. Check if C is stable (five-part) or developmental (sonata rondo)
5. In sonata rondo, check if B returns in tonic

# Context & Application
Rondo is commonly used for final movements of sonatas, concertos, and symphonies. The source analyzes Maria Hester Park's Sonata Op. 7, III (five-part rondo) and Beethoven's Op. 13 "Pathétique," III (sonata rondo) in detail, noting the analytical challenge of "becoming" -- when formal boundaries are blurred.

# Examples

# Common Errors
- **Error**: Assuming every return of A is exact
  **Correction**: A sections may be shortened, embellished, or have altered suffixes

# Common Confusions
- **Confusion**: Five-part rondo and sonata rondo function the same way
  **Clarification**: In sonata rondo, B returns in the tonic (like a recapitulation); in five-part rondo, B appears only once
