# Neighbor Six-Four

## Quick Definition

A second-inversion triad (typically I⁶₄) where the bass note functions as a **neighbor tone** (upper or lower) that returns to its starting pitch—creating the pattern bass-neighbor-bass while upper voices may sustain or provide their own neighboring motion, occurring on a weak beat as an unaccented embellishment, also called "pedal six-four" when the bass remains static while upper voices move, used to prolong a harmony through neighboring motion rather than passing, notated with ⁶₄ figured bass but analyzed as non-functional embellishment, distinguished from passing six-four (where bass continues to different pitch) and cadential six-four (strong beat, functional), common for adding rhythmic and melodic interest while maintaining harmonic stasis.

## Formal Definition

**Neighbor six-four** (also **pedal six-four**) is a second-inversion triad with neighbor motion in the bass or upper voices.

**Two types**:

**1. Neighbor bass** (true neighbor ⁶₄):
```
Bass: C → D → C (neighbor motion, returns)
Upper voices: Sustained or neighbor motion
I - V⁶₄ - I pattern common
```

**2. Pedal bass** (static bass, pedal ⁶₄):
```
Bass: C → C → C (static, sustained)
Upper voices: Move in neighbor motion
I - I⁶₄ - I with sustained bass
```

**Function**: Prolongation through neighbor motion

**Weak beat**: Unaccented embellishment

## Neighbor vs. Pedal Six-Four

**Neighbor bass** (neighbor ⁶₄):
```
        I       V⁶₄      I
Bass:   C   →   D   →   C   (neighbor, returns)

Bass moves up (neighbor) and returns
V⁶₄ has D (^2) in bass
Prolongs tonic
```

**Pedal bass** (pedal ⁶₄):
```
        I       I⁶₄      I
Bass:   C   →   C   →   C   (static pedal)

Bass sustains C
Upper voices create ⁶₄ sonority
Returns to original position
```

**Both prolong tonic through neighboring motion**

## Voice Leading

**Neighbor bass** (I-V⁶₄-I):
```
        I       V⁶₄      I
S:      E   →   D   →   E   (neighbor or other motion)
A:      C   →   B   →   C   (neighbor)
T:      G   →   G   →   G   (sustained)
B:      C   →   D   →   C   (NEIGHBOR, returns)

Bass neighbors up to D, returns to C
Upper voices may neighbor or sustain
Weak beat ⁶₄
```

**Pedal bass** (I-I⁶₄-I):
```
        I       I⁶₄      I
S:      E   →   G   →   E   (upper neighbor)
A:      C   →   E   →   C   (upper neighbor)
T:      G   →   C   →   G   (may move)
B:      C   →   C   →   C   (PEDAL, sustained)

Bass sustains C (pedal)
Upper voices neighbor around chord tones
Creates ⁶₄ sonority temporarily
```

## Common Patterns

**I - V⁶₄ - I** (neighbor bass):
```
C major:
I:   C-E-G    V⁶₄:  D-G-B    I:  C-E-G
Bass: C   →   D   →   C   (neighbor)

Most common neighbor ⁶₄
D is upper neighbor to C
Returns to I
```

**I - I⁶₄ - I** (pedal bass):
```
C major:
I:   C-E-G    I⁶₄:  C-G-E    I:  C-E-G
Bass: C   →   C   →   C   (pedal)

Bass static
Upper voices neighbor
Pedal ⁶₄ variant
```

**IV - I⁶₄ - IV** (less common):
```
Bass: F → F → F (pedal)
Or: F → G → F (neighbor)

Can occur on other chords
Same neighboring principle
```

## Metric Placement

**Weak beat** (crucial):
```
Beat:    1    2    3    4
         I   V⁶₄   I
        str  weak  str

⁶₄ on weak beat 2
Neighbor function
Unaccented
```

**Compare to cadential**:
```
Beat:    1    2    3    4
        I⁶₄   V    I
        str  weak  str

Cadential on STRONG beat
Different function entirely
```

## Neighbor vs. Other Six-Four Types

**vs. Passing six-four**:
- **Passing**: Bass continues to different pitch
- **Neighbor**: Bass returns to starting pitch

**vs. Cadential six-four**:
- **Cadential**: Strong beat, resolves to V, functional
- **Neighbor**: Weak beat, returns, embellishing

**vs. Arpeggiating six-four**:
- **Arpeggiating**: Bass arpeggiates chord members
- **Neighbor**: Bass neighbors around single pitch

**Neighbor = returns to origin**

## Musical Context

Neighbor six-four serves specific purposes:
- **Harmonic prolongation**: Extends single harmony
- **Neighbor motion**: Bass or upper voices neighbor
- **Weak beat**: Unaccented embellishment
- **Pedal effect**: Bass can sustain (pedal ⁶₄)
- **Rhythmic interest**: Adds motion without progression
- **Non-functional**: Doesn't create harmonic change
- **Classical device**: Common in tonic prolongations

Effective for adding motion while maintaining harmonic stasis.

## Examples

### Basic

**I-V⁶₄-I** (C major):
```
        I       V⁶₄      I
Chord:  C-E-G   D-G-B    C-E-G
Bass:   C   →   D   →   C   (neighbor)

D is upper neighbor to C
Weak beat placement
Prolongs tonic
```

**Voice leading**:
```
        I       V⁶₄      I
S:      E   →   D   →   E   (neighbor)
A:      C   →   B   →   C   (neighbor)
T:      G   →   G   →   G   (sustained)
B:      C   →   D   →   C   (NEIGHBOR)

Multiple voices neighbor
Bass returns to C
Clear neighboring motion
```

**I-I⁶₄-I pedal bass**:
```
        I       I⁶₄      I
Bass:   C   →   C   →   C   (PEDAL, sustained)

S/A/T:  Neighbor motion in upper voices

Pedal variant
Bass static
Upper voices create ⁶₄
```

**In phrase context**:
```
mm. 1-2: I - V⁶₄ - I  (neighbor ⁶₄ prolongs tonic)
mm. 3-4: IV - V - I    (functional progression)

Opening uses neighbor ⁶₄
Then moves to cadence
```

**Lower neighbor**:
```
        I       IV⁶₄     I
Bass:   C   →   B   →   C   (lower neighbor)

Less common
B is lower neighbor to C
Returns to I
```

### From Repertoire

**Mozart, Piano Sonatas**: I-V⁶₄-I neighbor patterns prolong tonic, weak beat placement standard.

**Haydn, String Quartets**: Neighbor ⁶₄ for harmonic stasis with melodic interest, demonstrates Classical prolongation.

**Beethoven, Piano Sonatas**: Pedal ⁶₄ with sustained bass, upper voices neighbor around tonic.

**Classical period generally**: Neighbor/pedal ⁶₄ standard for prolongation, distinguished from passing and cadential types.

**Bach, Organ works**: Pedal ⁶₄ particularly effective (literal pedal tone), upper voices move above sustained bass.

## Common Confusions

- Neighbor six-four = I⁶₄ (or V⁶₄) with **neighbor motion in bass**
- Bass moves away and **returns to same pitch** (neighbor pattern)
- Also called "pedal six-four" when bass is static (pedal)
- Occurs on **weak beat** (unaccented)
- Function: **Prolongation** (extends harmony through neighboring)
- Most common: I-V⁶₄-I (D neighbors C in bass)
- Pedal variant: I-I⁶₄-I (bass sustains C, upper voices neighbor)
- Different from **passing ⁶₄** (bass continues to different pitch)
- Different from **cadential ⁶₄** (strong beat, functional, before V)
- Different from **arpeggiating ⁶₄** (bass arpeggiates same chord)
- Bass returns to origin (defining characteristic)
- Upper voices may sustain or neighbor
- ⁶₄ figured bass (6th and 4th above bass)
- Non-functional (doesn't create new harmony)
- Weak beat crucial (distinguishes from cadential)
- "Neighbor" refers to bass function (neighbor tone)
- Can be upper or lower neighbor (upper more common)
- Pedal bass variant common in organ music
- Creates motion without harmonic change
