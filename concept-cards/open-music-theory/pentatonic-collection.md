# Quick Definition
A five-note collection built with the interval pattern M2-M2-m3-M2-m3 (e.g., C-D-E-G-A), prevalent in music across the globe. It can be generated as the black keys of the piano, as a stack of five perfect fifths, or as a major scale minus scale-degrees 4 and 7.

# Core Definition
The pentatonic collection removes the two semitone-producing scale degrees (4 and 7 in major) from the diatonic collection. The absence of semitones makes it rotationally ambiguous -- any member can function as a tonal center. There are five rotations (modes), with the minor pentatonic (starting on the 6th degree) being especially common. The pentatonic is common as a melodic basis; it need not be harmonized within the collection. Chen Yi's percussion concerto features pentatonic melodies accompanied by atonal chords.

# Prerequisites
None specific (basic pitch knowledge)

# Key Properties
1. Five notes, interval pattern: 2-2-3-2-3 (in semitones)
2. No semitones -- all steps are M2 or m3
3. Three generation methods: scale degrees 1-2-3-5-6; stack of fifths; complement of diatonic
4. Rotationally ambiguous -- any pitch can be tonal center
5. Five unique modes
6. Only two triads available (one major, one minor)

# Context & Application
Prevalent globally. In 20th-century classical music, used for melodic composition with potentially contrasting harmonic accompaniment.

# Examples
**Example 1**: C pentatonic: C-D-E-G-A (black key complement: Gb-Ab-Bb-Db-Eb).
**Example 2** (Chen Yi, percussion concerto): Pentatonic melody at string entrance accompanied by atonal brass chords.
