# Quick Definition
A partially-ordered row is a twelve-tone structure where the content of segments (e.g., trichords, tetrachords) is fixed but the internal ordering within segments is flexible. This deviates from strict serialism while maintaining aggregate completion and segment consistency.

# Core Definition
In strict serialism, all twelve pitches occur in a fixed order. Partially-ordered rows relax this constraint: segments (dyads, trichords, tetrachords, hexachords) have fixed pitch-class content, but the order within each segment can vary. This concept, introduced by Babbitt, is very common in practice -- even "strict" serial music uses chords (simultaneous pitches), which inherently involve partial ordering. The number of possible orderings with fixed segments: hexachords fixed = 518,400; tetrachords fixed = 13,824; trichords fixed = 1,296; dyads fixed = 64.

# Key Properties
1. Segment content is fixed; internal order is flexible
2. Still turns over the total chromatic (aggregate completion)
3. Common in practice, even in nominally "strict" serial music
4. The smaller the fixed segments, the fewer reorderings possible
5. Babbitt formalized this concept

# Context & Application
Partial ordering is extremely common in serial practice. Whenever a composer writes a chord from row pitches, they are using partial ordering. The concept bridges the gap between strict serialism and freer twelve-tone practice.

# Examples
**Example 1** (Webern, String Quartet Op. 28): Reversing each pair of pitches creates a new row with the same dyadic and tetrachordal segments but different internal ordering.
