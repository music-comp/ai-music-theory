# Harmonic Elision

## Quick Definition
Harmonic elision is a chromatic technique in which an expected chord in a progression is suppressed or skipped and replaced by a functionally distinct chord that shares some pitch material with the expected chord, creating a sense of overlapping harmonic structures that pushes the progression in an unexpected direction.

## Formal Definition
**Harmonic elision** occurs when:

**Expected chord is suppressed**: A chord anticipated by harmonic context does not appear

**Replacement chord is similar**: The substituted chord shares pitches with expected chord

**Function changes**: Replacement chord has different harmonic function

**Two types**:
1. Leading-tone elision
2. Raised-root elision

**Different from simple substitution**: Creates sense of overlapping, not just unexpected chord

## Leading-Tone Elision vs. Raised-Root Elision

**Leading-tone elision**:
```
The leading tone that should resolve UP
Instead moves DOWN (becomes lowered version)

Expected: B -> C (leading tone resolves to tonic)
Elision:  B -> Bb (leading tone becomes b7)

The expected tonic is replaced by V7 of the next chord
```

**Raised-root elision**:
```
The root of the expected chord is RAISED
Becomes a leading tone to something else

Expected: Root = C (tonic)
Elision:  C# appears instead (leading tone to D)

The progression is pushed UP the scale
```

## Leading-Tone Elision in Detail

**Mechanism**:
```
Dominant resolves, but NOT to expected tonic:

V7 -> expected I
G-B-D-F -> expected C-E-G

With leading-tone elision:
V7 -> V7/IV (or V7 of new key)
G-B-D-F -> C-E-G-Bb

B (leading tone) becomes Bb
Instead of resolving up to C, it becomes 7th of C7
```

**Voice leading**:
```
Standard:           With elision:
B -> C              B -> Bb (down instead of up!)
D -> C or E         D -> E or C
F -> E              F -> E or G
G -> G or C         G -> G or C

Leading tone doesn't resolve normally
```

**Common progressions**:
```
V6/5 -> expected I, actual V4/2/IV
G/B-D-F -> expected C-E-G
         actual C-E-G-Bb (C7, dominant of F)

The I chord is "elided" - skipped over
Replaced by V7/IV
```

**In Roman numerals**:
```
Expected: V6/5 -> I
Actual:   V6/5 -> V4/2/IV

The I is suppressed
V4/2/IV takes its place
Notice: Both have C in bass!
```

## Raised-Root Elision in Detail

**Mechanism**:
```
Expected chord root is raised by half step
Becomes leading tone of next chord

Expected: C (root of I)
Actual:   C# (leading tone of D)

The progression moves UP the scale
```

**Resulting chords**:
```
When C becomes C#, possible chords:
- A major (A-C#-E) = V of D
- A7 (A-C#-E-G) = V7 of D
- C#° (C#-E-G) = vii° of D
- C#°7 (C#-E-G-Bb) = vii°7 of D
- C#ø7 (C#-E-G-B) = viiø7 of D (less common)
```

**Voice leading**:
```
Expected I:          With elision:
C-E-G               C#-E-G (or A-C#-E)
                    ↑
                    Root raised!

The other voices may stay or adjust
New chord is applied to next chord
```

**Example progression**:
```
Expected: ii - V - I (in C major)
          Dm - G - C

With raised-root elision:
ii - V - V7/ii (expected I elided)
Dm - G - A7 (going to D, not C!)

C (expected root) became C# (leading tone to D)
Progression pushed to ii instead of resolving to I
```

## Spotting Elision in Analysis

**Clues in Roman numerals**:
```
V6/5 -> V4/2/IV  (leading-tone elision)
        ↑
        Expected I, got V/IV instead

Notice unexpected dominant function after V
```

**Harmonic incongruities**:
```
If you expect resolution but get:
- Another dominant chord
- Applied chord to unexpected target
- Chromatic alteration of expected bass

Consider elision as explanation
```

**Bass motion clues**:
```
Leading-tone elision: Bass often stays same
   V6/5/C -> V4/2/IV has C in bass of both

Raised-root elision: Bass moves up by half step
   Expected C, got C# (raised root)
```

## Musical Effect

**Creates harmonic ambiguity**:
```
Listener expects one chord
Hears something similar but different
Creates sense of overlapping
"Where are we going?"
```

**Extends tonal motion**:
```
Instead of resolving:
V -> I (done)

Elision continues:
V -> V/IV -> IV -> V -> I (extended)

Delays final resolution
Creates longer harmonic journey
```

**Chromatic enrichment**:
```
Introduces unexpected accidentals
Creates chromatic voice leading
More colorful than diatonic resolution
```

## Musical Context

Harmonic elision serves specific purposes:
- **Deferred resolution**: Extends journey to tonic
- **Chromatic color**: Introduces unexpected accidentals
- **Overlapping structures**: Creates harmonic ambiguity
- **Sequence extension**: Can generate sequential patterns
- **Surprise effect**: Subverts expectations
- **Romantic harmony**: Common in 19th century
- **Developmental technique**: Useful in development sections

## Examples

### Basic

**Leading-tone elision**:
```
Expected:
V6/5  ->  I
G/B-D-F   C-E-G

With elision:
V6/5  ->  V4/2/IV
G/B-D-F   C-E-Bb-G

B (leading tone) -> Bb (becomes seventh)
I is elided, replaced by V7/IV
Bass stays on C (similar sound, different function)
```

**Raised-root elision**:
```
Expected:
V  ->  I
G     C-E-G

With elision:
V  ->  V/ii  ->  ii
G     A-C#-E   D-F-A

Expected C root became C# (leading tone)
A major (V/ii) replaces expected C major
Progression pushed up to ii
```

**In sequence**:
```
V/vi -> vi -> V/V -> V -> V/IV -> IV -> ...

Each time expected resolution is elided
Replaced by dominant of next chord
Creates descending sequence of keys
```

### From Repertoire

**Beethoven, Piano Sonatas**: Harmonic elisions in development sections, extends tonal motion.

**Schubert, Lieder**: Elisions for text painting, unexpected harmonic turns.

**Wagner, Music Dramas**: Extensive use of elision for chromatic continuity.

**Brahms, Chamber Music**: Elided resolutions create harmonic ambiguity.

**Chopin, Ballades**: Elisions contribute to large-scale harmonic narrative.

## Common Confusions

- Harmonic elision = suppression of expected chord, replaced by similar but functionally different chord
- **Two types**: Leading-tone elision and raised-root elision
- Leading-tone elision: Leading tone moves DOWN instead of up
  - B -> Bb instead of B -> C
  - Expected I replaced by V7 of new target
- Raised-root elision: Root of expected chord is raised
  - C -> C# (becomes leading tone to D)
  - Progression pushed UP the scale
- Different from simple chord substitution
  - Elision implies overlapping, suppression
  - Substitution is single unexpected event
- Creates sense of harmonic "skipping over"
- Extends tonal motion, delays resolution
- Common in Romantic harmony
- Clue in analysis: Unexpected dominant after V
- Bass motion: May stay same (leading-tone) or rise (raised-root)
- Voice leading: Leading tone doesn't resolve normally
