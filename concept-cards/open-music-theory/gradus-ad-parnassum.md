# Quick Definition
Johann Joseph Fux's 1725 treatise on counterpoint that established the species counterpoint method, containing 122 exercises in two, three, and four voices across all six modes, serving as the standard pedagogical resource for learning counterpoint.

# Core Definition
**Gradus ad Parnassum** (*Steps to Parnassus*, 1725) by Johann Joseph Fux is the foundational treatise that established species counterpoint as a pedagogical method. It contains exercises in three sections: Part I (Two Voices, 46 exercises), Part II (Three Voices, 44 exercises), Part III (Four Voices, 32 exercises). Each section covers all five species across six modal finals (D, E, F, G, A, C). Fux uses one cantus firmus per modal final throughout, with minor variations (Ch. 7).

# Prerequisites
- **Species counterpoint** -- Gradus ad Parnassum is the primary text for this method

# Key Properties
1. Published 1725 by Johann Joseph Fux
2. Three sections: 2 voices (46 exercises), 3 voices (44), 4 voices (32)
3. Total: 122 exercises
4. One cantus firmus per modal final, used throughout
5. Six modal finals: D, E, F, G, A, C
6. Each section covers all five species
7. Dialogue format between teacher (Aloysius/Palestrina) and student (Josephus)

# Construction / Recognition
## To Use:
1. Select a cantus firmus from Fux's set for a given mode
2. Practice each species in order (1st through 5th)
3. Work in both upper and lower counterpoint positions

# Context & Application
Gradus ad Parnassum has been the standard counterpoint textbook for nearly 300 years. Composers from Mozart to Beethoven to Brahms to Hindemith studied from it. The Open Music Theory source provides all exercises in editable format (MusicXML, MuseScore, PDF) for both exercises and solutions.
