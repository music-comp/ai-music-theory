# Texture Redistribution

## Quick Definition

The process of reassigning musical material from one medium to another by separating elements that were combined (such as splitting an arpeggiated accompaniment into distinct chord tones and rhythmic figures), recombining elements that were separate, or revealing implicit voices and counterpoint that the original notation compressed into a single part.

## Formal Definition

**Texture Redistribution** is the reorganization of musical material across parts or instruments.

**Operations**:
- **Separation**: Split combined elements into distinct parts
- **Extraction**: Reveal implicit voices within compound textures
- **Recombination**: Merge separate elements differently
- **Revelation**: Expose hidden counterpoint or rhythms

**Context**:
```
Original (piano):  [Complex texture in two hands]
                            ↓
Redistribution:    [Multiple orchestral parts,
                    each with extracted element]

Reveals what was compressed in original notation
```

**Goal**: Realize the musical substance, not just the notation.

## Redistribution Operations

**Separating arpeggio into voices**:
```
Piano:    G3-D4-B4-G5-B4-D4 (arpeggiated)

Redistribution:
Cello:    G3───────────── (sustained bass)
Viola:    D4-D4-D4-D4-D4- (rhythmic middle)
Violin:   B4-G5-B4-G5-B4- (upper motion)

Three distinct parts from one gesture
```

**Extracting accents to separate part**:
```
Piano:    [melody with accent marks]

Redistribution:
Winds:    [full melody, as written]
Brass:    [accented notes only, short]

Accent = separate attack part
```

**Revealing metric layers**:
```
Piano LH: [broken thirds, steady eighths]

Redistribution:
Viola:    [thirds figure, eighths]     = 6/4 feel
Cello:    [root notes on beats]        = 12/8 feel

Metric dissonance revealed through separation
```

**Extending pedaled notes**:
```
Piano:    [chord] + [sustain pedal for 4 beats]

Redistribution:
Strings:  [chord, sustained for 4 beats]
          Each note held to pedal change

Explicit realization of pedal effect
```

## Redistribution for Orchestral Effect

**Creating timbral variation** (Mahler approach):
```
Same arpeggiated accompaniment:
Version 1: Harp + Violas (glissando gesture)
Version 2: Harp + Clarinets (even rhythm)
Version 3: Harp + Cellos (open strings)
Version 4: Harp + Basses (low register)

Same core gesture, varied redistribution
Creates timbral variation across movement
```

**Distributing pedal tones**:
```
Piano:    C pedal (broken octaves, constant)

Redistribution:
Timpani:  C (rolls, accents)
Basses:   C2 (whole notes)
Cellos:   C3 (quarter notes)
Violas:   C4 (eighth notes)

One pitch = multiple rhythmic layers
```

**Heterophonic redistribution**:
```
Arpeggio:  G-D-B (16ths, continuous)

Redistribution:
Harp:      G-D-B (16ths, as written)
Cellos:    G---D--- (dotted quarter on beats)

Same pitches, different rhythms
Creates heterophonic texture
```

## Musical Context

Texture redistribution serves specific purposes:
- **Clarity**: Separates compound textures for understanding
- **Timbral variety**: Same material, different instrumental colors
- **Practical realization**: Adapts idioms for different instruments
- **Expressive expansion**: Reveals hidden musical content
- **Analytical insight**: Exposes underlying structure
- **Variation technique**: Creates versions without changing notes

Redistribution is fundamental to orchestration and arrangement.

## Examples

### Basic

**Simple arpeggio redistribution**:
```
Piano:    [Broken chord: G-B-D-G-D-B repeated]

Option 1 (layered):
Bass:     G──────────── (sustained)
Viola:    B-D-B-D-B-D- (alternating motion)
Violin:   ─────G (top note only)

Option 2 (harp-like):
Harp:     [full arpeggio]
Strings:  G-B-D sustained chord

Multiple valid redistributions
```

**Metric layer extraction** (Chopin 13):
```
Piano LH: [continuous broken thirds in eighths]

Redistribution:
Viola:    [thirds figure]      → 6/4 feel
Cello:    [chord roots]        → 12/8 feel

Subtle metric conflict revealed
```

**Pedal tone distribution** (Beethoven Op. 13):
```
Piano:    C octave pedal (broken)

Redistribution:
Timpani:  C (roll + accent)    → percussive layer
Bass:     C2 (half notes)      → foundation
Cello:    C3 (eighths)         → rhythmic drive
Viola:    C4 (quarters)        → middle pulse

One pitch across four rhythmic levels
```

### From Repertoire

**Mahler, Symphony No. 4, iv**: Multiple redistributions of same arpeggiated accompaniment; violas/cellos with glissando at opening, clarinets at rehearsal 1, cellos with open strings later, basses at movement end.

**Bach, Cantata 29 (from BWV1006)**: Solo violin line redistributed to full orchestra; implied harmonies become explicit parts, melodic eighths get parallel thirds, quarter-note chords added.

**Ravel, Pictures at an Exhibition**: Piano textures redistributed for orchestral effect; creates new timbral possibilities, adds string glissandos and percussion, varies redistribution for each repeat.

**Stravinsky, Rite of Spring "Danse Sacrale"**: Simple bass-treble alternation redistributed across many instruments; bass alone shows complex redistribution (timpani, basses, tuba, bassoons in various combinations).

## Common Confusions

- Redistribution **reveals** content compressed in original
- Can **separate** combined elements OR **combine** separate ones
- Arpeggio redistribution = common orchestration task
- **Pedal notes** can become multiple rhythmic layers
- **Accents** can become separate attack parts
- **Metric layers** may be hidden in piano notation
- Mahler creates **variation** through redistribution alone
- Bach **adds** material beyond redistribution
- Multiple **valid solutions** for same original
- Redistribution is **not** just literal transcription
- Reveals **hidden counterpoint** in compound melodies
- Consider **heterophonic** possibilities (same notes, different rhythms)
- Orchestral redistribution = fundamental orchestration skill
