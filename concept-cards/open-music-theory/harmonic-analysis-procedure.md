# Quick Definition

A systematic procedure for harmonic analysis that works backward from the cadence: identify phrase endings first, analyze the cadence, find the strong predominant, then analyze forward from the tonic at the beginning, using bass-line patterns to guide educated guesses.

# Core Definition

The source provides a four-step strategy for harmonic analysis using the bass line to make educated guesses about the harmonic progression (OMT, Ch. IV.7):

1. **Identify phrase endings** by listening for goals, rests, or new beginnings after a potential cadence
2. **Analyze the phrase ending's cadence**: look for sol (^5) at HC or sol-do (^5-^1) at AC; check for cad. 6/4
3. **Look for the strong predominant**: back up from the cadence to find fa (^4) or re (^2) in the bass
4. **Analyze from the beginning**: use knowledge of tonic prolongations and bass-line patterns

For applying **Tb-PD-D-Te** labels (one set per phrase):
1. **D** goes on the cadential dominant
2. **Te** goes on the cadential tonic (omit at HC)
3. **PD** goes on the first strong predominant before the cadential dominant
4. **Tb** goes on the opening tonic

# Prerequisites

- **Phrase model** — The analysis procedure applies phrase model labels
- **Cadence** — Analysis begins with identifying cadences
- **Strong predominant** — Step 3 involves locating the PD
- **Tonic prolongation** — Step 4 involves recognizing prolongation patterns

# Key Properties

1. Work BACKWARD from the cadence (not forward from the beginning)
2. Bass line is the primary guide for making educated guesses
3. One set of Tb-PD-D-Te labels per phrase
4. PD label goes on the FIRST strong predominant before the cadential dominant
5. Tb label may be delayed or omitted (more common in Romantic music)

# Construction / Recognition

## Four-Step Analysis Procedure:
1. Listen and identify phrase endings
2. Analyze cadence (HC: ends on V; AC: V-I)
3. Find strong PD (fa in bass, usually ii6 or IV)
4. Analyze from beginning using prolongation knowledge

# Common Errors

- **Error**: Analyzing from left to right (beginning to end)
  **Correction**: The source recommends working backward from the cadence for more accurate results

- **Error**: Placing multiple PD labels in one phrase
  **Correction**: Only one PD label per phrase — on the first strong PD before the cadential dominant
