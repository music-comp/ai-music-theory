# Quick Definition

A passing tone is an embellishing tone approached by step and left by step in the same direction, either ascending or descending, filling in the space between two chord tones.

# Core Definition

**Passing tones** (PT) are approached by step and left by step in the *same direction*, either ascending or descending (OMT, Ch. IV.4). They belong to Category 1 of embellishing tones (those involving only stepwise motion).

# Prerequisites

- **Embellishing tone** — Passing tone is one specific type of embellishing tone
- **Consonance** — Understanding consonance/dissonance is needed to identify non-chord tones

# Key Properties

1. Approached by step
2. Left by step in the same direction
3. Can be ascending or descending
4. Fills in a melodic interval (typically a third) between two chord tones
5. Middle note of a three-note gesture

# Construction / Recognition

## To Identify:
1. Find a non-chord tone
2. Check: is it approached by step?
3. Check: is it left by step in the SAME direction?
4. If yes to both: it is a passing tone

## To Write:
1. Identify two chord tones a third apart in the same voice
2. Fill the gap with a stepwise note between them

# Context & Application

- **Typical contexts**: Any voice in any texture; extremely common embellishment
- **Common applications**: Creating smooth melodic lines; filling in thirds between chord tones; adding rhythmic interest

# Examples

**Example 1** (OMT Ch. IV.4, Example 1): Passing tones in Szymanowska, March no. 6, mm. 8-10 (bass voice).

**Example 2** (OMT Ch. IV.4, Example 3): Passing tones in a two-voice texture, (a) ascending and (b) descending.

# Relationships

## Builds Upon
- **Embellishing tone** — Passing tone is a stepwise embellishing tone type

## Enables
- More complex embellishment patterns

## Related
- **Neighbor tone** — Also stepwise, but returns to the starting pitch (opposite direction)

## Contrasts With
- **Neighbor tone** — Neighbor returns; passing tone continues in same direction
- **Appoggiatura** — Appoggiatura is approached by leap, not step

# Common Errors

- **Error**: Labeling a note as a passing tone when it changes direction
  **Correction**: If the note returns to the starting pitch, it is a neighbor tone, not a passing tone

# Common Confusions

- **Confusion**: Confusing passing tones with neighbor tones
  **Clarification**: Passing tones continue in the same direction; neighbor tones reverse direction and return
