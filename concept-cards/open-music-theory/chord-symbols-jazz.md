# Chord Symbols (Jazz)

## Quick Definition

A shorthand notation system for indicating harmony, specifying the root, quality, extensions, and bass note of a chord.

## Formal Definition

**Chord symbols** (also called lead sheet symbols) are an absolute notation system used in jazz to specify harmonies. Unlike Roman numerals, which show function relative to a key, chord symbols indicate exactly which pitches to play.

A chord symbol has four possible components:
1. **Root**: The letter name of the chord (C, F#, Bb, etc.)
2. **Quality**: The type of triad (major is assumed; minor, diminished, augmented indicated)
3. **Extensions**: Sevenths and upper extensions (9, 11, 13)
4. **Bass note**: If different from the root, shown after a slash (C/E = C chord with E in bass)

Default assumptions:
- A letter alone = major triad (C = C major)
- Added 7 = minor seventh (C7 = C-E-G-Bb, dominant seventh quality)
- Extensions (9, 11, 13) = major or perfect intervals unless altered with sharp/flat

## Musical Context

Chord symbols appear on lead sheets, the standard jazz score format that shows only melody and harmony. This allows performers to realize the harmony in their own way through voicings, while providing a common harmonic framework.

Chord symbols are not analytical tools; they are practical performance notation. The same harmony might be written differently depending on what is easiest to read in context.

## Examples

### Basic

- **C** = C major triad (C-E-G)
- **Cm** or **Cmi** or **C-** = C minor triad (C-Eb-G)
- **C7** = C dominant seventh (C-E-G-Bb)
- **Cmaj7** or **Cma7** or **C^7** = C major seventh (C-E-G-B)
- **Cm7** = C minor seventh (C-Eb-G-Bb)
- **C/E** = C major with E in the bass (first inversion)

### From Repertoire

Jazz lead sheets like "Autumn Leaves" or "All the Things You Are" use chord symbols throughout. A typical jazz ending might show: Dm7 - G7 - Cmaj7 (a ii-V-I in C major).

## Common Confusions

- Chord symbols are ABSOLUTE (C always means C), not relative like Roman numerals
- C7 is dominant seventh (major triad + minor seventh), NOT major seventh
- The slash notation (C/E) indicates bass note, not "C or E"
- Accidentals in extensions (#11, b9) mean "raise/lower," not necessarily a sharp/flat note
- Many variant notations exist; be prepared to interpret different systems
