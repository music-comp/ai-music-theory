# Quick Definition
Musical sections are classified as either core (main or contrasting, presenting primary content) or auxiliary (external prefixes/suffixes or connective transitions/retransitions), providing a framework for understanding form across genres.

# Core Definition
**Formal sections** are classified in a hierarchy (Summach 2012): **Core sections** contain a work's primary musical content and include **main sections** (first to present primary content, stable, repeated) and **contrasting sections** (may be stable or unstable, provide contrast). **Auxiliary sections** support core sections and include **external** sections (prefixes/introductions and suffixes/codas) and **connective** sections (transitions between A→B and retransitions between B→A). Transitions help lead away from the main section; retransitions prepare the return. Both come in large (with complete phrases) and small (without) varieties. Formal stability involves features like tonic expansions, regular hypermeter, and diatonic harmony; instability involves modulation, chromaticism, sequences, and irregular phrase lengths (Ch. 5).

# Prerequisites
- **Phrase** -- Sections are composed of phrases

# Key Properties
1. Core vs. auxiliary: primary content vs. supporting function
2. Core: main (A, primary theme, refrain) vs. contrasting (B, episode, development)
3. Auxiliary external: prefix (introduction) and suffix (coda, codetta)
4. Auxiliary connective: transition (A→B) and retransition (B→A)
5. Stability: less change, tonic expansions, regular hypermeter
6. Instability: more change, chromaticism, sequences, modulation
7. Large vs. small: whether section contains complete phrases
8. "Becoming" (Summach): gradual transformation between formal functions

# Construction / Recognition
## To Classify Sections:
1. Determine if section presents primary content (core) or supports it (auxiliary)
2. If core: is it the main section or a contrasting section?
3. If auxiliary: is it external (prefix/suffix) or connective (transition/retransition)?
4. Assess stability level: stable = core theme; unstable = development or connective

# Context & Application
This classification system applies across genres and eras. Main sections go by different names in different forms: primary theme (sonata), refrain (rondo), chorus (verse-chorus), strophe (AABA). Contrasting sections include secondary themes, episodes, developments, verses, and bridges. Understanding formal function helps identify sections even in unfamiliar genres.

# Common Errors
- **Error**: Calling every unstable section a "transition"
  **Correction**: Unstable contrasting sections are core sections, not auxiliary; transitions connect core sections

# Common Confusions
- **Confusion**: "Bridge" in classical and popular music means the same thing
  **Clarification**: In popular music, "bridge" refers to a contrasting core section; in classical analysis, "transition" is the connective auxiliary section
