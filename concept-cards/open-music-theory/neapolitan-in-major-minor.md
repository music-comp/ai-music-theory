# Neapolitan in Major vs Minor Keys

## Quick Definition

The Neapolitan sixth can appear in both major and minor keys but is more common in minor, where it requires fewer chromatic alterations and has a more natural relationship to the key's harmonic vocabulary.

## Formal Definition

The **Neapolitan sixth** (♭II6) functions as a chromatic predominant in both major and minor keys, but with different chromatic content:

**In minor keys** (more common):
- Some notes may be diatonic
- More idiomatic to the key
- Less dramatic chromatic shift

**In major keys** (less common but valid):
- All notes foreign to the key
- More dramatic effect
- Greater chromatic contrast

## Neapolitan in Minor Keys

### Structure in C Minor

**♭II6 chord**: D♭-F-A♭ (with F in bass)

| Note | Scale Degree | Status in C Minor |
|------|-------------|-------------------|
| D♭ | lowered-^2 | Chromatic (^2 is D natural) |
| F | ^4 | **Diatonic** |
| A♭ | lowered-^6 | **Diatonic** (natural minor) |

**Chromatic alterations needed**: ONE (lowered-^2)
- ^4 (F) is already diatonic
- lowered-^6 (A♭) is diatonic in natural minor

### Why More Common in Minor

1. **Fewer chromatic notes required**: Only the root (lowered-^2) is altered
2. **Natural fit**: lowered-^6 already exists in the natural minor scale
3. **Voice leading**: Smooth resolution to V (G major has G natural, not G♭)
4. **Historical use**: Baroque/Classical minor-key works use extensively

### Example Progression in C Minor

```
i    →    ♭II6    →    V    →    i
Cm        D♭/F         G         Cm

Only D♭ is chromatic to C minor
A♭ is diatonic (natural minor ^6)
F is diatonic (^4)
```

## Neapolitan in Major Keys

### Structure in C Major

**♭II6 chord**: D♭-F-A♭ (with F in bass)

| Note | Scale Degree | Status in C Major |
|------|-------------|-------------------|
| D♭ | lowered-^2 | Chromatic (^2 is D natural) |
| F | ^4 | Diatonic |
| A♭ | lowered-^6 | Chromatic (^6 is A natural) |

**Chromatic alterations needed**: TWO (lowered-^2 and lowered-^6)
- Only ^4 (F) is diatonic
- Both root and fifth are altered

### Why Less Common in Major

1. **More chromatic content**: Two altered notes instead of one
2. **Greater contrast**: More dramatic, even jarring effect
3. **Distant relationship**: The ♭II chord is more foreign to major
4. **Historical preference**: Major keys often used diatonic predominants

### Example Progression in C Major

```
I    →    ♭II6    →    V    →    I
C         D♭/F         G         C

Both D♭ and A♭ are chromatic to C major
Only F is diatonic
More dramatic chromatic effect
```

## Comparison Table

| Aspect | Minor Key | Major Key |
|--------|-----------|-----------|
| Chromatic notes | 1 (lowered-^2) | 2 (lowered-^2, lowered-^6) |
| lowered-^6 | Diatonic | Chromatic |
| Effect | Natural, expressive | Dramatic, striking |
| Frequency | Common | Less common |
| Historical use | Standard | Special effect |

## Voice Leading Comparison

**In minor** (C minor):
```
♭II6:    V:
D♭       B     (chromatic: lowered-^2 → ^7)
A♭       G     (diatonic note moving to diatonic)
F        G     (diatonic to diatonic)
```

**In major** (C major):
```
♭II6:    V:
D♭       B     (chromatic: lowered-^2 → ^7)
A♭       G     (chromatic: lowered-^6 → ^5)
F        G     (diatonic to diatonic)
```

More chromatic voice motion in major key context.

## Musical Context

### Minor Key Usage

- **Standard vocabulary**: Part of minor-key harmonic language
- **Baroque to Romantic**: Common throughout periods
- **Opera and art song**: Expressive intensity
- **Examples**: Mozart concertos, Beethoven sonatas, Schubert lieder

### Major Key Usage

- **Special effect**: For dramatic moments
- **Romantic era**: More adventurous harmonic vocabulary
- **Modal mixture link**: Related to borrowing from parallel minor
- **Less idiomatic**: Stands out more than in minor

## Examples

### Basic

**C minor with ♭II6**:
```
i  - iv  - ♭II6 - V  - i
Cm - Fm  - D♭/F - G  - Cm

Natural minor-key progression
♭II6 fits smoothly
```

**C major with ♭II6**:
```
I  - IV  - ♭II6 - V  - I
C  - F   - D♭/F - G  - C

More dramatic chromatic shift
Both D♭ and A♭ are foreign
```

### From Repertoire

**Schubert, "Erlkonig" (G minor)**:
- ♭II6 (A♭/C) in minor-key context
- Standard minor-key usage
- Tonicizes ♭II, then uses as predominant

**Beethoven, Sonata Pathetique (C minor)**:
- ♭II6 at dramatic cadential moments
- Idiomatic minor-key expression

**Less common major-key examples**:
- Romantic-era works occasionally use ♭II6 in major
- Creates unexpected chromatic color
- Often at especially dramatic moments

## Common Confusions

- The ♭II6 chord structure is THE SAME in major and minor keys (same notes)
- What differs is how chromatic those notes are to each key
- In minor: lowered-^6 is diatonic (natural minor), so only one chromatic note
- In major: lowered-^6 is chromatic, so two chromatic notes total
- The chord is MAJOR quality in both contexts
- Function is PREDOMINANT in both major and minor
- More common in minor because it requires fewer alterations
- Major-key usage is rarer but entirely valid
