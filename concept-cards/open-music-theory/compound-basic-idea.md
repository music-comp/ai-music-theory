# Quick Definition
An antecedent without a cadence -- a beginning type in hybrid forms consisting of a basic idea followed by a contrasting idea, but lacking the cadential closure that would make it a true antecedent.

# Core Definition
A **compound basic idea (c.b.i.)** is "an antecedent without a cadence." It contains a basic idea followed by a contrasting idea (like an antecedent), but does not end with a cadence (like a presentation). It is "compound" because it often functions as the basic idea of a large (16-measure) sentence, where the presentation comprises two c.b.i. units. The c.b.i. is one of three possible beginnings in hybrid forms (alongside antecedent and presentation) (Ch. 3).

# Prerequisites
- **Hybrid form** -- The c.b.i. is introduced as a beginning type in hybrid forms
- **Period** -- Must understand antecedent to see what the c.b.i. lacks (cadence)

# Key Properties
1. Basic idea + contrasting idea (like antecedent)
2. No cadence at the end (unlike antecedent)
3. One of three beginning types in hybrid forms
4. "Compound" because it can serve as basic idea of a large sentence

# Construction / Recognition
## To Identify:
1. Look for b.i. + c.i. (contrasting material, not repetition)
2. Verify no cadence at the end
3. If contrasting + no cadence: c.b.i. (not antecedent or presentation)

# Examples
**Example 1** (Ch. 3, Example 2): Haydn, Piano Sonata Hob. XVI:35, I -- c.b.i. where the bass avoids the half cadence that might have appeared.

# Relationships
## Contrasts With
- **presentation** -- Presentation has repetition; c.b.i. has contrast
- **antecedent-consequent** -- Antecedent has cadence; c.b.i. does not

# Common Confusions
- **Confusion**: A c.b.i. is just an incomplete antecedent
  **Clarification**: While structurally similar, the c.b.i. functions as a beginning type in hybrid forms, not a failed antecedent
