# Common Chord Modulation

## Quick Definition

A modulation technique that uses a chord functioning in both the old key and the new key as a pivot point for the key change—where a diatonic chord common to both keys is reinterpreted harmonically, analyzed with dual Roman numerals (e.g., "I in C = IV in G"), creating a smooth transition between tonal centers without chromatic alteration at the pivot moment, most common between closely related keys (those differing by one sharp or flat), and standard throughout common-practice music as the primary means of modulation in Classical style.

## Formal Definition

**Common chord modulation** (also called **pivot chord modulation**) is a modulation technique using a diatonic chord that belongs to both keys.

**Process**:
1. **Old key established**: Original tonic confirmed
2. **Pivot chord**: Chord diatonic in both keys
3. **Reinterpretation**: Pivot chord's function changes
4. **New key confirmed**: Cadence in new key

**Key characteristics**:
- **Pivot/common chord**: Diatonic in both keys
- **Dual function**: Different Roman numeral in each key
- **Smooth transition**: No chromatic alteration at pivot
- **Closely related keys**: Most common (differ by one accidental)
- **Cadential confirmation**: New key established by authentic cadence

**Notation**: Pivot analyzed with **two Roman numerals** (one per key)

## Pivot Chord Mechanics

**Pivot chord analysis**:
```
I in C major = IV in G major

Same pitches: C-E-G
Function in C: I (tonic)
Function in G: IV (predominant)

Pivot enables smooth modulation C→G
```

**Process example (C major → G major)**:
```
Measures: 1-4        5         6-8
Key:      C major    PIVOT     G major
Chords:   I-V-I      vi=ii     V-I

m. 5: Am chord (vi in C, ii in G)
Before: Am = vi in C
After: Am = ii in G (new function)
```

## Closely Related Keys

**Closely related keys** = differ by one sharp or flat

**From C major**:
- **G major** (add F#): One sharp more
- **F major** (add Bb): One flat more
- **A minor** (relative): Same key signature
- **E minor** (add F#): One sharp more
- **D minor** (add Bb): One flat more

**More pivot chord options** = easier modulation

**Distantly related keys**: Fewer common chords, more difficult modulation

## Common Pivot Chords

**C major → G major**:
```
Chords diatonic to both:
- C major: I in C = IV in G ✓
- Em: iii in C = vi in G ✓
- Am: vi in C = ii in G ✓ (most common)
- G major: V in C = I in G (but this IS the new tonic)

Am most common pivot (vi=ii)
```

**C major → F major**:
```
Common chords:
- F major: IV in C = I in F (but this IS new tonic)
- Dm: ii in C = vi in F ✓ (most common)
- Am: vi in C = iii in F ✓
- C major: I in C = V in F (but this IS old tonic)

Dm most common pivot (ii=vi)
```

**C major → A minor** (relative):
```
All diatonic chords shared!
Very easy modulation
Any chord can serve as pivot
```

## Analytical Notation

**Dual Roman numeral notation**:
```
Old key: C major    |  I    vi   |  ii   V⁷  I  ||
                           ↓
                         vi=ii
                           ↓
New key: G major    |      ii   |  V⁷  I     ||

Vertical line shows pivot moment
Both Roman numerals shown
```

**Bracket notation**:
```
C: I   vi   
      ┌─┴──┐
      vi=ii
      └───┬┘
G:     ii  V⁷  I

Bracket indicates pivot chord
Shows dual function clearly
```

## Voice Leading in Modulation

**Smooth voice leading** (C→G modulation):
```
C major:  I         vi          (old key)
          C-E-G     A-C-E
          
          vi=ii                 (PIVOT)
          
G major:            ii    V⁷    I    (new key)
                    A-C-E  D-F#-A-C  G-B-D

No chromatic change at pivot (A-C-E)
F# appears AFTER pivot (confirms G major)
```

**Chromatic notes confirm new key**:
- Appear **after** pivot chord
- Often involve new accidentals (F# for G major from C major)
- Confirm modulation through cadence

## Musical Context

Common chord modulation serves specific purposes:
- **Smooth key change**: No jarring chromatic leaps
- **Classical standard**: Primary modulation technique in Classical period
- **Closely related keys**: Most effective for nearby keys
- **Formal articulation**: Marks new sections (exposition to development)
- **Tonal variety**: Provides contrast within piece
- **Voice leading continuity**: Maintains smooth connections
- **Pedagogical clarity**: Clear analytical demonstration
- **Cadential confirmation**: New key established decisively

Most natural and common modulation technique in tonal music.

## Examples

### Basic

**C major → G major** (using Am pivot):
```
Phrase 1 (C major):  I  -  IV  -  V  -  vi
                     C     F      G     Am

Phrase 2 (G major):  ii  -  V⁷  -  I
                     Am    D⁷    G

Am = vi in C, ii in G (pivot)
D⁷ confirms G major (has F#)
```

**Analytical notation**:
```
C:  I    IV    V    vi   |
                    ──────
                    vi=ii |
                    ────── 
G:                  ii   | V⁷   I

Am serves as pivot chord
Dual function shown
```

**C major → F major** (using Dm pivot):
```
Phrase 1 (C major):  I  -  V  -  vi  -  ii
                     C     G     Am    Dm

Phrase 2 (F major):  vi  -  V⁷  -  I
                     Dm    C⁷    F

Dm = ii in C, vi in F (pivot)
C⁷ (with Bb) confirms F major
```

**C major → A minor** (relative):
```
C:  I    IV    V    vi   |
                    ──────
                    vi=i  |
                    ──────
Am:                 i    | iv   V   i

Easy modulation (same key signature)
vi becomes i
```

### From Repertoire

**Mozart, Piano Sonatas**: Common chord modulations to dominant key (I→V) in exposition, to relative minor, demonstrates Classical formal practice.

**Beethoven, Sonata form movements**: Modulates from tonic to dominant (or relative major in minor keys) using pivot chords, standard sonata form procedure.

**Bach, Preludes and Fugues**: Modulations to closely related keys using pivot chords, smooth voice leading throughout.

**Haydn, String Quartets**: Frequent modulations to dominant and subdominant using common chords, clear key areas defined by cadences.

**Classical period universal**: Common chord modulation is THE standard technique in Classical style for changing keys.

## Common Confusions

- Common chord modulation = uses chord diatonic to **both keys** as pivot
- Also called "pivot chord modulation"
- Pivot chord has **two Roman numerals** (one for each key)
- No chromatic alteration **at the pivot** (smooth transition)
- New key confirmed by **cadence** (usually authentic cadence)
- Most common between **closely related keys** (differ by one accidental)
- Closely related keys = more common chords = easier modulation
- Pivot chord analyzed with bracket or vertical alignment
- Process: old key → pivot → new key → cadence
- Chromatic notes appear **after** pivot (confirm new key)
- Different from direct/abrupt modulation (no pivot)
- Different from chromatic modulation (uses chromatic chords)
- Pivot usually predominant function in new key (ii, IV, vi)
- Am is common pivot C→G (vi in C, ii in G)
- Dm is common pivot C→F (ii in C, vi in F)
- Relative major/minor easiest (all chords shared)
- Classical period standard technique (Mozart, Haydn, Beethoven)
- Confirms new key with V-I cadence in new key
- "Diatonic modulation" = alternative term
- Smooth voice leading throughout
- Not same as tonicization (modulation is longer, more structural)
