# Flat Submediant (♭VI)

## Quick Definition

The flat submediant (♭VI) is a major triad built on the lowered sixth scale degree, borrowed from the parallel minor, featuring both a lowered root (lowered-^6) and lowered third (lowered-^3), creating a dark, rich sonority commonly used in Romantic and popular music.

## Formal Definition

The **flat submediant** is a borrowed chord with an altered root:

**Structure in C major**:
- Diatonic vi: A-C-E (A minor)
- Borrowed ♭VI: A♭-C-E♭ (A♭ major)
- Changed notes: 
  - Root: A → A♭ (^6 → lowered-^6)
  - Fifth: E → E♭ (^3 → lowered-^3)

**Characteristics**:
- Major quality (unlike diatonic vi which is minor)
- Requires two chromatic alterations
- The flat sign (♭) indicates the lowered ROOT
- Creates dramatic, dark color

**Roman numeral notation**: ♭VI (uppercase indicates major quality, ♭ indicates lowered root)

## Voice Leading

**♭VI to V resolution**:
```
♭VI: A♭-C-E♭    V:  G-B-D

A♭ → G (lowered-^6 → ^5, half-step descent in bass)
E♭ → D (lowered-^3 → ^2, chromatic descent)
C → B or D (^1 resolves to chord tone of V)
```

**♭VI to ♭VII resolution**:
```
♭VI: A♭-C-E♭    ♭VII: B♭-D-F

A♭ → B♭ (ascending whole step in bass)
Common in rock progressions
```

**Chromatic bass descent with ♭VI**:
```
I  -  V6/IV  -  ♭VI  -  V
^1    ^7       lowered-^6    ^5

Bass: C  -  B  -  A♭  -  G
      (chromatic descent)
```

This descending chromatic bass line is a hallmark of Romantic-era harmony.

## Comparison with Diatonic vi

| Aspect | vi (diatonic) | ♭VI (borrowed) |
|--------|---------------|----------------|
| Root | A natural | A♭ (lowered) |
| Quality | Minor | Major |
| Notes in C | A-C-E | A♭-C-E♭ |
| Chromatic content | None | Two altered notes |
| Character | Mild, subdued | Dark, dramatic |

## Common Progressions

**♭VI - V - I**:
```
♭VI - V - I
A♭  - G - C

Dramatic chromatic approach to cadence
Bass: A♭ → G (half-step descent)
```

**I - ♭VI - ♭VII - I (rock progression)**:
```
C - A♭ - B♭ - C

Common in rock and pop music
All three chords borrowed from C minor
```

**♭VI - ♭VII - I (double plagal)**:
```
A♭ - B♭ - C

Two borrowed chords in sequence
Rising bass by whole steps
Strong in rock/pop styles
```

**Descending chromatic bass**:
```
I - V/IV - iv - ♭VI - V - I
C - B   - Fm - A♭  - G - C

Extended chromatic descent: C - B - A♭ - G
♭VI as part of chromatic approach to V
```

## Musical Context

The ♭VI chord is prominent in:
- **Romantic era**: Brahms, Schubert, Wagner (rich chromatic harmony)
- **Rock and pop music**: Foundational borrowed chord
- **Film scores**: For dramatic, dark coloring
- **Musical theater**: Emotional intensity

**Expressive effects**:
- Creates sudden, dramatic darkness in major keys
- Provides rich, unexpected harmonic color
- Enables chromatic bass motion
- Connects to parallel minor without full modulation

## Examples

### Basic

**♭VI in C major**:
```
I - ♭VI - V - I
C - A♭  - G - C

A♭ major chord (A♭-C-E♭) borrowed from C minor
Dramatic shift from C major sound world
```

**Extended progression**:
```
I - IV - ♭VI - V - I
C - F  - A♭  - G - C

Mixture of diatonic and borrowed chords
♭VI provides chromatic color
```

**Rock progression**:
```
I - ♭VII - ♭VI - ♭VII - I
C - B♭   - A♭  - B♭   - C

All borrowed chords from C minor
Common in rock, creates modal sound
```

## Common Confusions

- ♭VI is a MAJOR chord (A♭ major in C), not minor like diatonic vi
- The ♭ indicates a lowered ROOT, not just any flat note
- ♭VI requires TWO chromatic alterations (root and fifth)
- Do not confuse with the Neapolitan (♭II), which is a different borrowed chord
- In the key of C major, ♭VI is A♭ major, NOT A minor with a flat
- The voice leading typically features bass descending by half-step to V (A♭ → G)
- ♭VI is borrowed from parallel MINOR, not relative minor
- In Roman numeral analysis, always show the ♭ before VI when the root is lowered
