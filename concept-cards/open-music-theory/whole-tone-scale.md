# Whole-Tone Scale

## Quick Definition

A six-note symmetrical scale constructed entirely of whole steps (major seconds), dividing the octave into six equal parts--its uniform interval structure eliminates any sense of tonal center since every note has identical intervallic relationships to its neighbors, creating the floating, dreamlike quality that made it a favorite of Impressionist composers like Debussy, who used it to evoke ambiguity, suspension, and otherworldly atmospheres.

## Formal Definition

**Whole-tone scale** (whole-tone collection) is a hexatonic (six-note) pitch collection with the following properties:

**Structure**:
- **Interval pattern**: 2-2-2-2-2-2 (all whole steps)
- **Total**: 6 x 2 = 12 semitones (one octave)
- **Cardinality**: 6 pitch classes

**Symmetry**:
- **Rotational symmetry**: Any note can serve as "root" with identical intervallic surroundings
- **Transpositional equivalence**: Only TWO unique whole-tone collections exist
- **No half steps**: Absence of semitones removes leading-tone pull

**Notation**:
- WT0 (or WT even): Contains pitch classes {0, 2, 4, 6, 8, 10} = C, D, E, F#, G#, A#
- WT1 (or WT odd): Contains pitch classes {1, 3, 5, 7, 9, 11} = C#, D#, F, G, A, B

## Construction and Interval Content

**Building the whole-tone scale**:
```
Starting on C (WT0):
C --[+2]--> D --[+2]--> E --[+2]--> F# --[+2]--> G# --[+2]--> A# --[+2]--> C

Pitch classes: C  D  E  F#  G#  A#  (C)
Semitones:     0  2  4   6   8  10  (12)
```

**The two whole-tone collections**:
```
WT0: C - D - E - F# - G# - A#
     (even pitch class numbers: 0, 2, 4, 6, 8, 10)

WT1: C# - D# - F - G - A - B  
     (odd pitch class numbers: 1, 3, 5, 7, 9, 11)

Together they exhaust all 12 pitch classes
WT0 and WT1 are complements of each other
```

**Interval vector**: [0,6,0,6,0,2]
- 0 minor seconds (no half steps)
- 6 major seconds (every adjacent pair)
- 0 minor thirds
- 6 major thirds (every alternate pair)
- 0 perfect fourths
- 2 tritones (maximum for hexachord)

## Harmonic Content

**Available triads** (limited):
```
Within WT0 (C-D-E-F#-G#-A#):

Augmented triads only:
- C+ = C - E - G#
- D+ = D - F# - A#
- E+ = E - G# - C (enharmonic: B#)
- (and enharmonic equivalents)

No major or minor triads possible
(Major/minor triads require both M3 and m3)
```

**Available seventh chords**:
```
Dominant seventh with raised fifth (7#5):
- C7#5 = C - E - G# - Bb (Bb = A#)
- Built on each scale degree

French augmented sixth sonority:
- C - E - G# - Bb contains Fr+6 structure
```

**Quartal/Quintal structures**:
```
Augmented fourths (tritones) available:
C - F#, D - G#, E - A#

Stacked tritones common in whole-tone harmony
```

## Transpositional Equivalence

**Only two unique forms**:
```
Transposing WT0 up any whole step yields WT0:
C-D-E-F#-G#-A# transposed by M2 = D-E-F#-G#-A#-C (same collection)

Transposing WT0 up any half step yields WT1:
C-D-E-F#-G#-A# transposed by m2 = C#-D#-F-G-A-B (the other collection)

This is "limited transposition"
```

**Why only two?**
```
12 pitch classes / 6 notes per scale = 2 unique collections

Transposition by 2 semitones maps the scale onto itself
Period of transposition = 2
Number of unique transpositions = 12/2 = 6... but these 6 reduce to 2 distinct collections
```

## Musical Characteristics

**Tonal ambiguity**:
- No half steps = no leading tones
- Every note equally "stable" or "unstable"
- No natural dominant-tonic pull
- Floating, suspended quality

**Textural effects**:
- Parallel motion in whole tones creates "sliding" effect
- Arpeggiated augmented triads shimmer without resolution
- Tremolo figures create hazy, undefined harmonies

**Common associations**:
- Dreams and dream sequences
- Water, mist, fog imagery
- Mystery, magic, the supernatural
- Timelessness, suspended animation
- Otherness, exoticism

## Musical Context

**Impressionism**: The whole-tone scale became a signature sound of French Impressionism, particularly associated with Claude Debussy. Its ability to suspend tonal function aligned with Impressionist goals of evoking atmosphere over narrative.

**Film music**: The "dream sequence" trope uses whole-tone collections to signal departure from reality.

**20th-century concert music**: Composers use whole-tone passages for specific coloristic effects within otherwise chromatic or atonal contexts.

**Limitations**: Extended whole-tone passages can become monotonous due to the lack of intervallic variety. Composers typically use it in alternation with other materials.

## Examples

### Basic

**WT0 scale with note names**:
```
C - D - E - F# - G# - A# - (C)
Intervals between adjacent notes: W-W-W-W-W-W
(W = whole step = 2 semitones)

All intervals within the scale:
M2 (whole step): C-D, D-E, E-F#, F#-G#, G#-A#, A#-C
M3: C-E, D-F#, E-G#, F#-A#, G#-C, A#-D
A4/d5 (tritone): C-F#, D-G#, E-A#
```

**Chord built on whole-tone scale**:
```
Whole-tone chord voicing:
Bass: C
        E (M3 above)
        G# (A5 above)
        Bb/A# (m7 above)
        D (M9 above)

All notes from WT0
"French sixth" sonority expanded
```

**Distinguishing WT0 from WT1**:
```
Does the passage contain C AND D?
  Yes --> WT0

Does the passage contain C AND C#?
  Yes --> Uses both collections (or chromatic)

Does the passage contain C# AND D#?
  Yes --> WT1
```

### From Repertoire

**Debussy, "Voiles" (Preludes, Book I)**: Opens with pure whole-tone writing establishing an atmosphere of suspended motion. The title ("Sails" or "Veils") captures the ambiguity the whole-tone scale creates.

**Debussy, "La Mer"**: Whole-tone passages evoke the shimmering, formless quality of the sea.

**Ravel, "Jeux d'eau"**: Brief whole-tone passages create water imagery through cascading arpeggios.

**Puccini, _Turandot_**: Whole-tone scales used for exotic, mysterious Chinese setting.

**Film music**: The stereotypical "wobbly" dissolve into a dream sequence often employs whole-tone glissandi or arpeggios.

**Chen Yi, percussion concerto**: Pentatonic melodies accompanied by contrasting whole-tone harmonies.

## Common Confusions

- Whole-tone scale has 6 notes (hexatonic), not 7 like diatonic scales
- Only TWO unique whole-tone collections exist (not 12 transpositions)
- Contains NO half steps--this is its defining characteristic
- Cannot build major or minor triads within the whole-tone scale
- Augmented triads are the ONLY triads available
- "Whole-tone" refers to the interval between adjacent notes, not the total span
- WT0 and WT1 together contain all 12 chromatic pitches
- Not the same as Messiaen's Mode 1 (though related--Mode 1 IS the whole-tone scale)
- Transposing by M2 gives the SAME collection, not a new transposition
- The "floating" quality comes from lack of semitones, not from any specific chord
