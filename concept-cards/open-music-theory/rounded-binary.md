# Quick Definition
A binary form subtype where the beginning of the A section returns in the home key somewhere in the middle of the second reprise, preceded by a contrasting B section, creating the pattern ||:A:||:BA':||.

# Core Definition
In **rounded binary form**, "the beginning of A returns in the home key somewhere in the middle of the second reprise." Not all of A needs to return -- only the beginning. The return "may be exactly the same" or include "slight variations, like change of octave, accompanimental pattern, and/or melodic embellishments." The B section at the start of the second reprise is "typically less stable than the A section and may involve common destabilizing features like sequences, chromaticism, and dominant pedals." A half cadence before the return of A is common in 18th-century music (Ch. 6).

# Prerequisites
- **Binary form** -- Rounded binary is a subtype

# Key Properties
1. Structure: ||:A:||:BA':||
2. A returns in home key mid-second reprise
3. Only the beginning of A needs to return
4. Return may include slight variations
5. B section typically less stable (sequences, chromaticism, pedals)
6. HC before A' return is common in 18th century

# Examples
**Example 1** (Ch. 6, Example 4): Mozart, Symphony No. 25, III, Menuetto -- clear rounded binary with HC at m. 20 before A' at m. 21.
