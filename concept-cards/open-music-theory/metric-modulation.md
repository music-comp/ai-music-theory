# Quick Definition
Metric modulation smooths out abrupt tempo changes by introducing subdivisions or beat groupings in the first tempo that match durations in the new tempo, making the transition nearly indiscernible to the listener. Notated with "note value = note value" indications (e.g., eighth note = eighth note).

# Core Definition
Metric modulation links two tempos through a common rhythmic value. The division of the beat may stay the same while the beat changes (e.g., eighth note constant as beat moves from quarter to dotted quarter), or the beat may stay the same while the subdivision changes. Elliott Carter is the technique's best-known practitioner. In his "Canaries" (8 Pieces for 4 Timpani), triplets in 3/4 set up a transition to 3/8, where the triplet eighth becomes the new beat unit, creating a seamless metric shift.

# Key Properties
1. Links two tempos through a common rhythmic value
2. Notated with "note = note" indication
3. Nearly indiscernible to listener -- recognized only in retrospect
4. Two main types: keep subdivision constant, or keep beat constant
5. Strongly associated with Elliott Carter

# Context & Application
Metric modulation is a sophisticated rhythmic technique used primarily in 20th/21st-century concert music. It enables fluid tempo transitions without jarring discontinuities.

# Examples
**Example 1** (Elliott Carter, "Canaries"): Triplets in 3/4 become the beat unit of 3/8, with the eighth note remaining constant.
