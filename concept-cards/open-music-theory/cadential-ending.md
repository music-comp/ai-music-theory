# Quick Definition
An ending type in hybrid forms defined by the core bass pattern mi-fa-sol-do (scale degrees 3-4-5-1), harmonized typically as I6-ii6-V(7)-I, expanding the cadential idea to fill a full subphrase.

# Core Definition
A **cadential ending** harmonizes the core bass pattern mi-fa-sol-do (3-4-5-1) with I6-ii6(or IV)-V(7)-I. It differs from a cadential idea (which comes at the end of a continuation) by being expanded to four measures, replacing the continuation. The bass pattern may be embellished with fi before sol (chromatic approach: 3-4-raised 4-5-1, tonicizing the dominant). The clearest cadential endings are four measures long with one bass note per measure (Ch. 3, "New: Cadential").

# Prerequisites
- **Hybrid form** -- The cadential ending is an ending type in hybrid forms

# Key Properties
1. Core bass pattern: mi-fa-sol-do (3-4-5-1)
2. Common harmonization: I6-ii6-V(7)-I
3. May be embellished with fi before sol (tonicizing V)
4. Four measures, one bass note per measure (clearest form)
5. One of three ending types alongside continuation and consequent
6. Expands the cadential idea to subphrase level

# Examples
**Example 1** (Ch. 3, Example 4): Haydn, String Quartet Op. 64, No. 4, II -- cadential ending with mi-fa-sol-do bass pattern.
