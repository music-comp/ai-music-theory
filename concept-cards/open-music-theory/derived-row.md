# Quick Definition
A derived row is a twelve-tone row whose discrete segments (dyads, trichords, or tetrachords) all belong to the same set class, meaning the entire row can be considered "derived from" a single pitch-class set type.

# Core Definition
Derived rows feature several instances of only one set class among their discrete (non-overlapping) segments. A twelve-tone row can be divided into six dyads, four trichords, three tetrachords, or two hexachords. When all segments of one division type belong to the same set class, the row is derived. Because set-class content is preserved under transposition and inversion, derived rows guarantee the regular recurrence of specific set classes throughout a piece, cultivating compositional unity. The term can also refer specifically to rows derived from another row's subsegment.

# Prerequisites
- Twelve-tone row and set class

# Key Properties
1. Discrete segments all belong to the same set class
2. Guarantees recurring set-class content across all row forms
3. Common divisions: 6 dyads, 4 trichords, 3 tetrachords, 2 hexachords
4. The number 12 has many factors (2,3,4,6), enabling diverse segmentation
5. Set-class content preserved under P, I, R, RI operations

# Context & Application
Webern frequently used derived rows. His String Quartet Op. 28 row divides into three chromatic tetrachords (0123) and six semitone dyads. This ensures that chromatic clusters permeate the piece regardless of which row form is used.

# Examples
**Example 1** (Webern, String Quartet Op. 28): Three discrete tetrachords, all set class (0123). Six discrete dyads, all semitones.
**Example 2** (Webern, Konzert Op. 24): Four discrete trichords, all set class (014).
