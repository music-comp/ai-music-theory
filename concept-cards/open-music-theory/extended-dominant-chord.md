# Extended Dominant Chord

## Quick Definition

Dominant chords with added tones stacked in thirds beyond the seventh, including the ninth (V9), eleventh (V11), and thirteenth (V13), typically found in root position with specific resolution tendencies where the ninth resolves down by step, the eleventh holds as a common tone, and the thirteenth leaps down by third to the tonic, creating richer sonorities that require careful voicing choices in four-voice textures since not all chord tones can be included.

## Formal Definition

**Extended dominant chords** add tones above the seventh:

**Three extensions**:

1. **V9** (dominant ninth):
   - Adds ^6 above the root (= ^9th of chord)
   - Ninth resolves **down by step**
   - Replaces doubled root in four-voice texture

2. **V11** (dominant eleventh):
   - Adds ^1 above the root (= ^11th of chord)
   - Eleventh holds as **common tone** (to ^1 of I)
   - Replaces the third in four-voice texture
   - Sounds like IV with ^5 in bass

3. **V13** (dominant thirteenth):
   - Adds ^3 above the root (= ^13th of chord)
   - Thirteenth leaps **down by third** to ^1
   - Replaces the fifth in four-voice texture

**Standard structures in C (V on G)**:
```
V7:  G - B - D - F         (root, 3rd, 5th, 7th)
V9:  G - B - (D) - F - A   (adds 9th, often omit 5th)
V11: G - (B) - D - F - A - C  (adds 9th + 11th, omit 3rd)
V13: G - B - (D) - F - (A) - E  (adds 13th, omit 5th, possibly 9th)
```

## Voicing Principles

**Essential and optional tones**:
```
All extended dominants MUST include:
- Root (G)
- Seventh (F)

The extension itself is usually present
Other tones are negotiable depending on texture
```

**V9 voicing**:
```
Full: G - B - D - F - A
      (root - 3rd - 5th - 7th - 9th)

Four-voice: G - B - F - A  (omit 5th)
            or
            G - B - D - A  (omit 7th, less common)

Ninth (A) replaces doubled root
```

**V11 voicing**:
```
Full: G - B - D - F - A - C
      (root - 3rd - 5th - 7th - 9th - 11th)

Common voicing (omit 3rd):
G - D - F - A - C
(sounds like Dm7 over G, or IV with ^5 in bass)

The 11th conflicts with the 3rd (semitone apart)
Usually omit 3rd (B), retain 11th (C)
```

**V13 voicing**:
```
Full: G - B - D - F - A - C - E
      (all seven notes!)

Four-voice: G - B - F - E  (omit 5th, 9th, 11th)
            or
            G - B - A - E  (omit 5th, 7th, 11th)

Thirteenth (E) replaces fifth
```

## Resolution Tendencies

**Ninth resolution**:
```
V9:   G - B - F - A     →    I:   C - C - E - G
      ↓   ↓   ↓   ↓
      A → G (ninth resolves DOWN by step)
      B → C (leading tone up)
      F → E (seventh down)
```

**Eleventh resolution**:
```
V11:  G - D - F - C     →    I:   C - E - E - C
      ↓   ↓   ↓   ↓
      C → C (eleventh = COMMON TONE)
      D → E (fifth up, or to root)
      F → E (seventh down)

11th stays as ^1 of I (no motion)
```

**Thirteenth resolution**:
```
V13:  G - B - F - E     →    I:   C - C - E - C
      ↓   ↓   ↓   ↓
      E → C (thirteenth LEAPS DOWN by third to ^1)
      B → C (leading tone up)
      F → E (seventh down)

Distinctive: 13th leaps DOWN (not step motion)
```

## Musical Context

Extended dominant chords serve specific purposes:
- **Richer sonority**: More complex dominant sound
- **Post-common-practice**: Late Romantic and beyond
- **Jazz harmony**: Foundation of jazz chord vocabulary
- **Impressionism**: Debussy, Ravel extended tertian harmony
- **Resolution variety**: Different approach tones to tonic
- **Color over function**: Sonority as expressive element
- **Contemporary styles**: Film music, musical theater

## Examples

### Basic

**V9 in C major**:
```
V9:    G - B - D - F - A    (full)
       G - B - F - A        (four-voice, omit D)
       ↓   ↓   ↓   ↓
I:     C - C - E - G

A (ninth = ^6) resolves DOWN to G (^5 of I)
```

**V11 in C major**:
```
V11:   G - (B) - D - F - A - C  (full, often omit B)
       G - D - F - C            (four-voice, no 3rd)
       ↓   ↓   ↓   ↓
I:     C - E - E - C

C (eleventh = ^1) is COMMON TONE (no resolution needed)
Sounds like Dm7/G or Fmaj/G (IV/V)
```

**V13 in C major**:
```
V13:   G - B - (D) - F - (A) - E  (omit some tones)
       G - B - F - E               (four-voice)
       ↓   ↓   ↓   ↓
I:     C - C - E - C

E (thirteenth = ^3) leaps DOWN by third to C (^1)
Distinctive resolution: down by 3rd (not stepwise)
```

**Comparison of all extended dominants**:
```
V7:    G - B - D - F     →  C - C - E - G
V9:    G - B - F - A     →  C - C - E - G    (9th down by step)
V11:   G - D - F - C     →  C - E - E - C    (11th = common tone)
V13:   G - B - F - E     →  C - C - E - C    (13th down by 3rd)
```

### From Repertoire

**Debussy, Prélude à l'après-midi d'un faune**: Extended tertian harmonies blur dominant function.

**Ravel, piano works**: Stacked thirds create complex dominant sonorities.

**Jazz standards**: V9, V11, V13 are standard jazz chord types with specific voicing conventions.

**Musical theater (Rodgers, Sondheim)**: Extended dominants for sophisticated harmonic color.

**Film scores**: Extended dominants create lush, romantic textures.

**Scriabin, late works**: Extreme extensions of tertian harmony.

## Common Confusions

- Extensions are tones ABOVE the seventh (9th, 11th, 13th)
- Always include ROOT and SEVENTH in extended dominants
- V9: ninth resolves DOWN by step
- V11: eleventh is COMMON TONE (holds to ^1)
- V13: thirteenth leaps DOWN by third
- In four-voice texture, must omit some chord tones
- V11 usually omits the 3rd (conflicts with 11th)
- V11 sounds like IV with ^5 in bass (Dm7/G in C)
- V13 often omits 5th and possibly 9th or 11th
- These are DOMINANT chords (resolve to tonic)
- Different from "added-tone" chords (add2, add9)
- Fundamental to jazz harmony; less common in classical
- "Dominant 9th" is different from "major 9th" chord
- Extended dominants still have dominant function
