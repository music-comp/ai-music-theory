# Quick Definition

A pedal tone is a sustained or repeated note (usually in the bass) that remains static while the chords above it change, creating a series of consonances and dissonances against the held note.

# Core Definition

**Pedal tones** (PED) are often found in the bass and consist of a series of static notes below chord changes that do not include the bass (OMT, Ch. IV.4). They are labeled using the scale degree number of the pedal note. Pedal tones belong to Category 3 (embellishing tones involving static notes).

# Prerequisites

- **Embellishing tone** — Pedal tone is one specific type of embellishing tone

# Key Properties

1. Static (sustained or repeated) note, usually in the bass
2. Chords above change while the pedal remains
3. Labeled by scale degree (e.g., "tonic pedal" or "dominant pedal")
4. Creates alternating consonance and dissonance against changing harmonies
5. Often found at beginnings (tonic pedal) or endings (dominant pedal) of sections

# Construction / Recognition

## To Identify:
1. Find a bass note that remains static while upper-voice harmonies change
2. Confirm that the static note does not always belong to the changing chords
3. Label with the scale degree of the pedal note

# Context & Application

- **Typical contexts**: Introductions, codas, development sections

# Common Confusions

- **Confusion**: Thinking the pedal tone must always be dissonant
  **Clarification**: The pedal alternates between consonance (when it belongs to the chord) and dissonance (when it does not)
