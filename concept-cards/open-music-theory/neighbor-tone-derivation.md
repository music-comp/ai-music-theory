# Neighbor-Tone Derivation of Common-Tone Chords

## Quick Definition
Common-tone chords (CT°7 and CT+6) are derived from the simultaneous sounding of multiple neighbor tones against one held common tone, where each non-common voice creates chromatic neighbor motion around a chord tone of the embellished harmony, resulting in a diminished seventh or augmented sixth sonority that functions as embellishment rather than progression.

## Formal Definition
**Neighbor-tone derivation** explains common-tone chords as:

**Simultaneous neighbors**: Multiple voices create neighbor motion at once

**Common tone**: One voice sustains (usually the root)

**Chromatic neighbors**: Other voices move by half step away and back

**Resulting sonority**: °7 or +6 chord emerges from combined neighbors

**Function**: Embellishment of static harmony (not functional progression)

## Single Neighbor Tone Review

**Basic neighbor motion**:
```
Chord tone -> Neighbor -> Chord tone

Upper neighbor:
C -> D -> C (step up, step back)

Lower neighbor:
C -> B -> C (step down, step back)

Chromatic neighbors (half step):
C -> C# -> C (chromatic upper)
C -> Cb -> C (chromatic lower)
```

## Multiple Simultaneous Neighbors

**Two neighbors at once**:
```
C major triad: C - E - G

Two voices move:
C -> C (holds)
E -> Eb -> E (chromatic lower neighbor)
G -> G# -> G (chromatic upper neighbor)

Creates chromatic embellishment
```

**Three neighbors (one common tone)**:
```
C major triad: C - E - G - C (four voices)

One holds, three move:
C -> C (COMMON TONE)
E -> Eb -> E (chromatic lower)
G -> Gb -> G (chromatic lower)
C -> A -> C (moving down)

The three moving voices create °7 chord!
C - Eb - Gb - A = C°7 (or respelled)
```

## Deriving CT°7

**From C major triad**:
```
Start:     C - E - G - C
           (root) (3rd) (5th) (root)

Apply chromatic neighbors:
C:  hold (common tone)
E:  Eb (lower chromatic neighbor)
G:  Gb (lower chromatic neighbor)  
C:  A (enharmonic Bbb, neighbor of C)

Middle:    C - Eb - Gb - A
           = fully diminished seventh sonority

Return:    C - E - G - C

The °7 chord emerges from neighbor motion!
```

**Identifying the common tone**:
```
CT°7 on C: C - Eb - Gb - A
           ↑
           C is the common tone
           
The chord is named by its common tone
CT°7 on C embellishes C major (or C chord)
```

## Deriving CT+6

**From C major triad (more chromatic)**:
```
Start:     C - E - G - C
           (root) (3rd) (5th) (root)

Apply neighbors (all chromatic):
C:  hold (common tone)
E:  Eb (lower chromatic neighbor, half step)
G:  F# (lower chromatic neighbor, half step)
    and Ab (upper chromatic neighbor, half step)

Middle:    C - Eb - F# - Ab
           = German sixth sonority (CT+6)

Return:    C - E - G - C

Three chromatic neighbors (Eb, F#, Ab)
Creates "darker" sound than CT°7
```

**Why "augmented sixth"**:
```
CT+6: C - Eb - F# - Ab

Interval Ab to F# = augmented sixth
Same interval structure as Ger+6
Hence the name CT+6
```

## Comparison of Derivations

**CT°7 neighbors**:
```
From C major:
C: common
E: Eb (chromatic lower, half step)
G: Gb (chromatic lower, half step)
C: A or Bbb (neighbor motion)

Two clearly chromatic half-step neighbors
```

**CT+6 neighbors**:
```
From C major:
C: common
E: Eb (chromatic lower, half step)
G: F# AND Ab (both chromatic neighbors to G)

All three non-common tones are chromatic
"Darker" because more chromatically altered
```

## Incomplete Neighbor Patterns

**Not all voices need return**:
```
Full neighbor: C - Eb - Gb - A - C - E - G - C
               (start)  (CT°7)  (return)

Incomplete: C - Eb - Gb - A - C - E - G - B
            (start)  (CT°7)  (different voicing)

Some voices may not complete the neighbor motion
Still functions as embellishment
```

**Flexible voice leading**:
```
The embellishing chord doesn't require:
- Exact return to starting pitches
- All voices to move as neighbors
- Strict voice-for-voice correspondence

As long as:
- Common tone present
- Neighbor motion implied
- Function is embellishment
```

## Musical Context

Understanding neighbor-tone derivation:
- **Explains the chord**: CT chords aren't random, but neighbor-tone clusters
- **Voice leading logic**: Each voice has melodic purpose (neighbor motion)
- **Common tone anchor**: One voice provides stability
- **Prolongation function**: Extends single harmony through embellishment
- **Romantic idiom**: Systematized in 19th-century harmony
- **Compositional tool**: Composers think in neighbor motion

## Examples

### Basic

**CT°7 from neighbor tones**:
```
C major:  C - E - G - C
          |   |   |   |
CT°7:     C - Eb- Gb- A    (neighbors sound)
          |   |   |   |
C major:  C - E - G - C    (neighbors resolve)

C = common tone (holds through)
Eb, Gb, A = neighbor tones to E, G, C
```

**CT+6 from neighbor tones**:
```
C major:  C - E - G - C
          |   |   |   |
CT+6:     C - Eb- F#- Ab   (neighbors sound)
          |   |   |   |
C major:  C - E - G - C    (neighbors resolve)

C = common tone
Eb, F#, Ab = three chromatic neighbors
```

**Dominant embellishment**:
```
V (G major):  G - B - D - G
              |   |   |   |
CT°7:         G - Bb- Db- E  (neighbors)
              |   |   |   |
V (G major):  G - B - D - G

G = common tone
Bb, Db, E = neighbors to B, D, G
Prolongs dominant
```

### From Repertoire

**Chopin, Nocturnes**: Clear neighbor-tone motion in CT°7 passages, pedagogical examples.

**Brahms, Intermezzi**: CT+6 with identifiable neighbor derivation.

**Schubert, Lieder**: Neighbor-tone embellishments creating CT chords.

**Romantic period generally**: Understanding of CT chords as neighbor-tone conglomerates.

## Common Confusions

- CT chords derive from simultaneous neighbor tones
- **One voice holds** (common tone) while others move
- CT°7: Two or three chromatic neighbors create °7 sonority
- CT+6: Three chromatic neighbors create +6 (Ger6) sonority
- The common tone is usually the ROOT of the embellished chord
- Neighbors move by half step (chromatic) or whole step
- CT+6 is "darker" because ALL three neighbors are chromatic
- CT°7 may have one diatonic-seeming neighbor
- **Not functional chords**: They are embellishments
- Return to original chord (complete neighbor pattern)
- Incomplete neighbors possible (flexible voice leading)
- Understanding derivation clarifies function
- Romantic composers thought in neighbor-tone patterns
