# Quick Definition
A Forte number is an alternative catalog label for a set class in the format X-Y, where X is the cardinality (number of pitch classes) and Y is the position in Allen Forte's ordered list. For example, 3-11 is the Forte number for set class (037), which includes all major and minor triads.

# Core Definition
The Forte numbering system, developed by Allen Forte, provides a standardized catalog of all possible set classes. Each Forte number takes the form X-Y: X is the cardinality (how many pitch classes the set contains, from 0 to 12) and Y is the ordinal position within Forte's listing of all set classes of that cardinality. The numbers are arbitrary catalog positions, not mathematically derived. The set class table pairs Forte numbers with prime forms, interval vectors, and complement relationships. Set classes are also paired by complement: the set which, together with the original, completes the twelve-tone aggregate.

# Prerequisites
- Set class and prime form (understanding what is being catalogued)

# Key Properties
1. Format: X-Y where X = cardinality, Y = catalog position
2. Arbitrary ordering within each cardinality group
3. 220 total set classes in the complete catalog
4. Complements are paired in the table (a set and its complement add to 12 pcs)
5. Available on Wikipedia and many theory resources
6. Alternative to prime form as a set class label

# Context & Application
Forte numbers provide a shorthand for referencing set classes in analytical writing. While prime form is descriptive (you can read the intervals), Forte numbers are more compact and widely recognized in the literature. Both naming systems are in common use.

# Examples
**Example 1**: 3-11 = set class (037) = major and minor triads.
**Example 2**: 3-1 = set class (012) = chromatic trichord.
**Example 3**: 6-1 = set class (012345) = chromatic hexachord, used in Webern's Symphonie Op. 21.

# Common Confusions
- **Confusion**: 3-3 means "three of something"
  **Clarification**: It means the third set class in the list of trichords (3-note sets)
- **Confusion**: Forte numbers encode interval content
  **Clarification**: The Y number is an arbitrary catalog position; use the interval vector for interval content
