# Forte Number

## Quick Definition

A Forte number is a catalog designation for set classes, developed by theorist Allen Forte. It consists of two numbers separated by a hyphen: the first indicates cardinality (number of pitch classes), and the second indicates position in Forte's ordered list. For example, 3-11 is the eleventh trichord in Forte's catalog (the major/minor triad set class).

## Formal Definition

**Forte number**: A naming system for set classes in the format X-Y, where:
- **X** = cardinality (number of pitch classes: 3-9)
- **Y** = ordinal position in Forte's catalog for that cardinality

**Catalog organization** (Forte 1973):
- Sets are ordered primarily by interval vector
- Sets with smaller intervals appearing first in the vector come earlier
- Z-related pairs are indicated with "Z" (e.g., 4-Z15, 4-Z29)

**Examples**:
- 3-1 = (012), the chromatic trichord
- 3-11 = (037), the major/minor triad
- 4-27 = (0258), the major-minor seventh chord set class
- 5-35 = (02479), the pentatonic/diatonic set class
- 6-35 = (02468T), the whole-tone collection

**Cardinalities in Forte's list**:
- 3: 12 set classes (3-1 through 3-12)
- 4: 29 set classes (4-1 through 4-29, including Z-pairs)
- 5: 38 set classes
- 6: 50 set classes (most Z-pairs occur here)
- 7-9: complementary to 5-3

## Musical Context

Forte numbers serve as a **shorthand reference system** for set classes, particularly useful for:

1. **Looking up information**: Tables list properties (interval vector, prime form) by Forte number
2. **Citation in analysis**: "The passage emphasizes set class 3-3" is concise
3. **Cross-reference**: Scores and analyses can use the same numbering

**Limitations**:
- Numbers are arbitrary (3-3 isn't "three of something")
- Must memorize or look up the correspondence to prime forms
- Some theorists prefer prime-form labels as more musically transparent

**Alternative conventions**: Some sources use different orderings or notations. Wikipedia and recent textbooks often list both Forte numbers and prime forms.

### From Repertoire

**Schoenberg, Pierrot lunaire, "Nacht"**: The analysis can be described using Forte numbers: "The movement is built on transformations of 3-3"--immediately telling readers that set class (014) is central.

**Webern, Concerto Op. 24**: "The row derives from 3-3 manipulations" concisely describes the trichordal basis of the twelve-tone structure.

**Jazz harmony**: Forte numbers can describe characteristic chord types: "4-27 as the dominant seventh class; 4-26 as the minor seventh class."

## Common Confusions

- **Numbers are arbitrary catalog positions**: 3-11 doesn't mean "eleventh of something" in any musical sense
- **Must look up correspondence**: 3-11 = (037) requires reference unless memorized
- **Different editions may differ**: Some catalogs have minor variations
- **Z numbers indicate Z-relation**: 4-Z15 pairs with 4-Z29; both have identical interval vectors
- **Complementary sets have related numbers**: Sets of cardinality n and 12-n are complements
- **Prime form is often clearer**: (037) tells you more directly than 3-11
- **Zero-indexing**: Forte starts with 1, so there's no X-0
