# Raised-Root Elision

## Quick Definition
Raised-root elision is a type of harmonic elision in which the root of an expected chord is raised by half step to become a leading tone (or applied leading tone), replacing the expected chord with a dominant-function chord that pushes the harmonic progression higher up the scale to an unexpected tonal target.

## Formal Definition
**Raised-root elision** occurs when:

**Expected root is raised**: The anticipated chord's root moves up by half step

**Root becomes leading tone**: The raised note functions as ^7 or applied ^#X

**New chord emerges**: V, V7, or vii°7 of the new target (one step higher)

**Progression pushed up**: The harmonic motion moves to higher scale degree

**Function**: Redirects tonal motion upward

## Mechanism

**Normal resolution**:
```
V7  ->  I
       (Root = C)

In C major:
G7 -> C major (expected tonic)
```

**With raised-root elision**:
```
V7  ->  V7/ii (expected I elided)
       (Expected root C -> C# = leading tone to D)

In C major:
G7 -> A7 (going to D, not C!)

C (expected) became C# (leading tone to D)
```

**Voice leading**:
```
Expected:           Raised-root elision:
G -> G or C         G -> G or A
B -> C              B -> C# (!)
D -> C or E         D -> E or C#
F -> E              F -> E or G

The expected C becomes C# (raised root)
```

## Possible Resulting Chords

**When expected root is raised**:
```
Expected root: C (I in C major)
Raised root: C# (leading tone to D)

Possible replacement chords:
- A major: A-C#-E = V of D (ii in C)
- A7: A-C#-E-G = V7 of D
- C#°: C#-E-G = vii° of D
- C#°7: C#-E-G-Bb = vii°7 of D
- C#ø7: C#-E-G-B = viiø7 of D (rare)
```

**Most common**: V7 of the new target

## Bass Note Behavior

**Bass moves up by half step**:
```
Expected bass: C (root of I)
Actual bass: C# (as part of V/ii chord)

OR

Bass becomes new dominant root:
Expected bass: C
Actual bass: A (root of V/ii = A major)
```

**"Close to expected bass"**:
```
The new chord's bass should be near expected bass
Creates sense of overlapping/similarity

Expected I: C-E-G (C in bass)
V/ii: A-C#-E (A in bass, close to C)
or
vii°/ii: C#-E-G (C# in bass, very close to C!)
```

## Common Progressions

**V -> V/ii instead of V -> I**:
```
In C major:
Expected: G7 -> C (authentic cadence)
Actual:   G7 -> A7 (raised-root elision)
                ↓
              D minor (ii)

C (expected root) -> C# (in A7)
Progression moves to ii instead of I
```

**Sequence building**:
```
I - V/ii - ii - V/iii - iii - ...

Each time expected resolution is elided:
I:   C-E-G expected after V
     Replaced by V/ii (A7), goes to ii

ii:  D-F-A expected after V/ii
     Replaced by V/iii (B7?), goes to iii

Creates ascending sequence
```

## Recognizing in Analysis

**Clues**:
```
1. Dominant chord doesn't resolve to expected target
2. Next chord has root a half step above expected
3. New chord is V or vii of something
4. The expected bass note is "raised"
```

**Roman numeral patterns**:
```
V -> V/ii (raised-root elision, expected I)
V/IV -> V/V (raised-root elision, expected IV)
V/vi -> V/vii (raised-root elision, expected vi)

Pattern: V/X -> V/X+1 (moves up scale)
```

**Bass motion trace**:
```
Look for:
Expected C -> actual C# (half step UP)
Or A (new dominant root) close to C

The half-step UP motion is the signature
```

## Comparison with Leading-Tone Elision

| Feature | Leading-Tone Elision | Raised-Root Elision |
|---------|---------------------|---------------------|
| Motion | Leading tone DOWN | Root UP |
| Direction | ^7 -> ^b7 | Root -> raised version |
| Effect | New dominant of lower target | New dominant of higher target |
| Scale motion | Pushes DOWN | Pushes UP |
| Signature | Half step down | Half step up |

**Combined example**:
```
Leading-tone: V6/5 -> V4/2/IV (B -> Bb, goes lower)
Raised-root:  V -> V/ii (C -> C#, goes higher)

Opposite directions!
```

## Musical Effect

**Upward push**:
```
Expected resolution to tonic
Instead, motion continues UPWARD
Creates sense of "rising tension"
```

**Surprise and extension**:
```
Listener expects arrival
Instead, new dominant appears
Harmonic journey continues
But now moving UP the scale
```

**Ascending sequences**:
```
With raised-root elision:
i -> V/ii -> ii -> V/iii -> iii -> ...

Creates ascending chromatic patterns
Each chord leads to higher target
```

## Musical Context

Raised-root elision serves specific purposes:
- **Ascending motion**: Pushes progression higher
- **Extends journey**: Delays final resolution
- **Chromatic color**: Introduces raised accidentals
- **Sequence building**: Generates ascending patterns
- **Development technique**: Creates harmonic intensification
- **Surprise effect**: Unexpected upward turn
- **Romantic harmony**: Common in 19th-century music

## Examples

### Basic

**Simple raised-root elision**:
```
In C major:
V7:       G-B-D-F
Expected: C-E-G (I)
Actual:   A-C#-E-G (V7/ii)

Expected C root -> C# (in A7)
Expected I -> V7/ii
Progression goes to D minor (ii) instead
```

**With vii°7**:
```
In C major:
V7:       G-B-D-F
Expected: C-E-G (I)
Actual:   C#-E-G-Bb (vii°7/ii)

Expected root C -> C# in bass!
Very close bass note (C vs C#)
Strong sense of elision
```

**In sequence**:
```
I - V7/ii - ii - V7/iii - iii - V7/IV - IV

Each time, expected resolution is elided:
After V7/ii: expected ii, got V7/iii
After V7/iii: expected iii, got V7/IV

Ascending chromatic pattern
D -> D# -> E (bass could show this)
```

### From Repertoire

**Beethoven, Piano Sonatas**: Raised-root elisions create upward harmonic thrust.

**Wagner, Tristan und Isolde**: Extensive raised-root elisions extend chromaticism.

**Brahms, Symphonies**: Elisions in development sections push harmony upward.

**Chopin, Ballades**: Raised-root elisions for harmonic intensification.

**Schubert, Piano Sonatas**: Elisions create unexpected harmonic directions.

## Common Confusions

- Raised-root elision = expected root raised by half step
- Root becomes leading tone to new target
- Progression pushed UP the scale (opposite of leading-tone elision)
- **Expected root C -> C# (or whatever half step UP)**
- New chord is V, V7, or vii°7 of higher target
- V -> V/ii is common example (expected I, got V7/ii)
- **Bass should be close to expected bass**
  - Either half step higher (C -> C#)
  - Or new dominant root (C expected, A appears)
- Creates ascending harmonic sequences
- Different from leading-tone elision:
  - Leading-tone: ^7 -> ^b7 (DOWN)
  - Raised-root: Root -> raised (UP)
- Romantic period common device
- Key signature: Half-step UP motion of expected root
