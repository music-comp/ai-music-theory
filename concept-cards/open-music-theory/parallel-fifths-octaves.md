# Parallel Fifths and Octaves

## Quick Definition

A voice leading error where two voices move in parallel motion from one perfect fifth (or octave) to another perfect fifth (or octave), creating the forbidden progression P5→P5 or P8→P8 that compromises voice independence by making the two voices sound like a single reinforced line rather than independent melodic strands—one of the most fundamental prohibitions in common-practice four-part harmony writing, avoided through contrary or oblique motion and careful attention to voice leading between perfect consonances.

## Formal Definition

**Parallel fifths** occur when two voices move in parallel motion from one perfect fifth to another perfect fifth.

**Parallel octaves** occur when two voices move in parallel motion from one perfect octave to another perfect octave.

**Both are forbidden** in common-practice voice leading (SATB chorale style, species counterpoint, classical harmony exercises).

**Why forbidden?**
- Compromises voice independence
- Two voices sound like single line
- Reduces polyphonic texture to "hollow" doubling
- Violates principle of independent melodic lines

**Exception**: Parallel perfect intervals acceptable in:
- Intentional parallel organum (medieval style)
- Doubling for orchestral reinforcement
- Modern/popular music styles (different conventions)

## Types of Parallel Perfect Intervals

**Direct/Consecutive parallel fifths**:
```
Voice 1:  C → D    (interval: P5)
Voice 2:  F → G    (interval: P5, parallel motion = FORBIDDEN)

Both voices move up by whole step, maintaining P5
```

**Direct/Consecutive parallel octaves**:
```
Voice 1:  C → D    (interval: P8)
Voice 2:  C → D    (interval: P8, parallel motion = FORBIDDEN)

Both voices move in parallel octaves
```

**Parallel unisons** (also forbidden):
```
Voice 1:  C → D
Voice 2:  C → D    (same pitches, parallel unison = FORBIDDEN)

Effectively reduces texture to single voice
```

## Hidden (Direct) Fifths and Octaves

**Hidden/Direct fifths or octaves**: Similar motion to perfect interval, both voices leaping

**Generally avoided**, but less severe than parallel:
```
Voice 1:  C → G    (leap up)
Voice 2:  E → C    (leap down)
Result: Approaches octave by similar motion

Acceptable if:
- Soprano moves by step (not leap)
- Occurs in inner voices
- Musical context justifies
```

**More acceptable**:
```
Voice 1:  C → D    (step, not leap)
Voice 2:  E → G    (leap)
Result: Approaches fifth, but soprano stepwise = OK
```

## Avoiding Parallel Fifths and Octaves

**Use contrary motion**:
```
Instead of parallel:
V1: C → D (up)
V2: F → G (up, creates P5→P5)

Use contrary:
V1: C → D (up)
V2: F → E (down, avoids parallel)
```

**Use oblique motion**:
```
V1: C → C (stays)
V2: F → G (moves)

One voice static, other moves = no parallel
```

**Redistribute chord tones**:
```
Problematic:
S: G → A (creates P5→P5 with tenor)
T: C → D

Better:
S: G → F (different motion)
T: C → D
```

## Why the Rule Exists

**Historical/aesthetic reasons**:
- Perfect intervals considered "pure" and stable
- Parallel motion makes them too prominent
- Reduces independence of voices
- Common-practice ideal: independent melodic lines

**Acoustic reasons**:
- Perfect fifths have simple frequency ratios (3:2)
- Parallel motion emphasizes this acoustic relationship
- Voices blend rather than remaining distinct

**Pedagogical reasons**:
- Teaches careful voice leading
- Develops awareness of voice independence
- Foundation for contrapuntal writing

## Exceptions and Context

**Acceptable parallel perfect intervals**:
- **Orchestral doubling**: Instrumental sections doubled at octave
- **Medieval organum**: Intentional parallel fifths/fourths
- **Popular/rock music**: Different voice leading conventions
- **Consecutive fifths by contrary motion**: Not actually parallel (e.g., P5 up while other P5 down)

**Modern music**: Rules relaxed or ignored entirely depending on style

## Musical Context

Avoiding parallel fifths and octaves:
- **Essential pedagogy**: Core skill in chorale writing
- **Voice independence**: Maintains polyphonic texture
- **Historical practice**: Reflects common-practice norms
- **Contrapuntal clarity**: Each voice remains distinct
- **Harmonic sophistication**: Requires thoughtful voice leading

Understanding and avoiding parallel perfects is fundamental to traditional harmony.

## Examples

### Basic

**Parallel fifths (FORBIDDEN)**:
```
Chord 1:  S: G,  A: C  (P5 between soprano and alto)
Chord 2:  S: A,  A: D  (P5, parallel motion = ERROR)

Both voices move up by whole step, P5 → P5
```

**Corrected (contrary motion)**:
```
Chord 1:  S: G,  A: C  (P5)
Chord 2:  S: A,  A: C  (M6, soprano up, alto stays)

No longer parallel fifths
```

**Parallel octaves (FORBIDDEN)**:
```
Chord 1:  S: C,  B: C  (P8)
Chord 2:  S: D,  B: D  (P8, parallel = ERROR)

Soprano and bass in parallel octaves
```

**Hidden fifths** (acceptable with care):
```
Chord 1:  S: C,  B: E
Chord 2:  S: D,  B: G  (approaches P5)

Soprano stepwise (C→D) = acceptable
If soprano leaped (C→A), would be problematic
```

**Consecutive fifths by contrary motion** (OK):
```
Voice 1:  C → G  (P5 up)
Voice 2:  F → C  (P5 down)

Not parallel (contrary motion), acceptable
```

### From Repertoire

**Bach, Chorales**: Meticulous avoidance of parallel fifths and octaves, demonstrates proper voice leading principles, pedagogical models.

**Mozart, String Quartets**: Clean voice leading avoiding parallels, shows principles in instrumental writing.

**Palestrina, Masses**: Renaissance counterpoint avoids parallel fifths (though parallel thirds/sixths common), emphasizes voice independence.

**Negative examples** (intentional parallels for effect):
- **Debussy**: Uses parallel perfect intervals intentionally for coloristic effect (breaks traditional rules)
- **Medieval organum**: Intentional parallel fifths/fourths (pre-common-practice)

## Common Confusions

- Parallel fifths = two voices moving P5→P5 in same direction (forbidden)
- Parallel octaves = two voices moving P8→P8 in same direction (forbidden)
- Parallel unisons also forbidden (reduces texture to single voice)
- Hidden/direct fifths = similar motion to P5/P8 (less severe, sometimes OK)
- Consecutive fifths by contrary motion = OK (not actually parallel)
- Parallel thirds and sixths = ALLOWED (imperfect intervals)
- Rule applies to common-practice period (not all musical styles)
- Orchestral doubling at octave acceptable (different context from voice leading)
- Modern/popular music often ignores rule (different aesthetic)
- Parallel perfects forbidden in SATB chorale writing (pedagogical standard)
- "Why?" = compromises voice independence, acoustic prominence
- Hidden fifths acceptable if soprano moves stepwise
- Parallel motion OK for imperfect consonances (M3, m3, M6, m6)
- Rule teaches careful voice leading and voice independence
- Medieval organum intentionally uses parallels (historical exception)
- Parallel fourths treated differently (sometimes OK, context-dependent)
