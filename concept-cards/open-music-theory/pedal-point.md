# Pedal Point

## Quick Definition

A sustained or repeated note (usually in the bass) held through changing harmonies above it, where the pedal note alternates between being a chord tone and a non-chord tone as harmonies shift—named after organ pedal tones that can be held indefinitely, most commonly on the tonic (^1) or dominant (^5) scale degrees, creating harmonic tension when dissonant against upper voices while maintaining a stable reference pitch, typically appearing at beginnings (tonic pedal establishes key) or endings (dominant pedal prolongs tension before final resolution), and adding dramatic intensity through sustained bass against changing harmony.

## Formal Definition

**Pedal point** (or **pedal tone**, **pedal**) is a sustained or repeated pitch (usually in the bass) maintained through changing harmonies.

**Characteristics**:
- **Sustained pitch**: Held or repeated throughout passage
- **Changing harmony**: Chords change above pedal
- **Alternating function**: Pedal is sometimes chord tone, sometimes non-chord tone
- **Usually bass**: Most common in lowest voice (but can be in other voices)
- **Common scale degrees**: ^1 (tonic pedal) or ^5 (dominant pedal)
- **Structural function**: Prolongs single harmony or creates tension

**Types**:
- **Tonic pedal**: On ^1 (C in C major)
- **Dominant pedal**: On ^5 (G in C major)
- **Inverted pedal**: In upper voice instead of bass
- **Internal pedal**: In middle voice
- **Double pedal**: Two notes sustained simultaneously

## Common Pedal Types

**Tonic pedal** (on ^1):
```
Bass: C -------- C -------- C
      (sustained or repeated)

Harmony above changes:
I - IV - V - I
C   F    G   C

C in bass throughout
Establishes/confirms key
Common at openings
```

**Dominant pedal** (on ^5):
```
Bass: G -------- G -------- G
      (sustained)

Harmony above changes:
V - I⁶₄ - V - V⁷
G   C/G   G   G⁷

G in bass throughout
Creates tension before resolution
Common before final cadences
```

## Pedal Function

**Creates harmonic tension**:
```
Bass: C (pedal)

Above: C-E-G → F-A-C → G-B-D → C-E-G
       I       IV      V       I
       CT      NCT     NCT     CT

Pedal is chord tone in I (consonant)
Non-chord tone in IV and V (dissonant)
Returns to chord tone in I (resolution)
```

**Pattern**: Often Consonant → Dissonant → Consonant

## Voice Leading

**Standard tonic pedal**:
```
        I       ii      V       I
S:      G   →   A   →   B   →   C
A:      E   →   F   →   D   →   E
T:      C   →   D   →   G   →   G
B:      C -------- C -------- C (PEDAL)

Bass sustains C throughout
Upper voices move freely
Pedal alternates: CT, NCT, NCT, CT
```

**Standard dominant pedal**:
```
        V       I⁶₄     V⁷      I
S:      D   →   E   →   F   →   E
A:      B   →   C   →   D   →   C
T:      G   →   G   →   B   →   G
B:      G -------- G -------- G (PEDAL)

Bass sustains G (dominant)
I⁶₄ over dominant pedal creates tension
Resolves through V⁷ to I
```

## Inverted and Internal Pedals

**Inverted pedal** (soprano):
```
S:      C -------- C -------- C (PEDAL in soprano)
A:      E   →   F   →   D   →   E
T:      G   →   A   →   B   →   G
B:      C   →   F   →   G   →   C

Pedal in highest voice
Less common than bass pedal
Creates different effect
```

**Internal pedal** (alto or tenor):
```
S:      G   →   A   →   B   →   C
A:      E -------- E -------- E (PEDAL in alto)
T:      C   →   F   →   D   →   G
B:      C   →   F   →   G   →   C

Pedal in middle voice
Embedded in texture
Subtle effect
```

**Double pedal**:
```
S:      G -------- G -------- G (PEDAL)
A:      E   →   F   →   D   →   E
T:      C   →   A   →   B   →   C
B:      C -------- C -------- C (PEDAL)

Both outer voices pedal
Very stable or very tense (depending on harmony)
Dramatic effect
```

## Musical Context

Pedal points serve specific purposes:
- **Stability/grounding**: Sustains reference pitch through changes
- **Tension building**: Creates dissonance against changing harmony
- **Key establishment**: Tonic pedal confirms tonal center
- **Dramatic preparation**: Dominant pedal before climax
- **Formal articulation**: Marks structural boundaries
- **Organ association**: Named after organ pedal keyboard
- **Common at beginnings/endings**: Frames compositions
- **Prolongation**: Extends single harmony over time

Essential device for creating drama and structural clarity.

## Examples

### Basic

**Tonic pedal at opening** (C major):
```
Bass: C -------- C -------- C -------- C
      (sustained)

Harmony:
      I       vi      IV      V
      C-E-G   A-C-E   F-A-C   G-B-D

C is chord tone in I (consonant)
C is non-chord tone in vi, IV, V (dissonant)
Establishes C as tonic
```

**Dominant pedal before cadence**:
```
Bass: G -------- G -------- G
      (sustained)

Harmony:
      V       I⁶₄     V⁷
      G-B-D   G-C-E   G-B-D-F

G sustained throughout
I⁶₄ creates special dissonance over G
Builds tension before resolution to I
```

**Inverted tonic pedal** (soprano):
```
Soprano: C -------- C -------- C
         (sustained)

Harmony below:
         I    V⁶   I   IV   I
         
C sustained in melody
Harmonies change beneath
Different effect than bass pedal
```

**Short dominant pedal**:
```
mm. 7-8 (cadential approach):
Bass: G --- G --- G --- G
      (one measure)

Above: V - I⁶₄ - V⁷ - I

Brief dominant pedal intensifies cadence
```

### From Repertoire

**Bach, Organ works**: Extensive pedal points (literal organ pedal), tonic pedals in preludes establish key, dominant pedals build tension in fugal episodes.

**Beethoven, Symphony No. 9, IV**: Famous dominant pedal before "Ode to Joy" theme, creates enormous tension and anticipation.

**Bach, "Little" Fugue in G minor**: Pedal points mark structural articulations, dominant pedal before final cadence.

**Romantic organ music** (Franck, Widor): Long pedal tones exploit organ's sustaining capacity, creates harmonic richness and drama.

**Mozart, "Dies Irae" (Requiem)**: Opening tonic pedal establishes d minor, creates ominous, grounded effect.

**Wagner, operas**: Pedal points create sustained tension, dominant pedals before climactic moments.

## Common Confusions

- Pedal point = sustained or repeated note through changing harmonies
- Usually in **bass** (but can be inverted or internal)
- Named after organ pedal keyboard (can sustain indefinitely)
- Alternates between chord tone and non-chord tone
- Pattern often: Consonant → Dissonant → Consonant
- **Tonic pedal** (^1): Establishes/confirms key, common at openings
- **Dominant pedal** (^5): Creates tension, common before cadences
- **Inverted pedal**: In soprano or upper voice (not bass)
- **Internal pedal**: In middle voice (alto/tenor)
- **Double pedal**: Two notes sustained simultaneously
- Different from suspension (suspension prepares, suspends, resolves in one voice)
- Different from ostinato (ostinato is melodic/rhythmic pattern, pedal is single pitch)
- Can last multiple measures (or even full sections)
- Creates harmonic tension when dissonant against changing chords
- I⁶₄ over dominant pedal common (cadential preparation)
- Organ works feature literal pedal tones (bass pedal keyboard)
- Not always fully sustained (can be repeated/rearticulated)
- Structural device (marks formal boundaries, prolongs harmony)
- Dramatic effect (builds tension, establishes stability)
