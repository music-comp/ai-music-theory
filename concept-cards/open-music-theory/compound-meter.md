# Quick Definition

A meter in which each beat divides into three equal parts and subdivides into six.

# Core Definition

**Compound meter** is a meter in which the beat divides into three, then further subdivides into six. Like simple meters, compound meters can be duple (2 beats), triple (3 beats), or quadruple (4 beats). In compound time signatures, the top number indicates the number of divisions (6, 9, or 12); divide by 3 to find the number of beats. The bottom number indicates the division unit (usually 8 for eighth note). The beat is always a dotted value: dotted quarter (if bottom = 8), dotted half (if bottom = 4), dotted eighth (if bottom = 16).

# Prerequisites

- **Beat**: the pulse being divided
- **Meter**: the organizational concept
- **Simple meter**: understanding the contrast helps

# Key Properties

- Beat divides into 3 (not 2 as in simple meter)
- Top number of time signature: divisions per measure (6, 9, or 12)
- Divide top number by 3 = number of beats (2, 3, or 4)
- Beat is always a dotted note value
- Counting: beats as "1, 2"; divisions as "1-la-li, 2-la-li"; subdivisions add "ta"
- 6/8: compound duple; 9/8: compound triple; 12/8: compound quadruple
- Beaming groups notes by beat (groups of 3 divisions)

# Construction / Recognition

A compound meter time signature has a top number that is a multiple of 3 (6, 9, or 12). The beat unit is always dotted.

# Context & Application

Compound meter is less common than simple meter but appears frequently in jigs, barcarolles, some waltzes, and various popular songs. The same conducting patterns (duple, triple, quadruple) apply in both simple and compound meters.

# Examples

- 6/8 (compound duple): 2 dotted-quarter beats per measure, each dividing into 3 eighth notes
- 9/8 (compound triple): 3 dotted-quarter beats per measure
- 12/8 (compound quadruple): 4 dotted-quarter beats per measure
- 6/4 (compound duple with quarter-note division): 2 dotted-half beats per measure

# Common Errors

- Interpreting the top number as beats (it is divisions; divide by 3 for beats)
- Thinking 6/8 has 6 beats (it has 2 dotted-quarter beats)

# Common Confusions

- 3/4 vs. 6/8: same total duration but different structures (3/4 = 3 quarter-note beats; 6/8 = 2 dotted-quarter beats)
- In simple meter, dotted notes cause beats to be counted in parentheses; in compound meter, dotted notes ARE the beat
