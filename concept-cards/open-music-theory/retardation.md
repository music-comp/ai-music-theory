# Quick Definition

A retardation is an embellishing tone approached by a static note and resolved upward by step, sharing the same three-stage pattern as a suspension but with upward instead of downward resolution.

# Core Definition

**Retardations** (RET) are approached by a static note and left by step *up* (OMT, Ch. IV.4). Like suspensions, retardations are always on a stronger part of the beat than the surrounding notes and follow the three-stage pattern of preparation, suspension (dissonance on strong beat), and resolution. The only difference from a suspension is the direction of resolution: upward.

# Prerequisites

- **Embellishing tone** — Retardation is one specific type of embellishing tone
- **Suspension** — Retardation is understood as the upward-resolving variant of the suspension pattern

# Key Properties

1. Approached by static note (same preparation pattern as suspension)
2. Resolved UP by step (opposite of suspension)
3. Always on a stronger part of the beat
4. Three-stage pattern: preparation, dissonance, resolution
5. Less common than suspension

# Construction / Recognition

## To Identify:
1. Find a non-chord tone on a strong beat
2. Check: prepared by a static note consonant in the previous chord?
3. Check: resolves UP by step?
4. If yes: retardation (if it resolved down, it would be a suspension)

# Context & Application

- **Typical contexts**: Cadences where ^7 holds and resolves up to ^1
- **Historical/stylistic notes**: Source illustrates alongside suspensions in Boulogne's String Quartet No. 4.

# Relationships

## Builds Upon
- **Suspension** — Retardation is the upward-resolving counterpart

## Contrasts With
- **Suspension** — Suspension resolves down; retardation resolves up

# Common Errors

- **Error**: Labeling a downward-resolving pattern as a retardation
  **Correction**: Downward resolution = suspension; upward resolution = retardation

# Common Confusions

- **Confusion**: Thinking retardation and suspension are the same thing
  **Clarification**: The sole difference is resolution direction: suspension = down, retardation = up
