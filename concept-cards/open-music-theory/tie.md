# Quick Definition

A curved line connecting two or more notes of the same pitch, combining their durations so that the tied-to notes are not rearticulated.

# Core Definition

A **tie** is a curved line connecting two or more notes of the same pitch. The tied-to notes are not rearticulated -- the first note is held for the combined duration of all tied notes. Ties can extend notes across bar lines (where dots cannot), clarify metrical structure within a measure, and create durations that cannot be expressed with a single note value or dotted note.

# Prerequisites

- **Note**: the symbols being connected
- **Note values**: the durations being combined

# Key Properties

- Connects notes of the SAME pitch only
- Tied-to notes are not rearticulated (first note is sustained)
- Can cross bar lines (unlike dots)
- Can clarify beat structure within a measure
- Looks like a slur but connects same pitches (slurs connect different pitches)

# Construction / Recognition

A tie is a curved line connecting two noteheads of the same pitch. It looks identical to a slur; the difference is that ties connect same pitches while slurs connect different pitches.

# Context & Application

Ties are used to extend notes across bar lines, to create durations that cannot be expressed as a single note value, and to clarify the metrical structure. For example, an eighth note tied to a sixteenth note within a beat makes the beat boundary visible, whereas a dotted eighth note might obscure it.

# Examples

- Half note tied to quarter note = 3 quarter-note beats (same as dotted half)
- Quarter note tied across a bar line = note sustained into the next measure
- Breaking a long note into tied shorter notes to show beat boundaries

# Relationships

- **Leads to**: syncopation
- **See also**: dot, note-values, slur (articulation)

# Common Errors

- Rearticulating a tied note (it should be held, not struck again)
- Confusing tie with slur

# Common Confusions

- Tie vs. slur: ties connect SAME pitches (combining duration); slurs connect DIFFERENT pitches (legato articulation)
- A dot can often replace a tie within a beat, but ties are needed across bar lines
