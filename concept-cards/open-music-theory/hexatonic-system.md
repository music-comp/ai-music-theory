# Hexatonic System

## Quick Definition

One of four collections of six triads (three major and three minor) generated by the PL cycle, named for the six-note hexatonic scale that emerges from combining all pitches of the constituent triads; each system contains triads whose major roots form an augmented triad (major thirds apart), creating a self-contained harmonic world where all triads connect via smooth voice-leading (P and L transformations) and the two poles of each system (the hexatonic poles, connected by H transformation) share no common tones.

## Formal Definition

**Hexatonic system** structure:

**Generated by PL cycle**:
```
C -P→ Cm -L→ Ab -P→ Abm -L→ E -P→ Em -L→ C

Six triads: C, Cm, Ab, Abm, E, Em
```

**Three major triads** (roots form augmented triad):
- C, E, Ab (= C+)
- Roots are major thirds apart

**Three minor triads** (relative minors of above):
- Cm, Em, Abm

**Hexatonic scale** (combining all pitches):
```
C, Cm, Ab, Abm, E, Em contain:
C, E, G (C major)
C, Eb, G (C minor)
Ab, C, Eb (Ab major)
Ab, Cb/B, Eb (Ab minor)
E, G#, B (E major)
E, G, B (E minor)

Combined pitches: C, Eb/D#, E, G, Ab/G#, B
Hexatonic scale: C - D#/Eb - E - G - G#/Ab - B - (C)
                (m3)   (m2)   (m3)  (m2)    (m3)  (m2)
Alternating minor thirds and minor seconds
```

**Four hexatonic systems**:
```
System 1 (Northern): C, Cm, Ab, Abm, E, Em
System 2 (Southern): Db, Dbm, A, Am, F, Fm
System 3 (Eastern):  D, Dm, Bb, Bbm, F#/Gb, F#m/Gbm
System 4 (Western):  Eb, Ebm, B, Bm, G, Gm
```

## Hexatonic Poles

**The H transformation**:
```
Within each hexatonic system, two triads are "poles":
- Maximum distance (3 half-step moves apart)
- NO common tones between them

System 1 poles:
C major (C-E-G) ←→ Ab minor (Ab-Cb-Eb)
E major (E-G#-B) ←→ Cm minor (C-Eb-G)
Ab major (Ab-C-Eb) ←→ Em minor (E-G-B)

Each major triad has a polar minor triad
H connects them (PLP = H)
```

**Hexatonic pole relationships**:
```
In System 1:
C ←H→ Abm (no common tones)
E ←H→ Cm (no common tones)
Ab ←H→ Em (no common tones)

The H transformation creates maximum contrast
within a self-contained harmonic world
```

## Harmonic Properties

**Self-contained voice-leading**:
- All six triads connect via P and L only
- No need to leave the system for smooth progressions
- Creates distinctive "hexatonic sound"

**Symmetry**:
- Three major and three minor triads
- Major roots form augmented triad
- Scale is symmetrical (alternating m3, m2)

**Tonal ambiguity**:
- No single triad is "tonic"
- All triads equally weighted
- Creates floating, non-functional sound

## Musical Context

Hexatonic systems appear in specific contexts:
- **Late Romantic**: Brahms, Wagner, Liszt, Wolf
- **Film music**: Self-contained harmonic worlds for scenes
- **Maximally smooth**: All progressions are parsimonious
- **Otherworldly effect**: Non-functional, floating quality
- **Analysis tool**: Identify hexatonic passages in repertoire
- **Composition tool**: Generate smooth progressions within a system
- **Cube Dance**: Each hexatonic system = one cube

## Examples

### Basic

**Complete hexatonic system 1**:
```
Triads: C, Cm, Ab, Abm, E, Em

PL cycle path:
C -P→ Cm -L→ Ab -P→ Abm -L→ E -P→ Em -L→ C

All voice-leading involves only half steps
Smooth transitions throughout the system
```

**Hexatonic scale derived**:
```
C major:  C - E - G
C minor:  C - Eb - G  
Ab major: Ab - C - Eb
Ab minor: Ab - Cb - Eb
E major:  E - G# - B
E minor:  E - G - B

Pitches: C, Eb, E, G, Ab, B
Scale: C - Eb - E - G - Ab - B - C
       (m3) (m2) (m3) (m2) (m3) (m2)
```

**Hexatonic poles in action**:
```
C major (C-E-G) to Ab minor (Ab-Cb-Eb)

No common tones!
C → Cb (down)
E → Eb (down)
G → Ab (up)

All three voices move by half step
Maximum transformation within the system
Dramatic contrast while staying hexatonic
```

**Using a hexatonic system**:
```
Film score technique:
Stay within System 1 for a scene:
C → Em → E → Abm → Ab → Cm → C → ...

Each transition is smooth (P or L)
Creates a distinctive, self-contained sound world
No functional relationships (no V-I)
Perfect for magical, mysterious, or otherworldly scenes
```

### From Repertoire

**Brahms, Violin/Cello Concerto, mm. 270-76**: Complete traversal of one hexatonic system via PL cycle.

**Wagner, Parsifal, Grail scenes**: Hexatonic progressions create ethereal, sacred atmosphere.

**John Williams, film scores**: Hexatonic systems used for wonder and magic (E.T., Close Encounters).

**Schubert, "Der Atlas"**: Early example of hexatonic-system thinking.

## Common Confusions

- Hexatonic system = 6 triads generated by PL cycle (NOT the scale)
- Hexatonic scale = the 6-note scale formed by combining those triads' pitches
- Four hexatonic systems exist (one for each augmented triad of major roots)
- System 1: C/Ab/E (roots), System 2: Db/A/F, etc.
- Each system has 3 major + 3 minor triads
- Major roots form an augmented triad
- All triads connect via P and L (smooth voice-leading)
- Hexatonic poles (H) have NO common tones
- H = PLP (three half-step moves)
- Each system is self-contained (can stay within it indefinitely)
- Creates non-functional, floating harmonic quality
- In Cube Dance, each hexatonic system = one cube
- Scale: alternating m3 and m2 (symmetrical)
- Great for film music, magical scenes, Romantic analysis
