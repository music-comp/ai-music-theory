# Enharmonic Pivot

## Quick Definition

A chord that facilitates modulation between keys through enharmonic respelling rather than through shared diatonic membership—where the same collection of pitches is notated differently to reflect a new functional interpretation, enabling sudden shifts to distant keys (particularly those related by half step or tritone) without the chromatic voice leading typical of other modulation types.

## Formal Definition

**Enharmonic pivot** is a modulation technique using enharmonic reinterpretation:

**Mechanism**:
1. Chord established with one spelling/function in original key
2. Same pitches respelled (enharmonic equivalence)
3. Respelled chord has different function in new key
4. Resolution confirms new key interpretation

**Key characteristic**: No voice movement at pivot point (pure respelling)

**Common enharmonic pivots**:
- **German +6 = V7**: Ger+6 respelled as dominant seventh
- **Diminished seventh**: Any note reinterpreted as leading tone
- **Augmented triad**: Any note reinterpreted as root

## German +6 = Dominant Seventh

**Enharmonic equivalence**:
```
Ger+6 in C: A-flat - C - E-flat - F#
V7 in D-flat: A-flat - C - E-flat - G-flat

F# = G-flat (enharmonic)
Same sound, different spelling
Different function in each key
```

**Voice leading**:
```
C major: Ger+6 (A-flat-C-E-flat-F#) →
         ↓ (respell F# as G-flat)
D-flat major: V7 (A-flat-C-E-flat-G-flat) → I (D-flat-F-A-flat)

Enables modulation: C → D-flat (up half step)
```

## Diminished Seventh Pivot

**Four possible interpretations**:
```
B-D-F-A-flat can be spelled as:
1. B°7 (vii°7 of C): B-D-F-A-flat
2. D°7 (vii°7 of E-flat): D-F-A-flat-C-flat
3. F°7 (vii°7 of G-flat): F-A-flat-C-flat-E-double-flat
4. A-flat°7 (vii°7 of A): G#-B-D-F

Four destinations related by minor third
```

**No voice movement**:
```
Same four pitches
Different spelling
Different leading tone
Resolution determines interpretation
```

## Augmented Triad Pivot

**Three possible interpretations**:
```
C-E-G# can be:
1. C+ (root C): resolves as V+ to F?
2. E+ (root E): resolves as V+ to A?
3. G#+ (root G#): resolves as V+ to C#?

Three destinations related by major third
```

**Context determines function**:
```
Voice leading (which note resolves where)
Approach (what precedes the chord)
Resolution (what follows)
```

## Keys Accessible via Enharmonic Pivot

**From German +6**:
```
Ger+6 in C = V7 of D-flat
Modulates: C → D-flat (half step up)

Or reverse:
V7 in C = Ger+6 of B
Modulates: C → B (half step down)
```

**From diminished seventh**:
```
°7 enables modulation to four keys
All related by minor third
C → E-flat → G-flat → A → (C)
```

**From augmented triad**:
```
+ triad enables modulation to three keys
All related by major third
C → E → G# → (C)
```

## Notation and Analysis

**Analytical marking**:
```
         Ger+6
C:  I    ─────
         = V7
D-flat:  ─────  I

Double line indicates enharmonic reinterpretation
Both analyses shown at pivot point
```

**Spelling reflects function**:
```
Write F# in C (Ger+6): F# → G expected
Write G-flat in D-flat (V7): G-flat part of V7

Spelling shows intended voice leading
```

## Musical Context

Enharmonic pivot enables:
- **Distant modulation**: Keys not closely related
- **Half-step modulation**: C → D-flat common via Ger+6
- **Tritone modulation**: Via diminished seventh
- **Sudden key change**: No chromatic preparation
- **Romantic technique**: 19th-century speciality
- **Dramatic effect**: Surprising tonal shifts
- **No voice motion**: Pure reinterpretation
- **Multiple destinations**: Flexibility in target key

Central to understanding Romantic modulatory technique.

## Examples

### Basic

**Ger+6 = V7 pivot** (C major → D-flat major):
```
C major: I - IV - Ger+6 |
         C   F    A-flat-C-E-flat-F#
                  ↓
                  Respell F# as G-flat
                  ↓
D-flat major:    | V7  -  I
                   A-flat-C-E-flat-G-flat  D-flat-F-A-flat

Same pitches: {A-flat, C, E-flat, F#/G-flat}
Different function: Ger+6 (in C) vs. V7 (in D-flat)
Enables C → D-flat modulation
```

**°7 pivot** (C major → E-flat major):
```
C major: I - V - vii°7 |
         C   G   B°7 (B-D-F-A-flat)
                 ↓
                 Respell B as C-flat
                 ↓
E-flat major:   | vii°7 - I
                  D°7 (D-F-A-flat-C-flat)  E-flat

B°7 = D°7 enharmonically
C → E-flat (minor third)
```

**Multiple °7 destinations**:
```
From B°7 in C major:

→ Keep as B°7: resolve to C (original key)
→ Respell as D°7: resolve to E-flat (m3 up)
→ Respell as F°7: resolve to G-flat (tritone)
→ Respell as A-flat°7: resolve to A (m3 down)

Same sound, four possible destinations
```

**+ triad pivot** (conceptual):
```
C+ (C-E-G#) in C major context
   ↓
Respell as E+ (E-G#-B#) for E major context
   or
Respell as G#+ (G#-B#-D##) for G# major context

Three possible interpretations
Major third relationships
```

### From Repertoire

**Schubert, "Der Wegweiser"**: Ger+6 = V7 pivot for dramatic half-step modulation.

**Liszt, "Transcendental Etudes"**: °7 pivots to navigate extreme tonal distances.

**Wagner, "Ring Cycle"**: Enharmonic pivots contribute to through-composed modulatory style.

**Chopin, Ballade No. 1**: °7 pivots for dramatic key changes, Ger+6 for half-step relationships.

**Brahms, Piano Quintet**: Sophisticated enharmonic pivots in development sections.

## Common Confusions

- Enharmonic pivot = modulation via respelling (not voice leading)
- Same pitches, different notation
- Different function in each key
- No voice movement at pivot point
- Most common: Ger+6 = V7 (for half-step modulation)
- Also common: °7 reinterpretation (for m3 modulation)
- Less common: + triad reinterpretation (for M3 modulation)
- Different from chromatic pivot (which involves voice leading)
- Different from common chord pivot (which uses diatonic sharing)
- Spelling reflects intended function
- F# in Ger+6 (expects resolution up)
- G-flat in V7 (part of dominant structure)
- Romantic technique (Schubert, Liszt, Wagner, Chopin)
- Enables sudden distant modulation
- Creates "magical" key change effect
- Requires equal temperament (enharmonics only work in ET)
- Analytical notation shows both interpretations
- Resolution confirms new key interpretation
- Symmetrical chords (°7, +) offer multiple destinations
