# Quick Definition
The magic hexachord, set class (014589), is a "celebrity" hexachord with exceptional combinatorial properties: it creates all-combinatorial rows in three transposition-related ways, corresponds to the 1:3 distance model mode (hexatonic collection), contains many internal triads, and has uniquely constrained subset/superset relationships.

# Core Definition
Set class (014589) has remarkable properties: all-combinatorial by transposition in three ways (by +/-2 and 6 semitones); only the whole-tone collection exceeds this. It corresponds to the hexatonic collection (alternating semitones and minor thirds). It contains all pitches of the hexatonic cycle from neo-Riemannian theory. It has only one possible 5-note subset, (01458), and only one possible 7-note superset, (0124589). Used in Webern's Konzert Op. 24, Schoenberg's Ode to Napoleon, and works by Maderna and Nono.

# Key Properties
1. Set class (014589)
2. All-combinatorial by transposition in three ways
3. Equivalent to the hexatonic collection (1:3 distance model)
4. Contains triads of the hexatonic cycle
5. Only one 5-note subset: (01458)
6. Only one 7-note superset: (0124589)

# Context & Application
The magic hexachord occupies a special position in twelve-tone theory due to its combinatorial richness and its connection to both set-theoretic and neo-Riemannian frameworks.

# Examples
**Example 1** (Webern, Konzert Op. 24): Both hexachords of the row are instances of (014589).
**Example 2** (Schoenberg, Ode to Napoleon): Uses (014589) as a structural hexachord.
