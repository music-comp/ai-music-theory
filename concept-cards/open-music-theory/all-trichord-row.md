# Quick Definition
An all-trichord row is a twelve-tone row that, when treated as circular, contains all 12 possible trichord set classes among its overlapping three-note segments. Only four distinct forms of this row exist, representing the maximum variety of trichordal content.

# Core Definition
As defined by Alan Marsden, all-trichord rows (or rings) contain, in the 12 sets of 3 consecutive pitch classes (treated circularly), all 12 possible trichord set classes. This extends the principle of "all-interval" rows to the trichordal level: just as all-interval rows contain all 11 intervals, all-trichord rows contain all 12 trichords. Exactly four distinct forms exist: [0,2,6,10,5,3,8,9,11,7,4,1], [0,2,6,10,11,9,8,3,5,1,4,7], [0,2,6,10,7,4,11,9,8,3,5,1], [0,2,6,10,1,4,5,3,8,9,11,7]. All share the opening tetrachord [0,2,6,10].

# Prerequisites
- Twelve-tone row and set class

# Key Properties
1. Contains all 12 trichord set classes in overlapping segments (treated circularly)
2. Only 4 distinct forms exist
3. All share the opening [0,2,6,10]
4. Logical extension of all-interval row concept
5. Some rotations are inversion-combinatorial

# Context & Application
All-trichord rows provide maximal trichordal variety, making them ideal for composition seeking maximum diversity of harmonic color.

# Examples
**Example 1**: Row 3: [0,2,6,10,7,4,11,9,8,3,5,1] -- rotation starting on pc 2 yields inversion-combinatorial with I5.
