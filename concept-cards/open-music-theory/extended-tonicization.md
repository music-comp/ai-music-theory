# Extended Tonicization

## Quick Definition

A prolonged emphasis on a non-tonic diatonic chord as a temporary tonic through multiple applied chords or a brief progression—creating a more sustained sense of a new tonal center than simple tonicization (which uses one or two chords) but without the cadential confirmation and structural shift of true modulation, occupying the gray area between brief chromatic embellishment and actual key change, typically lasting several measures with multiple chords functioning in the "temporary key," notated with analysis showing applied chords in sequence (e.g., ii/V - V7/V - V), and common in development sections, transitions, and Romantic-era passages where the boundaries between tonicization and modulation become fluid and ambiguous.

## Formal Definition

**Extended tonicization** is a prolonged tonicization using multiple chords to emphasize a temporary tonic, without confirming a true modulation through cadence.

**Characteristics**:
- **Multiple applied chords**: More than simple V/x → x
- **Longer duration**: Several measures
- **No cadence**: Lacks authentic cadence in "new" key
- **Gray area**: Between tonicization and modulation
- **Returns**: Eventually back to original key
- **Progressive**: May use ii/x, IV/x, V/x in sequence

**Pattern**: ii/x → V/x → x or similar multi-chord tonicizing progression

**Not quite modulation**: No PAC or structural confirmation

## Extended vs. Simple Tonicization

**Simple tonicization** (brief):
```
I - V7/V - V - I
C   D7     G   C

Single applied chord (V7/V)
Immediate resolution
Brief chromatic moment
```

**Extended tonicization** (prolonged):
```
I - ii/V - V7/V - V - vi/V - V - I
C   Am/G   D7     G   Em/G   G   C

Multiple chords tonicizing V
Longer passage
More sustained emphasis on G
Still returns to C without cadence in G
```

**Duration and complexity** differentiate them

## Extended vs. Modulation

**Extended tonicization**:
```
... ii/V - V7/V - V - IV ...

Multiple chords tonicize V
No authentic cadence in V
Returns without confirming V as structural tonic
Gray area
```

**Modulation**:
```
... ii/V - V7/V - V - IV/V - V/V - I/V |

Authentic cadence in V (V-I)
Structural confirmation
New key established
Clear modulation
```

**Key distinction**: Cadential confirmation

## Common Extended Tonicization Patterns

**Tonicizing V**:
```
ii/V - V7/V - V

In C major:
Am (vi in C, or ii in "key of G") - D7 - G

Multiple chords emphasize G
More than simple V7/V - V
No cadence confirms G major
```

**Tonicizing ii**:
```
IV/ii - V7/ii - ii

In C major:
G (V in C, or IV in "key of D") - A7 - Dm

Expands approach to ii
Extended tonicization
```

**With inversions and elaboration**:
```
vii°6/V - V6/4/V - V7/V - V

Multiple applied chords
Tonicizes V through several measures
Complex chromatic progression
```

## Gray Area

**Difficult to categorize**:
```
Where does tonicization end and modulation begin?

Factors:
- Duration (how long?)
- Cadence (PAC present?)
- Context (development vs. exposition?)
- Return (immediate or delayed?)
```

**Continuum**:
```
Brief tonicization → Extended tonicization → Modulation
(V/x-x)              (ii/x-V/x-x)          (PAC in x)

Boundaries fuzzy
Analytical judgment required
```

## Analytical Notation

**Show applied chords in sequence**:
```
C: I    ii/V   V7/V   V    IV    V    I

Multiple slashes indicate extended tonicization
Not shown as key change
```

**Alternative** (bracket):
```
C: I   [   tonicizing V:  ii  -  V7  -  I   ]  IV  V  I

Bracket shows extended zone
Still analyzed in C major
```

**Gray area notation**:
```
Some analysts may show brief modulation
Others show extended tonicization
Depends on context and preference
```

## Musical Context

Extended tonicization serves specific purposes:
- **Development sections**: Explores tonal areas without full modulation
- **Transitions**: Bridges formal sections
- **Romantic ambiguity**: Blurs tonal boundaries
- **Chromatic richness**: Multiple applied chords
- **Prolonged emphasis**: More than simple tonicization
- **Returns smoothly**: Avoids structural key shift
- **Gray area**: Between embellishment and modulation

Common in Romantic music and transitional passages.

## Examples

### Basic

**Extended tonicization of V** (C major):
```
Progression: I - ii/V - V7/V - V - I
             C   Am    D7     G   C

Am functions as ii in "key of G" (ii/V)
D7 = V7/V
Multiple chords tonicize G
No PAC in G
Returns to C major
```

**With more elaboration**:
```
I - IV/V - vii°7/V - V6/5/V - V - vi - ii - V - I
C   C/G    F#°7     D7/F#    G   Am   Dm   G   C

Several measures tonicizing V
Still returns without G major PAC
Extended tonicization
```

**Tonicizing ii**:
```
... V/ii - vii°7/ii - ii - V - I
... A      C#°7       Dm   G   C

Multiple applied chords to ii
Extended emphasis on Dm
No cadence in D minor
```

**In development section**:
```
mm. 20-25: [Extended tonicization of vi]
           IV/vi - V7/vi - vi - ii/vi - V/vi - vi

Six measures emphasizing vi
No authentic cadence in vi
Returns to main key
Development technique
```

### From Repertoire

**Beethoven, Piano Sonatas**: Development sections with extended tonicizations, explores tonal areas without full modulation, multiple applied chords.

**Mozart, Symphony No. 40**: Extended tonicizations in development, ii/x-V7/x-x patterns, gray area between tonicization and modulation.

**Brahms, Symphonies**: Extensive extended tonicizations, Romantic harmonic ambiguity, blurs boundaries through prolonged emphasis.

**Chopin, Preludes**: Extended chromatic tonicizations, multiple applied chords create rich harmonies, difficult to categorize as tonicization vs. modulation.

**Wagner, operas**: Extended tonicizations throughout, boundaries between keys fluid, chromatic harmony characteristic.

## Common Confusions

- Extended tonicization = **multiple applied chords** emphasizing temporary tonic
- Longer than simple tonicization (V/x-x)
- Uses ii/x, IV/x, vii°/x, V/x in sequence
- No **authentic cadence** in temporary key (key distinction from modulation)
- Gray area between tonicization and modulation
- Duration: Several measures (not just one or two chords)
- Returns to original key without structural shift
- Common in **development sections** (Sonata form)
- Romantic era: Boundaries more fluid
- Notation: Show applied chords in sequence (ii/V - V7/V - V)
- Not quite modulation (lacks cadence)
- More than simple tonicization (multiple chords)
- Continuum: Brief tonicization → Extended → Modulation
- Analytical judgment required (fuzzy boundaries)
- Can tonicize any diatonic chord (V, ii, vi most common)
- Multiple chords "in" temporary key
- Eventually returns to main key
- Creates tonal variety without modulation commitment
- Common in transitions and episodic passages
- Wagner, Brahms particularly use this technique
