# Quick Definition

An arpeggiating 6/4 chord is created when the bass leaps to the fifth of a chord while the upper voices sustain the chord. Unlike cadential, passing, and neighbor 6/4 types, arpeggiating 6/4 typically does not need to be labeled in analysis.

# Core Definition

**Arpeggiating 6/4** (arp. 6/4) is typically created when the bass leaps to the fifth of a chord while the upper voices sustain the chord (OMT, Ch. IV.9). It commonly appears in ending bass arpeggiations or waltz-style accompaniments. Unlike the other 6/4 types, arp. 6/4 typically does not need to be labeled in analysis — each measure could simply be labeled with the root-position Roman numeral.

# Key Properties

1. Bass arpeggiates to the fifth of the chord
2. Upper voices sustain the chord
3. May prolong any harmony
4. Does NOT typically need to be labeled in analysis
5. Common in waltz bass patterns and ending arpeggiations

# Construction / Recognition

## To Recognize:
1. Find a 6/4 chord
2. Check: did the bass arrive by arpeggiation (leap to the fifth)?
3. Check: are the upper voices sustaining the same chord?
4. If yes: arpeggiating 6/4 (no special label needed)

# Examples

**Example 1** (OMT Ch. IV.9, Example 3): Arpeggiating 6/4 in Josephine Lang, "Dem Konigs-Sohn."

**Example 2** (OMT Ch. IV.9, Example 5): Arpeggiating 6/4 in Sophie de Auguste Weyrauch, Six Danses No. 3 (waltz-style).
