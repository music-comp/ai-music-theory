# Enharmonic German Sixth

## Quick Definition
The German augmented sixth chord is enharmonically equivalent to a dominant seventh chord, allowing composers to reinterpret Ger+6 as V7 of a distant key (or vice versa) for smooth chromatic modulation, since the same four pitches can function either as a chromatic predominant resolving to V or as a dominant seventh resolving to a new tonic.

## Formal Definition
**Enharmonic German sixth** demonstrates:

**Sonic equivalence**: Ger+6 sounds identical to Mm7

**Spelling difference**: Same pitches, different notation

**Functional flexibility**: Can be predominant OR dominant

**Modulation potential**: Enables distant key relationships

**Pivot mechanism**: The chord is reinterpreted mid-progression

## The Enharmonic Relationship

**German sixth and dominant seventh**:
```
Ger+6 in C minor: Ab - C - Eb - F#

Respell enharmonically:
F# = Gb

Ab - C - Eb - Gb = Ab7 (Abdom7)
                 = V7 of Db major

Same sounds, different spellings!
Same chord can function as:
- Ger+6 in C (predominant, resolves to V of C)
- V7 of Db (dominant, resolves to Db)
```

**Interval structure comparison**:
```
Mm7 (V7):     Root - M3 - P5 - m7
Ab7:          Ab - C - Eb - Gb

Ger+6:        ^b6 - M3 - m3 - A2
Ab/C/Eb/F#:   Ab - C - Eb - F#

Same intervals: M3 + m3 + m3
But A2 (Eb-F#) = m3 (Eb-Gb) enharmonically
```

## Modulation Mechanism

**Starting in C minor, modulating to Db major**:
```
Progression in C minor:
i - iv - Ger+6 ...

At Ger+6 (Ab-C-Eb-F#):
Option 1: Resolve as Ger+6 -> I64 -> V -> i (stay in C)
Option 2: Reinterpret as V7/Db -> Db (modulate to Db)

The reinterpretation changes the harmonic destination
```

**Starting in Db major, arriving in C minor**:
```
Progression in Db major:
I - IV - V7 ...

At V7 (Ab-C-Eb-Gb):
Option 1: Resolve as V7 -> I (stay in Db)
Option 2: Reinterpret as Ger+6/C -> V -> i (modulate to C)

Same chord, opposite direction!
```

## Key Relationships

**Keys related by enharmonic Ger+6**:
```
Ger+6 in C = V7 of Db    (C and Db, half step apart)
Ger+6 in G = V7 of Ab    (G and Ab, half step apart)
Ger+6 in D = V7 of Eb    (D and Eb, half step apart)

Pattern: Keys a half step apart are connected
The ^b6 of one key = ^5 of the other
```

**Pivot relationship**:
```
In C:  Ger+6 bass = Ab = ^b6
In Db: V7 bass = Ab = ^5

Ab is ^b6 in C, ^5 in Db
This note is the enharmonic pivot
```

## Voice Leading Through Modulation

**C minor to Db major**:
```
C minor: i  - iv  - Ger+6 = V7/Db - I (Db major)
         Cm   Fm    Ab7        Db

Voice leading:
Ab -> Ab (common tone, becomes root of Db? No, goes to Db)
C  -> Db (resolve up as leading tone in Db context)
Eb -> Db or F (resolution in Db)
F# = Gb -> F or Ab (resolution in Db)
```

**Reinterpretation moment**:
```
Ger+6:  Ab - C - Eb - F#
        Heard as predominant in C
        
Becomes V7: Ab - C - Eb - Gb
            Heard as dominant of Db
            
Resolution: Db - F - Ab
            New tonic!
```

## Compositional Uses

**Sudden modulation**:
```
One moment in C, next moment in Db
The enharmonic chord is the pivot
Listeners experience smooth but surprising shift
```

**Return modulation**:
```
Start in C -> modulate to Db via Ger+6=V7
Later: Start in Db -> return to C via V7=Ger+6

The same chord works in both directions
Symmetrical relationship
```

**Development sections**:
```
Enharmonic Ger+6 enables:
- Distant modulations
- Tonal ambiguity
- Chromatic wandering
- Quick key changes
```

## Musical Context

The enharmonic German sixth enables:
- **Chromatic modulation**: Smooth distant key changes
- **Tonal flexibility**: Same chord, different functions
- **Romantic harmony**: Essential 19th-century technique
- **Expressive range**: Access to remote keys
- **Surprise effect**: Unexpected tonal destinations
- **Symmetrical planning**: Related keys share this pivot

## Examples

### Basic

**Ger+6 reinterpreted as V7**:
```
In C minor:
Cm - Fm - Ab/C/Eb/F# (Ger+6)...
                |
         Reinterpret as Ab7 (V7/Db):
                |
                v
         ... Ab7 - Db (new key!)

Same chord (Ab-C-Eb-F#/Gb)
Different function after reinterpretation
```

**V7 reinterpreted as Ger+6**:
```
In Db major:
Db - Gb - Ab7 (V7)...
                |
         Reinterpret as Ger+6/C:
                |
                v
         ... Ger+6 - G - Cm (new key!)

Same chord (Ab-C-Eb-Gb/F#)
Now functions as predominant in C
```

**Chromatic modulation passage**:
```
Cm: i - iv - Ger+6 = V7/Db - Db: I - IV - V - I

Cm: Cm - Fm - Ab-C-Eb-F# 
             = Ab-C-Eb-Gb - Db: Db - Gb - Ab - Db

Smooth modulation from C minor to Db major
Distance: Half step (C to Db)
```

## Common Confusions

- Ger+6 sounds identical to V7 (Mm7)
- Same four pitches, different spelling and function
- Ger+6: ^b6-^1-^b3-^#4 (predominant, resolves to V)
- V7: ^5-^7-^2-^4 (dominant, resolves to I)
- **Enharmonic respelling**: F# = Gb
- Ab-C-Eb-F# (Ger+6 in C) = Ab-C-Eb-Gb (V7 of Db)
- Enables modulation to keys half step apart
- C and Db connected by this pivot
- ^b6 of C = ^5 of Db (both Ab)
- Composer can resolve either way
- Reinterpretation = pivot moment
- Common in Romantic modulation
- Schubert, Chopin, Liszt, Wagner use extensively
- Not just theoretical: audibly smooth modulation
