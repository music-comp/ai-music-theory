# Quick Definition
Set-theory analysis identifies pitch-class sets in music and relates them through transposition and inversion, but has significant limitations: it is retrospective (developed after the music), does not address non-pitch parameters (rhythm, timbre, dynamics), and requires careful segmentation to avoid unfalsifiable claims.

# Core Definition
Set theory was popularized by Allen Forte decades after the free atonal repertoire was composed -- it is a retrospective analytical theory. Schoenberg himself felt that structure for free atonal music was impossible, leading to his development of serial technique. Set theory's flexibility is a double-edged sword: any group of pitches can be a set, so analysts could "prove" anything. The theory does not address: history and context, non-pitch parameters, or pitch parameters like voice leading, spacing, and order. These limitations should be addressed through other analytical means.

# Prerequisites
- Segmentation and set class

# Key Properties
1. Retrospective theory (post-dates the repertoire)
2. Does not address non-pitch parameters
3. Does not address voice leading, spacing, or order
4. Flexibility can lead to unfalsifiable claims
5. Best used alongside other analytical approaches
6. Segmentation choices determine analytical results

# Context & Application
Set theory is one tool among many for analyzing post-tonal music. It works best when combined with attention to rhythm, timbre, form, and other parameters that it cannot address on its own.

# Common Confusions
- **Confusion**: Set theory reveals what composers intended
  **Clarification**: It is a retrospective analytical tool; composers' methods may differ
- **Confusion**: Set theory is a complete analytical system
