# Twelve-Tone Analysis

## Quick Definition

Twelve-tone analysis is the process of identifying row forms, tracing their deployment throughout a composition, and understanding how the row's properties shape the music's structure—going beyond mere row-form labeling to address questions of form, texture, expression, and compositional strategy, recognizing that a catalog of row forms is analogous to listing keys in tonal music: necessary but insufficient for meaningful analytical insight.

## Formal Definition

**Twelve-tone analysis**: Systematic study of twelve-tone works encompassing:

1. **Row identification**:
   - Determine the prime row form
   - Construct the row matrix
   - Identify row properties (symmetry, derivation, combinatoriality)

2. **Row tracing**:
   - Follow row forms through the piece
   - Note row distribution across voices/instruments
   - Identify overlaps, elisions, simultaneities

3. **Structural analysis**:
   - How rows articulate form
   - Relationship between row forms and formal sections
   - Role of row properties in shaping structure

4. **Contextual interpretation**:
   - Generic implications (symphony, concerto, etc.)
   - Expressive content
   - Historical and stylistic context

**Analysis principle**: Row-form identification is necessary but not sufficient.

## Musical Context

Twelve-tone analysis addresses:
- **Technical details**: Which rows, where, in what combination
- **Formal structure**: How rows relate to form
- **Texture and timbre**: Klangfarbenmelodie, instrumentation
- **Expression**: What the music communicates
- **Tradition**: Relationship to inherited forms and genres

**Analytical balance**:
- Technical row analysis: essential foundation
- Musical interpretation: essential goal
- Neither alone is sufficient

## Examples

### Basic

**Basic analytical process**:
```
Step 1: Find the row
- Look at opening melody/chord
- Identify 12 consecutive pitch classes
- Write out as pitch-class numbers

Step 2: Build matrix
- Place identified row as P0 (or chosen reference)
- Generate all 48 forms
- Label according to chosen convention

Step 3: Trace rows in score
- Identify row forms measure by measure
- Note distribution across voices
- Mark overlaps and transitions

Step 4: Analyze structure
- Which rows appear in which sections?
- How do row changes articulate form?
- What row properties are exploited?

Step 5: Interpret musically
- What is the expressive effect?
- How does technique serve music?
- What is the relationship to genre/tradition?
```

**Row distribution notation**:
```
mm. 1-4:    P0 (violin), I0 (viola)
mm. 5-8:    P0 (continued), I0 (continued)
mm. 9-12:   R0 (violin), RI0 (viola)
            [retrograde forms mirror opening]

This shows HOW rows are used, not just WHICH rows
```

### From Repertoire

**Webern, Symphonie Op. 21, Movement I**:
```
ROW ANALYSIS:
Row: 9-6-7-8-4-5-11-10-2-1-0-3
- Retrograde equivalent (P0 = R6)
- Two chromatic hexachords (set class 6-1)
- Four trichords: (013), (014), (014), (013)
- Only 24 distinct forms

FORMAL STRUCTURE:
||: A :||: B A' :||
- Exposition repeat (mm. 1-25)
- Development-Recapitulation (mm. 25-end)
- Suggestive of sonata form? Binary form?

CANONIC TEXTURE:
Opening double canon:
- Clarinet/horn vs. harp/bass clarinet
- P0/I0 paired with I8/P4
- Klangfarbenmelodie throughout

SYMMETRY:
- Middle section (B) is palindromic
- m. 35 as midpoint
- Row symmetry reflected in formal symmetry

INTERPRETIVE QUESTIONS:
- What makes this a "symphony"?
- How does symmetry affect perception?
- Can we "hear" the row structure?
```

**Webern, Konzert Op. 24**:
```
ROW ANALYSIS:
Row: 11-8-2 | 3-7-6 | 8-4-5 | 0-1-9
- Four (014) trichords
- Each trichord = P, R, I, or RI of the cell
- P0 = RI7, I0 = R (etc.)
- Only 12 distinct forms
- Hexachords both (014589) "magic hexachord"

FORMAL INTERPRETATION:
- "Concerto" - but for what?
- Opening: row in non-piano instruments
- Second statement: piano alone
- Analogous to double exposition?

TRICHORDAL STRUCTURE:
Movement I: clear trichordal segmentation
Movement II: dyadic/tetrachordal emphasis (ic1)
Different movements exploit different properties

SATOR SQUARE:
Webern's interest in multi-directional reading
Row readable in multiple ways (P, R, I, RI at cell level)
Musical analogue to ancient palindrome
```

**Analysis beyond row-counting**:
```
WHAT analysis should address:
1. How does row structure enable the music?
2. What expressive content emerges?
3. How does piece engage with tradition?
4. What is audible vs. structural?

AVOID:
- Mere cataloging of row forms
- Assuming row = meaning
- Ignoring rhythm, dynamics, timbre
- Treating technique as end rather than means
```

## Common Confusions

- Row-form catalog is like key scheme: useful but incomplete
- Analysis must address MUSICAL questions, not just technical ones
- Row identification is necessary foundation, not final goal
- Same row properties can be used very differently by different composers
- Not all serial music strictly follows row ordering
- Texture, timbre, dynamics are equally important to analyze
- Form may or may not correspond to row structure
- Genre implications (symphony, concerto) are analytically relevant
- Symmetry may be structural without being audible
- Historical context affects interpretation
- Multiple valid analytical perspectives exist
- Analysis reveals ONE way of understanding, not THE way
