# Lament Bass and Augmented Sixth Connection

## Quick Definition
The lament bass is a descending tetrachord pattern from ^1 to ^5 (often chromaticized as ^1-^7-^b7-^6-^b6-^5) that historically served as the origin of the augmented sixth chord, where substituting ^#4 for ^4 in the iv6 chord of the lament progression creates an augmented sixth interval with the ^b6 bass.

## Formal Definition
**Lament bass** is a ground bass pattern:

**Diatonic form**: ^1-^7-^b7-^6-^5 (Phrygian tetrachord)
**Chromatic form**: ^1-^7-^b7-^6-^b6-^5 (all half steps)

**Connection to augmented sixth**:
- At ^b6 in bass, traditional harmony uses iv6 (^b6-^1-^4)
- Raising ^4 to ^#4 creates augmented sixth chord (^b6-^1-^#4)
- The A6 interval (^b6 to ^#4) expands to ^5 (octave)

**Historical origin**: Augmented sixth emerges from lament bass harmonization

## The Lament Bass Pattern

**Diatonic lament (Phrygian tetrachord)**:
```
Bass:  ^1  -  ^7  -  ^b7  -  ^6  -  ^5
       C      B      Bb      A      G  (in C minor)

Harmonization (Rule of the Octave style):
^1:   i
^7:   V6
^b7:  VII (or viio6)
^6:   iv6
^5:   V
```

**Chromatic lament (filled in)**:
```
Bass: ^1  - ^7  - ^b7 - ^6  - ^b6  - ^5
      C     B     Bb    A     Ab     G

More chromatic harmonizations possible
^b6 = Ab in C minor
```

## From iv6 to Augmented Sixth

**Standard lament harmonization at ^b6**:
```
Bass: ^b6 (Ab)
Chord: iv6 = Ab-C-F (Fm/Ab in C minor)
       ^b6-^1-^4

This is minor subdominant in first inversion
Common chord at this bass position
```

**Chromatic alteration creates augmented sixth**:
```
Standard iv6:        Augmented sixth (It+6):
Ab-C-F               Ab-C-F#
^b6-^1-^4            ^b6-^1-^#4
  |    |               |    |
  |    ^4              |    ^#4 (raised!)
  ^b6                  ^b6

Raising ^4 to ^#4 creates A6 interval
```

**The augmented sixth interval**:
```
^b6 (Ab) to ^#4 (F#) = Augmented sixth

Standard: Ab to F = m6 (8 half steps)
Raised:   Ab to F# = A6 (10 half steps)

A6 expands outward to octave on ^5:
Ab -> G (down half step)
F# -> G (up half step)
```

## Phrygian Half Cadence Connection

**Phrygian half cadence**:
```
iv6  -  V (in minor)
Fm/Ab   G

Bass descends by half step: ^b6 -> ^5 (Ab -> G)
Upper voices rise: ^1 and ^4 -> ^7 and ^5
```

**Augmented sixth intensifies this**:
```
Aug6  -  V
It+6    G

Same bass motion: ^b6 -> ^5 (Ab -> G)
But now: ^#4 also rises to ^5 (F# -> G)

Creates chromatic "wedge" voice leading
More dramatic approach to dominant
```

## Building All Three Augmented Sixths from Lament

**Starting from iv6** (Ab-C-F in C minor):
```
iv6:   Ab-C-F     (^b6-^1-^4)

Add #4 for Italian:
It+6:  Ab-C-F#    (^b6-^1-^#4)

Add ^2 for French:
Fr+6:  Ab-C-D-F#  (^b6-^1-^2-^#4)

Add ^b3 for German:
Ger+6: Ab-C-Eb-F# (^b6-^1-^b3-^#4)
```

**All three share the lament bass connection**:
- All have ^b6 in bass (from lament pattern)
- All have ^#4 (chromatic alteration of iv6)
- All resolve to V (completing the descent to ^5)

**Purcell, "Dido's Lament"**:
```

             ^1-^7-^b7-^6-^5-^4-^5

Chromatic descent with characteristic lament bass
Harmonized with various chords including potential A6 points
```

**Bach, "Crucifixus" from Mass in B minor**:

```

```

## Musical Context

The lament bass and augmented sixth connection illustrates:
- **Historical origin**: A6 chords emerge from lament tradition
- **Voice leading logic**: ^#4 substitutes for ^4 in iv6
- **Expressive function**: Both associated with grief, tragedy
- **Baroque foundation**: Purcell, Bach establish lament topic
- **Classical development**: Mozart, Beethoven refine A6 usage
- **Bass pattern**: ^b6 -> ^5 central to both
- **Predominant function**: Both prepare dominant
- **Chromatic intensification**: A6 is chromatic lament

## Examples

### Basic

**Lament bass with augmented sixth substitution**:
```
Standard lament:
i    V6    VII   iv6   V    i
Cm   G/B   Bb    Fm/Ab  G    Cm
^1   ^7    ^b7   ^6    ^5   ^1

With augmented sixth substitution:
i    V6    VII   It+6   V    i
Cm   G/B   Bb    Ab/C/F#  G  Cm
^1   ^7    ^b7   ^b6    ^5   ^1

iv6 (Ab-C-F) becomes It+6 (Ab-C-F#)
More chromatic, more dramatic
```

**Voice leading comparison**:
```
iv6 -> V:               It+6 -> V:
F -> G (^4 -> ^5)       F# -> G (^#4 -> ^5, closer!)
C -> B (^1 -> ^7)       C -> B (^1 -> ^7)
Ab -> G (^b6 -> ^5)     Ab -> G (^b6 -> ^5)

A6 resolution more dramatic (half step above ^5)
```

### From Repertoire

**Purcell, "Dido's Lament" (Dido and Aeneas)**: Quintessential lament bass, chromatic descent expresses grief.

**Bach, "Crucifixus" (Mass in B minor)**: Lament bass with chromatic harmonies, text painting of Christ's suffering.

**Handel, Sarabande from Keyboard Suite in D minor**: Lament bass pattern with various harmonizations.

**Mozart, Requiem, "Lacrimosa"**: Lament topic with augmented sixths, tragic expression.

**Chopin, Prelude in E minor**: Lament bass chromaticism, Romantic expression of grief.

## Common Confusions

- Lament bass = descending tetrachord ^1-^7-^b7-^6-^5 (or chromatic version)
- Historical origin of augmented sixth chords
- **Connection**: iv6 at ^b6 becomes A6 when ^4 is raised to ^#4
- iv6: ^b6-^1-^4 (minor subdominant, first inversion)
- A6: ^b6-^1-^#4 (chromatic alteration, creates A6 interval)
- Both share bass note ^b6 and inner voice ^1
- Both resolve to V (^5)
- Phrygian half cadence: iv6-V (^b6 -> ^5 in bass)
- Augmented sixth intensifies this with ^#4 -> ^5
- "Wedge" voice leading: ^b6 descends, ^#4 ascends to ^5
- Expressive association: grief, tragedy, sorrow
- Baroque examples: Purcell, Bach
- Classical refinement: Mozart, Beethoven
- Lament topic in music semiotics
