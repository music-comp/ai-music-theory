# Quick Definition
A binary form subtype with no substantial return of opening material in the second reprise -- the second reprise either continues A's ideas (A') or presents relatively new material (B), yielding ||:A:||:A':|| or ||:A:||:B:||.

# Core Definition
In **simple binary form**, "there is no substantial return of opening material in the second reprise." Two possible manifestations: (1) **A'** -- the second reprise continues with the same sorts of ideas; since A material is always present, there is no "return"; (2) **B** -- the second reprise contains relatively new material throughout (Ch. 6).

# Prerequisites
- **Binary form** -- Simple binary is a subtype

# Key Properties
1. No return of A in the second reprise
2. Two subtypes: ||:A:||:A':|| or ||:A:||:B:||
3. A': continues same ideas without clear return point
4. B: relatively new material
5. May be balanced (tail end of first reprise returns at tail end of second)

# Examples
**Example 1** (Ch. 6, Example 6): Bach, Bourree from Lute Suite BWV 996 -- simple binary where second reprise continues A's ideas (A').
