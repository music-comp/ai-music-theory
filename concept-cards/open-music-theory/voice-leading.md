# Voice Leading

## Quick Definition

The smooth and logical connection of individual melodic lines (voices) in polyphonic music, governed by principles that ensure each voice moves as efficiently as possible between chords while avoiding problematic intervals and maintaining independence—prioritizing stepwise motion over leaps, resolving tendency tones correctly (especially the leading tone to tonic), and avoiding parallel perfect intervals (fifths and octaves) that would compromise voice independence in the SATB (soprano-alto-tenor-bass) texture characteristic of common-practice harmony.

## Formal Definition

**Voice Leading** is the practice of connecting chords through smooth, logical melodic motion in each voice, following established principles that balance harmonic progression with melodic independence and contrary motion.

**Core principles**:

**1. Prefer stepwise motion**:
- Voices move by step (second) when possible
- Leaps used when necessary but minimized
- Smooth melodic lines in all voices

**2. Tendency tone resolution**:
- **Leading tone (^7)**: Resolves up to tonic (^1)
- **Seventh of chord**: Resolves down by step
- **Chordal dissonances**: Resolve to consonances

**3. Avoid parallel perfect intervals**:
- **Parallel fifths**: Forbidden
- **Parallel octaves**: Forbidden
- **Parallel unisons**: Forbidden
- Compromises voice independence

**4. Prefer contrary or oblique motion**:
- **Contrary motion**: Voices move in opposite directions
- **Oblique motion**: One voice moves, other sustains
- **Similar motion**: Acceptable with care
- **Parallel motion**: Only for imperfect intervals (3rds, 6ths)

**5. Maintain proper voice ranges**:
- Soprano, alto, tenor, bass within appropriate ranges
- Avoid excessive leaps (especially larger than octave)
- Smooth contours preferred

## SATB Voice Leading

**Four-voice texture** (Soprano-Alto-Tenor-Bass):

**Voice ranges**:
- **Soprano**: C4 to G5 (roughly)
- **Alto**: G3 to C5
- **Tenor**: C3 to G4
- **Bass**: E2 to C4

**Spacing rules**:
- **Upper three voices**: Within octave of each other
- **Bass**: Can be more than octave below tenor
- Avoid large gaps between adjacent upper voices

**Doubling**:
- **In triads**: Double root (most common), third, or fifth
- **Avoid doubling**: Leading tone, altered tones, dissonances
- **In seventh chords**: Complete chord preferred, omit fifth if needed

## Common Voice Leading Patterns

**V-I progression**:
```
V:  G-B-D     I:  C-E-G
S:  D  → C   (^2 → ^1, step down)
A:  B  → C   (^7 → ^1, leading tone up!)
T:  G  → E   (^5 → ^3, skip down third)
B:  G  → C   (^5 → ^1, skip up fourth)

Leading tone resolves up, smooth motion in other voices
```

**I-V progression**:
```
I:  C-E-G     V:  G-B-D
S:  G  → G   (^5 → ^5, common tone)
A:  E  → D   (^3 → ^2, step down)
T:  C  → B   (^1 → ^7, step down)
B:  C  → G   (^1 → ^5, skip up fifth)

Common tone in soprano, stepwise motion where possible
```

**V⁷-I with seventh resolution**:
```
V⁷: G-B-D-F   I:  C-E-G-C
S:  F  → E   (^4 → ^3, seventh resolves DOWN)
A:  D  → C   (^2 → ^1, step down)
T:  B  → C   (^7 → ^1, leading tone UP)
B:  G  → C   (^5 → ^1, skip to root)

Seventh (F) resolves down, leading tone (B) resolves up
```

## Voice Leading Errors to Avoid

**Parallel fifths/octaves**:
```
WRONG:
S:  C → D    (Perfect fifth with alto)
A:  F → G    (Perfect fifth, parallel = BAD)

Parallel motion in perfect intervals forbidden
```

**Hidden (direct) fifths/octaves**:
```
Acceptable with caution:
S:  C → G    (leap to octave)
B:  E → C    (similar motion, but allowed if soprano stepwise)

Avoid if both voices leap to perfect interval
```

**Voice crossing**:
```
Avoid (but sometimes necessary):
Alto higher than soprano temporarily
Tenor higher than alto
Creates unclear texture
```

**Unresolved leading tone**:
```
WRONG:
V:  G-B-D
I:  C-G-E    (B moved to G, didn't resolve to C)

Leading tone must resolve up to tonic
```

## Musical Context

Voice leading serves critical purposes:
- **Melodic clarity**: Each voice has smooth, singable line
- **Voice independence**: Voices maintain distinct identities
- **Harmonic progression**: Chords connect logically
- **Tonal stability**: Tendency tones resolve correctly
- **Pedagogical foundation**: Basis for chorale writing, composition
- **Historical practice**: Reflects common-practice conventions

Essential for SATB chorale writing, four-part harmony exercises, and composition.

## Examples

### Basic

**Good voice leading** (I-IV-V-I):
```
   I      IV     V      I
S: C  →   C  →   D  →   C   (stepwise, smooth)
A: E  →   F  →   D  →   E   (stepwise)
T: G  →   A  →   B  →   C   (stepwise)
B: C  →   F  →   G  →   C   (roots in bass)

All voices move smoothly, no parallel fifths/octaves
```

**Contrary motion** (preferred):
```
   I           V
S: C   →   G   (up)
A: E   →   D   (down)
T: G   →   B   (up)
B: C   →   G   (up)

Outer voices in contrary motion (S up, B up, but A down)
Creates independence
```

**Common tone retention**:
```
   I      V
S: G  →   G   (stays, common tone)
A: E  →   D   (step)
T: C  →   B   (step)
B: C  →   G   (leap to root)

Common tone held = smooth voice leading
```

### From Repertoire

**Bach, Chorales**: Model voice leading with stepwise motion, proper tendency tone resolution, avoiding parallel fifths/octaves—pedagogical standard for four-part harmony.

**Mozart, Piano Sonatas (four-voice textures)**: Clean voice leading even in keyboard idiom, demonstrates principles in compositional practice.

**Beethoven, String Quartets**: Voice leading principles applied to instrumental ensemble, each instrument as independent voice.

**Hymns (generic)**: Four-part hymn settings demonstrate practical voice leading accessible to amateur singers, smooth stepwise motion.

## Common Confusions

- Voice leading = connecting chords with smooth melodic lines in each voice
- Prefer stepwise motion (seconds) over leaps when possible
- Leading tone (^7) resolves UP to tonic (^1) - tendency tone
- Seventh of chord resolves DOWN by step
- Parallel fifths/octaves forbidden (compromises voice independence)
- Hidden/direct fifths acceptable with care (especially if soprano stepwise)
- Common tone between chords should be retained in same voice
- Contrary motion preferred (voices move opposite directions)
- Oblique motion good (one voice moves, other stays)
- Similar/parallel motion acceptable for imperfect intervals (3rds, 6ths)
- Voice crossing avoided (alto above soprano, etc.) but sometimes necessary
- Upper three voices within octave of each other (SATB spacing)
- Double root of triad most common (or third/fifth, not leading tone)
- Complete seventh chords preferred (all four notes)
- Voice leading independent of harmonic function (but supports it)
- SATB = pedagogical model (not only valid texture)
