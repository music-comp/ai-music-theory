# German Diminished Third

## Quick Definition
The German diminished third chord (Ger°3) is a 19th-century variant of the German augmented sixth in which ^#4 appears in the bass instead of ^b6, inverting the characteristic augmented sixth interval to become a diminished third that contracts inward to a unison on ^5, resembling vii°7/V but with ^b6 instead of ^6.

## Formal Definition
**German diminished third** (Ger°3) is an inverted German augmented sixth with:

**Structure**: Four notes (same pitches as Ger+6, different bass)
- ^#4 (raised subdominant) in bass
- ^b6 (lowered submediant) in upper voice
- ^1 (tonic) in middle voice
- ^b3 (lowered mediant) in middle voice

**Defining interval**: Diminished third (d3) between ^#4 (bass) and ^b6 (upper voice)

**Inversion relationship**:
- Ger+6: ^b6 in bass, A6 interval to ^#4
- Ger°3: ^#4 in bass, d3 interval to ^b6

**Function**: Chromatic predominant resolving to root-position V

## Interval Inversion

**Augmented sixth inverts to diminished third**:
```
Ger+6:                    Ger°3:
   ^#4 (F#)                  ^b6 (Ab)
    |                          |
   A6 (8+1=9 half steps)      d3 (3-1=2 half steps)
    |                          |
   ^b6 (Ab) in bass          ^#4 (F#) in bass

Inversion: A6 + d3 = octave
```

**Resolution direction reverses**:
```
Ger+6: A6 EXPANDS to P8 (outer voices move apart)
Ger°3: d3 CONTRACTS to P1 (outer voices move together)
```

## Comparison with vii°7/V

**Nearly identical structure**:
```
vii°7/V in C: F#-A-C-Eb (F# is leading tone to G)
Ger°3 in C:   F#-Ab-C-Eb (Ab instead of A)

Only difference: ^b6 (Ab) vs. ^6 (A)
```

**Same resolution target**:
```
Both vii°7/V and Ger°3 resolve to root-position V

vii°7/V: F#-A-C-Eb   ->  V: G-B-D-G
Ger°3:   F#-Ab-C-Eb  ->  V: G-B-D-G

^#4 (F#) always moves up to ^5 (G) in bass
```

**Distinguishing by ear**:
- vii°7/V has natural ^6 (brighter)
- Ger°3 has ^b6 (darker, more chromatic)

## Voice Leading

**Resolution pattern**:
```
Ger°3:    F#-Ab-C-Eb
          |   |   |   |
          v   v   v   v
V:        G - G - B - D

Voice leading:
F# -> G  (^#4 ascends by half step to ^5, in bass)
Ab -> G  (^b6 descends by half step to ^5)
C  -> B  (^1 descends by half step to ^7)
Eb -> D  (^b3 descends by half step to ^2)
```

**Key difference from Ger+6**:
- Ger+6 resolves to I64 first (to avoid parallels)
- Ger°3 resolves directly to root-position V
- No parallel fifth problem because ^#4 is now in bass

**Diminished third contracts to unison**:
```
Ger°3:        V:
Ab (soprano)  G
 |            |
d3 contracts  P1 (unison)
 |            |  
F# (bass)     G
```

## Historical Context

**19th-century development**:
- Ger+6 standard in Classical period
- Ger°3 emerges in Romantic period
- Composers inverted Ger+6 for variety
- Creates different bass line possibilities

**Voice leading advantage**:
- Allows bass motion ^#4 -> ^5 (ascending leading tone)
- Creates strong upward resolution in bass
- No need for I64 interpolation

## Musical Context

The German diminished third serves specific purposes:
- **Romantic variant**: 19th-century chromatic innovation
- **Bass ^#4**: Creates ascending chromatic bass to ^5
- **Direct resolution**: No I64 needed (unlike Ger+6)
- **vii°7/V resemblance**: Similar structure, slightly different color
- **Diminished third interval**: Contracts inward (opposite of A6)
- **Root-position V**: Resolves to V with ^5 in bass
- **Chromatic bass line**: Useful in ascending chromatic patterns

## Examples

### Basic

**German diminished third in C minor**:
```
Ger°3:  F#-Ab-C-Eb   V:  G-G-B-D
        |   |   |   |    |  |  |  |
Bass:   F#    ->     G   (up by half step)
Tenor:  Ab    ->     G   (down by half step)  
Alto:   C     ->     B   (down by half step)
Sop:    Eb    ->     D   (down by half step)

d3 (F#-Ab) contracts to unison (G-G)
```

**In chromatic bass line**:
```
i   -   iv6   -   Ger°3   -   V   -   i
Cm      Fm/Ab     F#/Ab/C/Eb   G     Cm
C       Ab        F#           G     C
                  ↑            ↑
             ascending chromatic bass
```

**Comparison with standard Ger+6**:
```
Standard: i - Ger+6 - I64 - V - i
          Cm  Ab/C/Eb/F#  G/C/E  G  Cm
Bass:     C   Ab      G    G  C

Variant:  i - Ger°3 - V - i
          Cm  F#/Ab/C/Eb  G  Cm
Bass:     C   F#      G   C
                ↑     ↑
          ascending chromatic
```

### From Repertoire

**Schubert, Piano Sonatas**: German diminished third chords in chromatic passages, Romantic harmonic color.

**Chopin, Nocturnes**: Ger°3 for chromatic bass lines, expressive harmony.

**Liszt, Piano Works**: German diminished thirds in virtuosic chromatic writing.

**Wagner, Music Dramas**: Both Ger+6 and Ger°3 used for chromatic variety.

**Late Romantic period**: Ger°3 becomes standard variant alongside Ger+6.

## Common Confusions

- German diminished third = inverted German augmented sixth (Ger°3)
- **^#4 in bass** (not ^b6 like standard Ger+6)
- Spelling: ^#4-^b6-^1-^b3 (bass to soprano)
- In C: F#-Ab-C-Eb (F# in bass)
- Same pitches as Ger+6, different bass note
- **Diminished third**: Interval between ^#4 and ^b6 (contracts to unison)
- Contrast with augmented sixth (which expands to octave)
- Resolves directly to root-position V (no I64 needed)
- Nearly identical to vii°7/V (only ^b6 vs ^6 different)
- vii°7/V: F#-A-C-Eb (natural A)
- Ger°3: F#-Ab-C-Eb (flat A)
- 19th-century innovation (Romantic period)
- Creates ascending chromatic bass line ^#4 -> ^5
- Function: Chromatic predominant
- Less common than standard Ger+6
- Named descriptively (not after nationality)
