# Quick Definition
Distance model modes are formed by alternating between two intervals in a repeating pattern: 1:2 (octatonic), 1:3 (hexatonic/magic hexachord), 1:5 (semitones and perfect fourths), etc. This restricted subset of modes of limited transposition is strongly associated with Bartok.

# Core Definition
Distance model modes are a more specific subset of modes of limited transposition, formed by strictly alternating two interval sizes. The 1:2 model produces the octatonic; the 1:3 model produces the hexatonic collection (magic hexachord); the 1:5 model produces set class (0167). Bartok frequently used these models, particularly the 1:5 distance model.

# Prerequisites
- Modes of limited transposition

# Key Properties
1. Alternation of exactly two interval sizes
2. 1:2 = octatonic
3. 1:3 = hexatonic (magic hexachord)
4. 1:5 = semitones and perfect fourths, producing set class (0167)
5. Strongly associated with Bartok

# Context & Application
Distance model modes provide a systematic way to generate symmetric pitch collections. They bridge set theory (producing specific set classes) and scalar theory (producing modes).

# Examples
**Example 1** (Bartok, From the Island of Bali): Opening uses the 1:5 distance model = set class (0167), creating harmonic ambiguity.
