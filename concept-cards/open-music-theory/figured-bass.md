# Figured Bass

## Quick Definition

A Baroque-era musical notation system using Arabic numerals written below a bass line to indicate the intervals above the bass that should be played, serving both as a shorthand for performers (who realize the harmonies at the keyboard) and as an analytical tool (showing chord inversions and voice leading)—where numbers represent intervals (6 = sixth, 4 = fourth, etc.), with standard abbreviations (6 for first inversion triads, 6/4 for second inversion, 7 for seventh chords), chromatic alterations shown by accidentals or strokes through numbers, still used today in music theory pedagogy for analyzing chord inversions and harmony.

## Formal Definition

**Figured bass** (also called **thoroughbass** or **basso continuo**) is a notation system indicating harmony through:
- **Bass line**: Written out fully (lowest voice)
- **Figures**: Arabic numerals below bass showing intervals above
- **Realization**: Performer fills in upper voices based on figures

**Historical purpose** (Baroque era):
- Keyboard player realizes harmony
- Provides harmonic framework
- Allows improvisation within guidelines

**Modern purpose** (music theory):
- Analytical notation for inversions
- Shows intervals above bass
- Indicates chromatic alterations

## Basic Figured Bass Symbols

**Root position triad** (5/3):
```
Bass:    C
Figure:  [empty] or 5/3

Indicates: 3rd and 5th above bass
Chord: C-E-G (root position)
```

**First inversion triad** (6 or 6/3):
```
Bass:    E
Figure:  6

Indicates: 3rd and 6th above bass (6th most important)
Chord: E-G-C (first inversion C major, I⁶)
```

**Second inversion triad** (6/4):
```
Bass:    G
Figure:  6/4

Indicates: 4th and 6th above bass
Chord: G-C-E (second inversion C major, I⁶₄)
```

**Seventh chord root position** (7):
```
Bass:    G
Figure:  7 or 7/5/3

Indicates: 3rd, 5th, and 7th above bass
Chord: G-B-D-F (V⁷ in C major)
```

## Seventh Chord Inversions

**Root position** (7):
```
Figure: 7 or 7/5/3
Example: G⁷ (V⁷) = G-B-D-F
```

**First inversion** (6/5 or ⁶₅):
```
Figure: 6/5 or ⁶₅
Bass: 3rd of chord
Example: B-D-F-G (V⁶₅)
```

**Second inversion** (4/3 or ⁴₃):
```
Figure: 4/3 or ⁴₃
Bass: 5th of chord
Example: D-F-G-B (V⁴₃)
```

**Third inversion** (4/2 or ⁴₂ or 2):
```
Figure: 4/2, ⁴₂, or 2
Bass: 7th of chord
Example: F-G-B-D (V⁴₂ or V²)
```

## Chromatic Alterations

**Accidentals** added to figures:
```
Figure: ♯6    = sharp the 6th above bass
Figure: ♭7    = flat the 7th above bass
Figure: ♮3    = natural the 3rd above bass
```

**Stroke through number** = raise by half step:
```
Figure: 6̸ or 6+ = sharpen the 6th
Figure: 4̸     = sharpen the 4th
```

**Accidental alone** = applies to 3rd above bass:
```
Figure: ♯     = sharpen 3rd (common for leading tones)
Figure: ♭     = flatten 3rd
```

## Common Abbreviations

**Empty** (no figure):
```
Means: Root position triad (5/3)
Most common harmony
```

**6**:
```
Means: First inversion triad (6/3)
Very common abbreviation
```

**6/4**:
```
Means: Second inversion triad
All figures needed (not abbreviated to 6 alone)
```

**7**:
```
Means: Root position seventh chord (7/5/3)
Common abbreviation
```

**#**:
```
Means: Raise the 3rd above bass (sharpen it)
Common for leading tones
```

## Figured Bass Realization

**Given figured bass**:
```
Bass:   C    E    F    G    C
Figure: [6]  [6]  [7]  [—]

Realization:
C-E-G-C (I, root position)
E-G-C   (I⁶, first inversion)
F-A-C-E♭ (IV⁷)
G-B-D   (V)
C-E-G   (I)
```

**Performer fills in upper voices**:
- Follows voice leading principles
- Avoids parallel fifths/octaves
- Creates smooth melodic lines
- Doubles appropriate notes

## Analytical Use

**Modern harmonic analysis** combines Roman numerals with figured bass:
```
C:  I    I⁶   IV   V⁶₅   I
    [—]  [6]  [—]  [⁶₅]  [—]

Roman numerals show function
Figured bass shows inversion
```

**Useful for**:
- Identifying chord inversions quickly
- Analyzing voice leading
- Understanding Baroque harmony
- Teaching chord structure

## Musical Context

Figured bass serves multiple purposes:
- **Baroque performance practice**: Continuo realization (harpsichord, organ)
- **Analytical notation**: Modern theory pedagogy
- **Inversion identification**: Quick visual reference
- **Historical connection**: Links to 17th-18th century practice
- **Voice leading**: Shows intervals and relationships
- **Pedagogical tool**: Teaches chord construction and realization
- **Improvisation basis**: Framework for harmonic improvisation

Essential skill for understanding Baroque music and harmonic analysis.

## Examples

### Basic

**Simple progression**:
```
Bass:   C    F    G    C
Figure: [—]  [—]  [7]  [—]

Analysis:
C major root position (I)
F major root position (IV)
G⁷ (V⁷)
C major root position (I)

Standard I-IV-V⁷-I progression
```

**With inversions**:
```
Bass:   C    G    A    G    C
Figure: [—]  [6]  [6]  [7]  [—]

Analysis:
C: I   V⁶  vi⁶  V⁷   I

First inversions (6) on G and A
Seventh chord (7) on G
```

**Chromatic alterations**:
```
Bass:   C    E    F#   G
Figure: [—]  [—]  [6]  [—]

Analysis:
C: I   I    V⁶/V  V
   (F# indicates secondary dominant)

F# appears in figure, shows chromatic alteration
```

**Suspensions**:
```
Bass:   G    G    G
Figure: [—]  [4]  [3]

Analysis:
V    4-3 suspension over V

4 suspends, resolves to 3
Shows non-chord tone pattern
```

### From Repertoire

**Baroque continuo parts**: Figured bass throughout (Corelli, Vivaldi, Bach), performers realize harmonies at keyboard from figures.

**Bach, Chorales (analytical editions)**: Often include figured bass beneath score for analytical clarity, shows inversions and voice leading.

**Handel, Messiah and operas**: Continuo parts with figured bass, harpsichordist realizes harmony in performance.

**Modern theory textbooks**: Use figured bass for analytical exercises, teaches chord identification and realization.

**Corelli, Trio Sonatas**: Model figured bass realizations, demonstrates Baroque harmonic practice and continuo technique.

## Common Confusions

- Figured bass = numbers below bass line showing intervals above
- Also called "thoroughbass" or "basso continuo notation"
- Numbers = intervals above the bass (not scale degrees)
- Empty (no figure) = root position triad (5/3)
- 6 = first inversion triad (6/3 abbreviated)
- 6/4 = second inversion triad (NOT abbreviated to 6)
- 7 = root position seventh chord
- ⁶₅ = first inversion seventh (pronounced "six-five")
- ⁴₃ = second inversion seventh ("four-three")
- ⁴₂ or ² = third inversion seventh ("four-two" or "two")
- Accidentals show chromatic alterations (♯6 = sharp the 6th)
- Stroke through number = raise by half step (6̸ = sharp 6th)
- Accidental alone = applies to 3rd above bass (♯ = sharpen 3rd)
- Baroque: performers realize harmony from figures (improvise upper voices)
- Modern: analytical tool showing inversions
- Not same as Roman numerals (which show function, not inversion alone)
- Figured bass + Roman numerals = complete analysis
- All intervals measured from bass (not from root)
- "Realization" = filling in upper voices from figured bass
- Voice leading principles apply (avoid parallels, smooth motion)
- Historical practice (17th-18th century continuo playing)
- Still taught today for theory and Baroque performance
