# Quick Definition

A notation system using Arabic numerals below bass notes to indicate intervals above the bass, showing chord inversions; abbreviated figures are standard (6 = first inversion triad, 6/4 = second inversion triad, 7 = root position seventh, 6/5 = first inversion seventh, 4/3 = second inversion seventh, 4/2 = third inversion seventh).

# Core Definition

**Figured bass** uses Arabic numerals (and sometimes accidentals) placed below or beside a bass note to indicate the intervals above that bass note, which musicians interpret as chords. The full figures show all intervals, but abbreviated figures are standard today. For triads: no figure = root position; 6 = first inversion; 6/4 = second inversion. For seventh chords: 7 = root position; 6/5 = first inversion; 4/3 = second inversion; 4/2 (or just 2) = third inversion. **Realizing** figured bass means turning these symbols into actual chords. Accidentals before figures indicate chromatic alterations; a slash through a figure or + sign means raise by a half step; an orphaned accidental applies to the third above the bass.

# Prerequisites

- **Inversion**: what figured bass indicates
- **Triad / seventh chord**: the chords being figured

# Key Properties

- Figures indicate intervals above the BASS (not the root)
- Triad figures: (none)=root pos, 6=1st inv, 6/4=2nd inv
- Seventh chord figures: 7=root pos, 6/5=1st inv, 4/3=2nd inv, 4/2=3rd inv
- Accidentals before figures: chromatic alterations
- Slash through figure or +: raise by half step
- Orphaned accidental: applies to the third above the bass
- Added to Roman numerals (not chord symbols)

# Construction / Recognition

Read the bass note and figures. The figures tell you what intervals to build above the bass. Realize the chord by finding the root and quality.

# Context & Application

Figured bass originated in the Baroque era as a performance shorthand for keyboard players. Today it is primarily used in music theory as a compact way to indicate chord inversions alongside Roman numerals.

# Examples

- Bass note E with "6" below: build a triad with E in the bass, third in first inversion = C major/E
- Bass note C with "7" below: root position seventh chord on C
- Bass note D with "6/5": first inversion seventh chord with D as the third = Bb major seventh first inversion

# Common Errors

- Figures indicate intervals above the BASS, not above the root

# Common Confusions

- No figure = root position triad (not "no chord")
- Figured bass is added to Roman numerals, not to chord symbols (chord symbols use slash notation)
