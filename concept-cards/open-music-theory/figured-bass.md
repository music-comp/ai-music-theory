# Figured Bass

## Quick Definition

A system of musical shorthand using Arabic numerals to indicate intervals above the bass note, allowing performers to realize (construct) complete chords.

## Formal Definition

**Figured bass** (also called thoroughbass or basso continuo figures) is a notational system that uses Arabic numerals and symbols placed below bass notes to indicate the intervals that should be played above those bass notes. Musicians then "realize" these figures by constructing the appropriate chords.

Standard figured bass symbols:

**Triads:**
- (no figure) or 5/3 = root position
- 6 or 6/3 = first inversion
- 6/4 = second inversion

**Seventh chords:**
- 7 or 7/5/3 = root position
- 6/5 or 6/5/3 = first inversion
- 4/3 or 6/4/3 = second inversion
- 4/2 or 6/4/2 = third inversion (sometimes just "2")

Additional symbols:
- Accidentals (♯, ♭, ♮) before a figure = alter that note
- Slash through a number = raise by half step
- + before a number = raise by half step
- Accidental alone = applies to the third above bass

## Musical Context

Figured bass was the standard practice in Baroque music (c. 1600-1750) for:
- Keyboard continuo parts (harpsichord, organ)
- Indicating harmony to improvisers
- Teaching harmony and composition
- Analyzing harmonic progressions

Modern uses:
- Roman numeral analysis (combined with Roman numerals to show function + inversion)
- Harmonic analysis of tonal music
- Teaching chord construction and voice leading
- Understanding Baroque performance practice

Figured bass is shorthand: it tells you which intervals to include but not the specific voicing, rhythm, or texture—these are left to the performer's discretion.

## Examples

### Basic

Realizing figures:
- Bass note C, no figures → C major triad in root position (C-E-G)
- Bass note E, figure "6" → C major triad in first inversion (E-G-C)
- Bass note G, figures "6/4" → C major triad in second inversion (G-C-E)
- Bass note G, figure "7" → G dominant seventh in root position (G-B-D-F)
- Bass note B, figures "6/5" → G dominant seventh in first inversion (B-D-F-G)

Chromatic alterations:
- Bass note D, figure "♯6" → D-F♯-B (B diminished, first inversion)
- Bass note F, figure "♯" → F-A-C♯ (augmented triad, raised third)

### From Repertoire

Nearly all Baroque continuo parts use figured bass. Bach's chorales are often analyzed using figured bass combined with Roman numerals. Modern theory textbooks use figured bass extensively for harmonic analysis.

## Common Confusions

- Figures show intervals ABOVE THE BASS, not above the root
- No figure doesn't mean no chord—it means root position triad
- Larger numbers go on top when stacking (6/4, not 4/6)
- Figure "6" alone implies 6/3 (first inversion triad)
- Figured bass doesn't specify voicing, doubling, or spacing—just which pitches to include
- Modern chord symbols (C, Dmi, G7) replaced figured bass in popular music but serve a different purpose
