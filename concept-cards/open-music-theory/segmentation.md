# Segmentation

## Quick Definition

Segmentation is the analytical process of deciding which notes to group together as pitch-class sets. It is perhaps the most critical and subjective step in set theory analysis--the analyst must justify why certain notes are grouped while others are excluded, based on musical criteria like contiguity, rhythm, timbre, register, or articulation.

## Formal Definition

**Segmentation**: The process of dividing a musical passage into meaningful groups of pitch classes for set-theoretic analysis.

**Criteria for segmentation** (partial list):
- **Contiguity**: Notes that are simultaneous or directly successive
- **Rhythmic profile**: Notes grouped by shared rhythm or metric position
- **Timbre/texture**: Notes sharing instrumental color or registral placement
- **Articulation**: Notes marked similarly (staccato, legato, accented)
- **Register**: Notes within a particular range (e.g., soprano line only)
- **Motivic correspondence**: Notes that function as a recurring motive

**The problem of segmentation**:
Because any group of pitch classes can form a set, the analyst must defend their choices. Undefended segmentation can "prove" anything--finding connections that are numerically valid but musically meaningless.

**Joseph Straus's guidance**: "Strive for a balance between imaginative seeking and musical common sense... you must stay within the boundaries of what can be meaningfully heard."

## Musical Context

Segmentation is where set theory becomes **interpretive** rather than merely computational. Two analysts examining the same passage might segment differently, leading to different (but potentially equally valid) analyses.

**Good segmentation practice**:
1. Start with obvious groupings (simultaneities, clear melodic fragments)
2. Justify less obvious groupings with multiple criteria
3. Acknowledge alternatives when they exist
4. Connect segmentation choices to musical meaning

**Warning signs of poor segmentation**:
- Cherry-picking notes to force a desired set class
- Ignoring musical boundaries (phrase marks, rests)
- Choosing notes from very different locations without justification
- Finding sets that exist by definition but carry no musical weight

## Examples

### Basic

**Well-justified segmentation**:
```
Passage: A chord (E, G, B) followed by a melodic line (C, D, F)

Segmentation 1: [4, 7, 11] (the chord) and [0, 2, 5] (the melody)
  Justification: Contiguity--chord is simultaneous, melody is successive

Segmentation 2: [4, 0, 2] (first notes of chord and melody)
  Problem: Why these notes? What musical rationale?
```

**Criteria in action**:
```
Given passage: RH plays E-F#-G# while LH plays C-D-Eb

Possible segmentations:
A. By hand: {4, 6, 8} and {0, 2, 3}
   Justified by: register, timbre (instrumental separation)

B. By beat: {4, 0} and {6, 2} and {8, 3}
   Justified by: metric alignment

C. Complete aggregate: {0, 2, 3, 4, 6, 8}
   Justified by: passage as a unit

Each segmentation reveals different relationships.
```

**Problematic segmentation**:
```
Analyst claims: "The piece is unified by set class (016)"
Method: Selected 3 notes from m.1, 3 from m.15, 3 from m.30

Problem: Without justifying why those specific notes from
distant locations should be grouped, this "finding" is
statistically inevitable but musically empty.
```

### From Repertoire

**Webern, "Wie bin ich froh!"**: How should the vocal line be segmented? By phrase? By breath mark? In dialogue with the piano? Each choice leads to different analytical observations.

**Schoenberg, Pierrot lunaire, "Nacht"**: The opening ostinato E-G-Eb can be segmented as a trichord, but should it include the next notes? Where does one motivic statement end and another begin?

**Bartok, "From the Island of Bali"**: The hands can be analyzed separately (revealing (0167) sets) or together (revealing octatonic content). Both are valid, revealing different aspects.

## Common Confusions

- **Any notes CAN be a set**: But should they? Segmentation requires musical justification
- **More is not better**: Finding 50 instances of a set class by dubious segmentation doesn't strengthen an analysis
- **Set theory doesn't prescribe segmentation**: The analyst must make and defend these choices
- **Segmentation is interpretive**: Different segmentations are possible; some are better justified than others
- **Start simple**: Begin with obvious groupings before seeking hidden connections
- **"Meaningful" is key**: Can a listener perceive the grouping? If not, reconsider
- **Segmentation =/= identification**: Finding a set class label is just the beginning; the analysis must say something about the music
