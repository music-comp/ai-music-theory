# Quick Definition
Segmentation is the process of dividing music into pitch-class sets for analysis. Because any group of pitches can be a set, the analyst must justify groupings based on musical criteria: contiguity, shared rhythm, metric placement, timbre, texture, articulation, or register.

# Core Definition
Segmentation is arguably the most important and subjective step in set-theory analysis. The flexibility of set theory is a double-edged sword: because any group of pitches can form a set, analysts must be aware of their segmentation choices and justify them musically. Straus (2016) advises balancing "imaginative seeking" with "musical common sense" -- neither restricting oneself to obvious groupings nor plucking notes randomly. Criteria for grouping include: contiguity (notes that are simultaneous or successive), shared rhythmic profile, shared metric placement, shared timbre/texture, shared articulation, and shared register.

# Prerequisites
- Pitch-class set (understanding that any group of pcs can be a set)

# Key Properties
1. Any group of pitches can be a set -- the analyst decides
2. Must be justified by musical criteria (not arbitrary)
3. Criteria: contiguity, rhythm, meter, timbre, texture, articulation, register
4. Contiguous notes are the strongest case; distant notes require more justification
5. Segmentation determines what the analysis reveals
6. Poor segmentation leads to unfalsifiable or meaningless claims

# Context & Application
Segmentation is where musical judgment enters set-theory analysis. Simply identifying one-note "sets" (all equivalent) is not helpful. The best analyses use segmentation that reflects audible musical groupings.

# Examples
**Example 1**: Grouping notes in a single melodic phrase (contiguous, shared rhythm) -- strong case.
**Example 2**: Grouping notes separated by rests or shared by rhythmic pattern -- reasonable case.
**Example 3**: Grouping distant notes while excluding intervening ones -- requires strong justification.
