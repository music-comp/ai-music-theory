# Augmented Dominant

## Quick Definition

A dominant chord (V or V7) with a raised fifth that creates an augmented triad or augmented-major seventh chord—intensifying the dominant's tendency toward resolution by adding an additional leading tone that pulls upward to the third of the tonic, creating a more urgent and chromatic dominant function than the unaltered dominant while maintaining clear functional identity.

## Formal Definition

**Augmented dominant** (V+ or V+7) is a chromatically altered dominant:

**Structure**:
- V+ (augmented triad): ^5-^7-#^2 (root-3rd-raised 5th)
- V+7 (augmented seventh): ^5-^7-#^2-^4 (adds minor seventh)

**In C major**:
```
V+:  G-B-D# (G augmented triad)
V+7: G-B-D#-F (G augmented-major seventh)
```

**Chromatic alteration**: D (^2) raised to D# (#^2)

**Function**: Intensified dominant, still resolves to I/i

## Voice Leading Characteristics

**Two tendency tones resolve upward**:
```
V+ → I (G+ to C):

B  → C (^7 → ^1, leading tone resolution)
D# → E (#^2 → ^3, raised fifth resolution)

Both resolve UP by half step
Creates parallel half-step motion
Intensifies drive to tonic
```

**V+7 → I resolution**:
```
V+7: G - B - D# - F    →    I: C - E - G - (C)
     ↓   ↓    ↓    ↓          ↓   ↓   ↓   ↓
     G → C (P4 up or P5 down)
     B → C (m2 up, leading tone)
     D# → E (m2 up, raised fifth)
     F  → E (m2 down, seventh resolves)

Three voices move by half step
Highly chromatic resolution
```

## Comparison to Regular Dominant

**V vs. V+**:
```
V:  G-B-D   (one leading tone: B → C)
V+: G-B-D#  (two leading tones: B → C, D# → E)

V+ adds urgency through additional chromatic pull
Same function, intensified effect
```

**V7 vs. V+7**:
```
V7:  G-B-D-F  (B → C up, F → E down)
V+7: G-B-D#-F (B → C up, D# → E up, F → E down)

V+7: Three voices move by half step (B, D#, F)
Even more intense chromatic resolution
```

## Resolution Patterns

**Standard V+ → I**:
```
Four-voice realization:
S: D# → E
A: B  → C
T: G  → G (or C)
B: G  → C

Soprano and alto resolve up by half step
Creates characteristic parallel half-step motion
```

**V+ → I with doubling**:
```
If root (G) doubled:
One G → C (bass motion)
Other voices resolve as above
```

**V+7 → I complete**:
```
S: F  → E (seventh resolves down)
A: D# → E (raised fifth resolves up)
T: B  → C (leading tone resolves up)
B: G  → C (root motion)

Three half-step motions simultaneously
Maximum chromatic intensity
```

## Context and Usage

**When to use V+**:
```
- Approaching climactic tonic arrival
- Heightening emotional intensity
- Creating chromatic color
- Extending dominant prolongation
- Romantic/chromatic style
```

**Preparation**:
```
V+ often approached from:
- IV (F in C major)
- ii (Dm in C major)
- Earlier V (embellished)

D natural → D# creates chromatic inflection
```

## Notation and Symbols

**Roman numeral notation**:
```
V+ or V(#5): Augmented dominant triad
V+7 or V7(#5): Augmented dominant seventh
```

**Figured bass**:
```
+ or #5 indicates raised fifth
7/#5 or 7/+ for seventh chord
```

## Musical Context

Augmented dominant serves specific purposes:
- **Intensified resolution**: More urgent than regular V
- **Chromatic color**: Adds expressive chromaticism
- **Double leading tone**: Both ^7 and #^2 resolve up
- **Romantic idiom**: Common in 19th-century music
- **Climactic arrivals**: Precedes important tonics
- **Expressive harmony**: Heightens emotional content
- **Whole-tone hint**: Contains segment of whole-tone scale
- **Clear function**: Unmistakably dominant despite chromatic alteration

Essential chromatic enhancement of dominant function.

## Examples

### Basic

**V+ → I in C major**:
```
V+: G - B - D#    →    I: C - E - G
    ↓   ↓    ↓          ↓   ↓   ↓
    G → C             (root motion)
    B → C             (leading tone up)
    D# → E            (raised fifth up)

B and D# both resolve up by half step
Creates (B-D#) → (C-E) parallel thirds motion
```

**V+7 → I in C major**:
```
V+7: G - B - D# - F    →    I: C - C - E - G
     ↓   ↓    ↓    ↓          ↓   ↓   ↓   ↓
     G → C               (root)
     B → C               (leading tone up)
     D# → E              (raised fifth up)
     F  → E              (seventh down)

Three chromatic resolutions
Maximum intensity dominant
```

**In progression**:
```
C:  I  -  IV  -  V+  -  I
    C     F      G+     C

F chord: F-A-C
G+: G-B-D# (D# chromatic alteration)
Resolution: G+ → C

D natural (from F chord) → D# (V+) → E (I)
Chromatic passing motion through altered dominant
```

**Comparison**:
```
Regular:   C - F - G  - C  (one leading tone: B → C)
Augmented: C - F - G+ - C  (two leading tones: B → C, D# → E)

V+ version more intense, chromatic
Same harmonic function, different color
```

### From Repertoire

**Brahms, Intermezzo Op. 118 No. 2**: V+ creates chromatic climax, D# → E resolution intensifies arrival on tonic.

**Chopin, Nocturne Op. 9 No. 2**: Augmented dominants in cadential approaches, romantic chromatic intensity.

**Wagner, "Tristan und Isolde"**: V+ contributes to chromatic harmonic language, intensified longing.

**Liszt, Piano Sonata in B minor**: V+ at climactic points, augmented fifth resolution creates powerful arrivals.

**Rachmaninoff, Piano Concertos**: Augmented dominants in cadential passages, romantic chromaticism.

## Common Confusions

- V+ = dominant with raised fifth (not "5th inversion" or other)
- Structure: V+ = root-M3-A5 (not M3-M3 stacking)
- In C: V+ = G-B-D# (D raised to D#)
- V+7 = G-B-D#-F (adds minor seventh)
- Two notes resolve up by half step: ^7 → ^1 and #^2 → ^3
- Seventh (if present) still resolves down: ^4 → ^3
- Function is still dominant (resolves to I)
- More intense than regular V (additional chromatic pull)
- Different from V7 (which has perfect fifth)
- D# is NOT a chord tone of C major (chromatic)
- Creates double leading-tone effect
- Common in Romantic music (Brahms, Chopin, Wagner)
- Can be preceded by IV or ii (D natural then altered to D#)
- Symbol: V+, V(#5), V+7, V7(#5)
- Contains portion of whole-tone scale (G-B-D#-F# would be whole-tone)
- Still clearly functional (not ambiguous like isolated + triad)
- Context establishes dominant function despite altered fifth
