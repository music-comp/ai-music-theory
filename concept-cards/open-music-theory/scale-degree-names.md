# Quick Definition

Traditional names for each scale degree: tonic (^1), supertonic (^2), mediant (^3), subdominant (^4), dominant (^5), submediant (^6), leading tone (^7).

# Core Definition

Each note of a major scale has a **scale-degree name**: tonic (^1), supertonic (^2), mediant (^3), subdominant (^4), dominant (^5), submediant (^6), and leading tone (^7). These names derive from intervallic relationships to the tonic: dominant = fifth above; mediant = third above (middle of tonic and dominant); supertonic = second above; subdominant = fifth below; submediant = third below. The prefix "sub-" means "below the tonic." In minor, lowered-^7 is called the **subtonic** (one whole step below tonic) rather than leading tone (one half step below).

# Prerequisites

- **Major scale**: the context for these names
- **Scale degree**: the numbering system these names parallel

# Key Properties

- ^1 = tonic (the "home" pitch)
- ^2 = supertonic (super = above; a second above tonic)
- ^3 = mediant (middle between tonic and dominant)
- ^4 = subdominant (a fifth below tonic)
- ^5 = dominant (inherited from medieval theory; the important fifth)
- ^6 = submediant (a third below tonic)
- ^7 = leading tone (half step below tonic) or subtonic (whole step below tonic)

# Construction / Recognition

The names apply to scale positions, not specific pitches. In any major key, ^5 is always the "dominant" regardless of what note it is.

# Context & Application

Scale-degree names are used extensively in harmonic analysis ("dominant chord," "subdominant chord"). Understanding the derivation of names (intervals above and below tonic) helps memorize them.

# Examples

- In C major: C=tonic, D=supertonic, E=mediant, F=subdominant, G=dominant, A=submediant, B=leading tone
- In A minor: G (lowered-^7) = subtonic; G# (raised ^7) = leading tone

# Common Errors

- Calling ^7 the "leading tone" when it is a whole step below tonic (that is the subtonic)

# Common Confusions

- Leading tone vs. subtonic: leading tone = half step below tonic; subtonic = whole step below tonic
- Subdominant means "a fifth below tonic," not "below the dominant"
