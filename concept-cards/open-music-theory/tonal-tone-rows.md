# Tonal Tone Rows

## Quick Definition

Tonal tone rows are twelve-tone rows deliberately constructed to incorporate tonal elements such as triads, perfect fifths, or diatonic segments, allowing composers to combine serial organization with the sound world of extended tonality—exemplified by Alban Berg's Violin Concerto (with its embedded triads and whole-tone segment), Hale Smith's Evocation (with quartal jazz-influenced harmony), and Benjamin Britten's Turn of the Screw (with its quartal structure organizing both theme and tonal areas).

## Formal Definition

**Tonal tone row**: A twelve-tone row designed to include tonal sonorities.

**Common features**:
- Embedded triads (major, minor, augmented, diminished)
- Perfect fifth/fourth chains
- Diatonic segments
- Quartal harmony
- Whole-tone segments
- Scalar passages

**Row design strategies**:
```
Triadic embedding:
Row segment: ...G-B-D... = G major triad
Row segment: ...C-Eb-G... = C minor triad

Fifth chains:
Row segment: ...C-G-D-A-E... = circle of fifths

Quartal structure:
Row segment: ...C-F-Bb-Eb... = perfect fourths
```

**Distinction from "pure" twelve-tone**:
- Traditional twelve-tone: avoids tonal implications
- Tonal tone rows: deliberately includes them
- Same technique, different aesthetic goals

## Musical Context

Tonal tone rows serve:
- **Bridge function**: Connects serial and tonal worlds
- **Expressive range**: Tonal colors within serial framework
- **Historical continuity**: Links to tradition while innovating
- **Stylistic synthesis**: Serial technique + tonal sound

**Composers using tonal rows**:
- Berg: Synthesis of Romantic expression and serial method
- Smith: Jazz harmonies within twelve-tone framework
- Britten: Tonal centricity with serial organization
- Others: Various combinations of tonal/serial

**Critical perspective**:
- Some see as "compromise" or dilution of serial principles
- Others see as creative synthesis
- Demonstrates flexibility of twelve-tone technique

## Examples

### Basic

**Triadic embedding**:
```
Row with triads:
C-E-G | B-D-F# | Bb-Db-F | A-C-Eb
 C+     B+/D     Bb+      Am/Eb-

Each trichord = major or minor triad
Tonal sonorities available throughout row
```

**Fifth chain**:
```
Row opening: C-G-D-A-E-B-...
             ↑ ↑ ↑ ↑ ↑ ↑
            All perfect fifths

Sounds like circle of fifths progression
Serial structure, tonal sound
```

**Quartal structure**:
```
Row: C-F-Bb-Eb-Ab-Db | Gb-B-E-A-D-G
     |←  fourths  →|   |← fourths →|

Built from stacked perfect fourths
Jazz-influenced sound
Still a twelve-tone row
```

### From Repertoire

**Berg, Violin Concerto** (1935):
```
Row: G-Bb-D-F#-A-C-E-G#-B-C#-Eb-F
     ↓
     Contains:
     G-Bb-D = G minor triad
     Bb-D-F# = Bb augmented (or D major)
     D-F#-A = D major triad
     A-C-E = A minor triad
     etc.

     Final four notes: B-C#-Eb-F = whole-tone segment

Allows:
- Tonal chord progressions
- Quote of Bach chorale (Es ist genug)
- Deeply expressive despite serial technique

"To the memory of an angel" (elegy)
Synthesis of tradition and innovation
```

**Hale Smith, Evocation**:
```
Row features set class [0,2,7] prominently

Quartal/quintal structure:
- Fourth + second = [0,2,7]
- Jazz-influenced sonority
- Bop and post-bop harmonic stylings

Maxile (2004): "quartal harmonic and
improvisational stylings of bop and post-bop"

African-American composer
Serial technique + jazz heritage
```

**Britten, Turn of the Screw**:
```
Row/theme: A-B-C-D-E-F#-G#-A#-...
Based on quartal structure

Tonal centers for acts:
Also serialized from same material!
- Theme serves as row
- Transpositions = different keys
- Serial organization of tonality itself

Unique synthesis:
- Opera (dramatic form)
- Serial pitch organization
- Tonal key scheme
- Ghost story subject matter
```

**Non-pitch tonal elements**:
```
Even non-tonal rows:
- Schoenberg often used tonal FORMS
- Waltzes, sonatas, etc.
- Tonal rhythms and phrase structures
- Serial pitch + tonal everything else

Twelve-tone technique doesn't dictate:
- Rhythm (usually free)
- Form (often traditional)
- Texture (varied)
- Expression (from austere to lush)
```

## Common Confusions

- Tonal tone rows = rows deliberately including tonal elements
- NOT a contradiction (serial technique, tonal sound)
- Berg's Violin Concerto is famous example
- Embedded triads, fifths, diatonic segments possible
- Demonstrates flexibility of twelve-tone technique
- Jazz harmony can be incorporated (Smith, Evocation)
- Quartal structures bridge twelve-tone and jazz
- Britten serialized tonal centers (Turn of the Screw)
- Even "pure" serialists often used tonal forms
- Schoenberg used waltzes, sonatas with serial pitch
- Tonal tone rows one point on spectrum of approaches
- Not all twelve-tone must avoid tonal reference
- Synthesis, not compromise, for many composers
