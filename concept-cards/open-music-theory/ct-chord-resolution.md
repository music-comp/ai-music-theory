# Common-Tone Chord Resolution

## Quick Definition
Common-tone chords resolve by returning to the chord they embellished, with the common tone sustaining throughout while the neighbor tones move back by half step to their original chord tones, creating a prolongational pattern that decorates rather than progresses the harmony.

## Formal Definition
**Common-tone chord resolution** involves:

**Return to origin**: The CT chord resolves to the same chord it departed from

**Common tone sustains**: One pitch holds throughout the progression

**Neighbor tones resolve**: Other voices return to original pitches

**Half-step motion**: Chromatic neighbors move by half step

**No functional progression**: Embellishes rather than progresses

## Resolution Pattern

**Basic pattern**:
```
Chord -> CT chord -> Same chord

I - CT°7 - I
V - CT°7 - V
I - CT+6 - I
```

**Voice leading**:
```
Each voice returns to its starting pitch:

C major: C - E - G - C
CT°7:    C - Eb - Gb - A
C major: C - E - G - C

C: stays (common tone)
Eb -> E (up half step)
Gb -> G (up half step)
A -> C (resolves back, unusual motion)
```

## CT°7 Resolution

**To tonic (I)**:
```
I:        C - E - G - C
CT°7:     C - Eb - Gb - Bbb(A)
I:        C - E - G - C

All neighbors resolve back:
Eb -> E (chromatic lower neighbor resolves up)
Gb -> G (chromatic lower neighbor resolves up)
Bbb -> C (enharmonic A, resolves up)
C -> C (common tone holds)
```

**To dominant (V)**:
```
V:        G - B - D - G
CT°7:     G - Bb - Db - Fb(E)
V:        G - B - D - G

All neighbors resolve back:
Bb -> B (chromatic lower neighbor)
Db -> D (chromatic lower neighbor)
Fb -> G (unusual motion, or E if respelled)
G -> G (common tone)
```

## CT+6 Resolution

**To tonic (I)**:
```
I:        C - E - G - C
CT+6:     C - Eb - F# - Ab
I:        C - E - G - C

All neighbors resolve back:
Eb -> E (lower neighbor, up half step)
F# -> G (lower neighbor, up half step)
Ab -> G (upper neighbor, down) or Ab -> C (back to root)
C -> C (common tone)
```

**The augmented sixth resolves differently**:
```
In CT+6:
The A6 interval (Ab-F#) doesn't expand to octave
Instead, both notes return to G!
Ab -> G (down)
F# -> G (up)

This is opposite of functional Ger+6
Where A6 expands to P8 on ^5
```

## Resolving to V7

**CT°7 bridging I to V7**:
```
I:        C - E - G - C
CT°7:     C - Eb - Gb - A
V7:       B - D - F - G

Not returning to same chord!
This is CT°7 as passing chord
C (common tone) -> B
Eb -> D
Gb -> F
A -> G

Still embellishing, but continuing to V7
Less common usage
```

**Incomplete resolution**:
```
Sometimes CT chord doesn't resolve fully:

I:        C - E - G - C
CT°7:     C - Eb - Gb - A
I (varied): C - E - G - E (different voicing)

Not all voices return to exact starting pitch
Function is still embellishment
```

## Comparison with Functional Resolution

**Functional Ger+6 resolution**:
```
Ger+6:    Ab - C - Eb - F#
I64:      G - C - E - G
V:        G - B - D - G

PROGRESSES to different chord
A6 expands to P8
Function is predominant -> dominant
```

**CT+6 resolution**:
```
I:        C - E - G - C
CT+6:     C - Eb - F# - Ab (same pitches as Ger+6!)
I:        C - E - G - C

RETURNS to same chord
A6 doesn't expand (both go to G)
Function is embellishment
```

**Key difference**: Functional chords progress, CT chords return

## Recognition by Resolution

**Identifying CT chords by context**:
```
If °7 or +6 chord is followed by:
- Same chord that preceded it -> CT chord
- Different chord (especially V) -> Functional chord

Resolution tells the function!
```

**Listening cue**:
```
CT chord: Hear chord, dissonance, SAME chord
Functional: Hear chord, dissonance, DIFFERENT chord

The return is the signature of CT function
```

## Musical Context

Common-tone chord resolution demonstrates:
- **Prolongation**: Extends single harmony
- **Return**: Resolution back to origin
- **Chromatic color**: Neighbor-tone motion adds chromaticism
- **Non-functional**: Decorates without progressing
- **Romantic device**: Common in 19th-century style
- **Voice leading clarity**: Each voice has clear path

## Examples

### Basic

**CT°7 resolving to tonic**:
```
In C major:
I:     C - E - G - E
       |   |   |   |
CT°7:  C - Eb- Gb- A
       |   |   |   |
I:     C - E - G - E

C = common tone throughout
All neighbors return by half step (or equivalent)
```

**CT+6 resolving to tonic**:
```
In C major:
I:     C - E - G - C
       |   |   |   |
CT+6:  C - Eb- F#- Ab
       |   |   |   |
I:     C - E - G - C

C = common tone
Eb -> E, F# -> G, Ab -> G or C
Darker sound than CT°7
```

**CT°7 resolving to dominant**:
```
In C major:
V:     G - B - D - G
       |   |   |   |
CT°7:  G - Bb- Db- E
       |   |   |   |
V:     G - B - D - G

G = common tone
Embellishes dominant harmony
```

### From Repertoire

**Chopin, Nocturne Op. 9 No. 2**: CT°7 embellishments with clear return resolutions.

**Brahms, Intermezzo Op. 118 No. 2**: CT chords resolve back to prolonged harmonies.

**Schubert, Impromptu D. 899 No. 3**: CT+6 resolutions in embellishing passages.

**Romantic period generally**: CT chord resolution as standard technique.

## Common Confusions

- CT chords resolve by returning to the same chord
- **Pattern**: Chord -> CT -> Same Chord (I - CT°7 - I)
- Common tone sustains throughout
- Neighbor tones return by half step
- CT°7: Neighbors resolve to original chord tones
- CT+6: All three chromatic neighbors resolve back
- **A6 in CT+6 doesn't expand** (unlike functional Ger+6)
  - Both Ab and F# go to G (not to octave)
- Resolution identifies function:
  - Returns to same chord = CT (embellishing)
  - Goes to different chord = Functional (progressing)
- Incomplete resolution possible (not all voices return exactly)
- CT°7 can bridge I to V7 (passing function)
- But most common is return resolution (prolongation)
- Listen for: Chord - dissonance - SAME chord
