# Chord-Scale Theory

## Quick Definition

An approach to jazz improvisation that associates each chord in a progression with a corresponding scale that contains all chord tones plus available extensions.

## Formal Definition

**Chord-Scale Theory** is a method for jazz improvisation that relates chords to scales. The core concept is that a thirteenth chord, when rearranged stepwise, yields a seven-note scale:

**The relationship**: A Dm13 chord (D-F-A-C-E-G-B) contains the same pitches as the D dorian mode (D-E-F-G-A-B-C).

**Basic chord-scale correspondences** (in a major key):
- **ii7 -> Dorian mode** (2nd mode)
- **V7 -> Mixolydian mode** (5th mode)
- **Imaj7 -> Ionian mode** (1st mode)

**Extended correspondences**:
- iii7 -> Phrygian (3rd mode)
- IV maj7 -> Lydian (4th mode)
- vi7 -> Aeolian (6th mode)
- vii half-dim7 -> Locrian (7th mode)

Roman numerals correspond to mode numbers (ii = 2nd mode, V = 5th mode, etc.).

## Musical Context

Chord-Scale Theory, based on George Russell's Lydian Chromatic Concept (1953) and popularized by Berklee College of Music, provides a systematic approach for beginning improvisers to make pitch choices.

The method is not about modulating to a new key with each chord, but about using diatonic modes to color chords within a key center. Chord tones should fall on downbeats; scale tones fill in as passing tones or extensions.

## Examples

### Basic

ii-V-I in C major:
- Dm7 -> D dorian (D-E-F-G-A-B-C)
- G7 -> G mixolydian (G-A-B-C-D-E-F)
- Cmaj7 -> C ionian (C-D-E-F-G-A-B)

All three scales contain the same pitches (C major), but each starts on the chord's root.

### From Repertoire

"Tune Up" (Miles Davis): A straightforward application of chord-scale relationships through multiple ii-V-I progressions.

"Giant Steps" (John Coltrane): Coltrane's solo demonstrates ionian on major chords, mixolydian on dominant chords, and dorian on minor chords, using arpeggios and scale fragments.

"Fly Me to the Moon" (Bart Howard): Contains six of the seven diatonic chord-scale relationships in a circle-of-fifths progression.

## Related Concepts

- **Prerequisite**: diatonic-modes, ii-v-i-progression, seventh-chord
- **See also**: extension

## Common Confusions

- Chord-Scale Theory does NOT mean each chord is a new key; the key center remains stable
- The mode provides available pitches, not a sequence to play mechanically
- Chord tones should be emphasized on strong beats; scale tones are passing/connecting
- Different chords of the same quality have different scales based on function (vi7 vs. ii7)
- The approach has limitations: it doesn't account for voice leading, chromaticism, or blues elements
