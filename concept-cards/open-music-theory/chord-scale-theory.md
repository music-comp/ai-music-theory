# Quick Definition
Chord-Scale Theory relates each chord in a progression to a parent scale: a thirteenth chord rearranged as a seven-note scale. For ii-V-I: dorian over ii (mi7), mixolydian over V (dom7), ionian over I (ma7). Roman numerals map to mode numbers (ii = 2nd mode = dorian). Place chord tones on downbeats to connect improvised melody to the progression.

# Core Definition
Based on George Russell's Lydian Chromatic Concept (1953), popularized by Aebersold, Baker, and Coker. Basic relationships: ii = dorian, V = mixolydian, I = ionian. All seven diatonic modes relate to Roman numerals (iii = phrygian, IV = lydian, vi = aeolian, viio = locrian). Multiple chord-scale choices exist for each quality (e.g., mi7 can use dorian, phrygian, or aeolian), but Roman numeral analysis helps choose the best fit for the key center. A seven-note mode = four-note seventh chord + three passing tones/extensions. Limitations: absence of voice leading between chords, lack of bebop/blues chromaticism, anachronism when applied to pre-1960s styles, and emphasis on eye/intellect over ear/intuition and the oral tradition.

# Key Properties
1. Each chord relates to a parent scale (thirteenth chord rearranged)
2. Roman numeral = mode number (ii = 2nd mode = dorian)
3. Basic: dorian (ii), mixolydian (V), ionian (I)
4. Chord tones on downbeats connect melody to harmony
5. Mode = chord + 3 passing tones (^2, ^4, ^6 or 9th, 11th, 13th)
6. Key-center awareness prevents treating each chord as a new key
7. Can be extended with melodic minor, harmonic minor, harmonic major modes

# Context & Application
"Tune Up" (Miles Davis): straightforward dorian-mixolydian-ionian over ii-V-I. "Fly Me to the Moon": six of seven diatonic chord-scale relationships in circle-of-fifths root movement. "Giant Steps" (Coltrane): fast tempo forces arpeggios and scale fragments, ionian on major, mixolydian on dominant, dorian on minor. Limitations acknowledged by educators: Hal Galper and Hal Crook emphasize melodic embellishment and blues-based improvisation before chord-scale relationships.

# Examples
**Example 1** ("Tune Up"): Emi7 (E dorian) - A7 (A mixolydian) - Dma7 (D ionian).
**Example 2** ("Giant Steps"): Coltrane uses ionian, mixolydian, and dorian scale fragments at high speed.

# Common Confusions
- **Confusion**: Each chord change means a new key.
  **Clarification**: Chord-scales color chords within a key center, not separate keys. Roman numeral analysis identifies the correct mode for each chord's function.
