# Augmented Triad Voice Leading

## Quick Definition

The characteristic voice-leading patterns associated with augmented triads, wherein the augmented fifth (or enharmonically respelled diminished fourth) creates a tendency tone that typically resolves outward by half step to expand the interval—enabling smooth chromatic connections between stable triads, often through parsimonious voice leading where only one or two notes change while common tones are retained.

## Formal Definition

**Augmented triad voice leading** describes resolution patterns of + chords:

**Primary tendency**:
- Augmented fifth expands outward by half step
- Creates resolution to major sixth or perfect fifth
- Direction determined by context

**Voice-leading parsimony**:
```
+ triad differs from adjacent major/minor triads by one semitone
C+ (C-E-G#) → C (C-E-G): G# → G (one note moves)
C+ (C-E-G#) → Am (A-C-E): G# → A, C common, E common
```

**Resolution possibilities**:
```
Augmented fifth can:
1. Expand upward: G# → A (to major sixth)
2. Contract downward: G# → G (to perfect fifth)
3. Hold as common tone (enharmonic reinterpretation)
```

## Resolution to Stable Triads

**Augmented to major (same root)**:
```
C+ → C
C-E-G# → C-E-G

Only G# moves (down to G)
Returns augmented fifth to perfect fifth
Common tones: C, E
One-note voice leading
```

**Augmented to major (different root)**:
```
C+ → F
C-E-G# → C-F-A

G# → A (up)
E → F (up)
C = common tone
Two notes move by half step
```

**Augmented to minor**:
```
C+ → Am
C-E-G# → A-C-E

G# → A (up)
C, E = common tones
One note moves by half step
```

## V+ Resolution Patterns

**V+ → I (most common)**:
```
In C major:
G+ (G-B-D#) → C (C-E-G)

G → C (P5 up / P4 down)
B → C (m2 up, leading tone)
D# → E (m2 up, augmented fifth resolves)

Two chromatic resolutions (B, D#)
Strong drive to tonic
```

**V+ → I voice leading detail**:
```
Soprano: D# → E (augmented fifth up)
Alto:    B  → C (leading tone up)
Tenor:   G  → G (common tone or to C)
Bass:    G  → C (root motion)

Parallel half-step motion (D#-B) → (E-C)
Creates intense resolution
```

## Common Tone Augmented Sixth

**Relation to augmented sixth chords**:
```
German+6: A-flat-C-E-flat-F# (in C)
C+:       C-E-G#

Different chords, but both contain augmented interval
Both feature half-step resolution of augmented interval
```

**CT+6 voice leading**:
```
C: I - CT+6 - I
   C   A-flat-C-E-flat-F#   C

Common tone: C retained
Chromatic neighbor motion in other voices
Returns to same harmony
```

## Connecting Major Triads by Third

**Major third cycle voice leading**:
```
C major → E major → G#/A-flat major → C major

C-E-G → E-G#-B → G#-B#-D# → C-E-G

Each step: one note changes
G → G# (C → E)
B → B# (E → G#)
D# → E (G# → C)

Smooth chromatic cycle
Augmented triad = pivot point
```

**Through augmented triad**:
```
C → C+ → E
C-E-G → C-E-G# → E-G#-B

C → C+ : G → G# (one note)
C+ → E : C → B (enharmonic: C+ = E+)

Augmented triad mediates between M3-related triads
```

## Parsimonious Voice Leading

**Minimal motion principle**:
```
From C+, reach many triads with minimal voice leading:

C+ (C-E-G#) to:
C (C-E-G):   G# → G (1 note, down)
E (E-G#-B):  C → B (1 note, down)
Am (A-C-E):  G# → A (1 note, up)
F (C-F-A):   E → F, G# → A (2 notes, both up)

High connectivity with small motions
```

**Neo-Riemannian perspective**:
```
Augmented triad = vertex in neo-Riemannian space
Connects multiple major/minor triads
Represents maximally smooth voice leading point
```

## Musical Context

Augmented triad voice leading enables:
- **Chromatic connection**: Links stable harmonies smoothly
- **Intensified dominant**: V+ stronger resolution than V
- **Third relations**: Facilitates modulation by M3
- **Romantic chromaticism**: Expressive voice leading
- **Impressionist color**: Whole-tone connections
- **Parsimonious motion**: Minimal voice changes
- **Ambiguity resolution**: Context clarifies interpretation
- **Film music**: Creates tension and release

Essential for understanding chromatic voice leading and smooth harmonic motion.

## Examples

### Basic

**V+ → I resolution** (C major):
```
G+: G - B - D#    →    C: C - E - G
    ↓   ↓   ↓           ↓   ↓   ↓
    G → C (P4 up)
    B → C (m2 up, leading tone)
    D# → E (m2 up, augmented 5th resolves)

Both tendency tones (B, D#) resolve up by half step
Intensifies resolution to tonic
```

**C+ to adjacent triads**:
```
To C major:  C+ (C-E-G#) → C (C-E-G)
             G# → G (half step down)
             
To A minor:  C+ (C-E-G#) → Am (A-C-E)
             G# → A (half step up)
             
To E major:  C+ (C-E-G#) → E (E-G#-B)
             C → B (half step down, enharmonic shift)

Each requires only one voice to move by half step
```

**Major third cycle via +**:
```
C → C+ → E → E+ → G# → G#+ → C

C (C-E-G) → C+ (C-E-G#): G→G#
C+ → E (E-G#-B): C→B (or reinterpret C+ as E+)
E → E+ (E-G#-B#): B→B#
E+ → G# (G#-B#-D#): E→D# (or reinterpret E+ as G#+)
...

Complete M3 cycle
Augmented triads facilitate each step
```

**Passing augmented triad**:
```
C - C+ - Am
I    +   vi

C: C-E-G
C+: C-E-G# (G rises to G#)
Am: A-C-E (G# rises to A)

Chromatic passing motion: G → G# → A
Connects I to vi smoothly
```

### From Repertoire

**Liszt, "Transcendental Etude No. 10"**: V+ resolutions create intense climaxes, augmented fifth voice leading drives tension.

**Debussy, "Preludes"**: Augmented triads move to related harmonies, parsimonious voice leading creates floating effect.

**Wagner, "Parsifal"**: Augmented triads in sacred/mystical passages, smooth chromatic voice leading.

**Ravel, "Daphnis et Chloe"**: Augmented chord progressions, voice-leading parsimony creates orchestral color.

**Film scores (John Williams)**: V+ resolutions for dramatic moments, augmented fifth resolution intensifies arrivals.

## Common Confusions

- Augmented fifth = tendency tone (wants to resolve)
- Primary resolution: outward by half step (G# → A)
- Can also contract: G# → G (return to perfect fifth)
- V+ → I = most common augmented triad resolution
- In V+, both leading tone AND augmented fifth resolve up
- Creates double half-step resolution (intensified dominant)
- Augmented triad connects to M3-related major triads
- C+ connects C major to E major to A-flat major
- Parsimonious voice leading: only 1-2 notes move
- Neo-Riemannian theory formalizes these relationships
- Different from augmented sixth (different structure, similar interval)
- CT+6 = common-tone augmented sixth (embellishing function)
- Voice leading determines enharmonic interpretation
- Symmetry means multiple valid spellings
- Context (approach and resolution) clarifies function
- Romantic/Impressionist composers exploit smooth voice leading
- More about color and connection than functional progression
