# Passing Six-Four

## Quick Definition

A second-inversion triad (typically I⁶₄) where the bass note functions as a **passing tone** between two other chord tones—creating linear stepwise bass motion while the upper voices sustain or move by step, occurring on a weak beat as an unaccented embellishment, used to prolong a harmony (often tonic) through scalewise bass motion, notated with ⁶₄ figured bass but analyzed as embellishment rather than structural chord, distinguished from cadential six-four (which occurs on strong beat before V) and neighbor six-four (which involves neighbor motion), and common in Classical music for creating smooth voice leading and harmonic prolongation through linear bass movement.

## Formal Definition

**Passing six-four** is a second-inversion triad with a passing tone in the bass.

**Characteristics**:
- **Bass = passing tone**: Connects two chord tones stepwise
- **Weak beat**: Unaccented (unlike cadential ⁶₄)
- **Linear motion**: Bass moves scalewise
- **Prolongation**: Extends single harmony
- **Upper voices**: Usually sustain or move by step
- **Most common**: I⁶₄ passing between I and I⁶ (or reverse)

**Function**: Embellishment through linear bass motion

**Not functional**: Doesn't create new harmony, just passing motion

## Passing Six-Four Patterns

**I - I⁶₄ - I⁶** (ascending bass):
```
I:      C-E-G    I⁶₄:  G-C-E    I⁶:  E-G-C
Bass:   C    →   D   →   E

^1-^2-^3 bass ascent (passing)
D (^2) is passing tone
Prolongs tonic through stepwise bass
```

**I⁶ - I⁶₄ - I** (descending bass):
```
I⁶:  E-G-C    I⁶₄:  G-C-E    I:  C-E-G
Bass: E   →   D   →   C

^3-^2-^1 bass descent (passing)
D (^2) is passing tone
Returns from I⁶ to root position
```

**V⁶₄ passing** (less common):
```
V - V⁶₄ - V⁶
Bass passes through ^6
Similar linear function
```

## Voice Leading

**Standard passing six-four**:
```
        I       I⁶₄      I⁶
S:      G   →   G   →   G   (sustained)
A:      E   →   E   →   E   (sustained)
T:      C   →   C   →   C   (sustained)
B:      C   →   D   →   E   (PASSING, stepwise)

Upper voices sustain
Bass passes through D
Weak beat placement
```

**With upper voice motion**:
```
        I       I⁶₄      I⁶
S:      E   →   E   →   E
A:      C   →   C   →   C
T:      G   →   G   →   G or C
B:      C   →   D   →   E   (passing)

Still emphasizes bass passing motion
Upper voices may sustain or move slightly
```

## Passing vs. Other Six-Four Types

**vs. Cadential six-four**:
- **Cadential**: Strong beat, resolves to V, functional
- **Passing**: Weak beat, passes, embellishing

**vs. Neighbor six-four**:
- **Neighbor**: Bass is neighbor tone (returns to same pitch)
- **Passing**: Bass continues to different pitch

**vs. Arpeggiating six-four**:
- **Arpeggiating**: Bass arpeggiates same chord
- **Passing**: Bass connects different chord positions

**Passing is unaccented, linear, connects positions**

## Metric Placement

**Weak beat** (crucial):
```
Beat:    1    2    3    4
         I   I⁶₄   I⁶
         str weak  str

I⁶₄ on weak beat 2
Passing function
Not accented
```

**Compare to cadential**:
```
Beat:    1    2    3    4
        I⁶₄   V    I
        str  weak  str

Cadential ⁶₄ on STRONG beat
Functional, not passing
Accented dissonance
```

## Musical Context

Passing six-four serves specific purposes:
- **Linear bass motion**: Stepwise connection
- **Tonic prolongation**: Extends I through bass motion
- **Weak beat**: Unaccented embellishment
- **Voice leading smoothness**: Connects chord positions
- **Non-functional**: Doesn't create new harmony
- **Classical phrase structure**: Common in tonic zones
- **Embellishment**: Decorates through passing motion

Common device for prolonging harmony with linear bass.

## Examples

### Basic

**I-I⁶₄-I⁶** (C major):
```
        I       I⁶₄      I⁶
Chord:  C-E-G   G-C-E    E-G-C
Bass:   C   →   D   →   E   (^1-^2-^3, passing)

D is passing tone
Weak beat placement
Prolongs tonic
```

**Voice leading**:
```
        I       I⁶₄      I⁶
S:      G   →   G   →   G   (sustained)
A:      E   →   E   →   E   (sustained)
T:      C   →   C   →   C   (sustained)
B:      C   →   D   →   E   (PASSING)

Only bass moves
Upper voices static
Clear passing motion
```

**I⁶-I⁶₄-I** (reverse):
```
        I⁶      I⁶₄      I
Bass:   E   →   D   →   C   (^3-^2-^1, passing)

Descending bass
D passing from E to C
Returns to root position
```

**In phrase context**:
```
mm. 1-2: I - I⁶₄ - I⁶  (tonic prolongation with passing bass)
mm. 3-4: IV - V - I     (functional progression)

Opening uses passing ⁶₄
Then moves to cadence
```

**With vii°6**:
```
I - vii°6 - I⁶₄ - I⁶

Bass: C-D-D-E (or C-D-E with vii°6 passing)
Combination of passing motions
Prolongs tonic
```

### From Repertoire

**Mozart, Piano Sonatas**: Passing ⁶₄ in tonic prolongations, I-I⁶₄-I⁶ common phrase openings, smooth bass motion.

**Haydn, String Quartets**: Passing six-four connects chord positions, demonstrates Classical voice leading, weak beat placement.

**Beethoven, Piano Sonatas**: I⁶₄ passing in phrase interiors, linear bass motion prolongs harmony.

**Bach, Chorales**: Passing six-four less prominent (Baroque shorter phrases), but appears in longer passages.

**Classical period generally**: Passing ⁶₄ standard for tonic prolongation with linear bass, distinguished from cadential ⁶₄ by weak beat placement.

## Related Concepts

- **Prerequisite**: passing-tone, chord, voice-leading
- **Leads to**: cadential-six-four, neighbor-six-four, tonic-prolongation

## Common Confusions

- Passing six-four = I⁶₄ (or other ⁶₄) with **passing tone in bass**
- Bass moves **stepwise** (passing motion)
- Occurs on **weak beat** (unaccented)
- Function: **Prolongation** (extends harmony through linear motion)
- Most common: I-I⁶₄-I⁶ (ascending) or I⁶-I⁶₄-I (descending)
- Different from **cadential ⁶₄** (strong beat, before V, functional)
- Different from **neighbor ⁶₄** (bass returns to same note)
- Different from **arpeggiating ⁶₄** (bass arpeggiates same chord)
- Upper voices usually sustain (bass is active voice)
- Bass pattern: ^1-^2-^3 or ^3-^2-^1 (passing through ^2)
- ⁶₄ figured bass (6th and 4th above bass)
- Non-functional (doesn't create new harmony)
- Embellishment (decorates through motion)
- Classical tonic prolongation device
- Weak beat crucial (distinguishes from cadential)
- Stepwise bass motion (connects positions)
- "Passing" refers to bass function (passing tone)
- Can occur with any triad (I⁶₄ most common)
- Creates smooth voice leading
