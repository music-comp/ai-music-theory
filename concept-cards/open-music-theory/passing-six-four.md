# Quick Definition

A passing 6/4 chord is built on a passing tone in the bass, prolonging tonic or predominant harmonies. The chords on both sides of a passing 6/4 always have the same function.

# Core Definition

The **passing 6/4** (pass. 6/4) is a 6/4 chord built on a passing tone in the bass (OMT, Ch. IV.9). It most commonly prolongs tonic or predominant harmonies. The chords on both sides of the pass. 6/4 are always the same function (e.g., I-pass.6/4-I6, or IV6-pass.6/4-ii6). The progression can also work backward (e.g., I6-pass.6/4-I).

# Prerequisites

- **Cadential six-four** — Understanding 6/4 chord types requires knowing the cadential 6/4 first
- **Tonic prolongation** — Pass. 6/4 is one method of prolongation

# Key Properties

1. Built on a passing tone in the bass (three stepwise bass notes)
2. Chords on both sides have the SAME function
3. Most commonly prolongs tonic (I-pass.6/4-I6) or predominant (IV6-pass.6/4-ii6)
4. Bass doubles in the 6/4 chord (same as cad. 6/4)
5. Can work in either direction (ascending or descending bass)

# Construction / Recognition

## To Write:
1. Write the bass: three stepwise notes where first and last belong to the same functional area
2. Spell the pass. 6/4: fourth and sixth above the middle bass note; double the bass
3. Write soprano: should be a moving line (stepwise), not static
4. Fill in inner voices with minimal motion

## To Recognize:
1. Find a 6/4 chord
2. Check: is the bass a passing tone (stepwise between two notes)?
3. Check: are the surrounding chords the same function?
4. If yes: passing 6/4

# Relationships

## Builds Upon
- **Tonic prolongation** — Pass. 6/4 is an additional prolongation technique

## Contrasts With
- **Cadential six-four** — Cad. 6/4 embellishes dominant; pass. 6/4 prolongs a function via passing bass
- **Neighbor six-four** — N. 6/4 uses static bass with neighbor motion above; pass. 6/4 uses stepwise bass

# Common Errors

- **Error**: Placing pass. 6/4 between chords of different functions
  **Correction**: Both surrounding chords must be the same function (both tonic, or both predominant)

# Common Confusions

- **Confusion**: Labeling a passing 6/4 as a cadential 6/4
  **Clarification**: Check the bass: if it is a passing tone (stepwise), it is pass. 6/4; if it is sol (^5) with 6-5, 4-3 resolution, it is cad. 6/4
