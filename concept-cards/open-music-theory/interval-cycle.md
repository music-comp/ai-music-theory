# Interval Cycle

## Quick Definition

A sequence of pitches generated by repeatedly adding the same interval, eventually cycling back to the starting pitch class--the cycle length depends on whether the generating interval divides evenly into 12 semitones: cycles of minor seconds produce all 12 pitch classes, cycles of perfect fifths also traverse all 12 (the "circle of fifths"), while cycles of minor thirds produce only 4 pitches (a diminished seventh chord), major thirds produce only 3 (an augmented triad), and tritones produce only 2, demonstrating how interval cycles are foundational to symmetrical pitch collections.

## Formal Definition

**Interval cycle** (pitch-class cycle) is the sequence of pitch classes generated by iterating a constant interval. Given a starting pitch class p and an interval i (in semitones):

**Cycle notation**: C(i) denotes the cycle generated by interval i

**Cycle length**: The number of distinct pitch classes before returning to start
- Length = 12 / GCD(i, 12)
- Where GCD = Greatest Common Divisor

**Complete vs. Incomplete cycles**:
- **Complete cycle**: Contains all 12 pitch classes (interval and 12 are coprime)
- **Incomplete cycle**: Contains fewer than 12 pitch classes (interval divides 12)

## The Twelve Interval Cycles

| Interval | Semitones | GCD(i,12) | Cycle Length | Result |
|----------|-----------|-----------|--------------|--------|
| m2 | 1 | 1 | 12 | Chromatic scale |
| M2 | 2 | 2 | 6 | Whole-tone scale |
| m3 | 3 | 3 | 4 | Diminished 7th chord |
| M3 | 4 | 4 | 3 | Augmented triad |
| P4 | 5 | 1 | 12 | Circle of fourths |
| A4/d5 | 6 | 6 | 2 | Tritone dyad |
| P5 | 7 | 1 | 12 | Circle of fifths |
| m6 | 8 | 4 | 3 | Augmented triad (inverted) |
| M6 | 9 | 3 | 4 | Diminished 7th (inverted) |
| m7 | 10 | 2 | 6 | Whole-tone (inverted) |
| M7 | 11 | 1 | 12 | Chromatic (inverted) |

## Complete Cycles (Length 12)

**C(1) - Minor second cycle = Chromatic scale**:
```
C - C# - D - D# - E - F - F# - G - G# - A - A# - B - (C)
Interval: +1 semitone repeatedly
Contains: All 12 pitch classes
```

**C(5) - Perfect fourth cycle = Circle of fourths**:
```
C - F - Bb - Eb - Ab - Db - Gb - B - E - A - D - G - (C)
Interval: +5 semitones repeatedly
Contains: All 12 pitch classes
Same pitch classes as chromatic, different ORDER
```

**C(7) - Perfect fifth cycle = Circle of fifths**:
```
C - G - D - A - E - B - F# - C# - G# - D# - A# - F - (C)
Interval: +7 semitones repeatedly
Contains: All 12 pitch classes
Retrograde of C(5)
```

**C(11) - Major seventh cycle**:
```
C - B - A# - A - G# - G - F# - F - E - D# - D - C# - (C)
Interval: +11 semitones = -1 semitone
Retrograde of chromatic scale
```

## Incomplete Cycles (Symmetrical Collections)

**C(2) - Major second cycle = Whole-tone scale**:
```
C - D - E - F# - G# - A# - (C)
Interval: +2 semitones repeatedly
Length: 6 pitch classes
Two distinct starting points partition all 12 pc's:
  WT0 = C-D-E-F#-G#-A#
  WT1 = C#-D#-F-G-A-B
```

**C(3) - Minor third cycle = Diminished seventh chord**:
```
C - Eb - Gb - Bbb(A) - (C)
Interval: +3 semitones repeatedly
Length: 4 pitch classes
Three distinct starting points partition all 12 pc's:
  C°7 = C-Eb-Gb-A
  C#°7 = C#-E-G-Bb
  D°7 = D-F-Ab-B
```

**C(4) - Major third cycle = Augmented triad**:
```
C - E - G# - (C)
Interval: +4 semitones repeatedly
Length: 3 pitch classes
Four distinct starting points partition all 12 pc's:
  C+ = C-E-G#
  C#+ = C#-F-A
  D+ = D-F#-A#
  Eb+ = Eb-G-B
```

**C(6) - Tritone cycle**:
```
C - F# - (C)
Interval: +6 semitones repeatedly
Length: 2 pitch classes
Six distinct starting points partition all 12 pc's
```

## Mathematical Properties

**Cycle length formula**:
```
Length of C(i) = 12 / GCD(i, 12)

Examples:
C(5): GCD(5,12) = 1, length = 12/1 = 12
C(4): GCD(4,12) = 4, length = 12/4 = 3
C(6): GCD(6,12) = 6, length = 12/6 = 2
```

**Number of distinct cycles of interval i**:
```
Number of cycles = GCD(i, 12)

Examples:
C(2): GCD(2,12) = 2 → 2 distinct whole-tone collections
C(3): GCD(3,12) = 3 → 3 distinct dim7 chords
C(4): GCD(4,12) = 4 → 4 distinct aug triads
```

**Complementary intervals**:
```
C(i) and C(12-i) produce the same pitch classes in reverse order

C(5) and C(7): same pc's, reversed (fourths vs fifths)
C(4) and C(8): same pc's, reversed (M3 vs m6)
C(3) and C(9): same pc's, reversed (m3 vs M6)
```

## Partitioning Pitch-Class Space

**How cycles partition the 12 pitch classes**:
```
Interval 2: Two cycles of 6 (whole-tone scales)
   {0,2,4,6,8,10} and {1,3,5,7,9,11}

Interval 3: Three cycles of 4 (dim7 chords)
   {0,3,6,9}, {1,4,7,10}, {2,5,8,11}

Interval 4: Four cycles of 3 (aug triads)
   {0,4,8}, {1,5,9}, {2,6,10}, {3,7,11}

Interval 6: Six cycles of 2 (tritone pairs)
   {0,6}, {1,7}, {2,8}, {3,9}, {4,10}, {5,11}
```

## Musical Context

**Compositional applications**:

1. **Sequential patterns**: Melodic sequences based on interval cycles
2. **Root progressions**: Chord roots following cycle patterns
3. **Symmetrical collections**: Using incomplete cycles as pitch material
4. **Transformation cycles**: Neo-Riemannian cycles (PL, PR) traverse interval cycles
5. **Serial music**: Derived rows using interval cycles

**Historical significance**:
- Circle of fifths: Foundation of tonal harmony
- Minor-third cycles: Romantic modulation technique
- Major-third cycles: Late Romantic "chromatic" progressions
- All cycles: 20th-century symmetrical organization

## Examples

### Basic

**C(3) cycle - Root motion by minor thirds**:
```
Chord progression:
C - Eb - Gb - A - C

Roman numerals (impossible to maintain single key):
I - bIII - bV - VI - I (in C)
But each chord could be local tonic

Effect: Tonal ambiguity, all chords equally weighted
```

**C(4) cycle - Root motion by major thirds**:
```
Chord progression:
C - E - Ab - C

In C major: I - III - bVI - I
But III and bVI require chromatic alteration
Creates "uncanny" triadic progression
```

**Combining cycles - Octatonic from two C(3) cycles**:
```
C(3) starting on C: C - Eb - Gb - A
C(3) starting on Db: Db - E - G - Bb

Combined: C - Db - Eb - E - Gb - G - A - Bb
This is OCT0,1 (the octatonic collection)
```

### From Repertoire

**Circle of fifths (traditional)**: Countless tonal works use C(7) for sequential motion and modulation. The complete cycle represents the universe of tonal keys.

**Chopin, Prelude in E minor**: Bass descends through portions of C(5) (fourths).

**Liszt, "Faust" Symphony**: Uses complete C(4) cycle (augmented triad) for Mephistopheles theme.

**Wagner, _Ring_ cycle**: Frequent use of C(3) progressions (minor-third cycles) for modulatory passages.

**Bartok**: Systematically explores interval cycles as structural and motivic material, particularly "axis system" based on C(3) and C(6).

**Coltrane, "Giant Steps"**: Chord changes based on C(4) cycle (major thirds), creating the famous "Coltrane changes."

## Common Confusions

- Interval cycle refers to PITCH CLASSES, not specific pitches (octave equivalence assumed)
- C(5) and C(7) contain the SAME pitch classes in different order (complementary)
- Complete cycles (length 12) traverse ALL pitch classes; incomplete cycles do NOT
- Circle of fifths IS an interval cycle: C(7)
- Incomplete cycles generate SYMMETRICAL collections
- The "cycle" aspect means it returns to the starting pitch class
- Cycle length depends on GCD with 12, not just the interval size
- Multiple distinct cycles exist for intervals that don't traverse all 12 pc's
- C(3) cycles generate dim7 chords; COMBINING two C(3) cycles generates octatonic
- Major-third cycle produces augmented triads, NOT hexatonic (hexatonic needs two aug triads)
