# Neapolitan Progressions

## Quick Definition

Neapolitan progressions are the standard harmonic patterns involving the Neapolitan sixth chord, most commonly ♭II6 → V and ♭II6 → viio7/V → V, which exploit the chord's predominant function to create dramatic chromatic approaches to cadences.

## Formal Definition

The **Neapolitan sixth** participates in a limited but powerful set of progressions due to its predominant function. These progressions typically occur in cadential contexts.

**Core progressions**:
1. **♭II6 → V**: Direct resolution to dominant
2. **♭II6 → viio7/V → V**: With applied diminished seventh

**Extended contexts**:
- ♭II6 → cad.6/4 → V
- i → ♭II6 → V → i
- iv → ♭II6 → V → i

## Primary Progressions

### ♭II6 → V (Direct Resolution)

The most basic Neapolitan progression:

```
♭II6         →         V
D♭/F (in C)           G

Function:
PD           →         D

Bass motion:
^4           →         ^5
(F)          →         (G)
```

**Characteristics**:
- Simple, direct approach to dominant
- Bass rises by step (^4 → ^5)
- Upper voices descend chromatically

### ♭II6 → viio7/V → V (With Applied Chord)

The applied viio7 intensifies the approach:

```
♭II6    →    viio7/V    →    V
D♭/F         F#o7            G

Bass motion:
F      →    F#         →    G
^4          #^4             ^5
(chromatic ascent)
```

**Characteristics**:
- Adds chromatic bass motion (F → F# → G)
- viio7/V creates additional tritone tension
- More dramatic than direct resolution
- Common in Romantic-era music

### ♭II6 → cad.6/4 → V

The cadential 6/4 delays the dominant:

```
♭II6    →    cad.6/4    →    V
D♭/F         C/G             G-B-D

Voice motion (soprano):
D♭     →    C          →    B
lowered-^2   ^1              ^7
```

**Characteristics**:
- Smooths the soprano line (lowered-^2 → ^1 → ^7)
- Creates suspense before dominant
- Very common, especially in Classical style

## Approach Patterns

### i → ♭II6 → V → i (Basic Minor-Key Cadence)

```
i      →    ♭II6    →    V     →    i
Cm          D♭/F         G          Cm

Function:
T           PD           D          T
```

Standard minor-key cadential pattern with Neapolitan.

### iv → ♭II6 → V → i (Predominant Expansion)

```
iv     →    ♭II6    →    V     →    i
Fm          D♭/F         G          Cm

Function:
PD          PD           D          T
```

Two predominants create longer approach to dominant.

### i → iv → ♭II6 → V → i (Full Approach)

```
i      →    iv     →    ♭II6    →    V     →    i
Cm          Fm          D♭/F         G          Cm
```

Comprehensive cadential pattern with multiple predominants.

## Less Common Progressions

### ♭II6 → V4/2 (Inverted Dominant)

```
♭II6    →    V4/2
D♭/F         G/F

Bass: F (^4) → F (common tone)
```

Rare; resolves to inverted dominant instead of root position.

### ♭II (Root Position) → V

```
♭II     →    V
D♭          G

Bass: D♭ (lowered-^2) → G (^5)
```

Uncommon; lacks the smooth voice leading of first inversion.

## Extended Tonicization of ♭II

The Neapolitan can be prolonged as a temporary key area:

```
(♭II as key area)    →    ♭II6    →    viio7/V    →    V    →    i
    D♭ major                D♭/F         F#o7            G         Cm
    prolonged
```

**Example from Schubert's "Erlkonig"**:
- ♭II first appears as a tonicized area (with pedal point)
- Then functions as ♭II6 in cadential progression
- Demonstrates both extended and local use

## Approach Chords to ♭II6

What can precede the Neapolitan?

**Common approaches**:
- **i → ♭II6**: From minor tonic
- **iv → ♭II6**: From subdominant
- **i6 → ♭II6**: From first-inversion tonic
- **VI → ♭II6**: From submediant

**Smooth voice leading into ♭II6**:
- Prepare lowered-^6 if possible
- Bass ^4 can be prepared or approached by step

## Musical Context

Neapolitan progressions are used for:
- **Dramatic cadences**: High-stakes harmonic moments
- **Emotional intensity**: Particularly in opera and art song
- **Minor-key expression**: The chord's most idiomatic context
- **Chromatic color**: Adding richness to standard progressions

## Examples

### Basic

**Standard ♭II6 → V → i in C minor**:
```
♭II6:    V:       i:
D♭/F     G        Cm

Analysis: ♭II6 - V - i
Function: PD  - D - T
```

**With viio7/V**:
```
♭II6:    viio7/V:    V:       i:
D♭/F     F#o7        G        Cm

Analysis: ♭II6 - viio7/V - V - i
Bass:     F   - F#      - G  - C
         (chromatic ascent)
```

**Full cadential approach**:
```
i:    iv:    ♭II6:    V:       i:
Cm    Fm     D♭/F     G        Cm

Multiple predominants intensify cadence
```

### From Repertoire

**Schubert, "Erlkonig" (G minor)**:
```
Progression at climax:
♭II6 → viio7/V → V7 → i
A♭/C  → C#o7   → D7 → Gm

First tonicizes ♭II, then uses it in cadential progression
```

**Chopin, Nocturne in F minor, Op. 55, No. 1**:
```
Standard Neapolitan cadential progression
♭II6 occurring in context of F minor
Creates characteristic Romantic color
```

**Beethoven, Piano Sonata "Pathetique" (C minor)**:
```
Dramatic use of ♭II6 at cadential points
Part of the sonata's tragic character
```

## Common Confusions

- ♭II6 is a PREDOMINANT, not a dominant (does not resolve directly to tonic)
- The most common progression is ♭II6 → V, not ♭II6 → i
- viio7/V between ♭II6 and V is common and intensifies the progression
- Root-position ♭II → V is possible but much less common than ♭II6 → V
- The cadential 6/4 often appears between ♭II6 and V in Classical style
- Extended tonicization of ♭II is different from using it as a single chord
- ♭II6 can be approached from various chords (i, iv, VI, etc.)
