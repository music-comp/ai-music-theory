# Secondary Neo-Riemannian Transformations

## Quick Definition

Three additional Neo-Riemannian operations beyond the basic P, L, R that appear frequently in the repertoire: Slide (S) moves the perfect fifth by half step while changing mode, connecting triads a semitone apart; Nebenverwandt (N) moves the minor third by half step while changing mode, connecting a major triad to the minor triad a fifth below; and Hexpole (H) moves all three voices by half step with no common tones, connecting the two poles of a hexatonic (PL) cycle—all of which can be expressed as combinations of P, L, and R.

## Formal Definition

**Three secondary transformations**:

**S (Slide)**:
- Moves the **perfect fifth** by **half step**
- Changes the **mode**
- Connects major triad to minor triad **one semitone higher**
- Example: C major → C# minor
- Coined by David Lewin

**N (Nebenverwandt)**:
- Moves the **minor third** by **half step**
- Changes the **mode**
- Connects major triad to minor triad **a fifth below**
- Example: C major → F minor
- "Nebenverwandt" = "neighbor-related" (German)
- Introduced by Richard Cohn

**H (Hexpole)**:
- Moves **all three voices** by **half step**
- **No common tones** (unique among transformations)
- Connects the two **hexatonic poles** (opposite corners of PL cycle)
- Example: C major → Ab minor (or E minor)
- Attributed to Robert Cook

## Voice-Leading Detail

**S (Slide) transformation**:
```
C major: C - E - G
         ↓   |   ↓      (P5 moves by half step, third stays)
C# minor: C#- E - G#

Preserves: the THIRD (E)
Moves: C → C# (root up half step)
       G → G# (fifth up half step)
Mode: Major → Minor

Effectively "slides" the root/fifth pair up by semitone
Opposite of P (which preserves fifth, moves third)
```

**N (Nebenverwandt) transformation**:
```
C major: C - E - G
         ↓   ↓   |      (m3 moves by half step, fifth stays)
F minor: C - Eb- Ab... wait, let me recalculate

C major: C - E - G
N transformation to F minor: F - Ab - C

Looking at the interval structure:
C major (C-E-G) shares G with... 
Actually, N moves the minor third interval.
In C major, the m3 would be E-G.
N: E → Eb (down half step), and... 

Let me look at this more carefully.
C major to F minor via N:
C (C-E-G) → Fm (F-Ab-C)
Common tone: C
Moving: E → F (up half step), G → Ab (up half step)

So N on C major:
Preserves: one pitch (C)
Moves: two pitches (E→F, G→Ab)
Result: F minor (a fifth below C major)
```

**H (Hexpole) transformation**:
```
C major: C - E - G
         ↓   ↓   ↓      (ALL voices move by half step)
Ab minor: Ab- Cb- Eb

C → B (down half step, enharmonic Cb)
E → Eb (down half step)
G → Ab (up half step)

No common tones!
Connects "poles" of the hexatonic PL cycle
C major and Ab minor are maximally distant within their hexatonic system
```

## Relationship to PLR

**All secondary transformations as PLR combinations**:
```
S = LPR    (Slide)
    C -L→ Em -P→ E -R→ C#m
    C major → C# minor via L-P-R

N = RLP    (Nebenverwandt)
    C -R→ Am -L→ F -P→ Fm
    C major → F minor via R-L-P

H = PLP    (Hexpole)
    C -P→ Cm -L→ Ab -P→ Abm
    C major → Ab minor via P-L-P
```

**Voice-leading "work"**:
```
P and L: Move one voice by half step (minimal)
R: Move one voice by whole step (twice as much)

S and N: Move two voices by half step total
H: Move three voices by half step total (most "work")

S = 2 semitones motion (like R)
N = 2 semitones motion (like R)  
H = 3 semitones motion (NO common tones)
```

## Musical Context

Secondary transformations appear in specific contexts:
- **S (Slide)**: Chromatic shift up/down to parallel key relationship
- **N (Nebenverwandt)**: "Neighbor-like" motion, dramatic key relationships
- **H (Hexpole)**: Maximum distance within hexatonic system, dramatic contrast
- **Romantic repertoire**: Brahms, Wagner, Wolf, Liszt
- **Film music**: Dramatic transformations for scene changes
- **Weitzmann regions**: S and N can be traced through augmented triads
- **Analytical refinement**: More precise than describing as "PLR compound"

## Examples

### Basic

**S (Slide) from C major**:
```
C major: C - E - G
    ↓ S
C# minor: C# - E - G#

Third (E) is common tone
Fifth slides up: C-G → C#-G#
Mode changes: Major → Minor

Also: C minor → B major (S works both ways)
C minor (C-Eb-G) → B major (B-D#-F#)
Eb is common tone (= D#)
```

**N (Nebenverwandt) from C major**:
```
C major: C - E - G
    ↓ N
F minor: F - Ab - C

C is common tone
E → Ab, G → F (neighbor motion)
Result: minor triad P5 below (C → F)
Mode changes: Major → Minor

"Neighbor-related": the moving voices move like neighbors
```

**H (Hexpole) from C major**:
```
C major: C - E - G
    ↓ H
Ab minor: Ab - Cb - Eb

NO common tones!
All voices move by half step:
C → B (Cb)
E → Eb
G → Ab

Hexatonic poles:
In the PL cycle containing C major:
C - Cm - Ab - Abm - E - Em - C

C major and Ab minor are opposite "poles"
Maximum distance within the hexatonic system
```

**S, N, H as PLR compounds**:
```
S = LPR:
C -L→ Em -P→ E -R→ C#m
(L: C→Em, P: Em→E, R: E→C#m)
Result: C → C#m (Slide)

N = RLP:
C -R→ Am -L→ F -P→ Fm  
(R: C→Am, L: Am→F, P: F→Fm)
Result: C → Fm (Nebenverwandt)

H = PLP:
C -P→ Cm -L→ Ab -P→ Abm
(P: C→Cm, L: Cm→Ab, P: Ab→Abm)
Result: C → Abm (Hexpole)
```

### From Repertoire

**Wagner, music dramas**: N and H transformations for dramatic key changes between scenes.

**Brahms, late piano works**: S relationships between chromatic mediant-related keys.

**Film music**: H transformation used for dramatic reveals or supernatural moments.

**Wolf, Lieder**: Subtle use of S and N for text-painting.

## Common Confusions

- S, N, H are "secondary" but still important transformations
- All can be expressed as PLR combinations (S=LPR, N=RLP, H=PLP)
- S (Slide): Major ↔ minor one semitone apart (C ↔ C#m)
- N (Nebenverwandt): Major ↔ minor a fifth apart (C ↔ Fm)
- H (Hexpole): Hexatonic poles, NO common tones (C ↔ Abm)
- S and N each move 2 semitones total (like R)
- H moves 3 semitones total (maximum for single transformation)
- H is unique: only transformation with NO common tones
- "Nebenverwandt" means "neighbor-related" in German
- S preserves the THIRD (opposite of P which preserves fifth)
- All secondary transformations toggle (applying twice = return)
- Useful for precise analysis of non-PLR relationships
- Can be traced through Weitzmann regions (augmented triad networks)
