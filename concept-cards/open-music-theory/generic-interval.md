# Generic Interval

## Quick Definition

The distance between two notes counting by letter names, always starting with the first note counted as "one."

## Formal Definition

A **generic interval** (also called interval size or interval number) measures the distance between two pitches by counting the number of letter names spanned, including both the starting and ending notes. Generic intervals are named using ordinal numbers: unison, second, third, fourth, fifth, sixth, seventh, octave.

**Critical counting rule**: When counting generic intervals, always count the first note as "one" (not zero). Count each letter name once, including both the starting and ending notes.

Generic intervals specify only the letter-name distance, not the exact number of half steps. The specific quality (major, minor, perfect, augmented, diminished) requires additional information beyond the generic interval.

## Musical Context

Generic intervals provide the basic "skeleton" of interval measurement. Knowing that two notes are a "fifth" apart tells you they span five letter names, but doesn't specify whether it's a perfect fifth (7 half steps), diminished fifth (6 half steps), or augmented fifth (8 half steps).

Musicians use generic intervals in sight-reading and analysis as a quick way to gauge melodic leaps and harmonic relationships before considering exact interval quality.

## Examples

### Basic

From F to C:

- F (1), G (2), A (3), B (4), C (5) = a fifth
- Common mistake: counting F to G as "one"—this gives four instead of five

From C to E:

- C (1), D (2), E (3) = a third

From D to D (same letter):

- D (1) = a unison (or prime)

From D to D (octave higher):

- D (1), E (2), F (3), G (4), A (5), B (6), C (7), D (8) = an octave (eighth)

### From Repertoire

The opening melody of "Twinkle, Twinkle Little Star" moves from C to C (unison/prime), then C to G (fifth), then G to G (unison), creating a recognizable pattern of generic intervals.

## Common Confusions

- **Always count the first note as "one," not zero**—this is the most common error
- Generic interval alone doesn't tell you the exact number of half steps—you need the quality too
- The interval from C to E and from C to E♭ are both generic thirds, but different specific intervals (major vs. minor)
- Compound intervals (larger than an octave) extend the system: ninth, tenth, eleventh, etc.
