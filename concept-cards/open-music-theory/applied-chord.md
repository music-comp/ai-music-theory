# Applied Chord

## Quick Definition

An umbrella term for any chord that temporarily functions as the dominant or leading-tone chord of a diatonic scale degree other than the tonic—encompassing both secondary dominants (V/x, V7/x) and secondary leading-tone chords (vii°/x, vii°7/x), creating temporary tonicization through chromatic alterations that establish momentary dominant-tonic relationships outside the primary key, notated with slash notation (/) meaning "of" to show the applied relationship, introducing chromatic notes that function as temporary leading tones or chordal sevenths, and serving as the primary means of expanding harmonic vocabulary beyond strictly diatonic resources while maintaining the original tonal center.

## Formal Definition

**Applied chord** (also called **secondary chord**) is any chord functioning as V, V7, vii°, or vii°7 of a diatonic chord other than the tonic.

**Types of applied chords**:

**1. Secondary dominants**:
- **V/x**: Major triad functioning as dominant of x
- **V7/x**: Dominant seventh of x
- Most common type

**2. Secondary leading-tone chords**:
- **vii°/x**: Diminished triad as leading-tone of x
- **vii°7/x**: Fully diminished seventh as leading-tone of x
- Less common but equally valid

**Notation**: Slash (/) means "of"
- V/V = "five of five" (dominant of the dominant)
- vii°7/ii = "seven-diminished-seven of two"

**Function**: Creates temporary tonicization of target chord

## Applied Chord Terminology

**Synonymous terms**:
- **Applied chord** (umbrella term)
- **Secondary chord** (same meaning)
- **Secondary dominant** (specific type: V/x or V7/x only)
- **Secondary leading-tone** (specific type: vii°/x or vii°7/x only)

**"Applied"** emphasizes the functional application to non-tonic chords

## Slash Notation

**Format**: [Quality]/[Target]

**Examples**:
```
V/V    = dominant OF the dominant
V7/ii  = dominant seventh OF the supertonic
vii°/vi = diminished seven OF the submediant
vii°7/IV = fully diminished seventh OF the subdominant
```

**Reading**:
- Before slash: Chord quality/function
- After slash: Target chord (what it resolves to)
- Slash = "of"

## Common Applied Chords

**In C major**:

**Applied to V** (dominant):
- V/V = D or D7
- vii°/V = F#° or F#°7

**Applied to ii** (supertonic):
- V/ii = A or A7
- vii°/ii = C#° or C#°7

**Applied to vi** (submediant):
- V/vi = E or E7
- vii°/vi = G#° or G#°7

**Applied to IV** (subdominant):
- V/IV = C or C7 (same as primary I or I7, so less common)
- vii°/IV = B° or B°7

**Applied to iii** (mediant):
- V/iii = B or B7
- vii°/iii = D#° or D#°7

## Chromatic Alterations

**Creating temporary leading tones**:
```
V/V in C major = D or D7 (D-F#-A-C)

F# = raised ^4 in C
F# = temporary leading tone TO G (^7 in "key of G")

Chromatic alteration creates tonicization
```

**Pattern**: Raise note a half step below target root

**All applied chords introduce chromaticism** (except those that happen to be diatonic)

## Applied Chords vs. Primary Chords

**Primary dominant** (V or V7):
```
In C major: G or G7
Resolves to I (C major)
Diatonic
Primary tonic
```

**Applied dominant** (V/x):
```
In C major: V/V = D or D7
Resolves to V (G major)
Chromatic (has F#)
Temporary tonic (G)
```

**Same function, different target**

## Tonicization Through Applied Chords

**Process**:
```
1. Applied chord introduces chromaticism
2. Creates temporary dominant-tonic relationship
3. Target chord briefly feels like tonic
4. Returns to original key

No modulation (brief, no cadence)
```

**Example**:
```
I - V7/V - V - I
C   D7     G   C

D7 tonicizes G
G briefly emphasized
Returns to C
Applied chord function
```

## All Inversions Valid

**Applied chords can be inverted**:
```
V6/V, V4/3/V, V4/2/V   (inverted applied dominants)
vii°6/V, vii°4/3/V     (inverted applied leading-tones)

All inversions function same way
Inversion shown in notation
```

## Musical Context

Applied chords serve critical purposes:
- **Chromatic enrichment**: Beyond diatonic harmony
- **Tonicization**: Temporary emphasis on non-tonic chords
- **Forward momentum**: Applied chords drive to targets
- **Harmonic variety**: Expands tonal vocabulary
- **Common-practice universal**: Baroque through Romantic
- **V/x most common**: Secondary dominants predominate
- **Versatile**: Can tonicize most diatonic chords
- **No modulation**: Maintains original key structurally

Essential for understanding chromatic harmony in tonal music.

## Examples

### Basic

**V7/V** (most common applied chord):
```
Progression: I - V7/V - V - I
             C   D7     G   C

D7 = applied dominant (V7/V)
Tonicizes G
Returns to C
```

**vii°7/ii** (applied leading-tone):
```
Progression: vii°7/ii - ii - V - I
             C#°7       Dm   G   C

C#°7 = applied leading-tone (vii°7/ii)
Tonicizes Dm
Chromatic approach
```

**Multiple applied chords**:
```
I - V/vi - vi - V/ii - ii - V - I
C   E      Am   A      Dm   G   C

Chain of applied chords
Each tonicizes its target
Progressive tonicization
```

**Applied chord in inversion**:
```
I - V6/5/V - V - I
C   D7/F#    G   C

V6/5 = first inversion applied dominant
Same function, inverted
```

**All types**:
```
Secondary dominants: V/V, V7/ii, V/vi (most common)
Secondary leading-tones: vii°/V, vii°7/ii (less common)

All are "applied chords"
Umbrella term
```

### From Repertoire

**Bach, Well-Tempered Clavier**: Extensive applied chords, V/V common, vii°7/x for chromatic color, Baroque chromatic harmony.

**Mozart, Piano Sonatas**: Applied chords throughout, V7/V before dominant arrival, V/vi common in lyrical passages.

**Beethoven, Symphonies**: Rich use of applied chords, chains of tonicizations in developments, expands tonal palette.

**Chopin, Preludes**: Applied chords for chromatic color, multiple tonicizations in brief span, Romantic chromatic vocabulary.

**Popular music**: V/vi very common ("Something" by Beatles, countless others), applied chords standard in verse-chorus progressions.

## Common Confusions

- Applied chord = **umbrella term** for V/x, V7/x, vii°/x, vii°7/x
- Also called "secondary chord" (same meaning)
- Includes **secondary dominants** (V/x, V7/x) - most common
- Includes **secondary leading-tones** (vii°/x, vii°7/x) - less common
- Slash notation: "/" = "of" (V/V = dominant OF five)
- Creates **tonicization** (temporary emphasis, not modulation)
- Introduces **chromatic notes** (temporary leading tones)
- Can tonicize any major/minor diatonic chord (not vii°)
- V/I would just be V (redundant, not "applied")
- All inversions valid (V6/5/V, vii°4/3/ii, etc.)
- Most common: V/V, V7/ii, V/vi, V/IV
- Voice leading same as primary V7→I
- Temporary leading tone resolves UP
- Chordal seventh resolves DOWN
- No modulation (brief, returns to original key)
- Universal in common-practice music (Baroque→Romantic)
- Expands vocabulary beyond diatonic chords
- "Applied" = functions as V or vii° applied to non-tonic
- Same as "secondary" (interchangeable terms)
- Notation shows target after slash (what it resolves to)
