# Quick Definition
A phrase-level form consisting of a phrase followed by a written-out repeat (often varied), where both phrases end with the same cadence type -- distinguishing it from a period, in which the consequent ends with a stronger cadence.

# Core Definition
A **repeated phrase** consists of "a phrase followed by a written-out repeat." It refers to a phrase with a written-out repeat that adds additional measures, not a phrase between two repeat signs. The repetition is often varied (embellished melody, new texture). Both phrases end with the same cadence type, distinguishing the repeated phrase from a period, "in which the consequent ends with a stronger cadence than the antecedent" (Ch. 2, "The Repeated Phrase").

# Prerequisites
- **Phrase** -- A repeated phrase consists of two statements of a phrase

# Key Properties
1. Phrase + written-out repeat
2. Both phrases end with the same cadence type
3. Repetition often varied (embellishment, texture)
4. Not the same as using repeat signs
5. Adds measures to the piece

# Construction / Recognition
## To Identify:
1. Find two similar phrases in succession
2. Check if both end with the same cadence type
3. If same cadence: repeated phrase (not period)

# Context & Application
The repeated phrase is a common phrase-level form that sometimes gets confused with the period. The key distinction is the cadence pattern.

# Examples
**Example 1** (Ch. 2, Example 12): Schubert, "Du bist die Ruh" -- two phrases with identical cadence type, the second with varied melody.

# Relationships
## Contrasts With
- **period** -- Period has weak→strong cadences; repeated phrase has same→same

# Common Confusions
- **Confusion**: A repeated phrase is the same as a period
  **Clarification**: In a period, the second phrase ends with a stronger cadence; in a repeated phrase, both cadences are the same
