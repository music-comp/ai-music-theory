# Minor Subdominant (iv)

## Quick Definition

The minor subdominant (iv) is a borrowed chord in major keys, created by lowering the sixth scale degree (^6 to lowered-^6), transforming the diatonic major IV chord into a minor triad that functions as a poignant, darkened predominant.

## Formal Definition

The **minor subdominant** is one of the most common borrowed chords in major-key harmony:

**Structure in C major**:
- Diatonic IV: F-A-C (F major)
- Borrowed iv: F-A♭-C (F minor)
- Changed note: A becomes A♭ (^6 becomes lowered-^6)

**Characteristics**:
- Only requires borrowing one note (lowered-^6)
- Retains predominant function
- Creates minor quality on subdominant
- Often followed by V or I (plagal motion)

## Voice Leading

**iv to V resolution**:
```
iv:  F-A♭-C    V:  G-B-D
     
A♭ → G (lowered-^6 → ^5, chromatic descent)
F → D or B (^4 resolves to chord tone of V)
C → B or D (^1 resolves to chord tone of V)
```

**iv to I resolution (chromatic plagal)**:
```
iv:  F-A♭-C    I:  C-E-G

A♭ → G (lowered-^6 → ^5, half-step descent)
F → E (^4 → ^3)
C → C (common tone)
```

The chromatic descent from A♭ to G is particularly expressive, creating a poignant "sighing" effect.

**IV - iv - I progression**:
```
IV:  F-A-C    iv:  F-A♭-C    I:  C-E-G

Creates chromatic line: A → A♭ → G
"Creeping" chromatic motion
Very expressive cadential pattern
```

## Comparison with Diatonic IV

| Aspect | IV (diatonic) | iv (borrowed) |
|--------|---------------|---------------|
| Quality | Major | Minor |
| Third | A natural (^6) | A♭ (lowered-^6) |
| Character | Bright, warm | Dark, poignant |
| Chromatic content | None | One altered note |
| Function | Predominant | Predominant (unchanged) |

## Musical Context

The minor subdominant appears in:
- **Romantic era**: Brahms, Schubert, Chopin use extensively
- **Popular music**: Common in ballads and emotional passages
- **Gospel/R&B**: Fundamental to the style
- **Film scores**: For emotional coloring

**Expressive effects**:
- Adds darkness or poignancy to major-key passages
- Creates "aching" chromatic voice leading
- Intensifies cadential approaches
- Suggests parallel minor without full modulation

## Examples

### Basic

**Simple iv in C major**:
```
I - iv - V - I
C - Fm - G - C

F-A♭-C replaces F-A-C
A♭ provides chromatic color
```

**IV to iv progression**:
```
I - IV - iv - I
C - F  - Fm - C

Chromatic line: A → A♭ → G
Moving from bright IV to dark iv
Creates expressive chromatic plagal cadence
```

**In cadential context**:
```
I - ii - iv - V - I
C - Dm - Fm - G - C

iv as intensified predominant
Darker approach to dominant
```

### From Repertoire

**Brahms, Symphony No. 3, III (C major section)**:
- Uses iv extensively for characteristic warmth and darkness
- Demonstrates Romantic-era predilection for borrowed iv

**Chopin, Nocturne in E♭ major, Op. 9, No. 2**:
- Employs iv for poignant chromatic color
- Creates expressive plagal gestures

**Gospel tradition**:
- IV - iv - I progression ("amen cadence" with mixture)
- Foundational sound of the style

**Popular music example**:
- Many ballads use iv for emotional moments
- "Creep" by Radiohead: uses iv chord for expressive effect

## Common Confusions

- The iv chord borrows only ONE note (lowered-^6), making it the simplest borrowed chord
- The iv chord is NOT the same as IV7 (dominant seventh on subdominant)
- In minor keys, iv is diatonic, not borrowed
- The function remains predominant; only the quality changes
- Voice leading: the lowered-^6 (A♭ in C major) wants to resolve DOWN to ^5 (G)
- IV - iv - I creates a chromatic line: ^6 - lowered-^6 - ^5
- Do not confuse with tonicization of IV (V/IV - IV)
