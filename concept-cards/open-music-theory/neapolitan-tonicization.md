# Neapolitan Tonicization

## Quick Definition

Neapolitan tonicization occurs when the ♭II chord is prolonged through an extended tonicization or even used as a temporary key area, rather than functioning as a single predominant chord within a cadential progression.

## Formal Definition

While the Neapolitan sixth (♭II6) most commonly appears as a single chord in cadential contexts, it can also be:

1. **Tonicized**: Approached with applied chords (V/♭II, viio/♭II)
2. **Prolonged**: Extended through pedal points, neighboring chords, etc.
3. **Used as a key area**: Serving as a temporary tonic for an extended passage

**Key principle**: Any chord can be tonicized, including chromatic chords like the Neapolitan.

## Tonicization of ♭II

### Applied Chords to ♭II

**V/♭II (or V7/♭II)**:
```
In C minor: V/♭II = A♭ major (or A♭7)
            Tonicizes D♭ major (♭II)
            
Progression: V/♭II → ♭II → V → i
             A♭    → D♭  → G → Cm
```

**viio/♭II (or viio7/♭II)**:
```
In C minor: viio/♭II = C diminished
            Leads to D♭ major (♭II)
            
Progression: viio/♭II → ♭II → V → i
             Co       → D♭  → G → Cm
```

### Effect of Tonicization

- Makes ♭II sound like a temporary tonic
- Adds weight and importance to the Neapolitan
- Creates longer approach to the dominant
- Increases dramatic intensity

## ♭II as a Key Area

### Extended Tonicization

When ♭II is used as a key area, not just a single chord:

```
Original key: C minor
♭II key area: D♭ major (temporary tonic)
Return to: C minor (via ♭II6 → V → i)
```

**Characteristics**:
- Multiple chords confirm ♭II as temporary tonic
- May include pedal point on lowered-^2
- Cadences within the ♭II key area
- Eventually returns to original key

### Schubert's "Erlkonig" Example

**Structure**:
1. Piece is in G minor
2. ♭II (A♭ major) is first tonicized and prolonged
3. Elaborated with pedal point
4. Then used in standard cadential progression: ♭II6 → viio7/V → V7 → i

```
G minor:    [♭II as key area]    →    ♭II6  →  viio7/V  →  V7  →  i
            (A♭ major prolonged)      A♭/C      C#o7       D7     Gm
```

**This demonstrates both**:
- Extended tonicization of ♭II
- Standard use as predominant chord

## Prolongation Techniques

### Pedal Point on ♭II

```
Bass holds lowered-^2 (D♭ in C minor)
Upper voices move within ♭II key area
Creates emphasis on the Neapolitan sound
```

### Neighboring Chords

```
♭II - (neighboring harmony) - ♭II
Prolongs the Neapolitan chord
Returns to ♭II before proceeding to V
```

### Arpeggiation

```
♭II chord tones outlined melodically
Prolongs Neapolitan through melodic elaboration
```

## Comparison: Single Chord vs. Key Area

| Aspect | ♭II6 as Chord | ♭II as Key Area |
|--------|---------------|-----------------|
| Duration | Brief (1 chord) | Extended (phrase or more) |
| Cadences | None within | May have internal cadences |
| Applied chords | None | V/♭II, viio/♭II possible |
| Preparation | May arrive directly | Often tonicized approach |
| Function | Predominant | Temporary tonic |

## Voice Leading from Tonicized ♭II

**After tonicization, ♭II still resolves as predominant**:
```
[♭II tonicization] → ♭II6 → V → i
    (key area)        PD    D   T
```

The voice leading for ♭II6 → V remains the same:
- lowered-^2 → ^7 (descending)
- lowered-^6 → ^5 (descending)
- ^4 → ^5 (ascending in bass)

## Musical Context

Neapolitan tonicization creates:
- **Dramatic weight**: Emphasizes the chromatic predominant
- **Extended color**: Prolongs the exotic Neapolitan sound
- **Structural importance**: Makes ♭II a key event, not just passing chord
- **Romantic expression**: Common in 19th-century dramatic works

## Examples

### Basic

**Simple tonicization**:
```
i   →  V/♭II  →  ♭II  →  V   →  i
Cm     A♭       D♭      G       Cm

Applied V introduces ♭II
♭II then resolves normally to V
```

**Extended tonicization with return**:
```
i   →  [♭II key area]  →  ♭II6  →  V  →  i
Cm     (D♭: I-IV-V-I)     D♭/F    G     Cm
         prolonged

♭II treated as temporary tonic
Then functions as predominant
```

### From Repertoire

**Schubert, "Erlkonig"**:
```
G minor piece
♭II (A♭ major) first tonicized with pedal point
Then: ♭II6 - viio7/V - V7 - i
      A♭/C - C#o7   - D7 - Gm

Demonstrates both extended and local Neapolitan use
```

**Beethoven sonatas (minor keys)**:
- Occasionally tonicize ♭II for dramatic effect
- Creates extended chromatic passages

**Romantic opera**:
- ♭II tonicization for dramatic climaxes
- Creates extended foreign-key excursions

## Common Confusions

- Tonicizing ♭II does NOT change its eventual function as predominant
- After tonicization, ♭II still resolves to V (predominant function)
- V/♭II is NOT the same as V in the home key
- Extended tonicization creates ♭II as a KEY AREA, not just a chord
- The voice leading from ♭II6 → V remains the same regardless of prior tonicization
- Tonicization is different from modulation: we return to the home key
- Not all Neapolitans are tonicized; single-chord use is more common
