# Secondary Leading-Tone Chord

## Quick Definition

A diminished triad or diminished seventh chord built on the leading tone of a scale other than the tonic—functioning as vii° or vii°7 of a diatonic chord other than I, notated as vii°/x or vii°7/x where x is the target chord, serving the same tonicizing function as secondary dominants but with diminished quality instead of major, introducing chromatic alterations to create temporary leading tones, resolving to the target chord with characteristic voice leading where the diminished fifth resolves inward, less common than secondary dominants but equally valid for temporary tonicization, and particularly effective in minor keys where the fully diminished seventh sound is native.

## Formal Definition

**Secondary leading-tone chord** is a diminished triad (vii°) or fully diminished seventh (vii°7) functioning as the leading-tone chord of a scale other than the tonic.

**Structure**: Built on raised note a half step below target root

**Notation**: vii°/x or vii°7/x
- vii° or vii°7 = diminished/fully diminished quality
- / = "of"
- x = target chord (temporary tonic)

**Function**: Tonicizes target chord (same as secondary dominant, different quality)

**Relationship to V7/x**: vii°/x = V7/x without root

## Secondary Leading-Tone vs. Secondary Dominant

**Secondary dominant** (V/x or V7/x):
```
In C major: V/V = D or D7
            (major quality)

Most common applied chord
Stronger, more stable
```

**Secondary leading-tone** (vii°/x or vii°7/x):
```
In C major: vii°/V = F#° or F#°7
            (diminished quality)

Less common but equally valid
More linear voice leading
Lighter texture (no root doubling issues)
```

**Shared function**: Both tonicize the same target

## Common Secondary Leading-Tone Chords

**vii°7/V** (in C major):
```
Chord: F#°7 (F#-A-C-Eb)
Target: V (G major)

F# = raised ^4 (leading tone TO G)
Progression: vii°7/V → V

Tonicizes dominant
```

**vii°7/ii** (in C major):
```
Chord: C#°7 (C#-E-G-Bb)
Target: ii (D minor)

C# = raised ^1 (leading tone TO D)
Progression: vii°7/ii → ii

Tonicizes supertonic
```

**vii°7/vi** (in C major):
```
Chord: G#°7 (G#-B-D-F)
Target: vi (A minor)

G# = raised ^5 (leading tone TO A)
Progression: vii°7/vi → vi

Tonicizes submediant
```

## Voice Leading

**vii°7/V → V** (in C major):
```
vii°7/V: F#-A-C-Eb   V: G-B-D-G
S:       Eb → D          (♭^3/V → ^2/V, resolves down)
A:       C  → B          (^4/V → ^3/V)
T:       A  → G or D     (^2/V → ^1/V or ^5/V)
B:       F# → G          (^7/V → ^1/V, leading tone up!)

F# (temporary leading tone) resolves UP to G
Diminished intervals resolve inward
Same voice leading as primary vii°7→I
```

**Diminished fifth resolution**:
```
vii°/x contains diminished fifth
Resolves inward by half steps
F#-C → G-B (in vii°/V → V)

Characteristic smooth voice leading
```

## vii° vs. vii°7

**vii°/x** (diminished triad):
```
Three notes
Lighter texture
Less tension
Diatonic in major keys (as primary vii°)
```

**vii°7/x** (fully diminished seventh):
```
Four notes
Maximum tension
More common in secondary function
All minor thirds (symmetrical)
Native sound of harmonic minor
```

**vii°7/x more common** as secondary function (richer, more chromatic)

## Chromaticism

**Raised notes create temporary leading tones**:
```
vii°7/V in C major: F#°7
F# = raised ^4 (becomes ^7 in "key" of G)

vii°7/ii in C major: C#°7
C# = raised ^1 (becomes ^7 in "key" of D)

Pattern: Raise note half step below target root
```

**Same chromatic alterations as V7/x**:
```
V7/V = D7 (D-F#-A-C)
vii°7/V = F#°7 (F#-A-C-Eb)

Share F# (raised ^4)
vii°7/V = upper structure of V9/V
```

## Comparison to Primary vii°7

**Primary vii°7** (in C major: B°7):
```
Functions as leading-tone to I
B-D-F-Ab resolves to C-E-G

Diatonic leading tone (^7→^1)
Dominant function
```

**Secondary vii°7** (e.g., vii°7/V = F#°7):
```
Functions as leading-tone to V
F#-A-C-Eb resolves to G-B-D

Chromatic leading tone (raised ^4→^5)
Tonicizing function
```

**Same quality, different target**

## Musical Context

Secondary leading-tone chords serve specific purposes:
- **Tonicization**: Same as secondary dominants
- **Linear voice leading**: Smooth stepwise motion
- **Lighter texture**: No root (like primary vii°)
- **Chromatic color**: Raised notes create leading tones
- **Minor key affinity**: Fully diminished native to minor
- **Less common than V/x**: But equally valid
- **Classical/Romantic**: Appears throughout common-practice
- **Versatile**: Can tonicize any major/minor diatonic chord

Effective chromatic device for temporary tonicization.

## Examples

### Basic

**vii°7/V in C major**:
```
Progression: I - vii°7/V - V - I
             C   F#°7      G   C

F#°7 (F#-A-C-Eb) tonicizes G
F# is chromatic (raised ^4)
Resolves to V, then to I
```

**vii°7/ii in C major**:
```
Progression: vii°7/ii - ii - V - I
             C#°7       Dm   G   C

C#°7 (C#-E-G-Bb) tonicizes Dm
C# is chromatic (raised ^1)
Strengthens approach to ii
```

**vii°7/vi** (in popular music):
```
Progression: I - vii°7/vi - vi - IV
             C   G#°7        Am   F

G#°7 tonicizes Am
G# is chromatic (raised ^5)
Common progression
```

**Comparison with V7/x**:
```
Using V7/V:    I - V7/V - V
               C   D7     G

Using vii°7/V: I - vii°7/V - V
               C   F#°7      G

Same function, different quality
vii°7 more linear, lighter
```

**Chain of secondary leading-tones**:
```
vii°7/iii → iii → vii°7/vi → vi → vii°7/ii → ii → V → I

Each chord tonicized by its leading-tone
Creates chromatic sequence
Less common than V7/x chain
```

### From Repertoire

**Bach, Well-Tempered Clavier**: Secondary leading-tone chords in fugal episodes, tonicizes various scale degrees, demonstrates Baroque chromatic practice.

**Mozart, Piano Sonatas**: vii°7/V before dominant arrival, lighter than V7/V, smooth voice leading.

**Chopin, Preludes**: Rich use of secondary leading-tone chords, particularly vii°7/x for chromatic color.

**Beethoven, Piano Sonatas**: Secondary diminished sevenths in development sections, tonicizes remote areas.

**Romantic period**: Increased use of vii°7/x for chromatic harmony, particularly in minor keys where fully diminished native.

## Common Confusions

- Secondary leading-tone = vii° or vii°7 OF a diatonic chord (not I)
- Notation: vii°/V = "seven-diminished of five" (leading-tone of V)
- Function: **Tonicizes** target chord (like V/x but different quality)
- Diminished quality (not major like V/x)
- vii°7/x = fully diminished seventh (all minor thirds)
- Raised note creates temporary leading tone
- vii°/V in C = F#° or F#°7 (contains raised ^4)
- vii°/ii in C = C#° or C#°7 (contains raised ^1)
- Less common than V/x, but equally valid
- Voice leading: diminished fifth resolves inward
- Temporary leading tone resolves UP
- Same targets as secondary dominants (V, ii, vi, IV, iii)
- Cannot tonicize vii° (unstable)
- vii°7/x = V9/x without root (relationship)
- More linear than V/x (lighter texture)
- Particularly effective in minor keys
- Fully diminished seventh most common (vii°7/x)
- Chromatic color without heavy dominant sound
- Can be inverted (vii°6/5/x, vii°4/3/x, etc.)
- Same chromatic alterations as corresponding V7/x
