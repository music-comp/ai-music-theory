# Quick Definition

A secondary leading-tone chord is a diminished triad or diminished seventh chord (vii-o/x or vii-o7/x) that functions as the leading-tone chord of a diatonic chord other than the tonic, creating tonicization. It is less common than secondary dominants.

# Core Definition

**Secondary leading-tone chords** (vii-o/x, vii-o7/x) are diminished triads or diminished seventh chords that tonicize non-tonic diatonic chords (OMT, Ch. IV.15). They are identified by quality: if a chromatic chord is a diminished triad or diminished seventh, it receives the label vii-o(7)/x.

As with primary leading-tone chords, composers commonly lower the chordal seventh in major contexts to create a fully diminished seventh chord (vii-o7) rather than half-diminished.

# Prerequisites

- **Tonicization** — Secondary leading-tone chords create tonicization
- **Applied chord** — Secondary leading-tone is one type of applied chord
- **Leading-tone chord** — The primary vii-o7 provides the template for secondary usage

# Key Properties

1. Quality: diminished triad or diminished seventh
2. Less common than secondary dominants
3. Fully diminished seventh preferred over half-diminished
4. Voice leading follows same principles as primary vii-o7

# Construction / Recognition

## To Identify:
1. Find a chromatic chord
2. Check quality: diminished triad or diminished seventh?
3. If yes: it is vii-o(7)/x
4. Determine x: in what key is this chord vii-o? That key's tonic = x

# Examples

**Example 1** (OMT Ch. IV.15, Examples 3-4): vii-o7/V in Josephine Lang, resolving through cad. 6/4 to V7.

**Example 2** (OMT Ch. IV.15, Example 9): vii-o7/ii in Maria Szymanowska, Minuet No. 4 — tonic triad with raised ^1 and added ^b7 = vii-o7/ii.

# Relationships

## Builds Upon
- **Applied chord** — Secondary leading-tone is the vii-o/x subtype

## Contrasts With
- **Secondary dominant** — V/x is major/Mm7 quality; vii-o/x is diminished quality

# Common Confusions

- **Confusion**: Not recognizing half-diminished sevenths as potential applied chords
  **Clarification**: The source notes it is rare but possible for a half-diminished seventh to act as an applied chord
