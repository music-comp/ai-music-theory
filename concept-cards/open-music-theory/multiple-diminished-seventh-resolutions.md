# Multiple Diminished Seventh Resolutions

## Quick Definition

The capacity of any fully diminished seventh chord to resolve convincingly to four different major or minor triads whose roots are located a minor third apart—made possible by the chord's symmetrical structure and the ability to reinterpret any of its four notes as a leading tone resolving up by half step to a new tonic, each resolution representing a different enharmonic spelling and functional interpretation of the same sonority.

## Formal Definition

**Multiple diminished seventh resolutions** describes the resolution flexibility of °7 chords:

**Principle**: Any °7 chord can resolve to four different keys because:
- Each of its four notes can serve as a leading tone
- Leading tone resolves up by half step to tonic
- Four notes = four possible tonics
- Tonics are related by minor thirds

**Resolution formula**:
```
Given °7 with notes: N1-N2-N3-N4

N1 as leading tone → resolves to N1+1 semitone (tonic 1)
N2 as leading tone → resolves to N2+1 semitone (tonic 2)
N3 as leading tone → resolves to N3+1 semitone (tonic 3)
N4 as leading tone → resolves to N4+1 semitone (tonic 4)
```

**Enharmonic respelling required**: Different spelling reflects different resolution

## Four Resolutions of One Chord

**B°7 = B-D-F-A-flat resolves to**:
```
1. B as leading tone (^7):
   B°7 = vii°7 in C
   B-D-F-A-flat → C major/minor
   B → C (leading tone resolution)

2. D as leading tone (respell as C#°7):
   D(C#)-F(E)-A-flat(G)-B → E-flat major/minor
   (or respell: C#-E-G-B-flat → D major/minor)

3. F as leading tone (respell as E#°7):
   F(E#)-A-flat(G#)-B-D(C##) → F#/G-flat major/minor
   E# → F# (leading tone resolution)

4. A-flat as leading tone (respell as G#°7):
   A-flat(G#)-B-D-F(E#) → A major/minor
   G# → A (leading tone resolution)
```

## Voice Leading Principles

**Consistent resolution pattern**:
```
For each resolution:
- Leading tone rises by half step to tonic
- Other voices resolve by step (usually down)
- Diminished fifth contracts to third
- Diminished seventh contracts to fifth

Standard °7 → I voice leading, applied to each spelling
```

**Resolution to major vs. minor**:
```
B°7 → C major: B-D-F-A-flat → C-E-G-C
B°7 → C minor: B-D-F-A-flat → C-E-flat-G-C

Same °7, same voice leading tendency
Third of resolution chord determines major/minor
```

## Enharmonic Spellings for Each Resolution

**B°7 spelled four ways**:
```
Resolution to C:
  B-D-F-A-flat (B = leading tone of C)
  vii°7 in C → I

Resolution to E-flat:
  D-F-A-flat-C-flat (D = leading tone of E-flat)
  vii°7 in E-flat → I

Resolution to G-flat:
  F-A-flat-C-flat-E-double-flat (F = leading tone of G-flat)
  vii°7 in G-flat → I

Resolution to A:
  G#-B-D-F (G# = leading tone of A)
  vii°7 in A → I

Same sound, four spellings, four destinations
```

## Resolution Tendencies

**Which note becomes leading tone?**:
```
Determined by:
1. Voice leading context (approach to chord)
2. Bass motion (usually leading tone in bass or soprano)
3. Compositional intent (target key)
4. Metric/phrase position
```

**Voice leading confirmation**:
```
Once leading tone is identified:
- It resolves UP by half step
- Other voices follow standard °7 → I pattern
- Spelling adjusted to reflect interpretation
```

## Compositional Applications

**Surprise modulation**:
```
Listener expects one resolution
Composer provides different interpretation
Creates sudden key change
```

**Ambiguity and suspense**:
```
Hold °7 without resolving
Multiple resolutions remain possible
Delay reveals eventual interpretation
```

**Sequence of resolutions**:
```
Same °7 (or enharmonic set) resolves differently each time
Creates chromatic harmonic motion
Explores multiple key areas
```

## Musical Context

Multiple diminished seventh resolutions enable:
- **Dramatic modulation**: Unexpected key changes
- **Tonal ambiguity**: Listener uncertain of destination
- **Compositional flexibility**: Same chord, multiple functions
- **Romantic expression**: Expressive key shifts
- **Developmental technique**: Explore multiple keys from single chord
- **Surprise effect**: Subvert expected resolution
- **Voice leading elegance**: Smooth path to distant keys
- **Minor third cycle**: Sequential exploration of four keys

Central technique for Romantic chromatic harmony.

## Examples

### Basic

**B°7 to four destinations**:
```
1. To C major:
   B°7 (B-D-F-A-flat) → C (C-E-G)
   vii°7 → I in C major
   
2. To E-flat major:
   D°7 (D-F-A-flat-C-flat) → E-flat (E-flat-G-B-flat)
   vii°7 → I in E-flat major
   
3. To G-flat major:
   F°7 (F-A-flat-C-flat-E-double-flat) → G-flat (G-flat-B-flat-D-flat)
   vii°7 → I in G-flat major
   
4. To A major:
   G#°7 (G#-B-D-F) → A (A-C#-E)
   vii°7 → I in A major

Same four pitches, different functions
```

**Resolution in context**:
```
In C major, approaching °7:
I - IV - vii°7 - ???

Possible continuations:
a) → I (resolve to C, expected)
b) → respell, resolve to E-flat (surprise!)
c) → respell, resolve to A (even more remote)

Compositional choice determines path
```

**Sequence using multiple resolutions**:
```
B°7 → C major → D°7 → E-flat major → F°7 → G-flat major → G#°7 → A major → (B°7 → C)

Same °7 sonority respelled and resolved four ways
Complete minor third cycle
Returns to starting key
```

**Delayed resolution (ambiguity)**:
```
vii°7 held over bar line...
Multiple resolutions remain possible...
Finally resolves to unexpected key
Creates tension through ambiguity
```

### From Repertoire

**Beethoven, "Waldstein" Sonata**: °7 chords resolve unexpectedly, multiple resolution options exploited in development.

**Chopin, Ballade No. 1**: Diminished seventh resolves to various keys, creates narrative harmonic drama.

**Wagner, "Götterdämmerung"**: Extended °7 passages, delayed resolution increases tension, eventual resolution often surprising.

**Schubert, "Wanderer" Fantasy**: °7 chords pivot to distant keys, multiple resolutions within continuous development.

**Liszt, Piano Sonata in B minor**: Virtuosic exploitation of °7 resolutions, navigates vast tonal spaces.

## Common Confusions

- Any °7 can resolve to FOUR different keys (not just one)
- Keys are related by minor third (m3 apart)
- Each of four notes can serve as leading tone
- Leading tone rises by half step to tonic
- Different resolutions require different spellings
- B°7 = D°7 = F°7 = A-flat°7 (same sound)
- Resolution to major or minor equally valid
- Third of target chord determines major/minor quality
- Voice leading otherwise identical for all resolutions
- Compositional context determines which resolution used
- Can sequence through all four resolutions
- Creates minor third cycle (returns after four keys)
- Romantic composers exploit this systematically
- Not same as "deceptive" resolution (which is unexpected but still functional)
- °7 resolution flexibility = enharmonic + symmetry properties
- Listener expectation can be subverted for dramatic effect
- Same °7 can appear multiple times with different resolutions
- Spelling always reflects intended voice leading
