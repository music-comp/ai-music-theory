# Common-Tone Augmented Sixth

## Quick Definition
The common-tone augmented sixth (CT+6) is a German augmented sixth chord used as a chromatic embellishment rather than a predominant, sharing the root of the chord it embellishes (usually I or V) while three other voices create chromatic neighbor tones, producing a darker sound than the common-tone diminished seventh because all three neighbors are chromatic.

## Formal Definition
**Common-tone augmented sixth** (CT+6) is:

**Structure**: Same pitches as German sixth (Ger+6)
- Root of embellished chord (common tone)
- Three chromatic neighbor tones

**Function**: Embellishment (not predominant like Ger+6)

**Sound**: Like German sixth / dominant seventh

**Key difference from Ger+6**:
- Ger+6: Predominant function, resolves to V
- CT+6: Embellishing function, resolves back to I (or V)

## Construction

**Building CT+6 to embellish C major (I)**:
```
Start with C major triad: C - E - G

Find neighbors:
- C: Keep as common tone (root)
- E: Lower chromatic neighbor = Eb
- G: Upper neighbor = Ab, Lower neighbor = F#

CT+6: C - Eb - F# - Ab

Same pitches as Ab-C-Eb-F# (Ger+6)
But different function!
```

**Why "augmented sixth" name**:
```
CT+6: C - Eb - F# - Ab

Interval Ab to F# = augmented sixth
Even though function is embellishment
Name reflects interval content
```

**Common tone is not always bass**:
```
CT+6 can be voiced with any note in bass:
C - Eb - F# - Ab (C in bass)
Eb - F# - Ab - C (Eb in bass)
F# - Ab - C - Eb (F# in bass, = d3 interval with Ab)
Ab - C - Eb - F# (standard Ger+6 voicing)

Common tone (C) can be in any voice
```

## Voice Leading

**CT+6 embellishing tonic**:
```
I:     C - E - G - C
CT+6:  C - Eb - F# - Ab
I:     C - E - G - C

Voice leading:
C  -> C  -> C  (common tone holds)
E  -> Eb -> E  (chromatic lower neighbor)
G  -> F# -> G  (chromatic lower neighbor)
C  -> Ab -> C  (chromatic neighbor, unusual motion)
```

**All three non-common tones are chromatic neighbors**:
```
E to Eb: Half step down (chromatic)
G to F#: Half step down (chromatic)
C to Ab: Minor 3rd down (unusual but functional)

This makes CT+6 "darker" than CT°7
```

## Comparison with CT°7

**CT°7 vs CT+6**:
```
Embellishing C major:

CT°7: C - Eb - Gb - A
      Two chromatic neighbors (Eb, Gb)
      One diatonic-ish motion (C to A)

CT+6: C - Eb - F# - Ab
      THREE chromatic neighbors (Eb, F#, Ab)
      Only C holds as common tone

CT+6 = darker, more chromatic
```

**Sound difference**:
```
CT°7: Fully diminished seventh sound
      Symmetric, tense, "bright" dissonance

CT+6: Dominant seventh sound (Mm7)
      Asymmetric, "dark" dissonance
      More weight, richer
```

## Recognition

**Identifying CT+6 in analysis**:
```
1. Same harmony before and after
   I - ??? - I (or V - ??? - V)

2. German sixth sound (Mm7)
   But NOT resolving to V

3. Common tone present
   One pitch shared with embellished chord

4. Three chromatic neighbor tones
   All move by half step (or minor 3rd)

5. Returns to starting chord
   Prolongation, not progression
```

**Distinguishing from Ger+6**:
```
Ger+6:  iv - Ger+6 - I64 - V - I
        Predominant function
        Resolves TO dominant

CT+6:   I - CT+6 - I
        Embellishing function
        Resolves BACK to tonic

Same pitches, different context
```

## Spelling Considerations

**Enharmonic flexibility**:
```
CT+6 in C major: C - Eb - F# - Ab

Could be respelled:
C - Eb - Gb - Ab? (No, Gb doesn't lead to G)
C - D# - F# - G#? (Possible, depending on context)

Spell to show voice leading:
Eb -> E (not D# -> E which looks like step)
F# -> G (leading tone motion)
Ab -> G or Ab -> C (depending on resolution)
```

## Musical Context

The common-tone augmented sixth serves specific purposes:
- **Darker embellishment**: More chromatic than CT°7
- **German sixth sound**: Dominant seventh quality
- **Non-functional**: Does not progress to V
- **Prolongation**: Extends tonic (or dominant)
- **Three chromatic neighbors**: Maximum chromaticism
- **Romantic idiom**: Expressive, emotional
- **Voice leading color**: Creates chromatic lines

## Examples

### Basic

**CT+6 embellishing tonic (C major)**:
```
I:     C - E - G - C
       |   |   |   |
CT+6:  C - Eb- F#- Ab
       |   |   |   |
I:     C - E - G - C

C = common tone
Eb, F#, Ab = chromatic neighbors
Darker than CT°7
```

**CT+6 embellishing dominant (G major in C)**:
```
V:     G - B - D - G
       |   |   |   |
CT+6:  G - Bb- C#- Eb
       |   |   |   |
V:     G - B - D - G

G = common tone
Bb, C#, Eb = chromatic neighbors
Prolongs dominant harmony
```

**In context**:
```
I - IV - I - CT+6 - I - V - I
C   F    C   Cm7    C   G   C

CT+6 adds chromatic color
Does not change harmonic function
```

### From Repertoire

**Chopin, Mazurka Op. 67 No. 4 in A minor**: CT+6 embellishes A minor tonic, German sixth sound without predominant function.

**Brahms, Intermezzi**: Common-tone augmented sixths prolong tonic harmonies.

**Wagner, Tristan und Isolde**: CT+6 in chromatic prolongations.

**Schubert, Piano Sonatas**: CT+6 for expressive chromatic color.

**Late Romantic generally**: CT+6 as standard embellishing device.

## Common Confusions

- Common-tone augmented sixth = CT+6
- Same pitches as German sixth (Ger+6)
- **Different function**: Embellishment, not predominant
- Shares root of embellished chord (common tone)
- Three chromatic neighbor tones (darker than CT°7)
- CT°7 has two chromatic neighbors
- CT+6 has THREE chromatic neighbors (all half steps)
- Returns to chord it embellished (prolongation)
- Does NOT resolve to V like functional Ger+6
- Common tone can be in any voice (not just bass)
- Augmented sixth interval still present (A6 between two of the tones)
- May be inverted to diminished third
- Dominant seventh sound (Mm7)
- Romantic specialty (Chopin, Brahms, Wagner)
- Label context, not just sonority
