# Parallel Chromatic Sequence

## Quick Definition

A chromatic sequence in which entire chord structures (blocks of harmony) move in parallel motion, maintaining the same chord quality and voicing throughout while ascending or descending chromatically or by other consistent intervals, including parallel 6/3 (first inversion) chords, parallel dominant sevenths, and parallel augmented triads that create distinctive non-functional harmonic effects.

## Formal Definition

**Parallel chromatic sequences** involve:

**Characteristic features**:
- Entire chords move in **parallel motion** (planing)
- Chord **quality and voicing** remain constant
- Movement typically by **chromatic** or other consistent intervals
- Creates non-functional, coloristic harmony

**Three main types**:

1. **Parallel 6/3 chords** (first inversion triads):
   - Block of first-inversion chords moves chromatically
   - All voices move in parallel
   - Creates smooth chromatic voice-leading in all parts

2. **Parallel dominant chords**:
   - Dominant seventh chords move in parallel
   - Same voicing maintained throughout
   - No functional resolution—pure color and motion

3. **Parallel augmented triads**:
   - Augmented triads (symmetrical) move chromatically
   - Only four distinct augmented triads exist
   - Three half-steps returns to enharmonic equivalent

## Voice Leading

**Parallel motion principles**:
```
All voices move the same direction by the same interval
No voice-leading "rules" apply (no resolution tendencies)
Creates "planing" effect—block harmony in motion

Parallel 6/3 example (ascending chromatically):
C/E  → C#/E# → D/F#  → Eb/G  → E/G#  → F/A  ...
E-G-C → E#-G#-C# → F#-A-D → G-Bb-Eb → G#-B-E → A-C-F

All three voices ascend by half step together
```

**Parallel dominant sevenths**:
```
G7     → Ab7    → A7     → Bb7    ...
G-B-D-F → Ab-C-Eb-Gb → A-C#-E-G → Bb-D-F-Ab

All four voices ascend by half step
Each chord has identical quality (Mm7)
No resolution—continuous chromatic ascent
```

## Harmonic Function

**Non-functional harmony**:
- Traditional voice-leading rules suspended
- No tendency-tone resolutions
- Harmonic "color" rather than "function"
- Tonal center obscured or suspended

**Coloristic effects**:
- Creates smooth, gliding harmonic motion
- Impressionistic quality (associated with Debussy)
- Cinematic effect (film scores)
- Modal or post-tonal character

## Musical Context

Parallel chromatic sequences appear in various contexts:
- **Impressionism**: Debussy, Ravel—planing as harmonic technique
- **Film music**: Smooth chromatic motion for scene transitions
- **Jazz voicings**: Block chord movement
- **Late Romantic**: Precursors in Wagner, Mahler
- **Popular music**: Power chords, chromatic bass descents
- **Neo-classical**: Stravinsky, Prokofiev
- **Contemporary classical**: Extended techniques

## Examples

### Basic

**Parallel 6/3 chords (chromatic descent)**:
```
E/G# → Eb/G → D/F# → Db/F → C/E → B/Eb → Bb/D → A/C# → Ab/C ...

Soprano: G# - G - F# - F - E - Eb - D - C# - C ...
Alto:    E  - Eb - D - Db - C - B - Bb - A - Ab ...
Bass:    B  - Bb - A - Ab - G - Gb - F - E - Eb ...

All voices descend chromatically in parallel
First-inversion triads throughout
No functional relationships
```

**Parallel dominant sevenths (ascending)**:
```
C7:    C-E-G-Bb
       ↓ ↓ ↓ ↓ (all up by half step)
Db7:   Db-F-Ab-Cb
       ↓ ↓ ↓ ↓
D7:    D-F#-A-C
       ↓ ↓ ↓ ↓
Eb7:   Eb-G-Bb-Db
       ...

Each chord is a dominant seventh
No resolution between chords
Pure chromatic planing
```

**Parallel augmented triads**:
```
C+:    C-E-G#
       ↓ ↓ ↓ (up by half step)
Db+:   Db-F-A (enharmonically same as Db-F-A)
       ↓ ↓ ↓
D+:    D-F#-A#
       ↓ ↓ ↓
Eb+:   Eb-G-B (enharmonically = C+!)

Only four distinct augmented triads exist
(Due to symmetry: C+ = E+ = G#+ enharmonically)
After three half-steps, returns to same triad
```

### From Repertoire

**Debussy, "La cathédrale engloutie"**: Parallel organum-like chords, including parallel fifths and triads.

**Debussy, "Prélude à l'après-midi d'un faune"**: Chromatic parallel motion in orchestral textures.

**Ravel, "Jeux d'eau"**: Parallel chord planing creates shimmering effect.

**Film scores (John Williams, Howard Shore)**: Parallel chromatic sequences for dramatic or transitional passages.

**Satie, Gymnopédies**: Parallel harmonic motion in simple textures.

## Common Confusions

- Parallel chromatic sequences suspend traditional voice-leading rules
- "Parallel" means entire chords move together (planing)
- Not the same as "parallel fifths/octaves" error in counterpoint
- In this context, parallel motion is the GOAL, not an error
- Three types: parallel 6/3s, parallel dominants, parallel augmented
- Creates coloristic, non-functional harmony
- Associated with Impressionism (Debussy, Ravel)
- Parallel augmented triads: only 4 distinct ones exist (symmetry)
- After 3 half-steps, augmented triad returns to enharmonic equivalent
- Commonly used in film music and jazz
- Tonal center is suspended or obscured
- Harmonic "color" replaces harmonic "function"
