## Quick Definition

Common stock chord progressions in pop/rock that recur cyclically and can be recognized even when varied through inversion, chromatic alteration, or rotation.

## Formal Definition

Harmonic schemas are prototypical chord progressions that appear frequently across pop/rock repertoire. Like mental prototypes for concepts (e.g., "bird"), schemas can be recognized even when varied from their basic form. Variations may include chromatic inflection, chord inversion, chord substitution, or rotation (starting on a different chord in the cycle). Schemas often repeat cyclically within sections.

## Musical Context

Understanding schemas aids in:
- Identifying harmonies by ear
- Recognizing common patterns across songs
- Understanding how chord progressions create meaning
- Analyzing variations and deviations from norms

### Major Schema Categories

1. **Blues-based schemas**: Feature plagal motion and flat-side harmonies
   - 12-bar blues, double plagal, extended plagal

2. **Four-chord schemas**: Use I, IV, V, vi in different orders
   - Doo-wop, singer/songwriter, hopscotch

3. **Classical schemas**: Derived from common-practice progressions
   - Lament, circle-of-fifths

4. **Puff schemas**: Built on I-iii-IV motion

5. **Modal schemas**: Imply modes other than major/minor
   - Mixolydian, aeolian, dorian, lydian progressions

## Examples

### Basic Example

A schema like I-V-vi-IV can appear as:
- Root position: C-G-Am-F
- With inversions: C-G/B-Am-F
- Rotated: vi-IV-I-V (Am-F-C-G)

### From Repertoire

- Multiple songs share the same underlying schema despite surface differences
- The "Axis of Awesome" comedy routine demonstrates how many songs use the same four-chord schema

## Common Confusions

- **Schema vs. progression**: A schema is a prototype; specific progressions are instances of that schema
- **Variations as the same schema**: Inverted, substituted, or rotated versions still count as the same schema if recognizable
- **Multiple valid interpretations**: Some progressions could be analyzed as variations of different schemas
