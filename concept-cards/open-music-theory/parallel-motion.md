# Parallel Motion

## Quick Definition

When two voices move in the same direction by the same interval size, maintaining the same interval type between them.

## Formal Definition

**Parallel motion** is a type of motion between two voices in which both voices move in the same direction (both ascending or both descending) by the same generic interval, such that the interval type between them remains constant.

Characteristics:
- Both voices move in the same direction (both up or both down)
- Both voices move by the same generic interval size (both by step, both by third, etc.)
- The interval between the voices remains the same type (e.g., parallel thirds means thirds before and thirds after)

Example:
- Voice 1: C → D → E (ascending steps)
- Voice 2: A → B → C (ascending steps)
Interval: M3 → M3 → M3 (parallel thirds)

Types of motion between voices:
1. **Parallel**: Same direction, same interval type maintained (this concept)
2. **Similar**: Same direction, different intervals
3. **Contrary**: Opposite directions
4. **Oblique**: One voice moves, the other stays on the same pitch

## Musical Context

Parallel motion has specific roles and restrictions in voice leading:

**Advantages**:
- Creates a unified, blended sound
- Easy to sing/perform (voices move together)
- Strong, clear harmonic effect
- Common in certain styles (organum, parallel 6ths in popular music)

**Restrictions in counterpoint**:
- **Parallel perfect fifths**: Forbidden (P5 → P5)
- **Parallel perfect octaves**: Forbidden (P8 → P8)
- **Parallel imperfect consonances**: Allowed in moderation (e.g., 3-3-3, but not too many)

Why parallel perfects are forbidden:
- Diminish independence of voices (too much tonal fusion)
- Reduce harmonic variety
- Create an overly static effect
- Limit motion and goal-directedness

Parallel imperfect consonances (thirds, sixths) are acceptable because they maintain some harmonic variety while still creating a unified sound.

## Examples

### Basic

**Parallel thirds** (allowed):
- Upper: C → D → E
- Lower: A → B → C
(M3 → M3 → M3)

**Parallel fifths** (forbidden):
- Upper: C → D
- Lower: F → G
(P5 → P5) ❌

**Parallel sixths** (allowed in popular music):
- Upper: E → F → G
- Lower: G → A → B♭
(M6 → M6 → m6)

### From Repertoire

**Allowed parallel motion**:
- Popular music: Guitar parts in parallel thirds or sixths
- Medieval organum: Parallel fourths and fifths (different style conventions)
- Impressionist music (Debussy): Parallel chords for color

**Avoided parallel fifths/octaves**:
- Bach chorales: Meticulously avoid parallel perfect consonances
- Classical counterpoint: Parallel fifths are hallmarks of poor voice leading

## Common Confusions

- Parallel motion requires the SAME interval type, not just the same direction (same direction but different intervals = similar motion)
- Parallel imperfect consonances are allowed; parallel perfect consonances are forbidden
- The restriction on parallel fifths/octaves applies specifically to tonal counterpoint—other styles (medieval, impressionist, popular) may use them freely
- Parallel motion across non-adjacent beats (e.g., downbeat to downbeat) can sometimes be acceptable even with perfects, depending on context
- Not all motion in the same direction is parallel—both voices must move by the same generic interval
