# Quick Definition
Parallel motion is a subtype of similar motion where both voices move in the same direction by the same interval, maintaining the same interval type (e.g., parallel thirds) -- parallel perfect consonances (P5-P5, P8-P8) are strictly forbidden in counterpoint.

# Core Definition
**Parallel motion** occurs when "the two parts move in the same direction (both up or both down) by the same distance, such that the starting and ending intervals are of the same type (e.g., parallel thirds)" (Ch. 1). It is a special case of similar motion. Parallel imperfect consonances (parallel 3rds, 6ths) are permitted but should not exceed three in a row. Parallel perfect consonances (parallel 5ths, parallel 8ves) are strictly forbidden because they "promote tonal fusion at the expense of melodic independence" (Ch. 2).

# Prerequisites
- **Interval** -- Must understand intervals to identify parallel motion

# Key Properties
1. Both voices move same direction by same interval
2. Starting and ending intervals are the same type
3. Parallel 5ths and 8ves: strictly forbidden (destroy independence)
4. Parallel 3rds and 6ths: permitted but max three in a row
5. Subset of similar motion

# Construction / Recognition
## To Identify:
1. Check if both voices move in the same direction
2. Check if the interval type stays the same (e.g., both are thirds)

# Context & Application
The prohibition against parallel fifths and octaves is one of the most fundamental rules in Western tonal music, extending from species counterpoint through common-practice harmony. Parallel imperfect consonances provide smooth texture but limit independence.

# Common Errors
- **Error**: Writing parallel fifths or octaves between any two voices
  **Correction**: Always check successive intervals for forbidden parallels

# Common Confusions
- **Confusion**: Parallel motion and similar motion are the same
  **Clarification**: Parallel motion maintains the same interval type; similar motion moves the same direction but by different intervals
