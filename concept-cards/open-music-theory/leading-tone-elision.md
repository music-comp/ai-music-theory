# Leading-Tone Elision

## Quick Definition
Leading-tone elision is a type of harmonic elision in which a chord's leading tone fails to resolve upward by half step as expected and instead becomes the lowered version of itself, transforming the expected resolution into a new dominant function chord (typically V7 or vii°7) that targets a different tonal center.

## Formal Definition
**Leading-tone elision** occurs when:

**Leading tone moves down**: ^7 -> ^b7 (or applied leading tone likewise)

**Expected resolution suppressed**: The triad that should receive the leading tone is skipped

**New chord emerges**: Usually V7 or vii°7 of a new target

**Bass often unchanged**: The expected root becomes the root of V7/X

**Function**: Extends tonal motion by deferring resolution

## Mechanism

**Normal leading-tone resolution**:
```
V7  ->  I
^7  ->  ^1

In C major:
B -> C (leading tone resolves UP by half step)
```

**With leading-tone elision**:
```
V7  ->  V7/IV (expected I elided)
^7  ->  ^b7 of new chord

In C major:
B -> Bb (leading tone moves DOWN by half step)
B becomes the seventh of V7/IV (C7)
```

**Voice leading comparison**:
```
Normal:                   Elision:
B -> C (up)              B -> Bb (down)
D -> C (down)            D -> C or E
F -> E (down)            F -> E or G
G -> G                   G -> G

Leading tone fails to resolve!
```

## Common Progressions

**V6/5 to V4/2/IV**:
```
V6/5:     B-D-F/G (in C major, G7 with B in bass)
Expected: C-E-G (I)

With elision:
V6/5:     B-D-F/G
V4/2/IV:  Bb-C-E/G (C7 with Bb in bass)

B -> Bb (leading tone elided down)
Both have same upper notes (D-F/G -> C-E/G similar)
Bass changes from B to Bb
```

**In Roman numerals**:
```
Expected: V6/5 -> I
Actual:   V6/5 -> V4/2/IV

The I is suppressed
Replaced by dominant of IV
```

**With diminished seventh**:
```
vii°7 -> expected I

With elision:
vii°7 -> vii°7/IV (or some V7)

The diminished seventh reinterpreted
Now functions as applied chord
```

## Bass Note Behavior

**When leading tone is in bass (V6, V6/5, vii°, vii°7)**:
```
These chords have leading tone in bass:
V6 = ^7 in bass
V6/5 = ^7 in bass
vii° = ^7 in bass
vii°7 = ^7 in bass

With leading-tone elision:
Bass MUST move (^7 -> ^b7)
Changes inversion of resulting chord
```

**Example**:
```
V6/5: B-D-F-G (B in bass)
      ↓
V4/2: Bb-C-E-G (Bb in bass)

Bass: B -> Bb
Inversion changes from 6/5 to 4/2
```

**When leading tone is in upper voice**:
```
V or V7 with ^5 in bass:
G-B-D-F (G in bass)

With elision:
G-Bb-C-E (G in bass still)

Bass can stay same!
Only upper voice (B -> Bb) changes
Inversion may be same
```

## Recognizing in Analysis

**Clues**:
```
1. Dominant function chord
2. Followed by another dominant function chord
3. Leading tone appears to "drop" a half step
4. Expected tonic doesn't appear
```

**Roman numeral patterns**:
```
V6/5 -> V4/2/IV (leading-tone elision)
V7 -> V7/IV (leading-tone elision)
vii°7 -> V7/IV (leading-tone elision, reinterpreted)

Any V or vii followed by V or vii of new target
```

**Voice leading trace**:
```
Look for:
^7 -> ^b7
or
Applied ^#X -> ^X (raised scale degree becomes natural)

The half-step DOWN motion is the signature
```

## Musical Effect

**Deferred resolution**:
```
Expected: V -> I (cadence, arrival)
Elision:  V -> V/IV -> ... (continues)

Resolution is put off
Harmonic journey extends
```

**Surprise and continuity**:
```
Listener expects arrival on tonic
Instead, motion continues
Creates sense of "not yet"
```

**Sequence potential**:
```
V/vi -> V/V -> V/IV -> V -> I

Each elision leads to next
Creates descending pattern
Common in development sections
```

## Musical Context

Leading-tone elision serves specific purposes:
- **Delays cadence**: Extends harmonic motion
- **Creates continuity**: Avoids premature resolution
- **Chromatic color**: Introduces unexpected accidentals
- **Sequence building**: Generates chromatic patterns
- **Development technique**: Useful for extending ideas
- **Surprise effect**: Subverts listener expectations
- **Romantic harmony**: Common in 19th-century music

## Examples

### Basic

**Simple leading-tone elision**:
```
In C major:
V7:       G-B-D-F
Expected: C-E-G (I)
Actual:   C-E-G-Bb (V7/IV)

B -> Bb (leading tone drops)
Expected I becomes V7/IV
```

**With bass change**:
```
In C major:
V6/5:     G7/B (B-D-F-G)
Expected: C-E-G (I)
Actual:   C7/Bb (Bb-C-E-G = V4/2/IV)

B -> Bb in bass
Changes inversion
```

**In sequence**:
```
V7/vi -> V7/V -> V7/IV -> V7 -> I
E7      D7      C7       G7    C

Each dominant has leading-tone elision
A# -> A, G# -> G, F# -> F
Creates descending chromatic bass
(if voices arranged appropriately)
```

### From Repertoire

**Beethoven, Symphony No. 5, I**: Leading-tone elisions extend development section.

**Mozart, Piano Sonatas**: Elisions in development, deferred resolutions.

**Schubert, "Erlkonig"**: Leading-tone elisions for dramatic effect.

**Brahms, Symphony No. 4, I**: Extended passages with leading-tone elision.

**Chopin, Preludes**: Elisions create chromatic ambiguity.

## Common Confusions

- Leading-tone elision = leading tone moves DOWN instead of up
- ^7 -> ^b7 (or applied leading tone likewise)
- Expected triad is suppressed/skipped
- Replaced by dominant function chord (V7 or vii°7) of new target
- **Bass behavior depends on original inversion**:
  - If leading tone in bass: bass must change
  - If leading tone in upper voice: bass may stay same
- Common pattern: V6/5 -> V4/2/IV
- Different from deceptive cadence (which goes to vi)
- Elision implies suppression and overlapping
- Creates sense of "not yet arriving"
- Extends harmonic journey
- Can generate chromatic sequences
- Romantic period common device
- Key signature: Half-step DOWN motion of leading tone
