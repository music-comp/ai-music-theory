# Twelve-Tone Composition

## Quick Definition

Twelve-tone composition is the practice of creating music using a twelve-tone row as the primary pitch source, ranging from strict adherence to row ordering to free approaches that use the row as a general guide—involving choices about how literally to follow the row, how to segment and present it (melodically, harmonically, or both), how much repetition to allow, and how to balance serial constraints with musical expression and formal design.

## Formal Definition

**Twelve-tone composition**: Creating music from twelve-tone row material.

**Spectrum of approaches**:
```
FREE ←――――――――――――――――――――――――――――――→ STRICT

Free:
- Row as general pitch reservoir
- Repetitions allowed
- Order suggestions, not rules
- Expressive freedom primary

Strict:
- Exact row order maintained
- No pitch repetition until row complete
- All parameters possibly serialized
- Technical constraints primary
```

**Compositional decisions**:
1. Row selection (or design)
2. Degree of strictness
3. Segmentation approach (trichords, tetrachords, etc.)
4. Textural presentation (melodic, chordal, mixed)
5. Rhythmic treatment (free or serialized)
6. Formal organization

## Musical Context

Twelve-tone composition involves balancing:
- **Constraint and freedom**: How strictly to follow row
- **Unity and variety**: Row coherence vs. musical interest
- **Technique and expression**: Method vs. meaning
- **Tradition and innovation**: Inherited forms vs. new approaches

**Historical range**:
- Schoenberg: Often used tonal forms with twelve-tone pitch
- Webern: Maximum concentration, symmetry
- Berg: Combined twelve-tone with tonal elements
- Dallapiccola: Lyrical, free approach
- Babbitt: Maximum systematization

## Examples

### Basic

**Approach 1: Free fantasia**:
```
Constraints:
- Use row as pitch source
- Emphasize trichordal segments
- Allow note repetition
- Free rhythm and phrasing

Example opening:
Row trichord 1: E-Eb-G
Could become: E--Eb---E-G--Eb-G-E
(repeated, varied rhythm, expressive)

Benefit: Expressive freedom
Challenge: Maintaining serial identity
```

**Approach 2: Moto perpetuo**:
```
Constraints:
- Continuous sixteenth notes
- Repeat each trichord multiple times
- Move to next trichord by retaining one pitch
- 3-against-4 rhythmic pattern

Example:
Trichord 1 (E-Eb-G): E-Eb-G-E-Eb-G-E-Eb-G-E...
Shift to trichord 2: ...E-Eb-G-E-Eb-G-C-Eb-G-C-...
(retain Eb-G, add C from next trichord)

Benefit: Clear process
Challenge: Avoiding monotony
```

**Approach 3: Strict fugue**:
```
Constraints:
- Row as subject
- Combinatorial countersubject
- No pitch repetition across voices
- Traditional fugal procedures

Example subject (12 notes):
Row: E-Eb-G-A-F#-C-... (complete row)

Combinatorial answer:
Hexachord-combinatorial I form
First hexachords complement = aggregate

Benefit: Connects to tradition
Challenge: Complex construction
```

### From Repertoire

**All-trichord rows** (compositional exploration):
```
Marsden's four all-trichord rows:
1. [0, 2, 6, 10, 5, 3, 8, 9, 11, 7, 4, 1]
2. [0, 2, 6, 10, 11, 9, 8, 3, 5, 1, 4, 7]
3. [0, 2, 6, 10, 7, 4, 11, 9, 8, 3, 5, 1]
4. [0, 2, 6, 10, 1, 4, 5, 3, 8, 9, 11, 7]

Properties:
- Circular reading includes all 12 trichord types
- Maximum variety
- Under-explored by composers
- Challenge: "make use of this in composition"
```

**Dallapiccola, Piccola Musica Notturna** (1954):
```
Approach: Free and lyrical
- Row present but unfolds gradually
- Repetitions common
- Luxuriant atmosphere
- "As much Debussy as serialist"

Demonstrates: Twelve-tone need not be austere
```

**Tavener, The Lamb**:
```
Approach: Serial but not twelve-tone
- Only 5-7 pitch classes in "row"
- Clear P, I, R, RI relationships
- Modal final on G
- Tonal/modal sound world

Demonstrates: Serial technique beyond twelve-tone
```

**Compositional process example**:
```
Starting point: All-trichord row with combinatoriality

1. Free opening (fantasia)
   - Solo instrument
   - Explore first trichords
   - Establish character

2. Fugato section
   - Strict four-voice texture
   - Combinatorial pairs
   - Process-driven

3. Moto perpetuo
   - Rhythmic drive
   - Trichord repetition
   - Building density

4. Return to opening
   - Relaxed, reflective
   - Row associations recall opening

Demonstrates: Multiple approaches in single piece
```

## Common Confusions

- Twelve-tone composition ranges from FREE to STRICT
- No single "correct" approach to using a row
- Pitch repetition: some composers allow, others avoid
- Row segments can be melodic, chordal, or both
- Chordal presentation = partial ordering (notes sound together)
- Rhythm typically free (unless total serialism)
- Same row can yield very different pieces
- Technique serves music, not vice versa
- Traditional forms (fugue, sonata) can use twelve-tone pitch
- "Serialism" is broader than "twelve-tone"
- Derived rows guarantee motivic recurrence
- Combinatoriality enables contrapuntal combinations
- Row properties suggest compositional strategies
- Multiple compositional approaches can combine in one piece
