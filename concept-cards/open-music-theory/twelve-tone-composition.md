# Quick Definition
Twelve-tone composition involves choosing rows with interesting properties, then generating pitch material through various approaches ranging from "free" (flexible repetition, intuitive phrasing) to "strict" (no repetitions, combinatorial voice-pairing), with row properties suggesting specific compositional strategies.

# Core Definition
Compositional approaches vary widely. A free fantasia might allow note repetition and flexible grouping while respecting the row's trichordal structure. A process-driven moto perpetuo might cycle through trichords with metrical displacement (3-against-4). A strict fugue might use combinatorial pairs to ensure no pitch repetition across four simultaneous voices. Row properties (all-trichord, combinatorial, symmetrical) suggest strategies. The balance between strict constraints and free creative choice is a central compositional decision.

# Prerequisites
- Twelve-tone row and hexachordal combinatoriality

# Key Properties
1. Infinite compositional approaches from the same row
2. Spectrum from free to strict
3. Row properties suggest strategies (derived rows suggest cell-based writing)
4. Combinatoriality enables polyphonic writing without pitch duplication
5. Trichordal rotation enables continuous variation
6. Rhythmic decisions are typically free (not serialized in standard practice)

# Context & Application
The chapter demonstrates composition with "all-trichord" rows (exactly 4 distinct forms), showing free fantasia, moto perpetuo, and strict fugue approaches. Combinatoriality is practically achieved through inversion-combinatorial rotations.

# Examples
**Example 1**: Free fantasia for solo viola using overlapping trichords with repetition allowed.
**Example 2**: Moto perpetuo cycling through trichords with 3-against-4 metrical dissonance.
**Example 3**: Four-voice fugue using combinatorial pairs to avoid pitch duplication at trichord, hexachord, and row levels.
