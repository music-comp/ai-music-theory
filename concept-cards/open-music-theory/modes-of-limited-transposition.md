# Modes of Limited Transposition

## Quick Definition

Scales identified by Olivier Messiaen that cannot be transposed 12 different ways because their internal symmetry causes certain transpositions to reproduce the same pitch-class content--for example, the whole-tone scale (Messiaen's Mode 1) has only 2 unique transpositions and the octatonic scale (Mode 2) has only 3, a property Messiaen found theologically meaningful, suggesting the "charm of impossibilities" where mathematical limitation points toward transcendence and eternity.

## Formal Definition

**Mode of limited transposition** is a scale whose transpositional symmetry produces fewer than 12 distinct transpositions.

**Criterion**: A scale is a mode of limited transposition if transposing it by some interval less than an octave produces the identical pitch-class collection.

**Mathematical basis**:
- If T(n)(scale) = scale for some n < 12
- Then the scale has limited transposition
- Number of unique transpositions = 12 / n (where n is the smallest such interval)

**Messiaen's catalog**: Seven modes of limited transposition, numbered 1-7.

## Messiaen's Seven Modes

### Mode 1: Whole-Tone Scale
```
Pattern: 2-2-2-2-2-2 (all whole steps)
Notes: 6
Transpositions: 2
Example: C-D-E-F#-G#-A#

Symmetry: T(2)
Same as: WT0, WT1
```

### Mode 2: Octatonic Scale
```
Pattern: 1-2-1-2-1-2-1-2 (alternating half-whole)
Notes: 8
Transpositions: 3
Example: C-C#-D#-E-F#-G-A-Bb

Symmetry: T(3)
Same as: OCT0,1 / OCT1,2 / OCT2,3
Also called: Diminished scale (jazz)
```

### Mode 3: Nine-Note Scale
```
Pattern: 2-1-1-2-1-1-2-1-1
Notes: 9
Transpositions: 4
Example: C-D-Eb-E-F#-G-Ab-Bb-B

Symmetry: T(4)
Contains three augmented triads
```

### Mode 4: Eight-Note Scale
```
Pattern: 1-1-3-1-1-1-3-1
Notes: 8
Transpositions: 6
Example: C-Db-D-F-F#-G-Ab-B

Symmetry: T(6)
Two tritone-related tetrachords
```

### Mode 5: Six-Note Scale
```
Pattern: 1-4-1-1-4-1
Notes: 6
Transpositions: 6
Example: C-Db-F-F#-G-B

Symmetry: T(6)
Two tritone-related trichords
```

### Mode 6: Eight-Note Scale
```
Pattern: 2-2-1-1-2-2-1-1
Notes: 8
Transpositions: 6
Example: C-D-E-F-F#-G#-A#-B

Symmetry: T(6)
Two tritone-related tetrachords
```

### Mode 7: Ten-Note Scale
```
Pattern: 1-1-1-2-1-1-1-1-2-1
Notes: 10
Transpositions: 6
Example: C-Db-D-Eb-F-F#-G-Ab-A-B

Symmetry: T(6)
Most chromatic of the modes
```

## Properties and Relationships

**Subset relationships**:
```
Mode 1 (whole-tone) is a subset of:
- Mode 3
- Mode 6

Mode 2 (octatonic) stands alone (not subset of others)

Modes 4, 5, 6, 7 all have T(6) symmetry:
- Built from tritone-related cells
- 6 unique transpositions each
```

**Intervallic content**:
```
Mode 1: Most uniform (all M2)
Mode 2: Two interval types (m2, M2)
Mode 3: Three interval types (m2, M2, m3)
Modes 4-7: Include larger gaps (m3, M3)
```

**Rotations (starting points)**:
Each mode can begin on different scale degrees, creating different "rotations" that Messiaen considered distinct color shadings.

## Messiaen's Theoretical Framework

**"The charm of impossibilities"**:
Messiaen viewed limited transposition as expressing theological concepts:
- **Impossibility** as a form of **transcendence**
- Mathematical limits pointing to the **infinite**
- The **eternal** suggested by patterns that fold back on themselves

**Color associations**:
Messiaen had synesthesia and associated specific colors with each mode and transposition, describing them in his treatise _The Technique of My Musical Language_.

**Non-retrogradable rhythms**:
Messiaen paired modes of limited transposition with "non-retrogradable rhythms" (palindromic rhythms)--both exhibit symmetry that transcends ordinary progression.

## Musical Characteristics

**Mode 1 (Whole-tone)**:
- Dreamy, floating quality
- No leading tones
- Used for mystery, dreams, water

**Mode 2 (Octatonic)**:
- Rich triadic content
- "Magical" or "supernatural" quality
- Major/minor triads without dominant function

**Mode 3**:
- Augmented triad basis
- Shimmering, unstable
- Contains Mode 1 as subset

**Modes 4-7**:
- More angular, with larger intervals
- Less frequently used in other repertoire
- Distinctively "Messiaenic" sound

## Musical Context

**Messiaen's compositions**:
Nearly all of Messiaen's music uses modes of limited transposition as primary pitch material, including:
- _Quartet for the End of Time_ (1941)
- _Turangalila Symphony_ (1948)
- _Vingt Regards sur l'Enfant-Jesus_ (1944)
- _Catalogue d'oiseaux_ (1958)

**Broader 20th-century usage**:
Modes 1 and 2 were already in common use before Messiaen codified them:
- Mode 1: Debussy, Ravel
- Mode 2: Rimsky-Korsakov, Stravinsky, Bartok

Messiaen's contribution was theoretical systematization and modes 3-7.

**Influence**:
Messiaen's modes influenced his students (Boulez, Stockhausen, Xenakis) and later composers interested in systematic pitch organization.

## Examples

### Basic

**Mode 2 transpositions**:
```
OCT0,1: C - C# - D# - E - F# - G - A - Bb
OCT1,2: C# - D - E - F - G - Ab - Bb - B
OCT2,3: D - Eb - F - F# - G# - A - B - C

Only 3 distinct collections
Transposing OCT0,1 up a minor third = still OCT0,1
```

**Mode 3 construction**:
```
Pattern: 2-1-1-2-1-1-2-1-1 (three identical trichords)

Starting on C:
C -[2]- D -[1]- Eb -[1]- E -[2]- F# -[1]- G -[1]- Ab -[2]- Bb -[1]- B -[1]- C

Contains three augmented triads:
C-E-Ab, D-F#-Bb, Eb-G-B

Transpositions: 4 (symmetric at T(4))
```

**Why limited transposition?**:
```
Mode 2 (octatonic) on C: C-C#-D#-E-F#-G-A-Bb
Transpose up m3: D#-E-F#-G-A-Bb-C-C# = same pitches!

The internal symmetry (period of 3 semitones) means:
- T(3) maps the collection onto itself
- Only 12/3 = 4 positions... but some are equivalent
- Result: 3 unique transpositions
```

### From Repertoire

**Messiaen, _Quartet for the End of Time_, "Liturgie de cristal"**: Opens with Mode 2 and Mode 3 superimposed, creating shimmering textures that evoke eternity.

**Messiaen, "Le banquet celeste"**: Early organ work exploring Mode 2 in extremely slow tempo.

**Messiaen, _Vingt Regards_, No. 1 "Regard du Pere"**: Uses Mode 2 in its opening "Theme of God."

**Messiaen, _Turangalila Symphony_**: Extensive use of all seven modes throughout the ten movements.

**Debussy, "Voiles"**: Pure Mode 1 (whole-tone), predating Messiaen's systematization.

**Stravinsky, _The Rite of Spring_**: Mode 2 (octatonic) passages, particularly in "Augurs of Spring."

## Common Confusions

- "Limited transposition" means FEWER than 12 unique transpositions, not "no transposition"
- Mode 1 = whole-tone scale, Mode 2 = octatonic scale (these have other names too)
- Messiaen identified 7 modes, but Modes 1 and 2 were already in common use
- Each mode has multiple "rotations" (starting points) that Messiaen considered distinct
- Modes 3-7 are less commonly used by other composers
- The "limitation" is a MATHEMATICAL property, not a compositional restriction
- NOT the same as church modes (those are not transpositionally symmetric)
- Number of transpositions = 12 / period of symmetry
- Modes 4-7 all have 6 transpositions (T(6) symmetry = tritone-based)
- Messiaen's theological interpretation is personal; the mathematical properties are objective
