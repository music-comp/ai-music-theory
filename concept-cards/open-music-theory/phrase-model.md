# Quick Definition

The phrase model describes the typical order of harmonic functions in a tonal phrase: Tonic beginning (Tb), Predominant (PD), Dominant (D), and Tonic ending (Te), progressing left to right to create forward motion toward a cadential goal.

# Core Definition

The **phrase model** refers to the typical order and flow of harmonic functions in a phrase (OMT, Ch. IV.1). Its principle is that a phrase needs at least tonic function and dominant function harmonies to exhibit a sense of trajectory. More often, phrases also include a predominant harmony to heighten the trajectory toward closure. Phrases almost always progress from left to right in the model (T to PD to D to T), not from right to left.

The model assigns one set of labels per phrase: **Tb** (tonic beginning), **PD** (predominant), **D** (dominant), **Te** (tonic ending). Each phrase gets one and only one set of these labels (OMT, Ch. IV.7).

# Prerequisites

- **Harmonic function** — The phrase model organizes the three functional categories (T, PD, D) into a temporal sequence

# Key Properties

1. Minimum requirement: tonic + dominant function creates forward motion
2. Common layout: T-PD-D-T (with optional final tonic at half cadences)
3. Functions progress left to right, not right to left
4. Each phrase receives exactly one set of Tb-PD-D-Te labels
5. Tb goes on the opening tonic; PD on the first strong predominant before cadential dominant
6. D goes on the cadential dominant; Te on the cadential tonic (omitted at half cadences)

# Construction / Recognition

## To Apply Phrase Model Labels:
1. Locate the phrase ending and identify the cadence
2. Apply **D** to the cadential dominant
3. If authentic cadence, apply **Te** to the cadential tonic; if half cadence, omit Te
4. Back up to find the first strong predominant before the cadential dominant; apply **PD**
5. Apply **Tb** to the tonic that starts the phrase
6. Verify the functional flow proceeds left to right

## Performing Harmonic Analysis Using the Phrase Model (OMT Ch. IV.7):
1. Identify phrase endings by listening for goals, rests, or new beginnings
2. Analyze the cadence (HC ends on V; AC ends V-I)
3. Look for the strong predominant (fa in the bass, typically ii6 or IV)
4. Analyze from the beginning using knowledge of tonic prolongations

# Context & Application

- **Typical contexts**: Harmonic analysis of common-practice phrases; pedagogy of tonal harmony
- **Common applications**: Guides analytical procedure (work backward from cadence); informs composition (build phrases with functional direction)
- **Historical/stylistic notes**: Central to Classical-era phrase construction; Romantic music sometimes delays or omits Tb. The source notes that delay or omission of the opening tonic is more common in Romantic music.

## Worked Example

Analysis of a phrase ending with PAC:
1. Identify cadence: V7-I in mm. 7-8 (PAC)
2. Label D on V7 (m. 7), Te on I (m. 8)
3. Find strong PD: ii6 in m. 6, label PD
4. Label Tb on opening I in m. 1
5. Result: I ... ii6 - V7 - I = Tb ... PD - D - Te

# Common Errors

- **Error**: Assigning multiple PD labels in a single phrase
  **Correction**: Each phrase gets exactly one set of Tb-PD-D-Te labels; PD goes on the first strong predominant before the cadential dominant

- **Error**: Placing Tb on a non-tonic chord
  **Correction**: Tb labels the tonic that begins the phrase; rarely, a phrase may delay or omit this tonic

# Common Confusions

- **Confusion**: Thinking every chord must have a phrase-model label
  **Clarification**: Only one chord per function per phrase gets labeled; other chords between labels are part of prolongation areas

- **Confusion**: Believing PD always involves IV or ii
  **Clarification**: PD goes on the first strong predominant (IV, ii, ii6) before the cadential dominant; weak predominants (vi, iii) do not receive the PD label
