# Flat Mediant (♭III)

## Quick Definition

The flat mediant (♭III) is a major triad built on the lowered third scale degree, borrowed from the parallel minor, featuring both a lowered root (lowered-^3) and lowered seventh (lowered-^7 as the chord's fifth), creating a distinctly chromatic, dramatic sonority.

## Formal Definition

The **flat mediant** is a borrowed chord with an altered root:

**Structure in C major**:
- Diatonic iii: E-G-B (E minor)
- Borrowed ♭III: E♭-G-B♭ (E♭ major)
- Changed notes:
  - Root: E → E♭ (^3 → lowered-^3)
  - Fifth: B → B♭ (^7 → lowered-^7)

**Characteristics**:
- Major quality (diatonic iii is minor)
- Requires two chromatic alterations
- The flat sign (♭) indicates the lowered ROOT
- Creates dramatic, distinct color
- Less common than ♭VI or ♭VII but still significant

**Roman numeral notation**: ♭III (uppercase indicates major quality, ♭ indicates lowered root)

## Voice Leading

**♭III to IV resolution**:
```
♭III: E♭-G-B♭    IV:  F-A-C

E♭ → F (ascending half step in bass)
G → A (ascending)
B♭ → A or C (lowered-^7 resolves)
```

**♭III to I resolution**:
```
♭III: E♭-G-B♭    I:  C-E-G

E♭ → E (lowered-^3 → ^3, chromatic motion)
G → G (common tone)
B♭ → C (lowered-^7 → ^1)
```

**♭III to ♭VI progression**:
```
♭III: E♭-G-B♭    ♭VI: A♭-C-E♭

Common borrowed chord sequence
E♭ → A♭ (ascending fourth in bass)
Creates rich chromatic color
```

## Comparison with Diatonic iii

| Aspect | iii (diatonic) | ♭III (borrowed) |
|--------|----------------|-----------------|
| Root | E natural | E♭ (lowered) |
| Quality | Minor | Major |
| Notes in C | E-G-B | E♭-G-B♭ |
| Chromatic content | None | Two altered notes |
| Character | Subtle | Dramatic |
| Usage | Less common | Less common |

## Common Progressions

**I - ♭III - IV - I**:
```
C - E♭ - F - C

♭III as passing chord to IV
Creates chromatic bass motion
```

**♭III - ♭VI - ♭VII - I**:
```
E♭ - A♭ - B♭ - C

Sequence of borrowed chords
All from parallel minor
Very dramatic effect
```

**I - ♭III - ♭VII - IV - I**:
```
C - E♭ - B♭ - F - C

Mixing multiple borrowed chords
Common in rock contexts
```

## Musical Context

The ♭III chord appears in:
- **Romantic era**: Part of chromatic mediant relationships
- **Rock and pop music**: Less common than ♭VI or ♭VII but still used
- **Film scores**: Dramatic chromatic coloring
- **Progressive rock**: Extended harmonic vocabulary

**Function notes**:
- ♭III is sometimes considered a chromatic mediant
- Can function as a dramatic alternative to iii
- Often appears in sequences with other borrowed chords
- Creates strong chromatic color when juxtaposed with diatonic I

## Examples

### Basic

**♭III in C major**:
```
I - ♭III - IV - I
C - E♭   - F  - C

E♭ major chord borrowed from C minor
Creates chromatic bass: C - E♭ - F - C
```

**Multiple borrowed chords**:
```
I - ♭III - ♭VI - ♭VII - I
C - E♭   - A♭  - B♭   - C

All borrowed from parallel minor
Creates rich, dark progression
```

**♭III to V motion**:
```
I - ♭III - V - I
C - E♭   - G - C

Dramatic chromatic motion to dominant
E♭ → G in bass (chromatic mediant relationship)
```

## Common Confusions

- ♭III is a MAJOR chord (E♭ major in C), not minor like diatonic iii
- The ♭ indicates a lowered ROOT, not just any flat note
- ♭III requires TWO chromatic alterations (root and fifth)
- Less common than ♭VI or ♭VII, but still an important borrowed chord
- Do not confuse with III in minor keys (which is diatonic, not borrowed)
- The relationship between I and ♭III is a chromatic mediant relationship (major third apart)
- ♭III shares one common tone with I (the fifth of ♭III is the third of I is wrong; G is the third of ♭III and fifth of I)
