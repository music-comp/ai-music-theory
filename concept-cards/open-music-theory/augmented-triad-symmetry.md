# Augmented Triad Symmetry

## Quick Definition

The structural property of augmented triads whereby their equal division of the octave into three major thirds creates a perfectly symmetrical sonority—resulting in only four distinct augmented triad types in the twelve-tone chromatic system, enharmonic equivalence between any two augmented triads a major third apart, and connections to whole-tone collections, hexatonic systems, and neo-Riemannian transformations.

## Formal Definition

**Augmented triad symmetry** describes the structural properties of + chords:

**Mathematical basis**:
```
Octave = 12 semitones
Augmented triad = 3 notes
12 ÷ 3 = 4 semitones between each note
4 semitones = major third (M3)

M3 + M3 + M3 = 12 (octave)
```

**Consequence**: Only **four unique augmented triads**:
```
Set 1: C+ = E+ = G#/A-flat+ (C-E-G#)
Set 2: D-flat+ = F+ = A+ (D-flat-F-A)
Set 3: D+ = F#/G-flat+ = A#/B-flat+ (D-F#-A#)
Set 4: E-flat+ = G+ = B+ (E-flat-G-B)
```

**Comparison to °7 symmetry**:
```
°7: divides octave into 4 (m3s) = 3 unique chords
+: divides octave into 3 (M3s) = 4 unique chords

4 × 3 = 12 and 3 × 4 = 12 (both cover chromatic collection)
```

## Four Unique Augmented Sonorities

**Set 1** (containing C, E, G#):
```
C+:   C  - E  - G#
E+:   E  - G# - B# (=C)
G#+:  G# - B# - D## (=E)

Pitch classes: {C, E, G#}
Three spellings, one sound
```

**Set 2** (containing D-flat, F, A):
```
D-flat+: D-flat - F - A
F+:      F - A - C# (=D-flat)
A+:      A - C# - E# (=F)

Pitch classes: {D-flat, F, A}
```

**Set 3** (containing D, F#, A#):
```
D+:   D - F# - A#
F#+:  F# - A# - C## (=D)
A#+:  A# - C## - E## (=F#)

Pitch classes: {D, F#, A#/B-flat}
```

**Set 4** (containing E-flat, G, B):
```
E-flat+: E-flat - G - B
G+:      G - B - D# (=E-flat)
B+:      B - D# - F## (=G)

Pitch classes: {E-flat, G, B}
```

## Relation to Whole-Tone Scale

**Augmented triads and whole-tone collections**:
```
Whole-tone scale 1: C-D-E-F#-G#-A#
Contains augmented triads: C+, D+, E+, F#+, G#+, A#+
(But C+ = E+ = G#+, and D+ = F#+ = A#+)

Two unique + triads per whole-tone collection
```

**Two whole-tone scales**:
```
WT1: C-D-E-F#-G#-A# → contains C+ and D+
WT2: D-flat-E-flat-F-G-A-B → contains D-flat+ and E-flat+

Four + triads = two from each whole-tone scale
```

## Multiple Interpretations

**Enharmonic respelling**:
```
C+ played in isolation:
- C as root? C major with raised 5th?
- E as root? E major with raised 5th?
- G# as root? G# major with raised 5th?

Without context, all three equally valid
Context (approach/resolution) determines spelling
```

**Voice leading determines root**:
```
If G# → A (resolves up):
  Spell as C+ (C-E-G#), G# = raised 5th

If C → B (resolves down):
  Spell as E+ (E-G#-B#), B# resolving?

Leading-tone behavior clarifies interpretation
```

## Neo-Riemannian Connections

**Hexatonic systems**:
```
C - E - G# (augmented triad)
↓   ↓   ↓
Connects C major - E major - A-flat major

Major triads related by M3
Augmented triad = "common subset"
```

**PLR operations**:
```
P (parallel), L (leading-tone), R (relative)
Moving through these connects triads
Augmented triad appears at certain points
Voice-leading parsimony principle
```

## Musical Context

Augmented triad symmetry enables:
- **Tonal ambiguity**: No clear root acoustically
- **Three destinations**: Each note can be root
- **Whole-tone connection**: Links to whole-tone harmony
- **Voice-leading flexibility**: Multiple resolution paths
- **Romantic chromaticism**: Coloristic sonority
- **Impressionist harmony**: Debussy, Ravel
- **Modulation tool**: Pivot via reinterpretation
- **Neo-Riemannian analysis**: Connects triadic voice leading

Fundamental to understanding symmetric harmony and chromatic voice leading.

## Examples

### Basic

**Four unique + triads**:
```
Set 1: C-E-G#     (C+ = E+ = G#+)
Set 2: D-flat-F-A  (D-flat+ = F+ = A+)
Set 3: D-F#-A#    (D+ = F#+ = A#+)
Set 4: E-flat-G-B (E-flat+ = G+ = B+)

Only four distinct sounds
12 notes ÷ 3 per chord = 4 unique chords
```

**One chord, three roots**:
```
C-E-G# can be:

1. C+ (C major with raised fifth)
   V+ of F (resolve to F major)
   
2. E+ (E major with raised fifth)
   V+ of A (resolve to A major)
   
3. G#/A-flat+ (A-flat major with raised fifth)
   V+ of D-flat (resolve to D-flat major)

Same sound, three possible functions
Resolution determines interpretation
```

**Whole-tone scale connection**:
```
Whole-tone scale: C-D-E-F#-G#-A#

Augmented triads within:
C+ = C-E-G#
D+ = D-F#-A#

Both + triads share whole-tone scale
Moving between them = whole-tone motion
```

**Symmetry visualization**:
```
Augmented triad clock:

        C
       / \
      /   \
     E-----G#

Equilateral triangle
Each vertex 4 semitones (M3) from neighbors
Rotate 4 semitones = same chord, different spelling
```

### From Repertoire

**Liszt, "Faust Symphony"**: Augmented triads represent Mephistopheles' ambiguity, symmetry as metaphor for evil's instability.

**Debussy, "Voiles"**: Whole-tone and augmented triad harmony, exploits symmetry for floating, rootless effect.

**Ravel, "String Quartet"**: Augmented triads connect chromatic passages, voice-leading parsimony.

**Film scores**: Augmented triad symmetry creates suspense, ambiguity used for psychological effect.

**Berg, "Wozzeck"**: Augmented triads contribute to expressionist harmonic language.

## Common Confusions

- Symmetry = equal interval structure (all major thirds)
- Only FOUR unique + sonorities in chromatic system
- Each + has THREE enharmonic spellings (one per note as "root")
- Different from °7 symmetry (which has four notes, three unique chords)
- + divides octave in three; °7 divides in four
- 4 + triads × 3 notes = 12 (covers chromatic collection)
- 3 °7 chords × 4 notes = 12 (same coverage)
- Whole-tone scale contains two + triads (C+ and D+ in WT1)
- No acoustically privileged root (like °7)
- Context/voice-leading determines interpretation
- Neo-Riemannian theory formalizes relationships
- Hexatonic system relates major triads by M3
- + triad = intersection point of hexatonic system
- Romantic/Impressionist composers exploit symmetry
- Creates ambiguity, floating quality
- Less versatile for modulation than °7 (only 3 destinations vs. 4)
- But offers different tonal colors and connections
