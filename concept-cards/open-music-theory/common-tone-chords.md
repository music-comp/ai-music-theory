# Common-Tone Chords

## Quick Definition
Common-tone chords are chromatic embellishing chords (either diminished seventh or augmented sixth) that share a pitch with the chord they embellish, functioning not as harmonic progressions but as the culmination of multiple simultaneous neighbor tones that prolong a single harmony.

## Formal Definition
**Common-tone chords** are chromatic embellishing sonorities:

**Two types**:
1. CT°7 (common-tone diminished seventh)
2. CT+6 (common-tone augmented sixth)

**Defining characteristics**:
- Share a "common tone" with embellished chord
- Result from simultaneous neighbor-tone motion
- Prolong single harmony (no functional progression)
- Return to same chord they departed from

**Function**: Embellishment, not progression

## Derivation from Neighbor Tones

**Single neighbor tone**:
```
Simple neighbor motion:
C - D - C (upper neighbor to C)
C - B - C (lower neighbor to C)
```

**Multiple simultaneous neighbors**:
```
Chord tone -> Neighbor -> Chord tone

In C major triad:
C -> C (common tone, stays)
E -> Eb (lower chromatic neighbor)
G -> Ab (upper chromatic neighbor)

All voices move as neighbors simultaneously
Creates chromatic chord in the middle
```

**CT°7 emerges from this pattern**:
```
C major:     C - E - G
Neighbors:   C - Eb - Ab - Bbb (sounds like A)
C major:     C - E - G

The neighbor chord = C°7 or Db°7 (enharmonic)
One common tone (C) connects all three chords
```

## CT°7 (Common-Tone Diminished Seventh)

**Construction on ^1**:
```
In C major, embellishing I:
Build °7 on ^1 (C):

CT°7: C - Eb - Gb - Bbb (= A enharmonically)

This shares C with C major triad (common tone)
```

**Voice leading pattern**:
```
I:        C - E - G - C
CT°7:     C - Eb - Gb - A
I:        C - E - G - C

C stays (common tone)
E -> Eb -> E (chromatic neighbor)
G -> Gb -> G (chromatic neighbor)  
C -> A -> C (unusual motion, or hold C)
```

**Resolving to V7**:
```
I:        C - E - G - C
CT°7:     C - Eb - Gb - A
V7:       B - D - F - G

Can also connect I to V7
CT°7 creates chromatic bridge
```

## CT+6 (Common-Tone Augmented Sixth)

**Same pitches as Ger+6, different function**:
```
Ger+6:  ^b6 - ^1 - ^b3 - ^#4 (predominant function)
CT+6:   Same pitches but embellishes I or V

Function difference:
Ger+6: Resolves to V (harmonic progression)
CT+6: Resolves back to embellished chord (prolongation)
```

**Construction**:
```
To embellish C major (I):

Find neighbors to C triad:
- Root (C): Keep as common tone
- Third (E): Lower neighbor = Eb
- Fifth (G): Upper and lower neighbors = Ab and F#

CT+6: C - Eb - F# - Ab
      = Same as Ab-C-Eb-F# (Ger+6 spelling)

Shares C with C triad (common tone)
```

**Darker sound than CT°7**:
```
CT°7:  Uses two chromatic neighbors (Eb, Gb)
CT+6:  Uses THREE chromatic neighbors (Eb, F#, Ab)

CT+6 is "darker" because all neighbors are chromatic
CT°7 has one diatonic neighbor in some contexts
```

## Comparison: CT°7 vs CT+6

| Feature | CT°7 | CT+6 |
|---------|------|------|
| Chord type | Diminished seventh | German sixth (Mm7) |
| Common tone | Usually root of I | Usually root of I |
| Neighbors | 2 chromatic | 3 chromatic |
| Sound | Tense, bright | Darker, richer |
| Function | Embellishment | Embellishment |

## Incomplete Neighbors

**CT°7 with incomplete neighbors**:
```
Not all voices need full neighbor motion:

I:        C - E - G
CT°7:     C - Eb - Gb
I:        C - E - G (but different voicing)

Some voices might skip the return
Creates more varied voice leading
```

**Flexibility in voice leading**:
```
The embellishing chord doesn't require:
- All voices to move
- Perfect neighbor resolution
- Same voicing on return

As long as common tone is present
And function is embellishment (not progression)
```

## Recognition Techniques

**Identifying common-tone chords**:
```
1. Same chord before and after
   I - ??? - I or V - ??? - V

2. One pitch shared (common tone)
   Look for held or repeated note

3. Other voices move by step
   Chromatic neighbor motion

4. °7 or +6 sonority
   Diminished seventh or German sixth sound

5. No functional progression
   Doesn't drive harmony forward
```

**Distinguishing from functional chords**:
```
Functional vii°7:    vii°7 -> I (resolves TO tonic)
Common-tone CT°7:    I -> CT°7 -> I (embellishes tonic)

Functional Ger+6:    Ger+6 -> V (predominant function)
Common-tone CT+6:    I -> CT+6 -> I (embellishes tonic)
```

## Musical Context

Common-tone chords serve specific purposes:
- **Prolongation**: Extend single harmony through time
- **Chromatic color**: Add chromaticism without progression
- **Voice leading interest**: Create chromatic lines
- **Expressive intensification**: Heighten emotion at static harmony
- **Romantic idiom**: Particularly common in 19th century
- **Non-functional**: Don't drive harmonic motion
- **Returns to origin**: Always resolve back to embellished chord

## Examples

### Basic

**CT°7 embellishing tonic**:
```
I:     C - E - G - C
CT°7:  C - Eb - Gb - Bbb(A)
I:     C - E - G - C

C = common tone throughout
Other voices: chromatic neighbors
```

**CT+6 embellishing tonic**:
```
I:     C - E - G - C
CT+6:  C - Eb - F# - Ab
I:     C - E - G - C

C = common tone
Sounds like German sixth
But function = embellishment
```

**CT°7 embellishing dominant**:
```
V:     G - B - D - G
CT°7:  G - Bb - Db - E
V:     G - B - D - G

G = common tone
Prolongs dominant
```

### From Repertoire

**Chopin, Nocturnes**: Common-tone diminished sevenths embellish tonic, chromatic Romantic style.

**Chopin, Mazurka Op. 67 No. 4**: CT+6 embellishing A minor tonic, German sixth sound without progression.

**Brahms, Piano works**: Both CT°7 and CT+6 for chromatic prolongation.

**Wagner, Music dramas**: Common-tone chords in chromatic harmony.

**Schubert, Lieder**: CT°7 for expressive text painting.

## Common Confusions

- Common-tone chords = chromatic embellishing sonorities (CT°7 or CT+6)
- Share a pitch (common tone) with chord being embellished
- Result from multiple simultaneous neighbor tones
- **CT°7**: Diminished seventh chord built on ^1
- **CT+6**: Same pitches as German sixth, different function
- Both prolong a single harmony (usually I or V)
- **Not functional**: Don't create harmonic progression
- Return to same chord they departed from
- CT+6 is "darker" (all three neighbors chromatic)
- CT°7 vs functional vii°7: CT embellishes, vii°7 resolves
- CT+6 vs Ger+6: CT embellishes, Ger+6 progresses to V
- Romantic period specialty (Chopin, Brahms, Wagner)
- Common tone can be in any voice
- Incomplete neighbors possible (not all voices return)
