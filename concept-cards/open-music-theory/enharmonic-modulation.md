# Enharmonic Modulation

## Quick Definition

A modulation technique that exploits the enharmonic respelling of a chord to reinterpret its function and pivot to a new key—most commonly using the German augmented sixth (Ger⁺⁶) which is enharmonically equivalent to a dominant seventh chord (V⁷), or the fully diminished seventh (°7) which can be respelled four ways due to its symmetrical structure, enabling dramatic modulations to distant keys (often a half step away) through the reinterpretation of the same sound with different notation and function, characteristic of late Romantic music (Liszt, Wagner) for sudden, magical key changes without chromatic voice leading, purely through notational reinterpretation.

## Formal Definition

**Enharmonic modulation** is a modulation technique using enharmonic reinterpretation of a chord as the pivot.

**Process**:
1. **Old key**: Chord has one spelling and function
2. **Enharmonic respelling**: Same sound, different notation
3. **New function**: Respelled chord has different function
4. **New key**: Respelling enables pivot to distant key

**Key characteristics**:
- **Same sound**: Pitch content identical
- **Different spelling**: Notation changes
- **Different function**: Harmonic role reinterpreted
- **Distant keys**: Often half-step or tritone relationships
- **No voice leading**: Pure reinterpretation

**Common enharmonic pivots**:
- **Ger⁺⁶ = V⁷**: Most common enharmonic equivalence
- **°7**: Four possible respellings (symmetrical)

## German Sixth = Dominant Seventh

**Enharmonic equivalence**:
```
Ger⁺⁶ in C major: A♭-C-E♭-F#
                  =
V⁷ in G♭ major:   A♭-C-E♭-G♭

F# = G♭ (enharmonically)
Same sound, different function
```

**Voice leading**:
```
C major: Ger⁺⁶  |
         A♭-C-E♭-F#
         ↓
         Respell F# as G♭
         ↓
G♭ major:  V⁷    | I
           A♭-C-E♭-G♭  D♭-F-A♭

No actual voice motion at pivot
Pure reinterpretation
Dramatic half-step key change (C → D♭)
```

**Enables modulation**: C major → D♭ major (half step up)

## Diminished Seventh Enharmonics

**Symmetrical structure** (all m3s):
```
One °7 chord has four spellings:

C°7  = C-E♭-G♭-B♭♭(A)
E♭°7 = E♭-G♭-B♭♭-D♭♭(C)
G♭°7 = G♭-B♭♭-D♭♭-F♭♭(E♭)
A°7  = A-C-E♭-G♭

All sound identical
Different functions in different keys
```

**Enharmonic pivot**:
```
vii°7/V in C: B°7 = B-D-F-A♭
              =
vii°7 in A♭:  G°7 = G-B♭(B♮)-D♭(D♮)-F♭(F♮)

Respell to pivot to A♭ major
Symmetry enables multiple respellings
```

**Enables modulation to**: Four different keys (related by m3)

## Common Enharmonic Modulations

**Half-step modulation** (via Ger⁺⁶):
```
C major → D♭ major (or C# major)

Ger⁺⁶ in C = A♭-C-E♭-F#
          ↓ (respell F# → G♭)
V⁷ in D♭ = A♭-C-E♭-G♭

Modulates up by half step
```

**Tritone modulation** (via °7):
```
C major → F# major

vii°7/V in C = B°7
            ↓ (respell)
vii°7 in F# = E#°7 (enharmonic equivalent)

Dramatic tritone relationship
```

**Minor third cycle** (via °7):
```
°7 symmetry enables modulations by m3:
C → E♭ → G♭ → A → C (returns)

Each step uses enharmonic respelling
Divides octave equally
```

## Enharmonic Modulation Process

**No actual voice leading**:
```
Old key:  Chord spelled one way
          ↓
          RESPELLING (same pitches)
          ↓
New key:  Chord spelled differently, new function

Voices don't actually move
Notation/interpretation changes
```

**Cadential confirmation**:
```
Old key: ... Ger⁺⁶ |
                   ↓ (respell)
New key:         | V⁷ - I

Respelled chord resolves in new key
Cadence confirms modulation
```

## Musical Effect

**Creates**:
- **Sudden shift**: No chromatic preparation
- **Dramatic effect**: Surprising key change
- **Distant keys**: Half-step, tritone relationships
- **Magical quality**: "Pivots" without motion
- **Romantic idiom**: Characteristic of late 19th century
- **Tonal ambiguity**: Exploits enharmonic equivalence

**Different from chromatic modulation**: No actual chromatic voice leading, pure respelling

## Musical Context

Enharmonic modulation serves specific purposes:
- **Dramatic key change**: Sudden shifts to remote keys
- **Late Romantic technique**: Liszt, Wagner, Franck
- **Exploits equal temperament**: Enharmonic equivalence only works in equal temperament
- **Ger⁺⁶ most common**: Augmented sixth to dominant seventh
- **Diminished seventh**: Symmetry enables multiple pivots
- **Distant relationships**: Half-step modulations common
- **No voice leading needed**: Pure reinterpretation
- **Tonal magic**: Creates sense of transformation

Essential technique for understanding late Romantic harmony.

## Examples

### Basic

**Ger⁺⁶ = V⁷ modulation** (C → D♭):
```
C major: I  -  Ger⁺⁶  |
         C     A♭-C-E♭-F#
                    ↓
                (respell F# → G♭)
                    ↓
D♭ major:            | V⁷  -  I
                     | A♭-C-E♭-G♭  D♭-F-A♭

F# respelled as G♭
Enables pivot to D♭ major
Half-step key change
```

**Analytical notation**:
```
C: I    Ger⁺⁶ |
         ═════
         Ger⁺⁶ = V⁷
         ═════
D♭:            | V⁷   I

Double line shows enharmonic reinterpretation
```

**Diminished seventh pivot** (C → E♭):
```
C major: V  -  vii°7  |
         G     B°7 (B-D-F-A♭)
                    ↓
                (respell as D°7: D-F-A♭-C♭(B))
                    ↓
E♭ major:            | vii°7  -  I
                     | D°7        E♭

Symmetrical °7 respelled
Pivots to E♭ major (m3 away)
```

**Multiple enharmonic paths**:
```
From C major using B°7:

Respell as B°7  → to C major/minor
Respell as D°7  → to E♭ major/minor
Respell as F°7  → to G♭ major/minor
Respell as A♭°7 → to A major/minor

Four possible destinations from one sound
```

**Progression example**:
```
mm. 1-4 (C major): I - IV - V - I
m. 5:              Ger⁺⁶ (A♭-C-E♭-F#)
                   ↓ respell
mm. 6-8 (D♭ major): V⁷ - I - IV - I

Sudden shift to D♭ via enharmonic pivot
```

### From Repertoire

**Beethoven, "Moonlight" Sonata, Op. 27 No. 2**: Enharmonic modulation in development (C# minor context), uses diminished seventh enharmonics.

**Liszt, Piano works**: Extensive enharmonic modulations, particularly via Ger⁺⁶ = V⁷, enables fluid motion to distant keys.

**Wagner, "Tristan und Isolde"**: Famous enharmonic reinterpretations, diminished seventh and augmented sixth pivots, creates harmonic ambiguity and chromaticism.

**Schubert, Piano Sonatas**: Enharmonic modulations to distant keys, particularly third-related keys via °7.

**Franck, Organ works and Symphony**: Enharmonic modulations central to style, half-step relationships via Ger⁺⁶.

**Late Romantic generally**: Enharmonic modulation characteristic technique, exploits equal temperament fully.

## Common Confusions

- Enharmonic modulation = modulation via **respelling** (not voice motion)
- Same sound, different notation and function
- Most common: **Ger⁺⁶ = V⁷** (F# = G♭, E# = F, etc.)
- German augmented sixth enharmonically equals dominant seventh
- **No voice leading** at pivot (pure reinterpretation)
- Diminished seventh symmetrical: four possible respellings
- °7 enables modulations by minor third (C → E♭ → G♭ → A → C)
- Enables **distant modulations** (half-step, tritone common)
- C → D♭ via Ger⁺⁶ = V⁷ (very common)
- Late Romantic technique (Liszt, Wagner, Franck, Schubert)
- Requires **equal temperament** (enharmonics only work in equal temperament)
- Different from chromatic modulation (which has voice leading)
- Different from common chord (which uses diatonic pivot)
- "Magical" effect (sudden key change without chromatic motion)
- Ger⁺⁶ in C = V⁷ in D♭ (F# → G♭ respelling)
- Analytical notation shows respelling with special marking
- Confirms new key with cadence
- Exploits notation to reinterpret harmonic function
- Characteristic of late 19th-century tonal exploration
