# Parsimonious Voice Leading

## Quick Definition

Voice leading in which no single voice moves more than a step (whole step or half step), with half-step motion being the most parsimonious; the central principle underlying Neo-Riemannian theory, where the basic transformations (P, L, R) are valued precisely because they preserve common tones and minimize voice-leading distance, enabling smooth connections between triads regardless of their functional relationship or key membership.

## Formal Definition

**Parsimonious voice leading** principles:

**Definition of parsimony**:
- From Latin "parsimonia" = frugality, economy
- Musical parsimony = minimal voice-leading motion
- Most parsimonious = half-step motion
- Still parsimonious = whole-step motion
- Not parsimonious = leaps (thirds or larger)

**Measuring parsimony**:
```
Total semitone displacement:
C → Cm: 1 semitone (E → Eb)
C → Am: 2 semitones (G → A)
C → Em: 1 semitone (C → B)
C → Abm: 3 semitones (C→B, E→Eb, G→Ab) via H

Lower total = more parsimonious
```

**Neo-Riemannian rankings**:
```
Most parsimonious (1 half step total):
P: C → Cm (E → Eb)
L: C → Em (C → B)

Moderately parsimonious (2 semitones total):
R: C → Am (G → A, one whole step)
S: C → C#m (C → C#, G → G#, two half steps)
N: C → Fm (E → F, G → Ab, two half steps)

Least parsimonious (3 semitones total):
H: C → Abm (all three voices move by half step)
```

## Why Parsimony Matters

**Smooth voice leading**:
- Each voice moves minimally
- No large leaps to track
- Easy to follow aurally
- Creates sense of coherence

**Alternatives to functional logic**:
- Traditional: Chords cohere by function (T-PD-D-T)
- Parsimonious: Chords cohere by voice-leading proximity
- Music can be triadic but non-functional AND still coherent

**The Neo-Riemannian insight**:
```
Brahms's progression makes no functional sense:
Ab - Abm - E - Em - C - Cm - Ab

But every move is maximally parsimonious (P or L)
This IS the logic that makes it cohere
```

## Parsimonious Spaces

**The Tonnetz as voice-leading space**:
- Adjacent triads share an edge
- Edge = parsimonious connection
- Distance on Tonnetz ≈ voice-leading distance

**The Cube Dance**:
- Every edge = one half-step motion
- Adjacent vertices = maximally parsimonious
- Augmented triads = "hubs" for parsimony

## Measuring Distance

**Total voice-leading distance**:
```
From C (C-E-G) to various triads:

To Cm (C-Eb-G):    |E-Eb| = 1 semitone  (P)
To Em (B-E-G):     |C-B| = 1 semitone   (L)
To Am (A-C-E):     |G-A| = 2 semitones  (R)
To F (F-A-C):      |E-F| + |G-A| = 3    (L + R)
To Abm (Ab-Cb-Eb): |C-B| + |E-Eb| + |G-Ab| = 3 (H)
To F#m (F#-A-C#):  |C-C#| + |E-F#| + |G-A| = 5

Closer = more parsimonious
C is "close" to Cm, Em, Am
C is "far" from F#m
```

## Musical Context

Parsimonious voice leading appears in:
- **Late Romantic**: Brahms, Wagner, Wolf, Mahler
- **Film music**: Smooth transitions, non-functional progressions
- **Minimalism**: Gradual voice-leading transformations
- **Analysis criterion**: Judging coherence of non-functional music
- **Composition tool**: Generate smooth progressions
- **Counterpoint tradition**: Smooth voice leading always valued
- **Neo-Riemannian theory**: Parsimony is the central organizing principle

## Examples

### Basic

**Comparing parsimony**:
```
From C major to various chords:

Most parsimonious (1 half step):
C (C-E-G) → Cm (C-Eb-G)    P transformation
C (C-E-G) → Em (B-E-G)     L transformation

Moderately parsimonious (2 semitones):
C (C-E-G) → Am (A-C-E)     R transformation
   G → A = whole step = 2 semitones

C (C-E-G) → C#m (C#-E-G#)  S transformation
   C → C#, G → G# = 2 half steps = 2 semitones

Less parsimonious (3 semitones):
C (C-E-G) → Abm (Ab-Cb-Eb) H transformation
   C → B, E → Eb, G → Ab = 3 half steps

Not parsimonious (more than 3):
C (C-E-G) → Dm (D-F-A)
   C → D, E → F, G → A = whole + half + whole = 4
```

**A parsimonious progression**:
```
C - Cm - Ab - Abm - E - Em - C

C → Cm:   1 (P)
Cm → Ab:  1 (L)
Ab → Abm: 1 (P)
Abm → E:  1 (L)
E → Em:   1 (P)
Em → C:   1 (L)

Total: 6 semitones for 6 chord changes
Average: 1 semitone per change = maximally parsimonious
```

**Non-parsimonious for contrast**:
```
C - Dm - Em - F - G - Am - C (diatonic ascending)

C → Dm:  C→D, E→F, G→A = 4 semitones
Dm → Em: D→E, F→G, A→B = 5 semitones
etc.

Much more voice-leading work!
Functional, but not parsimonious
```

### From Repertoire

**Brahms**: Parsimonious PL cycles create the distinctive chromatic sound.

**Wagner, Tristan**: Parsimony enables continuous chromatic motion without losing triadic coherence.

**Film music (Howard Shore, Lord of the Rings)**: Parsimonious progressions for continuous underscore.

**Schubert, Lieder**: Early examples of privileging parsimony over function.

## Common Confusions

- Parsimonious = "economical" voice leading (minimal motion)
- Most parsimonious = half-step motion (1 semitone per voice)
- Still parsimonious = whole-step motion (2 semitones)
- Not parsimonious = leaps (3+ semitones per voice)
- P and L are maximally parsimonious (1 semitone total)
- R is less parsimonious (2 semitones, but still good)
- H is least parsimonious of named transformations (3 semitones)
- Total semitone displacement = sum of all voice motions
- Parsimony ≠ same as functional logic (different organizing principles)
- Parsimonious music can be coherent WITHOUT functional harmony
- The Tonnetz and Cube Dance visualize parsimonious relationships
- Adjacent = parsimonious; distant = less parsimonious
- Central to understanding Neo-Riemannian analysis
