# Quick Definition
A six-note collection formed by alternating minor seconds and minor thirds (interval pattern 1-3-1-3-1-3). Only four distinct hexatonic collections exist, named by their lowest semitone (e.g., HEX0,1). Each contains three major triads, three minor triads, and two augmented triads.

# Core Definition
The hexatonic collection alternates semitones and minor thirds. Like the octatonic, it can only be transposed a limited number of times (four) before cycling back. It is equivalent to set class (014589), the "magic hexachord." It can be generated by juxtaposing two augmented triads a semitone apart. Contains triads but no tonic chord or home key. Named "hexatonic" for its six notes, though other six-note scales exist (blues scale).

# Prerequisites
None specific

# Key Properties
1. Six notes, interval pattern 1-3-1-3-1-3
2. Only 4 distinct collections
3. 3 major triads + 3 minor triads + 2 augmented triads per collection
4. Can be generated from two augmented triads a semitone apart
5. Equivalent to set class (014589) / magic hexachord
6. Named by lowest semitone: HEX0,1; HEX1,2; etc.

# Context & Application
The hexatonic collection connects to neo-Riemannian theory (hexatonic cycles), twelve-tone theory (magic hexachord), and the distance model (1:3 mode).

# Examples
**Example 1**: HEX0,1 = {0,1,4,5,8,9} = C-C#-E-F-Ab-A.
