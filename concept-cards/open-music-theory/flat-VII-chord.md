# Flat Subtonic (♭VII)

## Quick Definition

The flat subtonic (♭VII) is a major triad built on the lowered seventh scale degree, borrowed from the parallel minor (or Mixolydian mode), featuring a lowered root (lowered-^7) that creates a major chord a whole step below tonic, extremely common in rock and popular music.

## Formal Definition

The **flat subtonic** is a borrowed chord with an altered root:

**Structure in C major**:
- Diatonic viio: B-D-F (B diminished)
- Borrowed ♭VII: B♭-D-F (B♭ major)
- Changed note: Root B → B♭ (^7 → lowered-^7)

**Characteristics**:
- Major quality (diatonic vii is diminished)
- Only requires one chromatic alteration (the root)
- The flat sign (♭) indicates the lowered ROOT
- Creates modal, "mixolydian" flavor

**Roman numeral notation**: ♭VII (uppercase indicates major quality, ♭ indicates lowered root)

## Voice Leading

**♭VII to I resolution**:
```
♭VII: B♭-D-F    I:  C-E-G

B♭ → C (lowered-^7 → ^1, whole-step ascent in bass)
D → E or C (^2 resolves to chord tone of I)
F → E or G (^4 resolves to chord tone of I)
```

Unlike the leading tone (^7 → ^1), the lowered-^7 approaches tonic from below by whole step rather than half step, creating a less directed but still satisfying resolution.

**♭VII to IV resolution**:
```
♭VII: B♭-D-F    IV:  F-A-C

Common in rock progressions
B♭ → F (descending fourth in bass)
Relaxed, modal sound
```

## Comparison with Diatonic viio

| Aspect | viio (diatonic) | ♭VII (borrowed) |
|--------|-----------------|-----------------|
| Root | B natural | B♭ (lowered) |
| Quality | Diminished | Major |
| Notes in C | B-D-F | B♭-D-F |
| Chromatic content | None | One altered note |
| Function | Dominant | Subtonic/modal |
| Character | Tense, unstable | Stable, modal |

## Common Progressions

**♭VII - I (plagal-style cadence)**:
```
♭VII - I
B♭   - C

Whole-step approach to tonic
Modal, less directional than V-I
Common in rock
```

**I - ♭VII - IV - I**:
```
C - B♭ - F - C

Extremely common rock progression
Creates modal, relaxed sound
Bass descends then ascends
```

**♭VI - ♭VII - I (double plagal)**:
```
A♭ - B♭ - C

Two borrowed chords approaching tonic
Rising bass by whole steps
Very common rock/pop progression
```

**I - ♭VII - ♭VI - ♭VII - I**:
```
C - B♭ - A♭ - B♭ - C

Descending then ascending borrowed chord pattern
Creates rich modal color
```

## Musical Context

The ♭VII chord is most prominent in:
- **Rock music**: One of the defining harmonic characteristics
- **Pop music**: Very common borrowed chord
- **Blues**: Modal inflections
- **Folk music**: Modal traditions
- **Film scores**: For accessible, modal coloring

**Stylistic note**: While ♭VII can be analyzed as borrowed from parallel minor, in rock and pop it is so common that it functions as part of the style's basic harmonic vocabulary, often better understood through the lens of modal mixture or Mixolydian mode.

## Examples

### Basic

**♭VII in C major**:
```
I - ♭VII - IV - I
C - B♭   - F  - C

B♭ major chord borrowed from C minor
Creates modal, rock-style sound
```

**Double plagal progression**:
```
♭VI - ♭VII - I
A♭  - B♭   - C

Both chords borrowed
Ascending whole-step bass motion
Classic rock ending
```

**Extended rock progression**:
```
I - ♭VII - ♭VI - V
C - B♭   - A♭  - G

Descending bass: C - B♭ - A♭ - G
Mixes borrowed chords with diatonic V
```

## Common Confusions

- ♭VII is a MAJOR chord (B♭ major in C), not diminished like diatonic viio
- The ♭ indicates a lowered ROOT, not just any flat note
- ♭VII only requires ONE chromatic alteration (the root)
- The chord is sometimes called the "subtonic" (vs. "leading tone" for ^7)
- In rock/pop, ♭VII is so common it may not feel "borrowed"—it's part of the style's vocabulary
- The resolution ♭VII → I is by ascending whole step, not half step like viio → I
- Can also be understood through Mixolydian mode (where lowered-^7 is diatonic)
- Do not confuse with V/IV (which has B natural in C major)
