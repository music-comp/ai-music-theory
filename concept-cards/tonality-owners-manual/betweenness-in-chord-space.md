# Quick Definition

The geometrical property of the spiral diagram that encodes which chords can be inserted between two others without disrupting the overall voice-leading trajectory -- "a picture is worth a thousand words" (p. 52).

# Core Definition

The spiral diagram "gives us a notion of betweenness, showing how larger voice leadings can be factored into smaller moves" (p. 52). On the 3-in-12 diagram, the two-step clockwise progression from C major to Bb "lowers each voice by major second; there are exactly three chords lying between C and Bb on the spiral, each preserving the stepwise descending voice leading" (p. 52). These are B, Eb, and G major. The geometrical structure encodes the intuition that G major lies "on the way" from C major to Bb major, "these intuitions of 'betweenness' are packed into a single percept, rather than many disconnected verbal descriptions" (p. 52).

# Prerequisites

- **Spiral Diagrams for Chord Space** -- Betweenness is a property of the geometric representation

# Key Properties

1. Chords "between" two others preserve the voice-leading trajectory when inserted
2. Betweenness is geometrical (voice-leading), not harmonic-functional
3. Multiple chords can lie between the same two endpoints
4. Loop families arise from different selections of "between" chords
5. The four angular positions function as "slots" that can be filled or left open

# Construction / Recognition

## To Identify Between Chords:
1. Locate start and end chords on the spiral
2. Identify all chords lying on the spiral path between them
3. Verify that inserting each chord preserves the voice-leading direction
4. Different selections produce different progressions in the same loop family

# Context & Application

Betweenness explains why loop families contain multiple related progressions: they select different subsets of chords from the same overall path through chord space. The "Rose Parade" progression (I-V-II-IV) is maximal, filling all four slots; eliminating one chord produces "Helpless," "Eight Days a Week," or other family members.

# Examples

**Example 1** (p. 52, Figure 2.1.6): B, Eb, and G major all lie between C and Bb on the spiral, each preserving descending voice leading.

**Example 2** (pp. 59-60, Figure 2.3.4): I-V-II-IV is maximal; eliminating II gives "Helpless"; eliminating V gives "Eight Days a Week."

# Common Errors

- **Error**: Equating betweenness with temporal ordering in a piece
  **Correction**: Betweenness is a voice-leading property; the chords may appear in any temporal order

# Common Confusions

- **Confusion**: Thinking between chords must be harmonically related
  **Clarification**: Betweenness is geometrical, not based on harmonic function
