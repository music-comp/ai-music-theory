# Quick Definition

The systematic approach to nonharmonic tones that emerged by the late baroque, incorporating new devices (seventh chords, cadential 6/4, incomplete neighbors, pedals) within rules nearly as strict as Palestrina's. Monteverdian anarchy domesticated.

# Core Definition

By the late baroque, the Monteverdian freedom of the seconda prattica had been domesticated into what Tymoczko calls the "standardized second practice" (p. 238). Eighteenth-century composers embraced seventh chords, the cadential 6/4, incomplete neighbors, and pedals, but subjected them to rules almost as inviolable as those of the first practice. J. S. Bach is astoundingly systematic: of more than ten thousand nonharmonic tones in his chorales, all but about ten are well-behaved (p. 237). This system remains in force throughout much of the eighteenth and nineteenth centuries, with few composers coming close to Monteverdi's radical freedom (p. 238).

# Key Properties

1. Incorporates seventh chords, cadential 6/4, incomplete neighbors, and pedals (p. 235)
2. Rules are almost as strict as Palestrina's
3. Bach's chorales: more than ten thousand nonharmonic tones, all but ~10 well-behaved
4. Imposes a dual constraint on analysis: dissonances must be recognized species AND harmonies must obey functional norms
5. Notes leapt-to and leapt-away-from must be harmonic (p. 239)
6. About 95% of Bach's chord progressions conform to standard functional grammar

# Construction / Recognition

## To Analyze Music in the Standardized Second Practice:
1. Identify harmonies such that all dissonances belong to recognized nonharmonic species
2. Verify harmonic successions obey functional norms
3. Check that notes both leapt-to and leapt-away-from are treated as harmonic
4. Use nonharmonic penalties to "score" competing harmonic interpretations

# Context & Application

The standardized second practice is not the same as Monteverdi's seconda prattica. Monteverdi advocated aesthetic freedom; the standardized second practice subjects new devices to equally strict rules. "Monteverdian anarchy has been domesticated" (p. 238). Computational analysis can exploit these constraints: nonharmonic penalties can be used to score harmonic interpretations, producing reasonably accurate automatic analysis (p. 239, Fig. 5.4.7).

# Examples

**Example 1** (p. 238, Fig. 5.4.6): Anomalous nonharmonic tones in Bach's chorales -- "arpeggiated anticipations" constitute the most common anomaly.

**Example 2** (p. 239, Fig. 5.4.7): A computer analysis of the opening of the first Mozart piano sonata using nonharmonic penalties, correctly identifying chords about 75% of the time.

# Common Errors

- **Error**: Equating Monteverdi's seconda prattica with the standardized second practice
  **Correction**: Monteverdi advocated aesthetic freedom from rules; the standardized second practice re-imposes strict rules on new devices

# Common Confusions

- **Confusion**: Thinking nonharmonic reduction is always analytically unproblematic in this style
  **Clarification**: The syntax allows reduction, but reduction can misrepresent the music's semantics (p. 239)
