# Quick Definition

A modulatory schema featuring a sudden, dramatic turn to a distant key, followed by a gradual return to the tonic -- typically through a series of descending fifths.

# Core Definition

Tymoczko identifies the *helicopter drop* as "a sudden and dramatic turn to a distant key, followed by a gradual return to the tonic" (p. 376). The schema takes a large leap on circular scale space followed by a series of short steps back, creating an asymmetry between departure (sudden) and return (gradual). This contrasts with the paired-sequence design, where departure and return are more equal.

# Prerequisites

- **Modulatory schemas** -- The broader category of modulatory patterns

# Key Properties

1. Sudden departure to a distant key (large leap in scale space)
2. Gradual return via descending fifths (series of short steps)
3. Asymmetric: departure is dramatic, return is gradual
4. Typically occurs in sonata-form development sections
5. The return discharges harmonic tension accumulated by the distant arrival

# Construction / Recognition

## To Identify a Helicopter Drop:
1. Look for a sudden modulatory jolt to a distant key at the start of a development or passage
2. Trace the return path: it should be gradual, usually by descending fifths
3. Contrast with paired-sequence design, where departure and return are balanced

# Context & Application

The helicopter drop is one of several modulatory schemas found in sonata-form developments. It creates maximum dramatic effect by beginning at a point of high tonal tension and gradually releasing it. The schema can be compared to a physical helicopter dropping someone in a remote location, requiring a long walk back.

# Examples

**Example 1** (p. 376, Figure 8.4.2): The first-movement development of Beethoven's *Pathetique* -- jolts from G minor to E minor (via enharmonic reinterpretation of the diminished seventh), then descends by fifths back to the tonic.

**Example 2** (p. 376): The development of Beethoven's Op. 59, no. 2, I -- moves through a circle of major-third-related minor triads (g--e-flat--b) to reach a distant B minor, then ascends by step back through a long near sequence.

# Common Errors

- **Error**: Expecting the return path to match the departure in speed and distance
  **Correction**: The asymmetry between sudden departure and gradual return is the defining characteristic

# Common Confusions

- **Confusion**: Thinking the helicopter drop is the same as any distant modulation
  **Clarification**: The schema specifically pairs a sudden distant arrival with a gradual fifth-based return
