# Quick Definition

A sustained note, initially harmonic, held through one or more chord changes, becoming nonharmonic against the changing harmony. Unique among nonharmonic tones in being irreducible -- removing a pedal requires recomposition rather than simple reduction.

# Core Definition

A pedal tone is any note that is initially harmonic and sustained through one or more chord changes (p. 237). Pedals are both a rhetorical effect and a species of nonharmonic tone. In practice, pedals almost always occur on tonic or dominant scale degrees and typically return to harmonic status before they move. They are unique in the nonharmonic bestiary in being irreducible: where other nonharmonic tones embellish specific notes, pedals do not -- removing them requires recomposition (p. 237). Many textbooks dodge this by stipulating the music embellishes the pedal, but Tymoczko argues this conflates syntactic reduction with summarizing reduction (p. 237).

# Key Properties

1. Initially harmonic, sustained through chord changes
2. Almost always on tonic or dominant scale degree
3. Typically returns to harmonic status before moving
4. Irreducible -- cannot be reduced to another note
5. Both a rhetorical effect and a species of nonharmonic tone
6. The only nonharmonic species largely limited to specific scale degrees (fn. 50)

# Construction / Recognition

## To Identify a Pedal Tone:
1. Locate a sustained bass note (or occasionally upper voice)
2. Verify it was harmonic when it first sounded
3. Check that harmonies change above (or around) it
4. Confirm it typically sits on tonic or dominant scale degree
5. Verify it returns to harmonic status before departing

# Context & Application

Pedal tones are one of the new devices embraced in the standardized second practice. Mozart's piano sonatas contain about a hundred pedals, all conforming to standard principles (tonic or dominant, returning to harmonic status). Bach's chorales contain a few exceptions (Fig. 5.4.5).

# Common Errors

- **Error**: Claiming the music "embellishes" the pedal tone
  **Correction**: This conflates syntactic nonharmonic reduction with summarizing reduction (p. 237)

# Common Confusions

- **Confusion**: Treating the formal definition too broadly (any sustained note through chord changes)
  **Clarification**: The definition is overbroad; actual pedals follow specific conventions (tonic/dominant, return to harmonic status)
