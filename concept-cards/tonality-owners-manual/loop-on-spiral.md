# Quick Definition

A full circuit around the center of the spiral diagram, corresponding to transposition along the smaller chord-like collection (t_{+-1}), moving each note by one chordal step.

# Core Definition

"A full loop around the center of the space corresponds to a transposition along the smaller chord-like collection, moving each note upward or downward by one chordal step as if the chord were a scale. A clockwise loop moves notes downward by one chordal step while a counterclockwise loop moves notes upward by one chordal step" (p. 44). This requires "jumping rings" (leaving the spiral at some point). "An n-fold loop transposes each voice by octave and is equivalent to sliding along the complete spiral" (p. 44). Paths returning to their starting point "without enclosing the center leave each voice exactly where it began" (p. 44).

# Prerequisites

- **Spiral Diagrams for Chord Space** -- Understanding the spatial framework

# Key Properties

1. Corresponds to transposition along the chord (t_{+-1})
2. Clockwise loop = downward chordal step; counterclockwise = upward
3. Double loop = two chordal steps; triple = three; etc.
4. n-fold loop = octave transposition = sliding along the complete spiral
5. Requires "jumping rings" (leaving the spiral)
6. Paths not enclosing the center leave voices unchanged

# Construction / Recognition

## To Loop:
1. Start at a point on the spiral
2. Trace a path that encircles the center of the diagram
3. This requires jumping between rings of the spiral
4. A clockwise loop produces t_{-1}; counterclockwise produces t_1
5. The sign of the chordal transposition is opposite to the scalar transposition direction

# Context & Application

Loops are central to understanding efficient voice leading between chords at different radial positions. Efficient voice leadings combine a loop with a slide in the opposite direction, so the two operations partially cancel. In rock music, repeating chord progressions trace loops through chord space; each complete loop produces a Shepard-tone passacaglia effect.

# Common Errors

- **Error**: Confusing loops enclosing the center with paths returning to start without enclosing center
  **Correction**: Only paths enclosing the center produce chordal transposition; others leave voices unchanged

# Common Confusions

- **Confusion**: Thinking a loop is simply going "around" the spiral line
  **Clarification**: A loop requires jumping between rings; it encircles the center of the diagram
