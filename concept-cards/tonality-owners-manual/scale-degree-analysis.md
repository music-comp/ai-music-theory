# Quick Definition

A "thin" and relatively theory-neutral approach to harmonic analysis in which Roman numerals refer to collections of scale degrees rather than encoding claims about chord function, behavior, or essence.

# Core Definition

Scale-degree analysis interprets Roman numerals as referring to tertian structures over a bass: "I6" means "scale degrees 1, 3, and 5 with 3 in the bass" (p. 253). It is a "thin" record of tertian sonorities, largely equivalent to figured-bass symbols (p. 254). The traditional "functional" approach uses "thick" and theory-laden labels encoding phenomenological impressions, beliefs about behavior, or claims about essence (p. 253). Tymoczko defaults to scale-degree analysis because it provides vocabulary for exploring how scale-degree configurations change function over centuries, offers shared vocabulary for discussing disagreements, and makes claims like "dominants proceed to tonics" falsifiable rather than definitional (p. 255).

# Key Properties

1. Roman numerals refer to collections of scale degrees, not functional meanings
2. "Thin" and theory-neutral; largely equivalent to figured-bass symbols
3. The relation between I and I6 is a matter for investigation, not presupposition (p. 254)
4. "Dominants proceed to tonics" becomes a testable claim (p. 255)
5. Enables tracing how scale-degree configurations change function over centuries
6. Even a computer can check whether scale degrees 5, 7, 2 proceed to 1, 3, 5

# Construction / Recognition

## To Perform Scale-Degree Analysis:
1. Identify sounding scale degrees at each harmonic change
2. Assign Roman numerals based on scale-degree content and bass note
3. Do not encode functional claims in labels
4. Treat similarity of labels as hypothesis, not presupposition

# Context & Application

The cadential six-four debate exemplifies the difference: scale-degree analysis labels it I64 (scale degrees 1, 3, 5 with 5 in bass), while functional analysis prefers V (p. 254). Tymoczko notes that functional analysis "can sometimes come dangerously close to circularity" when labels are divorced from scale-degree content (p. 255).

# Examples

**Example 1** (p. 253, Fig. P6.1): Bach's "Jesu, meine Freude" (BWV 64.8) -- a scale-degree analyst labels starred chords as mediants; a function theorist calls them dominants.

**Example 2** (p. 253, Fig. P6.1): Schumann's "Am Kamin" from Kinderszenen, analyzed as a "down by third, up by step" sequence.

# Common Errors

- **Error**: Treating scale-degree labels as necessarily implying inversional equivalence
  **Correction**: The relation between I and I6 is open to investigation (p. 254)

# Common Confusions

- **Confusion**: Thinking scale-degree analysis ignores function
  **Clarification**: It separates labeling from theorizing, using labels as neutral ground for evaluating functional claims (p. 255)
