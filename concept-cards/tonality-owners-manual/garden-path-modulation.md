# Quick Definition

A modulation where key areas are juxtaposed to create the impression of an anomalous harmonic hiccup -- a seemingly nonfunctional progression that is actually the byproduct of two overlapping functional progressions in different keys.

# Core Definition

Garden-path modulations juxtapose key areas to create the impression of an anomalous harmonic progression (p. 306). Unlike pivot-chord modulations (which present overlapping syntactical progressions in different keys), garden-path modulations do not strongly signal the start of the second key, creating a nonsyntactical progression across the key boundary (p. 307, Fig. P7.4). The term derives from "garden-path sentences" in linguistics, where apparent syntactical violations result from misconstruing ambiguous phrases (fn. 13). These create effects of modality even while conforming to functional tonal laws (p. 307).

# Key Properties

1. Key areas juxtaposed without clear signaling of the new key
2. Creates the impression of a nonfunctional progression
3. Both keys are individually syntactical; the anomaly occurs at the boundary
4. Can create effects of modality within functional harmony
5. Named by analogy with garden-path sentences in linguistics

# Construction / Recognition

## To Identify a Garden-Path Modulation:
1. Locate an apparently nonsyntactical progression
2. Check whether everything before the boundary is syntactical in one key
3. Check whether everything after is syntactical in a different key
4. If both hold, the anomaly is a garden-path modulation, not true nonfunctionality

# Context & Application

Nineteenth-century composers used garden-path modulations to create impressions of modality even while conforming to functional laws (p. 307). This is analogous to using nonharmonic tones to extend harmonic vocabulary -- maintaining deniability while creating nonfunctional effects.

# Examples

**Example 1** (p. 307, Fig. P7.5): Bach's "In allen meinen Taten" (BWV 13.6, mm. 3-4) -- a V-iii progression that sounds modal but results from juxtaposed keys.

**Example 2** (p. 307, Fig. P7.5): Grieg's "Gade" (Op. 57, no. 2, mm. 99-103) -- an unmistakably mixolydian cadence that is "immediately and retrospectively demystified."

# Common Errors

- **Error**: Labeling apparently "modal" progressions in Bach as genuinely nonfunctional
  **Correction**: Many occur across key boundaries and are actually garden-path modulations (fn. 14)

# Common Confusions

- **Confusion**: Thinking garden-path modulations are compositional errors
  **Clarification**: They are deliberate compositional devices creating specific effects
