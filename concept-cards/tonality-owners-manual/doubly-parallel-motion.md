# Quick Definition

Motion in which voices move along both chord and scale simultaneously, combining transposition along two hierarchically nested collections to produce a series of harmonies sharing the same intervals in the same abstract registral configuration.

# Core Definition

Doubly parallel motion combines "transposition along the chord" (t_x) and "transposition along the scale" (T_y), which "combine to form a kind of doubly parallel motion along a pair of hierarchically nested collections" (p. 41). Together, "the two operations generate a wide range of harmonies from a single starting point, all broadly similar in arranging the same intervals in the same abstract registral configuration; indeed these two transpositions are the only operations that preserve both chord type and distance in chordal steps" (p. 42). The operations commute, subscripts add, and inversion along both chord and scale (i_x I_y) is also possible.

# Key Properties

1. Combines chordal transposition t_x with scalar transposition T_y
2. Preserves both chord type and chordal-step distance
3. The operations commute: t_x T_y = T_y t_x
4. For an n-note chord in an o-note scale, t_n = T_o
5. Inversion along both levels (i_x I_y) is also possible
6. Produces harmonies sharing the same abstract registral configuration

# Construction / Recognition

## To Identify Doubly Parallel Motion:
1. Check if inner voices maintain the same chordal-step spacing throughout
2. Verify that the chord type remains constant
3. Express the transformation as t_x T_y
4. Note that when measured in chordal steps, voices move in parallel; in diatonic or chromatic steps, they may diverge

# Context & Application

In rock harmony (Ch. 2), inner voices are modeled as moving in doubly parallel motion with the melody using the same t_x **T**_y, while the bass uses a different chordal transposition. This simplification avoids the hierarchical picture of a 1-in-3 diagram nested within a 3-in-12 diagram.

# Examples

**Example 1** (p. 38, Figure P2.3): Scarlatti K.3 -- right hand moves t_1 while left hand moves T_2, producing very similar results since t_{-1} T_2 "does very little."

**Example 2** (p. 53, Figure 2.1.8): In Ch. 2's model, inner voices move in doubly parallel motion with melody while the bass moves independently.

**Example 3** (p. 60): "Knockin' on Heaven's Door" -- background voices shadow melody at two chordal steps, producing scalar intervals of sixth or fifth depending on the chord.

# Common Errors

- **Error**: Confusing doubly parallel motion with simple parallel motion
  **Correction**: Simple parallel motion uses one transposition; doubly parallel uses two at different hierarchical levels

# Common Confusions

- **Confusion**: Thinking voices always move by the same intervals in doubly parallel motion
  **Clarification**: They move by the same chordal-step intervals, but this translates to different chromatic or diatonic intervals
