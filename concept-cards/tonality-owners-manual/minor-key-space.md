# Quick Definition

A model of key space that reconciles circular voice-leading logic with the insight that both parallel and relative keys are closely related, by representing minor keys as spatially extended objects that provide shortcuts between otherwise-distant major keys.

# Core Definition

Since both parallel and relative major/minor relationships are important, Tymoczko favors a model that represents them simultaneously. Building on Vial's eighteenth-century graph (Figure 8.3.1), he develops a circular model (Figure 8.3.3) that superimposes spaces for diatonic, acoustic (melodic-minor ascending), and harmonic-minor scales. Minor keys are represented as spatially extended objects spanning multiple positions on the circle, because "changes between minor scale-forms [do] not count as modulations even though they move through scale space" (p. 373). This nonlocality allows A minor to be close to C major (relative), G major, D major, and A major (parallel) simultaneously.

# Key Properties

1. Minor keys are spatially extended, spanning multiple positions on the circular model
2. This extension provides shortcuts between otherwise-distant major keys
3. The model reconciles both parallel and relative proximity
4. Enharmonicism requires chromaticism: no obvious sharpward path from iii to IV within diatonic keys (p. 374)
5. Diatonic modulations tend to cancel out; chromaticism is needed for complete circuits
6. The model can be augmented with information about the global tonic (Figure 8.3.4)

# Construction / Recognition

## To Use the Model:
1. Locate the major keys on the circle of fifths
2. Represent each minor key as an extended region spanning its diatonic, harmonic-minor, and melodic-minor forms
3. Parallel and relative relationships are both short-distance paths
4. Check modulatory sequences against the model to see if they involve loops
5. Use darkened colors to indicate keys whose tonics belong to a given diatonic collection (Figure 8.3.4)

# Context & Application

The model explains why the modulatory pathway I--V--ii (e.g., G--D--a) is one of the most important in functional tonality: D major and A minor are close in this space even though they seem distant in simpler models. The model also shows that "enharmonicism requires chromaticism" (p. 374): purely diatonic modulations are bounded and tend to cancel out; it is only when key areas are "conceived chromatically, allowing for sharpward motion from mediant to subdominant, that enharmonicism becomes commonplace" (p. 374).

# Common Errors

- **Error**: Using Vial's flat graph without recognizing its inability to represent enharmonic loops
  **Correction**: The circular model preserves the geometry of enharmonic equivalence that Vial's graph obscures (Figure 8.3.2)

# Common Confusions

- **Confusion**: Thinking minor keys are "points" on the circle like major keys
  **Clarification**: Minor keys are spatially *extended* because their multiple scale forms occupy different positions
