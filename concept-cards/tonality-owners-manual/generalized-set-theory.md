# Quick Definition
A theoretical framework using spiral diagrams to reveal structural analogies between different chord-and-scale domains, showing how the same abstract patterns of voice leading and internal structure recur at different levels of the musical hierarchy.

# Formal Definition
When a spiral diagram has one chord at each angular position (n-note chord in o-note scale, with n not dividing o and the two sharing no common factor), the most-even n-note chord is a near interval-cycle with one interval slightly different from the others. A "generalized circle of fifths" is formed by shifting the position of this unusual interval. Nearly even chords can be generated by scrambling the voice leadings on this generalized circle (Figure 8.7.8). The result is a system of analogies: the diatonic scale in chromatic space is structurally analogous to the seventh chord in diatonic space; the acoustic (melodic minor) scale is analogous to the stack-of-fourths tetrachord; harmonic major/minor are analogous to further diatonic tetrachords (Figure 8.7.9). All analogous objects share both internal structure (gapped interval stacks) and contrapuntal relationships (single-step voice leadings).

# Musical Context
This framework extends the seven common twentieth-century scales (diatonic, acoustic, harmonic minor, harmonic major, octatonic, whole-tone, hexatonic -- Figure 8.7.2) to arbitrary chord-in-scale domains. It provides a practical tool for composers exploring unfamiliar collections, adapting functional-era techniques to new harmonic realms via the "Prime Directive" (using spiral diagrams to chart interesting paths through musical possibility).

# Common Confusions
- This is not the same as Forte's atonal set theory: Tymoczko's generalized set theory goes beyond taxonomy to illuminate abstract voice-leading structures that recur across domains.
- The system of analogies is mathematical, not necessarily perceptual: hearing these analogies requires training and familiarity with the relevant collections.
