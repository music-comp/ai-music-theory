# Quick Definition

A theoretical framework using spiral diagrams to reveal structural analogies between different chord-and-scale domains, showing how the same abstract patterns of voice leading and internal structure recur across different levels of the musical hierarchy.

# Core Definition

When a spiral diagram has one chord at each angular position (n-note chord in o-note scale, with n not dividing o and sharing no common factor), the most-even chord is a near interval-cycle. A "generalized circle of fifths" is formed by shifting the unusual interval's position (p. 398). Nearly even chords can be generated by "scrambling" the basic voice leading on this generalized circle (Figure 8.7.8). The result is "a remarkable system of analogies linking different chord-in-scale domains" (p. 399): the diatonic scale in chromatic space is structurally analogous to the seventh chord in diatonic space; the acoustic (melodic-minor) scale is analogous to the stack-of-fourths tetrachord; all analogous objects share both internal structure and contrapuntal relationships (Figure 8.7.9).

These relationships "hint at a music theory that has yet to be written, a generalized set theory going beyond taxonomy to illuminate abstract structures reappearing across different chord-and-scale domains" (p. 401).

# Key Properties

1. Most-even chords in any scale are near interval-cycles (one interval differs from the others by one scale step)
2. A generalized circle of fifths connects these chords by shifting the unusual interval
3. Nearly even chords are generated by scrambling voice leadings on this circle
4. Analogous objects share both internal (harmonic) structure and external (contrapuntal) relationships
5. The seven common twentieth-century scales (diatonic, acoustic, harmonic minor/major, octatonic, whole-tone, hexatonic) emerge as the most-even and symmetrical collections (Figure 8.7.2)
6. These scales can be integrated with functional harmony via chord-scale compatibility (Figure 8.7.6)

# Construction / Recognition

## To Find Analogous Structures:
1. Identify the chord-in-scale domain (e.g., 3-in-7, 7-in-12, 4-in-7)
2. Find the most-even chord (near interval cycle)
3. Construct the generalized circle of fifths by shifting the unusual interval
4. Generate less-even chords by scrambling the basic voice leading (applying it too early or too late)
5. Compare the resulting structures across different domains for analogies

# Context & Application

The framework extends traditional diatonic theory to arbitrary collections. Grieg's *Elegie* (Op. 47, no. 7) treats harmonic minor as an object in its own right, creating a pun between chromatic and harmonic-minor hearings (Figure 8.7.1). Tymoczko's own *Wheels within Wheels* uses a triply nested sequence with three basic voice leadings simultaneously (Figure 8.7.7). Inspired by the Prime Directive, composers can "adapt their techniques to arbitrary collections, using the spiral diagrams to chart interesting paths through a new world of musical possibility" (p. 401).

# Common Errors

- **Error**: Conflating this with Forte's atonal set theory
  **Correction**: Tymoczko's generalized set theory emphasizes voice-leading relationships and cross-domain analogies, not just taxonomic classification

# Common Confusions

- **Confusion**: Thinking the analogies are merely mathematical curiosities
  **Clarification**: They have practical compositional significance -- the same techniques that work for triads in diatonic scales can be adapted to arbitrary collections
