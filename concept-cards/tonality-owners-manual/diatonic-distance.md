# Quick Definition

Harmonic distance between two major triads defined as the minimum number of semitonal voice-leading shifts needed to transform a diatonic scale containing one chord into a scale containing the other -- a voice-leading distance at the scalar level.

# Core Definition

"I will define the harmonic distance between two major triads as the smallest distance from a scale containing one chord to a scale containing the other" (p. 54). Distance between scales is measured on the circle of fifths, where each step represents one semitonal shift (e.g., F to F# transforms C diatonic to G diatonic). This is "very closely related to the circle-of-fifths distance between triads, here justified by the fact that fifth-related triads create coherent diatonic backgrounds or macroharmonies" (p. 55). "It is, in other words, a voice-leading distance at another hierarchical level" (p. 55).

# Prerequisites

- **Voice Leading** -- Diatonic distance is a voice-leading distance at the scalar level

# Key Properties

1. Distance 0: C-F, C-G, C-D, C-Bb (all share a diatonic scale)
2. Distance 1: C-Eb, C-A
3. Distance 2: C-E, C-Ab (major-third related)
4. Distance 3: C-Db, C-B (semitonally related)
5. Distance 4: C-F# (tritone related, maximum)
6. Rock musicians implicitly favor diatonically close progressions
7. This norm is weak and implicit, not absolute

# Construction / Recognition

## To Calculate Diatonic Distance:
1. Find the closest diatonic scale containing chord A
2. Find the closest diatonic scale containing chord B
3. Count the minimum circle-of-fifths steps between those scales
4. For a complete progression, measure the total distance including the return to the initial chord and scale

# Context & Application

Tymoczko proposes that "rock musicians favor chord progressions that are diatonically close" (p. 55), a weak norm absorbed implicitly through exposure to Western music. Combined with the melodic principle, diatonic distance predicts the observed distribution of rock root progressions: more fifth-related triads and major-second-related triads, fewer semitonally or tritone-related triads.

# Common Errors

- **Error**: Equating diatonic distance with interval size
  **Correction**: C to D (M2) has distance 0, same as C to F (P5), because both share a diatonic collection

# Common Confusions

- **Confusion**: Thinking diatonic distance is the same as common-tone counting
  **Clarification**: It is "similar to, but not quite the same as, a model based on common tones" (p. 55); it is based on voice-leading shifts between scales
