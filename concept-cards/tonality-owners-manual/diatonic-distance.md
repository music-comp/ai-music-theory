# Quick Definition
A measure of harmonic distance between chords based on the minimum number of semitonal shifts needed to transform a diatonic scale containing one chord into a scale containing the other.

# Formal Definition
Diatonic distance between two major triads is the smallest distance from a scale containing one chord to a scale containing the other, where distance between scales is measured on the circle of fifths (each step corresponding to one semitonal voice-leading shift). Thus C and G major triads have diatonic distance 0 (both in C diatonic), C and Eb major have distance 1 (C is in F diatonic, Eb in Bb diatonic, and these scales are one step apart), C and E major have distance 2, semitonally related triads are distance 3, and tritone-related triads are maximally distant at 4 steps.

# Musical Context
Tymoczko proposes that rock musicians favor chord progressions that are diatonically close -- lying in a single diatonic scale or a small collection of closely related scales. This is a weak norm learned implicitly through extensive exposure to Western music. The suggestion is that rock musicians have absorbed a diatonic preference without formal instruction. Because the norm is implicit and not absolute, we expect progressions between non-diatonic triads too, with frequency decreasing as diatonic distance increases.

# Examples
- C and F major: distance 0 (both in C diatonic)
- C and D major: distance 0 (both in G diatonic)
- C and Bb major: distance 0 (both in F diatonic)
- C and Eb major: distance 1
- C and E/Ab major: distance 2
- C and Db/B major: distance 3
- C and F# major: distance 4 (maximum)
- Rolling Stone corpus confirms: fifths most common, then M2, m3, M3, m2, with tritones absent (Figure 2.2.4)

# Common Confusions
- Diatonic distance is not the same as interval size -- C to D (M2) has the same diatonic distance (0) as C to F (P5)
- This is a *voice-leading* distance at the scalar level, similar to but not quite the same as a common-tone model
- The total diatonic distance of a progression is measured for the complete cycle returning to the initial chord and scale (Figure 2.2.3)
