# Quick Definition

The spiral diagram for two-note chords (dyads) in diatonic space, where imperfect consonances are arranged with seven equally spaced points and neighboring points connected by the basic voice leading. It can be collapsed into a circle since each angular position contains exactly one chord.

# Core Definition

The 2-in-7 spiral diagram represents all diatonic dyads (Figure 3.1.1, p. 97). Since the chord has two notes, the line of transposition winds twice around the circle; since the diatonic scale has seven notes, there are seven equally spaced points. Sliding along the spiral transposes along the scale; looping around transposes along the chord, turning thirds into sixths and vice versa. Because there is exactly one chord at every angular coordinate, radial motion is completely determined by angular motion, allowing the spiral to be collapsed into a circle (p. 98). The compressed version (Figure 3.3.9, p. 112) represents each angular segment as a basic voice leading, switching between the interval's two inversions.

# Key Properties

1. Two loops for a two-note chord; seven points for the seven-note diatonic scale
2. Each point represents a complete two-note chord (not a single note)
3. Adjacent points are connected by the basic voice leading
4. Fifth-related dyads are literally adjacent, privileging fifth motion
5. Can be collapsed to a circle since angular position uniquely determines the chord
6. The same graph represents any two-note interval in any seven-note scale

# Construction / Recognition

## To Construct:
1. Draw a spiral winding twice around a central point
2. Place seven equally spaced points along the spiral
3. Label consecutively with scale tones (C, D, E, F, G, A, B)
4. Each point represents a dyad (the labeled note plus a note a third/sixth away)
5. Optionally add curved arrows for voice exchanges (two-step and five-step)

## To Identify Paths:
1. Count clockwise steps for the number of basic voice leadings applied
2. Odd steps transpose along the chord (third becomes sixth)
3. Even steps preserve the interval type

# Context & Application

The dyadic circle is the foundation for understanding two-voice counterpoint geometrically. It generates common galant schemas: the converging cadence takes a single clockwise step; the Fonte (descending fifths) makes a series of clockwise moves; the Monte alternates clockwise steps with three-step counterclockwise moves; the Quiescenza alternates rightward and leftward steps. These examples suggest that "the basic idioms of functional composition are not so much arbitrary conventions as responses to the basic affordances of musical space" (p. 103).

# Common Errors

- **Error**: Reading points as single notes rather than complete chords
  **Correction**: Each point represents a complete two-note chord (e.g., both C and E)

# Common Confusions

- **Confusion**: Conflating the dyadic circle of fifths with the acoustic circle of fifths
  **Clarification**: These are three independent phenomena that converge on the importance of the fifth: the dyadic circle, the acoustic circle, and the circle connecting diatonic scales (p. 99)

- **Confusion**: Thinking the diagram only works for thirds and sixths
  **Clarification**: The same graph represents any two-note interval in any seven-note scale by relabeling the note names
