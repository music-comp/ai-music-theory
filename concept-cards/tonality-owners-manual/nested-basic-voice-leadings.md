# Quick Definition

Two or more basic voice leadings operating simultaneously at different structural levels -- for example, a triadic basic voice leading operating within a diatonic scale whose own basic voice leading is simultaneously active.

# Core Definition

In Beethoven's Ninth Symphony scherzo passage (mm. 143-176), the chordal basic voice leading moves each triad's fifth up by scale step to become the root of the next triad (clockwise on the triadic spiral), while the scalar basic voice leading lowers the leading tone semitonally to connect fifth-related scales (counterclockwise on the scalar spiral). These are "hierarchically self-similar transformations occurring on two different structural levels" (p. 359, Fig. P8.3). The notation combines diatonic transposition T with chromatic transposition **T**: the scalar voice leading **T**_{-7}t_4 lowers the leading tone by semitone while keeping every other note fixed. The passage takes eighteen counterclockwise steps along the triadic spiral and eight clockwise steps along the spiral of diatonic scales.

# Key Properties

1. Chordal basic voice leading: fifth ascends by scale step to become the next root (clockwise on triadic spiral)
2. Scalar basic voice leading: leading tone lowered by semitone (counterclockwise on scalar spiral)
3. Both are basic voice leadings -- single angular steps on their respective spiral diagrams
4. The scalar voice leading **T**_{-7}t_4 (or **T**_5t_{-3}) shifts one note by semitone while keeping all others fixed
5. Beethoven's passage: 18 counterclockwise triadic steps, 8 clockwise scalar steps
6. These are the general mechanism underlying modulatory sequences that generate repeating Roman numeral patterns

# Construction / Recognition

## To Identify Nested Basic Voice Leadings:
1. Look for a repeating chordal pattern (e.g., descending thirds by ascending diatonic step)
2. Check whether the underlying scale is simultaneously moving by its own basic voice leading
3. Use spiral diagrams to visualize both levels: one for chords within scales, one for scales within chromatic space
4. Verify that each level takes a single angular step on its respective spiral

# Context & Application

This concept contrasts with the neo-Riemannian analysis of the same Beethoven passage (Cohn 1997), which models it with two nonhierarchical transformations (R and L) in alternation, operating directly on chromatic triads without mediation by the diatonic collection. Tymoczko's advantages: (1) it describes the sequence using standard harmonic procedures, (2) it offers a unified explanation of the voice leadings (each triad's fifth moves up by scale step), and (3) it generalizes easily to any chord in any scale. The neo-Riemannian advantage: it connects Beethoven's procedures to nineteenth-century chromaticism. "The two analyses thus highlight Beethoven's position at the fulcrum between classical and Romantic eras" (p. 360). Nested basic voice leadings are not restricted to this passage -- they are the general mechanism underlying modulatory sequences.

# Examples

# Common Errors

- **Error**: Thinking nested basic voice leadings only occur in the Beethoven Ninth passage
  **Correction**: They are the general mechanism underlying modulatory sequences that generate repeating patterns of Roman numerals -- essential for any modulatory sequence to produce the same progression in each new key

# Common Confusions

- **Confusion**: Thinking one analysis (hierarchical vs. neo-Riemannian) must be correct and the other wrong
  **Clarification**: "Neither of these is correct as a matter of simple fact" (p. 360) -- they highlight different aspects of the music and have different explanatory advantages
