# Quick Definition

The book's culminating synthesis: the collectional (quadruple) hierarchy as a point of contact between schema theory, scale theory, voice-leading geometry, neo-Riemannian theory, and Schenkerian analysis -- a unified framework showing how different styles exploit the same fundamental geometrical substrate.

# Core Definition

The collectional hierarchy is the organizational strategy of "surface voices moving inside chords that move inside scales that are themselves moving inside the aggregate" (p. 527). The spiral diagrams provide "an elegant tool for visualizing this structure, a unified set of geometrical models revealing the interdependence of harmony and counterpoint: wheels within wheels, each turning independently of the others" (p. 527). Styles are characterized by different "settings of this complex machine": Renaissance polyphony, rock, Bach preludes, Romantic subjectivity, impressionism, jazz, and minimalism all arise from different configurations of the same basic ingredients (p. 527).

1. Surface voices move inside chords inside scales inside the aggregate

4. Neo-Riemannian transformations arise from combining hierarchical inversions

6. Musical knowledge is often implicit: culture preserves geometrical discoveries as idioms

# Construction / Recognition

## To Apply the Synthesis:
1. Identify the relevant hierarchical levels (subchord, chord, scale, chromatic)
2. Use spiral diagrams to represent voice-leading possibilities at each level
3. Analyze how surface voices move relative to these nested collections
4. Recognize schemas as specific exploitations of the geometrical substrate
5. Compare how different styles configure the same basic machine

# Context & Application

The Conclusion traces schemas to geometry: dyadic space for the Quiescenza, Fonte, and Monte; triadic space for the Prinner and Romanesca; canonic fourth-progression for the Fenaroli; sentential logic for the Meyer, Do-Re-Mi, and Sol-Fa-Me (p. 528). It shows how Bebop extends the diatonic fifth-sequence by chromaticizing voice leading, making Charlie Parker's "Blues for Alice" "an ancient musical logic, part of a dialogue beginning before Ockeghem" (p. 529). Compositionally, the approach lets us "extend the core techniques of earlier music" to new creative practice (p. 530-531).

# Examples

**Example 1** (p. 528): Nine Gjerdingen schemas traced to geometrical origins in specific spiral-diagram spaces.

**Example 2** (pp. 528-529): Charlie Parker's "Blues for Alice" -- three turns through the 2-in-12 chromatic diagram with upper-voice fifths sliding downward, connecting Bebop to pre-Ockeghem voice-leading logic.

**Example 3** (pp. 531-532): A new composition using contrary-motion technique inspired by the Waldstein -- a four-voice canon generating scale degrees along which melodies ascend, creating "simple and algorithmic but also charming" process music.

# Common Errors

- **Error**: Treating the synthesis as claiming all music works the same way
  **Correction**: Different styles use different "settings" of the same machine; the claim is about shared geometric substrate, not identical usage

- **Error**: Assuming conscious geometric awareness is required
  **Correction**: "There are few if any musicians today who can... fluently manipulate the resulting possibilities" (p. 528); the knowledge is usually implicit

# Common Confusions

- **Confusion**: Thinking the synthesis privileges one theoretical tradition over others
  **Clarification**: It shows how schema theory, scale theory, voice-leading geometry, neo-Riemannian theory, and Schenkerian analysis illuminate different aspects of the same structure

- **Confusion**: Believing the collectional hierarchy is only relevant to Western tonal music
  **Clarification**: "Around the world we can hear musicians deploying an organizational strategy whose origins date to the early Renaissance" (p. 527)
