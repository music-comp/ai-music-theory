# Quick Definition

A harmonically stable sequence has transposition arrows differing only by octave, producing transpositionally related blocks. A harmonically unstable (wedge) sequence has different transpositions for different voices, creating contrary-motion patterns through unrelated vertical states.

# Core Definition

Harmonically stable sequences are "structure-preserving in a very general way, producing transpositionally related blocks regardless of their cells' content" (p. 158). All transpositions differ only by octave. Harmonically unstable sequences "create contrary-motion 'wedge' patterns that move through unrelated vertical states" (p. 158). Their grand periods typically contain multiple simple periods. In earlier music, unstable sequences often "exploit unique features of the sequential unit to create a consonant result," typically involving "the sort of invertible counterpoint found in Figure 4.1.5" (p. 159). For repeating contrapuntal patterns, harmonic stability means connecting transpositionally related chords and linking melodic intervals to specific chordal elements (p. 161).

# Key Properties

1. Stable: all transpositions differ only by octave
2. Unstable: different transpositions create wedge patterns
3. Unstable sequences' grand periods contain multiple simple periods
4. Unstable sequences in tonal music exploit invertible counterpoint for consonance
5. For repeating patterns: stable = connected to a spiral diagram motion
6. Independent dimension from registral stability/instability

# Construction / Recognition

## To Identify:
1. Check transpositional labels on all arrows
2. If all differ only by octave: harmonically stable
3. If different: harmonically unstable (wedge)
4. For unstable: check for invertible counterpoint ensuring consonance

# Context & Application

Schoenberg's "Angst und Hoffen" (Op. 15 no. 7) contains a wedge sequence (Figure 4.1.4). Bach's WTC second E minor prelude features invertible counterpoint at the twelfth (Figure 4.1.5). As music evolves from Renaissance to twentieth century, contrary-motion wedge sequences become increasingly important for harmonic expansion.

# Common Errors

- **Error**: Assuming harmonically stable means the harmony doesn't change
  **Correction**: It means successive blocks are transpositionally related, preserving harmonic quality

# Common Confusions

- **Confusion**: Conflating harmonic stability with registral stability
  **Clarification**: These are independent dimensions; a sequence can be harmonically stable but registrally unstable or vice versa
