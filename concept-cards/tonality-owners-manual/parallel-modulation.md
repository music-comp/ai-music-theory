# Quick Definition
A modulation between keys sharing the same tonic but differing in mode (e.g., C major to C minor), which preserves scale-degree roles while changing some pitch classes.

# Formal Definition
The parallel relationship connects keys with the same tonic but different modes (e.g., C major and C minor, or C ionian and C mixolydian). In the scale-degree-preserving model of key distance, parallel keys are among the closest possible neighbors because most scale degrees remain in place while a few shift by semitone. On the spiral diagram, the parallel modulation is a *slide* combined with potential mode changes. Parallel and relative relationships are both important in functional tonality: the eighteenth-century theorist Vial proposed a grid structure (Figure 8.3.1) that models both, with one diagonal axis representing fifth-related motion and the other alternating between parallel and relative modulations.

# Musical Context
The parallel modulation is fundamental to minor-key tonality, where the three scale forms (natural, harmonic, melodic minor) can be understood as different positions within scale space relative to the parallel major. Minor keys' "spatial extension" in the key-space model (Figure 8.3.3) reflects the syntactic equivalence of these scale forms.

# Common Confusions
- Parallel modulation is not the same as relative modulation: parallel keys share a tonic (C major/C minor) while relative keys share a key signature (C major/A minor).
- Changes between minor-scale forms (natural, harmonic, melodic) are not usually counted as modulations, even though they involve genuine motion through scale space.
