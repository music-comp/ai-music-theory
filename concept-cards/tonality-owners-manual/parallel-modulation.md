# Quick Definition

A modulation between keys sharing the same tonic but differing in mode (e.g., C major to C minor), which preserves scale-degree roles while changing some pitch classes -- one of the two closest key relationships in the scale-degree-preserving model of key distance.

# Core Definition

The parallel relationship connects keys with the same tonic but different modes (e.g., C major and C minor). In the scale-degree-preserving model of key distance, parallel keys are among the closest possible neighbors because most scale degrees remain in place while a few shift by semitone (p. 362, Fig. 8.1.1). On the spiral diagram, the parallel modulation is represented as a slide combined with potential mode changes (p. 363, Fig. 8.1.4). Minor keys' "spatial extension" in key-space models (Fig. 8.3.3) reflects the syntactic equivalence of the three minor scale forms (natural, harmonic, melodic), with changes between them not counting as modulations even though they involve genuine motion through scale space (p. 373). This nonlocality arises from convention rather than deep features of musical geometry.

# Key Properties

1. Parallel keys share the same tonic but differ in mode (e.g., C major / C minor)
2. Close in scale-degree-preserving distance (most scale degrees stay fixed)
3. Relatively distant in pitch-class-changing distance (tonics are the same but collections differ)
4. Minor keys are spatially extended in key-space models due to three scale forms
5. Changes between minor scale forms are not counted as modulations despite involving motion in scale space
6. The parallel relationship combines with the relative relationship to model both types of major-minor proximity

# Construction / Recognition

## To Identify Parallel Modulation:
1. Check that both keys share the same tonic pitch class
2. Verify that the mode changes (major to minor or vice versa)
3. Note which scale degrees shift by semitone (typically 3, 6, and/or 7)
4. In minor keys, distinguish between changes of scale form (not modulation) and genuine parallel modulation

# Context & Application

The parallel modulation is fundamental to minor-key tonality, where the three scale forms can be understood as different positions within scale space relative to the parallel major. The eighteenth-century theorist F. G. Vial proposed a grid structure (Fig. 8.3.1) that models both parallel and relative relationships, with one diagonal axis representing fifth-related motion and the other alternating between parallel and relative modulations. However, Vial's graph obscures the circular geometry of enharmonic equivalence. Tymoczko favors a model (Fig. 8.3.3) that reconciles circular voice-leading logic with the insight that parallel and relative keys are both closely related, showing minor keys as spatially extended and thus close to multiple major keys simultaneously.

# Common Errors

- **Error**: Confusing parallel with relative modulation
  **Correction**: Parallel keys share a tonic (C major / C minor); relative keys share a key signature (C major / A minor)

# Common Confusions

- **Confusion**: Treating changes between minor-scale forms as modulations
  **Clarification**: Changes between natural, harmonic, and melodic minor are not usually counted as modulations, even though they involve genuine motion through scale space -- this is a syntactic convention (p. 373)
