# Quick Definition

The zone of second-order idioms and practices surrounding the first-order defaults of the harmonic grammar, some features of which remain fixed throughout the functional tradition while others evolve historically.

# Core Definition

Tymoczko conceives the descending-thirds model "not as a set of universal laws but as first-order defaults surrounded by a penumbra of second-order idioms and practices" (p. 314). Some penumbral features remain fixed throughout the functional tradition: mediants act as post-tonic chords moving to vi or IV, as alternative dominants, and as tonic substitutes (Figure 7.1.6). Similarly, V--vii^ø7^ supports melodic 7--6--5 against bass 5--4--3. Other penumbral features evolve historically: harmonic practice congeals during the eighteenth century (decreasing vi--V and nonsequential iii), then expands in the nineteenth (increasing ct^o7^ and ii^ø7^, recovery of iii).

# Key Properties

1. Distinguishes first-order defaults from second-order conventional idioms
2. Some penumbral features are fixed across all periods (e.g., mediant flexibility)
3. Other penumbral features evolve historically (e.g., decline and recovery of iii)
4. The penumbra explains why functional tonality accommodates historical variation while maintaining a stable core grammar
5. The hourglass metaphor captures the penumbra's historical evolution: widest in early and late practice, narrowest in the classical era

# Construction / Recognition

## To Identify Penumbral Progressions:
1. Check whether the progression conforms to the descending-thirds model (first-order)
2. If not, check whether it matches a known second-order idiom (e.g., iii as post-tonic, ct^o7^)
3. Consider the historical period: earlier and later styles have wider penumbras
4. Note whether the penumbral feature is fixed (present in all periods) or evolving (period-specific)

# Context & Application

The concept of the penumbra is crucial for understanding why functional harmony is not a rigid system. Different periods and composers exhibit different penumbral features while sharing the same core grammar. The classical era (Haydn, Mozart, Beethoven) represents maximal harmonic regimentation -- the narrowest penumbra. The evolution is captured by Figure 7.1.7.

# Common Errors

- **Error**: Dismissing penumbral progressions as "wrong" or "rule-breaking"
  **Correction**: They are conventional second-order defaults that complement the first-order grammar

# Common Confusions

- **Confusion**: Assuming all penumbral features are period-specific
  **Clarification**: Some (like the mediant's flexibility) persist across all periods; others are historically contingent
