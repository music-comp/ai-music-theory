# Quick Definition

A continuously descending canonic line embedded in the ubiquitous four-chord rock sequence D-A-E-G -- a "deep schema, rarely grasped explicitly but existing in the musical unconscious -- and manifesting in many seemingly unrelated ways" (p. 68).

# Core Definition

Since all four maximal loop families are rotations of D-A-E-G with different tonics, and each complete loop transposes voices down by one chordal step, the same underlying canon appears in "Helpless," "Natural Woman," "The Air Near My Fingers," and countless other songs. Three songs in three keys can be "played at the same time without dissonance" (p. 67), creating "a strange sort of polytonality without dissonance, the different keys largely a function of where one feels the four-bar hypermetric accent" (p. 67).

# Prerequisites

- **Shepard-Tone Passacaglias** -- The canon arises from the passacaglia structure
- **Loop Families in Rock** -- All families share this canon

# Key Properties

1. All four loop families are rotations of the same D-A-E-G sequence
2. The canon is a deep schema, not consciously recognized
3. Three songs in three keys can be superimposed without dissonance
4. Scale degree becomes "a function of attention" (duck/rabbit illusion analogy)
5. Described "only half-jokingly" -- it is a theoretical construct
6. Voices enter every two measures in the canonic representation

# Construction / Recognition

## To Hear the Canon:
1. Take any four-chord rock loop (e.g., D-A-E-G)
2. Trace the descending stepwise line through the progression
3. Note how the line continues across the repeat boundary
4. Sing the canonic line along with the recording -- "you will realize how obvious it is" (p. 65)

# Context & Application

The canon reveals rock centricity as "often a matter of phrasing and musical emphasis rather than abstract pitch relationships" (p. 68). O-Zone's "Dragostea Din Tei" modulates between C major and A minor without departing from its repeating loop, using only hypermetric and orchestrational cues (p. 68).

# Common Errors

- **Error**: Taking the "fundamental canon" as a literal claim about all rock music
  **Correction**: It is described "only half-jokingly" as a theoretical construct revealing deep structure

# Common Confusions

- **Confusion**: Thinking composers consciously intend the canon
  **Clarification**: It is implicit, existing "in the musical unconscious"
