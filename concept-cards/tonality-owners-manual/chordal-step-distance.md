# Quick Definition
Distance measured in steps along a chord's intrinsic scale rather than in semitones or diatonic steps, relevant whenever composers are concerned with efficient voice leading.

# Formal Definition
Chordal-step distance measures intervals using the notes of a chord as the unit of measurement, treating the chord as a small scale. When two chords are voiced with the same spacing in chordal steps, the most efficient voice leading between them will always connect them directly. This is because transposition along the chord and transposition along the enclosing scale are the *only* operations that preserve both chord type and distance in chordal steps. For an n-note chord, there are n fundamentally distinct voicings (spacing patterns), and the efficient voice leading between two chords depends on which voicing is used.

# Musical Context
Chordal-step distance is relevant whenever composers seek smooth voice leading -- which is much of the time. Composers might use transposition along the chord unknowingly, as a byproduct of trying to minimize contrapuntal motion. In motivic contexts, composers intentionally move objects along the chord; in contrapuntal contexts, the same transformations arise implicitly. The concept is familiar in guitar pedagogy, where it is used to construct inversions that keep the left hand in roughly the same position.

# Common Confusions
- Chordal-step distance is not the same as semitone distance or diatonic-step distance -- it uses the chord itself as the ruler
- Two chords with the same spacing in chordal steps are not necessarily in the same register -- they share an abstract voicing pattern
- The concept applies to any chord size, from dyads to seven-note scales
