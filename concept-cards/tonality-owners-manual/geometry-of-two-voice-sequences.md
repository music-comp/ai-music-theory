# Quick Definition

The complete classification of two-voice harmonically consistent sequences using the dyadic spiral: without voice exchanges, odd steps = canonic, even = transpositional; with voice exchanges, the relationship reverses. This exhausts all harmonically consistent two-voice possibilities.

# Core Definition

"The isomorphism between sequence and voice leading allows us to use the spiral diagrams to explore the geometry of sequential possibility" (p. 165). For two-voice harmonically consistent repeating contrapuntal patterns: without voice exchanges, odd steps = canonic or transpositional depending on parity; with voice exchanges, the relationship reverses (Figure 4.3.1, p. 165). The spiral diagrams prove that transpositional, canonic, and contrary-motion "are the only harmonically consistent two-voice possibilities" (p. 165). Geometry also justifies including permutation as a sequence-generating operation, since "any harmonically stable voice leading generates a sequence, and some of these permute their voices" (p. 165).

# Key Properties

1. Complete classification of all two-voice possibilities
2. Without exchanges: odd steps = canonic, even = transpositional
3. With odd exchanges: even steps = canonic, odd = antiparallel
4. Most common: single-step (basic voice leading) -- canonic
5. Larger motions (5+ steps) produce awkward leaps, are rare
6. Harmonically unstable canons can be generated by contrary-motion distortion

# Construction / Recognition

## To Classify:
1. Count steps on the dyadic circle
2. Count voice exchanges
3. Apply the parity rules to determine sequence type
4. Check if harmonically stable (same transpositions) or unstable (different)

# Context & Application

The most common canonic sequence uses single-step motion (the basic voice leading), in "a substantial proportion of baroque and classical sequences, embellished lightly if at all" (p. 166). Classical sequences usually feature descending fifths; earlier styles more frequently use ascending fifths with passing tritones. The two-step voice exchange combined with one step produces Pathetique-style antiparallel motion. Any two-voice canonic pattern can be generated from parallel or antiparallel motion by contrary-motion distortion (Figure 4.3.4, p. 167).

# Common Errors

- **Error**: Assuming there might be other two-voice sequence types beyond transpositional, canonic, and contrary-motion
  **Correction**: The spiral diagram proves these are the only possibilities

# Common Confusions

- **Confusion**: Thinking voice exchanges create a separate category
  **Clarification**: Voice exchanges flip the parity relationship but don't create new categories
