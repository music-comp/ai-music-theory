# Quick Definition

A geometric framework in which chords are represented as points in higher-dimensional spaces and voice leadings as paths between them, revealing the deep mathematical structure underlying musical practice.

# Core Definition

Voice-leading geometry represents each chord as a point in a space where each musical voice corresponds to its own dimension. In *A Geometry of Music* (2011), Tymoczko described "twisted, singular, and higher-dimensional spaces" (p. 49). In this book, the simpler spiral diagrams serve as "the music-theoretical equivalent of a consumer product, allowing readers to enjoy the benefits of sophisticated musical geometry without mastering its details -- much as we can use GPS without fully understanding the general-relativistic calculations it performs" (Prelude, p. 46). A chord's angular position on the spiral corresponds to the sum of its pitch classes.

# Prerequisites

This is a foundational concept with no prerequisites within this source.

# Key Properties

1. Each chord is a point in a higher-dimensional space
2. Each musical voice corresponds to one dimension
3. Voice leadings are paths between points
4. The geometry is twisted, singular, and higher-dimensional
5. Spiral diagrams are simplified 2D representations
6. Angular position corresponds to the sum of pitch classes
7. Self-intersection on the diagram is an artifact of 2D projection

# Construction / Recognition

## To Use the Geometric Framework:
1. Identify the chord type and scale (e.g., triads in chromatic space)
2. Select the appropriate spiral diagram (e.g., 3-in-12)
3. Locate chords as points on the diagram
4. Interpret paths between points as voice leadings
5. Decompose paths into sliding (T_y) and looping (t_x) components

# Context & Application

The geometric approach was developed by Tymoczko in collaboration with Callender, Elkies, Hall, and Quinn. The geometry is "intrinsically neutral with respect to harmonic progression, acquiring directionality from external factors such as the preference for descending melody" (p. 76). The spiral diagrams model a small collection of spaces: 3-in-12 for rock (chromatic triads), 2-in-7 and 3-in-7 for early music (diatonic dyads and triads), and 7-in-12 for modulation (diatonic scales).

# Common Errors

- **Error**: Interpreting spiral diagram points as single notes
  **Correction**: Points represent entire chords (or scales); this is a common source of confusion noted explicitly by Tymoczko

# Common Confusions

- **Confusion**: Thinking the geometry prescribes what music should sound like
  **Clarification**: It describes the space of possibilities; directionality comes from external factors like melodic preferences

- **Confusion**: Being troubled by self-intersection of the spiral line
  **Clarification**: This is an artifact of 2D projection; the actual line does not intersect itself in the higher-dimensional space
