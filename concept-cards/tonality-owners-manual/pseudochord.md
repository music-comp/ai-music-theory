# Quick Definition

A sonority that is "neither harmonic nor nonharmonic but suspended between those worlds," arising from two voices moving in parallel thirds against a fixed pedal point, occupying the same rhythmic duration as surrounding harmonies.

# Core Definition

Tymoczko identifies an idiom in which two voices move in parallel thirds against a fixed pedal point (Figure 7.5.10), producing sonorities that seem to "contravene the general prohibition on I--ii--I^6^ progressions" (p. 336). The D--F--C sonority (an apparent ii^7^) is particularly interesting: "It feels uncomfortable to dismiss the chord as 'merely nonharmonic,' since it occupies the same rhythmic duration as the other harmonies; the phrase does not *sound* like a I--I^6^--IV progression in which the first chord lasts twice as long as the others" (p. 336). Tymoczko calls this a *pseudochord*, occupying a liminal space between harmonic and nonharmonic status.

# Key Properties

1. Two voices move in parallel thirds against a fixed pedal point
2. The resulting sonority occupies the same rhythmic duration as surrounding harmonies
3. It cannot comfortably be classified as either harmonic or nonharmonic
4. Both tonic and dominant forms exist (Figure 7.5.10)
5. The idiom is "delicately balanced between harmonic and nonharmonic" (p. 336)

# Construction / Recognition

## To Identify a Pseudochord:
1. Look for a sustained pedal point (usually tonic or dominant bass)
2. Find two upper voices moving in parallel thirds
3. Check whether the resulting sonority contravenes normal harmonic grammar (e.g., producing an apparent ii over a tonic pedal)
4. Assess whether the sonority occupies the same rhythmic weight as surrounding harmonies
5. If it is neither clearly harmonic nor clearly nonharmonic, it may be a pseudochord

# Context & Application

The pseudochord idiom appears in Bach's C-sharp major prelude from *WTC* Book I (Figure 7.7.6), where the ascending-fifth sequence uses this idiom without tonicization of new sequential units. The concept is analytically important because it challenges the binary distinction between harmonic and nonharmonic tones that underlies much conventional theory.

# Common Errors

- **Error**: Analyzing the pseudochord as a standard harmonic chord (e.g., ii^7^)
  **Correction**: The progression I--ii--I^6^ is generally prohibited; the sonority arises from linear motion, not harmonic logic

- **Error**: Dismissing the pseudochord as "merely nonharmonic"
  **Correction**: It occupies the same rhythmic duration as surrounding harmonies and has a palpable harmonic quality

# Common Confusions

- **Confusion**: Thinking the pseudochord concept undermines harmonic analysis
  **Clarification**: It identifies a specific, recognizable idiom that challenges the harmonic/nonharmonic binary -- not a license for arbitrary analysis
