# Quick Definition

A sequence that preserves the registral distance between voices from one grand period to the next. All canonic voice groups are automatically registrally stable, since each line passes through the same sequence of transpositions.

# Core Definition

"Registrally stable sequences preserve distance between voices from one grand period to the next, while contrary-motion sequences alter those distances by one or more octaves" (p. 158). A canonic group is always registrally stable because "each line passes through the same sequence of transpositions with each grand period" (p. 159). In Bach's G-sharp minor fugue (Figure 4.1.3), the upper two voices are registrally stable (both move by -1 per grand period), while the bass moves by -8, forming a contrary-motion relationship. The term "contrary motion" encompasses both oblique and similar motion from one grand period to the next (p. 159).

# Prerequisites

- **Simple Period and Grand Period** — Registral stability is measured across grand periods

# Key Properties

1. Distance between voices preserved from one grand period to the next
2. All canonic groups are automatically registrally stable
3. Non-canonic voices may form contrary-motion relationships
4. Independent from harmonic stability/instability
5. "Contrary motion" encompasses oblique and similar motion across grand periods

# Construction / Recognition

## To Check:
1. Identify the grand period
2. Measure the total transposition of each voice across one grand period
3. If all voices transpose by the same amount: registrally stable
4. If different: contrary-motion (registrally unstable)

# Context & Application

Most standard functional sequences are registrally stable. Contrary-motion sequences become more important in the nineteenth and twentieth centuries. The distinction is independent of harmonic stability: a sequence can be harmonically stable but registrally unstable (or vice versa). Some passages have mixed stability -- canonic groups internally stable but in contrary motion with non-canonic voices.

# Examples

**Example 1** (p. 159): Bach WTC G-sharp minor fugue -- upper voices registrally stable, bass contrary.

# Common Errors

- **Error**: Assuming registrally stable means voices stay in the same register
  **Correction**: It means the distance between voices is preserved across grand periods, not that individual voices don't move

# Common Confusions

- **Confusion**: Conflating registral with harmonic stability
  **Clarification**: These are independent dimensions
