# Quick Definition
The mathematical framework in which voice leadings are defined as collections of paths in pitch-class space, measured along contextually relevant scales, with distance always measured in scale steps -- enabling a unified treatment of chromatic, diatonic, and chordal transposition and inversion.

# Formal Definition
A voice leading is a collection of paths in pitch-class space, each combining an initial pitch class with a directed magnitude (e.g., "four semitones down"). Distance is always measured in scale steps, making interval size relative to context: E-G has chromatic size 3, diatonic size 2, pentatonic size 1, and triadic size 1. Transposition is represented by addition on input scale degrees (T for scalar, t for chordal, bold-T for chromatic); inversion by subtraction from a constant. Voice leadings can be bijective (note-to-note), spacing-preserving (strongly crossing-free), or involve voice exchanges. Any voice leading can be factored into a voice exchange and a spacing-preserving remainder. The spiral diagrams represent all spacing-preserving voice leadings between transpositions of a chord.

# Musical Context
This formalism underlies the entire book's analytical apparatus. It supports hierarchical set theory where transposition and inversion apply at chordal, scalar, and chromatic levels simultaneously. Transformations at one level often counteract analogues at another, producing efficient voice leading as residue -- this is the mathematical basis for the spiral diagrams and the Prime Directive.

# Examples
- (C, E, G) -> (C, F, A): bijective voice leading from C major to F major, with chromatic distances (0, 1, 2) or diatonic distances (0, 1, 1) (p. 535)
- Neo-Riemannian transformations: combining little-i inversion within the chord and big-I inversion within the chromatic scale, which nearly cancel to produce efficient voice leading (Figure A1.1, p. 535)
- Beethoven's Op. 109 variations theme: voice leadings analyzed into crossing, scalar transposition, and chordal transposition components (Figure A1.8, pp. 542-543)

# Common Confusions
- Voice leadings are abstract and register-free -- (C4, E4, G4) -> (C4, F4, A4) and (E3, C4, G4) -> (F3, C4, A4) instantiate the same voice leading
- Voice exchange is defined technically as a bijective voice leading whose paths sum to zero, involving contrary motion -- it is not the same as registral inversion
- Voice crossings never make a voice leading smaller, so minimal voice leadings are always crossing-free
