# Quick Definition

Long-range melodic motion through the notes of a tonic triad, reconceived not as a generic process independent of functional harmony but as a careful arrangement of schematic building blocks that exploit the fundamental geometry of musical possibility.

# Core Definition

Tymoczko argues that "the quadruple hierarchy underwrites a collectional analysis that is more precise than its Schenkerian antecedents" (p. 410). Rather than positing arpeggiation as "a generic process of 'arpeggiation,' existing independent of and prior to the conventions of functional harmony," it is "something more specific, a careful arrangement of schematic building blocks that themselves exploit the fundamental geometry of musical possibility" (p. 411). The strategic goal (e.g., ascent from root to fifth) is "achieved using familiar dyadic and seventh-chord voice-leading schemas while also remaining consistent with functional-harmonic norms" (p. 411).

# Key Properties

1. Arpeggiation is emergent, not primitive -- it results from well-chosen schematic arrangements
2. Specific schemas (ascending thirds/sixths, Quiescenza, fauxbourdon ROTO) produce the large-scale arpeggiation
3. The arrangement remains consistent with functional-harmonic norms
4. Different schematic paths through the same triad carry different harmonic implications
5. Grounds long-range structure in the same voice-leading geometry governing local practice

# Construction / Recognition

## To Identify Collectional Arpeggiation:
1. Identify the large-scale melodic goal (e.g., ascending from root to fifth)
2. Analyze the specific schemas used to achieve that ascent
3. Verify that each schema is consistent with functional harmony
4. Show how the arrangement of schemas produces the arpeggiation as an emergent property

# Context & Application

This reconception challenges the Schenkerian view that arpeggiation is a basic structural operation on par with stepwise descent. Instead, it is an emergent property of well-chosen schematic material. The distinction matters because it grounds long-range melodic structure in the same voice-leading geometry that governs local harmonic practice, rather than requiring a separate metaphysical framework.

# Examples

**Example 1** (pp. 410-411): Mozart's K.284, I -- two ascending arpeggiations along the tonic triad D-F#-A. The first uses ascending sequences of thirds and sixths (a near sequence moving the third D-F# along the scale D-F#-A). The second uses a contrary-motion Quiescenza and fauxbourdon ROTO variant (Figure 9.1.5).

**Example 2** (p. 411): The introductory fanfare of K.284 is a "two-octave near sequence of falling thirds that manages to sound iconic and functional without implying any specific harmonies."

# Common Errors

- **Error**: Treating arpeggiation as a primitive operation like stepwise motion
  **Correction**: It is an emergent product of schematic arrangement, not an irreducible structural move

- **Error**: Analyzing arpeggiation without identifying the specific schemas involved
  **Correction**: The specific schematic path matters -- different schemas carry different harmonic implications

# Common Confusions

- **Confusion**: Thinking arpeggiation and Schenkerian Brechung are the same concept
  **Clarification**: Tymoczko's reconception grounds arpeggiation in specific voice-leading schemas rather than abstract structural operations

- **Confusion**: Assuming arpeggiation through a triad can only be achieved one way
  **Clarification**: Multiple schematic paths can achieve the same large-scale arpeggiation with different harmonic implications
