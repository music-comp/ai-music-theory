# Quick Definition

A series of modulations that forms a complete loop surrounding the center of scale space, changing the scale-degree functions of abstract voices so that a scale returns to its original pitch classes but with different scale-degree assignments.

# Core Definition

When a series of modulations makes a complete loop in scale space, "it will change the scale-degree function of the abstract voices" (p. 367). For example, three descending major-third modulations from C major return to the white notes but with the tonic function shifted: C major becomes D-double-flat major, meaning the C slot (formerly tonic) now has leading-tone function (Figure 8.2.1). The nontrivial spelling (D-double-flat rather than C) signifies "the presence of a *nontrivial path*, a loop in voice-leading space that changes the voices' scale-degree roles" (p. 368). This is "conceptually the same phenomenon" as chordal inversion produced by loops in chord space -- "enharmonicism just *is* chordal inversion at the scalar level" (p. 367).

By contrast, "merely notational" enharmonic changes (as in Gottschalk's *Le Mancenillier*) do not correspond to any genuine scalar voice leading (p. 368).

# Key Properties

1. A complete loop in scale space changes scale-degree functions of abstract voices
2. Nontrivial enharmonic spelling signifies a nontrivial path, not a distinct harmonic object
3. Enharmonicism at the scalar level is analogous to chordal inversion at the chord level
4. Merely notational enharmonic changes have no observable consequence -- no difference in sound or fingering
5. Genuine enharmonicism involves an observable change in melodic slots' scale-degree roles
6. Enharmonicism requires chromaticism: purely diatonic modulations tend to cancel out

# Construction / Recognition

## To Distinguish Genuine from Notational Enharmonicism:
1. Trace the modulatory sequence on the spiral diagram
2. If the path forms a complete loop around the center: genuine enharmonicism (scale-degree roles change)
3. If the path retraces itself (goes out and comes back): trivial voice leading (roles preserved)
4. If the respelling is simply for notational convenience (avoiding double sharps/flats): merely notational
5. The piano-fingering test: genuine enharmonicism changes which finger plays the tonic; notational does not

# Context & Application

The significance of enharmonicism has been "obscured by its historical connection to issues of tuning and temperament" (p. 368). In a non-tempered system, C major and D-double-flat major differ acoustically. In a fixed chromatic universe, they are acoustically identical -- the spelling indicates a nontrivial *path*, not a distinct *location*. This reinterpretation allows enharmonic modulatory sequences (like those discussed by Lewin and Cohn) to be understood within a diatonic framework, contrary to claims that they force us to abandon "diatonically based models" (p. 369).

# Common Errors

- **Error**: Treating all enharmonic respellings as equivalent
  **Correction**: Genuine enharmonicism (loops) changes scale-degree roles; merely notational enharmonicism does not

# Common Confusions

- **Confusion**: Thinking enharmonic modulatory sequences prove the inadequacy of diatonic analysis
  **Clarification**: They show only that modulatory destinations must be conceived chromatically, not that the basic picture of chords inside scales must be abandoned (p. 374)
