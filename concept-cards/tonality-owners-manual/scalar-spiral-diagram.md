# Quick Definition
A spiral representation of diatonic scales within chromatic space, where sliding along the spiral represents scale-degree-preserving modulations and loops around the spiral represent scale-degree-changing modulations that produce enharmonic equivalence.

# Formal Definition
The scalar spiral diagram places seven-note diatonic scales in twelve-tone chromatic space, using the same geometrical framework previously applied to chords within scales. Sliding clockwise from C to F passes seven points for **T**_{-7} while passing twelve o'clock four times for t_4. The combination **T**_{-7}t_4 shifts B to B-flat while keeping all other melodic slots fixed -- this is the basic voice leading (Figure P8.2). Slides along the spiral represent scale-degree-preserving voice leadings; loops around the spiral represent scale-degree-changing voice leadings that alter abstract voices' roles. Complete loops produce enharmonic equivalence, just as loops in chord space produce chordal inversion.

# Musical Context
The diagram unifies the treatment of chords and scales under a single geometrical framework. It reveals that enharmonicism is simply chordal inversion at the scalar level. It also shows when repeating contrapuntal patterns can return each voice to its starting pitch (only when the pattern moves purely radially, which requires multiple chords at the same angular position -- possible for 3-in-12 triads since 3 divides 12, but not for 7-in-12 scales since 7 does not divide 12).

# Common Confusions
- The spiral diagram for scales is *not* the circle of fifths, though it is related: fifth-related scales are found approximately 30 degrees apart on the circle. In a Pythagorean (non-tempered) framework, the spiral would not close and B-sharp would be slightly displaced from C.
- Merely notational enharmonic respellings (which do not correspond to any scalar voice leading) should be distinguished from genuine enharmonic equivalences (which do).
