## Continuation Function Loosening

In subordinate themes, continuation function often achieves a **looser expression** compared to tight-knit main themes.

### Tight-Knit vs. Loose Continuation

**Tight-knit (main theme)**:
- Continuation fused with cadential function in single "continuation phrase"

**Loose (subordinate theme)**:
- Continuation and cadential functions have **distinct groups**
- Different melodic-motivic content, rhythmic patterning, accompanimental figuration

### Primary Loosening: Extension

Continuation achieves loose expression primarily through **extension**:
- Constituent units (fragments) repeated more than necessary
- **Model-sequence technique** especially suitable for extending continuation

### Delayed Fragmentation

Another way to extend continuation:
- Initial units same size as presentation units (no fragmentation yet)
- Continuation expressed by other means (harmonic acceleration, quicker rhythms, sequence)
- Fragmentation appears later, in a subsequent phrase
- This extends continuation function across multiple phrases
