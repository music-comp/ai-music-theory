# Quick Definition
The large ternary is a full-movement form consisting of three parts -- main theme, interior theme, and return of main theme -- used almost exclusively in slow movements and especially cultivated by Haydn.

# Core Definition
The large ternary consists of three parts. The two outer parts, both functioning as a main theme, normally have the same basic musical content, though the return is frequently embellished. The second part -- the interior theme -- creates contrast primarily through modal shift (Caplin, p. 588).

# Prerequisites
- **Small ternary** -- The theme type on which the main theme and interior theme are modeled
- **Interior theme** -- The contrasting middle part of the large ternary

# Key Properties
1. Full-movement form (not a theme type like the small ternary)
2. Main theme is normally a complete small ternary or small binary, beginning and ending in the home key with PAC
3. Interior theme creates contrast through modal shift (minore/maggiore) or different tonal region
4. Return brings the same basic structure, often with ornamental embellishment
5. An optional coda may follow, often referencing interior-theme material

# Construction / Recognition
## To Identify:
1. Confirm the form is tripartite at the full-movement level
2. Verify the outer parts function as main themes in the home key
3. Check that the interior part contrasts through modality (not subordinate key)
4. Confirm the outer parts are themselves built as small ternary or small binary

# Context & Application
Used almost exclusively in slow movements. Especially cultivated by Haydn, with significant examples by Mozart and Beethoven. The form must be distinguished from the small ternary -- they are not analogous forms despite both being tripartite.

# Examples
**Example 1** (p. 589): Haydn, String Quartet in G minor ("Rider"), Op. 74, No. 3, ii -- interior theme begins with shift to E minor (minore), built as truncated small ternary.

# Relationships
## Builds Upon
- **Small ternary** -- Main theme and interior theme are typically modeled on this form
## Enables
- **Main theme (large ternary)** -- The outer parts of the form
- **Interior theme** -- The contrasting middle part
- **Coda (large ternary)** -- Optional concluding section
## Related
- **Minuet/trio form** -- Similar tripartite structure but with different functional relations
## Contrasts With
- **Small ternary** -- A theme type, not a full-movement form; different functional labels
- **Sonata form** -- More complex; uses subordinate key rather than modal contrast

# Common Errors
- **Error**: Treating large ternary as a "bigger" small ternary
  **Correction**: They are fundamentally different formal types with different functional organizations; the large ternary is not an expanded small ternary

# Common Confusions
- **Confusion**: Using A-B-A' labels for the large ternary
  **Clarification**: These labels belong to the small ternary; use main theme / interior theme / return of main theme for the large ternary
