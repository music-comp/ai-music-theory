# Presentation vs. Compound Basic Idea

When an initiating phrase is supported by a straightforward tonic prolongation, distinguishing between a presentation and a compound basic idea depends on its melodic-motivic content.

## The Question

Is the material in mm. 3-4:
- A **repetition** of the basic idea (making it a presentation)?
- **Contrasting** material (making it a compound basic idea)?

## Clear Cases

In many cases, the situation is clear-cut:
- **Presentation**: Basic idea obviously repeated
- **Compound basic idea**: Significantly different material

## Ambiguous Cases

Ambiguity arises when the melodic "background" of the two ideas is similar:
- Surface: Ideas appear different
- Background: Underlying melodic scaffold is consistent

## Both Analyses Valid

In genuinely ambiguous cases:
- **Both interpretations can be supported**
- Focus on selected details supports each reading
- Neither is necessarily "correct"

## Analysis Criteria

When analyzing:
- Consider the **surface** melodic-motivic content
- Consider the **underlying** melodic framework
- Identify criteria supporting each interpretation
- Acknowledge ambiguity where it exists

## Key Point

Which interpretation is "correct"? Both are viable, so long as you identify the criteria used to support each reading.
