# Quick Definition
A deviation from the norm where the recapitulation's main theme returns in the context of subdominant harmony rather than the home-key tonic, challenging the strict double-return requirement.

# Core Definition
"The 'double return' of the main theme and the home key is often cited as a hallmark of classical sonata form. But a few examples from the repertory see the main theme return in the context of subdominant harmony" (p. 531). This has "antecedents in Baroque and pre-classical practice" and "raises the question of whether a true recapitulation is at hand." When the main theme begins in the subdominant, "a tonic setting of main-theme ideas may appear later in the movement, most likely in the coda."

# Prerequisites
- **Recapitulation section** — The section being deviated from
- **Double return** — The norm being violated

# Key Properties
1. Main theme returns in subdominant harmony, not tonic
2. Challenges the double-return requirement
3. Has antecedents in Baroque and pre-classical practice
4. Tonic setting of main-theme ideas may appear later (usually in coda)
5. A related variant: subordinate theme begins in subdominant, adjusted back to tonic

# Examples
Mozart, Piano Sonata in C, K. 545 — well-known example of recapitulation beginning in subdominant region.
