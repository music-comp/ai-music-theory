# Quick Definition
The development typically begins in the subordinate key, explores minor-mode tonal regions of the home key, and eventually returns to the home key, ending on dominant harmony.

# Core Definition
Caplin identifies the tonal organization as the "one relatively conventional aspect" of development sections (p. 443). Minor-mode regions for a major home key are, in order of importance: submediant (vi), mediant (iii), and supertonic (ii). For a minor home key: subdominant (iv) and dominant (v, minor because based on the natural minor scale). The emphasis on minor-mode regions creates marked contrast with the exposition's major-mode subordinate key.

# Key Properties
1. Begins typically in the subordinate key
2. Explores minor-mode regions of the home key
3. Eventually returns to the home key, ending with dominant harmony
4. Minor-mode regions contrast with the exposition's major-mode emphasis
5. Major-mode subdominant may appear early in the development as an exception
6. Beethoven expands the tonal spectrum through modal borrowing (bVI, bIII, bII)

# Construction / Recognition
## To Identify:
1. Note the opening key (usually the subordinate key from the exposition)
2. Track which minor-mode regions receive cadential confirmation as development keys
3. Identify the return to the home-key dominant

# Context & Application
The tonal plan provides the one predictable element in what is otherwise the least conventional section of sonata form. The emphasis on minor-mode regions ensures maximum contrast with the major-mode subordinate key of the exposition.

# Examples
**Example 13.7** (p. 461): Beethoven, Piano Sonata in G, Op. 14, No. 2 — uses development keys borrowed from the parallel minor (bVI = E-flat), illustrating modal borrowing that expands the tonal spectrum.
