# Quick Definition
When a tonic compound basic idea is repeated with a dominant version (I-V, V-I), the impression of antecedent-consequent may arise. But if there is only a single harmonic progression underlying each 4-m. phrase (no distinct cadential progression ending a prior prolongational one), the situation is exclusively prolongational and should be heard as a presentation, not a period.

# Core Definition
Caplin warns that statement-response repetition in a compound presentation can create the impression of an antecedent ending with HC and a consequent ending with authentic cadence. The critical test: is there a distinctly cadential progression that "ends" some prior prolongational progression? If the entire situation is exclusively prolongational, the 8-m. unit is an open-ended presentation, not a closed period.

# Key Properties
1. Statement-response (I-V, V-I) can mimic antecedent-consequent
2. Critical test: is there a distinct cadential progression?
3. If exclusively prolongational: presentation
4. If cadential progression ends prolongational: period
5. Check for root-position harmony at the ends of each 4-m. unit
