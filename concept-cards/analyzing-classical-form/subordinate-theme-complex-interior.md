# Quick Definition
Sometimes the interior theme of a large ternary takes the form of a subordinate-theme complex (transition, subordinate theme, retransition) within the tonal framework of the minore, rather than following the typical small ternary model.

# Core Definition
Sometimes the interior theme seems not to relate to the small ternary (binary) model. In some cases, the interior theme can give the impression of being a subordinate-theme complex (consisting of a transition, subordinate theme, and retransition) within the tonal framework of the minore (Caplin, p. 604).

# Prerequisites
- **Interior theme** -- The formal function that takes this unusual organization
- **Subordinate theme** -- The function replicated within the minore framework

# Key Properties
1. Contains transition-like, subordinate-theme-like, and retransition functions
2. Set within the minore tonal framework (not the standard subordinate key)
3. Does not establish V (major) or III (minor) as subordinate key
4. All secondary keys relate to the minor mode of the home key
5. Represents modal contrast, not tonal conflict

# Construction / Recognition
## To Identify:
1. Identify the minore framework
2. Note transition-like and subordinate-theme-like functions within it
3. Track how the material returns to the home-key dominant
4. Distinguish from both typical interior theme and regular sonata exposition

# Context & Application
This variant shows the diversity possible within the interior theme function. It provides a more complex internal organization while maintaining the modal (not tonal) contrast characteristic of interior themes.

# Examples
**Example 1** (p. 604): The interior theme may contain transition, subordinate theme, and retransition within the minore, resembling a subordinate-theme complex but in the wrong tonal framework for a true sonata exposition.

# Common Errors
- **Error**: Analyzing this as a true subordinate-theme complex within a sonata exposition
  **Correction**: The tonal framework is minore, not the subordinate key, so this remains an interior theme within a large ternary
