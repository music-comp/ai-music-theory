# Quick Definition
The most frequently found hybrid type, consisting of an antecedent phrase (mm. 1-4) followed by a continuation phrase (mm. 5-8), thus beginning like a period but ending like a sentence.

# Core Definition
Caplin identifies antecedent + continuation as the most common hybrid in the classical repertory. The first phrase is a standard antecedent (basic idea + contrasting idea ending with a weak cadence, usually HC). The second phrase does not bring a return of the basic idea; instead, it begins with new material that fragments the preceding ideas and typically modulates or drives toward a strong cadence, projecting continuation function. This hybrid almost always closes with a PAC to complement the weaker cadence ending the antecedent.

# Prerequisites
- **Antecedent phrase** — Must recognize the basic idea + contrasting idea + weak cadence structure
- **Continuation phrase** — Must identify fragmentation, acceleration, and forward-driving characteristics

# Key Properties
1. First phrase: standard antecedent closing with HC (or IAC)
2. Second phrase: continuation with fragmentation, harmonic acceleration, closing with PAC
3. Basic idea appears only once (at the beginning)
4. Harmonic acceleration at start of continuation may not be marked if the contrasting idea already accelerated the harmony toward the HC
5. In the absence of harmonic acceleration, clear fragmentation signals continuation function

# Construction / Recognition
## To Identify:
1. Confirm first phrase has basic idea + contrasting idea + weak cadence (antecedent)
2. Check that second phrase does NOT return the basic idea
3. Look for fragmentation, sequence, or harmonic acceleration in the second phrase
4. Verify a stronger cadence (typically PAC) closes the theme

# Context & Application
This hybrid brings aspects of the sentence and period in equal measure and sits in the middle of Caplin's hybrid spectrum. It is advantageous when the composer wishes to state the basic idea only once, or when modulating within 8 measures, since the continuation provides more space for modulation than a consequent would.

# Examples
**Example 1** (p. 121): Mozart, Piano Sonata K. 330, ii, mm. 1-8 — antecedent with HC at m. 4; continuation with fragmentation to 1-m. units and modulation to dominant.
**Example 2** (p. 127): Beethoven, "Pathetique" Sonata Op. 13, ii, mm. 1-8 — fragmentation signals continuation despite lack of harmonic acceleration (because contrasting idea already sped up harmony).

# Relationships
## Builds Upon
- **Antecedent phrase** — Provides the initiating function
- **Continuation phrase** — Provides the concluding function
## Enables
- **Compound period (ant+cont type)** — Can serve as the compound antecedent of a 16-m. period
## Related
- **Compound basic idea + continuation** — Similar second phrase but different initiating function
## Contrasts With
- **Period** — Period brings consequent (return of b.i.) rather than continuation
- **Antecedent + cadential** — Cadential type lacks continuational features

# Common Errors
- **Error**: Assuming the continuation phrase must show harmonic acceleration
  **Correction**: If the contrasting idea already accelerated harmony toward the HC, fragmentation alone may signal continuation function

# Common Confusions
- **Confusion**: Labeling this theme a "contrasting period"
  **Clarification**: The term "contrasting period" fails to identify the specific continuation function of the second phrase; Caplin's hybrid label is more precise
