# Quick Definition
An 8-m. period whose consequent modulates to a related key, closing with a PAC there. The antecedent always closes in the home key (never modulates). Cadential differentiation is maintained: HC (home key) remains syntactically weaker than PAC (new key), because syntactical strength is determined by type, not tonal context.

# Core Definition
Most periods conclude in the key in which they begin. Now and then, the consequent phrase modulates, and the theme closes with a PAC in a related tonality. Unlike the consequent, which is free to modulate, an antecedent phrase closes in the same key in which it begins (p. 112). The syntactical strength of a cadence is determined on the basis of its type, not on its tonal context: the HC of the opening key remains weaker than the PAC of the related key (p. 112).

# Prerequisites
- **Period** — The modulating period is a variant of the period
- **Modulation** — The consequent modulates to a new key

# Key Properties
1. Antecedent: closes in home key (never modulates)
2. Consequent: modulates to related key, closes with PAC there
3. Cadential differentiation maintained: HC (home key) < PAC (new key)
4. Syntactical strength determined by TYPE, not tonal context
5. Exception: reinterpreted HC (the one case where antecedent appears to modulate)

# Construction / Recognition
## To Identify:
1. Identify a period with standard antecedent (HC in home key)
2. Check if the consequent modulates to a new key
3. Verify PAC in the new key
4. Cadential differentiation still applies: HC < PAC regardless of key

# Context & Application
Modulating periods are less common than non-modulating ones. Typical destinations: dominant (V) from major; relative major (III) from minor. The principle that syntactical strength is by type ensures cadential differentiation functions across keys.

# Examples
**Example 1** (p. 112, Ex. 3.18): Haydn, Symphony No. 99, iv -- antecedent with HC in Eb, consequent modulates to Bb (V) with PAC.

# Common Errors
- **Error**: Thinking the antecedent modulates
  **Correction**: The antecedent always closes in the home key (exception: reinterpreted HC)

# Common Confusions
- **Confusion**: Thinking an HC in the home key is stronger than a PAC in a secondary key
  **Clarification**: Syntactical strength is by type: HC < PAC, regardless of key
