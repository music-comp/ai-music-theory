# Quick Definition
The main theme introduces the principal melodic-motivic material of the movement in a relatively tight-knit formal organization, confirming the home key through cadential closure (usually PAC, sometimes HC, rarely IAC) and defining the standard of tight-knit organization for the entire movement.

# Core Definition
The main theme presents the principal melodic-motivic material of the sonata form in a stable tonal and phrase-structural context. It is relatively tight-knit in formal organization and often structured as a conventional theme type (sentence, period, hybrid, etc.). The main theme confirms the home key through cadential closure -- usually a PAC, sometimes an HC (especially in minor-mode movements), or more rarely an IAC. The main theme defines a standard of tight-knit organization for the movement as a whole, to which all other sections can be compared as more or less loosely organized. This comparison is always relative to a given movement, not absolute. An exposition occasionally contains two distinct main themes, each ending with PAC, forming a main-theme group.

# Key Properties
1. Introduces principal melodic-motivic material
2. Relatively tight-knit formal organization
3. Often a conventional theme type (sentence preferred over period for first movements)
4. Confirms home key with cadential closure
5. Cadence types: usually PAC, sometimes HC, rarely IAC
6. Defines the standard of tight-knit organization for the movement
7. Main-theme group possible (two themes, each with PAC)

# Construction / Recognition
## Tight-Knit Organization Expressed Through:
1. Clear establishment of home-key tonic in presentation phrase
2. Cadential confirmation of the key at theme's end
3. Unified melodic material through motives derived from basic idea
4. Symmetrical grouping structure (e.g., two 4-measure phrases)
5. Compact and efficient presentation of phrase functions

# Context & Application
The sentence form is especially well suited for opening first-movement sonata forms because of its forward-driving character. The period's symmetrical balance makes it more suitable for finales, where a lighter, more relaxed affect is often projected. The distinction between tight-knit and loose form is always relative: what matters is how the main theme compares to the subsequent thematic functions in that particular movement.

# Examples
**Example** (p. 287): Beethoven, Piano Sonata in F minor, Op. 2, No. 1, i, mm. 1-8 -- a model sentence form expressing tight-knit organization through home-key tonic establishment, cadential confirmation, unified motivic material, and symmetrical grouping.

# Common Errors
- **Error**: Assuming all main themes must be assertive and "masculine" in character
  **Correction**: Many main themes exhibit hesitancy, sudden textural/dynamic changes, and marked rhythmic discontinuities; lyrical main themes also occur
