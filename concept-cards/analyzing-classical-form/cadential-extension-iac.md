# Quick Definition
When a subordinate theme reaches an IAC instead of the required PAC, the cadential function is extended: the preceding phrase is typically repeated, this time achieving the PAC. Though a certain antecedent-consequent quality results, the passage should not normally be considered a true period.

# Core Definition
Since a subordinate theme is required to close with a PAC in the subordinate key, the appearance of an IAC signals that the theme has not yet reached its true end. The preceding phrase is typically repeated, with the repetition leading to a PAC. This creates a certain sense of antecedent-consequent functionality, but Caplin stresses this should not normally be considered a period: the passage does not function as a self-contained, tight-knit theme; it rarely contains other characteristics of true antecedent and consequent phrases; and the phrase ending with the IAC sometimes elides with the following phrase. The IAC provides more closure than a deceptive cadence but remains insufficient for subordinate-theme completion (Caplin, Ch. 12, p. 386).

# Key Properties
1. IAC replaces expected PAC in subordinate theme
2. Signals the theme has not yet reached its true end
3. Preceding phrase typically repeated to achieve PAC
4. Creates antecedent-consequent quality but is NOT a true period
5. More conclusive than deceptive cadence, less than PAC
6. Phrase ending with IAC may elide with following phrase

# Construction / Recognition
## To Identify:
1. Locate a cadential progression in the subordinate theme
2. Check soprano: does it end on scale degree other than 1? (IAC)
3. Observe whether the phrase is repeated with a stronger cadential ending
4. Resist labeling as a period unless it truly functions as a self-contained theme

# Context & Application
This technique is one of the primary methods of extending cadential function in subordinate themes. The IAC creates a sense of partial closure that motivates continuation without fully disrupting the cadential process, making it a milder form of extension than evaded or deceptive cadences.
