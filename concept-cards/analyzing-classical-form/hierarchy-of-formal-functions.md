# Quick Definition
Formal functions operate at multiple hierarchical levels: the same phrase functions (presentation, continuation, cadential, etc.) used to construct main themes also construct transitions, subordinate themes, and development cores, though in looser formal expressions. Identifying these functions at all structural levels is what distinguishes Caplin's approach.

# Core Definition
Themes are constructed out of various formal functions (presentation, antecedent, continuation, cadential) associated with ideas and phrases. As analysis moves beyond main themes, the same phrase functions are used to construct other **thematic functions** (transition, subordinate theme, development core), though these functions usually acquire a looser formal expression. What distinguishes Caplin's approach from all prior approaches is the emphasis on identifying constituent formal functions at all levels of structure throughout the entirety of the full-movement form (Caplin, Ch. 9, p. 288).

# Key Properties
1. Phrase-level functions: presentation, antecedent, continuation, cadential, etc.
2. Theme-level functions: main theme (initiating), transition (medial), subordinate theme (concluding)
3. The same phrase functions appear at all thematic levels
4. Looser expression of phrase functions distinguishes later thematic regions
5. This multi-level functional analysis is Caplin's distinctive contribution

# Context & Application
This principle means that the analytical skills developed for Part I themes (sentence, period, hybrid) are directly applicable to the larger formal contexts of Part II. The transition uses the same building blocks as a main theme -- just loosened. The subordinate theme uses them too -- loosened further.
