# Quick Definition
Formal functions operate at multiple hierarchical levels: the same phrase functions (presentation, continuation, cadential, etc.) used to construct main themes also construct transitions, subordinate themes, and development cores, though in progressively looser formal expressions. Identifying these functions at all structural levels is what distinguishes Caplin's approach.

# Core Definition
In Part I, themes (mostly main themes) are constructed out of phrase functions such as presentation, antecedent, continuation, and cadential. As analysis moves beyond main themes, the same phrase functions are used to construct other **thematic functions** (transition, subordinate theme, development core), though these functions usually acquire a looser formal expression. What distinguishes Caplin's approach from all prior approaches is the emphasis on identifying constituent formal functions at all levels of structure throughout the entirety of the full-movement form (Caplin, Ch. 9, p. 288).

# Key Properties
1. Phrase-level functions: presentation, antecedent, continuation, cadential, etc.
2. Theme-level functions: main theme (initiating), transition (medial), subordinate theme (concluding)
3. The same phrase functions appear at all thematic levels
4. Looser expression of phrase functions distinguishes later thematic regions
5. This multi-level functional analysis is Caplin's distinctive contribution
6. The degree of looseness relative to the main theme is the primary measure of formal expression

| Context | Expression of Phrase Functions |
|---------|-------------------------------|

| Transition | Looser, extended |
| Subordinate Theme | Loosest, expanded |
| Development Core | Very loose, sequential |

# Context & Application
The hierarchy of formal functions is one of the most important theoretical contributions of this textbook. By recognizing that the same functions (presentation, continuation, cadential, etc.) operate throughout a movement -- not just within the main theme -- the analyst gains a unified vocabulary for describing all parts of sonata form. The analytical skills developed for Part I themes (sentence, period, hybrid) are directly applicable to the larger formal contexts of Part II. The transition uses the same building blocks as a main theme -- just loosened. The subordinate theme uses them too -- loosened further.
