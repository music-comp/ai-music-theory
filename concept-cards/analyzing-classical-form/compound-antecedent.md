# Quick Definition
The opening 8-m. unit of a compound period, structured as a complete simple theme (sentence, or hybrid c.b.i.+cont, or hybrid ant+cont) that closes with a weak cadence, usually an HC or reinterpreted HC.

# Core Definition
Three main types: (1) sentence (pres + cont), (2) hybrid c.b.i. + cont, (3) hybrid ant + cont. Closes with HC (regular or reinterpreted), rarely IAC. The basic idea should not return at m. 5 in a way that creates a premature consequent, which would spoil the effect of the real consequent at m. 9. In a sentential antecedent, the restatement at mm. 3-4 is a "repeat" (not a "return"), which does not anticipate the return at m. 9.

# Key Properties
1. Three structural categories
2. Usually closes with HC (regular or reinterpreted)
3. Basic idea must not return prematurely at m. 5 (as consequent)
4. Repeat (mm. 3-4 in sentence) vs. return (m. 9) are different functions
