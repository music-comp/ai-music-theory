# Quick Definition
When a monothematic exposition uses the same basic idea for both main and subordinate themes, the recapitulation typically deletes the second appearance of that idea in the subordinate theme to avoid redundant repetition in the home key.

# Core Definition
Special structural changes are required when the exposition uses the same basic idea for both main and subordinate themes. If the original structure of the subordinate theme were retained in the recapitulation, the basic idea would occur in the home key twice: first in the main theme and second in the tonally adjusted subordinate theme. To avoid this potential redundancy, the composer normally deletes the second appearance of the basic idea, since the first appearance is needed to signal the recapitulation's beginning. Simply omitting the basic idea at the subordinate theme's start may not suffice: the theme cannot necessarily begin logically with continuation function, so the composer must usually alter the theme more substantially, or may eliminate the subordinate theme entirely (if multiple themes exist in the subordinate group).

# Prerequisites
- Understanding of tonal adjustment procedures
- Knowledge of Haydn-style monothematic expositions

# Key Properties
- Same basic idea used for both main and subordinate themes in the exposition
- Tonal adjustment would create two home-key statements of the same idea
- Second appearance (in subordinate theme) typically deleted
- First appearance (in main theme) retained to signal recapitulation
- Simple deletion of basic idea may require further restructuring
- Theme may need more substantial alteration or complete elimination
- Particularly associated with Haydn's compositional practice

# Construction / Recognition
Identify monothematic expositions where both main and subordinate themes share the same basic idea. In the recapitulation, check whether the subordinate theme retains this basic idea (creating redundancy) or eliminates it. If eliminated, note how the theme is restructured to begin without its original opening.

# Context & Application
This issue is especially relevant for Haydn, who writes many monothematic expositions, though striking examples also appear in Mozart. The deletion reflects the principle that the recapitulation should avoid unnecessary repetition of material already well established in the home key. The required restructuring often results in some of the most creative and unusual subordinate theme organizations found in Classical recapitulations.

# Examples
- Haydn: typically deletes the basic idea from the subordinate theme in the recapitulation, with substantial restructuring of the remaining material
- Mozart: occasional striking examples of monothematic recapitulation adjustments

# Common Errors
- Assuming the subordinate theme must retain its basic idea even in a monothematic recapitulation
- Treating the restructured subordinate theme as an entirely new theme rather than as a modified version of the exposition's

# Common Confusions
- Deleting the basic idea from the subordinate theme is NOT the same as eliminating the subordinate theme -- the functional area remains, but its opening is restructured to avoid repeating material already stated in the home key
