# Recapitulation of Monothematic Exposition

Special structural changes required when the exposition uses the same basic idea for both main and subordinate themes.

## The Problem

If original structure of subordinate theme is retained in recapitulation, the basic idea would occur in home key twice:
1. First in main theme
2. Second in tonally adjusted subordinate theme

## Solution: Deletion

To avoid potential redundancy, composer normally deletes second appearance of basic idea. (First appearance needed to signal recapitulation beginning.)

## Additional Restructuring

Simply omitting basic idea at subordinate theme start may not suffice:
- Theme cannot necessarily begin logically with continuation function
- Composer must usually alter theme more substantially
- May eliminate subordinate theme entirely (if multiple themes exist)

## Haydn's Practice

Haydn, who writes many monothematic expositions, typically uses these procedures, though striking examples also found in Mozart.
