# Quick Definition
When main-theme material appears after subordinate-theme material in the recapitulation, though the main-theme passage typically functions as a subordinate theme (with loosening devices), not as a true main-theme return.

# Core Definition
"Some historians and theorists have called [this] a 'reversed' (or 'inverted') recapitulation, whereby the order of main and subordinate themes is switched" (p. 531). Caplin warns that "although this notion is useful on an entirely descriptive level, it suffers from some theoretical deficiencies." Crucially, "the passage containing main-theme material does not function as the main theme of a recapitulation; rather, this material is refashioned to function as a subordinate theme, thus exhibiting loosening devices associated with that function." The key distinction is between musical content and formal function.

# Key Properties
1. Subordinate-theme material appears before main-theme material
2. Main-theme material is refashioned to function as a subordinate theme
3. Loosening devices associated with subordinate-theme function appear in the main-theme passage
4. Must distinguish between musical content and formal function
5. Descriptively useful but theoretically problematic

# Construction / Recognition
## To Identify:
1. Note if the recapitulation begins without the main theme's opening
2. Look for main-theme material appearing later in the recapitulation
3. Check whether this later appearance exhibits subordinate-theme loosening devices
4. If so, the material functions as a subordinate theme despite its content

# Examples
**Example 14.15** (p. 528): Haydn, String Quartet in E-flat, Op. 50, No. 3, i — recapitulation begins with cadential idea (m. 88); after subordinate theme and grand pause, main-theme opening appears (m. 114) but with expanded cadential progression and loosening devices, functioning as a "second subordinate theme."
