# Quick Definition
In some periodic situations, the 2-m. contrasting idea is replaced by a full 4-m. continuation phrase (with fragmentation, model-sequence technique, and cadential closure), creating a form of phrase expansion where the consequent grows from 4 to 8 measures.

# Core Definition
Caplin identifies a specific type of phrase expansion in periodic contexts where a 2-m. contrasting idea is replaced by a full 4-m. continuation phrase. The expansion is motivated when the return of the basic idea in the consequent is harmonized differently (e.g., on the supertonic), requiring a more elaborate path back to the tonic for cadential confirmation. The continuation features fragmentation and model-sequence technique, creating a satisfying sense of "returning to the tonic" before the cadential confirmation.

# Prerequisites
- **Period** — The theme type where this deviation occurs

# Key Properties
1. 2-m. contrasting idea replaced by 4-m. continuation phrase
2. Results in an expanded consequent (8 mm. instead of 4)
3. Often motivated by harmonic displacement of the basic idea's return
4. Continuation features fragmentation and model-sequence technique
5. Creates 4+8 or similar asymmetrical structure

# Examples
**Example 1** (p. 176): Haydn, Op. 33/3, ii, mm. 1-10 -- periodic hybrid (c.b.i. + consequent); consequent's contrasting idea replaced by 4-m. continuation with fragmentation and model-sequence, closing with PAC.
