# Quick Definition
Model-sequence technique is a form of repetition where a given unit (model) is repeated through complete transposition of its content (sequence). Both melody and harmony are transposed by the same interval. It always involves an underlying sequential progression, but sequential progressions can occur without model-sequence technique.

# Core Definition
Model-sequence technique is a specific form of repetition: a given unit of music (the model) is completely transposed to another scale degree to create a sequence; both melody and harmony are transposed by the same interval and direction (p. 66). This is distinct from sequential progression, which is a particular way of arranging harmonies according to consistent root motion (such as descending fifths or ascending steps). Model-sequence technique will always be supported by an underlying sequential progression, but harmonic sequences can occur without model-sequence technique (p. 77). When used in a presentation phrase, it constitutes sequential repetition of the basic idea -- the rarest and least stable of the three repetition types (p. 66).

# Prerequisites
- **Continuation phrase** — Model-sequence technique most commonly appears in continuations
- **Sequential progression** — The harmonic framework underlying model-sequence technique

# Key Properties
1. A form of repetition: model stated, then transposed completely as sequence
2. Both melody AND harmony transposed by the same interval
3. Always supported by an underlying sequential progression
4. Sequential progressions can exist without model-sequence technique
5. Contributes to harmonic destabilization in continuation
6. Rare in simple 8-m. sentences (too little "room" before cadential progression)
7. More common when continuation function is extended
8. In presentations, constitutes sequential repetition (least stable type)

# Construction / Recognition
## To Identify:
1. Locate a unit (the model) that is immediately transposed
2. Verify that BOTH melody and harmony are transposed by the same interval
3. If only harmony is sequential (without complete melodic transposition), it is a sequential progression but not model-sequence technique
4. Label the model with a bracket; label subsequent units as "seq."

# Context & Application
Model-sequence technique typically appears in continuation phrases, where it contributes to harmonic destabilization and supports fragmentation. The fragmented units are often repeated sequentially (p. 77). Sequential harmonies appear infrequently in simple 8-m. sentences because there is often too little room between continuation onset and the cadential progression. They tend to be used when continuation function is extended (p. 77). In presentations, sequential repetition of the basic idea is rare because it threatens the tonic prolongational stability required by presentation function (p. 66).

# Examples
**Example 1** (p. 76, Ex. 2.21): Beethoven, Op. 135, iii -- continuation with descending-fifth sequential progression supporting model-sequence technique; fragmented units repeated sequentially.
**Example 2** (p. 67, Ex. 2.3): Beethoven, Op. 14, No. 2, i -- sequential repetition of basic idea in presentation (rare case); basic idea transposed up a step.

# Common Errors
- **Error**: Confusing statement-response repetition with sequential repetition when melody is transposed by a step
  **Correction**: Check the harmonic context: if harmony changes from I to V, it is statement-response; if BOTH melody and harmony are transposed, it is sequential (p. 67)

# Common Confusions
- **Confusion**: Equating any sequential harmonic progression with model-sequence technique
  **Clarification**: Model-sequence technique requires complete transposition of a unit (both melody and harmony); sequential progressions can occur without this specific repetition technique (p. 77)
