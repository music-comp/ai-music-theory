# Quick Definition
A parallel period is one in which the consequent begins with material closely resembling the antecedent's opening basic idea. This is the most common type of period. "Parallel" refers to the melodic-motivic relationship at the openings of antecedent and consequent, not to the cadential relationship.

# Core Definition
In a parallel period, the consequent phrase begins with a return of the original basic idea, projecting the sense of "repeating the antecedent" (p. 102). The return can take three forms: (1) exact return -- same basic idea with same harmonic support (most common); (2) dominant version -- basic idea supported by dominant harmony, creating statement-response character across the period; (3) sequential return -- basic idea transposed to another scale degree, usually up a step into the supertonic region (least stable) (pp. 103-105). Even extensive variation of the return is possible, as long as the fundamental melodic profile projects a clear sense that the opening idea has returned (p. 103). True contrasting periods (consequent beginning with different material) are rare in Caplin's framework because the return of the basic idea is essential to consequent function (p. 98).

# Prerequisites
- **Period structure overview** — The parallel period is the standard period type
- **Antecedent phrase** — First phrase of the period
- **Consequent phrase** — Second phrase, whose opening defines the period as "parallel"

# Key Properties
1. Consequent begins with return of the antecedent's basic idea
2. Most common type of period
3. "Parallel" refers to melodic-motivic similarity at phrase openings
4. Three forms of return: exact, dominant version, sequential
5. Exact return is most common and most stable
6. Variation of the return is permitted if basic profile is recognizable
7. True contrasting periods are rare (not recognized as periods by Caplin)

# Construction / Recognition
## To Identify:
1. Locate the basic idea in mm. 1-2 of the antecedent
2. Check whether mm. 5-6 bring a recognizable return of the same idea
3. If the return is exact (same harmony), it is a standard parallel period
4. If the return begins on V instead of I, it is a dominant-version return
5. If the return is transposed (melody AND harmony shifted), it is sequential

# Context & Application
Nearly all periods in classical music are parallel, since the return of the basic idea is what gives the consequent its sense of "repeating" the antecedent. Caplin (following Schoenberg) restricts the term "period" to cases where the consequent begins with similar material and exhibits weak-to-strong cadential differentiation. What other textbooks call a "contrasting period" (consequent beginning with different material) is treated by Caplin as a hybrid theme, not a period (p. 98).

# Examples
**Example 1** (p. 103, Ex. 3.8): Haydn, H. 27, iii -- exact return of the basic idea at m. 5.
**Example 2** (p. 103, Ex. 3.10): Mozart, K. 333, ii -- highly embellished return of basic idea, still recognizable.
**Example 3** (p. 104, Ex. 3.11): Haydn, H. 28, i -- dominant-version return, creating statement-response character across the period.
**Example 4** (p. 105, Ex. 3.12): Mozart, K. 576, i -- sequential return of basic idea, transposed up a step.

# Common Errors
- **Error**: Thinking "parallel" refers to the cadential relationship
  **Correction**: "Parallel" refers to the melodic-motivic relationship between the openings of antecedent and consequent

# Common Confusions
- **Confusion**: Assuming the basic idea must return identically
  **Clarification**: Extensive variation is permitted; what matters is that the fundamental melodic profile is recognizable as a return (p. 103)
