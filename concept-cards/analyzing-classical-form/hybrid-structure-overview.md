# Quick Definition
A structural summary of all four hybrid types, showing their first-phrase and second-phrase functions, cadential patterns, and positions on the sentence-period spectrum.

# Core Definition
The four hybrid types use syntactically appropriate combinations of phrase functions. Hybrid 1 (ant + cont): antecedent with weak cadence followed by continuation with PAC; begins like period, ends like sentence. Hybrid 2 (ant + cad): antecedent followed by exclusively cadential phrase on ECP. Hybrid 3 (c.b.i. + cont): compound basic idea (no cadence) followed by continuation; most sentence-like. Hybrid 4 (c.b.i. + cons): compound basic idea followed by consequent with return of basic idea; most period-like. Hybrids never begin with a presentation phrase.

# Prerequisites
- **Sentence** — One extreme of the spectrum
- **Period** — The other extreme
- **Hybrid themes** — The overarching concept

# Key Properties
1. All four types are 8 measures (normatively)
2. Two possible first phrases: antecedent (with cadence) or c.b.i. (without)
3. Three possible second phrases: continuation, cadential, or consequent
4. Spectrum position: sentence -- c.b.i.+cont -- ant+cont -- ant+cad -- c.b.i.+cons -- period
5. Presentation is never used as a first phrase in hybrids

# Construction / Recognition
## To Identify:
1. First phrase: does it cadence? Yes = antecedent; No = c.b.i.
2. Second phrase: does basic idea return? Yes = consequent. Is there fragmentation/acceleration? Yes = continuation. Is there an ECP with no continuational features? Yes = cadential.
3. Combine labels to identify the hybrid type

# Context & Application
This overview provides a quick-reference framework for identifying hybrid themes. The decision tree (cadence in first phrase? -> type of second phrase?) makes identification systematic.

# Common Errors
- **Error**: Thinking there are only two options (sentence or period) for any 8-m. theme
  **Correction**: Four hybrid types provide additional categories for themes mixing features

# Common Confusions
- **Confusion**: Expecting a presentation to begin a hybrid
  **Clarification**: Presentation is an initiating function reserved for the sentence; hybrids use antecedent or c.b.i. as initiating functions
