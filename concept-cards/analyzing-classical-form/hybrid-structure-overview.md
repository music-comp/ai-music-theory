# Hybrid Theme Structure Overview

Hybrid themes combine elements of sentence and period, creating four main types with distinct structural characteristics.

## The Four Types

### Type 1: Antecedent + Continuation
- Phrase 1: Antecedent (b.i. + c.i. → weak cadence)
- Phrase 2: Continuation (no return, destabilization → PAC)
- Begins like period, ends like sentence

### Type 2: Antecedent + Cadential
- Phrase 1: Antecedent (b.i. + c.i. → weak cadence)
- Phrase 2: Cadential (supported by ECP → PAC)
- Minimal continuation characteristics

### Type 3: Compound Basic Idea + Continuation
- Phrase 1: Compound b.i. (b.i. + c.i., NO cadence)
- Phrase 2: Continuation → any cadence type
- Most like sentence

### Type 4: Compound Basic Idea + Consequent
- Phrase 1: Compound b.i. (b.i. + c.i., NO cadence)
- Phrase 2: Consequent (return + c.i. → PAC)
- Most like period

## Spectrum Position

Sentence-like ← c.b.i.+cont | ant+cont | ant+cad | c.b.i.+cons → Period-like

## Key Distinction

Hybrids never begin with a presentation phrase. Instead, they use:
- Antecedent (with cadence)
- Compound basic idea (without cadence)
