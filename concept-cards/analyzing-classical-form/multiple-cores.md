# Quick Definition
A large development section may contain two cores: the first ending in a development key, the second closing with dominant harmony of the home key in preparation for the recapitulation.

# Core Definition
"If a core of the development ends in a development key, then a second core may follow, this one closing with dominant harmony of the home key, in preparation for the recapitulation" (p. 444). A second core "normally contains melodic-motivic material that differs from the first core." Multiple cores are normally used in large-scale works, with symphonic movements by Beethoven being especially likely to contain more than one core.

# Prerequisites
- **Core** — Must understand the single core before considering multiples
- **Development keys** — The first core ends in one of these

# Key Properties
1. First core always ends in a development key
2. Second core usually ends in the home key
3. Second core uses different melodic-motivic material
4. Normally found in large-scale works (symphonies, especially Beethoven)
5. Alternative to multiple cores: a retransition following a single core

# Construction / Recognition
## To Identify:
1. If the first core ends in a development key (not the home key), look for a second model-sequence process
2. Confirm the second core uses different material from the first
3. The second core should lead to home-key dominant

# Context & Application
Multiple cores represent the most expansive version of the development section. The choice between multiple cores (Plan 2) and a single core plus retransition (Plan 3) depends on the overall scope and dramatic pacing of the movement.
