# Multiple Cores

When a development section contains more than one core.

## Conditions for Second Core

If a core of the development ends in a development key, then a second core may follow, closing with dominant harmony of the home key in preparation for the recapitulation.

## Characteristics

- Second core normally contains melodic-motivic material differing from first core
- First core always ends in a development key
- Second core usually ends in the home key
- Multiple cores are normally used in large-scale works

## Typical Usage

- Symphonic movements by Beethoven are especially likely to contain more than one core
- Less common in chamber music and solo sonatas
- Reflects the greater scope and complexity of symphonic development sections

## Alternative to Second Core

Instead of a second core, a retransition may be added to bring the music back to the home key for the recapitulation.
