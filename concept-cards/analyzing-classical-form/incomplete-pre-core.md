# Quick Definition
A pre-core constructed from phrase functions that do not constitute a complete thematic unit, usually lacking a concluding function.

# Core Definition
An incomplete pre-core is "made up of one or two phrase functions that, taken as a whole, do not constitute a complete thematic unit" (p. 467). A concluding function is usually missing, though sometimes an initiation may be omitted instead. Pre-cores of this type tend to be relatively short.

# Prerequisites
- **Pre-core** — The broader category
- **Phrase functions** — Understanding initiating, medial, and concluding functions

# Key Properties
1. Does not constitute a complete thematic unit
2. Usually lacks a concluding function
3. Sometimes lacks an initiating function instead
4. Tends to be relatively short
5. Flows directly into the core without formal closure

# Construction / Recognition
## To Identify:
1. Check whether the pre-core has all three phrase functions (initiating, medial, concluding)
2. If missing the conclusion, it flows directly into the core
3. If missing the initiation, it begins directly with cadential or medial function

# Examples
**Example 13.6** (p. 467): Mozart, Symphony No. 36 "Linz" — pre-core begins with material from the subordinate theme's cadential area, transposed to A minor; lacks initiating function, beginning instead with a standing on the dominant leading to a cadential phrase.
