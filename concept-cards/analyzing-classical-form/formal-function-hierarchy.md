# Quick Definition
Formal functions operate at multiple levels of structure: the same phrase functions (presentation, antecedent, continuation, cadential) that construct themes also construct larger thematic functions like transitions, subordinate themes, and development cores, though in progressively looser expression.

# Core Definition
In Part I, themes (mostly main themes) are constructed out of phrase functions such as presentation, antecedent, continuation, and cadential. As we move beyond main themes, the same phrase functions are used to construct the other thematic functions of sonata form -- transition, subordinate theme, and development core -- though these functions usually acquire a looser formal expression. What distinguishes Caplin's approach from all prior approaches is this emphasis on identifying the constituent formal functions at all levels of structure throughout the entirety of the full-movement form.

# Prerequisites
- **Sentence** -- One of the theme types whose phrase functions appear at higher levels
- **Period** -- One of the theme types whose phrase functions appear at higher levels
- **Sonata form large-scale structure** -- The full-movement form where hierarchy operates

# Key Properties
1. Same phrase functions appear at all structural levels
2. Main theme: tight-knit, clearly defined expression of functions
3. Transition: looser, extended expression
4. Subordinate theme: loosest, expanded expression
5. Development core: very loose, sequential expression
6. This multi-level emphasis is the distinctive feature of Caplin's analytical approach

| Context | Expression of Phrase Functions |
|---------|-------------------------------|

| Transition | Looser, extended |
| Subordinate Theme | Loosest, expanded |
| Development Core | Very loose, sequential |

# Context & Application
The hierarchy of formal functions is one of the most important theoretical contributions of this textbook. By recognizing that the same functions (presentation, continuation, cadential, etc.) operate throughout a movement -- not just within the main theme -- the analyst gains a unified vocabulary for describing all parts of sonata form. The degree of looseness relative to the main theme becomes the primary measure of formal expression.
