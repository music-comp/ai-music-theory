# Quick Definition
A systematic five-step method for analyzing development sections: identify the core, find its end, analyze the pre-core, check for additional sections, and consider alternatives if no core is present.

# Core Definition
Caplin's analytical method (p. 448): Step 1 — look for a large-scale model (4-8 measures) sequenced at least once to identify a core. Step 2 — locate the HC or dominant arrival marking the core's structural end; the final boundary is where the standing on the dominant plays out. Step 3 — return to the beginning to analyze the pre-core. Step 4 — if the core closes in a development key, look for a second core or retransition. Step 5 — if no core can be identified, consider pseudo-core, transition-like, or subordinate-themelike units, or adopt an ad hoc approach.

# Prerequisites
- **Core** — The primary target of identification
- **Pre-core** — Analyzed after the core is located
- **Model-sequence technique** — The structural hallmark to look for

# Key Properties
1. Start by identifying the core (not the pre-core)
2. The core's model (4-8 measures) sequenced at least once is the key indicator
3. Work backward to analyze the pre-core after locating the core
4. Work forward from the core to find second cores or retransitions
5. If no core exists, use alternative analytical strategies

# Construction / Recognition
## Step-by-Step Method:
1. Look for large-scale model (4-8 measures) sequenced at least once
2. Find HC or dominant arrival at core's end; final boundary = end of standing on V
3. Return to beginning; pre-core = everything before the core
4. If core ends in development key: look for second core or retransition
5. If no core: consider pseudo-core, transition-like unit, subordinate-themelike unit, or ad hoc description

# Context & Application
This method provides a systematic entry point for what can be "extremely difficult" analysis (p. 484). When standard categories do not fit, flexibility is required: "be prepared to encounter situations that do not entirely conform" and "adopt an ad hoc approach" when needed.
