# Quick Definition
Recapitulation changes are classified as structural (harmonic-tonal, melodic-motivic, grouping, formal function) or ornamental (dynamics, instrumentation, register, texture), with structural changes motivated primarily by the recapitulation's different formal function.

# Core Definition
Caplin distinguishes two types (p. 499): Structural changes involve "harmonic-tonal organization, melodic-motivic material, grouping structure, and formal functions" and are "motivated primarily by fundamental differences in the function of the recapitulation, as compared with the exposition." Ornamental changes involve "dynamics, instrumentation, register, texture, accompanimental figuration, melodic embellishments, and the like" and are "motivated by general aesthetic concerns for variety." The chapter focuses on structural changes since they most directly affect formal organization.

# Key Properties
1. Structural: harmonic-tonal, melodic-motivic, grouping, formal function
2. Ornamental: dynamics, instrumentation, register, texture, embellishment
3. Structural changes motivated by different formal function in recapitulation
4. Ornamental changes motivated by aesthetic variety

## To Identify:

3. Ask why each structural change was made (functional motivation)

# Context & Application
Understanding the distinction between structural and ornamental helps prioritize analytical attention: structural changes reveal how the recapitulation's different formal function shapes the music, while ornamental changes reflect the composer's expressive goals.
