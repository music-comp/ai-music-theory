# Quick Definition
A hybrid type where an antecedent phrase is followed by a phrase supported entirely by an expanded cadential progression (ECP), projecting exclusively cadential function with minimal or no continuational characteristics.

# Core Definition
In this hybrid, the first phrase is a standard antecedent closing with a weak cadence. The second phrase displays minimal characteristics of continuation function: the music continues to group itself into 2-m. units (no fragmentation), the harmonic rhythm may even slow down, and the phrase is supported entirely by an ECP. Since the phrase lacks continuational features, it is labeled exclusively "cadential." Caplin places this type as somewhat more periodic on the hybrid spectrum, since continuational traits are missing.

# Prerequisites
- **Antecedent phrase** — Provides the opening function with weak cadential closure
- **Expanded cadential progression** — The harmonic foundation of the entire second phrase

# Key Properties
1. First phrase: standard antecedent with weak cadence
2. Second phrase: entirely supported by ECP, exclusively cadential function
3. No fragmentation in second phrase (maintains 2-m. grouping)
4. No harmonic acceleration (may even decelerate)
5. Basic idea appears only once
6. Rarely modulates (no space for modulation between HC and ECP)

# Construction / Recognition
## To Identify:
1. Confirm the first phrase is a standard antecedent with weak cadence
2. Check for an ECP underlying the entire second phrase
3. Verify absence of continuation characteristics (no fragmentation, no acceleration)
4. Distinguish from ant + cont by the lack of continuational features

# Context & Application
This hybrid type is somewhat more periodic in character since continuational traits are missing. It rarely modulates because there is simply no place for a modulating progression between the weak cadence ending the antecedent (which must be in the opening key) and the immediately following ECP.

# Examples
**Example 1** (p. 123): Beethoven, Violin Sonata Op. 12/1, iii, mm. 1-8 — antecedent with HC at m. 4, followed by new material over ECP with no fragmentation.
**Example 2** (p. 129): Haydn, String Quartet Op. 64/4, ii, mm. 1-8 — antecedent is a "mini-sentence"; second phrase is entirely cadential with no continuation.

# Common Errors
- **Error**: Labeling the second phrase "continuation" when it has an ECP
  **Correction**: If there is no fragmentation, no acceleration, and the phrase sits on an ECP, it is exclusively cadential

# Common Confusions
- **Confusion**: Confusing this with the continuation => cadential label
  **Clarification**: In a sentence context, an ECP-supported phrase usually shows continuational features too (continuation => cadential). Following an antecedent, the same type of phrase often lacks these features and is purely cadential.
