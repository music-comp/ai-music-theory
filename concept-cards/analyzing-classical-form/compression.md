# Quick Definition
Compression occurs when a formal function is expressed in fewer measures than would normally be expected, achieving its purpose more quickly while retaining essential elements in condensed form. Combined with extended units, compression creates the asymmetry characteristic of loose organization.

# Core Definition
A formal unit is compressed when it occupies fewer measures than standard, achieves its function more quickly, and retains essential elements in condensed form. Compression contrasts with extension, where a function takes longer than expected. In transitions, compression often occurs in the continuation function, which may be reduced to a single bar leading quickly to cadential function. When combined with an extended or redundantly repeated presentation, the compressed continuation creates dramatic contrast in proportions and produces asymmetrical grouping -- both criteria of loose organization. The resulting urgency contributes to the transition's forward momentum toward its dominant goal (Caplin, Ch. 11, pp. 333, 346).

# Prerequisites
- **Continuation** -- The function most commonly compressed in transitions
- **Tight-knit vs. loose organization** -- Compression is a criterion of loosening

# Key Properties
1. Function expressed in fewer measures than standard
2. Essential elements retained but condensed
3. Contrasts with extension (which lengthens)
4. Creates asymmetry when combined with extended units
5. Produces urgency and forward momentum
6. Often affects continuation function in transitions

# Construction / Recognition
## To Identify:
1. Compare the length of each phrase function to norms (e.g., 2-bar continuation vs. 4-bar presentation)
2. A continuation of 1-2 bars following a 4+ bar presentation suggests compression
3. Check whether essential continuation features (fragmentation, harmonic acceleration) are present but condensed
4. Note the resulting asymmetry in grouping structure

# Context & Application
Compression is particularly effective in transitions, where the compressed continuation drives urgently toward the half cadence. It frequently appears alongside redundant repetition of the presentation, creating a dramatic contrast: an overly long beginning followed by an abbreviated middle, producing the asymmetrical proportions characteristic of loose formal organization.

# Examples
**Example 1** (p. 333): Beethoven, Piano Sonata Op. 49/1, i, mm. 9-15 -- Transition with asymmetrical grouping (4+3); the continuation phrase is compressed while the half-cadential progression is slightly expanded.
**Example 2** (p. 346): Haydn, Piano Trio H. 30, i, mm. 16-26 -- Redundant repetition of presentation followed by compressed continuation (mm. 24-26) leading to home-key HC.

# Common Errors
- **Error**: Assuming compression means the function is missing or incomplete
  **Correction**: Compression retains essential elements; the function is expressed, just more quickly than expected
