# Quick Definition
Contrary to the stereotype of the "masculine" main theme, classical main themes frequently exhibit hesitancy, uncertainty, and marked discontinuities in rhythm, texture, and dynamics. It is often not until the transition that the movement seems to "get under way."

# Core Definition
Since A. B. Marx proposed the distinction between a "masculine" main theme and a "feminine" subordinate theme, listeners have assumed main themes are aggressively assertive. While some (especially symphonic or Sturm und Drang works) conform to this stereotype, the broader repertory shows main themes frequently exhibit **hesitancy and uncertainty**: sudden changes in texture, dynamics, and articulation, along with marked discontinuities in rhythmic momentum. It is often not until the transition that the movement seems to "get under way." Main themes can also be lyrical and songlike (Caplin, Ch. 10, pp. 322-323).

# Key Properties
1. The masculine/feminine stereotype is rejected as a generalization
2. Main themes frequently feature hesitancy and discontinuity
3. Sudden changes in texture, dynamics, articulation are common
4. The transition often provides the first sense of momentum
5. Some main themes are lyrical; some juxtapose masculine and feminine styles

# Context & Application
This observation has practical consequences: do not confuse a hesitant main theme with an introduction. Despite instabilities, the main theme still contains sufficient tonal, cadential, and phrase-structural solidity to function as the true formal beginning.
