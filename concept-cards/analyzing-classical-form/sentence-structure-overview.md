# Sentence Structure Overview

The sentence structure can be visualized as a hierarchy of formal functions at multiple levels.

## Hierarchical View

**Theme Level (8 measures)**:
Sentence = Presentation (4m) + Continuation (4m)

**Phrase Level**:
- Presentation = Basic idea (2m) + Repetition (2m)
- Continuation = Fragmentation + Cadence

**Idea Level**:
- Basic idea: Initial melodic-motivic statement
- Cadential idea: Concluding formulaic material

## Functional Progression

| Measures | Function | Character |
|----------|----------|-----------|
| 1-2 | Basic idea | Characteristic, initiating |
| 3-4 | Repetition | Reinforcing, still initiating |
| 5-6 | Fragmentation | Destabilizing, medial |
| 7-8 | Cadential | Conventional, concluding |

## Harmonic Foundation

- Mm. 1-4: Tonic prolongation
- Mm. 5-6: Harmonic acceleration
- Mm. 7-8: Cadential progression

## Formal Functions

Three temporal functions:
1. **Presentation** = Beginning
2. **Continuation** = Middle
3. **Cadential** = End (fused with continuation)

## Key Insight

The sentence projects a clear trajectory from beginning through middle to end, giving it forward-driving character.
