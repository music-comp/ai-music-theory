# Return of the Basic Idea

The **return of the basic idea** signals the start of the consequent phrase in a period. This return projects the sense that the consequent "repeats" the antecedent.

## Types of Return

Like the repetition in a sentence's presentation, the return can take various forms:

### Exact Return
Most typical. The basic idea is supported by the same harmony as at the opening (mm. 1-2).

### Dominant Version Return
The basic idea returns with dominant harmonic support, creating a statement-response relationship across the period (ant: I-V, cons: V-I).

### Sequential Return
The basic idea is transposed to another scale degree, usually up a step into the supertonic region. This creates a less stable expression.

### Varied Return
Extensive "variation" technique may embellish the basic idea while the fundamental melodic profile still projects a clear sense of return.

## Distinction: Repetition vs. Return

- **Repetition**: Restatement occurring immediately (without intervening material)
- **Return**: Restatement occurring after intervening contrasting material

The consequent **repeats** the antecedent by bringing a **return** of the basic idea (separated by the contrasting idea of the antecedent).

## Harmonic Considerations

Different harmonic support for the return may:
- Delay completion of tonic prolongation
- Create statement-response patterns across the period
- Add harmonic interest to the consequent
