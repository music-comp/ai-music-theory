# Quick Definition
The b.i. returns at the start of the consequent phrase (mm. 5-6) to project the sense that the consequent "repeats" the antecedent. Return types: exact (most typical, same harmony), dominant version, sequential (transposed, usually up a step), or varied (embellished). Distinguished from repetition: return occurs after intervening contrasting material.

# Core Definition
In order for the consequent phrase to project the sense of "repeating the antecedent," it begins by bringing back the original basic idea. This return can take a variety of forms, analogous to those in the presentation. Most typically, the consequent begins with an exact return of the basic idea supported by the same harmony as in the opening two bars (p. 102). On occasion, the b.i. takes the form of a "dominant version" (ant: I-V, cons: V-I) (p. 104). Less stably, the b.i. may be restated sequentially, usually transposed up a step (p. 105).

# Key Properties
1. Signals start of consequent phrase (mm. 5-6)
2. Projects the sense that the consequent "repeats" the antecedent
3. Exact return: same harmonic support (most typical)
4. Dominant version: b.i. on V instead of I (statement-response across the period)
5. Sequential return: transposed, usually up a step to supertonic region (less stable)
6. Varied return: extensive embellishment while fundamental profile remains clear
7. Distinguished from repetition: return occurs after contrasting material

# Construction / Recognition
## To Identify:
1. Look for the b.i. material at mm. 5-6
2. Determine the type of return (exact, dominant, sequential, varied)
3. Note harmonic changes relative to the original b.i.

# Context & Application
The return of the b.i. is what distinguishes the period from hybrid themes. In Caplin's system, if the consequent does NOT begin with similar material, the theme is classified as a hybrid, not a period.

# Examples
**Example 1** (p. 103, Ex. 3.8): Haydn, H. 27, iii -- exact return with same harmony.

**Example 2** (p. 104, Ex. 3.11): Haydn, H. 28, i -- dominant version return (ant: I-V, cons: V-I).

**Example 3** (p. 105, Ex. 3.12): Mozart, K. 576, i -- sequential return up a step to supertonic.

**Example 4** (p. 103, Ex. 3.10): Mozart, K. 333, ii -- varied return with extensive embellishment.

# Common Errors
- **Error**: Expecting an identical return in all cases
  **Correction**: The return may be dominant version, sequential, or extensively varied

# Common Confusions
- **Confusion**: Confusing "return" with "repetition"
  **Clarification**: Repetition is immediate (sentence); return is after intervening material (period)
