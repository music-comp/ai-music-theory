# Quick Definition
The ascending stepwise sequence is the most popular sequential pattern used within codas, naturally projecting an increasingly intense emotional excitement as the model rises by step with each repetition.

# Core Definition
Prominent tonicizations and sequential progressions frequently occur early in a coda to provide harmonic contrast between the end of the recapitulation and the end of the coda, both of which emphasize the home-key tonic. The ascending stepwise pattern is the most popular sequence within codas because it naturally projects an increasingly intense emotional excitement. Although model-sequence technique in a coda may suggest the core of a development, the sequencing is nonmodulatory and the harmonies remain closely bound to the home key.

# Prerequisites
- Understanding of the coda as an after-the-end function following the recapitulation
- Knowledge of model-sequence technique

# Key Properties
- Model rises by step with each repetition (ascending stepwise pattern)
- Naturally projects increasingly intense emotional excitement
- Provides harmonic contrast within the home-key framework
- Sequencing is nonmodulatory, unlike development cores
- Harmonies remain closely bound to the home key
- Commonly appears early in the coda

# Construction / Recognition
Look for a sequential passage early in the coda where the model is transposed upward by step with each repetition. The passage will build energy and momentum while remaining harmonically anchored to the home key, unlike the modulatory sequences of a development core.

# Context & Application
The ascending stepwise sequence serves the coda's need to create variety and build energy toward the final cadential goal without undermining the home-key stability that defines the after-the-end function. It frequently appears at the start of a coda, where the music has just concluded the recapitulation's emphasis on tonic and needs to create some harmonic motion before arriving at the coda's own concluding PAC.

# Examples
- Beethoven, String Quartet in F, Op. 18, No. 1, i, mm. 274ff.: ascending scale pattern projects overall harmony progressing through flat-side regions before leading to home-key dominant
- General pattern: coda starts with model-sequence passage using ascending stepwise motion, building toward climactic cadential arrival

# Common Errors
- Mistaking coda sequential passages for development-like instability when they remain firmly in the home key
- Overlooking the ascending stepwise pattern as a distinctive marker of coda sections

# Common Confusions
- Model-sequence technique in a coda is NOT the same as a development core -- the coda's sequences are nonmodulatory and harmonically bound to the home key, even if they superficially resemble developmental passages
