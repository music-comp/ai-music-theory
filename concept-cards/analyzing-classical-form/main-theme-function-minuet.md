# Quick Definition
Main-theme function in a modulating minuet A section arises through initial tonic-stabilizing progressions. Its expression ranges from minimal (no home-key cadence before modulation) to strongest (an early authentic cadence in the home key before the section ends).

# Core Definition
Main-theme function in a modulating A section always arises by virtue of initial tonic-stabilizing progressions of the home key. If the music modulates before any home-key cadence, main-theme expression will be minimal. If an HC appears, expression is moderate. The sense of main-theme function is strongest when the opening music closes with a PAC -- an early authentic cadence -- before the end of the section (Caplin, pp. 636-637).

# Prerequisites
- **Minuet exposition (A section)** -- The section where main-theme function appears

# Key Properties
1. Minimal: modulates before any home-key cadence (sentential form likely)
2. Moderate: opens with home-key HC (periodic form likely)
3. Strongest: early authentic cadence (home-key PAC before section ends)
4. In nonmodulating A sections: exclusively main-theme function

# Construction / Recognition
## To Identify:
1. Look for tonic-stabilizing progressions at the section's opening
2. Determine what cadential articulation occurs in the home key
3. Assess the relative "weight" of home-key vs. subordinate-key material

# Context & Application
The degree of main-theme expression has analytical consequences: stronger main-theme function allows for clearer differentiation of thematic functions within the A section.

# Examples
**Example 1** (p. 636): If the music modulates before any home-key cadence, main-theme expression is minimal and the form is likely sentential.
