# Quick Definition
Antecedent function is an initiating formal function that presents fundamental melodic material (basic idea + contrasting idea) and closes with weak cadential punctuation (HC or IAC), creating expectation for stronger closure in the consequent.

# Core Definition
Antecedent function creates a solid structural beginning for a period by establishing the fundamental melodic-motivic content and achieving partial (weak) cadential closure. Like presentation function, antecedent function expresses the temporal sense of "beginning," but unlike presentation, it achieves cadential closure (albeit weak). The antecedent presents the basic idea followed by a contrasting idea leading to an HC or IAC. The period does not bring a specific medial formal function; it contains only the two functions of antecedent (initiating) and consequent (concluding) (pp. 95-97).

# Prerequisites
- **Period structure overview** — Antecedent function is one of two functions in the period
- **Basic idea** — The antecedent begins with a basic idea
- **Contrasting idea** — Follows the basic idea in the antecedent

# Key Properties
1. Initiating formal function (expresses "beginning")
2. Presents the basic idea followed by a contrasting idea
3. Closes with a weak cadence (HC or IAC, never PAC)
4. Creates expectation for stronger closure
5. Unlike presentation function, achieves cadential closure
6. Unlike presentation, uses contrasting rather than repeating material
7. In compound periods, the compound antecedent is itself structured as a simple theme

# Construction / Recognition
## To Identify:
1. Look for a phrase that begins with a basic idea (2 m.)
2. Check that the basic idea is followed by contrasting (not repeated) material
3. Verify weak cadential closure at the end (HC or IAC)
4. Confirm that a consequent follows with stronger closure

# Context & Application
Antecedent function is one of two formal functions in the period (the other being consequent). It makes up the first phrase. Its weak cadence creates the fundamental motivation for the consequent to follow with stronger closure. In compound periods, compound antecedent function is expressed by an 8-m. unit that is itself structured as a simple theme (sentence, or hybrid antecedent + continuation or c.b.i. + continuation), closing with a weak cadence (usually HC) at m. 8.

# Examples
**Example 1** (p. 96, Ex. 3.1): Mozart, K. 525, ii, mm. 1-4 -- b.i. (mm. 1-2), contrasting idea leading to HC (mm. 3-4); antecedent function clearly initiating.

## Contrasts With
- **Consequent function** — Concluding vs. initiating; strong vs. weak cadence
- **Presentation function** — No cadence, repetition of b.i. vs. weak cadence, contrast after b.i.
- **Continuation function** — Medial function vs. initiating function

# Common Errors
- **Error**: Confusing antecedent function with presentation function because both are initiating
  **Correction**: Presentation repeats the b.i. with no cadence; antecedent follows b.i. with contrasting idea and weak cadence

# Common Confusions
- **Confusion**: Thinking any first phrase of a two-phrase theme has antecedent function
  **Clarification**: Antecedent function specifically requires b.i. + c.i. + weak cadence; a presentation phrase (b.i. + repetition, no cadence) has presentation function, not antecedent function
