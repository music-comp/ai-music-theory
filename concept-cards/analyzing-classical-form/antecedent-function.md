# Antecedent Function

**Antecedent function** is an initiating formal function that presents fundamental melodic material and closes with weak cadential punctuation.

## Characteristics

Antecedent function:
- Presents the basic idea
- Introduces contrasting material
- Achieves partial (weak) closure
- Creates expectation for stronger closure

## Temporal Meaning

Like presentation function, antecedent function expresses **beginning**:
- Initiates the thematic process
- Establishes melodic-motivic content
- But unlike presentation, achieves cadential closure

## Distinction from Presentation

Both are initiating functions, but:
- **Presentation**: No cadence, basic idea repeated
- **Antecedent**: Weak cadence, basic idea followed by contrast

## In the Period

Antecedent function makes up the first phrase of a period:
- Establishes the material
- Creates incomplete closure
- Motivates the consequent

## Compound Antecedent

In compound periods, the compound antecedent:
- Occupies 8 measures
- Is itself structured as a simple theme
- Still closes with weak cadence
