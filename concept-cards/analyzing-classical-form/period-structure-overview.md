# Period Structure Overview

The period structure can be visualized as a symmetrical design based on cadential differentiation.

## Hierarchical View

**Theme Level (8 measures)**:
Period = Antecedent (4m) + Consequent (4m)

**Phrase Level**:
- Antecedent = Basic idea (2m) + Contrasting idea (2m) → weak cadence
- Consequent = Basic idea returns (2m) + Contrasting idea (2m) → strong cadence

## Structural Symmetry

| Measures | Function | Cadence |
|----------|----------|---------|
| 1-2 | Basic idea | — |
| 3-4 | Contrasting idea | HC or IAC |
| 5-6 | Basic idea (return) | — |
| 7-8 | Contrasting idea | PAC |

## Formal Functions

Two functions only:
1. **Antecedent** = Beginning/Initiating
2. **Consequent** = End/Concluding

No distinct medial function in the period.

## Cadential Requirement

The essential relationship:
- Antecedent: Weak cadence (HC or IAC)
- Consequent: Strong cadence (PAC)

This weak-to-strong progression defines period form.

## Key Insight

The period projects balance and repose through its symmetrical construction and the satisfying completion of cadential expectation.
