# Quick Definition
All conventional theme types can be labeled by their constituent phrase functions, revealing that each combines an initiating, medial, and/or concluding function in a temporally logical (syntactical) order.

# Core Definition
Caplin emphasizes that themes should be understood through their phrase functions: the period is "antecedent + consequent," the sentence is "presentation + continuation" (the latter fusing continuation and cadential functions). The hybrids are similarly labeled. Phrase functions divide into temporal categories: initiating (presentation, antecedent, c.b.i.), medial (continuation), and concluding (cadential, consequent). Conventional themes always arrange these in syntactically appropriate order, respecting the temporal logic of beginning, middle, and end.

# Prerequisites
- **Sentence** — Presentation + continuation
- **Period** — Antecedent + consequent
- **Hybrid themes** — Four additional combinations

# Key Properties
1. All six conventional theme types can be described as combinations of phrase functions
2. Functions fall into three temporal categories: initiating, medial, concluding
3. Syntactically appropriate themes respect temporal ordering
4. Combinations like "consequent + presentation" or "continuation + antecedent" are nonsyntactical
5. The continuation phrase of the sentence fuses medial (continuation) and concluding (cadential) functions

# Construction / Recognition
## To Identify:
1. Label each 4-m. phrase with its function
2. Verify the combination follows temporal logic (initiating -> medial/concluding)
3. If the ordering is violated, the combination is nonsyntactical

# Context & Application
This approach is fundamental to Caplin's analytical method. Rather than forcing themes into rigid categories, the phrase-function approach reveals the underlying temporal logic and allows for nuanced analysis of hybrids and ambiguous cases.

# Common Errors
- **Error**: Trying to label all second phrases as "consequent" (the traditional approach)
  **Correction**: Use the specific functional label (continuation, cadential, consequent) that matches the actual characteristics

# Common Confusions
- **Confusion**: Thinking any combination of phrase functions is valid
  **Clarification**: Only syntactically appropriate (temporally logical) combinations occur in the repertory
