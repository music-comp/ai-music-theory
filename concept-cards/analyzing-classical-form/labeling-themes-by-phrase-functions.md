# Labeling Themes by Phrase Functions

Themes can be labeled in terms of their constituent **phrase functions**. This approach highlights the temporal logic underlying formal organization.

## Theme Types as Phrase Function Combinations

| Theme Type | Phrase Functions |
|------------|------------------|
| Sentence | Presentation + Continuation |
| Period | Antecedent + Consequent |
| Hybrid 1 | Antecedent + Continuation |
| Hybrid 2 | Antecedent + Cadential |
| Hybrid 3 | Compound Basic Idea + Continuation |
| Hybrid 4 | Compound Basic Idea + Consequent |

## Temporal Categories

Phrase functions divide into temporal categories:

**Initiating functions:**
- Presentation
- Antecedent
- Compound basic idea

**Medial function:**
- Continuation

**Concluding functions:**
- Cadential
- Consequent

## Syntactical Appropriateness

Conventional theme types bring a **syntactically appropriate** combination of functions:
- The logical ordering of beginning, being-in-the-middle, and ending is respected

## Nonsyntactical Combinations

Some combinations would be temporally illogical:
- "Consequent + Presentation" (ending before beginning)
- "Continuation + Antecedent" (middle before beginning)

These combinations do not occur in the repertoire because they violate temporal logic.
