# Quick Definition
Both are 8-m. themes with two 4-m. phrases, beginning with a 2-m. b.i. Key differences: sentence has one cadence, period has two; sentence repeats b.i. immediately, period returns b.i. after contrasting material; sentence projects mobility, period projects balance.

# Core Definition
Similarities: both are normatively 8 measures, divided into two 4-m. phrases; both end with a cadence; both begin with a 2-m. basic idea that is restated at some point (p. 114). Differences: the sentence has one cadence, the period has two; the sentence can end with any cadence type (PAC, IAC, HC), the period cannot end with HC; in the sentence, the b.i. is repeated within the presentation, in the period, the b.i. returns at the start of the consequent (p. 114-115). The sentence projects the character of mobility and forward drive; the period projects the character of balance and repose (p. 115).

# Prerequisites
- **Sentence** — One of the two theme types being compared
- **Period** — The other theme type

# Key Properties
1. Similarities: 8 m., two 4-m. phrases, begin with b.i., end with cadence
2. Cadences: sentence = 1; period = 2
3. Ending cadences: sentence = PAC/IAC/HC; period = PAC/IAC (never HC)
4. B.i. restatement: sentence = repeated (mm. 3-4); period = returns (mm. 5-6)
5. Aesthetic: sentence = mobility/drive; period = balance/repose
6. Presentation is open-ended; antecedent provides partial closure
7. Continuation destabilizes; consequent parallels

# Construction / Recognition
## To Distinguish:
1. Check mm. 3-4: repetition of b.i. = sentence; contrasting material with cadence = period
2. Count cadences: one = sentence; two = period
3. Check for b.i. return at m. 5: present = period

# Context & Application
It is not always possible to predict from the opening b.i. whether a sentence or period will follow. The determining factor is what happens in mm. 3-4: if the b.i. is repeated, a sentence is forming; if new material with a cadence appears, a period is forming.

# Common Errors
- **Error**: Labeling any two-phrase theme as either sentence or period
  **Correction**: Hybrid themes (Ch. 4) exist for cases that don't fit either type

# Common Confusions

  **Clarification**: Some themes are genuinely ambiguous, and hybrid forms exist
