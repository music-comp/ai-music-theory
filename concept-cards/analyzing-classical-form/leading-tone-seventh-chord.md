# Quick Definition
A seventh chord built on the leading tone (VII7) that has dominant function when resolving to tonic but loses this function in sequential contexts when progressing to non-tonic harmonies.

# Core Definition
"The leading-tone diminished triad in first inversion (VII6) and the leading-tone seventh chord (VII7 and its three inversions) also have dominant function when they resolve to tonic harmony. (These harmonies are not considered dominants when, in some sequential situations, they progress to nontonic harmonies, such as III.)" (p. 31). The leading-tone seventh chord's function is context-dependent, hinging on whether it resolves to tonic.

# Prerequisites
- **Dominant function** — VII7 can express dominant function
- **Scale degree** — Built on scale degree 7 (the leading tone)

# Key Properties
1. Forms: VII7, VII6/5, VII4/3, VII4/2
2. Fully diminished (vii°7) common in minor; half-diminished (viiø7) diatonic in major
3. Has dominant function ONLY when resolving to tonic
4. Loses dominant function in sequential contexts (e.g., VII-III)
5. VII7/V (as diminished seventh) is the most typical V/V-type pre-dominant
6. Can substitute for V in certain prolongational contexts

# Construction / Recognition
## To Identify:
1. Locate a seventh chord built on scale degree 7
2. Determine the quality (fully diminished or half-diminished)
3. Check the resolution: to tonic (dominant function) or to non-tonic (non-functional)
4. In sequential contexts, classify as pattern element rather than functional dominant

# Context & Application
The leading-tone seventh chord functions as dominant when resolving to I, appears in prolongational progressions as subordinate harmony, and may appear in sequential progressions without dominant function. The fully-diminished form (°7) is particularly associated with V/V function (VII7/V), serving as the most typical pre-dominant of the raised-fourth-degree category.

# Common Errors
- **Error**: Assuming VII always has dominant function
  **Correction**: VII in sequences progressing to non-tonic harmonies (like III) is not dominant

# Common Confusions
- **Confusion**: Confusing VII7 (dominant function) with VII7/V (pre-dominant function)
  **Clarification**: VII7 resolving to I is dominant; VII7/V resolving to V is pre-dominant
