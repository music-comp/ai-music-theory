# Quick Definition
The recapitulation resolves the tonal conflict by bringing back exposition material firmly in the home key. Main theme, transition, and subordinate theme return in order, with the transition adjusted to remain in the home key and the subordinate theme transposed.

# Core Definition
The recapitulation resolves the tonal conflict of the movement by bringing back most of the material of the exposition firmly in the context of the home key. The start is signaled by the return of the main theme's basic idea in the home key. The thematic units return in order but undergo **structural changes** (harmonic-tonal and phrase-structural) and **ornamental changes** (instrumentation, dynamics, texture). The transition must be adjusted to remain in the home key; the subordinate theme is transposed to the home key. The final PAC of the recapitulation must provide cadential confirmation of the home key (Caplin, Ch. 9, pp. 301-305).

# Prerequisites
- **Sonata form overview** -- Recapitulation is the third required section

# Key Properties
1. Main theme usually returns without significant structural alteration
2. Transition must be adjusted to avoid modulation (often emphasizes subdominant region)
3. Subordinate theme transposed into home key
4. Final PAC must confirm the home key
5. Haydn substantially reworks the entire recapitulation; Mozart and Beethoven bring subordinate themes largely unaltered

# Construction / Recognition
## To Identify:
1. Return of main-theme basic idea in the home key signals the start
2. Compare bar by bar with the exposition, noting structural and ornamental changes
3. The principal analytical method is comparison
4. Ask "why" about each change to suggest compositional rationales

# Context & Application
The subdominant emphasis early in the recapitulation's transition serves a dual purpose: it makes the return to tonic for the subordinate theme sound fresh, and the tonicized subdominant easily becomes the pre-dominant leading to the home-key dominant that ends the transition.

# Examples
**Example 1** (p. 302): Beethoven, Op. 2, No. 1, i, mm. 101-119 -- Main theme returns structurally unchanged; transition adjusted to remain in F minor with subdominant emphasis (Bb minor).

# Common Errors
- **Error**: Expecting the recapitulation to be an exact transposition of the exposition
  **Correction**: Structural and ornamental changes are the norm; the transition is always adjusted

# Common Confusions
- **Confusion**: Assuming all composers treat the recapitulation the same way
  **Clarification**: Haydn almost always effects major structural changes; Mozart and Beethoven typically keep the subordinate theme largely intact
