# Quick Definition
Pre-core/core technique is a frequent mode of organizing development sections, where a pre-core of lesser intensity leads to a core featuring a large model that is sequenced, fragmented, and driven toward an HC and standing on the dominant.

# Core Definition
The **core** of a development establishes a relatively large-sized model (4-8 mm.), which is sequenced one or more times. Subsequent fragmentation leads to an HC (or dominant arrival) of either the home key or a development key, after which a standing on the dominant appears. The core projects emotional instability, restlessness, and dramatic conflict. A **pre-core** usually precedes the core as a passage of lesser emotional intensity. The grouping structure of a core often resembles an extended sentence, but the model and sequence do not prolong tonic harmony, so they cannot form a genuine presentation (Caplin, Ch. 9, pp. 295-296).

# Prerequisites
- **Sonata form overview** -- Must understand the role of the development section
- **Model-sequence technique** -- The core is built on model-sequence procedure

# Key Properties
1. Core: large model (4-8 mm.) + sequence(s) + fragmentation + HC + standing on the dominant
2. Pre-core: lesser emotional intensity, often sounds like presentation function
3. Core's grouping resembles an extended sentence but is NOT a genuine sentence
4. The model-sequence does not prolong tonic, so no genuine presentation function exists
5. Pre-core is often structurally incomplete (no cadence)
6. If HC is in the home key, recapitulation normally follows; if in a development key, more material usually follows

# Construction / Recognition
## To Identify:
1. Find the relatively large model that is then sequenced -- this marks the beginning of the core
2. Material preceding this model is the pre-core
3. After the sequence, listen for fragmentation leading to an HC or dominant arrival
4. The final standing on the dominant marks the end of the development

# Context & Application
Development sections are considerably less conventional in organization than expositions. While pre-core/core technique appears frequently, one cannot predict in advance which components a given development may contain.

# Examples
**Example 1** (p. 296): Beethoven, Op. 2, No. 1, i, mm. 49-55 -- Pre-core with basic idea in subordinate key, extended; structurally incomplete, suggesting only presentation function.
**Example 2** (p. 297): Same work, mm. 55-81 -- Core with 8-m. model based on subordinate-theme material, incomplete sequence, fragmentation through progressively smaller models (2 mm., then 1 m.).

## Related
- **Sentence** -- Core resembles but is NOT a sentence
## Contrasts With
- **Sentence** -- A sentence has genuine presentation with tonic prolongation; a core does not

# Common Errors
- **Error**: Labeling the core's model-sequence as a "presentation"
  **Correction**: Without tonic prolongation, the model-sequence cannot constitute genuine presentation function

# Common Confusions
- **Confusion**: Treating the standing on the dominant's grouping structure as a sentence
  **Clarification**: The lack of harmonic activity and cadential articulation completely rules out the sentence label
