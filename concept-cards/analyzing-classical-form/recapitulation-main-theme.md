# Quick Definition
The main theme in the recapitulation most often returns without significant structural alterations, though ornamental changes (dynamics, rhythm, accompaniment) are likely. The most significant possible structural change involves the omission of the theme's closing cadence, since cadential confirmation of the home key is no longer required.

# Core Definition
Most often, the main theme returns without any significant structural alterations. Ornamental changes of some kind, however, are likely to occur, especially in chamber and orchestral genres: more emphatic rhythmical expression, greater dynamic intensity, or different accompanimental placement. The most significant structural change involves the main theme's closure. In the exposition, the main theme is required to end with a cadence so that the home key can be confirmed prior to being abandoned in favor of the subordinate key. In the recapitulation, the home key will necessarily become confirmed in the course of the subordinate theme, so a cadence at the end of the main theme is no longer required and may sometimes be omitted.

# Key Properties
1. Usually returns without significant structural alterations
2. Ornamental changes are likely (dynamics, rhythm, accompaniment)
3. Most significant structural change: possible omission of closing cadence
4. Cadence no longer required because subordinate theme will confirm home key
5. Ornamental changes especially prominent in chamber and orchestral genres

# Construction / Recognition
## To Analyze:
1. Compare main theme in recapitulation with exposition version bar by bar
2. Note ornamental changes (dynamics, rhythm, register, articulation)
3. Check whether the closing cadence is preserved, altered, or omitted
4. Assess whether any structural changes affect grouping or formal functions

# Examples
**Example** (p. 302): Beethoven, Op. 2, No. 1, i, mm. 101-108 -- main theme returns structurally unchanged; principal ornamental differences include more emphatic rhythmical expression due to greater dynamic intensity and placement of accompanimental chords on strong metrical positions in the continuation.
