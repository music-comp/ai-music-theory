# Quick Definition
A nonconventional main theme cannot be easily categorized as sentence, period, hybrid, or small ternary, yet it usually maintains tight-knit organization relative to later thematic regions. First-movement forms particularly favor nonconventional main themes. Analysis should proceed bottom-up.

# Core Definition
Many sonata forms begin with main themes that are **nonconventional** -- they cannot be easily accommodated by standard categories. First-movement forms are particularly likely to feature them (slow-movement and finale themes are usually conventional). Although nonconventionality is a criterion of loose organization, such themes are usually more tightly knit than subsequent units. The distinction between nonconventional and "deviant conventional" is not always clear-cut. Categories include: eight-measure themes, tonic pedal/fanfare gestures, omission of initiating function, large-scale presentation, and loose organization (Caplin, Ch. 10, pp. 310-319).

# Key Properties
1. Cannot be classified as sentence, period, hybrid, or small ternary
2. First movements particularly favor nonconventional organization
3. Usually still more tightly knit than subsequent thematic units
4. Many are still eight measures long
5. Component units usually exhibit identifiable formal functionality

# Construction / Recognition
## To Identify:
1. Use a **bottom-up** approach (not top-down)
2. First consider the harmonic organization
3. Group material into basic units on the surface
4. Establish higher-level groupings embracing lower-level ones
5. Assign formal function labels (initiating, medial, concluding, or more specific ones)
6. Accept that the functions may not organize in standard ways

# Context & Application
Nonconventional themes demonstrate that formal functionality exists even when standard theme types do not. The component functions (basic idea, continuation, cadential) are typically identifiable; what makes the theme nonconventional is that these functions do not combine in standard ways.

# Examples
**Example 1** (p. 312): Haydn, Op. 74/3, iv, mm. 1-8 -- 8-m. theme with 2+3+3 grouping; sentential but not a sentence.
**Example 2** (p. 312): Mozart, K. 504, i, mm. 37-45 -- Introduction directly to continuation, bypassing initiating function.
**Example 3** (p. 314): Haydn, Symphony No. 97, i, mm. 14-25 -- Fanfare gestures over tonic pedal.

# Common Errors
- **Error**: Forcing a nonconventional theme into a standard category
  **Correction**: Accept nonconventionality and describe the actual functional succession

# Common Confusions
- **Confusion**: Assuming nonconventional means "formless" or lacking function
  **Clarification**: Component functions are usually identifiable; only their combination is nonstandard
