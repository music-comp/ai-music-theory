# Analyzing a Recapitulation

The methodology for analyzing a recapitulation through comparison with the exposition.

## Basic Approach

Begin analysis by comparing the recapitulation bar by bar with the exposition, identifying any changes.

## Types of Changes

### Structural Changes
Involve:
- Harmonic-tonal organization
- Melodic-motivic material
- Grouping structure
- Formal functions

Motivated by fundamental differences in function between recapitulation and exposition, or by development section content.

### Ornamental Changes
Involve:
- Dynamics
- Instrumentation
- Register
- Texture
- Accompanimental figuration
- Melodic embellishments

Motivated by aesthetic concerns for variety and particular expressive values.

## Key Questions

When making comparison:
- What changes were made?
- Why were these changes made?
- How do the changes relate to functional differences?
