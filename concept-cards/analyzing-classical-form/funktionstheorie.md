# Quick Definition
The "theory of functions" developed by Hugo Riemann, classifying harmonies into three main functional categories (tonic, dominant, subdominant/pre-dominant) rather than by individual scale degrees.

# Core Definition
"The late-19th-century German theorist Hugo Riemann developed the first Funktionstheorie ('theory of functions'). The modern North American adaptation of the function theory retains Riemann's category of tonic and dominant functions but usually reconceptualizes his 'subdominant' function into a more all-embracing pre-dominant function" (p. 25). This approach reveals that multiple Roman numeral chords share the same underlying function.

# Prerequisites
- **Roman numeral analysis** — Function theory builds upon and reinterprets scale-degree-based analysis

# Key Properties
1. Riemann's original three functions: Tonic (T), Dominant (D), Subdominant (S)
2. Modern adaptation retains Tonic and Dominant, expands Subdominant to Pre-dominant
3. Pre-dominant embraces more chord types: II, IV, bII, augmented sixths, V/V
4. Multiple Roman numerals may share the same function
5. Complementary to (not replacement for) Roman numeral analysis

# Construction / Recognition
## To Identify:
1. Classify each harmony by its functional role (tonic, dominant, or pre-dominant)
2. Recognize that different Roman numerals may share function (e.g., I and VI = tonic)
3. Use function labels alongside Roman numerals for deeper analytical insight
4. Note when a chord's function differs from its expected category

# Context & Application
Funktionstheorie provides a simplified classification of harmonic activity, reveals chord substitution patterns within functions, and frames the understanding of cadential progressions. The functional approach is complementary to Roman numeral analysis (Stufentheorie), providing functional interpretation of individual chords identified by scale degree.

# Relationships
## Builds Upon

## Enables
- **Cadential progression** — Functional ordering (tonic-pre-dominant-dominant-tonic) defines cadential structure
## Related
- **Stufentheorie** — The complementary "theory of steps" approach
- **Rameau theory of harmony** — Historical predecessor to both systems
## Contrasts With
- **Stufentheorie** — Focuses on functional categories rather than individual scale-degree steps

# Common Errors
- **Error**: Treating Funktionstheorie and Stufentheorie as mutually exclusive
  **Correction**: The two approaches are complementary; modern analysis uses both

# Common Confusions
- **Confusion**: Confusing Riemann's "subdominant" with modern "pre-dominant"
  **Clarification**: Modern North American practice expands Riemann's subdominant into a broader pre-dominant category embracing II, IV, bII, augmented sixths, and V/V
