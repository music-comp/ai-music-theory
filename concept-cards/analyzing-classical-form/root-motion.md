# Quick Definition
The intervallic relationship between successive chord roots, forming the basis for classifying sequential progressions into six types by size and direction.

# Core Definition
Root motion describes the interval and direction of movement between roots of successive harmonies. Sequential progressions "can be classified into six types based on the size and direction of the interval between the roots of the individual chords of the sequence" (p. 27). Root motion by fourths, sixths, and sevenths is accommodated through inversional equivalence (e.g., ascending fourth = descending fifth).

# Prerequisites
- **Scale degree** — Root motion is measured between scale-degree roots

# Key Properties
1. Descending fifth: most frequent (III-VI-II-V-I)
2. Ascending fifth: infrequent
3. Descending third: frequent (I-VI-IV-II)
4. Ascending third: most infrequent
5. Descending second: frequent (IV-III-II-I)
6. Ascending second: frequent (I-II-III-IV)
7. Descending fifth has special status (underlies V-I relationship)
8. Root motion by fourths, sixths, sevenths = inversional equivalents of fifths, thirds, seconds

# Construction / Recognition
## To Identify:
1. Determine the root of each successive chord
2. Calculate the interval and direction between roots
3. Reduce to one of six categories (using inversional equivalence)
4. Note: root motion may differ from bass motion when chords are inverted

# Context & Application
Understanding root motion classifies sequential progressions, explains the special status of descending-fifth motion (V-I relationship), helps identify non-functional patterns in sequences, and distinguishes functional progressions from pattern-based ones. The descending-fifth motion has special status because it underlies the fundamental V-I relationship.

# Common Errors
- **Error**: Not recognizing inversional equivalence (ascending fourth = descending fifth)
  **Correction**: Reduce all root motion to one of six categories through inversional equivalence

# Common Confusions
- **Confusion**: Conflating root motion with bass motion
  **Clarification**: Root motion measures the interval between chord roots; bass motion may differ when chords are in inversion
