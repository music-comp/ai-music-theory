# Quick Definition
Minore refers to a passage, variation, or interior theme set in the minor mode of a major-mode home key. Maggiore is the reverse: a passage set in the major mode of a minor-mode home key. Both create striking modal contrast.

# Core Definition
The interior theme contrasts with the main theme largely through being set in the opposite modality. A major-mode main theme is followed by an interior theme in the minor mode, often labeled minore in the score. A minor-mode main theme may be contrasted by a major-mode interior theme, termed maggiore. In theme and variations, one variation is typically written in the opposite mode (Caplin, pp. 588, 608-609).

# Prerequisites
- **Interior theme** -- The principal formal context for minore/maggiore contrast

# Key Properties
1. Minore: minor mode of a major-mode home key
2. Maggiore: major mode of a minor-mode home key
3. Often indicated by the composer in the score
4. Creates the most prominent contrast in an interior theme
5. In variations, the minore may alter harmonic-tonal organization and phrase functions
6. Modal shift may create nonsyntactical progressions requiring rewriting

# Construction / Recognition
## To Identify:
1. Look for a sudden shift to the opposite mode at the start of a new section
2. Check for the Italian marking minore or maggiore in the score
3. In variations, look for the one variation that changes mode

# Context & Application
The minore/maggiore contrast appears in large ternary forms (interior themes), theme and variations (one variation in opposite mode), and rondo couplets (interior theme couplets). It is one of the most recognizable features of classical slow movements.

# Examples
**Example 1** (p. 589): Haydn, String Quartet in G minor ("Rider"), Op. 74, No. 3, ii -- interior theme begins with shift to E minor (minore).
**Example 2** (p. 608): Minore variations often change the original harmonic-tonal organization, sometimes altering internal phrase functions even while the overall form is retained.

# Common Errors
- **Error**: Assuming minore simply means "in minor key"
  **Correction**: Minore specifically means the minor mode of the same key (e.g., C minor within a C major movement), not a different minor key
