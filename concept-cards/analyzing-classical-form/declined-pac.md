# Quick Definition
A declined PAC occurs when a transition's phrase structure implies an authentic cadence (as would befit a consequent) but ends with a half cadence instead, preventing the passage from functioning as a second main theme and preserving its transitional function.

# Core Definition
When a transition opens with a compound basic idea or presentation-like structure, the following phrase might be expected to function as a consequent leading to a PAC. If a PAC were achieved, the passage would project the sense of a "second" main theme rather than a transition. To fulfill the intended transitional function, the composer allows the anticipated consequent to "fail," ending with an HC instead. The resulting phrase structure is nonconventional -- neither a true sentence nor a true period -- and the 1-measure extension and chromatic alterations contribute to loosening appropriate for a transition. This deliberate avoidance of authentic closure is essential to maintaining transition function (Caplin, Ch. 11, pp. 346-347).

# Key Properties
1. A phrase structure implies consequent function leading to PAC
2. PAC is deliberately avoided; HC ends the phrase instead
3. If PAC occurred, passage would sound like a second main theme
4. Resulting structure is nonconventional (neither true sentence nor period)
5. Contributes to appropriate loosening for transition function
6. Chromaticism and extension often accompany the declined PAC

# Construction / Recognition
## To Identify:
1. Locate a transition that opens with a compound basic idea or presentation
2. Check whether the second phrase seems consequent-like
3. Note whether it ends with HC instead of expected PAC
4. Recognize the nonconventional formal result

# Context & Application
The declined PAC is a compositional strategy that ensures a transitional passage fulfills its proper thematic function. A PAC would create too much closure and stability, converting the passage into a second main theme. By declining the PAC, the composer maintains the open-ended, destabilizing character essential to transition function.

# Examples
**Example 1** (pp. 346-347): Beethoven, Piano Sonata Op. 2/3, i, mm. 13-21 -- Transition begins with compound basic idea (ascending arpeggios + descending scale). The second phrase (basic idea + reharmonized contrasting idea) creates an antecedent-like function but ends with HC at m. 21 instead of PAC, yielding a nonconventional structure with appropriate loosening.

# Common Errors
- **Error**: Analyzing the HC-ending phrase as a genuine antecedent expecting a consequent to follow
  **Correction**: The phrase already follows a prior compound basic idea; the HC is the transition's structural end, not the first half of a period
