# Nonconventional A Section

On occasion, the A section of a small ternary takes a **nonconventional** form, one that does not correspond to any standard theme type.

## Definition

A nonconventional A section:
- Does not match sentence, period, or hybrid patterns
- May still contain elements of these types
- Must still end with PAC

## Examples

Nonconventional structures may include:
- Extended basic idea + cadential phrase only
- Multiple thematic units combined
- Unusual grouping structures

## Functional Elements

Even in nonconventional forms:
- Basic idea typically begins the section
- Cadential function closes the section
- Conventional functional elements may be present

## Compound A Section

A nonconventional A section might consist of:
- Two complete simple themes combined
- First closing in home key, second modulating
- Creating a larger-than-typical exposition

## Analytical Approach

When analyzing nonconventional A sections:
1. Identify any conventional functional elements
2. Note the cadential structure
3. Describe the unique organization
4. Do not force a conventional label if it doesn't fit
