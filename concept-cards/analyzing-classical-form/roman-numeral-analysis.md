# Quick Definition
A system for identifying harmonies by the scale degree of their roots, using Roman numerals with figured-bass symbols to indicate inversions, developed in the 18th-19th centuries and foundational to harmonic analysis.

# Formal Definition
The Roman numeral system identifies individual harmonies in terms of the scale degrees of their roots. The seven Roman numerals indicate these roots with respect to a given key, and additional Arabic numerals indicate (in a manner derived from the figured-bass tradition) the various positions (inversions) of the harmonies.

# Musical/Theoretical Formulation
Basic notation:
- I = root-position tonic
- IV6 = first-inversion subdominant
- V4/3 = second-inversion dominant seventh

Caplin's convention:
- Uppercase Roman numerals are used exclusively for all chord qualities
- This follows texts like Aldwell, Schachter, and Cadwallader
- Chord quality (major, minor, diminished) is not distinguished in the numeral itself

Many theorists understand that Roman numerals do not define seven fully distinct harmonies, instead proposing classification into three main harmonic functions.

# Musical Context/Application
Roman numerals provide:
- Quick identification of harmonic roots
- Indication of scale-degree relationships
- Framework for understanding harmonic function
- Basis for comparing progressions across keys

The system is foundational but limited - understanding harmonic function (tonic, dominant, pre-dominant) provides deeper analytical insight than Roman numerals alone.

# Common Confusions
- Treating each Roman numeral as a distinct function (multiple numerals share function)
- Assuming uppercase/lowercase distinguish major/minor (Caplin uses uppercase throughout)
- Conflating Roman numeral identification with harmonic function analysis
- Not recognizing that Roman numerals are a descriptive, not explanatory, system
