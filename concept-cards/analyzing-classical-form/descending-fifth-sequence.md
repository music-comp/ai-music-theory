# Quick Definition
The most commonly used sequential progression, featuring roots descending by fifths (or ascending by fourths) in a "circle of fifths" pattern (e.g., III-VI-II-V-I). It has the strongest harmonic-functional expression of any sequence type because each link implies a dominant-to-tonic relationship.

# Core Definition
The most commonly used sequential progression features chords whose roots are organized into a series of descending fifths (most often alternating with ascending fourths). This "circle-of-fifths" progression can be varied in manifold ways through chord inversion, chromatic alteration, and added dissonances (p. 42). Compared to other categories, the descending-fifth pattern features the strongest harmonic-functional expression, since the root motion of a descending fifth lies at the basis of every dominant-to-tonic progression; this functional relation is implied, by analogy, at each link in the sequential chain (p. 43).

# Prerequisites
- **Sequential progression** — This is one of six types of sequential progression

# Key Properties
1. Most frequently used sequential progression
2. Root pattern: descending fifths (or ascending fourths)
3. Strongest harmonic-functional expression of any sequence type
4. Each link implies dominant-to-tonic motion by analogy (even without leading tones)
5. Can be varied with inversions, chromatic alterations, added dissonances (sevenths)
6. Basic pattern: III-VI-II-V-I

# Construction / Recognition
## To Identify:
1. Look for roots moving consistently by descending fifth (or ascending fourth)
2. Recognize the "circle of fifths" pattern
3. Note if embellished with chromatic alterations or secondary dominants
4. Label initial harmony with "seq."

# Context & Application
The descending-fifth sequence often appears between prolongational and cadential sections of themes. Its strong functional expression distinguishes it from other sequence types, making it feel less purely contrapuntal. May facilitate modulation to new keys.

# Common Errors
- **Error**: Treating each link as a genuine cadential V-I
  **Correction**: The dominant-tonic relationship is implied by analogy, not genuinely functional

# Common Confusions
- **Confusion**: Confusing descending-fifth sequence with genuine functional circle progressions
  **Clarification**: In sequential context, the harmonies are pattern-driven, not function-driven
