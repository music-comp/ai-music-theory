## Slow Introduction Overview

A **slow introduction** is an optional framing function that may precede the exposition in sonata form.

### Characteristics

- Marked contrast of tempo with the exposition (slow vs. fast)
- Often uses different thematic material
- Typically ends on dominant (preparing first theme entrance)
- Creates sense of preparation and expectation

### Function

The slow introduction serves to:
- Create formal weight and gravitas at the opening
- Establish tonal center before the main action begins
- Generate anticipation for the exposition
- Allow for dignified, stately character before energetic exposition

### Relationship to Main Theme

The beginning of the exposition is signaled by:
- Change to faster tempo
- Entrance of main theme's basic idea
- Return of home-key tonic (if introduction ended on dominant)

### Not to Be Confused With

A main theme with "introductory" character:
- Some main themes seem hesitant or preparatory
- But they are still the main theme (same tempo, proper form)
- A true slow introduction has contrasting tempo
