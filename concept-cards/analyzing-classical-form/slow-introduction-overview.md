# Quick Definition
A slow introduction is an optional framing function that may precede the exposition in sonata form, marked by a contrasting slow tempo, and typically ending on the dominant to prepare the main theme's entrance. It is not to be confused with a main theme that has "introductory" character.

# Core Definition
The slow introduction is one of two optional framing functions in sonata form (the other being the coda). It precedes the exposition and is marked by a contrasting slow tempo relative to the faster exposition. The slow introduction typically uses different thematic material, often ends on the dominant (preparing the main theme's entrance), and creates a sense of formal weight, gravitas, preparation, and expectation. The beginning of the exposition is signaled by the change to a fast tempo along with the entrance of the main theme's basic idea. Chapters 15 and 16 provide detailed treatment of slow introduction and coda.

# Key Properties
1. Optional framing function (not required)
2. Slow tempo contrasting with exposition's fast tempo
3. Often uses different thematic material
4. Typically ends on dominant, preparing main theme
5. Creates formal weight and gravitas
6. Not to be confused with main themes having "introductory" character

# Construction / Recognition
## Distinguishing from Main Theme:
| Feature | Slow Introduction | Main Theme with Introductory Character |
|---------|-------------------|---------------------------------------|
| Tempo | Slow (contrasting) | Same as rest of exposition |
| Formal status | Framing function | True formal beginning |
| Cadential/structural solidity | May lack | Sufficient for genuine beginning |

# Context & Application
Despite the textural, dynamic, and rhythmic instabilities that some main themes project (giving an "introductory" character), a true slow introduction is distinguished by its contrasting tempo. The slow introduction was especially common in symphonies and overtures, where it provides ceremonial weight before the energetic exposition. The slow introduction balances the coda at the other end of the movement.

# Common Confusions
- **Confusion**: A hesitant, uncertain main theme must be a slow introduction
  **Clarification**: Despite textural/dynamic instabilities, a main theme still contains sufficient tonal, cadential, and phrase-structural solidity to function as the true formal beginning; only a contrasting tempo signals a genuine slow introduction
