# Quick Definition
A pre-core structured as a relatively tight-knit sentence, period, or hybrid, analogous to a main theme but set in the subordinate key or a development key.

# Core Definition
The tight-knit pre-core takes the form of a conventional theme type and, by virtue of its placement at the beginning of the development, is analogous to a main theme (p. 466). It is often based on material from the exposition's main theme, though its formal organization is usually "somewhat looser than that of the main theme." The essential difference is tonal: the main theme resides in the home key, while the tight-knit pre-core is in the subordinate key or a development key.

# Prerequisites
- **Pre-core** — The broader category this belongs to
- **Sentence** — One of the possible tight-knit forms
- **Period** — Another possible tight-knit form

# Key Properties
1. Takes the form of sentence, period, or hybrid
2. Analogous to a main theme by placement at the development's start
3. Often based on main-theme material from the exposition
4. Somewhat looser organization than the original main theme
5. Set in subordinate key or development key (not home key)
6. Particularly common in Mozart

# Construction / Recognition
## To Identify:
1. Look for conventional theme-type organization (sentence, period, hybrid) at the development's start
2. Confirm it is not in the home key
3. Note material correspondence with the exposition's main theme

# Examples
**Example 13.10** (p. 466): Mozart, Piano Sonata in B-flat, K. 333, i — pre-core begins in subordinate key with material from main theme; forms an 8-m. sentence ending with PAC in m. 71; greater use of chromaticism makes it looser than original.

# Common Confusions
- **Confusion**: Hearing a tight-knit pre-core as the actual main theme returning
  **Clarification**: The tonal context (subordinate or development key, not home key) distinguishes it from a true main-theme return
