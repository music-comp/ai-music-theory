# Quick Definition
The simultaneous return of (1) the basic idea of the exposition's main theme and (2) tonic harmony of the home key at the opening of the recapitulation.

# Core Definition
"The opening of the recapitulation's main theme usually features what has traditionally been called a 'double return'" (p. 507): the return of the basic idea and the return of home-key tonic harmony. "For some theorists, both returns must take place at the same time in order to speak of a genuine sense of recapitulation." However, "these returns are sometimes not coordinated with each other; or one of them — the return of the opening basic idea — may be missing altogether." Caplin's concept of recapitulation "does not depend entirely on a 'double return' but relies on the appearance of other functional obligations as well."

# Key Properties
1. Two simultaneous returns: basic idea + home-key tonic
2. Traditional hallmark of classical sonata form
3. Returns sometimes not coordinated (one may precede the other)
4. Opening basic idea may be missing entirely (recapitulation without main theme)
5. Home-key tonic always returns somewhere in the recapitulation
6. Haydn and Mozart almost always open as in the exposition; Beethoven often gives a different, more forceful dynamic

# Construction / Recognition
## To Identify:
1. Look for the main theme's basic idea returning in the home key after the development
2. Confirm both elements are present and simultaneous
3. If one is missing, consider whether the passage still functions as a recapitulation

# Context & Application
The double return concept is important but not absolute. Subdominant recapitulations (main theme in IV, not I) and recapitulations without main-theme material both challenge the strict double-return requirement.
