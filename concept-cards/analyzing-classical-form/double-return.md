# Double Return

The simultaneous return of two essential elements at the opening of the recapitulation.

## Definition

The opening of the recapitulation's main theme usually features:
1. A return of the basic idea of the exposition's main theme
2. A return of tonic harmony of the home key

For some theorists, both returns must take place at the same time to speak of a genuine recapitulation.

## Exceptions

These returns are sometimes not coordinated:
- Thematic return without tonic (subdominant recapitulation)
- Tonic return without opening basic idea (deleted main theme)
- One or both may be delayed or missing

## Theoretical Consideration

The concept of recapitulation in Caplin's study does not depend entirely on a double return but relies on the appearance of other functional obligations as well.

## Typical Effect

Almost always in Haydn and Mozart, the recapitulation opens just as at the start of the exposition, reinforcing the character of "starting over again." Beethoven often gives a different, more forceful dynamic quality.
