# Quick Definition
An interior theme occupies a central position within a form, standing between statements of a main theme. It contrasts through modal shift (typically minore) or a different tonal region, and is never set in the standard subordinate key.

# Core Definition
The interior theme contrasts with the main theme largely through being set in the opposite modality. A major-mode main theme is followed by an interior theme in the minor mode (minore). The interior theme is modeled more or less on the small ternary (or small binary), though frequently left incomplete or distorted. It is never set primarily in the standard subordinate key -- this fundamentally distinguishes it from a subordinate theme (Caplin, pp. 588-589, 597-598).

# Prerequisites
- **Large ternary form** -- The full-movement form containing the interior theme
- **Small ternary** -- The form type on which the interior theme is usually modeled
- **Minore/maggiore** -- The modal shift that creates the primary contrast

# Key Properties
1. Central position between statements of a main theme
2. Contrasts primarily through modal shift (minore/maggiore)
3. Never set in the standard subordinate key (V for major, III/v for minor)
4. Usually modeled on small ternary or small binary, often distorted
5. Typically ends on home-key dominant, motivating the main theme's return
6. Often brings Sturm und Drang affect with active, rhythmically continuous accompaniment

# Construction / Recognition
## To Identify:
1. Look for a section standing between two statements of a main theme
2. Check for modal contrast (shift to minor or major)
3. Confirm the tonal region is NOT the standard subordinate key
4. Identify the underlying small ternary/binary structure and any distortions
5. Note whether the section ends on dominant harmony

# Context & Application
Interior themes appear in large ternary form (slow movements), rondo forms (as couplets), and minuet/trio form (where the trio can function similarly). The concept is crucial for distinguishing between formal types that use modal contrast (interior theme) versus tonal conflict (subordinate theme).

# Examples
**Example 1** (p. 589): Haydn, String Quartet in G minor ("Rider"), Op. 74, No. 3, ii -- interior theme begins in E minor (minore), built as truncated small ternary (A-B only).
**Example 2** (p. 605): Beethoven, Piano Sonata in E-flat, Op. 7, ii -- interior theme functions like a development section with model-sequence organization.

# Common Errors
- **Error**: Placing an interior theme in the dominant key
  **Correction**: Interior themes are never in the standard subordinate key; this would make it a subordinate theme

# Common Confusions
- **Confusion**: Equating interior theme with the B section of a small ternary
  **Clarification**: The interior theme is a full-movement-level function between main themes, while a B section is a theme-level function within a small ternary
