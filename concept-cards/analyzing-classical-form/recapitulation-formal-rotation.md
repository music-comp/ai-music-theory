# Quick Definition
The recapitulation fulfills a formal rotation by restating exposition material in roughly the same order, and the conventional labels (main theme, transition, subordinate theme) are maintained despite the fact that these units serve significantly different formal functions in the recapitulation.

# Core Definition
By restating the material of the exposition in roughly the same order, the recapitulation fulfills what Hepokoski and Darcy emphasize as a formal rotation. It is conventional to label the constituent thematic functions with the same terms as in the exposition: main theme, transition, and subordinate theme (including closing section). This practice is rooted in the traditional notion that formal units are defined primarily by their musical content, not necessarily by their formal function. Yet this labeling scheme obscures the significantly different formal functions that these units serve in the recapitulation. For the sake of tradition, the conventional labeling is maintained while acknowledging these functional differences.

# Key Properties
- Recapitulation restates exposition material in roughly the same order
- Conventional labels (main theme, transition, subordinate theme) maintained
- Labels are based on content, not function
- Formal functions differ significantly from exposition counterparts
- Main theme in recapitulation: signals return and rebeginning (not introduction of material)
- Transition: destabilizes for variety (not to establish a new key)
- Subordinate theme: confirms home key (not subordinate key)
- Hepokoski and Darcy emphasize rotational form as central organizing principle

# Construction / Recognition
Identify the major sections of the recapitulation by comparing with the exposition. Note that while the melodic-motivic content appears in the same order, the harmonic-tonal functions have changed: the transition no longer modulates to a new key, and the subordinate theme confirms the home key instead of the subordinate key.

# Context & Application
The concept of formal rotation is important for understanding the recapitulation's dual nature: it is simultaneously a return to familiar material (content) and a fulfillment of new formal obligations (function). Caplin maintains the traditional labels while carefully distinguishing the different functions these units serve. This approach balances respect for analytical tradition with sensitivity to the distinct formal requirements of each section.

# Examples
- General pattern: exposition presents main theme, transition, subordinate theme; recapitulation brings them back in the same order but with different functional roles
- Main theme in recapitulation signals "return" and "rebeginning" rather than introducing material for the first time

# Common Errors
- Assuming that because a passage is labeled "main theme" in the recapitulation, it has the same function as the exposition's main theme
- Treating the rotational ordering as absolute (some recapitulations reorder or omit units)

# Common Confusions
- The conventional labels do NOT imply identical formal functions -- "main theme" in the recapitulation primarily signals return, while "main theme" in the exposition primarily introduces and establishes material
