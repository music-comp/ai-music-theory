# Quick Definition
In some slow-movement sonata expositions, the main theme's final cadence is immediately followed by the subordinate theme in the new key, entirely bypassing transition function. The dominant emphasis is shifted into the subordinate theme itself.

# Core Definition
In some sonata expositions, the form becomes compressed when the final cadence of the main theme is immediately followed by the subordinate theme. The lack of transition often results in the emphasis on dominant of the new key becoming shifted into the subordinate theme proper, usually through an internal HC and standing on the dominant (Caplin, p. 614).

# Prerequisites
- **Slow-movement sonata** -- The context where this compression occurs

# Key Properties
1. Main theme cadence directly followed by subordinate theme
2. No transition present
3. Subordinate theme begins directly in the subordinate key
4. Dominant emphasis shifted into the subordinate theme (internal HC, standing on dominant)
5. May create recapitulation challenges when material is "monothematic"

# Construction / Recognition
## To Identify:
1. Check whether the main theme cadence is immediately followed by material in the subordinate key
2. Confirm no intervening modulatory passage (transition) exists
3. Look for internal dominant emphasis within the subordinate theme

# Context & Application
This is the second compression technique for slow-movement sonatas. When combined with Haydn's monothematicism (same material for main and subordinate themes), it creates significant challenges for the recapitulation, which may need to be drastically rewritten.

# Examples
**Example 1** (p. 614): Haydn, Piano Sonata in D, H. 24, ii -- main theme closes with HC at m. 6; subordinate theme begins directly in G major with main-theme material; the recapitulation is truncated, with only the main theme returning.
