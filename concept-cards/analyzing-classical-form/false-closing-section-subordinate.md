# Quick Definition
Within a subordinate-theme group, a PAC may be followed by material with codetta characteristics (tonic pedal, tonic scale degree in soprano, recessive dynamic) that is retrospectively understood as the beginning of a new subordinate theme. The codetta-like idea is reinterpreted as a basic idea whose repetition forms a presentation. Occasionally, this technique replaces the true closing section entirely.

# Core Definition
A true closing section appears only after the **final** theme of a subordinate-theme group. A prior theme's PAC may be followed by material with prominent codetta characteristics (tonic pedal, prolongation of tonic scale degree in soprano, recessive dynamic), but subsequent development reveals this material to function as the beginning of a new subordinate theme. The codetta-like idea is reinterpreted as a basic idea, whose repetition creates a presentation. Occasionally, an exposition contains no true closing section: a false closing section appears that is extended into a genuine subordinate theme (the last of the group) through continuation and cadential functions, resulting in a relatively tight-knit theme (Caplin, Ch. 12, pp. 411-412).

# Prerequisites
- **Subordinate-theme group** -- False closing sections occur between themes
- **Closing section** -- Must understand genuine closing sections
- **False closing section** -- Same technique as in transitions (Ch. 11)

# Key Properties
1. Material following PAC has codetta characteristics
2. Retrospectively understood as presentation for new subordinate theme
3. Tonic pedal, tonic scale degree, recessive dynamic = codetta appearance
4. Development beyond codetta scope reveals true thematic function
5. Sometimes replaces the true closing section entirely
6. Resulting theme tends to be relatively tight-knit
