# Quick Definition
The complete set of harmonies available within a key, organized by function (tonic, dominant, pre-dominant) rather than simply by scale degree.

# Formal Definition
Harmonic vocabulary refers to the collection of harmonies available for use within a tonal context. Rather than treating each of the seven scale degrees as producing distinct harmonies, a functional understanding groups harmonies into three main categories: tonic, dominant, and pre-dominant, each containing multiple chord types.

# Musical/Theoretical Formulation
**Tonic harmonies:**
- I, VI (in major)
- i, VI (in minor)

**Dominant harmonies:**
- V, VII (V7, VII7)
- III (in limited contexts as substitute)

**Pre-dominant harmonies:**
- IV, II, bII (various inversions)
- Secondary dominants of V (VII7/V, V/V)
- Augmented-sixth chords (It+6, Gr+6, Fr+6)

Additional vocabulary through:
- Modal borrowing (mixture)
- Chromatic alterations
- Secondary dominants of other degrees

# Musical Context/Application
Understanding harmonic vocabulary:
- Provides framework for analysis
- Clarifies functional relationships
- Enables recognition of chord substitution
- Distinguishes between diatonic and chromatic resources

The pre-dominant category is particularly rich, including both diatonic options (II6, IV) and chromatic options (augmented sixths, Neapolitan).

# Common Confusions
- Treating all seven scale degrees as producing equally distinct harmonies
- Not recognizing functional equivalence within categories
- Overlooking chromatic options that expand the vocabulary
- Assuming harmonic vocabulary is identical across major and minor modes
