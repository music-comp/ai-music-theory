# Quick Definition
If the exposition's transition is nonmodulatory, no tonal adjustment is necessary in the recapitulation, and the transition may retain its original structure -- though alterations may still occur for harmonic-tonal variety.

# Core Definition
If the exposition's transition is nonmodulatory, a tonal adjustment is not necessary in the recapitulation. The transition may retain its original structure. Even when not necessary, however, alterations may still occur to achieve greater harmonic-tonal variety and a fresh effect, especially if the preceding main theme remains unaltered. The nonmodulating transition may be kept intact particularly when the main theme of the recapitulation already provides secondary development (newly added model-sequence technique), already emphasizes flat-side regions, or has otherwise created sufficient variety.

# Prerequisites
- Understanding of tonal adjustment in the recapitulation
- Knowledge of transition deletions and compressions

# Key Properties
- No tonal adjustment necessary since the exposition's transition did not modulate
- Transition may retain original structure unchanged
- Alterations may still occur for harmonic variety even when not required
- Particularly likely to be retained when main theme already provides variety
- Flat-side emphasis in the main theme reduces need for transition alterations
- Secondary development in the main theme makes transition changes less pressing

# Construction / Recognition
Check whether the exposition's transition modulates. If it does not, compare the recapitulation's transition with the original. Determine whether it is retained unchanged or whether alterations have been made. If altered, consider whether the main theme was also changed (if the main theme provides sufficient variety, the transition may be retained; if the main theme is unchanged, the transition is more likely to be altered).

# Context & Application
The treatment of a nonmodulating transition in the recapitulation illustrates how structural changes are distributed across different units. If the main theme has already introduced flat-side emphasis and secondary development, the transition need not provide additional variety. Conversely, if the main theme is unchanged, the transition becomes the primary locus for harmonic-tonal variety in the early part of the recapitulation.

# Examples
- General pattern: main theme adds model-sequence technique and flat-side emphasis; nonmodulating transition follows identically to the exposition
- Alternative pattern: main theme retained unchanged; nonmodulating transition altered for variety

# Common Errors
- Assuming every transition must be altered in the recapitulation
- Failing to recognize that the need for transition changes depends on what happens in the main theme

# Common Confusions
- A nonmodulating transition retained unchanged is NOT evidence of a "lazy" recapitulation -- it may be a deliberate choice when sufficient variety has been achieved elsewhere
