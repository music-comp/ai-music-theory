# Quick Definition
Many formal units in classical movements present a grouping structure resembling the sentence but do not truly create this theme type. The term "sentence" should be reserved for relatively tight-knit themes with clear presentation and continuation phrases supported by appropriate harmonic progressions.

# Core Definition
Many formal units present grouping structures resembling the sentence but do not truly constitute this theme type. A core's model-sequence resembles a presentation, but without tonic prolongation it cannot form a genuine presentation. A standing on the dominant may have sentence-like grouping but completely lacks harmonic activity and cadential articulation. The term **sentence** is best reserved for (relatively) tight-knit themes featuring clear presentation and continuation phrases (Caplin, Ch. 9, p. 299).

# Prerequisites
- **Sentence** -- Must understand the genuine theme type
- **Presentation / Continuation** -- The constituent functions that define the sentence

# Key Properties
1. Sentence-like grouping does NOT equal a genuine sentence
2. A core lacks tonic prolongation in its model-sequence, so no genuine presentation
3. A standing on the dominant lacks harmonic activity and cadential articulation
4. The term "sentence" should be reserved for tight-knit manifestations
5. Many loose formal units are better described as "sentential" or "sentence-like"

# Construction / Recognition
## To Identify:
1. Check for genuine tonic prolongation in the presentation-like opening
2. Verify that continuation has real harmonic activity leading toward a cadence
3. If either is missing, describe the grouping as "sentential" rather than labeling it a sentence
4. Use this distinction especially for cores, standings on the dominant, and transitions

# Context & Application
This distinction becomes increasingly important as analysis moves beyond tight-knit main themes to looser thematic regions. The "sentence or sentential?" question arises particularly in transitions (Ch. 11), subordinate themes (Ch. 12), and development cores (Ch. 13).
