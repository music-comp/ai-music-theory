# Quick Definition
A subordinate theme can acquire significant formal loosening by starting in medias res -- beginning with continuation function (typically through sequential harmonies), cadential function (supported by a single ECP), or a standing on the dominant, rather than a standard presentation or compound basic idea.

# Core Definition
A subordinate theme can acquire significant formal loosening by giving the impression of starting in medias res ("in the middle of things"). The theme may start with continuation function (instead of standard initiation), cadential function, or a standing on the dominant from the end of the transition. This raises a theoretical conundrum: how can a passage be a "continuation" if not preceded by material it "continues"? Caplin resolves this through the concept of intrinsic vs. contextual functionality: because formal functions are so conventionalized, we can sometimes identify a given function independent of its actual position. When contextual placement differs from intrinsic temporal expression (a medial function appears as a beginning), a kind of "formal dissonance" results. If carefully controlled, this dissonance expresses loose organization; too great a dissonance produces illogical formal succession. Beginning with continuation occurs most often with the second or third subordinate theme of a group, since the new theme can be understood to "continue" the group as a whole (Caplin, Ch. 12, pp. 412-416).

# Key Properties
1. Three possibilities: beginning with continuation, cadential, or standing on dominant
2. Most effective continuation beginning: sequential harmonies (model-sequence)
3. Intrinsic functionality: can be identified independent of contextual position
4. Contextual vs. intrinsic mismatch creates "formal dissonance"
5. Controlled formal dissonance = loose organization; excessive = illogical
6. Most common with second or third subordinate theme in a group

# Construction / Recognition
## To Identify:
1. Check whether the subordinate theme begins with a presentation or compound basic idea
2. If not, determine the intrinsic function of the opening material
3. Sequential harmonies suggest continuation function
4. A single ECP from the start suggests cadential function
5. Retained dominant from transition suggests standing on the dominant
6. Verify that sufficient contrast with transition material signals a new theme

# Context & Application
The concept of intrinsic vs. contextual functionality is one of Caplin's most important theoretical contributions. It explains how a passage can have the intrinsic qualities of a continuation (fragmentation, sequential harmony, harmonic acceleration) while occupying the contextual position of a beginning. This formal "dissonance" is analogous to harmonic dissonance: it creates tension that can be artfully deployed for expressive purposes.

# Examples
**Example 1** (p. 413): Second subordinate theme beginning with 1-measure model sequenced by descending thirds; fragmentation relative to preceding 2-measure cadential idea creates continuation function at theme's start.
**Example 2** (pp. 413-414): First subordinate theme beginning with 3-measure model sequenced twice by ascending minor thirds; all harmonic and phrase-structural instability is highly indicative of continuation function; bold effect since it begins the first theme of the group.
**Example 3** (pp. 414-415): Beethoven, Piano Sonata Op. 31/3, i, mm. 46-53 -- Subordinate theme begins with ECP from the start; I6 progresses to IV, then dominant, then deceptive resolution; entire theme supported by cadential function.

# Common Errors
- **Error**: Assuming every subordinate theme must begin with a presentation
  **Correction**: Subordinate themes may begin with continuation, cadential function, or standing on the dominant; the resulting formal dissonance is a valid loosening device

# Common Confusions
- **Confusion**: Thinking "beginning with continuation" is a contradiction in terms
  **Clarification**: Intrinsic functionality (the passage's inherent qualities) can differ from contextual functionality (its position in the theme); this dissonance is the point
