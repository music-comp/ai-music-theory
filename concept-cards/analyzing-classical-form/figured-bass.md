# Quick Definition
A Baroque-era notation system using Arabic numerals to indicate intervals above a bass note, adapted in modern Roman numeral analysis to show chord inversions.

# Formal Definition
The figured-bass tradition provides a system of Arabic numerals indicating intervals above the bass. Modern Roman numeral analysis derives its inversion symbols from this tradition "in a manner loosely derived from" figured bass. The numerals show chord positions: 6 for first inversion, 6/4 for second inversion, etc.

# Musical/Theoretical Formulation
Standard figured-bass symbols in Roman numeral analysis:
- **No figures or 5/3**: Root position (often omitted)
- **6 or 6/3**: First inversion (third in bass)
- **6/4**: Second inversion (fifth in bass)

Seventh chord inversions:
- **7**: Root position seventh (5/3 assumed)
- **6/5**: First inversion seventh
- **4/3**: Second inversion seventh
- **4/2** or **2**: Third inversion seventh

The cadential six-four receives special notation: V(6-4 to 5-3), showing the embellishing intervals and their resolutions.

# Musical Context/Application
Modern usage of figured bass:
- Indicates chord inversion in harmonic analysis
- Derives from but simplifies original Baroque practice
- Combined with Roman numerals for complete harmonic description
- Clarifies bass note and upper-voice intervals

Historical context: The Roman numeral system was introduced by Abbe Vogler and popularized by Gottfried Weber, combining with figured-bass conventions for modern analytical notation.

# Examples
Chapter examples of figured-bass derived notation:
- "I = root-position tonic"
- "IV6 = first-inversion subdominant"
- "V4/3 = second-inversion dominant seventh"

The chapter notes that Arabic numerals indicate "the various positions (inversions) of the harmonies" (p. 23).

# Common Confusions
- Treating figured-bass numbers as scale degrees (they are intervals above bass)
- Not recognizing abbreviated figures (6 = 6/3, 7 = 7/5/3)
- Confusing figured bass with Roman numeral function (figures show intervals, not function)
- Applying original Baroque figured-bass rules to modern analytical use
