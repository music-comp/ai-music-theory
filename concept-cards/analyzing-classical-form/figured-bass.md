# Quick Definition
A Baroque-era notation system using Arabic numerals to indicate intervals above a bass note, adapted in modern Roman numeral analysis to show chord inversions.

# Core Definition
The figured-bass tradition provides a system of Arabic numerals indicating intervals above the bass. Modern Roman numeral analysis incorporates these symbols "in a manner loosely derived from" figured bass (p. 23) to indicate chord inversions. The numerals show chord positions: 6 for first inversion, 6/4 for second inversion, and specific figures for seventh-chord inversions. The cadential six-four receives special notation: V(6-4 to 5-3).

# Prerequisites
- **Scale degree** — Figured-bass symbols attach to Roman numerals based on scale-degree roots

# Key Properties
1. Root position: no figures or 5/3 (often omitted)
2. First inversion: 6 (or 6/3)
3. Second inversion: 6/4
4. Seventh chord inversions: 7, 6/5, 4/3, 4/2 (or 2)
5. Cadential six-four: V(6-4 to 5-3) shows embellishing intervals and resolutions
6. Arabic numerals indicate intervals above bass, not scale degrees

# Construction / Recognition
## To Identify:
1. Read the Roman numeral for the chord root (scale degree)
2. Read the Arabic figures for the inversion (intervals above bass)
3. Abbreviated figures: 6 = 6/3, 7 = 7/5/3
4. For cadential six-four, note the resolution notation with parentheses

# Context & Application
Modern usage of figured bass indicates chord inversion in harmonic analysis. The system derives from but simplifies original Baroque thoroughbass practice. When combined with Roman numerals, it provides a complete harmonic description: root identity (Roman numeral) plus bass position (figured bass). The Roman numeral system was introduced by Abbe Vogler and popularized by Gottfried Weber, combining with figured-bass conventions for modern analytical notation.

# Examples
**Example 1** (p. 23): "I = root-position tonic," "IV6 = first-inversion subdominant," "V4/3 = second-inversion dominant seventh."

**Example 2** (p. 23): Arabic numerals indicate "the various positions (inversions) of the harmonies."

# Common Errors
- **Error**: Treating figured-bass numbers as scale degrees
  **Correction**: They indicate intervals above the bass note, not positions in the scale

# Common Confusions
- **Confusion**: Not recognizing abbreviated figures (6 = 6/3, 7 = 7/5/3)
  **Clarification**: Standard abbreviations omit figures that can be inferred from context
