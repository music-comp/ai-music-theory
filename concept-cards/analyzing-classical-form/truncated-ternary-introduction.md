# Truncated Ternary in Slow Introduction

When a slow introduction's form resembles an incomplete small ternary.

## The Pattern

1. Opening section with prominent thematic material (A-like)
2. Cadential closure (usually PAC)
3. Standing on dominant passage (B-like, contrasting middle)
4. Expected A' section is truncated

## The Truncation

The implied small ternary becomes truncated when:
- Resolution to tonic expected for A' return
- Instead, that resolution initiates the exposition
- Main theme of exposition takes place of expected A' return

## Effect

Creates sense that exposition "interrupts" the introduction, or that introduction flows seamlessly into main theme.

## Example

Introduction ends on dominant. Resolution to tonic at beginning of exposition simultaneously:
- Provides elided cadence ending introduction
- Initiates main theme as new beginning
