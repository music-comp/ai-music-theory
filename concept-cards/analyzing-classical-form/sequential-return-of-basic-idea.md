# Quick Definition
A sequential return of the basic idea occurs when the basic idea returns at the start of the consequent transposed to another scale degree (usually up a step to the supertonic region). This is the least stable form of return, creating forward momentum and potentially suggesting continuation-like destabilization.

# Core Definition
A less stable harmonic expression arises when the basic idea of the antecedent is restated sequentially in the consequent, usually by being transposed up a step into the supertonic region (p. 105). The sequential return is one of three ways the basic idea can return at the start of the consequent, alongside exact return (same harmony, most stable) and dominant-version return (moderate stability). The sequential return creates the least stable expression because it delays the re-establishment of tonic prolongation and may suggest continuation-like destabilization, creating potential ambiguity between consequent and continuation function.

# Prerequisites
- **Parallel period** — Sequential return is one form of the parallel period's return
- **Consequent phrase** — The sequential return occurs at the start of the consequent
- **Basic idea** — The unit being returned sequentially

# Key Properties
1. Basic idea transposed to another scale degree (usually up a step)
2. Both melody and harmony transposed (complete transposition)
3. Typically to supertonic region (ii)
4. Least stable of the three return types
5. Delays re-establishment of tonic
6. May suggest continuation-like destabilization
7. Creates potential ambiguity between consequent and continuation
8. Still functions as consequent despite harmonic instability

# Construction / Recognition
## To Identify:
1. Check mm. 5-6 for a recognizable return of the basic idea
2. Verify that both melody and harmony are transposed (not just the melody)
3. Common destination: supertonic region (ii)
4. Compare with exact return (same harmony) and dominant version (I to V)
5. Despite instability, the phrase still functions as consequent if it closes with stronger cadence

# Context & Application
The sequential return is the rarest of the three return types in periods. Its instability means the consequent begins less firmly grounded than with an exact return, creating forward momentum similar to continuation function. This can lead to analytical ambiguity: when the basic idea returns sequentially, the sense of "consequent" may be weakened and continuation characteristics may emerge. Nevertheless, if the phrase closes with a stronger cadence than the antecedent, consequent function is confirmed.

# Examples
**Example 1** (p. 105, Ex. 3.12): Mozart, K. 576, i, mm. 1-8 -- basic idea returns at m. 5 transposed up a step into the supertonic region; least stable harmonic expression.

# Common Errors
- **Error**: Confusing a sequential return (consequent function) with genuine continuation function
  **Correction**: Check the cadential outcome; if the phrase achieves stronger closure than the antecedent, it is a consequent despite sequential opening

# Common Confusions
- **Confusion**: Thinking any melodic transposition at m. 5 is sequential
  **Clarification**: Sequential return requires transposition of BOTH melody and harmony; if only melody changes but harmony shifts from I to V, it is a dominant-version return (statement-response)
