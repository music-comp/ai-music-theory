# Quick Definition
The process of gradually eliminating characteristic motivic features until only uncharacteristic (conventional, formulaic) ones remain, which no longer demand a continuation. Introduced by Schoenberg. Especially associated with cadential function but may also occur within continuation.

# Core Definition
Schoenberg defined liquidation as: "Liquidation consists in gradually eliminating characteristic features, until only uncharacteristic ones remain, which no longer demand a continuation. Often only residues remain, which have little in common with the basic motive" (p. 79). Liquidation is especially associated with cadential formal function, but it may also occur within continuation function. Phrase-structural fragmentation often results in a degree of motivic liquidation, especially when the fragmented unit eliminates some motivic content of the original b.i. (p. 79).

# Prerequisites
- **Basic idea** — Liquidation eliminates the b.i.'s characteristic motives
- **Continuation phrase** — Liquidation occurs within continuation
- **Characteristic vs. conventional melody** — Liquidation transitions from characteristic to conventional

# Key Properties
1. Gradual elimination of characteristic motivic features
2. Result: only uncharacteristic (conventional, formulaic) material remains
3. Especially associated with cadential function
4. May also occur within continuation function
5. Fragmentation often causes partial liquidation
6. May be gradual (systematic over several measures) or immediate (entire new material at once)
7. Introduced by Schoenberg

# Construction / Recognition
## To Identify:
1. Compare motivic content of cadential/continuation material with the b.i.
2. Note which characteristic motives have been eliminated
3. Check if remaining material is conventional (formulaic, interchangeable)
4. Gradual liquidation is most palpable; immediate liquidation occurs when cont. brings entirely new material

# Context & Application
Liquidation marks the transition from characteristic (opening, individual) to conventional (closing, formulaic) melodic content. This process is functionally appropriate: openings should be distinctive, endings should be generic to allow closure.

# Examples
**Example 1** (p. 56, Ex. 2.1): Beethoven, Op. 2, No. 1 -- the ascending quarter-note motive "a" is largely eliminated in the continuation; only the turn motive "b" remains.

# Common Errors
- **Error**: Confusing fragmentation with liquidation
  **Correction**: Fragmentation concerns unit length; liquidation concerns motivic content elimination

# Common Confusions
- **Confusion**: Thinking liquidation always occurs gradually
  **Clarification**: When the continuation begins with entirely contrasting ideas, complete liquidation occurs immediately
