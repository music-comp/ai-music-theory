# Quick Definition
A pre-core whose modulatory, sentential phrase structure and harmonic goal of dominant harmony resemble a transition.

# Core Definition
A transition-like pre-core has a "usually sentential" phrase structure, modulatory character, and a harmonic goal of the dominant of a development key (p. 467). Sequential progressions are often found, but the model must be "sufficiently small so as not to suggest the beginning of the core proper" — usually no larger than one measure.

# Prerequisites
- **Pre-core** — The broader category
- **Transition** — The formal function it resembles

# Key Properties
1. Phrase structure usually sentential
2. Modulatory character, moving between tonal regions
3. Harmonic goal is the dominant of a development key
4. Sequential progressions may appear but with small models (usually 1 measure)
5. Small model size prevents confusion with the core

# Construction / Recognition
## To Identify:
1. Look for modulatory activity at the development's start
2. Check for sentential organization with a continuation leading to dominant
3. Confirm that any sequential models are small (1 measure), not the 4-8 measure models of a core

# Examples
**Example 13.9** (p. 464): Haydn, Piano Sonata in E-flat, H. 49 — pre-core begins in subordinate key with basic idea extended to 3 measures; continuation features 1-m. model-sequence technique; leads to HC and standing on dominant of C minor (development key).

# Relationships
## Builds Upon
- **Pre-core** — A specific organizational type
## Contrasts With
- **Tight-knit pre-core** — Non-modulatory, conventional theme type
- **Core** — Much larger models (4-8 measures vs. 1 measure)

# Common Errors
- **Error**: Mistaking a transition-like pre-core for the beginning of the core
  **Correction**: The model size is the key distinction; core models are 4-8 measures, while transition-like pre-core models are usually 1 measure
