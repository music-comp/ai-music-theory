# Quick Definition
A harmony that functions diatonically in both the original key and a new key, serving as the point of transition in a pivot-chord modulation.

# Formal Definition
A pivot chord is a harmony that can be analyzed as having a diatonic function in both the prevailing key and the new key during a modulation. This shared harmonic meaning allows for smooth transition between keys.

# Musical/Theoretical Formulation
Pivot chord characteristics:
- Functions diatonically in both keys
- Creates smooth connection between tonal areas
- Often appears at the point where the new key becomes perceptible

Analytical notation:
- Vertical brace connects the two analyses
- Upper label: function in original key
- Lower label: function in new key
- New key's relation to home key shown in parentheses

Example notation structure:
```
Original key: VI
              }
New key:      II    (V)
```

# Musical Context/Application
Pivot chords:
- Enable smooth modulation between related keys
- Are most easily found between closely related keys (sharing many common harmonies)
- May be identified retrospectively as the listener recognizes the new key
- Appear in analysis guidelines for the practice exercises

From the analysis guidelines (p. 49): "If the passage modulates, try to identify a 'pivot' harmony that can function diatonically in both the original and the new key."

# Examples
The Guide to Harmonic Annotation (p. 46) describes the notation:

# Common Confusions
- Assuming every modulation must have an identifiable pivot chord
- Confusing pivot chords with common tones (pivot involves full harmonic function)
- Not recognizing that the pivot chord has genuine function in both keys
- Overlooking retrospective reinterpretation of the pivot
