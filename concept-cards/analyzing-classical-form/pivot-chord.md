# Quick Definition
A harmony functioning diatonically in both the original key and a new key, serving as the point of transition in a pivot-chord modulation.

# Core Definition
A pivot chord is a harmony analyzed as having diatonic function in both the prevailing key and the new key during a modulation. "A pivot-chord modulation is indicated by a vertical brace connecting the harmonies of the prevailing key and the new key" (p. 46). The analyst should "try to identify a 'pivot' harmony that can function diatonically in both the original and the new key" (p. 49).

# Prerequisites
- **Roman numeral analysis** — Pivot chords are analyzed with Roman numerals in both keys

# Key Properties
1. Functions diatonically in both the old and new key
2. Creates smooth connection between tonal areas
3. Notated with a vertical brace connecting analyses in both keys
4. Most easily found between closely related keys
5. May be identified retrospectively as the listener recognizes the new key
6. Not every modulation requires an identifiable pivot chord

# Construction / Recognition
## To Identify:
1. Locate the point where a new key becomes perceptible
2. Examine harmonies near this point for dual diatonic function
3. Assign Roman numeral labels in both the original and new key
4. Notate with a vertical brace connecting the two analyses

# Context & Application
Pivot chords enable smooth modulation between related keys. They are most easily found between closely related keys that share many common harmonies. The pivot chord may be identified retrospectively as the listener recognizes the new key has been established.

# Examples
**Example 1** (p. 46): "A pivot-chord modulation is indicated by a vertical brace connecting the harmonies of the prevailing key and the new key."

**Example 2** (p. 49): Analysis guidelines advise: "If the passage modulates, try to identify a 'pivot' harmony that can function diatonically in both the original and the new key."

# Relationships
## Builds Upon
- **Roman numeral analysis** — Pivot chords require analysis in two keys simultaneously
## Enables
- **Modulation** — Pivot chords facilitate smooth key changes
## Related
- **Common tones** — Common tones within a pivot chord support smooth voice leading
- **Linking harmony** — Similar dual-function concept but between progressions, not keys
## Contrasts With
- **Linking harmony** — Linking harmony serves two progressions; pivot chord serves two keys

# Common Errors
- **Error**: Assuming every modulation must have an identifiable pivot chord
  **Correction**: Some modulations occur without a clear pivot; other modulatory techniques exist

# Common Confusions
- **Confusion**: Confusing pivot chords with common tones
  **Clarification**: Pivot chords involve full harmonic function in two keys; common tones are shared pitches between chords
