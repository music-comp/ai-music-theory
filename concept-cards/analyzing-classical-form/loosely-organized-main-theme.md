# Quick Definition
Some main themes use loosening techniques typical of subordinate themes (redundant repetitions, cadential extensions, internal dominant arrivals), yet they are still tighter than the actual subordinate theme. Comparison with the subordinate theme confirms the main theme's relative tight-knit position.

# Core Definition
Some main themes are constructed in a manner considerably less tightly knit than expected. The loosening techniques may resemble those of a subordinate theme: redundant repetitions, cadential extensions and expansions, and internal dominant arrivals. Although the form-functional characteristics may resemble a subordinate theme, the melodic, rhythmic, and textural aspects are usually typical of a main theme (especially "opening up" gestures and marked discontinuities). As a rule, a loosely organized main theme is still more tightly knit than the subordinate theme (Caplin, Ch. 10, pp. 318-319).

# Key Properties
1. Uses loosening devices typically associated with subordinate themes
2. Still maintains melodic/rhythmic/textural qualities typical of main themes
3. Comparison with actual subordinate theme reveals the main theme to be tighter
4. "Opening up" gestures and rhythmic discontinuities signal main-theme identity

# Examples
**Example 1** (p. 319): Beethoven, Op. 2/2, i, mm. 1-32 -- Loose main theme with expanded antecedent, extensions; but subordinate theme (Ex. 12.8) is even looser with modal shift, chromatic sequences, expanded cadential progressions.
