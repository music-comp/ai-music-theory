# Quick Definition
A moment when main-theme material returns within the development section in a development key (not the home key), creating the impression of recapitulation before the true one arrives.

# Core Definition
"A retransition sometimes starts with reference to the opening material from the main theme, usually in the development key just confirmed by a prior HC" (p. 471). This effect is characterized as a false recapitulation. "Although the gesture is recapitulatory, the tonal requirements of a genuine recapitulation are not met." The music eventually modulates back to the home key, and the passage from the false recapitulation to the real one functions as a retransition.

# Prerequisites
- **Retransition** — The false recapitulation functions within it
- **Recapitulation** — Must understand the true recapitulation's requirements
- **Double return** — The tonal requirement the false recapitulation fails to meet

# Key Properties
1. Uses opening material from the main theme
2. Set in a development key, not the home key
3. Gesture is recapitulatory but tonal requirements are not met
4. Eventually modulates back to home key for true recapitulation
5. The passage from false to true recapitulation = retransition
6. Usually follows a core ending with HC or dominant arrival in development key

# Construction / Recognition
## To Identify:
1. Main-theme material appears after the core's conclusion
2. The key is NOT the home key — it is still a development key
3. Following the false opening, the music modulates home
4. The true recapitulation follows after HC and standing on dominant in the home key

# Examples
**Example 13.13** (p. 472): Beethoven, Piano Sonata in G, Op. 14, No. 2, i — core ends on dominant of E-flat (bVI); following the fermata (m. 98), main-theme material appears in E-flat (development key); after presentation, music modulates home; HC at m. 107; true recapitulation at m. 125.

# Relationships
## Builds Upon
- **Retransition** — The false recapitulation functions within the retransition
## Contrasts With
- **Recapitulation** — The false version lacks the tonal requirements (home-key tonic)

# Common Errors
- **Error**: Identifying the false recapitulation as the true recapitulation
  **Correction**: Verify the tonal context — a genuine recapitulation requires the home key (the "double return"), not just main-theme material
