# False Recapitulation

When main theme material returns in a development key, creating the impression of recapitulation before the true one arrives.

## Definition

A retransition sometimes starts with reference to the opening material from the main theme, usually in the development key just confirmed by a prior HC. This effect is characterized as a false recapitulation.

## Characteristics

- Uses opening material from main theme
- Set in development key (not home key)
- Gesture is recapitulatory but tonal requirements are not met
- Eventually the music returns to home key for true recapitulation
- Functions as part of the retransition

## Typical Pattern

1. Core ends with HC or dominant arrival in development key
2. Main theme material appears in that development key
3. Following the opening presentation, music modulates back home
4. HC confirms home key, followed by standing on dominant
5. True recapitulation begins in home key

## Expressive Effect

Creates a moment of premature arrival that heightens anticipation for the genuine recapitulation.
