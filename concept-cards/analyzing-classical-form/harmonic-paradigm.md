# Quick Definition
A simple, model harmonic progression written as a short example, typically in C major and four-voice texture, demonstrating a specific type of progression or technique.

# Formal Definition
Harmonic paradigms are simple examples that demonstrate specific types of harmonic progressions or techniques. They take the form of short, four-voice progressions typically written in C major, with an upper voice that is typical for the progression. Most paradigms can also appear in minor mode with the usual alterations.

# Musical/Theoretical Formulation
Characteristics of paradigms in this chapter:
- Written in C major (or C minor when specifically minor-mode)
- Set in four voices
- Feature typical upper-voice motion for the progression
- Demonstrate one specific harmonic technique or progression type
- Serve as models for understanding real musical passages

Types of paradigms demonstrated:
- Prolongational progressions (pedal, neighboring, passing, substitute)
- Cadential progressions (authentic, half, deceptive)
- Sequential progressions (all six types)

# Musical Context/Application
Paradigms serve to:
- Isolate and illustrate specific harmonic techniques
- Provide reference models for analysis
- Demonstrate proper voice leading
- Show typical melodic patterns for each progression type

The paradigms can be transposed to any key and adapted to various textures in actual compositions.

# Common Confusions
- Treating paradigms as the only possible voicings (they are models, not prescriptions)
- Not recognizing that real music varies from paradigmatic models
- Assuming major-mode paradigms don't apply to minor (most can be adapted)
- Overlooking the "typical upper voice" as part of the paradigm's instruction
