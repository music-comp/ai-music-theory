# Quick Definition
A simple, model harmonic progression written as a short example in C major and four-voice texture, demonstrating a specific type of progression or technique.

# Core Definition
"Many of the examples in this chapter take the form of simple 'paradigms' written in the key of C major. They are usually set in four voices, with an upper voice that is typical for the progression. Most of the paradigms can also appear in minor (with the usual alterations). Paradigms associated especially with the minor are set in that mode" (p. 26). They serve as reference models for analyzing real musical passages.

# Prerequisites
- None specific; paradigms are introductory teaching tools

# Key Properties
1. Written in C major (or C minor for minor-specific topics)
2. Set in four voices
3. Feature a typical upper-voice melody for each progression type
4. Demonstrate one specific harmonic technique or progression type
5. Serve as models for understanding real musical passages
6. Most can be adapted to minor mode with standard alterations

# Construction / Recognition
## To Identify:
1. Look for short, four-voice examples in C major
2. Note the specific progression type being demonstrated
3. Observe the typical upper-voice motion associated with the progression
4. Recognize that the paradigm can be transposed and adapted to actual compositions

# Context & Application
Paradigms isolate and illustrate specific harmonic techniques, providing reference models for analysis. They demonstrate proper voice leading, show typical melodic patterns for each progression type, and can be transposed to any key and adapted to various textures in actual compositions. Examples 1.1-1.3, 1.7-1.22 present paradigms for prolongational, cadential, and sequential progression types.

# Common Errors
- **Error**: Treating paradigms as the only possible voicings
  **Correction**: Paradigms are models; real music varies considerably from paradigmatic forms

# Common Confusions
- **Confusion**: Assuming major-mode paradigms do not apply to minor
  **Clarification**: Most paradigms can appear in minor with the usual alterations; only those specifically associated with minor are presented in that mode
