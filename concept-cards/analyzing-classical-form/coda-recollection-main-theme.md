# Quick Definition
The most common compensatory function of the coda: recalling main-theme ideas to create a circular design for the overall form, since sonata form otherwise brings the main theme back only at the recapitulation's start.

# Core Definition
"The notion that the musical material at the beginning of a movement should return toward its end — thus lending a kind of circularity to the overall form — gained a certain currency in the classical period" (p. 560). Some forms require this (rondo, sonata-rondo), but "other formal types, such as the sonata and minuet, call for the return of the main theme only at the beginning of the recapitulation. In these forms, if the composers wish to bring back main-theme material late in the movement, they normally have to place it in a coda." This is "perhaps the coda's principal compensatory function, for most codas refer at some point to main-theme ideas."

# Key Properties
1. Most common compensatory function — most codas refer to main-theme ideas
2. Creates circular design for the overall form
3. Necessary because sonata form only returns main theme at recapitulation's start
4. Material may retain tight-knit form, be loosened, or function as closing section
5. When exclusively tonic-supported, main-theme material functions as closing section

# Examples
**Example 15.8** (p. 561): Haydn, Symphony No. 97, i — fanfare opening returns at m. 279; root-position tonic retained obsessively, prohibiting cadential activity; main-theme material now functions as closing section.
