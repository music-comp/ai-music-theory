# Quick Definition
Music can express its intrinsic temporal function (what it "sounds like" -- beginning, middle, or end) independent of its contextual location (where it actually appears in a theme). When these differ -- e.g., a "middle" function at a theme's beginning -- a formal "dissonance" results. If carefully controlled, this dissonance expresses loose organization; if excessive, it produces functional illogic.

# Core Definition
Formal functionality involves how music expresses its logical location in a temporal spectrum of beginnings, middles, and ends. One special property of music is the capacity to express its **intrinsic** temporal function independent of its **contextual** location. Because formal functions are so conventionalized and well defined by their specific characteristics, we can identify a function without necessarily taking into account its actual position. When contextual placement differs from intrinsic expression -- a medial function (continuation) at a structural beginning, for example -- a **formal "dissonance"** results. If carefully controlled, this dissonance expresses loose organization; too great a dissonance produces an illogical succession of functions (Caplin, Ch. 12, pp. 412-413).

# Key Properties
1. Intrinsic function: what the music "sounds like" (beginning/middle/end)
2. Contextual function: where it actually appears in the form
3. Functions are so conventionalized that intrinsic identification is possible
4. Mismatch creates "formal dissonance"
5. Controlled dissonance = loose organization (appropriate for subordinate themes)
6. Excessive dissonance = functional illogic

# Context & Application
This concept is central to understanding subordinate themes that begin with continuation, cadential function, or standing on the dominant. Sequential harmonies at a theme's opening intrinsically signal continuation; their contextual position as a theme's beginning creates formal dissonance expressing looseness.

# Examples
**Example 1**: A subordinate theme beginning with model-sequence technique -- intrinsically continuation, contextually a beginning -- creates formal dissonance expressing loose organization.
