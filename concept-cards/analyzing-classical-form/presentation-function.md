# Quick Definition
An initiating formal function that creates a solid structural beginning for the theme by establishing melodic-motivic content within a stable (tonic prolongational) harmonic environment. Distinguished from the presentation phrase (a grouping-structure term): the function concerns temporal initiation, the phrase concerns the 4-m. unit.

# Core Definition
Presentation function creates a solid structural beginning for the theme by establishing its melodic-motivic content within a stable harmonic-tonal environment. The initial statement of the basic idea sets forth the fundamental material of the theme, and the immediate repetition fully "presents" it to the listener. The underlying tonic prolongational progression provides the requisite harmonic stability (p. 68). The terms "presentation phrase" and "presentation function" refer to different phenomena: the former is a term of grouping structure, the latter of formal function (p. 69).

# Prerequisites
- **Sentence** — Presentation is one of three formal functions of the sentence
- **Basic idea** — The b.i. and its repetition express presentation function

# Key Properties
1. Initiating formal function -- articulates "beginning"
2. Establishes melodic-motivic content through statement and repetition
3. Requires tonic prolongational harmony (stability)
4. Enhances formal initiation through b.i. repetition
5. Distinguished from presentation phrase (grouping vs. function)
6. B.i. is itself an initiating function at a lower structural level

# Construction / Recognition
## To Identify:
1. Look for b.i. statement + repetition with tonic prolongation
2. Verify no cadential closure
3. Note the distinction between the phrase (4-m. unit) and the function (temporal beginning)

# Context & Application
Presentation function is one of three temporal functions of the sentence: presentation (beginning), continuation (middle), cadential (ending). The distinction between grouping structure and formal function is central to Caplin's approach.

# Examples
**Example 1** (p. 56, Ex. 2.1): Beethoven, Op. 2, No. 1 -- tonic version + dominant version create presentation function within a 4-m. presentation phrase.

# Common Errors
- **Error**: Confusing presentation phrase with presentation function
  **Correction**: The phrase is a grouping unit; the function is a temporal role

# Common Confusions
- **Confusion**: Thinking presentation function requires exact repetition
  **Clarification**: Statement-response and sequential repetition also express presentation function
