# Quick Definition
A contrapuntal embellishment where a seventh above the bass suspends and resolves to a sixth, commonly applied in series to embellish descending-second sequential progressions.

# Core Definition
The 7-6 suspension is a contrapuntal ornament frequently used to embellish the descending-second (stepwise) sequential progression. The basic descending-second sequence uses all first-inversion chords (to avoid parallel fifths), and the 7-6 suspension adds melodic interest by creating a chain of preparation-suspension-resolution patterns over this foundation (Caplin, p. 45).

# Prerequisites
- **Voice leading** — The 7-6 suspension is a voice-leading embellishment
- **Parallel fifths** — The underlying first-inversion foundation avoids parallel fifths

# Key Properties
1. Upper voice sustains the seventh above bass, then resolves to sixth
2. Creates preparation-suspension-resolution pattern
3. Applied in series within descending-second sequences
4. The seventh is dissonant, the sixth consonant
5. Creates alternating tension and release
6. The underlying progression uses first-inversion chords

# Construction / Recognition
## To Identify:
1. Locate a descending-second sequential progression
2. Check for first-inversion chords as the foundation
3. Look for the upper voice alternating between seventh and sixth above the bass
4. Verify the pattern repeats in series through the sequence

# Context & Application
The 7-6 suspension embellishes descending-second sequences, adding melodic and rhythmic variety while maintaining proper voice leading. It transforms a simple stepwise descent into a more elaborate melodic-contrapuntal texture through chains of dissonance-resolution motions.

## Contrasts With
- **5-6 pattern** — 7-6 uses dissonance-resolution in descending sequences; 5-6 uses consonant alternation in ascending sequences

# Common Errors
- **Error**: Treating suspended notes as chord tones
  **Correction**: The seventh is a suspended dissonance resolving to the consonant sixth; it is not a structural chord tone

# Common Confusions
- **Confusion**: Confusing 7-6 suspension with 5-6 pattern
  **Clarification**: 7-6 embellishes descending-second sequences with dissonance-resolution; 5-6 solves parallel fifths in ascending-second sequences
