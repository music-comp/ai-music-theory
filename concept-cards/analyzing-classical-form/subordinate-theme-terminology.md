# Quick Definition
Caplin prefers "subordinate theme" over traditional terms like "second theme," "secondary theme," or "second subject" because these imply a numbering scheme (starting from a "first theme") that often cannot be sustained in analysis. The term "subordinate" does not imply inferior aesthetic value but relates directly to the "subordinate key" confirmed by this theme.

# Core Definition
Various terms have traditionally been used for what Caplin calls the subordinate theme: "second theme," "secondary theme," and "second subject." These terms are problematic because they suggest a numbering scheme starting from the "first theme" (main theme) that often cannot be sustained in analysis -- a given subordinate theme is not necessarily the literal "second" theme of a movement. The term "subordinate theme" does not imply a theme of inferior aesthetic value; rather, it relates directly to the expression "subordinate key," accurately describing the tonal region confirmed by this theme. The terminological choice thus reflects the form-functional emphasis on the subordinate theme's tonal role: confirming the subordinate key with a PAC (Caplin, Ch. 12, p. 376).

# Key Properties
1. Traditional terms: "second theme," "secondary theme," "second subject"
2. These imply numbering that breaks down in practice
3. "Subordinate" does NOT imply inferior value

5. Emphasizes form-functional relationship between theme and key
6. More analytically precise than numbering-based alternatives

# Construction / Recognition
## To Identify:
1. Use "subordinate theme" for the thematic function that confirms the subordinate key with a PAC
2. Avoid "second theme" unless the literal position warrants it
3. In a group of multiple subordinate themes, number them: subordinate theme 1, 2, 3, etc.

# Context & Application
The terminological choice has analytical consequences. Using "second theme" implies a sequential ordering from "first theme" that can mislead when the exposition contains more than two main thematic areas. Using "subordinate theme" foregrounds the functional relationship to the subordinate key and avoids the implication that the theme is numerically second in a sequence.
