# Quick Definition
When comparing exposition and recapitulation, changes are classified as ornamental (melody, texture, dynamics, instrumentation, accompaniment -- not affecting fundamental organization) or structural (tonality, harmony, grouping structure, formal functions -- altering fundamental organization).

# Core Definition
Ornamental changes affect aspects that do not alter the fundamental organization: melodic embellishment, texture (added or reduced voices), dynamics (louder or softer), instrumentation (different instruments), and accompanimental patterning. Structural changes alter the fundamental organization: tonality (tonal adjustment), harmony (different progression), basic melodic patterning, grouping structure (different phrase lengths), and formal functions (different phrase types). The analytical procedure involves four steps: (1) compare exposition and recapitulation bar by bar; (2) observe every change; (3) classify each change as ornamental or structural; (4) ask why -- what musical purpose does the change serve? When sections are identical, one should ask why the composer maintained identity and what purposes exact repetition serves.

# Key Properties
1. Ornamental: melody, texture, dynamics, instrumentation, accompaniment
2. Structural: tonality, harmony, grouping structure, formal functions
3. Four-step procedure: compare, observe, classify, ask why
4. Identical sections also merit analysis (why no changes?)
5. Clear answers may not always be found
6. The effort to understand changes always yields insights

# Construction / Recognition
## Classification Guide:
| Change Type | Category | Affects Fundamental Organization? |
|-------------|----------|----------------------------------|
| Melodic embellishment | Ornamental | No |
| Texture variation | Ornamental | No |
| Dynamic changes | Ornamental | No |
| Instrumentation | Ornamental | No |
| Accompanimental pattern | Ornamental | No |
| Tonal adjustment | Structural | Yes |
| Different harmonic progression | Structural | Yes |
| Different phrase lengths | Structural | Yes |
| Different formal functions | Structural | Yes |

# Context & Application
This classification system, introduced for the small ternary, applies equally to sonata-form recapitulations (Ch. 9). The distinction helps analysts prioritize their attention: structural changes reveal deep compositional choices about form and tonal plan, while ornamental changes show how the composer refreshes material without altering its essential structure. Both are worth noting, but structural changes carry greater analytical significance.
