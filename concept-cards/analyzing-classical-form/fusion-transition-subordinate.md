# Quick Definition
Form-functional fusion occurs when a single thematic unit embraces both transition and subordinate-theme functions: it modulates to the new key (transition function) and achieves PAC closure there (subordinate-theme function), but no clear boundary between the two functions is identifiable. Annotate as "transition/subordinate theme" with the slash indicating fusion.

# Core Definition
In some expositions, we cannot identify either a clear concluding function for the transition or an initiating function for the subordinate theme, yet essential elements of both are present. Transition function is expressed by modulation; subordinate-theme function by PAC closure and cadential extensions typical of subordinate themes. The concept of form-functional **fusion** means a single thematic unit embraces both functions. It is not possible to find an appropriate initiating moment for the subordinate theme, even in retrospect. Three situations create obscured boundaries: (1) transition lacks concluding function, (2) subordinate theme lacks initiating function, (3) both are missing. Annotate: **transition/subordinate theme**, with the slash (/) indicating fusion (Caplin, Ch. 12, pp. 423-430).

# Key Properties
1. Single thematic unit embracing both transition and subordinate-theme functions
2. Transition function: modulation to new key
3. Subordinate-theme function: PAC closure in new key + cadential extensions
4. No clear boundary identifiable, even in retrospect
5. Three situations: transition lacks end, subordinate theme lacks beginning, or both
6. Annotation: "transition/subordinate theme" (slash = fusion)
7. Especially common in Haydn

# Context & Application
When encountering fusion, there is no clear spot to position the second functional label. The slash notation acknowledges that two functions share a single thematic unit without claiming to identify where one ends and the other begins.
