# Quick Definition
A systematic approach to analyzing classical themes: (1) identify cadences and label them (PAC, IAC, HC); (2) determine theme length (8 m. simple or 16 m. compound, accounting for R = 2N or R = 1/2N); (3) divide into phrases and identify phrase deviations; (4) determine phrase functions (presentation, continuation, antecedent, consequent); (5) identify theme type; (6) consider ambiguities.

# Core Definition
Formal analysis of classical themes proceeds from the general to the specific, and from the most objectively identifiable features to those requiring more interpretation. Cadences should be identified first, since they are the most structurally significant events and their type (PAC, IAC, HC) has direct formal consequences (p. 77). The label should be placed where the final harmony of the cadential progression first appears (p. 80). Theme length must account for the relationship between real and notated measures (R = 2N or R = 1/2N). Phrase functions are then determined by examining harmonic, melodic, and rhythmic processes. Finally, the combination of phrase functions identifies the theme type: sentence (presentation + continuation), period (antecedent + consequent), hybrid, or compound.

# Key Properties
1. Start with cadences -- the most structurally significant features
2. Label cadences at the point of cadential arrival (where final harmony first appears)
3. Determine real measure count (accounting for notational devices)
4. Divide into phrases (typically 4 m. each in simple themes)
5. Identify phrase functions by examining continuation characteristics, harmonic support, etc.
6. Theme type follows from the combination of phrase functions
7. Embrace ambiguity rather than forcing simple labels

# Construction / Recognition
## To Analyze:
1. Locate all cadences; label each as PAC, IAC, or HC with measure numbers
2. Count real measures; determine if simple (8 m.) or compound (16 m.)
3. Divide into phrases; note any deviations (extensions, expansions, compressions)
4. For each phrase, determine function: Is it initiating (presentation/antecedent), medial (continuation), or concluding (cadential/consequent)?
5. Match phrase-function combination to theme type
6. Consider whether alternative interpretations are possible

# Context & Application
This workflow applies to all theme analysis throughout the book. The approach emphasizes that formal analysis is not purely mechanical; identifying harmonic acceleration, for instance, "relies on a good deal of musical judgment and experience" (p. 75). Ambiguity is common -- some passages may support multiple valid readings, and analysts should embrace this complexity rather than forcing a single interpretation.

# Examples
**Example 1** (p. 56, Ex. 2.1): Beethoven, Op. 2, No. 1, i -- applying workflow: HC at m. 8; 8 m. theme; presentation (mm. 1-4) + continuation (mm. 5-8); therefore sentence.
**Example 2** (p. 96, Ex. 3.1): Mozart, K. 525, ii -- HC at m. 4, PAC at m. 8; 8 m.; antecedent (mm. 1-4) + consequent (mm. 5-8); therefore period.

# Common Errors
- **Error**: Identifying theme type before analyzing cadences and phrase functions
  **Correction**: Always start with cadences; theme type is the conclusion, not the starting assumption

# Common Confusions
- **Confusion**: Expecting every theme to fit neatly into one category
  **Clarification**: Many themes are ambiguous or deviant; consider alternative interpretations and note what evidence supports each reading
