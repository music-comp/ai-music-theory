# Formal Analysis Workflow

A systematic approach to analyzing classical themes helps ensure thorough and accurate identification of formal structures.

## Step 1: Identify Cadences

- Locate all cadences in the theme
- Label each as PAC, IAC, or HC
- Note measure numbers of cadential arrivals

## Step 2: Determine Theme Length

- Count real measures (consider R = ½N or R = 2N)
- Identify 8m (simple) or 16m (compound) structure
- Note any deviations from normative length

## Step 3: Identify Phrase Structure

- Divide theme into phrases (typically 4m each)
- Identify any phrase deviations
- Note extensions, compressions, internal expansions

## Step 4: Analyze Phrase Functions

For each phrase, determine:
- Is it initiating, medial, or concluding?
- What specific function (presentation, continuation, antecedent, etc.)?
- What evidence supports this identification?

## Step 5: Identify Theme Type

Based on phrase functions:
- Sentence: Presentation + Continuation
- Period: Antecedent + Consequent
- Hybrid: One of four types
- Compound: 16m versions of above

## Step 6: Consider Ambiguities

- Are alternative interpretations possible?
- What evidence supports each reading?
- Embrace complexity rather than forcing simple labels
