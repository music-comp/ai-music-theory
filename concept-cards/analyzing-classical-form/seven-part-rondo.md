## Definition

The seven-part rondo is an enlarged version of the five-part rondo, created by adding an additional couplet and return of the refrain. The result is an ABACADA pattern.

## Structure

| Section | Function |
|---------|----------|
| Refrain 1 (A) | Main theme |
| Couplet 1 (B) | Subordinate-theme complex or interior theme |
| Refrain 2 (A) | First return |
| Couplet 2 (C) | Interior theme |
| Refrain 3 (A) | Second return |
| Couplet 3 (D) | **Additional** interior theme |
| Refrain 4 (A) | Final return |

## Additional Couplet Characteristics

The extra couplet is usually organized as an **interior theme**:
- Melodic-motivic material differs from earlier interior themes
- Tonal region contrasts with previous couplets
- Formal organization provides variety

## Important Distinction

The regular sonata-rondo (ABACABA) also has seven parts, but the seven-part rondo is **not** a sonata-rondo:
- Seven-part rondo: Does not contain a couplet construed as recapitulation of subordinate-theme complex
- Sonata-rondo: Couplet 3 recapitulates couplet 1 material

## Example

Haydn, Piano Sonata in A-flat, H. 43, iii: A seven-part rondo
