# Quick Definition
All rondo forms feature a principal theme (refrain) alternating with contrasting passages (couplets). The two main classical types are the five-part rondo (ABACA) and the sonata-rondo (ABACABA). Letter labels are inadequate because they indicate melodic material but not formal function.

# Core Definition
All rondo forms display the same basic pattern: a principal thematic idea (the refrain) alternates regularly with two or more contrasting passages (couplets). In the classical era, most rondos relate to two general types: the five-part rondo (ABACA) and the sonata-rondo (ABACABA). It is more useful to identify parts as refrains or couplets (numbered by position) with labels specifying formal function, rather than using letter labels (Caplin, pp. 664-665).

# Prerequisites
- **Sonata form** -- Required for understanding sonata-rondo's sonata aspects
- **Small ternary** -- Common form for the refrain

# Key Properties
1. Refrain (A) alternates with couplets (B, C)
2. Two main classical types: five-part rondo and sonata-rondo
3. Letter labels (ABACA, ABACABA) are traditional but limited
4. Better to use refrain/couplet labels with formal function designations
5. Rondo derives from French rondeau (Baroque); sonata derives from Italian binary dance
6. Quick identification: rondos lack internal repeat signs dividing the movement

# Construction / Recognition
## To Identify:
1. Look for a main theme that returns multiple times in the home key
2. Check for contrasting couplets between refrain statements
3. Look for absence of internal repeat signs (exposition repeat) -- suggests rondo over sonata
4. Determine whether the form is five-part or seven-part (sonata-rondo)

# Context & Application
Rondos are used most often for finales (sonata-rondo) or slow movements (five-part rondo). The dramatic emphasis falls on the return of the refrain rather than on tonal conflict.

# Common Confusions
- **Confusion**: Using A-B-A' letter labels interchangeably with small ternary labels
  **Clarification**: Rondo letter labels refer to different formal units than small ternary labels; adopt refrain/couplet terminology instead
