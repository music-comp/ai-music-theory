# Quick Definition
A slow introduction resides on the hierarchical level of exposition/development/recapitulation and contains thematic units, while a thematic introduction resides on the level of basic/contrasting ideas with no melodic profile — analogous to the coda/codetta distinction.

# Core Definition
"Just as a coda must be distinguished from a codetta, so too must a slow introduction be differentiated from an introduction that precedes a theme" (p. 573). A thematic introduction "resides on a hierarchical level comparable to that of a basic idea, contrasting idea, etc. This short unit is normally supported by a tonic prolongation and generally has no melodic profile." A slow introduction "resides on a level comparable to that of an exposition, development, recapitulation, and coda, and it normally consists of one or more thematic units."

# Key Properties
1. Both express before-the-beginning temporal function
2. Differ in hierarchical location: thematic intro = idea level; slow intro = section level
3. Differ in formal organization: thematic intro = short, tonic prolongation, no melody; slow intro = thematic units, varied harmonies
4. Parallel to coda/codetta distinction
