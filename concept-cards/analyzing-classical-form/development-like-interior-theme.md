# Quick Definition
Occasionally, an interior theme takes on the organization of a sonata-like development section, featuring model-sequence technique, exploration of multiple tonal regions, and characteristics of a core, while still maintaining the minore tonal framework typical of interior themes.

# Core Definition
Sometimes the interior theme functions more like a genuine development section, with model-sequence organization, a "dominant version" of the opening idea, cadences of "limited scope" within sequential passages, and a standing on the dominant. Despite these developmental features, all tonal regions explored relate to the minor mode of the home key, maintaining the minore character of an interior theme (Caplin, pp. 604-605).

# Prerequisites
- **Interior theme** -- The formal function that occasionally takes on development-like features
- **Development** -- The sonata-form section whose techniques are borrowed

# Key Properties
1. Model-sequence organization with "dominant version" of opening idea
2. Exploration of multiple tonal regions (e.g., bVI, iv, bII)
3. Fragmentation following sequences
4. Cadences of "limited scope" within sequential passages
5. Standing on the dominant and possible false recapitulation
6. All tonal regions relate to minor mode of home key (preserving minore character)
7. Resembles a core without a pre-core

# Construction / Recognition
## To Identify:
1. Look for model-sequence technique within an interior theme
2. Check for exploration of multiple tonal regions
3. Confirm the regions relate to the minore (not to standard development keys)
4. Note the standing on the dominant leading to main theme return

# Context & Application
This variant demonstrates the flexibility of the interior theme concept. While primarily a formal function associated with modal contrast, it can absorb developmental techniques. The key analytical distinction is that the tonal regions still relate to the minore framework, not to the typical development-key areas.

# Examples
**Example 1** (p. 605): Beethoven, Piano Sonata in E-flat, Op. 7, ii -- interior theme (mm. 25-50) in A-flat major (bVI), features descending-third sequential motion through A-flat, F minor, and D-flat major, arrives on home-key HC, includes standing on the dominant with false recapitulation.

# Common Errors
- **Error**: Classifying a development-like interior theme as a true development section
