# Quick Definition
Three terms for "saying something again": restatement (general term for any re-presentation), repetition (immediate, without intervening material -- sentence), and return (after intervening contrasting material -- period). "The consequent phrase repeats the antecedent by bringing a return of the original basic idea."

# Core Definition
The general term used to describe the process of presenting material again is restatement. A restatement occurring immediately, without intervening material, is termed a repetition. A restatement occurring after intervening contrasting material is termed a return. Usage: "The consequent phrase repeats the antecedent by bringing a return of the original basic idea" -- nothing stands between antecedent and consequent (repeat), but the two statements of the b.i. are separated by intervening material (return) (p. 105).

# Prerequisites
- **Basic idea** — The b.i. is the material being restated/repeated/returned

# Key Properties
1. Restatement: general term for any re-presentation of prior material
2. Repetition: immediate restatement without intervening material
3. Return: restatement after intervening contrasting material
4. Sentence: b.i. is repeated (mm. 1-2 -> mm. 3-4, no intervening material)
5. Period: b.i. returns (mm. 1-2 -> mm. 5-6, after contrasting idea)

# Construction / Recognition
## To Apply:
1. Restatement: any re-presentation
2. Repetition: nothing intervenes between statements
3. Return: contrasting material intervenes

# Context & Application
This terminological precision is important for accurate formal analysis. In a period, "the consequent phrase repeats the antecedent by bringing a return of the original basic idea" -- both terms are technically correct for different aspects of the situation.

# Examples
**Example 1** (p. 105): "The consequent phrase repeats the antecedent by bringing a return of the original basic idea."

# Common Errors
- **Error**: Using "repetition" and "return" interchangeably
  **Correction**: Repetition is immediate; return is after contrasting material

# Common Confusions
- **Confusion**: Thinking "return" implies identical restatement
  **Clarification**: Returns may be varied, transposed, or embellished
