# Quick Definition
The main theme's closing cadence may be deleted in the recapitulation because the home key will necessarily be confirmed later in the subordinate theme, making cadential articulation at the end of the main theme dispensable.

# Core Definition
In the exposition, the main theme's cadence serves to establish and confirm the home key and provide clear articulation before the transition. In the recapitulation, the home key was already reestablished toward the end of the development and will receive ultimate confirmation later in the subordinate-theme area. A cadence to end the main theme is therefore dispensable, and its deletion creates greater continuity between the main theme and transition, potentially leading to the fusion of these units.

# Prerequisites
- Understanding of recapitulation harmonic-tonal organization
- Familiarity with deletion of thematic restatements in the recapitulation

# Key Properties
- Main theme's closing cadence eliminated in recapitulation
- Home key already reestablished at end of development
- Home key will receive ultimate confirmation in subordinate theme
- Cadential articulation between main theme and transition becomes unnecessary
- Creates greater continuity and forward momentum
- May lead to fusion of main theme and transition

# Construction / Recognition
Compare the end of the main theme in the exposition and recapitulation. If the exposition's main theme ends with a clear cadence (PAC or HC) but the recapitulation's main theme flows directly into transition material without cadential articulation, a deletion of the home-key cadence has occurred.

# Context & Application
This deletion is one of several structural changes that reflect the different formal functions the main theme serves in the recapitulation versus the exposition. In the exposition, the main theme must introduce, establish, and confirm the home key. In the recapitulation, these functions are no longer required; the main theme primarily signals "return" and "rebeginning." Eliminating the cadence thus removes a redundancy and creates a more streamlined formal design.

# Examples
- General pattern: exposition main theme ends with PAC, recapitulation main theme flows directly into transition without cadence
- Often combined with deletion of thematic restatements and fusion of main theme and transition

# Common Errors
- Assuming every main theme must end with a cadence in the recapitulation
- Failing to recognize that the absence of a cadence is a deliberate structural change, not an oversight

# Common Confusions
- The deletion of the home-key cadence is NOT the same as an evaded cadence -- the cadential process itself is eliminated, not merely deflected
