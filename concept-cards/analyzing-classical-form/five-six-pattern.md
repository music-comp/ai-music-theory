# Quick Definition
A contrapuntal technique where an upper voice alternates between a fifth and sixth above the bass, used especially in ascending-second sequences to avoid parallel fifths.

# Formal Definition
The 5-6 pattern is a contrapuntal procedure where one of the upper voices moves from a fifth above the bass to a sixth, creating an alternation that breaks up potential parallel fifths in stepwise progressions. This technique generates intervening first-inversion chords that stand, by analogy, in a dominant-to-tonic relationship to the succeeding root-position chords.

# Musical/Theoretical Formulation
How the pattern works:
- Bass moves stepwise (e.g., 1-2-3-4)
- Upper voice alternates: 5-6-5-6 above bass
- Creates alternation: root position - first inversion
- Breaks the parallel fifths that would occur in simple root-position motion

Functional implication:
- Each six-three chord resembles a dominant of the following harmony
- Creates chain of implied V-I motions
- Can be enhanced with chromatic alterations (genuine secondary dominants)

# Musical Context/Application
The 5-6 pattern:
- Solves the parallel-fifth problem in ascending stepwise motion
- Is the standard solution for ascending-second sequences
- Generates first-inversion interpolations between root-position chords
- May be chromatically altered for stronger functional effect

The technique appears more often than the first-inversion-only solution for ascending-second sequences.

# Examples
Example 1.22b-d (pp. 45-46) demonstrates the 5-6 pattern:
- (b) Basic 5-6 pattern with upper voice motion against bass
- (c) Chromatic alterations making each six-three a genuine secondary dominant

# Common Confusions
- Not recognizing the 5-6 pattern as a voice-leading solution
- Missing the implied dominant-tonic relationships created by the pattern
- Confusing with 7-6 pattern (different technique, different context)
- Treating the interpolated chords as equally structural to the main harmonies
