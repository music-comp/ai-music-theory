# Quick Definition
A contrapuntal technique where an upper voice alternates between a fifth and sixth above the bass, used especially in ascending-second sequences to avoid parallel fifths.

# Core Definition
The 5-6 pattern is a contrapuntal procedure where one upper voice moves from a fifth above the bass to a sixth, generating intervening first-inversion chords that break up parallel fifths in stepwise progressions. "The stepwise ascent usually remains in root position, while the parallel fifths are broken up by means of a 5-6 pattern formed by one of the upper voices against the bass" (p. 45). The resulting six-three chords stand, by analogy, in a dominant-to-tonic relationship to the succeeding root-position chords.

# Prerequisites
- **Parallel fifths** — The 5-6 pattern exists to solve the parallel-fifth problem
- **Voice leading** — Understanding interval motion between voices

# Key Properties
1. Upper voice alternates: 5-6-5-6 above a stepwise bass
2. Creates alternation between root-position and first-inversion chords
3. Breaks parallel fifths that would occur in simple root-position stepwise motion
4. Each interpolated six-three chord resembles a dominant of the following harmony
5. Can be enhanced with chromatic alterations creating genuine secondary dominants

# Construction / Recognition
## To Identify:
1. Look for stepwise bass motion (ascending seconds)
2. Check the upper voice for alternating fifths and sixths above the bass
3. Note the alternation between root-position and first-inversion chords
4. In chromatic variants, the six-three chords become genuine secondary dominants

# Context & Application
The 5-6 pattern is the standard solution for ascending-second sequences, where simple root-position stepwise motion would produce parallel fifths. The pattern generates first-inversion interpolations between root-position chords, and each interpolated chord implies dominant-to-tonic motion at the next step. Chromatic alteration can strengthen this implication by converting each six-three chord into a genuine secondary dominant.

# Common Errors
- **Error**: Not recognizing the 5-6 pattern as a voice-leading solution
  **Correction**: The pattern exists specifically to avoid parallel fifths in ascending stepwise motion

# Common Confusions
- **Confusion**: Confusing the 5-6 pattern with the 7-6 suspension
  **Clarification**: The 5-6 pattern uses consonant intervals in ascending sequences; the 7-6 suspension uses dissonance-resolution in descending sequences
