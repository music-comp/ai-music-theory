# Quick Definition
A frequently occurring sequential progression with roots descending by thirds (I-VI-IV-II). Often embellished with passing chords that fill in bass leaps and introduce implied dominant-tonic relationships at each step.

# Core Definition
The descending-third progression is a frequently occurring sequence. More often than not, the leap in the bass voice is filled in by stepwise motion, producing intervening passing chords in first inversion. These passing chords stand as "dominants" (literally or by analogy) to the preceding root-position chord, then resolve "deceptively" to the next root-position chord (a tonic substitute) (pp. 43-44).

# Prerequisites
- **Sequential progression** — This is one of six types

# Key Properties
1. Frequently used in classical music
2. Basic pattern: I-VI-IV-II (roots descend by thirds)
3. Often embellished with first-inversion passing chords filling bass leaps
4. Each passing chord implies V of the preceding harmony, resolving deceptively
5. Functional interpretation becomes more evident with root-position passing chords (Ex. 1.19d)

# Construction / Recognition
## To Identify:
1. Look for roots moving consistently by descending third
2. Check for passing chords creating stepwise bass motion between main harmonies
3. Note the implied V-I-then-deceptive pattern at each link

# Context & Application
The descending-third sequence creates rich harmonic texture when embellished. The passing chords introduce harmonic-functional color while maintaining sequential logic.

# Common Errors
- **Error**: Treating the passing chords as structurally equal to the main harmonies
  **Correction**: Passing chords are subordinate embellishments of the sequential pattern

# Common Confusions
- **Confusion**: Confusing the "deceptive" resolution of passing chords with actual deceptive cadences
  **Clarification**: The deceptive quality is analogical within the sequence, not a formal cadential event
