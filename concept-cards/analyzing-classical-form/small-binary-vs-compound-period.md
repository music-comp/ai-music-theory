# Quick Definition
When Part 1 of a small binary ends with an HC, one might think it is a compound antecedent. But if this unit is fully repeated (ending again with HC), the compound period option is no longer viable: the antecedent of any period is never repeated prior to the onset of the consequent. Reinterpret as Part 1 of a small binary.

# Core Definition
The whole effect of a periodic formation is that the first repetition of an opening unit brings stronger cadential closure. If a presumed compound antecedent is fully repeated (with repeat signs or written out), and ends again with the same weak cadence, we should reinterpret that structure as Part 1 of a small binary, not a compound antecedent. The period option requires that the first repetition bring a consequent with stronger closure.

# Key Properties
1. If HC-ending unit is repeated and ends again with HC: small binary
2. Period requires first repetition to bring stronger closure (consequent)
3. Antecedent is never repeated before consequent in a period
4. Repeat signs are the critical diagnostic clue
