# Quick Definition
A sequential progression ending with harmonies suggestive of a cadential progression (e.g., ii-V-I) does not normally create a genuine cadence, because the final unit is a repetition of a prior unit and would not normally be heard as a distinct closing unit. Classical composers typically write a separate cadential progression following the sequence to effect cadential closure.

# Core Definition
A sequential progression, especially a descending-fifth one, can sometimes end with harmonies suggestive of a cadential progression (e.g., II-V-I). Students might be tempted to analyze the final unit of the model-sequence pattern as a cadential idea. In most cases, this would be a mistake: since the final unit is a repetition of a prior unit, it would not normally be heard to function as a closing unit, one that distinguishes itself from what is being repeated. A cadential idea should normally be different from what precedes it, in order to acquire a genuine concluding function. For this reason, the classical composers usually write a distinct cadential progression, which follows the sequential progression, to effect cadential closure. If a thematic unit seems to "end" with the conclusion of the sequence, as in cases of premature dominant arrival, then we experience a "noncadential" ending (Caplin, Ch. 11, pp. 356-357).

# Key Properties
1. Sequential endings with ii-V-I do NOT normally create genuine cadences
2. Final sequential unit is a repetition, not a distinct closing unit
3. Cadential ideas must be different from what precedes them
4. Classical composers write distinct cadential progressions after sequences
5. Sequences ending on dominant create premature dominant arrival
6. "Noncadential" endings result when no distinct cadential progression follows

# Construction / Recognition
## To Identify:
1. Locate a sequential passage (model-sequence technique)
2. Check whether the final link of the sequence lands on harmonies suggesting a cadence
3. Determine if this final link is simply the last repetition of the model
4. Look for a separate, distinct cadential unit following the sequence
5. If no distinct cadential unit follows, the ending is noncadential

# Context & Application
This distinction is critical for analyzing transitions, where sequential progressions frequently lead to the transition's harmonic goal. If the dominant at the end of a descending-fifth sequence is the transition's final harmony, the result is a dominant arrival rather than a genuine HC, because no separate cadential unit distinguishes this moment as a formal ending. Understanding this principle prevents mistaken cadential analyses and clarifies the nature of premature dominant arrivals.

# Examples
**Example 1** (pp. 355-356): Beethoven, Symphony No. 4, Op. 60, i, mm. 81-108 -- Descending-fifth sequential progression; last harmonic link is V of subordinate key at m. 92; no distinct cadential progression follows; noncadential (premature dominant arrival).
