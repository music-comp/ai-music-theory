# Quick Definition
Bass motion that outlines the chord tones of a single harmony through arpeggiated movement, prolonging that harmony by connecting root position and inversions without changing the underlying chord.

# Core Definition
Bass arpeggiation is a prolongational technique where the bass voice moves through chord tones of a sustained harmony, creating melodic interest while maintaining harmonic stability. This motion connects different positions of the same chord (e.g., I to I6) and serves as one of the fundamental contrapuntal processes within prolongational progressions. The conventional accompaniment pattern called "Alberti bass" consists of arpeggiation figurations (Caplin, Ch. 1).

# Prerequisites
- **Prolongational progression** — Bass arpeggiation is one technique within prolongational progressions
- **Harmonic inversion** — Understanding chord positions is essential to recognizing arpeggiated connections

# Key Properties
1. Outlines chord tones of the prolonged harmony
2. Connects different inversions of the same chord (e.g., I to I6)
3. Creates melodic activity in the bass without changing the underlying harmony
4. Produces a prolongational effect through leaping rather than stepwise motion
5. Distinguishes inversion changes within a single harmony from root motion between different harmonies

# Construction / Recognition
## To Identify:
1. Locate bass motion that leaps between chord tones
2. Verify that the harmony remains the same throughout (only the inversion changes)
3. Confirm that the passage functions as prolongation, not progression to a new harmony
4. Note whether the arpeggiation is literal (open leaps) or filled in (Alberti bass figuration)

# Context & Application
Bass arpeggiation commonly appears in Alberti bass patterns and similar accompaniment figures, creating rhythmic vitality while maintaining harmonic stability. It may combine with other prolongational techniques (neighbor motion, passing motion) within a single prolongational passage. The technique is especially common in keyboard textures of the Classical period.

## Contrasts With
- **Root motion** — Root motion involves movement between different harmonies; arpeggiation remains within one harmony

# Common Errors
- **Error**: Treating each arpeggiated bass note as indicating a different harmony
  **Correction**: When the bass outlines chord tones of a single harmony, the harmony itself does not change; only its inversion or voicing changes

# Common Confusions
- **Confusion**: Confusing arpeggiation (within one harmony) with root motion (between different harmonies)
  **Clarification**: Arpeggiation moves through tones of a single chord; root motion connects fundamentally different chords
