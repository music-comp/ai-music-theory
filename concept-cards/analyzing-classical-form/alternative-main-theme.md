# Quick Definition
An alternative main theme is an entirely new theme at the start of the solo exposition, used when the ritornello main theme is too orchestral in character for the solo instrument. The ritornello main theme then typically reappears immediately in the solo transition or as a second theme.

# Core Definition
On occasion, the solo exposition begins with an entirely new theme. This alternative main theme tends to appear when the ritornello main theme is highly orchestral in character (loud fanfare figures, polyphonic textures) and not likely to be rendered idiomatically by the soloist. If an alternative main theme is used, the ritornello main theme usually reappears immediately in the transition. The alternative main theme will seldom begin the recapitulation (Caplin, pp. 707-708).

# Prerequisites
- **Solo exposition** -- The section where the alternative main theme appears
- **Opening ritornello** -- Contains the original main theme being replaced

# Key Properties
1. Entirely new theme at start of solo exposition
2. Used when ritornello main theme is unidiomatic for solo
3. More pianistic and lyrical in character
4. Ritornello main theme reappears in solo transition (principle 2)
5. Seldom used to begin the recapitulation
6. May appear at start of development or after original main theme in recapitulation
7. In some cases, never appears again after the solo exposition

# Examples
**Example 1** (p. 707): Mozart, Piano Concerto in D minor, K. 466 -- intensely brooding orchestral opening replaced by considerably more pianistic and lyrical alternative main theme; Mozart never attempts to imitate the orchestral opening in the piano part.
