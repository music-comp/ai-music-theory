## Definition

An alternative main theme is a new main theme appearing at the start of the solo exposition, entirely different from the ritornello main theme. It is used when the orchestral theme would not be idiomatic or effective for the solo instrument.

## When It Occurs

The ritornello main theme may be highly orchestral in character:
- Loud, fanfare-like figures for full orchestra
- Polyphonic textures highlighting different instrumental sonorities
- Material that would not create similar impression on solo instrument

## Examples

### Mozart, Piano Concerto in D minor, K. 466
- Opening ritornello: Intensely brooding orchestral texture (mm. 1-4ff.)
- Solo exposition: Considerably more pianistic and lyrical alternative theme
- Mozart never attempts to imitate the orchestral opening in piano part

## Consequences for Form

### Transition Material
If an alternative main theme is used:
- The immediately following transition will be based on the **ritornello main theme**
- This follows the principle that the ritornello main theme should return soon

### Recapitulation
The alternative main theme:
- Will seldom be used to begin the recapitulation
- May appear elsewhere in the movement:
  - At start of development section
  - After original main theme (creating a theme group)
- In some cases, never appears again

## Aesthetic Function

The alternative main theme allows the solo to:
- Have its own distinctive melodic-motivic profile
- Present material suited to its instrumental character
- Establish identity separate from the orchestra
