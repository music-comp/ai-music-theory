## Definition

The main theme in concerto form, appearing in the opening ritornello, is a tight-knit conventional theme that always closes with a PAC. Unlike sonata form, a concerto main theme never closes with an HC.

## Theme Type Preference

The **compound sentence** is particularly favored for concerto main themes, though other conventional types appear:
- Simple sentence
- Period
- Hybrids
- Occasional nonconventional themes

## Comparison to Rondo and Sonata

| Form | Main Theme Cadence |
|------|-------------------|
| Concerto | Always PAC |
| Rondo | Always PAC |
| Sonata | May be HC |

The concerto shares with rondo the requirement for strong PAC closure.

## Transition Beginning

Unlike sonata expositions (where transition can begin like main theme):
- Concerto ritornello transition almost **always begins with new material**
- This creates clear formal articulation between sections

## Solo Main Theme Options

### Option 1: Based on Ritornello
- Brings back ritornello main theme
- May include same formal plan
- Often with variation procedures for virtuosic character

### Option 2: Alternative Main Theme
- Entirely new theme for solo
- Used when orchestral theme is not idiomatic for solo instrument
- More pianistic/lyrical in character
