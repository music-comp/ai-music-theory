# Quick Definition
The concerto main theme (in the opening ritornello) is a tight-knit conventional theme that always closes with PAC (never HC, like rondo). The compound sentence is particularly favored. The ritornello transition almost always begins with new material, unlike sonata practice.

# Core Definition
The opening ritornello begins with a tight-knit main theme closing with a PAC. Like a rondo but unlike a sonata, a concerto main theme does not close with an HC. The compound sentence is particularly favored. The main theme is followed by a more loosely organized thematic region ending with a home-key HC (resembling a nonmodulating transition), which almost always begins with new material (Caplin, p. 703).

# Prerequisites

# Key Properties
1. Tight-knit, conventional theme
2. Always closes with PAC (never HC)
3. Compound sentence particularly favored
4. Ritornello transition almost always begins with new material (unlike sonata)
5. Solo main theme may reuse ritornello material or be entirely new (alternative)
