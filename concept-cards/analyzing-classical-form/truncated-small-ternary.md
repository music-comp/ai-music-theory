# Quick Definition
A truncated small ternary is an incomplete thematic structure consisting of only an exposition (A section) and contrasting middle (B section), with the expected recapitulation (A' section) eliminated.

# Core Definition
A truncated small ternary consists of A and B sections only, with the A' section completely eliminated. The B section typically ends on home-key dominant harmony, which directly motivates the return of the main theme in the larger form. This truncation is most commonly found in interior themes of large ternary form and in rondo couplets (Caplin, pp. 589, 601).

# Prerequisites
- **Small ternary** -- The complete form from which the truncated version derives
- **Interior theme** -- The principal context where truncation occurs

# Key Properties
1. Contains only A (exposition) and B (contrasting middle) sections
2. The expected A' (recapitulation) is eliminated
3. B section typically ends on home-key dominant
4. The dominant ending motivates the main theme's return
5. The return of the main theme in the larger form substitutes for the missing A'

# Construction / Recognition
## To Identify:
1. Look for a modulating A section (often to relative major in minore)
2. Identify the B section with its characteristic dominant emphasis
3. Confirm the absence of any recapitulatory return of the A section's opening material
4. Note that the main theme of the larger form returns directly after the B section

# Context & Application
Most commonly found within interior themes of large ternary form. Also appears in rondo couplets built as interior themes. The truncation creates an open-ended structure that generates strong expectations for the return of the main theme.

# Examples
**Example 1** (p. 601): Haydn, String Quartet in B-flat, Op. 64, No. 3, ii -- A section closes with PAC in relative major; B section brings contrasting middle with standing on the dominant; main theme returns directly without A' section.
**Example 2** (p. 589): Haydn, String Quartet in G minor ("Rider"), Op. 74, No. 3, ii -- interior theme as truncated small ternary.

## Contrasts With

# Common Errors
- **Error**: Confusing truncated small ternary with small binary
  **Correction**: In small binary, the second part is not a contrasting middle expecting an A' return; in truncated small ternary, the A' section is specifically eliminated from an expected three-part form
