# Quick Definition
A comprehensive system of notational conventions for harmonic analysis, including symbols for keys, harmonies, progressions, modulations, and special harmonic situations.

# Formal Definition
The Guide to Harmonic Annotation provides standardized notation for analyzing tonal music. It covers key indication, harmony labeling, inversions, modulation, tonicization, and specialized notation for prolongational, cadential, and sequential progressions.

# Musical/Theoretical Formulation
**Key indication:**
- Major key: boldface uppercase pitch + colon (C:)
- Minor key: boldface lowercase pitch + colon (c:)

**Harmony:**
- Uppercase Roman numerals regardless of chord quality
- Augmented sixths: national labels (It+6, Gr+6, Fr+6)
- Sustained harmony: Roman numeral + straight line (V6 ———)

**Inversions:**
- Standard figured-bass symbols (I6, V4/3)
- Cadential six-four: V(6-4 to 5-3) showing dominant function with embellishment
- Same harmony changing inversion: I——6

**Progressions:**
- Prolongational: subordinate harmonies in parentheses
- Cadential: horizontal square bracket
- Sequential: "seq." after initial harmony, subsequent chords in parentheses

**Special situations:**
- Pedal point: "ped." after Roman numeral
- Passing/neighboring chords: labeled "p" or "n"
- Nonfunctional chords: chord quality in parentheses (°7, m7)
- Omitted analysis: ellipses (I ...)
- Alternative interpretation: square brackets

# Musical Context/Application
This notation system:
- Distinguishes progression types visually
- Highlights structural vs. subordinate harmonies
- Clarifies modulation and tonicization
- Enables precise analytical communication

Consistent use of these conventions produces "precise and accurate harmonic analyses."

# Examples
From the Guide (pp. 46-47):
- "I ped.–(IV–V7)–I" shows tonic pedal with subordinate harmonies
- "[I6 II6 V7 I]" shows cadential progression with square bracket
- "I seq.–(VII6–VI6–V6)–IV6–V" shows sequential progression
- "V7→II" shows secondary dominant with arrow to tonicized harmony

# Common Confusions
- Not using parentheses for subordinate harmonies (they clarify structure)
- Omitting the square bracket for cadential progressions
- Using Roman numerals for purely contrapuntal chords
- Forgetting the "seq." label for sequential progressions
