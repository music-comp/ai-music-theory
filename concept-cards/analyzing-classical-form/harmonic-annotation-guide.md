# Quick Definition
A comprehensive system of notational conventions for harmonic analysis: uppercase Roman numerals for all harmonies, parentheses for subordinate harmonies in prolongational and sequential contexts, horizontal square brackets for cadential progressions, "seq." for sequences, "ped." for pedal points, and special symbols for modulation, tonicization, and nonfunctional chords.

# Core Definition
The Guide to Harmonic Annotation provides standardized notation for analyzing tonal music (pp. 46-48). Key conventions include: uppercase Roman numerals regardless of chord quality; parentheses for subordinate harmonies; horizontal square brackets for cadential progressions; "seq." label for sequential progressions; "ped." for pedal points; arrows for secondary dominants; and national labels for augmented sixths.

# Key Properties
1. Key: major = uppercase pitch + colon (C:); minor = lowercase (c:)
2. Harmony: uppercase Roman numerals regardless of chord quality
3. Inversions: standard figured-bass symbols (I6, V4/3)
4. Cadential six-four: V(6/4-5/3), showing dominant function
5. Prolongational: subordinate harmonies in parentheses
6. Cadential: horizontal square bracket embracing fundamental harmonies
7. Sequential: "seq." after initial harmony; interior harmonies in parentheses
8. Pedal: "ped." after Roman numeral; subordinate harmonies in parentheses, no inversions
9. Passing/neighboring: labeled "p" or "n" in parentheses
10. Nonfunctional: chord quality in parentheses (o7, m7) instead of Roman numerals
11. Tonicization: arrows pointing to tonicized harmony (V7->II)
12. Modulation: vertical brace connecting old and new key analyses
13. Sustained harmony: Roman numeral + straight line
14. Omitted analysis: ellipses (I ...)

# Construction / Recognition
## To Annotate a Passage:
1. Identify the key and label it (C: or c:)
2. Label each harmony with uppercase Roman numeral + inversion
3. Identify progression types and apply appropriate notation
4. Use parentheses for subordinate harmonies in prolongational/sequential contexts
5. Use square brackets for cadential progressions
6. Mark secondary dominants with arrows
7. Note pedal points and nonfunctional chords with special symbols

# Context & Application
Consistent use of these conventions produces "precise and accurate harmonic analyses" (p. 17). The notation system visually distinguishes progression types, highlights structural vs. subordinate harmonies, and clarifies modulation and tonicization. The ECP (expanded cadential progression) uses the abbreviation "ECP" rather than an overly long bracket.

# Examples
**Example 1** (pp. 46-47): I ped.-(IV-V7)-I shows tonic pedal; [I6 II6 V7 I] shows cadential progression; I seq.-(VII6-VI6-V6)-IV6 shows sequential progression.

# Common Errors
- **Error**: Omitting parentheses for subordinate harmonies
  **Correction**: Use parentheses to clarify structural hierarchy

# Common Confusions
- **Confusion**: Thinking square brackets are optional for cadential progressions
  **Clarification**: Brackets are strongly encouraged to distinguish cadential from prolongational progressions
- **Confusion**: Using Roman numerals for purely contrapuntal passing chords
  **Clarification**: Use chord quality symbols (m7, o7) when the chord lacks genuine harmonic function
