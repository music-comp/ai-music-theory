# Quick Definition
The opening 8-m. unit of a compound sentence, consisting of a 4-m. compound basic idea repeated (statement-response most common, exact less frequent, sequential rare), all supported by tonic prolongational harmony with no cadence.

# Core Definition
The compound presentation has the same basic functional elements as a simple presentation: an open-ended initiating unit immediately repeated in the context of tonic prolongation. Statement-response repetition (I-V, V-I) is most common. When the tonic c.b.i. is repeated with a dominant version, an antecedent-consequent impression can arise, but Caplin cautions that if there is only a single harmonic progression underlying each 4-m. phrase (no distinct cadential progression ending a prior prolongational progression), the entire situation is exclusively prolongational and should be heard as a presentation, not a period.

# Key Properties
1. 4-m. c.b.i. + 4-m. repetition
2. Statement-response most common
3. Entirely tonic prolongational (no cadence)
4. Can be confused with period when statement-response implies I-V, V-I
5. Must check: is there a distinct cadential progression? If not, it is a presentation.
