# Quick Definition
The technique of using harmonies containing notes from the opposite mode (minor in major, or vice versa), also called mixture. Enriches pre-dominant harmonies (II6, IV) with dissonant sevenths and chromatic alterations while maintaining functional identity.

# Core Definition
Both II6 and IV can be enriched through the addition of dissonant sevenths, and even greater variety can be gained by means of modal borrowing (or mixture), whereby chords containing notes from the minor scale are used in major-mode contexts, or vice versa (p. 32). Modal borrowing maintains the functional identity of harmonies while altering their quality through chromatic inflection.

# Prerequisites
- **Harmonic function** — Must understand functional categories to see that borrowed chords retain their function

# Key Properties
1. Uses notes from the opposite mode (minor notes in major, major notes in minor)
2. Also called "mixture"
3. Enriches pre-dominant harmonies with chromaticism
4. Borrowed chords retain their original function
5. Maintains the original tonic (unlike modulation)

# Construction / Recognition
## To Identify:
1. Look for chromatically altered chords that match the parallel mode
2. Verify the chord retains its original function (e.g., borrowed iv is still pre-dominant)
3. Confirm no modulation is taking place

# Context & Application
Modal borrowing is especially useful for creating expressive contrast and adding harmonic variety within pre-dominant harmonies. It appears in cadential progressions, sequential contexts, and deceptive resolutions. One notable example: the first of two consecutive diminished-seventh chords prolonging pre-dominant function serves as a replacement for the pre-dominant II from the minor mode (p. 39).

# Examples
**Example 1** (pp. 38-39, Ex. 1.13e): Two diminished-seventh chords prolonging pre-dominant; the first replaces II from minor mode.

# Common Errors
- **Error**: Treating borrowed chords as modulation
  **Correction**: Modal borrowing maintains the original tonic; only mode quality changes

# Common Confusions
- **Confusion**: Assuming borrowed chords lose their original function
  **Clarification**: Borrowed iv is still pre-dominant, just with minor-mode quality
