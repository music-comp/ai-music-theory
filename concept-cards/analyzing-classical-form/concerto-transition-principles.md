## Two Guiding Principles

The choice of material to begin the solo transition is guided by:

### Principle 1: Avoid Ritornello Succession
The solo section should **not reproduce** the same succession of ideas found in the ritornello from main theme to transition.

### Principle 2: Alternative Main Theme Prompts Return
The use of an alternative main theme prompts the **immediate reappearance** of material from the ritornello main theme.

## Scenarios Explained by These Principles

### Scenario A
- Solo main theme = ritornello main theme
- Solo transition = **new material** (Principle 1)
- Found in approximately half of Mozart's mature concertos

### Scenario B
- Alternative main theme used
- Solo transition = **ritornello main theme** (Principle 2)

### Scenario C
- Alternative main theme used
- Ritornello main theme used as "second" theme (theme group)
- Solo transition = **new material** (Principle 1)

### Scenario D
- Alternative main theme used
- Solo transition = **ritornello transition**
- Succession of ideas differs from ritornello because of alternative main theme (Principle 1)

## Exception

A significant number of concertos bring:
- Solo main theme and transition that largely **restate** those of opening ritornello
- With possibility of structural changes and ornamental variations
- These cases reinforce the "double exposition" concept
