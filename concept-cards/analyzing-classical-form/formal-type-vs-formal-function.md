# Quick Definition
Formal types (sentence, period, hybrid, etc.) are conventional arrangements of formal elements with no predetermined temporal location. Formal functions (presentation, continuation, cadential, antecedent, consequent) relate to temporal senses of beginning, middle, or ending. Types contain specific sets of functions.

# Core Definition
The terms sentence and period refer to formal types, in this case theme types. Each theme type embraces a conventional set of phrase functions. The sentence contains the functions of presentation, continuation, and cadential. The period contains the functions of antecedent and consequent. A function relates to some temporal sense of beginning, being-in-the-middle, or ending. A type does not have any predetermined temporal location; the sentence, for example, is not necessarily associated with a beginning, middle, or end of anything. Later we will see that certain theme types are used in specific contexts where they fulfil a formal function, as when a sentence or period takes on the initiating function of main theme (p. 96).

# Prerequisites
- **Sentence** — One of the theme types
- **Period** — Another theme type

# Key Properties
1. Formal TYPE: conventional arrangement; no predetermined temporal location
2. Formal FUNCTION: relates to temporal sense (beginning, middle, ending)
3. Sentence TYPE contains functions: presentation, continuation, cadential
4. Period TYPE contains functions: antecedent, consequent
5. Types may later take on larger-scale functions (e.g., sentence as main theme)
6. The distinction prevents confusing internal structure with larger-scale role

# Construction / Recognition
## To Apply:
1. Identify the theme TYPE (sentence, period, hybrid, etc.)
2. Identify the FUNCTIONS within that type
3. Consider the larger-scale FUNCTION the type serves in its formal context

# Context & Application
This distinction is crucial for multi-level analysis. A sentence has a fixed internal organization (type) but may serve various roles in the larger form (function). The internal functions (presentation, continuation, cadential) describe temporal relationships WITHIN the theme.

# Examples
**Example 1** (p. 96): A sentence (type) may serve as main theme (function); the same sentence type may appear as subordinate theme, closing theme, etc.

# Common Errors
- **Error**: Assuming a sentence always functions as a "beginning"
  **Correction**: A sentence (type) has no predetermined temporal location; it may appear anywhere

# Common Confusions
- **Confusion**: Conflating the internal functions of a type with its larger-scale function
  **Clarification**: Presentation is a function WITHIN a sentence; main theme is a function OF the sentence within the movement
