# Formal Type vs. Formal Function

It is essential to distinguish between **formal types** and **formal functions** when analyzing classical form.

## Formal Type

A **formal type** refers to a conventional arrangement of formal elements. Theme types include:
- Sentence
- Period
- Hybrid themes
- Small ternary
- Small binary

A type does NOT have a predetermined temporal location. A sentence, for example, is not necessarily associated with a beginning, middle, or end of anything larger.

## Formal Function

A **formal function** relates to some temporal sense of:
- **Beginning** (initiating functions)
- **Being-in-the-middle** (medial functions)
- **Ending** (concluding functions)

Each theme type embraces a conventional set of phrase functions.

## Theme Types and Their Functions

| Theme Type | Phrase Functions |
|------------|------------------|
| Sentence | Presentation, Continuation, Cadential |
| Period | Antecedent, Consequent |
| Hybrids | Various combinations |

## Later Usage

Theme types may take on specific formal functions in larger contexts:
- A sentence or period may function as **main theme** of a movement
- The same theme types may appear in other functional positions

The distinction allows us to analyze both the internal organization (type) and the role within larger structures (function).
