# Quick Definition
Consequent function is a concluding formal function that repeats the antecedent by returning the basic idea and achieving stronger cadential closure (usually PAC). It completes the thematic statement initiated by the antecedent.

# Core Definition
The consequent phrase repeats the antecedent by bringing a return of the original basic idea, followed by a contrasting idea (which may or may not resemble the antecedent's) leading to a stronger cadence, usually a PAC, or more rarely an IAC if the antecedent ended with HC (pp. 96-97). The return of the basic idea signals that consequent function has begun -- that the antecedent is being "repeated" with the promise of stronger closure. The consequent's cadential progression often begins earlier within the phrase and occupies greater temporal weight than the antecedent's, contributing to the sense of stronger closure (p. 107). Consequent function expresses the temporal sense of "ending."

# Prerequisites
- **Antecedent function** — The consequent responds to and completes the antecedent
- **Period structure overview** — Consequent is the concluding function of the period

# Key Properties
1. Concluding formal function (expresses "ending")
2. Returns the basic idea to signal the "repeat" of the antecedent
3. Closes with a stronger cadence than the antecedent (usually PAC)
4. Contrasting idea may resemble antecedent's c.i. or bring new material
5. Cadential progression often begins earlier and has greater temporal weight
6. Resolves the incompleteness created by the antecedent
7. The period does not elide antecedent with consequent

# Construction / Recognition
## To Identify:
1. Look for a return of the basic idea after the antecedent's weak cadence
2. Verify that a contrasting idea follows, leading to a stronger cadence
3. The cadence must be stronger than the antecedent's (e.g., PAC vs. HC)
4. Check that the cadential progression starts earlier or is more emphatic

# Context & Application
Consequent function is one of two formal functions in the period. Its return of the basic idea is crucial: without it, the sense of "repeating" the antecedent is lost. Both are concluding functions at different levels -- consequent at the phrase level, cadential at the idea level. The consequent phrase contains cadential function within it. In compound periods, compound consequent function is expressed by an 8-m. unit closing with PAC.

# Examples
**Example 1** (p. 96, Ex. 3.1): Mozart, K. 525, ii, mm. 5-8 -- basic idea returns (mm. 5-6), new contrasting idea with PAC (mm. 7-8).
**Example 2** (p. 106, Ex. 3.14): Mozart, K. 281, i, mm. 5-8 -- consequent with entirely new contrasting idea material, still closes with PAC.

# Common Errors
- **Error**: Expecting the contrasting idea to always match the antecedent's
  **Correction**: The consequent's contrasting idea may use the same material, different material, or a mix; what matters is the return of the b.i. and stronger cadence

# Common Confusions
- **Confusion**: Thinking any second phrase following a first phrase has consequent function
  **Clarification**: Consequent function requires return of the basic idea and stronger cadential closure relative to an antecedent; a continuation phrase has continuation function, not consequent function
