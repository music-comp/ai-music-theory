# Consequent Function

**Consequent function** is a concluding formal function that responds to the antecedent by bringing back the opening material and achieving stronger cadential closure.

## Characteristics

Consequent function:
- Returns the basic idea
- Achieves stronger closure than antecedent
- Completes the thematic statement
- Resolves the incompleteness of the antecedent

## Temporal Meaning

Consequent function expresses **ending**:
- Completes what was initiated
- Answers the antecedent's "question"
- Achieves satisfactory closure

## How It Achieves Closure

The consequent achieves stronger closure through:
- Cadence type (PAC vs. HC/IAC)
- Expanded cadential progression
- Greater temporal weight on cadence

## Relation to Cadential Function

Both are concluding functions:
- **Consequent**: Higher-level (phrase function)
- **Cadential**: Lower-level (idea function)

The consequent phrase contains cadential function within it.

## Return as Signal

The return of the basic idea signals that:
- Consequent function has begun
- The antecedent is being "repeated"
- Stronger closure is forthcoming
