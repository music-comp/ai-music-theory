# Quick Definition
The opening of a theme's second phrase can be functionally ambiguous when what seems like a return of the basic idea (suggesting consequent) is modified in ways -- different harmonic support, sequential quality, fragmentation -- that suggest continuation instead.

# Core Definition
Caplin identifies this ambiguity when the melody of mm. 5-6 uses the identical pitches as the opening basic idea (suggesting consequent), but the harmonic context introduces sequential quality (e.g., vi in place of I), parallel voice-leading patterns, and potentially fragmented grouping. The melody may also be re-grouped to suggest 1-m. fragments rather than a 2-m. idea. All these features point toward continuation rather than consequent. Both interpretations can be legitimately supported.

# Prerequisites
- **Consequent phrase** — Return of basic idea leading to strong cadence
- **Continuation phrase** — Fragmentation, acceleration, sequence

# Key Properties
1. Melodic identity with basic idea suggests consequent
2. Different harmonic support (sequential quality) suggests continuation
3. Potential fragmentation of grouping structure suggests continuation
4. Modulating harmonic progression suggests continuation
5. Both views can be legitimately supported

# Construction / Recognition
## To Identify:
1. Check if mm. 5-6 use the same melodic content as mm. 1-2 (favors consequent)
2. Check harmonic support: is it tonic-based (consequent) or sequential/destabilizing (continuation)?
3. Check grouping: does the phrase maintain 2-m. units (consequent) or fragment (continuation)?
4. Check tonality: does the phrase modulate (strongly favors continuation)?

# Context & Application
This ambiguity arises particularly when a theme could be analyzed as either a period (with consequent) or a hybrid (with continuation). Caplin uses this to illustrate that formal analysis should embrace multiple perspectives rather than force definitive labels.

# Examples
**Example 1** (p. 135): Haydn, Piano Trio H. 13, i, mm. 1-8 — melody in mm. 5-6 has identical pitches to basic idea (consequent), but vi harmony creates sequential quality and chromatic C# suggests fragmentation into 1-m. units (continuation).

# Common Errors
- **Error**: Automatically labeling any return of the basic idea as "consequent"
  **Correction**: Examine the harmonic context, grouping structure, and tonal direction

# Common Confusions
- **Confusion**: Thinking melodic identity always determines function
  **Clarification**: Harmonic context and grouping structure can override melodic identity in determining formal function
