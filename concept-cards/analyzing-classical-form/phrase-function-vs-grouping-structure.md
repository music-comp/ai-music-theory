# Quick Definition
Grouping structure describes how music is divided into units by size and boundaries (phrase = 4 m., idea = 2 m., theme = 8 m.). Formal function describes the temporal meaning of a passage (presentation = beginning, continuation = middle, cadential = ending). The same grouping unit can have different functions; the same function can appear in different grouping contexts.

# Core Definition
The opening unit of the sentence is a phrase insofar as four measures group together to form a coherent whole; this phrase serves a distinct formal function, termed presentation (p. 68). Grouping structure refers to how music is divided into units: "phrase" is a 4-m. grouping unit, "idea" is a 2-m. grouping unit, "theme" is an 8-m. grouping unit. These terms describe size and boundaries. Formal function refers to the temporal meaning of a passage: presentation function expresses formal beginning, continuation function expresses formal middle, cadential function expresses formal ending. These terms describe temporal role. The labels "idea" and "phrase" refer to grouping structure; "basic idea" and "presentation" refer to formal function (p. 69). This distinction is central to the theory of classical form.

# Key Properties
1. Grouping structure: how music divides into units (size, boundaries)
2. Formal function: temporal meaning (beginning, middle, ending)
3. "Phrase" = grouping term (4-m. unit); "presentation" = function term
4. The same grouping unit can express different functions
5. The same function can appear in different grouping contexts
6. Formal function relates to general notions of time
7. Phrases are often named by their function (e.g., "continuation phrase")
8. But phrase (grouping) and function (meaning) remain distinct concepts

# Construction / Recognition
## To Apply:
1. When labeling, distinguish between the grouping unit and its function
2. "Continuation phrase" = a phrase (grouping) expressing continuation function (meaning)
3. The grouping and function are complementary, not identical
4. Keep this distinction in mind when analyzing ambiguous passages

# Context & Application
This distinction becomes essential in many analytical situations. For instance, continuation function can appear within a 2-m. contrasting idea (not a full 4-m. phrase); a cadential idea is a 2-m. grouping unit expressing cadential function. Formal functionality relates to general temporalities: beginning, being-in-the-middle, and ending. These temporal meanings apply to passages of music just as they apply to everyday experiences (p. 69). The concept of formal function is central to Caplin's entire theoretical framework.

# Examples
**Example 1**: "Presentation phrase" = a 4-m. grouping unit (phrase) expressing presentation function (formal beginning).
**Example 2**: "Cadential idea" = a 2-m. grouping unit (idea) expressing cadential function (formal ending).
**Example 3**: A contrasting idea (2-m. grouping) may display continuation function characteristics (fragmentation, acceleration), showing function and grouping operating at different levels.

# Common Errors
- **Error**: Treating "presentation" as only a grouping term (a 4-m. unit)
  **Correction**: "Presentation" refers to a formal function (expressing beginning); the 4-m. unit is a "presentation phrase" (grouping + function combined)

# Common Confusions
- **Confusion**: Assuming that grouping boundaries always correspond to functional boundaries
  **Clarification**: The same function can span different grouping units, and a single grouping unit can fuse multiple functions (as the continuation phrase fuses continuation and cadential functions)
