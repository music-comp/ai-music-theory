# Phrase Function vs. Grouping Structure

A crucial distinction underlies the terminology of classical form analysis: the difference between **grouping structure** and **formal function**.

## Grouping Structure

Refers to how music is divided into units:
- **Phrase**: A 4-measure grouping unit
- **Idea**: A 2-measure grouping unit
- **Theme**: An 8-measure (or larger) grouping unit

These terms describe **size** and **boundaries**.

## Formal Function

Refers to the temporal meaning of a passage:
- **Presentation function**: Expresses formal beginning
- **Continuation function**: Expresses formal middle
- **Cadential function**: Expresses formal ending

These terms describe **temporal role**.

## Example Distinction

"Presentation phrase" vs. "presentation function":
- **Presentation phrase**: A 4-measure **grouping unit**
- **Presentation function**: A **formal function** expressing initiation

The phrase is a unit; the function is its temporal meaning.

## Why This Matters

Separating these concepts allows precise analysis:
- The same grouping unit can have different functions
- The same function can appear in different grouping contexts
- Clear terminology prevents confusion

## Labeling Convention

When labeling, we often name phrases by their function:
- "Continuation phrase" = a phrase expressing continuation function
- But the phrase (grouping) and function (meaning) remain distinct concepts
