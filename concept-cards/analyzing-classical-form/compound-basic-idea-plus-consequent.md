# Quick Definition
An infrequently occurring hybrid type that strongly resembles the period, with the only essential difference being that the contrasting idea in mm. 3-4 does not bring a weak cadence.

# Core Definition
This hybrid begins with a compound basic idea (basic idea + contrasting idea, no cadence). Measures 5-6 bring back the opening basic idea in the manner of a consequent phrase, and the subsequent contrasting idea brings an emphatic PAC to close the theme. It differs from a period solely in the absence of a weak cadence at m. 4, making it the most period-like position on the hybrid spectrum. The basic idea appears twice (at mm. 1-2 and 5-6), like the period.

# Prerequisites
- **Compound basic idea** — The initiating phrase without cadential closure
- **Consequent phrase** — The concluding phrase that returns the basic idea and closes with PAC

# Key Properties
1. First phrase: compound basic idea (b.i. + c.i., no cadence, tonic prolongation)
2. Second phrase: consequent with return of basic idea and PAC
3. Infrequently occurring type
4. Basic idea appears twice (like sentence and period)
5. Return of b.i. in mm. 5-6 often supported by different harmony (frequently dominant)
6. Consequent frequently accelerates harmonic rhythm compared to c.b.i., giving a degree of continuational expression
7. A single tonic prolongation may underlie the first seven measures

# Construction / Recognition
## To Identify:
1. Confirm first phrase has b.i. + c.i. without cadence
2. Check for return of b.i. at mm. 5-6 (consequent function)
3. Verify a strong cadence (PAC) closes the theme
4. Distinguish from period: no weak cadence at m. 4

# Context & Application
This hybrid occupies the most period-like position on the spectrum. It is infrequently occurring but notable for its combination of open-ended beginning (no cadence at m. 4) with the satisfying return of the basic idea. The harmonic acceleration in the consequent often imparts some continuational expression, creating a subtle blend of functions.

# Examples
**Example 1** (p. 125): Beethoven, String Quartet Op. 18/2, iv, mm. 21-28 — c.b.i. with no harmonic motion into m. 24; consequent returns b.i. with dominant harmony and closes with emphatic PAC.

# Relationships
## Builds Upon
- **Compound basic idea** — Provides the initiating function
- **Consequent phrase** — Provides the concluding function with b.i. return
## Enables
- **Formal variety** — Offers a period-like option without cadence at midpoint
## Related
- **Period** — Nearly identical; differs only at m. 4 (cadence vs. no cadence)
## Contrasts With
- **Period** — Period has weak cadence ending antecedent
- **C.b.i. + continuation** — Continuation does not return the basic idea

# Common Errors
- **Error**: Calling this a period because the basic idea returns at m. 5
  **Correction**: Without a weak cadence at m. 4, the first phrase is a c.b.i., not an antecedent, and the theme is a hybrid

# Common Confusions
- **Confusion**: Mistaking harmonic acceleration in the consequent for continuation function
  **Clarification**: The consequent frequently accelerates harmonic rhythm relative to the c.b.i., but the return of the basic idea confirms consequent function; the acceleration is a secondary continuational "expression"
