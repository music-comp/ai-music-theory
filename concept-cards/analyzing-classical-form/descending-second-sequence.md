# Quick Definition
A frequently used sequential progression with roots descending by step (IV-III-II-I), using first-inversion chords throughout to avoid parallel fifths. Often embellished with 7-6 suspensions.

# Core Definition
Sequential progressions by descending seconds occur often in the literature; however, they pose a potential problem of voice leading. If the chords were placed in root position, parallel fifths could easily arise. Therefore, the unembellished form finds all chords in first inversion, eliminating any interval of a fifth against the bass (p. 44). The progression is frequently embellished by a series of 7-6 suspensions (p. 45).

# Key Properties
1. Frequently used in classical music
2. Basic pattern: IV6-III6-II6-I6 (all first inversion)
3. Root-position version creates parallel fifths
4. First inversion eliminates fifths against bass
5. Common embellishment: 7-6 suspensions

# Construction / Recognition
## To Identify:
1. Look for roots descending by step with all chords in first inversion
2. Check for 7-6 suspension embellishments

# Context & Application
A frequent sequential type. The voice-leading constraint (avoiding parallel fifths) dictates the first-inversion usage, a distinctive feature of this sequence.

# Common Errors
- **Error**: Using root-position chords in a descending-step sequence
  **Correction**: Root position creates parallel fifths; use first inversion

# Common Confusions
- **Confusion**: Confusing with descending passing motion in prolongational contexts
  **Clarification**: Sequential progressions involve consistent root-motion pattern destabilizing harmony
