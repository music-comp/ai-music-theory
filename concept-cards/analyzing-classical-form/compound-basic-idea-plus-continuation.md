# Compound Basic Idea + Continuation (Hybrid Type 3)

**Compound basic idea + continuation** is a hybrid type that very closely resembles the sentence theme type, with the essential difference that a contrasting idea appears in place of repeating the basic idea.

## Structure

- **First phrase (mm. 1-4)**: **Compound basic idea** (basic idea + contrasting idea, NO cadence)
- **Second phrase (mm. 5-8)**: **Continuation** (fragmentation, acceleration → cadence)

## Resemblance to Sentence

This hybrid differs from a sentence only in mm. 3-4:
- **Sentence**: Basic idea repeated
- **This hybrid**: Contrasting idea (new material)

Like the sentence, it may end with any cadential type, including a half cadence.

## Continuation Characteristics

When supported by an ECP, the phrase usually features:
- Prominent continuational characteristics
- Fragmentation
- Harmonic acceleration

Label: **continuation⇒cadential** (if ECP is present with continuational features)

## Exclusively Cadential Option

If an ECP-supported phrase has few or no continuational features, labeling the phrase as exclusively **cadential** may be appropriate.

## Modulation

The continuation phrase of this hybrid type may modulate to a closely related key, just like the sentence.
