# Quick Definition
A frequently occurring hybrid type that very closely resembles the sentence, with the essential difference that a contrasting idea appears in mm. 3-4 in place of repeating the basic idea.

# Core Definition
In this hybrid, the opening 4-m. phrase is a compound basic idea (basic idea + contrasting idea, no cadence, tonic prolongational harmony). The second phrase is a continuation featuring fragmentation, harmonic acceleration, and cadential closure. Like the sentence, the continuation fuses continuation and cadential functions and may end with any cadential type, including an HC. When the continuation is supported by an ECP and features prominent continuational characteristics, the label "continuation => cadential" applies. If few or no continuational features are present, labeling the phrase as exclusively "cadential" may be appropriate.

# Prerequisites
- **Compound basic idea** — The initiating phrase function (b.i. + c.i. without cadence)
- **Continuation phrase** — The concluding function with fragmentation and acceleration

# Key Properties
1. First phrase: compound basic idea (tonic prolongational, no cadence)
2. Second phrase: continuation with standard features (fragmentation, acceleration)
3. Very close to sentence; only difference is mm. 3-4 (contrasting vs. repeated material)
4. Basic idea appears only once
5. May modulate to a closely related key
6. Most sentence-like position on the hybrid spectrum

# Construction / Recognition
## To Identify:
1. Confirm first phrase has b.i. + c.i. with no cadence and tonic prolongation
2. Look for continuation features in second phrase (fragmentation, acceleration)
3. Distinguish from sentence: does mm. 3-4 bring genuinely contrasting material or a varied repetition?
4. Note: this distinction can be ambiguous (see presentation vs. c.b.i. ambiguity)

# Context & Application
This hybrid type arises frequently in the repertory. It occupies the most sentence-like position on Caplin's hybrid spectrum. Like the sentence, it states the basic idea only once and can modulate. It is useful when the composer wants sentence-like forward drive without the redundancy of repeating the basic idea.

# Examples
**Example 1** (p. 124): Haydn, Piano Sonata H. 35, i, mm. 1-8 — c.b.i. with tonic pedal destroying potential HC, followed by continuation with fragmentation and harmonic acceleration closing with PAC.
**Example 2** (p. 130): Haydn, Symphony No. 95, iii, mm. 1-8 — c.b.i. over tonic pedal, then continuation => cadential with ECP and marked harmonic acceleration.

## Contrasts With
- **Sentence** — Sentence repeats the basic idea; this hybrid brings contrasting material
- **Antecedent + continuation** — Different initiating function (antecedent has cadence)

# Common Errors
- **Error**: Always labeling this as a sentence because of the surface resemblance
  **Correction**: If mm. 3-4 bring genuinely new contrasting material rather than a varied repetition of the basic idea, the hybrid label is more appropriate

# Common Confusions
- **Confusion**: Uncertainty about whether mm. 3-4 are a "varied repetition" or "contrasting idea"
  **Clarification**: Caplin acknowledges this ambiguity is genuine; both analyses may be viable, depending on whether one focuses on surface contrasts or underlying melodic frameworks
