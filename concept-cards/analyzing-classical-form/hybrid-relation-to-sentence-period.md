# Hybrid Relation to Sentence and Period

The hybrid themes can be situated on a spectrum of formal possibilities, with the sentence and period occupying the two extreme positions.

## The Spectrum

| Most Sentence-like | ← | → | Most Period-like |
|-------------------|---|---|------------------|
| Sentence | cbi + cont | ant + cont | ant + cad | cbi + cons | Period |
| (pres + cont) | | | | | (ant + cons) |

## Relationships Explained

**Compound basic idea + continuation** (most like sentence):
- Very much like a sentence
- Only difference: basic idea is not repeated (contrasting idea instead)

**Antecedent + continuation** (balanced hybrid):
- Brings aspects of sentence and period in equal measure
- Begins like period, ends like sentence

**Antecedent + cadential** (somewhat periodic):
- Somewhat more periodic since continuational traits are missing

**Compound basic idea + consequent** (most like period):
- Closely resembles a period
- Only difference: no weak cadence at m. 4

## Appearances of Basic Idea

Important difference among theme types:

**Two statements of basic idea:**
- Sentence
- Period
- Compound basic idea + consequent

**One statement of basic idea:**
- Antecedent + continuation
- Antecedent + cadential
- Compound basic idea + continuation

This distinction affects how themes function in larger formal contexts.
