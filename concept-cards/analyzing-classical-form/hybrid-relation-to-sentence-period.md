# Quick Definition
The four hybrid types can be situated on a spectrum between the sentence and the period, ranging from most sentence-like (c.b.i. + continuation) to most period-like (c.b.i. + consequent), with important differences in how many times the basic idea appears.

# Core Definition
Caplin places the six theme types on a single spectrum: sentence | c.b.i.+cont | ant+cont | ant+cad | c.b.i.+cons | period. The c.b.i. + continuation is very much like a sentence except the basic idea is not repeated. The c.b.i. + consequent closely resembles a period. The antecedent + continuation brings aspects of both in equal measure. The antecedent + cadential is somewhat more periodic since continuational traits are missing.

# Prerequisites
- **Hybrid themes** — Must know all four types to understand the spectrum
- **Sentence** — One endpoint of the spectrum
- **Period** — The other endpoint

# Key Properties
1. Spectrum from sentence-like to period-like across six theme types
2. Basic idea appears twice in: sentence, period, and c.b.i. + consequent
3. Basic idea appears once in: ant + cont, ant + cad, and c.b.i. + cont
4. Single-statement themes are useful for modulation (more space in continuation)
5. Single-statement themes are useful where overemphasis of basic idea is undesirable

# Construction / Recognition
## To Identify:
1. Determine the theme type
2. Place it on the spectrum
3. Note how many times the basic idea appears
4. Consider whether sentence-like or period-like characteristics predominate

# Context & Application
Themes with a single statement of the basic idea are advantageous in larger-scale contexts where the composer wishes to avoid overemphasizing the basic idea, and in modulating themes where the continuation provides more space for key changes than a consequent.

# Common Errors
- **Error**: Treating the spectrum as rigid categories rather than a continuum
  **Correction**: The spectrum shows relative positions; individual themes may exhibit features that complicate their placement

# Common Confusions
- **Confusion**: Assuming all hybrids state the basic idea only once
  **Clarification**: The c.b.i. + consequent states the basic idea twice, like the sentence and period
