# Quick Definition
A phrase that begins as expected continuation but is retrospectively reinterpreted as cadential because an expanded cadential progression (ECP) supports the entire 4-m. phrase. The symbol => stands for "becomes," denoting retrospective reinterpretation. Both continuation and cadential characteristics are present.

# Core Definition
Cadential function acquires greater status when a single cadential progression begins in m. 5 of the theme and is stretched out to support the entire 4-m. phrase -- an expanded cadential progression (ECP). The term continuation=>cadential is employed, where the symbol => stands for "becomes" and denotes a retrospective reinterpretation of formal function. What we expect to be a continuation phrase is understood retrospectively to be a cadential phrase based on an ECP, that nevertheless contains continuational characteristics (pp. 83-84). Following theorist Janet Schmalfeldt, the double arrow has been adopted by many scholars (p. 84).

# Prerequisites
- **Continuation phrase** — The cont.=>cad. is a variant of the continuation phrase
- **Expanded cadential progression** — The ECP triggers the retrospective reinterpretation

# Key Properties
1. ECP supports entire 4-m. phrase (beginning at m. 5)
2. Symbol => means "becomes" (retrospective reinterpretation)
3. Both continuation AND cadential characteristics are present
4. Fragmentation, harmonic acceleration typically still found
5. Cadential function is prominent from the start of the phrase
6. Introduced by Janet Schmalfeldt
7. Analytical notation: ECP abbreviation replaces long bracket

# Construction / Recognition
## To Identify:
1. Check if a single cadential progression begins at m. 5 and extends to m. 8
2. If so, label as ECP
3. Check for continuation characteristics (fragmentation, acceleration) within the ECP
4. If both present: cont.=>cad.

# Context & Application
The notion of retrospective reinterpretation relates to form-functional fusion but is not identical to it. Fusion refers to two functions in the same grouping unit; retrospective reinterpretation concerns the dynamic listening process of changing one's interpretation. The => symbol is restricted to retrospective reinterpretation, not all fusion.

# Examples
**Example 1** (p. 84, Ex. 2.24): Haydn, Op. 42, i -- ECP from m. 5 with obvious fragmentation (two stages) and harmonic acceleration.

**Example 2** (p. 85, Ex. 2.25): Mozart, K. 464, ii -- ECP but limited fragmentation; new 2-m. idea repeated, with slight harmonic and surface-rhythm acceleration.

# Common Errors
- **Error**: Using cont.=>cad. for any continuation with a cadential progression
  **Correction**: Only applies when the ECP begins at m. 5 and supports the entire phrase

# Common Confusions
- **Confusion**: Confusing retrospective reinterpretation (=>) with all fusion
  **Clarification**: => specifically denotes changing interpretation as music unfolds; fusion is a broader concept
