# Quick Definition
Some main themes project an "introductory" character through hesitancy and instability, but they must not be confused with actual introductions. Despite textural, dynamic, and rhythmic instabilities, the main theme retains sufficient tonal, cadential, and phrase-structural solidity to function as the true formal beginning.

# Core Definition
The hesitancies and uncertainties projected by some exposition openings can lead to confusion about formal functions. A main theme may seem to possess an "introductory" character. However, such themes must not be confused with an actual introduction: despite textural, dynamic, and rhythmic instabilities, the main theme still contains sufficient **tonal, cadential, and phrase-structural solidity** to function as the true formal beginning of the exposition (Caplin, Ch. 10, p. 323).

# Key Properties
1. Main theme may have "introductory" character but is NOT an introduction
2. Distinguishing criterion: tonal, cadential, and phrase-structural solidity
3. A main theme establishes the home key, has cadential articulation, has clear phrase structure
4. An actual introduction may be harmonically unstable, lack full cadential closure
5. Main themes may also be preceded by genuine thematic or slow introductions
