# American Standard Pitch Notation (ASPN)

Key Takeaways

  * [pb_glossary id="4585"]American Standard Pitch Notation (ASPN)[/pb_glossary] provides labels for specific musical frequencies by combining a note name (such as C) with a subscript octave designation (such as 4).
  * A [pb_glossary id="2533"]pitch[/pb_glossary] is a discrete tone with an individual frequency (e.g. C4), while a [pb_glossary id="2535"]pitch class[/pb_glossary] is less specific (e.g., C in general).
  * ASPN differentiates between [pb_glossary id="2588"]octaves[/pb_glossary], from C to B. The octaves are labeled from lowest to highest, beginning with 0 and continuing in ascending numerical order (1, 2, etc.).
  * A piano keyboard primarily uses the ASPN octave designations 1 through 7, although small portions of octaves 0 and 8 are included.
  * [pb_glossary id="1363"]Middle C[/pb_glossary] is C4 in ASPN. It is helpful to memorize the ASPN label of this note as a starting point.



# American Standard Pitch Notation and Pitch versus Pitch Class

In order to discuss specific notes, or [pb_glossary id="2533"]pitches[/pb_glossary], we will use American Standard Pitch Notation, abbreviated [pb_glossary id="4585"]ASPN[/pb_glossary]. ASPN designates specific musical pitches by combining a note name (such as C) with a subscript [pb_glossary id="2588"]octave[/pb_glossary] designation (such as 4), creating a bipartite label (for example, C4). ASPN labels are very useful, since they can identify every possible musical note within human hearing range, from the lowest pitches to the highest. The [Reading Clefs](https://viva.pressbooks.pub/openmusictheory/chapter/clefs/) chapter introduced [pb_glossary id="3557"]octave equivalence[/pb_glossary], the concept that explains why notes one or more octaves apart have the same letter name. Music theorists distinguish between a pitch, a discrete tone with an individual frequency (e.g. C4 using ASPN), versus a [pb_glossary id="2535"]pitch class[/pb_glossary], which is less specific (e.g., C in general). A pitch class includes all the pitches with the same letter name, in any octave, along with their enharmonic equivalents. For example, all Cs are the same pitch class, and the enharmonically equivalent notes D𝄫 and B♯ are also part of the C pitch class. In this chapter we are naming specific pitches with ASPN. 

# ASPN and Octave Designations

ASPN differentiates between [pb_glossary id="2588"]octaves[/pb_glossary], beginning with the pitch C and ending with the pitch B. This means that each new octave designation begins on the note C, as seen in Example 1. The octaves are labeled from lowest to highest, beginning with 0 and continuing in numerical order (1, 2, 3, etc.). The pitch [pb_glossary id="1363"]middle C[/pb_glossary] is C4, which is useful to memorize. ASPN octave designations; each octave begins with the pitch C.[/caption]   All letter names within an octave (below the C of the next octave) receive the same octave designation. For example, all of the notes in Example 2 would be designated in the 4 octave, because they are above C4 but below C5. Accidentals applied to a note do not have an effect on its ASPN number. For example, B♯3 and C4 have different octave numbers despite being enharmonically equivalent, because the B♯ is still considered part of the lower octave. # ASPN and the Keyboard

ASPN labels are very helpful for finding specific notes on the piano keyboard. Example 3 depicts a piano keyboard with each octave labeled using ASPN notation. As you can see, the piano keyboard spans the full octaves 1 to 7. It also contains a small part of both octaves 0 and 8. ASPN labels are the same regardless of instrument or voice type. In other words, a C4 will always be labeled as such regardless of whether it is produced with a flute, trombone, violin, or voice.
